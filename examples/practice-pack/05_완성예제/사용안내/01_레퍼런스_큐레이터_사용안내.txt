이미지 수집·비교·무드보드

제품·레퍼런스 이미지 PNG/JPG/WebP를 여러 개 선택하세요. CSV에는 file,title,category,tags,source,rights 열을 씁니다. 파일명으로 이미지를 연결합니다.

기능:
이미지 드롭·폴더 수집
CSV 파일명 매칭
카테고리·태그 검색
선정 후보 표시
이미지 확대
메타데이터 편집
후보 2~4개 비교
선정 이유 기록
무드보드 이동
무드보드 크기·캡션
이미지 중복 확인
출처 누락 검사
무드보드 HTML
출처 CSV
이미지 포함 HTML 복원

첫 테스트 버튼은 초기 화면과 다른 프로젝트·자료를 로드합니다. 직접 수정한 자료가 있으면 교체 전 확인합니다. 이미지·영상은 HTML에 포함됩니다. 브라우저 저장 후 다른 PC로 옮기려면 현재 HTML을 저장하세요. 교육용 가정은 실제 업무에 맞게 검수하세요.
