# 새 가상 테스트 자산

정리일: 2026-10-08. 이 폴더의 SVG·PNG·WebM은 공개 실습용으로 새로 만든 도형 테스트 자료입니다. 실제 제품 사진, 수강생 제출 이미지, 촬영 영상, 고객 로고를 사용하지 않았습니다.

- `product_01`~`product_17`: 사각형·원·삼각형으로 만든 서로 다른 가상 제품 placeholder. 번호·색·위치·모서리 차이로 분류·중복·배치 기능을 시험합니다.
- `preview_0`~`preview_4`: 각 도구의 목적을 표시하는 가상 도형 안내 이미지. 실제 실행 화면 캡처가 아닙니다.
- `floor-plan`: 6개 구역을 표시한 가상 도면. 실제 건물 치수나 이동 경로를 나타내지 않습니다.
- `clip_0`~`clip_3`: canvas에서 움직이는 도형과 시간을 녹화한 무음 영상. 요청 길이는 각각 16·18·12·14초입니다. 브라우저 녹화 시점에 따라 실제 길이는 조금 달라질 수 있습니다.

생성 방법은 [generate-assets.cjs](generate-assets.cjs)에 있습니다. Node.js·Playwright·Chromium이 필요합니다. 사용할 Chrome 실행 파일을 `CHROME_PATH` 환경 변수로 지정할 수 있습니다. 스크립트는 새 SVG와 canvas만 사용하고 이전 사진·영상 파일을 읽지 않습니다. SVG를 렌더해 PNG를 만들고, canvas를 VP8 WebM으로 녹화합니다.

실습 HTML과 테스트 JSON에는 같은 자산의 data URI가 들어 있습니다. 테스트 자료의 기존 파일명은 불러오기 기능과의 호환을 위해 유지했습니다. 동일 내용의 중복 이미지도 의도적으로 남겨 중복 확인을 시험합니다. 실제 제품과 일치한다는 해석이나 촬영물의 사용 권리 확인에 이 자료를 이용하지 않습니다.

원본 외부 라이브러리와 글꼴의 라이선스는 이 자산의 설명과 별개입니다. 저장소의 제3자 고지를 확인하세요.
