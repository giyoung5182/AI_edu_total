# 교육용 견적 검수 기준 · v1 · 2026-10-07

ORBIT 가상 영상 캠페인. 프로님 사례의 업무 주제를 참고해 강사가 확장한 학습 예제이며 실제 제출물 복제가 아니다.

## 준비한 CSV

유형,항목,수량,단가,개월,참여율,근거 순서. 인건비·외주·경비만 사용한다.

수량·단가는 0보다 커야 한다. 인건비의 개월은 0보다 커야 하고 참여율은 0보다 크고 1 이하다.

외주·경비의 개월·참여율은 계산에 쓰지 않지만 호환 입력에는 1을 적는다.

근거는 빈칸일 수 없다. 값이 있다고 실제 증빙이 확보됐다는 뜻은 아니다.

동일 유형·항목은 중복 의심으로 보류한다. 실제로 별도 작업이면 승인 후 항목명을 구분한다.

## 교육용 계산

인건비 = 수량×단가×개월×참여율. 외주·경비 = 수량×단가.

관리비=직접비의 10%, 할인=0원, 부가세=공급가의 10%.

청구 합계 예산은 13,000,000원. 모든 요율·금액은 교육용 가정이다.

오류가 있으면 계산 가능한 행의 금액만 참고로 표시하고 전체 견적은 확정하지 않는다.

## 정상 샘플의 대조값

기획·PM 4,000,000 / 촬영 3,000,000 / 편집 3,000,000 / 이동비 500,000원.

직접비 10,500,000 → 관리비 1,050,000 → 공급가 11,550,000 → 부가세 1,155,000 → 합계 12,705,000원.

## 오류 샘플의 담당자 수정 지시

기획·PM 참여율 1.2는 입력 실수이므로 0.5로 수정한다.

촬영 근거는 '가상 촬영 견적'으로 확인했다.

두 번째 편집 행은 복사 실수이므로 수정본에서 제외한다. 원본은 유지한다.

이동비 수량 -5는 입력 실수이므로 5로 수정한다.

이 지시는 교육용 시나리오다. 실무에서는 이렇게 사람이 확정한 수정값을 받은 뒤 바꾼다.
