## Claude Code에서 이 폴더를 쓰는 방법

- 이 폴더를 작업 프로젝트로 연다. 위 가져오기 줄은 공통 규칙을 중복 작성하지 않기 위한 것이다.

- 캠페인 견적 검토에는 campaign-estimate-review 스킬을 사용한다.

- 숫자를 수정한 뒤 estimate-reviewer에게 원본·수정본·기준을 독립 대조하도록 요청한다.

- 처음부터 결과 예시를 정답처럼 베끼지 않는다. input/에서 직접 판단하고 output/ 예시는 마지막에 비교한다.

- Python이 실행되는 환경이라면 checks/check_estimate.py를 실행한다. 실행할 수 없으면 이유를 밝히고 계산표를 수동 대조한다.



## 지침 적용 확인

대화 시작 때 읽은 규칙과 기준 파일 이름을 짧게 알려준다. 파일이 있다는 사실만으로 적용 성공이라 하지 않는다.

웹 채팅에서는 이 파일이 자동 적용된다고 가정하지 않는다. 원본·기준·지침을 직접 첨부하고 적용해 달라고 요청한다.
