# 캠페인 견적 검수 작업폴더

2026-10-07 · 교육 프로젝트 교육용 가상 업무 · 파일 그대로 압축 해제해서 사용

1. 00_시작.html을 연다. 구조 설명과 요청문, 규칙 검사 체험을 먼저 본다.

2. tools/01_견적검토_완성예제.html을 연다. 이 폴더의 정상 견적이 이미 들어 있다.

3. Claude Code에서 이 폴더를 작업 프로젝트로 선택하고 requests/01_첫작업.txt를 보낸다.

4. 문제가 보이면 requests/02_수정후재검사.txt로 담당자가 확인한 값만 수정한다.

웹/Cowork에서 .claude/agents와 파일 자동 적용을 보장하지 않는다. 웹에서는 원본·기준·규칙을 직접 첨부해 지시한다.

.claude는 숨김 폴더처럼 보일 수 있다. 이 안의 스킬과 담당자 파일도 함께 전달해야 한다.

AGENTS.md는 공통 규칙이다. 담당자 파일은 .claude/agents/ 안에 별도로 있다.

CLAUDE.md는 프로젝트 지침이며 서비스의 상위 시스템 프롬프트를 바꾸는 파일이 아니다.

Python 검사는 선택 사항이다. 실행 환경이 없다면 시작 HTML의 규칙 체험과 도구 계산으로 대조한다.

HTML 계산기는 AI 분석을 호출하지 않는다. 자료의 의미와 근거를 먼저 AI에게 검토시키는 사례다.

모든 샘플은 가상이며 사내 단가·승인·보안 정책의 실제 적용을 보장하지 않는다.
