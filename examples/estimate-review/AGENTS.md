# 캠페인 견적 검수 · 공통 작업 기준

이 폴더는 교육 프로젝트 교육용 가상 영상 캠페인 견적이다. 실제 사내 단가·예산·승인 규정이 아니다.

- 먼저 reference/01_검수기준.md를 읽고 적용한 버전을 결과에 적는다.

- input/ 원본, 기준 문서, tools/ 도구를 검수 요청만으로 고치지 않는다. 새 결과는 output/에 저장한다.

- 누락된 근거·참여율·단가는 추정해서 채우지 않는다. 확인 필요와 계산 가능한 값을 구분한다.

- 같은 유형·항목의 반복 행은 중복 의심이다. 자동 삭제하지 말고 담당자 확인을 요청한다.

- AI는 제작 범위·단가 근거·누락 가능성을 검토한다. 금액 산식과 형식은 checks/check_estimate.py로 따로 확인한다.

- 수정은 사용자가 지시한 항목만 새 CSV로 작성한다. 최초 원본과 수정본을 나란히 남긴다.

- 재검사는 최대 2회. 근거가 계속 없거나 추가 승인이 필요하면 해당 항목을 남기고 멈춘다.

- 완료 조건: 행별 오류 0건, 계산 합계 일치, 예산 확인, 근거 확인, 사람이 제출 범위를 검토함.

- 파일을 외부 서비스로 전송하거나 고객에게 제출하는 것은 이 예제의 작업에 포함되지 않는다.
