# 캠페인 견적을 자료부터 검토하기

1. 요청한 CSV와 reference/01_검수기준.md를 읽는다. 원본 행 수·필드·기준 버전을 기록한다.

2. 유형·항목·숫자·근거를 확인한다. 인건비는 수량×단가×개월×참여율, 외주·경비는 수량×단가다.

3. 범위 누락, 단가의 증빙 필요, 일정과 인력의 타당성을 설명한다. 파일에 없는 상식으로 회사 정책을 만들어내지 않는다.

4. checks/check_estimate.py의 실행 결과 또는 수동 계산과 대조한다. 오류가 있는 행을 청구 합계에 확정 반영하지 않는다.

5. output/에 행 번호·문제·근거 위치·조치·담당자 확인 항목이 담긴 검토 Markdown을 만든다.

6. 사용자가 수정값을 주면 원본을 보존하고 새 CSV를 만든다. estimate-reviewer에게 독립 대조를 요청한다.

7. 기준을 통과하면 다음 작업으로 넘긴다. 최대 2회 재검사 후 미해결 문제는 memory/에 남기고 멈춘다.

## 결과에 꼭 남길 것

적용 기준, 검사한 파일·행 수, 오류/확인 필요, 계산 결과, 제외된 행, 사람이 결정할 사항.
