# 사용자의 실제 요구에서 얻은 인사이트

정리일 2026-10-08 · 이 채팅에 제공된 사용자 작성 메시지의 의미 재서술. 이름·시각·원문 대화는 공개하지 않습니다.

요구: 대화를 프로젝트와 폴더로 묶고, 각 대화에서 실제 작성 프롬프트와 주요 사례를 추출해 다음 교육자료의 에셋으로 만들고 싶다.

인사이트: 대화 요약만으로는 수업 재료가 완성되지 않습니다. 재사용하려면 목표·입력·결정·요청문·실제 결과·검수 조건이 연결돼야 합니다. 사용자 작성 요청과 AI가 제안한 요청을 구분해야 작성 주체가 보존됩니다.

에셋으로 전환한 것: 프로젝트 지도 CSV, 대화목록 CSV, 프롬프트 카드, 사례 카드, 실습 카드, 가상 카드뉴스 프로젝트.

확인 수준: 실제 사용자 요구 확인 / 자료 구조 설계. 전체 개인 대화의 수집·프로젝트 이동·분류와 사례 실행은 이 작업에서 수행하지 않았습니다.
