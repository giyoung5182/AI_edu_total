# 가상 프로젝트: 근거를 보존한 카드뉴스 5장

새 작성 교육 실습 설계 · 실행 미확인. 외부 PDF·엑셀 원문의 복제나 실제 제출물 성공 사례가 아닙니다.

가상의 동네 도서관 행사 CSV가 준비됐다면 이를 카드별 문안과 검수표로 바꿉니다. 카드뉴스 이미지를 자동 생성하는 도구는 포함하지 않습니다.

```csv
event_id,title,date,time,venue,capacity,fee,source_id
E001,가상 AI 읽기 모임,2026-11-01,14:00,가상 배움도서관,20,무료,S001
```

## 요청문

```text
이 CSV 한 행을 근거로 5장 카드뉴스 문안을 작성하세요.
1장은 행사명과 대상, 2장은 일시·장소, 3장은 프로그램,
4장은 준비물, 5장은 신청 방법을 넣으세요.
CSV에 없는 프로그램·준비물·신청 주소는 미제공으로 표시하세요.
각 카드에 source_id와 검수 항목을 붙이고,
헤드라인은 20자 이내, 본문은 60자 이내로 제안하세요.
없는 정보를 채운 완성본 대신 확인 필요 목록을 함께 주세요.
```

기대결과: 행사명·날짜·시간·장소·정원·비용은 입력과 일치하고, 없는 정보는 미제공으로 표시됩니다. 문자 수 기준은 공백·문장부호 포함입니다. 실제 실행에서 길이·누락 표시를 다시 검사해야 합니다.

오류 시험: date를 빈칸으로 바꾸면 날짜를 추정하지 않아야 합니다. capacity에 음수를 넣으면 검수표에 오류가 표시돼야 합니다.

확장: 문안을 승인한 뒤 가상 이미지와 고정 레이아웃에 배치합니다. 저장한 이미지·PDF를 다시 열어 줄바꿈·글자 잘림·출처·날짜를 검사합니다. PPT 확장은 편집 가능한 요소와 이미지 요소를 구분해 확인합니다.
