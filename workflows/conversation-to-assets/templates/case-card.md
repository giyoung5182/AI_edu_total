# 사례 카드

- ID / 프로젝트 / 실제 사례 또는 가상 실습:
- 근거 위치(내부용) / 공개 근거 / 입력·출력 버전:
- 해결하려던 문제 / 이전 작업 방식:

## 진행과 결정

준비 파일 → 실제 요청 → 첫 결과 → 발견한 문제 → 수정 요청 → 다음 결과를 기록합니다. 중간 결과가 없으면 생략 이유를 적습니다.

## 확인한 것

| 항목 | 확인 방법 | 실제 결과 | 확인 수준 |
|---|---|---|---|
| 파일 수신 | 파일 존재·형식 | | |
| 텍스트 추출/OCR | 원문 표본 대조 | | |
| 규칙 계산/비교 | 기대값 대조 | | |
| AI 의미 해석 | 판단 근거 검토 | | |
| 저장·재열기 | 저장 파일 다시 열기 | | |

## 교육으로 바꿀 때

가상 준비물 / 익명화·수치 교체 / 실제 요청문 / 정상 기대결과 / 오류 입력 / 검수 기준 / 미확인 한계. 측정하지 않은 시간절감·성능 향상은 넣지 않습니다.
