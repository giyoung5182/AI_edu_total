# 수업용 실습 에셋

- 대상 / 선수지식 / 목적 / 실습 ID / 버전:
- 준비물: 입력 파일·도구·이용 조건·가상 데이터 표시
- 근거: 원 사례 또는 설계 출처·확인일·권리

## 해볼 일

1. 준비 파일을 열고 필수 필드·누락·단위를 확인합니다.
2. 아래 요청문을 목적·규칙·출력에 맞게 채워 실행합니다.
3. 결과를 저장하고 다시 열어 기대값과 비교합니다.
4. 오류 입력을 하나 넣고 실패를 어떻게 표시하는지 확인합니다.

```text
이 입력으로 [결과]를 만들어 주세요. [규칙]을 적용하세요.
값이 없거나 근거가 부족하면 임의로 채우지 말고 표시하세요.
결과와 함께 검사한 항목·수정한 항목·미확인 항목을 작성하세요.
```

## 결과 확인

정상 기대결과 / 오류 기대결과 / 계산·사실·형식 기준 / 저장·재열기 기록.

## 강사용 메모

흔한 실패 / 질문할 지점 / 난이도 확장 / 제품·계정별 차이 / 다음 교육에 바꿀 입력.
