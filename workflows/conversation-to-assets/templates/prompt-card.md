# 프롬프트 카드

- ID / 프로젝트 / 제목:
- 작성 주체: 실제 사용자 / AI 제안 / 새 작성 교육예시 중 선택
- 표현: 원문 / 익명화 편집 / 의미 재서술
- 비공개 근거: 대화 ID·메시지 위치·파일 버전
- 공개 범위 / 작성일 / 편집일:
- 목표 / 준비할 입력 / 사용할 환경:

## 재사용 요청문

```text
[목표] 무엇을 만들거나 결정할지
[입력] 제공한 파일과 각 필드의 의미
[규칙] 반드시 지킬 조건, 바꿔도 되는 범위
[출력] 파일형식·구조·분량
[검수] 사실·계산·형식의 통과 기준
[불명확] 추측 대신 표시하고 질문할 항목
```

## 왜 유용한가

대화에서 확인된 선택·수정·반복 이유를 적습니다. 성공했다고 느낀 이유와 실제 검증 결과를 구분합니다.

## 결과와 한계

입력 버전 / 결과 파일 / 검증 방법 / 확인 수준 / 실패 조건 / 다른 업무로 바꿀 빈칸.
