# 질문 없이 공개 지식 대시보드 만들기

Python 표준 라이브러리만 사용합니다. 별도 API 키·서버·패키지 설치가 필요 없습니다.

```sh
python build_dashboard.py
```

실행 후 `index.html`을 브라우저에서 엽니다. 입력 데이터는 `../../knowledge/cards.json`이며 카드 문서와 주차 기록도 재생성합니다. 정리된 지식·정정·활용은 그대로 유지하고 질문자와 대화 원문은 데이터에 포함하지 않습니다. 검색·주제·원본 상태·주차 필터로 원하는 카드를 고른 뒤 “지식·활용·근거 보기”를 펼칩니다.

데이터를 추가할 때 `id`는 중복 없이 부여하고, `first_date`·`last_date`는 ISO 날짜, `weeks`는 ISO 주차로 기록합니다. `checked_on`은 실제 확인한 날짜만 씁니다. `status`는 공식확인·부분확인·커뮤니티경험·정정·미확인 중 하나를 사용하고, 공식확인에는 공식 링크, 정정에는 정정 본문이 필요합니다. `evidence_note`에 확인 범위와 한계를 남깁니다. 질문 원문·개인 이름·대화 링크를 새로 넣지 않습니다.

생성기는 질문 필드가 들어온 데이터와 중복 ID·날짜 오류·근거 누락을 거절합니다. 개인정보의 완전 자동 판별기는 아니므로 새 데이터는 사람이 검토해야 합니다. 공식 링크 검사는 URL 형식만 검사하며 내용의 최신성이나 링크 도달 성공을 보장하지 않습니다.
