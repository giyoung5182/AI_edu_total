# 공식 명령 28개: 기능별 한국어 메모

2026-10-08 [공식 원문](https://learn.chatgpt.com/docs/reference/slash-commands)을 직접 읽고 짧게 재서술했습니다. 현재 앱 환경·권한에 따라 보이는 명령은 다릅니다. 이 목록을 저장해도 새 기능이나 권한이 설치되지 않습니다.

| 명령 | 하는 일 |
|---|---|
| /approve | 자동 심사 거절의 재시도 승인 |
| /archive | 현재 채팅 보관 |
| /chat | 프로젝트 없는 채팅 선택 |
| /cloud | 클라우드 실행 선택 |
| /cloud-environment | 클라우드 환경 선택 |
| /compact | 현재 맥락 압축 |
| /fast | 제공되는 빠른 서비스 설정 |
| /feedback | 피드백 보내기 화면 |
| /fork | 채팅 복사 |
| /goal | 지속 목표 설정 |
| /ide-context | IDE 맥락 공유 설정 |
| /init | 프로젝트 AGENTS 초안 생성 |
| /local | 로컬 프로젝트 실행 |
| /mcp | 연결 서버 상태 |

`/`를 입력해 실제 메뉴를 확인합니다. 스킬은 `$`로도 호출하고, 활성 스킬과 사용자 프롬프트(`/prompts:이름`)는 메뉴에 추가될 수 있습니다. 일반 요청 별칭과 공식 동작은 [구분 안내](../../methods/slash-commands-and-prompt-labels.md)를 따릅니다. 위 명령은 이번 정리 작업에서 실행하지 않았습니다.
