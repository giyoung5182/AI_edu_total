# 한국어 문체 다듬기 원문과 스킬 메모

2026-10-08 기존 Chrome 세션에서 [노션 원문](https://app.notion.com/p/3c6fd99f0e5f8185ba9fcf4beafa7367)을 직접 읽었습니다. 본문 기준일2026-08-24, README v2.3.2 기준으로 소개하며70패턴을 언급합니다. 현재 원 저장소는 같은 버전 표기에서10범주85패턴(hold1포함)을 안내합니다. 소개문 숫자와 현재 소스 숫자를 같은 값으로 합치지 않습니다.

유용한 절차는 진단할 문체 문제를 고르고, 해당 구간을 제한적으로 수정한 뒤 원문의 의미와 변경 범위를 대조하는 것입니다. 번역투·기계적 병렬·상투구·피동·접속사·일률적 리듬 등을 다루지만 지표만으로 AI 작성 여부를 확정하지 않습니다.

노션의 Codex 단일 호출 설명과 현재 원 Codex 스킬의 light·standard·heavy3경로도 다릅니다. 입력 상태와 필요한 검토에 따라 경로를 고릅니다. 호출 수를 줄이는 구조를 읽는 것과 실제 토큰 절감 측정은 별개입니다. 숫자·고유명사·인용·주장 강도·인과관계를 [검수 절차](../../methods/writing-style-review-workflow.md)로 대조하세요.

[MIT 원문·지원 코드·지역 패키징](../../vendor/korean-writing-review/README.md)을 보존했습니다. 현재 앱에 전역 설치·활성화하거나 글을 실제 윤문한 결과가 아닙니다. 설치 명령·모델 설정·다중 에이전트 안내는 참고 원문입니다.
