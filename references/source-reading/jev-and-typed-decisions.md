# Jev 글과 공식 문서를 직접 읽은 메모

2026-10-08 · [공유 글](https://seo2-heimish.tistory.com/20) · [공식 질문 규격](https://docs.typesafe.ai/primitives) · [시작 문서](https://docs.typesafe.ai/introduction/quickstart) · [원문 소스](../../vendor/jev-ultrafast/README.md).

공유 글은 카드뉴스 제작법이 아니라 분류·판단 담당을 기존 생성 AI와 나누는 활용 글입니다. 논문·메일·게임·브라우저 사례를 다루지만 시간과 비용은 외부 제작자의 보고입니다. 요약에 원문 URL을 남기고, 주제 분류와 이용 가능 여부·실제 결과 유무를 별도로 판단하는 흐름이 교육에 유용합니다.

공식 문서의 질문 유형은 Choice(선택지), Score(정의한 수준), Noul(예/아니오 확률)입니다. Noul0.5를 중간 실력이나 확정 판단으로 해석하지 않습니다. 같은 상태를 보는 독립 질문은 한 요청으로 묶고, 이전 결과가 있어야 다음 입력을 만들 수 있을 때만 요청을 나눕니다. 확률·confidence와 사람에게 넘길 기준을 함께 설계합니다.

공개 코드에서는 관찰한 DOM 요소에 번호를 붙이고 행동과 대상을 고릅니다. 텍스트 입력은 별도 보조 모델이 담당합니다. 실행 전 상태와 대상을 다시 확인하고, 완료 응답 뒤에도 실제 결과를 검수합니다. [가상 자료 분류 실습](../../methods/source-classification-workflow.md)부터 시작하세요.

확인: 문서·코드·라이선스. 미확인: 실제 API·계정 승인·실행 속도·비용·전체 브라우저 동작.
