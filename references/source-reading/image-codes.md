# 이미지 비밀코드100 원문 메모

2026-10-08 기존 Chrome 세션에서 [노션 원문](https://app.notion.com/p/3c5fd99f0e5f8108a4ccfd3f5fa0bea3)을 직접 읽었습니다. 번호1~100의 표는10범주에 각각10개로 구성됩니다.100개 모두 용도·긴 기본 생성문·재첨부 편집문·입력 예시를 읽었고, 스크롤 경계 누락은 다시 확인했습니다. [읽기 범위](reading-status.json)를 기록했습니다.

원문은 이 이름들을 공식 내장 명령이나 숨은 권한으로 설명하지 않습니다. 사진이나 목표에 원하는 표현을 붙이는 사용자 프롬프트입니다. 코드 이름만 저장하기보다 대상·유지할 특징·바꿀 요소·출력·검수 기준을 명시한 요청문으로 보관해야 재사용하기 쉽습니다.

시작은 목적에 맞는 후보 몇 개를 골라 하나씩 비교하는 방식입니다. 구조 표현·광고·시각 스타일을 실제 제품 사양·실제 사건의 증거로 사용하지 않습니다. 원문이 제시하는 기본 생성과 후속 편집도 분리하고, 입력과 수정 내용을 기록합니다.

상세 지침에서도 마모는 보이는 흔적만 다루고, 실측치가 없으면 치수 숫자를 넣지 않으며, 열상은 개념 시각화라고 표시하도록 합니다. 이런 그림은 내부 검사·온도·시선 집중도의 실제 측정 결과가 아닙니다. 음식 시안에 입력에 없는 장식·증기가 추가될 수 있어 실제 메뉴 사진의 증거로도 쓰지 않습니다.

일부 예시 캡션은 프롬프트 대상과 불일치합니다.22번 스마트폰/카메라,23번 엔진/여객기,31번 전동드릴/손목시계를 구분해 읽어야 합니다. 새 입력으로 결과를 재현하고 검수한 사례로 분류하지 않았습니다.
