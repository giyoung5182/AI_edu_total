# 노션 교육자료 수집·공개 편집 범위

정리일: 2026-10-08. 소유자의 요청으로 연결된 노션 교육자료를 읽고 별도 공개 편집본을 만들었습니다. 노션 원문은 수정하지 않았습니다.

## 확인한 범위

- 교육 프로젝트의 고객사별 자료 목록 39행에서 교육자료 57개의 원문 링크와 하위 페이지·하위 DB를 따라갔습니다.
- 프롬프트·GEMS·스킬 및 AI 활용 콘텐츠 목록 22개와 개인 자료 안의 AI 스터디 2개를 추가했습니다. Skills DB 입구는 문서 본문과 구분하고, 연결된 스킬 4개의 속성과 페이지를 확인했습니다.
- 실습 910개는 속성 요약과 별개로 910개의 상세 본문을 모두 수집하고 저장 파일을 다시 읽어 고유 ID·누락·중복을 대조했습니다.
- 개념 사전 418행, 표준 모듈 31행, 표준 용어 13행, 개념 카드 19행, 실습 속성 910행, 설명 이미지 속성 970행을 DB COUNT와 대조했습니다. SQL의 LIMIT/OFFSET을 끝까지 조회했으며 응답의 has_more만으로 전수 여부를 판정하지 않았습니다.
- 모듈·용어·개념 카드 63개는 별도 페이지 본문이 비어 있고 지식이 속성에 있음을 확인했습니다. JSON 목록은 그 속성을 편집한 자료입니다.

## 공개용으로 편집한 내용

[교육자료 입구](../knowledge/notion-education/README.md)에서 교안·가이드와 상세 실습을 찾을 수 있습니다. [프로젝트별 목록](../knowledge/notion-education/projects.md)은 교육자료 57개와 추가 활용 자료의 시작점을 연결합니다. [프롬프트 모음](../knowledge/notion-education/prompts.json)은 원문에 있는 긴 요청문을 중복 바이트 기준으로 묶은 공개 편집본입니다. 모든 요청문이 작성자의 실제 실행 사례라는 뜻은 아닙니다.

고객·수강생·담당자 실명, 연락처·이메일·차량번호, 계정·출석·설문·초대 링크와 특정 회사의 수주 이력은 제거하거나 일반적인 입력 칸으로 바꿨습니다. 계정 안내 및 개별 업무·성장 분석 페이지 14개는 공개에서 제외했습니다. 실제 개인 대조표와 원문 URL은 비공개 기록으로 관리합니다.

## 첨부·검증 한계

설명 이미지 970행은 제목·캡션·모듈 연결 정보입니다. **이미지 파일 970장을 내려받아 확인한 결과가 아닙니다.** 원문에 설명이 없던 항목의 설명을 새로 만들어 채우지 않았습니다.

14개 원문 페이지는 미지원 블록을 보고합니다. 해당 블록을 추가 조회했으나 대다수는 첨부·외부 객체이며 파일 내용은 복원되지 않았습니다. 제목 없는 블록은 유형을 확정하지 않았습니다. 원문의 잘림 표식을 보존하고 해당 문서는 부분 수집으로 표시했습니다. 그 밖에 응답에 상태가 없는 경우 완전성을 확정한 것으로 간주하지 않습니다.

원본 PDF·XLSX·이미지·영상·글꼴, 다른 강사의 첨부 교안, 외부 링크의 문서는 자동 복제하지 않았습니다. 교육 이력 장부, 개인 일정·철학·업무 관리, 회사 조직 기록은 교육자료 공개 범위에 넣지 않았습니다.

이 작업은 본문 수집·익명화·정적 연결 확인입니다. 원문이 설명하는 현재 요금·화면·성능을 새로 검증하거나, 도구를 설치·실행하거나, 외부 AI API를 호출하지 않았습니다. HTML 검색 목록은 저장소를 내려받아 브라우저에서 열어 사용하세요.
