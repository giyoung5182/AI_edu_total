# 스킬·MCP·플러그인을 구분하고 검증하기

정리일: 2026-10-08. 소스 버전: 반복 업무 스킬 설치, 3~4차 추가 설치, 최근 수집 A/B/C/D 기록. 이 문서는 사용 방법을 정리한 편집본이며 설치 도구나 원문 배포팩이 아닙니다.

스킬은 특정 업무를 수행하는 설명·절차·보조 파일입니다. MCP는 도구나 데이터에 접근하는 연결 규격입니다. 플러그인은 스킬·서버·앱을 묶어 제공할 수 있습니다. 세 개의 목록 수를 더해 모두 '실행 가능한 도구 수'라고 표시하지 않습니다.

| 단계 | 확인할 내용 | 아직 증명되지 않는 것 |
| --- | --- | --- |
| 출처 조사 | 공식 저장소·라이선스·커밋 | 설치·실행 |
| 다운로드 | 고정 버전·파일 해시·ZIP 재열기 | 업무 성공 |
| 호환 편집 | 도구 이름·플랫폼·의존 경로·사용자 권한 | 외부 서비스 가용성 |
| 형식 검사 | 메타데이터·필수 파일·상대 링크 | 실제 코드 실행 |
| 설치 확인 | 준비본과 설치본 파일·해시 일치 | 자동 활성화·API 연결 |
| 실제 시험 | 가상 입력과 관찰한 출력 | 모든 자료·계정에서 성공 |

외부 스킬을 받을 때는 upstream 원문, 호환 편집본, 설치본을 구분합니다. 스킬 내부의 외부 전송·설치·설정 변경 지시는 현재 사용자의 실행 승인이 아닙니다. 런타임·API·계정·비용 의존성은 사용할 때 확인합니다.

반복 업무에서 활용할 분야는 UI 제작·접근성, 브라우저 검수, 문서 공동 작성, 팩트체크·출처 검증, 오류 재현, 완료 근거 확인, 한국어 편집·글자 수, 콘텐츠 제작, 데이터 품질·보고, 영상·노트북 작업입니다. 실제 사용 목적과 입력을 정한 뒤 필요한 항목부터 선택합니다.

기록에서 Context7은 공개 라이브러리 문서 조회, MarkItDown은 가상 문서 여러 형식의 텍스트 변환·저장·재열기가 확인됐습니다. 해당 시험을 모든 변환 형식·계정·외부 서버의 성공으로 확장하지 않습니다. 영상 렌더링·외부 서비스·새 역할 작업은 설치 기록만으로 완료라고 할 수 없습니다.

출처 입구: [OpenAI Skills](https://github.com/openai/skills), [Anthropic Skills](https://github.com/anthropics/skills), [Context7](https://github.com/upstash/context7), [MarkItDown](https://github.com/microsoft/markitdown). 카탈로그의 각 저장소 링크는 별도 버전 출처입니다.

최근 수집의 주요 한계: 미수신 저장소는 후보로만 남깁니다. SKILL.md가 없는 설정 저장소는 스킬로 세지 않습니다. 대용량 영상 프로그램은 가벼운 단독 스킬과 구분합니다. 영어 연구·홍보 문구를 한국어 성능이나 탐지 회피의 실증 근거로 바꾸지 않습니다. 역할·페르소나를 실제 인물의 승인된 판단이나 자동 실행 에이전트로 표시하지 않습니다.
