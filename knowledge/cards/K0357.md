## 정리된 지식

- Microsoft 공식 문서: 원격 데스크톱 호스트(접속을 받는 PC)는 Windows Pro·Enterprise·Education·Server 에디션만 가능
- Windows Home 에디션은 호스트가 될 수 없고 다른 PC에 접속하는 클라이언트로만 사용 가능
- 특수문자·Shift 문제의 원인(키보드 레이아웃·IME)과 왼쪽 Shift 우회는 커뮤니티 경험

## 교육과 업무에 활용

- 원격 작업 환경 구축 전 호스트 PC의 Windows 에디션부터 확인
- 키 입력 문제는 원격 도구 교체가 가장 빠른 해결책인 경우가 많음
