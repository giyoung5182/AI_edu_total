## 정리된 지식

- OpenAI 공식 소개: GPT-6.1 Sol은 'Astra에 근접한 지능을 Astra 표준 토큰 가격의 5분의 1로' 제공(DevDay 2026, 2026-09-29)
- API 가격(100만 토큰당): 입력 $2·캐시 입력 $0.10·출력 $10, 모델명 gpt-6.1-sol (Astra 표준 $10/$50)
- ChatGPT에서는 Plus·Pro·Business·Enterprise·Edu의 Work와 Codex에서 제공, Chat에는 아직 미제공. 릴리스 노트상 순차 배포라 시점·기기별로 모델 목록이 다를 수 있음
- 함께 발표된 Ultrafast: Codex에서 최대 8배·API 최대 6배 빠른 생성(별도 카드)
- Codex fast 모드는 구독 한도 기준 Standard의 2.5배 소모 — 속도 옵션이 켜져 있으면 같은 작업도 한도가 빨리 줄어듦
- 미확인: 출시 초기 속도 저하 사과와 10/2 유료 계정 일괄 리셋은 Codex 총괄(Tibo)의 X 게시글 기준, '리셋량 절반'·'사용량 사전 축소 반영'은 공식 근거 없음
- [추가 2026-09-29] - 공식 소개 글 보강: OSWorld 2.0(최대 추론 강도)에서 GPT-6.1 Sol과 Astra의 차이 2.1%p, 작업당 비용은 Astra의 약 7분의 1. 캐시 입력($0.10)은 표준 입력가보다 95% 낮음

## 교육과 업무에 활용

- 신모델 발표 직후 '안 보임'은 대부분 순차 배포·클라이언트 버전 문제 — 앱·CLI 업데이트부터
- 발표일 ≠ 전원 사용 가능일, 모델 버전 숫자 ≠ 성능 순위
- 대량 반복 작업은 신모델 출시 때마다 같은 과제로 비용 대비 품질 재측정
- 한도 소모가 급증하면 fast 모드 여부·병렬 작업의 중복 입력부터 점검
