## 정리된 지식

- Claude Code 공식 시스템 요구사항은 4GB 이상 RAM, x64 또는 ARM64 프로세서, 인터넷 연결이며 GPU 요구사항은 없음. Claude Desktop은 macOS 11·Windows 10 이상, Linux의 Cowork 작업공간은 여유 디스크 약 25GB와 RAM 8GB 이상을 요구. API로 호출하는 이미지·영상 생성은 제공사 서버에서 연산되므로 로컬 GPU가 쓰이지 않음. 병렬 에이전트·브라우저 다중 실행 시 16~32GB 권장은 커뮤니티 체감이며 공식 권장값은 아님. 맥 모니터 관련 답은 사용 경험.
- [추가 2026-09-11] 9/11 커뮤니티: 원격 지시로 computer use를 돌리는 홈서버 용도면 결과물은 프로세서와 무관하고 차이는 OS 최적화·속도·전력, Mac 안에서는 애플 실리콘이 인텔맥보다 효율 우위라는 의견(체감).

## 교육과 업무에 활용

비개발자 수강생 장비 안내 시 '로컬 모델을 돌리지 않으면 GPU 투자 불필요, RAM 우선'으로 정리. 최소 사양(공식)과 쾌적 사양(체감)을 구분해 제시.
