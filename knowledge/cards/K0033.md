## 정리된 지식

Anthropic 마이그레이션 문서: Claude Opus 4.7 이후 모델(Opus 5.5 포함)에서 temperature·top_p·top_k를 기본값이 아닌 값으로 지정하면 400 오류, Python SDK v1.0 이상은 해당 파라미터를 정의하지 않음. 동작 제어는 프롬프트로 하도록 권장. Opus 5.5에서는 effort가 사고 깊이를 제어하는 유일한 요청 파라미터이며 기본값 medium. OpenAI 추론 가이드도 effort 값(none·minimal·low·medium·high·xhigh·max, 모델별 상이)으로 속도·토큰 사용과 품질을 조절한다고 설명. MoE 구조 때문이라는 공식 설명은 찾지 못함.

## 교육과 업무에 활용

API 교육에서 '온도 조절' 예제가 최신 모델에서는 오류가 날 수 있음을 안내하고, effort·프롬프트 중심 제어로 교안 업데이트 필요.
