## 정리된 지식

- 공식 문서: VS Code 확장은 채팅 패널용 CLI 사본을 내장하며, 통합 터미널에서 claude를 쓰려면 별도 CLI 설치 필요
- 명령·스킬은 CLI는 전체, 확장은 일부만 지원. '!' Bash 단축과 탭 완성은 CLI 전용, MCP 설정과 체크포인트는 양쪽 지원
- ~/.claude/settings.json 설정은 확장과 CLI가 공유
- 확장은 플랜 검토·편집, 인라인 diff, 대화 기록 탭 등 그래픽 기능 제공

## 교육과 업무에 활용

- 입문자는 확장으로 시작, CLI 전용 명령이 필요할 때 통합 터미널 병행
- '성능 차이'가 아니라 '지원 명령 범위·편의성 차이'로 설명
- 설정 파일 공유 구조를 알려 두 환경 설정 충돌 방지
