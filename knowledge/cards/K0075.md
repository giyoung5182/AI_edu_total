## 정리된 지식

- openai/codex 공식 이슈에 Windows 콘솔 깜빡임이 다수 등록됨: #48059(CLI 0.157.0에서 터미널 창 반복 팝업, codex.exe가 띄운 app-server 데몬이 powershell·conhost를 보이는 창으로 실행), #48540(0.157.1 업데이트 후 셸 명령마다 깜빡임), #48859(창이 포커스를 빼앗아 입력 방해)
- #48059 보고자들이 확인한 우회책: 0.155.0 또는 0.156.0으로 다운그레이드, codex --no-daemon 실행 시 감소. 공식 수정 버전은 확인되지 않음
- 앱 로딩 멈춤도 공식 이슈 다수: 26.924.x 업데이트 후 기존·새 채팅이 로딩에서 멈추고 26.917.71314로 롤백하면 해결(#48535, #48345 — 둘 다 Linux 데스크톱 보고), Windows 데스크톱 업데이트 후 로딩 화면 고정(#48655, 롤백 해결 여부는 기록 없음)
- [추가 2026-09-08] 9/8 VS Code용 Codex 확장이 무한 로딩되는 증상을 버전 다운그레이드로 해결했다는 사례 추가(이전 버전 롤백 우회책과 일치).

## 교육과 업무에 활용

- 업데이트 직후 이상 증상은 해당 버전의 공식 이슈 검색 → 롤백을 1차 대응으로 안내
- 교육장 PC는 강의 직전 도구 자동 업데이트를 피하는 운영 원칙 필요

## 정정과 한계

'컴퓨터 권한을 주고 모니터링시키기'는 원인 해결책이 아님. 공식 이슈상 특정 버전(0.157.x, 앱 26.924.x)의 회귀 버그이며, 확인된 우회책은 이전 버전 롤백. '업데이트 권장'은 오히려 문제 버전으로 올라갈 수 있어 주의 필요.
