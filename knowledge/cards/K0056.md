## 정리된 지식

- Claude 고객센터: Claude는 이미지 생성 도구처럼 사진·일러스트를 만들지 않음. 대신 HTML·SVG로 다이어그램·차트·인터랙티브 시각물을 만들고, 업로드한 이미지를 보고 분석 가능
- 영상: Remotion은 React 코드로 영상을 만드는 도구이며, 공식 Agent Skills(npx skills add remotion-dev/skills)를 Claude Code·Codex·Cursor 등에서 사용 가능. 즉 Claude가 '영상 파일을 직접 생성'하는 것이 아니라 영상을 렌더링하는 코드를 작성하는 방식
- 사진형 이미지가 필요하면 이미지 생성 모델(API)을 별도로 연결해야 함
- Concat은 원본 정리 시 확인에서 공식 저장소를 특정하지 못함
- [추가 2026-09-29] 9월 추가: Claude는 사진 생성이 안 된다는 확인(9/29), 교육용 동영상은 Remotion + Opus 5.5, 3D는 three.js 병행 추천(9/27).
- [추가 2026-09-09] HTML을 영상으로 렌더링하는 오픈소스 HyperFrames(HeyGen, Apache 2.0)도 Remotion과 함께 AI 코딩 에이전트용 영상 제작 대안으로 공유됨 — HTML·CSS·애니메이션을 결정적 MP4로 렌더링
- [추가 2026-10-02] 커뮤니티 사례: Opus 5.5로 모션그래픽을 구독 한도 안에서 제작(3D는 Blender 연동), 레퍼런스 영상을 보여주고 '똑같이' 요청, 줌 녹화 50분 링크로 유튜브 롱폼 편집을 맡긴 사례. 실사(사람이 걷는 영상 등)는 코드로 만들 수 없어 외부 영상 모델(API)·Wan 등 영상 특화 모델이 필요하다는 의견
- [추가 2026-10-05] 게임 리소스 제작 사례: 이미지는 Gemini, Claude는 이미지 생성 없이 분석만 가능, 이펙트는 수학적 로직(코드)으로 구현
- [추가 2026-09-29] - [추가 2026-10-05] 원작자 공개 자료 확인: Stephan Livera의 X 게시물(Opus 5.5 Max effort, '15초 모션그래픽 쇼릴' 한 문장 프롬프트) 존재 확인, 조회수 222만은 원문 미확인. ## 교육과 업무에 활용

- 'AI가 만든다'와 'AI가 만드는 코드를 짠다'의 차이를 교육 초반에 구분
- 영상 실습은 Remotion 스킬 설치→템플릿 수정→렌더링 흐름으로 구성 가능

## 정정과 한계

'Opus 5.5로 영상 가능'은 정정 필요: Claude는 영상을 직접 생성하지 않으며, 가능한 것은 Remotion 등으로 영상을 만드는 코드를 작성·렌더링하는 방식임.
