## 정리된 지식

- Laya(GitHub NandhaKishorM/laya): 텍스트 생성 없이 단일 forward pass로 선택·점수·예/아니오 판단, Apache-2.0, 영어(ModernBERT-large 421M)·다국어(mmBERT-base 322M, 100+ 언어) 등 체크포인트, TypeSafe의 POST /v1/systemone 프로토콜 구현으로 기존 Jev 클라이언트를 코드 변경 없이 연결
- OpenAI Decisions API: 사용자가 정의한 질문·선택지에 대한 판단 특화, DevDay(9/29) 기준 제한 프리뷰·수일 내 확대 예정, 가격 미공개
- [추가 2026-09-29] - DevDay 2026 공식 요약 보강: Decisions API는 사용자가 정한 질문과 '유한한 사전 정의 답' 범위에 Luna의 지능을 집중해 실시간 판단, 맥락은 텍스트 또는 이미지로 제공, 제한 프리뷰이며 '수일 내 광범위 출시 예정'
- 시연 영상의 '기존 방식보다 약 10배 빠른 판단'(고객 요청 1만 건 배정 비교) 문구는 공식 요약문에 없어 원문 미확인

## 교육과 업무에 활용

- 라우팅·필터링 같은 반복 판단은 생성형 LLM 대신 판단 전용 모델로 비용 절감 가능
- 실서비스 투입 전 자체 데이터로 정확도(예: 95% 목표) 검증
- Laya 저장소가 여러 개 존재하므로 원 저장소·라이선스 확인
