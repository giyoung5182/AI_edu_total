## 정리된 지식

- Claude Code 오류 문서: 'Your organization has disabled Claude subscription access for Claude Code'는 서버측 조직 설정이라 로컬 설정·환경변수·CLI 플래그로 덮어쓸 수 없음. Agent SDK와 -p 비대화형 모드에서는 oauth_org_not_allowed 코드로 표시
- 대응: 관리자에게 Claude Code 접근 활성화 요청, Console API 키로 인증, 관리자인데 옵션이 없으면 Anthropic 지원팀 문의
- 공식 이슈 anthropics/claude-code#96596(Open): Google Play로 구매한 Pro 개인 사용자가 v2.1.281에서 같은 오류(원격 관리 설정 403)를 겪은 회귀 버그로 보고됨 → 개인 요금제에서도 발생 가능
- status.claude.com에 2026-09-16 'Google Play subscription issues' 장애 기록 존재(동일 원인인지는 확인되지 않음)

## 교육과 업무에 활용

- 기관 계정 교육 시 로그인 차단은 개인 문제가 아닌 조직 설정일 가능성부터 점검
- 개인 요금제에서 발생하면 공식 이슈 확인 후 지원팀 문의가 현실적 대응
