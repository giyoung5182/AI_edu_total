## 정리된 지식

- Ollama 공식 모델 페이지 기준 7B 모델은 최소 8GB, 13B는 16GB, 70B는 64GB RAM이 일반적으로 필요. Kimi K3 공식 모델 카드는 총 2.8T 파라미터(활성 104B)·MXFP4 가중치로, 4비트 기준으로도 가중치만 약 1.4TB로 계산돼 Mac Studio 최대 512GB 구성도 넘어섬(단순 산술, 공식 요구사양은 미기재). 64GB 장비는 70B급 양자화 모델이 상한선에 가까움. 클라우드 프런티어 모델과 동등한 품질을 로컬에서 낸다는 공식 근거는 없음.
- [추가 2026-07-30] Ollama 공식 블로그는 Kimi K3를 2.8조 파라미터 모델로 소개. 커뮤니티: M1 맥북 64GB에서 양자화판으로 분당 약 4토큰 출력 사례(정상 사용 불가 수준), 1bit 양자화판도 수백 GB, exo 분산추론은 버그·비전 미지원으로 포기 → LLM은 아직 클라우드가 유리하고 TTS·OCR·임베딩 등 특화 모델은 로컬로 쓸 만하다는 결론
- [추가 2026-06-03] 커뮤니티 경험(공식 확인 아님): 로컬 모델은 요약·RAG 검색 용도는 쓸 만하나 긴 컨텍스트·추론·코드가 많은 에이전트 작업(OpenClaw류)은 어렵다는 의견 다수, 구매 전 OpenRouter 등으로 같은 오픈 모델을 API로 먼저 시험해 용도 적합성 확인, 목돈 대신 RunPod 등 GPU 임차 대안 언급
- [추가 2026-10-02] 128GB M5 Max에서 122B 로컬 모델은 겨우 구동, 프런티어 모델 세션 20~30개는 무난하다는 사례. Kimi K3급은 포기하고 Qwen 외 현실적 대안이 없어 구독 증설로 선회. Codex 에이전트 10개 이상 동시 실행 시 RAM 32GB에서 다운됐다는 보고

## 교육과 업무에 활용

로컬 LLM 교육 시 '보안상 외부 전송 불가 업무용 소형 모델'과 '클라우드 프런티어 모델'의 용도를 구분. 장비 선정은 쓰려는 모델 크기에서 역산하도록 안내.
