## 정리된 지식

- Codex 내장 브라우저: ChatGPT 데스크톱 앱과 웹에서 제공(Codex CLI·IDE 확장에서는 불가). 페이지 열기·클릭·입력·스크린샷·결과 확인 가능. 기존 브라우저의 탭·로그인 세션을 공유하지 않는 별도 프로필이라 필요 시 그 안에서 직접 로그인. 파일 업로드 자동화 불가, 제출·구매 등 민감 동작 전 승인 요구
- Tencent BrowserSkill: MIT 라이선스 오픈소스. CLI(bsk)와 브라우저 확장으로 AI 에이전트가 사용자의 실제 로그인된 브라우저를 쓰게 함. 이미 열린 탭은 명시적으로 '빌렸다가 반납'하고 에이전트 작업은 별도 창에서 진행. Claude Code·Codex·Cursor·OpenClaw·Hermes Agent 등 셸 명령을 실행할 수 있는 에이전트면 사용 가능
