## 정리된 지식

- Anthropic 공식 발표: Claude Opus 5.5는 2026-09-22 출시, 웹·데스크톱 앱·Claude Code·Cowork 및 Pro/Max/Team/Enterprise에서 사용 가능 → 데스크톱에서 안 보이면 앱 업데이트가 우선 조치
- ChatGPT & Codex 공식 변경 이력: GPT-6 Sol·Luna 지원은 Codex CLI 0.157.0(2026-09-25)에 추가됨. 9/23 시점 CLI 선택기에 Sol이 없었던 것은 이 일정과 부합
- openai/codex 이슈 #47972: GPT-6 모델이 CLI·모바일에는 있으나 Windows 데스크톱 선택기에 없다는 보고에 OpenAI 지원이 '배포 기간 중 표면/클라이언트별로 모델 제공이 다를 수 있다'고 답했고, 보고자는 CLI에서 codex --model gpt-6-sol 직접 지정으로 사용 가능함을 확인했다고 기록함(OpenAI가 제시한 공식 우회책은 아님)
- 'low → light' 명칭 변경은 OpenAI 공식 문서에서 확인하지 못함(ChatGPT 도움말은 Instant·Medium·High·Extra High·Pro 명칭 사용)
- [추가 2026-07-26] Opus 5 출시 당일: CLI는 즉시 적용, IDE는 업데이트·새로고침 필요, Orca 컨테이너는 재로그인·재시작으로 해결. /model에 5만 보일 때는 /model claude-opus-4-8처럼 모델 ID 직접 지정 또는 설정 JSON 수정
- [추가 2026-09-23] 9월 사례 추가: Astra(9/5)·Opus 5.5(9/23)·GPT-6 Sol(9/23)이 안 보일 때 앱 재시작·업데이트로 해결, Codex 앱에 내장된 CLI가 구버전이면 앱 재설치로 해결, 시간이 지나 자동으로 나타나거나 모델명이 일시적으로 custom으로 표시되는 사례도 있음.
- [추가 2026-07-10] GPT-5.6은 2026-07-09 출시, OpenAI는 전 세계 순차 배포로 24시간 내 전체 제공 예정이라고 발표 — 출시 당일 Codex에 모델이 안 보이면 앱 업데이트가 우선 조치
- [추가 2026-10-01] GPT-6.1 Sol은 공식상 ChatGPT Work와 Codex 제공(Chat 미제공). 출시 직후 Codex CLI·데스크톱·VS Code 확장에서 6.1이 안 보이거나 보이다 사라지는 사례 다수, 확장을 최신으로 해도 미표시 보고
