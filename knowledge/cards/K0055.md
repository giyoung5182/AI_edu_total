## 정리된 지식

- effort 단계: low·medium·high·xhigh·max. Opus 5.5·Sonnet 5.5의 기본값은 medium이며, 공식 문서는 테스트상 Opus 5.5 medium이 Opus 5 high와 같거나 앞선다고 설명. 일상 기능 구현은 medium, 검증이 중요한 버그 수정은 high, 어려운 문제는 max 권장
- 설정 방법: /effort high, 실행 시 claude --effort high, /model 선택기에서 좌우 화살표
- ultracode: xhigh effort와 자동 워크플로우(여러 서브에이전트 동시 실행)를 결합한 설정. /effort ultracode(또는 /effort 슬라이더에서 Tab으로 Ultracode 토글 후 Enter)는 현재 세션만 적용, 설정 파일의 "ultracode": true는 모든 세션에 유지
- 끄는 방법: /effort high(일반 수준 복귀) 또는 /effort ultracode off(v2.1.284 이상). 설정 파일에 ultracode:true가 있으면 새 세션마다 다시 켜지므로 해당 키 삭제 필요
- 프롬프트에 'ultracode' 단어를 쓰면 그 요청만 워크플로우로 실행됨. 강조 표시는 Option+W(mac)/Alt+W로 해제, /config에서 키워드 트리거 끄기 가능
- 비용: ultracode는 요청마다 토큰을 더 쓰므로 구독 한도에 더 빨리 도달
- [추가 2026-09-30] 커뮤니티 경험: max effort에서도 울트라코드 사용 가능, 한 사용자는 에이전트 500개가 열리며 5시간 한도를 3번 소진했다고 공유(대규모 병렬 실행 시 한도 급소진 주의)

## 교육과 업무에 활용

- 비개발자 실습에서는 기본값(medium) 유지를 권장하고 ultracode는 토큰 소모가 큰 고급 옵션으로 별도 안내
- '설정이 안 꺼진다' 문의 시 세션 설정과 영구 설정(settings 파일)을 구분해 점검

## 정정과 한계

'울트라코드는 탭으로 전환'은 맞음(공식 문서: /effort 슬라이더에서 Tab으로 Ultracode 토글). 다만 '토큰이 넉넉하면 제일 똑똑한 모델'이라는 답은 공식 권장(작업 난이도에 맞춰 effort 선택)과 다름.
