## 정리된 지식

- Google MediaPipe Face Landmarker: 얼굴 랜드마크와 함께 표정 계수(blendshape) 52종을 선택적으로 출력(output_face_blendshapes 옵션, 기본값 꺼짐). 눈 깜빡임·시선 방향 같은 표정 감지에 활용 가능
- Android·iOS·Python·웹(JavaScript) 지원으로 웹캠 기반 시제품을 개인이 만들 수 있는 공개 도구
- 음성인식 부분은 원본 정리 시 확인 범위에서 특정 공식 도구를 검증하지 않음
- 실제 사용자 적용 시 정확도·피로도·오작동 대비는 사용 환경에서 별도 검증 필요

## 교육과 업무에 활용

- 바이브코딩의 사회적 활용 사례(접근성 보조 도구)로 소개 가능
- 공개 모델+웹캠 조합으로 시작하되 실사용 전 반복 테스트 필요성 강조
