## 정리된 지식

Claude Code 공식 문서: 비포크 서브에이전트는 대화 기록·읽은 파일 없이 새 격리 컨텍스트로 시작하며, 요청은 메인 대화와 같은 사용 한도에 합산. 포크(/subtask)는 부모 대화 전체를 상속하고 프롬프트 캐시를 공유해 같은 맥락이 필요한 작업에 더 저렴. oh-my-pi는 GitHub 공개 코딩 에이전트 프로젝트로 실존 확인, handoff 스킬의 구체 동작은 미확인.

## 교육과 업무에 활용

'반복 작업은 LLM 판단 대신 스크립트로 고정'하는 비용 절감 원칙 교육. 맥락 필요 작업엔 포크 방식 검토.
