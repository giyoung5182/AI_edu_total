## 정리된 지식

- Claude Code 설정 참조 문서: language 키로 기본 응답 언어를 지정할 수 있으며, 값(예: "korean")을 '항상 그 언어로 응답하라'는 지시로 Claude에 그대로 전달함. 값 검증은 하지 않아 오타도 그대로 전달됨. 같은 값이 음성 받아쓰기·자동 세션 제목 언어에도 적용
- 기본값은 미설정 상태 → 영어 문서·코드·로그가 많은 작업에서는 영어로 답할 수 있으므로 language 설정 또는 CLAUDE.md에 언어 지시를 두는 방식이 해결책
- Grok이 중국어를 섞는 원인은 xAI 공식 문서에서 확인하지 못함
- [추가 2026-09-19] 9월 추가 사례: Claude가 작업 중 일본어·영어·한국어를 섞음(9/2), Codex Astra 엑스트라 하이가 한자·중국어·알 수 없는 언어를 출력(9/19), CLAUDE.md에 한국어만 쓰라고 해도 Opus가 가끔 일본어를 쓴다는 경험. 원인에 대한 공식 설명은 여전히 없음.
- [추가 2026-09-30] Opus 5.5에서 한국어로 답하다 갑자기 영어로 바뀌는 현상이 다수 보고됨. 공식 claude-code GitHub에도 'Opus 5.5·Sonnet 5.5가 세션 중 영어로 drift', 'CLAUDE.md 언어 규칙을 무시하고 일부 답을 영어로' 등 이슈가 등록돼 있음(사용자 보고, Anthropic 공식 원인 발표 아님) — 따라서 'CLAUDE.md에 강제하면 해결'은 완전한 해법이 아님. GPT Astra도 일본어가 섞이는 코드스위칭 사례 보고
- [추가 2026-10-02] 2026-09-30~10-02 Opus 5.5가 한국어 질문에도 영어로 작업·답변하는 현상이 다수 보고됨. '한국어로' 재지시 시 잠시 복구되나 재발 — 공식 원인 설명은 확인되지 않음. Claude Code에서는 설정 파일의 language 키로 응답 언어를 고정하는 것이 공식 대응 수단
- [추가 2026-10-04] Opus 5.5 이후 한국어로 요청해도 영어로 답하는 현상 보고가 이어짐. 세션 종료 후 이어가기로 해소된 사례, 에이전트 간 영어·사용자 대상 한국어로 지침을 둬도 영어가 섞인다는 사례, CLAUDE.md·스킬에 한국어 강제 시 대부분 해결되나 가끔 재발한다는 경험. 원인에 대한 공식 설명은 확인되지 않음.

## 교육과 업무에 활용

- 교육 환경 세팅 체크리스트에 ~/.claude/settings.json의 "language": "korean" 설정 포함
- 모델의 언어 혼입은 공식 설명이 없는 경우 '확인 필요'로 안내
