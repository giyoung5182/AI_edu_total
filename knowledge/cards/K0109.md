## 정리된 지식

Anthropic 개발자 공식 X 계정(ClaudeDevs) 게시물로 2026-09-14부터 Pro·Max·Team·seat 기반 Enterprise의 Claude Code 표준 주간 한도를 25% 영구 상향한다고 공지된 것으로 보도됨(AI타임스·BleepingComputer). 기본값 100 기준 150(프로모션) → 125(상향 후)로 프로모션 기간 대비 약 17% 감소. 해당 X 게시물은 이 환경에서 원문을 열지 못했고, Claude 도움말(Pro/Max로 Claude Code 사용)에는 관련 내용이 없어 공식 문서 대조는 미완료. 커뮤니티 체감 수치(100→150→125)는 보도 내용과 일치.

## 교육과 업무에 활용

'올랐다/줄었다'는 비교 기준선(기본값 vs 프로모션) 차이로 설명. 요금제 공지 해석 시 기준선부터 확인하는 습관 교육 사례.
