## 정리된 지식

- Claude Cowork: 지정한 폴더·연결 도구에서 다단계 작업을 수행해 문서·슬라이드·스프레드시트 결과물을 만드는 기능. Pro 이상(Pro·Max·Team·Enterprise) 포함, 데스크톱(macOS·Windows·Linux·ChromeOS)·웹·모바일(베타)
- ChatGPT Work: 긴 다단계 작업과 완성 결과물용 에이전트, 유료 요금제 대상. Codex와는 ChatGPT 데스크톱 앱 안에서 별도 화면으로 공존
- Claude 무료 플랜: 웹·데스크톱·모바일 채팅, 웹 검색·파일 생성·코드 실행, Sonnet·Haiku 모델. Opus와 Claude Code·Cowork는 유료(Pro 이상)
- [추가 2026-07-14] Cowork 데스크톱은 코드 실행을 호스트와 분리된 전용 Linux 가상머신에서 수행(macOS는 Virtualization.framework, Windows는 Hyper-V) — Windows에서 가상화 기능이 꺼져 있으면 문제가 될 수 있다는 커뮤니티 답과 맥이 닿으나, 필수 조건으로 명시된 문구는 확인하지 못함
- [추가 2026-07-11] OpenAI 도움말: Chat은 빠른 대화형 도움, Work는 긴 다단계 작업과 완성 산출물용 에이전트, Codex는 소프트웨어 개발 전용 — 문서 작업·요약도 다단계 산출물이면 Work, 가벼운 요약은 Chat
- [추가 2026-10-04] Work와 Chat 차이 체감: 파일 수십 개 폴더를 연결하고 무게 있는 목표를 주면 Work가 '대신 일하는 직원'처럼 작동, Chat은 1회성 질문용

## 교육과 업무에 활용

- 요금제별 사용 가능 모델·기능을 교육 첫 시간에 표로 안내
- 생활기록부처럼 학생 개인정보가 담긴 자료는 기관 개인정보 처리 기준 확인 후 AI 입력 여부를 판단하도록 안내

## 정정과 한계

'무료로 Opus 5.5 사용 가능'이라는 취지의 답은 공식 가격 페이지와 다름: 무료 플랜은 Sonnet·Haiku만 제공하며 Opus는 유료 요금제 필요. 또한 'Work는 코딩용'은 부정확 — 코딩은 Codex, Work는 다단계 문서·산출물 에이전트(OpenAI 도움말).
