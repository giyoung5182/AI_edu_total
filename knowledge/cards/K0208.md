## 정리된 지식

- Claude Code 모델 설정 문서: 관리자는 managed·policy 설정의 availableModels로 선택 가능 모델을 제한하고, enforceAvailableModels로 기본 옵션까지 허용 목록 적용, 관리자 콘솔에서 조직·역할별 기본 모델 지정 가능
- Team 플랜: 최소 2명·최대 150석, Standard($25 월간/$20 연간)와 Premium($125/$100) 혼합, Standard는 Pro 세션 사용량의 1.25배·Premium은 6.25배
- ChatGPT Business도 최소 2석, 기본적으로 관리자·소유자는 멤버의 비공개 대화를 모두 볼 수 없음
- Enterprise 사용량 구조는 이번에 확인하지 못함

## 교육과 업무에 활용
