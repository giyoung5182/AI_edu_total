# 여러 구독 계정 전환은 Orca의 계정 관리·핫스왑으로 가능 — 한도 소진 시 자동 전환은 공식 기능으로 확인되지 않음

> 역사 자료. 확인 수준과 확인일은 원본 기록을 보존한 값입니다. 공개 편집일의 최신 기능·가격·법률 확인을 의미하지 않습니다.

- 카드: K0263
- 분류: 도구·사용법
- 기록 기간: 2026-09-07 ~ 2026-10-02
- 원본 확인일: 2026-10-06
- 원본 상태: **부분확인**
- 공개 편집일: 2026-10-08

## 정리된 지식

- Orca 문서: 여러 Claude 계정을 관리하며 실행 중인 Claude 세션이 있어도 계정 전환이 가능(인증 갱신 충돌을 막는 가드 적용)
- '한도 도달 시 다른 계정으로 자동 전환(failover)' 기능은 Orca 저장소에 기능 요청 이슈로 열려 있어 공식 구현으로 확인되지 않음
- 본인 소유 복수 계정 운용과 달리 타인과의 계정 공유는 OpenAI·Anthropic 약관상 금지(기존 카드 K0091)
- [추가 2026-10-02] 계정 한도 소진 시 cc-switch 같은 공개 스크립트로 계정을 바꿔도 동일 세션에서 이어 작업한다는 사례 — 다계정 운영의 약관 리스크는 K0377 참조

## 교육과 업무에 활용

- 다계정 운용 시 계정별 한도·리셋 시점을 표로 관리
- 계정 공유와 본인 복수 계정 사용을 구분해 약관 리스크 안내

## 정정과 한계

'Orca가 알아서 다른 계정 한도까지 쓴다'는 체감은 공식 기능으로 확인되지 않음(자동 failover는 미구현 요청 상태)
