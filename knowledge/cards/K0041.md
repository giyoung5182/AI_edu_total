## 정리된 지식

- Claude Code /usage의 Session 블록 금액: 토큰 수에 정가(list price)를 곱해 로컬에서 계산한 추정치. Pro·Max 구독자는 구독에 사용량이 포함되어 이 금액이 실제 청구와 무관
- 구독자는 같은 화면에서 요금제 사용량 막대와 최근 24시간·7일 사용 원인(스킬·서브에이전트·MCP 서버별 비중)을 확인 가능
- Codex(ChatGPT 요금제): chatgpt.com/codex/settings/usage 사용량 대시보드, Codex CLI 세션 안의 /status 명령으로 남은 한도 확인
- ChatGPT 채팅 화면에서 Pro 모델 잔여 횟수를 보는 위치는 원본 정리 시 확인 범위에서 공식 문서를 찾지 못함
- [추가 2026-09-08] 9/8 커뮤니티: Codex 한도는 설정의 사용량 화면, 모바일 앱에서도 사용량 및 한도 메뉴에서 확인 가능. 공식 도움말은 설정·사용량 대시보드와 CLI /status를 안내.
