# CLI '크레딧 부족'은 API 선불 크레딧 소진 — 구독 로그인(/login)으로 전환하면 구독 한도 사용, API는 서비스 연동용

- 공개 편집일: 2026-10-08

## 정리된 지식

- Claude Code 오류 문서: 'Credit balance is too low'는 Console 조직의 선불 크레딧 소진을 뜻함. 대응은 결제 설정에서 크레딧 추가·자동 충전, 또는 Pro·Max·Team·Enterprise 구독자는 /login으로 구독 인증 전환
- Claude 도움말: ANTHROPIC_API_KEY 환경변수가 설정되어 있으면 Claude Code가 구독 대신 API 키로 인증해 API 요금이 부과됨. 구독만 쓰려면 claude logout 후 구독 계정으로만 로그인
- 구독(Pro/Max)은 Claude 앱과 Claude Code가 같은 사용 한도를 공유하고, 한도 소진 시 선택지로 상위 요금제 업그레이드, 사용량 크레딧, 리셋 대기, 집중 작업용 Console API 크레딧 구매가 안내됨
- JEV의 Gemini 호출 방식은 공식 확인 대상이 아님(커뮤니티 설명)

## 교육과 업무에 활용

- '크레딧 부족'과 '사용 한도 도달'은 다른 과금 체계의 메시지라는 점을 구분해 안내
- 수강생 PC에 남아 있는 ANTHROPIC_API_KEY 환경변수로 의도치 않은 API 과금이 생길 수 있음을 주의사항으로 포함
