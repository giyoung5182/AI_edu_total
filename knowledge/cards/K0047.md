## 정리된 지식

- Codex CLI(TUI): 설정 파일의 notify 항목으로 알림 시점과 작업 완료 시 외부 프로그램(예: 소리 재생 스크립트) 실행을 지정
- IDE 확장: 연결된 Codex 호스트에 notify를 설정
- ChatGPT 데스크톱 앱: Settings에서 턴 완료 알림을 '표시 안 함 / 앱이 백그라운드일 때만 / 항상' 중 선택
- Orca 같은 관리 도구의 알림은 추가 선택지이며 필수 아님

## 교육과 업무에 활용

- 장시간 에이전트 작업 실습 시 완료 알림 설정을 사전 준비 항목에 포함

## 정정과 한계

Orca 사용은 가능한 방법 중 하나일 뿐이며, Codex 자체에 notify 설정과 앱 알림 설정이 공식 기능으로 있음.
