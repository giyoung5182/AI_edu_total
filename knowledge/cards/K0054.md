## 정리된 지식

- Cognition 공식 블로그(2026-04-27): Devin CLI는 내 코드베이스·도구·환경에 접근하는 터미널 로컬 코딩 에이전트
- 핵심 기능: 작업이 노트북 역량을 넘으면 '자체 컴퓨터를 가진 클라우드 에이전트'로 세션을 넘겨 노트북을 닫아도 계속 실행
- 모델: 발표 시점 기준 Opus 4.7·GPT-5.5·자체 SWE-1.6 중 선택
- 설치: curl -fsSL https://cli.devin.ai/install.sh | bash
- 요금제는 devin.ai/pricing 공식 페이지 기준 Free/Pro $20/Max $200/Teams(2026-09-29 확인)

## 교육과 업무에 활용

- 로컬 실행과 클라우드 위임을 한 흐름으로 잇는 도구 사례로, Claude Code의 --cloud·teleport와 비교 설명 가능

## 정정과 한계

'그냥 Devin을 CLI로 쓰는 것'은 부분만 맞음: 공식 설명상 Devin CLI는 로컬에서 직접 실행되는 에이전트이며, 클라우드 Devin으로의 핸드오프가 차별점.
