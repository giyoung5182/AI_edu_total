## 정리된 지식

- Claude Code /usage: 세션 비용·플랜 사용량 한도·활동 통계 표시(Pro·Max·Team·Enterprise는 한도 사용 내역 포함), /cost·/stats는 별칭
- Codex: 설정·사용량 대시보드, CLI /status로 확인
- CodexBar: 여러 AI 코딩 제공자의 사용량·리셋 카운트다운을 메뉴바에 표시하는 MIT 오픈소스, 주 플랫폼은 macOS 14 이상(CLI는 macOS·Linux)
- 자작·서드파티 도구의 수치는 추정이므로 공식 화면과 차이가 날 수 있음
