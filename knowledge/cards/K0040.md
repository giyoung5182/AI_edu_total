# Claude 리셋권(Limit reset)은 웹·데스크톱 Settings > Usage에서만 사용, Claude Code 터미널·IDE에서는 불가

## 정리된 지식

- Limit reset(리셋권): 일부 유료 요금제에 가끔 지급되는 혜택. 사용 시 5시간 세션 한도 또는 주간 한도 중 해당 리셋이 가리키는 한도를 즉시 가득 채워 줌
- 사용 위치: claude.ai 웹 또는 Claude Desktop의 Settings > Usage → 'Reset for free' 클릭 후 확인. 한도에 도달했을 때도 같은 버튼이 표시됨
- 한도에 닿기 전에도 사용 가능, 되돌릴 수 없음, 주간 한도의 정기 리셋 일정은 그대로 유지, 미사용 리셋은 제시된 만료 일시에 소멸
- 고객센터 문서 기준 Claude 모바일 앱과 Claude Code 터미널·IDE에서는 현재 사용 불가
- Claude Code의 /usage(별칭 /cost)는 한도 사용량 막대·리셋까지 남은 시간·사용량 원인 분석을 보여 주는 '조회' 명령. VS Code 확장에서는 /usage가 Account & usage 창을 엶
- [추가 2026-09-23] 9/23 Opus 5.5 출시와 함께 Claude 구독자에게 리셋권 1회 지급(공식 발표: 원할 때 저장해 쓰는 rate limit reset). 커뮤니티 확인: 데스크톱 설정>사용량에서 보이고 모바일에선 안 보임, 유효기간 약 1달(10/23). 공식 도움말: 5시간 세션 또는 주간 한도 중 제공 유형에 따라 초기화, 웹·데스크톱에서만 사용, 주간 리셋 일정은 변하지 않음.
- [추가 2026-10-04] 공식 도움말: Claude 리셋(Limit reset)은 '자격 있는 요금제에 가끔(occasionally)' 지급되며 Settings > Usage(웹·데스크톱)에서 'Reset for free'로 사용, 만료가 있으면 같은 화면에 표시되고 표시된 날짜·시각에 만료, 사용 후에도 주간 한도는 원래 요일·시각에 리셋.
- [추가 2026-10-04] Claude 리셋권은 장별 사용 만료일이 있는 쿠폰 형태로 비정기 지급(매달 지급 아님), 아끼다 만료되는 경우가 많다는 경험

## 교육과 업무에 활용

- 리셋권 안내 시 '어디서 누르는가(웹·Desktop 설정)'와 '어디서 확인하는가(/usage)'를 구분해 설명
- 교육 현장에서는 한도 소진 대비로 웹 설정 화면 경로를 미리 시연

## 정정과 한계

커뮤니티 답 중 '/usage로 리셋권 사용'은 부정확함: /usage는 사용량 조회 화면이며, 리셋권 사용 버튼은 공식 문서상 웹·Desktop의 Settings > Usage에 있음. '/limit-reset을 CLI에서 실행' 팁은 고객센터 문서(터미널·IDE 미지원)와 맞지 않음. 일부 블로그가 /limit-reset 명령을 소개하지만 공식 명령어 목록(commands 문서)에서는 확인되지 않음.
