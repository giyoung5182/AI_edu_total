## 정리된 지식

- kordoc(chrisryugj/kordoc, MIT): HWP 3.x/5.x·HWPX·HWPML·PDF·XLS·XLSX·DOCX·이미지를 마크다운으로 변환
- HWPX 재생성, 원본 서식 유지 양식 자동 채우기, 신구대조, 개인정보 가림, API 키 없는 로컬 한국어 OCR 기능 제공(저장소 설명 기준)
- 사용: npx kordoc(Node.js 20 이상), MCP 서버 설정 npx -y kordoc setup(Claude Desktop·Cursor·Codex 등), Claude Code 플러그인 제공
- HWP(바이너리)와 HWPX(XML 기반)는 서로 다른 포맷이라는 커뮤니티 설명은 kordoc 지원 목록에서도 별도 항목으로 구분됨
- Claude 자체의 HWPX 생성 기능 여부는 Anthropic 공식 문서로 확인하지 못함

## 교육과 업무에 활용
