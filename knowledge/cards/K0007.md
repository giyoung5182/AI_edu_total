# Claude 구독 한도는 5시간 세션+주간 창, 초과분은 사용 크레딧(API 단가)으로 별도 결제

## 정리된 지식

- Anthropic 문서: Pro/Max 한도는 Claude(웹·앱)와 Claude Code가 공유. 세션은 첫 메시지부터 5시간 단위이며 Team/Enterprise 좌석도 5시간 롤링 창+주간 창으로 리셋. 한도 초과 시 사용 크레딧을 켜면 표준 API 단가로 계속 사용 가능하고, Pro/Max는 월 지출 한도를 설정할 수 있어 한도 도달 시 올리거나 해제해야 함. 크레딧 사용 중에는 메인 대화 프롬프트 캐시 TTL이 1시간에서 5분으로 줄어 휴식 후 재개 시 전체 맥락을 다시 처리하게 되므로 크레딧 소모가 커질 수 있음. Max 문서에는 월 50세션이 '유연한 기준'으로 언급됨(하드 캡 아님).
- [추가 2026-08-05] 커뮤니티 확인: 사용량 화면의 '현재 세션'은 5시간 사용 한도이며 100%가 되면 주간 한도가 남아도 재설정 시각까지 사용 불가, 5시간 창은 첫 메시지 기준으로 시작한다는 경험(아침 정해진 시각에 첫 메시지를 보내 창을 고정하는 팁). 주간 초기화 요일이 사람마다 다르다는 관찰. 자동충전을 껐는데 잔액이 마이너스로 표시된 사례는 원인 미확인
- [추가 2026-09-28] 후속 논의: 5시간·주간 창이 있어 한 번에 몰아 쓰기는 불가라는 답. 한도 소진 후에도 계속 돌아가면 사용 크레딧(설정>사용량에서 수동 활성화·선충전, 자동 충전 선택, 하루 사용 한도 $2,000)이 켜져 있는지 확인. 피크 시간대 한도 축소 주장은 공식 확인 안 됨.

## 교육과 업무에 활용

'구독=무제한'이 아니라 '5시간·주간 창+초과 종량제' 구조로 설명. 크레딧 사용 시 월 지출 한도부터 설정하도록 안내.

## 정정과 한계

'5시간 제한은 Business 전용이고 Pro부터 없다'는 답은 틀림: Pro/Max 모두 5시간 세션 단위 한도가 적용됨. 크레딧을 샀는데 못 쓰는 사례의 정확한 원인(월 지출 한도 설정 등)은 공식 확인 필요.
