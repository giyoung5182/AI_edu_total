## 정리된 지식

- Hermes Agent(Nous Research): MIT 라이선스 오픈소스 에이전트. 자연어로 설정하는 내장 cron 스케줄러(일일 리포트·야간 백업 등), 텔레그램·디스코드·슬랙·왓츠앱·시그널 메신저 게이트웨이, 에이전트가 관리하는 기억, 작업 중 스킬 자동 생성(agentskills.io 표준 호환)
- 모델: Nous Portal·OpenRouter·OpenAI·자체 엔드포인트 등 선택, hermes model로 전환
- 설치: curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
- OpenClaw에서 이전: hermes claw migrate로 설정·기억·스킬·API 키 가져오기 지원
- OpenClaw는 github.com/openclaw/openclaw의 오픈소스 개인 AI 비서
- '코딩 같은 실제 작업엔 약하다'는 평가는 공식 비교 자료가 아닌 사용 체감
- [추가 2026-07-15] Claude Code 법률 문서상 제3자 개발자가 Free·Pro·Max 자격증명으로 요청을 중계하는 것은 허용되지 않으므로, Hermes에 Claude를 붙이려면 API 키 방식이어야 함(커뮤니티도 '구독제는 연결 안 됨, API는 요금 폭탄', 'Claude OAuth 지원 중단'이라고 답)
- [추가 2026-08-18] Hermes Agent 공식 문서 기준 Nous Portal, ChatGPT 구독 기반 OpenAI Codex(OAuth), 추가 크레딧을 구매한 Claude Max(OAuth), xAI SuperGrok, OpenRouter 등 다수 제공자와 Ollama·vLLM·llama.cpp 등 로컬 모델 지원 → '구독 연동은 GPT만 가능'이라는 커뮤니티 설명은 부정확. 커뮤니티 체감: gateway 방식 24시간 대기, 장기기억·셀프 스킬, cron 예약, 토큰 소모 큼. Nous 측 유료 플랜은 모델 크레딧·호스팅 비용 성격이라는 의견
- [추가 2026-09-17] 커뮤니티 의견 추가: 자체 운영(Hermes·OpenClaw)의 이점은 작업 스타일·지시 누적 저장과 개인 정보를 로컬에 두는 점, 반면 Codex·Claude Code도 비슷한 기능을 제공해 이유를 모르겠다는 반론. 9월 기준 많이 쓰는 도구로 Codex·Claude Code·Hermes·Grok Bot이 언급됨.
- [추가 2026-06-17] 커뮤니티 경험: Hermes는 초기 설정이 가볍고, 직접 연동은 커스텀 자유도가 높다는 비교; Hermes도 Claude·Codex 모델을 연결할 수 있어 로컬 PC 유무보다 모델 성능으로 판단하라는 의견. Claude 구독 OAuth를 서드파티에 연결하는 것은 Anthropic 정책상 불허(새 카드 참조)
- [추가 2026-10-05] 맥미니에서 돌리는 Hermes를 원격으로 쓰려면 디스코드 연동을 쓰라는 커뮤니티 답. Hermes가 API 크레딧을 쓰는지는 연결한 제공자에 따라 다름 — 공식 Providers 문서상 OpenAI·Anthropic API 키 등은 토큰 단위 과금, Nous Portal 등 구독형은 구독 한도 사용, Ollama 등 로컬 모델은 외부 크레딧 불필요.

## 교육과 업무에 활용

- 상시 실행 개인 비서형(예약·메신저) 에이전트와 코딩 에이전트의 용도 차이를 구분해 소개
- 오픈소스 에이전트는 소프트웨어 무료, 모델 API·서버 비용 별도라는 점 안내

## 정정과 한계

'구독 연동은 GPT만 가능'은 부정확 — Hermes Agent 공식 문서상 ChatGPT(Codex OAuth), Claude Max(OAuth, 추가 크레딧), SuperGrok, OpenRouter와 로컬 모델 등 다수 제공자 지원.
