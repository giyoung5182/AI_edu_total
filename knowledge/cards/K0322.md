## 정리된 지식

- Codex auto-review: approvals_reviewer를 "auto_review"로 설정하면 사람 대신 별도 리뷰어 에이전트가 승인 요청을 판단, approval_policy는 "on-request" 등 승인 요청이 나오는 정책이어야 함
- 설정 참조 기준 approvals_reviewer 기본값은 "user"(사람 승인)
- 검토 대상: 샌드박스 권한 상승 요청 셸 명령, 차단된 네트워크 요청, 허용 경로 밖 파일 수정. 'reviewer swap이지 권한 부여가 아님' — 샌드박스 범위는 그대로
- Claude Code auto mode: 두 번째 모델(분류기)이 사람 대신 행동을 검토하며 v2.1.283 이상에서 대화형 터미널·VS Code의 기본 시작 모드
- 'agy CLI'의 동등 기능은 확인하지 않음

## 교육과 업무에 활용

- 기업 교육에서 '전체 자동 승인(yolo)'과 '자동 리뷰(샌드박스 유지)'를 구분해 보안 정책과 함께 설명
- 설정 예시는 기본값(user)을 명시해 오해 방지
