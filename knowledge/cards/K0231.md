## 정리된 지식

- Orca GitHub PR #12265 'fix(terminal): stop Windows IME keys from triggering shortcuts'(병합 여부는 이번에 확인하지 못함): Windows IME의 Shift·자모 입력 등이 수정자+Enter로 바뀌던 문제 수정, 한국어·일본어 입력 문제 해결
- Orca 공식 문서: 권장 원격 구성은 두 컴퓨터 모두 Orca 데스크톱 앱을 Tailscale로 연결, 헤드리스 환경은 'orca serve --pairing-address <서버 IP>'로 창 없이 런타임 실행
- SSH 워크트리는 노트북의 Orca가 런타임을 소유하고 원격은 일부 워크트리·터미널만 실행하는 방식, 원격 서버 방식은 서버가 전체 런타임을 소유
- 서버 방식은 Codex·Claude Code 등 CLI 인증을 서버 컴퓨터에서 따로 해야 함
- [추가 2026-10-01] 2026-10-01 Orca에서 Claude 로그인이 약 10분마다 끊긴다는 보고(GitHub 이슈 존재 언급), 공식 클라이언트에서는 끊기지 않음 — 재시작으로 임시 대응
- [추가 2026-10-02] Orca에서 Codex 사용 시 스크롤하면 이전 대화가 로드되어 위로 못 올라가는 버그 보고(해결책 미공유), 대안으로 herdr 언급
