## 정리된 지식

- Tailscale 공식 문서: 기기 간 암호화 P2P 연결로 NAS·홈서버를 인터넷에 노출하거나 포트포워딩하지 않고 원격 접근 가능, MagicDNS로 기기 이름 접속 지원. Claude Code 공식 인증 문서: 브라우저가 로컬 콜백 서버에 닿지 못하면(SSH·WSL2·컨테이너 등) 로그인 후 표시되는 코드를 터미널의 'Paste code here if prompted'에 붙여넣으면 되고, 브라우저 로그인이 불가능한 환경은 'claude setup-token'으로 1년짜리 OAuth 토큰을 발급해 CLAUDE_CODE_OAUTH_TOKEN으로 지정 가능. 질문 속 'localhost:8080'을 요구한 주체가 Claude Code인지 MCP 서버 등 다른 구성요소인지는 대화만으로 확인되지 않음. NAS 파일 정리는 사용 경험.
- [추가 2026-08-06] NAS에 홈페이지·ERP를 올린 경우: 보안 구축 자신이 없으면 NAS 유지, ERP DB는 HDD 부하 우려, NAS를 원격 드라이브로도 쓰면 보안 위험 증가, NAS 로그를 에이전트에게 분석시켜 분리 시점 판단(커뮤니티)

## 교육과 업무에 활용

원격 작업 환경 교육 시 '공인 IP 포트 개방 대신 VPN 메시(Tailscale)'를 기본값으로 안내. 원격 인증은 localhost 콜백 구조를 먼저 설명하면 오류 해석이 쉬워짐.
