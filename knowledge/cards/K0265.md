## 정리된 지식

- Notion 도움말: MCP 도구는 사용자의 Notion 권한 전체로 동작해 사용자가 접근 가능한 모든 것에 접근
- 어떤 MCP 클라이언트·AI 앱을 허용할지 관리하는 관리자 통제는 Enterprise 플랜 기능
- 게스트의 MCP 사용 가능 여부는 도움말에서 확인되지 않음
- Codex는 원격 MCP 서버에 codex mcp login <서버명>으로 OAuth 로그인하며, 관련 설정은 로컬 config.toml에 저장
- '비즈니스 요금제가 아니면 MCP 제한'이라는 커뮤니티 주장은 확인되지 않음

## 교육과 업무에 활용

- 사내 도입 시 '누구 권한으로 무엇에 접근하는가'를 먼저 설계(개인 OAuth vs 공용 토큰)
- 연결 오류는 재로그인·권한 확인이 1순위
- 공용 계정 토큰 공유 대신 사용자별 인증을 원칙으로
