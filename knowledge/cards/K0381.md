## 정리된 지식

- 공식 도움말: 뱅크드 리셋은 구매 크레딧이 아니며 플랜 한도를 영구히 늘리지 않음, 현금·API 크레딧·양도 가능한 잔액이 아님
- 리셋을 쓰면 주간 리셋일이 Codex 사용을 재개한 시점부터 약 1주 뒤로 이동하고, 원래 요일의 주간 리셋은 따로 받지 않음
- 리셋은 최소 하나의 사용량 창을 실제로 새로 채웠을 때만 소모
- 보유 리셋 확인: 데스크톱 앱·CLI·웹의 settings → usage. 만료는 계정이나 오퍼에 표시된 내용을 확인하라고만 안내(시각·시간대 기준은 공식 미기재)
- 10/3 일괄 리셋과 '28일 챌린지'는 티보 본인 X 게시물·보도 기준이며 OpenAI 공식 문서로는 미확인. '리셋량 절반' 주장도 미확인

## 교육과 업무에 활용

- 리셋권은 '보너스 100%'가 아니라 다음 주간 리셋을 당겨쓰는 수단 — 정규 리셋 직후·한도 소진 직후에 쓸 때 효율적
- 만료 예정 리셋권은 사용량 화면에서 만료 표시를 직접 확인
- 일괄 리셋 같은 비정기 이벤트에 의존한 사용 계획은 지양
