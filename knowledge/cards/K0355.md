## 정리된 지식

- Claude Code 공식 법률·준수 문서: Free·Pro·Max 사용자는 Consumer Terms 적용, Pro·Max 광고 사용량은 '평범한 개인 사용'을 전제
- OAuth(구독 로그인)는 구독 구매자 본인의 Claude Code·Anthropic 네이티브 앱 사용을 위한 것
- 제품·서비스를 만드는 개발자(Agent SDK 포함)는 Console API 키나 지원 클라우드 사업자 인증을 써야 하며, 사용자를 대신해 Free·Pro·Max 자격증명으로 요청을 중계하거나 Claude 로그인 토큰을 수집·보관하는 것은 금지
- 호스팅 플랫폼에서도 최종 사용자가 수정되지 않은 Claude Code에 본인 구독으로 로그인하는 것은 허용, Anthropic은 사전 통지 없이 제한 조치 가능

## 교육과 업무에 활용

- 판단 기준은 '어디서 돌리나'가 아니라 '누구의 사용인가·누구에게 제공하나'
