## 정리된 지식

- Anthropic 공식 발표(2026-05-28): claude.ai와 API(claude-opus-4-8)에서 즉시 제공, 가격 입력 $5·출력 $25(백만 토큰당)
- fast mode는 입력 $10·출력 $50, 속도 2.5배
- 발표문에 '향후 수주 내 Mythos급 모델을 모든 고객에게 제공 예정' 언급
- Claude Code 모델 설정 문서: 모델 별칭·전체 이름 뒤에 [1m]을 붙여 1M 컨텍스트 요청(예: /model claude-opus-4-8[1m]); 현행 문서 기준 Anthropic API에서는 Opus 4.7 이상이 요금제와 무관하게 1M 창으로 실행되고 기본 자동 압축은 약 967K 토큰

## 교육과 업무에 활용

- '너무 빨리 압축된다'면 먼저 현재 모델의 컨텍스트 창(200K/1M) 확인
- 새 모델이 CLI에 안 보이면 도구 업데이트부터
