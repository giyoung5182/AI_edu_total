## 정리된 지식

- Claude Code 교차 세션 메시지: v2.1.224 이상(macOS·Linux, Windows는 v2.1.234 이상)에서 기본 활성. Claude가 ListAgents로 대상 세션을 찾고 SendMessage로 텍스트를 전달하며, @세션이름으로 대상 지정 가능. /list-agents(별칭 /peers)로 연결 가능한 세션 확인
- 메시지는 텍스트만 전달(대화 기록·파일은 아님), 받는 쪽 권한 확인은 그대로 작동, 다른 PC·클라우드 세션은 Remote Control 연결 시 가능
- Claude Code→Codex: OpenAI 공식 저장소 openai/codex-plugin-cc를 /plugin marketplace add openai/codex-plugin-cc → /plugin install codex@openai-codex → /codex:setup 순서로 설치. /codex:review(리뷰), /codex:adversarial-review(설계 반박 리뷰), /codex:rescue(작업 위임) 등 제공. ChatGPT 구독(무료 포함) 또는 OpenAI API 키와 Node.js 18.18 이상 필요(Codex CLI는 /codex:setup이 설치를 제안하거나 npm으로 직접 설치)
- Codex 공식 문서 기준 codex mcp-server 명령(Codex를 MCP 서버로 띄우던 방식)은 제거됨
- [추가 2026-07-16] 교차 세션 메시징: v2.1.224 이상(macOS·Linux)·v2.1.234 이상(Windows)에서 별도 설정 없이 켜짐, 같은 기기 세션은 로컬 소켓으로 전달되고 수신 세션의 권한 규칙이 그대로 적용
- [추가 2026-07-16] 에이전트 팀은 실험 기능으로 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1로 활성화, 팀원끼리 직접 메시지·공유 작업 목록, 단일 세션보다 토큰 사용이 크게 늘어남
- [추가 2026-08-20] 7/31 커뮤니티 안내: Claude Code에서 /plugin marketplace add openai/codex-plugin-cc 후 /plugin install codex@openai-codex로 설치, codex exec 헤드리스 호출이라 두 에이전트가 실제로 대화하는 구조는 아님(MCP 연결도 동일). OMC 같은 비공식 하네스를 구독 인증으로 쓰면 제재 위험이 있다는 주장은 공식 미확인. Claude를 메인, Codex를 서브로 두어 Claude 토큰을 아끼는 운용 사례
- [추가 2026-09-02] 커뮤니티 추가 사례: Orca에서 Claude가 Codex Luna를 워커로 호출, Claude 스킬로 호출 절차화. 반대로 Codex에 작업을 맡겼더니 Codex가 Claude를 서브에이전트로 호출해 Claude 한도 40%를 썼다는 사례(9/4)가 있어 교차 호출 시 양쪽 한도가 모두 소모됨에 주의. 9/13 '앤트로픽 공식 codex:review 훅'이라는 언급은 기존 카드대로 OpenAI 공식 플러그인(codex-plugin-cc)임.

## 교육과 업무에 활용

- 멀티 AI 협업 교육 시 '세션 간 메시지(같은 Claude끼리)'와 '플러그인 호출(다른 회사 AI)'을 나눠 시연
- 설계는 A, 리뷰는 B 방식 워크플로우를 /codex:adversarial-review 예시로 구체화

## 정정과 한계

'MCP로 연결'이라는 답은 원본 확인일의 공식 문서와 다름: Codex의 codex mcp-server는 제거되었고, Claude Code에서 Codex를 부르는 공식 경로는 codex-plugin-cc 플러그인임. pi·omp 연결 방법은 공식 확인하지 못함.
