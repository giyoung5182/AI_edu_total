## 정리된 지식

- Anthropic 발표: Opus 5.5는 2026-09-22 출시, 입력 $4/출력 $20 per MTok(Opus 5는 $5/$25), 캐시 읽기 $0.20. '기본 설정에서 일반 작업 기준 Opus 5보다 40% 저렴', 출력 속도 30% 이상 향상. 컨텍스트 1M, 최대 출력 128K. Claude Code 문서: Pro·Max·Team·Enterprise·API 계정의 'default' 모델은 Opus 5.5. Claude 모델 개요 문서도 '모델이 확실하지 않으면 Opus 5.5로 시작'을 권장.
- [추가 2026-09-23] 공식 발표 재확인: Opus 5.5는 입력 $4·출력 $20(각 20% 인하), 캐시 읽기 $0.20(60% 인하), 일반 작업 비용 40% 절감·출력 30% 이상 빠름, Pro·Max·Team·좌석형 Enterprise의 5시간 한도 상향과 원할 때 쓰는 리셋권 1회 지급. 9/17 돌던 'Opus 5.2 출시' 소문은 실제로 Opus 5.5 출시로 이어짐. 커뮤니티 체감 '3배 빨라짐'은 공식 수치(30% 이상)와 다름.
- [추가 2026-09-23] 공식 페이지의 '40%'는 일반 워크로드 실행 비용 기준 문구임(토큰 단가 인하율과 구분 필요).
