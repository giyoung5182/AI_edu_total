## 정리된 지식

- 모드는 Claude Code의 모양과 동작을 바꾸는 플러그인으로, 도구 호출·프롬프트 제출·화면 그리기 같은 이벤트에 JavaScript/TypeScript 핸들러를 붙이는 방식
- 할 수 있는 일: 대화 옆 패널·프롬프트 위 밴드 그리기, 기존 UI(도구 호출 행·스피너 등) 재구성, 도구 호출 보류·대체, 즉시 실행 /command 추가
- Claude Code v2.1.287 이상에서 기본 활성, /plugin install로 설치, 터미널과 데스크톱 앱 Code 탭에서 화면이 그려지고 VS Code 확장·claude -p에서는 그려지지 않음
- 모드는 샌드박스가 없고 사용자 권한으로 파일 읽기·쓰기·프로세스 실행·네트워크 요청·비밀 읽기·도구 호출 자동 승인이 가능 — 신뢰하는 작성자만 설치, claude plugin validate로 사전 점검
- 권한 확인 프롬프트는 모드가 바꿀 수 없음, 끄려면 --safe-mode 또는 disableAllHooks
- [추가 2026-10-01] - Claude 공식 블로그(2026-10-01): 모드는 'Claude Code의 동작을 바꾸는 작은 TypeScript 함수', 플러그인에 담겨 CLI·데스크톱 앱에서 /plugin으로 설치, 일반 플러그인처럼 디렉터리로 배포. 프롬프트 재작성·위험 명령 차단·커스텀 UI·내장 기능 대체 가능, Claude Code에 요청해 생성도 가능
- 조직용: 내장 sec-default 모드가 사용자가 설치한 모드의 보안 규칙 우회를 막음. 샘플 모드(token-weather·blast-radius·replay-theater)는 anthropics/claude-code-playground 저장소에 공개

## 교육과 업무에 활용

- 모드는 'UI 스킨'이 아니라 실행 코드 — 교육 시 플러그인 설치 보안 점검 절차와 함께 소개
- 상태 표시·컨텍스트 차트 같은 개인 대시보드는 Claude에게 모드 작성을 요청해 시작 가능
