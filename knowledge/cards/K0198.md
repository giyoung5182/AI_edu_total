## 정리된 지식

- Claude Code 법률·컴플라이언스 문서: OAuth 인증은 Free·Pro·Max·Team·Enterprise 구매자의 Claude Code 및 기타 Anthropic 네이티브 앱의 '일반적 사용'을 위한 것
- 제품·서비스를 만드는 개발자(Agent SDK 포함)는 API 키 인증을 써야 하며, 제3자 개발자가 Claude.ai 로그인을 자체 앱에 제공하거나 Free·Pro·Max 자격증명으로 사용자 요청을 중계하는 것을 허용하지 않고, 자격증명·세션 토큰을 수집·저장·중계할 수 없음. Anthropic은 사전 통지 없이 제재할 수 있다고 명시
- 개인이 자기 프로젝트에서 Agent SDK·claude -p를 쓰는 경우는 2026-06-15 기준 구독 한도에서 차감(도움말), Pro·Max 광고 한도는 '일반적 개인 사용'을 전제
- CLIProxyAPI 자체의 약관 적합성은 공식 판단 문서 없음 — 위 조항 기준으로 위험 소지 판단
- Claude Code 공식 법무·준수 문서: OAuth 인증은 Free·Pro·Max·Team·Enterprise 구독자의 Claude Code 및 Anthropic 자체 앱 '일반 사용'을 위한 것
- 제품·서비스를 만드는 개발자(Agent SDK 포함)는 Claude Console 또는 클라우드 사업자의 API 키 인증을 써야 하며, 제3자 앱에 Claude.ai 로그인을 제공하거나 Free·Pro·Max 자격증명으로 요청을 중계하는 것은 불허
- Anthropic은 사전 통지 없이 이 제한을 집행할 수 있다고 명시
- OpenAI 측 허용 여부: OpenClaw 공식 문서는 'OpenAI가 OpenClaw 같은 외부 도구에서 구독 OAuth 사용을 명시적으로 지원한다'고 쓰지만 OpenAI 자체 문서로는 확인하지 못함
- OpenAI는 Codex를 외부 제품에 깊게 통합하는 인터페이스로 Codex App Server(JSON-RPC 2.0, 오픈소스)를 공식 제공

## 교육과 업무에 활용

- 비공식 브릿지·프록시는 계정 정지 위험을 안고 쓰는 선택임을 명확히 교육
- 다른 회사 모델을 섞을 땐 각 사 API 키나 공식 플러그인 경로 권장
- 웹앱·팀 서비스에 AI를 붙일 땐 반드시 API 키 방식
