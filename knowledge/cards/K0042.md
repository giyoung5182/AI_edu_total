## 정리된 지식

- Remote Control: claude.ai/code 또는 Claude 모바일 앱(iOS·Android)을 내 PC에서 실행 중인 Claude Code 세션에 연결하는 기능. 코드 실행·파일 접근은 계속 내 PC에서 일어나므로 PC가 켜져 있고 claude 프로세스가 살아 있어야 함
- 시작 방법: 터미널에서 claude remote-control(서버 모드, 스페이스바로 QR코드 표시), claude --remote-control(또는 --rc), 이미 실행 중인 세션에서는 /remote-control(또는 /rc). VS Code 확장·Desktop 앱에서도 /rc 사용 가능
- 조건: Pro·Max·Team·Enterprise 구독 로그인 필요, API 키 방식은 미지원, Team·Enterprise는 관리자가 먼저 기능을 켜야 함
- Codex 쪽 원격: ChatGPT 데스크톱 앱 Settings > Connections에서 설정 후 폰 ChatGPT 앱으로 QR 연결. 공식 문서상 이 모바일 설정은 Codex CLI나 IDE 확장에서 시작할 수 없음(SSH 호스트 원격 연결은 데스크톱 앱에서 지원)
- [추가 2026-07-16] Remote Control 공식 문서: 세션은 내 컴퓨터에서 계속 로컬 실행되며, 노트북이 잠자기에 들어가거나 네트워크가 끊겨도 컴퓨터가 다시 온라인이 되면 자동 재연결 — 즉 원격 조작 중에는 로컬 머신이 켜져 있어야 함
- [추가 2026-07-28] 모바일에서 제어하려면 /remote-control, 기본 설정에서 remote-control을 항상 켜두면 모든 기기에서 세션 동기화된다는 경험, Tailscale로 개발 서버를 띄워 태블릿에서 확인하는 방식도 공유
- [추가 2026-07-10] Claude Cowork Dispatch: 폰의 Claude 앱으로 지시하면 데스크톱에서 로컬 파일·커넥터·앱으로 작업 후 결과만 전달, 컴퓨터가 깨어 있고 Claude Desktop이 열려 있어야 함, Pro·Max 제한 베타이며 현재 신규 사용자에게는 제공되지 않음(클라우드 세션은 PC가 꺼져도 동작)

## 교육과 업무에 활용

- 직접 원격 도구를 만들기 전에 공식 Remote Control(무료 포함 기능)부터 시연
- '원격 조작 = 내 PC가 계속 켜져 있어야 함' 조건을 비개발자에게 먼저 설명

## 정정과 한계

VS Code의 Codex 원격 가능 여부에 '있다'는 답은 부분적으로만 맞음: 공식 문서 기준 폰 원격 설정은 ChatGPT 데스크톱 앱에서 시작해야 하며 CLI·IDE 확장에서는 설정할 수 없음.
