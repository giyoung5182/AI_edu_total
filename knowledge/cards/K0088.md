## 정리된 지식

- Claude Code 공식 문서: claude.ai 구독 로그인 대화형 세션에서 사용 한도로 작업이 멈추면 세션을 열어둔 채 대기하다 리셋 후 자동으로 이어서 진행(기본 켜짐, v2.1.234 이상, autoContinueAtUsageLimit 설정). /rate-limit-options로 대기·추가 사용량·업그레이드 선택 가능
- /loop는 세션이 열려 있는 동안 프롬프트를 주기적으로 반복 실행, /schedule은 클라우드에서 도는 루틴(예약·트리거 실행) 생성
- Claude Code GitHub Actions: 이슈·PR 댓글에 @claude를 멘션하거나 새 이슈 본문에 포함하면 Claude가 분석·구현·커밋하며, prompt 입력을 주면 멘션 없이 모든 GitHub 이벤트(크론 포함)에 자동 실행 → '티켓 생성 시 자동 작업'을 공식 기능으로 구현 가능
- 비용은 GitHub Actions 실행 시간과 API 토큰(구독 OAuth 토큰 사용 시 구독 한도)으로 발생

## 교육과 업무에 활용

- '티켓→에이전트 자동 작업' 수요는 GitHub Actions의 @claude 워크플로우로 시연 가능
- 자동 실행에는 --max-turns·타임아웃 같은 상한 설정을 함께 교육
