## 정리된 지식

- 네이버 커머스API 공식 GitHub FAQ: 커머스API는 스마트스토어의 상품 관리·주문 처리·정산 등을 프로그램으로 다루는 API이며 인증 정보 발급이 필요하고, 상품 정보 수정도 API로 가능(수정 시 일부 정보가 제거되는 사례 FAQ 존재)
- Manus 공식 문서: 작업 복잡도에 따라 크레딧이 차감되는 크레딧제, Free·Pro·Team 플랜
- Manus 모델 구성(자사 모델·타사 모델 조합)에 대한 커뮤니티 설명은 공식 확인하지 않음

## 교육과 업무에 활용

- 커머스 자동화 교육은 '공식 API 제공 범위 확인 → 테스트 계정 → 실판매 반영' 순서
- 결제·재고처럼 돈이 걸린 작업은 멱등성(중복 실행 방지)과 사람 승인 단계 필수
- 공식 API가 없는 서비스의 무단 수집은 약관 위반 위험 안내
