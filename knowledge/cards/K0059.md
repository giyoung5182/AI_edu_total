## 정리된 지식

- Gemini CLI 공식 인증 문서: gemini 실행 후 'Sign in with Google' 선택이 기본 방법. Google AI Pro·Ultra 구독 계정으로 로그인 가능
- Google 공식 블로그(2025-09-24): 모든 Google AI Pro·Ultra 구독자에게 Gemini CLI와 Gemini Code Assist를 더 높은 요청 한도로 제공, 기존 Google 계정으로 로그인해 사용
- 조직(Workspace) 계정은 Google Cloud 프로젝트 설정이 추가로 필요
- 요금제별 구체 한도는 공식 한도 페이지에서 별도 확인 필요
- [추가 2026-08-07] Google 공식 개발자 블로그(2026-05-19): Gemini CLI를 Antigravity CLI로 전환, 2026-06-18부터 무료·유료 개인 사용자 대상 Gemini CLI 요청 중단(Enterprise는 유지). 구글의 코딩 에이전트는 Antigravity 계열이라는 커뮤니티 답과 일치, 프론트 화면을 망가뜨려 검색용으로만 쓴다는 체감도 있음

## 교육과 업무에 활용

- 구독형 AI를 터미널 도구에서 재사용하는 공통 패턴(Claude Code·Codex·Gemini CLI 모두 계정 로그인 방식) 설명에 활용

## 정정과 한계

'제미나이 구독했으면 CLI 가능'은 2026-06-18 이후 개인 사용자에게는 맞지 않음 — Google 공식 개발자 블로그(2026-05-19) 발표로 개인 대상 Gemini CLI 요청 중단, Antigravity CLI로 전환.
