## 정리된 지식

- Claude API 캐시 읽기는 기본 입력 단가의 0.1배, 캐시 쓰기는 5분 1.25배·1시간 2배이며 이 배수는 Batch API 할인과 중첩 적용(공식 문서)
- 구독 요금제의 정확한 토큰 환산량은 공개되지 않으므로 '구독 30만원 = API 천만원' 같은 수치는 커뮤니티 추정
- '구독제 적자 운영' 주장은 공식 확인 불가
- [추가 2026-10-02] 기업 현장 체감: 회사가 API 방식으로 개인당 월 $2,000 한도를 줘도 정가가 높아 체감상 $200 구독과 비슷하다는 사례, 대기업은 API 비용 감당이 어렵다는 의견

## 교육과 업무에 활용

- 비용 판단 기준: 사람이 대화하며 반복 작업하면 구독, 정형화된 대량 처리·서비스 연동은 API(캐싱·배치 설계)
- 간헐적 고급 모델 사용은 API가 유리할 수 있어 사용 패턴별 계산 예시 제공
