## 정리된 지식

- Claude 도움말: 리셋은 자격 있는 요금제에 수시로 지급되며 사용 시 5시간 세션 한도 또는 주간 한도(보유한 리셋 종류에 따라)를 즉시 가득 채움. 사용 위치는 웹·Claude 데스크톱의 설정 > 사용량 > 'Reset for free' 버튼이며 모바일 앱과 Claude Code 터미널에서는 사용 불가. 주간 리셋 요일·시각은 그대로 유지, 사용 전 다운그레이드·해지 시 소멸
- Claude Code 공식 명령어 목록에는 /limit-reset이 없음(한도 관련은 /usage, /usage-credits, /rate-limit-options)
- OpenAI 도움말: 'full banked reset'은 5시간·주간 Codex 사용 창을 모두 새로 채우지만, 다음 주간 리셋은 리셋 사용 후 사용 재개 시점 기준 약 1주 뒤로 이동(예: 금요일 리셋 예정 → 화요일 사용 시 다음 화요일경)
- '툴 사용한도 만료' 안내의 정확한 의미는 공식 문서에서 확인하지 못함

## 교육과 업무에 활용

- '리셋이 안 된다' 문의는 사용 위치(웹·데스크톱 설정)부터 확인하도록 안내
- 코덱스 리셋은 '추가 한도'가 아니라 '주기 재시작'에 가깝다는 점을 요금제 교육에 반영

## 정정과 한계

커뮤니티 지식베이스의 '리셋권은 한도 50%만 채운다'는 체감과 달리, 공식 도움말(Claude·OpenAI 모두)은 리셋이 해당 한도를 '가득(full)' 채운다고 설명함. 다만 Codex는 다음 정기 리셋일이 뒤로 밀려 주 단위 총량 체감이 줄 수 있음.
