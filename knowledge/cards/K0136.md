## 정리된 지식

Claude Code 공식 문서: Opus 5.5·Sonnet 5.5·Fable 등은 low/medium/high/xhigh/max 지원, 기본값은 대부분 high이고 Opus 5.5·Sonnet 5.5는 medium. 전환은 /effort(슬라이더 또는 /effort high), /model 선택기 좌우 화살표, --effort 플래그, 설정 파일. 권장 용도: low 빠른 교환, medium 범위 명확한 일상 개발, high 검증 중요 작업, xhigh 더 깊은 추론, max 어려운 자율 과제(수익 체감 가능). ultracode는 모델 effort 단계가 아니라 어느 effort에서든 동적 워크플로우를 계획하는 Claude Code 설정(/effort ultracode로 켜고 끄거나, /effort 슬라이더에서 Tab으로 토글 후 Enter. 켜고 꺼도 effort 단계는 변하지 않음).
- [추가 2026-10-04] 공식 문서: Ultracode는 /effort 슬라이더의 토글이지만 모델 effort 단계가 아니며, 켜거나 꺼도 effort 레벨은 바뀌지 않음(세션의 effort 그대로 동적 워크플로 실행). Opus 5.5·Sonnet 5.5 effort 단계는 low·medium·high·xhigh·max.

## 교육과 업무에 활용

작업 유형별 effort 선택표로 교육. '높을수록 좋다'가 아니라 비용 대비 효과로 선택.

## 정정과 한계

'탭하면 effort 모드가 전환된다'는 부정확 — 공식 문서상 /effort 슬라이더에서 Tab을 누르면 바뀌는 것은 effort 단계가 아니라 Ultracode 토글(Enter로 적용)이며, Ultracode를 켜고 꺼도 effort 단계는 그대로 유지됨. effort 단계 전환은 /effort·/model·--effort.
