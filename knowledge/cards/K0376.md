## 정리된 지식

- 공식: macOS·Windows의 ChatGPT 데스크톱 앱에서 ChatGPT Work·Codex로 사용, 앱 클릭·입력·이동을 자율 수행
- 필요한 앱 로그인은 사용자가 미리 해야 하며 시스템이 자격증명을 관리하지 않음, 보내기·제출·중요 데이터 변경 전 일시정지
- 같은 앱에 Computer Use 작업 2개 동시 실행 금지, Windows는 화면 전면을 점유(macOS는 백그라운드 가능)
- 웹·모바일 Cloud Work는 로컬 앱에 직접 접근 불가

## 교육과 업무에 활용

- 레거시 자동화는 '사람 로그인 → 에이전트 조작 → 중요 동작 승인' 3단계로 설계
- 비밀번호를 프롬프트에 넣지 않고 비밀번호 관리자·로그인 유지 활용
- 사내 도입 전 IT 보안팀과 허용 범위 합의
