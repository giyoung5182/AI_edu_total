## 정리된 지식

- 공식 channels: MCP 서버가 실행 중인 Claude Code 세션에 이벤트를 밀어 넣는 기능, Telegram·Discord·iMessage 플러그인 제공, 리서치 프리뷰
- 설치: /plugin install telegram@claude-plugins-official → /telegram:configure <토큰> → claude --channels plugin:telegram@claude-plugins-official 로 재시작 → 페어링 후 allowlist 정책
- 세션이 열려 있을 때만 메시지 도착(상시 운용은 백그라운드·지속 터미널), Bun 필요
- Pro·Max 개인은 바로 사용, Team·Enterprise는 Owner가 활성화해야 함

## 교육과 업무에 활용

- 자작 중계보다 공식 플러그인+발신자 allowlist로 보안 확보
- 채널로 권한 승인까지 넘기면 승인 권한을 가진 사람 범위 관리 필요
- 세션 자체를 폰에서 조작하려면 Remote Control과 구분해 안내
