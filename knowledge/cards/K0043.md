## 정리된 지식

- 클라우드 세션: Anthropic 관리 VM에서 도는 Claude Code 세션. 노트북을 닫아도 계속 실행되고 웹·모바일·Desktop·터미널에서 확인 가능. Pro·Max·Team 및 일부 Enterprise 좌석에서 사용 가능
- 코드는 GitHub에서 가져옴: claude --cloud "작업 내용"은 현재 폴더의 GitHub 원격 저장소·현재 브랜치를 복제하므로 로컬 커밋은 먼저 push 필요
- 원격 저장소가 없거나 Claude GitHub App이 설치되지 않은 저장소면 로컬 저장소를 번들로 묶어 업로드(100MB 미만, 추적되지 않은 파일은 제외, 커밋이 1개 이상 있어야 함)
- 반대 방향: claude --teleport로 클라우드 세션과 브랜치를 내 터미널로 가져옴. 이미 진행 중인 터미널 세션을 CLI로 클라우드에 밀어 올리는 것은 불가(Desktop 앱의 Continue in 메뉴는 가능)
- [추가 2026-08-11] Claude Code 공식 문서: 클라우드 세션은 claude --teleport(세션 선택기) 또는 claude --teleport <세션ID>, CLI 안에서 /teleport(/tp), claude.ai/code의 Open in > Terminal로 로컬 터미널로 가져올 수 있음. 요건은 깨끗한 git 상태·같은 저장소(포크 불가)·원격에 푸시된 브랜치·같은 claude.ai 계정. 가져온 뒤 작업은 로컬 사본에만 남음(커뮤니티의 zip 수동 이관보다 공식 경로)

## 교육과 업무에 활용

- 클라우드 세션 실습 전 '코드는 GitHub에 올려 두기'를 준비 단계로 안내
- 로컬 세션을 밖에서 조작하려면 클라우드가 아니라 Remote Control이라는 구분을 함께 설명

## 정정과 한계

'로컬 프로젝트를 못 옮긴다'는 답은 부분적으로 틀림: 대화(세션) 자체는 CLI에서 클라우드로 넘길 수 없지만, 프로젝트 코드는 GitHub push 또는 로컬 번들 업로드로 클라우드 세션에서 이어 작업 가능.
