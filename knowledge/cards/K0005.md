## 정리된 지식

- Anthropic 도움말: Fable 5/5.1은 모든 유료 플랜(Pro·Max·Team·Enterprise)에서 사용 가능. Max와 프리미엄 좌석은 주간 한도의 최대 50%를 추가 비용 없이 Fable에 쓸 수 있음. Pro와 표준 좌석은 플랜 할당량이 아니라 사용 크레딧(usage credits, 종량 결제)으로만 Fable 이용. Fable 사용이 주간 총량을 늘리지 않으며 '주간 한도를 넘어 쓸 수 없음'이 원칙이고, 한도 도달 시 크레딧으로 Fable을 계속 쓰거나 다른 모델로 전환.
- [추가 2026-07-22] 공식 경과: 2026-07-01 재배포 시 Pro·Max·Team·일부 Enterprise에 7/7까지 주간 한도의 최대 50% 포함, 이후 사용 크레딧(Anthropic 뉴스)
- [추가 2026-07-22] 7/18 발표: 7/20부터 Max·Team Premium에 50% 한도로 정식 포함, Pro·Team Standard는 사용 크레딧 방식+일회성 $100 크레딧(Claude 공식 X), 도움말은 이 프로모션 종료를 '2026-07-19 11:59:59 PM PT'로 표기, $100 크레딧은 Fable 5에만 적용
- [추가 2026-07-22] 커뮤니티의 '7일 이후 API 가격 2배' 주장은 공식 페이지에서 확인되지 않음
- [추가 2026-08-24] Claude 도움말: Fable 5가 2026-07-19 사용 크레딧 방식으로 전환될 때 자격 있는 Pro·표준 Team 좌석에 1회성 크레딧 지급(금액은 도움말에 미기재, 커뮤니티는 $100로 언급). Max·프리미엄 좌석은 주간 한도의 최대 50%까지 추가 비용 없이 사용. Max $100에서 Fable 전환 시 추가 크레딧 옵션을 켜라는 메시지가 떴다는 보고는 원인 미확인
- [추가 2026-09-26] 공식 도움말 재확인: Max와 Team·Enterprise 프리미엄 좌석은 주간 한도의 최대 50%까지 Fable 사용(추가 용량이 아니라 같은 주간 한도에서 차감), Pro·표준 좌석은 사용 크레딧 과금. 커뮤니티의 '50% 한도 사라졌나', '정책이 바뀌어 구독도 가능'은 이 구조(Max 포함, Pro 크레딧)로 정리됨. Fable 사용분은 사용량 설정(usage settings)에서 확인.

## 교육과 업무에 활용

'모델별 한도'와 '전체 주간 한도'는 별개가 아니라 포함 관계라는 점을 도식으로 설명.

## 정정과 한계

'주간 한도를 다 써도 Fable 한도가 남으면 계속 쓸 수 있다'는 답은 공식 설명과 다름: Fable 몫(최대 50%)은 주간 한도 안의 일부이며 주간 한도 소진 후에는 크레딧 결제가 필요. 'Max부터 사용 가능' 추측도 부분만 맞음(Pro는 크레딧으로 사용 가능).
