## 정리된 지식

- Claude Code MCP 문서는 DB 연결 예시에서 읽기 전용 DB 사용자를 쓰도록 안내 — 데이터 변경 없이 조회만 가능하게 하는 목적
- 외부 콘텐츠를 가져오는 MCP 서버는 프롬프트 인젝션 위험이 있으므로 연결 전 신뢰 여부 확인 권고
- 읽기 전용이라도 조회 결과가 모델 컨텍스트(외부 서비스)로 전송되는 점은 별도 사내 정책 판단 사항(공식 문서가 허용 여부를 정해주지 않음)

## 교육과 업무에 활용

- 'read-only = 안전'이 아니라 '변경 방지'일 뿐, 데이터 반출 여부는 사내 보안정책 판단이라는 구분 교육
- 개발·테스트 DB 또는 마스킹 데이터로 실습 설계
