# Windows(WSL)에서 Hermes 게이트웨이가 터미널 종료 시 멈추면 systemd 서비스+WSL VM 상시 유지로 해결

## 정리된 지식

- Hermes Agent 공식 WSL2 가이드: systemd를 켜두면 hermes gateway가 일반 리눅스처럼 동작하며, 설치 마법사가 WSL 시작 시 게이트웨이를 자동 실행하는 systemd 사용자 유닛 설치를 제안
- 터미널을 닫을 때 WSL VM이 내려가는 것을 막기 위해 Windows 작업 스케줄러로 로그인 시 백그라운드 프로세스(-d Ubuntu --exec /bin/sh -c "sleep infinity")를 띄워 VM을 유지하는 방법을 안내
- PC 자체는 켜져 있어야 한다는 점은 커뮤니티 답과 동일

## 교육과 업무에 활용

- 상시 에이전트 운영은 '프로세스 서비스화'와 '호스트 상시 가동'을 구분해 설명
- 맥미니 구매 전 기존 PC의 WSL 서비스화부터 시도

## 정정과 한계

'터미널을 닫으면 멈추는 것'은 피할 수 없는 현상이 아니라 WSL VM 종료 때문. systemd 서비스 등록+VM 유지 설정으로 터미널 없이 상시 실행 가능(PC 전원은 유지 필요)
