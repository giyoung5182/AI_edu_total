## 정리된 지식

- opusplan 별칭: 플랜 모드에서는 Opus로 추론·설계, 실행 모드에서는 자동으로 Sonnet으로 전환(/model opusplan)
- advisor 도구(실험 기능): 메인 모델이 접근 방식 결정 전·반복 오류·완료 선언 전 등 결정 지점에서 더 강한 자문 모델을 호출, /advisor opus·advisorModel 설정·--advisor 플래그로 지정
- advisor는 메인 모델 이상 등급만 허용(예: Sonnet 5.5 메인 → Fable·Opus 5 이상·Sonnet 5.5), Haiku는 자문 모델 불가
- 구독 요금제에서는 advisor 사용량도 플랜 한도에 포함(Fable 자문은 사용 크레딧), advisor 켜고 끄기는 메인 모델 프롬프트 캐시를 깨지 않음
- Anthropic API 전용(Bedrock 등 미지원)

## 교육과 업무에 활용

- 비용 절감형 조합: Sonnet 메인+Opus advisor, 계획 중심 작업은 opusplan
- 광고성 '자동 전환 스킬'보다 공식 기능부터 확인
