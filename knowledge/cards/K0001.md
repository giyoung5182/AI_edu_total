# Claude 리셋권(limit reset)은 한도를 가득 채우고 주간 리셋 요일은 그대로 유지

## 정리된 지식

- Anthropic 도움말 기준 limit reset은 사용자가 원하는 시점에 5시간 세션 한도 또는 주간 한도(제공된 종류에 따라)를 '가득(back to full)' 되돌리는 일회성 혜택. 사용해도 주간 한도는 원래 요일·시각에 그대로 리셋됨. 사용 위치는 웹/데스크톱 Settings > Usage의 'Reset for free' 버튼이며, 만료일이 있으면 같은 화면에 표시되고 만료 후 소멸. 사용 전에 다운그레이드하거나 해지하면 리셋권은 사라짐. 업그레이드 시 유지 여부와 대상 플랜 목록은 문서에 명시되지 않음.
- [추가 2026-08-25] 8월 커뮤니티에서는 'Claude에는 초기화권이 없다'는 인식이 있었고, 8/25 일부 사용자만 초기화됐다는 보고
- [추가 2026-09-30] 2026-09-30 사용량 탭 UI 개편으로 초기화권 칸에 '전체 초기화/5시간 초기화' 구분이 생겼다는 공유. 공식 도움말도 리셋이 5시간 세션 한도 또는 주간 한도를 다시 채우는 것이라고 설명하며, 웹·데스크톱 설정>사용량에서만 사용 가능(모바일·Claude Code 터미널 불가), 다운그레이드·해지 시 미사용 리셋 소멸

## 교육과 업무에 활용

리셋권은 주간 리셋 직전이 아니라 한도가 막힌 직후에 쓰는 것이 유리(요일 고정이므로 손실 없음). 해지·다운그레이드 전에 먼저 사용할 것.

## 정정과 한계

'리셋권은 50%만 채워준다'는 체감은 Claude 공식 문서와 다름: 문서는 한도를 '가득' 되돌린다고만 설명하며 부분 충전 비율 언급이 없음. 업그레이드 시 유지 여부는 공식 미확인. B079의 '리셋권 쓰면 리셋 요일도 바뀐다'는 답은 Claude에는 틀리고 Codex 뱅크드 리셋에만 해당.
