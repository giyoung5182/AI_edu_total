# Claude Team 플랜은 퇴사자 제거 후 빈 좌석 재배정 가능, 공개 도메인(gmail 등) 허용 도메인 추가 가능

> 역사 자료. 확인 수준과 확인일은 원본 기록을 보존한 값입니다. 공개 편집일의 최신 기능·가격·법률 확인을 의미하지 않습니다.

- 카드: K0011
- 분류: 요금제·사용량·비용
- 기록 기간: 2026-09-15 ~ 2026-09-15
- 원본 확인일: 2026-09-29
- 원본 상태: **공식확인**
- 공개 편집일: 2026-10-08

## 정리된 지식

Anthropic 도움말: Organization settings > Members에서 'Remove from team'을 하면 해당 좌석이 비어 다른 사용자에게 배정 가능(좌석 수 자체는 자동 감소하지 않음). 초대는 조직의 허용 이메일 도메인만 가능. 계정 생성자는 업무용 이메일이 필요하며, 이후 Owner가 @gmail.com·@yahoo.com·@hotmail.com 같은 공개 도메인을 다른 구성원용 허용 도메인으로 추가 가능.

## 교육과 업무에 활용

교육용 팀 계정 운영 시 '좌석 재배정' 방식으로 기수별 수강생 교체 가능. 공개 도메인 허용은 보안 정책과 함께 판단.
