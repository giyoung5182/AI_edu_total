## 정리된 지식

- 기존 지식베이스 기준: 여름 +50% 프로모션은 2026-09-13 종료, 2026-09-14부터 Pro/Max/Team 등 주간 한도 기본값 대비 25% 영구 상향(100→150→125, 프로모션 대비 약 17% 감소). 50% 프로모션은 주간 사용 한도에 대한 것이며, 컨텍스트 윈도우 크기 변경은 공식·보도에서 언급되지 않음. 이번 작업에서는 Anthropic 자사 공지 원문을 직접 열어보지 못해 보도 기준으로 유지.
- [추가 2026-07-20] ClaudeDevs 공식 X: Claude Code 주간 한도 50% 상향을 8월 19일까지 Pro·Max·Team·좌석 기반 Enterprise에 유지
- [추가 2026-08-28] Anthropic 개발자 공식 X(ClaudeDevs) 공지 기준 Claude Code 주간 한도 50% 상향이 8/19까지 연장됐다가 8/31까지 재연장, 이후 9/14부터 표준 주간 한도 25% 영구 상향. 8월 초 Cowork는 100% 상향(8/5까지)이었다는 커뮤니티 공유. 8월 말 프로모션 종료 안내문을 보고 9월 한도 부족을 우려하는 반응
- [추가 2026-09-27] 9/14 16시(KST)경 여름 +50% 프로모션 종료 후 체감 한도 급감 반응 다수, '50% 인상에서 25% 인상으로 줄었다'고 정리됨. 9/27 Opus 5.5 이후 '주간한도가 빨리 줄어든 게 아니라 5시간 세션 한도가 길어져 그렇게 보인다'는 해석(공식 발표상 5시간 한도 상향과 일치).
