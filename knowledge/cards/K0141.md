## 정리된 지식

Google 태그 관리자 공식 도움말: GA4 속성·웹 데이터 스트림 생성 → Tag Manager에서 새 태그 → 태그 유형 'Google 태그' + 측정 ID 입력 → 트리거 'Initialization - All Initialization Events' → 컨테이너 게시. 공식 문서가 GTM 경유를 직접 설치보다 '더 안정적'이라고 명시하지는 않음 — 안정성 평가는 커뮤니티 의견.

## 교육과 업무에 활용

외부 플랫폼 설정처럼 단계가 얽힌 작업은 구조를 이해하고 단계별로 나눠 지시해야 한다는 'AI 한계' 교육 사례.
