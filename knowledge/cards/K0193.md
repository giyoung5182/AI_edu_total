- 공식 발표: Opus 4.8이 여전히 전반적으로 더 유능하지만 Sonnet 5가 격차를 크게 좁혔고 일부 작업은 훨씬 낮은 비용으로 Opus 수준
- Claude Code 주간 노트: Pro·Team Standard·Enterprise 구독 좌석의 새 기본 모델, 네이티브 1M 토큰 컨텍스트, API 가격 $2/$10 per MTok(주간 노트는 8/31까지 프로모션, 발표 페이지는 8/10부터 정가로 표기 — 문서 간 표기 차이 있음), v2.1.197 이상 필요
