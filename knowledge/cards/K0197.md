## 정리된 지식

- Z.ai 공식: GLM Coding Plan은 Lite·Pro·Max 3단계이며 '월 18달러부터' 시작, Claude Code 외 Cline·OpenCode 등 도구 지원(2026-09 문서 기준, 현재 GLM-5.3 계열 중심)
- 문서 기준 크레딧: Lite 5시간 2,000·주간 10,000, Pro 12,000·60,000, Max 28,000·140,000, 싱가포르 시간 평일 14~18시가 피크
- ZCode는 Z.ai의 별도 앱으로 모델 연결 설정 문서 제공
- 연간 360→1,300달러 인상, 'ZCode 1.5배' 등 수치는 커뮤니티 발언으로 이번에 공식 확인 못함
- Z.ai 공식 문서 기준 GLM Coding Plan은 Lite·Pro·Max 3단계, 월 18달러부터 시작
- 5시간·주간 크레딧 한도 구조(Lite 2,000/10,000, Pro 12,000/60,000, Max 28,000/140,000)
- Claude Code, Cline, OpenCode 등 외부 코딩 도구에서 사용 가능, GLM-5.3·GLM-5.3-Flash 지원(2026-09 기준 문서)
