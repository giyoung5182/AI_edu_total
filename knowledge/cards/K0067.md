## 정리된 지식

- 공식 문서: ChatGPT Voice는 GPT-Live 기반으로 Chat·Work·Codex에서 말로 아이디어를 정리하고 작업을 조율하는 기능
- 데스크톱 앱 기준 Plus·Pro·Business·Edu·Enterprise 요금제에서 제공, 무료 계정 미지원으로 명시
- 데스크톱 앱 전체에서 동시에 하나의 음성 대화만 가능, iOS는 데스크톱 호스트와 페어링한 Remote에서 사용
- 모바일 앱 단독 음성 기능의 요금제별 제공 범위는 원본 정리 시 확인 범위에서 확인하지 못함
- [추가 2026-09-30] GPT Live가 말 중간에 끼어드는 현상에 대해 '원래 중간에 끼어들게 설계됐다', '초기보다 추임새를 넣으며 말이 끝나는 지점을 잘 잡도록 적응형으로 나아졌다'는 사용자 체감. 설정으로 조정하는 공식 옵션은 확인되지 않음
