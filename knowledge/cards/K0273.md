## 정리된 지식

- rtk(Rust Token Killer): git·npm 등 개발 명령의 출력을 압축해 에이전트에 전달하는 Apache 2.0 CLI 프록시, Claude Code에는 PreToolUse hook으로 명령을 자동 치환
- rtk 문서도 '최대 90%'는 bash 출력 기준이며 전체 API 비용 절감 폭은 훨씬 작다고 명시, 절감률은 추정치
- Claude Code agent teams 문서: 팀원 수에 비례해 토큰이 선형 증가하므로 루틴 작업은 단일 세션이 비용 효율적

## 교육과 업무에 활용

- 절약 3원칙 교육: 필요한 맥락만 주기, 검증 범위를 명시하기, 병렬은 필요한 곳에만
- 도구로 출력을 잘라낼 때는 에이전트가 오류 정보를 놓칠 위험을 함께 설명
