## 정리된 지식

- Claude Code 데이터 사용 문서: 세션 재개를 위해 대화 기록을 ~/.claude/projects/ 아래 평문으로 기본 30일 보관하며 cleanupPeriodDays 설정으로 기간 조정 가능. Claude 데스크톱·Cowork에서 시작하거나 마지막으로 이어간 세션 기록은 기본적으로 이 기한에서 제외
- 기록 누적이 PC 속도를 떨어뜨린다는 공식 설명은 찾지 못함. 실제 원인(백그라운드 프로세스, 디스크 용량 등)은 개별 확인 필요
- [추가 2026-07-21] Codex GitHub 이슈: logs_2.sqlite-wal이 수십~수백 GB까지 무한 증가하는 문제가 CLI(0.140.0 이후)와 데스크톱 모두에서 보고, 원인은 CODEX_HOME 감시 TRACE 로그의 자기 피드백 루프·WAL 크기 제한 부재로 분석, 임시 조치는 Codex 종료 후 WAL 정리, 설정 sqlite_home으로 감시 폴더 밖 이동(이슈 기준 부분 수정·미해결)
