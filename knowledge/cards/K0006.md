## 정리된 지식

- Claude Code 공식 문서: fast mode는 다른 모델이 아니라 Opus를 속도 우선 설정으로 돌리는 것으로 최대 2.5배 빠름. 구독 플랜(Pro/Max/Team/Enterprise)에서는 사용 크레딧으로만 과금되며 플랜 사용량이 남아 있어도 크레딧에서 바로 차감. 단가는 Opus 5.5 기준 입력 $8/출력 $40 per MTok(일반 Opus 5.5 $4/$20의 2배). 대화 도중 켜면 전체 대화 맥락을 fast 요금의 비캐시 입력으로 한 번 다시 계산하므로 세션 시작 시 켜는 것이 저렴. Team/Enterprise는 Owner가 먼저 활성화해야 함.
- [추가 2026-08-17] Opus 5 출시일에도 fast 모드는 사용 크레딧 전용이었다는 커뮤니티 확인. Anthropic 발표 기준 Opus 5 fast mode는 약 2.5배 속도·기본 가격의 2배
- [추가 2026-05-29] Anthropic Opus 4.8 발표: fast mode 입력 $10·출력 $50으로 일반 단가($5/$25)의 2배, 속도 2.5배, '이전 모델 대비 3배 저렴'이라고 명시
- [추가 2026-10-04] 공식 문서 재확인: fast mode는 Opus 5.5·Opus 5·Opus 4.8에서만 지원(Sonnet·Haiku 미지원), Opus 5.5 fast 단가 입력 $8·출력 $40(표준 $4/$20의 2배), 구독 요금제에서는 한도와 무관하게 사용 크레딧에서만 차감되고 크레딧을 켜야 사용 가능.

## 교육과 업무에 활용

fast mode는 '구독 한도 소모'가 아니라 '추가 결제'임을 명확히 안내하고, 조직 도입 시 기본 비활성·세션별 opt-in 설정 권장.

## 정정과 한계

커뮤니티의 'Opus 4.8 fast mode는 6배 비싸다'는 공식 단가(일반의 2배: 입력 $10·출력 $50)와 다름.
