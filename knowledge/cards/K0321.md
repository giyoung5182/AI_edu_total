## 정리된 지식

- Android R8: 코드 축소·최적화·난독화(클래스·메서드 이름 단축)를 수행하며 release 빌드에서 활성화(AGP 9.3 이상은 optimization { enable = true }, 이전 버전은 isMinifyEnabled = true)
- 공식 문서는 난독화를 DEX 파일 크기 축소 목적으로 설명하며 보안 수단으로 제시하지 않음
- Android 보안 문서: 앱에 하드코딩한 비밀값은 리버스 엔지니어링 도구로 매우 쉽게 추출 가능, Android Keystore·KeyChain 사용 권장
- 'AI가 스크린샷으로 복제한다'는 관점은 커뮤니티 의견

## 교육과 업무에 활용

- 바이브코딩 앱 배포 교육에서 API 키·비밀값은 서버 측에 두는 원칙을 먼저 강조
- 난독화는 부가 조치로 설명하고, 기능 복제 방어는 코드가 아니라 데이터·운영·고객으로 해야 한다는 점 연결
