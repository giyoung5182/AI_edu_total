## 정리된 지식

- Claude Code 공식 CLI 시스템 프롬프트 플래그: --system-prompt·--system-prompt-file(기본 프롬프트 전체 교체, 둘은 동시 사용 불가), --append-system-prompt·--append-system-prompt-file(기본 프롬프트 뒤에 추가, 교체 플래그와 병용 가능)
- 공식 문서는 기본 도구 안내·안전 지침을 유지하려면 추가(append) 플래그를, 정체성·권한 모델이 완전히 다를 때만 교체 플래그를 쓰라고 안내. 교체 시 기본 프롬프트의 도구 안내·안전 지침이 모두 빠짐
- --model은 sonnet·opus·haiku·fable 별칭 또는 전체 모델명을 받음
- 공식 CLI에 --mode 플래그는 없음. claude-mode(Mineru98)는 셸 함수 래퍼로 settings/settings.<name>.jsonc를 --settings로 넘겨 플러그인·스킬·MCP 구성만 세션별로 바꾸며 시스템 프롬프트는 바꾸지 않음(bash·zsh는 jq 필요)
- 한글 토큰 문제 해소는 개인 체감으로 공식 확인 없음

## 교육과 업무에 활용

- 작업 유형별 시스템 프롬프트 파일을 만들어 append로 붙이는 방식은 버전 관리·재사용에 유리
- 교체(--system-prompt)는 안전·도구 지침까지 사라지므로 입문자에게는 append 권장
- 커뮤니티 명령어 예시는 공식 플래그인지 래퍼인지 구분해 안내

## 정정과 한계

'claude --mode=write'는 Claude Code 공식 플래그가 아니라 claude-mode 같은 셸 래퍼를 설치해야 동작하는 방식이며, 그 래퍼도 시스템 프롬프트가 아닌 설정·플러그인·스킬·MCP만 전환함. 시스템 프롬프트 추가는 공식 플래그 --append-system-prompt-file로 가능.
