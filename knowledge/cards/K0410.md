## 정리된 지식

- 공식 GitHub 릴리스: @open-slide/cli·core 2.0.0이 2026-09-26 배포(2.0.1은 09-27)
- 각 페이지는 1920×1080 캔버스 위 React 컴포넌트(.tsx), Claude Code·Cursor 등 에이전트가 /create-slide 등으로 작성
- 2.0 변경: 시각 편집기(스냅·크기 조절·레이어 순서), 텍스트 클릭 시 인라인 편집과 글자 크기·굵기·기울임·색·정렬 툴바, UI 재설계
- 'Export as PPTX': 서버·헤드리스 브라우저 없이 브라우저 안에서 각 페이지를 PowerPoint 기본 텍스트 상자·도형·이미지로 변환
- 요소에 남긴 코멘트는 소스에 @slide-comment 마커로 저장되고 /apply-comments로 에이전트가 반영
- MIT 라이선스 무료
- 화면에서 직접 바꾼 서식이 원본 코드에 그대로 기록되는지는 원문에 명시적 설명이 없어 원문 미확인

## 교육과 업무에 활용

- 'AI로 초안, 사람이 마무리' 발표자료 워크플로우의 사례 — 코드형 슬라이드의 약점(사후 수정)을 시각 편집기·PPTX 내보내기로 보완
- 고객사 제출용은 PPTX 변환 후 글꼴·레이아웃 깨짐 여부 확인 단계 포함
- 비개발자 교육 시 Node.js 등 설치 전제(2.0은 Node.js 20.19+ 요구) 안내
