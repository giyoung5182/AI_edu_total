## 정리된 지식

- 공식 herdr(herdr.dev, herdrdev/herdr): 코딩 에이전트용 런타임, 로컬·원격 서버에서 터미널 세션 유지, 연결이 끊겨도 작업 지속, 다른 기기에서 재접속. Apache 2.0, macOS·Linux·Windows, SSH로 여러 머신 통합, Herdr Cloud 준비 중
- 스마트폰 원격 승인·PWA·QR 설정·푸시 알림은 서드파티 동반 앱 0cv/herdr-mobile-relay 기능(AGPL v3.0 이상, Linux·macOS 대상)
- [추가 2026-10-05] herdr 공식 문서: 네이티브 Windows 지원 정식 제공(최신 stable 0.9.3), Windows는 ConPTY 기반이라 화면 갱신 중 커서가 깜빡이거나 튈 수 있음(host_cursor = "native"로 바꾸면 IME 위치는 정상화되나 깜빡임 재발), 기본 커서 방식 때문에 한국어 등 IME 위치 제약. 커뮤니티: Rust 기반이라 Orca보다 빠르고 가볍다는 체감, 모바일은 서드파티 클라이언트로 가능. unpeel은 Mac 전용이라는 공유

## 교육과 업무에 활용

본체 도구와 커뮤니티 확장(포크·플러그인)을 구분해 소개해야 하는 사례, 라이선스 표기는 공식 저장소 기준

## 정정과 한계

커뮤니티·기존 KB는 herdr 자체를 'AGPL 모바일 원격 승인 시스템'으로 설명했으나, 공식 herdr는 Apache 2.0 에이전트 런타임이고 모바일 원격 승인은 별도 서드파티 저장소(herdr-mobile-relay, AGPL) 기능
