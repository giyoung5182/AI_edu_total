## 정리된 지식

- 공식 문서: Claude Fable 5.1·5, Opus 5.5·5, Sonnet 5.5에는 요청을 거절할 수 있는 안전 분류기가 있고, 거절 시 stop_reason이 'refusal'로 반환됨(범주: cyber, bio, frontier_llm, reasoning_extraction, general_harms)
- API에는 거절 범주별 권장 모델로 재시도하는 서버측 폴백(베타)과 클라이언트측 폴백이 있으며, 목록의 모든 모델이 거절하면 마지막 모델의 거절 응답이 그대로 반환됨 → 'Fable→Opus 폴백 후에도 거절' 경험과 구조적으로 부합
- Claude Code 오류 문서: 정책 검사는 최신 프롬프트가 아니라 대화 전체를 평가하므로 같은 세션에서 새 메시지를 보내도 다시 거절되기 쉽고, --continue/--resume으로 다시 열어도 동일. 대응은 Esc 두 번 또는 /rewind로 되감기 후 표현 변경, 또는 /clear로 새 대화. 정책 검사는 모델마다 달라 모델 전환이 해결되는 경우도 있음
- Claude Code의 fallbackModel 설정은 '과부하·사용 불가' 시 백업 모델 체인이며 거절 대응용으로 문서화되어 있지 않음

## 교육과 업무에 활용

- 거절이 반복되면 같은 세션에서 계속 조르지 말고 되감기 또는 새 세션으로 전환
- 보안·사이버 주제 실습 설계 시 분류기 거절 가능성을 사전 안내
