## 정리된 지식

- herdr(ogulcancelik/herdr): Rust로 만든 터미널용 '에이전트 멀티플렉서'. 창(pane)·탭·워크스페이스로 여러 에이전트를 나눠 띄우고 터미널 출력을 읽어 에이전트 상태(대기·작업 중·막힘)를 감지. 서버-클라이언트 구조로 로컬·SSH·클라우드 연결 지원
- Orca(onorca.dev): 작업마다 별도 git worktree·에이전트 터미널·브라우저 탭을 주는 데스크톱 IDE. Claude Code·Codex·Cursor CLI 등 본인 구독을 그대로 사용, macOS·Windows·Linux 무료 오픈소스, 모바일 동반 앱과 SSH 원격 실행 지원
- Paseo(getpaseo/paseo): 내 PC에서 도는 데몬이 에이전트를 관리하고 폰·데스크톱·웹·CLI가 접속하는 구조, 직접 연결이 어려우면 암호화 릴레이 사용, Apache-2.0, 텔레메트리 없음
- kanvibe: 칸반 보드형 데스크톱 앱. 작업 생성 시 git worktree와 tmux/zellij 세션 자동 생성, DONE 이동 시 정리, SSH 원격 지원, AGPL-3.0
- 세 도구 모두 모델을 제공하지 않고 사용자의 기존 Claude·Codex 구독이나 CLI를 실행하는 '관리 계층'
- [추가 2026-08-27] 오케스트레이션 구현은 Orca·herdr처럼 터미널 간 주입 방식 또는 수동, Orca는 전용 오케스트레이션 스킬 제공(커뮤니티). 탭 간 '작업 끝나면 상대 탭에 알리기' 방식의 루프 구성 질문은 답변 없음

## 교육과 업무에 활용

- 비개발자에게는 '모델(두뇌)'과 '에이전트 관리 도구(작업대)'를 분리해 설명
- git worktree 개념(같은 저장소를 작업별 폴더로 복제해 충돌 없이 병렬 작업)을 먼저 짚은 뒤 도구 소개

## 정정과 한계

기존 지식베이스(kakao-community-remote-dev-tools)의 herdr 설명은 모바일 릴레이 포크(0cv/herdr-mobile-relay, Python/TypeScript) 기준임. 원본 herdr는 Rust 기반 터미널 에이전트 멀티플렉서로, 모바일 승인은 포크·릴레이 쪽 기능이므로 구분 필요.
