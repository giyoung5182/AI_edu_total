## 정리된 지식

- Google 발표(2026-09-02): Gemini 3.8 Flash는 '지금까지 최고의 추론·코딩 모델'로 소개되며 3.7 Flash와 같은 속도·저비용 유지, 복잡한 작업에서 추론 단계와 도구 호출을 더 많이 수행. 도입가 입력 $0.75/출력 $3.75 per 1M 토큰(2026-12-31까지, 이후 $1.50/$7.50). Gemini API 문서상 입력은 텍스트·이미지·영상·오디오·PDF, 출력은 텍스트만(이미지 생성 불가), 입력 한도 1,048,576 토큰, thinking 레벨 low/medium/high. Gemini API·AI Studio, Google Antigravity, Gemini 앱(Pro·Ultra), 검색 AI 모드에서 제공. 'Gemini 4' 출시는 Google 공식 채널에서 확인되지 않음.
- [추가 2026-09-04] 공식 블로그 기준 Gemini 3.8 Flash·3.8 Flash Cyber는 2026-09-02 발표, 도입가 입력 $0.75·출력 $3.75(100만 토큰당, 2027-01-01 인상 예정), 6주 만의 세 번째 Flash 출시. 커뮤니티 체감은 빠르지만 검수 필요(GEMINI 신규 카드 참고).

## 교육과 업무에 활용

앱 기능(이미지 생성 등)과 모델 자체 능력을 구분해 설명하는 사례. 같은 모델도 웹 앱과 개발자 도구(AGY)에서 체감이 다를 수 있다는 점은 커뮤니티 경험으로 소개.

## 정정과 한계

Gemini 3.8 Flash 모델 자체는 이미지를 생성하지 않음(출력: 텍스트). 공식 포지션은 그림 생성·잡담이 아니라 추론·코딩·에이전트 작업. OCR(이미지·PDF 입력 이해)은 입력 지원 범위상 가능.
