# 실습 3. 1회차 실행 — 정상 자료

정리일: 2026-10-08 · 교육 에셋 N0536

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AGENTS.md를 두고 정상 자료로 첫 실행을 해, 다음 회차와 비교할 기준 결과를 만든다.
## 진행 단계
1. **새 작업 시작** — Work 새 대화. 경로 A: 1회차 폴더만 허용 / 경로 B: 1회차 파일 3개 첨부
2. **한 줄 요청**
```javascript
AGENTS.md를 먼저 읽고 그대로 처리. 이번 회차 입력: 1회차(N = 1) — 01_출장실습데이터_통합.xlsx 「클레임이력」 시트, 02_고객문의메일_20건.txt
```
3. **승인 창** — 원본 수정·삭제를 묻는 승인 창이 나오면 거부
4. **저장** — 결과 파일을 1회차 폴더에 저장
## 막히는 지점
- 결과를 파일로 받을 수 없음 → 연결표·추적표·미처리를 표로 대화창에 출력받아 엑셀에, 텍스트는 메모장에 같은 파일명으로 저장
- 원본이 이미 바뀜 → 00_원본보관에서 다시 복사해 해당 회차 다시 실행
- AGENTS.md 규칙을 따르지 않은 것 같음 → 실행기록에 AGENTS.md를 읽었다는 문장이 있는지 확인
