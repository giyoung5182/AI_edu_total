# 실습 1. 문서 처리 페이지 만들기 — 자르고, 펼치고, 찾는다

정리일: 2026-10-08 · 교육 에셋 N0376

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
PDF를 업로드하면 500자·오버랩 50자 청크 카드 목록이 나타나는 페이지를 추가하고, 잘리다 망가진 조각을 직접 찾습니다.
## 진행 단계
1. **프롬프트 입력** — 터미널 A의 Claude Code에서 /clear 후 `/documents` 경로, 메뉴 "문서", PDF 파싱·청킹, 청크 카드(번호·파일명·글자 수·미리보기), 요약 정보, 로그 출력을 요청
2. **서버 재시작·접속** — 터미널 B에서 재시작 후 [개별 링크 제외]
3. **예측·업로드** — 청크 개수를 예측해 적고 업로드해 실제 개수와 비교
4. **대조** — 카드 3장을 눌러 원문 PDF와 대조
5. **손상 조각 찾기** — 두 개 이상 찾아 청크 번호와 이유를 메모, 옆자리와 비교
## 막히는 지점
- 업로드 후 반응이 없으면 터미널 B 로그에서 "파싱 시작" 확인
- 글자가 깨지면 로그와 함께 인코딩 확인 요청
- 문서 ①은 그림 주변, ②는 조항 경계, ③은 표가 있던 자리 카드를 우선 확인
