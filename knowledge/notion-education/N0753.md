## Step 01 :: 앱스크립트는 무엇인가
- Google Apps Script(앱스크립트, GAS): Google 시트 · 드라이브 · 지메일 · 캘린더 같은 Google 서비스를 **코드로 움직이는** Google 도구 ([공식 문서](https://developers.google.com/apps-script/overview))
- 별도 설치 없음 — 브라우저 안 코드 편집기에서 작성, 코드는 드라이브에 저장, 실행은 Google 서버에서 함
- Google 시트에 붙어서 시트를 대신 만지는 짧은 코드
- 같은 시트에서 같은 코드를 실행하면 매번 같은 결과 → 정해진 규칙의 반복 작업에 맞음
- 코드는 직접 쓰지 않음. ChatGPT에 요청해서 받고, 사람은 **붙여넣기 · 저장 · 실행 · 결과 확인**만 함

## Step 02 :: 언제 쓰나 · 왜 쓰나
**언제 쓰나 — 이런 일이 매주 반복될 때**
- 같은 기준으로 칸을 찾아 표시하는 일 (예: 영수증 빈칸 찾기)
- 조건에 맞는 행만 골라 다른 시트로 옮기는 일 (예: 확인할 건만 모으기)
- 정해진 요일 · 시각에 같은 작업을 다시 돌리는 일 (예: 월요일 아침 목록 갱신)
- 지메일 연동으로 메일 발송도 가능 — 이번 실습은 권한 범위를 줄이려고 메일 발송 제외
**왜 쓰나 — 사람과 앱스크립트의 일 나누기**
- 판단이 필요한 일 → 사람 (예: 영수증 없는 건을 승인할지 다시 요청할지)
- 판단 없이 규칙대로 하는 일 → 앱스크립트 (예: 영수증첨부가 "미첨부"인 행 모으기)
- 효과: 눈으로 찾다 놓치는 일 감소 · 매주 같은 기준 적용 · 담당자는 판단에만 시간 사용

## Step 06 :: 트리거 — 정해진 시간에 자동 실행

## 실습 ① 자료 정리 — 빈칸·숫자 아닌 칸 색칠
### 상황
- 출장정산 담당자(예시)는 매주 `출장정산내역` 시트(데이터 321행)를 눈으로 훑으며 확인할 칸을 찾음 → 줄이 많아 놓치기 쉬움
- 정산 내역에 영수증첨부 빈칸, 금액 칸에 글자가 섞인 값이 있음
- 눈으로 찾지 않고 앱스크립트로 해당 칸에 색을 칠해 한눈에 보이게 함
**왜 이 실습을 하나**
- 앱스크립트의 가장 기본 동작 = **시트 값 읽기 → 조건 확인 → 표시**
- 값은 그대로 두고 색만 바꿈 → 원본 자료를 망가뜨리지 않는 안전한 첫 실습
**이 실습으로 배우는 앱스크립트 기능**

```javascript
function markRows() {
  const sheet = SpreadsheetApp.getActive().getSheetByName('출장정산내역');
  const values = sheet.getDataRange().getValues();
  const head = values[0];
  const receipt = head.indexOf('영수증첨부');
  const air = head.indexOf('항공료');
  let rowCount = 0, cellCount = 0;
  for (let i = 1; i < values.length; i++) {
    if (values[i][receipt] === '') {
      sheet.getRange(i + 1, 1, 1, head.length).setBackground('#fff2cc');
      rowCount++;
    }
    if (typeof values[i][air] !== 'number') {
      sheet.getRange(i + 1, air + 1).setBackground('#f4cccc');
      cellCount++;
    }
  }
  Logger.log('노란 행 ' + rowCount + '개, 빨간 칸 ' + cellCount + '개');
}
```

- 노란 행: 시트 320행 `TR-2026-0151V` (영수증첨부 빈칸)
- 빨간 칸: 시트 319행 `TR-2026-0131V` 항공료 `1,850,000원` (숫자가 아니라 글자)
- 데이터 321행(머리글 제외) 기준. 값은 그대로이고 색만 바뀜
- 수가 다르면: 시트 이름이 `출장정산내역`인지, 1행 머리글 글자가 프롬프트와 같은지 확인

```javascript
function copyCheckRows() {
  const ss = SpreadsheetApp.getActive();
  const values = ss.getSheetByName('출장정산내역').getDataRange().getValues();
  const head = values[0];
  const pay = head.indexOf('결제방법');
  const receipt = head.indexOf('영수증첨부');
  const rows = values.filter((r, i) =>
    i > 0 && r[pay] === '개인카드 후정산' && r[receipt] === '미첨부');
  const out = ss.getSheetByName('확인 필요') || ss.insertSheet('확인 필요');
  out.clearContents();
  out.getRange(1, 1, 1, head.length).setValues([head]);
  if (rows.length > 0) {
    out.getRange(2, 1, rows.length, head.length).setValues(rows);
  }
  Logger.log('확인 필요 ' + rows.length + '건');
}
```
- 실행 로그: `확인 필요 16건` / `확인 필요` 시트: 머리글 1행 + 16행
- 16건 정산번호(앞의 `TR-2026-` 생략): 0008, 0013, 0041, 0076, 0115, 0134, 0152, 0159, 0171, 0192, 0230, 0251, 0266, 0283, 0041V, 0171V
- 영수증첨부가 **빈칸**인 0151V는 "미첨부"와 글자가 달라 들어가지 않음 → 실습 ①에서 노란색으로 따로 보임
- 0건이면: 조건 글자에 띄어쓰기가 다른지(`개인카드 후정산`) 확인

### 상황
- 출장정산 담당자(예시)는 월요일 아침마다 `copyCheckRows`를 직접 실행해야 함 → 출장 · 휴가 · 회의로 놓치면 목록이 지난주 상태로 남음

```javascript
function setWeeklyTrigger() {
  deleteMyTriggers();
  ScriptApp.newTrigger('copyCheckRows')
    .timeBased()
    .everyWeeks(1)
    .onWeekDay(ScriptApp.WeekDay.MONDAY)
    .atHour(9)
    .create();
}

function deleteMyTriggers() {
  ScriptApp.getProjectTriggers().forEach(t => ScriptApp.deleteTrigger(t));
}
```
- `setWeeklyTrigger` 실행 뒤 「트리거」 목록: `copyCheckRows` 1줄. 두 번 실행해도 1줄
- `atHour(9)`: 9시대 중 한 시점에 실행. 정확한 분은 Google이 정함
- `deleteMyTriggers` 실행 뒤 목록: 0줄
- 트리거가 실행되면 「트리거」 화면 옆 **실행(Executions)** 메뉴에 기록이 남음 \[확인 필요 — 메뉴 한글 이름\]
