## 변수 매핑 — "\{\{변수\}\}"를 어떻게 넣는가
Make.com에서 가장 헷갈리는 부분입니다. 이전 모듈의 데이터를 다음 모듈에 넣는 방법입니다.
**잘못된 방법:**
```plain text
Gmail 본문 입력창에 직접 타이핑:
  "{{B열}}" → 이렇게 타이핑하면 그냥 텍스트로 들어감
  실제 데이터가 들어오지 않음
```
**올바른 방법:**
```plain text
STEP 1. Gmail 모듈 설정창 열기
STEP 2. Body(본문) 입력창 클릭
STEP 3. 입력창 오른쪽에 작은 아이콘들이 보임
         → 그 중 지도 핀 모양 또는 번개 모양 아이콘 클릭
         → 또는 입력창 안을 클릭하면 커서가 생김
STEP 4. 이전 모듈의 결과가 드롭다운으로 나타남
         예: "1. Google Sheets > Row > B (매장명)"
         → 클릭하면 {{B}} 형태로 자동 삽입됨

핵심: 직접 타이핑이 아니라 드롭다운에서 선택해야 함
```
**변수 삽입 위치 찾기:**
```plain text
Gmail Send an Email 모듈 기준:
  To (받는 사람): 드롭다운에서 이메일 열 선택
  Subject (제목): 텍스트 + 드롭다운 변수 조합 가능
    예: "[교육기관] 새 요청 — " 타이핑 후
        드롭다운에서 B열(매장명) 선택
  Content (본문): 텍스트 + 변수 자유 조합
    엔터키로 줄바꿈 가능
    변수는 드롭다운에서 선택해서 삽입

💡 변수를 선택하면 화면에 {{x; B}} 또는 {{1.B}} 같은 형태로 표시됨
   이것이 정상입니다. 실제 실행 시 해당 열의 값이 들어옴
```

## Iterator + Text Aggregator 완전 이해
프로님과 프로님 시나리오에서 필요한 조합입니다. 가장 낯선 부분이므로 충분히 이해하고 시작합니다.
### 왜 필요한가
```plain text
문제 상황:
  Google Sheets Search Rows로 미처리 건 5개를 찾았음
  이 5개를 이메일 본문에 한꺼번에 넣고 싶음

그냥 Search Rows → Gmail 연결하면?
  → Make는 5개 이메일을 5번 따로 발송함
  → 원하는 것: 5개가 한 이메일에 목록으로 들어와야 함

해결:
  Search Rows → Iterator(1개씩 꺼내기) → Text Aggregator(한곳에 모으기) → Gmail
```
### Iterator — 모듈 추가하는 법
```plain text
STEP 1. Search Rows 모듈 오른쪽 [+] 클릭

STEP 2. 검색창에 "iterator" 입력
  → Tools 카테고리 아래 "Iterator" 선택
  → [Add] 클릭

STEP 3. Iterator 설정창이 열림
  Array 항목을 찾음
  → 오른쪽 드롭다운 클릭
  → "2. Google Sheets > Rows" 선택
    (이전 모듈인 Search Rows의 결과 배열)
  → [OK] 클릭

STEP 4. 캔버스에 Iterator 모듈이 추가되고
  Search Rows와 연결선이 생김

💡 Iterator의 역할:
   Search Rows가 가져온 여러 행을 "한 번에 하나씩" 처리하도록 변환
   5개 행이라면 5번 반복 실행됨
```
### Text Aggregator — 모듈 추가하는 법
```plain text
STEP 1. Iterator 모듈 오른쪽 [+] 클릭

STEP 2. 검색창에 "text aggregator" 입력
  → Tools 카테고리 아래 "Text aggregator" 선택
  → [Add] 클릭

STEP 3. Text Aggregator 설정창이 열림

  Source Module:
    → 드롭다운 클릭
    → "3. Iterator" 선택 (방금 만든 Iterator 모듈)

  Text:
    → 이메일 본문에 한 줄로 넣고 싶은 형식 입력
    → 텍스트 타이핑 + 드롭다운 변수 조합
    예시:
      "▶ " 타이핑 →
      드롭다운에서 B열(매장명) 선택 →
      " / " 타이핑 →
      드롭다운에서 C열(요청유형) 선택 →
      " / 접수일: " 타이핑 →
      드롭다운에서 A열(타임스탬프) 선택

  Row separator:
    → \n 입력 (줄바꿈 문자 — 각 건이 새 줄에 시작됨)

  → [OK] 클릭

STEP 4. Text Aggregator 설정 완료
  → Text Aggregator의 결과물이
    "▶ 강남점 / 정보수정 / 접수일: 2026-06-30
     ▶ 홍대점 / 사진교체 / 접수일: 2026-06-29
     ▶ 신촌점 / 영업시간 / 접수일: 2026-06-28"
    이런 형태의 텍스트 하나가 됨
```
### Gmail에 Text Aggregator 결과 넣기
```plain text
STEP 1. Text Aggregator 오른쪽 [+] 클릭 → Gmail → Send an Email

STEP 2. Gmail 설정창에서 Body(본문) 작성
  "안녕하세요.\n이번 주 미처리 요청 목록입니다.\n\n" 타이핑 →
  드롭다운 클릭 →
  "5. Text aggregator > Text" 선택 →
  "\n\n처리 부탁드립니다." 타이핑

💡 드롭다운에 "5. Text aggregator"가 보여야 정상
   보이지 않으면 Source Module 설정을 다시 확인
```
### 전체 흐름 확인
```plain text
완성된 시나리오 모양:

Schedule (매주 월요일 09:00)
    ↓
Google Sheets Search Rows (미처리 건 조회)
    ↓
Iterator (1건씩 꺼내기)
    ↓
Text Aggregator (모든 건을 한 텍스트로 합치기)
    ↓
Gmail Send an Email (합쳐진 목록을 이메일로 발송)

모듈 5개 → ops 5개/실행
```

## 공통 오류 대처법
### 오류 1: Connection failed / 계정 연결 불가
```plain text
증상: 구글 시트 모듈 추가 후 Connection 선택 시 오류
원인: 브라우저 팝업 차단 / 구글 계정 권한 만료

해결:
  1. 브라우저 주소창 오른쪽 팝업 차단 아이콘 클릭
  2. "항상 허용" 선택
  3. 모듈 → Connection 항목 → [Add] 클릭
  4. 구글 계정 로그인 → 모든 권한 체크 후 허용
  5. 파일 재검색
```
### 오류 2: 시나리오 실행했는데 아무 일도 없음
```plain text
원인 A: 시나리오가 비활성화 상태
  → 오른쪽 상단 토글 확인 → Active(파란색) 상태로 변경

원인 B: Watch Rows인데 새 행이 없음
  → [Run once] 클릭 → 시트에 테스트 행 수동 추가
  → 다시 [Run once] 클릭

원인 C: Filter 조건에 맞는 데이터가 없음
  → Filter를 임시로 제거 → 테스트 → 정상 확인 후 Filter 재추가

원인 D: 스케줄 트리거인데 아직 실행 시간이 안 됨
  → [Run once] 클릭으로 즉시 테스트
```
### 오류 3: 이메일에 변수가 \{\{1.B\}\} 그대로 나옴
```plain text
원인: 변수를 드롭다운으로 선택하지 않고 직접 타이핑한 것
해결:
  Gmail 모듈 다시 열기 →
  Body 입력창에서 직접 타이핑한 변수 삭제 →
  커서 놓고 드롭다운에서 해당 변수 다시 선택
```
### 오류 4: 구글 시트 파일이 목록에 안 보임
```plain text
원인: 파일이 공유 드라이브에 있거나 다른 계정 소유
해결 방법 1: 파일을 내 드라이브로 이동
해결 방법 2: Spreadsheet ID 직접 입력
  → 파일 URL에서 /spreadsheets/d/ 뒤의 긴 문자열 복사
  → Spreadsheet 항목에 직접 붙여넣기
```
### 오류 5: Schedule Timezone이 맞지 않음
```plain text
원인: Timezone이 UTC(협정 세계시)로 설정됨
증상: 설정한 시간보다 9시간 일찍 또는 늦게 실행됨

해결: Schedule 모듈 설정 → Timezone → Asia/Seoul 선택
  (UTC+9이므로 09:00 KST 설정 시 Asia/Seoul 반드시 지정)
```
### 오류 6: "There is no output bundle"
```plain text
증상: Run once 실행 후 이 오류가 빨간 느낌표로 표시됨
원인: 처리할 데이터가 없음

해결:
  Watch Rows: 시트에 새 행 추가 후 다시 Run once
  Search Rows: 검색 조건에 맞는 데이터가 없음 → 테스트 데이터 추가
  Schedule: 시간 조건 때문 → [Run once]로 즉시 실행
```

# Make.com 파트 마무리

## 오늘 완성한 것
```plain text
GAS가 "구글 시트 안에서 처리"했다면
Make.com은 "구글 시트 밖으로 연결"했다

오늘 완성한 것들:
  ✅ 구글 시트 변경 → 즉시 이메일 알림 (프로님)
  ✅ 정해진 시간 → 자동 보고 이메일 (프로님)
  ✅ GAS 버튼 → 즉시 다중 이메일 발송 (프로님)
  ✅ 새 행 → 텔레그램 + 캘린더 자동 등록 (프로님)
  ✅ 기초 시나리오 완성 (프로님 / 프로님)

앞으로 혼자 할 수 있는 것:
  → 기존 시나리오에 모듈 하나씩 추가
  → 조건이나 이메일 내용만 바꿔서 다른 업무에 적용
```
## Make.com 구독 취소 안내
```plain text
⚠️ Make.com Core 구독은 7월 11일(7회차) 전에 취소 권장

취소 방법:
  make.com 로그인
  → 우측 상단 프로필 아이콘 클릭
  → Billing 메뉴
  → Cancel subscription 클릭

⚠️ 취소해도:
  현재 청구 주기 종료일까지는 계속 사용 가능
  시나리오는 삭제되지 않음
  무료 플랜(월 1,000 ops)으로 자동 전환됨
  → 실행 횟수만 줄어들 뿐, 시나리오 구조는 유지
```
## ops 소비 참고
```plain text
프로님 시나리오 A: 모듈 2개 × 1회 = 2 ops/실행
프로님 시나리오 B: 모듈 5개 × 주 1회 × 4주 = 20 ops/월
프로님: 모듈 6개 × 실행횟수
프로님: 모듈 8개 × 실행횟수
프로님: 모듈 5개 × 월 1회 = 5 ops/월

Core 플랜 월 10,000 ops 기준으로 여유롭게 사용 가능
무료 플랜(월 1,000 ops)으로도 정기 실행 스케줄은 대부분 가능
```
