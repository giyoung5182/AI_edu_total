# 추가 실습 — 다른 주제로 처음부터 끝까지 돌려보기

정리일: 2026-10-08 · 교육 에셋 N1117

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
앞서 강사와 함께 한 과정을 다른 주제로 각자 처음부터 끝까지 진행합니다.
## 진행 단계
1. **주제 선택** — 주제 A 친환경·리사이클 패딩 트렌드 / 주제 B 2030 세대의 겨울 아우터 소비 트렌드 / 주제 C 해외 프리미엄 패딩 브랜드의 마케팅 전략 / 주제 D 개인 업무에 맞는 리서치 주제 선정(추천)
2. **1단계 시장 조사(계획 확인 포함)** — 연구 시작 전에 조사 계획을 읽고 한 줄 다듬기.
- 입력할 내용:
```javascript
[고른 주제]를 조사해줘.
다음 형식으로 정리해줘.

1. 핵심 트렌드 3가지
2. 소비자가 반응하는 메시지
3. 이미 잘하고 있는 브랜드 사례
4. 우리 브랜드가 적용할 수 있는 포인트 3가지
5. 내부 보고용 7문장 요약
```
1. **2단계 출처 검증** — 출처 2\~3개를 열어 내용 일치 / 날짜 / 출처 성격 확인. 이상한 항목은 빼거나 다시 요청.
2. **3단계 보고용 문장 만들기**
- 입력할 내용:
```javascript
위 조사 결과를 바탕으로 팀장에게 1분 안에 설명할 수 있는  내부 보고용 요약문을 만들어줘.
너무 길지 않게 8줄 이내로 정리해줘.
```
1. **4단계 교차 검증** — 의심스러운 수치·주장 하나를 골라 일반 Gemini 세션에서 확인.
```javascript
위 조사 내용 중 '[의심스러운 수치나 주장]' 부분이 맞는지,
다른 출처로 한 번 더 확인해서 근거를 보강하거나 정정해줘.
출처 링크도 함께 알려줘.
```
## 막히는 지점
- 공개 정보로 조사 가능한 주제만 사용하고, 내부·미공개 정보는 넣지 않음
