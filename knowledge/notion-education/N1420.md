# 실습 2. 자가진단으로 지침 다듬기 — 지침 v1.0 완성

정리일: 2026-10-08 · 교육 에셋 N1420

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
평가 기준을 단계로 주어 AI가 지침의 실제 약점을 찾게 하고, 개선판을 가상 문의로 미리 확인해 지침 v1.0을 완성한다.
## 진행 단계
1. **자가진단 요청** — ChatGPT 새 채팅에 실습 1 완성 지침을 붙여넣고 이어서 자가진단 프롬프트를 붙여넣어 Enter
- 입력할 내용:
```javascript
위 지침의 약점을 스스로 찾아 줘. 아래 기준으로 단계별로 평가해 줘.

1단계  R·O·P·E·K 다섯 요소가 각각 충분히 구체적인가? 모호한 표현이 있으면 집어 줘.
2단계  이 지침만 보고 누가 물어도 매번 같은 모양으로 답할 수 있는가?
3단계  파일에 없는 금액·비율·기한·조항 번호를 지어낼 위험이 있는 부분은 어디인가?
4단계  필요한 정보(지역·일정·결제수단·취소 시점)가 빠진 문의가 오면 되묻게 되어 있는가?
5단계  같은 주제를 다르게 정한 문서가 있을 때, 또는 파일에 [확인 필요]로 적힌 항목을
       한쪽으로 단정해 답할 여지가 있는가?

평가가 끝나면 개선한 지침 전체를 보여 줘. R·O·P·E·K 다섯 요소 이름과 순서는 그대로 두고, 규칙이 늘어나도 전체는 지금 길이를 넘기지 마.
```
2. **가상 문의로 미리 돌려 보기** — 개선판을 받으면 가상 문의를 입력하고, 입력창 **+** → 파일 추가로 규정 파일 2개를 첨부
- 입력할 내용:
```javascript
개선한 지침대로 일한다고 가정하고, 아래 문의에 실제로 답해 봐.
문의: 출발 3일 전에 출장을 취소하면 수수료가 몇 %야?
(참고 자료가 필요하면 지금 첨부하는 두 파일을 써.)
```
- 정상 결과: 두 문서의 수수료가 모두 나오고 "확인 필요"가 표시됨
3. **단정하면 보강** — 답이 한쪽 수수료만 단정하면 `5단계 기준으로 멈출 때 규칙을 더 구체적으로 고쳐 줘`를 입력하고 2단계를 다시 실행
4. **v1.0 저장** — 최종 지침 맨 위에 `지침 v1.0 · 작성일 · 작성자` 한 줄을 추가해 메모장 + 워크시트 `Part2` › `지침_원문`에 저장(Ctrl+S)
## 막히는 지점
- 가상 문의에서 AI가 한쪽 수수료만 단정하는 경우 → 5단계 기준으로 멈출 때 규칙을 더 구체적으로 고쳐 달라고 요청
