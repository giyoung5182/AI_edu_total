# 3. 보여주는 데이터: 차트·표·VBA로 완성하기

정리일: 2026-10-08 · 교육 에셋 N0910

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 실습 시작 전 준비
실습을 시작하기 전에 다음 사항을 직접 확인합니다.
- `copilot.microsoft.com`에 접속하여 로그인합니다.
- Excel을 열어 새 빈 시트를 준비합니다. Excel이 없다면 Google Sheets를 사용합니다.
- PowerPoint 또는 Google Slides를 열어 빈 슬라이드 1장을 준비합니다.
- Excel에서 `Alt + F11`을 눌러 VBA 편집기가 정상적으로 열리는지 확인합니다. 열리지 않는다면 아래 VBA 보안 설정 안내를 먼저 확인합니다.
> ⚠️ **보안 주의**: 사내 기밀 데이터나 고객 개인정보는 외부 AI 서비스에 입력하지 않습니다. 이 교안에 포함된 샘플 데이터를 사용합니다. 본인의 실제 업무 데이터를 사용하고 싶다면, 아래 "나만의 샘플 데이터 만드는 방법" 섹션을 참고하여 가상 데이터로 변환한 후 사용합니다.
> ⚠️ **VBA 보안 설정 안내**: VBA 매크로 실행 전, Excel에서 `파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정`에서 **"모든 매크로 포함"** 을 선택합니다. 실습 후에는 반드시 **"알림을 표시하고 VBA 매크로 비활성화"** 로 되돌립니다. 또한 Copilot이 생성한 코드를 실행하기 전에 원본 파일의 백업 사본을 반드시 만들어 둡니다.

## 학습 목표
이 모듈을 마치면 다음 네 가지를 할 수 있게 됩니다.
1. Copilot이 생성한 표와 데이터를 Excel, HWP, PPT로 옮기는 흐름을 이해하고, 각 도구별 붙여넣기 방법과 주의사항을 실행할 수 있습니다.
2. 데이터의 성격에 맞는 차트 유형을 스스로 선택하고, 해석 멘트를 Copilot으로 자동 생성하여 보고서에 바로 활용할 수 있습니다.
3. 반복 작업을 자동화하는 Excel VBA 매크로를 Copilot의 도움으로 작성하고 실행할 수 있습니다.
4. 분석 결과를 임원 보고용 Executive Summary 형식으로 압축하여 작성할 수 있습니다.

## 3-1. Copilot 결과 표를 Excel·HWP·PPT로 옮기는 흐름
Copilot이 데이터를 정리하거나 분석하여 출력하는 표는 기본적으로 **마크다운(Markdown) 형식**입니다. 마크다운 표는 파이프(`|`) 기호로 열을 구분하는 텍스트 기반 형식으로, 화면에서는 보기 좋게 표시되지만 Excel이나 HWP, PPT에 그대로 붙여넣으면 형식이 무너지는 경우가 생깁니다.
전체 흐름은 다음과 같습니다.
```plain text
[Copilot 채팅] → 표 생성 요청
        ↓
    마크다운 표 복사 (Ctrl+A 후 Ctrl+C)
        ↓
[Excel]               [HWP]                [PPT]
붙여넣기 후              붙여넣기 →             핵심 수치만 발췌하여
텍스트 나누기(|)         표 메뉴 →              PPT 표에 직접 입력
사용                   문자열을 표로
```
**Excel로 옮길 때** 열 구분이 제대로 되지 않는 경우 아래 방법으로 해결합니다.
```plain text
[Excel 텍스트 나누기 방법]
① 붙여넣은 내용이 있는 열(A열) 전체를 선택합니다.
② 상단 메뉴 "데이터" 탭 → "텍스트 나누기"를 클릭합니다.
③ "구분 기호로 분리됨"을 선택하고 "다음"을 클릭합니다.
④ 구분 기호에서 "기타"를 체크하고 입력란에 "|"(파이프)를 입력합니다.
⑤ "마침"을 클릭합니다.
```
**HWP(한글)로 옮길 때**는 마크다운 표를 붙여넣은 후 전체 텍스트를 선택하고 `표 메뉴 → 문자열을 표로` 기능을 사용하면 파이프 기호를 기준으로 열이 자동 분리됩니다.
**PPT로 옮길 때**는 표 전체를 텍스트로 붙여넣으면 서식이 무너질 수 있으므로, 핵심 수치만 발췌하여 PPT의 `삽입 → 표` 기능으로 직접 만든 표에 입력하는 방식을 권장합니다.

### 🖥️ 실습 1 — 비정형 수익성 데이터를 Copilot으로 표 정리하기
아래 모의 수익성 데이터를 Copilot으로 정형화하고 Excel에 옮깁니다. 데이터는 분야별로 표기 방식이 제각각인 비정형 형태로 작성되어 있습니다.
---
**\[모의 수익성 데이터 — 2025년 상반기 분야별 실적\]**
각 분야의 표기 방식이 다릅니다. 법인자문은 월별 매출·비용이 명시되어 있고, 소송은 구분자 없이 숫자만 나열되어 있으며, 부동산은 월 평균값만 제공됩니다. 노동 분야는 단위 표기가 마지막에만 있고, 지재권은 분기 묶음으로 표기되어 있습니다.
```plain text
법인자문: 1월 매출 3,200만원 비용 2,100만원 / 2월 매출 2,900만원 비용 2,050만원 /
3월 매출 3,100만원 비용 2,200만원 / 4월 매출 2,800만원 비용 2,150만원 /
5월 매출 2,700만원 비용 2,100만원 / 6월 매출 2,600만원 비용 2,050만원

소송: 1월 4,100만원 / 1,800만원, 2월 3,900만원 / 1,750만원, 3월 4,500만원 / 1,900만원
4월 4,200만원 / 1,850만원, 5월 4,800만원 / 1,950만원, 6월 5,100만원 / 2,000만원

부동산: 월 평균 매출 2,500만원, 비용 1,200만원 (1~6월 동일 수준 유지)

노동: 상반기 급증. 1월 1,800 / 900, 2월 2,200 / 1,000, 3월 3,100 / 1,300,
4월 3,800 / 1,500, 5월 4,200 / 1,700, 6월 4,900 / 1,900 (단위: 만원)

지재권: 1~3월 각 1,500만원(비용 800만원), 4~6월 각 1,200만원(비용 750만원)
```
---
1. Copilot 채팅 창에 아래 프롬프트와 위 데이터를 **함께** 붙여넣어 전송합니다.
```plain text
아래 텍스트 데이터를 표로 정리해줘.
컬럼: 분야, 월, 매출(만원), 비용(만원), 수익(만원), 수익률(%)
- 수익 = 매출 - 비용으로 계산해줘.
- 수익률 = 수익 / 매출 × 100으로 계산하고 소수점 첫째 자리까지 표시해줘.
- 부동산처럼 월별 차이가 없는 경우 1~6월 각각 동일한 값으로 행을 만들어줘.
- 누락된 데이터는 "미확인"으로 표시해줘.

[위 모의 수익성 데이터 붙여넣기]
```
1. Copilot이 출력한 표를 확인합니다. 수익과 수익률이 올바르게 계산되었는지, 30개 행(5개 분야 × 6개월)이 모두 생성되었는지 검토합니다.
2. 표를 Excel에 붙여넣습니다. 열 구분이 무너졌다면 위의 텍스트 나누기 방법을 사용합니다.
3. Excel 표에 `Ctrl + T`를 눌러 표 서식을 적용하고, `수익성분석_실습.xlsx`로 저장합니다.
**기대 결과**: 분야별·월별 매출, 비용, 수익, 수익률이 포함된 30행짜리 정형 데이터 표가 Excel에 완성됩니다.

## 3-2. 차트 유형 추천 및 해석 멘트 자동 생성
데이터를 표로 정리하는 것만으로는 의사결정자에게 충분한 정보를 전달하기 어렵습니다. 사람은 숫자 나열보다 시각화된 차트에서 패턴과 인사이트를 훨씬 빠르게 파악합니다.
**차트 유형 선택 기준**은 데이터로 무엇을 말하고 싶은지에 따라 결정됩니다.





목적

추천 차트

프롬프트 키워드




시간에 따른 변화

꺾은선 그래프

"추이, 변화, 월별"




항목 간 비교

막대 그래프

"비교, 순위, 분야별"




비율·구성

원형/도넛 차트

"비율, 구성, 전체 중"




두 변수의 관계

산점도

"상관관계, 분포"




목표 대비 실적

게이지/혼합 차트

"달성률, 목표 대비"


차트 유형을 선택한 후에는 Copilot에게 **해석 멘트 자동 생성**을 요청할 수 있습니다. 해석 멘트란 차트가 말하는 핵심 내용을 언어로 풀어쓴 설명으로, 보고서에서 차트 아래나 옆에 배치되는 분석 코멘트입니다.
```plain text
아래 데이터를 분석하고 임원 보고용 해석 멘트를 작성해줘.
- 핵심 인사이트 2가지 (수치 포함)
- 주목할 이상치 또는 변화 1가지
- 다음 액션 제안 1가지
문체: 간결하고 결론 우선으로

[데이터 붙여넣기]
```
> ⚠️ **주의**: Copilot이 생성한 해석 멘트는 반드시 직접 검토해야 합니다. 특히 수치가 포함된 경우 Copilot이 계산을 잘못하거나 데이터를 잘못 해석할 수 있습니다. Copilot의 멘트는 초안으로만 사용하고, 숫자는 원본 데이터와 반드시 대조합니다.

### 🖥️ 실습 2 — 차트 유형 선택 및 Excel 차트 생성
1. Copilot 채팅 창에 아래 프롬프트를 입력합니다.
```plain text
아래 데이터로 임원 보고용 차트를 만들려고 해.
데이터 구조: 5개 분야(법인자문, 소송, 부동산, 노동, 지재권)의
2025년 1~6월 매출, 비용, 수익률이 포함되어 있어.

아래 목적에 맞는 차트 유형을 각각 추천해줘:
① 분야별 월별 수익률 변화 추이를 보여주고 싶을 때
② 상반기 전체 매출에서 각 분야의 비중을 보여주고 싶을 때
③ 분야별 올해 상반기 총매출을 비교하고 싶을 때

각 목적마다 추천 차트 유형, 이유, Excel에서 만드는 방법을 알려줘.
```
1. 추천 결과를 읽고 아래 세 가지 중 **본인이 만들 차트 1개**를 선택합니다.
```plain text
① 꺾은선 그래프 — 분야별 월별 수익률 변화 추이
② 원형/도넛 차트 — 상반기 분야별 매출 비중
③ 묶음 막대 그래프 — 분야별 상반기 총매출 비교
```
1. 선택한 차트를 Excel에서 직접 만듭니다.
```plain text
[Excel 차트 생성 방법]
① 실습 1에서 저장한 Excel 파일을 열고, 차트에 사용할 데이터 범위를 선택합니다.
   (Ctrl을 누르며 불연속 범위를 다중 선택할 수 있습니다.)
② 상단 "삽입" 탭 → 원하는 차트 유형을 클릭합니다.
③ 차트가 삽입되면 우측 상단 "+" 버튼으로 제목·범례·데이터 레이블을 추가합니다.
④ 차트 제목을 더블클릭하여 의미 있는 제목으로 수정합니다.
⑤ 차트를 클릭하고 Ctrl+C로 복사하여 PPT에 붙여넣을 준비를 합니다.
```
**기대 결과**: 데이터의 특성에 맞는 차트가 Excel에 생성되고, PPT 삽입 준비가 완료됩니다.

## 3-3. 매크로·VBA 코드 작성 및 데이터 분석 자동화 연동
매달 같은 형식의 데이터를 처리하거나 반복적으로 같은 서식을 적용하는 작업이 있다면 Excel의 **VBA(Visual Basic for Applications) 매크로**를 활용하여 자동화할 수 있습니다. Copilot을 활용하면 자연어로 원하는 동작을 설명하는 것만으로도 즉시 사용 가능한 VBA 코드를 얻을 수 있습니다.
**VBA 코드 요청 프롬프트 패턴**은 다음과 같습니다. 시트명과 데이터 범위를 명확하게 지정하는 것이 가장 중요합니다. 범위가 모호하면 Copilot이 임의로 범위를 설정하여 엉뚱한 데이터가 처리될 수 있습니다.
```plain text
Excel VBA 매크로를 작성해줘.
기능: [원하는 동작 설명]
조건:
- 시트명: "데이터"
- 처리 범위: A2부터 마지막 행까지
- 결과 출력: "결과" 시트에 붙여넣기
코드와 함께 각 줄의 의미도 주석으로 달아줘.
```
실무에서 자주 요청하는 VBA 자동화 유형은 다음과 같습니다.


<colgroup>
<col>
<col width="573">
</colgroup>



작업

설명




시트 분리 저장

특정 열(예: 담당자명)을 기준으로 데이터를 나눠 각각 별도 시트 또는 파일로 저장합니다.




서식 일괄 적용

특정 조건(예: 수익률이 음수인 행)에 해당하는 행 전체에 빨간색 배경이나 굵은 글꼴을 자동으로 적용합니다.




데이터 통합

여러 시트에 분산된 동일한 형식의 데이터를 하나의 시트로 합칩니다.




이메일 자동 발송

Outlook과 연동하여 특정 조건이 충족되면 지정된 수신자에게 보고 이메일을 자동으로 발송합니다.


VBA 코드를 받은 후 Excel에서 실행하는 방법은 다음과 같습니다.
```plain text
[VBA 코드 실행 방법]
① Excel에서 Alt + F11을 눌러 VBA 편집기를 엽니다.
② 삽입 → 모듈을 클릭합니다.
③ Copilot이 생성한 코드를 붙여넣습니다.
④ F5를 누르거나 실행 버튼을 클릭합니다.
```

### 🖥️ 실습 3 — VBA 매크로 요청 및 실행해보기
아래 실습 데이터를 사용하여 VBA 매크로를 Copilot에 요청하고 직접 실행해봅니다.
---
**\[실습 데이터 — 담당자별 처리 건수\]**
아래는 담당자별로 처리한 소송 건 목록입니다. 담당자명 표기 방식이 일부 다르고, 처리 상태가 누락된 행도 포함되어 있습니다.

## 3-4. 임원·파트너 보고용 Executive Summary 작성하기
아무리 훌륭한 데이터 분석 결과물이라도 받는 사람이 빠르게 핵심을 파악하지 못하면 의사결정으로 이어지지 않습니다. 임원 보고에서는 **결론을 먼저, 근거를 그 다음에** 제시하는 것이 원칙입니다. 이것을 한 장에 압축한 것이 바로 **Executive Summary**입니다.
아래 프롬프트를 활용하면 Copilot이 긴 분석 결과를 즉시 압축해 줍니다. **"단언형, 수치 중심, 군더더기 없이"** 라는 문체 지시가 핵심입니다. 이 지시가 없으면 Copilot이 "\~한 것으로 보입니다"처럼 불확실한 표현을 사용하는 경향이 있어 임원 보고 신뢰도를 낮출 수 있습니다.
```plain text
아래 데이터 분석 결과를 임원 보고용 Executive Summary로 작성해줘.
분량: 5줄 이내
구성:
① 한 줄 결론 (가장 중요한 발견)
② 핵심 수치 2~3개 (전기 대비 변화율 포함)
③ 주요 리스크 또는 기회 1가지
④ 권고 액션 1가지
문체: 단언형, 수치 중심, 군더더기 없이
```
잘 작성된 Executive Summary의 예시는 다음과 같습니다.
```plain text
① 올해 상반기 전체 수익률은 전년 동기 대비 12.4% 증가하였으며,
   노동 분야 수임 건수 급증이 주요 원인입니다.
② 핵심 수치: 총 매출 23억 4천만 원(+8.2%), 수익률 34.7%(+3.1%p),
   노동 분야 매출 비중 28%(전년 19%)
③ 리스크: 법인자문 분야 수익률이 전 분야 중 유일하게 감소(-4.2%)하였으며,
   주요 고객 이탈 가능성이 있습니다.
④ 권고: 법인자문 담당 인력 재배치 및 7월 말까지 주요 고객 만족도 조사 실시를
   권고합니다.
```

## 나만의 샘플 데이터 만드는 방법
위 샘플이 본인 업무와 거리감이 느껴진다면 아래 두 가지 방법으로 직접 만들 수 있습니다. 단, 실제 매출·비용 수치, 고객명 등 기밀 정보는 절대 입력하지 않고 반드시 가상의 수치로 대체합니다.
**방법 1 — 실제 보고서 구조를 가상 수치로 치환하기**
실제 업무 데이터의 구조(분야 구성, 기간, 항목)는 그대로 유지하되, 아래와 같이 실제 수치와 정보만 치환합니다.
```plain text
실제 분야명    → A분야, B분야, C분야 등 익명 처리
실제 매출 수치 → 임의 숫자 (예: 1,500만원, 3,200만원)
실제 날짜      → 임의 날짜 (예: 1월, 2월 등 또는 2025-01)
표기 방식      → 분야마다 일부러 다르게 작성 (혼재 형태 유지)
이상치         → 특정 분야/월의 수치를 의도적으로 높거나 낮게 설정
```
**방법 2 — Copilot에게 샘플 생성 요청하기**
아래 프롬프트에서 `[업무 유형]`에 본인의 업무(예: 월별 수임료 실적, 프로젝트별 비용, 부서별 매출)를 입력합니다.
```plain text
나는 [업무 유형] 데이터를 다루고 있어.
비정형 텍스트 형태의 모의 실적 데이터를 만들어줘.

조건:
- 5개 카테고리(분야, 팀, 제품 등)의 6개월치 데이터
- 각 카테고리마다 표기 방식이 다를 것
  (예: 카테고리 A는 "매출 X원 비용 Y원" 형식,
   카테고리 B는 숫자만 나열, 카테고리 C는 월 평균만 제공)
- 하나의 카테고리에 눈에 띄는 이상치(급증 또는 급감) 포함
- 모든 수치는 가상으로 작성해줘.
```

## 실습 후 정리 사항
**결과물 저장**: 실습 1\~4에서 만든 Excel 수익성 파일, Executive Summary 텍스트, PPT 보고 슬라이드를 하나의 폴더에 저장합니다. 폴더명은 `트랙2_모듈3_실습결과_[날짜]`로 정리합니다.
**VBA 보안 설정 복원**: 실습 중 보안 설정을 변경했다면, 실습 후 반드시 `파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정`에서 **"알림을 표시하고 VBA 매크로 비활성화"** 로 되돌립니다.
**프롬프트 라이브러리 업데이트**: 이번 실습에서 사용한 차트 유형 추천 프롬프트, 해석 멘트 생성 프롬프트, Executive Summary 프롬프트, VBA 요청 프롬프트를 개인 프롬프트 라이브러리에 추가합니다. 특히 Executive Summary 프롬프트는 데이터 보고 외에도 회의 결과 요약, 프로젝트 현황 보고 등 다양한 상황에 재활용할 수 있으므로 별도로 메모해 둡니다.
**슬라이드 템플릿화**: 실습 4에서 완성한 슬라이드의 내용을 비운 빈 템플릿을 별도로 저장합니다. 다음 보고 때 이 템플릿에 새 데이터와 차트만 넣으면 동일한 형식의 슬라이드를 빠르게 완성할 수 있습니다.
**업무 적용 계획 수립**: 이 기술을 바로 적용할 수 있는 본인 업무 상황을 한 가지 정합니다. 예를 들어 "월말 팀 실적 보고를 이 슬라이드 형식으로 바꾸겠다"처럼 구체적으로 작성합니다.

## 모듈 요약 및 다음 모듈 안내
이 모듈에서 다음 네 가지를 배웠습니다.
1. Copilot이 생성한 마크다운 표를 Excel, HWP, PPT 각각에 올바르게 옮기는 방법과 열 구분이 무너졌을 때 텍스트 나누기로 해결하는 방법을 실습했습니다.
2. 데이터의 목적에 따라 꺾은선·막대·원형 차트 등 적합한 차트 유형을 선택하고 Copilot으로 해석 멘트를 자동 생성하는 방법을 익혔습니다.
3. VBA 매크로를 Copilot에게 자연어로 요청하여 코딩 없이 반복 작업을 자동화하는 방법을 직접 실행했습니다.
4. 분석 결과를 임원 보고용 Executive Summary로 압축하고, 차트·수치·요약을 하나의 슬라이드에 담는 전 과정을 완성했습니다.
다음 모듈인 **"미니 프로젝트: 우리 팀 숫자, 한 페이지로"** 에서는 오늘까지 배운 모든 기술을 통합하여, 직접 선택한 팀 데이터를 가지고 데이터 수집부터 한 장 보고서 완성까지의 전체 워크플로우를 실전처럼 수행하게 됩니다.
