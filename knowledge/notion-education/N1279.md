# STEP 2 — 비로그인 검증

정리일: 2026-10-08 · 교육 에셋 N1279

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
게시한 링크가 로그인 없이 열리는지 직접 확인합니다.
## 진행 단계
1. **시크릿 창 열기** — Windows: Ctrl + Shift + N / Mac: Cmd + Shift + N
2. **링크 접속** — 복사한 링크를 붙여넣고 접속
3. **휴대폰으로 열기** — 카카오톡으로 링크를 보내 휴대폰에서 열어보기
4. **옆자리 확인** — 옆자리 선생님께 링크를 보내 열어보게 하기
- 정상 결과: 시크릿 창에서 정상 열림(로그인 화면 안 뜸), 휴대폰에서 정상 열림, 카카오톡 인앱 브라우저에서도 동작
[원본 이미지 제외]
## 막히는 지점
- 시크릿 창은 로그인이 안 된 상태. 학생들은 이 링크만 있으면 됨(계정·가입·앱 설치 불필요)
- 게시본 하단에 "콘텐츠는 사용자가 생성한 것으로 검증되지 않았습니다" 문구가 붙음
