# 순서를 바꿔보자 — 알고리즘 순서 실험실
## 무엇을
학생이 화면에 있는 **활동 카드 5장을 끌어서 순서를 바꾼다.**<br>'실행' 버튼을 누르면 그 순서대로 캐릭터가 움직이고, 결과가 화면에 나온다.
예: 「라면 끓이기」 카드 5장
```plain text
물을 붓는다 / 불을 켠다 / 면을 넣는다 / 스프를 넣는다 / 불을 끈다
```
순서를 바꿔 실행하면 결과가 달라진다.<br>(면을 먼저 넣으면 "찬물에 면이 불었어요")
## 왜
**순서가 바뀌면 결과가 달라진다**는 것을 말이 아니라 눈으로 확인하게 한다.
"알고리즘은 순서다"라고 설명하는 것보다,<br>잘못된 순서로 실행해서 이상한 결과를 직접 보는 편이 훨씬 오래 남는다.
## 사용자
- 초등 4\~5학년
- 알고리즘 단원 도입 차시
- 수업 중 각자 태블릿 또는 휴대폰으로 접속
- 모둠별로 순서를 정해보고 발표하는 활동과 연결
## 화면 구성
```plain text
1. 맨 위 — 제목 "순서를 바꿔보자"
          그 아래 한 줄 안내 "카드를 끌어서 순서를 바꿔보세요"

2. 가운데 — 활동 카드 5장이 세로로 놓여 있다
           각 카드에 번호(1~5)와 내용이 적혀 있다
           손가락이나 마우스로 끌어서 위아래로 옮길 수 있다

3. 카드 아래 — 큰 '실행하기' 버튼

4. 실행하면 — 카드가 위에서부터 하나씩 차례로 켜진다
              각 단계마다 어떤 일이 일어나는지 한 줄로 나온다

5. 마지막 — 결과가 나온다
           올바른 순서면 "맛있는 라면 완성!"
           틀린 순서면 "무엇이 이상했을까요?" + 어느 단계가 문제였는지

6. 맨 아래 — '다시 하기' 버튼 (카드가 다시 섞인다)
```
## 완료 조건
- 카드 5장을 손가락으로 끌어서 순서를 바꿀 수 있다
- '실행하기'를 누르면 순서대로 하나씩 진행된다
- 마지막에 결과 문장이 나온다
- 틀렸을 때 **어느 단계가 문제였는지** 알려준다
- '다시 하기'로 처음부터 할 수 있다
- 휴대폰 세로 화면에서 잘리지 않는다
## 오늘 넣지 않는 것
- 학생 이름이나 시도 횟수 저장
- 로그인
- 여러 개의 활동 세트 (라면 하나로 충분)
- 점수 순위표
## 애매한 것
- 카드를 5장으로 할지 6장으로 할지 (5장으로 시작)
- 틀렸을 때 정답을 바로 알려줄지, 힌트만 줄지 (힌트만)
- 실행 속도를 얼마나 천천히 할지 (한 단계에 1초 정도)
