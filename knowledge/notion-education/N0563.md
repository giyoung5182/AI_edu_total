# 실습 · Skill 만들고 써보기

정리일: 2026-10-08 · 교육 에셋 N0563

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
방금 한 작업을 Skill로 정리하고, 다른 주제로 한 번 더 만들어 처음보다 시간이 줄어드는 것을 확인합니다.
## 진행 단계
1. **STEP 1 · Skill 만들기 (8분)** — skill-creator로 방금 진행한 작업을 Skill로 만듭니다.
- 입력할 내용:
```javascript
skill-creator를 써서, 방금 진행한 작업을
앞으로 반복해서 쓸 수 있는 Skill로 만들어줘.

이 Skill은 이런 상황에서 씁니다.
- 수업에 쓸 안내 자료 내용이 있습니다
- 그걸 학생들이 볼 수 있는 웹 페이지로 만들어야 합니다
- index.html 파일 하나로 만듭니다
- 초등학생이 보기 쉬워야 합니다

작업 순서와 확인할 점도 같이 넣어줘.
폴더 이름은 영문 소문자로 지어줘.
```
- 정상 결과: 승인 화면에서 \[수락\] 후 Skill 폴더가 생기고 만들어졌다는 응답이 나옴
1. **STEP 2 · 내용 확인 (4분)** — "방금 만든 Skill 내용을 보여줘."로 열어 확인합니다.
- 확인할 것: 언제 쓰는지 설명 / 받는 자료 / index.html 한 파일 / 글자 크기·쉬운 말 기준 / 작업 후 확인할 것
- 설명이 부족하면 "설명 부분을 더 구체적으로 고쳐줘…"로 보완하고, "방금 만든 Skill, 언제 쓰는 거야?"로 제대로 꺼내지는지 진단합니다.
2. **STEP 3 · 두 번째 결과물 만들기 (10분)** — 다른 주제로 하나 더 만듭니다.
- 입력할 내용:
```javascript
새로 class2 폴더를 만들고,
방금 만든 Skill을 써서 [다른 주제]로 하나 더 만들어줘.
```
- 정상 결과: class2 폴더에 새 index.html이 생기고 브라우저에서 열림, 처음(43분)보다 시간이 짧아짐
## 막히는 지점
- Skill을 안 쓰고 그냥 만듦 → 설명이 막연함, STEP 2로 돌아가 보완
- Skill을 못 찾음 → "아까 만든 Skill 어디 있어?"라고 질문
- 결과가 첫 번째와 딴판 → 빠진 기준을 한 줄 추가
