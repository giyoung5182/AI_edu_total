# 모델 vs 도구 — 같은 출장 1건으로 세 가지 요청해보기

정리일: 2026-10-08 · 교육 에셋 N0561

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 출장 1건으로 문장 쓰기(A), 합계 계산(B-1 문장 / B-2 코드), 외부 정책 확인(C)을 요청해 무엇이 모델의 생성이고 무엇이 도구 결과인지 관찰합니다.
## 진행 단계
1. **먼저 예측** — 워크시트 P1-2 예측 칸: 세 요청 중 그대로 믿기 가장 어려운 것은? / 정산 합계를 물으면 코드를 쓸까, 문장으로 바로 답할까?
2. **요청 A: 문장 쓰기** — ChatGPT 새 채팅(Chat 토글 유지)에서 입력.
- 입력할 내용:
```javascript
[자료] 출장 1건
- 정산번호: TR-2026-0010
- 출장지: 오사카
- 출발일: 2026-07-21 / 복귀일: 2026-07-25
- 항공권 등급: 이코노미 / 항공료: 544,833원
- 숙박비(1박당): 169,548원 / 숙박일수: 4박
- 일비(1일): 50,000원
- 결제방법: 법인카드

[요청 A]
위 출장 건을 고객사 출장 담당자에게 안내하는 2문장을 써줘.
금액은 위 자료에 있는 값만 쓰고, 합계는 쓰지 마.
```
- 정상 결과: 2문장 안팎의 안내문.
1. **요청 B-1: 계산을 문장으로** — 같은 채팅에 이어서 입력.
```javascript
[요청 B-1]
위 출장 건의 정산 합계를 원 단위로 알려줘.
합계 = 항공료 + (숙박비 1박당 × 숙박일수) + (일비 × 일비 일수)
일비 일수는 출발일과 도착일을 각각 1일로 센다.
답은 숫자 한 줄로만 줘.
```
1. **요청 B-2: 계산을 도구로** — 같은 채팅에 이어서 입력.
```javascript
[요청 B-2]
같은 합계를 이번에는 코드로 계산해줘.
① 항목별 금액(항공료, 숙박비 합계, 일비 합계)
② 일비 일수를 어떻게 셌는지
③ 최종 합계
를 순서대로 보여주고, 사용한 코드도 함께 보여줘.
```
- 정상 결과: 코드 블록 또는 '분석' 표시와 함께 항목별 금액.
1. **직접 검산** — 휴대폰 계산기나 엑셀로 항목별 금액을 계산해 P1-2 본인 검산 값 열에 기록(예: 숙박비 합계 `=169548*4`). B-1 답의 값·B-2 답의 값·일치 여부도 기록.
2. **요청 C: 외부 정책 확인**
```javascript
[요청 C]
인천–오사카 왕복 이코노미 항공권을 출발 전에 날짜 변경할 때
항공사 변경 수수료가 현재 얼마인지 알려줘.
어디에서 확인한 정보인지 출처와 기준일을 함께 적어줘.
```
1. **관찰·판정** — P1-2 관찰표(요청별 모델이 만든 부분 / 도구 흔적 / 확인 방법). A는 자료와 한 글자씩 같으면 '근거 확인', B는 본인 검산과 같으면 '근거 확인', C는 출처 링크를 열어 확인되면 '근거 확인'(출처가 없으면 '보류', 모델이 확인 불가라 답하면 '확인 불가 응답').
## 막히는 지점
- B-2에 코드 없이 풀이 문장만 나옴 → '방금 계산을 실제로 코드로 실행했는지 알려줘…'로 재질문.
- B-1과 B-2 합계가 다름 → 일비 일수 해석(규정집 제15조) 확인.
- A에 자료에 없는 조건이 들어감 → 해당 문장만 삭제 요청. C에 출처가 없음 → 출처·확인일 없는 정보는 쓰지 말라고 재요청.
