# 직접 확인 — 한글·영어 문장의 토큰 수 비교

정리일: 2026-10-08 · 교육 에셋 N0651

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 뜻의 문장이 몇 조각(토큰)으로 끊기는지 공식 화면에서 직접 확인합니다.
## 진행 단계
1. **토크나이저 열기** — 새 탭(Ctrl+T)에서 아래 주소 입력 후 Enter
- 입력할 내용:
```plain text
https://platform.openai.com/tokenizer
```
1. **문장 입력** — 가운데 입력칸에 두 문장을 하나씩 붙여넣기
- 입력할 내용:
```plain text
우리 팀은 다음 주에 출장 정산 결과를 정리합니다
```
```plain text
Our team will organize the travel expense results next week
```
1. **Tokens 숫자 확인** — 입력칸 아래 Tokens 숫자를 두 번 모두 확인(Characters는 보지 않음)
2. **기록** — 워크시트 Part1 시트 빈 곳 또는 메모장에 `한글 [ ]토큰 / 영어 [ ]토큰`
## 막히는 지점
- 한글이 토큰을 더 많이 쓰는 경우가 많음
- 이 화면은 ChatGPT 안의 실제 수와 정확히 같지 않음(경향 확인용)
- 로그인을 요구하거나 열리지 않으면 건너뛰고 강사 화면으로 확인
