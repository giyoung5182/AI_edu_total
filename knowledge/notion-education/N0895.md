## 2. 공통 흐름 — 모든 트랙이 거치는 3단계 (30분)
트랙이 달라도 앞 30분은 같음. 여기서 만든 것이 트랙별 재료가 됨.
```plain text
[1] Claude      → 문구·구성 확정
[2] Gem + AI Studio → 배경·소재 이미지
[3] 미리캔버스   → 텍스트 레이어
```
### 2-1. STEP 1 — Claude로 문구를 먼저 확정 (10분)
⚠️ **이미지부터 만들지 않음.** 글자가 몇 자인지 모르면 여백을 얼마나 비워야 할지 모름.
```plain text
순서
  ① 문구를 먼저 확정
  ② 글자 수를 셈
  ③ 그 길이에 맞춰 이미지 여백을 설계
  ④ 이미지 생성
```
**Claude 입력 — 발산 3안 먼저**
```plain text
[역할]
너는 외식 프랜차이즈 매장의 온라인 홍보를 담당하는 마케터야.
짧은 문구로 방문을 유도하는 카피가 특기야.

[상황]
브랜드: 【브랜드명】
소재: 【신메뉴명 / 공지 내용 / 행사 내용】
구성: 【재료 또는 핵심 정보】
게시처: 【소식탭 / 인스타 / 매장 POP / 사내 공지】

[요청]
A·B·C 3가지 방향으로 만들어줘.
  A = 정통·신뢰 강조
  B = 트렌디·가벼운 톤
  C = 감성·계절감

각 안마다:
① 메인 카피 (15자 이내)
② 서브 카피 (25자 이내)
③ 본문 (2줄 이내)
④ 해시태그 5개

[제약]
- 과장 표현 금지 ("최고", "1위", "국내 유일" 등)
- 실제 재료·사실에 없는 것을 언급하지 말 것
- 각 안의 톤이 확실히 구분되게 할 것
```
⚠️ **과장 표현 금지를 반드시 넣음.** 근거 없는 최상급 표현은 표시광고 문제가 될 수 있음.
**수렴 — 하나를 고르고 다듬음**
```plain text
B안으로 갈게. 다만 메인 카피가 조금 길어.
12자 이내 버전 3개만 더 줘. 나머지는 그대로 유지해.
```
💡 **"나머지는 그대로 유지"를 안 쓰면** Claude가 본문·해시태그까지 다시 써버림. STYLE LOCK과 같은 원리임.
**글자 수를 셈**
```plain text
메인 카피: 12자, 1줄
서브 카피: 22자, 1줄
→ 이미지 상단에 2줄이 들어갈 자리를 비워야 함
```
### 2-2. STEP 2 — Gem + AI Studio로 이미지 (12분)
**Gem에 세 단어만 입력**
```plain text
【브랜드명】, 【메뉴명 또는 소재】, 【용도】
```
→ 스타일 블록 + 콘텐츠 블록 + 금지 + 체이닝 2·3·4차가 나옴.
⚠️ **\[추정\] 표시가 붙은 항목을 반드시 실제와 대조해서 고침.** Gem이 재료·개수를 임의로 채웠을 수 있음.
**여백 지시를 붙임 (STEP 1의 글자 수 기준)**
```plain text
[레이아웃 추가 지시]
- 이미지에 어떤 텍스트도 넣지 말 것
- 상단 1/3은 배경만 두고 단순하게 비워둘 것 (2줄이 들어갈 자리)
- 하단 우측 모서리를 어둡고 단순하게 (로고 자리)
- 주요 피사체는 중앙에서 약간 아래에
```
**AI Studio에서 생성 → 체이닝 → 검수**
```plain text
1차(60%) → 2차 재료 → 3차 조명 → 4차 분위기
⚠️ Gemini 앱 아님. AI Studio (워터마크)
⚠️ 매 단계 저장 (되돌리기 없음)
⚠️ 2권 4-2 체크리스트로 확대해서 할루시네이션 검수
```
### 2-3. STEP 3 — 미리캔버스로 텍스트 (8분)
⚠️ **규격을 먼저 정함.** 나중에 바꾸면 레이아웃이 다 깨짐.

1080 × 1920 px

네이버 플레이스 소식탭

⚠️ 확인 필요 — 당일 확인


```plain text
1. miricanvas.com → 규격 선택
2. [업로드] → AI Studio 이미지 업로드 → 배경 배치
3. [텍스트] → 메인 / 서브 / 본문 / 가격을 각각 별도 요소로

```
⚠️ **확인 필요:** 미리캔버스 화면 구성은 수시로 변경됨. 당일 실제 화면으로 확인함.
⚠️ **하나의 텍스트 상자에 몰아넣지 말 것.** 각각 별도 요소여야 "타이틀만 위로"가 됨.
⚠️ **로고는 AI가 그린 것을 지우고 원본 파일을 얹음.**

## 3. 트랙 A — 홍보 포스터 (40분)
**결과물:** 신메뉴 포스터 3개 규격 (소식탭 / 인스타 1:1 / A4 POP)
### 3-1. 3개 규격 만들기
```plain text
[AI Studio — 체이닝 명령 B]
STYLE LOCK. 재료·조명·분위기는 동일하게 유지하고
구도만 아래 비율에 맞게 다시 잡아줘:
  ① 정사각형 (1:1)
  ② 세로 (A4 비율)
각 비율에서 글자 자리를 비워둘 것. 디자인 요소는 변경 금지.
```
```plain text
[미리캔버스]
1. 완성된 디자인을 복제
2. 규격 변경
3. 배경을 해당 비율 버전으로 교체
4. 텍스트 위치만 조정
```

💡 텍스트가 레이어이므로 **규격이 바뀌어도 다시 쓸 필요가 없음.** 위치만 옮김. 이것이 텍스트 분리의 진짜 이득임.

## 4. 트랙 B — 메뉴판 (40분)
**결과물:** A4 세로 메뉴판 (인쇄용)
### 4-1. 2권에서 해부한 문제를 실제로 고침
```plain text
[기존 방식의 문제]
프롬프트에 가격·용량을 넣음
  → AI가 "520cc 13,000"을 그림으로 그림
  → 오타·왜곡 위험 / 가격 바뀌면 처음부터 다시

[오늘 방식]
1. AI Studio — 배경만 (텍스트 없음, 상단·하단 여백 확보)
   ⚠️ 같은 스타일 블록으로 여러 제품을 생성 → 톤이 일치함
2. 미리캔버스 — A4 세로 템플릿
   제목 / 원산지 / 설명 / 용량·가격을 각각 텍스트 레이어로
3. 로고 원본을 얹음

[결과] 가격이 바뀌면 → 숫자만 수정. 3초.
```
### 4-2. ⚠️ 인쇄 해상도 — 여기서 대부분 무너짐
```plain text
A4를 300dpi로 인쇄하려면
  가로 2,480 px / 세로 3,508 px 필요

Google AI Studio 무료 등급 최대 출력
  약 2,048 px (2K)

  필요:  2,480 px
  가능:  2,048 px
         ──────── 부족
```
> **AI Studio에서 바로 뽑은 이미지는 A4 인쇄에 그대로 쓸 수 없음.**
**대응**
```plain text
[1안] 배경만 2K, 텍스트는 벡터로  ← 오늘 쓰는 방법
  미리캔버스에서 얹는 텍스트는 벡터라 확대해도 안 깨짐
  글자가 선명하면 인쇄물의 체감 품질이 크게 올라감
  → 이것만으로 상당수 해결됨

[2안] 업스케일 도구
  ⚠️ 확인 필요: 무료 도구를 리허설에서 검증 후 안내

[3안] 인쇄 규격을 낮춤 (250dpi 등)
  ⚠️ 확인 필요: 실제 인쇄소 요구 사양 확인 필요
```
⚠️ **숙제:** 현재 메뉴판을 어느 인쇄소에서 어떤 사양으로 넘기는지 확인해올 것.
💡 **웹·SNS용(1080px)은 지금 그대로 써도 충분함.** 문제는 인쇄물뿐임.

## 5. 트랙 C — 카드뉴스 (40분)
**결과물:** 5컷 카드뉴스 (1:1, 1080×1080)
### 5-1. 구성을 먼저 잡음
```plain text
[Claude에 입력]

5컷 카드뉴스 구성을 짜줘.
주제: 【매장 공지 / 신메뉴 소개 / 사내 안내】
대상: 【고객 / 가맹점주 / 임직원】

각 컷마다:
① 컷 번호와 역할 (표지 / 문제 제기 / 설명 / 강조 / 마무리)
② 메인 문구 (12자 이내)
③ 본문 (2줄 이내)
④ 이 컷에 어울리는 배경 이미지 설명 (텍스트 없이)

[제약]
- 표지 컷은 가장 강한 한 줄로
- 마지막 컷에는 행동 유도 문구 (방문·문의·확인 등)
- 과장 표현 금지
```
### 5-2. 5컷의 톤이 일치해야 함
⚠️ **카드뉴스의 성패는 5장의 톤이 같은가에 달림.** 5장을 따로 만들면 반드시 어긋남.
```plain text
[일관성 확보 방법]
1. 같은 스타일 블록으로 5장 생성 (콘텐츠 블록만 교체)
2. 첫 장이 마음에 들면, 그 이미지를 레퍼런스로 첨부해서 나머지 생성

   "첨부한 이미지의 톤·조명·색감을 그대로 유지하고,
    피사체만 【다음 소재】로 바꿔줘."

3. 미리캔버스에서 템플릿 1개 만들고 5장 복제
   → 배경과 문구만 갈아끼움
```
💡 3번이 핵심임. **템플릿을 복제하면 제목 위치·서체·컬러·로고 위치가 5장 모두 자동으로 같아짐.**
### 5-3. 사내 공지용이라면
```plain text
⚠️ 사내 공지·보고용 카드뉴스에 숫자가 들어간다면
   숫자를 AI가 그리게 하지 말 것.

   ❌ "3분기 매출 12억, 8% 증가한 인포그래픽 만들어줘"
      → AI가 12억을 12.4억으로 바꿔 그릴 수 있음. 사고임.

   ✅ AI Studio: 배경·그래픽 요소만 (숫자 없이)
      미리캔버스: 숫자를 텍스트 레이어로 직접 입력
```

### 6-2. 영상 프롬프트는 이미지와 다름
이미지 프롬프트는 \*\*"어떻게 보이는가"\*\*만 씀. 영상은 여기에 \*\*"어떻게 움직이는가"\*\*가 추가됨.
```plain text
[영상 프롬프트 5요소]

요소 1. 시작 이미지 (가장 중요)
   → 우리가 이미 만든 이미지를 그대로 씀
   → 밑그림이 있으니 결과가 훨씬 안정적임

요소 2. 피사체 동작 — 무엇이 움직이는가
   김이 천천히 피어오른다 / 국물이 자글자글 끓는다
   소스가 위에서 부어진다 / 치즈가 늘어난다
   젓가락이 고기 한 점을 집어 올린다
   숯불 위에서 지글거리며 연기가 오른다

요소 3. 카메라 무브 — 어떻게 찍는가
   천천히 다가감 (푸시인) / 천천히 물러남 (풀아웃)
   좌우로 스침 (팬) / 위에서 아래로 (틸트다운)
   피사체 주위를 도는 (오빗) / 손에 든 듯한 흔들림 (핸드헬드)

요소 4. 템포와 길이
   느리고 여유롭게 / 경쾌하고 빠르게
   길이: 8초 내외 (긴 영상은 여러 클립을 이어 붙임)

요소 5. 비율
   세로 9:16 (쇼츠·릴스·스토리)
   가로 16:9 (유튜브·매장 모니터)
```
### 6-3. 푸드 영상 프롬프트 템플릿
```plain text
[시작 이미지] 3권 STEP 2에서 만든 이미지를 첨부

[프롬프트]
시작 이미지의 구도와 색감을 그대로 유지할 것.

동작:
- 냄비에서 김이 천천히 피어오른다
- 국물 표면이 자글자글 끓는다
- 다른 요소는 움직이지 않는다

카메라:
- 천천히 피사체 쪽으로 다가간다 (느린 푸시인)
- 흔들림 없이 부드럽게

분위기:
- 따뜻하고 차분한 톤
- 8초, 세로 9:16

금지:
- 사람이나 손이 등장하지 않을 것
- 화면에 텍스트를 넣지 말 것
- 음식의 형태나 개수를 바꾸지 말 것
```
⚠️ **"다른 요소는 움직이지 않는다"가 중요함.** 안 쓰면 AI가 접시를 회전시키거나 재료를 스스로 늘림.
⚠️ **"화면에 텍스트를 넣지 말 것"** — 영상에서도 원칙은 같음. 자막·문구는 미리캔버스나 영상 편집 도구에서 레이어로 얹음.
### 6-4. 한국어와 영어
Flow는 한국어 프롬프트를 지원하지만, **복잡한 장면 묘사는 영어가 더 정확하다는 지적이 있음.**
```plain text
간단한 동작 → 한국어로 충분
  "김이 피어오른다", "천천히 다가간다"

복잡한 장면 → 영어 병기 권장
  slow dolly push-in toward the pot,
  steam rising gently, shallow depth of field,
  warm 2800K lighting, cinematic, no text, vertical 9:16
```
💡 영어가 어려우면 **Claude에게 번역을 시킴.**`"이 영상 프롬프트를 Veo에 최적화된 영문으로 바꿔줘"`
### 6-5. 영상 할루시네이션 검수
⚠️ **영상은 이미지보다 오류가 잘 보이지 않음.** 재생하면서 넘어가기 때문임.
```plain text
□ 음식의 개수가 도중에 늘거나 줄지 않는가
□ 형태가 도중에 뭉개지지 않는가
□ 국물·연기가 물리적으로 이상하게 움직이지 않는가
□ 손이 등장했다면 손가락이 정상인가
□ 화면에 글자가 생기지 않았는가
□ 그릇이나 배경이 도중에 바뀌지 않는가
```
**대응:** 프레임을 멈춰가며 확인함. 이상한 구간이 있으면 **그 부분을 잘라내거나 클립을 짧게 씀.**
### 6-6. 마감
```plain text
1. Flow에서 클립 다운로드
2. 미리캔버스에서 자막·로고를 레이어로 얹음
   ⚠️ 확인 필요: 미리캔버스 영상 편집 기능 지원 범위 확인 필요
3. 세로 9:16로 내보내기
```

## 7. 트랙 E — 인테리어 제안서 표준안 (40분)
**결과물:** 매장 인테리어 시작 전에 쓰는 **제안서 양식 1개**
### 7-1. 지금의 문제
```plain text
자료가 여기저기 흩어져 있음
무드보드 없이 인테리어를 시작함
갑자기 "AI로 간판 만들어줘" 요청이 옴
윗분 요청이 바뀔 때마다 방향이 통째로 달라짐
```
⚠️ **이건 이미지를 잘 만들어서 해결되는 문제가 아님.** 1권 1-5에서 말한 **하네스가 없는 문제**임. 자료·지침·양식·검토 기준이 없어서 매번 처음부터 시작하는 것.
> **오늘 만드는 것은 인테리어 이미지 한 장이 아니라, 다음번 매장에도 그대로 쓸 양식임.**
### 7-2. 제안서 표준안 구성
```plain text
[1] 프로젝트 개요
    매장명 / 위치 / 평수 / 오픈 예정일 / 예산 등급
    브랜드 (돌담 / 호프 / …)

[2] 컨셉 키워드 3개
    형용사 3개로 방향을 못 박음
    예: 정갈한 / 따뜻한 / 제주다운
    ⚠️ 이 3개가 이후 모든 판단의 기준이 됨

[3] 무드보드 (레퍼런스 6~9장)
    외관·파사드 / 홀 / 조명 / 마감재 / 사이니지
    각 이미지 아래에 "이 이미지에서 가져올 요소" 한 줄

[4] 레퍼런스 분석 (AI로 자동 생성)
    각 레퍼런스의 재질·색상·조명을 언어로 정리
    → 2권 2-3 '역방향 프롬프트 추출' 활용

[5] 방향 A·B·C 시안
    A = 보수적 / B = 현대적 / C = 도전적
    각 안마다 렌더링 이미지 1장 + 설득 포인트 1줄

[6] 확정 사양
    바닥 / 벽 / 천장 / 조명 / 사이니지 / 가구
    ⚠️ 미확정 항목은 "확인 필요"로 명시

[7] 사이니지 (간판) 계획
    위치 / 크기 / 서체 / 조명 방식
    ⚠️ 간판 글자는 AI로 그리지 않음. 렌더링에는 빈 패널로 두고
       실제 글자는 벡터로 별도 작업

[8] 결정 기록
    누가 / 언제 / 무엇을 확정했는가
    ⚠️ 이 칸이 "윗분 요청 때마다 딴판" 문제를 막음
```
### 7-3. AI가 도와주는 지점
**① 레퍼런스 분석 — 그림을 언어로**
```plain text
[레퍼런스 이미지 첨부 후]

이 인테리어 이미지를 전문적으로 분석해줘:
① 전체 컨셉 (한 문장)
② 주요 마감재 3가지 (한글 + 영문 표기)
③ 색상 팔레트 (HEX 코드 + 사용 위치)
④ 조명 분석 (색온도 추정 K, 방향, 직·간접)
⑤ 공간 분위기 키워드 5개
⑥ 이 스타일을 재현할 이미지 생성 프롬프트

⚠️ 추정한 항목은 [추정]으로 표시하고, 지어내지 말 것.
```
💡 이렇게 뽑아낸 것이 **\[4\] 레퍼런스 분석 칸**을 그대로 채움. 그리고 이게 있어야 다른 사람도 같은 방향으로 만들 수 있음.
**② 스케치·도면 → 3D 시각화**
```plain text
[손 스케치 또는 평면도 사진 첨부]

이 스케치를 분석하고 3D 공간으로 시각화해줘.

분석:
① 공간 유형과 추정 규모
② 동선 (입구 → 핵심존 → 출구)
③ 스케치에서 강조된 요소 3가지
④ 스케치에 없지만 결정이 필요한 요소

시각화:
- 재질: 【원하는 재질 — 비워두면 AI가 제안】
- 조명: 【색온도 K】
- 구도: 입구에서 바라보는 눈높이 와이드샷

금지:
- 간판·사이니지에 글자를 넣지 말 것 (빈 패널로 둘 것)
- 실존 브랜드 로고를 그리지 말 것
```
**③ 방향 A·B·C 시안**
```plain text
같은 스케치·컨셉으로 3가지 방향을 만들어줘.
  A안 (보수적): 기존 브랜드 표준에 충실
  B안 (현대적): 현재 트렌드 반영, 균형
  C안 (도전적): 대담한 해석

각 안마다:
- 대표 이미지 1장
- 마감재·조명 핵심 요소 3가지
- 설득 포인트 1줄
```
⚠️ **A·B·C를 먼저 보여주고 방향을 확정한 뒤 정교화함.** 하나만 만들어 가면 "이거 말고 다른 건 없어?"가 나옴. 1권 1-4의 발산·수렴 원칙임.
### 7-4. ⚠️ 인테리어 렌더링의 한계
정직하게 짚음.





AI로 되는 것

AI로 안 되는 것




방향·무드 시각화 (시안)

실제 시공 도면




마감재·조명 대안 비교

정확한 치수




레퍼런스를 언어로 정리

구조·안전 검토




클라이언트·임원 설득용 이미지

간판 글자 (반드시 벡터로)


> **AI 렌더링은 "방향을 합의하기 위한 그림"이지 "시공 도면"이 아님.**<br>이 선을 넘으면 현장에서 사고가 남.
### 7-5. 오늘의 목표
⚠️ **오늘 매장 하나를 완성하는 것이 아님.** **양식 1개를 만드는 것**임.
```plain text
[1] 위 8개 항목이 들어간 문서 양식을 만듦 (노션 또는 구글 문서)
[2] 한 매장을 예시로 [1]~[4]까지만 실제로 채워봄
[3] 다음 매장부터는 이 양식으로 시작함
```
**성공 기준:** 다른 사람에게 이 양식을 넘겨줘도 같은 방식으로 정리할 수 있음.

## 8. 최종 검수 — 트랙 공통
```plain text
[내용]
□ 메뉴명·가격·날짜에 오타가 없는가  ← 사람이 직접 확인. AI 믿지 말 것
□ 실제 사실과 일치하는가
□ 과장 표현이 없는가

[이미지·영상]
□ 워터마크가 없는가
□ AI가 그린 글자가 남아 있지 않은가
□ 로고가 원본 파일인가
□ 확대해서 손·젓가락·배경을 확인했는가

[규격]
□ 게시처 규격에 맞는가
□ 인쇄용이라면 해상도가 충분한가

[자산]
□ 템플릿·양식으로 저장했는가
□ 아카이브에 프롬프트와 함께 저장했는가
```

## 9. 체크 — 3권을 마치며
✅ 문구를 먼저 확정하고 그 길이에 맞춰 이미지 여백을 설계했음
✅ Gem이 \[추정\]으로 채운 정보를 실제와 대조했음
✅ 트랙 결과물 1건을 완성했음
✅ 텍스트를 각각 별도 레이어로 만들었음
✅ 로고는 AI가 아니라 원본 파일에서 얹었음
✅ 할루시네이션 검수를 확대해서 했음
✅ 다음번에 재사용할 **템플릿 또는 양식**으로 저장했음
✅ 4권에서 공유할 준비가 됐음 (무엇을, 어떻게, 어디서 막혔는지)

**4권 예고 — 공유와 자동화**
각자 만든 결과물을 서로 보여줌. 같은 도구로 서로 다른 것을 만들었으므로, **다른 트랙의 방법이 내 업무에 바로 쓰이는 경우가 많음.**<br>그리고 오늘 만든 것을 **어떻게 자동화할지** 각자 설계함. 4·5회차에서 배운 GAS와 Make.com이 여기서 다시 등장함.
