# [실습] 예산·원가 업무용 GPTs 구조 설계하기

정리일: 2026-10-08 · 교육 에셋 N0293

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
ChatGPT에서 예산·원가 업무용 GPTs를 직접 만듭니다. (오늘은 1단계 Instructions 실습, 2\~3단계는 개념 이해)
## 진행 단계
1. **만들기 진입** — ChatGPT 좌측 메뉴의 \[GPT 탐색\] → \[만들기\] 클릭
2. **Step 1. 이름과 설명 입력**
- 입력할 내용: 이름 `교육기관 비용·집행 보고 도우미` / 설명 `월간 비용·집행 보고서 작성 및 공종별 원가 초과 원인 분석을 도와주는 AI`
3. **Step 2. Instructions 입력**
```markdown
## 역할
당신은 교육기관 아파트 신축 프로젝트의 원가관리 담당자입니다.

## 행동 규칙
1. 모든 답변은 입력된 데이터와 사용자가 제공한 조건만 근거로 작성하세요.
2. 보고서는 다음 구조로 작성하세요:
   - 보고서 헤더(기준월, 대상, 작성자)
   - 공종별 예산 대비 집행 현황
   - 주요 차이 원인 (표: 번호/공종/차이/원인)
   - 액션아이템 (표: 번호/할 일/담당자/기한)
3. 수치가 부족하면 추정하지 말고 "추가 확인 필요"로 표시하세요.
4. 전문용어는 괄호 안에 쉬운 설명을 넣어주세요.
5. 표, 체크리스트 형태를 적극 활용하세요.
```
1. **Step 3. Conversation Starters 설정** — "이번 달 예산 집행 현황을 정리해줘", "공종별 원가 초과 원인 분석해줘", "월간 현금흐름 주의 항목 정리해줘", "추가 예산 승인 품의서 작성해줘"
2. **Step 4. 저장 후 테스트**
- 정상 결과: 유도 질문 중 하나를 클릭해 결과 확인. 매번 역할/맥락을 입력하지 않아도 일관된 결과가 나오는지 확인
