## 이게 무슨 말이냐면

우리가 ChatGPT를 쓸 때, 사실은 "AI 모델"이라는 두뇌한테 부탁을 하는 거예요. 그런 두뇌가 ChatGPT 말고도 세상에 엄청 많습니다. MiniMax, DeepSeek, GLM, Kimi 같은 애들이요.
원래 이 두뇌들은 쓸 때마다 돈을 냅니다. 그런데 엔비디아가 100가지 이상을 자기네 서버에 올려두고 무료로 열어버렸어요. 신용카드도 안 받습니다.
쉽게 말하면, 평소 유료로 빌려야 했던 고급 AI들을 한곳에 모아두고 "일단 공짜로 써보세요\~" 하고 문 열어둔 도서관 같은 거예요.

**추천 모델: MiniMax M3(클로드 오퍼스보다 약간 아래급), DeepSeek V4, GLM 5.1**

글로 설명하면 그림을 그려주고, 사진 편집도 돼요. 한글 글자가 들어간 이미지도 또렷하게 만들어 줍니다.
**추천 모델: Qwen-Image (그리기), Qwen-Image-Edit (편집)**

**추천 모델: Chatterbox TTS**
### 영상 만들기
글이나 사진 한 장만 넣으면 영상으로 바꿔줘요. 움직임도 꽤 자연스럽습니다.
**추천 모델: Cosmos3 Nano**

## 방법 2. API 코드 연동해서 나만의 AI 앱 만들기(이게 진짜에요.. 방법1보다 10배 활용성↑)
"매번 사이트 들어가지 말고, 내 전용 도구로 자동으로 돌리고 싶다" 싶을 때예요. 핵심은 이거예요. **코드를 내가 짜는 게 아니라, 클로드나 GPT한테 "만들어줘" 하고 시키는 거예요.** 요즘은 이걸 바이브 코딩이라고 불러요.
### 1단계. API 키(열쇠) 발급받기
방법 1처럼 build.nvidia.com 들어가서 모델 페이지를 연 다음, 이번엔 **"Get API Key"** 버튼을 누릅니다. `nvapi-` 로 시작하는 긴 문자열이 나오면 복사해서 메모장에 보관해요. 이게 내 전용 열쇠예요.
> 주의: 이 열쇠는 비밀번호 같은 거예요. 아무 데나 공개로 올리거나 모르는 사이트에 붙여넣지 마세요.
### 2단계. 클로드(claude.ai)나 ChatGPT 켜기
둘 중 아무거나 써도 돼요. 클로드는 만든 결과물을 화면에서 바로 실행해서 보여주는 기능(아티팩트)이 있어서 초보자한테 특히 편해요.
### 3단계. 아래 주문서를 그대로 붙여넣기
대괄호 \[ \] 부분만 내가 원하는 걸로 바꿔서 통째로 복사해 넣으세요.
```plain text
나는 코딩을 잘 모르는 초보자야. NVIDIA의 무료 AI API를 써서
[간단한 웹 도구]를 만들고 싶어.

연결 정보는 이거야 (OpenAI 호환이야):
- base_url: [개별 링크 제외]
- model: minimaxai/minimax-m3
- API 키는 내가 직접 넣을 거니까 코드에 'YOUR_API_KEY' 자리만 비워둬

요구사항:
1) 완성된 코드를 하나로 만들어줘
2) 코딩 모르는 사람이 따라 할 수 있게, 어디에 붙여넣고 어떻게 실행하는지 1번부터 알려줘
3) 내 API 키를 어디에 넣어야 하는지 정확히 짚어줘
```
### 4단계. 시키는 대로 실행하고, 열쇠 넣기
클로드/GPT가 코드랑 실행법을 쭉 설명해줄 거예요. 'YOUR_API_KEY' 라고 적힌 자리에 1단계에서 받은 `nvapi-...` 열쇠를 넣으면 내 전용 도구가 굴러갑니다. 막히면 그 화면에 "여기서 에러 나" 하고 그대로 물어보면 고쳐줘요.
> 팁: 만들고 싶은 걸 \[ \] 안에만 바꾸면 뭐든 돼요. "유튜브 자막 요약기", "상품 설명 영어 번역기", "사진 캡션 만들어주는 도구"처럼요.
