# 실습 2 | 내 브랜드 GEMS 직접 만들기

정리일: 2026-10-08 · 교육 에셋 N1489

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지금 이 자리에서 나만의 GEMS 1개를 완성하고 실제로 테스트합니다.
## 진행 단계
1. **만들 GEMS 선택 (2분)** — 나에게 가장 필요한 GEMS를 1개 고릅니다.
- 입력할 내용: GEMS 1(인스타 본문 작가) / 2(릴스 대본 전략가) / 3(카드뉴스 기획자) / 4(고객 상담 비서) / 7(월간 콘텐츠 플래너) 중 체크박스로 선택, "오늘 선택한 GEMS: ___"
2. **내 정보 입력 (5분)** — 브랜드명, 원장 이름, 인스타 계정, 팔로워 수, 타겟 고객 피부 고민, 주력 제품 3가지, 브랜드 컨셉 한 줄, 절대 쓰면 안 되는 표현을 빈칸에 채웁니다.
3. **시스템 프롬프트 완성 (8분)** — ① '공통 기본 설정' 복사 ② 【 】 부분을 내 정보로 교체 ③ 1권 부록 '제품 데이터베이스' 붙여넣기 ④ 내가 잘 쓴 게시물 3편 붙여넣기 ⑤ 선택한 GEMS의 '추가할 내용' 이어서 붙여넣기
- 정상 결과: 완성 체크(공통 기본 설정 완성 / 제품 DB 붙여넣기 / 게시물 3편 붙여넣기 / GEMS 추가 내용 붙여넣기) 모두 완료
4. **실제 테스트 (5분)** — 선택한 GEMS로 테스트 문장을 입력합니다.
- 입력할 내용: GEMS 1 "지금 이 계절에 어울리는 제품 1개로 본문 1편 써줘" / GEMS 2 "내 주력 제품으로 릴스 대본 1편 써줘" / GEMS 7 "이번 주 콘텐츠 5개 소재 뽑아줘"
- 정상 결과: "이거 내 문체 맞다!" 반응 경험, ChatGPT / Claude / Gemini에 GEMS 세팅 완료
