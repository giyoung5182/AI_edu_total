# [실습 1] 비용 초과 항목 자동 색상 표시

정리일: 2026-10-08 · 교육 에셋 N1134

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
B열이 "초과"인 행을 자동으로 빨간색으로 표시하는 VBA 매크로를 ChatGPT로 만들어 실행합니다.
## 진행 단계
1. **실습 파일 열기** — 「예산집행현황_색상표시.xlsx」를 엽니다(공종별 15건의 정상/주의/초과 데이터 입력됨).
2. **ChatGPT에 프롬프트 입력**
- 입력할 내용:
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
B열에 "초과"라고 적힌 셀과 같은 행 전체를 빨간색 배경으로 자동 표시하는 VBA 매크로를 만들어줘.

## 조건
- 데이터는 A1부터 시작 (1행은 헤더)
- B열에 "초과"가 있으면 해당 행 전체(A~B열)를 빨간색 배경 + 흰색 글자로 변경
- B열에 "정상"이 있으면 해당 행을 초록색 배경으로 변경
- B열에 "주의"가 있으면 해당 행을 노란색 배경으로 변경
- 코드에 한글 주석 포함

## 출력
VBA 코드만 출력해줘. 설명은 코드 내 주석으로.
```
3. **코드 복사** — ChatGPT가 생성한 코드를 복사합니다.
4. **모듈에 붙여넣기** — 엑셀에서 Alt+F11로 VBA 편집기(VBE)를 열고 \[삽입\] → \[모듈\]을 눌러 나온 흰 코드 창에 붙여넣습니다.
5. **실행** — Alt+F8 → "집행현황_색상표시" 선택 → 실행
- 정상 결과: "초과" 행은 빨간색, "정상" 행은 초록색, "주의" 행은 노란색으로 자동 표시됨
## 막히는 지점
- "매크로가 비활성화되었습니다": 파일 → 옵션 → 보안 센터 → 매크로 설정 → "모든 매크로 포함" 선택
- 코드 실행 시 오류: 오류 메시지를 ChatGPT에 붙여넣어 해결 요청
- 파일 저장 시 매크로가 사라짐: 형식을 "Excel 매크로 사용 통합 문서 (.xlsm)"로 저장
- Alt+F11이 안 열림: 파일 → 옵션 → 리본 사용자 지정 → "개발 도구" 체크 → 개발 도구 탭에서 Visual Basic 클릭
