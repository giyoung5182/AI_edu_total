# Step 04 :: 장표는 설계도를 먼저 만듭니다

정리일: 2026-10-08 · 교육 에셋 N1123

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
발표 장표를 만들기 전에 설계도(대상·메시지·근거·금지)를 먼저 잡아 봅니다.
## 진행 단계
1. **설계도 네 칸 이해** — 대상(누가 보나) / 메시지(한 장에 한 문장) / 근거(그 문장을 받치는 것) / 금지(넣으면 안 되는 것)
2. **설계도 요청**
- 입력할 내용:
```javascript
3-7_주간리포트.docx 내용으로 보고용 장표를 만들 건데, 설계도를 먼저 잡아줘.

- 대상 : 광고주 실무 담당, 5분 안에 훑어보는 사람
- 장당 메시지 : 한 장에 한 문장만
- 근거 : 정제데이터에 있는 것만 쓰고, 없는 건 '확인 필요'로 둬
- 금지 : 실명과 계약 금액은 넣지 마

장 수와 각 장의 제목, 그 장에 들어갈 것만 먼저 목록으로 보여줘.
아직 만들지는 마.
```
1. **목록 확인·수정** — 순서나 장 수를 고친 뒤 만들게 함
## 막히는 지점
- 「아직 만들지 마」가 중요함
