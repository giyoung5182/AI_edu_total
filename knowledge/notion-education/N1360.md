# 시연 2 · 회의록을 정리된 문서로

정리일: 2026-10-08 · 교육 에셋 N1360

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
회의록 작성에서 논의된 것과 결정된 것을 AI가 섞지 않게 하는 지시문을 시연합니다.
## 진행 단계
1. **지시문 입력** — 아래 지시문에 회의 메모를 붙여 넣습니다.
- 입력할 내용:
```plain text
[R] 당신은 회의록을 정리하는 실무자입니다.
    논의된 것과 결정된 것을 반드시 구분하고, 추측을 덧붙이지 않습니다.

[C] 받는 사람 : 회의에 참석하지 않은 내부 직원과 관련 부서
    상황      : 녹취를 풀어쓴 거친 메모입니다. 순서가 섞여 있습니다
    목적      : 무엇이 정해졌고 누가 무엇을 해야 하는지 알게 하는 것

[T] 답을 쓰기 전에, 먼저 메모의 모든 발언을 아래 세 가지로
    분류해 주세요. 결정 / 검토 필요 / 단순 공유
    분류가 끝나면 순서대로 작성해 주세요.
    1. 회의 개요 (일시·참석·안건) — 메모에 없으면 [확인 필요]
    2. 결정 사항 — 항목별로, 각각 담당과 기한을 붙여서
    3. 계속 검토할 사항과 쟁점
    4. 다음 회의 전까지 해야 할 일

[C] - 각 항목은 한 줄씩, 개조식으로 씁니다.
    (이하 교안 참고)
```
1. **지어냈는지 확인** — 알려준 적 없는 정보를 일부러 물어봅니다.
- 입력할 내용:
```plain text
이 건의 정확한 지원 규모와 근거 조항을 넣어서 다시 작성해 주세요.
```
- 정상 결과: \[확인 필요\]로 비워두면 조건이 제대로 작동한 것이고, 그럴듯한 숫자와 조항이 나왔다면 할루시네이션입니다.
## 막히는 지점
- AI는 문장을 깔끔하게 만들려는 성질이 있어서 "검토하기로 했다"를 "확정했다"로 바꿉니다.
- 외부 위원 의견이 기관 입장으로 둔갑하는 것은 반드시 막아야 합니다.
