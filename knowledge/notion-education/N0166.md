# 오늘의 활동 안내 — 스스로 따라가는 SW 수업
## 무엇을
학생이 **QR을 찍어 접속하면 오늘 할 일이 순서대로 보인다.**<br>한 단계를 마칠 때마다 직접 체크하고, 다 하면 완료 화면이 나온다.
교사가 칠판에 적거나 반복해서 말하던 것을 학생이 스스로 따라간다.
## 왜
같은 안내를 수업 중에 **네다섯 번 반복**하게 된다.<br>"지금 뭐 하는 거예요?" "몇 번까지 했어요?"가 계속 나온다.
학생이 자기 화면에서 확인하면 그 질문이 줄고,<br>**빨리 끝낸 학생이 다음으로 넘어갈 수 있어** 수업 흐름이 끊기지 않는다.
> 💡 **단순 안내만이면 종이가 낫습니다.**<br>이 도구가 값어치를 갖는 지점은 **학생이 직접 체크하며 진행한다**는 것과<br>**여러 차시를 한 곳에서 볼 수 있다**는 것입니다.
## 사용자
- 초등 3\~4학년
- SW 수업 전 차시 공통 (차시마다 내용만 교체)
- 수업 시작할 때 QR로 접속, 활동 내내 열어둠
- 개인 태블릿 또는 모둠 한 대
## 화면 구성
```plain text
1. 맨 위 — 오늘 날짜와 차시
          "3차시 · 반복 찾기"

2. 그 아래 — 오늘의 목표 한 줄
            "반복되는 규칙을 찾을 수 있어요"

3. 준비물 — 네모 체크칸이 있는 목록
           □ 학습지   □ 색연필   □ 패턴 카드

4. 활동 순서 — 번호가 붙은 카드 4개
   각 카드에
     · 큰 동그라미 번호
     · 무엇을 하는지 한 줄
     · '다 했어요' 체크 버튼

   체크하면 카드가 연하게 바뀌고 다음 카드가 강조된다

5. 진행 상황 — 화면 위쪽에 "2 / 4 완료" 표시

6. 다 하면 — "오늘 활동 끝!" 화면
            "다음 시간에는 무엇을 할까요?" 미리보기 한 줄

7. 맨 아래 — '지난 차시 보기' 버튼
            누르면 1·2차시 내용도 볼 수 있다
```
## 완료 조건
- QR이나 주소로 접속하면 바로 오늘 내용이 보인다
- 준비물을 하나씩 체크할 수 있다
- 활동 카드를 순서대로 체크하며 진행할 수 있다
- 위쪽에 몇 개 했는지 숫자로 보인다
- 다 하면 완료 화면이 나온다
- 지난 차시 내용도 볼 수 있다
- 휴대폰 세로 화면에서 한 손으로 볼 수 있다
## 오늘 넣지 않는 것
- 학생별 체크 기록 저장 (새로고침하면 초기화되어도 됨)
- 교사가 학생 진행 상황을 보는 기능
- 로그인
- 학생 이름 입력
> 💡 저장이 안 되어도 수업 중에는 문제가 없습니다.<br>한 시간 동안 화면을 열어두고 쓰는 용도이기 때문입니다.
## 애매한 것
- 차시를 몇 개까지 넣을지 (일단 3차시분)
- 지난 차시를 같은 화면에서 볼지, 눌러서 이동할지 (눌러서 이동)
- 완료했을 때 축하 효과를 넣을지 (시간 남으면)

### 내 수업 자료를 읽히고 싶으시면
**이 유형의 진짜 장점은 여기입니다.**
수업 지도안이나 계획 파일이 있으시면, 폴더에 같이 넣고 이렇게 말하세요.
```plain text
class-tool 폴더에 있는 수업계획.xlsx 를 읽고,
차시별 활동 순서와 준비물을 prd.md에 채워줘.
```
**손으로 옮겨 적을 필요가 없습니다.** 이게 기초과정과 가장 크게 다른 점입니다.
### 다른 형태로 바꾸고 싶으시면

```plain text
· 모둠 진행 상황판 — 모둠별로 어디까지 했는지
· 스스로 점검표 — 학습 목표 도달 여부를 학생이 체크
· 학생 작품 모아보기 — 사진과 설명을 모아서 전시
· 준비물 안내 (가정용) — 다음 차시 준비물을 학부모도 확인
```
