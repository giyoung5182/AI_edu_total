# 4. 프롬프팅 실습 — 나만의 완벽한 여행 계획 만들기

정리일: 2026-10-08 · 교육 에셋 N0378

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
구조화 프롬프트 4요소와 반복 피드백을 직접 체험하며 나만의 여행 계획을 만듭니다.
## 진행 단계
1. **템플릿 입력** — \[ \] 안을 본인 상황에 맞게 바꿔 AI에 입력
- 입력할 내용:
```javascript
# Role
당신은 제주도에서 10년간 거주하며 로컬 맛집과 숨은 명소를 전문으로
소개하는 여행 크리에이터입니다.

# Instruction
[본인이 원하는 여행 스타일]에 맞는 제주도 2박 3일 여행 일정을
짜 주세요.

# Context
- 여행 인원: [예: 회사 동료 4명]
- 여행 시기: [예: 5월 초]
- 예산: [예: 1인당 50만 원]
- 숙소: [예: 감성 있는 독채 펜션 선호]
- 취향: [예: 관광지보다 현지인이 가는 맛집, 조용한 카페, 자연 경관 선호]
- 이동 수단: [예: 렌터카]
- 제외: [예: 이미 가본 곳 - 성산일출봉, 협재해수욕장]

# Output Format
- 일정표 형식 (일자별 → 시간대별)
- 각 장소마다: 장소명 / 추천 이유 한 줄 / 예상 소요 시간 / 예상 비용
- 하루 마무리에 "오늘의 포인트" 한 줄 요약
- 맨 마지막에 전체 예상 비용 합계
```
1. **피드백으로 다듬기** — 예: 첫째 날 일정에 점심 후 1시간 여유 넣기 / 맛집 추천 이유 자세히 / 우천 시 대체 일정 추가 / 동료 공유용 표(시간·장소·활동·비용)로 정리
2. **역할만 바꿔 보기** — Role 변형 1(미식 칼럼니스트), 2(어드벤처 여행 가이드), 3(SNS 여행 인플루언서)로 바꿔 결과를 비교
