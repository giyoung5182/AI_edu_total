# (향후 과제) Gamma 전환과 보존표 대조

정리일: 2026-10-08 · 교육 에셋 N0317

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 5 설계서를 Gamma로 6장 발표자료로 만들고, 생성 전에 작성한 보존표와 한 줄씩 대조해 모두 일치(O)하는지 확인합니다.
## 진행 단계
1. **예측** — \[G\] 예측 칸: 보존표 항목 중 가장 먼저 사라질 것(n·분모 / 단위 / \[확인 필요\] / 판정 상태)
2. **보존표 먼저 작성** — \[B\] 근거표의 수치·n·분모·기간·단위·출처·상태를 \[G\]에 복사, 보고서·설계서 칸은 슬라이드 생성 전에 채움
3. **슬라이드용 텍스트 준비** — 채팅 P4-보고서에 "설계서 블록 2를 Gamma에 붙여넣을 슬라이드 텍스트로 바꿔 줘" 요청(장 사이 `---` 구분, 새 수치 추가 금지) → 복사
4. **Gamma에서 생성** — 브라우저 새 탭(Ctrl+T) → gamma.app 로그인 → 텍스트 붙여넣기
5. **보존표 대조** — 슬라이드를 보존표와 한 줄씩 대조
- 정상 결과: \[G\] 표 사용한 근거ID 행의 일치(O/X) 칸 모두 O + G 메모 2행(생성 전후 잔여 크레딧 · 사용한 입력 경로) 기록
## 막히는 지점
- Gamma 무료 크레딧(가입 시 400, 재충전 없음) → 재생성을 반복하지 말고 편집 화면에서 직접 수정
- 1회 생성 최대 10장
