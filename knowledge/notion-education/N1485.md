# 08. 공통 실습 / 배포 — 엑셀 장표 대시보드 웹앱 만들기

정리일: 2026-10-08 · 교육 에셋 N1485

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
엑셀 파일을 업로드하면 웹 화면에서 표와 차트로 보여 주는 작은 웹앱을 Claude Code로 만들고, GitHub 저장과 Vercel 배포까지 진행합니다.
## 진행 단계
1. **화면 구성 정리** — 상단 제목, 엑셀 업로드 영역, 핵심 지표 카드, 차트 영역, 데이터 표(검색/필터)를 먼저 정리합니다.
2. **Claude Code에게 요청** — React + Vite, xlsx 라이브러리, recharts, 백엔드·DB 없이 브라우저에서 직접 읽도록 요청합니다.
- 입력할 내용: 교안의 프롬프트 예시 (엑셀 업로드 → 표·핵심 지표 카드·지역별 매출/분기별 매출 추이/법인별 영업이익 차트·검색 또는 필터, run.bat 실행파일, design.md 참고)
3. **오류 수정 요청** — 오류가 나면 "npm run dev 실행 중 아래 오류가 발생했습니다. \[오류 메시지 붙여넣기\] 오류 원인을 확인하고 수정해주세요."로 요청합니다.
4. **결과물 다듬기** — 제목·설명, 지표 카드 배치, 2열 차트 카드, 넓은 표, 연한 배경, 버튼·카드 정리를 요청합니다.
5. **GitHub에 저장** — "여태까지의 진행사항을 github에 day1-excel-webapp이라는 이름으로 저장해줘"
6. **Vercel에 배포** — "여태까지의 진행사항을 vercel에 배포해줘" (수동: Vercel 접속 → GitHub 저장소 선택 → 설정 확인 → Deploy → 링크 확인)
7. **최종 체크리스트 확인** — 업로드, 표, 지표 카드, 차트, 화면 정리, GitHub 저장, 배포 링크 생성·정상 표시
8. **Padlet 공유** — 이름과 Vercel 배포 링크를 공유
## 막히는 지점
- npm run dev 실행 중 오류: 오류 메시지를 붙여 넣어 수정 요청
