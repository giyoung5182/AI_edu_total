# 방법 하나 · 기존 게시물을 첨부해 캐릭터 톤 이어받기

정리일: 2026-10-08 · 교육 에셋 N0649

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
기존 게시물 캡처를 첨부해 캐릭터 생김새·색상·선 굵기·배경 처리를 그대로 유지하고 자세만 바꾸는 이미지를 만듭니다("지금 바로 해보실 수 있어요").
## 진행 단계
1. **캡처 첨부** — 센터 인스타 게시물 캡처를 첨부합니다.
2. **프롬프트 입력**
- 입력할 내용:
```plain text
[센터 인스타 게시물 캡처를 첨부한 뒤]

첨부한 이미지의 캐릭터 생김새, 색상, 선 굵기, 배경 처리 방식을
그대로 유지해 줘.
캐릭터의 자세만 [작은 깃발을 들고 팔을 위로 올린 모습]으로 바꾸고,
나머지는 첨부 이미지와 동일하게 만들어 줘.
위쪽 3분의 1과 아래쪽 3분의 1은 단색 여백으로 비워 줘.
```
1. **결과 확인** — 캡처에서 말로 설명하기 어려운 특징까지 따라오는지 확인
## 막히는 지점
- 캡처는 화질이 낮아 결과가 뭉개질 수 있음 — 중요한 게시물은 담당자에게 원본을 받을 것
- 다른 기관이나 남의 이미지를 첨부해 따라 만드는 것은 조심
