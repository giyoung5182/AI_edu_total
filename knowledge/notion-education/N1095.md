# [실습] 품질정책문서 + 맥락 더하기 1 : 올바른 틀과 예시 제공하기

정리일: 2026-10-08 · 교육 에셋 N1095

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
품질 정책 문서의 틀과 예시를 맥락으로 제공해 프롬프트를 개선합니다.
## 진행 단계
1. **좋은 예시와 나쁜 예시 확인** — 좋은 예시는 역할, 데이터셋 설명, 포함할 항목, SQL 점검 조건, 확인 필요 표시, 출력 형식을 명시합니다. 나쁜 예시(`이 데이터셋 보고 품질정책문서 써줘. 좋게 써줘. 전문적으로 써줘.`)는 역할·데이터셋·항목·검증 조건이 불명확합니다.
2. **틀과 예시를 맥락으로 제공** — 데이터 품질정책 문서의 구성 요소 표(목적, 적용 범위, 품질 원칙, 품질 기준, 역할과 책임, 점검 주기, 위반 처리, 문서 관리)를 맥락으로 넣어 프롬프트를 개선합니다. 맥락 문서를 별도 파일로 업로드해도 되고, 프롬프트 맨 마지막에 덧붙여도 됩니다.
3. **공유** — 최종 프롬프트를 2주차 패들릿에 공유합니다.
## 막히는 지점
- 나쁜 예시의 문제: 어떤 역할의 관점인지 불명확, 데이터셋 설명 부족, 포함 항목 기준 없음, SQL 점검 가능 여부 검증 조건 없음, 모르는 내용을 단정해도 막을 장치 없음, 결과물 형식이 구체적이지 않음.
