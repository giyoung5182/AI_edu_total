# 트랙 3. 함정 질문 챌린지

정리일: 2026-10-08 · 교육 에셋 N0672

---

## 이 실습으로 하는 것
출제된 문제 5문항을 풀도록 내 문서 검색·답변 시스템을 개선한다. 목표는 5문항 중 4문항 이상에서 답 정합과 근거 정합을 동시에 만족시키는 것이다.
## 진행 단계
1. **문서 교체 적재** — PDF를 docs 폴더에 넣고 기존 적재를 비운 뒤 적재, 청크 수가 0이 아닌지 확인, 가벼운 질문으로 근거 청크가 달린 답이 오는지 확인.
2. **기준선** — 지식 기반 답변 모드를 켜고 5문항을 문구 그대로 입력. 통과/실패와 실패 증상(A 찾기, B 조각, C 지시)을 기록. 근거 청크를 펼쳐서 판정.
3. **예측** — 실패 문항마다 처방 하나를 고르고 어느 문항이 살아날지 예측해 적는다.
4. **처방은 한 번에 하나** — 청킹·파싱을 건드렸으면 재적재까지.
5. **재측정** — 실패했던 문항만 다시 입력해 예측과 비교. 통과였던 문항이 무너지지 않았는지도 확인.
6. **마감** — 4문항에 도달하면 전체를 한 번 더 돌려 최종 점수 확정, 최종 점수와 가장 효과가 컸던 처방 한 줄을 남긴다.
## 막히는 지점
- 반칙: 질문 문구 바꾸기, 정답 심기, 문항 전용 분기 만들기
- 증상이 겹치면 A → B → C 순서로 처방
- 검색 결과가 비어 있으면 적재 현황 확인 후 재적재
