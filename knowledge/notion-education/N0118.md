> **관광·콘텐츠 기획 전공 특별 제공 — 수료 후 영구 사용 가능, 단 외부 유출 절대 금함.**<br>이 교재는 수업에서 배운 R.C.T.C, BMAD Method, 에이전트 디자인 5기법을 실제로 구현한 실무형 에이전트 팀 5개를 담고 있습니다.<br>각 시스템 프롬프트를 **Gemini Gems** (무료) 설정창에 복사-붙여넣기하면 즉시 사용 가능합니다. ChatGPT GPTs 제작은 유료 플랜(Plus 이상)이 필요합니다.

## 📌 이 교재 활용 가이드
### 시스템 프롬프트 = 나만의 전담 전문가 팀
수업에서 배웠듯, 시스템 프롬프트는 AI에게 "넌 이런 전문가야, 이렇게 일해"를 미리 설정해두는 **마스터 지침서**입니다. 이 교재의 모든 팩은 단일 AI가 아니라 **BMAD Method 구조**를 적용한 에이전트 팀으로 설계되었습니다.
```plain text
일반 채팅창  =  매번 검색창에 긴 설명 반복
시스템 프롬프트  =  전담 전문가 팀 상시 대기 → 버튼 하나로 호출
```
### 에이전트 팀 구조 (BMAD Method 기반)
```plain text
[오케스트레이터] — 전체 팀 조율 + 작업 분배 + 품질 관리
      │
      ├── [전문가 A] — 고유 페르소나 + 전담 업무 + 출력물 형식
      ├── [전문가 B] — 고유 페르소나 + 전담 업무 + 출력물 형식
      ├── [전문가 C] — 고유 페르소나 + 전담 업무 + 출력물 형식
      ├── [전문가 D] — 고유 페르소나 + 전담 업무 + 출력물 형식
      └── [전문가 E] — 고유 페르소나 + 전담 업무 + 출력물 형식
```
각 에이전트는 수업에서 배운 **R.C.T.C 구조**로 설계되어 있으며, 명령어(`*` prefix), Advanced Elicitation, 품질 체크리스트까지 포함합니다.
### Gemini Gems 설정 방법
1. gemini.google.com 접속 → 구글 계정 로그인
2. 좌측 사이드바 → **'Gems'** 클릭
3. **'+ 새 Gem 만들기'** 버튼 클릭
4. 이름 입력 (예: "여행 콘텐츠 기획팀")
5. **'요청사항(Instructions)'** 입력란에 해당 팩 프롬프트 **전체 복사-붙여넣기**
6. 저장 → 완료!
> **팁:** 각 팩마다 별도의 Gem을 만드세요. 하나의 Gem에 여러 팩을 넣으면 성능이 저하됩니다.
### ChatGPT에서 시스템 프롬프트 활용하는 법
> ⚠️ **GPTs 직접 제작은 유료 플랜(Plus · Team · Enterprise)에서만 가능합니다.**<br>무료 계정은 아래 두 가지 방법으로 활용하세요.
**\[무료\] 방법 1 — 대화창에 직접 붙여넣기**
1. chatgpt.com 접속 → 새 대화 시작
2. 프롬프트 팩 전체를 첫 메시지로 붙여넣기
3. 이후 대화에서 바로 에이전트로 작동
> 단, 새 대화를 시작할 때마다 다시 붙여넣어야 합니다.
**\[무료\] 방법 2 — 남이 만든 GPTs 활용**
1. 좌측 사이드바 **'GPT 탐색(Explore GPTs)'** 클릭
2. 'Prompt Generator', 'System Prompt Creator' 등 검색
3. 해당 GPTs에 접속 → 원하는 에이전트 설계 요청
**\[유료 Plus 이상\] 방법 3 — 나만의 GPTs 직접 제작**
1. 좌측 **'탐색하기'** → **'GPT 만들기'** 클릭
2. **'구성(Configure)'** 탭 → **'지침(Instructions)'** 란에 프롬프트 붙여넣기
3. 저장하면 언제든 호출 가능한 전용 에이전트 완성
> 💡 **강사 추천:** 이 교재의 시스템 프롬프트는 **Gemini Gems**(무료)에 넣어 쓰는 것을 기본으로 합니다. GPTs 유료 구독자라면 동일하게 활용 가능합니다.

## 🔑 핵심 개념 복습 — 이 교재 전체에 적용되는 설계 원칙
### R.C.T.C 공식 (수업 핵심)





요소

의미

이 교재에서의 적용




**R** — Role

역할 + 경력 + 태도

각 에이전트의 페르소나 정의




**C** — Context

누가·왜·어떤 상황에서

사용 대상 + 업무 배경 명시




**T** — Task

단계별 구체적 지시

Step-by-Step 작업 절차




**C** — Constraints

형식·톤·금지사항

출력물 품질 기준 + 할루시네이션 방지


### BMAD Method 구조 원칙





원칙

적용 방식




오케스트레이터 중심 조율

팀장 1명이 전체 흐름 관리




전문가 분업

각 에이전트는 1개 핵심 역할만 담당




명령어 시스템 (`*` prefix)

`*help`, `*status`, `*agent`, `*elicit` 등




Advanced Elicitation

결과물 출력 후 0-9 피드백 옵션 제공




출력물 형식 명시

각 에이전트의 산출물 포맷 사전 정의

# 📦 Pack 1: 에이전트 설계 비서
### *"막연한 아이디어를 완성형 시스템 프롬프트로"*
**이 팩이 필요한 순간**
- 시스템 프롬프트를 만들고 싶은데 어디서 시작해야 할지 모를 때
- 내 아이디어를 제대로 된 전문가 에이전트로 만들고 싶을 때
- 기존 에이전트가 원하는 대로 작동하지 않아 고쳐야 할 때
- 복잡한 업무를 자동화하는 멀티 에이전트 팀을 설계하고 싶을 때
**팀 구성 한눈에 보기**
```plain text
[오케스트레이터] 프롬프트 총괄 디렉터
    ├── [Alex] 의도 분석가 — 사용자의 진짜 목적 파악
    ├── [Dana] 페르소나 설계자 — 최적의 전문가 정체성 부여
    ├── [Rex]  프로세스 아키텍트 — 단계별 작업 절차 설계
    ├── [Quinn] 제약조건 엔지니어 — 품질 기준 및 경계 설정
    └── [Vera] 품질 검증관 — 완성 프롬프트 최종 점검
```
