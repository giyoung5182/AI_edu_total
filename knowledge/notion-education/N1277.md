# 기획팀 Quick Win 실습 — 내 업무 RCTCK 워크시트로 자동화

정리일: 2026-10-08 · 교육 에셋 N1277

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
예시가 아닌 내 업무로 직접 RCTCK 프롬프트를 만들어 Claude에서 실행하고, 수업이 끝날 때 손에 쥐고 나갈 결과물을 만듭니다.
## 진행 단계
1. **자동화하고 싶은 업무 고르기 (3분)** — 기획팀에서 반복적으로 하는 작업 하나를 고릅니다(교안의 자동화 후보 예시 표 참고).
- 입력할 내용: "나는 이것을 자동화하고 싶다: "
2. **RCTCK 워크시트 작성 (10분)** — Role/Context/Task/Constraint/Knowledge 칸을 채웁니다. 완벽하지 않아도 되고 일단 채워 Claude에 넣어보는 것이 목표입니다.
- 입력할 내용:
```javascript
[R - Role] 당신은 ... ____________ 입니다.
[C - Context] 현재 ____ 상황입니다.
[T - Task] ____ 을/를 만들어 주세요. 구성: - ____
[C - Constraint] 분량 / 문체 / 금지
[K - Knowledge] 실제 자료 붙여넣기
```
1. **Claude 실행 (10분)** — 작성한 프롬프트를 claude.ai 새 대화에 붙여넣고 실행해 확인 1\~3을 점검합니다. 결과가 70%면 체이닝으로 이어갑니다("\[원하는 부분\]을 다시 써줘. \[구체적으로 어떻게\] 바꿔줘.").
- 정상 결과: 원하는 구조·회사 스타일 문체·구체적 내용으로 나옴.
2. **강사 피드백 (12:30\~12:50)** — 결과물을 화면에 띄우고 강사와 함께 RCTCK에서 약한 부분, K에 추가할 자료, 체이닝 방식을 확인합니다. 만든 프롬프트는 저장해 둡니다.
## 막히는 지점
- 확인 1 원하던 구조가 아니면: T(Task)의 구성 항목을 더 구체적으로 수정
- 확인 2 문체·톤이 다르면: K에 기존 제안서 텍스트를 추가
- 확인 3 내용이 너무 일반적이면: K에 클라이언트 정보를 더 구체적으로 추가
