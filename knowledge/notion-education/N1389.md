# 3단계 — 고쳐가며 완성 (13분)

정리일: 2026-10-08 · 교육 에셋 N1389

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
한 번에 완성되지 않는 대시보드를 코드를 보지 않고 말로 고쳐가며 완성합니다.
## 진행 단계
1. **말로 수정 요청** — 상황별 요청 예시
- 화면이 하얗다 → "아무것도 안 나온다. 콘솔 오류: \[붙여넣기\]"
- 한글이 깨진다 → "한글이 깨진다. UTF-8로 처리해줘"
- 차트가 안 보인다 → "차트 영역이 비어 있다. 표에는 데이터가 나온다"
- 글자가 작다 / 색이 마음에 안 든다 / 배치가 이상하다 → 어떻게 바꿀지 말로 설명
2. **수정 기록 작성** — 시도별로 무엇이 아쉬웠는지, 어떻게 말했는지 기록
3. **완성 확인** — 브라우저에서 열린다 / 한글이 안 깨진다 / 숫자가 분석 결과와 일치 / 내가 준 것 외의 숫자가 없다 / 표본이 적은 항목에 단서가 있다 / 상급자에게 보여줄 수 있는 수준이다
## 막히는 지점
- 세 번 이상 같은 것을 고치고 있다면 멈추고 새 대화창을 열어 지금까지 가장 나은 버전을 붙여넣고 다시 시작(컨텍스트 붕괴)
