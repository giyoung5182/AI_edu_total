# GAS 백엔드 활용 상세 과정 안내

정리일: 2026-10-08 · 교육 에셋 N0182

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

구글 시트를 데이터베이스로, 앱스크립트를 백엔드로 씁니다.<br>처음 한 번만 15분이면 끝납니다.
---
## 1단계 · 구글 시트 만들기
1. sheets.new 접속
2. 파일 이름을 `배포현황판 2026-08-10` 으로 변경
시트 안에 탭을 직접 만들 필요는 없습니다. 스크립트가 자동으로 만듭니다.
---
## 2단계 · 앱스크립트 붙여넣기
1. 시트 상단 메뉴 → **확장 프로그램 → Apps Script**
2. 새 탭이 열리면 기본으로 들어 있는 `function myFunction() {}` 를 **전부 지웁니다**
3. `Code.gs` 파일 내용을 **전부 복사해서 붙여넣기**
4. 저장 (Ctrl+S / Cmd+S)
### 이어서 시트 초기화
1. 편집기 위쪽 함수 선택 상자에서 **`시트만들기`** 선택
2. **실행** 클릭
3. 권한 요청 창이 뜹니다 → **권한 검토** → 본인 계정 선택
4. **"Google에서 확인하지 않은 앱"** 경고가 나옵니다<br>→ **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
> 이 경고는 정상입니다. 내가 방금 만든 스크립트라서 구글이 아직 검토하지 않았을 뿐입니다.
시트로 돌아가면 `배포현황` 탭에 43명 명단이 채워져 있어야 합니다.
---
## 3단계 · 웹 앱으로 배포
1. 앱스크립트 편집기 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 아이콘 → **웹 앱** 선택
3. 설정을 이렇게 맞춥니다

## 4단계 · index.html에 주소 넣기
`index.html` 을 열어 `<script>` 시작 부분을 찾습니다.
```javascript
const API = "";
```
복사한 주소를 따옴표 안에 붙여넣습니다.
```javascript
const API = "[개별 링크 제외]";
```
저장.
---
## 5단계 · GitHub + Vercel 배포
1. GitHub → **New repository** → 이름 `sw-deploy-board`, **Public**
2. `index.html` 을 그대로 드래그 업로드 → Commit
3. vercel.com → **Add New → Project** → 저장소 선택 → **Deploy**
설정은 아무것도 건드리지 않습니다. 1분 안에 주소가 나옵니다.
**`Code.gs`**** 와 ****`SETUP.md`**** 는 GitHub에 올리지 마세요.** 웹 앱 주소가 노출됩니다.

**배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 이때 주소는 그대로 유지됩니다

수강생 화면만 안 됨

권한 승인을 안 했거나, 조직 계정 정책으로 외부 공유가 막힌 경우. 개인 구글 계정으로 다시 배포

## 수업 중 운영 팁
- 시트를 열어 두면 43명이 입력하는 게 실시간으로 보입니다. 빔프로젝터에는 **현황판 쪽**을 띄우는 편이 낫습니다 (막대가 채워지는 게 보여서 분위기가 살아납니다)
- 화면은 10초마다 자동 갱신됩니다. 급하면 **지금 새로고침**
- 마칠 때 **CSV 내려받기** 또는 **표로 복사** 로 노션에 정리
- 다시 쓸 때는 앱스크립트에서 **`입력값_모두지우기`** 실행 (명단은 남고 주제·주소만 비워집니다)
---
## 알아 둘 제한
- 앱스크립트 무료 한도는 하루 실행 20,000회입니다. 43명 × 10초 갱신이면 하루 종일 써도 한참 남습니다
- 저장은 `LockService` 로 한 명씩 처리하므로 동시에 눌러도 값이 덮이지 않습니다
- 이름 확인 절차가 없어서 누구나 다른 사람 칸을 고칠 수 있습니다. 수업 규모에서는 이게 오히려 편합니다 (강사가 대신 입력 가능)
