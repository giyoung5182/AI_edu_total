# 실습 3 — VBA 매크로 요청 및 실행해보기

정리일: 2026-10-08 · 교육 에셋 N1058

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Copilot에 VBA 매크로를 자연어로 요청해 '완료' 행만 새 시트로 복사하는 코드를 받고 직접 실행합니다.
## 진행 단계
1. **실습 데이터를 표로 정리** — 아래 프롬프트 + 교안의 담당자별 처리 건수 데이터를 Copilot에 붙여넣습니다.
- 입력할 내용:
```javascript
아래 데이터를 표로 정리해줘.
컬럼: 담당 변호사, 사건 유형, 처리 상태, 처리일
- 담당자명에서 "변호사" 호칭은 제거해줘.
- 처리일은 YYYY-MM-DD 형식으로 통일해줘.
- 처리 상태가 없으면 "미확인"으로 표시해줘.

[실습 데이터 붙여넣기]
```
2. **Excel에 저장** — 정리된 표를 붙여넣고 시트 탭을 더블클릭해 이름을 "데이터"로 변경
3. **VBA 매크로 요청**
- 입력할 내용:
```javascript
Excel VBA 매크로를 작성해줘.
기능: "데이터" 시트에서 처리 상태가 "완료"인 행만 골라
      "완료건" 이라는 새 시트에 복사하기
조건:
- 시트명: "데이터"
- 처리 범위: A2부터 마지막 행까지
- 결과 출력: "완료건" 시트에 붙여넣기 (헤더 행 포함)
코드와 함께 각 줄의 의미도 주석으로 달아줘.
```
4. **코드 실행** — 생성된 코드를 복사해 `Alt + F11` → `삽입 → 모듈`에 붙여넣고 F5 또는 실행 버튼
5. **결과 확인**
- 정상 결과: "완료건" 시트가 생성되고 완료 건만 복사됨
## 막히는 지점
- 실행 전 원본 파일 백업 사본을 만들고 VBA 매크로 보안 설정을 확인합니다(실습 후 알림 표시 후 비활성화로 복원).
- 시트명과 범위를 명확히 지정하지 않으면 엉뚱한 데이터가 처리될 수 있습니다.
