# PoC 경로 A — 내 데이터로 Streamlit 대시보드 만들기
### 경로 A 목표
**샘플 데이터** → **내 실제 데이터로 작동하는 대시보드**
### ✅ Step 1. 실습 폴더 준비 + 원본 데이터

- 혹은 클로드코드에 한 번에 요청!
### 옵션 1: 샘플 데이터로 실습하기 (추천)

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]

제공된 `sample_raw_data.csv`를 폴더에 저장합니다. <br>(컬럼: 날짜, 담당자명, 사원번호, 담당팀, 러닝화_검색량, 등산화_검색량, 매출, 고객피드백)
### 옵션 2: 내 실제 파일로 실습하기

**실제 사내 데이터 사용 전 확인**
실제 업무 파일에는 고객명·사번 같은 민감정보가 포함될 수 있습니다. 회사 보안 정책상 AI 도구에 올려도 되는 데이터인지 먼저 확인하고, 확실하지 않으면 샘플 데이터로 실습하세요. Step 2의 민감정보 제거 패턴을 익힌 뒤 적용하는 것이 안전합니다.

### ✅ Step 2. 민감정보 제거 (Claude Code)
**`Claude Code 프롬프트`**
```plain text
폴더의 sample_raw_data.csv에서 민감정보를 제거해서
정제된 파일을 만들어줘.

사전 작업:
파일을 먼저 읽어서 실제 컬럼명을 확인한 뒤,
아래 기준에 따라 유지/삭제를 판단해줘.

컬럼 처리 기준 (역할 기반):
- 날짜 관련 컬럼 ✅ 유지
- 개인 식별 정보 (이름, 사번, ID 등) ❌ 삭제
- 팀/부서 정보 ✅ 유지
- 수치 데이터 (검색량, 매출 등) ✅ 유지
- 개인 의견/피드백 ❌ 삭제

출력 컬럼 순서:
날짜 → 팀/부서 → 수치 데이터 (파일에 있는 순서대로)

요청:
1. 실제 컬럼 목록과 유지/삭제 판단 결과를 먼저 표로 보여줘
2. 위 기준으로 정제된 cleaned_data.xlsx를 폴더에 저장해줘
3. 완료 후 정제 전/후 컬럼 수와 행 수를 요약해줘
```
### ✅ 확인 포인트
- Claude가 보여준 **유지/삭제 판단 표**가 기준과 맞는지 (잘못 판단했다면: "담당팀은 개인정보가 아니라 유지해야 해")
- `poc` 폴더에 **`cleaned_data.xlsx`** 생성 확인
- 파일을 직접 열어 이름·사번·피드백 컬럼이 정말 사라졌는지 눈으로 확인 ⭐
<details>
<summary>**`Claude가 실행하는 코드 예시 (참고용)`**</summary>
```python
"""
민감정보 제거
- 입력: sample_raw_data.csv
- 출력: cleaned_data.xlsx
- 삭제 기준: 개인 식별 정보(이름, 사번), 개인 의견/피드백
"""

import pandas as pd

# 1. 파일 읽기 및 컬럼 확인
df = pd.read_csv("sample_raw_data.csv")
print("원본 컬럼:", list(df.columns))

# 2. 역할 기반 판단 — 개인 식별 + 개인 의견 삭제
DROP_COLS = ["담당자명", "사원번호", "고객피드백"]
df_clean = df.drop(columns=DROP_COLS)

# 3. 컬럼 순서: 날짜 → 팀/부서 → 수치 데이터
KEEP_ORDER = ["날짜", "담당팀"]
final_cols = KEEP_ORDER + [c for c in df_clean.columns if c not in KEEP_ORDER]
df_clean = df_clean[final_cols]

# 4. 저장
df_clean.to_excel("cleaned_data.xlsx", index=False)
print(f"정제 완료: {len(df.columns)}개 → {len(df_clean.columns)}개 컬럼 | {len(df_clean)}행")
```

<summary>**`Claude Code가 생성하는 코드 예시 (참고용)`**</summary>
```python
"""
팀별 매출 분석 대시보드
- 입력: cleaned_data.xlsx (날짜 | 담당팀 | 러닝화_검색량 | 등산화_검색량 | 매출)
"""

import os
import streamlit as st
import pandas as pd
import plotly.graph_objects as go

st.set_page_config(page_title="팀별 매출 분석 대시보드", page_icon="💹", layout="wide")

# __file__ 기준 상대경로
BASE_DIR  = os.path.dirname(os.path.abspath(__file__))
FILE_PATH = os.path.join(BASE_DIR, "cleaned_data.xlsx")

@st.cache_data
def load_data():
    df = pd.read_excel(FILE_PATH)
    df["날짜"] = pd.to_datetime(df["날짜"])
    df["날짜_str"] = df["날짜"].dt.strftime("%Y.%m")
    return df

df = load_data()

# ── 사이드바 필터 ──
with st.sidebar:
    st.header("🔍 데이터 필터")
    all_teams = sorted(df["담당팀"].unique().tolist())
    selected_teams = st.multiselect("팀 선택", options=all_teams, default=all_teams)
    date_range = st.date_input("기간 선택",
                               value=(df["날짜"].min().date(), df["날짜"].max().date()))

sel = selected_teams if selected_teams else all_teams
start, end = pd.Timestamp(date_range[0]), pd.Timestamp(date_range[1])
fdf = df[(df["담당팀"].isin(sel)) & (df["날짜"] >= start) & (df["날짜"] <= end)].copy()

# ── KPI 카드 4개 ──
st.markdown("# 💹 팀별 매출 분석 대시보드")
k1, k2, k3, k4 = st.columns(4)
best, worst = fdf.loc[fdf["매출"].idxmax()], fdf.loc[fdf["매출"].idxmin()]
k1.metric("총 매출 합계", f"₩{fdf['매출'].sum()/1e8:.2f}억")
k2.metric("월평균 매출", f"₩{fdf['매출'].mean()/1e8:.2f}억")
k3.metric("매출 최고월", best["날짜_str"], f"₩{best['매출']/1e8:.2f}억")
k4.metric("매출 최저월", worst["날짜_str"], f"-₩{worst['매출']/1e8:.2f}억")

# ── 월별 매출 추이 (팀별 + 전체 합산) ──
fig = go.Figure()
for team in sel:
    tdf = fdf[fdf["담당팀"] == team].sort_values("날짜")
    fig.add_trace(go.Scatter(x=tdf["날짜_str"], y=tdf["매출"],
                             name=team, mode="lines+markers"))
total = fdf.groupby("날짜_str")["매출"].sum().reset_index()
fig.add_trace(go.Scatter(x=total["날짜_str"], y=total["매출"], name="전체 합산",
                         mode="lines+markers", line=dict(dash="dot")))
st.plotly_chart(fig, use_container_width=True, key="fig_line")

# ── 팀별 총매출 수평 막대 ──
team_total = fdf.groupby("담당팀")["매출"].sum().reset_index().sort_values("매출")
fig_bar = go.Figure(go.Bar(x=team_total["매출"], y=team_total["담당팀"], orientation="h",
                           text=[f"₩{v/1e8:.2f}억" for v in team_total["매출"]],
                           textposition="outside"))
st.plotly_chart(fig_bar, use_container_width=True, key="fig_bar")

# ── 상세 테이블 + CSV 다운로드 ──
sort_by = st.selectbox("정렬 기준", ["날짜", "매출"])
table = fdf.sort_values(sort_by)[["날짜_str", "담당팀", "매출"]].rename(columns={"날짜_str": "날짜"})
st.dataframe(table.style.format({"매출": "₩{:,.0f}"}), use_container_width=True, hide_index=True)
st.download_button("⬇️ 필터링 데이터 CSV 다운로드",
                   table.to_csv(index=False).encode("utf-8-sig"),
                   "cleaned_data_filtered.csv", "text/csv")
```
</details>

### Step 2. Claude Code로 보고서 초안 도구 만들기
기존에는 Google AI Studio로 별도 앱을 만들었지만, Claude Code에서는 프롬프트 하나로 바로 보고서 파일이 나옵니다.

### 1️⃣ Claude Code에 인포그래픽 요청
**`Claude Code 프롬프트`**
```plain text
내가 만든 자동화 도구를 팀에 소개하는 1페이지 인포그래픽을
HTML 파일로 만들어줘. 파일명: poc_onepager.html

제목: "[내 도구 이름]"
부제: "매주 30분 절감하는 자동 데이터 분석"

3단 구성:
- 왼쪽: "어떤 문제를 해결해요?" — 반복적인 수동 분석 → 자동 분석
- 가운데: "어떻게 사용해요?" — 1️⃣ 데이터 준비 / 2️⃣ 실행 / 3️⃣ 결과 확인
- 오른쪽: "효과가 뭐예요?" — 큰 글씨로 "주당 30분 절감" + 시계 아이콘

하단: 사용 방법 안내 + "팀에 공유하기" 문구
색상: 파랑(#0066CC) + 회색(#666666) + 흰색
스타일: 깔끔한 비즈니스 스타일, A4 가로 비율

완성되면 브라우저에서 열어볼 수 있게 폴더에 저장해줘.
```

- 수정은 대화로: "제목을 더 크게, 효과 숫자는 빨간색으로 강조해줘"
