### 📖 개념: AI 도구, 왜 이렇게 많을까?
- **ChatGPT = 범용 AI 어시스턴트**: 무엇이든 물어볼 수 있지만 특정 업무에 최적화되어 있지 않습니다. 처음 시작하기 가장 좋은 도구입니다.
- **GPTs = ChatGPT를 특정 목적에 맞게 세팅한 버전**: 마치 "특정 업무 전문가를 고용한 것"처럼 동작합니다. OpenAI 스토어에 수많은 템플릿이 이미 만들어져 있습니다.
- **Genspark = 검색·분석부터 문서·슬라이드·에이전트 제작까지, AI 업무용 올인원 워크스페이스**: 웹 검색과 AI 분석을 결합해 심층 리포트를 자동 생성하는 것이 핵심이며, 여기에 슬라이드·문서 제작과 나만의 **맞춤 AI 에이전트** 제작 기능까지 더해 "업무용 만능 작업대"에 가깝습니다. 이 에이전트 기능은 세션 6에서 직접 만들어봅니다.

**ChatGPT도 웹검색이 되는데 왜 Genspark를 따로 쓸까요?** ChatGPT 웹검색은 "질문에 답하려고" 자료를 찾는 데 가깝고, Genspark는 처음부터 "출처가 정리된 리포트 한 편"을 만드는 데 최적화돼 있습니다. 시장 조사처럼 종합 보고서가 필요하면 Genspark, 빠른 질의응답엔 ChatGPT가 적합합니다.

### 🔥 활동 1 — GPTs 탐방: 이미 만들어진 AI 도구 찾기
**실행 방법:**
- ChatGPT 좌측 메뉴에서 **"GPT 탐색"** 클릭
- 검색창에 아래 키워드 중 하나를 입력 (예: ChatGPT - Diagrams: Flowcharts & Mindmaps)
- 마음에 드는 GPT를 열고, 아래 질문을 입력해봅니다

**GPTs는 대부분 다른 사용자가 만든 것**입니다. 데이터 처리 방식이 불명확할 수 있으니 보안 수칙(회사 기밀정보·실제 고객사명 입력 금지)을 더욱 철저히 지키세요. 고를 때는 대화 수·별점·최근 업데이트 여부를 먼저 확인하세요.

**검색 키워드 (본인 직무에 맞게 선택):**
```plain text
- "production report" (생산/현장 관리)
- "project management" (기획/관리)
- "contract review" (계약/법무)
- "data analysis" (재무/구매)
- "safety checklist" (안전/품질)
- "quality inspection" (품질/설계 검토)
```
**GPT를 찾았다면, 세션 1의 5요소를 떠올리며 이렇게 물어보세요** (대괄호는 내 상황으로):
```javascript
저는 [본인 직무]를 담당하고 있습니다. (역할·맥락)
오늘 해결해야 할 문제는 [예: 생산 라인 정지 보고서 작성]입니다. (지시)
어떻게 도와줄 수 있는지, 필요한 정보가 있으면 먼저 물어봐 주세요.
```

**Padlet에 올리기** (`세션2 · 도구 체험`) — 내가 고른 GPT 이름과 "이건 내 업무의 어디에 쓸 만하겠다" 한 줄 소감을 올려주세요.

### 🔥 활동 2 — Genspark로 심층 리포트 만들기
**실행 방법:**
1. genspark.ai 접속 → 회원가입 또는 게스트 사용
2. **내가 실제로 궁금한 주제**로 검색어를 직접 만들어 입력합니다 (아래는 형태 참고용 예시)
3. 자동 생성된 리포트를 확인하고, 유용한 인사이트를 메모합니다
```plain text
[형태 예시 — 내 업무 주제로 바꿔 쓰세요]
- "2026년 자동차 부품 소재 가격 동향 및 납기 지연 원인 분석"
- "스마트 팩토리 생산 관리 기술 최신 트렌드"
- "제조업 품질 관리 AI 도입 사례"
```

**Padlet에 올리기** (`세션2 · 도구 체험`) — 내가 넣은 검색어와, 리포트에서 건진 인사이트 1가지를 올려주세요. 남들이 어떤 주제를 넣었는지 보면 활용 아이디어가 넓어집니다.

<details>
<summary>예상 결과 확인하기 👀</summary>
Genspark는 다음과 같은 형태의 리포트를 자동 생성합니다:
- **요약 섹션**: 핵심 인사이트 3\~5개
- **상세 내용**: 각 항목별 설명과 출처
- **관련 자료 링크**: 추가 참고 자료
- **시각화 자료**: 필요 시 차트나 표 포함
생성된 내용은 참고용이며, 중요한 의사결정에는 반드시 원본 출처 확인이 필요합니다.
</details>

**더 써볼 수 있는 것 (선택)**: 리포트가 마음에 들면 슬라이드/프레젠테이션으로 변환하는 기능을 눌러보세요. 방금 만든 리포트가 발표용 슬라이드로 바로 바뀝니다 — Genspark가 "만능 작업대"인 이유가 여기서 체감됩니다.


**미리보기: 나만의 AI 에이전트 만들기** — Genspark 좌측 "+ New"(또는 Custom Super Agent Store의 "Create New") 버튼을 누르면 입력→처리→출력 규칙을 짜서 돌리는 미니 AI 도구를 만들 수 있습니다. ChatGPT의 "GPT 만들기"로도 가능. 오늘은 버튼만 확인하고, 실제 제작은 세션 6에서 진행합니다.

### 🔥 활동 3 — ChatGPT로 '내 업무' 프로세스 시각화
**목표:** 예시 프로세스가 아니라 **내가 실제로 매번 거치는 업무 절차**를 AI에게 그림으로 그리게 합니다. 글로 설명하는 것과 다이어그램으로 보는 것의 차이를 체감합니다.
**실행 방법:**
1. **내 업무 절차를 단계별로 적어봅니다.** 매일 하는 일의 순서를 3\~6단계로 쓰면 됩니다. 아래는 형태 참고용 예시입니다.
```javascript
[형태 예시 — 내 업무로 바꿔 쓰세요]
부품 자재 발주 프로세스:
1단계: 자재 소요량 산출 → 2단계: 발주 요청서 제출 → 3단계: 견적 비교 →
4단계: 업체 선정·발주 → 5단계: 입고·품질 검수 → 6단계: 라인 투입
리스크 포인트: 2~3단계 사이 평균 3일 지연 / 5단계 불량 시 재발주 2~5일 지연
```
1. 내 절차를 붙여넣은 뒤, 이어서 요청합니다.
```plain text
위 내용을 인포그래픽 스타일의 플로우차트로 시각화 해줘.
각 단계를 박스로 표현하고, 리스크 포인트(지연·병목)는 색이나 표시로 강조해줘.
```
1. 생성된 다이어그램을 보고, "실제 병목이 여기 맞나?"를 스스로 점검합니다.

**Padlet에 올리기** (`세션2 · 도구 체험`) — 만든 다이어그램(캡처)이나 내 프로세스 설명을 올려주세요. 다른 직무의 업무 흐름을 구경하는 것만으로도 배울 게 많습니다. 이어서 "오늘 써본 도구 중 내 직무에서 가장 자주 쓸 것 같은 것 + 그 이유"도 한 줄로 올려주세요.

### 📌 세션 2 핵심 정리
① ChatGPT는 범용(문서 작성부터 간단한 시각화까지), GPTs는 특수목적, Genspark는 조사/분석·문서제작 — 목적에 맞게 골라 쓴다.
② GPTs 스토어에는 이미 수천 개의 업무 특화 AI가 있다. 먼저 찾아보는 것이 효율적이다.
③ AI 도구는 "결과물을 사람이 검토하고 보완"해야 완성된다.
**💼 세션 2를 마치고 바로 적용할 것**
- 팀에서 반복적으로 같은 질문·요청을 받는 업무가 있다면, GPTs로 전용 챗봇을 만들어 팀과 공유하는 걸 고려해보세요.
- GPTs는 대부분 타인이 만든 서드파티 도구입니다. 회사 기밀정보·실명 데이터는 절대 입력하지 마세요.
- Genspark 리포트는 발표 자료의 "초안"으로 쓰고, 제출·공유 전에는 반드시 출처를 직접 확인하세요.
- 도구를 고를 때는 "이 작업은 대화형인가(ChatGPT/GPTs), 조사·산출물형인가(Genspark)"부터 물어보면 선택이 빨라집니다.
