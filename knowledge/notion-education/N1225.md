# 실습 9 — 배포와 살아있는지 확인

정리일: 2026-10-08 · 교육 에셋 N1225

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
대시보드를 링크로 공유하고, 시트를 바꾸면 화면도 바뀔는지 검증한다. (오늘의 핵심 검증)
## 진행 단계
1. **HTML 파일 추가** — Apps Script 편집기 좌측 파일 「+」 → HTML → 이름 dashboard → 받은 HTML 코드 붙여넣기
2. **doGet 함수 추가** — Code.gs에 아래 함수를 추가한다
- 입력할 내용:
```javascript
function doGet() {
  return HtmlService.createHtmlOutputFromFile('dashboard')
    .setTitle('업무요청 현황');
}
```
3. **새 배포** — 상단 「배포」 → 「새 배포」 → 유형: 웹 앱 → 액세스 권한: 링크가 있는 모든 사용자(또는 내 조직 내 사용자) → 배포 → URL 복사
4. **살아있는지 확인(필수)** — 대시보드를 브라우저에 띄워두고 → 시트 요청접수에 새 요청 하나 제출 → 「화면데이터 갱신」 메뉴 클릭 → 대시보드 새로고침 → 전체건수가 1 늘어나는지 확인
- 정상 결과: 숫자가 바뀔 / 갱신일시가 바뀔 / 다른 기기에서도 링크가 열림
