# 1단계 · 구상 워크시트 → 2단계 · 메타 프롬프트로 지침 고도화

정리일: 2026-10-08 · 교육 에셋 N1318

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지침을 백지에서 쓰지 않고, 거친 구상을 적은 뒤 AI에게 다듬게 합니다(메타 프롬프트).
## 진행 단계
1. **구상 워크시트 작성** — 워크시트를 복사해 메모장에 붙여 넣고 빈칸을 채웁니다. 단어만 적어도 됩니다.
- 입력할 내용: 이름 / 대신해 줄 일 / 일하는 사람 / 입력 자료 / 결과물 모양 / 절대 하지 말아야 할 것 / 자료 부족 시 대응 / 지식란에 올릴 파일 (8문항)
2. **메타 프롬프트 실행** — 메타 프롬프트를 ChatGPT에 넣고 맨 아래에 워크시트를 붙입니다. AI는 빠진 것을 최대 5개까지 먼저 질문합니다.
3. **답변 후 지침 받기** — AI가 추가한 항목은 따로 목록으로 알려 줍니다. 검토합니다.
4. **허점 점검** — "이 지침대로 동작했을 때 잘못된 결과가 나올 수 있는 경우를 3가지 예측해 주세요. 그걸 막는 문장을 지침에 추가해 주세요."
## 막히는 지점
- 6번 금지 사항이 비면 AI가 빈칸을 창작으로 메웁니다.
