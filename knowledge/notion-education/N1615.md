## 03. 실습 1: 매크로 기록기로 첫 자동화
> ⏱ 예상 소요: 약 45분
💡 **매크로 기록기는 여러분의 클릭을 그대로 코드로 받아 적는 속기사입니다. <br>     코딩 없이 첫 매크로를 만듭니다.**
**실습 파일:** `complaints_report.xlsx` (서식 없는 민원 현황 표, 60행)
**☑️ 문제1: 서식 통일 매크로 기록**
"보고 전에 매번 하는 서식 작업"을 한 번만 하면서 녹화합니다.<br>이후로는 재생 버튼만 누르면 됩니다.
1. 개발 도구 → **매크로 기록** → 이름: `서식정리` → 확인 (지금부터 모든 클릭이 녹화됨 🔴)
2. 녹화 중 작업:
- 1행 선택 → 굵게 + 배경색 채우기
- 표 전체 선택 → 모든 테두리
- 열 머리글 전체 선택 → 경계선 더블클릭 (너비 자동 맞춤)
3. 개발 도구 → **기록 중지**
4. 민원현황 시트 우클릭 → 이동/복사 → 복사본 만들기 → 복사본에서 서식만 지우기 (홈 → 지우기 → 서식 지우기)
5. 개발 도구 → 매크로 → `서식정리` → **실행**
- 정답화면<br>서식을 지웠던 복사본 시트에 1초 만에 동일한 서식이 적용되면 성공. ✨
**☑️ 문제2: 절대 참조 vs 상대 참조**
개발 도구의 **\[상대 참조로 기록\]** 버튼의 차이를 실험으로 확인합니다.

### VBA-03. 직접 읽어보기
💡 **아래 미스터리 코드 2개가 무슨 일을 하는지, AI 없이 5가지 표지판만으로 해석해 보세요. **
**☑️ 미스터리 코드 1**
vba
```plain text
    Sub 미스터리1()
        Dim i As Long, lastRow As Long
        lastRow = Cells(Rows.Count, "A").End(xlUp).Row
        For i = 2 To lastRow
            If Cells(i, 4).Value = "접수" Then
                Cells(i, 4).Interior.Color = vbYellow
            End If
        Next i
    End Sub

```
- 예시 답안: "A열 기준 마지막 데이터 행까지 반복하면서, 4번째 열(D열=처리상태) 값이 '접수'인 셀을 노란색으로 칠한다"    → 미처리 민원 하이라이트 매크로.
**☑️ 미스터리 코드 2**
vba
```plain text
    Sub 미스터리2()
        Dim i As Long, lastRow As Long, cnt As Long
        lastRow = Cells(Rows.Count, "A").End(xlUp).Row
        cnt = 0
        For i = 2 To lastRow

            Dim lastRow As Long, i As Long, r As Long

                    wsSrc.Rows(i).Copy wsDst.Rows(r)
                    r = r + 1
                End If
            Next i

Sub 지점취합()

            Dim lastRow As Long, destRow As Long, srcRows As Long

            Application.DisplayAlerts = False
            On Error Resume Next
            ThisWorkbook.Sheets("통합").Delete
            On Error GoTo 0
            Application.DisplayAlerts = True

            Set wsTotal = ThisWorkbook.Sheets.Add(Before:=ThisWorkbook.Sheets(1))
            wsTotal.Name = "통합"

            destRow = 1
            For Each ws In ThisWorkbook.Worksheets          ' 모든 시트 반복 (관용구 2)
                If ws.Name <> "통합" Then                    ' 통합 시트 자신은 제외
                    lastRow = ws.Cells(ws.Rows.Count, "A").End(xlUp).Row
                    If destRow = 1 Then
                        ws.Range("A1:E" & lastRow).Copy wsTotal.Range("A1")   ' 첫 시트: 머리글 포함
                        wsTotal.Range("F1").Value = "지점명"
                        wsTotal.Range("F2:F" & lastRow).Value = ws.Name

                    Else
                        srcRows = lastRow - 1
                        ws.Range("A2:E" & lastRow).Copy wsTotal.Cells(destRow, 1)  ' 이후: 데이터만
                        wsTotal.Range(wsTotal.Cells(destRow, 6), _
                                      wsTotal.Cells(destRow + srcRows - 1, 6)).Value = ws.Name
                        destRow = destRow + srcRows
                    End If
                End If
            Next ws

            wsTotal.Columns("A:F").AutoFit
            MsgBox "총 " & (destRow - 2) & "행을 통합했습니다.", vbInformation
        End Sub

Sub 월간보고준비()
            Dim wsSrc As Worksheet, wsDst As Worksheet
            Dim lastRow As Long, i As Long, r As Long

            Set wsSrc = ThisWorkbook.Sheets("민원현황")

            Application.DisplayAlerts = False
            On Error Resume Next
            ThisWorkbook.Sheets("미처리").Delete
            On Error GoTo 0
            Application.DisplayAlerts = True

            Set wsDst = ThisWorkbook.Sheets.Add(After:=wsSrc)
            wsDst.Name = "미처리"
            wsSrc.Rows(1).Copy wsDst.Rows(1)

            lastRow = wsSrc.Cells(wsSrc.Rows.Count, "A").End(xlUp).Row
            r = 2
            For i = 2 To lastRow
                If wsSrc.Cells(i, "D").Value <> "완료" Then   ' 완료가 아닌 행
                    wsSrc.Rows(i).Copy wsDst.Rows(r)
                    r = r + 1
                End If
            Next i

            ' 보고용 서식
            With wsDst.Rows(1)
                .Font.Bold = True
                .Interior.Color = RGB(220, 230, 241)
            End With
            wsDst.Range("A1:D" & r - 1).Borders.LineStyle = xlContinuous
            wsDst.Columns("A:D").AutoFit

            MsgBox "미처리 " & (r - 2) & "건 — 보고 준비 완료", vbInformation
        End Sub
```

## 10. 요약
> ⏱ 예상 소요: 약 10분
💡 **금일 수업내용을 복기해 보겠습니다.**
- VBA는 엑셀에게 주는 작업 지시서 언어이고, 매크로는 그 지시서로 만든 자동화 한 덩어리입니다.
- 도구 선택: 셀 계산은 함수, 데이터 정제·병합은 파워쿼리, 서식·시트·저장 같은 '동작'은 VBA입니다.
- 매크로가 기본 차단된 이유는 매크로 바이러스 때문이며, 출처 모르는 파일의 매크로는 허용하지 않습니다.
- 매크로 기록기는 클릭을 코드로 기록하지만, 조건·반복·가변 범위는 못 하며 그 영역을 AI가 채웁니다.
- 절대 참조는 항상 같은 셀, 상대 참조는 현재 위치 기준 — 기록 전에 모드를 확인합니다.
- 매크로는 도형 버튼에 연결하면 VBA를 모르는 동료도 클릭 한 번으로 쓸 수 있습니다.
- 객체 모델은 Workbook(단지)→Worksheet(동)→Range(호수)의 주소 체계로 읽습니다.
- 문법 5가지(Sub/Dim/If/For/주석)와 관용구 2개만 알면 AI 코드의 대부분을 읽을 수 있으며, If는 어제 SQL의 WHERE와 같은 역할입니다.
- 프롬프트 5요소: 상황/데이터 구조/원하는 결과/제약/실행 방법. "한국어 주석" 요청을 항상 붙입니다.
- AI 코드는 실행 전 코드 리뷰 3가지(시트명 일치, Delete·SaveAs 동작, 원본 보존)를 30초간 확인합니다.
- 실행 후에는 검증 3종 세트(건수 대조·샘플 확인·원본 무결성)를 거친 뒤 실무에 적용합니다.
- AI와는 한 방이 아니라 핑퐁으로 코드를 진화시킵니다. MsgBox(알림)·InputBox(입력)를 붙이면 매크로가 '도구'가 됩니다.
- 디버깅은 F8 한 줄 실행으로 눈으로 확인하고, 안 풀리면 "오류 메시지 + 노란 줄"을 그대로 AI에게 줍니다.
- 오류 없이 결과만 이상한 경우(값 뒤 공백 등)가 가장 위험하며, 이것이 검증 3종 세트가 필요한 이유입니다.
- 어제 is_pii = 'Y'로 찾던 개인정보가 든 파일은 AI에 입력하지 않고, 구조와 가짜 예시만으로 요청합니다.
- 파워쿼리(데이터 준비) + VBA(손작업 자동화) 조합이 엑셀 자동화의 완성형이며, 핵심 역량은 코딩이 아니라 업무를 구조적으로 설명하는 능력입니다.
