# 실습 2. 환각 관찰 3질문 + 같은 질문 다시 묻기(P1-3)

정리일: 2026-10-08 · 교육 에셋 N0679

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
자료 없는 질문·준 자료 안의 질문·준 자료 밖의 질문에 대해 AI의 답과 확인 방법이 어떻게 달라지는지 관찰하고, 판정 상태 5가지로 판정합니다.
## 진행 단계
1. **먼저 예측** — P1-3 예측 칸: 자료 없이 내부 수치를 물으면 숫자를 말할까, 모른다고 할까? 규정집에 금액이 없는 항목을 물으면?
2. **질문 1 — 자료 없는 내부 정보** — 새 채팅(대화 ①). + 메뉴에 Gmail·Drive 같은 연결 앱이 보이면 임시 채팅 사용
- 입력할 내용:
```plain text
(고객사) 정산팀이 2026년 상반기에 반려한 출장 정산 건수와
주요 반려 사유 3가지를 알려줘.
```
- 결과를 P1-3 표 질문 1 행에 기록(답 요지 / 출처 표시 / 기준일 / 판정 상태)
1. **질문 1 다시 — 같은 질문, 새 대화(대화 ②)** — 글자 하나 바꾸지 않고 다시 입력, 대화 ①과 ②의 같은 점·다른 점을 재실행 비교 칸에 기록(두 답이 같아도 사실의 증거는 아님)
2. **질문 2 — 준 자료 안의 정보(대화 ③)** — 새 채팅에 04_출장관리_사내규정집.docx 첨부 후 입력
- 입력할 내용:
```plain text
첨부한 사내 규정집을 근거로 답해줘.
개인카드로 결제하고 나중에 정산하는 출장 건에서 영수증을 첨부하지 않으면
정산이 어떻게 처리되는지 알려줘.
근거 조항 번호와 원문 문장을 그대로 인용해줘.
```
- 직접 원문 대조: 규정집에서 Ctrl+F로 조항 번호 검색 → 인용문과 한 글자씩 비교
1. **질문 3 — 준 자료 밖의 정보** — 같은 대화 ③에 이어서(파일 재업로드 없음)
- 입력할 내용:
```plain text
해외 출장 중 현지 택시비·통신비 같은 기타 경비의 1일 상한액은 얼마야?
근거 조항 번호와 원문 문장을 인용해줘.
```
- 직접 원문 대조: Ctrl+F로 "기타 경비", "통신비", "교통비" 검색 → 금액이 실제로 적혀 있는지 확인
1. **관찰·판정** — 답 요지 / 출처 표시 / 원문 일치 / 기준일 / 판정 상태(근거 확인·근거 불일치·근거 없는 단정·확인 불가 응답·보류)를 표에 기록. 대화 ③은 닫지 않음(다음 실습에서 사용)
## 막히는 지점
- 연결 앱 검색이 시작되면 중지 버튼으로 멈추고 임시 채팅에서 다시 실행, 판정 칸에 "검색 시도(연결 앱) — 판정 전 중지"로 기록
- 질문 2·3에 조항 번호 없이 요약만 나오면 "조항 번호와 원문 문장을 규정집에 적힌 그대로 다시 보여줘. 요약하지 말고…"로 재요청
- 질문 2에 "파일을 읽을 수 없다"가 나오면 파일 카드가 붙어 있었는지 확인하고 다시 첨부
- 질문 3에서 금액을 만들어 내면 규정집에 적힌 문장만 근거로 다시 답하고, 없으면 "규정집에 금액 없음 — 담당 부서 확인 필요"로 답하게 함
