# 실습 ③ 트리거 — 불러오기를 매주 자동 실행

정리일: 2026-10-08 · 교육 에셋 N0668

---

## 이 실습으로 하는 것
손으로 확인한 copyCheckRows를 매주 월요일 9시대에 자동 실행하도록 트리거를 등록하고, 목록에서 확인한 뒤 삭제한다.
## 진행 단계
1. **코드 받아 실행** — 같은 ChatGPT 대화에 프롬프트 입력 → Copy code → 기존 코드 맨 아래에 붙여넣기 → 저장 → 드롭다운 `setWeeklyTrigger` → 실행
- 입력할 내용:
```javascript
copyCheckRows를 매주 월요일 오전 9시대에 자동 실행하는 시간 기반 트리거 코드를 추가해 줘. 기존 함수는 그대로 두고 추가할 함수만 줘.
- setWeeklyTrigger: 이 프로젝트의 기존 트리거를 먼저 모두 지우고, 위 트리거 1개만 등록(여러 번 실행해도 1개만 남게)
- deleteMyTriggers: 이 프로젝트의 트리거를 모두 삭제
- 메일 발송 코드는 넣지 말 것
```
- 권한 창이 다시 뜨면 자동 실행 관련 항목을 읽고 허용
1. **트리거 확인** — 왼쪽 세로 메뉴 시계 아이콘 「트리거」에서 목록 확인
- 정상 결과: `copyCheckRows` 1줄, 이벤트 시간 기반, 주 단위. 두 번 실행해도 1줄
2. **삭제** — 드롭다운 `deleteMyTriggers` → 실행 (또는 목록 줄의 ⋮에서 삭제), 「트리거」 화면 새로고침(F5)
- 정상 결과: 목록 0줄
## 막히는 지점
- 같은 트리거가 2개 이상이면 같은 일이 여러 번 실행됨
- 메일 발송 권한이 보이면 취소 후 ChatGPT에 해당 부분 삭제 요청
