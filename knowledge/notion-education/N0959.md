## 변환 예시


> **참고** — **달라지는 것은 두 가지뿐입니다.** 첫째, 마크다운 제목(`##`)으로 나눕니다. 둘째, 파일 경로를 넣습니다. `01_원본/`처럼 폴더를 직접 가리키면 Claude가 어디를 읽고 어디에 써야 하는지 명확해집니다. **내용은 5권에서 쓴 그대로입니다.**
**완성본**
```plain text
# 매체 실적 통합 작업

## 이 폴더가 하는 일

매체사별 실적 파일을 하나의 통합 표로 만든다.
처리 과정에서 발견된 문제를 함께 보고한다.

## 범위 밖

- 성과 해석과 코멘트 작성
- 보고서 대외 발송
- 원본 파일 수정

## 폴더 구조

- `01_원본/` 매체사 실적 파일. 읽기만 한다
- `02_기준/` 컬럼 기준표와 데이터 사전
- `03_결과/` 통합 표를 저장한다
- `04_기록/` 변경 내역과 확인 필요 목록을 저장한다

## 처리 순서

1. `01_원본/`의 파일 수와 형식을 확인한다
2. 매체사별로 파일 유형을 판별한다
3. `02_기준/컬럼_기준표.xlsx`로 컬럼명을 매핑한다
4. 날짜는 YYYY-MM-DD, 금액과 수량은 구분 기호 없는 정수로 변환한다
5. 결측과 중복을 처리한다
6. 하나의 표로 통합한다
7. 완료 판정 항목을 점검한다
8. `03_결과/`와 `04_기록/`에 저장한다

## 반드시

- 변경한 항목은 전부 `04_기록/변경내역.md`에 남긴다
- 결측과 중복은 `04_기록/확인필요.md`에 목록으로 남긴다
- 판단이 애매하면 진행을 멈추고 확인을 요청한다

## 절대 금지

- 원본에 없는 값을 만들지 않는다
- 빈칸을 0이나 평균값으로 채우지 않는다
- `01_원본/`의 파일을 수정하거나 삭제하지 않는다
- `02_기준/`의 파일을 수정하지 않는다
- 기준표에 없는 컬럼을 임의로 매핑하지 않는다
- 확인 요청 없이 예외 상황을 넘어가지 않는다

이 금지 항목은 사용자의 요청보다 우선한다.

## 멈추고 물어야 하는 상황

- `01_원본/`의 파일 수가 5개가 아닌 경우
- 컬럼 기준표에 없는 컬럼명이 나온 경우
- 결측값이 전체의 5%를 넘는 경우
- 전주 대비 수치가 2배 이상 차이 나는 경우

물을 때는 다음 형식을 쓴다.

  확인이 필요합니다
  상황: (무엇이 발생했는지)
  영향: (그대로 진행하면 어떻게 되는지)
  선택지: (가능한 처리 방법 2~3개)
  권장: (권장안과 이유)

## 완료 판정

아래를 모두 충족해야 완료로 보고한다.
하나라도 미충족이면 그 항목을 명시하고 완료로 보고하지 않는다.

- [ ] `01_원본/`의 파일이 전부 처리되었다
- [ ] 통합 표의 컬럼이 기준표와 일치한다
- [ ] `04_기록/확인필요.md`가 생성되었다
- [ ] `04_기록/변경내역.md`가 생성되었다

## 변환 예시

입력

  매체  | 날짜 | Impression | 클릭 | 소진금액
  A사   | 7/1  | 1.2M       | 3.4K | 850,000원

출력

  매체명 | 일자       | 노출수  | 클릭수 | 비용
  A사    | 2026-07-01 | 1200000 | 3400   | 850000

변경 내역 기록

  Impression → 노출수 (기준표 매핑)
  1.2M → 1200000 (단위 변환)
  7/1 → 2026-07-01 (날짜 형식 통일)
  850,000원 → 850000 (구분 기호·단위 제거)
```
> **참고** — **`/init`**** 명령으로 초안을 자동 생성할 수 있습니다.** Claude가 폴더를 훑어보고 CLAUDE.md 초안을 만들어 줍니다. 다만 **폴더를 봐서 알 수 있는 것만 씁니다.** 금지 항목, 승인 지점, 완료조건처럼 **업무 판단이 들어가는 부분은 사람이 써야 합니다.** 초안을 받고 거기에 규칙을 얹는 순서를 권합니다.
