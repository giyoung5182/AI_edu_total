# 1부. 자동화란 무엇인가
### 📖 개념: 오늘의 사례
오늘 여섯 권을 관통할 업무는 이것입니다.
```plain text
매체별 광고 실적을 취합해 주간 성과보고서를 작성한다
```
특별한 업무가 아닙니다. 매주 반복되고, 여러 곳에서 자료가 오고, 정해진 양식이 있고, 숫자를 다루고, 틀리면 곤란해집니다. **자동화 논의에 필요한 조건이 전부 들어 있어서** 사례로 골랐습니다.

매주 요청문을 다시 쓴다

### 📖 개념: 무엇이 자동화되는가 \[원리 넷\]
무엇이든 자동화되는 것은 아닙니다. **세 가지 조건**을 봅니다.
```plain text
1  반복되는가          매주·매월 같은 형태로 발생하는가
2  규칙이 있는가        무엇을 어떻게 처리할지 말로 설명할 수 있는가
3  입력이 존재하는가    처리할 자료가 실제로 있는가
```
세 가지가 모두 예여야 합니다. 하나라도 아니오면 자동화 대상이 아니거나, 아직 아닙니다.

# 2부. 어디를 자동화할 것인가
### 📖 개념: 왜 분해부터 하는가
"주간 성과보고를 자동화하겠다"는 문장은 **실행할 수 없습니다. 너무 큽니다.**
자동화는 업무 전체가 아니라 **단계 단위로 붙습니다.**


<colgroup>
<col>
<col width="392">
</colgroup>



나쁜 과제 (너무 넓음)

좋은 과제 (딱 핵심)




"주간 성과보고 전체를 자동화"

"매체별 실적 파일의 형식을 통일해 하나의 표로"




"광고 캠페인 관리 자동화"

"일일 소진 현황을 기준 대비 표로 정리"




"경쟁사 분석 자동화"

"수집한 소재를 유형별로 분류하고 태그 부여"




"문서 업무 자동화"

"요청서를 표준 양식으로 변환하고 누락 항목 표시"


> **참고** — **한 문장으로 "무엇을 넣으면 무엇이 나온다"를 말할 수 있어야 적정 크기입니다.** 설명에 "그리고", "또한"이 세 번 이상 들어가면 너무 큽니다.

### 📖 개념: Input – Process – Output 분해
```plain text
INPUT (들어오는 것)

  매체사별 실적 파일 5~6개      형식이 제각각. 엑셀·CSV 혼재
  광고주 요청사항 메일           비정형 텍스트
  전주 보고서                    비교 기준으로 사용
  집행 계획 대비 실적 기준표      사내 문서


PROCESS (처리하는 것)

  1  파일 수집·확인             누락 여부 점검
  2  형식 통일                   컬럼명·단위·날짜 형식 정리
  3  데이터 취합                 매체별 실적을 하나의 표로
  4  성과 계산                   CTR·CPC·전환율·목표 대비 달성률
  5  이상치 확인                 전주 대비 급변 구간 점검
  6  보고서 작성                 정해진 양식에 채워 넣기
  7  코멘트 작성                 성과 해석과 다음 주 제안


OUTPUT (나가는 것)

  주간 성과보고서 1부            정해진 양식
  원본 취합 데이터               내부 보관용
```
> **참고** — **분해하자마자 보이는 것이 있습니다.** 하나의 업무처럼 보였던 일이 실제로는 **성격이 다른 일곱 단계**입니다. 어떤 단계는 규칙이 명확하고, 어떤 단계는 판단이 필요합니다.<br><br>

### 🔥 활동 2 — 자동화 과제 정의서 작성
```plain text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
자동화 과제 정의서
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1] 대상 업무        매체별 광고 실적 취합 및 주간 성과보고 작성
[2] 수행 주기        매주 월요일
[3] 현재 소요 시간   약 4시간 / 주
[4] 관련 자료        매체사 실적 파일 5~6종, 기준표 1종

───────────────────────────────────────
[5] 우선 추진 과제
───────────────────────────────────────

  2·3단계 — 형식 통일 및 데이터 취합 자동화

  선정 근거
  - 반복과 오류가 동시에 발생하는 구간
  - 전체 소요 시간의 약 절반을 차지
  - 입력 파일이 매주 확보됨
  - 출력 형태가 표로 명확히 정해져 있음

───────────────────────────────────────
[6] 입력 · 처리 · 출력
───────────────────────────────────────

  입력   매체사별 실적 파일 (엑셀·CSV, 5~6개)
         컬럼 기준표 (사내 문서 1종)

  처리   파일 유형 판별 → 컬럼명 표준화 → 단위·날짜 형식 통일
         → 결측·중복 처리 → 하나의 표로 통합

  출력   통합 실적 표 1종 (정해진 컬럼 구조)
         처리 결과 요약 (처리 건수, 오류 건수, 확인 필요 항목)

───────────────────────────────────────
[7] 사람의 확인 지점
───────────────────────────────────────

  - 결측·이상 데이터 발견 시        → 처리 전 확인 요청
  - 신규 매체사 파일 유입 시        → 컬럼 매핑 확인
  - 통합 완료 후                    → 담당자 검수 후 다음 단계

───────────────────────────────────────
[8] 성공 기준 (숫자로)
───────────────────────────────────────

  - 파일 5개를 한 번에 처리해 통합 표 생성
  - 컬럼 불일치가 있어도 기준표에 따라 매핑
  - 결측·중복 항목이 별도 목록으로 표시
  - 처리 시간 4시간 → 1시간 이내

───────────────────────────────────────
[9] 최소 완성 범위
───────────────────────────────────────

  입력 2종 → 처리 → 검증 → 결과물 1종
  (정상 흐름 1회 + 예외 상황 1회 테스트)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
> **주의** — **아홉 개 항목 중 셋이 특히 중요합니다.**
**\[6\]** 흐릿하면 뒤가 전부 흐릿해집니다. "실적 파일"이 아니라 "엑셀·CSV, 5\~6개, 컬럼 구조 상이"까지 씁니다.
**\[7\]** 비워 두면 나중에 사고가 납니다. 앞에서 다룬 승인 지점 설계가 여기 들어옵니다.
**\[9\]** 어디까지 되면 성공인지 미리 정하는 칸입니다. 없으면 끝없이 손보게 됩니다.
**✅ 과제 검수 3초 체크**
- [ ] 매주 또는 매월 반복됩니까
- [ ] 입력 파일이 실제로 존재합니까
- [ ] 결과물 형식이 정해져 있습니까
셋 다 예가 나와야 통과입니다. 특히 **입력 자료가 없으면** 자동화 이전에 자료를 만드는 일이 선행 과제입니다.
> **워크시트에 적어두기** — 완성한 자동화 과제 정의서를 저장하세요. **\[6\] 입력·처리·출력**은 3권 데이터 설계의 재료가 되고, **\[7\] 확인 지점**은 4권 Agent 설계서의 승인 지점이 되며, **\[8\] 성공 기준**은 5권 테스트 케이스가 됩니다.

### 📌 2권 핵심 정리
① **\[원리 셋\]** 자동화는 빨리 하는 것이 아니라 **사람이 하던 단계를 없애는 것**이다. 도구보다 진단이 먼저다.
② **\[원리 넷\]** **반복되고, 규칙이 있고, 입력이 존재하는 일**만 자동화된다.
③ 방식은 생성형 AI · 워크플로 · Agent 셋이며, **하나를 고르는 게 아니라 단계마다 다르게 붙인다.**
④ AI는 그럴듯한 것을 만들기 때문에(원리 하나), **되돌릴 수 없는 지점 앞에 사람이 선다.**
⑤ 업무는 **Input–Process–Output**으로 쪼개고, **반복과 오류가 겹치는 단계**를 1순위로 잡는다. 대기 구간은 AI로 해결되지 않는다.
⑥ 성공 기준은 **반드시 숫자로** 쓴다. "빠르게" 대신 "4시간 → 1시간".
> **참고** — **여기까지 AI 도구는 하나도 쓰지 않았습니다.** 이 단계가 자동화의 절반이고, 이 절반을 건너뛴 자동화는 대부분 실패합니다. 3권에서는 이 과제를 실행하기 위해 **데이터와 지식이 어떤 상태여야 하는지**를 다룹니다.
