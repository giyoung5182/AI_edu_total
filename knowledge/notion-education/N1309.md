# [실습] 더미 데이터 생성 (10~20행)

정리일: 2026-10-08 · 교육 에셋 N1309

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설계한 입력 템플릿에 맞는 테스트 데이터를 ChatGPT로 생성합니다.
## 진행 단계
1. **프롬프트 입력** — 시뮬레이션 전문가 역할로 컬럼 구조(집행일자, 현장명, 공종, 계정, 예산금액, 집행금액, 집행상태, 초과사유, 후속상태, 작성자)와 조건(골조 초과율 약 40%, 토공·전기 15\~20%, 미조치 5건 이상, 탭 구분 출력)을 주고 더미 데이터 20행 요청
2. **엑셀 확인** — 생성된 데이터를 엑셀에 붙여넣고 입력 템플릿의 유효성 검사가 작동하는지 확인
