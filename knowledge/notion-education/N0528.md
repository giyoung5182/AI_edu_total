# 설계서를 AI에게 대신 쓰게 하기

정리일: 2026-10-08 · 교육 에셋 N0528

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
2부 클로드 대화창에 이어서 설계서 4블록 초안을 AI에게 쓰게 합니다.
## 진행 단계
1. **프롬프트 입력** — 아직 슬라이드는 만들지 말고 설계서 텍스트만 요청
- 입력할 내용:
```javascript
아래 자료를 읽고, 제안서 설계서 초안을 작성해 줘.
아직 슬라이드는 만들지 말고 설계서 텍스트만 줘.

설계서는 네 블록으로 구성해 줘.
블록 1 맥락: 개요, 유의사항 3개 이상, 최종 목적, 전체 흐름
블록 2 슬라이드 설계도: 각 장마다 분류 / 헤드메시지 / 내용 설명 / 시각 요소.
       표가 아니라 줄글로 서술해 줘
블록 3 디자인 규격: 색상 코드, 글꼴, 크기, 레이아웃 규칙
블록 4 산출 규칙: 말투, 사실 관계, 구성, 재량

조건
- 슬라이드는 총 9장
- 헤드메시지는 주제어가 아니라 결론이 담긴 완성 문장으로
- 6장은 위에서 제가 답한 딜레마 내용과 가치 키워드를 근거로 쓸 것
- 제가 주지 않은 수치·기관명·사례는 절대 추가하지 말고 [확인 필요]로 표시
- 출처가 있는 항목은 출처를 유지할 것
- 조사에서 "추측"으로 표기한 항목은 그 표기를 유지할 것
- 유의사항은 아래 제안서 종류와 대상의 특성을 근거로 직접 판단해서 써 줘

[제안서 종류] [받는 사람] [상대가 할 행동]
[3부 조사 정리표 — 출처 포함] [3부 조직이 지키는 것 세 가지]
```
1. **사람이 검토** — ① 유의사항 ② 헤드메시지만 순서대로 읽어 논리가 이어지는지 ③ \[확인 필요\] 표시 위치(자료 구멍)
## 막히는 지점
- 유의사항은 3개 이상 쓰기. 하나만 쓰면 AI가 그것만 과하게 반영
