# 젠스파크 AI Slides로 슬라이드 만들기

정리일: 2026-10-08 · 교육 에셋 N0502

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
젠스파크 AI Slides에 설계서를 넣어 9장 슬라이드를 만듭니다.
## 진행 단계
1. **들어가서 모드 정하기** — 젠스파크 홈 → 오피스 스위트 → AI 슬라이드(또는 왼쪽 New → 오피스 스위트). 프롬프트를 쓰기 전에 상단 모드 세 개를 먼저 정함: Professional(제안서는 읽는 문서, Edit 모드 가능) / Guide Mode 켜기(목차 확인 후 진행) / Ultra(한 번에 잘 나오는 게 이득, 메시지당 100\~600 크레딧)
- 정상 화면: 선택된 쪽에 테두리가 생김. Standard에서는 무료 할당량 배너가 뜨고, Ultra로 바꾸면 사라짐(크레딧 사용 신호).
2. **Skills 둔러보기(3분)** — 왼쪽 사이드바 Skills에서 게시자·역할·출력으로 필터. 없어도 괜찮음(설계서가 구조를 정해 둔 상태).
3. **생성 요청**
- 입력할 내용:
```javascript
[작업 순서]

1) 위 설계서를 읽고 작업 계획을 먼저 알려 줘. 아직 슬라이드는 만들지 마.
2) 내가 확인하면 첫 번째 슬라이드만 만들고 내 승인을 기다려 줘.
3) 승인하면 나머지를 정확히 같은 스타일로 만들어 줘.
   폰트, 색, 여백, 레이아웃 구조를 동일하게.
4) 생성 후 [확인 필요]로 남긴 항목을 목록으로 정리해 줘.

[설계서]
(여기에 완성한 설계서 4블록을 붙여넣기)
```
- 이유: 2번과 3번이 크레딧 절약의 핵심. 첫 장이 마음에 안 들면 거기서 멈출 수 있음.
## 막히는 지점
- 모드는 프로젝트를 만든 뒤 변경 불가(바꾸려면 새 프로젝트)
- 기본값이 크리에이티브일 수 있으니 프로페셔널을 눌렀는지 확인
