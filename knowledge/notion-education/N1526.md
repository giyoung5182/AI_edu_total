# 실습 D — 내 앱 만들기

정리일: 2026-10-08 · 교육 에셋 N1526

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

## 이 실습으로 하는 것
설계서를 새 대화에 붙여넣고 첫 결과물을 받습니다.
## 진행 단계
1. **새 대화** — 설계 대화 말고 새로
2. **모델 확인** — Sonnet
3. **설계서 전체 붙여넣기**
4. **계획 확인** — Claude가 "이렇게 만들 계획입니다" 3\~4줄을 먼저 보여줌
5. **진행** — 방향이 맞으면 "좋아, 그렇게 만들어줘"
6. **첫 결과물 확인(10:40\~10:45)** — 화면 뜸, 핵심 동작, 한글 깨짐, 창 좁혔을 때 레이아웃
7. **안전벨트(10:45\~10:47)** — \[코드\] 탭 → 전체 복사 → 메모장 저장
## 막히는 지점
- 패널 안 열림 → 설정 확인 → `이걸 아티팩트로 만들어줘`
- 화면 하얗게 빔 → `화면이 비어 있어. 오류를 찾아서 고쳐줘`
- 설계와 다름 → 빠진 항목만 재요청
- 규모 과다 → `핵심 기능 하나만 남기고 나머지는 빼줘`
