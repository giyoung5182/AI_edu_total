# 예시: 블로그 글 작성 GPT 만들기

정리일: 2026-10-08 · 교육 에셋 N1241

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
"실습해보기 좋은 간단한 예시"로 제시된 블로그 작성 GPT를 System Prompt로 만들어 봅니다.
## 진행 단계
1. **요구사항 확인** — 자연스럽고 부드러운 문체, 800\~1200자, 제목 → 개요 → 본문(3\~4단락) → 결론 구조
2. **System Prompt 입력**
- 입력할 내용: "당신은 전문 블로그 작가입니다. 사용자가 입력한 주제를 기반으로 구조화된 블로그 글을 작성합니다." 외 규칙(제목·개요·본문·결론 순, 800\~1200자, 자연스럽고 부드러운 문체)과 출력 형식(Markdown)
3. **테스트 및 개선** — 역할 준수, 규칙 준수, 말투 일관성, 출력 형식 유지, 모호한 질문에 재질문하는지 확인
4. **배포** — 링크 공유 / 비공개 / 특정 사용자 / 전체 공개 중 선택
