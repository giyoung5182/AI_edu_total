# 직무별 단순 규칙 3가지 추가

정리일: 2026-10-08 · 교육 에셋 N0404

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
복잡한 계산 없이 '무엇을 자동으로 표시할지' 단순 규칙 3개를 본인 시스템 프롬프트에 추가합니다.
## 진행 단계
1. **규칙 1 · 원가 초과 위험 TOP 3 자동 추출** — 초과금액 또는 초과율 기준 상위 3건을 "긴급 조치 대상"으로 자동 표시
2. **규칙 2 · 영향도 3단계 체크** — 🔴 높음(다음 월 현금흐름 또는 총예산에 직접 영향) / 🟡 중간(공종 내 조정으로 일부 흡수 가능) / 🟢 낮음(월마감 보고 수준에서 관리 가능)
3. **규칙 3 · 이상치 자동 탐지(±10%)** — 집행률: 계획 대비 +10% 이상 차이 → "이상" 표시 / 지급 예정액: 월평균 대비 +10% 이상 초과 → "이상" 표시
4. **추가** — 위 3가지 규칙을 본인 시스템 프롬프트에 추가
