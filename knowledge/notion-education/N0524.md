---

## 이 실습으로 하는 것
오늘 만드는 모든 파일이 들어갈 coding 폴더를 만들고 Claude 앱에 연결합니다.
## 진행 단계
1. **폴더 생성** — 바탕화면에 `coding`. (어제 쓴 project 폴더와 다른 폴더)
2. **폴더 연결** — Claude 데스크톱 앱 → 상단 Code 탭 → 로컬 선택(클라우드 아님) → coding 폴더 지정.
3. **첫 응답** — `안녕? 지금 어떤 폴더에 연결돼 있어?` 입력. 폴더 경로를 답하면 준비 완료.
## 막히는 지점
- Code 탭이 안 보임: 로그인 계정이 교육용 계정인지 확인.
- 폴더를 골랐는데 파일이 안 보임: 로컬을 선택했는지 확인.
