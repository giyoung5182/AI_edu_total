# 실습. 공통 주제로 발표자료(PPT) 만들기 — 고객 클레임 현황 보고 (필수)

정리일: 2026-10-08 · 교육 에셋 N0459

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클레임이력 시트(18건)를 근거로, ChatGPT에 '숫자는 시트에서 직접 세고 확인 안 된 원인은 단정하지 말 것'이라는 조건을 붙여 5장짜리 발표자료(.pptx)를 받습니다.
## 진행 단계
1. **자료 확인** — ChatGPT 웹 → 왼쪽 사이드바 새 채팅. 입력창 왼쪽 + → 사진 및 파일 추가로 `01_출장실습데이터_통합.xlsx` 첨부. 어떻게 ppt를 만들지 구조를 구상
2. **설계도 초안 받기**
- 입력할 내용:
```plain text
첨부 파일의 클레임이력 시트(18건)로 경영진 보고용 발표자료를 만들고 싶어.
우선 설계도 부터 짤거야.
- 주제: 2026년 2~8월 기업고객 클레임 현황과 개선 과제
- 5장 구성: ① 한 줄 결론 ② 유형별·고객사별 건수 ③ 귀책 확인 상태(확인 완료 / 확인 중) ④ 재발 건과 주요 사례 ⑤ 개선 과제와 요청 사항
- 숫자는 시트에서 코드로 직접 센 값만 쓰고, 장마다 근거(사용한 열 이름·건수)를 발표자 노트에 적어줘.
- 귀책이 "확인 중"인 건은 원인을 단정하지 않는다.
- PowerPoint 파일(.pptx)로 만들어 내려받을 수 있게 해줘.
```
1. **장표 생성** — 그 설계도로 장표를 만들게 함
2. **수정** — 고치고 싶은 장이 있으면 같은 채팅에 "○장의 ○○를 ○○로 바꿔서 파일 다시 만들어줘" 한 줄 요청
- 파일 링크가 나오지 않고 글로만 답하면 "pptx 파일로 만들어줘"를 한 번 더 요청 \[확인 필요 — 교안 표기\]
- 디자인을 더 다듬고 싶으면 받은 내용을 Gamma에 붙여 넣어 다시 만들 수 있음(선택)
3. **확인** — 5장 파일을 내려받아 열었는지, 숫자가 시트 건수와 같은지(18건)
- 정상 결과: 유형(상품불만 5·예약오류 4·항공지연 4·정산오류 4·요금분쟁 1), 재발 1건 등 교안 표준 답변과 합계 일치
## 막히는 지점
- CL-2026-004 원인을 '예약 확정 메일 미발송'으로 단정
- 재발을 '2건 이상'으로 과장
- 건수 합계가 18이 아님
