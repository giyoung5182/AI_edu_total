# SKILL 만드는 방법 STEP 0~2 (폴더·SKILL.md 생성)

정리일: 2026-10-08 · 교육 에셋 N1133

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프로젝트 안에 설정 폴더와 스킬 폴더를 만들고 SKILL.md 파일을 작성합니다.
## 진행 단계
1. **STEP 0 · 설정 폴더 생성** — 프로젝트 또는 작업 환경 안에 설정 폴더(예: `.agents`)를 만들고 그 안에 `skills` 폴더를 만듭니다. 여러 SKILL을 구분해서 저장하는 공간입니다.
- 정상 결과: `.agents/` 아래 `skills/` 구조
2. **STEP 1 · 스킬(폴더) 생성** — 예시: \[business-report-writing\]
3. **STEP 2 · ****SKILL.md**** 파일 생성** — 해당 폴더에 SKILL.md를 만듭니다. 여러 스킬이 있으면 폴더별로 관리합니다.
4. **프론트매터 작성** — name(소문자·숫자·하이픈, 디렉터리 이름과 일치), description(무엇을 하는지·언제 쓰는지)
- 입력할 내용:
```markdown
---
name: business-report-writer
description: 사용자가 제공한 자료, 웹 링크, 문서, 메모 등을 바탕으로 경영진 보고용 보고서를 작성할 때 사용합니다. 핵심 내용을 빠르게 파악한 뒤, 의사결정에 필요한 관점으로 재구성하여 보고서 형태로 정리합니다.
---
```
1. **본문 작성(또는 AI에게 생성 요청)** — 역할·목적·작성 원칙·문체 가이드·출력 방식·금지 사항·최종 목표 순으로 본문 작성
- 입력할 내용(AI에게 요청):
```javascript
skill을 따로 만들어서 에이전트를 운영하고자 해.
skill 이름은 data-analyst이며, 엑셀파일을 분석가능한 데이터로 변환하여 EDA를 수행하는 skill을 생성하고자 해
```
