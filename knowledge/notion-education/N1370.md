# Step 04 :: 완성 기준으로 점검합니다

정리일: 2026-10-08 · 교육 에셋 N1370

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
결과물이 내가 세운 기준을 실제로 만족하는지 점검합니다.
## 진행 단계
1. **다섯 줄 대조** — ① 데이터가 표로 다 나온다(건수 확인) ② 요약 숫자가 실제 건수와 맞는가(직접 세기) ③ 빈 항목이 「미입력」으로 표시 ④ 지연 건이 별도 구분 ⑤ 좁은 화면에서도 표가 잘리지 않음(창 좁히기)
2. **한 건 손 검산** — 화면 숫자 하나를 원본 데이터와 대조합니다. 전체 건수가 데이터 개수와 같은가, 계산에 쓴 건수 + 제외한 건수 = 전체인가.
3. **경계값 넣기** — 아무것도 안 넣고 실행(안내 문구) / 0 / 음수 / 아주 큰 수 / 숫자 자리에 글자.
4. **실행으로 확인** — 「수정했고 문제없습니다」 대신 "초기화한 뒤 화면이 어떤 상태인지 적어줘" 등으로 요청합니다. 확인 안 된 항목은 「미확인」으로 남기고 마지막에 직접 눌러봅니다.
## 막히는 지점
- 기준을 못 맞추겠으면 명세서의 문장을 지금 화면에 맞게 고쳐 씁니다.
- 화면이 멈추거나 아무 반응이 없으면 그것이 문제입니다.
