## 이 실습으로 하는 것
한 문장으로 두 에이전트를 순서대로 돌려 작업과 검증이 이어지는 흐름을 확인함.
## 진행 단계
1. **실행 요청**
- 입력할 내용:
```javascript
media-merger로 01_원본 파일을 통합한 다음,
result-verifier로 결과를 점검해줘.
```
2. **확인** — 두 에이전트가 각각 호출되는가(화면에 이름이 뜸) / merger의 처리 과정이 메인 대화에 쏟아지지 않는가 / verifier가 파일을 수정하지 못하는가 / verifier가 실제로 산출물을 읽고 판단했는가.
- 참고: `@`를 입력하면 에이전트 목록이 떠서 특정 에이전트를 지목할 수 있음.
