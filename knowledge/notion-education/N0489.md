# STEP 1~6 · 에이전트(Claude 프로젝트) 만들기

정리일: 2026-10-08 · 교육 에셋 N0489

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
어떤 에이전트든 동일하게 적용되는 여섯 단계로 Claude 프로젝트 에이전트를 만듭니다.
## 진행 단계
1. **프로젝트 생성** — claude.ai 접속 → 왼쪽 사이드바 \[프로젝트\] → \[새 프로젝트\]. 이름은 '나의 비서, 테스트, 업무용'이 아니라 '회의록 정리, 정책문서 대조, 취업 준비'처럼 업무명 그대로 씁니다(무료 5개 한도).
2. **자료 등록** — `프로젝트 지식` 칸에 파일 업로드. 대외비·개인정보·미공개 수치·결재 전 문서는 등록 불가.
- 입력할 내용:
```javascript
등록된 문서의 목차를 알려줘
```
- 정상 결과: 등록한 문서의 목차가 나오면 판독 성공.
1. **설정 전문 입력** — `지시사항` 칸에 설정 전문을 복사해 붙여넣기(코드블록 우상단 복사 버튼).
2. **대괄호 교체** — `[대괄호]` 부분을 본인 상황으로 교체(교체하지 않아도 작동하나 결과 품질이 크게 떨어짐).
3. **시험 실행** — 실제 업무 전에 아래 세 가지로 설정 적용 여부 확인.
```javascript
너는 어떤 역할이고, 어떤 자료를 근거로 삼는지 요약해줘
```
```javascript
답변할 때 반드시 지켜야 하는 규칙을 나열해줘
```
```javascript
근거를 찾을 수 없는 숫자를 발견하면 어떻게 처리하는지 알려줘
```
- 정상 결과: 세 번째 질문의 답이 "삭제하고 보고한다"로 나와야 정상.
1. **설정 전문 별도 보관** — 프로젝트는 로그인 계정에 저장되어 계정 상실 시 함께 소멸하므로 완성한 설정 전문을 메모장 파일로 별도 보관. 동료에게도 프로젝트가 아니라 설정 전문 텍스트를 전달.
## 막히는 지점
- 설정을 무시함 → 지시사항 저장 여부 확인 후 재입력
- 자료를 참조하지 않음 → 목차 확인 후 형식 변환 재등록
- 대화가 길어지자 규칙 이탈 → 새 대화 시작(설정은 유지)
- 등록하지 않은 정보를 사용 → `[참조 규칙]` 블록 강화
- 지어낸 숫자 출현 → `[반드시 지킬 것]` 세 줄 추가
- 요청하지 않은 내용을 덧붙임 → `[하지 않을 것]` 블록 추가
