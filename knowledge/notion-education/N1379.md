# 5단계 직접 해보기: 본인 업무 웹앱 빌드·로컬 저장 검증

정리일: 2026-10-08 · 교육 에셋 N1379

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
더미 데이터를 재료로 본인 직무 웹앱을 만들고 PC에 저장해 더블클릭으로 열리는지 검증합니다.
## 진행 단계
1. **첫 버전 만들기** — 템플릿의 \[ \]를 본인 업무로 채웁니다.
```javascript
나는 교육기관 [부서/직무]야.
[무엇을 입력하면] → [무엇을 보여주는] 웹앱을 단일 HTML 파일로 만들어줘.
- 데이터는 아래 더미를 써줘 (붙여넣기)
- 입력 폼 / 계산 또는 차트 / 'HTML로 저장' 버튼 포함
- 한국어 UI, 깔끔한 디자인

[더미 데이터 붙여넣기]
```
2. **다듬기** — "숫자에 천 단위 콤마", "모바일에서도 잘 보이게", "결과를 표로도 보여줘" 같은 자연어로 두세 번 고칩니다.
3. **저장** — 'HTML로 저장' 버튼(또는 Canvas 다운로드)으로 PC에 저장합니다.
4. **검증** — 파일을 더블클릭해 인터넷 없이 브라우저에서 열리는지 확인합니다.
- 성공 기준: 단일 HTML 파일이 PC에 저장됨 / 더블클릭 시 인터넷 없이 열림 / 입력 → 결과가 작동함 / 더미 데이터로 의미 있는 결과가 나옴
## 막히는 지점
- 실제 고객사명·수주 금액·환자/임상 정보·미공개 수치는 입력하지 않습니다.
- 외부 공유나 업무 정식 사용 전에는 사내 보안·IT 정책을 확인합니다.
- AI가 만든 계산식은 한 케이스 직접 검산합니다.
