# 1부 — 워크시트 지도 가이드
---
## 수강생이 막히는 지점 TOP 5
### 막힘 1: STEP 1 업무 흐름이 너무 뭉뚱그려져 있음
**수강생이 쓰는 것:**
```plain text
① 광고 성과를 엑셀에 정리한다
```
**왜 문제인가:**<br>이렇게 쓰면 자동화 포인트가 보이지 않습니다. "정리한다" 안에 5\~6개의 동작이 숨어 있습니다.
**지도 방법:**
```plain text
"그 '정리한다'를 세분화해보세요.
 사이트에 들어가서 → 뭘 클릭하고 → 어디서 어디로 옮기나요?
 각 동작을 분리해서 써주세요."
```
**목표 수준:**
```plain text
① 광고주센터 접속
② 날짜 필터를 어제로 설정
③ 매장명 클릭 → 지표 확인
④ 수치 드래그해서 복사
⑤ 엑셀 파일 열기
⑥ 해당 매장 탭 클릭
⑦ 날짜에 맞는 행 찾기
⑧ 붙여넣기
```

### 막힘 2: 판단인지 규칙인지 구분을 못함
**수강생이 헷갈리는 것:**
```plain text
"매장을 선택하는 건 판단인가요 규칙인가요?"
```
**지도 방법 — 이 질문을 해주세요:**
```plain text
"새로 입사한 직원한테 이 동작을 설명서로 만들어서
 전달할 수 있어요? 설명서대로 하면 항상 같은 결과가 나오나요?"

→ 설명서 가능 = 규칙 = 자동화 가능
→ 설명서 불가 = 판단 = 자동화 불가
```
**자주 나오는 판단 케이스:**
```plain text
"발주량을 결정할 때" → 재고 상황, 행사 여부 고려 → 판단
"보고서 문장을 쓸 때" → 뉘앙스, 상사 취향 고려 → 판단
"카카오톡 내용 해석할 때" → 비정형, 맥락 필요 → 판단
```
**자주 나오는 규칙 케이스:**
```plain text
"입력한 값을 다른 시트에 옮길 때" → 항상 같음 → 규칙
"날짜에 맞는 열을 찾을 때" → 규칙 기반 → 규칙
"금액을 합산할 때" → 계산 규칙 → 규칙
"기준 이하이면 이메일 발송" → 조건 명확 → 규칙
```

### 막힘 3: 파일 구조를 어떻게 설계해야 할지 모름
**수강생이 막히는 것:**
```plain text
"시트를 몇 개 만들어야 해요? 어떻게 나눠요?"
```
**지도 방법 — 이 질문으로 풀어주세요:**
```plain text
질문 1: "지금 어디에 뭘 입력하세요?"
        → 그게 [입력 시트]

질문 2: "입력한 게 어디에 저장돼야 해요?"
        → 그게 [이력 시트]

질문 3: "나중에 어떤 형태로 보고 싶어요?"
        → 그게 [보고서 시트]
```
**입력 시트 설계 포인트:**
```plain text
"매번 바뀌는 정보"만 입력하게 합니다.
항상 같은 정보(담당자명, 부서명 등)는 드롭다운 또는 자동완성.
→ 사람이 입력하는 시간 최소화
```
---
### 막힘 4: STEP 6 프롬프트 작성이 막막함
**수강생이 하는 것:**
```plain text
"잘 모르겠어서 그냥 '업무 자동화해줘'라고 썼어요"
```
**지도 방법:**
```plain text
"STEP 1~5에 이미 다 썼어요. 그걸 Claude 말투로 정리하면 됩니다.

STEP 1 → [내 업무 상황] 섹션
STEP 4 → [파일 구조], [셀 구조] 섹션
STEP 1의 자동화 대상 + STEP 2 → [동작 순서] 섹션
STEP 5 → [트리거] 섹션

이렇게 4개 섹션에 넣으면 완성입니다."
```
---
### 막힘 5: 자동화 불가 부분에 좌절
**수강생이 하는 것:**
```plain text
"카카오톡 자동화가 안 된다고요? 그럼 아무것도 못 하는 거 아닌가요?"
```
**지도 방법:**
```plain text
"업무 전체를 자동화하려는 게 아닙니다.
비효율의 핵심 부분만 해결하면 됩니다.

예: 프로님
카카오톡 읽기 (10분) + 업무보고 작성 (20분) + 배포 (5분) = 35분
                              ↑                      ↑
                         자동화 가능             자동화 가능

카카오톡 읽기만 제외하고 나머지 25분을 자동화할 수 있습니다.
35분 → 10분으로 줄어드는 겁니다."
```

# 2부 — GAS 트러블슈팅 가이드
---
## 오류 유형별 대처법
---
### 오류 1: 메뉴 \[📋 지출결의서\]가 생기지 않음
**원인 A: F5 새로고침 안 함**
```plain text
해결: F5 눌러서 새로고침
```
**원인 B: onOpen 함수가 실행되지 않음**
```plain text
해결:
Apps Script 편집창 → 상단 함수 드롭다운에서 "onOpen" 선택
→ ▶ 실행 버튼 클릭
→ 권한 허용 팝업이 뜨면 허용
→ 구글 시트로 돌아와서 F5
```
**원인 C: 코드가 저장되지 않음**
```plain text
해결:
Apps Script 편집창에서 Ctrl+S 다시 저장
→ 저장 후 F5 새로고침
```
---
### 오류 2: 제출 버튼 클릭 시 "매장명을 선택해 주세요" 알림이 계속 나옴
**원인: 코드의 셀 주소와 실제 파일 셀 위치가 다름**
```plain text
확인 방법:
지출결의서 시트에서 매장명 드롭다운이 있는 셀 클릭
→ 왼쪽 상단 이름 상자에서 실제 셀 주소 확인 (예: C5)

코드에서:
const FORM = {
  매장명: 'B3',  ← 이 주소를 실제 주소(C5)로 수정
  ...
}
```
---
### 오류 3: 제출이력에 데이터가 엉뚱한 열에 들어감
**원인: 제출이력 헤더 순서와 코드 appendRow 순서 불일치**
```plain text
확인 방법:
제출이력 시트 1행 헤더 순서 확인
A: 제출일시 / B: 매장명 / C: 명의구분 ... N: 총액

코드에서:
dbSheet.appendRow([
  제출일시,   // A열
  매장명,     // B열
  ...
]);

헤더 순서와 appendRow 순서가 정확히 일치해야 함
```
---
### 오류 4: Cannot read properties of null (reading 'getRange')
**원인: 시트 이름이 코드와 다름**
```plain text
가장 흔한 원인:
const SHEET_FORM = '지출결의서';  ← 코드의 시트명
실제 탭 이름: '지출결의서 '  (뒤에 공백 있음)

또는:
실제 탭 이름: '지출결의서(폼)'  (괄호 포함)

해결:
실제 탭 이름을 클릭해서 정확한 이름 확인
코드의 시트명 상수를 실제 이름으로 수정
```
---
### 오류 5: 권한 허용 화면에서 "Google에서 확인하지 않은 앱" 경고
**이것은 오류가 아닙니다. 정상적인 과정입니다.**
```plain text
[고급] 클릭
→ [교육기관_지출결의서_자동화(으)로 이동] 클릭
→ [허용] 클릭
```
**수강생에게 설명:**
```plain text
"Google이 공식 검토한 앱이 아니라는 뜻입니다.
 본인이 직접 만든 코드이므로 안전하게 허용하셔도 됩니다.
 이 경고는 모든 개인 GAS 프로젝트에서 나타납니다."
```
---
### 오류 6: 팝업이 열리지 않음 (Apps Script 편집창이 안 열림)
**원인: 크롬 팝업 차단**
```plain text
해결:
주소창 오른쪽 끝 팝업 차단 아이콘(🚫) 클릭
→ [이 사이트의 팝업 항상 허용] 선택
→ 다시 [확장 프로그램] → [Apps Script] 클릭

아이콘이 안 보이면:
크롬 주소창에 chrome://settings/content/popups 입력
→ 허용 목록에 docs.google.com 추가
```
---
### 오류 7: 코드 붙여넣기 후 저장 시 "구문 오류"
**원인: 코드를 일부만 복사하거나, 복사 중 글자가 깨짐**
```plain text
해결:
기존 코드 전체 삭제 (Ctrl+A → Delete)
→ 코드 전체를 다시 처음부터 복사
→ 붙여넣기 (Ctrl+V)
→ 저장 (Ctrl+S)

주의: 부분 복사 금지. 반드시 전체 복사
```
---
### 오류 8: 제출이력에 데이터가 안 들어감 (오류 메시지 없음)
**원인: 내역 A열(내용)이 비어있어서 저장 조건 미충족**
```plain text
코드 로직:
A11~A19 중 내용이 있는 행만 저장
→ A열이 비어있으면 아무것도 저장 안 됨

해결:
지출결의서 시트 A11셀에 내용을 입력했는지 확인
I11셀(공급가)만 입력하고 A11셀(내용)을 빈 채로 두면 저장 안 됨
```
---
### 오류 9: 총액이 0으로 저장됨
**원인: 총액 열이 코드와 다름**
```plain text
현재 코드:
총액열: 'K'  ← K열이 총액

파일에서 실제 총액이 어느 열인지 확인
→ 코드 FORM.총액열 수정
```
---
### 오류 10: 타이머(트리거) 설정 후 자동 실행이 안 됨
**원인 A: 트리거가 저장되지 않음**
```plain text
해결: Apps Script → 트리거 메뉴에서 설정 내용 재확인
```
**원인 B: 권한이 허용되지 않음**
```plain text
트리거 실행에도 권한 허용 필요
함수를 수동으로 한 번 실행해서 권한 허용 후
트리거 설정
```
**원인 C: 시간대 설정**
```plain text
트리거는 구글 계정의 시간대 기준
한국 시간(KST = UTC+9)으로 설정되어 있는지 확인
구글 계정 → 설정 → 시간대: (UTC+09:00) Seoul
```
