# 자유 대시보드 구성하기

정리일: 2026-10-08 · 교육 에셋 N0451

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정해진 정답을 따라 만들지 않고, 실습 파일 하나를 골라 "내가 보고 싶은 업무 질문"을 정한 뒤 대시보드 구조를 직접 잡아봅니다.
## 진행 단계
1. **데이터 고르기** — 영업 거래처 / 생산설비 / 품질 실습 엑셀 중 하나만 선택합니다(1차 버전은 한 파일).
2. **업무 질문 하나 정하기** — 영업: 어떤 거래처를 먼저 챙겨야 할까? / 생산설비: 어떤 설비나 라인이 운영 리스크가 클까? / 품질: 어떤 공정이나 제품군에서 품질 이슈가 반복될까?
3. **대시보드 아이디어 고르기** — 1차 버전은 KPI 카드 3\~4개, 차트 2\~3개, 우선 확인 대상 표 1개, 필터 1\~2개면 충분합니다.
4. **Claude Code에게 설계만 요청**
```javascript
실습파일/[선택한 파일명].xlsx를 사용해서 대시보드 아이디어를 잡고 싶어.

아직 HTML 파일은 만들지 말고, 먼저 설계안만 제안해줘.
아래 항목을 포함해줘.
- 이 데이터로 답할 수 있는 업무 질문 3개
- 초보자가 만들기 쉬운 대시보드 주제 3개
- 각 주제별 KPI 카드 후보
- 각 주제별 차트 후보
- 표로 보여주면 좋은 항목
- 1차 버전에서 빼도 되는 요소

나는 아이디어를 보고 하나를 골라서 직접 만들어볼 거야.
```
5. **1차 대시보드 만들기**
```javascript
방금 제안한 주제 중 [선택한 주제]로 1차 HTML 대시보드를 만들어줘.

조건은 다음과 같아.
- 선택한 엑셀 파일 하나만 사용
- KPI 카드 3~4개
- 차트 2개
- 우선 확인 대상 표 1개
- 필터는 1~2개만
- 파일명은 my_dashboard.html
- 화면 아래에는 `내가 이 대시보드로 확인하려는 질문`을 2줄로 정리

먼저 단순하게 만들고, 나중에 수정할 수 있게 구성해줘.
```
6. **질문으로 고쳐보기** — KPI 하나 바꾸기 / 차트 하나 바꾸기 / 표 기준 바꾸기(Top 10) / 필터 하나 추가 / 메모 영역을 상황·리스크·다음 액션 3줄로 중 하나만 골라 수정합니다.
## 막히는 지점
- 처음부터 세 파일을 모두 합치려고 하지 말고 한 파일만 사용합니다.
- 숫자가 복잡하면 먼저 건수와 비율만 봅니다.
- 막힐 때 힌트: 영업은 계약단계·계약금액·계약확률·리스크요인·다음조치일, 생산설비는 가동률·수율·정지시간·점검결과·조치필요여부, 품질은 판정·결함유형·심각도·조치상태·공정·라인을 중심으로 봅니다.
