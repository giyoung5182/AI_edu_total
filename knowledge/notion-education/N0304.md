# 과제 선정 워크시트 (자동화할 업무 선정)

정리일: 2026-10-08 · 교육 에셋 N0304

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
워크시트 4문항에 답하며 자동화할 업무를 고르고, 2일차 웹 도구 제작을 위한 입력·계산·결과를 정리한다.
## 진행 단계
1. **반복 작업 떠올리기** — 매주 또는 매월 반드시 해야 하는 작업은 무엇인가.
2. **오래 걸리는 단계** — 그 작업에서 가장 시간이 오래 걸리는 단계는.
3. **입력 데이터** — Excel / 텍스트 / 이메일 등 어떤 형태인가.
4. **결과물** — 보고서 / 차트 / 대시보드 / 이메일 등 원하는 결과물은.
5. **세 가지 정리** — 뭘 입력하나 / 어떤 계산·변환이 필요한가 / 결과를 어떻게 보여 줄까.
- 입력할 내용:
```javascript
1. 매주 또는 매월 반드시 해야 하는 작업은 무엇인가?
2. 그 작업에서 가장 시간이 오래 걸리는 단계는?
3. 입력 데이터는 어떤 형태인가? (Excel / 텍스트 / 이메일 등)
4. 원하는 결과물은 무엇인가? (보고서 / 차트 / 대시보드 / 이메일 등)
```
## 막히는 지점
- 사내 시스템(ERP 등) 연동이 필요하거나 사내 기밀 정보를 활용해야 하는 아이디어는 어려울 수 있어 사내 담당자와 협의가 필요함
