# 실습 1 — 데이터 유형 선정 및 샘플 데이터 확인

정리일: 2026-10-08 · 교육 에셋 N1463

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
조별로 데이터 유형 하나를 고르고 샘플 데이터를 준비해 추출 항목과 보고서 방향을 합의합니다. (10분)
## 진행 단계
1. **유형 선택** — 송무팀 사건 처리 통계, 자문 의뢰 분야별 패턴, 팀 업무 시간 분석, 고객 만족도 데이터 중 가장 익숙하거나 실무와 가까운 유형을 고릅니다.
2. **샘플 데이터 복사** — 선택한 유형의 샘플(날짜 표기·구분자·누락값이 섞인 비정형 형태)을 교안에서 찾아 복사합니다.
3. **붙여넣기** — 샘플을 텍스트 편집기에 붙여넣어 준비합니다.
4. **30초 합의** — 우리 조가 추출할 핵심 항목(4\~5개)과 보고서 헤드라인 방향(어떤 인사이트 중심인지)을 정합니다.
## 막히는 지점
- 사내 기밀 데이터나 고객 개인정보는 외부 AI 서비스에 입력하지 않음. 실제 업무 데이터를 쓰려면 교안의 '나만의 샘플 데이터 만드는 방법'으로 가상 데이터로 변환
