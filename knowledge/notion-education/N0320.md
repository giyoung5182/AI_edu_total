# 실습 8 — 대시보드 제작

정리일: 2026-10-08 · 교육 에셋 N0320

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
ChatGPT로 시트의 CSV를 읽어 요약 카드·차트·지연 건 표를 그리는 단일 HTML 대시보드를 만든다.
## 진행 단계
1. **요청하기** — ChatGPT에 아래를 넣는다 (대괄호 안을 본인 상황에 맞게 바꾸기)
- 입력할 내용:
```javascript
아래 조건으로 단일 HTML 파일 대시보드를 만들어라.

[데이터 출처]
Google Sheets CSV 게시 URL:
[여기에 주소 붙여넣기]

[만들 화면]
상단: 요약 카드 4개 (전체건수 / 완료 / 진행중 / 지연)
중단: 좌측 상태별 도넛 차트 / 우측 부서별 가로 막대
하단: 지연 건 표 (경과일 내림차순, 7일 이상은 붉게)

[기술 조건]
- HTML 파일 하나로 완결 (CSS, JS 포함)
- CSV를 fetch로 읽어 화면을 그릴 것
- 로딩 중 표시와 오류 처리 포함
(이하 교안 참고)
```
2. **저장과 실행** — 받은 코드를 메모장에 붙여넣고 dashboard.html로(UTF-8) 저장해 브라우저로 연다
3. **하나씩 고치기** — 안 되면 증상별 요청문을 쓴다 (예: "화면에 아무것도 안 나온다. 콘솔 오류: \[붙여넣기\]")
4. **폴백(웹 게시가 안 될 때)** — 데이터를 HTML 안에 직접 넣어 외부 연결 없이 동작하게 요청하고, 발표 시 "현재는 데이터를 직접 넣었지만, 시트 연동으로 전환하면 자동 갱신됩니다"라고 설명
- 정상 결과: 대시보드가 데이터를 읽어 그림
## 막히는 지점
- 한 번에 완성되지 않음: 화면이 하얇다 / CSV를 못 불러옴(CORS) / 한글 깨짐(UTF-8) / 숫자가 이상함(쉼표 포함 숫자) / 차트 영역이 비어 있음
