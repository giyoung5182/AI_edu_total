# 기능 1: 요약 실습

정리일: 2026-10-08 · 교육 에셋 N1099

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
예시 예산 집행 일보를 ChatGPT에 붙여넣어 본부장이 30초 안에 파악할 수 있는 요약을 만듭니다.
## 진행 단계
1. **예시 데이터 붙여넣기** — 교안의 예시 데이터를 그대로 복사해 ChatGPT에 붙여넣습니다.
2. **프롬프트 실행**
- 입력할 내용:
```javascript
## 역할
당신은 건설 프로젝트 예산 집행 데이터 분석 전문가입니다.

## 입력 데이터
[위 예시 데이터 표 그대로 붙여넣기]

## 요청
위 예산 집행 일보 데이터를 다음 구조로 요약해줘.

## 요약 구조
1. 한 줄 요약 (정상 / 주의 / 초과)
2. 핵심 수치 (정상 건수, 초과 건수, 초과율)
3. 주요 발견사항 TOP 3
4. 긴급 조치 필요 항목

## 조건
- 본부장이 30초 안에 파악 가능한 수준
- 수치는 반드시 포함
```
