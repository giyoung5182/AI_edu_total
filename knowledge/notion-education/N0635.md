# 리라이팅 실습 3: 나만의 업무 프롬프트 만들기

정리일: 2026-10-08 · 교육 에셋 N0635

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
본인의 실제 업무 중 하나를 골라 3요소 프롬프트를 직접 작성하고 개선합니다.
## 진행 단계
1. **업무 선택** — 월간 원가 회의록 / 본부 보고 회의록, 현금흐름 검토 메일 / 지급 일정 조정 요청 메모, 예산 대비 집행률 분석 결과 요약, 미청구·미수 현황 정리, 주간/월간 업무 보고서, 비용 리스크 및 후속 조치 의견 정리 중 하나를 고릅니다.
2. **프롬프트 작성** — "## 역할"에 본인의 실제 직무, "## 맥락"에 실제 업무 상황, "## 출력 형식"에 실제로 작성하는 문서 구조를 넣습니다.
3. **ChatGPT에 입력하고 결과 확인**
4. **후속 요청으로 결과 개선**
5. **제출** — 완료된 프롬프트와 결과를 패들렛에 올립니다.
## 막히는 지점
- 교안에 별도 기재 없음. (원칙: 사내 기밀 데이터, 실제 프로젝트명, 내부 원가, 협력사 단가, 계좌·개인정보는 AI에 입력하지 않음)
