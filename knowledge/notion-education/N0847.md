### AI 글쓰기의 기본 원리
```plain text
보통 글쓰기:
무엇을 쓸지 생각 (20분) → 어떻게 시작할지 고민 (10분)
→ 초안 작성 (40분) → 수정 (20분) → 완성 (총 90분)

R.C.T.C로 프롬프트 작성 (5분) → AI 초안 생성 (1분)
```

```plain text
AI는 초안 작성자입니다.

"내가 직접 써도 될 것 같은데" 싶을 때까지 대화를 이어가세요.
```

### 3-2-3. 발산 먼저, 수렴 나중 — AI 이미지의 황금 원칙
AI 이미지 생성에서 가장 많이 하는 실수가 있습니다.
```plain text
❌ 흔한 실수:
처음부터 완벽한 이미지를 한 번에 만들려고 한다.
→ "이게 아닌데…" → "조금 수정해줘" → 반복
→ 처음 방향에서 벗어나지 못하고 60% 수준에서 멈춤

✅ 올바른 방법: 발산 먼저 → 수렴 나중

[발산 단계] 먼저 여러 방향을 넓게 탐색
→ "A안(따뜻한 느낌), B안(차분한 느낌), C안(밝은 느낌) 3가지 만들어줘"
→ 가장 마음에 드는 방향 선택

[수렴 단계] 선택된 방향을 단계적으로 정교화
→ 분위기 조정 → 색감 조정 → 세부 디테일 완성
→ 90%+ 품질 달성
```
> 연구 결과: 발산→수렴 방식을 쓴 사람은 처음부터 수정만 반복한 사람보다 수정 횟수가 절반, 창의성은 2배 높은 결과를 만들었습니다.
**핵심 원칙:**
```plain text
AI는 처음부터 완벽하지 않아도 됩니다.
발산으로 방향 잡고, 수렴으로 완성하는 것이 프로의 방식입니다.
```

### 3-2-4. 6요소 구조 프롬프트 — 이미지 생성의 표준 공식
[원본 이미지 제외]
글쓰기에 R.C.T.C 공식이 있듯, 이미지 생성에는 6요소 공식이 있습니다.
```plain text
[주제/대상] + [스타일] + [재질/소재] + [조명] + [구도] + [화질/용도]
```
이 6가지를 채울수록 원하는 이미지에 가까워집니다.
---
### 6요소 상세 가이드
**요소 1. 주제/대상 (Subject)**
```plain text
무엇을 그릴 것인가
예: 봄날 공원 / 책 읽는 할머니 / 꽃다발 / 가을 단풍길
```
**요소 2. 스타일 (Style)**
```plain text
어떤 분위기로 그릴 것인가
수채화 스타일 / 사진 느낌 (포토리얼리스틱) / 동화책 그림체 /
일러스트레이션 / 유화 느낌 / 수묵화 느낌
```
**요소 3. 재질/소재 (Material)**<br>이미지에 나오는 소재나 질감을 구체적으로 지정할수록 정확해집니다.

### 3-2-6. 60% → 90% 품질 높이기 — 체이닝 기법
첫 번째 이미지가 마음에 안 들어도 괜찮습니다.<br>AI 이미지도 글쓰기처럼 **이어서 수정 요청**하면 품질이 높아집니다.
```plain text
체이닝 원칙:
한 번에 1~2가지만 수정 요청
"전부 다시 만들어줘"는 방향을 잃음
3~5번 수정으로 90%+ 달성 가능
```
**체이닝 수정 요청 5가지 패턴:**
```plain text
[분위기 조정]
"전체 분위기를 더 따뜻하게 바꿔줘.
 나머지는 그대로 유지해줘."

[색감 조정]
"색감을 좀 더 따뜻한 톤으로 바꿔줘.
 구성은 그대로."

[밝기 조정]
"조금 더 밝고 화사하게 바꿔줘."

[세부 조정]
"꽃을 더 많이 추가해줘. 다른 건 유지."

[각도/구도 조정]
"같은 장면을 위에서 내려다보는 시점으로 다시 만들어줘."
```
**이미지 체이닝 4단계 예시 (발산→수렴):**
```plain text
STEP 1. 발산 — 방향 탐색
"봄날 공원 이미지를 3가지 다른 분위기로 만들어줘.
 A: 따뜻하고 포근한 느낌
 B: 밝고 활기찬 느낌
 C: 차분하고 서정적인 느낌"

→ 가장 마음에 드는 방향 선택 (예: B)

STEP 2. 수렴 1회 — 분위기 정교화
"B안 방향으로, 꽃이 더 많이 보이게 바꿔줘.
 밝기는 유지해줘."

STEP 3. 수렴 2회 — 색감 정교화
"색감을 좀 더 파스텔 톤으로 부드럽게 바꿔줘."

STEP 4. 수렴 3회 — 마무리
"왼쪽 아래 공간을 조금 더 여백 있게 만들어줘.
 텍스트 넣을 자리가 필요해."

→ 완성 (90%+ 품질)
```

## 자주 나오는 질문 (2부)
**Q1. 이미지에 한글이 깨지거나 이상하게 나와요.**
AI는 한글 텍스트를 이미지 안에 정확하게 넣지 못합니다. 이건 모든 AI의 공통 한계입니다.<br>해결책: 배경 이미지만 AI로 만들고, 텍스트는 캔바(canva.com)에서 별도로 추가하세요.
**Q2. 이미지가 처음엔 괜찮은데 수정할수록 이상해져요.**
한 번에 너무 많은 것을 수정 요청하면 AI가 방향을 잃습니다.<br>한 번에 1가지만 수정 요청하고, "나머지는 그대로 유지해줘"를 꼭 붙여주세요.
**Q3. AI 이미지를 SNS에 올려도 되나요?**
개인 용도(카카오톡, 개인 SNS)는 대체로 문제없습니다.<br>블로그 게재나 상업적 사용은 해당 AI 서비스의 이용약관을 먼저 확인하세요.
**Q4. 무료로 이미지를 만들 수 있나요?**
네, ChatGPT 무료 버전, Gemini 무료, 캔바 무료 버전 모두 이미지 생성이 가능합니다.<br>다만 무료 버전은 하루에 만들 수 있는 이미지 수가 제한됩니다.
**Q5. 실존 인물 사진을 넣고 분석하거나 변환해도 되나요?**
본인 사진은 괜찮습니다.<br>타인의 사진(특히 연예인, 공인)을 변환하거나 합성하는 것은 초상권 침해 가능성이 있으니 삼가세요.
