3. 중복 행: 응답번호가 중복되거나 전체 내용이 동일한 행은 뒤에 나온 것을 제외
4. 이상치: 주간 합계 60시간 초과 행은 분석에서 제외하되 별도 표시
5. 음수: 해당 셀을 결측으로 처리
6. 척도 범위 이탈: 해당 셀을 결측으로 처리
7. 결측: 평균 계산 시 제외 (0으로 채우지 말 것)

정리 결과를 먼저 보고하라.
- 제외한 행 수와 사유
- 수정한 셀 수와 내용

### 검증 — AI가 제대로 했는지 확인 ★
전처리를 시켰다고 끝이 아닙니다. **원리 하나 — AI는 그럴듯한 것을 말합니다.**
- [ ] 제외한 행 수와 사유를 밝혔는가
- [ ] 수정한 셀 내용을 구체적으로 보고했는가
- [ ] 결측을 0으로 채우지 않았는가
- [ ] 이상치를 지우지 않고 표시했는가
- [ ] 부서 개수가 실제와 맞는가

> **왜 이게 중요한가**
**병합 셀은 AI가 읽을 때 빈칸으로 들어옵니다.** 그러면 "이 행의 거래처가 어디인지" 알 수 없습니다.
**단위가 문자로 섞이면 계산이 안 됩니다.** `1.2M`은 숫자가 아니라 글자입니다.
**소계 행이 섞이면 합계를 두 번 더합니다.**
**겉보기엔 멀쩡한 표가 조용히 틀린 숫자를 만듭니다.**

## 6. ✅ 체크
- [ ] 5단계 점검 순서를 말할 수 있다
- [ ] 0과 공백의 차이를 설명할 수 있다
- [ ] 전처리 전 집계에서 부서가 몇 개로 갈라지는지 확인했다
- [ ] 전처리 후 순위가 바뀌는 것을 확인했다
- [ ] AI의 전처리 결과를 검증하는 항목을 안다
- [ ] 이상치를 지우지 말고 표시해야 하는 이유를 안다
---
## 7. 📌 핵심 정리
**① 5단계 점검 — 구조 → 결측 → 이상치 → 일관성 → 중복**<br>아래로 갈수록 발견하기 어렵습니다.
**② 0과 공백은 다르다**<br>결측을 0으로 채우면 평균이 왜곡됩니다.
**③ 이상치는 지우지 말고 표시한다**<br>진짜 특이 사례일 수 있습니다. 제외했다면 기준을 기록합니다.
**④ 표기 흔들림이 집계를 망친다**<br>사람 눈에는 같아 보입니다. 부서 하나가 둘이 됩니다.
**⑤ AI는 물어봐야 알려준다**<br>먼저 "이 데이터 더럽습니다"라고 말해주지 않습니다.
**⑥ 한 행에 하나의 기록**<br>사람이 읽기 좋은 표와 AI가 읽기 좋은 표는 다릅니다.
