# 1️⃣ Genspark AI Developer 프로젝트 구성

**Genspark AI Developer**는 자연어로 원하는 기능과 화면을 설명하면 **입력→처리→출력 구조의 웹 시스템**을 만들어주는 구현 도구입니다.
이번 교육에서 Genspark는 리서치 도구가 아니라, 5차시 기획안을 실제 작동하는 MVP로 옮기는 역할로 사용합니다.

---
### 시작하기

**Step 1.** genspark.ai 접속 후 로그인
**Step 2.** 5차시 기획안 준비 (문제 정의 / 입력 데이터 3종 / 출력 형태 / 성공 기준)
**Step 3.** Genspark AI Developer에 아래 프롬프트로 시스템 구조 설계
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 업무 자동화 시스템 기획자입니다.

## 맥락
교육기관 예산·원가 담당자가 쓸 자동화 시스템을 만듭니다.
- 문제 정의: [5차시 확정]
- 입력 데이터: [5차시 설계한 3종]
- 출력물: [5차시 결정한 형태]

## 요청
이 시스템의 입력/처리/출력 구조를 정리해줘.

## 출력 형식
### 1. 입력
- 수집 방법
- 필수 필드

### 2. 처리
- 분석 단계 (순서대로)
- 핵심 판단 기준

### 3. 출력
- 결과물 형태
- 자동 생성 항목
```
**결과를 본인 기획안과 비교하고 구현 방향을 확정하세요.**

### 기능 1: 요약

**\[실습\] 위 예시 데이터를 그대로 ChatGPT에 붙여넣고 아래 프롬프트 실행**
```markdown
## 역할
당신은 건설 프로젝트 예산 집행 데이터 분석 전문가입니다.

## 입력 데이터
[위 예시 데이터 표 그대로 붙여넣기]

## 요청
위 예산 집행 일보 데이터를 다음 구조로 요약해줘.

## 요약 구조
1. 한 줄 요약 (정상 / 주의 / 초과)
2. 핵심 수치 (정상 건수, 초과 건수, 초과율)
3. 주요 발견사항 TOP 3
4. 긴급 조치 필요 항목

## 조건
- 본부장이 30초 안에 파악 가능한 수준
- 수치는 반드시 포함
```
**결과 확인**: B현장 골조 공종 초과 집중과 단가상승 반복 패턴이 잡혔는지?


**요약 핵심**: 한 줄 요약 + 핵심 수치 + TOP 3. 30초 안에 파악되는 분량으로 제한.

---
### 기능 2: 분류

**\[실습\] 같은 예시 데이터로 분류 프롬프트 실행**
```markdown
## 역할
당신은 건설 프로젝트 원가 초과 원인 분류 전문가입니다.

## 입력 데이터
[위 예시 데이터]

## 요청
초과 항목을 다음 분류 체계로 자동 분류해줘.

## 분류 체계
### 원인별
- 단가상승 / 물량증가 / 공정변경 / 기성조정

### 영향도
- 🔴 높음 / 🟡 중간 / 🟢 낮음

## 출력 형식
| 현장명 | 공종 | 초과일수 | 원인 | 영향도 | 후속 대책 |
```
**결과 확인**: 단가상승 3건 / 물량증가 1건 / 공정변경 1건으로 분류되는지?


**분류 핵심**: 원인 + 영향도 2차원. 어떻게 행동할지가 한눈에 보임.

---
### 기능 3: 액션추천

**\[실습\] 위 분류 결과를 바탕으로 액션추천 프롬프트 실행**
```markdown
## 역할
당신은 비용·집행 의사결정 지원 전문가입니다.

## 입력
[요약 결과 + 분류 결과]

## 요청
위 분석을 바탕으로 후속 대책을 추천해줘.

## 출력 구조
### 즉시 조치 (48시간 이내)
| 조치 | 대상 | 담당 | 완료 기한 |

### 금주 만회 (이번 주)
| 만회 항목 | 대상 | 투입 자원 | 예상 회복일 |

## 조건
- 우선순위 (예산 초과 영향 큰 순)
- 투입 자원(검토 시간/담당 부서/추가 승인 필요 여부) 명시
```
**결과 확인**: B현장 골조 단가상승 원인 확인 + 지급 예정 금액 재검토 같은 구체적 대책이 나오는지?


**액션추천 핵심**: 즉시(48h) / 금주 2단계 시간축. 담당자·기한·자원 명시되어야 실행 가능.


**3가지 기능 흐름**
**요약**(지금 어때?) → **분류**(왜?) → **액션추천**(어떻게?)

- 예시 데이터 → 본인 데이터로 교체
- 분류 체계 → 본인 업무에 맞는 카테고리로 수정
- 출력 형식 → 본인이 평소 받는 보고서 형식으로 수정

# 3️⃣ 직무별 단순 규칙 3가지 & 결과물 포맷
### 직무별 단순 규칙 3가지

**아래 3가지 규칙을 본인 시스템 프롬프트에 추가하세요. 복잡한 점수 계산은 필요 없습니다.**
**규칙 1. 원가 초과 위험 TOP 3 자동 추출**
```markdown
초과금액 또는 초과율 기준 상위 3건을 "긴급 조치 대상"으로 자동 표시
```
**규칙 2. 영향도 3단계 체크**
```markdown
🔴 높음 (다음 월 현금흐름 또는 총예산에 직접 영향)
🟡 중간 (공종 내 조정으로 일부 흡수 가능)
🟢 낮음 (월마감 보고 수준에서 관리 가능)
```
**규칙 3. 이상치 자동 탐지 (±10%)**
```markdown
집행률: 계획 대비 +10% 이상 차이 → "이상" 표시
지급 예정액: 월평균 대비 +10% 이상 초과 → "이상" 표시
```


**핵심**: 복잡한 계산식 X. **"무엇을 자동으로 표시할지" 단순 규칙 3개**면 충분.

---
### 결과물 포맷 고정

**\[실습\] 보고서 템플릿 만들기**
```markdown
## 역할
당신은 건설 프로젝트 비용·집행 보고서 디자인 전문가입니다.

## 요청
예산·원가 자동화 시스템의 출력 보고서 템플릿을 만들어줘.

## 조건
- A4 1~2페이지
- 본부장이 30초 안에 파악 가능
- 다음 구성 포함:
  1. 헤더 (프로젝트명, 기준월)
  2. 한 줄 요약 (정상/주의/초과)
  3. 핵심 수치 (KPI 3~5개)
  4. 상세 분석 표 (초과 공종/원인/영향도)
  5. 후속 대책 (우선순위 3~5개)

## 출력
마크다운 형태의 템플릿
```
**이 템플릿을 고정 출력 포맷으로 확정하세요.**


**포맷 고정 이유**: 한 번 정해두면 매월 같은 구조의 결과물이 나옴. 비교 가능하고 시스템이 됨.

# 4️⃣ AI Developer로 MVP 시스템 만들기

**여기가 진짜 MVP를 만드는 단계입니다.**
지금까지 ChatGPT에서 프롬프트로 실험했던 **요약 / 분류 / 액션추천 + 단순 규칙 3개 + 보고서 포맷**을 **AI Developer**가 실제 작동하는 시스템으로 만들어줍니다.
AI Developer는 Genspark의 기능 중 하나로, **"이런 기능의 시스템 만들어줘"** 라고 자연어로 요청하면 실제 작동하는 웹 시스템을 자동으로 생성합니다. 코딩 지식 필요 없습니다.

---
### AI Developer 시작하기

**Step 1.** genspark.ai → 사이드바에서 **AI Developer** 선택
**Step 2.** 5차시 기획안 + 2\~3차시에서 만든 프롬프트 + 단순 규칙 3개 + 보고서 포맷을 정리해두기
**Step 3.** AI Developer에 아래 프롬프트로 시스템 생성 요청
```markdown
## 만들고 싶은 시스템
교육기관 예산·원가 담당자가 쓸 [본인 업무] 자동화 시스템

## 입력
- 데이터 형태: [엑셀 / CSV / 텍스트]
- 필수 컬럼: [컬럼 5~7개]
- 예시 데이터: [위 예시 데이터 또는 본인 데이터 15행]

## 처리 (3가지 기능)
1. 요약: [요약 프롬프트 그대로]
2. 분류: [분류 프롬프트 그대로]
3. 액션추천: [액션추천 프롬프트 그대로]

## 단순 규칙 3개
- 원가 초과 위험 TOP 3 자동 추출
- 영향도 3단계 (🔴/🟡/🟢)
- 이상치 자동 탐지 (계획 대비 ±10%)

## 결과물 형태
- [본인이 정한 출력 형태 선택]
  - 옵션 A. 데이터 업로드 → 분석 결과 대시보드
  - 옵션 B. 입력폼 → 자동 분석 결과 페이지
  - 옵션 C. 단순 보고서 자동 생성 페이지
- 보고서 템플릿: [위 보고서 포맷 그대로]

## 요청
위 사양으로 실제 작동하는 웹 시스템을 만들어줘.
한국어 인터페이스로, 본부장이 바로 쓸 수 있게.
```
**Step 4.** AI Developer가 시스템 생성 (보통 2\~5분 소요)
**Step 5.** 생성된 시스템 URL 확인 → 예시 데이터로 작동 테스트

---

**본인 업무로 적용하세요.**
- 입력 데이터를 본인 업무 데이터로 교체
- 결과물 형태(A/B/C)를 본인 업무에 맞게 선택
- 보고서 포맷을 본인이 평소 작성하는 형식에 맞춤
**팁:** 처음부터 완벽하게 만들려 하지 마세요. 일단 작동하는 게 핵심. 수정·개선은 그 다음에.


**핵심**: AI Developer가 만든 결과물은 실제 작동하는 웹 시스템. URL 받으면 본인 PC에서 바로 열어서 테스트 가능.

# 5️⃣ 1차 데모 테스트 & 오류 수정

**\[실습\] AI Developer가 만든 시스템에 예시 데이터를 넣어보기**
**Step 1.** 시스템 URL 열기
**Step 2.** 예시 데이터(또는 본인 데이터) 업로드/입력
**Step 3.** 3가지 기능(요약/분류/액션추천) 모두 작동하는지 확인
**Step 4.** 결과물이 예상한 보고서 형태로 나오는지 확인

---
### 결과 검증 체크리스트

- 요약 수치가 원본 데이터와 일치하는가?
- 분류 기준이 일관되게 적용되었는가?
- 액션추천이 실무에서 실행 가능한 수준인가?
- 단순 규칙 3개(TOP3 / 영향도 / 이상치)가 정확히 작동하는가?
- 보고서 포맷이 정한 템플릿과 일치하는가?

### 오류 수정 — AI Developer에게 추가 요청

**문제 발견 시 AI Developer에게 자연어로 수정 요청**
```markdown
방금 만든 시스템에서 다음 문제를 수정해줘:

1. [발견된 문제 1] → [원하는 수정]
2. [발견된 문제 2] → [원하는 수정]

수정된 시스템 URL을 다시 줘.
```
**"전부 다시 해줘" 대신 문제를 구체적으로 짚어야 정확히 수정됩니다.**
