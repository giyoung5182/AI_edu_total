# 4. MCP — Claude가 다른 도구를 쓰게 하기
## 4-1. 무엇인가
**Claude에게 손을 붙여주는 것**입니다.
지금 Claude Code는 **내 컴퓨터의 폴더**만 다룹니다. 노션에 있는 자료, 구글 드라이브에 있는 파일은 못 봅니다.
MCP를 연결하면 그것들도 다룹니다.
```plain text
연결 전   "노션에 있는 지도안 좀 정리해줘"
          → 못 함. 내가 복사해서 붙여넣어야 함

연결 후   "노션에 있는 3차시 지도안 읽고 정리해줘"
          → 직접 읽어옴
```
> 💡 **비유하면**<br>MCP는 **주방**을 주는 것입니다. 도구와 재료에 접근하게 해줍니다.<br>Skill은 **조리법**입니다. 그 도구로 무엇을 어떻게 할지 알려줍니다.<br>둘은 다른 층입니다. 주방이 있어도 조리법이 없으면 뭘 할지 모릅니다.
## 4-2. 사실 오늘 이미 쓰셨습니다
이름을 안 붙였을 뿐입니다.
```plain text
· GitHub에 올린 것
· Vercel로 배포한 것
· (부록) 구글 시트에 기록을 보낸 것
```
전부 **외부 서비스와 연결**한 것입니다.
## 4-3. 어떻게 켜나 — 쉬운 길
Claude 데스크톱 앱에는 **미리 준비된 연결**들이 있습니다. 목록에서 골라 켜기만 하면 됩니다.
```plain text
1. Claude 데스크톱 앱을 엽니다
2. 설정에서 커넥터(연결) 항목을 찾습니다
3. 목록에서 원하는 것을 고릅니다
4. "연결" 을 누르면 로그인 창이 뜹니다
5. 계정으로 로그인하고 권한을 허용합니다
```
> ⚠️ **메뉴 위치는 앱 버전에 따라 조금씩 다릅니다.**<br>못 찾으시면 Claude에게 이렇게 물어보세요.
```plain text
지금 내 앱에서 노션을 연결하려면 어디로 가야 해?
화면 순서대로 알려줘.
```
**강사에게 쓸모 있는 것들**





연결

무엇을 할 수 있나




**구글 드라이브**

드라이브의 지도안·자료를 직접 읽어 정리




**노션**

노션에 정리한 수업 계획을 읽고, 결과를 다시 씀




**브라우저 조작**

웹에서 자료를 찾아 모아옴


## 4-4. 목록에 없는 것을 붙이려면
목록에 없는 도구는 **직접 추가**해야 합니다. 설정 파일에 주소를 적는 방식입니다.
**이건 난이도가 있습니다.** 다만 방법이 있습니다 — **Claude에게 물어보는 것**입니다.
```plain text
[연결하고 싶은 도구의 주소]

이걸 내 Claude 데스크톱 앱에 연결하고 싶어.
설치하는 법을 단계별로 알려줘.
초등학교 선생님이 이해할 수 있게 쉽게 설명해줘.
```
> 💡 이 방식이 비개발자에게 가장 현실적입니다. 설명 문서를 해독하려 애쓰지 마세요.
## 4-5. 주의할 것
**① 권한을 좁게 주세요**
```plain text
❌ 구글 드라이브 전체
✅ 이번 학기 폴더만
```
전체를 열어주면 **느려지고**, 실수로 다른 자료를 건드릴 위험도 생깁니다.
**② 학생 개인정보가 있는 곳은 연결하지 마세요**
```plain text
❌ 학생 명단이 있는 드라이브 폴더
❌ 평가 기록이 있는 시트
```
**③ 한 번에 여러 개 켜지 마세요**
연결이 많으면 Claude가 어떤 걸 쓸지 헷갈립니다. **필요한 것만** 켜세요.
**④ 학교 정책을 확인하세요**
학교 계정을 연결하실 때는 학교 정책을 먼저 확인하시는 게 안전합니다.

# 5. API — 내 결과물이 AI를 부르게 하기
## 5-1. 무엇인가
지금까지 만든 화면은 **정해진 대로만** 움직입니다.
```plain text
학생이 답을 넣음  →  미리 정해둔 정답과 비교  →  맞다/틀리다
```
API를 붙이면 **화면 안에서 AI가 판단**합니다.
```plain text
학생이 글을 씀  →  AI가 읽고 평가  →  "이 부분이 좋아요"
```
- \*"우리가 쓰는 Claude를 내 화면 안에 넣는 것"\*\*이라고 보시면 됩니다.
## 5-2. ⚠️⚠️ 가장 먼저 알아야 할 것 — 열쇠 문제
API를 쓰려면 \*\*열쇠(API 키)\*\*를 발급받습니다. 이 열쇠로 요금이 청구됩니다.
> **이 열쇠를 화면 코드에 넣으면 절대 안 됩니다.**
웹 화면의 코드는 **누구나 열어볼 수 있습니다.** 열쇠도 같이 보입니다.
```plain text
누가 그 열쇠를 가져가면
   → 그 사람이 쓴 요금이 나에게 청구됩니다
   → 자동으로 대량 사용되면 하루에도 큰 금액이 나갈 수 있습니다
```
**실제로 자주 일어나는 사고입니다.**
> 🚨 Claude가 "간단하게 이렇게 하면 됩니다" 하면서<br>화면 코드에 열쇠를 넣는 방식을 제안할 수 있습니다.<br>**그 제안을 받아들이지 마세요.**
## 5-3. 안전한 방법 — 중간에 하나 두기
열쇠를 **내 화면이 아닌 곳**에 숨겨둡니다. 앞선 부록에서 쓴 **구글 Apps Script**가 그 자리를 합니다.
```plain text
❌ 위험
   학생 화면 [열쇠 있음] ────→ AI
                                누구나 열쇠를 봄

✅ 안전
   학생 화면 [열쇠 없음] ──→ Apps Script [열쇠 보관] ──→ AI
                              여기는 학생이 못 봄
```
**Claude에게 요청할 때**
```plain text
AI에게 물어보는 기능을 붙이고 싶어.

단, API 키는 절대 화면 코드에 넣지 마.
구글 Apps Script를 중간에 두고, 키는 거기에만 보관하는 방식으로 만들어줘.

화면은 Apps Script에만 요청을 보내고,
Apps Script가 AI를 부르는 구조로 해줘.
```
> ⚠️ **이건 난이도가 있습니다.** 저장 기능을 먼저 붙여본 뒤에 시도하세요.
## 5-4. 요금 감각
**얼마나 나가는지 감을 가지고 계셔야 합니다.**
```plain text
· 한 번 물어볼 때마다 요금이 붙습니다
· 글이 길수록 더 나갑니다
· 학생 30명이 각자 다섯 번 물어보면 → 150번
```
**반드시 하실 것**
```plain text
□ 사용 한도를 미리 걸어두기 (넘으면 자동으로 멈추게)
□ 처음엔 아주 작게 시험해보기
□ 며칠 지켜보며 실제 금액을 확인하기
□ 학생에게 열기 전에 나 혼자 충분히 써보기
```
> ⚠️ **한도를 안 걸고 학생에게 열지 마세요.** 예상보다 훨씬 많이 나갈 수 있습니다.

# 6. 그래서 언제 무엇이 필요한가
```plain text
□ 내 컴퓨터 폴더로 충분하다              → 아무것도 필요 없음   ← 오늘
□ 노션·드라이브 자료를 자동으로 읽고 싶다  → MCP 연결
□ 결과를 어딘가에 쌓고 싶다              → 저장 (부록 참고)
□ 화면 안에서 AI가 판단해야 한다          → API (신중히)
□ 코드를 직접 고치고 싶다                → VS Code
```
## 순서
```plain text
① 오늘 배운 것으로 몇 개 만들어본다
② 불편한 게 생긴다
③ 그 불편을 해결하는 것만 하나 추가한다
④ 반복
```
**②번을 건너뛰지 마세요.** 불편을 겪기 전에 미리 붙이면 복잡하기만 합니다.

# 7. 정리
```plain text
① 오늘 한 것이 바이브 코딩이 맞다
② MCP는 Claude가 외부 도구를 쓰게 하는 것 (만드는 사람이 편해짐)
③ API는 내 결과물이 외부를 부르는 것 (요금이 나감)
④ VS Code·터미널은 같은 도구의 다른 창일 뿐
⑤ API 키는 절대 화면 코드에 넣지 않는다
⑥ 대부분은 AI 없이도 된다
```
