## 이 실습으로 하는 것
아래 중 하나를 선택하거나 응용 프롬프트를 작성해, 질문을 바꾸면 결과가 어떻게 달라지는지 비교합니다.
## 진행 단계
1. **1단계. 선택 A/B/C 중 하나 선택**
- 선택 A (타겟 분위기): 타겟을 20대 후반 직장인에서 대학생으로 바꿔 다시 만들기 (더 친근하고 트렌디, 조금 더 밝은 색감, SNS 피드에서 눈에 띄게, 너무 고급스럽기만 하지 않게)
- 선택 B (브랜드 톤): 도시적이고 절제된 프리미엄에서 더 대중적이고 따뜻한 방향으로 (편안한 겨울 거리 배경, 더 밝고 부드러운 색감, 광고 카피 공간 유지)
- 선택 C (용도): 인스타그램 광고용에서 상세페이지 메인 배너용으로 (제품 실루엣이 더 잘 보이게, 문구보다 제품 중심, 더 단순한 배경, 프리미엄 톤 유지)
2. **2단계. 결과 비교** — 무엇을 바꾸었는가 / 분위기가 어떻게 달라졌는가 / 제품 존재감이 강해졌는가·약해졌는가 / 브랜드 톤이 더 맞아졌는가 / 실제 업무에 어디에 쓰기 좋을 것 같은가
