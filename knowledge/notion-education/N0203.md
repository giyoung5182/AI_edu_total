[시트 구조]

시트 1: 요청접수 (입력 폼)
  B4  요청부서
  B5  요청자
  B6  연락처
  B7  분류
  B8  제목
  B9  내용
  B10 희망완료일
  B11 긴급여부

시트 2: 처리이력 (1행 헤더, 2행부터 데이터)
  A 접수번호  B 접수일  C 요청부서  D 요청자  E 분류
  F 제목  G 희망완료일  H 긴급여부  I 담당부서
  J 담당자  K 상태  L 완료일  M 소요일

시트 3: 담당자매핑 (1행 헤더, 2행부터)
  A 분류  B 담당부서  C 1차 담당자  D 백업 담당자  E 표준 처리일

[할 일]
1. 요청접수의 값을 읽는다
2. 요청부서·요청자·분류·제목이 비어 있으면
   경고창을 띄우고 중단한다
3. 접수번호를 자동으로 매긴다
   형식: REQ-2026-순번 (처리이력의 마지막 번호 다음)
4. 담당자매핑에서 분류에 맞는 담당부서와 1차 담당자를 찾는다

5. 처리이력 마지막 행에 추가한다

6. 완료 후 "REQ-2026-0XX 접수되었습니다" 알림을 띄운다
7. 알림 확인 후 요청접수의 B4~B11을 비운다

[예외]
- 처리이력 시트가 없으면 "시트를 찾을 수 없습니다" 알림

<summary>완성 코드 보기 — 요청 제출 ▶ 막혔을 때만 여세요</summary>

**먼저 직접 요청해 보세요.**
이 코드는 ***15분 이상 막혔을 때*** 보는 용도입니다.

```plain text
const SS = SpreadsheetApp.getActiveSpreadsheet();

function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('업무요청')
    .addItem('요청 제출', '요청제출')
    .addItem('표기 정리', '표기정리')
    .addToUi();
}

function 요청제출() {
  const ui = SpreadsheetApp.getUi();
  const 입력 = SS.getSheetByName('요청접수');
  const 이력 = SS.getSheetByName('처리이력');
  const 매핑 = SS.getSheetByName('담당자매핑');

  if (!이력 || !매핑) {
    ui.alert('시트를 찾을 수 없습니다. 시트 이름을 확인하세요.');
    return;
  }

  // 1. 값 읽기
  const 부서   = 입력.getRange('B4').getValue();
  const 요청자 = 입력.getRange('B5').getValue();
  const 연락처 = 입력.getRange('B6').getValue();
  const 분류   = 입력.getRange('B7').getValue();
  const 제목   = 입력.getRange('B8').getValue();
  const 내용   = 입력.getRange('B9').getValue();
  const 희망일 = 입력.getRange('B10').getValue();
  const 긴급   = 입력.getRange('B11').getValue();

  // 2. 필수 항목 확인
  if (!부서 || !요청자 || !분류 || !제목) {
    ui.alert('요청부서·요청자·분류·제목은 반드시 입력해야 합니다.');
    return;
  }

  // 3. 접수번호 채번
  const 마지막 = 이력.getLastRow();
  let 순번 = 1;
  if (마지막 > 1) {
    const 이전 = 이력.getRange(마지막, 1).getValue().toString();
    순번 = parseInt(이전.split('-')[2]) + 1;
  }
  const 접수번호 = 'REQ-2026-' + ('00' + 순번).slice(-3);

  // 4. 담당자 조회
  const map = 매핑.getRange('A2:E7').getValues();
  const hit = map.find(r => r[0] === 분류);
  const 담당부서
= hit ? hit[1] : '확인 필요';
  const 담당자   = hit ? hit[2] : '확인 필요';

  // 5. 이력에 추가
  const 오늘 = Utilities.formatDate(new Date(), 'GMT+9', 'yyyy-MM-dd');
  이력.appendRow([
    접수번호, 오늘, 부서, 요청자, 분류, 제목,
    희망일, 긴급, 담당부서, 담당자, '진행중', '', ''
  ]);

  // 6~7. 알림 후 폼 비우기
  ui.alert(접수번호 + ' 접수되었습니다.\\n담당: ' + 담당부서 + ' ' + 담당자);
  입력.getRange('B4:B11').clearContent();
}
```
