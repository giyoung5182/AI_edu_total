# 실습 4 — 쿼리 병합과 정합성 검증

정리일: 2026-10-08 · 교육 에셋 N1053

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
민원 표에 지역 마스터의 지역명·담당부서를 붙이고, 앤티 조인으로 마스터에 없는 코드를 검사합니다.
## 진행 단계
1. **문제1: 왼쪽 외부 병합** — `complaints_2026.csv`와 `region_master.xlsx`(첫 행을 머리글로)를 각각 다음으로 로드 → 연결만 만들기. 데이터 탭 → 데이터 가져오기 → 쿼리 결합 → 병합. 위: complaints_2026 / 아래: region_master → 양쪽에서 지역코드 열 클릭 → 조인 종류 왼쪽 외부 → 확인 → 새 열 아이콘에서 지역명·담당부서만 체크 → 닫기 및 로드.
- 정상 결과: 총 120행 유지.
2. (직접 풀어보기) 병합 표 → 삽입 → 피벗테이블 → 행: 담당부서 / 값: 민원ID 개수.
3. **문제2: 앤티 조인 정합성 검증** — 문제1과 동일하게 병합하되 조인 종류만 왼쪽 앤티 선택 → 확인.
- 정상 결과: 0행(실습 데이터의 지역코드는 모두 마스터에 존재).
## 막히는 지점
- 0행이 나오는 것을 확인하는 것 자체가 품질 점검 업무입니다.
