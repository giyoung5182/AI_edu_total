# 실습 3. 정제 전 집계와 "AI가 쓴 기준 되묻기"

정리일: 2026-10-08 · 교육 에셋 N1375

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
부서 표기를 그대로 센 결과와 정제한 결과를 비교하고, AI가 적용한 집계 기준을 되물어 확인한다. (교안상 '향후 과제' 토글)
## 진행 단계
1. **정제 전 그대로 세기** — 부서 열을 합치지 않고 인원수를 센다
- 입력할 내용:
```javascript
업무시간실태조사 시트에서 부서 열의 값을 "있는 그대로"(공백·표기 차이를 합치지 말고) 구분해서 인원수를 세어라.
코드로 계산하라.
출력: 부서 표기 | 인원 | 표기에 공백이 있으면 공백 위치 표시
표 아래에 부서 표기 개수와 인원 합계를 적어라.
```
2. **결과 기록** — P3-3 "정제 전" 표에 기록
3. **AI가 쓴 기준 되묻기** — 대상 행 수·제외 행·빈칸 처리·표기 통합·번호 중복 행 5항목을 "새 계산은 하지 마라"는 조건으로 되묻는다 (이하 교안 참고)
4. **답 기록** — P3-3 "되묻기 답변" 칸, 특히 5번(번호 중복 행 처리) 확인
5. **표준 목록 정하기** — 워드에서 04 규정집 제3조(적용 범위)의 부서 이름을 확인해 비표준 표기를 표준 이름으로 매핑 (AI 없이)
6. **정제 후 재집계** — 매핑을 넣어 부서_표준 새 열을 만들고 원본 부서 열은 그대로 두며 다시 센다 (이하 교안 참고)
- 정상 결과: 정제 전·후 인원 합계가 같음 / 원본 부서 열 옆에 부서_표준 새 열이 생김
## 막히는 지점
- 정제 전 표에서 공백 표기가 이미 합쳐져 나옴 → 공백 제거 없이 원본 값 그대로 다시 세고 따옴표로 감싸 출력하도록 재요청
- 원본 열을 덮어씀 → 표준화 결과는 부서_표준 새 열에만 넣도록 요청
- 합계가 줄어듦 → 빠진 응답번호 목록을 보이게 요청
