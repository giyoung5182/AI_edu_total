# (참고) Make.com 오류 해결 기초 프롬프트

정리일: 2026-10-08 · 교육 에셋 N0868

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

> 막히면 아래 프롬프트를 복사해서 Claude 채팅창에 붙여넣으세요.<br>화면 캡처가 있으면 같이 붙여넣으면 됩니다.

## 기초 프롬프트 (복사해서 사용)
```plain text
나는 지금 Make.com으로 자동화를 만들고 있어.
아래 내용을 참고해서 문제를 해결해줘.

[내 시나리오 구성]
- 트리거: Google Sheets Watch New Rows
- 시트 파일: MAKE 실습 비즈머니 잔액
- 시트 이름: 잔액_입력
- 필터: B열(잔액) ≤ 500000
- 액션: Gmail Send an Email

[문제 상황]
(아래 중 해당하는 것 작성 또는 오류 내용 직접 붙여넣기)

□ 오류 메시지가 떴어 → 내용:
□ 모듈에 빨간 표시가 떴어 → 어느 모듈:
□ Run once 눌렀는데 아무 반응 없어
□ 이메일이 발송되지 않아
□ 필터가 작동하지 않는 것 같아
□ 기타:

[화면 캡처]
캡처가 있으면 이 아래에 붙여넣기

원인이 뭔지, 어떻게 해결하는지 단계별로 알려줘.
```
---
## 자주 나오는 오류 7가지
---
### 오류 1: "The module didn't return any new data"
```plain text
원인: Run once를 누른 후 시트에 새 행을 추가하지 않음

해결:
① Run once 클릭 → "Waiting for data..." 상태 유지
② 그 상태에서 구글 시트로 이동
③ 새 행 입력 → Enter
④ Make.com으로 돌아와서 확인
```
---
### 오류 2: "Connection expired"
```plain text
원인: 구글 계정 연결이 만료됨

해결:
① Connection 항목 옆 [Reauthorize connection] 클릭
② 구글 계정 선택 → 허용
③ 다시 Save
```
---
### 오류 3: 필터를 통과하지 않음 (Gmail에 0 표시)
```plain text
원인: 필터 연산자가 "Text operators"로 설정돼 있음
      → 숫자를 문자로 비교해서 조건 불일치

해결:
① 필터 설정 열기 (렌치 아이콘 클릭)
② 가운데 연산자 드롭다운 클릭
③ "Numeric operators: Less than or equal to" 선택
④ Save
```
---
### 오류 4: 이메일 Content 작성 시 변수 목록이 안 보임
```plain text
원인: Make.com이 아직 시트 데이터 구조를 모름
      → 한 번도 데이터가 흐른 적이 없는 상태

해결:
① Run once 먼저 실행
② 시트에 테스트 행 추가 → Enter
③ 데이터가 한 번 흐른 후
④ 이메일 모듈 다시 열기 → 변수 목록 나타남
```
---
### 오류 5: 이메일은 왔는데 본문에 값이 없음 (빈칸)
```plain text
원인: 변수 매핑이 안 된 것
      → 그냥 텍스트로 입력하면 값이 안 들어옴

해결:
① Gmail Content 필드에서 값 넣을 위치에 커서 놓기
② 오른쪽 변수 패널에서 해당 열 클릭
③ {{변수명}} 형태로 자동 삽입됨
④ 텍스트가 아닌 변수 블록으로 들어가야 함
```
---
### 오류 6: 시트 파일이 목록에 안 보임
```plain text
원인: 구글 드라이브에 xlsx 파일로 올라간 것
      → 구글 시트로 변환이 안 된 상태

해결:
① 드라이브에서 해당 파일 우클릭
② [연결 앱] → [Google Sheets]로 열기
③ 자동으로 구글 시트로 변환됨
④ Make.com에서 다시 파일 선택
```
---
### 오류 7: Row with headers 오류 또는 헤더 인식 문제
```plain text
원인: 헤더 범위가 실제 헤더 행과 다르게 설정됨

해결:
헤더가 1행에 있으면 → A1:D1 입력
헤더가 4행에 있으면 → A4:D4 입력
(실제 시트에서 헤더가 몇 행인지 먼저 확인)
```
---
## 오류 확인 방법
```plain text
방법 1: 모듈 위 숫자 클릭
  초록 숫자 = 성공
  빨간 숫자 = 오류 → 클릭하면 상세 내용 확인

방법 2: 왼쪽 메뉴 [History]
  빨간 항목 클릭 → 오류 메시지 전체 복사
  → Claude에 붙여넣기 → "이 오류 원인과 해결법 알려줘"

방법 3: 화면 캡처
  오류 화면 그대로 캡처
  → Claude 채팅창에 이미지 붙여넣기
  → 기초 프롬프트와 함께 전송
```
