# ② Projects 시연 — 프로젝트에 교안 넣고 질문하기

정리일: 2026-10-08 · 교육 에셋 N1534

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프로젝트에 교안 파일을 넣고, 그 안의 대화가 파일을 자동 참조하는 것을 확인한다.
## 진행 단계
1. **새 프로젝트** — 왼쪽 사이드바 → \[프로젝트\] → \[새 프로젝트\]
2. **이름 입력** — 이름: "초등 SW 수업"
3. **파일 업로드** — 교안 파일 업로드
4. **질문** — 프로젝트 안에서 새 대화를 열고 아래 입력
- 입력할 내용:
```plain text
이 교안에서 5학년한테 어려울 만한 개념 3개만 짚어주고,
각각 어떻게 쉽게 바꿀 수 있을지 알려줘
```
## 참고 (지침)
- 프로젝트마다 지침(Instructions)을 넣을 수 있으며 그 프로젝트 안 모든 대화에 자동 적용됨
```plain text
나는 초등 5~6학년 SW 강사다.
답변은 항상 학생 눈높이 예시를 포함하고,
전문용어를 쓸 때는 반드시 괄호에 쉬운 설명을 달아라.
학습 목표를 먼저 제시한 뒤 활동을 설명해라.
```
