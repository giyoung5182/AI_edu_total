## 이 실습으로 하는 것
설계한 입력 템플릿으로 정상·예외 케이스가 섞인 더미 테스트 데이터를 만든다.
## 진행 단계
1. **테스트 데이터 생성 요청**
- 입력할 내용:
```javascript
앞에서 설계한 [내 솔루션명] 입력 템플릿에 들어갈
현실적인 테스트 데이터 15~20행을 만들어줘.

조건:
- 실제 [직무] 업무에서 발생할 법한 내용으로
- 정상 케이스 70%, 이상/예외 케이스 30% 포함
- 이상 케이스 예시: 값 누락, 기준치 초과, 비정형 텍스트 포함

표 형식으로 출력하고, 마지막에 "이 데이터셋에 포함된 이상 케이스 목록"을 정리해줘.
```
