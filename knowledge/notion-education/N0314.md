# 디자인팀 파트 B. 내 이미지 비율 문제 직접 해결

## 이 실습으로 하는 것
가로 띠형 2D나 3D 맵 텍스처 등 특수 비율 이미지 문제를 3가지 해결법으로 실제로 해결합니다.
## 진행 단계
1. **해결법 선택** — 비율 기준(2:1 이하 / 2:1\~5:1 / 5:1 이상, 3D 맵 텍스처용은 평면 뷰 프롬프트)
2. **해결법 1** — 프롬프트에 비율과 용도를 함께 명시(배너·현수막형, 3D 맵 텍스처용 평면 뷰)
3. **해결법 2** — ChatGPT로 16:9 기본 이미지 → Firefly 생성형 채우기로 좌우 확장
4. **해결법 3** — STYLE LOCK으로 구역별 분할 생성 → 캔버스에서 5\~10% 겹쳐 배치 → Firefly로 이음새 보정
## 막히는 지점
- 조명 방향 일치, 2\~3단계 분할 확장.
