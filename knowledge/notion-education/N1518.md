# 내 업무에 맞는 작은 AI 업무 도구 만들기

정리일: 2026-10-08 · 교육 에셋 N1518

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
각자 업무에서 반복되는 일 하나를 골라 Claude Code와 질문을 주고받으며 brd.md, prd.md를 만들고 결과물을 하나 만든 뒤 패들렛에 공유합니다.
## 진행 단계
1. **줄이고 싶은 업무 고르기** — 보고서·메일 초안·체크리스트·파일 정리 등 내 업무를 줄일 수 있는 것이면 무엇이든 가능
2. **Claude Code에게 설명하고 인터뷰받기** — 아이디어가 안 떠오르면 Claude Code가 먼저 질문하게 함
- 입력할 내용:
```javascript
내 업무에 맞는 AI 업무 도구를 하나 만들고 싶습니다.

아직 어떤 주제를 잡아야 할지 확실하지 않습니다.

바로 코드를 만들지 말고,
먼저 나를 인터뷰해 주세요.

이후 내가 만들고자 하는 것이 SKILL / 웹서비스 중 뭐로 만드는 것이 좋은지 정의해주세요.

질문을 통해 아래 내용을 정리하고 싶습니다.

1. 내가 자주 반복하는 업무는 무엇인지
2. 그 업무에서 시간이 오래 걸리는 부분은 무엇인지
3. 어떤 자료를 자주 받는지
4. 어떤 결과물이 있으면 도움이 되는지
5. 사람이 반드시 다시 확인해야 하는 것은 무엇인지

질문은 한 번에 많이 하지 말고 하나씩 해 주세요.
```
1. **brd.md**** / ****prd.md**** 만들기** — brd.md(무엇을 만들지), prd.md(어떻게 만들지) 정리
2. **결과물 만들기** — 직무별 아이디어 보드(인사·교육, 에너지, 신사업 추진, 철강 전략·영업, 경영기획) 참고
3. **history.md**** 만들기** — 세션이 바뀔 때마다 입력
- 입력할 내용:
```javascript
history.md 파일을 생성해줘.
history.md 파일에는 여태까지 진행한 대화의 맥락이 포함되도록 해주어라.
```
1. **요약 이미지 만들기** — ChatGPT에 로그인 후 입력(평가 요소 아님)
- 입력할 내용:
```javascript
history.md 내용을 바탕으로
요약 이미지를 6컷 만화로 만들어 주세요.
```
1. **패들렛에 결과 공유**
