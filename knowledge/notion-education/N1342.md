# STEP 4 · 고치기

정리일: 2026-10-08 · 교육 에셋 N1342

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
처음 결과를 고쳐 학생에게 보여줄 만한 화면으로 만든다.
## 진행 단계
1. **오류가 났을 때**
```javascript
지금 이런 오류가 났어. 원인 확인하고 고쳐줘.
[오류 메시지를 그대로 붙여넣기]
```
2. **화면 다듬기** — 제목 크게 / 글자 키우기 / 항목 간격 / 배경 흰색·연한 색 / 중요한 부분 색 구분(번호 목록으로 요청)
3. **디자인 지침 파일(선택)** — design-md.zip을 받아 마음에 드는 디자인 지침을 작업 폴더에 넣고 "같은 폴더에 있는 디자인 지침 파일을 참고해서 색과 글꼴, 간격을 다시 잡아줘. 내용은 그대로 두고 보이는 것만 바꿔줘."
4. **내용 변경** — "활동 순서가 위에 오면 좋겠어. 준비물은 아래로 내려줘." (계획모드로 요청한 뒤 작업계획을 살피고 변경)
5. **2회 규칙** — 같은 문제를 두 번 고쳐도 안 되면: ① 요구사항을 바꾸거나 ② 새 세션을 열고 같은 폴더를 선택해 겪은 문제를 조건으로 넣어 다시 요청(만든 파일은 폴더에 남음)
6. **스스로 검사(여유 시)** — 기준(초3 낱말, 글자 크기, 휴대폰 화면 잘림)을 주고 스스로 검사·수정하게 하고 고친 내용도 알려달라고 요청
- 정상 결과: 브라우저에서 열었을 때 학생한테 보여줄 만하다 싶으면 OK
## 막히는 지점
- 오류 메시지는 요약하지 말고 그대로 복사해서 통째로 붙여넣기
- 같은 문제를 두 번 고쳐도 안 되면 그만 고치기(세션 오염)
- 디자인 요청에는 "내용은 그대로 두고"를 꼭 넣기
