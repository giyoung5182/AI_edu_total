# 동료 만들기. 면책 점검 에이전트 추가

정리일: 2026-10-08 · 교육 에셋 N1042

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
보상 검토 에이전트에 동료로 붙일 면책 점검 에이전트를 같은 방법으로 만듭니다.
## 진행 단계
1. **실습 폴더에서 Claude Code 실행** — 폴더 빈 공간을 오른쪽 클릭해 터미널을 열고 `claude`를 입력합니다.
2. **면책 점검 에이전트 브리핑** — 입력창에 프롬프트를 붙여넣고 엔터를 누릅니다.
- 입력할 내용:
```plain text
data 폴더의 사고 건들 중에서 면책 사유가 있는 건을 가려내는 면책 점검 서브에이전트를 .claude/agents/ 폴더에 만들어줘.
데이터 폴더의 사고 건들을 읽고, 면책 사유나 그 가능성이 있는 건만 골라 주의 정도가 높은 순으로 표로 정리하는 역할이야.
면책 신호 예: 음주운전, 무면허 운전, 고의 사고 의심, 사고 경위 불명확 등.
표 열은 사고번호 / 사고유형 / 면책 신호 / 주의 정도(높음/중간)로 하고, 면책 사유 없는 건은 넣지 마.
(이하 교안 참고)
```
1. **초안 보정** — 파일 생성 여부를 물으면 허용(1번 또는 엔터). 초안이 나오면 규칙만 덧붙입니다.
- 입력할 내용: 자료에 없는 내용은 추측하지 말고 '확인 필요'로 표시 / 최종 면책 결정은 내리지 말고 점검 관점의 주의 신호만 제시
2. **Claude Code 재시작** — `/exit`로 끄고(또는 Ctrl+C 두 번) 같은 폴더에서 다시 `claude`를 실행합니다.
