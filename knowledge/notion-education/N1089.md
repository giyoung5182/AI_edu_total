# 실습 2. 업무 6건 기능 선택 + AI에게 반박 받기 (보충)

정리일: 2026-10-08 · 교육 에셋 N1089

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
업무 6건에 대해 Chat·프로젝트·심층 리서치·Work 중 어디서 시작할지 먼저 스스로 고르고, AI에게 반박을 받아 내 기준을 점검한다.
## 진행 단계
1. **선택표 먼저 채우기** — 메모장에 6건 표(업무 / 내 선택 / 이유 한 줄)를 옮겨 적고 AI 답을 보기 전에 내 선택과 이유를 모두 채워 내 기준을 고정한다
- 업무 예: 고객 문의 메일 1통의 회신 초안 / 3주간 매주 반복할 출장 정산 검토 / 항공사 수하물 규정 변경을 여러 출처로 비교 / 사내 규정집의 취소 수수료 조항 1개 확인 / 정산 엑셀을 검토해 보고서와 발표자료까지 제작 / 팀원 3명과 몇 주간 공유할 고객사 응대 기준
2. **새 채팅 열기** — 왼쪽 사이드바 새 채팅 클릭
3. **검토 요청** — 아래 프롬프트의 \[선택\]·\[이유\]를 본인 표 내용으로 바꿔 붙여넣고 Enter
- 입력할 내용:
```plain text
나는 ChatGPT의 Chat, 프로젝트, 심층 리서치, Work 중 업무별로 어디서 시작할지 골랐어.
아래 선택을 검토해줘.

[내 선택]
1. 고객 문의 메일 1통의 회신 초안 → [선택] / 이유: [이유]
2. 3주간 매주 반복할 출장 정산 검토(같은 규정집·같은 양식) → [선택] / 이유: [이유]
3. 주요 항공사의 최근 수하물 규정 변경을 여러 출처로 비교 → [선택] / 이유: [이유]
4. 사내 규정집의 취소 수수료 조항 1개 확인 → [선택] / 이유: [이유]
5. 정산 엑셀 검토 후 보고서 문서와 발표자료까지 제작 → [선택] / 이유: [이유]
6. 팀원과 같은 자료·기준을 몇 주간 공유하는 고객사 응대 기준 → [선택] / 이유: [이유]

규칙:
- 항목마다 "동의" 또는 "이의" 중 하나로 판정하고, 이의가 있으면 대안과 이유를 한 줄로 적어줘.
- 판단 기준은 (1) 일이 이어지는 기간 (2) 결과물 개수 (3) 외부 조사 필요 여부 (4) 단계 수 네 가지만 써.
- 요금제·기능 제공 범위처럼 확실하지 않은 내용은 단정하지 말고 "확인 필요"로 표시해줘.
- 표로 답해줘: 번호 | 내 선택 | 판정 | 대안 | 이유
```
1. **판정 확인** — 답이 나오면 표의 판정 열만 먼저 훑어보고, 이의가 나온 항목 번호와 이의 이유가 네 가지 기준 중 무엇에 근거하는지, 요금제·기능 범위를 단정한 문장이 있는지 관찰한다
- 정상 결과: AI의 이의는 참고할 반박 의견. 네 가지 기준에 비춰 내 이유가 더 타당하면 내 선택 유지. 기능 제공 여부가 걸린 항목은 '화면에서 확인 필요'로 보류
2. **최종 선택 기록** — 메모장 표에 최종 선택 열을 추가해 내 선택 유지/변경 + 이유를 적는다 (2일차 Part 2·Part 3 시작 전에 다시 봄)
## 막히는 지점
- AI가 네 가지 기준 외의 이유로 판정함 → 아래 요청
```plain text
판정 기준은 기간, 결과물 개수, 외부 조사 필요 여부, 단계 수 네 가지로만 제한했어.
[번호] 항목의 판정을 이 네 가지 기준으로만 다시 설명해줘. 나머지 항목은 그대로 둬.
```
- 모든 항목에 '동의'만 나옴 → 새 채팅에서 같은 프롬프트 끝에 `동의하더라도 반대 선택이 더 나은 상황을 항목마다 하나씩 적어줘.` 한 줄 추가 후 재실행
