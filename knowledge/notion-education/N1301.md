# [실습] 내 업무용 매크로 만들기

정리일: 2026-10-08 · 교육 에셋 N1301

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
두 옵션 중 하나를 골라 직접 프롬프트를 작성해 나만의 VBA 매크로를 만들고 결과를 패들렛에 공유합니다.
## 진행 단계
1. **옵션 선택 및 실습 파일 열기**
- 옵션 A: 「현장별_집행률집계.xlsx」 — 현장별 예산 집행률을 자동 계산하고 초과 집행 현장을 별도로 정리하는 매크로
- 옵션 B: 「공종별_원가초과관리.xlsx」 — 공종별 초과 건수 집계, 미완료 항목 강조, 공종별 위험 점수 산출 매크로
2. **ChatGPT에 프롬프트 입력** — 직접 작성해 보고 교안의 예시 프롬프트와 비교합니다.
- 입력할 내용(옵션 A 예시):
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
건설 프로젝트 현장별 예산 집행률을 자동 집계하는 매크로를 만들어줘.

## 데이터 구조 ("집행데이터" 시트)
- A열: 집행일자
- B열: 현장명 (A현장, B현장, C현장)
- C열: 계획 예산
- D열: 실제 집행
- E열: 초과사유 (초과 시)

## 매크로 기능
1. 현장별 집행률 자동 계산 (실제 집행/계획 예산)
2. 초과 현장만 별도 시트에 정리
3. 현장별 집행률 차트 자동 생성

## 조건
- 매크로 이름: 집행률집계_자동화
- 한글 주석 포함
- 오류 시 메시지 박스 표시
```
- 입력할 내용(옵션 B 예시):
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
공종별 원가 초과 항목을 자동 관리하는 매크로를 만들어줘.

## 데이터 구조 ("초과항목" 시트)
- A열: 발생일자
- B열: 공종명
- C열: 초과유형 (물량증가/단가상승/공정변경/기타)
- D열: 초과 내용
- E열: 후속조치 완료 여부 (완료/미완료)

## 매크로 기능
1. 공종별 초과 건수 자동 집계
2. 미완료 항목 빨간색 강조
3. 공종별 위험 점수 산출 (물량증가 -1점, 공정변경 -3점, 단가상승 -5점)

## 조건
- 매크로 이름: 원가초과_관리
- 한글 주석 포함
```
3. **코드 붙여넣고 실행** — Alt+F11 → 모듈에 코드 붙여넣기 → Alt+F8 → 실행
4. **오류 발생 시** — 오류 메시지를 ChatGPT에 보내 디버깅
5. **저장·공유** — 결과 확인 후 .xlsm으로 저장하고, 완료된 매크로 실행 결과(스크린샷)를 패들렛에 공유합니다.
## 막히는 지점
- 오류 메시지를 그대로 ChatGPT에 붙여넣어 수정된 코드를 받음
- 저장은 반드시 .xlsm 형식
