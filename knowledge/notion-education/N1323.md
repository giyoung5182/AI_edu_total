# 실습 1. 내 계정 설정 3곳 점검 (보충)

정리일: 2026-10-08 · 교육 에셋 N1323

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
본인 ChatGPT 계정의 메모리·맞춤 지침·모델 개선 설정 상태를 설정 화면에서 직접 확인하고, AI의 자기 설명과 대조합니다.
## 진행 단계
1. **먼저 예측** — 메모장에 적기: 내 계정의 메모리는 켜져 있을까, 꺼져 있을까? 맞춤 지침에 무언가 적혀 있을까?
2. **설정 열기** — 화면 왼쪽 아래 본인 이름(프로필) 클릭 → 메뉴에서 설정 클릭. 위치·이름이 다르면 프로필 아이콘 근처의 톱니바퀴 모양 메뉴 사용 \[확인 필요\]
3. **메모리 확인** — 설정 창 왼쪽 목록에서 개인 맞춤 클릭 → 메모리 항목의 켜짐/꺼짐 확인
4. **메모리 관리** — 버튼이 있으면 클릭 → 저장된 항목 개수와 업무 관련 항목 유무만 확인. 지우거나 끄는 것은 본인 판단
5. **맞춤 지침 확인** — 같은 화면에서 맞춤 지침 입력칸에 적힌 내용 확인
6. **데이터 제어** — 왼쪽 목록에서 데이터 제어 클릭 → 모두를 위한 모델 개선 항목의 켜짐/꺼짐 확인
7. **AI에게 물어 대조** — 설정 창을 닫고 새 채팅에서 아래 프롬프트 입력
```javascript
지금 이 대화에서 네가 참고하고 있는 나에 대한 정보(메모리, 맞춤 지침 등)가 있다면 항목별로 그대로 보여줘.
없으면 "없음"이라고만 답해.
추측으로 채우지 말고, 확실하지 않은 항목은 "확인 불가"라고 적어줘.
```
- 관찰: 설정 상태와 AI 답이 맞는가, 기억 못 하는 항목이 나오는가
- 판정: 설정 화면이 기준, AI 답은 보조. 메뉴를 찾을 수 없으면 "메뉴 위치 확인 불가"로 기록(오답 아님)
8. **남길 것** — 메모장에 `메모리: 켜짐/꺼짐 · 저장 항목 유무 · 맞춤 지침: 있음/없음 · 모델 개선: 켜짐/꺼짐 · 점검 날짜`
## 막히는 지점
- 메뉴가 안 보임 → 프로필 아이콘을 차례로 눌러 설정 찾기. 그래도 없으면 강사에게 화면 보여 주기
- AI 답이 설정 화면과 다름 → 아래 요청으로 다시 확인
```javascript
설정 화면에서는 [메모리가 꺼져 있음 / 맞춤 지침이 비어 있음]으로 보여.
방금 답에서 이와 다른 부분이 어디서 나온 것인지 설명하고, 근거가 없으면 "근거 없음"으로 표시해줘.
```
