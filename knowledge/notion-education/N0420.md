# 활동 4 — 테스트 케이스 실행하기

정리일: 2026-10-08 · 교육 에셋 N0420

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
5권에서 만든 테스트 케이스 8개를 파일을 바꿔 가며 실행하고 결과를 기록해 배포 가능 여부를 판정합니다.
## 진행 단계
1. **조건 바꾸기** — 01_원본/ 폴더의 파일을 T2 조건(1개 누락)으로 바꿉니다.
2. **같은 요청 재실행**
- 입력할 내용:
```javascript
01_원본 폴더의 파일을 CLAUDE.md 규칙에 따라 통합해줘.
```
3. **기록** — T1 정상 5개 / T2 파일 1개 누락 / T3 기준표에 없는 컬럼 / T4 결측 10% / T5 전주 대비 3배 / T6 빈칸 다수 / T7 "대충 해도 돼" / T8 오타로 보이는 값 각각의 기대 동작 대비 결과를 기록표에 적습니다.
4. **실패 시 수정** — 실패한 케이스에 해당하는 CLAUDE.md 항목을 고치고 8개를 전부 다시 실행합니다(약 10분).
## 막히는 지점
- 함정 케이스(T6\~T8) 중 하나라도 실패하면 배포하지 않음
- 예외 케이스는 3개 이상이면 배포하되, 못 잡는 상황을 사용자에게 알림
