## ★ 직접 적기 귀찮을 때 — AI에게 대신 정리시키기
워크시트를 손으로 채우기 번거로우면, \*\*지금 실습을 도와주는 AI 채팅창(이 대화)\*\*에<br>그냥 말로 상황을 던지고 "워크시트 형식으로 정리해줘"라고 하면 됩니다.
### 방법 1 — 작업 로그 자동 정리
실습 중 한 일을 대충 말하고 정리를 부탁합니다.
```plain text
예시 프롬프트:
"오늘 한 거 정리해줘. GitHub 연동했고, Cursor로 클론했고, npm install에서
 PowerShell 오류 나서 정책 바꿔서 해결했고, localhost 8080에서 앱 떴어.
 → 이걸 '날짜 | 무엇을 | 도구 | 결과 | 다음할일' 표로 정리해줘."
```
### 방법 2 — 수정 포인트 분류·우선순위
고칠 것들을 두서없이 말하면 AI가 분류·정렬해줍니다.
```plain text
예시 프롬프트:
"내 앱에서 고칠 거: 삭제가 안 돼, 색상이 칙칙해, 새로고침하면 데이터 날아가,
 지점이 4개만 있어. → 이걸 유형(A데이터/B버그/C기능/D UI)이랑 우선순위(1~5)로
 분류하고, 각각 Lovable에서 할지 Cursor에서 할지, 요청 프롬프트 초안까지 만들어줘."
```
### 방법 3 — 데이터 연동 현황 진단
```plain text
예시 프롬프트:
"내 앱은 Lovable Cloud 쓰고, 데이터 입력하고 새로고침하니까 유지돼.
 근데 다른 기기선 확인 안 해봤어. 구글시트 연동은 아직 안 했고 하고 싶어.
 → 데이터 연동 현황을 워크시트 항목(저장방식/위치/검증1~3/보안/GAS필요)에
 맞춰 정리하고, 다음에 뭘 해야 하는지 알려줘."
```
### 방법 4 — 통째로 정리
```plain text
예시 프롬프트:
"지금까지 내 앱 진행상황을 워크시트 5개 시트(기본정보/작업로그/수정현황/
 데이터연동/Lovable할일) 형식에 맞춰 한 번에 정리해줘.
 [여기에 내 앱 상황을 아는 만큼 편하게 서술]"
```
> 💡 AI가 표로 정리해주면, 그걸 워크시트 해당 칸에 복사해 넣으면 됩니다.<br>"적는 것"보다 "판단하는 것"에 시간을 쓰는 게 낫습니다.
> ⚠️ 단, AI가 정리한 것도 **본인이 한 번 눈으로 확인**하세요. 특히 데이터<br>저장이 "진짜 되는지"는 AI 말이 아니라 실제 화면(F5, DB화면)으로 확인해야<br>합니다.
