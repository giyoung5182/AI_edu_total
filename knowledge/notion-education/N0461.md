# PART 03 :: 실습 자료 준비하기 (실습용 CSV 만들기)

정리일: 2026-10-08 · 교육 에셋 N0461

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
사내 자료를 가져오지 않고, 형태는 같고 내용만 가짜인 실습용 CSV 데이터를 만듭니다.
## 진행 단계
1. **내 자료 형태 구분** — ① 표 모음(CSV 30\~50건) / ② 표 + 양식 / ③ 문서·자료(10\~20건) / ④ 입력형(만들지 않음) 중 어느 쪽인지 고릅니다.
2. **CSV 생성 요청** — coding 폴더에 03_데이터.csv로 저장하도록 요청합니다.
- 입력할 내용(① 표 모음):
```plain text
coding 폴더에 03_데이터.csv 로 저장해줘.

조건이야.
- 40건 만들어줘
- 찫 줄은 열 이름
- 클라이언트명은 A사, B사 식으로
- 상태가 골고루 섞이게
- 이름이 30자쥐 되는 것도 두 건 넣어줘
- 값이 비어 있는 것도 세 건 넣어줘
- 숫자가 0인 것도 하나 넣어줘
- 한글이 안 깨지게 UTF-8로 저장해줘

만들고 나서 파일 경로와 총 건수를 알려줘.
(이하 교안 참고)
```
- ②는 "열에 출력 양식 항목이 전부 채워질 수 있도록" 조건을 더하고, ③은 15건으로 문서에서 뽑아낸 항목만 만들어 달라고 요청합니다.
1. **보완 요청** — 예: "전부 진행중으로만 되어 있어. 완료랑 지연도 섞어줘." / "40건 요청했는데 22건이야. 나머지도 같은 형식으로 채워줘."
2. **확인** — 03_데이터.csv가 보이는가 / 엑셀에서 한글이 안 깨지는가 / 건수가 맞는가 / 실제 클라이언트명이 없는가 / 극단값이 섞였는가 / 상태가 골고루 섞였는가를 점검합니다.
## 막히는 지점
- 건수를 눈으로 세지 말고 AI에게 "총 몇 건이야?"라고 물어 확인합니다.
- UTF-8 저장 요청을 빼먹지 마세요. 없으면 엑셀에서 한글이 깨집니다.
- 파일이 안 만들어지면 coding 폴더에 저장해 달라는 말이 요청에 들어갔는지 확인합니다.
