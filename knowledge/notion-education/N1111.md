# Step 03 :: 반복 작업을 Skill로 묶습니다

정리일: 2026-10-08 · 교육 에셋 N1111

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
skill-creator를 이용해 오늘 진행한 작업을 반복해서 쓸 수 있는 Skill 폴더로 묶습니다.
## 진행 단계
1. **skill-creator 요청** — 업무 데이터 → 보기 좋은 화면 → 브라우저 저장소 연결 상황에서 쓰는 Skill로 만들어 달라고 요청합니다.
- 입력할 내용: "skill-creator를 써서, 오늘 진행한 작업을 앞으로 반복해서 쓸 수 있는 Skill로 만들어줘." 뒤에 상황과 반드시 포함할 단계(명세 네 칸, 실습 데이터, 뼈대부터 쌓는 순서, 저장 검증 3단계, 한 건 손 검산)를 적음
2. **이름 규칙 확인** — 파일 이름은 정확히 SKILL.md, 폴더 이름은 영문 소문자와 붙임표만.
3. **자주 틀리는 것 항목 추가** — SKILL.md에 목록을 하나 만들어 둡니다.
4. **확인** — `방금 만든 Skill, 언제 쓰는 거야?`라고 물어봅니다.
## 막히는 지점
- Skill 등록 오류: 폴더 이름에 한글·공백·대문자가 없는지, 파일 이름이 SKILL.md인지 확인.
- Skill이 안 불림: 이름을 직접 부르고, 설명(description)을 더 구체적으로 고칩니다.
