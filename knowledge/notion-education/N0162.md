## \[0. 역할\]
너는 공공기관 사업설명회 자료를 10년 이상 설계해 온 기획 전문가다.<br>다음 세 가지를 원칙으로 삼는다.
1. 슬라이드 제목은 주제어가 아니라 결론이 담긴 완성 문장으로 쓴다.<br>청중이 제목만 읽어도 요점을 파악할 수 있어야 한다.
2. 제공되지 않은 수치·사실·사업명은 어떤 경우에도 만들어 내지 않는다.<br>모르는 것은 `[확인 필요]`로 남긴다.
3. 자료의 목적은 설명이 아니라 청중의 행동 유발이다.<br>각 장이 어떤 행동에 기여하는지 판단하며 구성한다.

## \[블록 1. 맥락\]
### 1-1. 개요
```plain text
자료명       2026년 중소기업육성자금 지원사업 설명회
주최         교육기관 33 기업지원부
일시         2026년 [○월 ○일 ○요일] [○시 ○분]
장소         [장소명] / [현장 · 온라인 · 병행]
발표 시간    30분 (질의응답 15분 별도)
발표자       기업지원부 [담당자명] 주무관
산출 형식    16:9 슬라이드 14장
```
### 1-2. 청중
```plain text
규모         도내 중소기업 대표 및 실무 담당자 약 60명
구성         제조업 약 [○]%, 서비스·유통업 약 [○]%, 기타 [○]%
사전 지식    본 사업 신청 경험 없음 약 55%
             작년 신청 경험 있음 약 30% (그중 일부는 탈락 경험)
             타 기관 정책자금 이용 경험 약 [○]%
연령·직위    50대 이상 대표 비중이 높음. 실무 담당자는 30~40대
관심사       실제로 우리 회사가 받을 수 있는가, 얼마나, 언제까지 준비해야 하는가
```
### 1-3. 유의사항
각 항목에 근거를 함께 적었다. AI가 판단할 때 이 근거를 참고하도록 한다.
```plain text
1  금융 용어를 풀어 쓸 것
   근거: 신청 경험 없는 기업이 절반 이상. "거치기간", "보증서 발급",
        "변동금리 연동" 같은 표현은 한 번 풀어 준 뒤 사용

2  작년 대비 변경점을 좌우 대비로 보여줄 것
   근거: 재신청 기업 약 30%가 작년 기준으로 판단할 위험.
        변경 항목에는 표시를 넣어 시선을 유도

3  서류 준비와 심사 일정에 슬라이드를 충분히 배분할 것
   근거: 작년 설명회 후 문의 전화가 이 두 항목에 집중.
        여기서 해결하면 담당자 업무 부담이 실제로 줄어듦

4  신청할 수 없는 경우를 명확히 제시할 것
   근거: 자격 미달 기업의 불필요한 신청을 줄이는 것도 이 설명회의 목적.
        접수 후 반려는 기관과 기업 양쪽의 손실

5  숫자는 크게, 조건은 표로 제시할 것
   근거: 50대 이상 참석자 비중이 높음. 작은 글씨의 줄글은 읽히지 않음

6  발표 자료만 보고도 판단이 가능해야 할 것
   근거: 현장에서 사진을 찍어 회사로 가져가 검토하는 경우가 많음.
        발표자의 구두 설명 없이도 내용이 성립해야 함
```
### 1-4. 최종 목적
```plain text
컨셉
오늘 듣고 오늘 준비를 시작할 수 있는 설명회

청중이 하게 될 행동 (우선순위 순)
1  자사가 지원 대상에 해당하는지 그 자리에서 판단
2  설명회 직후 신청 서류를 다운로드
3  준비에 오래 걸리는 서류를 먼저 발급 신청
4  애매한 경우 담당 부서에 사전 문의

이 자료가 실패했다고 볼 수 있는 상태
- 설명회 후 "우리가 되는지 안 되는지 모르겠다"는 문의가 다수 발생
- 자격 미달 기업이 신청 후 반려되는 사례가 작년과 동일 수준
```
### 1-5. 전체 흐름
```plain text
도입     3분   사업 개요와 올해 변경점 요약           슬라이드 1~3
본론 1  10분   지원 대상과 자격 요건, 지원 내용        슬라이드 4~7
본론 2  12분   신청 절차, 서류 준비, 심사 기준         슬라이드 8~12
마무리   5분   일정, 문의처, 다음 단계                슬라이드 13~14
```
### 1-6. 예상 질문
각 슬라이드가 아래 질문 중 어떤 것에 답하는지 의식하며 구성한다.
```plain text
- 우리 업종도 되나요
- 작년에 떨어졌는데 올해 다시 신청해도 되나요
- 다른 정책자금을 이미 받고 있는데 중복 신청이 되나요
- 서류 준비에 얼마나 걸리나요
- 언제 돈이 들어오나요
- 심사에서 뭘 가장 많이 보나요
```

전체 14장을 4개 섹션으로 구성한다.<br>각 장은 `분류 / 헤드메시지 / 내용 설명 / 작성 예시 / 시각 요소 / 발표자 노트` 여섯 항목으로 지정한다.

### SECTION 1. 도입 — 결론을 먼저 (슬라이드 1\~3)
**슬라이드 1. 표지**
```plain text
분류        표지
헤드메시지  2026년 중소기업육성자금, 올해는 이렇게 달라집니다
내용 설명   사업명과 주최 기관, 설명회 일자를 제시함.
            부제로 올해 변경점이 있다는 사실을 미리 알려 주의를 환기함.
            표지에서부터 "작년과 다르다"는 신호를 주는 것이 목적임.
작성 예시   상단 소제목: 교육기관 33 기업지원부
            대제목: 2026년 중소기업육성자금
            부제: 올해는 이렇게 달라집니다
            하단: 2026. [○]. [○]. 지원사업 설명회
시각 요소   배경 이미지 (별도 제작한 그래픽을 삽입할 예정이므로
            좌측 절반은 단색으로 비워 둘 것)
발표자 노트 첫 30초에 "작년과 세 가지가 바뀌었다"를 언급하여
            재신청 기업의 주의를 확보
```
**슬라이드 2. 한 장 요약**
```plain text
분류        요약
헤드메시지  도내 중소기업이면 업종 제한 없이 최대 [○]억 원까지
내용 설명   지원 규모, 대상, 신청 기간 세 가지를 한 장에 압축하여 제시함.
            이후 슬라이드가 이 내용의 상세 설명임을 명시하여
            청중이 전체 그림을 먼저 잡게 함.
            이 한 장만 사진으로 찍어 가도 핵심이 전달되어야 함.
작성 예시   좌측 카드: 최대 [○]억 원 / 지원 한도
            중앙 카드: 도내 중소기업 / 업종 제한 없음
            우측 카드: [○]월 [○]일까지 / 신청 마감
            하단 한 줄: 상세 내용은 이어지는 슬라이드에서 안내
시각 요소   숫자 강조 3분할 카드. 숫자는 본문의 3배 이상 크기로
발표자 노트 "이 장만 사진 찍으셔도 됩니다" 라고 안내하여
            청중의 필기 부담을 덜어 줌
```
**슬라이드 3. 올해 달라진 점**
```plain text
분류        변경 안내
헤드메시지  제외 업종 축소, 신청 절차 2단계로 간소화
내용 설명   작년과 올해를 좌우로 대비하여 제시함.
            재신청 기업이 기존 기억으로 판단하지 않도록
            변경된 항목에는 표시를 넣어 시선을 유도함.
            변경이 없는 항목도 함께 제시하여 "무엇이 그대로인지"를
            동시에 확인할 수 있게 함.
작성 예시   행 1: 제외 업종 / [작년 내용] → [올해 내용] / 변경
            행 2: 신청 절차 / 3단계 → 2단계 / 변경
            행 3: 지원 한도 / [확인 필요] / 변경
            행 4: 신청 자격 / 도내 소재 중소기업 / 동일
시각 요소   좌우 대비 표 (구분 / 작년 / 올해 / 변경 여부)
            변경 행은 강조색 배경, 동일 행은 무채색
발표자 노트 작년 탈락 기업 중 제외 업종 사유였던 곳은
            올해 다시 검토할 필요가 있음을 강조
```

### SECTION 2. 자격과 지원 내용 — 우리가 되는가 (슬라이드 4\~7)
**슬라이드 4. 지원 대상**
```plain text
분류        정보 전달
헤드메시지  도내 소재, 업종 제한 없음, 상시근로자 [○]인 이상
내용 설명   소재지, 업종, 기업 규모, 신용 요건 네 가지 기준을 제시함.
            각 기준마다 "무엇으로 판단하는가"를 함께 안내하여
            청중이 자사 서류를 떠올리며 즉시 대조할 수 있게 함.
            판단 방법이 곧 준비할 서류와 연결됨을 암시함.
작성 예시   행 1: 소재지 / 도내 본사 또는 사업장 / 사업자등록증
            행 2: 업종 / 제한 없음 (일부 제외 업종은 슬라이드 5) / 업종코드
            행 3: 기업 규모 / 상시근로자 [○]인 이상 / 4대보험 가입자명부
            행 4: 신용 / [확인 필요] / 신용조회 동의 필요
시각 요소   4열 표 (기준 / 요건 / 판단 방법 / 준비 서류)
발표자 노트 "지금 이 네 줄만 보고 우리가 되는지 판단됩니다" 라고 안내
```
**슬라이드 5. 신청할 수 없는 경우**
```plain text
분류        정보 전달
헤드메시지  세금 체납, 휴폐업, 기존 융자 연체 시 신청 불가
내용 설명   자격 미달 사유를 명확히 제시함.
            애매한 경우의 판단 기준과 사전 문의 방법을 함께 안내하여
            불확실한 상태로 신청하는 것을 막음.
            이 장의 목적은 탈락시키는 것이 아니라
            헛된 준비 비용을 줄이는 데 있음을 톤에 반영할 것.
작성 예시   카드 1: 세금 체납 / 국세·지방세 완납증명서로 확인
            카드 2: 휴업 또는 폐업 / 신청일 기준 사업 영위 중이어야 함
            카드 3: 기존 융자 연체 / [확인 필요]
            하단 박스: 애매한 경우 신청 전 [담당 부서]로 문의
시각 요소   아이콘 3개 카드. 아이콘은 미니멀 벡터 형태
            하단에 문의 안내 박스를 별도 배치
발표자 노트 "여기 해당되시면 오늘 준비 안 하셔도 됩니다.
            대신 해소 후 다음 회차에 신청 가능합니다"
```
**슬라이드 6. 지원 내용**
```plain text
분류        데이터
헤드메시지  기업 규모별로 한도와 금리가 다르게 적용됨
내용 설명   한도, 금리, 상환 조건을 기업 규모별로 구분하여 제시함.
            자사가 어느 구간에 속하는지 표에서 바로 찾을 수 있게
            구간 기준을 좌측 열에 먼저 배치함.
            금리는 변동 가능성이 있으므로 기준 시점을 함께 표기함.
작성 예시   행 1: [구분 기준 1] / 최대 [○]억 원 / 연 [○]%
            행 2: [구분 기준 2] / 최대 [○]억 원 / 연 [○]%
            행 3: [구분 기준 3] / [확인 필요] / [확인 필요]
            표 하단 각주: 금리는 [○년 ○월] 기준이며 변동될 수 있음
시각 요소   3열 표 (구분 / 한도 / 금리)
            표 아래에 상환 조건을 한 줄 요약으로 배치
발표자 노트 금리는 확정치가 아님을 반드시 구두로 한 번 더 언급
```
**슬라이드 7. 중복 지원 가능 여부**

## \[블록 4. 산출 규칙\]
### 4-1. 말투
```plain text
- 구어체 사용 금지. 종결어미를 최소화하고 개조식으로 작성할 것
- 예: "신청 절차는 다음과 같습니다" (X) / "신청 절차" (O)
- 예: "이 사업은 도내 중소기업을 지원합니다" (X)
     / "지원 대상: 도내 중소기업" (O)
- 다만 헤드메시지는 완성 문장으로 쓸 것
  (헤드메시지는 결론 전달이 목적이므로 예외)
- 감탄사, 이모티콘, 물음표를 사용하지 말 것
- "여러분", "우리" 같은 호칭을 슬라이드 본문에 쓰지 말 것
```
### 4-2. 사실 관계
```plain text
- 내가 제공하지 않은 수치·사실·사업명은 절대 추가하지 말 것
- 자료에 없는데 필요한 항목은 [확인 필요]로 표시할 것
- 담당자가 직접 채워야 하는 항목은 [담당자 작성 필요]로 표시할 것
- 금리, 한도, 일정, 배점은 반드시 제공된 공고문 내용만 사용할 것
- 추정·예상·전망은 자료에 근거가 있을 때만 서술할 것
- 통계나 사례를 인용할 경우 출처를 함께 표기하고,
  출처를 알 수 없으면 아예 넣지 말 것
```
### 4-3. 구성
```plain text
- 한 장에 두 가지 이상의 주제를 섞지 말 것
- 내용이 넘치면 억지로 넣지 말고 장을 분리할 것
- 장을 분리하거나 추가했다면 작업 후 별도로 보고할 것
- 섹션 구분을 유지하고, 섹션이 바뀌는 지점을 시각적으로 표시할 것
- 헤드메시지만 순서대로 읽었을 때 발표 전체의 논리가 이어지는지
  작성 후 스스로 점검할 것
```
### 4-4. 재량
```plain text
- 설계도는 가이드임. 전체 맥락상 필요한 내용이 있으면 추가해도 됨
- 지시대로만 따르지 말고, 빠진 부분이 있다고 판단되면 보완할 것
- 단, 추가한 내용은 반드시 작업 후 보고에 명시할 것
```
### 4-5. 작업 후 보고
작업이 끝나면 슬라이드와 별도로 아래를 텍스트로 정리해서 제시할 것.
```plain text
1  추가한 슬라이드와 그 이유
2  분리하거나 합친 슬라이드
3  설계도와 다르게 처리한 부분과 그 이유
4  [확인 필요] 항목 전체 목록
5  [담당자 작성 필요] 항목 전체 목록
6  헤드메시지만 순서대로 나열한 목록
   (논리 흐름을 사람이 검토할 수 있도록)
```
