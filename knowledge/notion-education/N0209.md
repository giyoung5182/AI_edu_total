```javascript
주간집계 시트에 표로 작성
```

### 요청하기
```javascript
같은 스크립트에 함수를 추가해줘.

[할 일]
처리이력 시트를 집계해 주간집계 시트에 쓴다.

1. 주간집계 시트를 비우고 새로 작성한다
2. 아래 항목을 집계한다

  [상태별]
  완료 / 진행중 / 보류 각각의 건수와 비율

  [소요일]
  완료 건의 평균·최대·최소 소요일
  단, 완료일이 비어 있는 건은 계산에서 제외하고
  "완료일 누락 N건"으로 별도 표시

  [부서별]
  요청부서별 건수 (많은 순)

  [분류별]
  분류별 건수 (많은 순)

  [지연]
  희망완료일이 오늘보다 이전인데
  상태가 완료가 아닌 건의 목록
  접수번호 | 요청부서 | 제목 | 희망완료일 | 경과일
  경과일 내림차순

3. 맨 위에 "집계일시"와 "대상 건수"를 표시한다

[예외]
- 처리이력이 비어 있으면 "데이터가 없습니다" 알림 후 중단
- 상태값이 완료/진행중/보류가 아닌 건은
  "확인 필요"로 별도 집계하고 건수를 표시
- 희망완료일이 비어 있는 건은 지연 판정에서 제외하고
  "기일 미정 N건"으로 표시

[서식]
- 제목은 굵게
- 지연 건 중 경과일 7일 이상은 배경색 주황

메뉴에 「주간 집계」 항목을 추가해줘.
```

<summary>완성 코드 보기 — 집계 + 알림 ▶ 막혔을 때만</summary>

**먼저 직접 요청해 보세요.** 이 코드는 막혔을 때 보는 용도입니다.

```plain text
const 수신자 = '[이메일 비공개]';   // ← 본인 메일로 바꾸세요

function 주간집계알림() {
  const 결과 = 주간집계();
  알림발송(결과);
  로그기록(결과);
}

function 주간집계() {
  const 이력 = SS.getSheetByName('처리이력');
  const 출력 = SS.getSheetByName('주간집계');
  const rows = 이력.getRange(2, 1, 이력.getLastRow() - 1, 13).getValues();

  if (rows.length === 0) {
    SpreadsheetApp.getUi().alert('데이터가 없습니다.');
    return null;
  }

  const 오늘 = new Date();
  const 상태별 = { '완료': 0, '진행중': 0, '보류': 0, '확인 필요': 0 };
  const 부서별 = {};
  const 지연 = [];
  let 소요합 = 0, 소요수 = 0, 완료일누락 = 0;

  rows.forEach(r => {
    const 부서
= String(r[2]).trim().replace('영업팀', '영업');
    const 상태 = String(r[10]).trim();

    // 상태별
    if (상태별.hasOwnProperty(상태)) 상태별[상태]++;
    else 상태별['확인 필요']++;

    // 부서별
    부서별[부서] = (부서별[부서] || 0) + 1;

    // 소요일 — 완료일 없으면 계산에서 제외
    if (상태 === '완료') {
      if (r[11]) { 소요합 += Number(r[12]) || 0; 소요수++; }
      else 완료일누락++;
    }

    // 지연 — 희망일 없으면 판정 제외
    if (상태 !== '완료' && r[6]) {
      const 희망 = new Date(r[6]);
      if (희망 < 오늘) {
        const 경과 = Math.floor((오늘 - 희망) / 86400000);
        지연.push([r[0], 부서, r[5], r[6], 경과]);
      }
    }
  });

  지연.sort((a, b) => b[4] - a[4]);

  // 출력
  출력.clear();
  출력.getRange('A1').setValue('주간 처리 현황')
        .setFontWeight('bold').setFontSize(14);
  출력.getRange('A2').setValue(
    '집계일시 ' + Utilities.formatDate(오늘, 'GMT+9', 'yyyy-MM-dd HH:mm')
    + '  |  대상 ' + rows.length + '건');

  let r = 4;
  출력.getRange(r, 1).setValue('상태별').setFontWeight('bold'); r++;
  Object.keys(상태별).forEach(k => {
    출력.getRange(r, 1).setValue(k);
    출력.getRange(r, 2).setValue(상태별[k]);
    r++;
  });

  r++;
  출력.getRange(r, 1).setValue('완료 건 평균 소요일').setFontWeight('bold');
  출력.getRange(r, 2).setValue(소요수 ? (소요합 / 소요수).toFixed(1) : '-');
  r++;
  출력.getRange(r, 1).setValue('완료일 누락 (계산 제외)');
  출력.getRange(r, 2).setValue(완료일누락);
  r += 2;

  출력.getRange(r, 1).setValue('지연 건').setFontWeight('bold'); r++;
  if (지연.length) {
    출력.getRange(r, 1, 1, 5)
          .setValues([['접수번호', '부서', '제목', '희망완료일', '경과일']])
          .setFontWeight('bold');
    r++;
    출력.getRange(r, 1, 지연.length, 5).setValues(지연);
    // 7일 이상 주황
    지연.forEach((d, i) => {
      if (d[4] >= 7)
        출력.getRange(r + i, 1, 1, 5).setBackground('#FDE8D5');
    });
  } else {
    출력.getRange(r, 1).setValue('없음');
  }

  return { 상태별, 지연, 완료일누락, 총건수: rows.length };
}

function 알림발송(결과) {
  if (!결과) return;

  // 발송 조건
  const 보내야하나 =
    결과.지연.length >= 1 ||
    결과.상태별['보류'] >= 5 ||
    결과.완료일누락 >= 3 ||
    결과.상태별['확인 필요'] >= 3;

  if (!보내야하나) {
    SpreadsheetApp.getUi()
      .alert('특이사항 없음. 메일을 보내지 않았습니다.');
    return;
  }

  let 본문 = '이번 주 업무요청 처리 현황입니다.\\n\\n';
  본문 += '전체 ' + 결과.총건수 + '건';
  본문 += ' (완료 ' + 결과.상태별['완료'];
  본문 += ' / 진행중 ' + 결과.상태별['진행중'];
  본문 += ' / 보류 ' + 결과.상태별['보류'] + ')\\n\\n';

  if (결과.지연.length) {
    본문 += '[지연 건]\\n';
    결과.지연.forEach(d => {
      본문 += d[0] + ' | ' + d[1] + ' | ' + d[2] + ' | ' + d[4] + '일 경과\\n';
    });
    본문 += '\\n※ 경과일 7일 이상은 담당자 확인이 필요합니다.\\n';
  }

  const 제목 = '[업무요청] 확인 필요 ' + 결과.지연.length + '건 - '
              + Utilities.formatDate(new Date(), 'GMT+9', 'MM/dd');

  MailApp.sendEmail(수신자, 제목, 본문);
  SpreadsheetApp.getUi().alert('메일을 발송했습니다.');
}

function 로그기록(결과) {
  let 로그 = SS.getSheetByName('실행로그');
  if (!로그) {
    로그 = SS.insertSheet('실행로그');
    로그.appendRow(['실행일시', '대상건수', '지연건수', '메일발송']);
  }
  로그.appendRow([
    Utilities.formatDate(new Date(), 'GMT+9', 'yyyy-MM-dd HH:mm'),
    결과 ? 결과.총건수 : 0,
    결과 ? 결과.지연.length : 0,
    결과 && 결과.지연.length ? 'Y' : 'N'
  ]);
}
```

```javascript
   함수가 돌 때마다 "실행로그" 시트에 기록한다
   실행일시 | 대상건수 | 지연건수 | 메일발송여부 | 오류메시지

2. 이상 감지
   아래 경우 메일 제목 앞에 [점검필요]를 붙인다
   - 대상 건수가 지난주보다 20% 이상 줄었을 때
   - 3주 연속 같은 접수번호가 지연 목록에 있을 때
```

**두 번째가 특히 중요합니다.**
3주 연속 같은 건이 지연 중이면 ***알림 문제가 아니라 그 업무가 막혀 있다***는 뜻이에요.

### ① 드라이브 폴더의 파일 자동으로 읽기
**언제 쓰나** — 매주 시스템에서 내려받는 파일을 시트에 붙여넣고 있다면
```plain text
지정한 구글 드라이브 폴더를 검사해서
새 CSV(엑셀) 파일이 있으면 읽어 처리이력에 추가하는 GAS 코드를 만들어줘.

[조건]
- 폴더 ID는 코드 맨 위에 변수로 빼줄 것
- 이미 처리한 파일은 다시 읽지 말 것
  (처리한 파일명을 "처리로그" 시트에 기록)
- CSV 열 순서가 처리이력과 다를 수 있으니
  헤더를 읽어 이름으로 매칭할 것
- 필수 열이 없는 파일은 건너뛰고 로그에 기록
- 처리 후 파일을 "완료" 하위 폴더로 이동

메뉴에 「폴더 가져오기」 항목을 추가해줘.
```

**폴더 ID 찾는 법**
구글 드라이브에서 폴더를 열면 주소가 이렇게 나옵니다.
`drive.google.com/drive/folders/`**`1AbC...XyZ`**

**이게 가능해지면**

### ② 두 시트 대조해서 불일치 찾기 ★
**언제 쓰나** — 같은 내용이 두 곳에 있는데 맞는지 확인해야 할 때





상황

예

```plain text
두 시트를 대조해 불일치를 찾는 GAS 코드를 만들어줘.

[시트 구조]
시트 A: 시스템데이터  열: 전표번호 / 거래처 / 금액 / 일자
시트 B: 사내장부    열: 전표번호 / 거래처 / 금액 / 일자

[할 일]
전표번호를 기준으로 맞춰보고 아래 네 가지로 분류한다.

1. 양쪽에 있고 금액도 같음        → 정상
2. 양쪽에 있는데 금액이 다름      → 금액 불일치
3. A에만 있음                    → 장부 누락
4. B에만 있음                    → 시스템 미반영

결과를 "대조결과" 시트에 쓴다.
열: 구분 / 전표번호 / 거래처 / A금액 / B금액 / 차액

[서식]
금액 불일치는 배경 주황
누락·미반영은 배경 노랑

[예외]
- 전표번호가 빈 행은 건너뛰고 건수를 보고
- 양쪽 모두 비어 있으면 "대조할 데이터가 없습니다" 알림
- 금액 차이가 1원 이하면 정상으로 본다 (반올림 오차)

메뉴에 「대조 실행」 항목을 추가해줘.
```

그리고 사람은 ***불일치 목록만 보고 원인을 판단***하면 됩니다.
