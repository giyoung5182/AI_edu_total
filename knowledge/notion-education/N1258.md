# 실습 과제 3 — AI 적용 업무 데이터 흐름 설계서

정리일: 2026-10-08 · 교육 에셋 N1258

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

## 이 실습으로 하는 것
업무 중 AI를 적용할 수 있는 업무 1개를 골라 데이터 흐름 설계서를 작성합니다.
## 진행 단계
1. **업무 선택** — AI를 적용할 업무 1개.
2. **양식 작성** — 적용 업무명 / 문제 정의 / 입력 데이터 / 출력(예측) 결과 / 필요 테이블·데이터 / 전처리 필요 사항 / 모니터링 지표.
3. **제출** — 표 형식(Word 또는 PDF).
