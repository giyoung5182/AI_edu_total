# 역설계 실전 워크시트

정리일: 2026-10-08 · 교육 에셋 N0535

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
완벽한 결과물 한 건을 AI에게 주고, 같은 스타일로 쓰는 시스템 프롬프트를 AI가 짜게 합니다.
## 진행 단계
1. **문서 준비** — 가장 잘 썼다고 칭찬받은 하자 보고서 또는 건설사 청구 공문 1건 준비
2. **마법의 주문 입력**
- 입력할 내용:
```javascript
위 문서의 톤앤매너, 구조, 핵심 전략을 분석하여
동일한 스타일로 문서를 작성할 수 있는 System Prompt를 만들어줘.
Role, Objective, Process, Example 형식으로.
```
3. **Gem에 적용** — AI가 생성한 System Prompt 확인 후 Gem 요청사항 칸에 붙여넣기
4. **테스트** — 다른 상황에 테스트하여 톤앤매너 일치 여부 점검, 미세 조정
