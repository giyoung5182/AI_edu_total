## 이 실습으로 하는 것
실습 1\~3을 순서대로 실행하는 통합 매크로를 만들어 버튼 하나로 실행한다.
## 진행 단계
1. **통합 실행 코드 만들기** — AI에게 요청
- 입력할 내용:
```javascript
앞서 만든 VBA 코드들을 하나로 합쳐서,
아래 작업을 순서대로 실행하는 통합 매크로를 만들어줘.

1. [날짜강조] 시트에서 "계약일"이 2025-5-5 이후이면서
   "진행상태"가 "진행중"인 행을 빨간색으로 강조
2. [날짜강조] 시트의 데이터를 이용해 고객사별 계약금액
   피벗테이블과 막대그래프를 [정리요약] 시트에 생성
3. [날짜강조] 시트의 데이터를 고객사별로 나누어
   각각 별도의 엑셀 파일로 저장
   (저장 경로: [바탕화면의 고객사별_계약 폴더 경로 입력])

모든 작업이 끝나면 "전체 작업이 완료되었습니다!" 라는
메시지 박스를 띄워줘.

매크로 이름은 "전체실행"으로 해줘.
```
1. **버튼 만들기** — 개발 도구 → 삽입 → 단추(양식 컨트롤) → 시트에 드래그 → 매크로 지정에서 "전체실행" 선택 → 버튼 텍스트를 "자동 실행" 등으로 변경

- 정상 결과: "전체 작업이 완료되었습니다!" 메시지
