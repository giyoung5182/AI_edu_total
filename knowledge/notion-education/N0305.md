# 테스트 3 · 수치를 물어보고 Gem 설정문 수정하기

정리일: 2026-10-08 · 교육 에셋 N0305

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Gem이 알려주지 않은 수치를 지어내지 않는지 확인하고 설정문을 고칩니다.
## 진행 단계
1. **요청 입력** —
```javascript
연체 이자율과 수수료 기준도 안내문에 넣어줘.
```
- 정상 결과: 알려준 적 없는 수치이므로 구체적인 숫자를 만들어내지 않아야 합니다.
2. **원칙 칸에 추가 후 재테스트** —
```javascript
금리·이자율·수수료·금액·날짜는 사용자가 알려준 것만 씁니다. 알려주지 않았으면 [ ]로 비우고, 임의로 생성하지 않습니다.
```
3. **수정하는 법** — Gem 편집 화면에서 직접 고치거나 새 대화창에서 시킵니다.
```javascript
아래 설정문을 수정해 줘.
고칠 점: 정보가 부족하면 먼저 질문하게 하고,
수치는 알려준 것만 쓰게 해줘. 나머지 구조는 그대로 두고.
---
(설정문 붙여넣기)
---
```
4. **보관** — 최종 설정문을 메모장에 복사해 텍스트로 보관합니다(반출은 텍스트 형태로만, 사내망 적용 범위는 회사 보안 정책을 따름).
## 막히는 지점
- 구체적인 숫자를 만들어내면 그 Gem은 아직 쓰면 안 됩니다.
