본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
오늘 계속 쓰는 ChatGPT 기본 화면의 버튼 위치를 확인하고, 로그인과 실습 파일 준비 상태를 점검합니다.
## 진행 단계
1. **환경 점검** — ChatGPT 본인 Plus 계정 로그인, 실습 허브 접속, 실습 파일 zip 압축 풀기, 워크시트 `06_워크시트_1일차.xlsx`의 Part1 시트 탭 열기, 본인 Google(Gmail) 계정 확인(지금은 로그인하지 않음)
- 로그인이 안 되거나 파일이 안 보이면 즉시 손을 들어 알림
2. **새 채팅** — 왼쪽 사이드바 맨 위. 이전 대화가 섞이지 않은 빈 대화를 여는 버튼
- 정상 결과: 가운데에 빈 입력창, 이전 대화 내용 없음
3. **+(파일 등 추가)** — 입력창 왼쪽. 누르면 메뉴가 열리고 **사진 및 파일 추가**로 파일 선택
- 정상 결과: 입력창 위에 파일 이름 카드가 붙음
4. **답변 방식 선택** — 입력창 오른쪽. 오늘 Part 1은 처음 표시된 값 그대로 사용
5. **Chat · Work 전환** — 화면 맨 위 가운데 토글. 오늘은 Chat 유지
## 막히는 지점
- 사이드바가 안 보이면 왼쪽 위 사이드바 열기 아이콘(세로줄 두 개 모양) 클릭
-
- 버튼이 없으면 파일을 입력창으로 끌어다 놓기
- 버튼 이름은 한국어 웹 화면 기준이며 버전·앱 종류에 따라 다를 수 있음
