# 출처를 어떻게 확인하나요?
답변 문장마다 작은 번호가 붙습니다. 그게 **원문 위치**입니다.

**전부 확인할 필요는 없습니다. 순서가 있습니다.**
① 숫자가 들어간 문장 → ② 판정이 들어간 문장 → ③ 조항·주소를 인용한 문장
이 세 종류가 틀렸을 때 실수가 가장 큽니다.

## 바로 쓰실 수 있는 질문 모음
아래 프롬프트는 **그대로 복사해 쓰시면 됩니다.** 대괄호 안만 본인 상황으로 바꾸십시오.
### ① 원문 인용 요청 — 가장 자주 씁니다
```plain text
이 문서에서 [찾을 항목]이 나오는 부분을 찾아 아래 형식으로 정리해 주세요.

- 원문 : 해당 부분을 그대로 인용 (영문이면 영문 그대로)
- 위치 : 섹션명 또는 표 번호
- 해석 : 실무 관점에서 무엇을 뜻하는지 한두 줄

문서에 없으면 "문서에 없음"이라고만 답해 주세요.
비슷한 내용을 대신 제시하지 마세요.
```
### ② 수치 추출 — 단위 사고를 막습니다
```plain text
이 문서에서 [항목]과 관련된 수치를 전부 찾아 표로 정리해 주세요.

컬럼은 항목 / 값 / 단위 / 출처 위치 입니다.

지켜 주세요.
- 문서에 적힌 숫자를 단위까지 그대로 옮기세요.
- 반올림하거나 단위를 변환하지 마세요.
- 범위로 적힌 값은 범위 그대로 적으세요.
- 문서에 없는 항목은 [확인 필요]로 표시하세요.
```
### ③ 요구사항 추출 — 2분반 RFP용
```plain text
이 RFP에서 필수 요구사항만 뽑아 표로 정리해 주세요.

필수 판단 기준
- "~하여야 한다", "~를 포함한다" → 필수
- "~할 수 있다", "~이 바람직하다" → 권장
- "~를 제안한다" → 제안사 재량

컬럼은 분류 / 요구사항 원문 / 필수·권장 / 출처 위치 입니다.
분류는 기능 / 성능 / 보안 / 운영 / 관리로 나눠 주세요.

지켜 주세요.
- 요구사항 원문 표현을 바꾸지 말고 그대로 옮기세요.
- 요약하거나 줄이지 마세요.
- 판단이 들어간 항목에는 "(판단)"을 붙여 주세요.
```
### ④ 문서 간 대조 — 여러 개 올렸을 때
```plain text
등록한 문서들에서 [비교 항목]을 어떻게 정의하고 있는지 대조해 주세요.

컬럼은 문서명 / 정의 또는 값 / 출처 위치 입니다.

지켜 주세요.
- 각 값이 어느 문서에서 나왔는지 반드시 표기하세요.
- 서로 다르게 적힌 부분이 있으면 그 차이를 따로 정리해 주세요.
- 한 문서에만 있는 항목은 나머지를 [해당 없음]으로 표시하세요.
- 문서를 합쳐서 새로운 결론을 만들지 마세요.
```
### ⑤ 절차 정리 — 매뉴얼에서 순서 뽑기
```plain text
이 문서에서 [작업명] 절차를 단계별로 정리해 주세요.

각 단계마다 아래를 적어 주세요.
- 무엇을 하는지
- 문서의 어느 부분에 나오는지
- 주의사항이 있으면 함께

지켜 주세요.
- 문서에 없는 단계를 추가하지 마세요.
- 순서가 명시되지 않은 부분은 "순서 미명시"로 표기하세요.
- 일반적인 절차 지식으로 빈칸을 채우지 마세요.
```

**다섯 개 모두 마지막에 공통 문장이 있습니다**
「문서에 없으면 없다고 하세요」 · 「일반 지식으로 채우지 마세요」
이 두 줄이 빈칸을 지어내는 것을 막는 장치입니다. 질문할 때마다 붙이시면 됩니다.

**대화 안** — 지금 대화를 접고 새로 엽니다

이 요약을 새 대화에 붙여넣고 이어가시면 됩니다. **버티지 말고 새로 여는 편이 빠릅니다.**

**고칠 자리**

**지시문** — 수정 범위 규칙을 추가합니다


```plain text
아래 문서에서 3번 항목의 표현만 개조식으로 바꿔 주세요.

지켜 주세요.
- 나머지 항목은 한 글자도 건드리지 마세요.
- 숫자와 단위는 전부 그대로 두세요.
- 수정한 부분이 어디인지 마지막에 목록으로 알려 주세요.

[문서]
(여기에 붙여넣기)
```

**고친 곳만 보면 놓칩니다.**
수정 요청 후에는 **바뀌지 말아야 할 곳**도 함께 확인하셔야 합니다.
특히 숫자가 들어간 항목은 수정과 무관해도 다시 보시는 편이 안전합니다.

그래서 **중간중간 결과를 따로 저장**해 두시면 좋습니다.

```plain text
- 처리한 항목 수 : 총 몇 개
- 문서에서 직접 확인한 것 : 몇 개, 어떤 항목
- 확인하지 못한 것 : 몇 개, 어떤 항목
- 추측으로 채운 것 : 있으면 전부 표시

숫자로 답해 주세요. "모두" 또는 "대부분" 같은 표현은 쓰지 마세요.
```

**네 가지 중 이것만 오류가 나지 않습니다**
앞의 셋은 결과가 이상해서 눈에 띕니다. **이건 멀쩡해 보입니다.**
그래서 **세어 보는 습관**이 필요합니다. 원본 항목 수 = 처리한 수 + 제외한 수.
