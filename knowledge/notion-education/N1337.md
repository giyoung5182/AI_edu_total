# Step 02 :: 설계도 없이 시킨 것과 있는 것을 비교합니다

정리일: 2026-10-08 · 교육 에셋 N1337

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 요청을 설계도 없이 / 먼저 정하고 두 번 해보고 차이를 확인합니다.
## 진행 단계
1. **먼저 정하게 하기** — 새 대화에서 만들라고 하기 전에 AI가 먼저 묻게 함
- 입력할 내용:
```javascript
캠페인 진행 현황 화면을 만들 건데, 바로 만들지 말고 먼저 물어봐줘.

- 이 화면을 누가 언제 보는지
- 화면을 열자마자 가장 먼저 알아야 하는 것이 무엇인지
- 표에 반드시 있어야 하는 항목이 무엇인지
- 하면 안 되는 것이 무엇인지

한 번에 하나씩 물어봐. 다 답하면 그때 정리해서 보여줘.
```
1. **질문에 답하기** — AI가 되묻기 시작하고, 답하다 보면 원하는 것이 언어가 됨
2. **만들게 하기** — 정리된 내용을 확인한 뒤 입력
- 입력할 내용: `정리한 내용대로 만들어줘.`
3. **두 화면 비교** — 위에 뭐가 있나 / 표의 항목 / 고칠 때 어디를 짚을지를 기준으로 비교
## 막히는 지점
- 결과를 먼저 보면 기준이 결과 쪽으로 끌려가므로 기준을 먼저 적어 둠
