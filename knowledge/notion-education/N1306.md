# [실습] ChatGPT로 입력 템플릿 설계하기

정리일: 2026-10-08 · 교육 에셋 N1306

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
예산 집행 현황 입력 템플릿을 ChatGPT와 함께 설계해 엑셀에 적용합니다.
## 진행 단계
1. **프롬프트 입력** — 건설 프로젝트 예산·원가 데이터 관리 전문가 역할로, 컬럼 구조(컬럼명/데이터 타입/입력 규칙/예시값), 드롭다운 선택지, 유효성 검사 규칙, 엑셀 드롭다운 설정 방법을 요청
2. **엑셀에 적용** — 컬럼명 입력 → 데이터 유효성 검사로 드롭다운 설정 → 샘플 데이터 5행 직접 입력하여 테스트
