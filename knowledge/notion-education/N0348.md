# 워크시트 예시 답안 — 발주 내역 입력 → 업무보고 자동 생성

정리일: 2026-10-08 · 교육 에셋 N0348

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
카톡으로 받은 추가발주 요청을 직원이 구글 시트에 입력하면 업무보고 형식으로 자동 정리되도록, 6단계 워크시트(예시 답안)를 따라 자동화를 설계하고 Claude에 요청할 프롬프트까지 만듭니다.
## 진행 단계
1. **STEP 1. 현재 업무 흐름** — 카톡 발주 수신 → 내용 해석 → 라인 재공유 → 업무보고 양식에 수기 작성 → 전 부서 배포, 하루 2회 반복.
2. **STEP 2. 판단 vs 규칙** — 카톡 수신·해석·라인 재공유는 \[판단\] 자동화 불가, 양식 열기·작성·취합·배포는 \[규칙\] 자동화 가능, 하루 2회 반복은 \[반복\] 타이머 자동화 가능.
3. **STEP 3. 자동화 대상** — 구글 시트 입력 → 업무보고 형식 자동 생성 + 이메일 발송.
4. **STEP 4. 파일 구조** — 입력 시트 '발주입력'(입력시간·매장명·구분·품목·수량·비고), 이력 시트 '발주이력', 보고서 시트 '업무보고(오전)' / '업무보고(오후)'.
5. **STEP 5. 트리거** — 버튼 클릭 \[오전 보고 생성\] \[오후 보고 생성\], 타이머(오전 8시·오후 2시)는 5회차에 추가.
6. **STEP 6. Claude 요청 프롬프트**
- 입력할 내용:
```javascript
Google Apps Script 코드를 만들어줘.

[내 업무 상황]
직원이 발주 내역을 구글 시트에 입력하면
업무보고 형식으로 자동 정리되게 하고 싶어.

[파일 구조] '발주입력' / '발주이력' / '업무보고(오전)' / '업무보고(오후)' 시트
(이하 교안 참고)
```
## 막히는 지점
- 카카오톡·라인 자동 읽기는 정책상 불가, 품목 400개 드롭다운은 비현실적입니다.
