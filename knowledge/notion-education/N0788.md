# Gemini 와 함께 1분 만에 PPT 초안 완성하기
구글의 강력한 AI, **Gemini(제미나이)**를 활용해서 가장 골치 아픈 업무 중 하나인 **'프레젠테이션 슬라이드(PPT)'**를 순식간에 만드는 방법을 알아보겠습니다.

---
## 1. 왜 Gemini로 슬라이드를 만들까요?
프레젠테이션 제작 과정은 크게 **\[기획 → 초안 작성 → 디자인 → 수정\]**으로 나뉩니다. 여기서 가장 많은 에너지를 쓰는 단계가 바로 **'기획 및 초안 작성'**인데요.
Gemini는 마치 **손이 아주 빠른 보조 작가**와 같습니다. 주제만 던져주면 목차부터 세부 내용까지 순식간에 정리해 주니까요.
> 💡 핵심 포인트
Gemini를 사용하면 **'백지 공포증(Blank Canvas Syndrome)'**에서 탈출할 수 있습니다. 완벽한 결과물을 기대하기보다, **훌륭한 초안(Draft)**을 빠르게 얻는 것에 집중하세요.

---
## 2. 실전! Gemini로 슬라이드 제작하는 3단계 프로세스
단순히 "PPT 만들어줘"라고 하면 좋은 결과를 얻기 힘듭니다. 아래 단계별로 따라 해보세요.

### 1단계: 구체적인 구조와 목차 요청하기
먼저 전체적인 뼈대를 잡아야 합니다. 단순히 주제만 던지기보다, **청중, 목적, 슬라이드 장수**를 지정해주면 훨씬 퀄리티가 높아집니다.

> 📌 추천 프롬프트 (예시)
"나는 지금 '2025년 주식 투자 트렌드'를 주제로 사내 교육용 프레젠테이션을 준비하고 있어.<br>**신입사원**들을 대상으로 할 거고, **총 7장** 분량으로 구성해 줘.<br>각 슬라이드의 **제목과 핵심 내용(Bullet point)**을 포함해서 개요를 짜줘."

- 이때 필요한 정보들을 함께 넣어주면 더욱 좋습니다.

## 실습 : 특정 주제로 발표 슬라이드 만들기 (ChatGPT 활용)
본 실습에서는 AI를 활용하여 발표 슬라이드를 생성하는 과정을 경험합니다.
단순히 슬라이드를 바로 생성하는 것이 아니라, 먼저 **구조를 설계한 뒤 생성하는 방식**을 통해
더 완성도 높은 결과물을 만드는 것을 목표로 합니다.
많은 경우 AI에게 바로 “슬라이드 만들어줘”라고 요청하지만,
이러한 방식은 내용의 흐름이 부족하거나 메시지가 모호한 결과로 이어질 수 있습니다.
따라서 이번 실습에서는
**“구조 설계 → 생성”의 2단계 접근 방식**을 적용합니다.

---
### STEP 1. 슬라이드 구성 설계하기 (약 10장)
먼저 발표 주제에 맞는 전체 슬라이드 구성을 설계합니다.
이 단계에서는 실제 디자인보다는 **스토리 흐름과 메시지 구조**에 집중합니다.
슬라이드는 단순한 정보 나열이 아니라,
하나의 흐름을 가지는 콘텐츠이기 때문에
각 장이 어떤 역할을 하는지 명확하게 정의하는 것이 중요합니다.

이 과정에서는 각 슬라이드에 들어갈 내용을 정리하며,
전체 발표가 자연스럽게 이어지도록 구성합니다.

## NotebookLM이란?
**[개별 링크 제외]
NotebookLM은 구글이 만든 **문서 기반 AI 도구**입니다. 일반적인 AI 챗봇(ChatGPT, Gemini 등)이 인터넷에서 학습한 모든 정보를 바탕으로 답변한다면, NotebookLM은 **내가 올린 문서만을 바탕으로** 답변합니다.
쉽게 말해, "내 자료만 읽고 대답하는 개인 비서"입니다.

일반적인 질문, 창작

특정 문서 분석, 리서치, 보고서 작성


> NotebookLM의 가장 큰 장점은 \*\*"출처가 명확한 답변"\*\*입니다. AI가 답변할 때 문서의 어느 부분을 참고했는지 인라인 인용(Citation)을 달아주기 때문에, 즉시 원문을 대조하며 검증할 수 있습니다.

## NotebookLM 시작하기
### 접속 및 가입
1. notebooklm.google.com 에 접속합니다.
2. 구글 계정으로 로그인합니다 (무료).
3. "새 노트북"을 클릭합니다.
### 소스(문서) 업로드
노트북을 만든 후, AI가 읽을 자료를 올립니다. 다양한 형태의 소스를 지원합니다.
- **PDF 파일**: 보고서, 논문, 계약서 등
- **구글 문서/슬라이드**: Google Drive에서 바로 가져오기
- **웹사이트 URL**: 웹 페이지 내용을 소스로 추가
- **유튜브 URL**: 영상 내용을 분석 소스로 추가
- **텍스트 직접 입력**: 복사·붙여넣기로 추가
하나의 노트북에 **최대 50개의 소스**를 업로드할 수 있으며, 여러 문서를 올리면 문서 간의 공통점·차이점까지 분석해 줍니다.
---
## 핵심 기능 3가지
### 기능 1 — 문서 기반 질의응답
소스를 올리면 AI에게 자유롭게 질문할 수 있습니다. 일반 AI와 다른 점은, 답변에 반드시 **원문 인용 표시**가 포함된다는 것입니다.
**질문 예시 (2022 국방백서 기준):**
```plain text
북한의 주요 군사 위협 요인을 3가지로 정리해 줘.
```
```plain text
한국군의 국방개혁 추진 현황을 연도별 타임라인으로 정리해 줘.
```
```plain text
국방백서에서 언급된 한미동맹의 역할과 주요 협력 사항을 요약해 줘.
```
```plain text
북한 핵·미사일 위협에 대한 대응 전략이 어떻게 서술되어 있는지
해당 부분을 인용과 함께 정리해 줘.
```
**질문 팁**: 단순히 "요약해 줘"보다 구체적인 관점을 부여하면 더 좋은 답변을 얻을 수 있습니다. 앞서 배운 구조화 프롬프트의 원리를 그대로 적용하면 됩니다.

## 실습: 국방백서를 NotebookLM에 올려서 분석하기

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]


### 실습 미션
2022 국방백서 PDF를 NotebookLM에 올리고, 문서와 대화하며 핵심 내용을 추출합니다. 여기에 웹 소스(뉴스 기사, 유튜브 영상 등)를 추가로 연결해서, 문서 + 외부 정보를 교차 분석하는 것까지 체험합니다.
### 실습 순서
**1. 노트북 만들기**
- notebooklm.google.com 접속 → "새 노트북" 클릭
- 이름: "국방백서 분석" 으로 지정
**2. 소스 ① — 국방백서 PDF 업로드**
- 제공된 **2022 국방백서.pdf** 파일을 업로드합니다.
- 업로드가 완료되면 NotebookLM이 자동으로 핵심 요약과 추천 질문을 생성합니다. 먼저 이것들을 클릭해서 살펴보세요.
**3. 문서와 대화하기 — 기본 질문**
아래 질문들을 직접 입력해 봅니다. 답변에 달리는 **인용 표시**를 클릭하면 국방백서 원문의 해당 부분으로 바로 이동할 수 있습니다.
```plain text
북한의 핵·미사일 능력 현황을 정리해 줘.
```
```plain text
국방백서에 나온 한국군의 병력 규모와 주요 무기체계를
표 형식으로 정리해 줘.
```
```plain text
한미동맹과 관련된 내용을 모두 찾아서 요약해 줘.
```
```plain text
이 국방백서의 내용을 5장짜리 발표 슬라이드 목차로 구성해 줘.
각 슬라이드의 제목과 핵심 메시지를 포함해서.
```
**4. 소스 ② — 웹에서 소스 추가하기**
국방백서는 2022년 기준 자료입니다. 최신 정보를 추가하면 더 풍부한 분석이 가능합니다.
소스 추가 버튼(+)을 눌러 아래 중 1\~2개를 추가해 봅니다.
**웹사이트 URL 추가:**
- 국방부 공식 사이트의 최신 보도자료
- 최근 국방 관련 뉴스 기사 URL
**유튜브 URL 추가:**
- 국방 관련 유튜브 영상 URL (예: 최신 국방 정책 브리핑, 무기체계 소개 영상 등)
> **소스 추가 방법**: 소스 패널에서 "+" 버튼 클릭 → "웹사이트" 또는 "YouTube" 선택 → URL 붙여넣기 → 추가 완료
**5. 교차 분석하기 — PDF + 웹 소스 함께 질문**
웹 소스가 추가되면, 국방백서와 최신 자료를 함께 분석하는 질문을 해봅니다.
```plain text
국방백서(2022)에 서술된 북한 위협과
최근 추가한 뉴스 기사의 내용을 비교해 줘.
달라진 점이 있다면 정리해 줘.
```
```plain text
국방백서의 국방개혁 방향과 최근 기사에서 언급된 현재 진행 상황을
대조해서 표로 정리해 줘.
```
이것이 NotebookLM의 핵심 강점입니다. **여러 소스를 올려놓고 교차 질문**하면, 사람이 수작업으로 비교하는 것보다 훨씬 빠르게 공통점·차이점·변화 추이를 파악할 수 있습니다.
**6. AI 팟캐스트 만들어 보기**
- 스튜디오 패널 → 오디오 개요 → 설정에서 출력 언어를 **한국어**로 변경 → "생성" 클릭
- 생성되는 동안(3\~5분) 다른 기능을 탐색해 봅니다
- 완성된 팟캐스트를 들어보며, AI가 국방백서의 핵심을 어떻게 요약하는지 확인합니다
**7.슬라이드 만들어보기**
- 스튜디오에서 슬라이드 자료 만들기
### 실습 팁
- 소스를 업로드하면 NotebookLM이 자동으로 **핵심 요약과 추천 질문**을 보여줍니다. 처음에는 이것부터 클릭해 보면 어떤 질문이 가능한지 감이 잡힙니다.
