# 2. 비정형을 정형으로: 텍스트에서 데이터 뽑아내기

정리일: 2026-10-08 · 교육 에셋 N0907

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 실습 시작 전 준비
실습을 시작하기 전에 다음 사항을 직접 확인합니다.
- `copilot.microsoft.com`에 접속하여 로그인합니다. 모듈 1에서 이미 로그인한 상태라면 바로 진행합니다.
- 메모장 또는 별도의 텍스트 편집기를 열어 프롬프트를 복사·붙여넣기할 준비를 합니다.
- Excel 또는 Google Sheets를 열어 새 빈 시트를 준비합니다.
> ⚠️ **보안 주의**: 사내 기밀 데이터나 고객 개인정보는 외부 AI 서비스에 입력하지 않습니다. 실습에서는 반드시 이 교안에 있는 샘플 데이터를 사용합니다. 본인의 실제 업무 데이터를 사용하고 싶다면, 아래 "나만의 샘플 데이터 만드는 방법"을 참고하여 가상 데이터로 변환한 후 사용합니다.

## 학습 목표
이 모듈을 마치면 다음 세 가지를 할 수 있게 됩니다.
1. PDF·이메일·회의 메모 등 형식이 일정하지 않은 비정형 텍스트에서 필요한 항목을 추출하여 정돈된 표로 만드는 작업을 Copilot으로 수행할 수 있습니다.
2. 추출 기준과 항목을 프롬프트에 구체적으로 명세화하여, 같은 작업을 반복하더라도 일관된 품질의 결과를 얻을 수 있습니다.
3. 추출된 데이터에 누락값이나 이상치가 있는지 자동으로 점검하는 체크리스트를 Copilot으로 생성하고 활용할 수 있습니다.

## 2-1. PDF·이메일·메모에서 항목별 표 형태로 정보 추출하기
실무에서 우리가 다루는 문서의 대부분은 깔끔하게 정렬된 표 형태가 아니라, 사람이 자유롭게 작성한 텍스트 형태입니다. 이메일 본문에 담긴 고객의 요청 사항, 회의 중 빠르게 적은 메모, 또는 여러 페이지에 걸쳐 서술된 자문 의견서가 그 대표적인 예입니다. 이렇게 형식이 없거나 일정하지 않은 데이터를 **비정형 데이터**라고 합니다.
비정형 데이터를 표나 데이터베이스처럼 구조화된 형태로 바꾸는 것을 **정형화**라고 합니다. 정형화가 되어야 필터, 정렬, 통계 분석 등 다양한 후속 작업이 가능해집니다. 기존에는 이 과정을 사람이 직접 읽고 입력해야 했기 때문에 시간이 많이 걸리고 실수가 발생하기 쉬웠습니다. Copilot을 활용하면 비정형 텍스트를 채팅 창에 붙여넣고 "어떤 항목을 추출해서 어떤 형태로 정리해달라"고 지시하는 것만으로 구조화된 표를 즉시 만들 수 있습니다.
실무에서 자주 처리하게 되는 비정형 문서 유형과 추출 목표는 다음과 같습니다.

자문 의뢰서

의뢰인, 쟁점, 요청 사항

의뢰인·쟁점·결론 표

### 🖥️ 실습 1 — 샘플 문서 구조 파악 및 추출 항목 직접 정의하기
본격적인 추출 실습 전, 샘플 문서를 읽고 어떤 항목을 뽑을지 스스로 정의해봅니다. 이 과정을 거쳐야 이후 프롬프트를 단순 복사가 아닌 본인 업무에 맞게 설계할 수 있습니다.
아래 샘플 문서 3건을 읽어봅니다. 세 문서는 의도적으로 형식이 다르게 작성되어 있습니다.
---
**\[샘플 문서 1 — 명확한 구조형\]**
항목이 명확하게 구분되어 있는 형태입니다.
```plain text
수신: 법무팀
발신: 영업본부 프로님
날짜: 2025년 3월 4일

제목: 공급계약 해지 관련 법적 검토 요청

안녕하세요. 저희 팀이 진행 중인 A사와의 공급계약 건에 관해
법적 검토를 요청드립니다.

주요 쟁점:
1. 계약 기간 내 일방적 해지 가능 여부
2. 위약금 산정 기준의 적정성

검토 후 의견을 3월 10일까지 회신 주시면 감사하겠습니다.
```
---
**\[샘플 문서 2 — 서술형 혼합\]**
항목 구분 없이 긴 문장으로 이어지는 형태입니다.
```plain text
이번 건은 B사 대표이사 박지수 씨가 의뢰한 건으로,
작년 말 체결된 기술이전계약에서 로열티 지급 조건에 대한
해석 차이가 발생하였습니다. 박 대표는 계약서 제7조의
"순매출액" 정의가 불명확하다고 주장하며 법적 해석을
요청하였습니다. 당사 검토 결과, 업계 표준 정의에 따르면
B사 측 해석이 타당한 것으로 판단됩니다. 접수일은 2025년
2월 28일이며, 검토 완료 예정일은 3월 14일입니다.
```
---

**\[샘플 문서 3 — 항목 누락형\]**
일부 항목이 비어 있는 형태입니다.
```plain text
의뢰인: C물산 법무팀 프로님
문의 내용: 하도급법 위반 여부 검토 요청
접수일: 3/7
담당 변호사:
(검토 중)
```
---

세 문서를 읽은 후, 공통적으로 추출할 수 있는 항목이 무엇인지 아래 빈칸에 직접 적어봅니다.
```plain text
내가 추출하고 싶은 항목:
① ________________
② ________________
③ ________________
④ ________________
```
작성이 끝나면 옆 수강생과 비교해봅니다. 이 실습에서 사용할 최종 추출 항목은 아래와 같이 확정합니다.
```plain text
확정된 추출 항목: 문서번호 / 의뢰인 / 접수일 / 쟁점 / 결론(또는 검토 상태) / 특이사항
```

## 2-2. 추출 기준·항목을 프롬프트로 명세화하는 방법
Copilot이 비정형 텍스트에서 데이터를 추출할 때 품질을 결정하는 핵심 요소는 **프롬프트의 명세화 수준**입니다. "이 텍스트를 표로 만들어줘"라는 막연한 지시보다, "어떤 항목을 추출하고, 없는 값은 어떻게 처리하며, 날짜 형식은 어떻게 통일할지"를 구체적으로 지정할수록 원하는 결과에 가까운 표가 나옵니다.
명세화된 프롬프트는 두 가지 수준으로 나눌 수 있습니다.
**기본 추출 프롬프트** — 단일 문서나 짧은 텍스트에서 특정 항목을 뽑아낼 때 사용합니다.
```plain text
아래 텍스트에서 다음 항목을 추출하여 표로 정리해줘.
추출 항목: [항목1], [항목2], [항목3]
- 항목이 없으면 "해당없음"으로 표시
- 여러 건이 있으면 행을 나눠서 표시
- 날짜는 YYYY-MM-DD 형식으로 통일

[텍스트 붙여넣기]
```
이 구조에서 중요한 세 가지는 다음과 같습니다. 첫째, **추출 항목을 명확하게 나열**해야 합니다. 항목 이름이 애매하면 Copilot이 잘못된 열을 만들 수 있습니다. 둘째, **누락값 처리 규칙**을 미리 정해두어야 합니다. 규칙이 없으면 Copilot이 빈 칸으로 두거나 임의로 추정값을 넣을 수 있습니다. 셋째, **날짜 형식 통일** 지시를 포함해야 합니다. "3월 5일", "03/05", "2025.3.5" 등 다양한 형식이 섞이면 통일 규칙을 명시하지 않는 한 열 전체 형식이 들쑥날쑥해집니다.
**고급 명세화 프롬프트** — 여러 문서를 한꺼번에 처리하거나 하나의 통합 표로 합쳐야 할 때 사용합니다. "문서번호" 열을 반드시 포함하면 나중에 원본 문서와 대조할 때 어느 행이 어느 문서에서 왔는지 추적할 수 있습니다.
```plain text
아래 [문서 수]개의 텍스트를 각각 분석하여
하나의 통합 표로 만들어줘.
컬럼: 문서번호 / [항목1] / [항목2] / [항목3] / 특이사항
동일 항목이 여러 번 등장하면 세미콜론(;)으로 구분해줘.
```
> **프롬프트 작성 팁**: 항목명은 본인의 업무 언어로 작성할수록 실무 적용이 빨라집니다. 법무팀이라면 "의뢰인, 쟁점, 결론", 영업팀이라면 "고객명, 요청사항, 응대 결과"처럼 실제 업무에서 쓰는 용어를 그대로 사용합니다.

### 🖥️ 실습 2 — 명세화 프롬프트로 3개 문서 통합 추출하기
실습 1의 샘플 문서 3건을 사용하여 하나의 통합 표를 만들어봅니다.
1. Copilot 채팅 창을 새로 열고, 아래 프롬프트 전체를 복사합니다. `[샘플 문서 1 텍스트]`, `[샘플 문서 2 텍스트]`, `[샘플 문서 3 텍스트]` 자리에는 실습 1의 각 문서 내용을 그대로 붙여넣습니다.
```plain text
아래 자문 의견서 3건을 분석하여 하나의 통합 표로 만들어줘.
추출 항목: 문서번호, 의뢰인, 접수일, 쟁점, 결론(또는 검토 상태), 특이사항
처리 규칙:
- 문서번호는 순서대로 1, 2, 3으로 부여해줘.
- 접수일은 YYYY-MM-DD 형식으로 통일해줘.
- 항목을 찾을 수 없으면 "미확인"으로 표시해줘.
- 쟁점이 여러 개면 세미콜론(;)으로 구분해줘.

[샘플 문서 1 텍스트]
---
[샘플 문서 2 텍스트]
---
[샘플 문서 3 텍스트]
```
1. 출력된 표를 아래 체크 항목으로 직접 검토합니다.
```plain text
□ 문서 3건이 각각 1행씩, 총 3행으로 표현되었는가?
□ 접수일이 YYYY-MM-DD 형식으로 통일되었는가?
□ 항목이 없는 셀이 "미확인"으로 처리되었는가?
□ 쟁점이 두 개 이상인 문서에서 세미콜론(;)으로 구분되었는가?
□ 예상하지 못한 열이 추가되거나, 빠진 열은 없는가?
```
1. 결과가 기대와 다른 부분이 있다면 아래 후속 프롬프트로 수정을 요청합니다.
```plain text
문서 2의 접수일이 누락된 것 같아. 본문에서 날짜를 다시 찾아서 채워줘.
또한 문서 3의 담당 변호사 항목이 빈 칸인데, "미배정"으로 바꿔줘.
```
1. 완성된 표를 Excel에 붙여넣어 `자문의견서_추출_실습.xlsx`로 저장합니다. 이 파일은 다음 실습에서 바로 사용합니다.
**기대 결과**: 구조가 제각각인 세 문서가 통일된 컬럼의 표 한 장으로 정리됩니다. 항목이 누락된 문서 3은 "미확인" 또는 "미배정"으로 처리되어 표의 일관성이 유지됩니다.

## 2-3. 누락·이상치 점검용 체크리스트 자동 생성하기
Copilot이 데이터를 추출하여 표를 만들어 주더라도, 그 결과를 그대로 사용하는 것은 위험합니다. AI는 텍스트의 맥락을 파악하는 능력은 뛰어나지만, 원본 데이터에 오류가 있거나 표현이 모호한 경우 잘못된 값을 넣거나 항목을 건너뛸 수 있습니다. 따라서 추출 결과를 사용하기 전에 반드시 **데이터 품질 검증** 단계를 거쳐야 합니다.
이 검증 과정 역시 Copilot에게 맡길 수 있습니다. 추출된 표를 Copilot에 다시 붙여넣고 아래 프롬프트를 사용하면 자동으로 품질 체크리스트가 생성됩니다.

```plain text
위에서 추출한 표를 기준으로 데이터 품질 체크리스트를 만들어줘.
확인 항목:
- 필수 컬럼 누락 여부
- 날짜 형식 불일치
- 동일 항목 중복 입력
- 이상값 (평균 대비 2배 이상 차이)
각 항목별 점검 결과를 ✅/⚠️/❌ 로 표시해줘.
```
이 프롬프트를 실행하면 Copilot이 표 전체를 스캔하여 다음과 같은 형태의 체크리스트를 출력합니다.





점검 항목

결과

비고




필수 컬럼 누락 여부

⚠️

3행 "결론" 열 값 없음




날짜 형식 불일치

✅

전체 YYYY-MM-DD 통일됨




동일 항목 중복 입력

❌

1행과 5행 의뢰인명 동일




이상값

✅

이상 범위 내


> ⚠️ **주의**: Copilot의 체크리스트가 항상 완벽한 것은 아닙니다. 실제로는 값이 있는데 누락으로 표시하거나, 중복이 아닌데 중복으로 잘못 판단하는 경우가 있습니다. 체크리스트는 참고 자료로만 사용하고, 반드시 원본 데이터와 직접 대조하여 최종 확인합니다.

### 🖥️ 실습 3 — 품질 체크리스트 생성 및 문제 항목 검증하기
실습 2에서 완성한 표를 대상으로 품질 검증을 진행합니다.
1. 실습 2에서 생성된 표 전체를 복사하여 Copilot 채팅 창에 붙여넣은 후, 아래 프롬프트를 입력합니다.
```plain text
위에서 만든 표를 기준으로 데이터 품질 체크리스트를 만들어줘.
확인 항목:
- 필수 컬럼(문서번호, 의뢰인, 접수일, 쟁점) 누락 여부
- 날짜 형식 불일치 여부
- 동일 의뢰인 중복 입력 여부
- "미확인" 항목이 몇 건인지
각 항목별 점검 결과를 ✅/⚠️/❌ 로 표시하고,
문제가 있는 경우 어느 행(문서번호)에서 발생했는지 명시해줘.
```
1. 출력된 체크리스트에서 ⚠️ 또는 ❌ 항목을 찾아 확인합니다.
2. 문제가 표시된 항목을 실습 1의 원본 샘플 문서와 직접 비교합니다. 예를 들어 "3행 '쟁점' 누락"이라고 표시되었다면, 샘플 문서 3을 다시 읽어보고 실제로 쟁점 정보가 없는지, 아니면 Copilot이 찾지 못한 것인지를 판단합니다.
**기대 결과**: Copilot이 표의 각 항목을 점검하여 누락값·중복·형식 오류 등을 표 형태의 체크리스트로 출력합니다. 전체 데이터를 직접 읽지 않고도 문제 항목을 빠르게 파악할 수 있습니다.

## 2-4. 어려운 Excel 함수, Copilot에게 물어보기
데이터를 표로 정리하고 나면 다음 단계는 Excel에서 추가 분석을 하는 것입니다. 이때 많은 실무자가 막히는 지점이 바로 **Excel 함수**입니다. VLOOKUP, SUMIF, COUNTIFS 같은 함수는 매우 유용하지만, 인수 구조가 복잡하고 조건을 조합하는 방법이 헷갈리는 경우가 많습니다.
Copilot은 이런 상황에서 "함수 작성 도우미"로 활용할 수 있습니다. 원하는 동작을 자연어로 설명하면, Copilot이 그에 맞는 Excel 수식을 작성해주고 각 인수의 의미도 함께 설명해 줍니다.
**함수 요청 기본 프롬프트**는 다음과 같습니다. 단순히 함수 이름을 묻는 것이 아니라, **데이터 구조(어느 열에 무엇이 있는지)** 와 **원하는 조건과 출력 형태**를 함께 설명하는 것이 핵심입니다.
```plain text
Excel에서 [원하는 동작]을 하는 함수를 알려줘.
- 데이터 범위: A열에 날짜, B열에 금액
- 조건: 2024년 데이터만
- 출력: 합계
수식과 함께 각 인수의 의미도 설명해줘.
```
실무에서 자주 요청하는 함수 유형은 다음과 같습니다.





목적

요청 키워드 예시




조건부 합계

"특정 조건을 만족하는 행의 금액 합계를 구하고 싶어"




다중 조건 검색

"두 가지 조건을 동시에 만족하는 값을 찾고 싶어"




중복 제거

"중복된 값을 제거하고 고유한 값만 목록으로 추출하고 싶어"




날짜 계산

"두 날짜 사이의 영업일 수를 계산하고 싶어"

### 🖥️ 실습 4 — 누락 항목 보완 재프롬프트 + 내 업무 함수 요청하기
**파트 A — 재프롬프트로 표 완성하기**
실습 3의 체크리스트에서 발견된 문제 항목을 대상으로 아래 재프롬프트 예시를 참고하여 직접 보완을 요청합니다.
누락 항목 보완 요청 예시입니다.
```plain text
이전에 만든 표에서 문서 3번의 "쟁점" 항목이 "미확인"으로
되어 있는데, 원문을 다시 보니 "하도급법 위반 여부 검토"라는
내용이 있었어. 해당 행을 수정해줘.
```
날짜 형식 수정 요청 예시입니다.
```plain text
문서 2의 접수일이 "2025년 2월 28일"로 표시되어 있는데,
다른 행과 맞춰서 "2025-02-28" 형식으로 바꿔줘.
```
추가 열 삽입 요청 예시입니다.
```plain text
표에 "처리 상태" 열을 추가해줘.
문서 1은 "검토 요청 중", 문서 2는 "검토 완료", 문서 3은 "검토 중"으로
각각 입력해줘.
```
각 재프롬프트를 실행한 후 수정이 올바르게 반영되었는지 확인하고, 최종 완성된 표를 Excel에 저장합니다.
**파트 B — 내 업무에서 필요한 Excel 함수 요청하기**
아래 프롬프트에서 `[원하는 동작]` 자리에 본인의 업무에서 필요한 함수 작업을 직접 입력하여 요청해봅니다.
```plain text
Excel에서 [원하는 동작]을 하는 함수를 알려줘.
- 데이터 범위: [내 데이터의 열 구조 설명]
- 조건: [원하는 조건]
- 출력: [원하는 결과 형태]
수식과 함께 각 인수의 의미도 설명해줘.
```
예를 들어 "담당 변호사별 처리 건수를 세고 싶어", "접수일이 2025년 1분기인 건만 모아서 합산하고 싶어"처럼 자유롭게 입력합니다.
**기대 결과**: 초기 추출 결과의 오류와 누락이 재프롬프트를 통해 보완되어 완성도 높은 표가 완성됩니다. Excel 함수 작성도 Copilot에게 자연어로 요청하면 즉시 수식과 설명이 제공됩니다.

## 나만의 샘플 데이터 만드는 방법
위 샘플이 본인 업무와 거리감이 느껴진다면 아래 두 가지 방법으로 직접 만들 수 있습니다. 단, 실제 고객명·계약 내용 등 기밀 정보는 절대 입력하지 않고 반드시 가상의 내용으로 대체합니다.
**방법 1 — 기존 업무 문서를 가상 데이터로 치환하기**
실제 업무 문서의 구조(형식·항목 구성)는 그대로 유지하되, 아래와 같이 실제 정보만 치환합니다.
```plain text
고객·의뢰인 이름 → 프로님, 김철수 등 가상 이름
날짜           → 임의 날짜 (예: 3월 1일, 3/5, 2025.3.7 등 형식 혼재)
금액·수치      → 임의 숫자 (예: 500만원, 1,200만원)
회사명         → A사, B법인, C물산 등 익명 처리
담당자         → 일부러 비워두거나 "미정"으로 표기
```
**방법 2 — Copilot에게 샘플 생성 요청하기**
아래 프롬프트에서 `[업무 유형]` 자리에 본인의 업무(예: 법무 자문 의뢰 접수, 회의 결과 메모, 이메일 응대 이력)를 입력합니다.
```plain text
나는 [업무 유형]을 담당하고 있어.
비정형 텍스트 형태의 샘플 문서 3건을 만들어줘.

조건:
- 문서 1: 항목이 명확하게 구분된 구조형
- 문서 2: 항목 구분 없이 서술형으로 이어지는 형태
- 문서 3: 일부 항목이 비어있는 누락형
- 날짜 표기 방식이 문서마다 다를 것 (예: 3월 4일 / 2025.2.28 / 3/7)
- 모든 이름, 회사명, 내용은 가상으로 작성해줘.
```

## 실습 후 정리 사항
**결과물 저장**: 실습 2\~4에서 만든 최종 표와 품질 체크리스트를 하나의 파일에 함께 저장합니다. 파일명은 `트랙2_모듈2_실습결과_[날짜].xlsx` 형식으로 저장합니다.
**프롬프트 라이브러리 업데이트**: 이번 실습에서 사용한 기본 추출 프롬프트, 고급 다중 문서 프롬프트, 체크리스트 생성 프롬프트, 재보완 프롬프트를 개인 프롬프트 라이브러리에 추가합니다. 각 프롬프트 옆에 어떤 상황에 쓰는 것인지 한 줄로 메모해 두면 나중에 빠르게 찾을 수 있습니다.
**업무 적용 계획 수립**: 본인의 업무에서 이 기술을 바로 적용할 수 있는 문서 유형을 한 가지 정합니다. 예를 들어 "매주 수신되는 고객 이메일에서 요청 항목을 표로 정리하는 데 활용하겠다"처럼 구체적으로 작성합니다.

## 모듈 요약 및 다음 모듈 안내
이 모듈에서 다음 세 가지를 배웠습니다.
1. 비정형 텍스트에서 필요한 항목을 추출하여 구조화된 표를 만드는 방법을 이해하고 직접 실행했습니다.
2. 프롬프트에 추출 항목·누락값 처리 규칙·날짜 형식 통일 지시를 명세화하면 결과 품질이 크게 높아진다는 점을 체험했습니다.
3. 추출 결과에 대한 데이터 품질 체크리스트를 Copilot으로 자동 생성하고, 문제 항목을 재프롬프트로 보완하는 전체 워크플로우를 완성했습니다.
다음 모듈인 **"보여주는 데이터: 차트·표·VBA로 완성하기"** 에서는 오늘 정리한 데이터를 시각화하여 임원 보고용 차트와 슬라이드로 완성하는 방법을 배웁니다. Copilot이 차트 유형을 추천해주고 해석 멘트까지 자동으로 생성해주는 과정을 직접 경험하게 됩니다.
