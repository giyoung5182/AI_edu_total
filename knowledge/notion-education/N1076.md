# 실습4: 디버깅 훈련

정리일: 2026-10-08 · 교육 에셋 N1076

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
오류를 일부러 내 보고 AI와 F8 한 줄 실행으로 해결하는 법을 익힙니다.
## 진행 단계
1. **문제1 일부러 오류 내기** — 완료건추출 코드의 `"민원현황"`을 `"민원 현황"`(공백 추가)으로 바꾸고 F5
- 정상 결과: \[디버그\] 클릭 시 `Set wsSrc = ...Sheets("민원 현황")` 줄이 노란색, 런타임 오류 '9'
- 입력할 내용:
```javascript
방금 준 VBA 코드에서 오류가 났어:
"런타임 오류 '9': 아래 첨자 사용이 잘못되었습니다"
[디버그]를 누르니 이 줄이 노란색이야:
Set wsSrc = ThisWorkbook.Sheets("민원 현황")
원인과 수정된 전체 코드를 줘.
```
1. **문제2 F8 한 줄 실행** — VBA와 엑셀 창을 나란히 놓고 F8을 반복, `lastRow` 위에 마우스를 올려 값 확인
- 정상 결과: `lastRow = 61` 툴팁 표시
2. **문제3 자주 만나는 오류** — 런타임 9(시트/파일 이름 불일치), 런타임 1004(잘못된 범위·보호된 시트), 컴파일 오류(코드 일부만 복사)
## 막히는 지점
- 오류 후 재실행 전 ■(재설정) 버튼으로 멈춘 실행을 초기화
