## 4-1. Playwright MCP로 웹 데이터 가져오기
### 4-1-1. Playwright MCP 설치
Playwright 는 AI 가 브라우저를 제어하는 도구입니다. MCP(Model Context Protocol) 서버로 연결합니다.
```plain text
브라우저를 자동 제어할 수 있는 Playwright MCP 도구를 설치해줘. 설치 후 동작 확인까지 부탁해.
```
> **AI 가 보여줄 예상 결과**
설치 명령을 실행하겠습니다.
```plain text
claude mcp add playwright -- npx @playwright/mcp@latest
```
설치 완료 후 한 번 동작을 확인합니다… ✅ 브라우저 제어 가능 확인.
이제 “네이버 열어줘” 같은 자연어로 브라우저를 제어할 수 있습니다.

## 4-3.  뉴스 제목 수집과 긍정/부정 분류
뉴스 전문을 복사하지 않습니다. 제목, 날짜, 언론사, URL, 주제만 수집하고, 같은 흐름에서 교육기관 관점의 긍정/부정 분류까지 붙입니다.

### 4-3-1. 수집 범위 정하기
```plain text
뉴스 제목 수집 실습을 시작할게. 최근 7일 기준으로 교육기관 외부환경에 영향을 줄 수 있는 뉴스 키워드를 정리해줘. 키워드는 펄프 가격, 해상 운임, 친환경 포장재, 전자소재, 건자재 수요를 포함하고, 각 키워드가 어떤 그룹사나 사업 영역에 영향을 줄 수 있는지 한 줄씩 설명해줘. 아직 웹 수집이나 파일 저장은 하지 마.
```

### 4-3-2. 공개 뉴스 제목 수집하기
```plain text
위 키워드로 공개 웹에서 최근 7일 뉴스 제목을 15~20개 수집해줘. 뉴스 전문은 복사하지 말고 title, date, source_name, source_url, topic만 수집해줘. 출처 URL이 없거나 날짜 확인이 어려운 결과는 제외해줘. 결과를 먼저 표로 보여주고, 아직 CSV 저장은 하지 마.
```

### 4-3-3. 교육기관 관점으로 긍정/부정 분류하기
```plain text
방금 수집한 뉴스 목록을 교육기관 관점에서 sentiment가 긍정 또는 부정이 되도록 분류해줘. affected_affiliates에는 영향을 받을 수 있는 한솔 계열사 또는 사업 영역을 적고, rationale에는 판단 근거를 1문장으로 써줘. 판단이 애매한 경우에도 둘 중 하나로 분류하되, rationale에 애매한 이유를 함께 밝혀줘.
```

### 4-3-4. CSV로 저장하기
```plain text
분류가 끝난 뉴스 목록을 date, title, topic, source_name, source_url, sentiment, affected_affiliates, rationale, collected_at 컬럼 순서로 news_data/news_sentiment_collected.csv에 저장해줘. collected_at은 저장 시각으로 채우고, source_url이 비어 있는 행은 저장하지 마.
```

### 4-3-5. 저장 결과 빠르게 검증하기
```plain text
news_data/news_sentiment_collected.csv를 다시 열어서 행 수, 컬럼명, source_url 누락 여부, sentiment 누락 여부를 확인해줘. 문제가 있는 행이 있으면 수정하지 말고 먼저 어떤 행인지 표로 알려줘.
```

## 4-4. 마무리: LLM을 넘어 AI Agent로 일하기
> LLM은 질문에 답하고 텍스트를 생성하는 데 강합니다. 하지만 AI Agent는 여기서 한 단계 더 나아가, 브라우저·파일·코드·데이터 도구를 사용해 실제 작업을 실행하고 결과를 검증합니다.
이번 실습에서 한 일은 단순히 “뉴스와 환율을 설명해달라”가 아니었습니다. 웹페이지를 열고, 데이터를 확인하고, 기준에 따라 분류하고, CSV 파일로 저장하고, 다시 열어 오류가 없는지 검증했습니다. 즉, 텍스트 생성이 아니라 업무 절차를 끝까지 수행한 것입니다.
### LLM 요청과 AI Agent 요청의 차이





구분

LLM에게 하는 요청

AI Agent에게 하는 요청




뉴스

최근 뉴스 내용을 요약해줘.

최근 7일 뉴스 제목을 수집하고, 출처 URL을 확인한 뒤, 긍정/부정으로 분류해서 CSV로 저장하고 검증해줘.




환율

최근 환율 흐름을 알려줘.

서울외국환중개 화면에서 최근 7영업일 USD/KRW 매매기준율을 확인하고, 1480원 기준으로 분류해 파일로 저장해줘.




검증

결과가 맞는지 봐줘.

저장된 파일을 다시 열어 행 수, 컬럼명, URL 누락, 분류 오류를 확인하고 문제가 있는 행을 알려줘.


### AI Agent가 실행하는 업무 흐름
1. 목표를 이해합니다.
2. 필요한 도구를 선택합니다.
3. 브라우저나 파일을 직접 조작합니다.
4. 데이터를 수집하고 기준에 따라 분류합니다.
5. 결과물을 저장합니다.
6. 저장된 결과를 다시 열어 검증합니다.
7. 오류나 다음 조치를 알려줍니다.
AI Agent를 잘 쓰려면 “무엇을 물어볼까?”에서 멈추지 않고, “어떤 작업을 어떤 기준으로 실행하고, 어떤 결과물까지 만들어야 하는가?”를 함께 지시해야 합니다. 리더의 역할은 답변을 받는 데서 끝나는 것이 아니라, 반복 업무를 실행 가능한 절차와 산출물로 정의하는 데 있습니다.
