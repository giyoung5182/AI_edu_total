# 실습 1 — 비정형 수익성 데이터를 Copilot으로 표 정리하기

정리일: 2026-10-08 · 교육 에셋 N1253

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
분야별로 표기 방식이 제각각인 모의 수익성 데이터를 Copilot으로 정형화하고 Excel에 옮깁니다.
## 진행 단계
1. **프롬프트와 데이터를 함께 전송** — Copilot 채팅 창에 아래 프롬프트와 교안의 모의 수익성 데이터를 함께 붙여넣습니다.
- 입력할 내용:
```javascript
아래 텍스트 데이터를 표로 정리해줘.
컬럼: 분야, 월, 매출(만원), 비용(만원), 수익(만원), 수익률(%)
- 수익 = 매출 - 비용으로 계산해줘.
- 수익률 = 수익 / 매출 × 100으로 계산하고 소수점 첫째 자리까지 표시해줘.
- 부동산처럼 월별 차이가 없는 경우 1~6월 각각 동일한 값으로 행을 만들어줘.
- 누락된 데이터는 "미확인"으로 표시해줘.

[모의 수익성 데이터 붙여넣기]
```
2. **출력된 표 검토** — 수익과 수익률 계산이 맞는지, 30개 행(5개 분야 × 6개월)이 모두 생성됐는지 확인합니다.
3. **Excel에 붙여넣기** — 열 구분이 무너졌다면 A열 선택 → 데이터 탭 → 텍스트 나누기 → 구분 기호로 분리 → 기타에 `|` 입력 → 마침
4. **표 서식 적용·저장** — `Ctrl + T`로 표 서식 적용 후 `수익성분석_실습.xlsx`로 저장
- 정상 결과: 분야·월별 매출, 비용, 수익, 수익률이 들어있는 30행 정형 데이터 표
## 막히는 지점
- 마크다운 표는 Excel에 붙이면 열 구분이 무너질 수 있어 텍스트 나누기를 씁니다.
- 사내 기밀·고객 개인정보는 외부 AI 서비스에 입력하지 말고 교안 샘플 데이터를 씁니다.
