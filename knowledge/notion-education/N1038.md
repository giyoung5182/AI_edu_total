# Step D · AI 인터뷰로 설계서 채우기

## 이 실습으로 하는 것
ChatGPT가 한 번에 하나씩 질문하고 사람이 답하는 방식으로 설계서의 빈칸을 채움.
## 진행 단계
1. **새 채팅 열기** — ChatGPT 사이드바 새 채팅. 같은 업무 자료를 계속 쓸 계획이면 그 업무 프로젝트 안의 새 대화도 가능.
2. **프롬프트 입력** — `[ ]`를 바꾸고 맨 아래에 메모장의 설계서를 붙여넣은 뒤 Enter.
- 입력할 내용:
```javascript
나는 교육기관 22에서 일한다. [업무 이름]을 자동화 도구로 만들기 전에 아래 설계서 1장을 채우려 한다.

진행 방식
- 바로 만들지 말고 먼저 질문해 줘. 한 번에 하나씩 질문해 줘.
- 설계서 1번 칸부터 순서대로, 비어 있거나 막연한 칸만 물어봐 줘.
- 6번 프로세스 쪼개기 표는 단계마다 "누가(사람 / AI) · 필요한 자료 · 결과물 · 판단이 필요한가"를 하나씩 물어봐 줘.
- 내가 모른다고 하거나 답이 없는 칸은 지어내지 말고 [확인 필요]로 남겨 줘.
- 회사 규정 수치·금액·기한은 추측해서 채우지 마.
(이하 교안 참고)
```
3. **인터뷰 진행** — 답은 짧게, 본인 업무에서 실제로 하는 것만. 모르면 "모름". AI가 선택지를 제안하면 본인 자료로 확인된 것만 고름.
4. **설계서 받기** — 코드 상자 오른쪽 위 Copy code → 메모장 D2P5_설계서.txt에 덮어 붙여넣기 → Ctrl+S. \[확인 필요\]로 남은 칸은 맨 아래에 모아 누구에게 확인할지 1줄씩.
- 정상 결과: 설계서 칸이 채워진 전체가 코드 상자 하나로 나옴.
## 막히는 지점
- 질문이 다른 칸으로 넘어가면 `지금 칸으로 돌아가 줘`.
- 대화가 길어져 앞 내용이 흐려지면 `지금까지 채운 설계서를 먼저 보여 줘` 후 저장하고 이어감.
