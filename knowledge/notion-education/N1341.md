# 실습 2. 위치 담당의 합류 — 채팅방에 지도가 뜬다

정리일: 2026-10-08 · 교육 에셋 N1341

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
대피소 데이터와 지도를 다루는 위치 담당을 투입해 채팅방에 지도가 올라오게 합니다.
## 진행 단계
1. **대피소 좌표 파일 추가** — shelters.csv를 현재 프로젝트 폴더에 추가합니다.
2. **프롬프트 입력** — 창②에 입력하고 진행한 뒤 서버를 재시작합니다.
- 입력할 내용:
```plain text
재난 대응 팀에 위치 담당을 추가해 주세요. 요구사항입니다.

1. 위치 담당(gemini-2.5-flash-lite)의 도구 동작입니다.
   - shelters.csv를 읽습니다. 시설명, 구분, 위도, 경도,
     주소 열이 있습니다.
(이하 교안 참고)
```
1. **질문** — "지금 여기서 지진이 나면 어디로 대피해야 하나요?" 검색 담당과 위치 담당의 배지가 함께 움직이는 것을 확인합니다.
2. **지도 확인** — 지도 카드 말풍선의 마커 세 개를 눌러 시설명과 거리를 확인합니다.
3. **실지 대조** — 가장 가까운 대피소 이름을 지도 앱이나 동네 지리와 맞춰 봅니다.
4. **브리핑 확인** — 행동요령(청크 근거)과 대피소 안내(위치 보고 근거)가 한 문서로 합쳐지고 근거 표기가 각각 달려 있으면 성공입니다.
## 막히는 지점
- 지도가 회색으로만 뜸 / 마커가 바다나 엉뚱한 곳에 찍힘 / 거리 값이 비현실적으로 큼 / CSV를 못 읽음 / 절약 모드 전환이 안 보임(429 미발생이면 정상)
