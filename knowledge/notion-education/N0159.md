## 0-4. 오늘의 방침 — 도구가 아니라 설계


## 원리 하나 \| 이미지 AI는 그림을 그리지 않고, 노이즈를 걷어낸다
**원리**
이미지 생성 AI 대부분은 확산 모델(Diffusion Model) 방식입니다. 학습 단계에서 정상 이미지에 노이즈를 덧씌워 완전한 잡음으로 만드는 과정을 관찰하고, 그 과정을 거꾸로 되돌리는 법을 배웁니다.
[원본 이미지 제외]
화가가 흰 종이에 선을 긋는 것이 아니라, 조각가가 돌덩어리에서 형태가 아닌 부분을 깎아 내는 쪽에 가깝습니다. **시작점이 무작위 잡음**이라는 점이 결정적입니다.
**그래서 생기는 현상**
- 같은 프롬프트를 넣어도 매번 결과가 다릅니다. 오류가 아니라 구조상 당연합니다.
- "아까 그거 다시 만들어 줘"가 되지 않습니다. 그 잡음은 사라졌습니다.
- 좋은 결과가 나오면 그 자리에서 저장해야 합니다.
**실전 노하우**
```plain text
잘못된 방식: "다시 만들어 줘"          → 완전히 다른 이미지
올바른 방식: "이 이미지에서 구도와 색감은 그대로 두고,
             상단 여백만 지금의 두 배로 넓혀 줘"  → 기준을 유지한 수정
```
**적용 지점** Part 2-7 체이닝, Part 2-8 수정 지시문

## 원리 둘 \| AI는 글자를 글자로 이해하지 않는다
**원리**
이미지 모델에게 문자는 의미를 가진 기호가 아니라 **특정한 형태의 무늬**입니다. 영문 알파벳은 26자에 형태가 단순하고 학습 데이터에 압도적으로 많습니다. 한글은 초성·중성·종성이 결합해 글자 수가 수천 자에 이르고 데이터 비중도 낮습니다.

**그래서 생기는 현상**
- 한글을 넣으면 한글처럼 생겼지만 존재하지 않는 글자가 나옵니다.
- 글자 수가 늘어날수록 왜곡이 심해집니다.
- 기관명이나 사업명이 잘못 표기되면 그대로 배포할 수 없습니다.
**주의**
공공기관 홍보 포스터는 문자 정보가 많습니다. 사업명, 신청 기간, 대상, 문의처가 모두 정확해야 합니다. **이미지 AI에게 이 정보를 그리게 시키면 안 됩니다.**
[원본 이미지 제외]
**실전 노하우**
```plain text
1단계  이미지 AI로 배경과 그래픽만 생성 (문구 없이, 여백 확보)
2단계  파워포인트에서 한글 텍스트 레이어 추가
3단계  폰트·크기·위치 조정하여 완성
```
이 방식은 왜곡이 없을 뿐 아니라, 신청 기간이 바뀌었을 때 텍스트만 고치면 된다는 실무적 이점이 훨씬 큽니다.
**적용 지점** Part 3 전체, 3권 부록 C

## 원리 셋 \| 학습한 것의 평균으로 수렴한다
**원리**
AI는 학습 데이터에서 본 것들의 통계적 중심을 향해 결과를 만듭니다. 프롬프트가 짧고 막연할수록 그 중심값에 가까운 결과가 나옵니다.
"홍보 포스터"라고만 입력하면 AI가 학습한 수천만 장의 평균이 나옵니다. 어디선가 본 것 같은, 무료 템플릿처럼 보이는 결과의 정체입니다.
**그래서 생기는 현상**
- 짧은 프롬프트 → 흔한 결과
- 다른 기관 홍보물과 구분되지 않는 이미지
- "전문적인", "세련된", "고급스러운" 같은 형용사는 거의 작동하지 않습니다. 그 단어의 시각적 기준이 학습 데이터마다 달라 결국 평균으로 돌아갑니다.
**실전 노하우**
형용사를 명사와 수치로 바꾸세요.

## 원리 다섯 \| 내 프롬프트는 한 번 번역된다
**원리**
ChatGPT나 Gemini에서 이미지를 만들 때, 입력한 한국어 문장이 이미지 모델에 곧바로 들어가지 않습니다. 언어 모델이 해석해서 이미지 모델이 알아듣는 형태로 다시 작성한 뒤 전달합니다.
```plain text
[내 한국어 문장]  →  언어 모델이 해석·재작성  →  [이미지 모델]  →  결과
```
**그래서 생기는 현상**
- 한국어로 써도 됩니다. 굳이 영어로 옮길 필요가 없습니다.
- 대화로 수정 지시가 통합니다. "조금 더 밝게"가 작동하는 이유입니다.
- 반대로 내가 쓴 표현이 그대로 반영되지 않는 경우가 생깁니다.
- 같은 프롬프트를 다른 도구에 넣으면 결과 차이가 큽니다. 중간 번역기가 다르기 때문입니다.
**실전 노하우**
정밀 제어가 필요할 때는 재작성을 통제하세요.
```plain text
"아래 프롬프트를 해석하거나 바꾸지 말고 그대로 사용해서 이미지를 만들어 줘."
```
아이디어 단계에서는 반대로 활용하세요. **AI에게 프롬프트 자체를 쓰게 하는 것**이 가능합니다.
```plain text
"교육기관 청년 채용박람회 홍보 포스터를 만들려고 해.
 이미지 생성용 프롬프트를 6요소 구조로 3안 작성해 줘.
 아직 이미지는 만들지 말고 프롬프트만 줘."
```
이것이 2권 Part 4의 설계서 개념과, 3권 부록 B의 프롬프트 비서 Gem이 성립하는 근거입니다.

## 원리 여섯 \| 슬라이드는 디자인보다 구조가 먼저 정해진다
**원리**
발표자료 자동 생성 도구는 입력을 받으면 곧바로 디자인을 시작하지 않습니다. 먼저 내용을 슬라이드 단위로 쪼개고 위계를 잡습니다. 그 구조가 정해진 다음에 레이아웃이 결정됩니다.
```plain text
[입력]  →  구조 분해  →  장 단위 분할  →  레이아웃 배치  →  [슬라이드]
              ↑
      여기 품질이 결과 품질을 좌우합니다
```
**그래서 생기는 현상**
- 주제 한 줄만 입력하면 AI가 구조를 혼자 지어냅니다. 그럴듯하지만 우리 기관 내용이 아닙니다.
- 디자인이 아무리 좋아도 구조가 틀리면 쓸 수 없습니다.
- 생성 후 편집으로 구조를 고치는 것은 처음부터 다시 만드는 것과 비슷한 노력이 듭니다.
**실전 노하우**
**구조를 사람이 먼저 확정하고, AI에게는 그것을 시각화하는 일만 맡기세요.** 이것이 2권 Part 4 설계서의 존재 이유입니다.
**적용 지점** 2권 Part 4 전체

## 원리 일곱 \| 한 장에 한 메시지여야 레이아웃이 잡힌다
**원리**
슬라이드 AI는 한 장에 담긴 내용의 밀도를 보고 레이아웃을 고릅니다. 내용이 하나면 큰 제목과 여백이 있는 레이아웃을, 항목이 셋이면 3분할 레이아웃을 고릅니다. 여러 주제가 섞여 있으면 판단하지 못하고 글자만 빽빽한 장이 나옵니다.
**실전 노하우**
설계서를 쓸 때 **한 항목 = 한 메시지 = 한 장**으로 미리 쪼개세요.
그리고 각 장의 제목을 주제어가 아니라 결론 문장(헤드메시지)으로 쓰세요.

## 2-2. 공공기관 포스터의 정보 위계
포스터를 만들기 전에 어떤 정보가 어느 자리에 들어가는지부터 정합니다. 이것이 정해져야 여백을 어디에 확보할지 결정됩니다.
[원본 이미지 제외]
```plain text
[상단]      기관명 / 로고
            ↓
[상단 1/3]  사업명 (가장 큰 글씨)
            부제 또는 한 줄 설명
            ↓
[중단]      배경 그래픽 영역  ← AI가 만드는 부분
            ↓
[하단 1/3]  지원 대상
            신청 기간
            신청 방법
            문의처
            ↓
[최하단]    주최·주관 표기
```
**실전 노하우**
여기서 나오는 결론이 프롬프트의 마지막 문장입니다.
```plain text
"상단 3분의 1과 하단 3분의 1은 단색 여백으로 비워 두고,
 시각 요소는 중앙 영역에만 배치해 줘."
```
여백을 지정하지 않고 만든 이미지는 나중에 텍스트를 얹을 자리가 없어 결국 다시 만들게 됩니다. `원리 넷`의 긍정형 전환이기도 합니다.

## 2-5. 나쁜 프롬프트와 좋은 프롬프트
### 사례 1 — 기업지원부, 지원사업 모집 공고 포스터
```plain text
나쁜 프롬프트

"중소기업 지원사업 모집 포스터 만들어 줘. 전문적이고 신뢰감 있게.
 글자는 '2026년 중소기업육성자금 모집'이라고 넣어 줘."
```
무엇이 문제인가
- 형용사만 있음 `원리 셋`
- 한글 문구를 이미지에 넣게 시킴 `원리 둘`
- 규격과 여백 지정 없음
- 주제가 추상적임. "지원사업"은 시각적 형태가 없음
```plain text
좋은 프롬프트

플랫 벡터 일러스트 스타일로 만들어 줘.
화면 중앙에 서류 한 묶음과 노트북, 작은 화분 하나가 놓인 책상을
위에서 수직으로 내려다본 구도로 그려 줘.
책상 위 물건은 세 개까지만 두고 나머지는 비워 줘.
색은 짙은 남색과 흰색만 사용하고 강조색은 주황 하나만,
모든 면은 단색으로 채우고 경계선은 뚜렷하게 표현해 줘.
배경은 밝은 회색 단색이야.
상단 3분의 1과 하단 3분의 1은 밝은 회색 단색으로 비워 두고,
시각 요소는 중앙 영역에만 배치해 줘.
세로 3:4 비율, 고해상도.
```
### 사례 2 — 일자리지원부, 채용박람회 포스터
```plain text
나쁜 프롬프트

"채용박람회 포스터. 사람 많고 활기찬 분위기로. 글자 없이."
```
무엇이 문제인가
- "글자 없이"가 `원리 넷` 정면 위반
- "활기찬"은 `원리 셋`의 형용사 함정
- 실제 사람 얼굴이 나오면 초상권 검토가 필요해짐
```plain text
좋은 프롬프트

아이소메트릭 일러스트 스타일로 만들어 줘.
넓은 전시홀 안에 부스가 격자로 배치되어 있고,
부스 사이를 걷는 사람들은 얼굴 이목구비 없이
단순화된 실루엣 형태로 표현해 줘.
위에서 45도 각도로 내려다본 부감 구도,
밝고 균일한 조명,
색은 짙은 청록과 밝은 노랑 두 계열로만 제한하고
모든 면을 단색으로 채워 줘.
상단 40%와 하단 25%는 흰색 단색으로 비워 두고
부스 영역은 중앙에만 배치해 줘.
세로 3:4 비율, 고해상도.
```
**실전 노하우**
인물을 실루엣이나 단순화된 형태로 지정하면 초상권 리스크가 낮아지는 동시에, 어색한 AI 얼굴 문제도 함께 해결됩니다. 공공기관 홍보물에서는 특정 성별·연령에 치우친 인물 묘사가 지적받는 경우도 있어, 형태를 단순화하는 편이 안전합니다.

## 2-7. 발산에서 수렴으로 — 체이닝 4단계

```plain text
1단계  발산 (텍스트만, 이미지 생성 안 함)

       "2번 방향으로 6요소 구조 프롬프트를 작성해 줘. 아직 만들지 마."
       → 빠진 요소를 채웁니다

3단계  생성
       완성된 프롬프트로 1회 생성

```
1·2단계를 건너뛰고 곧바로 생성하면 마음에 안 들 때마다 재생성하게 됩니다. 한도를 소진시키는 가장 흔한 패턴입니다.

# Part 3. 한글 텍스트 얹기와 포스터 완성 (10분)
## 3-1. 왜 한글이 깨지는가
`원리 둘`
이미지 모델에게 문자는 의미가 아니라 형태입니다. 한글은 조합형 문자라 경우의 수가 방대하고 학습 데이터 비중도 낮습니다.
**핵심**
이것은 **개선되기를 기다릴 문제가 아니라 우회할 문제**입니다. 설령 한글 렌더링이 완벽해져도, 신청 기간이 바뀔 때마다 이미지를 다시 생성해야 한다면 실무에서는 비효율입니다. 텍스트를 분리해 두는 방식은 정확도와 무관하게 그 자체로 옳은 작업 구조입니다.
---
## 3-2. 해결법 세 가지
### 해결법 1 — 생성과 텍스트를 분리한다 (오늘 쓰는 방식)
```plain text
1  이미지 AI로 배경 그래픽만 생성 (문구 없이, 여백 확보)
2  파워포인트로 가져오기
3  한글 텍스트 레이어 추가
4  폰트·크기·자간·위치 조정 후 내보내기
```
### 해결법 2 — 짧은 영문은 텍스트 특화 도구로
영문 슬로건이 필요하다면 Ideogram 계열이 유리합니다. 다만 한글은 여전히 왜곡되므로 국문 표기가 필수인 공공 홍보물에는 적용 범위가 좁습니다.
### 해결법 3 — 여백을 프롬프트로 설계한다
`원리 넷`
```plain text
"상단 3분의 1과 하단 3분의 1은 단색 여백으로 비워 두고,
 시각 요소는 중앙 영역에만 배치해 줘."
```
이 한 문장이 재생성 횟수를 크게 줄입니다.
---
## 3-3. 파워포인트로 한글 얹기
별도의 디자인 도구를 새로 배우지 않아도 됩니다. 파워포인트는 이미 설치되어 있어 추가 가입이 필요 없고, 기관 보안 정책상 외부 서비스 사용이 제한되는 경우에도 문제가 없습니다.
```plain text
1  디자인 - 슬라이드 크기 - 사용자 지정에서 규격 설정
   (A4 세로: 21cm × 29.7cm / 정사각형: 25cm × 25cm)
2  이미지 삽입 후 슬라이드 전체에 맞춤
3  텍스트 상자 추가, 확보한 여백 위에 배치
4  가독성이 부족하면 반투명 도형을 텍스트 뒤에 깔기
   (도형 삽입 - 채우기 - 투명도 30~50%)
5  파일 - 다른 이름으로 저장 - PNG 또는 PDF
```
**실전 노하우**
배경 제거가 필요하면 그림 서식의 배경 제거 기능을 쓰세요. 기관 로고를 배경 없이 얹을 때 유용합니다.

## 3-4. 포스터 텍스트 작성 원칙
배경보다 중요한 것이 문자 정보입니다. 세 가지만 지키세요.
**첫째, 사업명은 한 줄에 들어가게.** 두 줄로 넘어가면 시선이 분산됩니다. 긴 사업명은 앞부분을 작게 뒷부분을 크게 처리하세요.
```plain text
2026년 충청북도            ← 작게
중소기업육성자금 모집      ← 크게
```
**둘째, 하단 정보는 네 항목 이하로.** 대상·기간·방법·문의처가 기본입니다. 더 필요한 정보는 QR코드로 연결하세요.
**셋째, 글자 크기 위계를 세 단계로만.** 사업명(가장 큼) / 소제목 / 본문. 네 단계 이상이면 지저분해집니다.
