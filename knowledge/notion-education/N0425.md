# 실습 4. 데이터 운영 확산 로드맵 수립

정리일: 2026-10-08 · 교육 에셋 N0425

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 팀·부서의 6개월 데이터 운영 로드맵을 단계별 과제·담당자·완료 기준·KPI와 함께 작성합니다.
## 진행 단계
1. **1단계(1\~2개월)** — 기반 과제 2가지 이상
2. **2단계(3\~4개월)** — 체계 구축 과제 2가지 이상
3. **3단계(5\~6개월)** — 확산·고도화 과제 1가지 이상
4. **과제별 담당자·완료 기준·KPI 1개 기재** — KPI는 "핵심 데이터 완전성 95% 이상"처럼 수치로
## 막히는 지점
- 1단계에 모든 것을 하려는 욕심 주의, 기반 → 체계 → 확산 순서 준수
