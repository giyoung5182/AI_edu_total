# 홍보 문구 변환 프롬프트 — 센터 계정용 / 개인 채널용

정리일: 2026-10-08 · 교육 에셋 N0674

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
딥딕한 정책 안내문을 읽는 사람 기준의 인스타 문구로 바꾸고, 개인 채널용 글도 만듭니다.
## 진행 단계
1. **센터 계정 게시물용 문구 3안**
- 입력할 내용:
```plain text
너는 청년 정책을 청년 눈높이로 옮기는 홍보 담당자야.

[안내문]
(공고 내용 그대로 붙여넣기)

위 안내문을 인스타그램 게시물 문구로 바꾸어 줘. 아래 조건을 지켜 줘.

1. 첫 문장은 정책 이름이 아니라, 읽는 사람이 겪었을 상황으로 시작할 것
2. 전체 다섯 줄 이내
3. 신청 자격과 마감일은 반드시 포함할 것
4. 안내문에 없는 내용은 절대 만들어내지 말 것.
   확인이 필요한 부분은 [확인 필요]로 표시할 것
5. 느낌표는 두 개까지만
6. "여러분", "많은 관심 바랍니다" 같은 표현은 쓰지 말 것
7. 마지막에 저장하거나 친구에게 보낼 이유가 되는 한 줄을 붙일 것

문구 3안을 서로 다른 시작점으로 작성해 줘.
```
- 정상 결과: \[확인 필요\]로 표시된 항목이 있으면 반드시 원문과 대조
1. **개인 채널용 글** — \[정보\]와 ［내 계정 성격］(플랫폼·평소 말투·팔로워)을 넣고 홍보처럼 보이지 않게, 내 경험에서 시작하는 두 가지 버전을 요청합니다(교안 프롬프트 참고). 말투를 설명하지 말고 내가 쓴 글을 붙여 말투·구조·문장 호흡을 추출하게 하는 방법도 있습니다.
2. **본인 말투로 고쳐 게시** — AI가 쓴 걸 그대로 올리지 않고 본인 말투로 한 번 고칩니다.
## 막히는 지점
- AI는 모르는 정보를 그럴듯하게 지어냄 — 날짜·금액·자격 요건은 사람이 직접 확인
- 참여자 명단, 연락처, 신청서 같은 자료는 AI에 올리지 않음
