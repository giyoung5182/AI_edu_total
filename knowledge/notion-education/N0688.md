# 캔바에서 명함을 처음부터 만듭니다 (작업 파일·안전 영역 사각형)

정리일: 2026-10-08 · 교육 에셋 N0688

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
캔바에서 92 × 52mm 명함 작업 파일을 만들고, 글자 배치 기준이 되는 74 × 34mm 안전 영역 사각형을 만듭니다.
## 진행 단계
1. **엑셀 확인** — `명함 설계·검수` 시트를 열고 `C7:C19`의 선택 유형과 앞·뒷면 내용을 확인합니다. QR이나 뒷면을 선택하지 않았다면 관련 칸은 비워 둡니다.
2. **맞춤형 크기 만들기** — 캔바 로고(홈) → 맞춤형 크기 → 단위를 px에서 mm로 변경 → 가로 92, 높이 52 입력 → 새 디자인 만들기 → 디자인 이름을 본인 이름으로 변경
- 정상 결과: 단위를 먼저 mm로 바꾼 뒤 숫자를 넣습니다.
3. **안전 영역 사각형 만들기** — 요소 → `사각형` 검색 → 사각형 선택 → 위치 → 고급에서 가로 74, 높이 34, 좌표 X 9, Y 9 입력 → 투명도로 연하게 조절
- 정상 결과: 이 사각형은 4권에서 삭제합니다(안전 영역 확인용).
## 막히는 지점
- 단위를 먼저 mm로 바꾸고 숫자를 넣습니다.
- 사각형을 지우는 것을 잊으면 명함에 네모 테두리가 인쇄됩니다.
