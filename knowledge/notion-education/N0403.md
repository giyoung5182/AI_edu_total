# 실습 2-B-1. 존 컨셉 텍스트 생성

정리일: 2026-10-08 · 교육 에셋 N0403

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
부스 내 3개 존의 컨셉 텍스트를 생성한다. 헤더 사인·인쇄물·제안서에 바로 쓸 수 있는 수준을 목표로 한다.
## 진행 단계
1. **프롬프트 입력 (6분)** — 교안의 RCTCK 프롬프트와 \[전시 정보\]를 입력한다.
- 입력할 내용: 전시 공간 브랜딩 카피라이터 역할로 존마다 ① 존 네이밍 ② 한 줄 서브타이틀 ③ 타겟 페르소나 ④ 존 설명문 ⑤ 핵심 씬 3가지 ⑥ 소재·분위기 키워드 5개와 세 존의 스토리 흐름 요약을 요청 (이하 교안 참고)
2. **결과 확인 (3분)** — 네이밍이 2\~4단어로 기억에 남는지 / 페르소나가 나이·직업·도시로 구체화됐는지 / 설명문이 제품 나열이 아닌 생활 장면인지 / 존 사이 스토리 흐름이 있는지 / "혁신", "특별한" 같은 진부한 표현이 없는지.
- 정상 결과: 교안의 기대 출력 예시(THE CRAFTSMAN'S ROOM, FOREST TOUCH, SLOW HOME)와 같은 구조
3. **체이닝 (4분)** — 네이밍 대안 9개 요청 / 1인칭 감각 묘사로 설명문 다시 쓰기. 실제 프로젝트에서는 \[전시 정보\]만 바꿔 다시 실행한다.
