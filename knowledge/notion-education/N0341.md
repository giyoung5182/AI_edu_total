# STEP 4 · 제작 요청문 (포트폴리오 웹페이지 만들기)

정리일: 2026-10-08 · 교육 에셋 N0341

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
재료 문서만 사용해 여덟 섹션짜리 포트폴리오 웹페이지(portfolio.html)를 대화로 만듭니다.
## 진행 단계
1. **요청문 채우기** — \[지원 직무\]와 전체 톤(전문적/간결한/따뜻한/과감한 중 하나)을 채웁니다.
- 입력할 내용:
```plain text
[R] 당신은 개인 포트폴리오 웹페이지를 만드는 웹 디자이너입니다.
채용 담당자가 3분 안에 훑어보는 페이지를 주로 만듭니다.

[C] 저는 [지원 직무] 직무로 지원하는 경력 전환자입니다.
이 폴더의 portfolio-source.docx 에 제 재료가 들어 있습니다.

[T] 아래 여덟 개 섹션으로 단일 HTML 파일을 만들어
이 폴더에 portfolio.html 이름으로 저장하세요.
1. 첫 화면 2. 소개 3. 경력 4~6. 경험 3건 7. 역량 8. 연락처
(이하 교안 참고)
```
1. **결과 확인** — portfolio.html을 더블클릭해 브라우저로 엽니다.
- 정상 결과: 여덟 섹션이 다 있고 순서가 맞으며, 내 문장이 살아 있고, 없는 경력·숫자가 없고, 경험마다 결과가 보이며, 창을 좁혀도 글자가 겹치지 않음.
## 막히는 지점
- 파일 하나 안에 넣으라는 제약이 없으면 CSS 파일이 따로 생겨 메일로 보내면 디자인이 깨집니다.
- 외부 링크를 불러오지 말라는 제약이 없으면 인터넷이 없는 곳에서 글꼴과 배치가 무너집니다.
- 가짜 프로젝트를 만들지 말라는 제약이 없으면 빈 섹션을 채우려고 없는 경력이 들어옵니다.
