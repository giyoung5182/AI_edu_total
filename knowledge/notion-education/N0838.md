## 실습 전 핵심 개념 — AI 보고서 초안의 올바른 활용법
AI가 보고서를 잘 써줘도 그대로 제출하면 안 되는 이유가 있습니다.
**AI가 잘하는 것:**
```plain text
✅ 숫자를 문장으로 빠르게 변환
✅ 일관된 형식·문체 유지
✅ 보고서 구조 자동 생성
✅ Word 파일로 즉시 다운로드
✅ 대상별 맞춤 톤 조정 (본부장용 vs 내부용)
```
**AI가 못하는 것:**
```plain text
❌ 현장 맥락 해석
   ("된장육수가 급감한 게 행사 때문인지 오입력 때문인지")
❌ 내부 의사결정 기준 반영
   ("이 품목은 3일치 재고가 있으면 안전한 회사 기준")
❌ 미래 예측·리스크 판단
❌ 최종 책임
```
**올바른 활용 공식:**
```plain text
AI 초안(80%) + 담당자 현장 맥락 추가(20%) = 완성본

잘못된 활용:
AI 초안을 그대로 제출 → 현장 맥락 없는 보고서
```

### 보고서 초안 검토 3단계
초안이 나오면 바로 제출하지 말고 반드시 확인합니다.
**1단계. 수치 대조**
핵심 수치 3개를 원본 분석 결과와 직접 비교합니다.
```plain text
확인할 수치:
① 월간 출고 TOP 1 수치 (700,625인가)
② 긴급 품목 수 (1개인가, 품목명이 청양고추인가)
③ 돌판김치 불일치 차이 (982개인가)
```
**2단계. 현장 맥락 추가**
AI가 알 수 없는 현장 상황을 직접 추가합니다.
```plain text
AI가 쓴 것: "된장육수 실재고 1개로 즉시 발주 필요"

담당자가 추가할 것:
"→ 5월 행사로 인한 소비 급증. 내일 입고 예정(5월 28일).
   발주는 완료됐으나 입고 전 매장 출고 시 부족 가능."
```
**3단계. 보고 대상 확인**
```plain text
본부장님 보고용: 수치 중심, 전문 용어 최소, 결론 먼저
내부 담당자용: 상세 내용 포함, 조치 항목 구체적으로
```
보고 대상이 다르면 같은 채팅에서 이어서 요청:
```plain text
위 보고서를 본부장님 보고용 2~3줄 요약 버전으로도 만들어줘.
수치와 즉시 조치 사항 중심으로.
```

### DSRF 직접 작성 — 단계별 연습 가이드
처음 DSRF를 혼자 작성하는 분들을 위한 단계별 가이드입니다.
**STEP 1: 질문을 먼저 한국어로 적는다**
```plain text
"이번 달 차량 수리비를 카테고리별(식대/유류대/차량정비/기타)로
 얼마씩 썼는지 알고 싶어."
```
**STEP 2: 질문에 필요한 데이터가 어디 있는지 파악한다**
```plain text
파일명: 통장내역_비교.xlsx
시트: Sheet1
관련 열: A(날짜), B(거래처명), C(분류), D(금액)
데이터 범위: 2행~200행
```
**STEP 3: 어떤 형태로 결과를 받을지 결정한다**
```plain text
표: | 카테고리 | 건수 | 금액 | 비율(%) |
정렬: 금액 내림차순
추가: 맨 아래에 총합 행
```
**STEP 4: 제외할 것을 생각한다**
```plain text
- 합계 행 제외
- 금액이 0원인 항목 제외
- 분류 열이 비어있는 항목은 "기타"로 처리
```
**STEP 5: DSRF로 합친다**
```plain text
[D] 첨부한 파일은 5월 차량 수리 내역이야.
    Sheet1에 날짜(A열)·거래처명(B열)·분류(C열)·금액(D열)이 있어.
    데이터는 2행~200행이야.

[S] 이번 달 차량 관련 지출을 카테고리별로 집계하고 싶어.
    월말 결산 보고서 작성에 활용할 예정이야.

[R] 아래 표로 만들어줘:
    | 카테고리 | 건수 | 금액(원) | 비율(%) |
    금액 기준 내림차순 정렬.
    맨 아래에 전체 합계 행 추가.

[F] 합계 행 제외.
    금액 0원 항목 제외.
    분류가 비어있는 항목은 "기타"로 처리.
    금액은 천 단위 콤마 포함. 비율은 소수점 1자리 %.
```

### 4회차 예고 — 자동화가 어디까지 가능한가
오늘 배운 것들은 모두 "사람이 요청하면 AI가 처리"하는 방식입니다. 4회차부터는 "사람이 요청하지 않아도 자동으로 처리"하는 방식으로 넘어갑니다.
```plain text
3회차까지 (반자동):
담당자가 파일을 열고 → Claude에 업로드하고 → 프롬프트를 입력하고 → 결과를 받아서 → 보고서를 작성한다

4회차 이후 (자동):
파일이 업데이트되면 → Make.com이 자동으로 감지하고 → Claude가 자동으로 분분석하고 → 결과가 카카오톡으로 자동 발송된다
```
오늘 만든 보고서 프롬프트 템플릿이 4회차 자동화의 핵심 재료가 됩니다. 오늘 프롬프트를 잘 저장해두는 것이 4회차 준비의 시작입니다.
