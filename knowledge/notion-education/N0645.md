# 업무 15건 분류 + 우리 팀 기준 1줄 (판단표)

정리일: 2026-10-08 · 교육 에셋 N0645

## 이 실습으로 하는 것
AI 없이, 3축(근거·검증·책임)으로 업무 15건을 A/B/C 3등급으로 분류하고 우리 팀 기준 1줄을 정해 판단이 갈리는 지점을 드러냅니다.
## 진행 단계
1. **먼저 예측** — 12건 중 옆 사람과 등급이 다를 것 같은 번호 2개.
2. **우리 팀 기준 1줄 정하기** — 형식 `[조건]이면 한 등급 올린다/내린다`를 P1-5 우리 팀 기준 칸에 기록.
3. **개인 분류** — 12건 + 내 업무 3건(13\~15행의 '(내 업무)'를 더블클릭해 본인 업무 입력). 근거·검증·책임 칸은 ▼ 목록에서 O/△/X 선택, 등급은 A/B/C 선택, 이유 칸에 근거·검증·책임 중 하나 이상의 단어를 넣어 한 줄.
- 3축 표시 뜻: 근거 O = 판단 자료를 AI에게 줄 수 있음 / 검증 O = 틀렸을 때 알아챌 수 있음 / 책임은 틀렸을 때 영향이 작으면 O, 크면 X로 통일(교안: 확인 필요 표기).
4. **옆 사람과 비교** — 판단이 갈린 번호 1개를 기록.
## 막히는 지점
- 책임 축 O/X 방향은 교안·워크시트에 정의 없음 — 강사 안내에 따름.
