# Step C·D · 설계서 1장을 ChatGPT 인터뷰로 채우기

정리일: 2026-10-08 · 교육 에셋 N1529

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설계서 1장 틀을 채우고, ChatGPT가 한 번에 하나씩 묻는 인터뷰로 빈칸을 완성합니다.
## 진행 단계
1. **설계서 틀 붙여넣기 (Step C)** — 틀(1 업무 이름 \~ 14 진행 상황: 위임표 출처, 지금 방식과 걸리는 시간, 목표, 입력 자료, 프로세스 쪼개기 표, 도구 조합, 지침(ROPEK 요약), 폴더 구조, 자동 실행(트리거), 사람이 판단할 지점, 완료 기준, 주의)을 메모장에 붙여넣고 Step A·B에서 적은 것부터 옮겨 적은 뒤 `D2P5_설계서.txt`로 저장합니다.
2. **인터뷰 프롬프트 실행 (Step D)** — ChatGPT 새 채팅에 아래 프롬프트를 `[ ]`만 바꿔 입력하고 맨 아래에 메모장의 설계서를 붙여넣습니다.
- 입력할 내용:
```javascript
나는 [회사]에서 일한다. [업무 이름]을 자동화 도구로 만들기 전에 아래 설계서 1장을 채우려 한다.
진행 방식
- 바로 만들지 말고 먼저 질문해 줘. 한 번에 하나씩 질문해 줘.
- 설계서 1번 칸부터 순서대로, 비어 있거나 막연한 칸만 물어봐 줘.
- 6번 프로세스 쪼개기 표는 단계마다 "누가 · 필요한 자료 · 결과물 · 판단이 필요한가"를 하나씩 물어봐 줘.
- 내가 모른다고 하거나 답이 없는 칸은 지어내지 말고 [확인 필요]로 남겨 줘.
- 회사 규정 수치·금액·기한은 추측해서 채우지 마.
- 절대 니가 직접 제작하지는 마. 코드·지침·파일은 만들지 말고 설계서만 채워.
- 질문이 끝나면 설계서 1~13번 칸을 채운 전체를 코드 상자 하나로 보여 줘.
[메모장의 설계서 붙여넣기]
```
3. **인터뷰 진행** — 답은 짧게, 본인 업무에서 실제로 하는 것만, 모르면 "모름". 질문이 다른 칸으로 넘어가면 "지금 칸으로 돌아가 줘", 대화가 길어져 앞 내용이 흐려지면 "지금까지 채운 설계서를 먼저 보여 줘" 후 메모장에 저장하고 이어갑니다.
4. **저장** — 코드 상자 Copy code → 메모장 `D2P5_설계서.txt`에 덮어 붙여넣기 → Ctrl+S. `[확인 필요]`로 남은 칸은 맨 아래에 모아 누구에게 확인할지 1줄씩 적습니다.
## 막히는 지점
- 질문이 다른 칸으로 넘어감 / 대화가 길어져 앞 내용이 흐려짐 → 위 인터뷰 요령 참고.
