# PoC 경로 A Step 3. 대시보드 생성 (Claude Code)

정리일: 2026-10-08 · 교육 에셋 N0385

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정제된 cleaned_data.xlsx로 로컬에서 계속 쓸 수 있는 Streamlit 대시보드를 만들고, 내 실제 데이터로 교체한다.
## 진행 단계
1. **터미널에서 Claude Code 실행** — VS Code 터미널 또는 PowerShell에서 폴더로 이동해 claude를 실행한다.
- 입력할 내용:
```javascript
cd poc
claude
```
2. **프롬프트 입력** — 사이드바 필터, KPI 카드 4개, 월별 매출 추이 라인차트, 팀별 매출 수평 막대차트, 상세 테이블, CSV 다운로드 버튼을 요청한다.
- 입력할 내용:
```javascript
이 폴더의 cleaned_data.xlsx로 Streamlit 대시보드를 만들어줘.

【파일 정보】
- 컬럼: 날짜(datetime) | 담당팀(str) | 러닝화_검색량 | 등산화_검색량 | 매출(int)
- 데이터: 월간 13행
- 팀 종류: 마케팅팀, 영업팀, 전략팀

【구현 요구사항】
1. 사이드바 필터 — 팀 선택(멀티셀렉트, 기본값: 전체), 기간 선택(date_input)
2. KPI 카드 4개 — 총 매출 합계, 월평균 매출, 매출 최고월(날짜+금액), 매출 최저월(날짜+금액)
3. 월별 매출 추이 라인차트 — 팀별 색상 구분 + 전체 합산 라인
4. 팀별 매출 비교 수평 막대차트 — 매출 금액 라벨 표시 (억원 단위)
5. 월별 상세 데이터 테이블 — 정렬 기능 (날짜/매출 기준), 매출 ₩ 포맷
6. CSV 다운로드 버튼 (필터링된 데이터 기준)

【기술 조건】
- Plotly 차트 사용 (matplotlib 금지)
- __file__ 기준 상대경로로 데이터 로드
- st.plotly_chart()에 고유 key 추가
- 파일명: cleaned_dashboard.py
- 한국어 주석 포함

파일을 만든 뒤 필요한 패키지(streamlit, plotly, openpyxl 등)를 설치하고,
streamlit으로 실행해서 브라우저에서 확인할 수 있게 해줘.
에러가 나면 직접 수정해서 다시 실행해줘.
```
3. **실행 확인** — Claude Code가 파일 생성 → 패키지 설치 → 실행까지 진행한다. 실행 승인을 요청하면 Yes를 선택한다.
- 정상 결과: 브라우저에서 [개별 링크 제외] 에 대시보드가 열린다.
4. **성공한 방식을 재사용 규칙으로 저장** — CLAUDE.md / SKILL.md로 저장하는 단계(교안 토글 안의 이미지 참고).
5. **내 데이터로 교체 (PoC 핵심)** — 코드를 직접 고치지 말고 Claude Code에 말로 요청한다.
- 입력할 내용:
```javascript
데이터 파일을 내 실제 파일인 [파일명]으로 바꿔줘.
컬럼 구성이 달라: [실제 컬럼명 나열]
파일을 먼저 읽어보고 차트와 KPI를 내 데이터에 맞게 수정해서 다시 실행해줘.
```
