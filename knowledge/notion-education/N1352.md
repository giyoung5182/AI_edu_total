# 활동 2-3 — 텍스트 응답 분석

정리일: 2026-10-08 · 교육 에셋 N1352

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설문 주관식 응답을 주제별로 분류하고 대표 응답을 원문 그대로 인용합니다. (8분)
## 진행 단계
1. **분석 요청** — 아래 프롬프트를 입력합니다.
- 입력할 내용:
```javascript
"가장_불편한점"과 "개선_희망사항" 열의 주관식 응답을 분석하라.

1. 무응답 건수와 비율
2. 응답 내용을 5개 이내 주제로 분류하고, 주제별 건수
3. 각 주제의 대표 응답 1건씩 인용 (원문 그대로)
4. 여러 주제에 걸치는 응답은 "복합"으로 별도 표기
5. 분류가 애매한 응답은 "분류 보류"로 표기

주의:
- 응답에 없는 내용을 추가하지 마라
- 원문을 요약할 때 의미를 바꾸지 마라
- 무응답을 임의로 해석하지 마라
```
1. **워크시트 작성** — 주제·건수·대표 응답(원문)과 무응답, 분류 보류, 복합 건수를 적습니다.
## 막히는 지점
- 원문을 다듬어 인용하면 온도가 사라짐
- 주제를 너무 크게 잡으면 아무 정보도 없음
- 건수만 세고 내용을 안 보면 1건짜리 응답이 가장 중요할 수 있음
- 무응답을 임의로 해석하지 않음
