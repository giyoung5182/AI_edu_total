# 5-10. 직접 써보기 — 향후 과제 (나만의 업무 비서 만들기)

정리일: 2026-10-08 · 교육 에셋 N1022

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지도자님 업무 중 매달 또는 매 기수마다 반복되는 것 하나를 골라 업무 비서(Gem)를 만들고 결과물 1건을 뽑습니다.
## 진행 단계
1. **반복 업무 고르기** — 아래 양식의 맨 위 칸에 적습니다.
2. **여섯 덩어리 지침 채우기** — 양식을 채웁니다.
- 입력할 내용:
```plain text
[내가 반복하는 업무]
_____________________________________________

[1. 너는 누구인가]
_____________________________________________

[2. 우리 기관 정보]
_____________________________________________

[3. 무슨 일을 하나]
_____________________________________________

[4. 항상 지킬 규칙]
- ___________________________________________
- ___________________________________________
- ___________________________________________

[5. 절대 하지 말 것]
- ___________________________________________
- ___________________________________________

[6. 시작할 때 물어볼 것]
1) __________________________________________
2) __________________________________________
3) __________________________________________
```
3. **Gem으로 저장** — 5-4의 순서(Gemini 앱 → Gems → 새 Gem → 이름 → 지침 칸 → 저장)로 만듭니다.
4. **결과물 1건 뽑기** — 만든 비서로 결과물을 하나 받습니다.
