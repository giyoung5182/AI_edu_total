# 실습 1. 워크시트 작성과 트랙 선택

정리일: 2026-10-08 · 교육 에셋 N1209

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
미션 정의 워크시트 다섯 칸을 채워 만들 프로젝트를 확정합니다.
## 진행 단계
1. **워크시트 작성** — ① 해결할 일 → ② 입력 자료 → ③ 원하는 출력 → ④ 필요한 부품 → ⑤ 팀 명단 순서로 종이나 메모장에 적기 (데이터 → 도구 → 역할 순서)
2. **트랙 선택** — 5분 안에 ①이 떠오르지 않으면 가이드 트랙의 예시 미션 중 하나 선택
3. **강사 확인** — ②의 자료가 지금 확보 가능한가, ③의 출력이 이번 시간 안에 나올 크기인가
4. **구축 시작**
## 막히는 지점
- 교안에 별도로 적힌 막히는 지점 없음 (역할 이름은 "검색 담당"처럼 기능으로 짓도록 안내)
