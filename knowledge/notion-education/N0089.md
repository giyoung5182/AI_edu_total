## 복사용 전체 프롬프트
```plain text
링커리어 합격 자기소개서를 조사하고, 지원자에게 맞춘 인사이트와 경험 적용법, 전체 사례 비교표를 담은 한국어 PDF 한 개를 제작해줘.

## 1. 사용자가 수정할 지원자 정보

- 학력: `[학교명 / 전공 / 학위]`
- 지원 유형: `[신입 / 경력 / 인턴]`
- 희망 기업 규모: `[대기업 / 중견기업 / 중소기업 / 공기업 / 외국계 등]`
- 희망 직무: `[직무명]`
- 수집 기간: 23년~26년
- 조사 사이트: 링커리어 합격 자기소개서

## 2. 조사 목표와 원칙

지원자 조건에 맞는 합격 자기소개서를 수집하고, 중복을 제거한 뒤 다음을 분석한다.

- 실제 답변에서 반복되는 역량과 서술 방식
- 기업·직무별 경험과 성과 제시 방식의 차이
- 지원자가 자신의 경험에 적용할 수 있는 작성 방법

학력과 전공은 사례를 선별하는 필수 조건으로 사용하지 않는다. 특정 학교나 전공 출신으로 검색 범위를 제한하지 말고, 최종 인사이트와 경험 적용법을 맞춤화하는 데만 활용한다.

관찰한 답변의 특징을 합격의 원인으로 단정하지 않는다. 지원자의 경험이나 수집하지 못한 정보를 만들어내지 않는다.

## 3. 도구와 브라우저 사용 제한

링커리어 검색과 상세 본문 열람은 반드시 Computer Use로 사용자의 브라우저를 직접 조작해 수행한다.

다음 방식은 사용하지 않는다.

- Agent Reach, Exa, 별도 인터넷 검색 도구
- 네이버·구글 등 외부 검색엔진
- curl, Jina Reader, API 호출
- 사이트 HTML 직접 요청
- 별도 크롤링 프로그램
- 브라우저 쿠키를 다른 도구로 복사하는 방식

시작할 때 현재 브라우저 상태와 열린 탭을 확인한다. 링커리어 탭이 있으면 사용하고, 없으면 전용 탭을 만든다. 다른 탭을 이동하거나 닫지 않는다.

검색창, 필터, 정렬 메뉴, 페이지 이동 버튼을 직접 조작하고 실제 화면에 표시되는 결과와 상세 본문을 읽는다. 브라우저 로그인 상태가 다른 도구에도 적용된다고 가정하지 않는다.

Computer Use를 사용할 수 없거나 접근이 막히면 제한을 명시한다. 금지된 방법으로 우회하거나 확인하지 못한 내용을 조사 완료로 보고하지 않는다.

수집한 자료를 정리·분석하고 PDF로 제작하는 작업에는 로컬 파일 처리 도구를 사용할 수 있다.

## 4. 검색 범위와 방법

1. 희망 직무를 기본 검색어로 사용한다.
2. 실제 채용 업무가 겹치는 인접 직무 3개를 선정한다.
3. 검색 전에 선정한 인접 직무와 선정 근거를 간단히 기록한다.
4. 사이트에서 제공하는 직무·기업 규모·지원 유형·연도 필터를 활용한다. 필요한 필터가 없으면 상세 내용에서 직접 확인한다.
5. 검색 결과를 최신순으로 정렬한다.
6. 수집 기간에 해당하는 페이지를 빠짐없이 확인한다. 기간보다 오래된 사례가 연속해서 나타나는 지점까지 다음 페이지를 확인한다.
7. 여러 검색어에서 반복된 사례는 중복 여부를 확인한다.

검색 결과 수, 확인한 페이지 범위, 상세 열람 여부를 기록한다. 검색어별 결과 수에는 중복이나 수집 기간 밖 자료가 포함될 수 있으므로 실제 포함 사례 수와 구분한다.

## 5. 핵심 사례 포함 기준

다음 조건을 모두 충족한 자료만 핵심 사례로 집계한다.

- 지원 시기가 수집 기간에 해당한다.
- 기업 규모가 지원자 조건에 맞는다.
- 지원 유형이 지원자 조건과 일치한다.
- 희망 직무 또는 업무가 명확히 겹치는 인접 직무다.
- 실제 자기소개서 문항과 답변 본문을 읽을 수 있다.
- 링커리어 상세 페이지에 합격 자기소개서라고 표시되어 있다.

인접 직무는 직무명만 보고 포함하지 않는다. 답변이나 직무 설명에서 희망 직무와 연결되는 업무를 확인한다.

미리보기만 읽은 자료는 핵심 사례에 포함하지 않는다. 연도·기업 규모·지원 유형·직무·합격 여부가 불분명한 자료는 확인 불가로 분류한다.

제외 사유와 확인 불가 여부는 조사 기록에 남기되, PDF에 개별 제외 자료 목록을 넣지는 않는다.

## 6. 사례별 기록 항목

각 사례에서 다음을 기록한다.

- 기업명과 기업 규모
- 지원 연도와 상·하반기
- 직무명과 지원 유형
- 합격 표시 근거
- 자기소개서 문항 요약
- 답변의 핵심 내용
- 사용 경험과 본인이 수행한 행동
- 정량적 성과와 비교 기준
- 예상치·제안·불명확한 지표 등 해석상 주의점
- 강조 역량
- 답변의 서술 구조
- 희망 직무와의 업무 관련성
- 지원자 핵심 경험과의 관련성
- 링커리어 상세 페이지 URL

답변 전문을 복제하지 않는다. 분석에 필요한 요약과 짧은 발췌만 사용한다.

팀 성과와 개인 기여를 구분하고, 예상 성과나 제안 내용을 실제 실적으로 바꾸지 않는다. 원문에 없는 비교 기준이나 수치를 추가하지 않는다.

## 7. 중복 제거와 집계

기업명, 직무명, 지원 시기, 문항, 경험, 성과 수치, 문장 구조, 상세 페이지 URL을 비교한다.

- 같은 자기소개서가 여러 검색어에서 발견되면 한 건으로 집계한다.
- 같은 기업과 직무라도 경험과 답변이 다르면 별도 사례로 유지한다.
- 같은 경험을 활용한 서로 다른 지원서는 답변 내용과 구성을 비교해 판단한다.
- 같은 경험이 반복된다는 이유로 이를 서로 독립된 경험의 증거처럼 해석하지 않는다.

다음 수치를 구분해 기록한다.

- 검색어별 사이트 표시 결과 수
- 실제 확인한 자료 수
- 상세 본문을 읽은 고유 사례 수
- 미리보기만 확인한 고유 자료 수
- 제외한 고유 자료 수와 주요 사유
- 포함 기준을 충족한 사례의 중복 제거 전·후 건수
- 중복 제거 후 연도별 사례 수

같은 자료를 여러 번 열어도 상세 열람한 고유 사례 수는 한 건으로 계산한다. 집계 기준을 일관되게 적용한다.

## 8. PDF 구성

PDF는 다음 순서로 제작한다.

- 1페이지: 핵심 인사이트
- 2페이지: 내 경험에 적용하는 방법
- 3페이지 이후: 전체 핵심 사례 비교표

앞의 두 페이지는 각각 한 페이지로 완결한다. 별도 표지, 목차, 장황한 조사 과정, 개별 제외 자료 목록은 넣지 않는다.

비교표 페이지 수는 실제 사례 수와 내용 길이에 맞춘다. 특정 사례 수나 전체 페이지 수에 억지로 맞추지 않는다.

### 1페이지 — 핵심 인사이트

상단에 조사에서 얻은 가장 중요한 결론을 쉬운 문장 하나로 쓴다.

추상적인 구호 대신 “자기소개서에서 무엇을 어떻게 써야 하는지”가 바로 이해되도록 한다.

핵심 인사이트 3개를 선정하고, 각각 다음을 담는다.

- 구체적인 작성 원칙
- 이를 뒷받침하는 실제 기업·직무 사례
- 사례에서 확인한 행동과 결과
- 지원자가 자기소개서에 적용할 방법
- 클릭 가능한 원문 링크

하단에는 지원자 배경에 맞는 짧은 적용 방향과 권장 서술 순서를 넣는다. 분석한 고유 사례 수와 수집 기간도 간단히 표시한다.

인사이트는 실제 수집 결과에서 도출한다. 일부 사례의 특징을 전체 사례의 공통점으로 과장하지 않는다. 빈도를 제시한다면 실제로 집계한다.

### 2페이지 — 내 경험에 적용하는 방법

다음 세 단계로 구성한다.

**① 어떤 경험을 고를지**

핵심 경험이 제공되었다면 실제 경험 중 우선 활용할 경험과 선정 이유를 제시한다. 비교 사례와 어떤 행동·역량이 연결되는지 설명한다.

미제공이면 전공 과제·동아리, 아르바이트, SNS·대외활동 등에서 찾을 수 있는 경험을 조건부로 제시한다.

활동의 규모나 이름보다 본인의 판단·행동과 이를 확인할 자료가 있는 경험을 우선한다.

**② 무엇을 정리할지**

희망 직무와 경험에 맞춰 다음 다섯 항목을 구체적인 질문으로 제시한다.

- 문제: 누구의 어떤 문제를 해결하려 했나?
- 판단 자료: 조사·관찰·기록에서 무엇을 확인했나?
- 선택 이유: 왜 그 방법을 골랐나?
- 내가 한 일: 직접 맡고 바꾼 것은 무엇인가?
- 확인한 결과: 어떤 기준과 기간에서 무엇이 달라졌나?

수치가 없다면 제안 채택, 운영 변화, 구체적 피드백 등 확인 가능한 결과를 찾도록 안내한다. 결과가 확인되지 않았다면 그 한계를 그대로 표시한다.

**③ 어떻게 문장으로 옮길지**

실제 경험이 제공되었다면 확인된 사실만으로 자기소개서 문단 예시를 작성한다. 빠진 정보는 대괄호로 남긴다.

미제공이면 직접 채워 완성할 수 있는 문장 틀을 제공한다.

하단에는 “경험 선택 → 근거 자료 찾기 → 핵심 내용 정리 → 문단 작성”처럼 지금 실행할 일을 짧게 제시한다.

### 3페이지 이후 — 기업·직무별 합격 자기소개서 비교표

중복 제거한 모든 핵심 사례를 최신 지원 시기부터 수록한다.

다음 6개 열을 사용한다.

1. **기업·직무·시기**
   기업명, 직무명, 지원 시기, 기업 규모, 지원 유형, 클릭 가능한 원문 링크

2. **주요 문항 요약**
   실제 자기소개서 질문을 짧게 정리

3. **핵심 경험·행동**
   사용 경험과 지원자가 직접 수행한 행동

4. **성과 수치·해석**
   정량 성과와 비교 기준, 불명확한 지표나 예상치 여부

5. **역량·서술 구조**
   강조 역량과 답변 전개 순서

6. **내 경험과의 관련성**
   제공된 경험과의 구체적인 연결점. 미제공이면 연결 가능한 경험 유형과 조건부 안내

각 페이지에 열 제목, 사례 번호 범위, 전체 사례 수, 페이지 번호를 표시한다. 원문 링크는 “원문 보기”처럼 짧게 표시해도 되지만 실제 상세 페이지 URL로 연결되어야 한다.
```

# 완성된 PDF로 나만의 자소서 AI 만들기

**합격 사례 분석 PDF + 내 경험 + 지원 공고를 함께 활용하세요.**
PDF는 작성 방식을 참고하는 자료입니다. 내 자소서의 사실과 경험은 내가 제공한 자료에서 가져옵니다.
이 가이드는 ChatGPT 프로젝트 기준입니다. 실제 PDF를 평가한 내용이 아니라, 앞의 프롬프트로 만든 PDF를 활용하는 절차입니다.

## 1. 프로젝트 만들고 PDF 넣기
