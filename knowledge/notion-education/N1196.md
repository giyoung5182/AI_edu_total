# 3부 로고 제작

정리일: 2026-10-08 · 교육 에셋 N1196

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AI로 만든 그림(심볼)에 Canva에서 가게 이름 글씨를 얹어 라벨 스티커·포스터·부스 간판에 쓸 로고를 만듭니다.
## 진행 단계
1. **AI로 로고 심볼 만들기** — 글자 없이 그림만, 단순 평면 아이콘, 흰색/투명 배경, 서로 다른 아이디어 4개
- 입력할 내용:
```javascript
로고에 쓸 아이콘을 그려줘.

- 가게가 파는 것: [아이템]
- 주고 싶은 느낌: [2부에서 정한 느낌]
- 색: [메인 컬러]와 [보조 컬러]만 사용

조건은 이래.
- 글자는 넣지 말고 그림만 그려줄 것
- 단순한 평면 아이콘 스타일
- 배경은 흰색 또는 투명
- 아주 작게 줄여도 무엇인지 알아볼 수 있을 만큼 단순할 것

서로 다른 아이디어로 4개 만들어줘.
```
- 마음에 안 들 때: "선을 더 줄이고 단순하게", "색을 두 가지만", "더 귀엽게/깔끔하게", "글자는 빼고 그림만" 으로 다시 요청. 완성 그림은 PNG로 저장
1. **Canva 캔버스 만들기** — canva.com → \[디자인 만들기\] → \[맞춤형 크기\] → 단위 mm, 가로 50 세로 50
2. **배경 컬러 지정** — \[배경\] 탭에서 메인 컬러 선택(HEX 코드 직접 입력 가능)
3. **그림 올리기** — \[업로드\] → \[파일 업로드\] → 저장한 PNG를 끌어다 놓고 크기 조정
4. **상호명 입력** — \[텍스트\] → \[제목 추가\] → 상호명 입력, 글자 색은 보조 컬러
5. **정렬과 여백** — 가장자리에서 3mm 이상 안쪽 배치, \[위치\] → \[가운데 정렬\]
6. **다운로드·제출** — \[공유\] → \[다운로드\] → PNG, 파일명 `교육기관_팀명_로고.png`, 지정 폴더에 업로드
- 제출 전 확인: 손바닥 크기에서 상호명이 읽히는가 / 색 3개 이하 / 가장자리 글자 잘림 없음 / 그림 안에 깨진 글자 없음 / 파일명 형식 준수
## 막히는 지점
- AI가 준 그림을 그대로 로고로 쓰기(가게 이름이 없음)
- 요소를 너무 많이 넣기, 색을 여러 개 쓰기
- 글자를 가장자리에 붙이기
- AI 그림 속 깨진 한글을 그대로 두기
