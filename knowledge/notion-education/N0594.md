# 작업 폴더 만들기(day1/test1)와 설치 확인 체크리스트

## 이 실습으로 하는 것
오늘 실습을 진행할 작업 폴더를 만들고 도구 준비 상태를 점검합니다.
## 진행 단계
1. **day1 폴더 만들기** — 바탕 화면에서 마우스 오른쪽 버튼 → `새로 만들기` → `폴더` 선택 → 이름을 `day1`로 바꿉니다.
2. **test1 폴더 만들기** — `day1` 폴더를 열고 그 안에 새 폴더를 만들어 이름을 `test1`로 바꿉니다. 첫 실습은 `test1`에서 진행하고, 이후 실습은 `test2`, `test3`, `test4`… 폴더에서 진행합니다.
3. **설치 확인 체크리스트** — Claude Desktop 설치, Claude 계정 로그인, GitHub 플러그인 연결, Vercel 플러그인 연결, Claude Code 실행 가능, 실습용 작업 폴더 생성 여부를 확인합니다.
## 막히는 지점
- 진행하다가 막히는 부분이 있으면 튜터에게 질문
