# Step 3. 메인에 연결하고 실행하기 (라우팅)

정리일: 2026-10-08 · 교육 에셋 N0575

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 Subagent에게 이름을 불러 일을 맡기고, 라우팅이 어떻게 동작하는지 확인합니다.
## 진행 단계
1. **이름을 불러 배정** — 터미널 입력창에 아래를 입력하고 엔터를 누릅니다.
- 입력할 내용:
```javascript
보상검토 에이전트한테 data 폴더의 사고 건들을 보상 검토 맡겨줘.
운전자보험 약관의 보상 기준을 기준으로, 건별로 판정과 사유를 표로 정리해줘.
```
- 정상 결과: Claude가 보상검토 담당에게 배정해 실행하고, 폴더 안 사고 건들을 하나씩 읽으며 검토하기 시작합니다.
1. **(확인) 이름을 빼면** — 이름 없이 요청하면 메인 Claude가 직접 처리해 버리는 경우가 있습니다. 이때는 에이전트 이름 없이 메인이 폴더와 파일을 읽는 흐름만 보입니다.
2. **(팁) 반드시 고정하고 싶다면** — 입력창에서 `@`를 눌러 에이전트를 태그하면 해당 에이전트 실행이 보장됩니다.
## 막히는 지점
- 이름을 빼면 메인이 직접 해버릴 수 있습니다. 자동 라우팅의 원래 성질이며, 데모에서는 이름을 불러 배정합니다.
- 이름을 불렀는데도 메인이 직접 한다면 요청에 에이전트를 가리키는 말("보상검토")이 있는지, description에 "보상 검토, 사고 건 검토, 보상 심사" 같은 호출 문구가 있는지 확인합니다.
- 서브에이전트가 자기 자신을 무한 호출하면(`Waiting for background agents`) 에이전트 파일 YAML에 `disallowedTools: [Agent]`를 추가하고(Agent의 A는 대문자) Claude Code를 재시작합니다.
