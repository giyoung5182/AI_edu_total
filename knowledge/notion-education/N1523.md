# 실습 2 — 요청 제출 자동화

정리일: 2026-10-08 · 교육 에셋 N1523

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
요청접수 시트의 입력값을 검사하고 접수번호를 매겨 처리이력에 한 줄 추가하는 스크립트를 AI에게 만들게 한다.
## 진행 단계
1. **AI에게 요청하기** — 시트 구조, 할 일, 예외를 적은 요청문을 AI에게 보낸다(교안의 요청문 전문 참고). 요청접수 B4\~B11 입력 폼, 처리이력(A\~M열), 담당자매핑(A\~E열) 구조와 필수 항목 검사, REQ-2026-순번 채번, 담당자 조회('확인 필요' 처리), 처리이력 추가, 알림 후 폼 비우기를 적는다.
- 입력할 내용:
```javascript
Google Apps Script 코드를 만들어줘.

[시트 구조]

시트 1: 요청접수 (입력 폼)
  B4  요청부서
  B5  요청자
  B6  연락처
  B7  분류
  B8  제목
  B9  내용
  B10 희망완료일
  B11 긴급여부
(이하 교안 참고)
```
1. **코드 붙여넣고 실행** — 받은 코드를 붙여넣고 메뉴 「업무요청」 → 「요청 제출」을 실행한다. 막히면 완성 코드(교안 접힘 영역)를 본다.
2. **테스트 값 입력** — 요청부서 품질, 요청자 본인 이름, 분류 구매·자산, 제목 시험장비 교정 업체 계약 검토, 내용 계약 만료 예정으로 검토 요청, 희망완료일 2026-09-05, 긴급여부 일반 등을 입력해 제출한다.
- 정상 결과: 접수번호가 순서대로 매겨지고, 담당부서·담당자가 자동으로 들어가며, 접수일은 오늘 날짜, 상태는 '진행중', 입력 폼은 비워진다.
3. **예외 테스트** — 제목을 비우고 제출, 분류를 비우고 제출(경고창 후 중단 기대), 분류에 '기타' 직접 입력('확인 필요'로 진행 기대).
## 막히는 지점
- 15분 이상 막혔을 때만 완성 코드를 본다.
- 빈 값이 그대로 쌓이면 나중에 집계가 전부 어긋난다.
