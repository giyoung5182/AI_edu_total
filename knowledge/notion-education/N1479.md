# Step 06 :: 제출 전 · 내 도구가 지어내는지 9문항으로 확인합니다

정리일: 2026-10-08 · 교육 에셋 N1479

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
데이터에 없는 질문(C유형)을 포함한 9문항으로 도구가 값을 지어내는지 확인합니다.
## 진행 단계
1. **질문 9개 만들기** — coding 폴더에서 새 대화를 열고 입력.
- 입력할 내용: "이 화면과 03_데이터.csv를 보고 정확성 평가 질문 9개를 만들어줘." A유형 3(데이터에 그대로 있는 것), B유형 3(여러 값을 연결·계산), C유형 3(데이터에 답이 없는 것), 각 문항의 통과 답 포함
2. **채점** — O(맞게 답함) / △(묻지 않은 숫자를 덧붙임) / X(없는 것을 지어냄).
3. **규칙 보강** — △면 CLAUDE.md에 "묻지 않은 수치나 추정치를 덧붙이지 않는다", X면 "데이터에 없는 내용은 '확인 필요'로 표시한다"를 추가.
4. **재질문** — O가 아니었던 문항만 새 대화에서 다시 묻습니다.
## 막히는 지점
- C유형 세 문항이 가장 중요하며 하나라도 X나 △면 A·B가 다 맞아도 업무에 쓸 수 없습니다.
