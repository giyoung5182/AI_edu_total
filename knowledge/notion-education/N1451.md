# 4단계 직접 해보기: 차트와 HTML 저장 버튼 추가

---

## 이 실습으로 하는 것
앞서 만든 ROI 웹앱에 차트와 저장 버튼을 더해 보고용으로 가져갈 수 있게 합니다.
## 진행 단계
1. **추가 요청**
```javascript
방금 만든 ROI 웹앱에 아래를 추가해줘.
- 수율을 70%~99%까지 바꿔가며 ROI가 어떻게 변하는지 막대그래프 (Chart.js CDN 사용)
- 우측 상단에 'HTML로 저장' 버튼 — 현재 입력값까지 포함해 단일 HTML 파일로 다운로드
```
2. **차트 확인** — 수율을 바꿨을 때 막대그래프가 움직이는지 봅니다.
3. **저장** — 'HTML로 저장'을 눌러 파일이 받아지는지 확인합니다.
## 막히는 지점
- 차트가 안 보이면 "Chart.js CDN으로 단일 HTML 다시 만들어줘"라고 한 번 더 요청합니다.
- '단일 HTML 파일로'라는 문구가 있어야 독립 실행 파일이 만들어집니다.
