# 리라이팅 실습 1: 월간 원가 회의록

정리일: 2026-10-08 · 교육 에셋 N0663

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Before 프롬프트를 3요소(역할·맥락·출력형식)를 적용한 After 프롬프트로 리라이팅하고 결과를 확인합니다.
## 진행 단계
1. **Before 확인** — 개선 전 프롬프트:
```javascript
오늘 월간 원가 회의록 써야 하는데 도와줘.
골조비 초과랑 마감 기성 지연, 현금 집행 일정 이야기했고
결정사항 5건 액션아이템 7건 나왔어.
```
1. **After 프롬프트를 ChatGPT에 입력** — 본인의 업무에 맞게 수정해 사용합니다.
- 입력할 내용:
```javascript
## 역할
당신은 교육기관 현장 원가관리 담당자입니다.

## 맥락
- 프로젝트: ○○아파트 신축공사
- 회의명: 5월 월간 원가 점검 회의
- 일시: 2026년 5월 6일 (화) 14:00~16:00 / 본사 회의실 A
- 참석자: 사업본부 3명, 현장 원가 담당 4명, 공무·공사 담당 5명
- 주요 논의: 골조 공종 집행률 초과 / 마감 기성 청구 지연 / 6월 현금 유출 집중
- 결정사항 5건, 액션아이템 7건 발생

## 출력 형식
다음 구조의 회의록을 작성해줘:
1. 회의록 헤더 (회의명, 일시/장소, 작성자)
2. 참석자 (표: 소속/직위/성명)
3. 안건별 논의 내용 요약 (3개 안건)
4. 결정사항 (표: 번호 / 내용 / 근거)
5. 액션아이템 (표: 번호 / 할 일 / 담당자 / 기한)
6. 다음 회의 일정 및 준비 사항
```
1. **결과 확인 후 재시도** — 생성된 회의록을 확인하고, 본인의 실제 회의 상황으로 맥락을 수정하여 다시 시도합니다.
