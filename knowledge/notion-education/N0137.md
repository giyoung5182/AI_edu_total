# Ch 1 심화 — 피벗 설계 사고의 확장
---
## 피벗 설계를 잘하는 사람과 못하는 사람의 차이
피벗을 잘 쓰는 사람은 데이터를 열기 전에 이미 머릿속에 "어떤 표가 나와야 하는가"가 그려져 있습니다.
**못하는 사람의 패턴:**
```plain text
1. 엑셀을 열고 피벗을 삽입한다
2. 필드 목록을 보며 "이걸 행에 넣어볼까?" 하다가 막힌다
3. 결국 아무 열이나 드래그해보며 맞는 결과가 나올 때까지 시도한다
4. 나온 결과를 "맞나?"라고 생각하며 그냥 쓴다
→ 분석 시간 30분 + 결과 신뢰도 낮음
```
**잘하는 사람의 패턴:**
```plain text
1. "본부장님이 묻는 것이 무엇인가?"를 먼저 생각한다
2. 그 답에 필요한 데이터가 어느 시트에 있는지 파악한다
3. 피벗 구조를 머릿속으로 설계하고 엑셀을 연다
4. 설계대로 5분 안에 완성한다
5. 결과를 검증하고 보고서에 삽입한다
→ 분석 시간 5분 + 결과 신뢰도 높음
```
오늘 Ch 1의 핵심은 "피벗을 만드는 것"이 아니라 "피벗 설계 사고를 익히는 것"입니다.

## 교육기관 구매부에서 자주 쓰는 피벗 질문 패턴
실제 업무에서 자주 쓰이는 질문 유형과 그에 맞는 피벗 구조입니다.
**패턴 1 — 순위 파악 (가장 많은/적은 것)**
```plain text
질문: "이번 달 가장 많이 나간 품목 TOP 10은?"
피벗: 행=품목명 / 값=월총출고 합계 / 정렬=내림차순 / 필터=상위 10
```
**패턴 2 — 위험 탐지 (기준 이하인 것)**
```plain text
질문: "실재고가 10개 이하인 품목은?"
피벗: 행=품목명 / 값=실재고 / 필터=10 이하 / 정렬=오름차순
```
**패턴 3 — 비교 분석 (두 값의 차이)**
```plain text
질문: "장부와 실물이 다른 품목은?"
→ 피벗 전 계산 열 추가 (합재고-실재고)
피벗: 행=품목명 / 값=차이 합계 / 정렬=내림차순 / 필터=0 초과
```
**패턴 4 — 카테고리별 집계**
```plain text
질문: "육류/채소/조미료 카테고리별 출고 비율은?"
→ 품목 마스터 표에 카테고리 열 추가 필요 (1회차 매핑표 활용)
피벗: 행=카테고리 / 값=월총출고 합계 / 정렬=내림차순
```
**패턴 5 — 시간별 추이**
```plain text
질문: "이번 달 날짜별 출고 추이는?"
→ 날짜별 시트(1~31) 데이터 통합 필요
피벗: 행=날짜 / 값=매장출고 합계 / 정렬=날짜 오름차순
```

## Claude에게 피벗을 더 잘 요청하는 방법
**기본 요청과 상세 요청의 차이:**
```plain text
기본 요청:
"이번 달 출고 TOP 10 표 만들어줘"
→ AI가 어떤 시트를 쓸지, 어떤 열을 기준으로 할지 임의로 결정
→ 결과가 의도와 다를 수 있음

상세 요청:
"월총합 시트의 '월총출고' 열을 기준으로
 품목명(품목명 앞 코드 제거)과 월총출고 수량을
 내림차순으로 정렬해서 상위 10개 표로 만들어줘.
 맨 아래에 10개 합계 행 추가."
→ 원하는 결과가 정확하게 나옴
```
**결과 검증 질문 패턴:**
```plain text
"이 표에서 1위 품목의 수치가 월총합 시트 원본에서
 몇 번째 행에 있는 값이야? 직접 확인해줘."

"분석에 사용된 전체 품목 수가 몇 개야?
 합계·소계 행을 제외했을 때 기준으로."

"위 결과에서 합계(%)가 100%가 되는지 확인해줘."
```

## 실습 1 추가 — 월간 출고 트렌드 분석
질문 1\~3 외에 시간이 남으면 추가 분석을 해봅니다.
같은 채팅에서:
```plain text
[D] 같은 재고파악 파일이야.

[S] 오늘 분석한 월간 출고 TOP 10 품목 중
    실재고가 위험 수준(10 이하)인 품목이 겹치는 것이 있는지 확인하고 싶어.
    즉 "많이 나가면서 동시에 재고도 부족한 품목"을 찾고 싶어.

[R] 교차 분석 결과를 표로 만들어줘:
    | 품목명 | 월총출고 순위 | 27일 실재고 | 위험 등급 | 조치 권고 |
    위험 등급 기준: 0=긴급 / 1~5=매우위험 / 6~10=위험

[F] 월총합 TOP 10에 포함된 품목만.
    실재고 데이터는 27 시트 기준.
    품목명 코드 제거.
```
> **이 분석의 의미:** 출고량이 많으면서 재고도 부족한 품목이 가장 위험합니다. 단순히 "재고가 적다"가 아니라 "많이 나가면서 재고도 없다"는 이중 위험을 파악하는 것이 컨설팅 시각입니다.

### 실습 1-C 상세 — 교차 분석 프롬프트 단계별 설명
**교차 분석이 왜 강력한가:**
단순히 "많이 나간 품목" 또는 "재고가 적은 품목"을 따로 보는 것보다, **두 조건이 동시에 해당하는 품목**을 찾는 것이 실무에서 훨씬 유용합니다.
```plain text
단순 분석: "월간 출고 TOP 10은 갈비, 배추, 등갈비..."
교차 분석: "출고량이 많으면서 재고도 부족한 품목은 된장육수입니다.
           이 품목은 즉시 발주 + 발주량 증가가 필요합니다."
```
**교차 분석 프롬프트 구성:**
```plain text
[D] 같은 재고파악 파일이야.
    월총합 시트: 품목별 월간 출고 데이터
    27 시트: 5월 27일 기준 실재고 데이터

[S] 아래 두 조건을 동시에 만족하는 품목을 찾고 싶어:
    조건 1: 월간 출고 TOP 10에 포함된 품목
    조건 2: 27일 기준 실재고가 30개 이하인 품목

[R] 교차 분석 결과 표:
    | 품목명 | 월출고 순위 | 월총출고 | 실재고 | 위험도 | 권장 조치 |

    위험도:
    - 실재고 0: 🔴 긴급
    - 실재고 1~10: 🟠 위험
    - 실재고 11~30: 🟡 주의

    위험도 높은 순서로 정렬.
    조건 2를 만족하지 않는 TOP 10 품목은 "정상" 표시.

[F] 품목명 코드 제거.
    두 시트의 품목명이 다를 수 있으니 유사한 것을 매칭해줘.
    매칭이 불확실하면 '확인 필요'로 표시.
```
**예상 결과 해석:**
```plain text
만약 결과에서 "갈비(국내산 원육)"이
월간 출고 1위이면서 실재고가 낮게 나오면:

→ 이 품목은 가장 많이 나가는데 재고도 적다는 뜻
→ 현재 발주 주기로는 충분하지 않을 수 있음
→ 담당자에게 발주 주기 조정 여부 확인 요청
```

### 피벗 설계 연습 — 각자 해보기
오늘 실습 파일이 아닌 본인 업무 파일로 피벗 설계를 연습합니다.
**연습 방법:**
```plain text
① 본인 업무에서 자주 집계하는 것 1가지를 정한다
② 아래 질문에 답한다:
   - 무엇을 기준으로 볼 것인가? → 행(Rows)
   - 얼마나인가? → 값(Values)
   - 어떤 순서로? → 정렬
   - 조건은? → 필터
③ DSRF로 Claude에게 요청한다
```
**예시 — 프로님:**
```plain text
① 매주 화장실 청결 X(개선 필요) 매장 수를 본부장별로 집계

② 질문:
   - 무엇을 기준으로: 본부장명
   - 얼마나: X 매장 수
   - 어떤 순서로: 오름차순 (적은 쪽이 좋으므로)
   - 조건: O는 제외, X인 것만

③ 프롬프트:
"[D] 화장실 청결 확인 데이터야.
 A열: 본부장명 / B열: 매장명 / C열: 확인결과(O/X)

 [S] 본부장별로 이번 주 X(개선 필요) 매장 수를 집계하고 싶어.

 [R] | 본부장 | X 매장 수 | 매장 목록 |
     X 매장 수 내림차순 정렬.

 [F] O인 매장 제외. X인 것만."
```

### 피벗 결과물의 여정
오늘 Ch 1에서 만든 것들이 오늘 하루 안에 어떻게 활용되는지 전체 흐름입니다.
```plain text
Ch 1 실습 1-A:
재고파악 파일 업로드 + 피벗 구조 질문
→ Claude: "질문 1은 월총합 시트 / 행=품목 / 값=월총출고..."

Ch 1 실습 1-B:
피벗 결과 파일 생성 (3가지 방법 중 선택)
→ 5월_월간출고_TOP10.xlsx 다운로드

Ch 2 실습 2-A:
같은 채팅에서 차트 요청
→ 5월_월간출고_TOP10.png 다운로드

Ch 2 실습 2-B:
NotebookLM에 분석 결과 업로드
→ 인포그래픽 구조 텍스트 생성

Ch 3 실습 3-A:
같은 채팅에서 보고서 초안 요청
→ 구매부_5월_재고현황_초안.docx 다운로드

Ch 3 실습 3-B:
Claude for PowerPoint에 보고서 기반 슬라이드 요청
→ 6장짜리 프레젠테이션 생성

→ Ch 2·3 차트 PNG를 슬라이드에 삽입
→ 완성된 보고서 + 슬라이드
```
**핵심:** 한 번의 파일 업로드로 Ch 1·2 전체를 같은 채팅에서 진행합니다. Ch 3에서 새 채팅을 열 때 Ch 1·2의 결과 요약을 붙여넣으면 됩니다.

### 이번 달 분석과 지난달 분석 비교하기
월간 데이터를 지속적으로 쌓아두면 트렌드 분석이 가능합니다.
**지금 당장 할 수 있는 것:**
```plain text
4월 재고파악 파일이 있다면:

"지난달(4월) 월간 출고 TOP 10과
 이번 달(5월) 월간 출고 TOP 10을 비교해줘.

두 달 모두 TOP 10에 있는 품목: 변화 없음
4월에만 있었던 품목: 5월에 순위 하락
5월에 새로 진입한 품목: 4월 대비 출고 급증

표 형식:
| 품목명 | 4월 순위 | 5월 순위 | 변화 | 주목 이유 |"
```
**앞으로 6개월 치 데이터가 쌓이면:**
```plain text
"6개월 월간 출고 데이터를 기반으로
 계절성 패턴이 있는 품목을 찾아줘.
 예: 여름에 출고가 급증하는 품목이 있는가?"
```
이것이 4·5회차 자동화 이후의 진짜 AI 활용 — **데이터 기반 의사결정**입니다.

### 패턴 1. 특정 날짜 범위 집계
월초·월중·월말로 나눠서 재고 변화를 보고 싶을 때 씁니다.
```plain text
[D] 재고파악 파일의 1~31일 시트들이야.
    각 시트가 하루치 데이터를 담고 있어.

[S] 5월 1일~10일 (월초) / 11~20일 (월중) / 21~31일 (월말)
    구간별 매장출고 합계를 비교하고 싶어.

[R] 구간별 비교 표:
    | 품목명 | 월초(1~10) | 월중(11~20) | 월말(21~31) | 추세 |
    추세: 증가↑ / 감소↓ / 유지→ 로 표시.
    월말 출고가 월초의 1.5배 이상이면 "월말집중" 태그.

[F] 합계·소계 행 제외. 코드 제거.
    각 구간 합계는 일수로 나눈 일평균으로 계산.
```
> **왜 유용한가:** 월말에 재고가 급감하는 패턴이 있으면 월말 전에 미리 발주를 늘려야 합니다. 이 분석이 발주 계획의 근거가 됩니다.
---
### 패턴 2. 카테고리별 재고 현황
품목 마스터 표의 카테고리 분류를 활용합니다.
```plain text
[D] 두 개의 파일을 첨부했어.
    파일 1: 재고파악 27일 시트
    파일 2: 품목 마스터 관리표 (품목코드·품목명·카테고리 포함)

[S] 카테고리별로 오늘 재고 현황을 집계하고 싶어.

[R] 카테고리별 요약 표:
    | 카테고리 | 전체 품목 수 | 위험 품목 수 | 위험 비율 | 즉시 조치 필요 |
    위험 비율 내림차순 정렬.

[F] 두 파일의 품목명이 다를 수 있으니 코드로 매칭해줘.
    매칭 안 되는 품목은 "카테고리 미분류"로 처리.
```
> **활용 포인트:** "채소류 카테고리에서 위험 품목이 가장 많다"는 인사이트가 나오면 채소 공급업체와 납기 협상을 우선적으로 진행해야 합니다.
---
### 패턴 3. 공급업체별 입고 현황
원자재입고 파일의 업체명 열을 활용합니다.
```plain text
[D] 원자재입고양식 파일이야.
    '업체명' 열에 공급업체 이름이 있어.

[S] 공급업체별로 이번 달 입고 금액과 품목 수를 집계하고 싶어.

[R] 공급업체별 현황 표:
    | 업체명 | 입고 품목 수 | 총입고금액 | 평균입고금액 | 비율(%) |
    총입고금액 내림차순 정렬.

[F] 입고 없는 업체 제외.
    합계 행 제외.
    금액 천 단위 콤마. 비율 소수점 1자리.
```
> **활용 포인트:** 한 업체에 편중된 거래가 보이면 리스크 분산이 필요합니다. 이 데이터가 공급업체 협상 및 거래처 다양화 전략의 근거가 됩니다.
---
### 패턴 4. 주간 트렌드 분석
매주 어떤 패턴이 반복되는지 파악합니다.
```plain text
[D] 재고파악 파일의 여러 날짜 시트야.
    1~7일(1주), 8~14일(2주), 15~21일(3주), 22~28일(4주)

[S] 주별 재고 소진 패턴을 분석하고 싶어.
    특정 요일에 재고가 급감하는 품목이 있는가?

[R] 주별 비교 표 + 패턴 설명:
    1. 주별 평균 매장출고 TOP 5 품목
    2. 주별 변동이 가장 큰 품목 3개와 그 패턴 설명
    3. 재입고가 가장 시급한 요일·시점 예측

[F] 합계·소계 행 제외. 코드 제거.
    분석 결과는 한국어로.
```

### 피벗 설계 오류 모음 — 이렇게 하면 실패합니다
실제 실습에서 자주 생기는 실패 패턴과 해결책입니다.
**실패 1: 너무 많은 것을 한 번에 요청**
```plain text
❌ 나쁜 예:
"파일 분석하고 피벗 만들고 차트도 만들고 보고서도 만들어줘"

✅ 좋은 예:
Step 1: "이 파일의 구조를 파악하고 피벗 설계를 알려줘"
Step 2: "질문 1에 맞는 피벗 결과 파일을 만들어줘"
Step 3: "이 결과로 차트를 만들어줘"
Step 4: "차트를 포함한 보고서 초안을 만들어줘"
```
**실패 2: 검증 없이 결과를 바로 사용**
```plain text
❌ 나쁜 예:
결과 나옴 → 즉시 보고서에 붙여넣기

✅ 좋은 예:
결과 나옴 → "분석에 사용된 품목 수가 몇 개야?" → 기대값 확인
         → 임의 품목 2~3개 원본 파일과 직접 대조
         → 이상 없으면 사용
```
**실패 3: 시트 명시 없이 요청**
```plain text
❌ 나쁜 예:
"이 파일에서 월간 출고 TOP 10 뽑아줘"
→ AI가 27 시트를 볼지, 월총합 시트를 볼지 임의로 결정

✅ 좋은 예:
"월총합 시트의 '월총출고' 열을 기준으로 TOP 10 뽑아줘"
```
**실패 4: 소수점이 나오는 것을 그냥 두기**
```plain text
❌ 나쁜 예:
"갈비 700,625.3" → 보고서에 그대로 사용

✅ 좋은 예:
[F]에 "수량은 반드시 정수(소수점 없음)로" 명시
또는 결과 후 "소수점이 있어. 반올림해서 정수로 변환해줘" 수정 요청
```

### Claude Pro 사용 시 크레딧 아끼는 방법
오늘 실습은 파일을 여러 번 올리지 않고 같은 채팅에서 이어서 하도록 설계됐습니다. 크레딧을 아끼는 추가 팁들입니다.
```plain text
① 같은 채팅 이어서 쓰기
   파일을 한 번 올리면 같은 채팅에서 계속 참조 가능

② 결과가 나쁘면 처음부터 새 채팅 대신 수정 요청
   "3번 항목이 이상해. 이 부분만 수정해줘"
   → 전체를 다시 하는 것보다 크레딧 절약

③ 파일 크기 줄이기
   큰 파일은 필요한 시트만 별도 저장해서 업로드

④ 검증 질문은 짧게
   "품목 수가 몇 개야?" (O)
   "분석에 사용된 전체 품목 수를 합계 행 제외하고 알려줘" (X - 불필요하게 길다)
```

## DSRF 작성 연습 문제 — 직접 작성해보기
아래 상황에서 어떻게 DSRF를 작성할지 빈칸을 채워보세요.
**상황:** 5월 27일 기준으로 "입고가 있었는데도 실재고가 합재고보다 낮은 품목"을 찾고 싶습니다.
```plain text
[D] 첨부한 파일은 _________________ 야.
    ________ 시트에 ________열이 있어.

[S] _________________ 을 파악하고 싶어.
    이 정보로 _________________ 에 활용할 예정이야.

[R] _________________ 형식으로 만들어줘.

[F] _________________ 제외.
```
**정답 예시:**
```plain text
[D] 첨부한 파일은 교육기관 구매부 재고파악 파일이야.
    '27' 시트에 품목명·전일재고·매장출고·입고·합재고·실재고 열이 있어.

[S] 이번 달 입고가 있었음에도(F열 > 0) 합재고(G열)보다 실재고(H열)가 낮은
    품목을 찾고 싶어. 즉 입고 후에도 실재고가 장부보다 낮은 이상 품목 탐지.
    재고 손실 가능성이 있는 품목을 파악해 입고 검수 강화에 활용할 예정이야.

[R] | 품목명 | 입고 수량 | 합재고 | 실재고 | 차이 | 위험도 |
    차이 내림차순 정렬.
    "이 품목들은 입고됐음에도 실재고가 장부보다 낮습니다.
    원인 파악이 필요합니다."라는 한 줄 요약을 표 아래에 추가.

[F] 입고 수량이 0인 품목 제외.
    실재고가 합재고 이상인 정상 품목 제외.
    코드 제거. 수량은 정수로.
```

## 오늘 실습 1 전체 프롬프트 모음 — 복사해서 바로 쓰기
### 프롬프트 1-A: 파일 구조 파악 + 오류 탐지
```plain text
[D] 첨부한 파일은 교육기관 구매부 재고파악 파일이야.
    '월총합' 시트에 품목별 월총입고·월총출고 데이터가 있고
    '27' 시트에 5월 27일 전일재고·매장출고·입고·합재고·실재고 데이터가 있어.

[S] 먼저 두 시트의 전체 구조를 파악하고
    수량 칸에 숫자가 아닌 값(오입력)이 있는지 확인해줘.

[R] [표 1] 파일 구조 요약
    - 각 시트별 전체 품목 수 (합계·소계·샘플 행 제외)
    - 수량 칸에 숫자가 아닌 값 존재 여부

    [표 2] 오입력 목록 (있을 경우)
    | 시트명 | 품목명 | 날짜/열 | 입력값 | 오입력 유형 |

[F] 합계·소계·샘플 행은 품목 수에서 제외.
    오입력 유형: 문자입력(o·x·-) / 음수 / 비정상 큰 값.
    품목명 앞 코드 제거.
    수량은 정수로만.
```

### 프롬프트 1-B-①: 월간 출고 TOP 10 결과 파일
```plain text
[D] 같은 재고파악 파일의 월총합 시트야.

[S] 이번 달 월총출고 기준 상위 10개 품목을 알고 싶어.

[R] 아래 표를 엑셀 파일로 만들어줘:
    | 순위 | 품목명 | 월총출고 | 구성비(%) |

    구성비: 해당 품목 월총출고 / 전체 월총출고 합계 × 100
    소수점 1자리 %. 예: 46.9%

    월총출고 내림차순 정렬.
    맨 아래에 TOP 10 합계 행 추가.
    파일명: 5월_월간출고_TOP10.xlsx

[F] 합계·소계 행 제외.
    품목명 앞 코드 제거.
    수량은 정수(소수점 없음).
    구성비 소수점 형식 예: 46.9% (0.468... 형식 금지).
```

### 프롬프트 1-B-②: 실재고 위험 품목
```plain text
[D] 같은 재고파악 파일의 27 시트야.

[S] 5월 27일 기준 실재고가 10개 이하인 위험 품목 목록을 만들고 싶어.
    발주 우선순위 설정에 활용할 예정이야.

[R] 위험 품목 표:
    | 등급 | 품목명 | 전일재고 | 실재고 | 권장 조치 |

    등급 기준:
    🔴 긴급: 실재고 0개 이하
    🟠 위험: 실재고 1~5개
    🟡 주의: 실재고 6~10개

    실재고 오름차순 정렬.
    표 아래에 "긴급 N개, 위험 N개, 주의 N개 — 총 N개 품목 발주 검토 필요" 요약.

[F] 합계·소계 행 제외.
    매장출고·실재고 모두 0인 품목(미사용 품목) 제외.
    품목명 코드 제거. 수량 정수.
```

### 프롬프트 1-B-③: 합재고 vs 실재고 불일치
```plain text
[D] 같은 재고파악 파일의 27 시트야.

[S] 합재고(장부재고)와 실재고(실물재고) 차이가 큰 품목을 찾고 싶어.
    재고 실사 및 입고 검수 강화 대상 파악에 활용할 예정이야.

[R] 불일치 TOP 5 표:
    | 순위 | 품목명 | 합재고 | 실재고 | 차이 | 차이 비율(%) | 원인 추정 |

    차이 = 합재고 - 실재고
    차이 비율 = 차이 / 합재고 × 100
    차이 절대값 내림차순 정렬.
    원인 추정: "입고 검수 오차 가능성" / "출고 누락 가능성" 등

    표 아래에 "이 품목들은 장부와 실물 간 오차가 큽니다.
    재고 실사 또는 입고 기록 재확인이 필요합니다." 한 줄 추가.

[F] 합재고=실재고인 정상 품목 제외.
    합재고·실재고 모두 0인 품목 제외.
    코드 제거. 차이 비율 소수점 1자리.
```

### 프롬프트 1-C: 통합 검증
```plain text
방금 만든 세 가지 분석 결과를 검증해줘.

[검증 1] 월간 출고 TOP 10
   1위 품목명과 월총출고 수치를 알려줘.
   월총합 시트 원본에서 직접 확인한 값인지 확인해줘.

[검증 2] 위험 품목 목록
   실재고 0인 긴급 품목이 있어? 있으면 품목명과 수량 알려줘.
   27 시트 H열에서 직접 확인한 값인지 확인해줘.

[검증 3] 불일치 TOP 5
   1위 품목의 합재고·실재고·차이를 알려줘.
   27 시트 G열(합재고)과 H열(실재고)에서 직접 확인한 값인지.

각 검증 항목에 "✅ 확인됨" 또는 "⚠️ 불일치 - 수정 필요"로 표시해줘.
```
