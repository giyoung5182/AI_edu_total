# 활동 1 — 데이터 사전 만들기

정리일: 2026-10-08 · 교육 에셋 N1276

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정제한 데이터에 따라붙는 설명서(데이터 사전)를 빈칸 양식에 맞춰 작성합니다.
## 진행 단계
1. **데이터 이름 작성**
2. **컬럼별 기입** — 컬럼명 / 유형 / 허용값·형식 / 설명 / 개인정보
3. **처리 규칙 기입** — 결측 / 중복 / 단위
- 교안 예시: 결측은 미집계는 빈칸 유지·집행 후 0은 0으로 기록 / 동일 매체·동일 일자 중복은 최신 파일 기준 대체 / 금액은 원 단위 정수, 천 단위 구분 기호 제거
- 정상 결과: 이 문서가 있으면 자동화 지시문의 절반이 이미 쓰인 셈(5권에서 Agent에게 이 사전을 그대로 넣음)
