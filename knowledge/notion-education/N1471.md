# [실습] 입력 데이터 3종 설계

정리일: 2026-10-08 · 교육 에셋 N1471

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
시스템에 필요한 입력 데이터 3종을 설계하고 출력물 형태를 정합니다.
## 진행 단계
1. **입력 데이터 3종 설계**
- 입력할 내용: 역할(예산·원가 데이터 설계자), 입력(문제 정의, 목표), 요청(입력 데이터 3종 설계), 각 데이터별 데이터명·형태(엑셀/CSV/텍스트)·컬럼 구조(5개 이상)·예시 데이터 3행·수집 방법
- 4차시에서 만든 입력 템플릿을 그대로 활용해도 됨
2. **출력물 형태 결정** — 출력 유형(보고서 생성형/의사결정 보조형/분류·집계형), 구체 형식, 포함 항목을 정함
