## 이 실습으로 하는 것
배부받은 Gemini API 키를 프로젝트의 .env 파일에만 저장합니다. 키는 결제 수단에 연결된 유료 키이므로 유출에 주의합니다.
## 진행 단계
1. **AI Studio 접속** — [개별 링크 제외]
2. **로그인** — 배부받은 Google 계정
3. **키 발급** — API 키 발급 메뉴에서 새 키 생성 (화면 구성은 수시로 바뀌므로 "API Key" 또는 "API 키" 문구를 찾음)
4. **키 복사 및 임시 보관**
5. **.env에만 보관** — 코드 파일에 직접 적지 않고, Claude Code 대화창·공유 문서에 붙여넣지 않음
## 막히는 지점
- 파일명이 ".env.txt"로 저장됨 → 탐색기 보기 메뉴에서 "파일 확장명"을 켜고 `.env`로 수정
- 리눅스 영역 폴더를 못 찾음 → 탐색기 주소창에 `\\wsl$` 입력
