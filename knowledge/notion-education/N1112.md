# 실습 1 | Canvas로 교육기관 실무 자료 만들기 (20분)

정리일: 2026-10-08 · 교육 에셋 N1112

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
표준 예시 프롬프트를 분석한 뒤 본인 업무용 프롬프트를 직접 작성하고, Gemini Canvas에서 제품 소개 기획서 또는 마케팅 자료를 만들어 구글 문서로 저장합니다.
## 진행 단계
1. **표준 예시 확인 (3분)** — 민타비20 고객 배포용 기획서 프롬프트를 읽고 각 줄이 왜 들어갔는지 생각합니다.
- 정상 결과: 독자·목적·"반드시"/"하지 말 것"이 분리되어 있음을 확인
2. **나만의 프롬프트 직접 작성 (5분)** — 자료 유형, 대상 제품, 독자, 목적, 반드시 포함할 것, 하지 말 것을 채워 프롬프트를 씁니다.
3. **Canvas 실행 + 수정 (10분)** — Gemini Canvas 모드를 열고 프롬프트를 입력해 초안을 확인합니다.
- 입력할 내용: 수정 1은 마음에 안 드는 부분 1곳 지목, 수정 2는 다른 형식으로 변환 (예: "이 내용을 인스타 본문 200자로 압축해줘")
- 정상 결과: 수정 명령 최소 2회 실행
4. **저장 (2분)** — Canvas 오른쪽 상단 "구글 문서로 내보내기"를 클릭해 구글 드라이브에 저장하고 링크를 복사합니다.
- 정상 결과: Canvas 초안 생성 완료 / 수정 명령 2회 이상 / "이거 실제로 쓸 수 있다" 수준 확인 / 구글 문서 저장 완료
## 막히는 지점
- Canvas는 도구 메뉴에서 직접 켜야 하며 자동으로 열리지 않음
- 모바일 앱에서는 열람만 가능하고 텍스트 스타일·형식 편집은 데스크탑에서만 가능
