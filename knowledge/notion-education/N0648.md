# 실습 2. 청킹 크기 실험

정리일: 2026-10-08 · 교육 에셋 N0648

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 문서를 다른 크기로 잘라 보고 차이를 관찰합니다.
## 진행 단계
1. **개수 예측** — 크기 500자로 자른 결과가 총 몇 개였는지 확인하고, 300자로 줄이면 몇 개쯤 될지 예측해 적습니다.
2. **300자로 재업로드** — 페이지의 청크 크기를 300으로 바꾸고 같은 문서를 다시 업로드해 실제 개수를 예측과 비교합니다.
3. **1000자로 재업로드** — 청크 크기를 1000으로 바꿔 한 번 더 업로드합니다.
4. **같은 내용 카드 비교** — 300자 버전과 1000자 버전에서 같은 내용을 다룬 카드를 찾아 펼쳐 봅니다.
- 300자 카드: 내용이 도중에 끊기지 않았는지 봅니다.
- 1000자 카드: 서로 다른 주제가 한 카드에 섞이지 않았는지 봅니다.
5. **판단** — 어느 크기가 이 문서에 알맞아 보이는지 각자 판단합니다.
- 정상 결과: 정답은 없고, 판단 근거를 말할 수 있으면 성공입니다.
