# 실습 2-B-2. 수정 요청 메일 (한국어·영어 동시)

정리일: 2026-10-08 · 교육 에셋 N1450

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
현장에서 파악한 수정 사항을 정중하고 명확하게 전달하는 메일을 한국어·영어로 동시에 생성한다.
## 진행 단계
1. **프롬프트 입력 (5분)** — 수정 사항을 \[수정 요청 내용\]에 채워 입력한다.
- 입력할 내용: 시니어 디자이너 역할, 호칭 → 수정 사항 번호 나열 → 마감 → 마무리 형식, 각 수정은 현재 상태 → 요청 → 이유 순, A4 반 장, 사과 표현 최소화, 마감은 구체적 날짜·시간 (이하 교안 참고)
2. **결과 확인 (2분)** — 수정 사항이 번호로 나열됐는지 / 현재→요청→이유 순서인지 / 마감이 구체적인지 / 불필요한 사과 표현이 없는지.
3. **체이닝 (3분)** — 영어 버전을 더 직접적으로 / 추가 비용 안내 문구 포함해 다시 쓰기.
