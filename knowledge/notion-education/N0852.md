## 지금까지 우리가 온 길
4회차를 시작하기 전에, 지금까지 배운 것이 어떤 흐름인지 한 번 돌아봅니다.
```plain text
1회차 — 비정형 → 정형 (변환)
  사진으로 온 발주서, 메신저 메시지를
  Claude가 읽고 정리된 표로 만들어줬다

2회차 — 정형 → 분석 (패턴 발견)
  엑셀 파일을 Claude에 올리면
  오입력을 탐지하고, 재고 위험 품목을 분류해줬다

3회차 — 분석 → 보고서 (전달)
  분석 결과를 차트·인포그래픽·Word 보고서·PPT 슬라이드로
  자동 완성했다

4회차 — 반복 → 자동화 (GAS)  ← 오늘
  지금까지는 "사람이 요청해야 AI가 처리"했다면
  오늘부터는 "버튼 하나로 자동 처리"한다

5회차 — 연결 → 자동화 심화 (Make.com)
  카카오톡 자동 알림 등 외부 서비스까지 연결
```
1\~3회차에서 만든 보고서 프롬프트 템플릿들이 오늘 자동화의 재료가 됩니다.

### GAS가 뭔지 모르는 분을 위한 설명
**Google Apps Script**, 줄여서 **GAS**라고 합니다.

```plain text
  엑셀에도 매크로(반복 작업 자동화)가 있습니다.
```

### GAS는 어디에 있는가
구글 시트 파일 안에 내장되어 있습니다. 별도 프로그램 설치 필요 없습니다.
```plain text
구글 시트 열기
→ 상단 메뉴: [확장 프로그램]
→ [Apps Script] 클릭
→ 편집창 열림 (여기에 Claude가 만들어준 코드를 붙여넣으면 됩니다)
```
---
### 함수(Function)란 무엇인가
GAS 코드는 **함수**로 이루어져 있습니다. 함수는 "이름 붙은 명령 묶음"입니다.
```javascript
// 이것이 함수입니다
function 지출결의서제출() {
  // 여기 안에 있는 내용이
  // 버튼을 누르면 순서대로 실행됩니다
}
```
함수를 만들면:
- 상단 메뉴에 버튼으로 등록할 수 있습니다
- 정해진 시간에 자동 실행되게 할 수 있습니다
- Claude에게 "이 함수에 이런 기능 추가해줘"라고 수정 요청할 수 있습니다
---
### 오늘 방식 — 코드를 몰라도 됩니다
```plain text
전통 방식:
코드를 직접 공부하고 → 직접 작성하고 → 디버깅한다
(개발자 수준 필요)

오늘 방식:
내 업무를 Claude에게 설명한다
→ Claude가 코드를 작성한다
→ 구글 시트에 붙여넣고 실행한다
→ 결과가 의도와 다르면 Claude에게 수정 요청한다
```
**담당자의 역할:**
- 내 업무 구조를 정확히 설명할 수 있어야 합니다
- 결과가 의도대로 작동하는지 확인할 수 있어야 합니다
- 오류가 나면 오류 메시지를 복사해서 Claude에게 전달할 수 있어야 합니다
코드 자체를 이해하거나 외울 필요는 전혀 없습니다.

### 반드시 알아야 할 것 — GAS는 구글 시트 형식에서만 작동
이것이 프로님이 막혔던 핵심 원인입니다. 매우 중요합니다.
**파일 형식의 차이:**
```plain text
엑셀 파일(.xlsx):
  마이크로소프트 엑셀에서 만든 파일 형식
  구글에서 열 수 있지만 내부는 엑셀 형식 그대로

구글 시트(.gsheet):
  구글 드라이브에서 처음부터 만든 파일
  GAS(Apps Script)를 완전히 지원
```
**눈에 보이는 것 vs 실제:**
```plain text
상황: 엑셀 파일을 구글 드라이브에 올리고 더블클릭
화면: 구글 시트처럼 보임
실제: 내부는 .xlsx 형식 → Apps Script 메뉴가 없거나 실행 안 됨
```
**올바른 방법:**
```plain text
drive.google.com 접속
→ [+ 새로 만들기] → [Google 스프레드시트]
→ 처음부터 구글 시트로 만들기
→ 여기서만 GAS가 정상 작동
```

### GAS 코드의 구조 — 읽는 법만 알아두기
코드를 짤 필요는 없지만, 받은 코드에서 어디를 수정해야 하는지 알면 편합니다.
```javascript
// // 로 시작하는 줄 = 주석 (설명, 실행 안 됨)

const SHEET_FORM = '지출결의서';  // ← 시트 이름. 실제 탭 이름과 일치해야 함

function 지출결의서제출() {       // ← 함수 이름. 메뉴에 이 이름으로 등록됨

  const 매장명 = formSheet.getRange('B3').getValue();
  //                                  ↑ 셀 주소. 실제 셀과 일치해야 함

  dbSheet.appendRow([매장명, ...]);  // ← 제출이력 시트에 한 줄 추가

}
```
**수정이 필요한 부분은 주로 2가지:**
1. 시트 이름 (`'지출결의서'`, `'제출이력'` 등)
2. 셀 주소 (`'B3'`, `'A11'` 등)
이 두 가지만 실제 파일과 일치시키면 대부분 정상 작동합니다.

### 프로님 — 지출결의서 자동화 (직접 시도하셨음)
3회차 후 직접 GAS 자동화를 시도하셨습니다.<br>프로님의 시도가 오늘 전체 수업의 주요 소재입니다.
**완성된 것:**
```plain text
엑셀 지출결의서 폼 v23 완성
매장 드롭다운 (매장정보 시트와 연동)
거래처 드롭다운 (거래처목록 시트와 연동)
GAS 코드 작성 완료
```
**막힌 지점 3가지와 정확한 원인:**
```plain text
막힌 지점 1: .xlsx 파일에서 Apps Script 실행 안 됨
원인: 엑셀 형식 파일은 GAS를 지원하지 않음
해결: 구글 드라이브에서 새 구글 시트를 만들고 시트를 복사

막힌 지점 2: Apps Script 클릭해도 편집창이 안 열림
원인: 크롬이 팝업을 차단해서 새 탭이 열리지 않음
해결: 주소창 팝업 차단 아이콘 → 허용
```

### 왜 이 개념을 먼저 배우는가
자동화를 계획할 때 가장 많이 하는 실수:
```plain text
"이것도 자동화할 수 있을 것 같은데?"
→ 시작하고 나서 막힘
→ 시간 낭비
```
반대로, 자동화가 가능한 범위를 먼저 알면:
```plain text
가능한 것을 빠르게 구현
불가능한 것은 우회 방법을 설계
시간을 아낄 수 있음
```
이번 프로님이 수업 전에 직접 Claude와 자동화 가능 여부를 검토하신 것이 이 개념의 가장 좋은 실제 사례입니다. 그 내용을 함께 봅니다.

### GAS로 할 수 있는 것
```plain text
✅ 구글 시트 데이터 읽기·쓰기·정리

   예: 실재고 10 이하 품목만 따로 모으기

   예: 매일 오전 8시, 오후 2시에 함수 자동 실행

✅ 조건 만족 시 즉시 알림
   예: 비즈머니 잔액이 50만원 이하가 되면 이메일 발송

   예: 네이버에서 다운받은 CSV 파일을 읽어서 해당 시트에 자동 입력

   예: 업무보고 파일을 특정 폴더에 자동 저장
```

```plain text
   이유: 로그인 필요 + 웹사이트 크롤링 정책 위반 가능

❌ 이지포스·ERP 등 외부 시스템 직접 접속
   이유: 보안 정책 + 별도 API 필요

   이유: 카카오 비즈니스 API는 유료 + 별도 계정 필요
```
