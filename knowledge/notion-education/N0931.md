# 8/4 통합회차(8+9회차) 준비 과제

정리일: 2026-10-08 · 교육 에셋 N0931

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

> **안내일:** 7/31 (바이브 코딩 실습 종료 후)<br>**제출/지참일:** 8/4 (화) 15:00\~21:00 (6시간 통합 진행)<br>**과제 성격:** 이번엔 이사님이 "배우는" 회차가 아니라, 지금까지 배운 것을 바탕으로 **직접 설계자가 되어보는** 회차입니다. 8/4 당일에는 이 과제를 함께 검토하고 다듬는 데 시간을 씁니다.
---
## 왜 이 과제가 중요한가
```plain text
1~7회차는 "AI 강사로서 알아야 할 것"을 배우는 시간이었습니다.
8/4는 "그걸로 실제 강의를 설계할 수 있는가"를 확인하는 자리입니다.

이 과제를 미리 준비해 오셔야, 당일 6시간을 "이론을 더 배우는 시간"이
아니라 "이사님이 만든 결과물을 함께 다듬는 시간"으로 쓸 수 있습니다.
```

> 💡 **기초/중급 중 기초만 필수** — 두 클래스(기초/중급)로 나눠 생각해보되, 시간이 부족하면 기초 하나만 완성해 와도 됩니다.

## 1단계 — 강의평 분석
```plain text
지금까지 진행한 강의(토요일 정기 강의 등)의 후기·반응·질문을
모아서 정리합니다. 매 강의마다 반복적으로 해야 하는 작업이니,
이번 기회에 정리 방식 자체를 하나 만들어 두면 계속 재사용할 수 있습니다.

정리 항목 예시:
- 수강생들이 가장 좋아했던 부분
- 가장 이해하기 어려워했던 부분
- 자주 나온 질문 (7회차 실습에서 다룬 질문 유형 분류 참고)
- 다음 강의에 반영하면 좋을 점

💡 활용 팁: 7회차에서 만든 "질문분류 에이전트"를 여기 그대로
   써보세요. 지금까지 쌓인 질문·후기 자료를 넣고 분류를
   맡기면 이 1단계 작업 시간을 크게 줄일 수 있습니다.
```
---
## 2단계 — 니즈 조사 설계 및 분석
```plain text
"사람들이 AI 강의에서 무엇을 원하는가"를 직접 조사해봅니다.
설문지를 설계하고, (실제로 돌릴 여유가 없다면) 최소한 문항
설계까지는 완성해 옵니다.

조사 대상을 두 갈래로 나눠 생각합니다.
① 외부 수강생·잠재 수강생 대상
② 내부 구성원(팔라즈 조직원 등) 대상 — 워크숍 니즈 파악용
```
**설문 문항 설계 예시 (참고용, 그대로 안 써도 됩니다)**
```plain text
1. AI를 업무·일상에서 얼마나 자주 사용하시나요?
2. AI를 사용하면서 가장 어렵게 느끼는 부분은 무엇인가요?
3. 아래 중 배우고 싶은 주제를 골라주세요 (복수 선택)
   [ ] AI 기본 개념   [ ] 프롬프트 잘 쓰는 법
   [ ] 이미지/콘텐츠 제작   [ ] 업무 자동화
   [ ] 나만의 AI 도구 만들기   [ ] 기타 (직접 입력)
4. 강의는 어떤 형식이 편하신가요? (1회성 특강 / 여러 회차 연속 과정)
5. 이 강의를 듣고 나면 무엇이 달라지길 기대하시나요?
```
```plain text
분석 결과는 짧게 요약합니다.
"조사 결과, ○○에 대한 니즈가 가장 높았고, 이는 3단계 주제
선정에 다음과 같이 반영했다" 정도의 한두 문단이면 충분합니다.

💡 활용 팁: 5회차에서 배운 NotebookLM 딥리서치나, 7회차에서
   배운 서브에이전트 방식으로 응답 결과를 분석해도 좋습니다.
```

## 3단계 — 주제 선정
지금까지 배운 것을 바탕으로 강의 주제를 뽑습니다. 아래 두 갈래로 나눠서 각각 정리합니다.
```plain text
(1) 외부인 대상 — 어떤 주제로 강의할 수 있을까
(2) 내부 워크숍 주제 — 조직 구성원 대상으로 어떤 걸 다룰 수 있을까
```

## 4단계 — 커리큘럼 설계 (최소 2개, 외부용)
```plain text
3단계에서 뽑은 외부용 주제 중 최소 2개를 골라, 실제 진행 가능한
커리큘럼(스텝)으로 구체화합니다.

두 가지 형태를 각각 최소 1개씩 만들어 보는 것을 권합니다.
① 연속된 프로그램 (여러 회차로 이어지는 과정)
② 단일 프로그램 (1회성 특강, 그 안에 여러 콘텐츠 포함)

정할 것:
- 총 몇 시간짜리 특강/과정으로 만들 것인가
- 특강이라면 그 안에 다룰 주제를 몇 개 정도로 구성할 것인가
  (10개 후보 주제 중 조합해도 좋습니다)
```
**커리큘럼 작성 양식 (지금까지 계속 써온 형식 그대로)**
```plain text
프로그램명: ________________________________
형태: [ 연속 프로그램 / 단일 프로그램(1회성) ]
총 시간: ________
대상: ________________________________

| 회차/파트 | 주제 | 한 줄 설명 | 소요 시간 |
|----------|------|-----------|----------|
|          |      |           |          |
|          |      |           |          |
|          |      |           |          |
```
> 💡 이 양식은 지금까지 이사님 코칭 과정 전체가 정리되어 온 방식과 동일합니다. 스스로 강사가 되어 같은 틀로 짜보는 연습입니다.
---
## 5단계 — 강의자료 1개 완성
```plain text
4단계에서 만든 커리큘럼 중 1개 회차(또는 특강 전체)를 골라
실제 강의에서 쓸 수 있는 수준의 자료로 완성합니다.

이번 기회에 지금까지 배운 도구를 실제로 활용해 보세요.
- Gamma로 슬라이드 초안 만들기 (4·5회차)
- NotebookLM으로 자료 정리 (4회차)
- Canva로 보조 이미지·카드뉴스 제작 (4회차)
- 이미지 생성 프롬프트 활용 (3회차)

완성 기준: 실제로 그 자리에서 시연하거나 발표해도 어색하지 않은 정도
```

## 8/4 당일 진행 방식 (참고)
```plain text
8/4 당일에는 이 5가지 산출물을 가지고 함께:
- 커리큘럼 구조를 다듬고
- 세대별 교수법(누구에게 어떻게 다르게 설명할지)을 적용해보고
- 기존 강의 자료(이 신규 자료 포함) 재설계 코칭을 받고
- 어려운 질문 대응 훈련과 모의강의로 마무리합니다

→ 즉, 오늘 준비해 오시는 것이 "정답"일 필요는 없습니다.
   8/4에 함께 고쳐나갈 "초안"이면 충분합니다.
```
