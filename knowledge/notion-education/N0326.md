# 실습 1 — 버전별 기능 비교표를 Copilot으로 직접 생성해보기

정리일: 2026-10-08 · 교육 에셋 N0326

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
배운 버전별 기능 차이를 Copilot에게 직접 요청해 비교표로 만듭니다.
## 진행 단계
1. **비교표 요청** — copilot.microsoft.com 채팅 창에 붙여넣고 전송
- 입력할 내용:
```javascript
Microsoft Copilot의 무료(웹), Pro, M365 버전별 기능 차이를
아래 기준으로 비교표를 만들어줘.
비교 항목:
- 텍스트 기반 데이터 정리
- 파일 업로드 후 분석
- Excel 내 Copilot 사용
- 대용량 데이터 처리
- 조직 내부 데이터 연동
- 월 비용(대략적인 금액)
표 형식으로 출력하고, 표 아래에 실무 선택 기준을 3줄로 요약해줘.
```
- 정상 결과: 버전별 기능 비교표와 실무 선택 기준 요약이 한 번에 생성됨
1. **후속 프롬프트** — 월 비용이 달러로만 나오면 입력
```javascript
월 비용 항목을 한화(원화)로도 추가해줘.
```
1. **저장** — 비교표를 메모장이나 Word에 붙여넣어 `Copilot_버전비교표_[오늘날짜].docx`로 저장
