# 4-11. 직접 써보기 — 실습 2

정리일: 2026-10-08 · 교육 에셋 N1492

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
담당 프로그램 하나를 골라 ChatGPT로 문구를 확정한 뒤, 글자까지 들어간 모집 포스터 1장을 만듭니다.
## 진행 단계
1. **홍보 문구 먼저 정하기(3분)** — 포스터를 바로 만들지 말고 문구부터 확정합니다.
- 입력할 내용:
```plain text
너는 지자체 생활체육 프로그램 홍보를 10년간 담당한 홍보 전문가야.

교육기관 17의 [프로그램명] 모집 포스터에 들어갈 문구를 정해줘.

[참고 자료]
- 프로그램명:
- 대상:
- 기간:
- 요일·시간:
- 장소:
- 정원:
- 참가비:
- 신청 방법:

[조건]
- 큰 제목 1줄 (12자 이내)
- 작은 제목 1줄 (20자 이내)
- 정보 항목 5개 이하, 각 항목은 한 줄
- 맨 아래 신청 안내 1줄
- "함께해요", "여러분을 초대합니다" 같은 흔한 표현은 쓰지 말 것
- 어려운 외래어 금지

큰 제목은 서로 다른 느낌으로 3가지 안을 제시해줘.
```
- 정상 결과: 큰 제목 3가지 안 + 작은 제목·정보·신청 안내가 글자 수 제한 안에서 나옴
2. **포스터 이미지 생성(3분)** — 문구가 확정되면 같은 대화창에서 이어서 요청합니다(새 대화를 열면 문구를 다시 붙여넣어야 함).
- 입력할 내용:
```plain text
위에서 정한 1안 문구로 모집 포스터 이미지를 만들어줘.

[포스터 안에 넣을 글자] - 아래 글자를 정확히 그대로 넣어줘
큰 제목: (여기에 확정한 큰 제목)
작은 제목: (여기에 확정한 작은 제목)
정보:
  기간 -
  시간 -
  장소 -
  정원 -
  참가비 -
신청:

[디자인 조건]
- 세로형 포스터 (비율 3:4)
- 어르신들이 보시는 아파트 게시판용이니 글자를 아주 크게
- 배경은 실내 체육관에서 탁구 치는 밝은 분위기, 사람 얼굴은 크게 나오지 않게
- 밝은 배경에 어두운 글씨로, 글자와 배경 밝기 차이를 크게
- 글자가 그림에 묻히지 않도록 글자 뒤에 여백 확보
- 한글 맞춤법을 정확히 지킬 것
- 위에 적은 글자 외에 다른 글자는 넣지 말 것
```
3. **말로 수정(3분)** — 다시 만들지 말고 고쳐 달라고 합니다.
- 입력할 내용:
```plain text
글자는 좋은데 배경이 너무 어두워. 더 밝게 해줘. 나머지는 그대로.
```
- 정상 결과: 마음에 들었던 부분은 유지되고 지적한 부분만 바뀜
4. **저장과 공유(1분)** — 생성된 이미지를 길게 누르면 저장 메뉴가 나옵니다. 사진첩에 저장한 뒤 밴드나 카카오톡에 올립니다.
5. **눈으로 확인** — 날짜·시간·전화번호나 신청 방법·맞춤법·요청하지 않은 이상한 글자가 섞이지 않았는지 하나씩 봅니다.
- 입력할 내용:
```plain text
방금 만든 포스터에 들어간 글자를 전부 읽어서 알려줘.
내가 요청한 문구와 다른 부분이 있으면 짚어줘.
```
- 정상 결과: AI가 대조 결과를 알려줌(교안: 최종 확인은 반드시 눈으로)
## 막히는 지점
- 정확도가 크게 올랐지만 완벽하지 않음. 날짜와 전화번호는 한 글자만 틀려도 사고
- 글자가 깨지면 정보 다섯 줄을 네 줄로 줄임
- 무료 계정은 새로 만들 때마다 한도가 소모되므로 처음부터 다시 만들지 말고 수정으로 해결
