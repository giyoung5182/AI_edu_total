## 오늘 해결하는 문제

> *"이 데이터를 매일 이렇게 뽑는 게 맞나? 한 달 전체 흐름을 한눈에 볼 수 있으면 좋겠는데.""분석 결과를 보고서로 만들려면 또 시간이 걸리는데, AI가 초안을 잡아줄 수 있지 않을까?"*

```plain text

```

## 실습 전 핵심 개념 — 질문이 먼저, 데이터는 그다음
데이터 분석에서 가장 흔한 실수는 **"일단 데이터를 뽑고 나서 어디에 쓸지 생각하는 것"** 입니다.
올바른 순서는 반대입니다.
```plain text
❌ 잘못된 순서:
데이터 뽑기 → "이걸로 뭘 하지?"

✅ 올바른 순서:
"이 질문에 답하고 싶다" → 그 답을 뽑을 지표 설계 → 데이터 분석
```
**교육기관 구매부에 적용하면:**

지표 (설계)

데이터 (분석)




"이번 달 어떤 품목을 가장 많이 출고했나?"

품목별 월간 총출고량

월총합 시트 월총출고 열




"재고 위험이 반복되는 품목이 있나?"

주별 위험 등급 등장 횟수

날짜별 시트 실재고 추이




"입고 대비 출고가 빠른 품목은?"

품목별 재고 회전율

입고/출고 비율 계산


**오늘 실습 3에서 배우는 것은 이 "질문 → 지표 → 데이터" 순서로 사고하는 방법입니다.**

## 실습 전 핵심 개념 — 피벗이란 무엇인가
피벗 테이블은 대량의 데이터를 "내가 원하는 질문"에 맞게 즉시 재구성하는 도구입니다.
**피벗의 구조:**
```plain text
┌─────────────────────────────────────────┐
│  필터 (Filters)                          │
│  → 전체 데이터 중 어떤 조건만 볼 것인가    │
├──────────────┬──────────────────────────┤
│  행 (Rows)   │  값 (Values)              │
│  → 무엇을    │  → 얼마나                  │
│    기준으로  │    (합계·평균·개수 등)      │
│    볼 것인가 │                            │
├──────────────┤                            │
│  열 (Columns)│                            │
│  → 어떻게   │                            │
│    나눌 것인가│                           │
└──────────────┴──────────────────────────┘
```
**교육기관 재고파악에 적용하면:**

## 실습 전 핵심 개념 — 피벗 설계 3단계
```plain text
STEP 1. 질문을 정한다
        "이번 달 어떤 품목이 가장 많이 출고됐나?"

STEP 2. 필요한 축을 결정한다
        행: 품목명 (무엇을 기준으로)
        값: 월총출고 합계 (얼마나)
        정렬: 내림차순 (많은 것부터)

STEP 3. 추가로 보고 싶은 것을 덧붙인다
        전월 대비 증감? → 열에 월 추가
        카테고리별 비교? → 필터에 카테고리 추가
```

## 실습 3-A. 피벗 설계 — Claude에게 구조 물어보기 (20분)
### 왜 이 실습을 하는가
피벗 테이블은 강력한 도구지만 처음 접하면 "어느 필드를 어디에 놓아야 하는가"가 막막합니다. Claude에게 내가 원하는 질문을 말하면 피벗 구조를 설계해줍니다. 그 구조를 이해하면 직접 만들 수도 있고, Claude Pro에 만들어달라고 할 수도 있습니다.
---
**STEP 1.** 실습 2에서 쓴 **같은 채팅**에서 이어서 요청합니다.
> 파일을 다시 올릴 필요 없습니다. AI가 앞서 분석한 맥락을 그대로 기억하고 있습니다.
**STEP 2.** 아래 프롬프트 전송
```plain text
이 재고파악 파일로 아래 3가지 질문에 답하는
피벗 테이블을 각각 만들고 싶어.

[질문 1] 이번 달 매장출고가 가장 많은 품목 TOP 10은?
[질문 2] 27일 기준 실재고가 위험 수준(10 이하)인 품목 목록은?
[질문 3] 합재고와 실재고 차이가 가장 큰 품목 TOP 5는?

각 질문별로:
- 어느 시트를 써야 하는지
- 피벗의 행·열·값에 뭘 넣어야 하는지
- 정렬·필터 설정 방법
을 단계별로 알려줘.
```
---
### 결과 나오면 — 이런 상황이 생길 수 있습니다
**질문 1에서 27일 하루치 데이터로 분석 결과가 나왔다면?**
프롬프트에 "이번 달 매장출고"를 요청했는데 27일 하루치로 분석 결과가 나오는 경우가 있습니다.
**왜 이렇게 나오는가:**
AI는 두 시트(월총합·27)를 모두 인식하지만 어느 시트가 "이번 달 전체"를 담고 있는지 확신하지 못하면 데이터가 더 명확한 시트를 선택합니다. 이것이 DSRF에서 **\[D\] 데이터 명시**가 중요한 이유입니다. 어느 시트를 써야 하는지 명시하지 않으면 AI가 임의로 판단합니다.
**이럴 때 어떻게 하는가:**
같은 채팅에서 바로 수정 요청합니다.
```plain text
질문 1을 다시 해줘.
월총합 시트의 월총출고 열 기준으로
이번 달 전체 출고량 TOP 10을 뽑아줘.
27일 하루치가 아닌 월간 누계 기준이야.
```
> **이것이 반복 정제(Iteration)입니다.** 첫 결과가 틀렸다고 다시 처음부터 할 필요 없습니다. 틀린 부분만 구체적으로 짚어서 수정 요청하면 됩니다.
---
### 피벗 테이블 만드는 3가지 방법
피벗 구조를 파악했으면 실제로 만들어야 합니다. 본인에게 맞는 방법을 선택합니다.
**방법 1. 엑셀을 잘 다루는 분 — 직접 만들기**
```plain text
1. 재고파악 파일 열기
2. 월총합 시트 클릭
3. 데이터 범위 선택 → 삽입 → 피벗 테이블 → 새 시트에 생성
4. Claude가 알려준 대로 행·열·값 드래그
5. 정렬·필터 설정
```
**방법 2. Claude Pro에 만들어달라고 하기 (추천)**
엑셀 드래그가 익숙하지 않으면 Claude에게 결과 파일을 직접 만들어달라고 합니다.
```plain text
월총합 시트 기준 월총출고 TOP 10 결과를
피벗 테이블로 만들어줘.
엑셀 파일로 다운로드할 수 있게.
```
→ 엑셀 파일로 다운로드 가능. 단, 결과 파일을 받은 후 반드시 검증합니다.
> **결과 파일 검증 포인트:**<br>구성비(%)가 소수점 17자리로 나오는 경우가 있습니다. 이럴 때 바로 수정 요청합니다.
```plain text
"구성비를 소수점 1자리 %로 다시 만들어줘. 예: 0.4686 → 46.9%"
```
**방법 3. 코파일럿 — 다음 회차에서 배웁니다**
엑셀 파일 안에서 자연어로 "월총출고 기준 TOP 10 피벗 만들어줘"라고 말하면 자동 생성됩니다. M365 환경이 확인되면 3회차 이후에 진행합니다.

## 실습 3-B. Claude로 보고서 초안 생성 (30분)
### 왜 이 실습을 하는가
피벗으로 데이터를 구조화했습니다. 이제 이것을 보고서로 만들어야 합니다. 지금은 담당자가 숫자를 보면서 문장을 직접 씁니다. 형식도 매번 다르고 시간도 많이 걸립니다.
Claude에게 오늘 분석 내용을 주면 보고서 초안이 3분 안에 나옵니다. Word 파일로 바로 다운로드할 수 있습니다.
**단, AI 보고서 초안의 한계를 알아야 합니다:**





AI가 잘하는 것

AI가 못하는 것




숫자를 문장으로 바꾸기

현장 맥락 해석 ("왜 이 품목이 급감했나")




형식에 맞게 구조화

내부 의사결정 기준 반영




일관된 문체 유지

미래 예측·리스크 판단


```plain text
올바른 활용:
AI 초안(80%) → 담당자가 현장 맥락 추가·검수(20%) → 최종 보고서
```

같은 채팅에서 이어서 요청합니다.

```plain text
5. 내일 주의 관찰 품목

[형식]
- 제목: 2026년 5월 27일 구매부 일일 재고 현황
- 수신: 본부장님
- 작성: 프로님
- 전문 용어 최소화, 비전문가도 이해할 수 있게
```

### 결과 나오면 — 보고서 검토 3가지
**1. 수치가 실제 분석 결과와 일치하는가**<br>핵심 수치 3개를 원본 결과와 반드시 대조합니다.
**2. 현장 맥락이 빠진 부분이 있는가**<br>"된장육수 재고 1개" — AI는 발견했지만 왜 이렇게 됐는지는 모릅니다. 담당자가 알고 있는 배경(행사·발주 지연 등)을 추가합니다.
**3. 보고 대상에 맞는 언어인가**<br>본부장님 보고용이라면 전문 용어를 줄이고 숫자 중심으로 작성합니다.

## 실습 3-C. 피벗 + AI 결합 심화 (시간 남으면)
엑셀에서 만든 피벗 결과를 Claude에 붙여넣어서 추가 분석을 요청합니다.
**STEP 1.** 엑셀 피벗 결과 복사 → Claude 채팅에 붙여넣기
**STEP 2.** 아래 프롬프트 전송
```plain text
위에 붙여넣은 표는 이번 달 재고파악 품목별 출고 현황이야.

아래 분석을 해줘:

1. 출고량 기준 TOP 5 품목의 공통점이 있어?
   (카테고리·단위 등)

2. 이 데이터를 보고 다음 달 발주 계획에서
   특별히 주의해야 할 품목을 3개만 뽑아줘.
   이유도 함께 설명해줘.

3. 이 분석 결과를 공급업체와 협상할 때 쓸 수 있는
```

## 2회차 과제 — DSRF 직접 작성 \*작성 후 구글드라이브 업로드
