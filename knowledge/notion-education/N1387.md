# 실습 5: 피벗 해제와 그룹화

정리일: 2026-10-08 · 교육 에셋 N1387

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
가로형 보고서 표를 세로형 분석 데이터로 바꾸고, 파워쿼리 안에서 지역별로 집계합니다.
## 진행 단계
1. **문제1: 피벗 해제** — 데이터 가져오기 → Excel → `wide_format_unpivot.xlsx` → 시트 선택 → \[데이터 변환\] → 첫 행을 머리글로 → 지역 열 하나만 선택 → 변환 → 다른 열 피벗 해제 → 컬럼 이름 `월`, 값 `열사용량`으로 변경 → 닫기 및 로드.
- 정상 결과: 60행(지역 10 x 월 6).
2. **문제2: 그룹화** — 변환 → 그룹화 → 그룹 기준: 지역 → 새 열 이름 `상반기합계` / 연산: 합계 / 열: 열사용량.
- 정상 결과: 지역별 1행씩 총 10행.
3. (직접 풀어보기) 적용된 단계에서 그룹화 단계의 톱니바퀴 → 집계 추가 → 새 열 `월평균` / 연산: 평균 / 열: 열사용량.
## 막히는 지점
- 피벗 해제 때 지역 열 하나만 선택해야 합니다.
