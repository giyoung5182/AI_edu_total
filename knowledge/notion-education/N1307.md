## 이 실습으로 하는 것
작성한 CLAUDE.md가 실제로 읽히고, 규칙대로 동작하며 승인 지점에서 멈추는지 확인합니다.
## 진행 단계
1. **작업 폴더 지정** — 데스크탑 앱에서 Code 탭을 열고 작업 폴더를 지정합니다.
2. **읽힘 확인**
- 입력할 내용:
```javascript
/context
```
- 정상 결과: Memory files 항목에 `CLAUDE.md`가 보임
3. **요청**
- 입력할 내용:
```javascript
01_원본 폴더의 파일을 CLAUDE.md 규칙에 따라 통합해줘.
```
4. **승인 지점 확인** — 기준표에 없는 컬럼을 넣어 둔 파일에서 Claude가 멈추고 "확인이 필요합니다"(상황/영향/선택지/권장) 형식으로 묻습니다.
5. **결과물 확인**
- 정상 결과: 03_결과/에 통합 표, 04_기록/에 변경내역.md·확인필요.md가 생기고 01_원본/은 그대로
## 막히는 지점
- Memory files 항목에 CLAUDE.md가 안 보이면 파일 위치나 이름을 확인
