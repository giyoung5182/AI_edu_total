# 실습 3. 검색 실험 — 성공과 실패를 모두 목격한다

정리일: 2026-10-08 · 교육 에셋 N1275

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
의미 검색 페이지를 만들고 두 유형의 질문으로 검색이 잘 되는 경우와 안 되는 경우를 실험합니다.
## 진행 단계
1. **검색 페이지 추가** — /search, 메뉴 "검색", 질문 임베딩 후 상위 K개(기본 3) 청크 카드(순위·유사도·청크 번호·미리보기), 로그에 질문과 1위 청크 번호
2. **질문 준비** — 질문 A: 문서 표현을 쓰지 않고 일상 말로 / 질문 B: 문서의 정확한 용어나 번호를 그대로
3. **예측** — 어느 쪽을 의미 검색이 더 잘 찾을지 근거와 함께 적기
4. **검색·확인** — A, B를 각각 검색하고 1위 카드 원문에 답이 있는지 확인
5. **비교** — 예측과 실제를 비교하고 더 헤맨 쪽의 이유 추측
6. **추가 실험** — 자유 질문 수집, 실습 1의 손상 조각 관련 질문
## 막히는 지점
- 검색 결과가 비면 적재 현황 확인
- 점수가 전부 낮으면 문서에 있는 내용으로 다시 질문
