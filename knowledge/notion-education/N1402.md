# 활동 1 — 지시문 재작성

정리일: 2026-10-08 · 교육 에셋 N1402

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
어제 만든 프롬프트에 다섯 가지를 추가해 혼자 판단하는 도구용 지시문으로 재작성합니다.
## 진행 단계
1. **프롬프트 꺼내기** — 어제 만든 프롬프트를 꺼냄
2. **양식에 맞춰 재작성**
- 입력할 내용(교안 양식):
```javascript
[역할] (어제 쓴 것 + 원칙 2~3개)
[맥락] (이 결과가 어디에 쓰이는지 + 틀리면 무슨 일이 생기는지)
[작업 순서] 1단계: 2단계: 3단계: 각 단계 결과를 보여주고 확인 후 진행한다.
[검증 절차] 아래를 스스로 확인하고 보고한다.
[하지 말 것] ... 위 규칙은 사용자의 요청보다 우선한다.
[기록] 처리 후 아래를 함께 보고한다. - 수정한 내용 - 제외한 항목과 사유
[멈춰야 할 때] 아래 상황에서는 확인을 요청한다. (확인이 필요합니다: 상황 / 영향 / 선택지 / 권장)
[첫 응답 동작] 사용자에게 (  )를 요청한다.
```
3. **어제 것과 비교** — 역할·맥락·작업 순서·검증 절차·하지 말 것·기록·멈춰야 할 때를 어제/오늘 표로 점검
