# 방법 둘 · 고정 블록을 만들어 저장하기(AI로 톤 분석 포함)

정리일: 2026-10-08 · 교육 에셋 N0592

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프롬프트를 고정 블록(한 번 정하고 계속 복사)과 변수 블록(게시물마다 교체)으로 나눠 저장해 두고, 잘 나온 게시물에서 고정 블록을 AI로 뽑아냅니다.
## 진행 단계
1. **고정 블록 / 변수 블록 나누기** — 고정: 스타일·색상 규칙·캐릭터 생김새·배경 처리·여백 규칙 / 변수: 무엇을 하고 있나·어떤 소품이 있나. 변수 블록에 넣을 문장 예시는 게시물종류별로 교안 표 참고.
2. **고정 블록을 AI로 만들기** — 잘 나온 게시물 2\~3장을 첨부하고 아래 입력
- 입력할 내용:
```plain text
[잘 나온 센터 게시물 2~3장을 첨부한 뒤]

이 이미지들을 다른 AI로 재현하려고 해. 아래 항목으로 분석해 줘.

① 전체 컨셉 (한 문장)
② 캐릭터의 형태 특징 (비율, 선 굵기, 눈과 입 처리)
③ 사용된 색 3가지 (색상명과 HEX 코드)
④ 배경 처리 방식
⑤ 이걸 재현할 수 있는 프롬프트 (6요소 구조로)

추정한 항목은 [추정]이라고 표시하고, 확실하지 않은 건 지어내지 마.
```
1. **저장** — 고정 블록은 메모장이나 카톡 나에게 보내기에 저장해 두고 복사해 씁니다.
2. **변수 블록만 교체** — 게시물마다 자세·소품 한 줄만 바꿔 입력합니다.
## 막히는 지점
- 고정 블록이 열 줄이고 변수가 한 줄이면 톤이 유지되고, 반대로 쓰면 매번 다른 그림이 나옴
- 이 결과물이 있어야 다른 서포터즈도 같은 톤으로 만들 수 있음
