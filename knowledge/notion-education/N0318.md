# 실습 4. 업무 지도 카드 — 조립법을 내 일에 댄다

정리일: 2026-10-08 · 교육 에셋 N0318

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
화면을 잠시 접고 종이 또는 메모장에 세 칸짜리 카드를 작성해, 오늘의 조립법(데이터 → 담당 → 지시)을 내 일에 대 봅니다.
## 진행 단계
1. **① 반복 업무 적기** — 회사나 일상에서 반복하는 \[결정\] 또는 \[찾아보는 정보\] 하나를 적습니다. (예: 주간 회의 안건 정리 / 규정 조항 확인 / 환율 걸린 견적 검토 / 출장 준비)
2. **② 부품 고르기** — 문서에 근거해 답하기(A·B·C) / 입장을 다투고 결정하기(D) / 나눠 쓰고 합치기(E) / 두 가지 이상의 조합 중 동그라미를 칩니다.
3. **③ 실측 붙이기** — 메뉴판에서 빌려올 카드, 또는 "이런 데이터를 주는 API가 있다면" 하는 희망 사항을 적습니다. (없으면 "없음"도 답)
## 막히는 지점
- 5분 안에 ①이 떠오르지 않으면 예시 중 하나에 동그라미를 치는 것으로 충분합니다.
