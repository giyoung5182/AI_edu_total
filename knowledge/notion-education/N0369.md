# Step E · 상황별 시작점으로 첫 단계 1개 만들기 (E-1~E-4)

정리일: 2026-10-08 · 교육 에셋 N0369

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설계서를 보고 내 상황에 맞는 시작점 1개를 고르고, 그 시작점의 첫 단계 1개만 오늘 완성함. 바로 "만들어 줘" 하지 않음.
## 진행 단계
1. **시작점 고르기** — 같은 규정·기준으로 문의가 반복되고 근거 파일이 있음 → E-1 지침 먼저 / 열 이름·형식이 제각각이거나 개인정보가 섞임 → E-2 자료 먼저 / 실제 자료를 올릴 수 없거나 자료가 없음 → E-2-1 가짜 데이터 / 여러 파일을 읽어 결과 파일을 만들고 회차마다 다시 돌림 → E-3 폴더 먼저 / 설계서 7번에 도구가 둘 이상 → E-4 조합.
2. **E-1 지침 먼저** — 새 채팅에서 설계서 8번(ROPEK 요약)으로 프로젝트 지침 작성 → 자가진단으로 개선 → 지침 v1.0 저장 → 프로젝트 만들기(프로젝트 전용 메모리 선택) → 지침·소스 넣기 → 프로젝트에서 문의 1개 입력해 응답 양식 확인.
- 정상 결과: 답이 지침의 응답 양식대로 옴.
3. **E-2 자료 먼저** — 원본 보관(사본 이름 끝 `_정리본`) → 개인정보 가리기 → 열 이름 통일 → 새 채팅에 정리본 첨부해 5단계 점검(구조·결측·이상값·일관성·중복) → 고칠지는 사람이 결정, 정리기록.txt에 기록.
- 정상 결과: 정리본 1개 + 정리기록.
4. **E-2-1 가짜 데이터** — 실제 자료의 열 이름과 값의 종류만 메모 → 새 채팅에서 가짜 데이터 xlsx 생성 프롬프트 실행(열 순서·값 종류·행 수·일부러 넣을 오류 지정, 누가 봐도 가짜인 이름) → 받은 오류 목록의 행번호를 엑셀에서 직접 확인.
- 정상 결과: 가짜 데이터 파일(EX_ 접두) + 오류 목록.
5. **E-3 폴더 먼저** — 영어 소문자·숫자·하이픈으로 업무 폴더 만들기 → 새 채팅에서 AGENTS.md 6칸 초안 받기 → 처리 규칙을 내 기준으로 고쳐 UTF-8로 저장(파일 형식 '모든 파일') → Work 새 작업에서 round-01 폴더 연결 후 시작 보고 요청.
- 입력할 내용: `AGENTS.md를 먼저 읽고 그대로 처리. 이번 회차 입력: 1회차(N = 1) — [입력 파일 이름을 모두 적기]` / `시작하기 전에 ① AGENTS.md를 읽었는지와 버전 ② 실제로 연 입력 파일과 건수를 먼저 보고해 줘.`
- 정상 결과: AGENTS.md + 시작 보고(읽은 파일·건수)를 notes에 저장.
6. **E-4 조합** — 설계서 6번 표의 순서대로 한 도구씩, 앞 도구 결과가 원본과 맞는 것을 본 뒤 다음 도구로. 오늘은 첫 도구의 첫 단계만.
7. **기록** — 설계서 14번에 진행 상황과 "다음 단계" 1줄 기록.
## 막히는 지점
- Work가 AGENTS.md를 알아서 읽는지는 \[확인 필요\]라 요청문에 매번 적고 첫 보고로 확인.
- 원본 수정·삭제를 묻는 창이 뜨면 거부.
- 가짜 데이터 파일 링크가 없으면 `xlsx 파일로 만들어 줘` 한 번 더, 그래도 없으면 `표로 보여 줘` 후 엑셀에 붙여넣기.
- 실제 자료를 붙여넣고 "비슷하게 바꿔 줘"로 만들지 않음(원본이 AI에 들어감).
