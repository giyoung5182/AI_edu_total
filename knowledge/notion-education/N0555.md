# 4. 시각자료로 바꾸기 (인포그래픽·슬라이드·데이터 표)

정리일: 2026-10-08 · 교육 에셋 N0555

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정리된 자료를 NotebookLM의 인포그래픽·슬라이드 자료·데이터 표로 바꾸고, 다음 세션(Genspark)에 쓸 PPT 구성안을 뽑아 둡니다.
## 진행 단계
1. **인포그래픽** — 설명 칸에 아래 내용을 넣습니다.
- 입력할 내용(앞부분):
```javascript
이 NotebookLM에 들어 있는 자료만 기준으로
이 프로젝트의 핵심 내용을 한 장짜리 인포그래픽으로 정리해줘.
포함할 내용: 프로젝트 목적 / 핵심 메시지 3~5개 / 꼭 알아야 할 실행 항목 / 먼저 봐야 할 자료
조건: 한국어, 한눈에 이해되게, 보고용으로 깔끔하게
(이하 교안 참고)
```
1. **슬라이드 자료** — 프로젝트 개요 / 핵심 메시지 / 공통 내용 / 실행 항목 / 먼저 검토할 자료 구성으로 요청합니다.
2. **데이터 표** — 주제 / 핵심 내용 / 관련 자료 / 바로 쓸 수 있는 포인트 열로 요청하고, 경쟁사 비교표(브랜드 / 핵심 메시지 / 타겟 / 강점 / 참고 포인트)도 만들어 봅니다.
3. **Genspark 준비** — "총 12페이지로 구성해주고, 각 페이지에 들어갈 요소를 정리해서 작성해줘" 프롬프트로 PPT 재료를 뽑습니다.
- 팁: 그냥 눌러도 생성되지만 설명 칸에 무엇을 어떤 형태로 보고 싶은지 넣으면 결과가 목적에 맞아집니다.
