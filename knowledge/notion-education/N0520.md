# 실습 3: 폴더 병합 자동화

정리일: 2026-10-08 · 교육 에셋 N0520

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
월별 파일 6개를 클릭 몇 번으로 하나의 표로 만들고, 새 파일 추가 후 새로고침으로 갱신합니다.
## 진행 단계
1. **문제1: 폴더 병합** — 데이터 탭 → 데이터 가져오기 → 파일에서 → 폴더에서 → `monthly_data` 선택 → \[결합 및 변환\] → 샘플 파일 확인 창에서 \[확인\] → Source.Name 열 확인 → 닫기 및 로드.
- 정상 결과: 총 360행(6개월 x 60행).
2. **문제2: 새 파일 추가 → 새로고침** — `heat_usage_2026_07.csv`를 `monthly_data` 폴더에 복사 → 엑셀에서 데이터 탭 → 모두 새로 고침.
- 정상 결과: 360 → 420행.
3. **문제3: 자동 새로고침** — 우측 쿼리 및 연결 → monthly_data 우클릭 → 속성 → 파일을 열 때 데이터 새로 고침 체크.
4. (직접 풀어보기) 병합 표 선택 → 삽입 → 피벗테이블 → 행: 지역 / 열: 사용일자 / 값: 열사용량 합계. 7월 열까지 나타나면 성공.
## 막히는 지점
- 폴더 병합에 이상한 파일이 들어오면(임시파일 \~\$, 다른 형식) 폴더 정리 또는 확장자 필터.
- 새로고침이 안 되거나 경로 오류면(파일 이동·이름 변경) 데이터 원본 설정에서 경로 다시 지정.
