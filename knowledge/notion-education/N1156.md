# 바이브코딩 업무자동화 프로젝트

정리일: 2026-10-08 · 교육 에셋 N1156

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 업무의 비효율을 제거하는 웹사이트를 바이브코딩으로 직접 만듭니다. 업무 프로세스를 Input → AI → Output 으로 먼저 구조화한 뒤 진행합니다.
## 진행 단계
1. **프로젝트 주제 확인** — 내 업무의 비효율을 제거하는 웹사이트 제작하기
2. **문제 정의** — "내가 제거하고 싶은 업무는 무엇인가?"
3. **AI와 설계** — "이 문제를 해결하려면 뭐가 필요한지 같이 정리해보자"
4. **결과물 개발** — AI와 대화하며 결과물 만들기. 대외비 자료 사용 금지, 더미데이터를 제작해서 진행
5. **테스트** — 원하는 대로 동작하는지 확인하고 개선 요청
6. **프로젝트 제출** — 추후 공지
[원본 이미지 제외]
- 입력할 내용(프롬프트가 막힐 때 쓰는 기법 예시):
```javascript
역할: 재무회계 담당 / 목표: 전표 검토 현황판 / 조건: 한 페이지, 표와 그래프
"내 업무를 먼저 이해해줘" → "자동화할 부분을 찾아줘" → "화면을 설계해줘"
이런 문제를 해결하고 싶은데, 어떻게 만들면 좋을지 나를 인터뷰해서 파악해줘
```
## 막히는 지점
- 프롬프트가 막힐 때: ① 개괄식 정리(역할·목표·조건) ② 단계별 지시 ③ 역질문기법(AI가 나를 인터뷰)
