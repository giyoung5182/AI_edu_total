# Part 1. AI 작동 원리 다섯 가지
이 파트가 이 교재에서 가장 중요합니다. 여기 나오는 다섯 가지 원리로 **이후 교재의 모든 기술이 설명됩니다.**
## 1-1. 원리 하나 — AI는 다음에 올 말을 예측한다
### 무슨 일이 벌어지고 있나
우리는 AI가 "생각하고 답한다"고 느끼지만, 실제로 벌어지는 일은 다릅니다.
AI는 인터넷의 방대한 글을 학습해서 **지금까지의 말 다음에 올 확률이 가장 높은 말을 하나씩 이어 붙이는 방식**으로 문장을 만듭니다.
```plain text
"오늘 날씨가 참" → 다음에 올 확률: "좋네요"(높음) / "덥네요"(높음) / "책상"(거의 0)
```
이걸 수만 번 반복하면 한 편의 보고서가 나옵니다.
[원본 이미지 제외]

### 여기서 따라 나오는 두 가지 성질
**성질 하나. 문장을 그럴듯하게 만드는 데는 세계 최고입니다.**<br>확률이 높은 말만 골라 이으니 결과는 항상 자연스럽고 매끄럽습니다. 그래서 안내문, 보고서 초안, 홍보 문구를 정말 잘 씁니다.
**성질 둘. 사실인지 아닌지는 검사하지 않습니다.**<br>AI의 판단 기준은 "이게 사실인가"가 아니라 "이 말이 자연스러운가"입니다. 이 둘은 다릅니다. 그래서 숫자, 날짜, 사람 이름, 법령 조항이 틀릴 수 있습니다.
### 할루시네이션의 정체
**할루시네이션(hallucination, 환각)** 은 AI가 없는 사실을 그럴듯하게 지어내는 현상입니다.
```plain text
질문: 국민체육진흥법 몇 조에 생활체육 지도자 배치 근거가 있어?
답변: 국민체육진흥법 제23조에 따라... (조항 번호가 틀림)
```
**원리**<br>AI 입장에서 "국민체육진흥법 제" 다음에 올 확률이 높은 말은 숫자입니다. 어떤 숫자가 사실인지는 확인하지 않고 **그럴듯한 숫자를 채워 넣습니다.** 빈칸을 비워두는 것보다 채우는 게 자연스럽기 때문입니다.
그래서 할루시네이션은 AI의 결함이 아니라 **작동 방식 자체에서 나오는 필연적 특성**입니다. 기술이 발전해도 완전히는 없어지지 않습니다.
**주의 — 절대 그대로 믿으면 안 되는 다섯 가지**
1. 숫자 (예산액, 참가 인원, 통계)
2. 날짜 (행사일, 공고 기한)
3. 사람 이름과 직함
4. 법령, 조례 조항 번호
5. 기관명, 부서명
공통점이 보이시나요. 전부 **자연스러움과 정확함이 일치하지 않는 정보**입니다. 어떤 숫자를 넣어도 문장은 자연스럽습니다. 그래서 AI가 가장 잘 틀립니다.
**핵심**<br>초안은 AI, 검토는 사람.
## 1-2. 원리 둘 — 정보를 주면 예측 범위가 좁아진다
### 왜 구체적으로 말하면 결과가 좋아지나
원리 하나에서 AI는 확률이 높은 말을 고른다고 했습니다. 그런데 **확률은 앞에 어떤 말이 있느냐에 따라 완전히 달라집니다.**
```plain text
"홍보글 써줘"
→ AI가 고를 수 있는 후보가 무한대. 인터넷에서 가장 흔한 홍보글이 나옴

"중구체육회 어르신 탁구교실, 60세 이상, 정원 20명, 무료, 아파트 게시판용"
→ 후보가 확 좁아짐. 이 조건에 맞는 말만 남음
```
**원리**<br>프롬프트에 정보를 넣는 것은 AI를 똑똑하게 만드는 게 아니라 **AI가 고를 수 있는 답의 범위를 좁히는 일**입니다. 좁힐수록 내가 원하는 답에 가까워집니다.
이것이 컴퓨터를 잘하는 사람보다 자기 업무를 정확히 아는 사람이 AI를 잘 쓰는 이유입니다. **범위를 좁힐 재료를 가진 쪽이 이깁니다.**
[원본 이미지 제외]

### 여기서 나오는 실무 결론
- 역할을 주는 것("너는 홍보 담당자야")도 범위 좁히기입니다
- 조건을 주는 것("200자 이내")도 범위 좁히기입니다
- **자료를 주는 것이 가장 강력한 범위 좁히기**입니다. AI는 우리 체육회 사정을 하나도 모르기 때문입니다
이 원리가 Part 5의 업무 비서 만들기로 이어집니다. **매번 똑같이 반복되는 범위 좁히기를 아예 저장해두는 것**이 업무 비서입니다.
## 1-3. 원리 셋 — 흔한 표현일수록 먼저 나온다
### 왜 AI가 만든 글은 뻔한가
AI가 고르는 기준은 "학습 데이터에서 자주 나온 말"입니다. 그러니 결과는 자연히 **인터넷에서 가장 흔한 표현**이 됩니다.
```plain text
"홍보 문구 만들어줘"
→ "여러분을 초대합니다", "함께해요", "건강한 노후" ...
   인터넷 홍보물에 수십만 번 나온 표현들
```
이건 AI가 창의력이 없어서가 아니라 **확률이 높은 쪽을 고르도록 만들어졌기 때문**입니다.
### 여기서 나오는 강력한 기술 — 금지어 지정
그렇다면 뻔한 결과를 피하는 방법은 명확합니다. **확률 1등을 못 쓰게 막으면 됩니다.**
```plain text
"함께해요", "여러분을 초대합니다" 같은 흔한 표현은 쓰지 말 것
```
**원리**<br>"잘 써줘"는 범위를 좁히지 못합니다. 무엇이 잘 쓴 건지 AI가 알 수 없기 때문입니다. 반면 "이건 쓰지 마"는 **후보 목록에서 특정 항목을 직접 제거**합니다. 그래서 2등, 3등 표현이 올라옵니다.
실무 고수들이 프롬프트에 금지 조건을 반드시 넣는 이유가 이것입니다. **칭찬보다 금지가 훨씬 정확하게 작동합니다.**

## 1-4. 원리 넷 — 맥락에는 한계가 있고, 길수록 흐려진다
### 대화창 하나가 기억 상자 하나
AI는 하나의 대화창 안에서만 앞의 내용을 기억합니다. 새 대화를 열면 지금까지 한 이야기를 전부 잊습니다.
그런데 그 기억 상자에도 크기가 있습니다. 이것을 **맥락창(context window)** 이라고 합니다.
**원리**<br>AI는 답을 만들 때 대화창 안의 모든 내용을 한 번에 훑어봅니다. 그런데 내용이 길어지면 **주의가 분산됩니다.** 사람이 30페이지 회의록을 읽고 나면 앞부분이 흐릿해지는 것과 비슷합니다. 그래서 대화가 길어질수록 앞에서 준 지시를 슬슬 어기기 시작합니다.

# Part 3. AI에게 말 거는 법
## 3-1. 왜 같은 AI인데 결과가 다른가
같은 ChatGPT를 쓰는데 어떤 사람은 대단하다고 하고 어떤 사람은 별거 없다고 합니다.
차이는 딱 하나, **프롬프트(prompt)** 입니다. 프롬프트란 AI에게 보내는 지시문, 쉽게 말해 "AI에게 일 시키는 말"입니다.
원리 둘에서 봤듯이 프롬프트는 AI가 고를 수 있는 답의 범위를 좁히는 도구입니다. 좁히는 재료를 많이 넣은 사람이 좋은 결과를 얻습니다.
## 3-2. 나쁜 예와 좋은 예
### 나쁜 예
```plain text
탁구교실 홍보글 써줘
```
어느 지역인지, 누구 대상인지, 언제인지 모릅니다. 원리 셋에 따라 인터넷에서 가장 흔한 홍보글이 나옵니다. 그대로 못 씁니다.
### 좋은 예
```plain text
너는 지자체 생활체육 프로그램 홍보를 10년 담당한 홍보 담당자야.

교육기관 17에서 운영하는 '어르신 탁구교실' 참가자를 모집하려고 해.
- 대상: 중구 거주 만 60세 이상
- 기간: 8월 5일 ~ 10월 28일, 매주 화·목 오전 10시~11시
- 장소: 중구국민체육센터 탁구장
- 정원: 20명, 참가비 무료
- 신청: 중구체육회 사무국 전화 접수

중구 지역 어르신들이 보시는 아파트 게시판에 붙일 안내문을 써줘.
- 글씨를 크게 읽으실 것을 고려해 문장은 짧게
- 어려운 외래어 쓰지 말 것
- 제목 1줄 + 본문 200자 내외 + 신청 안내
- 마지막에 참여를 권하는 따뜻한 한 문장
```
손볼 것 거의 없이 바로 인쇄해서 붙일 수 있는 안내문이 나옵니다.
**핵심**<br>차이는 AI의 성능이 아니라 정보를 얼마나 줬느냐입니다.
## 3-3. R.C.T.C.K — 프롬프트 다섯 요소
위의 좋은 예를 뜯어보면 다섯 조각으로 되어 있습니다.





요소

뜻

무엇을 쓰나

AI에게 누구인지 알려주기

**이 다섯 글자를 꼭 기억해 두세요.** Part 5에서 업무 비서를 만들 때 이 다섯 개가 그대로 쓰입니다.
### 다섯 개 중 무엇이 가장 중요한가
초보자는 R(역할)이 제일 신기해서 거기 집착합니다. 하지만 실무에서 결과를 결정하는 건 압도적으로 **K(자료)** 입니다.
**원리**<br>역할 부여는 AI가 이미 아는 것 중에서 범위를 좁힙니다. "홍보 담당자"라고 하면 홍보 담당자가 쓸 법한 표현 쪽으로 기울죠. 하지만 **우리 체육회 사정은 애초에 AI 안에 없습니다.** 없는 것은 좁힐 수가 없습니다.
그래서 자료를 안 주면 AI는 원리 하나에 따라 그럴듯한 숫자를 지어냅니다. 역할 부여를 빼먹어도 결과는 그럭저럭 나오지만, 자료를 안 주면 아무리 좋은 프롬프트도 소용없습니다.
### 왜 굳이 역할을 주는가
그렇다고 R이 무의미한 건 아닙니다. 원리 셋 때문입니다.
역할을 안 주면 AI는 "일반적인 글"의 확률 분포에서 답을 고릅니다. "너는 공공기관 문서 전문가야"라고 하면 **그 직업군이 쓰는 어휘와 문장 구조 쪽으로 확률이 기울어집니다.** 한 줄로 결과의 톤 전체가 바뀌는 이유입니다.

AI가 "참가 인원은 몇 명입니까, 만족도 조사는 하셨습니까" 하고 물어봅니다. 답만 하면 됩니다.
**원리**<br>좋은 프롬프트란 결국 원리 둘의 범위 좁히기를 잘한 것입니다. 그런데 **어떤 정보가 범위를 좁히는 데 유용한지는 AI가 더 잘 압니다.** 그 판단을 AI에게 넘기고 우리는 답만 채우는 것입니다.
초보자에게 효과가 가장 큰 기술입니다. 이 기법 하나만 익혀도 프롬프트를 못 쓰는 문제가 통째로 사라집니다.
### 기술 둘. 3안 요청 — 여러 개 뽑고 고르기
`원리 셋`
```plain text
위 내용으로 안내문 제목을 3개 만들어줘.
1안은 정중하게, 2안은 친근하게, 3안은 눈에 띄게.
각각 왜 그렇게 썼는지 한 줄로 설명도 붙여줘.
```
**원리**<br>AI는 확률 1등부터 내놓습니다. 한 개만 요청하면 가장 뻔한 게 나옵니다. 여러 개를 요청하면 **2등, 3등, 4등 후보까지 꺼내게 되고 그 안에 신선한 게 섞여 있습니다.**
게다가 "정중하게 / 친근하게 / 눈에 띄게"처럼 서로 다른 방향을 지정하면 세 개가 서로 다른 확률 영역에서 나옵니다. 그냥 "3개 만들어줘"라고 하면 비슷비슷한 게 세 개 나옵니다.
**주의**<br>초보자가 가장 많이 하는 실수는 첫 번째 결과를 그냥 쓰는 것입니다. 첫 답변은 초안일 뿐입니다.
### 기술 셋. 되묻기 — 대화를 이어가야 좋아진다
`원리 둘, 원리 넷`
한 번 묻고 끝내는 것은 AI를 10퍼센트만 쓰는 것입니다.
```plain text
좋은데 너무 딱딱해. 조금 더 따뜻하게 다시 써줘.
```
```plain text
2번 문단만 반으로 줄여줘. 나머지는 그대로 둬.
```
```plain text
어르신들이 읽으실 거라 글자가 많으면 안 돼. 절반 분량으로.
```
**원리**<br>첫 답변이 나오면 그 답변 자체가 대화창 안의 새로운 정보가 됩니다. 즉 **두 번째 요청은 첫 답변을 재료로 삼는 변환 작업**이 됩니다. 원리 다섯에 따라 변환은 정확합니다.
그래서 처음부터 완벽한 프롬프트를 쓰려고 애쓰는 것보다 대충 시작해서 세네 번 다듬는 쪽이 훨씬 빠르고 결과도 좋습니다.
AI와의 대화는 디자이너에게 시안 수정을 요청하는 것과 같습니다. "다시 해줘"가 아니라 **어디를, 어떻게**를 말해야 합니다.
### 기술 넷. 출력 형식 지정
`원리 둘`
이 한 줄을 붙이는 것과 안 붙이는 것의 차이가 큽니다.
```plain text
결과를 표로 정리해줘.
```
```plain text
번호 매긴 목록으로 줘.
```
```plain text
그대로 복사해서 문자로 보낼 수 있게, 설명 없이 본문만 줘.
```
**원리**<br>AI는 학습 과정에서 "사용자를 돕는 친절한 조수"처럼 답하도록 조정되었습니다. 그래서 "네, 알겠습니다. 여기 안내문입니다" 같은 인사말이 확률적으로 앞뒤에 붙습니다.
"본문만"이라고 지정하면 그 확률 경로를 차단합니다. **원리 셋의 금지어 지정과 같은 원리**입니다.

### 기술 다섯. 맞춤형 지침 — 한 번 세팅하고 계속 쓰기
`원리 둘`
매번 "나는 중구체육회 지도자야"를 반복해서 쓰고 계신가요. 그럴 필요가 없습니다.
ChatGPT 설정에 **맞춤형 지침(Custom Instructions)** 을 넣어두면 모든 대화에 자동 적용됩니다.
**설정 경로**
```plain text
ChatGPT 앱 → 좌측 또는 우측 상단 메뉴 → 설정
→ 개인 맞춤 설정 → 맞춤형 지침
```
두 개의 입력칸이 있습니다. 위쪽은 나에 대한 정보, 아래쪽은 답변 방식입니다.
**위쪽 칸 (나에 대해)**
```plain text
나는 서울특별시 중구체육회 소속 생활체육 지도자입니다.
주요 업무는 생활체육 프로그램 운영, 참가자 모집 홍보,
사업 결과보고서 및 공문 작성, 회원 안내입니다.
교육 대상은 주로 중구 지역 주민이며 어르신 비중이 높습니다.
```
**아래쪽 칸 (답변 방식)**
```plain text
- 항상 한국어로 답변할 것
- 공공기관 문서 어투를 기본으로 하되, 홍보물은 친근하게
- 불필요한 인사말과 서론 없이 결과부터 제시할 것
- 어려운 외래어 대신 쉬운 우리말을 쓸 것
- 확실하지 않은 숫자, 날짜, 법령은 반드시 "확인 필요"로 표시할 것
- 결과가 길면 표나 번호 목록으로 정리할 것
```
**원리**<br>맞춤형 지침은 매 대화의 맨 앞에 이 내용이 자동으로 붙는 것과 같습니다. 즉 **원리 둘의 범위 좁히기를 영구적으로 걸어두는 장치**입니다. R과 C를 매번 쓸 필요가 없어집니다.
2026년 현재 각 칸당 1,500자까지 넣을 수 있고, 설정을 바꾸면 이미 열려 있는 대화에도 즉시 반영됩니다. 답변이 지나치게 들뜬 말투라면 열정도 슬라이더를 낮추면 훨씬 담백해집니다.
**이 기술이 Part 5의 예고편입니다.** 맞춤형 지침은 계정 전체에 하나만 걸 수 있는데, 업무마다 다른 지침이 필요하죠. 그걸 업무별로 여러 개 만들어두는 것이 Part 5에서 배울 **업무 비서(Gem)** 입니다.
### 기술 여섯. 음성 입력 — 스마트폰의 최대 무기
`원리 다섯`
노트북에는 없는 장점입니다. 타이핑이 느리신 분은 입력창의 마이크 아이콘을 누르고 그냥 말씀하세요.
```plain text
"어제 어르신 탁구교실 8회차 마지막 수업 했고, 참가자는 스물다섯 명이었고,
만족도 조사에서 4.6점 나왔고, 다음 기수 재등록 의사가 열여덟 명이었어.
이걸로 결과보고서 초안 만들어줘."
```
말로 하면 30초, 타이핑하면 5분입니다.
**핵심 요령**<br>말할 때는 문장을 예쁘게 다듬으려 하지 마세요. 두서없이 생각나는 대로 다 말하고 마지막에 이렇게 덧붙이면 됩니다.
```plain text
내가 말한 게 두서없는데, 정리해서 보고서로 만들어줘.
```
**원리**<br>정리는 **원리 다섯의 변환 작업**입니다. 재료가 이미 내 말 안에 다 있으니 AI가 지어낼 필요가 없고 따라서 정확합니다.
반대로 내가 말을 예쁘게 다듬느라 정보를 빠뜨리면 그 빈칸을 AI가 지어냅니다. **정보를 많이, 형식은 대충**이 정답입니다.

스마트폰의 두 번째 무기는 카메라입니다. 입력창의 플러스 버튼에서 사진 촬영을 누르세요.

**원리**<br>"우리 기관 양식대로 써줘"를 말로 설명하려면 어렵습니다. 제목 위치, 항목 순서, 들여쓰기, 문체를 전부 글로 옮겨야 합니다.
그런데 사진을 보여주면 **그 형식 전체가 한 번에 재료로 들어옵니다.** 그러면 생성이 아니라 변환 작업이 됩니다. 노트북이 없는 오늘 환경이 단점이 아니라 오히려 강점이 되는 지점입니다.

### 기술 여덟. 단계 쪼개기
`원리 넷`
한 번에 큰 걸 시키면 결과가 얕습니다. 단계로 나누세요.
```plain text
1단계: 어르신 대상 신규 생활체육 프로그램 아이디어를 10개 뽑아줘.
```
결과 확인 후
```plain text
2단계: 그중 예산 500만 원 이하, 실내에서 가능한 것 3개만 골라줘.
```
결과 확인 후
```plain text
3단계: 3번 아이디어로 사업계획서 목차를 짜줘.
```
**원리**<br>한 번에 "사업계획서 써줘"라고 하면 AI는 아이디어 발상과 선별과 구조 설계를 **한 번의 예측 흐름 안에서** 처리해야 합니다. 맥락창의 주의가 여러 과제로 분산되어 어느 것도 깊어지지 않습니다.
쪼개면 각 단계의 결과가 다음 단계의 재료가 됩니다. 즉 **매 단계가 원리 다섯의 변환 작업**이 되어 정확도가 올라갑니다.
