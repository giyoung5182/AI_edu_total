# 3장 — 실습: 비즈머니 잔액 부족 → 충전 요청 이메일 자동 발송
---
## 만들 것
```plain text
구글 시트 비즈머니_잔액 시트를 감지해서
잔액이 50만원 이하이면
충전 요청 이메일을 자동으로 발송한다
```
**모듈 3개만 씁니다**
```plain text
[Google Sheets]  →  [Filter]  →  [Gmail]
 시트 변경 감지      조건 확인     이메일 발송
```
---
## 실습에 쓸 파일
```plain text
파일명: 프로님_비즈머니알림_실습해보기
시트명: 비즈머니_잔액
확인할 셀: (현재 잔액)
현재 값: 500,000원 → 이미 기준 이하 상태
기준: 500,000원 이하이면 이메일 발송
```
> 강사가 공유한 링크로 파일을 열고 내 드라이브에 사본 저장 후 시작합니다.<br>**\[파일\] → \[사본 만들기\] → 내 드라이브에 저장 / or 불러오기**
---
## STEP 0. 사전 확인 (1분)
```plain text
1. 내 드라이브에 파일 열기
   → 비즈머니_잔액 시트 탭 클릭
   → I4 셀 값 확인: 500,000원

2. make.com 로그인
   → 오른쪽 위 이름 확인 (내 계정 맞는지)
```
---
## STEP 1. 새 시나리오 만들기 (1분)
```plain text
① make.com 왼쪽 메뉴 → [Scenarios] 클릭

② 오른쪽 위 [+ Create a new scenario] 클릭

③ 팝업이 뜨면 [Build from scratch] 또는 그냥 [X] 닫기
   → 빈 캔버스 화면이 열림

④ 왼쪽 위 시나리오 이름 클릭
   → "비즈머니_잔액알림" 입력 → Enter
```
---
## STEP 2. 트리거 추가 — 구글 시트 감지 (5분)
```plain text
① 캔버스 가운데 큰 [⊕] 클릭

② 검색창에 "Google Sheets" 입력

③ [Google Sheets] 선택

④ 오른쪽 패널에서 [Watch Rows] 선택
   (새 행이 추가될 때 감지)
```
**연결 설정:**
```plain text
⑤ Connection: [Add] 클릭
   → 구글 계정 선택 팝업 열림
   → 본인 구글 계정 클릭
   → [계속] → [허용] 클릭
   → Make.com으로 돌아오면 연결 완료
```
> ⚠️ **팝업이 안 열리면:** 브라우저 주소창 오른쪽 팝업 차단 아이콘 클릭 → 허용 → \[Add\] 다시 클릭
**시트 선택:**
```plain text
⑥ Spreadsheet ID: 클릭
   → "프로님_비즈머니알림_실습해보기" 검색 또는 선택

⑦ Sheet Name: "비즈머니_잔액" 선택

⑧ Limit: 1 (2가 아니라 1로 변경)

⑨ [OK] 클릭

⑩ 팝업: "어디서부터 시작할까요?"
Choose manually 선택 후 가장 마지막 행 선택 (2026-06-19)

```

## STEP 4. 필터 추가 — 잔액 조건 확인 (3분)
두 모듈 사이 화살표 선이 보이시죠? 그 선 위에 마우스를 올려보세요.
`Google Sheets 모듈 → (화살표 선) → Gmail 모듈`
[원본 이미지 제외]
```plain text
① 트리거 모듈과 다음 모듈 사이 화살표 위의
   [렌치 아이콘 🔧] 클릭

   → 아직 다음 모듈이 없으면:
     트리거 모듈 오른쪽 [⊕] 클릭 → 모듈 추가 전에
     화살표가 생긴 후 렌치 클릭

② [Set up a filter] 클릭
```
**필터 설정:**
```plain text

  왼쪽 값: [I4 열 선택] 또는 직접 입력
           (Run once 실행 후 변수 목록에서 I열 선택)
  연산자:  Less than or equal to (≤)
  오른쪽 값: 500000

→ [OK]
```

## STEP 5. 저장 + 테스트 (5분)
**저장 먼저:**
```plain text
① 하단 [Save] 클릭 (저장 안 하면 테스트 불가)
```
**데이터 한 번 흘려보내기:**
```plain text
② 하단 [Run once] 클릭
   → "Waiting for data..." 메시지 표시

③ 구글 시트로 이동
   → 비즈머니_잔액 시트에서 아무 빈 셀에
     임시 값 입력 후 Enter (새 행 추가 트리거용)
   → 또는 I4 셀 값을 잠깐 수정 후 Enter

④ Make.com으로 돌아오면
   → 트리거 모듈 위에 숫자 "1" 표시 확인
   → 초록색 체크 = 성공 / 빨간색 = 오류
```

## STEP 6. 주기 설정 + ON (1분)
```plain text
구글시트 맨 처음 모듈의 왼쪽 하단에 있는 시계 버튼 누르
   → Every: 15 minutes 선택
   → [Save]

② 하단 오른쪽 스위치 → [ON] 켜기

완료!
이제 15분마다 시트를 확인해서
잔액이 기준 이하이면 자동으로 이메일 발송됩니다.
```

## 완성된 시나리오 구조

```plain text
[Google Sheets]     [Filter]         [Gmail]
 Watch Rows     →  I4 ≤ 500,000  →  Send an Email
 (시트 감지)        (잔액 조건)       (충전 요청 이메일)
```
