# 실습 4. 조직 확산 로드맵 수립 (과제 A 전사 로드맵 / 과제 B 개인 실행 계획)

정리일: 2026-10-08 · 교육 에셋 N1515

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
파일럿→검증→확산→정착 4단계 조직 확산 로드맵(전사)과 내 업무 영역의 개인 실행 로드맵을 작성한다.
## 진행 단계
1. **과제 A 전사 로드맵** — 파일럿(2026년 하반기) / 검증(2027 상반기) / 확산(2027 하반기) / 정착(2028년 이후) 각 단계의 핵심 활동과 목표 지표를 표에 쓴다.
2. **과제 B 개인 로드맵** — 즉시 착수(1개월 이내) / 단기(1\~3개월) / 중기(3\~6개월) / 장기(6개월\~1년)별로 개선 과제, 사용할 SQL·도구, 성공 기준을 쓴다.
3. **셀프 체크리스트·제출** — 체크 항목 8개를 확인하고 과제 1\~4(슬라이드 구성안, 개선 과제, 사례 분석표, 로드맵+개인 계획)을 표 형식으로 제출한다.
- 정상 결과: 예시 답안 예) 파일럿은 에너지사업팀 열 사용량 데이터 품질 관리, 목표 지표 결측률 1% 이하·지역명 표준화 완료
## 막히는 지점
- 확산 실패 패턴: 규정으로 강제하면 저항이 생김 / 복잡한 절차는 아무도 따르지 않음 / 큰 성과만 기다리면 모멘텀을 잃음 / 현업 의견을 무시하면 현실과 멀어짐 / 경영진 관심이 없으면 예산·인력이 안 붙음
