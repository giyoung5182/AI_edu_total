# 3-3. 프롬프트 체이닝으로 결과 다듬기

정리일: 2026-10-08 · 교육 에셋 N0338

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
첫 결과물이 나온 뒤 같은 창에서 이어서 수정 요청을 하며 품질을 70점에서 90점으로 끌어올립니다.
## 진행 단계
1. **수정 요청 입력** — 첫 번째 결과물이 나온 후 같은 창에서 이어서 입력
- 입력할 내용 예:
```javascript
"전체적인 방향은 좋은데, 두 번째 항목을 더 구체적으로 써줘."
"표 형식을 더 읽기 쉽게 바꿔줘."
"격식체가 너무 딱딱해. 좀 더 자연스럽게 다듬어줘."
"이 내용에 수치 근거를 추가해줘."
"A4 1장으로 줄여줘. 핵심만 남기고."
```
2. **원칙** — 한 번에 1\~2가지만 수정 요청, 마음에 드는 부분은 "이 부분은 유지해줘"라고 명시, 3\~4번 수정이면 원하는 수준 도달 가능
## 막히는 지점
- "전부 다 다시 써줘"는 방향을 잃을 수 있으므로 피할 것
