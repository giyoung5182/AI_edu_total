# 미니 콘테스트 — 결과물 제출·체험·피드백

정리일: 2026-10-08 · 교육 에셋 N0573

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
결과물을 제출 가능한 형태로 정리해 제출하고, 동료 결과물을 체험해 피드백을 주고받습니다.
## 진행 단계
1. **작품 제목 정리** — 한눈에 기능이 보이게 적습니다. (예: `주간보고 3줄 요약기`, `회의 Action Item 추출기`, `팀 일정 시각화 보드`)
2. **Pain Point / 해결 방식 / 더미 데이터 작성** — 해결하려던 병목을 한두 문장으로, 도구가 문제를 푸는 방식을 설명, 필요하면 더미 데이터 준비
- 정상 결과: 실제 회사 데이터는 넣지 않고 형식만 유사한 가상 예시 2\~3줄을 씁니다.
3. **HTML 파일 최종 점검, 보안 체크**
4. **콘테스트 플랫폼 제출** — HTML 파일을 다운 받는 링크를 제공합니다.
- 입력할 내용:
```javascript
작품명:

작품 설명:

HTML 파일 업로드:

예시 데이터:
```
1. **동료 결과물 체험, 추천 또는 피드백** — 문제 정의가 명확한가, 입력과 출력이 직관적인가, 바로 써보고 싶은 흐름인가, 다른 업무에 확장 가능성이 있는가를 봅니다. 피드백은 `멋있다`보다 구체적으로 줍니다.
2. **적용 아이디어 짧게 공유** — 바로 써볼 포인트 하나, 추가하면 좋을 기능 하나, 확장 가능한 아이디어 하나
