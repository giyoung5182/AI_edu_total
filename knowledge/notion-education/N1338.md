# 실습 2. 표준 용어 사전 만들기

정리일: 2026-10-08 · 교육 에셋 N1338

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 의미의 데이터를 하나의 표준 용어로 정리합니다.
## 진행 단계
1. **같은 의미의 표현 묶기** — 예: 지역·지사·사업소.
2. **표준 용어 사전 항목 작성** — 표준 용어명 / 영문명 / 정의 / 사용 예시 / 비고
3. **예시 답안과 비교**
- 정상 결과(예시): 지역·지사·사업소 → 공급지역(supply_region), 민원분류·문의유형 → 민원유형(complaint_type), 처리상태(processing_status), 열사용량(heat_usage), 설비명(facility_name), 설비코드(facility_code)
