## 이 실습으로 하는 것
2일차 실습을 위해 Python 3.13.14를 설치하고 버전을 확인합니다.
## 진행 단계
1. **다운로드** — Windows 사용자는 Python 3.13.14 Windows installer (64-bit), 맥 사용자는 .pkg 파일.
2. **설치** — "Add Python to PATH" 옵션을 반드시 체크. "install now" → next.
3. **버전 확인** — 윈도우 검색창에 cmd(또는 PowerShell), 맥/리눅스는 터미널에서 입력합니다.
```javascript
python --version
# 또는
python -V
```
## 막히는 지점
- 이미 설치되어 있는 분들도 버전을 3.13.14로 통일합니다.
