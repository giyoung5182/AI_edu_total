## 이 실습으로 하는 것
요소를 한 번에 다 넣지 않고 하나씩 더하며, 어떤 요소가 결과를 바꿨는지 관찰합니다. (교안에는 '향후 과제'로 표시)
## 진행 단계
1. **합격 기준 정하기** — 워크시트 P2-1에 합격 기준 3개를 관찰 가능한 문장으로 기록(합격 기준 4종 중 최소 2종).
2. **안내서 첨부** — ChatGPT 새 채팅에 03_상품요금규정_안내서.docx 첨부.
- 정상 결과: 입력창 위에 파일 이름 카드가 붙음
3. **v0 — 조건 없음**
- 입력할 내용:
```plain text
첨부한 안내서의 6장을 요약해줘.
```
1. **v1 — C(맥락)만 추가** — 읽는 사람과 용도를 추가해 처음부터 다시 작성.
2. **v2 — 내 합격 기준을 제약으로 추가** — 대괄호 자리를 P2-1의 내 기준으로 바꿔 입력.
3. **v3 — K 처리 규칙만 추가** — 근거 범위, 수치는 원문 그대로, \[확인 필요\] 유지, 마지막 줄 근거 표기.
4. **기록·판정** — P2-2 표에 달라진 점·충족 수·남은 문제를 기록하고, 먼저 적은 합격 기준으로 판정.
## 막히는 지점
- 파일 첨부 오류 / 6장을 놓치고 1장부터 요약 / 대괄호를 바꾸지 않고 전송 / 답이 중간에 끊김
- 표 구간 누락, \[확인 필요\] 문구가 단정 문장으로 바뀜, 부록 내용 혼입
