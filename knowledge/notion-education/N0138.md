### 같은 AI, 완전히 다른 결과
ChatGPT를 한 번쯤은 써보셨을 겁니다.
그런데 누군가는 "별로 쓸모없던데?" 하고, 누군가는 매일 의사결정 시간을 절반으로 줄이고 있습니다.
이 차이는 AI의 성능 문제가 아닙니다.
**"어떻게 지시했느냐"**의 차이입니다.

**참고: 생성형 AI가 답변하는 방식**
생성형 AI는 텍스트가 주어졌을 때, 뒤에 올 확률이 가장 높은 단어(토큰)를 예측하여 문장을 생성합니다. 이 원리 때문에 AI는 **사실을 알려주는 것이 아니라, "그럴듯한 답변"을 생성**합니다.
사실과 다른 내용을 자신 있게 만들어내는 현상을 **할루시네이션(Hallucination)**이라고 합니다.
→ AI의 결과물은 반드시 사람이 확인해야 합니다.

# 1️⃣ 최신 LLM 트렌드 : 2026년 AI는 이렇게 달라졌습니다
2024년 이전의 AI는 학습된 데이터만으로 답변했습니다.
2025\~2026년의 AI는 **실시간으로 웹을 검색하고, 문서를 읽고, 출처를 밝히며 답변**합니다.
이것을 **RAG(Retrieval-Augmented Generation, 검색 증강 생성)**이라고 합니다.

### 사례 1: 87페이지 기술 제안서 → 5분 핵심 파악
**상황:** 협력사에서 온 기술 제안서 87페이지. 내일 오전 회의인데, 아직 다 못 읽었습니다.
**AI 활용법:** PDF를 ChatGPT에 업로드한 뒤, 아래 구조화 프롬프트를 입력합니다.
```javascript
## 역할
너는 건설 프로젝트를 검토하는 리더의 전략 보좌관이야.

## 지시
첨부한 기술 제안서를 읽고 다음을 정리해줘:
1. 핵심 제안 내용 3줄 요약
2. 우리 측에서 확인해야 할 리스크 포인트
3. 경쟁사 대비 차별점
4. 7장의 공정 일정이 현실적인지 검토 (일반적인 건축 공사 기준)

## 출력양식
- 형식: 항목별 개조식, A4 1페이지 이내
```
**핵심 포인트:**
- 문서를 "읽는" 게 아니라 **"질문하는"** 것
- 관점을 지정하면 (리스크 / 비용 / 일정) 해당 시각으로 분석해줌
- 여러 문서를 비교 분석하는 것도 가능

### 사례 2: 분기별 공사 진행률 → 리더 보고용 시각화
**상황:** 분기별 공사 진행률 데이터가 엑셀에 있습니다. 리더 보고용으로 시각화해야 합니다.
**AI 활용법:** 엑셀/CSV 파일을 ChatGPT에 업로드한 뒤, 아래 구조화 프롬프트를 입력합니다.
```javascript
## 역할
너는 건설 데이터를 다루는 경영관리 분석 전문가야.

## 지시
첨부한 공사 진행률 데이터를 분석해줘:
1. 전체 현황 요약
2. 지연되고 있는 현장 TOP 5
3. 월별 추이를 막대 차트로 시각화 (지연 현장은 빨간색)
4. 데이터에서 주목할 만한 이상 신호

## 출력양식
- 형식: 요약 표 + 차트
- 톤: 리더 보고용 간결체
```
**핵심 포인트:**
- 엑셀 함수를 몰라도 데이터 분석 가능
- 차트를 직접 생성해줌 (다운로드 가능)
- "이 데이터에서 이상한 점 있어?" 같은 열린 질문도 가능

# 2️⃣ 기존 프롬프트 VS 최신 프롬프트 (맥락 중심 설계)

### 구조화 프롬프트의 3요소 — 역할·지시·출력양식
복잡한 기법이 아닙니다. 아래 세 가지만 챙긴 틀에 맞춰 쓰면 됩니다.
① **역할**(누구로서 답할지) → ② **지시**(무엇을 할지) → ③ **출력양식**(어떤 형태로).
```javascript
## 역할
너는 [직책/전문분야] 전문가야.
[추가 맥락: 경력, 소속, 상황 등]

## 지시
[구체적으로 해야 할 일을 설명]

## 출력양식
- 형식: [표/리스트/문단/개조식 등]
- 분량: [글자수/항목수/페이지수]
- 포함할 항목: [반드시 들어가야 할 내용]
- 톤: [공식적/간결한/설득력 있는 등]
```

# 4️⃣ \[실습\] 신규 사업 타당성 검토 프롬프트

아래 프롬프트를 **그대로 복사해 ChatGPT에 붙여넣으세요.** 직접 타이핑하실 필요 없습니다 — 복사·붙여넣기로 빠르게 따라오시면 됩니다.

```javascript
## 역할
너는 건설 사업개발 15년차 전략 컨설턴트야.
교육기관의 신사업 진출 타당성을 검토하는 보고서를 작성한다.

## 지시
교육기관이 "스마트 주거 서비스" 사업에 진출하려고 한다.
아래 관점에서 타당성 검토 보고서를 작성해줘:
1. 시장 규모 및 성장성 (국내 기준)
2. 주요 경쟁사 현황 (현대건설, 대우건설, 포스코이앤씨, DL이앤씨)
3. 교육기관의 강점과 약점
4. 주요 리스크 요인 3가지
5. 진출 시 예상 ROI 시나리오 (낙관/중립/비관)
6. 최종 권고 (Go/No-Go 및 근거)

## 출력양식
- 형식: 각 항목을 표로 정리한 뒤, 마지막에 1페이지 리더 요약
- 톤: 투자위원회 보고용 격식체
- 분량: 전체 3페이지 + 리더 요약 1페이지
```
