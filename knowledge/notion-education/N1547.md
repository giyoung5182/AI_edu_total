## Claude Code — 자연어로 개발을 지시하는 도구
[원본 이미지 제외]
Claude Code는 터미널에서 실행되는 AI 개발 도구입니다.<br>우리가 한국어로 요청하면, Claude Code가 코드를 작성합니다.<br>파일을 만들고, 수정하고, 프로그램을 실행하는 것까지 해냅니다.<br>우리는 코드를 직접 타이핑하지 않습니다.
실제로 주고받는 대화는 이런 모습입니다.

우리: 지금 폴더에 hello.txt 파일을 만들고 "안녕하세요"라고 적어 주세요.
Claude Code: hello.txt 파일을 생성하겠습니다.<br>\[Write 도구 사용 승인 요청: hello.txt\]
**우리: (y를 눌러 승인)**
Claude Code: hello.txt 파일을 만들었습니다.

**중간에 승인 요청이 등장합니다.**
<br>Claude Code는 파일 생성, 명령 실행 같은 작업 전에 우리에게 허락을 구합니다.<br>무엇을 하려는지 읽어 보고 승인하는 습관이 안전한 사용의 기본입니다.<br>내용을 모르는 채 무조건 승인하는 것은 피합니다.

### 프롬프트 캐싱 — 같은 내용을 두 번 보내면 두 번째는 싸다
**Claude Code는 대화할 때마다 지금까지의 대화 전체를 다시 읽습니다.**<br>대화가 길수록 읽는 양이 늘고, 비용과 시간이 함께 늘어납니다.
프롬프트 캐싱은 이미 읽은 앞부분을 저장해 두는 기능입니다. 저장된 부분은 다시 읽을 때 훨씬 싸고 빠르게 처리됩니다.
`/cost`를 실행하면 실제 숫자로 확인됩니다.
```plain text
Total cost:  $0.42
Usage:       8,100 tokens input (fresh):  ← 새로 읽은 양 (정가)
                     125,300 tokens cache read    ← 저장본을 다시 읽은 양 (저렴)
```
cache read 항목이 클수록 캐싱이 잘 활용되고 있다는 뜻입니다.<br>우리가 캐싱을 직접 조작할 일은 없습니다.<br>비용 화면에서 이 숫자의 의미를 읽을 수 있으면 충분합니다.

## 로컬 서버 — 내 컴퓨터가 요청을 받고 응답한다
[원본 이미지 제외]
**서버는 요청을 받아 응답을 돌려주는 프로그램입니다. <br>그 프로그램이 내 컴퓨터에서 실행되면 로컬 서버라고 부릅니다.**
브라우저 주소창의 `localhost:8000`은 내 컴퓨터의 8000번 창구라는 뜻입니다.<br>인터넷 어딘가가 아니라, 지금 이 노트북 안입니다.
요청과 응답은 이렇게 왕복합니다.
[원본 이미지 제외]
서버가 꺼지면 응답할 프로그램이 없어집니다.<br>브라우저를 새로고침해도 "연결할 수 없음"만 나타납니다.<br>서버가 살아 있어야 서비스가 삽니다.<br>이번 실습에서 서버를 직접 껐다 켜며 이 사실을 확인합니다.

## 두 개의 AI — 만드는 AI와 서비스 안의 AI
이번 세션에는 AI가 두 개 등장합니다.<br>둘의 역할이 다르다는 것이 이번 세션의 가장 중요한 구분입니다.
[원본 이미지 제외]
구분이 헷갈릴 때는 완성된 서비스에서 확인하면 됩니다.<br>챗봇에 "안녕"이라고 입력했을 때 답을 만드는 것은 Gemini입니다.
이때 Claude Code는 아무 일도 하지 않습니다.<br>Claude Code의 일은 그 챗봇 프로그램을 만드는 시점에 이미 끝났습니다.
서버 코드가 Gemini를 부르는 실제 요청은 이런 형태입니다.
```json
POST [개별 링크 제외]

{
  "contents": [
    { "parts": [ { "text": "지진이 나면 어떻게 해야 하나요?" } ] }
  ]
}
```
사용자가 챗봇에 입력한 문장이 `text` 자리에 들어갑니다.<br>Gemini가 돌려준 답변을 서버가 받아 브라우저에 전달합니다.<br>이 왕복이 챗봇 대화 한 번의 전부입니다.
---
### API 키 — 서비스 안의 AI를 부르는 열쇠
Gemini를 호출하려면 API 키가 필요합니다.<br>API 키는 "이 요청은 내 계정의 요청이다"를 증명하는 문자열입니다.<br>Google AI Studio에서 무료로 발급받으며, 신용카드는 필요 없습니다.<br>무료 사용량 안에서 이번 실습 전체를 진행할 수 있습니다.

API 키는 비밀번호와 같습니다. 다음 세 가지를 지킵니다.
- 키를 코드 파일 안에 직접 적지 않습니다.
- 키를 화면 공유, 채팅, 문서에 노출하지 않습니다.
- 이 자료의 모든 예시에는 실제 키 대신 `YOUR_API_KEY`라고만 적혀 있습니다.<br>이 자리에 각자 발급받은 키를 넣습니다.

### 실습 3. AI 챗봇 만들기
이제 터미널 A의 Claude Code에게 챗봇 제작을 지시합니다.<br>아래 프롬프트를 그대로 입력합니다.
**Claude Code 프롬프트**
```plain text

1. 브라우저에서 열리는 채팅 페이지를 만들어 주세요. 입력창에 질문을 쓰고 전송하면 대화 목록에 질문과 답변이 말풍선으로 쌓이는 단순한 화면이면 됩니다.

2. 답변은 Gemini API(모델: gemini-2.5-flash)가 생성합니다. API 키는 .env 파일의 GEMINI_API_KEY 값을 읽어 사용하고, 코드에 키를 직접 적지 마세요.

3. 서버 터미널에 로그가 자세히 출력되게 해 주세요. 질문을 받은 시각, Gemini 호출 시작, 응답 반환과 소요 시간이 각각 한 줄씩 보이면 좋겠습니다.

4. 필요한 패키지 설치 명령과 서버 실행 명령을 알려 주세요.

6. 코드를 완성한 뒤, 최소한 서버 기동과 메인 페이지(/) 요청이 에러 없이 200으로 응답하는지 실제로 실행해 검증하고, 검증 결과를 알려 주세요. (Gemini 호출은 키가 필요하므로, 키 없이도 페이지 렌더링 단계까지는 확인해 주세요.)
```

## **잘 안 될 때**
**Q. 페이지는 열리는데 답변이 안 옴**
- **원인**: API 키 미설정 또는 오타
- **해결**: `.env`의 키 값을 확인합니다. 앞뒤 공백, 따옴표가 없어야 합니다. 수정 후 서버를 껐다 다시 켭니다
**Q. 401 또는 403 에러 로그**
- **원인**: 키가 유효하지 않음
- **해결**: 실습 2로 돌아가 키를 다시 발급받아 교체합니다
**Q. 429 에러 로그**
- **원인**: 무료 사용량 한도 초과
- **해결**: 1\~2분 기다렸다가 다시 시도합니다. 반복되면 진행요원을 호출합니다
**Q. Address already in use**
- **원인**: 8000번 창구를 다른 프로그램이 사용 중
- **해결**: 창①에서 `Ctrl+C` 후 재실행합니다. 안 되면 Claude Code에 "8001 포트로 실행하는 명령을 알려 주세요"라고 요청합니다
**Q. 답변이 안 오고 멈춘 듯함**
- **원인**: 정상 범위의 지연
- **해결**: 첫 응답은 수 초 걸릴 수 있습니다. 창①에 "호출 시작" 로그가 있다면 기다립니다
**Q. 서버 실행 명령을 잊음**
- **해결**: 창②에 "서버 실행 명령을 다시 알려 주세요"라고 요청합니다
⚠️ 에러가 나면 창①의 로그부터 읽습니다. 로그에는 무엇이 실패했는지가 거의 항상 적혀 있습니다.<br>로그를 복사해 Claude Code에 붙여넣고 "이 에러를 해결해 주세요"라고 요청하는 것도 좋은 방법입니다.

## 실습 확장 (선택)
기본 실습을 마친 분은 아래를 자유롭게 시도합니다.<br>순서는 없으며, 하나만 해도 됩니다.

## 이번 실습 결과물
이번 세션을 마친 우리 손에는 다음이 있습니다.
- 브라우저에서 대화할 수 있는 AI 챗봇 웹 서비스
- 서버의 생사와 서비스의 생사가 같다는 것을 확인한 경험
- 요청 한 건이 로그 몇 줄로 나타나는지 아는 눈
- 발급받은 나만의 Gemini API 키 (.env 파일 안에만 존재)
지금 프로젝트 폴더의 구조입니다.
```plain text
~/disaster-bot/
├── CLAUDE.md          ← /init이 만든 프로젝트 안내 파일
├── .env               ← API 키 보관 (외부 공유 금지)
├── server.py          ← 로컬 서버 (요청 수신, Gemini 호출, 로그 출력)
├── static/
│   └── index.html     ← 채팅 화면
└── requirements.txt   ← 설치한 패키지 목록
```
파일 이름은 Claude Code의 작업에 따라 조금 다를 수 있습니다.<br>구조가 다르더라도 챗봇이 동작하면 문제없습니다.<br>정확한 구조가 궁금하면 Claude Code에 이렇게 요청합니다.<br>"지금 프로젝트의 파일 구조를 보여 주세요."
**지금 우리가 가진 부품**
```plain text
부품 A. AI와 대화하는 웹 챗봇 (로컬 서버 + Gemini 연결)
```
