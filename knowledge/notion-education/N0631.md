# (같이해보기) 업무 쪼개기 → 본인 업무 위임표 작성(P1-6)

정리일: 2026-10-08 · 교육 에셋 N0631

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
본인 업무 1건을 AI에게 맡길 수 있는 단위로 쪼개 단계별 위임표를 만듭니다. 같은 업무도 단계에 따라 등급이 갈립니다(교안 예시: 환불 안내).
## 진행 단계
1. **내 업무 1건 선택** — 앞 실습의 내 업무 13\~15번 중 등급이 애매했던 것. 먼저 예측: 사람 승인 단계가 몇 개 나올까?
2. **As-Is — 지금 하는 순서** — 동사로 4\~6단계 적기(`[무엇을] [어떻게 한다]`). 워크시트 P1-6 업무명 칸과 단계(As-Is) 열에 입력
- 단계 목록 초안이 필요하면 새 채팅에서(회사 실명·고객명·금액은 넣지 않음)
- 입력할 내용:
```plain text
나는 기업출장관리 회사의 [부서명] 담당자야.
[업무 이름]을 할 때 보통 거치는 단계를 동사 중심으로 4~6단계로 나눠줘.
각 단계에 필요한 입력 자료가 무엇인지도 한 줄씩 적어줘.
우리 회사 규정이나 수치는 모르니 추측해서 채우지 말고 "[확인 필요]"로 남겨줘.
```
1. **Pain — 막히는 곳** — 시간이 많이 들거나 실수가 나는 단계에 ★와 한 줄 이유
2. **To-Be — 위임 구분** — 단계마다 AI 초안 / 규칙·도구 처리 / 사람 승인 중 하나 + 등급(A·B·C) + 이유(근거·검증·책임) + 사람이 확인할 것. 한 단계에 두 구분이 필요하면 두 행으로 나눔
3. **핵심 변화 1줄** — `가장 먼저 바꿀 단계는 [번호]단계([단계 이름]), 이유는 [★ 이유 + 위임 구분]`을 P1-6 하단 칸에 기록
4. **판정** — 각 단계가 동사로 적혀 있고, 모든 단계에 위임 구분과 이유가 있으며, 사람 승인 단계에 승인자가 적혀 있으면 합격. 판별 질문: "이 단계를 신입에게 설명서로 만들어 줄 수 있는가?"
## 막히는 지점
- 7단계 이상 또는 한 단계에 동사 2개 → "단계를 6개 이하로 줄여줘. 한 단계에는 동사를 하나만 쓰고…"
- 규정·기한·금액이 \[확인 필요\] 없이 적히면 워크시트에 옮기지 않음
- 사람 승인 행에 승인자가 없으면 직책(예: 팀장) 추가
- 모든 행이 AI 초안이면 대외 발송·금액 확정·예외 결정 단계가 빠졌는지 확인
