## 이 실습에서 무엇을 하는가
1권에서 GAS가 무엇인지 개념을 배웠습니다. 이제 실제로 설치하고 버튼이 작동하는 것을 직접 확인합니다.
오늘 실습의 핵심 과제는 **프로님이 막혔던 3가지 문제를 해결**하는 것입니다.
```plain text
프로님이 미리 시도하신 것:
  엑셀 v23 완성 (지출결의서 폼)
  드롭다운 설정 (매장·거래처)
  GAS 코드 작성

막혔던 지점:
  문제 1. .xlsx 파일에서 Apps Script 실행 안 됨
  문제 2. 크롬 팝업 차단으로 편집창이 안 열림
  문제 3. 코드를 엉뚱한 파일(빈 시트)에 저장

오늘 해결 순서:
  STEP A → 문제 1 해결: 구글 시트 새로 만들기
  STEP B → 기존 v23 데이터 가져오기
  STEP C → 문제 2·3 해결: 올바른 파일에서 Apps Script 열고 코드 설치
  STEP D → 권한 허용 + 메뉴 확인
  STEP E → 테스트
```

## 시작 전 핵심 개념 — 왜 .xlsx로 하면 안 되는가
이 개념은 GAS를 처음 쓰는 사람이 가장 많이 막히는 지점입니다. 한 번만 제대로 이해하면 다시는 안 막힙니다.
---
### 파일 형식이란 무엇인가
컴퓨터 파일에는 형식(포맷)이 있습니다. 문서를 어떤 방식으로 저장하느냐의 차이입니다.
```plain text
.xlsx = 마이크로소프트 엑셀 형식
  마이크로소프트가 만든 규격
  엑셀 프로그램에 최적화
  구글에서도 열 수 있지만 "번역해서" 보여주는 것

.gsheet = 구글 스프레드시트 형식
  구글이 만든 규격
  Google Apps Script를 완전히 지원
  구글 드라이브에서 새로 만들면 이 형식
```
---
### 구글에서 엑셀 파일을 열면 무슨 일이 생기는가
```plain text
상황: 엑셀 파일을 구글 드라이브에 올리고 더블클릭해서 열기

눈에 보이는 것:
  구글 시트처럼 보임
  수식도 되고, 셀 편집도 됨
  "이게 구글 시트 아닌가?" 싶음

실제로 일어나는 일:
  내부는 .xlsx 형식 그대로 유지
  구글이 임시로 번역해서 보여주는 것
  Apps Script 메뉴 자체가 없거나, 있어도 실행 안 됨

결론:
  Apps Script를 쓰려면 반드시 .gsheet 형식이어야 함
  → 구글 드라이브에서 처음부터 새로 만들어야 함
```
---
### 올바른 방법과 잘못된 방법
```plain text
잘못된 방법 (프로님이 겪은 상황):
  엑셀 v23 파일을 구글 드라이브에 올림
  → 더블클릭해서 열고
  → 거기서 Apps Script를 열려고 했음
  → 실행 안 됨 또는 편집창이 안 열림

올바른 방법:
  구글 드라이브에서 [+ 새로 만들기] → [Google 스프레드시트]
  → 빈 구글 시트가 생성됨 (.gsheet 형식)
  → 여기에 기존 데이터를 복사해 넣음
  → Apps Script 정상 작동
```

## STEP A. 구글 시트 새로 만들기 (10분)
---
### A-1. 구글 드라이브 접속
브라우저(크롬 권장)에서 주소창에 입력:
```plain text
drive.google.com
```
구글 계정으로 로그인되어 있지 않다면 로그인합니다.
> **꿀팁:** 구글에 로그인된 상태에서 주소창에 `sheets.new`를 입력하면 새 구글 시트가 바로 열립니다. 가장 빠른 방법입니다.
---
### A-2. 새 구글 시트 만들기
**방법 1 (드라이브에서):**
```plain text
왼쪽 상단 [+ 새로 만들기] 버튼 클릭
→ [Google 스프레드시트] 클릭
→ 빈 스프레드시트 생성됨
```
**방법 2 (주소창에서):**
```plain text
주소창에 sheets.new 입력 후 Enter
→ 새 구글 시트 바로 생성
```
---
### A-3. 파일 이름 변경
파일이 열리면 상단에 "제목 없는 스프레드시트"라고 쓰여 있습니다.<br>이 이름을 클릭해서 변경합니다.
```plain text
"제목 없는 스프레드시트" 클릭
→ 전체 선택 후 삭제
→ "교육기관_지출결의서_자동화" 입력
→ Enter 또는 다른 곳 클릭
```
**확인 방법:**
- 브라우저 탭 제목이 "교육기관_지출결의서_자동화"로 바뀌어 있으면 성공
- 구글 드라이브에서도 이 이름으로 파일이 보임

## STEP B. 기존 v23 시트 데이터 가져오기 (15분)
---
### 왜 복사-붙여넣기가 아닌 시트 탭 복사 방식을 쓰는가
두 방법의 차이:
```plain text
복사-붙여넣기:
  셀 내용은 옮겨짐
  BUT 수식이 깨질 수 있음
      드롭다운(유효성 검사)이 사라질 수 있음
      서식(셀 크기, 색상, 테두리)이 달라질 수 있음

시트 탭 복사:
  수식·드롭다운·서식 모두 그대로 이동
  프로님이 v23에서 설정한 드롭다운도 그대로 살아남
  훨씬 안정적
```
---
### B-1. 파일을 구글 시트로 열기
```plain text
구글 드라이브에서 파일 찾기
→ 파일 위에서 마우스 우클릭
→ [연결 앱] 클릭
→ [Google Sheets] 클릭
→ 새 탭에서 v23 파일이 구글 시트로 열림
```
> **주의:** 이 상태의 v23은 여전히 .xlsx 형식입니다. 데이터를 "보기 위해서" 여는 것이지, 여기서 GAS를 실행하려는 게 아닙니다.
---
### B-2. 시트 탭 하나씩 복사하기
v23에서 시트 4개를 새로 만든 "교육기관_지출결의서_자동화" 파일로 복사합니다.
**복사할 시트 목록:**
1. 지출결의서
2. 매장정보
3. 거래처목록
4. 월별지출집계
**각 시트 복사 방법:**
```plain text
① 하단 시트 탭에서 [지출결의서] 탭 위에 마우스 우클릭
② [다른 스프레드시트로 복사] 클릭
③ 파일 선택 창이 열림
④ "교육기관_지출결의서_자동화" 검색 또는 찾아서 선택
⑤ [선택] 버튼 클릭
⑥ "시트가 복사되었습니다" 메시지 확인
```
위 과정을 4개 시트 모두에 반복합니다.
> **트러블슈팅:** "다른 스프레드시트로 복사" 메뉴가 없다면, v23 파일이 아직 .xlsx 형식입니다. v23 파일에서 \[파일\] → \[Google Sheets로 저장\]을 먼저 실행한 후 다시 시도하세요.
---
### B-3. 복사 확인
"교육기관_지출결의서_자동화" 파일로 전환합니다.<br>브라우저 탭에서 이 파일을 클릭하거나, 구글 드라이브에서 다시 열면 됩니다.
하단 시트 탭에 아래 4개가 있는지 확인:
```plain text
✅ 지출결의서
✅ 매장정보
✅ 거래처목록
✅ 월별지출집계
```
---
### B-4. 제출이력 시트 새로 만들기
v23에는 없는 시트를 직접 만듭니다.<br>이 시트가 GAS가 데이터를 쌓아나가는 "저장소" 역할을 합니다.
```plain text
① 하단 [+] 아이콘 클릭
② 새 시트가 생성됨 ("시트1" 또는 "Sheet1")
③ 새 시트 탭 위에 더블클릭
④ "제출이력" 입력 → Enter
```
---
### B-5. 제출이력 헤더 입력
제출이력 시트의 1행에 열 이름(헤더)을 입력합니다.<br>이 순서가 GAS 코드의 저장 순서와 **반드시 일치**해야 합니다.
```plain text
A1: 제출일시
B1: 매장명
C1: 명의구분
D1: 법인명
E1: 사업자번호
F1: 대표자명
G1: 본부장
H1: 결의일
I1: 결의인
J1: 내용
K1: 거래처
L1: 공급가
M1: 부가세
N1: 총액
```
**입력 방법:**
```plain text
A1 셀 클릭 → "제출일시" 입력 → Tab 키 (옆 셀로 이동)
→ "매장명" 입력 → Tab → 계속...
→ N1까지 입력
```
**헤더 서식 설정 (선택사항):**
```plain text
1행 전체 선택 (행 번호 "1" 클릭)
→ Ctrl+B (굵게)
→ 배경색 아이콘 클릭 → 연회색 선택
```
> **왜 헤더 순서가 중요한가:** GAS 코드에서 데이터를 저장할 때 A열부터 순서대로 넣습니다. 헤더 순서가 코드와 다르면 "매장명" 자리에 "법인명"이 들어가는 오류가 생깁니다. 반드시 위 순서를 지켜주세요.

## STEP C. Apps Script 코드 설치 (20분)
---
### C-1. Apps Script 편집창 열기
"교육기관_지출결의서_자동화" 파일에서:
```plain text
상단 메뉴바에서 [확장 프로그램] 클릭
→ [Apps Script] 클릭
```
**팝업이 열리지 않는 경우 (프로님이 겪은 문제):**
크롬이 팝업을 차단하면 Apps Script 편집창이 새 탭으로 열리지 않습니다.<br>주소창 오른쪽 끝을 확인합니다.
```plain text
주소창 오른쪽 끝 팝업 차단 아이콘 확인 (🚫 또는 □ 모양)
→ 아이콘 클릭
→ "항상 허용" 또는 "이 사이트의 팝업 허용" 선택
→ 다시 [확장 프로그램] → [Apps Script] 클릭
```
아이콘이 안 보이면:
```plain text
크롬 주소창에 chrome://settings/content/popups 입력 → Enter
→ "허용" 섹션에서 [추가] 클릭
→ docs.google.com 입력 → [추가]
→ 다시 시도
```
> **이것이 프로님이 막혔던 두 번째 지점입니다.** Apps Script는 항상 새 탭으로 열립니다. 팝업 차단을 해제해야 열립니다.
---
### C-2. 올바른 파일에서 열었는지 확인
Apps Script 편집창이 열리면 상단에 파일 이름이 보입니다.
```plain text
확인: 편집창 상단 제목이 "교육기관_지출결의서_자동화" 인지 확인

만약 다른 이름이 보인다면:
→ 지금 열려 있는 편집창을 닫기
→ "교육기관_지출결의서_자동화" 파일로 돌아가기
→ 거기서 다시 [확장 프로그램] → [Apps Script] 클릭
```
> **이것이 프로님이 막혔던 세 번째 지점입니다.** Apps Script는 "지금 열려 있는 파일"에 연결됩니다. 다른 파일을 보다가 Apps Script를 열면 다른 파일에 코드가 들어갑니다.
---
### C-3. 코드 요청 + 기존 코드 삭제
#### 프로님 — GAS 코드 요청 프롬프트 예시
<br>수강생들이 본인 파일에 맞게 수정할 때 이 형식을 참고합니다.
---
```plain text
Google Apps Script 코드를 만들어줘.

[내 업무 상황]
나는 교육기관 디자인팀에서 지출결의서를 담당하고 있어.
지출결의서 폼을 작성하고 나면 매번 집계 파일을 따로 열어서
해당 매장 탭을 찾고, 해당 월 열을 찾고, 금액을 수동으로 입력해야 해.
이 과정이 건당 15분씩 걸리고 실수도 가끔 생겨서 자동화하고 싶어.

[파일 구조]
구글 스프레드시트에 아래 시트들이 있어:
- '지출결의서' 시트: 내역을 입력하는 폼
- '제출이력' 시트: 제출된 내역이 한 줄씩 쌓이는 DB
- '월별지출집계' 시트: 매장별 월간 집계 보고서

[셀 구조]
- B3셀: 매장명 (드롭다운)
- E3셀: 명의구분
- B4셀: 법인명
- D4셀: 사업자번호
- B5셀: 대표자명
- D5셀: 본부장
- B8셀: 결의일
- F8셀: 결의인
- 내역 입력 범위: A11~A19=내용, B11~B19=거래처, I11~I19=공급가, K11~K19=총액

[제출이력 시트 헤더 순서 (A~N열)]
A=제출일시, B=매장명, C=명의구분, D=법인명, E=사업자번호,
F=대표자명, G=본부장, H=결의일, I=결의인,
J=내용, K=거래처, L=공급가, M=부가세, N=총액

[동작 순서]

[제출] 버튼 클릭 시:
1. B3셀(매장명) 확인 → 비어있으면 "매장명을 선택해주세요" 알림 후 중단
2. 내역(A열) 입력된 건수와 총액(K열) 합계 계산
3. 내역이 0건이면 "내역을 입력해주세요" 알림 후 중단
4. "매장명: OO / 내역 N건 / 총액 OOO원 / 제출하시겠습니까?" 확인 팝업
5. [예] 클릭 시에만 진행, [아니오]이면 취소
6. A열에 내용이 있는 행만 제출이력 시트에 appendRow
   (저장 순서는 헤더 A~N 순서와 정확히 일치)
7. "N건 저장 완료! 폼 내역을 초기화할까요?" 완료 팝업
8. [예] 클릭 시 내역 입력 셀(A·B·I열 11~19행) clearContent

[월별집계 갱신 버튼]
별도 함수로:
제출이력 시트 전체 읽기 → 매장별·월별 합산 → 월별지출집계 시트에 자동 입력
(매장명 | 1월~12월 | 연합계 형식)

[트리거]
파일 열릴 때 onOpen() 함수로 메뉴 자동 생성

[메뉴]
'📋 지출결의서' 메뉴:
- '☑ 제출 (이력에 저장)' → 지출결의서제출
- '🗑 폼 초기화' → 폼초기화
- (구분선)
- '📊 월별집계 갱신' → 월별집계갱신

[주의사항]
- 부가세는 K열에 없으면 공급가 × 10%로 자동 계산
- 총액은 K열에 없으면 공급가 + 부가세로 자동 계산
- 코드 상단에 시트명과 셀 주소를 상수(const)로 분리해줘
  → 나중에 파일 구조가 바뀌면 상수 부분만 수정할 수 있게
```

### 이 프롬프트의 핵심 포인트
**1. 헤더 순서를 명시했다**
```plain text
A=제출일시, B=매장명 ... N=총액
```
이것이 없으면 Claude가 임의 순서로 appendRow를 작성합니다.<br>→ 데이터가 엉뚱한 열에 들어가는 오류 발생
**2. 확인 팝업을 요청했다**
```plain text
"매장명: OO / 내역 N건 / 총액 OOO원 / 제출하시겠습니까?"
```
바로 저장하면 실수로 클릭했을 때 복구가 어렵습니다.<br>확인 팝업이 있으면 한 번 더 검토할 수 있습니다.
**3. 상수 분리를 요청했다**
```plain text
코드 상단에 시트명·셀 주소를 const로 분리해줘
```
이렇게 하면 파일 구조가 바뀔 때 상단 const만 수정하면 됩니다.<br>코드 전체를 뒤질 필요가 없습니다.
**4. 예외 처리 두 가지를 명시했다**
```plain text
① 매장명 비어있음 → 중단
② 내역 0건 → 중단
```
이것이 없으면 빈 폼을 제출해도 빈 행이 저장됩니다.
**5. 월별집계를 별도 함수로 요청했다**
```plain text
제출할 때마다 자동 갱신 X
→ 별도 버튼으로 필요할 때만 실행
```
제출할 때마다 전체 집계를 갱신하면 데이터가 쌓일수록 느려집니다.<br>필요할 때만 버튼으로 실행하는 것이 효율적입니다.

### C-4. 새 코드 붙여넣기
아래 코드 전체를 복사(Ctrl+A → Ctrl+C)한 후 편집창에 붙여넣기(Ctrl+V)합니다.
```javascript
// ════════════════════════════════════════════════
// 교육기관 지출결의서 자동화 GAS 코드
// 작성: Claude (심지 AI 실무 교육 4회차)
// 수정 시 반드시 시트명·셀 주소 확인
// ════════════════════════════════════════════════

// ── 1. 시트명 설정 ───────────────────────────────
// 실제 탭 이름과 한 글자라도 다르면 오류 발생
const SHEET_FORM = '지출결의서';   // 입력 폼 시트
const SHEET_DB   = '제출이력';     // 데이터 저장 시트

// ── 2. 지출결의서 셀 위치 ────────────────────────
// v23 파일의 실제 셀 주소와 일치해야 함
const FORM = {
  매장명:     'B3',   // 매장명 드롭다운 셀
  명의구분:   'D3',
  법인명:     'B4',
  사업자번호: 'D4',
  대표자명:   'B5',
  본부장:     'D5',
  결의일:     'A8',
  결의인:     'F8',
  내역시작행: 11,     // 내역 입력 시작 행
  내역끝행:   19,     // 내역 입력 끝 행
  내용열:     'A',    // 항목(내용) 열
  거래처열:   'C',    // 거래처 열
  공급가열:   'I',    // 공급가 열
  부가세열:   'K',    // 부가세 열
  총액열:     'L',    // 총액 열
};

// ════════════════════════════════════════════════
// 함수 1: 제출 버튼을 누르면 실행
// ════════════════════════════════════════════════
function 지출결의서제출() {
  const ss        = SpreadsheetApp.getActiveSpreadsheet();
  const formSheet = ss.getSheetByName(SHEET_FORM);
  const dbSheet   = ss.getSheetByName(SHEET_DB);

  // ── 매장명 확인 ──────────────────────────────
  const 매장명 = formSheet.getRange(FORM.매장명).getValue();
  if (!매장명) {
    SpreadsheetApp.getUi().alert('⚠️ 매장명을 선택해 주세요.');
    return; // 매장명 없으면 여기서 멈춤
  }

  // ── 내역 건수·총액 미리 계산 (확인 팝업용) ─────
  const ui = SpreadsheetApp.getUi();
  let 총액합계 = 0;
  let 내역수   = 0;
  for (let r = FORM.내역시작행; r <= FORM.내역끝행; r++) {
    const 내용 = formSheet.getRange(FORM.내용열 + r).getValue();
    if (!내용) continue;
    const 총액 = formSheet.getRange(FORM.총액열 + r).getValue() || 0;
    총액합계 += 총액;
    내역수++;
  }

  // ── 내역이 없으면 중단 ───────────────────────
  if (내역수 === 0) {
    ui.alert('⚠️ 내역(A열)을 1건 이상 입력해 주세요.');
    return;
  }

  // ── 제출 전 확인 팝업 ───────────────────────
  // 실수 방지: 내용 확인 후 [예]를 눌러야 저장됨
  const 확인 = ui.alert(
    '제출 확인',
    `매장명: ${매장명}\n내역: ${내역수}건\n총액 합계: ${총액합계.toLocaleString()}원\n\n제출하시겠습니까?`,
    ui.ButtonSet.YES_NO
  );
  if (확인 !== ui.Button.YES) return; // [아니오] 클릭 시 취소

  // ── 공통 정보 읽기 ──────────────────────────
  const 제출일시   = new Date();
  const 명의구분   = formSheet.getRange(FORM.명의구분).getDisplayValue();
  const 법인명     = formSheet.getRange(FORM.법인명).getDisplayValue();
  const 사업자번호 = formSheet.getRange(FORM.사업자번호).getDisplayValue();
  const 대표자명   = formSheet.getRange(FORM.대표자명).getDisplayValue();
  const 본부장     = formSheet.getRange(FORM.본부장).getDisplayValue();
  const 결의일     = formSheet.getRange(FORM.결의일).getDisplayValue();
  const 결의인     = formSheet.getRange(FORM.결의인).getDisplayValue();

  // ── 내역 행별로 제출이력에 저장 ─────────────
  // 중요: appendRow의 순서 = 제출이력 헤더 A~N 순서와 일치
  let 저장수 = 0;
  for (let r = FORM.내역시작행; r <= FORM.내역끝행; r++) {
    const 내용 = formSheet.getRange(FORM.내용열 + r).getValue();
    if (!내용) continue; // 내용 없는 행 건너뜀

    const 거래처 = formSheet.getRange(FORM.거래처열 + r).getValue();
    const 공급가 = formSheet.getRange(FORM.공급가열 + r).getValue() || 0;
    const 부가세 = formSheet.getRange(FORM.부가세열 + r).getValue()
                  || Math.round(공급가 * 0.1); // 부가세 없으면 공급가의 10%
    const 총액   = formSheet.getRange(FORM.총액열 + r).getValue()
                  || 공급가 + 부가세;

    // A~N 헤더 순서대로 저장
    dbSheet.appendRow([
      제출일시,   // A: 제출일시
      매장명,     // B: 매장명
      명의구분,   // C: 명의구분
      법인명,     // D: 법인명
      사업자번호, // E: 사업자번호
      대표자명,   // F: 대표자명
      본부장,     // G: 본부장
      결의일,     // H: 결의일
      결의인,     // I: 결의인
      내용,       // J: 내용
      거래처,     // K: 거래처
      공급가,     // L: 공급가
      부가세,     // M: 부가세
      총액        // N: 총액
    ]);
    저장수++;
  }

  // ── 완료 팝업 + 폼 초기화 여부 확인 ─────────
  const 결과 = ui.alert(
    '☑ 제출 완료',
    `[${매장명}] ${저장수}건 저장 완료!\n\n폼 내역을 초기화할까요?`,
    ui.ButtonSet.YES_NO
  );
  if (결과 === ui.Button.YES) 폼초기화();
}

// ════════════════════════════════════════════════
// 함수 2: 폼 내역 초기화
// ════════════════════════════════════════════════
function 폼초기화() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
                              .getSheetByName(SHEET_FORM);
  // 내역 입력 셀만 지움 (매장명·결의일 등 공통 정보는 유지)
  for (let r = FORM.내역시작행; r <= FORM.내역끝행; r++) {
    sheet.getRange(FORM.내용열   + r).clearContent();
    sheet.getRange(FORM.거래처열 + r).clearContent();
    sheet.getRange(FORM.공급가열 + r).clearContent();
  }
  SpreadsheetApp.getActiveSpreadsheet()
                .toast('내역 초기화 완료. 다음 지출결의서를 입력하세요.', '☑', 4);
}

// ════════════════════════════════════════════════
// 함수 3: 월별 집계 갱신
// ════════════════════════════════════════════════
function 월별집계갱신() {
  const ss      = SpreadsheetApp.getActiveSpreadsheet();
  const db      = ss.getSheetByName(SHEET_DB);
  const summary = ss.getSheetByName('월별지출집계');

  // 데이터 없으면 안내
  if (db.getLastRow() <= 1) {
    SpreadsheetApp.getUi().alert('제출이력에 데이터가 없습니다.\n먼저 지출결의서를 제출해 주세요.');
    return;
  }

  // 제출이력 전체 읽기 (2행부터: 1행은 헤더)
  const data = db.getRange(2, 1, db.getLastRow()-1, 14).getValues();
  const 집계 = {};

  data.forEach(row => {
    const 제출일시 = row[0];  // A열: 제출일시
    const 매장명   = row[1];  // B열: 매장명
    const 총액     = row[13]; // N열: 총액
    if (!매장명) return;

    const 월 = new Date(제출일시).getMonth() + 1; // 1~12
    if (!집계[매장명]) 집계[매장명] = {};
    집계[매장명][월] = (집계[매장명][월] || 0) + (총액 || 0);
  });

  // 월별지출집계 시트 새로 작성
  summary.clearContents();
  const 헤더 = ['매장명','1월','2월','3월','4월','5월','6월',
                '7월','8월','9월','10월','11월','12월','연합계'];
  summary.appendRow(헤더);
  summary.getRange(1,1,1,14).setFontWeight('bold').setBackground('#E8F0FE');

  // 매장별 데이터 입력
  Object.keys(집계).sort().forEach(매장명 => {
    const row = [매장명];
    let 연합계 = 0;
    for (let m = 1; m <= 12; m++) {
      const 금액 = 집계[매장명][m] || 0;
      row.push(금액);
      연합계 += 금액;
    }
    row.push(연합계);
    summary.appendRow(row);
  });

  // 1행 고정 (스크롤해도 헤더 보임)
  summary.setFrozenRows(1);
  ss.toast(`월별집계 갱신 완료! (${Object.keys(집계).length}개 매장)`, '☑', 4);
}

// ════════════════════════════════════════════════
// 함수 4: 파일 열릴 때 자동으로 메뉴 생성
// 이 함수는 직접 실행하지 않아도 됨
// 파일을 열 때마다 자동으로 실행됨
// ════════════════════════════════════════════════
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📋 지출결의서')
    .addItem('☑ 제출 (이력에 저장)', '지출결의서제출')
    .addItem('🗑 폼 초기화',          '폼초기화')
    .addSeparator()
    .addItem('📊 월별집계 갱신',      '월별집계갱신')
    .addToUi();
}

M2: 33000 (자동 계산된 부가세: 330000 × 10%)
N2: 363000 (자동 계산된 총액: 330000 + 33000)
```
이 데이터가 올바르게 들어가 있으면 **프로님 작업 완성**입니다.

## 오류 대처 — 문제가 생겼을 때

### 오류 유형과 해결 방법
**오류 1: 메뉴 \[📋 지출결의서\]가 안 보임**
```plain text
원인: onOpen 함수가 아직 실행되지 않음
해결:
  방법 A: F5로 새로고침
  방법 B: Apps Script 편집창 열기
          → 상단 함수 선택 드롭다운에서 "onOpen" 선택
          → ▶ 실행 버튼 클릭
          → 구글 시트로 돌아와서 확인
```
**오류 2: "매장명을 선택해 주세요" 알림이 계속 나옴**
```plain text
원인: 코드의 FORM.매장명 = 'B3' 인데 실제 드롭다운이 다른 셀에 있음
해결:
  지출결의서 시트에서 매장명 드롭다운이 어느 셀인지 확인
  Apps Script 편집창에서 매장명: 'B3' 부분을 실제 셀로 수정
  예) 드롭다운이 C5에 있으면 → 매장명: 'C5'
```
**오류 3: 데이터가 제출이력의 엉뚱한 열에 들어감**
```plain text
원인: 제출이력 헤더 A~N 순서와 코드의 appendRow 순서 불일치
해결:
  제출이력 시트의 1행 헤더 순서 재확인
  A: 제출일시 / B: 매장명 / ... / N: 총액
  헤더가 다른 순서로 되어 있으면 헤더를 코드 순서에 맞게 수정
```
**오류 4: ****`Cannot read properties of null (reading 'getRange')`**
```plain text
원인: 시트명이 코드와 다름
      코드: const SHEET_FORM = '지출결의서'
      실제: '지출결의서 ' (공백이 뒤에 붙어있거나 이름이 다름)
해결:
  지출결의서 탭 이름 정확히 확인 (공백 포함 여부 포함)
  Apps Script에서 SHEET_FORM 또는 SHEET_DB 값을 실제 탭 이름으로 수정
```
**오류 5: ****`ReferenceError: FORM is not defined`**
```plain text
원인: 코드를 일부만 복사해서 FORM 상수가 없음
해결: 코드 전체를 다시 선택해서 복사 후 붙여넣기
```

# 코드 구조 설명 — 작동 원리 이해하기
> **방금 버튼 하나로 데이터가 저장됐습니다. 어떻게 된 걸까요?**<br>코드를 외울 필요 없습니다. 구조만 이해하면 나중에 Claude에게 수정을 요청할 수 있습니다.
---
## 전체 구조 한눈에 보기
방금 설치한 코드는 함수 4개로 이루어져 있습니다.
```plain text
onOpen()          → 파일 열릴 때 자동 실행: 상단 메뉴 [📋 지출결의서] 생성
지출결의서제출()   → [제출] 버튼 클릭 시 실행: 데이터 읽고 저장
폼초기화()        → [초기화] 버튼 클릭 시 실행: 입력 내용 지우기
월별집계갱신()    → [월별집계 갱신] 버튼 클릭 시 실행: 매장별 월간 집계
```
이 중 핵심은 `지출결의서제출()` 함수입니다. 나머지는 보조 역할입니다.
---
## 코드를 읽는 법 — 딱 두 가지만
코드 전체를 이해할 필요는 없습니다. 수정이 필요한 부분은 딱 두 곳입니다.
### 수정 포인트 1: 시트 이름
```javascript
const SHEET_FORM = '지출결의서';   // ← 이 이름이 실제 탭 이름과 달라지면 오류
const SHEET_DB   = '제출이력';     // ← 이 이름이 실제 탭 이름과 달라지면 오류
```
탭 이름을 바꿨다면 여기도 똑같이 바꿔야 합니다. 공백 하나, 대소문자 하나라도 다르면 오류가 납니다.
### 수정 포인트 2: 셀 주소
```javascript
const FORM = {
  매장명:     'B3',   // ← 지출결의서 시트에서 매장명 드롭다운이 있는 셀
  결의일:     'B8',   // ← 결의일 입력 셀
  내역시작행: 11,     // ← 내역 첫 번째 행 번호
  내역끝행:   19,     // ← 내역 마지막 행 번호
  내용열:     'A',    // ← 내용(품목명) 열
  공급가열:   'I',    // ← 공급가 열
  ...
};
```
파일 구조가 달라지면 여기 셀 주소만 바꾸면 됩니다. Claude에게 "내 파일에서 매장명이 C5에 있어, 수정해줘"라고 하면 됩니다.

## 버튼 클릭 시 내부에서 일어나는 일
\[제출\] 버튼을 클릭했을 때 코드가 어떤 순서로 실행됐는지입니다.
```plain text
1단계: 매장명 확인
   B3셀을 읽음 → "부화점"
   비어있으면 "매장명을 선택해주세요" 알림 후 중단

2단계: 내역 건수·총액 계산
   A11~A19셀을 읽으며 내용이 있는 행 카운트
   K열(총액)을 합산
   → "1건 / 33,000원"

3단계: 확인 팝업 표시
   "매장명: 부화점 / 내역: 1건 / 총액: 33,000원 / 제출하시겠습니까?"
   [예] 클릭 시 4단계로 / [아니오] 클릭 시 중단

4단계: 나머지 정보 읽기
   명의구분(E3), 법인명(B4), 결의일(B8) 등 읽기

5단계: 제출이력 시트에 저장
   내용이 있는 행(A열)만 골라서
   A~N열 헤더 순서대로 한 줄씩 appendRow()

6단계: 완료 팝업
   "1건 저장 완료! 초기화할까요?"
   [예] → 폼초기화() 실행
```

# 자동화 원리 — 무엇을 어떻게 자동화한 것인가
> 코드를 이해하는 것보다 중요한 것이 있습니다.<br>**"어떤 문제를 해결하기 위해 이렇게 설계했는가"** 를 이해하는 것입니다.
---
## 자동화 전 — 무엇이 문제였는가
지출결의서 업무의 원래 흐름입니다.
```plain text
① 지출결의서 폼 작성 (10분)
        ↓
② 집계 파일 열기
        ↓
③ 해당 매장 행 찾기
        ↓
④ 해당 월 열 찾기
        ↓
⑤ 금액 직접 입력
        ↓
⑥ 파일 저장
```
이 흐름에서 비효율적인 부분은 **②\~⑥** 입니다.
```plain text
문제 1: 단순 반복
   매번 같은 순서로 같은 일을 함
   실수 가능성 있음 (엉뚱한 셀에 입력)

문제 2: 두 파일 사이 수동 연결
   지출결의서(입력) → 집계 파일(저장)을
   사람이 매번 직접 연결

문제 3: 집계가 자동으로 안 됨
   매장별 월간 합계를 볼 때마다 수동 계산 필요
```
---
## 자동화의 핵심 아이디어
자동화를 설계할 때 핵심 질문은 하나입니다.
> **"사람이 반복하는 판단 없는 동작이 무엇인가?"**
판단이 필요한 것 → 사람이 해야 함<br>판단 없이 규칙대로 하는 것 → 자동화 가능
지출결의서 업무로 적용하면:





동작

판단 필요?

자동화 가능?




내역 내용 입력

✅ 사람이 판단

❌ 자동화 불가




매장명 선택

✅ 사람이 판단

❌ 자동화 불가




제출이력에 저장

❌ 규칙대로

✅ 자동화 가능




해당 매장·월에 집계

❌ 규칙대로

✅ 자동화 가능




폼 초기화

❌ 규칙대로

✅ 자동화 가능


사람이 해야 할 것과 GAS가 할 것을 이렇게 나눴습니다.
```plain text
사람:  내역 입력 + 버튼 클릭
GAS:   저장 + 집계 + 초기화
```
---
## 자동화 설계 — 세 가지 연결
이 자동화는 세 개의 시트를 연결하는 구조입니다.
```plain text
[지출결의서 시트]          [제출이력 시트]        [월별지출집계 시트]
  입력 폼                   데이터베이스              보고서
  사람이 작성       →        GAS가 저장      →       GAS가 집계
  (매번 초기화)             (누적 쌓임)             (버튼 클릭 시 갱신)
```
이 구조를 만들 때 핵심 결정이 두 가지였습니다.
**결정 1: 내역을 행 단위로 저장한다**
지출결의서 한 장에 내역이 여러 건 있을 수 있습니다. 이것을 한 장 = 한 행으로 저장하면 나중에 품목별 분석이 어렵습니다. 그래서 내역 한 건 = 한 행으로 저장했습니다.
```plain text
지출결의서 1장 (부화점, 3개 내역)
→ 제출이력에 3행으로 저장
  행1: 부화점 / 숙소임대료 / 330,000원
  행2: 부화점 / 전기료 / 85,000원
  행3: 부화점 / 관리비 / 120,000원
```
**결정 2: 집계는 별도 버튼으로 분리한다**
제출할 때마다 집계를 자동 갱신하면 데이터가 많아질수록 느려집니다. 그래서 집계는 필요할 때 수동으로 버튼을 눌러서 실행하게 했습니다.
---

지출결의서 자동화의 구조는 다른 업무에도 똑같이 적용됩니다.
```plain text
[입력 폼 시트]    →    [이력 시트]    →    [집계/보고서 시트]
  사람이 입력          GAS가 저장          GAS가 정리
```
수강생별로 대입하면:

집계 시트

프로님

주류원장 입력

입고이력

거래처별 월간집계




프로님

광고 성과 입력

일별이력

매장별 월간집계




프로님

발주이력

업무보고 자동생성


구조는 같습니다. 달라지는 것은 시트 이름과 셀 주소뿐입니다.

## 자동화를 설계하는 순서
본인 업무에 GAS를 적용할 때 코드 요청 전에 먼저 이 순서로 생각합니다.
```plain text
STEP 1. 반복되는 업무 흐름을 적는다
        (지금 어떤 순서로 무엇을 하고 있는가)

STEP 2. 각 동작에서 "판단이 필요한가" 표시한다
        (판단 없이 규칙대로 하는 것 = 자동화 대상)

STEP 3. 파일 구조를 설계한다
        (입력 폼 / 이력 DB / 집계 보고서)

STEP 4. 트리거를 결정한다
        (버튼 클릭? 시간 기반 자동 실행?)

STEP 5. Claude에게 코드를 요청한다
        (STEP 1~4가 명확하면 코드가 정확하게 나옴)
```
이 다섯 단계가 4부 본인 업무 적용 실습의 핵심입니다.
