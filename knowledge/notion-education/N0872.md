## 1\~5회차에서 쌓은 것 전체 지도
```plain text
1회차: Claude 기초
  RCTCK 프롬프트 구조 이해
  Claude로 업무 문서 작성·요약
  ↓

2회차: Claude 심화 — DSRF 분석
  데이터 해석·보고서 작성 자동화
  CSV 업로드 → Claude로 인사이트 추출
  ↓

3회차: Claude + 구글 시트
  프롬프트로 시트 분석 자동화
  보고서 프롬프트 설계
  ↓

4회차: GAS — 구글 시트 안 자동화
  Claude에게 코드 요청하는 법
  버튼 클릭 → 시트 자동 처리
  이메일 자동 발송 (GAS)
  ↓

5회차 (오늘): Make.com — 앱 간 자동화
  구글 시트 → 이메일·알림
  주기 실행 + 조건 실행 + 즉시 실행
  ↓

다음 단계 (자율):
  n8n + Claude API 연동
  AI가 판단하는 자동화로 발전
```

# 3장 — Make.com 운영 가이드
---
## 시나리오 관리 — 계속 쓰려면
**매주 한 번 확인할 것:**
```plain text
make.com → [Scenarios] → 목록 확인

✅ 초록 (ON): 정상 작동 중
❌ 빨간 (오류): 확인 필요 → [History] 탭

오류 확인 방법:
  왼쪽 [History] 클릭
  빨간 항목 클릭
  오류 메시지 복사
  → Claude에 "이 Make.com 오류 해결법 알려줘"
```
**자주 끊기는 경우:**
```plain text
원인:  연결(Connection)이 만료된 것
해결:  왼쪽 [Connections] → 해당 앱 → [Reauthorize]
      구글 계정 다시 로그인 → 확인
```
---
## Operations 관리
```plain text
무료 플랜: 월 1,000 operations
  모듈 3개 × 1회 실행 = 3 ops

내 시나리오 월 소비량 계산:
  하루 1회 × 모듈 3개 × 20일 = 60 ops/월 → 여유 있음
  하루 10회 × 모듈 5개 × 20일 = 1,000 ops/월 → 한계

남은 ops 확인:
  make.com 오른쪽 위 프로필 → Operations

1,000 ops 다 쓰면?
  Core 플랜 ($9/월, 10,000 ops) 으로 업그레이드
  또는 실행 주기 늘리기 (15분 → 1시간)
```
---
## 시나리오가 멈췄을 때 대처
```plain text
① 이메일 알림 받기 (사전 설정 권장)
   make.com → [Settings] → 시나리오 오류 시 이메일 알림 ON

② History 탭에서 오류 확인
   빨간색 항목 → 어느 모듈? 어떤 메시지?

③ 가장 빠른 해결
   오류 메시지 복사 → Claude에 "이 오류 해결법 알려줘"

④ 그래도 안 되면
   시나리오 OFF → 수동으로 업무 진행
   다음 날 강사에게 카톡으로 문의

중요:
   자동화가 멈춰도 수동으로 할 수 있어야 합니다.
   자동화는 도움이지, 유일한 방법이 되면 안 됩니다.
```

# 4장 — 전체 5회차 복습 + Q&A
---
## 오늘 핵심 3가지
```plain text
핵심 1: GAS = 시트 안 / Make.com = 시트 밖
  GAS는 구글 시트 내부에서 처리
  Make.com은 외부 앱으로 전달·연결

핵심 2: 트리거가 자동화의 시작
  언제 실행되는가를 먼저 결정해야
  Make.com은 시간·조건·즉시(웹훅) 세 가지

핵심 3: 자동화는 반복될수록 가치
  한 번 만들면 → 매일 절약
  지금 당장 완벽하지 않아도 됨 → 쓰면서 개선
```
---
## 앞으로 혼자서 하는 법
```plain text
1단계: 자동화 아이디어 발굴
   "내가 매번 반복하는 것은 무엇인가?"
   → 설계 워크시트 STEP 1~2

2단계: GAS인지 Make.com인지 결정
   시트 안 처리 → GAS
   외부 전달·알림 → Make.com

3단계: 설계 (STEP 3~6)
   트리거·데이터·이메일 내용 먼저 설계

4단계: Claude에 검토 요청
   "이 Make.com 구성이 가능한지 검토해줘"

5단계: Make.com에서 직접 만들기
   2권·3권 교재 보면서 단계별로

6단계: 오류 나면
   오류 메시지 복사 → Claude에 질문
```
---
## 막혔을 때 Claude에게 물어보는 법
**잘 작동하는 질문 패턴:**
```plain text
패턴 1: 오류 해결
"Make.com에서 이런 오류가 났어. [오류 메시지 붙여넣기]
어떤 원인인지, 어떻게 고치는지 알려줘."

패턴 2: 구성 검토
"Make.com으로 이걸 하려고 해.
트리거: 구글 시트 변경
조건: 잔액이 50만원 이하이면
액션: 이메일 발송
이 구성이 맞는지, 어느 모듈을 써야 하는지 알려줘."

패턴 3: 모듈 찾기
"Make.com에서 구글 시트의 특정 셀 값을 읽어서
이메일로 보내고 싶어. 어떤 모듈을 어떤 순서로 써야 해?"

패턴 4: 이메일 내용 작성
"Make.com 이메일 본문에
구글 시트에서 가져온 {{잔액}} 값을 넣어서
충전 요청 이메일을 쓰려고 해. 본문 형식 만들어줘."
```


# 7장 — 오늘 수업 마무리
---
## 오늘 한 일 한 줄 정리
```plain text
우리가 1회차부터 오늘까지 쌓은 것:

1회차: Claude로 문서 작성하는 법 배움
2회차: Claude로 데이터 분석하는 법 배움
3회차: Claude로 구글 시트 활용하는 법 배움
4회차: GAS로 구글 시트 자동화 만드는 법 배움
5회차: Make.com으로 앱 간 자동화 연결하는 법 배움

→ 오늘부터 내 업무가 사람 없이 돌아가기 시작함
```
---
## 마지막으로 — 자동화를 계속하려면
```plain text
가장 중요한 것 한 가지:

"작은 것 하나를 끝까지 완성해서 실제로 돌아가게 하는 것"

완벽한 자동화 시스템을 처음부터 만들려고 하면 지침
→ 오늘 만든 시나리오 하나를 1주일 동안 실제로 사용
→ 오류 나면 고치면서 익숙해지기
→ 그 다음에 하나 더 추가

그렇게 6개월이 지나면
내 업무의 80%는 자동으로 돌아가고 있을 것
```
