# 🌱 사전 학습 \| AI 활용 데이터 분석 기초 개관
## "데이터 분석이 처음인 분도, AI가 처음인 분도 — 여기서 출발합니다"
## 0-1. 데이터 분석이란 무엇인가? — 가장 쉬운 정의
> **데이터 분석 = 숫자와 정보 속에서 '의미 있는 이야기'를 꺼내는 일**
```plain text
예시로 시작해봅시다.

아래 숫자들을 보세요:
  청주시 지원 기업: 45개사
  충주시 지원 기업: 28개사
  제천시 지원 기업: 12개사

이것만 보면 그냥 숫자입니다.

그런데 '데이터 분석'을 하면 이렇게 됩니다:
  → "청주 편중이 심하다. 전체의 56%가 청주에 집중."
  → "제천은 목표 대비 달성률이 80%로 가장 낮다."
  → "지역 균형 지원 정책이 필요하다."

숫자에서 '판단의 근거'를 만드는 것이 데이터 분석입니다.
```
### 행정 업무에서 데이터 분석이 필요한 순간들





상황

"사유가 있습니다"

## 0-2. AI 이전의 데이터 분석 vs. AI 이후 — 무엇이 달라졌나
### 전통적 데이터 분석 방법 3가지와 한계
```plain text
방법 1: 엑셀 수동 작업
  하는 일: 피벗테이블, VLOOKUP, 차트 직접 작성
  한계:    함수를 모르면 막힘 / 파일 여러 개 취합이 번거로움
           오류가 어디서 났는지 찾는 데 시간이 더 걸림

방법 2: 전문 통계 도구 (SPSS 등)
  하는 일: 회귀분석, 상관분석 등 고급 통계
  한계:    배우는 데 시간이 많이 걸림 / 일반 행정직에게 과함
           우리 기관 응답자 중 SPSS 사용자는 단 1명

방법 3: 수작업 집계·보고서 작성
  하는 일: 데이터 보고 직접 표·문장 작성
  한계:    시간이 오래 걸림 / 실수 가능성 높음
           창의적 인사이트보다 단순 집계에 시간 소모
```
### AI 데이터 분석이 바꿔놓은 것
```plain text
✅ 이제 달라진 것들:

1. 함수를 몰라도 됩니다
   "A열 날짜 형식을 YYYY-MM-DD로 바꿔줘"
   → AI가 수식 생성, 내가 엑셀에 붙여넣기

2. 파일 여러 개 취합이 쉬워졌습니다
   "5개 팀 실적 파일을 하나로 합쳐줘"
   → ChatGPT Plus가 자동 통합

3. 보고서 초안을 AI가 먼저 씁니다
   데이터 분석 결과 → AI가 보고서 초안 생성
   → 담당자는 검토·수정에 집중

4. 차트를 자동으로 만들어줍니다
   "시군별 달성률을 막대 차트로 만들어줘"
   → 완성된 차트 이미지 즉시 생성

⚠️ 하지만 달라지지 않은 것들:
   - 데이터의 정확성 검증 → 여전히 사람이
   - 분석 결과의 의미 해석 → 여전히 사람이
   - 최종 판단과 결정 → 여전히 사람이
   - AI 결과물 검토·승인 → 반드시 사람이
```

## 0-3. AI 데이터 분석의 4가지 방법 — 목적별 선택 가이드
> 초보자가 가장 많이 하는 실수: "ChatGPT에 데이터 붙여넣고 분석해달라고 했는데 결과가 이상해요."<br>방법이 잘못된 겁니다. 목적에 맞는 방법을 쓰면 결과가 달라집니다.
### 방법 1 \| 자연어 질의 방식 — "대화하듯 물어보기"
```plain text
어떤 것인가:
  엑셀 데이터를 복사해서 붙여넣거나 파일을 올린 후
  "시군별로 집계해줘", "차트 만들어줘" 식으로 말로 요청

언제 쓰는가:
  ✅ 간단한 집계·요약이 필요할 때
  ✅ 엑셀 수식을 모르는데 빠른 답이 필요할 때
  ✅ 초보자가 처음 시작할 때

장점:
  - 별도 도구 설치 불필요
  - 즉각적인 결과
  - 누구나 바로 시작 가능

단점·유의사항:
  - 복잡한 수치 계산은 오류 가능성 있음 → 반드시 검증
  - 데이터 크기 제한 (무료 버전은 작은 데이터만)
  - 민감 데이터 입력 주의

사용 도구: ChatGPT (무료), Claude (무료)

교육기관 활용 예:
  "아래 데이터에서 달성률이 80% 미만인 사업만 골라줘"
  "지원유형별로 총 기업 수를 합산해줘"
```
---
### 방법 2 \| 파일 업로드 분석 방식 — "파일을 통째로 넘기기"
```plain text
어떤 것인가:
  엑셀 파일을 AI에게 직접 업로드하면
  AI가 파일을 읽고 Python 코드를 자동 생성해서 실행
  → 실제 계산 결과를 신뢰도 높게 제공

언제 쓰는가:
  ✅ 행이 많은 데이터 (100행 이상)를 분석할 때
  ✅ 차트까지 자동 생성하고 싶을 때
  ✅ 피벗테이블 수준의 집계가 필요할 때
  ✅ 탐색→진단→예측→처방 4단계 분석이 필요할 때

장점:
  - 신뢰도가 높음 (코드 실행 기반)
  - 대용량 데이터 처리 가능
  - 차트 이미지 자동 생성
  - 데이터 전처리(날짜 통일, 빈 셀 처리 등)도 자동

단점·유의사항:
  - ChatGPT Plus 유료 구독 필요 ($20/월), 클로드를 추천하나 클로드도 거의 유료 사용 (무료가 가능하나 기능 몇 개 없음)
  - 파일명을 영어로 변경 필수 (한글 파일명 오류 원인)
  - 민감 데이터 마스킹 후 업로드 필수
  - 결과는 반드시 검증 (완벽하지 않음)

사용 도구: ChatGPT Plus (고급 데이터 분석)

교육기관 활용 예:
  기업지원실적_2025.xlsx → company_support_2025.xlsx로 변환 후
  ChatGPT Plus에 업로드 → "시군별 달성률 막대 차트 만들어줘"
```

### 방법 3 \| 소스 기반 분석 방식 — "내 자료만 참고하게 하기"
```plain text
어떤 것인가:
  공개 통계 PDF, 보도자료 URL, 내부 문서 등을
  NotebookLM에 '소스'로 등록하면
  AI가 오직 그 소스 안에서만 답변

언제 쓰는가:
  ✅ 공개 통계 자료로 보고서 초안을 만들 때
  ✅ 할루시네이션(거짓 정보)이 절대 있으면 안 될 때
  ✅ 출처를 모든 수치에 표시해야 할 때
  ✅ 보안이 중요해서 외부 정보 유입을 막고 싶을 때

장점:
  - 할루시네이션 구조적 차단 (소스 밖은 모른다고 답함)
  - 모든 답변에 출처 인용 번호 자동 표시
  - 완전 무료
  - 스마트폰에서도 사용 가능

단점·유의사항:
  - 소스에 없는 정보는 답할 수 없음
  - 소스 자체가 오래된 자료면 오래된 정보를 인용
  - 딥 리서치 결과도 원출처 확인 필요

사용 도구: NotebookLM (완전 무료)
```

```plain text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
목적: 데이터 전체를 한 눈에 파악, 숨어있는 이상값 발견

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 0-5. AI 데이터 분석 전 꼭 알아야 할 5가지
> 이 5가지를 모르면 AI를 써도 효과가 절반 이하입니다.
### ① 데이터 품질이 AI 결과 품질을 결정한다
```plain text
"쓰레기가 들어가면 쓰레기가 나온다 (Garbage In, Garbage Out)"

AI는 내가 준 데이터만큼만 분석할 수 있습니다.

정리 안 된 데이터 → AI도 이상한 결과
셀 병합 있는 데이터 → 피벗테이블·분석 오류
날짜 형식이 섞인 데이터 → 시계열 분석 불가
숫자에 단위 텍스트 섞임 → 합계·평균 계산 불가

→ AI에게 보내기 전, 반드시 데이터를 기본 정리하세요.
   (이것 자체도 AI에게 도움받을 수 있습니다!)
```
### ② AI는 계산기가 아니라 언어 모델이다
```plain text
AI의 강점:             AI의 약점:
✅ 자연어 이해          ❌ 복잡한 수치 직접 계산 -> 할 수는 있지만 오류 있을 수 있음.
✅ 패턴 인식            ❌ 실시간 인터넷 검색 (기본 설정)
✅ 보고서 초안 작성     ❌ 기관 내부 최신 데이터 접근
✅ 아이디어 제안        ❌ 법적 책임이 있는 최종 판단
✅ 코드·수식 생성       ❌ 완벽한 정확성 보장

→ AI는 "계산"보다 "코드·수식 생성"에 시키는 것이 훨씬 정확합니다. 단 여러 번의 교차 검증을 하거나 ai 모델 교차 활용 등을 한다면 훨씬 용이함.
```

### ③ 데이터 양이 많을수록 좋지만, 한계가 있다
```plain text
무료 ChatGPT:
  - 파일 업로드 불가 / 붙여넣기로 소량만 가능
  - 긴 텍스트는 뒷부분이 잘릴 수 있음

ChatGPT Plus / Claude:
  - 엑셀 파일 업로드 가능
  - 수십만 행까지 처리 가능 (파일 업로드 방식)
  - 컨텍스트 창 한도 내에서 처리

NotebookLM:
  - 소스 파일 50개 (무료) / 300개 (유료) 업로드 가능
  - PDF 1개당 최대 500,000 단어

→ 데이터가 많으면 핵심 샘플만 먼저 붙여넣기,
   또는 파일 업로드 방식 사용
```
### ④ 반드시 검증하고, 최종 책임은 담당자에게 있다
```plain text
AI 결과물의 위상:
  AI 생성 초안 ≠ 최종 보고서
  AI 계산 수치 ≠ 확정 수치
  AI 제안 방안 ≠ 결정된 정책

반드시:
  담당자가 검토 → 수치 대조 → 수정·보완 → 서명·제출

공문서·보고서에 AI 생성 내용을 검증 없이 그대로 사용하면
담당자 책임이 발생할 수 있습니다.
```

```plain text
  "이 데이터에서 지원금액 평균을 구하는 엑셀 수식을 만들어줘"
  → =AVERAGE(E2:E21) 같은 수식 생성 → 내가 직접 엑셀에서 실행 → 정확

  또는 ChatGPT Plus / Claude Skills:
  → AI가 Python 코드 자동 생성 → 가상환경에서 직접 실행 → 수치 출력
  → 신뢰도 거의 100%에 가까워짐
```

** 파일을 직접 넣어서 분석할 때 — 신뢰도 높이는 방법**
**보충 설명**: "AI에게 코드를 만들게 하라"는 원칙은 여전히 유효합니다. <br>다만 Claude, ChatGPT Plus처럼 파일을 직접 읽고 분석하는 기능이 크게 좋아진 지금은, 파일을 올려서 바로 분석을 요청하는 방식도 충분히 실용적입니다. 단, 이 방식은 **신뢰도를 올리는 별도의 기법**이 필요합니다.
---
**파일 직접 분석 방식이 적합한 상황**
✅ 이럴 때 파일 직접 업로드가 효과적:<br>  - 행 수가 적당한 데이터 (500행 이하 권장)<br>  - 수식이나 집계보다 패턴·경향 파악이 목적일 때<br>  - 자연어 설명이 필요한 인사이트 도출이 목적일 때<br>  - 차트 이미지까지 한 번에 받고 싶을 때<br><br>⚠️ 이럴 때는 코드 생성 방식이 더 안전:<br>  - 정확한 합계·평균 등 수치 계산이 핵심일 때<br>  - 수만 행 대용량 데이터일 때<br>  - 결과에 법적·공식적 책임이 따를 때
---


### 기법 1 \| 분석 전 "데이터 구조 먼저 확인" 요청
> AI가 파일을 제대로 읽었는지 먼저 검증하는 것이 핵심입니다.<br>분석 요청 전에 반드시 이 단계를 먼저 거치세요.
`[프롬프트]<br><br>이 파일을 분석하기 전에 먼저 데이터 구조를 확인해줘.<br><br>1. 전체 행 수와 열 수<br>2. 각 열의 이름과 데이터 타입 (숫자/텍스트/날짜)<br>3. 빈 셀이 많은 열 있으면 알려줘<br>4. 이상해 보이는 값이나 형식 오류 있으면 알려줘<br>5. 이 데이터로 분석할 수 있는 것과 없는 것을 구분해줘<br><br>→ 구조 확인 후 분석 요청할게.`
> 이 단계에서 AI가 열 이름을 잘못 읽거나 행 수를 다르게 말하면<br>파일이 제대로 인식되지 않은 것입니다. 파일 형식을 바꿔서 다시 올리세요.
---
### 기법 2 \| "계산 근거를 같이 보여달라" 요청
> 파일 직접 분석에서 할루시네이션이 가장 많이 나오는 곳이 수치 계산입니다.<br>계산 결과만 받지 말고, **어떻게 계산했는지**를 함께 받으세요.
`[프롬프트에 반드시 포함할 문구]<br><br>수치를 계산할 때는 반드시 아래를 같이 보여줘:<br>- 계산에 사용한 행 범위 (예: 2행~26행)<br>- 계산 방법 (합산인지, 평균인지, 필터 후 집계인지)<br>- 제외된 행이 있으면 이유와 함께 알려줘<br><br>→ 내가 엑셀로 직접 재확인할 수 있도록.`
---
### 기법 3 \| 단계별 분리 요청 (한 번에 다 시키지 않기)
> "분석하고 차트 만들고 보고서도 써줘"를 한 번에 요청하면<br>각 단계의 오류를 확인하기 어렵습니다.<br>**한 단계씩 요청하고, 확인 후 다음 단계로 넘어가세요.**
`잘못된 방식:<br>  "이 파일 분석해서 차트 만들고 보고서 초안까지 써줘"<br>  → AI가 분석을 잘못해도 보고서가 그럴듯하게 나와서 오류를 못 잡음<br><br>올바른 방식:<br><br>  1단계: "데이터 구조 확인해줘" → 확인<br>  2단계: "시군별 지원 기업 수 집계해줘" → 수치 검증<br>  3단계: "이걸 막대 차트로 만들어줘" → 차트 확인<br>  4단계: "분석 결과 요약 보고서 초안 써줘" → 검토 후 활용`
---
### 기법 4 \| "틀린 부분을 솔직하게 말해달라" 명시
> AI는 기본적으로 답을 주려고 합니다.<br>모르는 것을 모른다고 말하게 하려면 명시적으로 요청해야 합니다.
`[프롬프트에 포함할 문구]<br><br>분석 중 아래 상황이 생기면 솔직하게 알려줘:<br>- 데이터가 부족해서 확실하지 않은 내용<br>- 계산 결과가 이상하게 느껴지는 부분<br>- 파일에서 읽지 못한 데이터가 있는 경우<br>- 내 질문이 이 데이터로 답하기 어려운 경우<br><br>→ 자신 없는 내용을 자신있게 말하는 것보다<br>   "확인이 필요합니다"라고 하는 게 훨씬 낫습니다.`
---
### 기법 5 \| 핵심 수치는 엑셀로 교차 검증
> 파일을 직접 분석해도 핵심 수치는 반드시 원본과 대조하세요.<br>특히 합계·평균·달성률처럼 보고서에 직접 들어가는 숫자는<br>AI 결과를 그대로 쓰지 말고, 엑셀 수식으로 한 번 더 확인합니다.
`검증 방법:<br>  AI가 "전체 지원 기업 수 573개사" 라고 했다면<br>  → 엑셀에서 =COUNTA(C2:C28) 또는 =SUM(D2:D28) 으로 직접 확인<br>  → 일치하면 사용 / 다르면 AI 수치 삭제 후 엑셀 값으로 교체<br><br>자주 오류가 나는 수치 유형:<br>  ❌ 필터 조건이 있는 집계 (예: 달성률 90% 이상인 것만 합산)<br>  ❌ 소수점 반올림·올림·버림<br>  ❌ 단위 혼용 데이터 (백만원 / 원이 섞인 경우)<br>  ❌ 빈 셀이 포함된 평균 계산`
---
### 파일 직접 분석 신뢰도 체크리스트
`파일 업로드 전:<br>□ 파일명 영어로 변경했는가? (한글 파일명 → 오류 원인)<br>□ 셀 병합 해제했는가?<br>□ 민감 정보 마스킹했는가?<br><br>분석 요청 시:<br>□ 데이터 구조 먼저 확인 요청했는가?<br>□ 계산 근거를 함께 보여달라고 했는가?<br>□ 단계별로 나눠서 요청하고 있는가?<br>□ 불확실한 내용은 솔직히 말해달라고 했는가?<br><br>결과 검토 시:<br>□ 핵심 수치 2~3개를 엑셀로 재확인했는가?<br>□ AI가 "데이터에 없는 내용"을 만들어낸 곳은 없는가?<br>□ 최종 보고서에 올리기 전 담당자 직접 검토했는가?`

### 🔷 도구 ② \| NotebookLM — 공개 통계로 할루시네이션 없는 보고서
> **핵심**: 내가 올린 자료 안에서만 답하기 때문에 공공기관에서 가장 안전하게 쓸 수 있는 AI입니다. 할루시네이션을 구조적으로 차단합니다.
### NotebookLM 작동 원리 (RAG 기술)
```plain text
일반 AI (ChatGPT 무료 등):
  질문 → AI 학습 데이터(인터넷 전체)에서 확률적 추정 → 할루시네이션 발생 가능

NotebookLM (RAG 방식):
  질문 → 내가 올린 문서 안에서만 검색
       → 근거 있는 답변 + 출처 인용 번호 자동 표시
       → 문서에 없으면 솔직하게 "해당 정보 없음"
                                 ↑ 이게 공공기관에 결정적으로 중요
```

```plain text
  ② 회귀 분석으로 KPI 예측 모델이 필요할 때
  ③ 기업 지원 효과를 통계적으로 증명해야 할 때

신뢰도 원리:
  일반 AI: "이 데이터에서 상관관계를 분석해줘"
           → AI가 확률적으로 추정 → 오류 가능성 높음

  Claude Skills: AI가 분석용 Python 코드 자동 생성
                 → 코드를 가상환경에서 직접 실행
                 → 실제 계산값(실행 결과)을 응답에 반영
                 → 신뢰도 거의 100%에 가까워짐

교육기관 활용 예:
  "기업 지원 만족도 CSV 데이터를 업로드할게.
   만족도 점수에 영향을 미치는 요인을 다중 회귀 분석으로 찾아줘.
   분석 결과와 인포그래픽이 포함된 보고서를 생성해줘."
```
