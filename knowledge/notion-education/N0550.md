## 이 실습으로 하는 것
Claude에게 코드를 요청하기 전에 본인 업무를 구조화하는 설계 워크시트를 작성함.
## 진행 단계
1. **현재 업무 흐름 적기(STEP 1)** — 동사 중심으로 최대한 세분화(귀찮거나 실수가 생기는 부분일수록 더 쪼갬)
2. **판단 vs 규칙 표시(STEP 2)** — 각 동작에 \[판단\]/\[규칙\]/\[반복\] 표시. 헷갈리면 "새로 입사한 직원에게 설명서로 만들 수 있는가"를 질문(만들 수 있으면 규칙)
3. **자동화 대상 선택(STEP 3)** — \[규칙\]·\[반복\] 중 매일 반복·실수 잦음·여러 파일 오감·시간 오래 걸림 기준으로 우선순위 결정, 예상 절약 시간 계산
4. **파일 구조 설계(STEP 4)** — 입력 시트·이력 시트·보고서 시트와 열 구성 작성
5. **트리거 결정(STEP 5)** — 버튼 클릭 / 매일 정해진 시각 / 조건 기반 중 선택
6. **프롬프트 초안(STEP 6)** — 위 내용을 \[내 업무 상황\]\[파일 구조\]\[셀 구조\]\[동작 순서\]\[트리거\]에 옮겨 Claude 요청 초안 작성
