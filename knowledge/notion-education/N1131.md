# Step 1~4 학생 작성 순서 (재료리스트 마감)

정리일: 2026-10-08 · 교육 에셋 N1131

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
팀별 재료리스트를 정해진 순서대로 입력하고 계산 결과를 확인해 발주 가능한 상태로 마감합니다.
## 진행 단계
1. **목표 생산 개수 입력** — 몇 개를 만들어 팔 것인지 결정
- 입력할 내용: 숫자만 입력 (단위를 함께 입력하면 계산 오류 발생)
2. **판매 가격 입력** — 손님 1명이 1개를 살 때 낼 금액
- 중간발표에서 정한 가격이 있으면 그대로 입력 후 계산 결과를 보고 조정
3. **재료 검색 및 입력** — 품명은 용량·수량·규격까지 기재 (예: 글리세린 투명 비누베이스 1kg)
- 구매 링크 필수 입력
- 배송비는 항목마다 확인해 입력, 무료배송은 0 입력
- 수령처 표시: 상하는 재료는 팀원 집, 나머지는 센터
4. **계산 결과 확인** — 단위 원가, 마진, 마진율 자동 계산
- 마진율 30% 미만이면 판매가 인상 / 재료 교체 / 구성 축소 중 선택
- 잔액이 음수이면 재료 삭감
## 막히는 지점
- 목표 생산 개수 칸에 단위를 넣으면 계산 오류
- 링크가 없으면 발주 시 동일 상품 확인 불가
- 누락 빈발 항목: 개별 포장재, 라벨 스티커 용지, 배송비, 일회용 장갑·물티슈·테이프 등 소모품, 부스 진열용 소품
