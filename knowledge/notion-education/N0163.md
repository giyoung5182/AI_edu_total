## 1 · Claude 데스크톱 앱 설치
Claude Code는 이 앱 안에 이미 들어 있습니다. 별도로 더 받으실 것은 없습니다.
**다운로드**: [개별 링크 제외]
```plain text
STEP 1-1. 위 주소로 접속합니다.

STEP 1-2. 본인 운영체제(Windows / macOS)에 맞는 버전을 받습니다.
  → 페이지가 대개 자동으로 감지해줍니다.

STEP 1-3. 다운로드된 파일을 실행하고 기본값 그대로 설치합니다.
  → 특별히 바꿀 옵션이 없습니다.

STEP 1-4. 설치가 끝나면 앱을 실행합니다.
```
> ⚠️ **Windows에서 "PC를 보호했습니다" 경고(SmartScreen)가 뜨면**<br>\[추가 정보\] → \[실행\] 을 누르시면 됩니다. 정식 서명된 프로그램이지만 신규 버전에서 가끔 뜹니다.
> ⚠️ **Mac에서 "확인되지 않은 개발자" 경고가 뜨면**<br>애플 로고 → 시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤 → **\[그래도 열기\]**

앱 화면 **왼쪽 아래**에 `업데이트하려면 다시 시작` 같은 안내가 보이면, **눌러서 업데이트를 완료**해 주세요.
버전이 다르면 화면 구성이 달라집니다. 수업 중 강사 화면과 본인 화면이 어긋나면 따라가기 어려워집니다.
> ✅ **체크포인트**: 업데이트 안내가 더 이상 보이지 않으면 완료.

## 3 · GitHub · Vercel 가입
만든 결과물을 보관하고(GitHub), 인터넷 주소로 공개하는(Vercel) 무료 서비스입니다. 둘 다 결제 정보 입력이 필요 없습니다.
### 3-1. GitHub 가입
```plain text
STEP 3-1. github.com 접속 → 우측 상단 [Sign up]
STEP 3-2. 이메일 / 비밀번호 / 사용자 이름(username) 입력
STEP 3-3. 이메일로 온 인증 링크 클릭 → 가입 완료
```
> ⚠️ **사용자 이름(username)은 신중히 정해주세요.** 나중에 결과물 주소에 들어갈 수 있습니다.<br>📬 **인증 메일이 안 오면** 스팸함과 프로모션함을 확인해 주세요.
### 3-2. Vercel 가입
```plain text
STEP 3-4. vercel.com 접속 → 우측 상단 [Sign Up]
STEP 3-5. ★ 반드시 [Continue with GitHub] 버튼으로 가입
STEP 3-6. 권한 승인 화면에서 [Authorize] 클릭
```
> 💡 **왜 GitHub 계정으로 가입하나요?**<br>이메일로 따로 가입하시면 나중에 GitHub와 연결하는 단계가 하나 더 생깁니다. 처음부터 GitHub 계정으로 가입하시면 두 서비스가 자동으로 연결됩니다.
> 🔑 **아이디와 비밀번호는 당일 다시 필요합니다.** 기억해 두시거나 메모해 주세요.

## 4 · 저장 공간 확보 및 사양 확인
### 4-1. 저장 공간 — 최소 5GB (넉넉하게 10GB 권장)
당일 여러 개발 도구와 실습 파일이 설치·생성됩니다.
```plain text
[Windows] 파일 탐색기 → '내 PC' → C: 드라이브 남은 공간 확인
[Mac]     애플 로고 → '이 Mac에 관하여' → '저장 공간' 탭

공간이 부족하면:
  · 다운로드 폴더의 큰 파일 정리
  · 휴지통 비우기
  · 안 쓰는 프로그램 삭제
```
### 4-2. 내 컴퓨터 사양 — 최소 사양 확인 필요.
```plain text
최소 사양:
  · 운영체제: Windows 10 이상 / macOS 12(몬터레이) 이상
  · 메모리(RAM): 4GB 이상 (8GB 이상 권장)

확인 방법:
  [Windows] 설정 → 시스템 → 정보
            → "설치된 RAM", "시스템 종류(64비트)", "Windows 사양"

  [Mac]     애플 로고 → '이 Mac에 관하여'
            → macOS 버전 / 메모리 / 칩 확인
            ★ 칩(Apple M1·M2·M3 또는 Intel) 정보가 중요합니다
```

## 💡 알아두면 좋은 개념 — PATH
실습 당일 "분명 설치했는데 명령어가 안 먹혀요"의 대부분이 이것 때문입니다.
PATH는 쉽게 말해 **"컴퓨터가 프로그램을 찾아다니는 주소록"** 입니다.
```plain text
git --version 을 쳤을 때
컴퓨터는 "git이 어디 있지?" 하고 이 주소록을 뒤집니다.

  주소록에 등록돼 있으면 → 찾아서 실행 (버전 숫자 출력)
  등록돼 있지 않으면    → "내부 또는 외부 명령이 아닙니다" 오류
```
- 설치할 때 **'Add to PATH'가 켜져 있어야** 이 주소록에 자동 등록됩니다. Git·Node 모두 기본으로 켜져 있어 손댈 필요가 없습니다.
- 방금 프로그램을 깔았는데 **이미 열려 있던 창**은 옛 주소록을 기억합니다. 그래서 설치 후에는 **창을 새로 열어야** 갱신된 주소록을 읽습니다.
- **첫 번째 대응은 언제나 "창 새로 열기"** 입니다. 그래도 안 되면 컴퓨터 재시작.
