# 실습 · 홍보물 1종 만들기 (15분)

정리일: 2026-10-08 · 교육 에셋 N1433

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
문서 성격에 맞는 경로(A: 배경 생성 후 파워포인트로 문구 얹기 / B: 완성본 한 번에 생성)를 골라 홍보물 1종을 만들고, 글자와 숫자를 눈으로 대조합니다.
## 진행 단계
1. **만들 것과 경로 고르기 (1분)** — ① 채용 카드뉴스 → 경로 A / ② 안전 캠페인 포스터 → 경로 B / ③ 입주사 안내물 → 경로 A
2. **프롬프트 복사 후 수정 (3분)** — 교안의 프롬프트를 복사해 두세 곳만 우리 상황으로 바꿉니다.
3. **생성 (4분)** — 마음에 안 들면 재생성하지 말고 부분 수정 지시문을 씁니다.
- 입력할 내용:
```javascript
구도와 색은 그대로 두고, 헤드라인 문구만 "___"로 바꿔 줘
텍스트 위치와 크기는 유지하고, 대비만 더 강하게 해 줘
배경 안에 들어간 알아볼 수 없는 글자를 지우고 배경과 같은 단색으로 채워 줘
```
4. **문구 얹기 또는 확인 (6분)** — 경로 A는 파워포인트에서 문구를 얹고, 경로 B는 글자를 확대해 확인합니다.
5. **저장 (1분)** — 결과물을 저장하고, 사용한 프롬프트를 따로 저장합니다.
완료 기준: 문서 성격에 맞는 경로 선택 / 프롬프트에 6요소 포함 / 색 두세 가지로 제한 / 여백을 위치와 비율까지 지정 / 경로 B라면 네 가지 조건 포함 / 글자와 숫자를 확대해 눈으로 대조 / 사용한 프롬프트 저장
## 막히는 지점
- 글자가 아예 안 나온다 → "이미지 위에 직접 합성해서 출력" 추가
- 글자가 배경에 묻힌다 → 반투명 오버레이 + 색 지정
- 배경에 알아볼 수 없는 글자가 낀다 → "지정한 문구만 표시" 추가
- 날짜·연락처가 틀렸다 → 경로 A로 전환하거나 전수 대조
