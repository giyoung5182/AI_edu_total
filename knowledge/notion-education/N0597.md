# 실습 환경 정리 (클렌징 절차)

정리일: 2026-10-08 · 교육 에셋 N0597

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
반출을 마친 뒤 공용 PC에서 개인 파일과 로그인 정보를 정리한다. 강사가 함께 확인한다.
## 진행 단계
1. **반출 확인** — 내 메일에 파일이 도착했는지 다시 확인
2. **작업 폴더 삭제** — 바탕화면에 만든 폴더를 통째로 삭제
3. **다운로드 폴더** — 내려받은 이력서와 자료를 삭제
4. **휴지통 비우기** — 삭제한 파일이 휴지통에 남지 않게 비움
5. **클로드 로그아웃** — 데스크톱 앱에서 로그아웃
6. **노션 로그아웃** — 개인 자료가 남아 있는지 확인한 뒤 로그아웃
7. **브라우저 정리** — 메일에서 로그아웃하고 브라우저를 닫음
## 막히는 지점
- 이력서에는 개인정보가 들어 있어 공용 PC에 남기면 다음 사용자가 볼 수 있음
- 3번 다운로드 폴더를 잊는 경우가 많음
