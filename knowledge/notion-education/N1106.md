# 2.3 실습하기 — 상황별 RCTC 프롬프트 작성(일정·미팅록·식단)

정리일: 2026-10-08 · 교육 에셋 N1106

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
주어진 세 가지 상황에 맞는 RCTC 프롬프트를 직접 작성한다.
## 진행 단계
1. **일정 정리** — 캘린더에 일정이 10가지 넘게 복잡할 때 엑셀 시트로 일목요연하게 정리해 주는 프롬프트를 작성한다. 교안의 일정 설명문(월·화·수·목·금·토 일정 등)을 재료로 쓴다.
2. **미팅록 정리·인사이트** — 고객사 미팅 후 미팅록을 정리하고 핵심 인사이트를 뽑는 프롬프트를 작성한다. 교안의 클로바노트 음성 변환 텍스트(뷰티앤코 미팅)를 재료로 쓴다.
3. **맞춤 식단** — "다이어트 식단 짜기 - 50대 여자 / 당뇨 위험 환자 / 다이어트 경험 있지만 매번 실패함" 조건으로 프롬프트를 작성한다.
- 정상 결과: 역할(R)·맥락(C)·과업(T)·제약(C)·정보(K)가 담긴 프롬프트. 빠진 요소는 교안의 "프롬프트가 안 통할 때 — 흔한 실수 5가지와 처방" 표로 진단
## 막히는 지점
- 교안 진단표: 결과가 뱕뱕하면 R 추가 / 엉뚱한 방향이면 C 추가 / 원하는 것과 다르면 T를 단계로 쪼개기 / 길거나 형식이 안 맞으면 제약 추가 / 지어내면 K에 정확한 정보 입력
