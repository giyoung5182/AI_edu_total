# 1단계 직접 해보기: Canvas 첫 웹앱(D-day 계산기)

정리일: 2026-10-08 · 교육 에셋 N1421

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
자연어 한 줄로 Gemini Canvas에서 웹앱을 만들고, 대화로 수정해 보는 흐름에 익숙해집니다.
## 진행 단계
1. **Canvas 열기** — `gemini.google.com`에서 입력창의 **+** 를 누르고 **Canvas**를 선택합니다.
2. **프롬프트 입력** — 아래 프롬프트로 웹앱을 부탁합니다.
```javascript
간단한 '시약·원료 유효기간 D-day 계산기' 웹앱을 단일 HTML 파일로 만들어줘.
- 유효기간 날짜를 입력하면 오늘부터 며칠 남았는지 보여줘
- 30일 이하로 남으면 빨간색 경고
- 한국어 UI, 깔끔한 카드 디자인
```
3. **미리보기 확인** — 옆 미리보기에서 직접 날짜를 넣어봅니다.
4. **자연어로 수정** — "경고 기준을 7일로 바꿔줘", "색을 더 차분하게", '글자 더 크게' 같은 말로 두세 번 수정합니다.
