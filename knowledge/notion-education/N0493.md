# 조기 완료자 · 추가로 써볼 자동화

정리일: 2026-10-08 · 교육 에셋 N0493

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
두 실습을 끝낸 사람이 시간이 남을 때 같은 방식으로 추가 자동화를 해봅니다.
## 진행 단계
1. **조건에 따라 자동 색칠하기(쉬움)** — C열 값이 "미완료"면 노란색, "완료"면 초록색으로 칠하는 매크로를 프롬프트로 요청
2. **반복 보고서 양식 자동 채우기** — "데이터" 시트의 각 행을 "보고서양식" 시트의 정해진 셀에 채우고 행마다 새 시트로 복사해 저장
3. **PDF 출력 / 더미 데이터 생성** — 활성 시트를 "시트이름_오늘날짜.pdf"로 저장하는 매크로, 또는 작업번호·작업내용·상태·담당자·마감일 컬럼의 더미 데이터 20행 생성 요청
