## 이 실습으로 하는 것
소스를 두 층으로 나눠 노트북을 구성하고, 5대 프레임과 Few-Shot 예시를 갖춘 프롬프트로 질문한 뒤 Self-Critique로 검증합니다.
## 진행 단계
1. **소스 아키텍처 설계 + 품질 체크 (10분)** — 0\~3회차 교안(고신호) + 참고할 AI 뉴스 기사 1\~2개(저신호)를 구분해 하나의 노트북에 업로드
- 정상 결과: 소스 품질 체크리스트 4가지(텍스트 선택 가능 여부, 최신 여부, 출처 명확성, 모순 소스 혼재 여부)를 넣기 전에 적용
2. **5대 프레임 + Few-Shot 프롬프트 (10분)** — 관점 지정 + 대상 지정 + 형식 지정 + 근거 요구 + 불확실성 처리 5요소를 모두 포함해 질문하고, Few-Shot 예시 1개를 추가해 형식 고정
3. **Self-Critique 루프 체험 (5분)** — 받은 답변에 "소스와 다른 부분이 있는지 스스로 검토해줘"라고 요청하고 답변이 어떻게 수정되는지 확인
## 막히는 지점
- 스캔 품질이 낮은 PDF는 텍스트 인식 실패 → 텍스트 PDF로 변환하거나 OCR 후 업로드
- 같은 교안의 구버전·신버전을 동시에 올리면 섞어서 답변
- 소스 1개만 넣고 "다각도로 분석해줘"라고 요청하는 것은 불가능한 요청
