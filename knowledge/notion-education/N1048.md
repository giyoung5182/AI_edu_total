# 02. SQL 기본 문법 및 조회 실습

정리일: 2026-10-08 · 교육 에셋 N1048

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 테이블(theglory)로 SELECT, WHERE, CASE WHEN, ORDER BY 기본 문법을 직접 조회해 봅니다.
## 진행 단계
1. **기본 조회** — SELECT로 컬럼을 고르고 FROM으로 테이블을 지정합니다. 중복 없이 보려면 DISTINCT를 씁니다.
```sql
SELECT DISTINCT 컬럼이름
FROM 테이블이름
;
```
2. **WHERE 조회** — 구글 드라이브의 theglory.csv를 DBeaver에 업로드한 뒤 성별이 F인 데이터를 가져옵니다.
```sql
select *
from basic.theglory
where 성별 ='F'
;
```
3. **CASE WHEN** — 조건에 따라 '역할구분' 컬럼을 새로 만듭니다.
```sql
select * ,
case when 이름 in ('문동은', '주여정') then '선'
                else '악' end as '역할구분'
from basic.theglory
;
```
- 정상 결과: 맨 오른쪽에 '역할구분' 컬럼이 추가됨
4. **복합 조건** — 날짜가 비어있지 않고, 성별이 M이 아니고, 직업이 아나운서·승무원·화가 중 하나이고, 나이가 30\~40세인 데이터를 AND로 묶어 조회합니다.
```sql
SELECT *
FROM basic.theglory
WHERE 날짜 IS NOT NULL
AND (성별!='M')
AND (직업 IN('아나운서','승무원','화가'))
AND (나이 BETWEEN 30 AND 40)
```
5. **ORDER BY** — 나이 기준 오름/내림차순, 컬럼 번호 사용, 다중 조건 정렬을 차례로 실행합니다.
```sql
select 날짜, 이름, 성별, 나이, 직업
from basic.theglory
order by 1 desc, 4 ASC;
```
## 막히는 지점
- 교안에 별도 기재 없음 (MySQL에서 구문 끝은 세미콜론, ORDER BY는 SQL 구문의 가장 마지막에 수행된다는 설명만 있음)
