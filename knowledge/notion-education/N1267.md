## 이 실습으로 하는 것
Windows 기준으로 실습에 필요한 도구 6가지를 순서대로 설치한다.
## 진행 단계
1. **Python 설치** — python.org/downloads에서 설치한다.
- 정상 결과: 설치 화면에서 "Add Python to PATH"에 체크한 뒤 설치한다.
2. **Git 설치** — git-scm.com/downloads에서 설치하면 Git Bash도 함께 설치된다. 옵션은 기본값 그대로 Next를 눌러도 된다.
3. **GitHub CLI 설치** — 터미널(cmd 또는 Git Bash)에서 명령어를 순서대로 실행한다.
- 입력할 내용:
```javascript
winget install --id GitHub.cli
gh auth login
```
- 정상 결과: 안내 메시지에서 방향키와 Enter로 선택하고, 브라우저에서 GitHub 로그인을 완료한다.
4. **코드 에디터 설치** — 둘 중 하나를 선택한다. VSCode는 Terminal → New Terminal 또는 Ctrl + \` 로 터미널을 열고 claude를 입력하면 Claude Code를 실행할 수 있다. 필수 확장 프로그램은 Python, Jupyter, 추천은 Office Viewer, vscode-pdf.
5. **Node.js 설치** — nodejs.org/ko/download에서 LTS 버전을 선택해 설치한다. npm 명령어를 쓸 수 있게 된다.
6. **Claude Code 설치** — Claude Pro 이상 구독이 필요하다. 옵션 A는 Claude Desktop 앱 설치, 옵션 B는 터미널에서 설치한다.
- 입력할 내용:
```javascript
npm install -g @anthropic-ai/claude-code
```
- 정상 결과: 터미널에 claude를 입력해 실행할 수 있다.
## 막히는 지점
- Python 설치 시 "Add Python to PATH" 체크 누락
