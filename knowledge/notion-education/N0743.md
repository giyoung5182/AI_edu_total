# 전역 작업 규칙

## 파일 저장 위치
- 모든 산출물(HTML, 코드, 문서 등)은 반드시 현재 프로젝트 폴더 안에만 생성한다.
- /tmp, $TMPDIR, /private 등 임시 디렉토리에는 어떤 산출물도 만들지 않는다.
- 테스트용 파일이 꼭 필요하면 프로젝트 폴더 안에 만들고, 작업이 끝나면 삭제한다.
- 파일을 만든 뒤에는 최종 저장 경로를 응답에 명시한다.

## 검증·테스트
- 웹페이지 제작 및 수정 완료 후 테스트를 절대로 하지 않는다. 항상 사용자가 직접 파일을 열어서 직접 테스트 할 수 있도록 안내한다.
- 검증은 사용자가 명시적으로 요청할 때만 수행한다.
- 검증이 필요해 보이면 실행하지 말고 "확인해볼까요?" 한 줄로만 물어본다.

## worktree 대응
- 작업 경로에 `.claude/worktrees`가 포함되어 있으면, 작업을 시작하기 전에
  자동 worktree에서 실행 중임을 한 줄로 알리고 실제 저장 경로를 보여준다.
- 사용자가 원본 폴더 작업을 원하면 원본 프로젝트 루트로 이동해서 작업한다.

## 5. 참고사항
#### 1) ‘Code’ 탭이 열리지 않는다면
1. 유료 플랜(Pro·Max·Team·Enterprise) 계정으로 로그인했는지 확인합니다. ‘Code’ 탭은 유료 플랜에서만 열립니다.
2. 그래도 안 되면 클로드 데스크톱 앱을 완전히 종료했다가 다시 켭니다.
3. Windows에서 ‘Code’ 탭에 Git 관련 안내가 뜨면, Git을 설치한 뒤 앱을 다시 켭니다.
---
#### 2) 클로드코드 외 다른 것들은 왜 설치했을까?
1. **파이썬**: 클로드코드가 코드를 실행할 때 쓰는 프로그래밍 언어입니다.
2. **Git**: 코드 변경 이력을 관리하는 도구이자, Windows에서 ‘Code’ 탭이 동작하는 데 필요합니다.
3. **클로드 데스크톱 앱**: 상단 ‘Code’ 탭에서 클로드코드를 사용하는 본체입니다.
