# AI Developer로 MVP 시스템 만들기

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지금까지 ChatGPT에서 실험한 기능을 Genspark AI Developer로 실제 작동하는 웹 시스템으로 만듭니다.
## 진행 단계
1. **AI Developer 선택** — genspark.ai 사이드바에서 AI Developer
2. **자료 정리** — 5차시 기획안 + 2\~3차시 프롬프트 + 단순 규칙 3개 + 보고서 포맷
3. **시스템 생성 요청**
- 입력할 내용(요약): 만들고 싶은 시스템 / 입력(데이터 형태·필수 컬럼 5\~7개·예시 데이터 15행) / 처리(요약·분류·액션추천 프롬프트) / 단순 규칙 3개 / 결과물 형태(옵션 A 대시보드, B 입력폼, C 보고서 자동 생성 페이지) / 요청: 한국어 인터페이스로 실제 작동하는 웹 시스템 (이하 교안 참고)
4. **생성 대기** — 보통 2\~5분
5. **테스트** — 생성된 시스템 URL을 확인하고 예시 데이터로 작동 테스트
## 막히는 지점
- 처음부터 완벽하게 만들려 하지 말고 일단 작동하는 것이 핵심
