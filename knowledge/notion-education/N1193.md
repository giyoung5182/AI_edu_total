# 4단계. Claude Code 설치와 인증

정리일: 2026-10-08 · 교육 에셋 N1193

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Claude Code를 네이티브 인스톨러로 설치하고 인증합니다. Node.js 같은 사전 요구사항과 관리자 권한은 필요 없으며 반드시 Ubuntu 터미널 안에서 실행합니다.
## 진행 단계
1. **설치**
```bash
curl -fsSL [개별 링크 제외] | bash
```
1. **확인** — 터미널을 닫았다가 다시 열고 실행
```bash
claude --version
claude doctor
```
- 정상 결과: 버전 번호가 나오고 doctor가 정상 보고
1. **인증** — 교육 운영 안내를 따름. 방식 A(발급 API 키): `~/.bashrc`에 환경 변수로 등록. 방식 B(계정 로그인): 프로젝트 폴더에서 `claude` 실행 시 브라우저 인증 창이 열림. 자동으로 안 열리면 터미널에 표시된 URL을 브라우저에 붙여넣기
## 막히는 지점
- `claude` 명령을 찾지 못하면 PATH 문제:
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```
- 인증 오류: 4단계 인증 절차 재수행, `claude doctor`로 상태 확인
- 키 실값은 어떤 파일에도 적지 않음(교안 보안 안내)
