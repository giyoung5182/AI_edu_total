# 2단계 — 대시보드 만들기 (20분)

정리일: 2026-10-08 · 교육 에셋 N1223

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
1단계 결과를 유형별 요청 프롬프트에 채워 단일 HTML 대시보드를 만들고 브라우저에서 엽니다.
## 진행 단계
1. **본인 유형의 프롬프트 고르기** — 집계형(숫자와 차트) / 점검형(통과·미통과와 조치 목록) / 조사형(발견과 출처) / 문서형(본문과 검토 결과). 모든 유형은 상단 요약 → 중단 본문 → 하단 목록 구조
- 입력할 내용(집계형 예시, 발췌):
```javascript
아래 내용으로 단일 HTML 파일 대시보드를 만들어줘.
[제목] / [상단 요약 카드 4개] / [중단 차트 2개] / [하단 표]
(이하 교안 참고)
```
2. **공통 조건 붙이기** — 디자인(흰 배경, 딥그린 주색, 주황 강조 하나, 1280px 기준), 기술(HTML 파일 하나, UTF-8 명시, 차트는 CDN 로드 실패 시 표로 대체, 작성일 표시), 금지(내가 준 내용 외 추가 금지, "확인 필요" 항목 임의 판단 금지)
3. **저장하고 열기** — 받은 코드를 메모장에 붙여넣기 → 파일명.html로 저장(UTF-8) → 더블클릭해 브라우저로 열기
- Work 기능을 쓰면 "이 코드를 대시보드.html 로 폴더에 저장해줘"로 더 간단히 가능
## 막히는 지점
- 교안에 별도 기재 없음(오류 대응은 3단계에 정리)
