# 4-6. 실습 — Gem 맛보기 (10분)

정리일: 2026-10-08 · 교육 에셋 N1096

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
교안의 Gem 미리보기 A(홍보글 & SNS 비서) 지침을 붙여넣어 나만의 Gem을 만들고 첫 대화를 테스트합니다. 3종 Gem 완성은 다음 회차(2차시)에 진행합니다.
## 진행 단계
1. **Gemini 접속 → Gems 열기** — 왼쪽 사이드바에서 "Gems"를 클릭합니다.
2. **새 Gem 만들기** — "+ 새 Gem 만들기"를 클릭합니다.
3. **지침 붙여넣기** — 교안의 Gem 미리보기 A(홍보글 비서)를 복사해 "요청사항" 칸에 붙여넣습니다. ROPE+K 구조(Role·Objective·Process·Example·Constraints)로 되어 있습니다.
4. **이름 입력** — `내 가게 홍보 비서`
5. **저장 후 첫 대화 테스트**
- 입력할 내용:
```plain text
안녕! 나를 소개해줘. 너는 어떤 걸 도와줄 수 있어?
```
## 막히는 지점
- Gem을 만들다 잘못되면 "요청사항" 칸을 고치고 저장하면 즉시 적용됨. 완벽하게 만들 필요 없이 쓰면서 다듬음
- AI가 만든 글은 가격·날짜·메뉴 이름 등 사실 정보를 반드시 확인 후 사용
