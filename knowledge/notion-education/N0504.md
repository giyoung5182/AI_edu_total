# 실습 3 — 품질 체크리스트 생성 및 문제 항목 검증하기

정리일: 2026-10-08 · 교육 에셋 N0504

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 2에서 만든 표의 품질 체크리스트를 Copilot으로 만들고, 문제 항목을 원본과 대조해 검증한다.
## 진행 단계
1. **체크리스트 요청** — 실습 2의 표 전체를 Copilot 채팅 창에 붙여넣은 후 프롬프트 입력
- 입력할 내용:
```javascript
위에서 만든 표를 기준으로 데이터 품질 체크리스트를 만들어줘.
확인 항목:
- 필수 컬럼(문서번호, 의뢰인, 접수일, 쟁점) 누락 여부
- 날짜 형식 불일치 여부
- 동일 의뢰인 중복 입력 여부
- "미확인" 항목이 몇 건인지
각 항목별 점검 결과를 ✅/⚠️/❌ 로 표시하고,
문제가 있는 경우 어느 행(문서번호)에서 발생했는지 명시해줘.
```
2. **문제 항목 찾기** — 출력된 체크리스트에서 ⚠️ 또는 ❌ 항목을 확인
3. **원본과 비교** — 표시된 항목을 실습 1 원본 샘플 문서와 직접 비교, 실제로 정보가 없는지 Copilot이 찾지 못한 것인지 판단
- 정상 결과: 누락값·중복·형식 오류 등이 표 형태의 체크리스트로 출력됨
## 막히는 지점
- 값이 있는데 누락으로 표시하거나, 중복이 아닌데 중복으로 잘못 판단하는 경우가 있음 → 체크리스트는 참고용, 원본과 직접 대조
