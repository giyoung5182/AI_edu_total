# 2. AI 사용 규칙
## 2-1. 지켜야 할 네 가지
**하나, 우리 정보를 구체적으로 줄 것**
- "포스터 만들어줘"로만 물으면 아무 데나 쓸 수 있는 뻔한 결과가 나옴
- 아이템, 가게 이름, 손님, 가격, 컬러까지 적어야 우리 팀 것이 나옴
**둘, 여러 개를 받아서 고를 것**
- 한 개만 달라고 하지 말고 3\~4개를 받은 뒤 팀원끼리 선택
- 마음에 안 들면 지워버리지 말고 "어떻게 고쳐달라"고 이어서 요청
**셋, 한글 글자를 한 자씩 읽어볼 것**
- AI가 만든 그림 안의 한글은 획이 빠지거나 없는 글자가 섞여 나오는 경우가 있음
- 받은 그림은 확대해서 글자를 한 자씩 확인
- 깨졌으면 아래처럼 다시 요청
```javascript
글자가 깨져서 나왔어. 글자만 정확한 한글로 다시 써서 만들어줘.
[정확한 글자를 다시 적어줄 것]
```
**넷, 가격과 정보는 우리가 줄 것**
- AI는 우리 가격이나 재료를 모름
- 비워두면 그럴듯한 숫자를 지어내므로 반드시 직접 입력
## 2-2. 팀 기본 정보 정리
프롬프트를 쓸 때마다 반복해서 들어가므로, 시작 전에 메모장에 한 번 적어두고 복사해서 사용
- 가게 이름:
- 파는 것(구체적으로):
- 손님:
- 가격:
- 주고 싶은 느낌:
- 메인 컬러 / 보조 컬러:

# 3. ① 로고 (20분)
## 3-1. 만드는 것
- 포장에 붙일 스티커와 부스 간판에 쓸 표시
- 정사각형 형태, 단순할수록 좋음
## 3-2. 프롬프트
```javascript
중학교 플리마켓에서 쓸 가게 로고를 만들어줘.

- 가게 이름: [이름]
- 파는 것: [아이템]
- 주고 싶은 느낌: [예: 귀여운 / 깔끔한 / 웃긴]
- 색: [메인 컬러]과 [보조 컬러]만 사용

조건은 이래.
- 가로세로 비율이 같은 정사각형
- 배경은 단색
- 가게 이름 "[이름]"을 정확한 한글로 크게 넣을 것
- 아주 작게 줄여도 알아볼 수 있을 만큼 단순할 것
- 그림은 1개만 넣을 것

서로 다른 스타일로 4개 만들어줘.
```

색을 두 가지만 써서 다시 만들어줘

더 귀엽게 / 더 깔끔하게 다시 만들어줘




글자가 깨짐

이름이 안 보임

가게 이름을 더 크게 키워줘

# 4. ② 제품 가상 이미지 (20분)
## 4-1. 만드는 것
- 손님이 "사고 싶다"고 느낄 만한 제품 사진
- 아직 실물이 없거나 사진이 예쁘게 안 찍힐 때 AI로 대신 만드는 것
- 메뉴판과 상품 안내판, 포스터에 모두 사용
## 4-2. 프롬프트
```javascript
제품 홍보용 사진을 만들어줘.

- 제품: [아이템을 아주 구체적으로]
- 포장 상태: [예: 투명 용기에 담겨 있음 / 비닐 봉투에 들어 있음]
- 분위기: [예: 밝고 깔끔하게 / 따뜻하고 감성적으로]

조건은 이래.
- 제품이 화면 가운데 크게 들어갈 것
- 배경은 단순할 것
- 글자는 넣지 말 것
- 실제 사진처럼 보일 것

서로 다른 구도로 3개 만들어줘.
```
- 이 이미지에는 글자를 넣지 않음. 제품만 보이면 됨
- 사진 느낌이 아니라 그림 느낌을 원하면 "실제 사진처럼" 대신 "귀여운 일러스트로"로 바꿈
## 4-3. 팀별 작성 요령





팀 유형

이렇게 적기




먹거리

어떤 재료가 보이는지, 어떤 그릇에 담기는지까지




향·화장품

용기 모양과 크기, 놓인 배경




문구·굿즈

안에 들어가는 물건들을 펼쳐놓은 모습


## 4-4. 확인
- 실제로 팔 물건과 너무 다르지 않은가
- 손님이 보고 샀는데 받은 것과 차이가 크면 항의를 받게 됨
- 지나치게 화려하면 오히려 신뢰가 떨어짐

# 5. ③ 가격표 (15분)
## 5-1. 만드는 것
- 부스 앞에 걸어 손님이 바로 읽는 표
- 가격표는 예쁜 것보다 **잘 읽히는 것**이 훨씬 중요
- 품목과 가격이 한눈에 들어와야 함
## 5-2. 프롬프트
```javascript
플리마켓 부스에 걸 가격표 이미지를 만들어줘.

- 가게 이름: [이름]
- 파는 것과 가격:
  [품목1] [가격]원
  [품목2] [가격]원
- 세트나 묶음 구성: [있으면 적기]
- 색: [메인 컬러]와 [보조 컬러]

조건은 이래.
- 세로로 긴 A4 비율
- 맨 위에 가게 이름, 그 아래에 품목과 가격을 표 형태로
- 위에 적어준 글자를 정확한 한글로 넣고, 다른 글자는 넣지 말 것
- 가격 숫자를 가장 크고 진하게
- 멀리서도 읽히게 글자를 크게

서로 다른 디자인으로 3개 만들어줘.
```
## 5-3. 고쳐달라고 말하는 법





상황

이렇게 요청




글자가 깨짐

글자만 정확한 한글로 다시 써줘




가격이 작음

가격 숫자를 더 크게 키워줘




품목이 빠짐

\[빠진 품목\]을 추가해줘




너무 복잡함

장식을 줄이고 글자가 잘 보이게 다시 만들어줘


## 5-4. 확인
- 품목과 가격이 빠짐없이 다 들어갔는가
- 숫자가 정확한가 (0 개수 확인)
- 재료리스트에 적은 최종 판매 가격과 같은가
- 2\~3걸음 떨어져서 봤을 때 읽히는가

## 6-3. 프롬프트

중학교 플리마켓 부스에 걸 홍보 포스터를 만들어줘.

- 가게 이름: [이름]
- 한 줄 소개: [슬로건]
- 파는 것: [아이템]
- 대표 가격: [가격]원
- 색: [메인 컬러]과 [보조 컬러]
- 느낌: [예: 귀여운 / 신나는 / 감성적인]

조건은 이래.
- 세로로 긴 포스터 비율
- 가게 이름을 맨 위에 가장 크게
- 위에 적어준 글자만 정확한 한글로 넣고, 다른 글자는 넣지 말 것
- 멀리서도 보이게 글자를 크게

서로 다른 디자인으로 3개 만들어줘.
