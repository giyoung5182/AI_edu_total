# 1.1 지금 AI를 어떻게 쓰고 계시나요? — 질문 ①~③ 체크인

정리일: 2026-10-08 · 교육 에셋 N0611

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지금 AI를 어떤 업무에 쓰는지, 결과물을 실무에 바로 썼는지, 업무 중 AI가 가장 필요한 곳이 어디인지 체크합니다(대화형 체크인).
## 진행 단계
1. **질문 ① — "지금 AI를 어떤 업무에 쓰고 계신가요?"** — 글쓰기·카피, 고객 DM 답변 초안, 콘텐츠 아이디어, 이미지 생성, 정보 검색·요약, 거의 쓰지 않음, 기타 중 체크
2. **질문 ② — "AI 결과물이 실제 업무에 바로 쓸 수 있었던 적이 얼마나 됐나요?"** — 자주 바로 썼다 / 절반 정도는 수정해 썼다 / 대부분 다시 직접 썼다 / 결과가 별로라서 직접 쓰는 게 낙다고 느꼈다 중 체크
3. **질문 ③ — "업무 중 AI가 가장 필요한 곳은 어디인가요?"** — 응답을 오늘 실습 챕터(Ch 2\~4)와 연결. 비어 있으면 실습이 막히니 지금 하나씩 정해 둡니다.
