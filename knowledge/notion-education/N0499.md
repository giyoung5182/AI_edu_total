# 활동 1 — 흩어진 여러 시트를 한 방에 통합하기

정리일: 2026-10-08 · 교육 에셋 N0499

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
라인별로 쪼개진 시트를 ChatGPT가 짜준 VBA 매크로 하나로 "통합" 시트에 합칩니다.
## 진행 단계
1. **파일 열기** — 실습 파일을 엽니다.
2. **ChatGPT 프롬프트** — 프롬프트를 붙여넣고 생성된 VBA 코드를 복사
- 입력할 내용: 비개발자임을 밝히고, 목표(1라인·2라인·3라인 시트의 생산 실적을 "통합" 새 시트에 합치기), 요구사항(헤더는 한 번만, 마지막 열에 시트 이름을 "출처 라인"으로 표시, 실행 후 통합된 행 수를 메시지로 알림), 어디에 붙여넣는지도 알려달라는 요청
3. **VBA 편집기** — \[개발도구\] → \[Visual Basic\] → \[삽입\] → \[모듈\]로 빈 코드 창을 만들고 붙여넣기 (단축키 Alt F11)
4. **실행** — F5(또는 실행 ▶ 버튼)
- 정상 결과: "통합" 시트가 새로 생기고 세 라인 데이터가 한 곳에 모임
5. **Padlet 업로드** — 통합 시트 결과 캡처 또는 내 어떤 작업에 쓰겠다를 올림
- 한 걸음 더: 요구사항을 내 업무 조건으로 바꿔 다시 요청(예: 월별 시트, 출처 표시를 부서명으로)
## 막히는 지점
- \[개발도구\] 탭이 안 보이면 \[파일\] → \[옵션\] → \[리본 사용자 지정\]에서 "개발 도구" 체크
- 회사 PC는 매크로 실행이 막혀 있을 수 있으니 보안 경고가 뜨면 IT팀에 매크로 사용 가능 여부 확인
- 실제 엑셀 파일을 통째로 ChatGPT에 올리지 말고 컬럼 구조와 조건만 말로 설명
