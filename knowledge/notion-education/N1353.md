# 실습 2. 품질 점검 SQL 자동화 쿼리 작성

---

## 이 실습으로 하는 것
반복 점검을 SQL 자동화 쿼리로 만든다. 설비 마스터 점검 쿼리를 직접 작성한다.
## 진행 단계
1. **통합 점검 쿼리 이해** — 열 사용량·민원 쿼리의 CASE WHEN 하나가 점검 항목 하나에 대응함을 확인한다. 결과값이 0이 아니면 오류가 있다는 신호.
2. **설비 마스터 점검 쿼리 작성** — 전체 건수 / facility_id NULL / facility_name NULL 또는 빈값 / facility_name 중복(서브쿼리) / region NULL 건수.
3. **월별 품질 추이 쿼리 확인** — DATE_FORMAT으로 월 단위 집계, 결측률(%) 계산.
