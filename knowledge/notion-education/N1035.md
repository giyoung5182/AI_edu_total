# 2-3. 응답 저장 기능 요청 프롬프트 (참고)

정리일: 2026-10-08 · 교육 에셋 N1035

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
게시한 앱에 학생 응답을 모아 보는 저장·집계 기능을 추가합니다. (오늘 타임테이블에는 별도 시간 없음, 시간이 되면 진행)
## 진행 단계
1. **게시 먼저** — 반드시 "게시 → 저장 기능 추가" 순서
2. **요청 프롬프트 입력**
- 입력할 내용:
```plain text
학생들의 응답을 모아서 볼 수 있게 만들어줘.

[기능]
- 각 문제별로 학생들이 어떤 보기를 골랐는지 집계
- 집계 결과를 막대그래프로 보여주는 화면을 따로 추가
- 집계 화면은 하단의 작은 버튼으로만 들어가게
- 전체 응답 수와 문제별 정답률도 표시

[기술 조건]
- 브라우저 localStorage는 절대 쓰지 마
- Artifacts의 공유 저장소(window.storage, shared 옵션)를 사용해줘
- 저장이 실패해도 앱이 멈추지 않게 예외 처리해줘
- 응답은 문제를 다 푼 시점에 한 번만 저장해줘
- 저장되는 데이터에 이름 같은 개인정보를 넣지 마

나머지 기능은 그대로 유지해줘.
```
- 정상 결과: 5문제를 다 풀면 딱 한 번 문제별 선택 보기 번호만 익명 저장, 화면 하단의 작은 📊 버튼으로 집계 화면(전체 응답 수·문제별 정답률·보기별 선택 인원 막대그래프) 진입
## 막히는 지점
- "window.storage"라고 정확한 이름을 주는 것이 핵심
- 공유 저장 앱을 처음 여는 사람에게는 "당신의 데이터가 다른 사용자에게 보입니다" 확인 창이 뜸
