# 🛠️ 실습 2 — 오늘 만들 도구 설계안 확정

정리일: 2026-10-08 · 교육 에셋 N1113

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
위임 매트릭스에서 ⭐ 1순위로 나온 업무 하나를 골라 S3\~S5에서 만들 도구의 설계안을 작성합니다.
## 진행 단계
1. **설계안 요청**
- 입력할 내용:
```javascript
내가 자동화하고 싶은 업무: [업무명 입력]

이 업무를 위한 AI 도구를 설계해줘.
다음 항목을 채워서:

① 도구 이름:
② 입력: 사용자가 뭘 넣는가?
③ 처리: AI가 어떤 방식으로 처리하는가?
④ 출력: 어떤 형태로 결과가 나오는가?
⑤ 예상 절감 시간: 회당 몇 분?
⑥ 주의사항: 사람이 반드시 검토해야 할 부분

Claude Code에서 파일 처리·문서 생성으로 끝낼 일인지,
Streamlit 대시보드 같은 앱으로 만들 일인지도 추천해줘.
```
2. **구현 가능성 체크**
- 입력할 내용:
```javascript
[위 설계안 붙여넣기]

이 설계가 실제로 구현 가능한지 체크해줘.
불가능하거나 너무 복잡한 부분이 있으면 단순화 방법 제안해줘.
```
