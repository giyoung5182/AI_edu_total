# 토큰 수 직접 확인 (한글 vs 영어)

정리일: 2026-10-08 · 교육 에셋 N0580

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 뜻의 한글·영어 문장이 몇 토큰으로 끊기는지 화면으로 확인합니다.
## 진행 단계
1. **토크나이저 화면 열기** — 새 탭(Ctrl+T) → 주소창에 [https://platform.openai.com/tokenizer](https://platform.openai.com/tokenizer) 붙여넣기 → Enter.
2. **두 문장을 하나씩 입력**
- 입력할 내용:
```javascript
우리 팀은 다음 주에 출장 정산 결과를 정리합니다
```
```javascript
Our team will organize the travel expense results next week
```
1. **Tokens 숫자 확인** — 입력칸 바로 아래 Tokens 숫자를 두 번 모두 확인(Characters는 보지 않음).
2. **기록** — 워크시트 Part1 시트 빈 곳 또는 메모장에 `한글 [ ]토큰 / 영어 [ ]토큰`.
- 교안 설명: 한글이 토큰을 더 많이 쓰는 경우가 많음. 이 화면은 모델마다 나누는 방식이 달라 경향을 보는 용도.
## 막히는 지점
- 화면이 로그인을 요구하거나 열리지 않으면 건너뛰고 강사 화면으로 확인.
