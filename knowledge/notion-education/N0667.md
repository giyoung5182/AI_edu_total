# 실습 3. 정제 전 집계와 "AI가 쓴 기준 되묻기" (향후 과제)

정리일: 2026-10-08 · 교육 에셋 N0667

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
부서 표기를 그대로 센 결과와 정리 후 결과를 비교하고, AI가 어떤 기준으로 세었는지 되물어 기록합니다.
## 진행 단계
1. **정제 전 그대로 세기** — 부서 열 값을 공백·표기 차이를 합치지 않고 코드로 인원수를 세게 합니다. 결과를 P3-3 정제 전 표에 기록합니다.
2. **AI가 쓴 기준 되묻기** — 대상 행 수, 제외 행, 빈칸 처리, 표기 통합, 번호 중복 행 처리를 항목별로 답하게 합니다(새 계산 금지). 답을 P3-3 되묻기 답변 칸에 기록합니다.
3. **표준 목록 정하기(AI 없이)** — 워드로 04 규정집을 열어 제3조에 적힌 부서 이름을 근거로 매핑을 P3-3에 적습니다.
4. **정제 후 재집계** — 매핑을 넣어 원본 부서 열은 그대로 두고 부서_표준 새 열을 만들어 다시 세게 합니다.
- 정상 결과: 정제 전·후 인원 합계가 같고, 원본 부서 열 옆에 부서_표준 열이 생김
## 막히는 지점
- 정제 전 표에서 이미 공백 표기가 합쳐져 나옴 → 공백 제거 없이 원본 값 그대로 다시 세고 따옴표로 감싸 출력하게 요청
- 원본 열을 덮어씀 / 공백 표기가 여전히 따로 셈 / 합계가 줄어듦 (교안에 수정 요청 문구 있음)
