# 1. 이 교육을 왜 받는가
## 영업관리부 미팅에서 직접 들은 말들
지난 미팅에서 이런 이야기들이 나왔습니다.
> *"라인 메신저 보면서 업무보고 엑셀을 씁니다. 오전에 한 번, 오후에 한 번. 매번 15\~20분씩 걸려요."*
> *"발주 채널이 이지포스, 카카오톡, 문자, 라인… 너무 많아서 하나하나 다 확인해야 합니다."*
> *"영수증 분류해서 차량유지비에 기입하고, 통장내역이랑 대조하는 것도 전부 눈으로 하나하나 해요."*
> *"ERP 재고 데이터 복사 붙여넣기, 출력, 냉장고 돌면서 실재고 체크… 하루에 두 번씩 합니다."*
> *"전체적으로 느껴지는 문제점은 사람 확인 의존도가 너무 높다는 거예요."*
→ 이 교육의 출발점입니다.

## 이 교육이 해결하려는 것
**핵심 문제 하나:**<br>이지포스·ERP·엑셀 3개 시스템이 분리된 채로 운영되고,<br>이를 연결하는 **모든 반복 작업을 사람이 수기로 처리하고 있습니다.**
이 교육은 그 반복 작업을 AI로 대체해서<br>**더 중요한 판단 업무에 집중할 수 있도록** 만드는 것이 목표입니다.

## 파트별 핵심 목표
### 🔷 파트 A — 실무 데이터 분석·자동화 (1\~5회차 · 약 25시간)
**목표:** 지금 매일 반복하는 수기 작업을 AI·자동화로 제거한다
- 1\~3회차: AI 도구(Claude·Gemini)로 텍스트·데이터·보고서 처리
- 4\~5회차: Make.com·GAS로 알림·취합·분류 완전 자동화
**파트 A 종료 후 변화:**
- 라인 메신저 → 업무보고: **15\~20분 → 40초**
- 미발주 매장 전화 독촉: **매일 반복 → 14:30 자동 알림**
- 야간 추가발주 모니터링: **직원 수동 확인 → 자동 취합**
---
### 🔷 파트 B — 디자인·마케팅·영상·인테리어 (6\~9회차 · 약 20시간)
**목표:** AI로 고품질 콘텐츠를 빠르게 만든다
- 6\~7회차: 이미지 생성·인테리어 시각화 (프로님 + 프로님 핵심)
- 8\~9회차: 홍보 영상·SNS 콘텐츠 자동화
**파트 B 종료 후 변화:**
- 홍보 포스터: 외주 또는 수동 제작 → **AI로 5분 완성**
- 인테리어 시안: 스케치업 도면 → **Gemini 렌더링 즉시 생성**
- SNS 콘텐츠: 즉흥 제작 → **1개월 캘린더 자동 설계**
---
### 🔷 파트 C — 업무 분석·컨설팅·결산 자동화 (10\~12회차 · 약 15시간)
**목표:** '도구 사용자'에서 '사내 AI 컨설턴트'로 성장한다
- 10회차: 다른 부서 업무도 AI 적용 가능성 직접 진단
- 11회차: 사무국 결산 자동화 직접 설계·구현·인수인계
- 12회차: 전체 결과물 사내 DB화 + 즉석 컨설팅 시뮬레이션
**파트 C 종료 후 변화:**
- "이 업무 AI로 될까?" → **스스로 진단하고 솔루션 설계**
- 사무국 결산 보고서: 수동 작성 → **자동 초안 생성 + 인수인계**

# 3. 교육이 더 잘 되려면 — 실제 업무 데이터 수집 방법
## 왜 실제 데이터가 필요한가
이 교육의 가장 큰 특징은 **가상 데이터가 아닌 교육기관의 실제 업무 데이터로 실습**한다는 것입니다.
영창 발주서 실물, 라인 메신저 실제 내용, 다이소 영수증 실물, 차량정비비 실제 엑셀 — 이것들이 1회차에서 쓰인 이유는 **교육이 끝나면 내일 당장 같은 방법으로 실제 업무에 쓸 수 있기 때문**입니다.
앞으로 남은 11회차도 마찬가지입니다. 실제 교육기관 데이터로 실습할수록 교육 효과가 높아지고, 강사가 더 맞춤형으로 설계할 수 있습니다.
---
## 데이터 수집 채널 2가지
### 채널 1. 회차 전 정기 요청 메일
**방식:**<br>각 회차 1주 전, 강사가 담당 창구(프로님 등)에게 이메일로 필요 자료 목록을 발송합니다.
**여러분이 하실 일:**
- 메일에 나온 자료 목록을 확인하고 가능한 것부터 준비
- 실제 금액·개인정보는 가려도 됩니다 (양식 구조만 있으면 충분, 단 그 양식으로 어떤 업무를 하는지에 대한 설명 필요)
- 준비 어려운 항목은 회신 메일로 미리 알려주세요 (대체 자료 강사가 준비)
**이미 받은 자료 예시 (1회차):**<br>영창 발주서 사진, 라인 메신저 캡처, 업무보고 엑셀 양식, 차량정비비 엑셀, 통장내역, 다이소 영수증, 원자재입고양식, 재고파악양식 — 이 모든 자료 덕분에 1회차 실습을 교육기관 맞춤형으로 할 수 있었습니다
