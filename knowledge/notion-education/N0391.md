# 실습 2 — 데이터 정제

정리일: 2026-10-08 · 교육 에셋 N0391

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 1에서 AI가 진단한 5가지 문제를 파워쿼리로 하나씩 치료하고 모든 조치를 적용된 단계로 남깁니다.
## 진행 단계
1. **준비** — 데이터 가져오기 → CSV → `heat_usage_2026_04_messy.csv` → \[데이터 변환\] → 우측 \[적용된 단계\]에서 '변경된 유형' 제거.
2. **문제1: 빈 행·중복 행 제거** — 홈 → 행 제거 → 빈 행 제거. 열 전체 선택(Ctrl+A) → 홈 → 행 제거 → 중복된 항목 제거.
- 정상 결과: 행 수가 66행 → 63행 → 60행.
3. **문제2: 공백 제거와 대소문자 통일** — 지역 열 우클릭 → 변환 → 공백 제거. 고객ID 열 우클릭 → 변환 → 대문자.
- 정상 결과: 지역 열 필터에서 분당이 하나만 보임.
4. (직접 풀어보기) 열사용량_Gcal을 숫자 타입으로: 열 머리글 타입 아이콘 → 10진수.
5. **문제3: 날짜 형식 통일** — `2026-04-17` / `2026.04.24` / `26년4월3일`이 섞인 사용일자 열을 하나의 날짜 타입으로 통일합니다.
- 정상 결과: 전체 60행, 사용일자 열에 날짜 아이콘, Error 0건.
6. **문제4: 조건 열** — 열 추가 → 조건 열 → 새 열 이름 `사용구분` → 열사용량_Gcal 크거나 같음 1500이면 `고사용`, 기타 `일반`.
- 정상 결과: 고사용 10건 / 일반 50건.
7. (직접 풀어보기) 사용일자 열 선택 → 열 추가 → 날짜 → 월 → 월.
8. **문제5: 예제의 열** — 열 추가 → 예제의 열 → 첫 행에 `C000120-분당` 입력 → Enter. 홈 → 닫기 및 로드.
## 막히는 지점
- 순서: 행 단위 오염 먼저, 값 정리, 타입 변환은 나중.
- 열에 Error 값이 가득하면 타입 변환 실패(형식 혼용): 타입 단계 삭제 → 값 통일 후 다시 타입.
- 한글이 깨지면 가져오기 창에서 파일 원본을 65001 UTF-8로.
