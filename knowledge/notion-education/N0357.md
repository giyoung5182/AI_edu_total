# 실습 · 같은 질문을 두 번 (5분)

정리일: 2026-10-08 · 교육 에셋 N0357

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 주제를 블록 없이(A) 한 번, RCTCK 블록을 채워서(B) 한 번 돌려 결과를 비교합니다.
## 진행 단계
1. **A — 블록 없이**
- 입력할 내용:
```javascript
[관심 분야] 시장 동향 알려줘
```
1. **B — 블록을 채워서**
- 입력할 내용: R 당신은 이 분야에서 10년간 실무를 해 온 기획자입니다. / C 저는 \[관심 분야\]에 제안을 하려 합니다. 기획 제안서의 배경으로 쓸 것입니다. / T 1) 최근 2년 변화 2) 수요가 느는 지점 세 가지를 알려 주세요. / C 국내, 최근 2년. 광고성 글은 제외. 표로 정리하고 출처 링크를 붙일 것. 확인되지 않은 수치는 만들지 마세요.
2. **비교** — 바로 쓸 수 있나 / 출처가 붙어 있나 / 다른 분야에 넣어도 말이 되나, 세 항목을 A·B 각각 확인합니다. 세 번째가 핵심입니다.
## 막히는 지점
- A는 분야 이름만 바꿔도 그대로 쓸 수 있을 텐데, 그러면 제안서의 근거가 못 됩니다.
