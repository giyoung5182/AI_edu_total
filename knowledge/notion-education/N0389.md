# 실습 3. 1회차 실행 — 정상 자료 (필수)

정리일: 2026-10-08 · 교육 에셋 N0389

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AGENTS.md가 준비되면 정상 자료(메일 20건 + 클레임이력 18건)로 첫 실행합니다. 이 1회차 결과가 다음 회차와 비교할 기준이 됩니다.
## 진행 단계
1. **새 작업 시작** — Work 새 작업(새 대화) 시작. 경로 A: 1회차 폴더만 허용 / 경로 B: 1회차의 파일 3개 첨부.
2. **한 줄 요청**
- 입력할 내용:
```plain text
AGENTS.md를 먼저 읽고 그대로 처리. 이번 회차 입력: 1회차(N = 1) — 01_출장실습데이터_통합.xlsx 「클레임이력」 시트, 02_고객문의메일_20건.txt
```
1. **승인 창 거부** — 원본 수정·삭제를 묻는 승인 창이 나오면 거부합니다.
2. **결과 저장** — 결과 파일을 1회차 폴더에 저장합니다.
## 막히는 지점
- 결과를 파일로 받을 수 없음: 표로 대화창에 출력하게 해 붙여넣어 같은 파일명으로 저장
- AGENTS.md 규칙을 따르지 않은 것 같음: 실행기록에서 읽었다는 문장 확인
