# 📌 필요한 것 2가지

# 🍎 Mac 사용자 가이드
## Step 1️⃣ Python 설치 확인 (30초)
### 1-1. 터미널 열기
```plain text
Cmd+Space (또는 Spotlight 열기)
→ "terminal" 입력
→ 첫 번째 Terminal 클릭
```
### 1-2. Python 버전 확인
```plain text
터미널에 입력:
python3 --version

그리고 Enter 누르기
```
### 1-3. 결과 확인
```plain text
【경우 1】이렇게 나타나면:
Python 3.9.x (또는 3.10 이상)

→ 성공! ✅
→ Step 2로 이동

【경우 2】이렇게 나타나면:
command not found: python3

→ 아직 설치 안 됨
→ 아래 1-4 설치 진행
```
### 1-4. Python 설치 (필요할 때만)
**방법 A: Homebrew 사용 (추천) - 가장 간단!**
```plain text
Step 1️⃣ 터미널에 입력:
/bin/bash -c "$(curl -fsSL [개별 링크 제외])"

그리고 Enter 누르기

Step 2️⃣ 암호 입력 화면이 나올 수 있음
Mac 로그인 암호 입력
(화면에 보이지 않지만 정상!)

Step 3️⃣ 설치 완료 기다리기
(3-5분 소요, 터미널이 여러 줄 출력)

Step 4️⃣ Homebrew 설치 완료 후
터미널에 입력:
brew install python3

Enter 누르기

Step 5️⃣ 설치 진행 중
(2-3분 소요)

Step 6️⃣ 설치 확인
터미널에 입력:
python3 --version

결과:
Python 3.11.x (또는 이상)
→ 성공! ✅
```
**방법 B: 공식 웹사이트에서 설치**
```plain text
Step 1️⃣ 웹브라우저 열기
[개별 링크 제외] 접속

Step 2️⃣ macOS 버튼 클릭
黄색 "Download Python 3.x.x" 버튼

Step 3️⃣ 파일 다운로드
다운로드 폴더에 파일 저장됨

Step 4️⃣ 설치 파일 실행
다운로드된 .pkg 파일 더블클릭

Step 5️⃣ 설치 진행
화면의 "다음" 버튼 계속 클릭

Step 6️⃣ 암호 입력
Mac 로그인 암호 입력

Step 7️⃣ 설치 완료 대기
(2-3분 소요)

Step 8️⃣ 터미널 재시작
완전히 닫았다가 다시 열기

Step 9️⃣ 설치 확인
터미널에 입력:
python3 --version

결과:
Python 3.9.x 이상
→ 성공! ✅
```
---
## Step 2️⃣ VS Code 설치 (2분)
### 2-1. VS Code 설치 확인
```plain text
Applications 폴더 확인
(Finder → Applications)

Visual Studio Code 파일이 있나?

【있으면】
더블클릭으로 실행 → OK! ✅

【없으면】
아래 2-2 설치 진행
```
### 2-2. VS Code 설치 (없을 때만)
```plain text
Step 1️⃣ 웹브라우저 열기
[개별 링크 제외] 접속

Step 2️⃣ Mac 버튼 클릭
"Download for Mac" 버튼

Step 3️⃣ Apple Silicon vs Intel 선택
→ 최신 Mac (M1/M2/M3): Apple Silicon
→ 구형 Mac (2015 이전): Intel

❓ 어느 것인지 모르면:
메뉴 → Apple 로고 → About This Mac
"Chip" 또는 "Processor"로 확인

Step 4️⃣ 파일 다운로드
다운로드 폴더에 파일 저장됨

Step 5️⃣ 파일 압축 해제
다운로드된 zip 파일 더블클릭
(자동으로 해제됨)

Step 6️⃣ Applications 폴더로 이동
Finder → Applications 폴더 열기
VS Code 파일을 그곳으로 드래그

Step 7️⃣ VS Code 실행
Applications에서 Visual Studio Code 더블클릭
(처음 실행 시 암호 입력 필요할 수 있음)

Step 8️⃣ 첫 실행 설정 완료
"Extensions" 탭 보이면 설치 성공! ✅
```

### 1-4. Python 설치 (필요할 때만)
```plain text
Step 1️⃣ 웹브라우저 열기
[개별 링크 제외] 접속

Step 2️⃣ Windows 버튼 클릭
"Download Python 3.x.x for Windows" 클릭

(최신 버전 자동으로 제시됨)

Step 3️⃣ 파일 다운로드
"python-3.x.x-amd64.exe" 파일 다운로드

Step 4️⃣ 설치 파일 실행
다운로드 폴더에서 더블클릭

Step 5️⃣ 설치 시작 화면
⚠️ 매우 중요!!

【반드시 체크】
하단의 체크박스:
"Add Python 3.x to PATH" ✓

(이것을 안 하면 나중에 오류 발생!)

Step 6️⃣ "Install Now" 클릭
자동으로 설치 진행 (2-3분)

Step 7️⃣ 설치 완료 화면
"Setup was successful" 메시지
→ Close 클릭

Step 8️⃣ 설치 확인
Command Prompt를 새로 열기
(기존 창 닫았다가 다시 열기)

터미널에 입력:
python --version

결과:
Python 3.9.x 이상
→ 성공! ✅
```

# ⚠️ 자주 묻는 문제
## Q1. "Python을 설치했는데 계속 command not found가 나와요"
```plain text
해결:
【Mac】
- 터미널을 완전히 닫았다가 다시 열어보기
- 터미널 재시작이 필요할 수 있음

【Windows】
- Command Prompt를 완전히 닫았다가 다시 열기
- 설치할 때 "Add Python to PATH" 체크했는지 확인
- 안 했으면 Python 다시 설치 (이번엔 체크!)
```
## Q2. "VS Code에서 폴더를 열 수 없어요"
```plain text
해결:
File → Open Folder
→ 원하는 폴더 선택
→ Open 클릭

(드래그 앤 드롭도 가능)
```
## Q3. "설치 중에 암호를 묻는데 뭘 입력해야 하나요?"
```plain text
해결:
Mac 로그인할 때 사용하는 암호를 입력하세요
(입력해도 화면에 보이지 않지만 정상입니다)
```
