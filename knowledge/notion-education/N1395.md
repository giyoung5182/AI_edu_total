# 실습 3. 채팅방에 검색을 연결하기

정리일: 2026-10-08 · 교육 에셋 N1395

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
채팅방이 하이브리드 검색 결과를 근거로 답하게 만들고, 토글 하나로 일반 지식 답변과 문서 근거 답변을 비교합니다.
## 진행 단계
1. **프롬프트 입력, 서버 재시작, 채팅 페이지 열기**
- 입력할 내용:
```plain text
채팅 페이지에 문서 근거 기반 대화를 추가해 주세요. 요구사항입니다.

1. 채팅 페이지에 [지식 기반 답변 모드] 토글 버튼을 추가해 주세요.
   아래는 토글이 켜졌을 때의 동작입니다.

2. 질문이 들어오면 하이브리드 검색으로 상위 K개(기본 3) 청크를
   찾은 뒤, 청크를 근거로 포함한 프롬프트를 조립해
   Gemini(gemini-2.5-flash)에 보내 주세요.

3. 프롬프트에는 다음 지시를 포함해 주세요.
   - 근거만 사용해 답할 것
   - 근거에 없는 내용은 "문서에서 확인되지 않습니다"라고 답할 것
   - 답변 끝에 사용한 근거의 청크 번호를 표기할 것
   기존의 채팅방 말투 지시는 그대로 유지해 주세요.

4. 답변 말풍선 아래에 근거 청크 목록을 작게 표시해 주세요.
   청크 번호와 출처 문서명이 보이고, 누르면 청크 원문이
   펼쳐지게 해 주세요.

5. 서버 로그에 질문 수신 → 검색 완료(청크 번호들) →
   Gemini 호출 → 응답 반환이 순서대로 출력되게 해 주세요.
```
1. **\[지식 기반 답변 모드\] 켜기**
2. **준비 질문 A를 채팅방에 그대로 묻기**
3. **근거 확인** — 답변 아래 근거 청크 번호를 누르고 원문 펼치기
4. **대조** — 답변의 문장과 청크 원문을 한 줄씩 대조. 답변 내용이 실제로 근거 안에 있으면 성공
5. **문서에 없는 질문** — 예: "달에서 지진이 나면?", "10년 뒤 주가는?" 등을 던져 "문서에서 확인되지 않습니다" 계열의 답이 오는지 확인
6. **토글 끄고 비교** — 같은 질문을 다시 던져 일반 지식 답변과 문서 근거 답변을 나란히 비교
7. **자유 질문** — 내 문서에 궁금했던 것을 묻고 답변마다 근거 번호가 붙는지 확인
## 막히는 지점
- 근거 번호가 안 붙음: Claude Code에 "답변에 청크 번호 표기가 빠집니다. 프롬프트를 점검해 주세요"라고 요청
- 문서에 없는 내용을 그럴듯하게 답함: "근거에 없으면 모른다고 답하도록 지시를 강화해 주세요"라고 요청
- 답변이 느려짐: 정상 범위(검색·프롬프트 조립 단계 추가). 터미널 B 로그에서 어느 단계가 오래 걸리는지 확인
- 말투가 딱딱해짐: "지식 기반 모드에서도 기존 말투 지시가 유지되게 해 주세요"라고 요청
