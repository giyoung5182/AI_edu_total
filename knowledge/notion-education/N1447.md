# 3. 대시보드 만들기 — AI에게 일을 시키는 3단계 프로세스

정리일: 2026-10-08 · 교육 에셋 N1447

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
방산 산업 프로젝트 CSV 데이터를 바탕으로, HTML 하나로 동작하는 반응형 웹 대시보드를 AI에게 만들게 한다.
## 진행 단계
1. **STEP 1. 역할 부여하고 데이터 주입하기** — ChatGPT나 Gemini를 켜고 데이터 파일을 업로드하거나 일부를 붙여넣는다.
- 입력할 내용:
```javascript
너는 지금부터 세계 최고의 프론트엔드 개발자이자 데이터 분석가야.
내가 업로드한 '방산 산업 프로젝트 데이터'를 바탕으로
HTML 파일 형태의 대시보드 코드를 작성해줘.
디자인은 모던하고 깔끔한 다크 모드 스타일로 부탁해.
```
1. **STEP 2. 구체적인 시각화 요구하기** — 차트 3가지(지역별 프로젝트 수 Bar, 사업분야별 예상계약금액 비중 Doughnut, 고객등급별 평균 수주확률 Bar)와 KPI 카드 4개, 필터 드롭다운(지역, 사업분야, 프로젝트단계)를 Chart.js로 요청한다.
- 입력할 내용:
```javascript
데이터를 분석해서 다음 3가지 차트를 Chart.js 라이브러리를 사용해 그려줘.
1. `지역` 컬럼을 활용한 지역별 프로젝트 수 (Bar Chart)
2. `사업분야`별 `예상계약금액(억원)`의 합계 비율 (Doughnut Chart)
3. `고객등급`에 따른 `수주확률(%)` 평균 (Bar Chart)
(이하 교안 참고)
```
1. **결과 확인** — 교안의 결과예시 화면과 비교한다.
