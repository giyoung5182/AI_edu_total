# AI 원리 실험소 — 실습 화면에서 확인 (15분)

정리일: 2026-10-08 · 교육 에셋 N0675

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Step 03까지의 설명을 직접 눌러보며 확인하는 실험 화면(AI 원리 실험소) 5개 탭을 순서대로 실행합니다.
## 진행 단계
1. **링크 열기** — Claude에 로그인한 상태에서 교안의 실험소 공유 링크를 새 탭에서 엽니다(로그인하지 않으면 AI 기능이 동작하지 않음).
2. **내 것으로 복제** — 오른쪽 위 공유 → Copy(복제). 링크로 연 화면은 보기만 되고 AI 기능은 꺼져 있고, Copy하면 내 계정 화면이 되어 AI가 켜지며 사용량은 내 계정에서 나갑니다.
3. **AI 기능 확인** — 실험1 \[내 문장으로 직접\]에 `이번 리뉴얼의 목표는` 같은 문장을 쓰고 \[다음 후보 뽑기\]를 눌러 Claude 사용 허용을 켭니다.
4. **탭 5개 순서대로** — ① 다음 말 고르기(3분) / ② 컨텍스트 윈도우(4분) / ③ 할루시네이션(3분) / ④ 새 대화로 옮기기(5분) / ⑤ 정리 퀴즈(3분, 열한 문항).
- 정상 결과: 맨 위 후보만 계속 고르면 어떤 문장이 되는지, 앞에서 정한 규칙이 어떻게 밀려나는지 등을 탭별로 확인.
## 막히는 지점
- Copy하지 않으면 AI 기능이 꺼져 있음. 눌렀을 때 Claude 사용 허용을 켜야 함.
