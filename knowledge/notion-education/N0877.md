# 1. 프로님 시나리오 — 강사 실습
## 시나리오 A: Watch Rows → Gmail
### 테스트용 시트 만들기
```plain text
구글 시트 새 파일 생성 → 시트명: 요청관리_테스트

열 구성:
A열 헤더: 타임스탬프
B열 헤더: 매장명
C열 헤더: 요청유형
D열 헤더: 플랫폼
E열 헤더: 상세내용
G열 헤더: 요청자
H열 헤더: 연락처
I열 헤더: 처리상태
```
### 실습 순서
**1단계: 새 시나리오 생성**
```plain text
make.com → Scenarios → Create a new scenario
```
**2단계: Google Sheets Watch Rows**
```plain text
[+] → "google sheets" 검색 → Watch Rows

Connection: 본인 구글 계정
Spreadsheet: 방금 만든 테스트 시트
Sheet: 요청관리_테스트
Where to start: All new rows
Limit: 1
[OK]

⚠️ 막히는 포인트 1:
  파일 검색이 안 될 경우
  → Spreadsheet 드롭다운 맨 아래 "Enter a Spreadsheet ID" 선택
  → 파일 URL에서 /spreadsheets/d/ 뒤 ID 복사해서 붙여넣기
```
**3단계: Gmail Send an Email**
```plain text
Watch Rows 오른쪽 [+] → Gmail → Send an Email

Connection: 본인 구글 계정 (Watch Rows와 동일)
To: 본인 이메일 주소
Subject: "[테스트] " + B열 변수 + " / " + C열 변수
Content: 원하는 형태로 B~I열 변수 삽입

⚠️ 막히는 포인트 2: 변수 삽입
  Content 입력창 클릭 → 커서 위치
  → 입력창 오른쪽 또는 하단에 드롭다운 트리거 아이콘
  → 클릭하면 이전 모듈(Watch Rows)의 열들이 보임
  → "1. Google Sheets > Row > B" 같은 형태로 선택
  → {{1.B}} 또는 비슷한 형태로 삽입됨
```
**4단계: Run once + 테스트**
```plain text
[Save] → [Run once] → "Waiting for data..." 상태

→ 구글 시트에서 새 행 추가:
  B열: 강남점 / C열: 사진교체 / D열: 네이버 /
  E열: 메인사진 교체 요청 / G열: 프로님 / H열: [연락처 비공개] / I열: 미처리

→ Make 화면 자동으로 실행됨
→ 본인 이메일 수신 확인

⚠️ 막히는 포인트 3: "Waiting for data..."가 안 끝날 경우
  → Make 페이지 새로고침 → [Run once] 다시 클릭
  → 시트에 새 행 추가 → 1~2분 대기
```
**5단계: 토글 ON**
```plain text
정상 확인 후 → 오른쪽 상단 토글 → Active(파란색)
```

## 시나리오 B: Schedule → Search Rows → Iterator → Text Aggregator → Gmail
**강사 선행 학습 포인트:**<br>Iterator와 Text Aggregator는 처음 접하면 헷갈립니다. 아래 실습 전에 개념을 완전히 이해하고 시작하세요.
```plain text
핵심 개념:
Search Rows = 여러 행을 한꺼번에 가져옴 (배열)
Iterator = 그 배열을 하나씩 꺼냄 (반복 처리)
Text Aggregator = 반복 처리된 것을 다시 하나로 합침

이 3개를 연결하면:
여러 행 → 하나씩 꺼냄 → 한 텍스트로 합침 → 이메일 1개
```
### 테스트 데이터 준비
```plain text
위 테스트 시트의 I열(처리상태)에 "미처리"가 있는 행 3개 추가:
  행 2: 강남점 / 사진교체 / 네이버 / ... / 미처리
  행 3: 홍대점 / 영업시간 / 카카오맵 / ... / 미처리
  행 4: 신촌점 / 정보수정 / 네이버 / ... / 미처리

처리완료 행도 1개 추가 (필터 테스트용):
  행 5: 종로점 / 전화번호 / 구글맵 / ... / 처리완료
```
### 실습 순서
**1단계: 새 시나리오 생성**
```plain text
[Create a new scenario]
```
**2단계: Schedule 트리거**
```plain text
[+] → Schedule → Run a scenario
Every week / Monday / 09:00 / Asia/Seoul
[OK]

실습 팁: 테스트 시에는 Every day로 설정 후 나중에 매주로 변경
```
**3단계: Search Rows**
```plain text
Schedule 오른쪽 [+] → Google Sheets → Search Rows

Spreadsheet: 테스트 시트
Sheet: 요청관리_테스트
Filter:
  Column: I
  Condition: Equal to
  Value: 미처리
Limit: 100
[OK]

테스트: [Run once] → 초록 체크 확인 → 모듈 클릭 → 몇 건 조회됐는지 확인
```
**4단계: Iterator**
```plain text
Search Rows 오른쪽 [+] → Tools → Iterator
(검색: "iterator")

Array: 드롭다운 → "2. Google Sheets > Rows" 선택
[OK]

⚠️ 막히는 포인트:
  드롭다운에 "Rows"가 안 보이는 경우
  → Search Rows 모듈을 먼저 [Run once]로 실행해서 데이터가 있어야
    Iterator가 배열을 인식함
  → Search Rows 먼저 실행 → 그다음 Iterator 설정
```
**5단계: Text Aggregator**
```plain text
Iterator 오른쪽 [+] → Tools → Text aggregator
(검색: "text aggregator")

Source Module: "3. Iterator" 선택

Text: (타이핑 + 드롭다운 조합)
  "▶ " 타이핑 →
  드롭다운에서 B열 선택 (매장명) →
  " / " →
  드롭다운에서 C열 선택 (요청유형) →
  " / " →
  드롭다운에서 A열 선택 (타임스탬프)

Row separator: \n
[OK]

⚠️ 막히는 포인트:
  드롭다운에서 "3. Iterator" 또는 열 변수가 안 보이는 경우
  → Run once로 Iterator까지 실행 후 다시 시도
  → 또는 Text 입력창 클릭 후 오른쪽 작은 아이콘 클릭
```
**6단계: Gmail**
```plain text
Text Aggregator 오른쪽 [+] → Gmail → Send an Email

To: 본인 이메일
Subject: "[테스트] 주간 미처리 현황"
Content:
  "안녕하세요. 이번 주 미처리 요청 목록입니다.\n\n" →
  드롭다운에서 "5. Text aggregator > Text" 선택 →
  "\n\n처리 부탁드립니다."
[OK]
```
**7단계: 전체 Run once 테스트**
```plain text
[Run once] → 이메일 수신 확인
이메일 본문에 3개 항목이 줄바꿈으로 나열되면 성공:

예상 이메일 본문:
  안녕하세요. 이번 주 미처리 요청 목록입니다.

  ▶ 강남점 / 사진교체 / 2026-06-29
  ▶ 홍대점 / 영업시간 / 2026-06-28
  ▶ 신촌점 / 정보수정 / 2026-06-27

  처리 부탁드립니다.
```

# 2. 프로님 시나리오 — 강사 실습
## 사전 준비: 텔레그램 봇 만들기
```plain text
STEP 1. 텔레그램 앱 → @BotFather 검색 → 시작
STEP 2. /newbot 입력
STEP 3. 봇 표시 이름: JJDDTestBot
[개별 아이디 제외 — 본인 계정으로 준비하세요.]
STEP 5. Bot Token 메모장에 복사
  예: 7281234567:AAFkL9mz...

STEP 6. 본인 텔레그램에 새 그룹 채팅방 만들기
  → 본인 계정 + 봇 초대
  → 채팅방 이름: 교육기관 발주 테스트

STEP 7. Chat ID 확인
  브라우저에서:
  [개별 링크 제외]
  → 결과에서 "chat":{"id": -123456789} 부분 복사
  → ⚠️ 그룹 채팅방 ID는 음수(-)로 시작하는 것이 정상
```
## Watch Rows + Router + 텔레그램 실습
### 테스트 시트 준비
```plain text
구글 시트 새 파일: 발주렌탈_테스트

A열: 입력일시
B열: 유형 (발주 또는 렌탈)
C열: 품목명
D열: 수량
E열: 거래처 (발주용)
F열: 입고예정일 (발주용)
G열: 매장명 (렌탈용)
H열: 출고예정일 (렌탈용)
```
### 실습 순서
**1단계: 새 시나리오 + Watch Rows**
```plain text
[+] → Google Sheets → Watch Rows
Spreadsheet: 발주렌탈_테스트
Where to start: All new rows
Limit: 1
[OK]
```
**2단계: Router 추가**
```plain text
Watch Rows 오른쪽 [+] → Flow Control → Router
→ 캔버스에 Router 모듈 생성
→ 두 개의 빈 브랜치(경로)가 나타남
```
**3단계: 브랜치 1 — 발주 Filter**
```plain text
브랜치 1 경로의 선 위에 있는 [렌치] 아이콘 클릭
→ "Set up a filter" 클릭

Label: 발주
Condition:
  첫 번째: 드롭다운 → B열(유형) 선택
  두 번째: Text > Equal to
  세 번째: 발주
[OK]
```
**4단계: 브랜치 1 끝에 Telegram**
```plain text
브랜치 1 경로 [+] → Telegram Bot → Send a Message

Connection:
  [Add] → Bot Token 입력 → [Save]

Chat ID: 준비 단계에서 확인한 숫자 입력

Text:
  "📦 [발주 테스트]\n▶ 품목: " →
  드롭다운에서 C열 선택 →
  "\n▶ 수량: " → D열 선택 →
  "\n▶ 거래처: " → E열 선택 →
  "\n▶ 입고예정일: " → F열 선택
[OK]

⚠️ 막히는 포인트: Connection 오류
  → Telegram Bot 앱 연결 시
    Bot Token을 입력하면 바로 연결됨
    OAuth 같은 별도 인증 없음
  → Token 형식: 숫자:영문숫자 혼합 (콜론 포함 전체 복사)
```
**5단계: 브랜치 2 — 렌탈 Filter + Telegram**
```plain text
Router의 두 번째 브랜치 렌치 아이콘 → Filter
  Label: 렌탈
  Condition: B열 = 렌탈

브랜치 2 [+] → Telegram → Send a Message
  Chat ID: 동일
  Text: "🔄 [렌탈 테스트]\n▶ 매장: " + G열 + "\n▶ 품목: " + C열 +
        " " + D열 + "\n▶ 출고예정일: " + H열
```
**6단계: 테스트**
```plain text
[Save] → 토글 ON
시트에 발주 행 추가:
  B열: 발주 / C열: 테스트상품 / D열: 10 / E열: 테스트거래처 / F열: 2026-07-01

→ 1~2분 내 텔레그램 메시지 수신 확인

렌탈 행도 추가해서 브랜치 2 테스트:
  B열: 렌탈 / G열: 테스트매장 / C열: 렌탈상품 / D열: 5 / H열: 2026-07-02

→ 다른 내용의 텔레그램 메시지 수신 확인
```

# 3. 프로님 시나리오 — 강사 실습
## Custom Webhook + Search Rows + Router 3분기 + Update Row
### 테스트 시트 준비
```plain text
구글 시트 새 파일: 휴무테스트

A열: 해당날짜
B열: 삭제직원명
C열: 삭제직원이메일
D열: 추가직원명
E열: 추가직원이메일
F열: 관리자이메일
G열: 관리자체크 (TRUE 또는 FALSE)
H열: 변경사유
I열: 발송여부 (대기 또는 발송완료)

테스트 데이터 1행 추가:
A: 2026-07-01 / B: 프로님 / C: [이메일 비공개] /
D: 김철수 / E: [이메일 비공개] /
F: [이메일 비공개] / G: TRUE / H: 개인 사정 / I: 대기
```
### 실습 순서
**1단계: 새 시나리오 + Custom Webhook**
```plain text
[+] → Webhooks → Custom Webhook

Webhook name: 휴무테스트
[Add] 클릭
→ Webhook URL 생성됨 → 메모장에 복사
[OK]

화면에 "Waiting for data..." 표시
```
**2단계: 테스트 데이터 전송 (Webhook 연결 확인)**
```plain text
실제 수업에서는 GAS 버튼으로 전송하지만
강사 사전 실습에서는 Postman 또는 브라우저로 테스트:

방법 A: 브라우저 주소창에 아래 입력
  Webhook URL 뒤에 ?test=1 추가해서 접속
  (GET 방식 간단 테스트)

방법 B: Make.com 테스트 기능 활용
  Custom Webhook 설정창 → "Redetermine data structure" 클릭
  → 샘플 데이터 JSON 입력창이 나타남
  → 아래 JSON 붙여넣기:
  {
    "date": "2026-07-01",
    "trigger": "manual"
  }
  → [Save] 클릭 → 데이터 구조 인식됨

⚠️ 핵심:
  실제 수업에서는 GAS 버튼이 Webhook URL을 호출함
  강사 실습에서는 임시 방법으로 연결 확인
```
**3단계: Search Rows**
```plain text
Webhook 오른쪽 [+] → Google Sheets → Search Rows

Spreadsheet: 휴무테스트
Sheet: Sheet1
Filter:
  Column: I
  Condition: Equal to
  Value: 대기
Limit: 100
[OK]
```
**4단계: Router (3 브랜치)**
```plain text
Search Rows 오른쪽 [+] → Flow Control → Router
→ 기본 2개 브랜치 생성됨
→ 세 번째 브랜치 추가: Router 모듈 클릭 → + Add route
```
**5단계: 브랜치 1 — 관리자**
```plain text
렌치 아이콘 → Filter:
  Label: 관리자
  G열(관리자체크) = TRUE

[+] → Gmail → Send an Email:
  To: 드롭다운 → G열 또는 F열(관리자이메일) 선택
  Subject: "[휴무변경알림] 관리자 확인"
  Content:
    "관리자 알림\n해당날짜: " + A열 +
    "\n취소: " + B열 +
    "\n추가: " + D열
```
**6단계: 브랜치 2 — 취소 당사자**
```plain text
렌치 아이콘 → Filter:
  Label: 취소당사자
  C열(삭제직원이메일) > Is not empty

[+] → Gmail:
  To: C열 선택 (삭제직원이메일)
  Subject: "[교육기관] 휴무 취소 안내"
  Content: A열 + " 휴무가 취소되었습니다. 출근 부탁드립니다."
```
**7단계: 브랜치 3 — 추가 당사자**
```plain text
렌치 아이콘 → Filter:
  Label: 추가당사자
  E열(추가직원이메일) > Is not empty

[+] → Gmail:
  To: E열 선택 (추가직원이메일)
  Subject: "[교육기관] 휴무 추가 안내"
  Content: A열 + " 휴무로 변경되었습니다."
```
**8단계: Update Row — 발송여부 업데이트**
```plain text
각 브랜치 Gmail 다음에 추가:
[+] → Google Sheets → Update a Row

⚠️ 막히는 포인트: Row number 설정
  Row number = 어떤 행을 업데이트할지 지정
  → 드롭다운에서 Search Rows 모듈의 Row number 변수 선택
    (예: "2. Google Sheets > Row > Row Number")
  → 이 변수를 선택해야 해당 행이 업데이트됨

Values:
  I열(발송여부): "발송완료" 직접 입력
  (추가 열이 있다면) J열(발송일시): now() 함수 또는 {{now}} 변수
[OK]
```
**9단계: 전체 테스트**
```plain text
[Save]
→ [Run once] 클릭 → "Waiting for data..."
→ 테스트 데이터를 Webhook으로 전송 (방법 A 또는 B)

확인:
  1. 관리자 이메일 수신 확인
  2. 삭제직원 이메일 수신 확인
  3. 추가직원 이메일 수신 확인
  4. 시트에서 I열이 "발송완료"로 바뀐 것 확인

⚠️ 브랜치별로 이메일이 다르게 와야 정상
   같은 내용이 3번 오면 Filter 조건이 잘못된 것
```

# 4. 프로님 시나리오 — 강사 실습
## Schedule + Get a Range + Iterator + Text Aggregator + Gmail
### 테스트 시트 준비
```plain text
구글 시트 새 파일: 차량정비테스트

시트명: 합계테스트

데이터 예시:
  A열: 업체명    B열: 금액
  A2: 바른자동차  B2: 1200000
  A3: 신속카센터  B3: 850000
  A4: 든든정비소  B4: 2300000
  A5: 빠른서비스  B5: 650000
  A6: 전문카닥터  B6: 1900000

→ B열 합계 금액이 200만원 초과인 업체: 든든정비소, 전문카닥터
```
### 실습 순서
**1단계: 새 시나리오 + Schedule**
```plain text
[+] → Schedule

테스트용 설정: Every day / 09:00 (실제는 Every month / Day:28)
Timezone: Asia/Seoul
[OK]
```
**2단계: Get a Range**
```plain text
Schedule 오른쪽 [+] → Google Sheets → Get a Range

Spreadsheet: 차량정비테스트
Sheet: 합계테스트
Range: A2:B6
  (업체명과 금액이 있는 범위 — 헤더 행 제외)
Value render option: Formatted value
[OK]

⚠️ 막히는 포인트:
  Range를 어떻게 입력하는지 헷갈릴 수 있음
  → 항상 "시트명!셀범위" 또는 그냥 "A2:B6" 형식
  → 시트명이 한글이면 '합계테스트'!A2:B6 형식 필요할 수 있음
```
**3단계: Iterator**
```plain text
Get a Range 오른쪽 [+] → Tools → Iterator

Array: 드롭다운 → "2. Google Sheets > Data" 또는 "Rows" 선택
[OK]
```
**4단계: Text Aggregator**
```plain text
Iterator 오른쪽 [+] → Tools → Text aggregator

Source Module: "3. Iterator" 선택

Text: (핵심 부분 — 200만원 초과 표시 포함)
  드롭다운에서 A열(업체명) 선택 →
  ": " →
  드롭다운에서 B열(금액) 선택 →
  "원"

Row separator: \n
[OK]

⚠️ 200만원 초과 강조 표시:
  이 단계에서 조건부 텍스트를 넣기는 복잡함
  → 간단 방법: 이메일 본문에 "※ 200만원 초과 업체를 별도 확인해주세요" 추가
  → 복잡 방법: Filter 분기 추가 (수업 시간 내 어려울 수 있음)
  → 수업에서는 간단 방법 채택 권장
```
**5단계: Gmail**
```plain text
Text Aggregator 오른쪽 [+] → Gmail → Send an Email

To: 본인 이메일 (수업에서는 프로님, 부장 이메일)
Subject: "[테스트] 차량 정비비 월간 현황"
Content:
  "안녕하세요.\n이번 달 차량 정비비 지출 현황입니다.\n\n" →
  드롭다운에서 "5. Text aggregator > Text" 선택 →
  "\n\n※ 200만원 초과 업체는 별도 검토 바랍니다.\n자동 발송"
[OK]
```
**6단계: 테스트**
```plain text
[Save] → [Run once]

수신 이메일 확인:
  바른자동차: 1200000원
  신속카센터: 850000원
  든든정비소: 2300000원
  빠른서비스: 650000원
  전문카닥터: 1900000원

이렇게 목록이 들어오면 성공
```
