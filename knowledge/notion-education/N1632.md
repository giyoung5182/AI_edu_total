<summary>**☑️ 데이터란 무엇인가요?**</summary>
데이터는 업무 과정에서 발생하는 사실, 기록, 관찰 결과, 측정값, 문서, 이미지 등을 의미합니다.

- 단점: 비정형 데이터는 자유로운 형식 때문에 바로 분석하기 어렵습니다. 문서 제목, 작성일, 작성부서, 키워드, 관련 업무 같은 메타데이터가 없으면 검색과 관리가 어려워집니다.

## 02. 데이터 생성·저장·활용 흐름

**데이터 라이프 사이클을 살펴봅니다. **

<details>
<summary>**☑️ 데이터 흐름을 이해해야 하는 이유**</summary>
데이터 활용이 잘되지 않는 이유는 분석 도구가 부족해서만은 아닙니다.
데이터가 처음 만들어지는 방식, 저장되는 위치, 관리 기준, 활용 목적이 명확하지 않기 때문인 경우가
많습니다. 데이터 흐름을 이해하면 다음 질문에 답할 수 있습니다.
- 이 데이터는 어느 업무에서 만들어졌나요?
- 누가 입력했나요?
- 어떤 시스템에 저장되나요?
- 어떤 기준으로 가공되나요?
- 어떤 보고서나 분석에 활용되나요?
- 오류가 발생하면 어느 단계에서 수정해야 하나요?

**데이터 라이프 사이클을 살펴보겠습니다.**
[원본 이미지 제외]


**각 단계는 독립적으로 존재하지 않습니다. 앞 단계에서 오류가 발생하면 뒤 단계의 활용 품질에도 영향**
**을 주게 됩니다. **
```json
업무 발생
→ 데이터 생성
→ 데이터 수집
→ 데이터 저장
→ 데이터 가공
→ 데이터 활용
→ 데이터 보관·폐기
→ 데이터 관리
```

## 05. 요약

**금일 수업내용을 복기해 보겠습니다. **

- 데이터는 업무 활동의 결과로 생성되는 기록입니다.
- 데이터는 업무를 설명하고 의사결정을 지원하는 중요한 자산입니다.
- 정형 데이터는 행과 열로 구성되어 분석과 집계에 적합합니다.
- 비정형 데이터는 문서, 이미지, 음성처럼 자유로운 형식의 데이터입니다.
- 반정형 데이터는 JSON, XML, 로그처럼 일부 구조를 가진 데이터입니다.
- 비정형 데이터도 메타데이터를 붙이면 구조적으로 관리할 수 있습니다.
- 데이터는 생성, 수집, 저장, 가공, 활용, 보관·폐기의 흐름을 가집니다.
- 데이터 문제는 대부분 입력 기준과 저장 구조에서 시작됩니다.
- 공사 데이터는 민원, 시설, 계약, 예산, 문서, 안전 데이터가 서로 연결됩니다.
- 데이터 연결을 위해서는 공통 식별자가 필요합니다.
- 표준화되지 않은 데이터는 분석 결과의 신뢰도를 떨어뜨립니다.
- 데이터 품질관리는 신뢰할 수 있는 데이터 활용의 기본 조건입니다.
- 메타데이터와 데이터 사전은 데이터를 같은 의미로 이해하게 해주는 기준입니다.
- 데이터 거버넌스는 조직 전체가 데이터를 체계적으로 관리하기 위한 운영 체계입니다.
- 데이터 구조가 정리되어야 분석, 자동화, AI 활용이 가능해집니다.
