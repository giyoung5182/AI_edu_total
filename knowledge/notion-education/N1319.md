# 1단계 · 영역 조사 (25분)

정리일: 2026-10-08 · 교육 에셋 N1319

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
제안 주제에 대해 최근 변화, 수요가 느는 지점, 이미 있는 것, 진입 장벽 네 가지를 젠스파크 슈퍼 에이전트로 조사해 제안서 2·3장의 재료를 만듭니다.
## 진행 단계
1. **슈퍼 에이전트 열기** — 왼쪽 New → AI 팀 → 슈퍼 에이전트
2. **Ultra로 바꾸기** — 입력창 왼쪽 ⚡ 버튼에서 Ultra 선택 (출처를 끌어오는 작업이라 모델 힘이 결과를 가름. 메시지당 100\~600 크레딧)
3. **프롬프트 붙여넣기** — 대괄호를 채워 입력
- 입력할 내용:
```javascript
[R] 당신은 이 분야에서 10년간 실무를 해 온 기획자입니다.
새로 진입하려는 사람에게 뭘 알려줘야 하는지 알고 있습니다.

[C] 저는 [제안 주제 한 문장]을 제안하려 합니다.
이 자료는 기획 제안서의 배경과 문제 정의에 쓸 것입니다.

[T] 아래 네 가지를 조사하세요.
    1) 최근 2년간 이 영역에서 뭐가 달라졌나
    2) 수요가 늘거나 불편이 남아 있는 지점은 어디인가
    3) 이미 이 일을 하고 있는 곳은 어디이며 어떻게 하고 있나
    4) 새로 시작하려면 어떤 장벽이 있나

[C] 범위는 국내, 최근 2년입니다.
대상은 [구체적인 사람을 적으세요]입니다.
광고성 블로그 글과 홍보 보도자료는 제외하세요.
결과를 항목별 표로 정리하고 각각 출처 링크를 붙이세요.
확인되지 않은 수치는 만들지 마세요.
출처가 없는 항목은 출처 없음이라고 표시하세요.
결과를 파일로 전달해 주세요.
```
4. **이 창을 오늘 끝까지 열어 둔다** — 슈퍼 에이전트는 여러 단계로 처리해 몇 분 걸림. 기다리는 동안 다음 단계(조직 조사) 프롬프트를 미리 준비.
- 정상 결과: 항목별 표 + 출처 링크가 붙은 결과 파일
## 막히는 지점
- 대괄호를 비워 두면 일반론 결과가 나옵니다.
- 이미 하고 있는 곳을 빼면 받는 사람이 가장 먼저 그걸 물어봅니다.
- 조사가 끝나도 바로 슬라이드로 만들고 싶어지지만 참아야 합니다(크레딧 낭비).
