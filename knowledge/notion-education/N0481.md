# [실습] 보고서 유형별 프롬프트 작성하기

정리일: 2026-10-08 · 교육 에셋 N0481

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
요약형·분석형·설득형 중 하나를 골라 본인 업무 상황에 맞게 프롬프트를 수정해 ChatGPT에 입력하고, 결과를 개선합니다.
## 진행 단계
1. **유형 선택·프롬프트 수정** — 위 3가지 유형 중 하나를 선택하여 본인의 실제 업무 상황에 맞게 프롬프트를 수정하고 ChatGPT에 입력
2. **결과 확인** — 결과물이 실제 업무에 바로 사용할 수 있는 수준인지 확인
3. **개선** — 부족한 부분은 후속 요청으로 개선. 마음에 들지 않는 부분을 지정하여 재생성 요청('수정해줘' 연습)
- 입력할 내용:
```markdown
위 보고서에서 2번 항목을 더 구체적으로 수정해줘.
수치 데이터를 표로 정리하고, 전월 대비 비교를 추가해줘.
```
1. **업로드** — 완료된 보고서를 패들렛에 올리기
