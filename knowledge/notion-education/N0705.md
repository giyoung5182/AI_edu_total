## 위임 매트릭스란?
**위임 매트릭스**는 업무를 "AI에게 맡길 수 있는가 없는가"로 분류하는 의사결정 도구입니다.
무작정 모든 업무를 AI에 맡기려 하면 오히려 시간이 더 걸리거나 실수가 납니다.
핵심은 하나입니다. **패턴이 있고 반복되는 업무인가?**
AI 위임이 잘 맞는 업무의 조건:
- 매번 비슷한 방식으로 처리한다
- 뭘 넣고 뭘 받을지 명확하다
- 결과를 내가 검토하고 수정할 수 있다
- 틀려도 큰 문제가 없다
### 2x2 구조로 이해하기







패턴 높음 (반복적)

패턴 낮음 (매번 다름)




**AI 위임 가능**

⭐ **지금 자동화 1순위**

△ 효과가 낮음, 보류




**AI 위임 불가**

💡 업무 프로세스 자체 재설계 필요

사람이 직접 해야 함

## 🗂️ 실습 1 — 내 업무 25개 뽑고 분류하기
**Claude Code** 터미널에서 아래 프롬프트를 본인 상황에 맞게 고쳐서 실행하세요.
```plain text
나는 교육기관 [   ] 담당이야.
내 주간 업무 TOP3야.
1.
2.
3.

최대 25개 작업으로 나눠줘.

각 작업마다 다음 형식으로 작성해줘:
| 번호 | 업무명 | 중요도(1-10) | 소요시간(분/회) | 반복빈도 | AI 위임 가능 여부 | 이유 한 줄 |

반복빈도: 일/주/월/비정기
AI 위임 가능: O / X / △(부분 가능)
```

**"25개가 안 나와요" — 더 잘게 쪼개면 됩니다**
예를 들어 "보고서 작성"도 → ① 데이터 수집, ② 초안 작성, ③ 검토·수정, ④ 공유 발송으로 4개입니다.
이메일 확인, 회의 준비, 자료 정리도 각각 하나씩 샙니다.
모르겠으면 손 들어주세요.

### Step 2. 다른 관점에서 비판 받기
같은 내용을 다른 관점으로 다시 검토하면 판단이 달라지는 항목을 발견할 수 있습니다.
```plain text
[위 결과 붙여넣기]

너는 이제 AI 자동화 프로젝트를 많이 실패해본
비판적인 컨설턴트 역할이야.

방금 정리한 내용에서
AI 위임 가능 판단이 너무 낙관적이거나 보수적인 항목을
지적해줘. 각 지적마다 "왜 재검토해야 하는지" 이유 포함.
```

**다른 관점을 만드는 방법**
같은 모델이라도 역할을 부여하거나 **새 채팅**에서 다시 물으면 판단이 달라집니다. 직전 대화의 맥락없이 보게 되기 때문입니다.
더 확실하게 하려면 ChatGPT 등 다른 AI 새 탭에 동일 프롬프트를 붙여넣어도 됩니다.
같은 질문에 다른 답이 나오면 그 항목이 애매하다는 신호입니다.

### Step 3. 2차 버전으로 최종 확정
```plain text
피드백 반영해서 위임 매트릭스를 수정해줘.
최종적으로:
- ⭐ 1순위 자동화 대상: 상위 3개
- 💡 프로세스 재설계 필요: 상위 2개
- ✋ 사람이 직접: 나머지
로 구분해서 정리해줘.

정리가 끝나면 위임매트릭스.xlsx 파일로 폴더에 저장해줘.
```

**Claude Code니까 가능한 한 줄**
마지막 줄처럼 파일 저장까지 요청하면, 화면에만 남는 게 아니라 작업 폴더에 엑셀 파일로 남습니다. S3\~S5 실습 내내 이 파일을 참조합니다. (아직 실습 폴더에서 실행하지 않았다면 `cd` 로 폴더를 이동한 뒤 `claude` 를 실행하세요.)

## 📚 오판 패턴 — 자주 틀리는 3가지
위임 가능 여부를 판단하다 보면 헷갈리는 패턴이 반복됩니다. 대표적인 세 가지를 정리합니다.
<details>
<summary>❌ 오판 1 — "AI가 할 수 있으니까 위임 가능하다"</summary>
**예시:** 고객사 클레임 대응 메일 작성
AI가 초안을 쓸 수는 있습니다. 하지만 그 클레임이 생긴 맥락, 관계, 적절한 톤 조절은 사람만이 판단할 수 있어요.
이런 업무는 **부분 위임(△)**으로 분류합니다.
"AI가 초안 → 사람이 검토·수정·발송"이 올바른 흐름입니다.
</details>
<details>
<summary>❌ 오판 2 — "민감한 데이터니까 위임 불가다"</summary>
**예시:** 인사 고과 데이터 집계 (숫자 합산)
숫자를 합산하는 행위 자체는 패턴이 있고 검토 가능합니다.
"민감하다"는 이유가 아니라 **"이 데이터를 AI 도구에 보내도 되는가"**를 따져야 합니다.
→ 회사가 승인한 AI 환경인지 보안 정책을 먼저 확인하고, 애매하면 **민감정보를 제거한 뒤 처리**하면 됩니다. (민감정보 제거 패턴은 S6 경로 A에서 실습합니다.) 업무 자체가 위임 불가는 아닙니다.
</details>
<details>
<summary>❌ 오판 3 — "나 혼자만 쓰면 된다"</summary>
**예시:** 팀 전체가 매주 반복하는 엑셀 취합 작업
내가 자동화 도구를 만들었다면 팀 전체의 효율이 올라갑니다.
혼자 몰래 쓰는 게 아니라, 오늘 만든 도구와 프롬프트를 내일 팀 채팅에 공유하는 게 맞습니다.
</details>
### AI 위임해도 사람이 남겨야 할 판단들
```plain text
어떤 업무든 최종 판단은 사람이 합니다:

- 숫자의 맥락 해석 ("이 수치가 좋은 건지 나쁜 건지")
- 관계와 감정이 들어간 커뮤니케이션
- 회사 정책·규정 해석
- 최종 서명·승인·책임
```

## 🛠️ 실습 2 — 오늘 만들 도구 설계안 확정
위임 매트릭스에서 ⭐ 1순위로 나온 업무를 하나 골라서, S3\~S5에서 실제로 만들 도구의 설계안을 작성합니다.
```plain text
내가 자동화하고 싶은 업무: [업무명 입력]

이 업무를 위한 AI 도구를 설계해줘.
다음 항목을 채워서:

① 도구 이름:
② 입력: 사용자가 뭘 넣는가?
③ 처리: AI가 어떤 방식으로 처리하는가?
④ 출력: 어떤 형태로 결과가 나오는가?
⑤ 예상 절감 시간: 회당 몇 분?
⑥ 주의사항: 사람이 반드시 검토해야 할 부분

Claude Code에서 파일 처리·문서 생성으로 끝낼 일인지,
Streamlit 대시보드 같은 앱으로 만들 일인지도 추천해줘.
```
설계안이 나오면 실현 가능성도 물어보세요:
```plain text
[위 설계안 붙여넣기]

이 설계가 실제로 구현 가능한지 체크해줘.
불가능하거나 너무 복잡한 부분이 있으면 단순화 방법 제안해줘.
```
<details>
<summary>💡 뭘 만들지 결정이 안 되면 — 이 템플릿으로 시작하세요</summary>
```plain text
① 도구 이름: CSV/엑셀 월별 자동 집계기
② 입력: 작업 폴더에 파일 넣기 (CSV 또는 엑셀)
③ 처리: 월별 합산, 이상값 탐지, 상위 항목 정렬 (Claude Code가 직접 실행)
④ 출력: 요약 엑셀 파일 + 차트 이미지 (심화: Claude Code로 대시보드화)
⑤ 예상 절감: 회당 40분
⑥ 주의사항: 이상값 원인 해석은 사람이
```
