# 4. 자유 실습: 만들고 싶은 웹사이트 만들기

정리일: 2026-10-08 · 교육 에셋 N1202

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만들고 싶은 것을 자유롭게 골라 AI로 단일 HTML 웹사이트를 만들고 피드백으로 개선한다.
## 진행 단계
1. **아이디어 고르기** — 교안 예시(주식 모의투자 사이트, 개인 포트폴리오, 칸반 보드, 점심 룰렛, 가계부, 딕모도로 타이머) 중 하나를 고르거나 직접 떠올린다.
2. **프롬프트 입력** — 예: 점심 룰렛.
- 입력할 내용:
```javascript
HTML, CSS, JavaScript로 점심 메뉴 랜덤 룰렛을 만들어줘.

- 원형 룰렛에 메뉴 8개 (김치찌개, 돈까스, 파스타, 쌍국수,
  초밥, 햄버거, 비빔밥, 치킨)
(이하 교안 참고)
```
1. **HTML로 저장해 실행** — 결과를 HTML 파일로 저장해 브라우저에서 열어 본다.
2. **피드백으로 개선** — 마음에 안 드는 부분을 말로 요청해 계속 고친다.
## 막히는 지점
- 처음부터 완벽하게 만들지 말고 기본 버전 후 피드백으로 하나씩 개선한다.
- 에러가 나면 에러 메시지를 그대로 AI에게 붙여넣어 "이 에러 고쳐줘"라고 요청한다.
