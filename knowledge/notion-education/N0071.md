# 3. 내 챗GPT·클로드 구독 연결하기 (2분)
[원본 이미지 제외]

어사이드가 AI를 가져오는 방법은 세 가지입니다. ① 어사이드 크레딧 ② **내가 이미 쓰는 구독 연결** ③ API 키. 비개발자는 ②번만 보면 됩니다. ③번은 개발자용이니 그냥 넘기세요.

### 연결 순서
1. 어사이드를 열고 **Settings(설정) → Models(모델) → Providers(제공자)** 로 들어갑니다.
2. **Connect(연결)** 버튼을 누르고, **Subscription(구독)** 칸에서 내가 쓰는 서비스를 고릅니다.
3. 로그인 창이 뜨면 평소 쓰던 계정으로 로그인하고 허용을 누릅니다. 창이 저절로 닫히면 연결 끝입니다. 비밀번호를 어사이드에 입력하는 게 아니라, 해당 사이트에서 로그인하는 방식입니다.
4. 마지막으로 **Settings → Models → Task models(작업 모델)** 에서 기본 모델을 방금 연결한 것으로 바꿉니다.

**마지막 4단계를 빼면 연결해도 소용없습니다.** 기본 모델을 바꾸지 않으면 어사이드 크레딧이 계속 빠집니다.

# 5. 첫 작업은 이걸로 (일상적인 작업)
[원본 이미지 제외]
괄호 안만 내 상황으로 바꿔서 사이드바에 붙여넣으면 됩니다. 마지막 줄의 금지 문장은 지우지 마세요.
### ① 블로그, 글쓰기부터 업로드 직전까지
```javascript
네이버 블로그에 올릴 글을 쓸 거야.
주제: (여기에 주제)
1. 내 블로그 글쓰기 화면을 열어줘
2. 제목 3개를 먼저 제안하고 내가 고를 때까지 기다려
3. 고른 제목으로 본문을 1500자 내외, 소제목 3개로 나눠서 써줘
4. 카테고리와 태그까지 채워줘
5. 발행 버튼은 절대 누르지 마. 임시저장까지만 하고 나한테 알려줘
```
### ② 인스타 팔로잉 정리, 스크롤은 그만
```javascript
인스타그램 팔로잉을 정리할 거야.
1. 내 팔로잉 목록을 끝까지 내려서 전부 모아줘
2. 그중 나를 팔로우하지 않는 계정만 골라줘
3. 계정 이름과 마지막 게시물 날짜를 표로 정리해서 보여줘
4. 언팔로우는 하지 마. 목록만 주면 내가 직접 고를게
```
### ③ 홈택스 서류, 찾지 말고 맡기기
```javascript
홈택스에서 서류를 찾을 거야.
필요한 서류: (예: 2025년 근로소득 원천징수영수증)
1. 해당 서류 발급 화면까지 이동해줘
2. 어느 메뉴를 거쳐 갔는지 순서대로 알려줘
3. 조회 조건(연도, 구분)을 채워서 화면까지 띄워줘
4. 발급이나 제출 버튼은 누르지 마. 거기서 멈추고 알려줘
```

홈택스·은행처럼 본인인증이 필요한 곳은 **내가 먼저 로그인해두고** 시켜야 합니다. 공동인증서나 간편인증 화면은 대신 넘어가지 못합니다.

### ④ 기차표는 맡기고, 여행만 준비
```javascript
기차표를 알아볼 거야.
날짜: (예: 10월 3일) / 출발: (예: 서울) / 도착: (예: 부산)
원하는 시간대: (예: 오전 9시 이후) / 인원: (예: 2명)
1. 코레일에서 위 조건으로 시간표를 조회해줘
2. 조건에 맞는 열차 3개를 소요시간, 좌석 종류, 요금과 함께 표로 보여줘
3. 내가 하나를 고르면 좌석 선택까지만 진행해줘
4. 결제는 절대 하지 마. 결제 직전에 멈추고 알려줘
```
### ⑤ 스팸·뉴스레터 한 번에 정리
```javascript
메일함을 정리할 거야.
1. 최근 3개월 안 읽은 메일을 발신자별로 묶어서 개수와 함께 표로 보여줘
2. 뉴스레터와 광고성 메일을 따로 구분해줘
3. 3개월 동안 한 번도 안 연 발신자는 구독 해지 후보로 표시해줘
4. 삭제나 구독 해지는 하지 마. 목록만 주면 내가 고를게
```

# 6. 요금제 — 사실상 결제할 필요는 없습니다

**어사이드는 AI를 파는 회사가 아닙니다.** 내가 이미 쓰고 있는 챗GPT나 클로드 구독을 연결하면, 그 토큰을 그대로 가져와서 씁니다. 어사이드가 하는 일은 그 AI에게 브라우저 화면을 쥐여주는 것이고, 그 부분은 무료입니다.

그래서 순서는 이렇습니다. **무료로 설치 → 내 챗GPT·클로드 구독 연결 → 끝.** 결제 화면은 안 봐도 됩니다.
유료 요금제는 "AI 구독이 아예 없는 사람"을 위해 어사이드가 모델 값을 대신 내주는 크레딧 묶음입니다. 내 구독을 연결한 사람에게는 같은 걸 두 번 사는 셈이라 의미가 없습니다. 아래 표는 참고로만 보세요.

# 7. 알아두면 좋은 것

**프롬프트 마지막에 금지 문장을 직접 적으세요.** "결제하지 마", "발행하지 마", "삭제하지 마". 승인 기능이 있어도 한 줄 더 적는 게 확실합니다.
**되돌릴 수 있는 것부터 시키세요.** 회사 계정이나 금융 계정은 처음부터 물리지 마세요.
**화면을 사람처럼 보고 누르는 방식**이라, 사이트 화면이 개편되면 중간에 헤맵니다. 오래 멈춰 있으면 중단하고 조건을 더 구체적으로 적어 다시 시키세요.
**새로 나온 서비스입니다.** 내 로그인 상태를 맡기는 일이니, 어디까지 맡길지는 직접 선을 그어두세요.

<details>
<summary>**크레딧이 너무 빨리 줄어요**</summary>
크레딧이 줄고 있다면 내 챗GPT·클로드 구독이 연결되지 않은 상태일 가능성이 큽니다. 4번 섹션을 다시 따라해주세요. 특히 마지막 단계(Task models에서 기본 모델 바꾸기)를 빼먹는 경우가 많습니다. 연결한 뒤에도 무겁다면 한 번에 시키던 작업을 두세 개로 쪼개고, 조회만 하면 되는 작업은 권한을 읽기만으로 두세요.
</details>
