# [실습] R&R 초안을 AI로 작성해보자

정리일: 2026-10-08 · 교육 에셋 N0432

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
시애틀 건물 에너지 벤치마킹 데이터를 기준으로 데이터 품질관리 R&R 초안과 RACI 매트릭스를 AI로 작성합니다.
## 진행 단계
1. **맥락 준비** — 시애틀시 관련 법안(20,000제곱피트 초과 건물 소유자의 연간 보고 등)과 가상 조직도·부서별 업무분장표·담당자별 업무 메모를 맥락으로 제공합니다. 추가 검색으로 보완해도 됩니다.
2. **프롬프트 실행** — 예시 프롬프트로 요청합니다.
- 입력할 내용(요약): 공공기관 데이터 거버넌스 컨설턴트 역할, 데이터셋 설명, 배경과 역할 후보 7개(Building Owner / Property Manager, OSE Program Manager, Data Steward, Open Data Portal Administrator, IT / System Administrator, Public Data User, Data Governance Committee), 작성할 내용(주요 책임, 품질관리 활동 목록, 활동별 RACI, A는 한 명만, 불확실하면 "확인 필요", Markdown 표)과 활동 10가지 (이하 교안 참고)
3. **평가 공유** — 결과가 현실적인지, 좋은 부분과 사람이 2차로 검토해야 할 부분을 2주차 패들릿에 공유합니다.
## 막히는 지점
- RACI에서 A(Accountable)는 반드시 1명이어야 합니다.
- 조직 메모에 최종 승인자가 겹치는 경우(예: 업로드 승인권 의견 불일치)가 있어 사람의 검토가 필요합니다.
