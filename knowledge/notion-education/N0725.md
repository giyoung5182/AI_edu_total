## 실습 1. 내 계정 설정 3곳 점검 (보충)
**1. 왜 하는가** — 본인 Plus 계정은 교육 후에도 남음. 메모리·맞춤 지침이 켜져 있으면 실습 결과가 사람마다 달라짐
**2. 준비** — ChatGPT 웹(chatgpt.com) 로그인, 새 채팅 화면. 메모장 1개
**3. 먼저 예측** — 메모장에 적기
- 내 계정의 메모리는 켜져 있을까, 꺼져 있을까?
- 맞춤 지침에 무언가 적혀 있을까?
**4. 실행**
① 화면 왼쪽 아래 **본인 이름(프로필)** 클릭 → 메뉴에서 **설정** 클릭. 위치·이름이 다르면 프로필 아이콘 근처의 톱니바퀴 모양 메뉴 사용 \[확인 필요\]
② 설정 창 왼쪽 목록에서 **개인 맞춤** 클릭 → **메모리** 항목의 켜짐/꺼짐 상태 확인
③ 같은 화면에서 **메모리 관리**(저장된 메모리 목록 보기) 버튼이 있으면 클릭 → 저장된 항목 개수와 업무 관련 항목 유무만 확인. **지우거나 끄는 것은 본인 판단**(오늘 실습 진행에는 영향 없음)
④ 같은 **개인 맞춤** 화면에서 맞춤 지침(커스텀 인스트럭션) 입력칸에 적힌 내용 확인
⑤ 설정 창 왼쪽 목록에서 **데이터 제어** 클릭 → **모두를 위한 모델 개선** 항목의 켜짐/꺼짐 확인
⑥ 설정 창 닫기 → **새 채팅**에서 아래 프롬프트 복사 → 입력창 붙여넣기 → Enter
```plain text
지금 이 대화에서 네가 참고하고 있는 나에 대한 정보(메모리, 맞춤 지침 등)가 있다면 항목별로 그대로 보여줘.
없으면 "없음"이라고만 답해.
추측으로 채우지 말고, 확실하지 않은 항목은 "확인 불가"라고 적어줘.
```
**5. 관찰**
- ②\~⑤에서 본 설정 상태와 ⑥의 답이 서로 맞는가
- 답에 내가 기억하지 못하는 항목이 나오는가
**6. 판정**
- 설정 화면(②\~⑤)이 기준. ⑥의 AI 답은 보조 확인용. 둘이 다르면 **설정 화면을 믿음** 〔원칙③〕
- 메뉴 이름이 다르거나 찾을 수 없으면 → "메뉴 위치 확인 불가"로 기록(오답 아님)
**7. 고칠 때**
- 메뉴가 안 보임 → 화면 오른쪽 위·왼쪽 아래의 프로필 아이콘을 차례로 눌러 **설정** 찾기. 그래도 없으면 강사에게 화면 보여 주기
- ⑥의 답이 설정 화면과 다름 → 아래 요청으로 다시 확인
```plain text
설정 화면에서는 [메모리가 꺼져 있음 / 맞춤 지침이 비어 있음]으로 보여.
방금 답에서 이와 다른 부분이 어디서 나온 것인지 설명하고, 근거가 없으면 "근거 없음"으로 표시해줘.
```
**8. 남길 것** — 메모장에 `메모리: 켜짐/꺼짐 · 저장 항목 유무 · 맞춤 지침: 있음/없음 · 모델 개선: 켜짐/꺼짐 · 점검 날짜`. Part 1 Step 05(보안 기준)에서 다시 봄
> ✅ **확인 기준** — 메모리 켜짐/꺼짐 상태를 설정 화면에서 직접 확인함 · 맞춤 지침에 적힌 내용 유무를 확인함 · 모델 개선(학습 사용) 설정 상태를 확인함

**6. 판정**
- AI의 이의는 참고할 **반박 의견**. 네 가지 기준에 비춰 내 이유가 더 타당하면 내 선택 유지

[번호] 항목의 판정을 이 네 가지 기준으로만 다시 설명해줘. 나머지 항목은 그대로 둬.
