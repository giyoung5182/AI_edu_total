# PART 2. 파이썬 문법 — 딱 7개만
> **파이썬을 배우는 게 아닙니다.** 내일 코드를 읽고 오타를 찾을 수 있으면 됩니다.
## ① `=` 는 "같다"가 아니라 **"넣어라"**
```python
df = bdq.getData(...)
```
> 오른쪽 결과를 **`df`****라는 상자에 넣어라**
📦 **비유:** 택배를 받아서 **상자에 이름표를 붙이는 것**
- `df` = 상자 이름 (아무 이름이나 됨. 관례상 데이터는 `df`)
- 한 번 넣어두면 **그다음부터 ****`df`****라고 부르면 됩니다**
> 🔴 **그래서 순서가 중요합니다.** 상자에 안 넣고 `df`를 부르면<br>**`NameError: name 'df' is not defined`** ← "그런 상자 없는데요?"
## ② 따옴표 `" "` 는 **"이건 글자야"** 라는 표시
```python
my_sql = "SELECT * FROM EDU.PUBLIC_TITANIC LIMIT 100"
```
**왜 필요:** 파이썬은 따옴표가 없으면 **명령어인 줄 압니다.**<br>따옴표로 감싸면 **"이건 그냥 글자니까 해석하지 마"** 가 됩니다.
🏷️ **비유:** **비닐로 씌우는 것.** 안에 뭐가 있든 건드리지 말라는 표시
> 🔴 **반드시 짝을 맞춰야 합니다.** 하나만 있으면<br>**`unterminated string literal`** ← "비닐을 안 닫았는데요?"
**🖥️ 눈으로 확인:** VS Code에서 **글자 부분만 색이 다릅니다.**<br>색이 **줄 끝까지 계속 이어지면** → 안 닫힌 것
> ⚠️ **한/영 상태 주의.** 한글로 치면 `"` 대신 `”`가 들어가는데 **눈으로 구분이 안 됩니다.**
## ③ 괄호 `( )` 는 **"이걸 넣어서 실행해"**
```python
print(df)
```
> `print`라는 기계에 `df`를 **넣어서** 돌려라
⚙️ **비유:** **믹서기.** `print(  )` 가 믹서기고 괄호 안이 재료
**괄호가 비어 있어도 됩니다**
```python
bdq.getTableList()
```
> 재료 없이 그냥 **버튼만 누르는 것**
> 🔴 **괄호도 짝을 맞춰야 합니다.** 안 맞으면 `SyntaxError`
## ④ 점 `.` 은 **"\~의"**
```python
bdq.getData(...)
```
> **bdq의 getData 기능**을 써라
```python
df.head()
```
> **df의 head 기능** = 앞부분만 보여주기
🏢 **비유:** **`회사.영업팀`** 처럼 소속을 나타냅니다
## ⑤ `print()` 는 **"화면에 보여줘"**
> 🔴 **어제 헷갈렸던 부분입니다.**





어디

`print` 필요?




**`.py`**** 파일**

✅ **꼭 필요** — 없으면 계산만 하고 안 보여줌




**`>>>`**** (파이썬 창)**

❌ 없어도 보여줌


```python
# .py 파일에서
df.head()          ← 계산은 하는데 화면에 안 나옴 ❌
print(df.head())   ← 화면에 나옴 ✅
```
📺 **비유:** 계산은 머릿속으로 하고, **`print`****는 "말해봐"** 라고 시키는 것
> 계산기가 답을 알고 있어도, **화면에 띄우라고 해야** 보이는 거죠
## ⑥ `import` 는 **"도구 꺼내오기"**
```python
import bigdataquery as bdq
```
> `bigdataquery`라는 도구를 가져와서 **`bdq`****라는 짧은 별명**으로 쓰겠다
🧰 **비유:** **공구함에서 드라이버를 꺼내는 것.** 꺼내야 쓸 수 있습니다
> 🔴 **맨 위에 한 번만** 쓰면 됩니다. 안 쓰면 `ModuleNotFoundError`
## ⑦ 대소문자를 **구분합니다**
```python
Fare   ≠   fare   ≠   FARE
```
> 🔴 **어제 테이블명 오타로 막힌 게 이것 때문**입니다.<br>사람 눈엔 같아 보여도 컴퓨터는 **완전히 다른 것**으로 봅니다.
**특히 헷갈리는 글자**





헷갈림

예




**I**(대문자 아이) vs **l**(소문자 엘) vs **1**(숫자 일)

`TITANIC`




**O**(대문자 오) vs **0**(숫자 영)






**`_`**(언더바) vs **`-`**(하이픈)

`PUBLIC_TITANIC`


⭐ **이름은 손으로 치지 말고 복사해서 붙여넣는 게 안전합니다.**

# PART 3. 내일 쓸 코드 — 한 줄씩 해부
```python
import bigdataquery as bdq
```
> 🔧 **공구함에서 ****`bigdataquery`****를 꺼내 ****`bdq`****라 부르겠다**
```python
my_sql = "SELECT * FROM EDU.PUBLIC_TITANIC LIMIT 100"
```
> 📝 **주문서를 써서 ****`my_sql`**** 상자에 넣는다**<br>— 따옴표로 감쌌으니 **"이건 그냥 글자야"**
```python
df = bdq.getData(param = my_sql)
```
> 📦 **bdq의 getData 기능에 주문서를 넣고, 결과를 ****`df`**** 상자에 담는다**<br>— `param =` 은 **"이 재료의 이름은 param이야"** 라는 표시
```python
print(df.head())
```
> 📺 **df의 앞부분(head)을 화면에 보여줘**<br>— `head()` 는 **앞 5줄만** 보여주는 기능
```python
df.to_csv("결과.csv", index=False, encoding="utf-8-sig")
```
> 💾 **df를 ****`결과.csv`**** 라는 파일로 저장해라**<br>— `index=False` : 파이썬이 붙이는 번호 칸 빼줘<br>— `encoding="utf-8-sig"` : **한글 안 깨지게**
```python
print("저장 완료")
```

# 📖 부록 C. 용어 사전





용어

한 줄 정의




**데이터레이크**

회사 데이터를 다 모아둔 거대한 **호수**




**Data Square**

데이터를 **찾는** 검색 사이트 (도서관 검색대)




**카탈로그**

호수에 뭐가 들었는지 적힌 **목록표**




**Hue**

SQL로 데이터를 **꺼내오는** 곳 (대출 창구)




**임팔라**

대용량 데이터를 빠르게 조회하는 **엔진**




**SQL / 쿼리**

"이런 데이터 주세요"라고 묻는 **주문서**




**스키마**

표의 뼈대 (어떤 칸이 있는지)




**메타데이터**

데이터에 대한 설명 (단위·담당·주기)




**리니지(계보)**

어디서 와서 어떻게 가공됐는지 **족보**




**numeric**

**숫자 타입** — 계산이 되는 값




**파티션**

데이터를 **날짜별·라인별 서랍**으로 나눠 저장한 구조




**Array 타입**

한 칸에 값이 여러 개 든 형태 (**가방**)




**unnest**

그 여러 값을 **한 줄씩 펼치는 것**




**LIMIT**

"몇 건만 가져와" 제한




**BigDataQuery**

데이터레이크 데이터를 **파이썬 코드로** 꺼내는 패키지




**pandas / DataFrame**

파이썬에서 표를 다루는 도구 / 그 표




**결측치**

**빈칸** — 값이 없는 칸




**교차 분석**

두 조건을 **겹쳐서** 보는 것




**CSV**

쉼표로 칸을 나눈 표 파일 (엑셀로 열림)




**Spotfire**

시각화 프로그램




**Information Link+**

Spotfire에서 데이터레이크를 **조회하는 기능**




**IL+ Manager**

**3단계 권한을 관리**하는 도구 (관리자용)




**HTML**

웹페이지를 만드는 문서 형식




**대시보드**

숫자를 한눈에 보게 그려놓은 화면




**터미널 / PowerShell**

명령을 실행하는 검은 창 (`PS >`)




**파이썬 REPL**

터미널에 `python`을 치면 나오는 `>>>` 상태




**VS Code**

코드를 쓰는 프로그램 (메모장의 고급 버전)




**세션 초기화**

AI와의 **대화를 새로 시작**하는 것 (`+` 버튼)
