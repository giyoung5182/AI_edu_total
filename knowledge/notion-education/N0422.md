# 실습 1. 무질서 집필 — 실패를 직접 만든다

정리일: 2026-10-08 · 교육 에셋 N0422

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
집필 페이지를 만들고 5개 장을 조율 없이 다섯 에이전트에게 맡겨, 결과물이 어떻게 무너지는지 직접 수집한다.
## 진행 단계
1. **프롬프트 입력** — 창②(Claude Code)에서 `/clear`를 실행한 뒤 프롬프트를 입력한다.
- 입력할 내용: 프로젝트에 집필 페이지를 추가해 달라는 요구사항(/writing 경로, "집필 시작" 버튼, 5개 장을 gemini-2.5-flash-lite 에이전트가 각각 집필, 장 제목 외 정보 일절 미제공, 호출 간 대기, 자동 재시도 금지·실패 장만 "실패" 표시, 카드 5장 표시, "실패한 장 다시 시도" 버튼, 서버 로그 출력) (이하 교안 참고)
2. **서버 재시작·페이지 열기** — 창①에서 서버를 재시작하고 /writing 페이지를 연다.
3. **무질서 집필 실행** — "무질서 집필 시작"을 누르고 창①의 로그로 다섯 에이전트가 각자 일하는 것을 지켜본다.
4. **카드 읽기** — 완성된 카드 다섯 장을 펼쳐 전부 읽는다.
5. **실패 찾기** — 체크리스트로 무너짐을 수집하고 위치(몇 장, 어느 문장)를 메모한다. 범위 중복 / 용어 불일치 / 문체 불일치 / (보너스) 같은 처치인데 숫자·순서가 다른 곳.
6. **비교** — 옆자리와 수집 결과를 비교한다. 실행마다 결과가 달라 서로 다른 실패를 찾는다.
## 막히는 지점
- 다섯 장이 너무 멀쩡하게 나옴: 우연히 결이 맞은 것. 한 번 더 실행
- 일부 장만 생성 실패: 창①의 로그를 창②에 붙여넣어 해결 요청
- 429 에러: 무료 한도. "호출 사이 대기를 늘려 주세요"라고 요청하고 1\~2분 뒤 재실행
- 생성이 오래 걸림: 5회 순차 호출 + 대기이므로 정상
