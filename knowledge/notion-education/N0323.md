# 실습 2-A-1. 브리프 → 제안서 전 챕터 초안

정리일: 2026-10-08 · 교육 에셋 N0323

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클라이언트 브리프를 입력하면 PLANNING + DESIGN 두 챕터를 동시에 초안으로 생성하고, 체이닝 1회로 결과를 개선하는 흐름을 익힙니다.
## 진행 단계
1. **프롬프트 입력 (5분)** — 아래 프롬프트를 Claude에 붙여넣습니다. \[클라이언트 브리프\] 항목만 실제 정보로 채우거나, 오늘은 하단 연습용 브리프를 그대로 사용합니다.
- 입력할 내용:
```javascript
[R - Role]
당신은 전시 디자인 전문 회사 교육기관코리아의 수석 기획자 겸 크리에이티브 디렉터입니다.

[T - Task]
PLANNING 챕터와 DESIGN 챕터를 함께 작성해 주세요.
PLANNING: PROLOGUE / INSIGHT 3가지 / STRATEGY 4개 / SOLUTION 3가지
DESIGN: MESSAGE / CONCEPT / SPACE STORY / DESIGN DIRECTION
(이하 교안 참고)
```
1. **결과 검토 (3분)** — PROLOGUE가 역설적 선언으로 시작하는가, INSIGHT 3가지가 서로 다른 관점을 다루는가, STRATEGY 전략명이 임팩트 있는 영문 구인가, CONCEPT 네이밍이 독창적인가, DESIGN DIRECTION에 색상·소재·조명이 각각 구체적인가를 확인합니다. 미흡하면 Step 3, 모두 충족되면 Step 4로 이동합니다.
- 정상 결과: Golden Sample 적용 시 역발상 관점과 브랜드 문제 진단이 담긴 INSIGHT가 나옵니다.
2. **체이닝 수정 (5분)** — 가장 먼저 수정하고 싶은 것을 골라 같은 대화창에 입력합니다.
- 입력할 내용: "INSIGHT 섹션을 다시 써줘. 각 인사이트에 '이 브랜드가 지금까지 이렇게 해왔는데, 그게 실은 이런 문제가 있었다'는 역발상 관점을 추가해줘." (CONCEPT 네이밍 3방향 재제시, SPACE STORY 1인칭 재작성 프롬프트도 교안에 있음)
3. **실제 프로젝트 적용 (나머지 시간)** — 연습용 브리프 대신 진행 중인 실제 프로젝트 정보(클라이언트, 전시명, 장소·시기, 컨셉 키워드, 타겟, 부스 규모, 요청 사항)를 넣고 다시 실행합니다. 미완성 정보여도 됩니다.
체크리스트: PROLOGUE 역설적 선언 / STRATEGY 영문 전략명 / CONCEPT 독창성 / 추상 개념과 공간 요소 연결 / 체이닝 1회 이상
## 막히는 지점
- 결과 검토에서 미흡한 항목이 있으면 Step 3 체이닝으로 수정합니다.
- Golden Sample 없이 쓰면 시장 분석 보고서 수준의 나열이 됩니다.
