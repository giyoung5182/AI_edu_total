## PART 2. AI 모델이 여러 개인 이유 (15분)
> 수강생이 가장 많이 헷갈려하는 부분입니다. "ChatGPT 안에도 모델이 여러 개고, Claude도 Opus·Sonnet이 있고, Gemini도 Flash·Pro가 있고..." — 이 구조를 강사가 명확히 설명할 수 있어야 합니다.
### 왜 하나의 AI 서비스 안에 모델이 여러 개인가
모든 AI 회사는 **성능·속도·비용**의 트레이드오프 때문에 모델을 계층화합니다.
```plain text
같은 회사의 AI라도:

고성능 모델 (Flagship)
  → 복잡한 추론, 긴 문서, 전문적 작업에 강함
  → 느리고 비쌈
  → 예: Claude Opus, GPT-5.5 (Thinking), Gemini 3.1 Pro

균형형 모델 (Balanced)
  → 일상 업무, 대부분의 사용 케이스에 충분
  → 속도·비용·성능 최적 균형
  → 예: Claude Sonnet, GPT-5.5 (Instant), Gemini 3.5 Flash

경량형 모델 (Lite/Mini)
  → 단순 작업, 빠른 응답, 저비용 대량 처리
  → 예: Claude Haiku, GPT-5.4 mini, Gemini 3.1 Flash-Lite
```
### 강사가 기억할 핵심 원칙
> ⚠ **모델명은 외우지 마세요 — 강의 직전에 검색해서 확인하는 것이 맞습니다.**<br>AI 모델은 몇 주 단위로 업데이트됩니다. 특정 버전을 단정하면 그 자리에서 틀린 정보가 될 수 있습니다.<br>"현재 기준으로는 이렇습니다"라고 말하는 강사가 더 신뢰받습니다.
### 왜 같은 회사가 여러 모델을 운영하는가 — 비유
> "식당에서 런치 세트, 코스 요리, 프리미엄 코스를 따로 파는 것과 같아요. 재료는 비슷하지만 손이 많이 가는 요리일수록 시간도 오래 걸리고 비싸죠. AI도 '얼마나 깊이 생각하게 할 것인가'에 따라 시간과 비용이 달라집니다."

## PART 3. ChatGPT 완전 정복 (55분)
### 3-1. ChatGPT란 무엇인가
**회사:** OpenAI (2015년 설립, 2022년 ChatGPT로 AI 대중화 시작)
**한 줄 정의:**
> "가장 먼저 AI를 대중화한 범용 AI 서비스. 이미지 생성부터 코딩, 문서 작성, 데이터 분석까지 가장 넓은 생태계를 갖춘 AI"
**ChatGPT가 중요한 이유:**
- AI 대중화의 출발점 → 수강생 대부분이 "AI" 하면 ChatGPT를 떠올림
- 가장 넓은 사용자 생태계 → 수강생 질문이 가장 많이 나오는 AI
- 강사가 가장 잘 알아야 하는 AI

### 3-3. ChatGPT 핵심 기능 7가지
**① 텍스트 생성·편집 (가장 기본)**
```plain text
- 글쓰기, 번역, 요약, 교정
- 강의 자료 초안 작성
- 이메일·보고서 작성
강사 활용: 강의 소개문, 수강생 안내문, 홍보 문구 생성
```
**② 이미지 생성 (DALL-E 통합)**
```plain text
- 텍스트로 이미지 생성
- 강의 자료 삽입용 일러스트 생성
- "AI가 그림도 그린다"의 가장 직관적인 시연 도구
강사 활용: 수강생에게 "배를 그려줘" 실습 → 동음이의어 예시로 활용
```
**③ 파일·문서 분석**
```plain text
- PDF, 엑셀, 이미지 업로드 후 AI와 대화
- "이 계약서에서 불리한 조항 찾아줘"
- "이 엑셀 데이터를 요약해줘"
강사 활용: 강의 자료 PDF 업로드 → "이 내용으로 퀴즈 5개 만들어줘"
```
**④ 실시간 웹 검색**
```plain text
- 최신 정보 검색 후 답변 (Perplexity와 유사)
- 학습 데이터 컷오프 한계 극복
- 출처 제공 (단, Perplexity보다 출처 투명성 낮음)
```
**⑤ 코드 생성·실행 (Code Interpreter)**
```plain text
- 코드 작성·디버깅
- 데이터 분석·시각화
- 강사가 직접 쓸 일은 적지만, 수강생 질문에 대응 가능해야 함
```
**⑥ 음성 대화 (Voice Mode)**
```plain text
- 말로 대화하고 AI가 말로 답변
- 실시간 통역·번역 가능
- 시니어 수강생에게 "AI랑 전화하는 느낌"으로 소개 가능
```
**⑦ GPTs — 나만의 특화 AI 만들기**
```plain text
- 특정 목적에 맞는 AI 챗봇 직접 제작
- 강의 Q&A 봇, 교육기관 20 안내 봇 등 제작 가능
- Gems(Google)·Claude Projects와 유사한 개념
→ 3회차 Gems 심화에서 더 깊이 다룸
```

### 3-4. ChatGPT 실습 (25분)
**실습 1 — 기본 텍스트 생성: 강의 소개문 만들기 (5분)**
```plain text
입력:
"60대 이상 시니어를 대상으로 AI 일상 활용법을 가르치는
강의 소개문을 친근하고 쉽게 3줄로 써줘"

확인 포인트:
  □ 어조·난이도가 요청에 맞는가?
  □ 이걸 수정해서 바로 쓸 수 있는가?
  □ RCTC+K로 프롬프트를 더 구체화하면 어떻게 달라지는가?
```
**실습 2 — 이미지 생성: 수강생과 함께 할 수 있는 실습 (5분)**
```plain text
입력: "배를 그려줘"
→ AI가 어떤 '배'를 그리는지 확인 (선박? 과일? 복부?)

두 번째 입력: "바다를 항해하는 배를 그려줘"
→ 구체적 프롬프트의 차이 직접 체험

강사 교훈: 이 실습 자체가 "AI에게 구체적으로 말해야 하는 이유"의
           가장 직관적인 시연 콘텐츠
```
**실습 3 — 파일 분석: 기존 강의 자료 활용 (10분)**
```plain text
기존 강의 자료 PDF 업로드 후:

Q1. "이 자료의 핵심 내용을 3줄로 요약해줘"
Q2. "이 자료를 바탕으로 수강생용 퀴즈 5개 만들어줘"
Q3. "이 자료에서 수강생이 어려워할 만한 용어를 찾아서
    쉽게 설명해줘"

강사 교훈: 강의 자료를 AI에 넣으면 준비 시간이 1/3로 줄어든다
```
**실습 4 — 음성 대화 체험 (5분)**
```plain text
음성 모드 켜기 → 말로 질문하기:
"오늘 강의에서 AI가 뭔지 설명하는 좋은 비유를 알려줘"

확인 포인트:
  □ AI의 음성 답변이 자연스러운가?
  □ 시니어 수강생에게 이걸 보여줄 때 어떤 반응이 나올 것 같은가?
  □ "카카오 음성 인식이랑 다른 점이 뭐야?"라는 질문에 뭐라고 답할 것인가?
```

## PART 4. Gemini 완전 정복 (40분)
### 4-1. Gemini란 무엇인가
**회사:** Google DeepMind
**한 줄 정의:**
> "구글이 만든 AI. 구글 검색·Gmail·드라이브 등 구글 생태계와 가장 잘 연동되고, 멀티모달(텍스트·이미지·음성·영상) 처리에 강한 AI"

- 안드로이드 스마트폰 기본 탑재 → 시니어 수강생 접근성 높음
- 구글 검색과 연동 → 실시간 정보 검색에 강함
