# 실습 2. 챗봇에 검색을 연결하기

정리일: 2026-10-08 · 교육 에셋 N1335

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
챗봇이 하이브리드 검색 결과를 근거로 답하고, 근거 청크 번호를 함께 표시하게 만듭니다.
## 진행 단계
1. **프롬프트 입력** — 창②에 Claude Code 프롬프트를 입력하고 진행합니다.
- 입력할 내용:
```javascript
채팅 페이지의 챗봇 대화에 문서 근거 기반 대화를 추가해 주세요.
1. '지식 기반 답변 모드' 토글 버튼 추가 (ON일 때 아래 동작)
2. 질문이 들어오면 하이브리드 검색으로 상위 K개(기본 3) 청크를 찾아 근거로 포함한 프롬프트를 조립해 Gemini(gemini-2.5-flash)에 전송
3. 프롬프트에 포함: 근거만 사용해 답할 것 / 근거에 없으면 "문서에서 확인되지 않습니다"라고 답할 것
4. 서버 로그에 질문 수신 → 검색 완료(청크 번호들) → Gemini 호출 → 응답 반환 순서로 출력
```
- 추가 구현(생각해볼 부분): 토글 툴팁, 답변 말풍선 아래 근거 청크 목록(눌러서 원문 펼침), 문장별 청크 번호 표기
2. **서버 재시작** — 창①에서 재시작하고 채팅 페이지를 엽니다.
3. **질문** — "지진이 나면 가장 먼저 뭘 해야 하나요?"
4. **근거 확인** — 답변 아래 근거 청크 번호를 확인하고 눌러서 원문을 폅니다. 답변 문장과 청크 원문을 한 줄씩 대조하고, 답변이 실제로 근거 안에 있으면 성공입니다.
5. **문서에 없는 질문** — 예: "화성에서 지진이 나면 어떻게 하나요?" → "문서에서 확인되지 않습니다" 계열 답이 오는지 확인.
6. **자유 질문** — 예: "엘리베이터에 갇히면?" 등. 답변마다 근거 번호가 붙는지 지켜봅니다.
## 막히는 지점
- 답변에 근거 번호가 안 붙음: 창②에 "답변에 청크 번호 표기가 빠집니다. 프롬프트를 점검해 주세요"라고 요청.
- 문서에 없는 내용을 그럴듯하게 답함: 창②에 "근거에 없으면 모른다고 답하도록 지시를 강화해 주세요"라고 요청.
- 429 에러 로그: 무료 사용량 한도 초과. 1\~2분 기다렸다가 재시도.
