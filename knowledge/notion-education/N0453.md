# 문제5: 인라인 뷰로 평균 90 이상 계약종별 (어려움)

정리일: 2026-10-08 · 교육 에셋 N0453

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
2023-07-01 사용요금 데이터로 계약종별 평균 사용요금 인라인 뷰를 만들고, 평균이 90 이상인 계약종별만 평균 높은 순으로 조회합니다. 결과에는 계약종별, 사용요금 건수, 평균 사용요금, 최대 사용요금을 포함합니다.
## 진행 단계
1. **쿼리 작성**
```sql
SELECT
    v.`계약종별`,
    v.사용요금_건수,
    v.평균사용요금,
    v.최대사용요금
FROM (
    SELECT
        `계약종별`,
        COUNT(*) AS 사용요금_건수,
        ROUND(AVG(`금액`), 2) AS 평균사용요금,
        MAX(`금액`) AS 최대사용요금
    FROM KDHC
    WHERE `기준일자` = '2023-07-01'
      AND `요금종별` = '사용요금'
    GROUP BY `계약종별`
) v
WHERE v.평균사용요금 >= 90
ORDER BY v.평균사용요금 DESC;
```
2. **정답화면 비교** — 전체(3건, 100.69), 업무용(6건, 97.47) 2행이 나오는지 확인합니다.
