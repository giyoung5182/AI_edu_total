# 6. 배포하기 — 2단계 첫 배포 / 재배포

정리일: 2026-10-08 · 교육 에셋 N0549

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클로드 코드에 한 줄로 부탁해 폴더를 GitHub에 올리고(push) Vercel로 배포(deploy)해 사이트 주소를 받습니다.
## 진행 단계
1. **첫 배포** — 클로드 코드에 입력합니다.
- 입력할 내용:
```plain text
이 폴더를 깃허브 새 저장소에 올리고, 버셀로 배포해서 사이트 주소 알려줘
```
2. **재배포(파일 수정 후)** — 수정한 뒤 다시 올릴 때 입력합니다.
- 입력할 내용:
```plain text
수정한 거 깃허브 푸시하고 버셀에 다시 배포해줘
```
## 막히는 지점
- 배포는 됐는데 사이트가 빈 화면: index.html이 루트(최상위) 폴더에 없을 수 있으므로 프로젝트 최상위 폴더에 index.html이 있는지 확인
