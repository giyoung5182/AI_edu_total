# 실습 3. 웹 담당 합류와 종합 시연

정리일: 2026-10-08 · 교육 에셋 N0450

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
마지막 멤버인 웹 담당을 합류시키고 팀 전체를 가동하며, 문서에 없는 질문에서 우회 동작을 확인합니다.
## 진행 단계
1. **프롬프트 입력** — 창②에 입력하고 패키지를 설치한 뒤 서버를 재시작합니다.
- 입력할 내용:
```plain text
재난 대응 팀에 웹 담당을 추가해 주세요. 요구사항입니다.

1. 웹 담당(gemini-2.5-flash-lite)은 Tavily로 웹을 검색하고,
   상위 결과 2~3건을 제목, 요약, 출처 주소와 함께 보고합니다.
(이하 교안 참고)
```
1. **종합 시연** — "지금 여기서 지진이 나면 어떻게 해야 하죠?" 손을 떼고 분배 → 검색·위치 보고 → 브리핑 → 채점까지 개입 없이 완주되는지 봅니다.
2. **우회 실험 예측** — "올해 태풍 전망은 어떤가요?" 문서에 답이 없는 질문입니다. 검색 담당이 뭐라고 보고할지, 팀이 어떻게 움직일지 예측해 적습니다.
3. **확인** — 정상 결과: 검색 담당의 "관련 근거를 찾지 못했습니다" 보고, 오케스트레이터의 경로 전환 말풍선, 웹 담당의 검색 결과 보고(출처 주소 포함), "문서 근거 없음, 웹 출처 기반" 표기가 붙은 브리핑.
4. **자유 질문** — 문서에 있을 질문과 없을 질문을 섞어 던지고 경로가 알맞게 갈리는지 봅니다.
## 막히는 지점
- 웹 검색 결과가 비어 있음 / 문서에 있는 질문인데 웹 경로로 감 / 문서에 없는 질문인데 억지 브리핑이 나옴 / 전체 소요가 길다(정상)
