## **💬 Claude Desktop 설치하기**
먼저 Claude Desktop을 설치하겠습니다.

## **🔌 GitHub 커넥터 연결하기**
다음으로 GitHub 플러그인을 연결하겠습니다.
GitHub는 오늘 만든 프로젝트를 저장하는 공간입니다.
쉽게 말하면,<br>내가 만든 웹앱 파일을 보관하고<br>나중에 다시 수정할 수 있게 남겨두는 곳이라고 생각하시면 됩니다.
---
## **🚀 Vercel 커넥터 연결하기**
이번에는 Vercel 플러그인을 연결하겠습니다.
Vercel은 우리가 만든 웹앱을<br>인터넷 주소로 접속할 수 있게 배포해주는 도구입니다.
오늘 실습의 마지막에는<br>내가 만든 결과물을 Vercel에 올려서<br>링크로 공유할 예정입니다.

Vercel은 GitHub에 올라간 프로젝트를 가져와서 배포하는 방식으로 많이 사용합니다.<br><br>그래서 GitHub 연결이 먼저 되어 있으면<br>Vercel 배포가 훨씬 편해집니다.

## 📁 오늘 사용할 작업 폴더
먼저 바탕 화면에 오늘 쓸 폴더를 만듭니다.
### 바탕 화면에 day1 폴더 만들기
바탕 화면에서 마우스 오른쪽 버튼을 누릅니다.<br>`새로 만들기`를 누르고 `폴더`를 선택합니다.<br>폴더 이름은 `day1`로 바꿉니다.
### day1 안에 test1 폴더 만들기
`day1` 폴더를 엽니다.<br>그 안에 새 폴더를 하나 더 만듭니다.
폴더 이름은 `test1`로 바꿉니다.<br>오늘의 첫 실습은 이 `test1` 폴더 안에서 진행합니다.
이후 실습은 `test2`, `test3`, `test4`… 폴더에서 진행합니다.
