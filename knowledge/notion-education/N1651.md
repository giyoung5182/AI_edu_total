### 프롬프트 5요소 (이것만 기억하면 됩니다)





요소

스스로에게 던질 질문




**① 역할**

AI가 누구처럼 답해야 하나? ("너는 OO 담당자야")




**② 맥락**

어떤 상황·배경 데이터인가?




**③ 지시**

정확히 뭘 시키나? (한 문장으로)




**④ 형식**

결과물의 모양은? (분량·톤·구조: 요약형/분석형/설득형)




**⑤ 제약**

지킬 규칙·금지사항은? ("없는 수치 지어내지 마", "A사로 익명화")



결과가 애매하면 "5요소 중 뭐가 빠졌지?"부터 물어보세요.

### 나쁜 프롬프트 고치기 3단계
```javascript
1단계) 일단 막연하게 써본다     예) "생산 지연 보고서 써줘"
2단계) 빠진 요소를 찾아 채운다   → 역할·맥락·형식·제약을 추가
3단계) 결과를 보고 짚어서 고친다  예) "1번 항목을 숫자로 바꿔줘"
```
**나쁜 예 → 좋은 예**
- 🔴 "이거 번역해줘"
- 🟢 "너는 제약 분야 전문 번역가야(역할). 아래 영문을(맥락) 한국어로 번역해줘(지시). 독자는 비전문가이니 전문용어는 괄호로 풀고, ① 3줄 요약 → ② 전체 번역 순으로(형식). 원문 수치는 바꾸지 마(제약)."

### 세션 1 · 보고서 작성
**요약형 보고서**
```plain text
역할: [직무] 담당자
상황: [오늘 발생한 이슈 2~3줄]
요청: 위 내용을 팀장에게 보고할 수 있는 일일 보고서를 요약형으로 작성해줘. 5줄 이내, 핵심만.
```
**분석형 보고서**
```plain text
역할: [직무] 담당자
상황: [최근 반복되는 패턴/수치 2~3줄]
요청: 이 데이터를 바탕으로 원인 분석과 개선 방향을 담은 분석 보고서를 작성해줘. 원인 → 영향 → 개선 방안 순으로.
```
**설득형 보고서**
```plain text
역할: [직무] 담당자
목적: [도입하고 싶은 것]
근거: [현재 손실/비용 + 기대 효과]
요청: 의사결정자를 설득하기 위한 제안 보고서를 작성해줘. "문제 → 비용 영향 → 해결안 → 기대효과" 구조로.
```
**수정 요청(Iterative Editing)**
```javascript
방금 작성한 보고서에서:
1. 첫 번째 항목을 더 구체적인 수치로 바꿔줘
2. 전체 톤을 조금 더 공식적으로 바꿔줘
3. 결론 부분을 3줄로 줄여줘
```
### 세션 2 · AI 도구 활용
**GPT에게 업무 상황 설명하기**
```plain text
안녕하세요. 저는 자동차부품 제조 기업에서 [본인 직무]를 담당하고 있습니다.
오늘 제가 해결해야 할 문제는 [문제 설명]입니다. 어떻게 도와주실 수 있나요?
```
**Genspark 심층 리포트 검색어 예시**
```javascript
"[업계/주제] 최신 동향 및 원인 분석"
"[업계] 원가 절감 사례"
```
**프로세스 시각화(ChatGPT)**
```javascript
위 내용을 인포그래픽 스타일의 플로우차트로 시각화 해줘.
각 단계를 박스로 표현하고, 리스크 포인트는 별도로 강조해줘.
```
### 세션 3 · 엑셀 자동화
**VBA 코드 요청**
```plain text
나는 VBA를 전혀 모르는 비개발자야.
다음 엑셀 자동화 코드를 단계별로 설명하면서 작성해줘: [원하는 자동화 내용]
코드 작성 후, 어디에 붙여넣어야 하는지도 알려줘.
```
**여러 시트 통합**
```javascript
"[시트A]", "[시트B]", "[시트C]"의 데이터를 "통합" 새 시트에 하나로 합치는 매크로 작성해줘.
헤더는 한 번만 남기고, 마지막 열에 출처 시트 이름을 표시해줘.
```
**두 표 자동 매칭(조회 자동화)**
```plain text
"[대상 시트]" A열(기준 코드)을 기준으로 "[참조 시트]"에서 값을 찾아 채워 넣는 매크로 작성해줘.
찾는 값이 없으면 "확인 필요"로 표시하고 강조해줘. 처리 후 몇 행을 처리했는지 메시지로 알려줘.
```
**더미 데이터 생성**
```javascript
다음 형식의 엑셀 더미 데이터를 20행 만들어줘. 표 형식으로 출력해줘.
컬럼: [컬럼명과 형식 나열]
```
### 세션 4 · 내 프로젝트 기획서
```javascript
나는 [직무] 소속 기업 임직원이야.
내 업무의 문제: [문제 상황 / 현재 방식 / 개선 목표]
AI 솔루션으로 만들고 싶은 것: [입력 데이터 / 원하는 출력물 / 성공 기준]
이 내용을 바탕으로 AI 프로젝트 기획서를 작성해줘.
다음 항목으로 구성해줘: 1) 문제 정의 2) AI 활용 방안 3) MVP 기능 정의(핵심 3가지) 4) 성공 기준(수치 포함)
```
### 세션 5 · 입력 데이터 설계
**입력 템플릿 설계**
```plain text
내가 만들 AI 솔루션은: [직무 / 목적 / 처리할 데이터]
이 솔루션에 데이터를 입력하기 위한 엑셀 템플릿을 설계해줘.
컬럼 수 최대 10개, 데이터 타입 명시, 예외 케이스 처리 방법 포함, 예시 데이터 5행 포함.
```
**더미 테스트 데이터 생성**
```plain text
앞에서 설계한 [솔루션명] 입력 템플릿에 들어갈 현실적인 테스트 데이터 15~20행을 만들어줘.
정상 케이스 70%, 이상/예외 케이스 30% 포함. 이상 케이스 목록도 함께 정리해줘.
```
### 세션 6 · 에이전트 시스템 프롬프트 (Genspark / GPTs 공통)
```plain text
당신은 [직무] 전문가 AI 어시스턴트입니다.
역할: [솔루션 목적] 전문 분석가
입력 받을 데이터: [형식 / 주요 컬럼]
처리 방법: 1) [이상 항목/핵심 이슈] 탐지 2) [유형 분류 기준]에 따라 분류 3) [우선순위/위험도] 판단
출력 형식: 분석 요약 / TOP 3 우선 처리 항목 / 전체 분류 결과 / 다음 단계 액션 아이템
규칙: 입력 데이터에 없는 정보는 절대 만들지 않는다. 불확실한 항목은 "확인 필요"로 표시한다.
```
### 세션 7 · 발표 시나리오
```javascript
내가 만든 AI 솔루션을 짧고 임팩트 있게 발표할 시나리오를 작성해줘.
프로젝트 정보: [이름·직무 / 해결한 문제 / 만든 솔루션 / 주요 기능 / 기대 효과]
시나리오 구조: ① 상황 설명 ② 라이브 데모 입력 ③ 결과 설명 ④ 활용 방안 + 기대 효과
발표하는 사람이 자연스럽게 읽을 수 있도록 구어체로 작성해줘.
```
**발표 슬라이드 HTML (라이브 데모 보완용)**
```javascript
아래 발표 시나리오 내용을 바탕으로, 발표용 슬라이드 1장을 HTML 파일로 만들어줘.
발표 내용: [이름·직무 / 해결한 문제 / 만든 솔루션 / 주요 기능 / 기대 효과]
요구사항: CSS 포함 단일 HTML 파일, 문제→솔루션→기대효과 순서, 큰 글씨·넉넉한 여백,
스크린샷/표 대신 핵심 메시지와 숫자만 크게 표시.
```
