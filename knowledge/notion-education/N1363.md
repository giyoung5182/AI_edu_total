## 이 실습으로 하는 것
엑셀 데이터를 기반으로 프로젝트를 관리하는 프로그램을 Codex(Antigravity)로 만들고, 완성된 Python 코드를 다른 사람도 쓸 수 있는 .exe 실행파일로 바꾸는 흐름을 익힙니다.
## 진행 단계
1. **만들 프로그램 설명** — 만들고 싶은 프로그램(엑셀 데이터 기반 종합 프로젝트 관리)을 Codex(Antigravity)에게 설명
2. **코드 작성·실행·수정** — AI가 작성한 코드를 실행해 보고 결과를 보며 수정 요청. 작게 만들고 실행해 보고 계속 개선
- 규칙이 정해진 처리(컬럼명 통일, 결측치 처리, 날짜 형식 통일, 여러 파일 취합)는 한 번 만든 코드를 AI 없이 반복 실행 가능
3. **exe 실행파일 요청** — 다른 사람이 Python 설치 없이 더블클릭으로 쓰도록 요청
- 입력할 내용:
```javascript
이 Python 코드를 다른 사람도 쉽게 쓸 수 있도록
Windows 실행파일(.exe)로 만들어줘
```
- 정상 결과: 실행 코드 정리, 필요한 라이브러리 정리, 실행파일 빌드 명령어, 배포 시 주의사항을 함께 안내
## 막히는 지점
- 교안에 별도 기재 없음. 다만 코드 그대로는 사용자 PC에 Python 설치·라이브러리 설치·터미널 실행이 필요하다고 안내(그래서 exe로 패키징)
