# 내 프로젝트 주제 정하고 화면 이미지 Padlet에 올리기

정리일: 2026-10-08 · 교육 에셋 N0510

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 일에서 번거로운 일 하나를 골라 Gemini와 PRD로 정리하고, 만들 화면을 이미지로 그려 Padlet에 올립니다.
## 진행 단계
1. **Gemini와 아이디어 잡기** — 번거로운 일을 동료에게 푸념하듯 적어 Gemini와 방향을 잡습니다.
- 입력할 내용:
```javascript
요즘 이런 일이 번거로운데, 단일 html로 간단히 풀 방법이 있을까?
[여기에 번거로운 일을 한두 줄로 적습니다]
```
- 정상 결과: Gemini가 입력칸·자동 계산·결과 표시 방향을 몇 가지 제안함
1. **PRD 만들기** — 대화 내용을 입력·처리·결과로 정리시킵니다.
- 입력할 내용:
```javascript
지금까지 이야기한 내용을 PRD로 정리해줘. 무엇을 입력하고, 어떻게 처리하고, 무엇을 보여줄지가 들어가게.
```
- 정상 결과: 입력·처리·결과로 묶인 설명서 한 장
1. **문서·툴 방향 정하기** — 읽기만 하면 되면 문서, 값을 넣고 결과를 받아야 하면 툴로 정합니다.
2. **화면 이미지 그리기** — PRD로 화면 이미지를 그리게 하고 필요하면 수정을 요청합니다.
- 입력할 내용:
```javascript
이 PRD대로 만들 화면을 이미지로 그려줘.
```
```javascript
결과를 화면 위쪽에 크게 보여주고, 입력칸은 아래로 모아줘.
```
```javascript
PRD 기준으로 문제 상황과 해결 방안을 4컷 만화로 그려줘
```
1. **Padlet에 공유하기** — 마음에 드는 이미지를 Padlet에 올리고 1분간 아이디어를 소개합니다.
## 막히는 지점
- 실제 계약명·사람 이름·금액은 빼거나 가짜로 바꿔서 입력
- 이 이미지는 아직 코드가 아니며, 코드 변환은 3교시(Stitch)부터
- 순수 HTML 한계: 함께 보기·수정, 영구 보관, 로그인·권한, 자동 발송·기록, 실시간 외부 정보
