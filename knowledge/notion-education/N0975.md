```plain text
현장은 [규모·용도]이며 상주 인력은 [인원]명입니다.
이 문서는 [수신처]에 [시점]까지 제출하는 [문서명]입니다.

1) 자료에서 점검 시각별로 항목을 분리하세요.
2) 기계 / 전기 / 소방 / 승강기 / 방재 / 기타로 분류하세요.
3) 측정값이 있는 항목과 없는 항목을 구분해 표시하세요.
4) 관리기준을 벗어났거나 조치가 필요한 항목만 골라내세요.
5) 조치 시급도 순으로 정렬하세요.

미측정·미실시 항목은 그대로 기재하고 사유를 함께 적으세요.
설비 이상의 원인을 단정하지 마세요. 원인 추정은
"~로 추정되며 확인 필요함" 형태로만 쓰세요.
"만전을 기하겠음" "지속적인 관리" 같은 관용 문구는 쓰지 마세요.

아래는 [자료명] 원문입니다. 여기 적힌 사실만 사용하세요.
```
## 체크리스트 판정 검증
```plain text

다음을 표로 정리해 주세요.

1) 관리기준을 벗어났는데 판정이 "양호"로 기재된 항목
2) 측정값이 비어 있는데 판정이 기재된 항목
3) 기준값 자신이 기재되지 않은 항목
4) 판정 표기가 서로 다른 것 (양호 / 정상 / ○ 등)
5) 단위가 섞여 있는 항목

각 항목마다 기준값과 측정값을 나란히 보여 주세요.
판정을 다시 매기지는 마세요. 어느 항목을 다시 봐야 하는지만 알려 주세요.
```

# 3. 성장사업본부
## 실적 데이터 정리 (제안서 전 필수 단계)
```plain text
첨부는 [기간] 용역 실적 데이터입니다.
제안서에 넣기 전에 먼저 정리가 필요합니다.

1) 본부명·현장명 표기가 갈라진 것을 대표 명칭으로 통일하세요.
2) 금액 단위를 전부 백만원 기준으로 환산하고,
   환산한 행을 목록으로 보여 주세요.
3) 연도별·사업부문별 수주 금액과 건수를 집계하세요.
4) 재계약 건과 신규 건을 구분해 재계약률을 계산하세요.
5) 같은 현장이 반복 등장하는 경우를 찾아 연속 수행 기간을 계산하세요.

환산이나 통합 과정에서 판단이 애매했던 행은 [확인 필요]로 표시하세요.
제가 제공하지 않은 실적·현장명·인증명은 절대 추가하지 마세요.
```

2번을 반드시 넣으십시오. 이 지시가 없으면 **15.2억이 15.2백만원으로 합산**됩니다.

```plain text
당신은 건물 에너지 진단과 설비 효율 개선 사업을 수행해 온 에너지 담당자입니다.

첨부는 [현장명]의 [기간] 에너지 사용량 데이터입니다.

1) 전력·상수도·가스를 각각 전월 대버·전년 동월 대뱄로 정리하세요.
2) 증감폭이 특이한 항목을 골라내세요.
3) 계절 요인으로 설명되는 부분과 설명되지 않는 부분을 구분하세요.
4) 설명되지 않는 부분에 대해 추가 확인이 필요한 사항을 적으세요.
5) 위 결과를 진단보고서의 에너지 사용 실적 장으로 작성하세요.

삭감 원인을 단정하지 마세요. "~로 인한 것으로 분석됨"은
근거 데이터가 있을 때만 쓰고, 없으면 "확인 필요함"으로 적으세요.
```
