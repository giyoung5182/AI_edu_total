# 공무팀 Quick Win 실습

정리일: 2026-10-08 · 교육 에셋 N0578

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
앞의 예시 프롬프트는 참고용이고, 이번에는 내 업무로 직접 RCTCK 프롬프트를 만들어 실행합니다.
## 진행 단계
1. **자동화하고 싶은 업무 고르기 (3분)** — 후보 예시: 시공 완료 후 제출 보고서, 구두 합의·메신저 → 공문 변환, 견적서 → 반입 체크리스트, 견적서 수량·단가 계산 오류 검증, 일일 현장 보고서, 업무 협조 요청·계약 공문. "나는 이것을 자동화하고 싶다: ___"로 선택한 업무를 적습니다.
2. **RCTCK 워크시트 작성 (10분)** — R(역할), C(상황), T(작성할 문서와 구성), C(제약: "\~하였습니다" 공문 스타일, 금액 숫자+한글 병기, 추가 조건), K(실제 자료 붙여넣기)를 채웁니다. 자료 복사: 견적서는 텍스트 드래그 복사, 카카오톡은 대화 선택 복사, 손글씨 메모는 Gemini에 사진을 찍어 텍스트 추출 후 붙여넣기.
3. **Claude 실행 (10분)** — 프롬프트를 claude.ai 새 대화에 붙여넣고 실행한 뒤 4가지를 확인합니다.
- 정상 결과: 확인 1 문체가 공문체인가 / 확인 2 금액이 숫자+한글로 병기됐는가 / 확인 3 표가 마크다운 형식인가 / 확인 4 K 자료를 제대로 반영했는가
4. **강사 피드백 (12:30\~12:50)** — 결과물을 화면에 띄우고 강사와 함께 확인합니다. 만든 프롬프트는 저장해 두고, 매번 쓰는 문서는 Gemini Gems에 세팅하면 더 빠릅니다.
## 막히는 지점
- 공문체가 아니면: C에 "반드시 공문 스타일로" 명시 후 재실행
- 금액 한글 병기가 없으면: 체이닝으로 "금액을 한글 병기로 다시 써줘"
- 표가 마크다운이 아니면: T에 "표는 마크다운 형식으로 출력" 추가
- K 반영이 부족하면: K 자료를 더 구체적으로 붙여넣기
