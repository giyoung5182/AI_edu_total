# 실습 3 | 교육기관 Gems 직접 만들기

정리일: 2026-10-08 · 교육 에셋 N1145

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
교안의 완성 예시를 분석한 뒤 본인 업무에 맞는 Gems 시스템 프롬프트를 직접 쓰고 등록·테스트합니다. (25분)
## 진행 단계
1. **STEP 1 표준 예시 확인 + 프롬프트 분석 (4분)** — 완성된 Gems 1(고객 상담 비서) 시스템 프롬프트의 각 줄이 왜 들어갔는지 봅니다. (역할 범위 제한, 제품 정보 짧게 요약, "지어내지 않기" 명시)
2. **STEP 2 시스템 프롬프트 작성 (6분)** — Gems 1(고객 상담)·2(마케팅 기획)·3(제품 본문) 중 하나를 골라 ① 역할 ② 가장 중요한 제품 정보 2\~3개 ③ 출력 형식(길이·톤·형태) ④ 절대 금지 표현을 채우고 하나의 시스템 프롬프트로 합칩니다.
3. **STEP 3 Gemini Gems에 등록 (8분)** — gemini.google.com → 왼쪽 사이드바 Gems → + 새 Gem 만들기 → 이름 입력 → 지시사항에 \[공통 기본 설정\] + \[직접 작성한 시스템 프롬프트\] 순서로 붙여넣기 → 저장.
4. **STEP 4 실제 업무 소재로 테스트 (7분)** — 선택한 Gems에 맞는 테스트 입력(고객 DM 답변, 주간 소재 7개 표, 제품 본문 3종 등)을 넣어 봅니다.
5. **STEP 5 체이닝으로 다듬기 + 완성 판단** — "\[이 부분\]이 마음에 안 드는데, \[이 방향\]으로 수정해줘. 나머지는 그대로 유지해줘"처럼 이어 요청하고, 완성 기준(금지 표현 없음, 브랜드 느낌, 바로 보낼 수준, 누가 써도 동일 품질)을 확인합니다.
## 막히는 지점
- 역할이 생각나지 않으면 매일 반복하는 업무 1가지를 역할로 쓰기
- 너무 길게 쓰려고 하지 말고 짧게 시작해 쓰면서 추가
- Gemini Gems는 팀원 간 직접 공유 링크 기능이 제한적이라 시스템 프롬프트를 팀 노션에 올려 두고 각자 붙여넣는 방식 권장
