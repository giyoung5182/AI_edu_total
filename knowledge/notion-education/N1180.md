# 실습 3 — 비정형 텍스트 데이터를 표로 변환하기

정리일: 2026-10-08 · 교육 에셋 N1180

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
서식이 제각각인 메모 텍스트를 Copilot으로 구조화된 표로 변환합니다.
## 진행 단계
1. **샘플 선택** — 샘플 A(자문 의뢰 메모), B(주간 업무 보고 메모), C(고객 응대 이력 메모) 중 하나. 맞는 게 없으면 기존 메모를 가상 데이터로 치환하거나 Copilot에게 가상 샘플 생성을 요청.
- 입력할 내용(샘플 C 예, 샘플 데이터 본문은 교안 참고):
```javascript
아래 고객 응대 이력을 표로 정리해줘.
컬럼: 날짜, 고객명, 문의 유형, 처리 상태, 담당자
날짜는 YYYY-MM-DD 형식으로 통일해줘.
누락된 항목은 "미확인"으로 표시해줘.

(이하 교안 참고)
```
1. **결과 검토** — 날짜가 YYYY-MM-DD로 통일되었는지, 누락값이 "미배정"/"미확인"으로 처리되었는지, 구분자가 섞여도 열이 올바르게 분리되었는지 확인
2. **후속 프롬프트로 개선**
```javascript
날짜 열에서 연도가 빠진 항목은 2025년으로 채워줘.
이름에서 직책(대리, 과장 등)이 포함된 경우 직책을 별도 열로 분리해줘.
```
1. **Excel 적용** — 완성된 표를 Excel에 붙여넣고 `Ctrl + T`로 표 서식 적용
- 정상 결과: 이후 필터·정렬을 바로 쓸 수 있는 데이터베이스 형태
## 막히는 지점
- 기밀 정보는 입력 금지, 가상 내용으로 대체
- 데이터가 복잡·모호하면 결과가 의도와 다를 수 있으니 항상 검토
