# 4️⃣ 실습: 나만의 업무 병목을 PRD로 쓰기

정리일: 2026-10-08 · 교육 에셋 N0393

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
반복되는 업무 병목 하나를 골라 I-L-O로 분해하고 AI에 붙여넣을 PRD 초안을 만듭니다.
## 진행 단계
1. **주제 고르기** — A 트랙(내가 매주 반복하는 일 중 줄이고 싶은 것) / B 트랙(팀원이 자주 막히는 일) / C 트랙(한 번도 시도해 보지 않은 영역) 중 하나. 오늘 끝까지 설명하고 검증할 수 있는 문제를 고릅니다.
2. **I-L-O 작성하기**
- 입력할 내용:
```javascript
선택 트랙(A/B/C):
문제:
활용 상황:
Input:
Logic:
Output:
예외 상황:
데이터 보안 조건:
```
3. **PRD로 확장하기** — 사용 상황 / 입력값 / 처리 규칙 / 출력 형식 / 디자인 가이드 / 구현 제약(HTML, CSS, JavaScript만 사용, 하나의 HTML 파일, 브라우저에서 바로 실행) / 데이터 보안 조건 템플릿을 채웁니다.
- 흐름: 주제 선택 → I-L-O → 예외 상황 정리 → 데이터 보안 조건 확인 → PRD 완성
## 막히는 지점
- 실제 고객명·임직원 개인정보·계약·매출·인사 정보는 입력하지 않고 더미 데이터를 사용합니다.
