# 실습 C-1 | 회의록 RCTCK 프롬프트 직접 작성하기

정리일: 2026-10-08 · 교육 에셋 N0482

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Clova Note 녹취록을 공식 회의록과 액션아이템 표로 변환하는 RCTCK 프롬프트를 작성합니다.
## 진행 단계
1. **녹취록 준비** — 교안 4-2 기준: 앱에서 녹음 → 자동 텍스트 변환(1\~5분) → 전체 복사 (실습에서는 녹취록 샘플 사용)
2. **빈칸 워크시트 작성** — R·C·T·C·K
3. **표준 작성본과 비교**
- 입력할 내용(표준 작성본 요약):
```javascript
R: 너는 공공기관 회의록 작성 경력 7년의 행정 담당자야. 결정 사항과 논의 내용을 명확히 구분하고, 회의에서 언급되지 않은 내용은 단 한 줄도 추가하지 않아. 액션아이템은 반드시 담당부서·업무내용·완료기한 세 가지 요소를 갖춰야 해.
C: 교육기관 33 상반기 실적 점검 회의 녹취록을 회의록으로 정리해야 해. 원장님이 직접 확인하고 기안 결재를 받는 공식 문서야.
T: 1. 회의 기본 정보 2. 보고 사항 요약 3. 논의 주요 내용 4. 핵심 결정 사항 5. 액션아이템 표(순번 | 담당부서 | 업무 내용 | 완료 기한 | 비고) 6. 다음 회의 예상 안건
C: 녹취록에서 명확히 언급된 내용만 포함. 화자 이름이 미상인 경우 "화자 미상 (직급 추정)". 기한이 언급되지 않은 항목은 "기한 미정 - 담당자 확인 필요". 단계별로 차근차근 생각하면서 작업해줘.
K: 아래는 우리 부서가 사용하는 회의록 양식이야. 이 형식 그대로 작성해줘. [기존 회의록 양식] [Clova Note 녹취록 샘플 전문]
```
4. **비교 체크리스트** — "언급되지 않은 내용 추가 금지" 원칙, 액션아이템 필수 3요소, 표 컬럼 \| 구분자, "다음 회의 안건", "기한 미정" 처리, CoT 문장, 양식과 녹취록 구분
## 막히는 지점
- Clova Note는 전문 용어가 분리될 수 있고 잡음 환경에서 인식률이 떨어지며 화자 이름은 수동 입력
