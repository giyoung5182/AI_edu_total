# 2-9. 실습 1 — 오픈이노베이션 스타트업 모집 포스터

정리일: 2026-10-08 · 교육 에셋 N0628

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
레퍼런스를 시각 언어로 분해해 만든 프롬프트(A·B·C 중 하나)로 스타트업 모집 포스터를 생성하고, 이미지 안 한글을 검수·부분 수정한 뒤 본인 부서 사업으로 바꿔 한 번 더 만듭니다.
## 진행 단계
1. **프롬프트 A · B · C 중 하나를 고르세요 (1분)** — 처음이면 C를 권합니다. 가장 안정적으로 나옵니다.
- A: 짙은 남색 단색 배경 + 청록 반투명 곡선 + 원형 발광 오브젝트 / B: 밝은 회백색 배경 + 남색·주황 곡선 띠 / C: 짙은 남색 배경 + 반투명 청록 원 세 개와 평행선 (도형 중심)
- 입력할 내용(프롬프트 C의 그래픽 구성 부분, 텍스트 항목은 프롬프트 A의 것을 그대로 사용):
```javascript
공공기관 스타트업 모집 포스터를 만들어 줘.
[프롬프트 A의 텍스트 항목은 그대로 사용하되 아래로 교체]

[전체 형식]
- 세로 3:4 비율, 고해상도
- 배경: 짙은 남색 단색 (#12225C)

[그래픽 구성]
- 화면 중앙 우측에 크기가 다른 원 세 개를 겹쳐 배치해 줘
- 원은 각각 반투명한 청록색이고, 겹치는 부분은 더 밝게 표현해 줘
- 가장 큰 원은 화면 우측 가장자리에서 일부 잘려 나가게 배치해 줘
- 화면 좌측 하단에 가는 흰색 선 여러 개를 평행하게 그어
  대각선 방향 질감을 만들어 줘
- 색은 짙은 남색, 청록, 흰색 세 가지만 사용해 줘
- 도형 외에 다른 그래픽은 넣지 말아 줘
(이하 교안 참고)
```
1. **복사해서 붙여넣고 1회 생성 (2분)**
2. **검수 프롬프트로 한글 확인 (2분)** — 특히 전화번호와 모집기간을 확인합니다.
- 입력할 내용:
```javascript
이 이미지 안에 들어간 한글 텍스트를 전부 읽어서 그대로 적어 줘.
순서는 위에서 아래로.
```
- 정상 결과: 읽어 준 내용과 지시한 문구가 한 글자씩 일치
1. **틀린 곳을 부분 수정 (3분)** — 재생성이 아니라 수정입니다.
- 입력할 내용:
```javascript
전체 구성과 색은 그대로 두고,
[잘못된 글자]라고 적힌 부분만 [올바른 글자]로 고쳐 줘.
```
1. **본인 부서 사업으로 문구를 바꿔 한 번 더 생성 (4분)** — 부서별 치환표(사업명·제목 문구 예시)를 참조합니다.
## 완료 기준
- 이미지 안 한글을 전부 읽어서 대조했다 / 전화번호와 날짜가 정확하다 / 색이 세 가지 이내다 / 글자가 그래픽에 묻히지 않는다 / 상단과 하단 여백이 확보되어 있다 / 레퍼런스를 그대로 베끼지 않았다 / 파일을 다운로드했고 프롬프트를 저장했다
## 막히는 지점
- 한글이 계속 깨질 때: 카드 블록 두 개를 하나로, 최하단 주최·주관 줄 삭제, 본문 세 줄을 두 줄로, 그래도 안 되면 문구를 빼고 배경만 생성한 뒤 파워포인트에서 얹기(1권 Part 3 방식)
- 숫자와 날짜는 틀리면 배포 사고이므로 특히 주의
