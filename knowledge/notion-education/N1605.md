<summary>**☑️ CASE WHEN을 통해 조건에 따라 다른 결과값을 부여해요!**</summary>
CASE WHEN절은 아래와 같은 기본 구조를 가지고 있어요.
**WHEN은 조건에 따라 더 추가 할 수 있어요. 조건식을 모두 만족하지 않을 경우, **
**ELSE로 간주되게 됩니다.  **
```sql
SELECT CASE WHEN 조건식1 THEN 결과1
            WHEN 조건식2 THEN 결과2
            ELSE 결과3
            END AS 새로운 컬럼이름
FROM 테이블명
;
```
앞서 살펴보았던 THEGLORY 테이블에서, 이름이 ‘문동은’ 이거나 ‘주여정’ 인 경우를 ‘선’ 으로,
이 외의 값들은 ‘악’으로 구분하여 ‘역할구분’ 이라는 새로운 컬럼을 생성해볼게요!
```sql
select * ,
case when 이름 in ('문동은', '주여정') then '선'
                else '악' end as '역할구분'
from basic.theglory
;
```

SELECT *
FROM basic.theglory
WHERE 날짜 IS NOT NULL
AND (성별!='M')
AND (직업 IN('아나운서','승무원','화가'))
AND (나이 BETWEEN 30 AND 40) -- 30 이상, 40 이하

전체 데이터를 기준으로 조회할 때는 GROUP BY절이 필요하지 않지만,
**특정 컬럼을 기준으로 데이터를 요약해서 비교**하고 싶을 때 주로 사용해요.
**SQL 작성방법은 아래와 같아요. **
- 1️⃣** SELECT 뒤 기준컬럼(나라, 성별, 레벨..등등) 작성**
- **2️⃣ 집계함수(COUNT, MAX, MIN, AVG, SUM) 작성**
- **3️⃣ WHERE 절 뒤 GROUP BY 기준컬럼 작성 (WHERE 절은 생략 가능합니다.)**
- ⚠️**주의할 점**

1️⃣, **2️⃣번 작성 후, 3️⃣번을 작성하지 않을 경우 에러가 발생됩니다. <br>그 이유는, 데이터를 SELECT할 때, 2️⃣**번 **집계함수는** 여러 데이터로부터 **하나의 행을 반환**하지만, 1️⃣번 **기준컬럼은 N 개의 값을 반환**하기 때문에,  **3️⃣****번 GROUP BY 절을 사용하여 기준컬럼 당 값 1개를 반환 할 수 있도록 명시해야 합니다. <br><br>**✨여기서 잠깐! **위에서 전체 데이터를 기준으로 살펴보았다면, 이번엔 기준을 ‘성별’로 두어볼까요? **
그럼 아래와 같이, 성별 집계함수를 사용할 수 있게 됩니다! 🙂
- 성별 기준 데이터 갯수= 성별`(기준)` + 데이터 갯수`(집계함수)`
- 성별 기준 평균 나이= 성별`(기준)` + 평균 나이`(집계함수)`
- 성별 기준 최대 나이= 성별`(기준)` +최대 나이`(집계함수)`
- 성별 기준 최소 나이= 성별`(기준)` + 최소 나이`(집계함수)`
- 성별 기준 나이 합계 = 성별`(기준)`+ 나이 합계`(집계함수)`
```sql
# 집계함수와 GROUP BY 절을 함께 사용하는 SQL문 - 실습

select 성별 # 기준 컬럼 🚩
, count(*)as cnt #집계함수 ✅
, avg(나이)as avg_age #집계함수 ✅
, max(나이)as max_age #집계함수 ✅
, min(나이)as min_age #집계함수 ✅
, sum(나이)as sum_age #집계함수 ✅
from basic.theglory
group by 성별 # 기준 컬럼 🚩
```

<summary>**☑️ HAVING ≠ WHERE !  **</summary>
Having절은 Group By에 의한 결과를 필터링 할 때 사용됩니다.
SQL 구문에서는 Group By 절 뒤에 위치해요.
데이터 필터링이라는 기능을 가지고 있는 WHERE 과의 차이점은 아래와 같아요.
**WHERE절은 Group By 전 데이터를 기준으로 필터링, HAVING절은 Group By후 **
결과값을 기준으로 데이터를 필터링합니다. 차이점을 꼭 기억해주세요!





**필터링 구문**

**필터링 시점**




WHERE

**GROUP BY 전 데이터 필터링**




HAVING

**GROUP BY 후 결과값을 가지고 데이터 필터링**


```sql
# 집계함수, GROUP BY절, HAVING을 함께 사용하는 SQL문

select 기준컬럼, 집계함수(조건컬럼을 기준으로 여러개의 집계함수 동시사용 가능)
from 테이블명
where 조건 #(생략가능)
group by 기준컬럼
having 조건식
;
```

theglory 테이블을 기준으로, 실제 SQL구문을 작성해 보겠습니다.
**차례로 **아래 조건들을 살펴볼게요!
- 1️⃣ **나이가 31세 이상이고, **
- **2️⃣ 성별을 기준으로 평균 나이를 구하고,**
- **3️⃣ 평균 나이가 41초과인 경우**
 1️⃣은 전체 데이터에 대한 필터링이예요. 따라서, WHERE 절을 사용해야 합니다.
** 2️⃣는 집계함수와 GROUP BY 를 사용해서 작성해 주어야 합니다. **
** 3️⃣은 GROUP BY 된 결과값을 필터링 해야 하므로, HAVING 절을 사용해야 합니다. **
```sql
# 집계함수, GROUP BY절, HAVING을 함께 사용하는 SQL문 - 실습
select 성별, avg(나이)as avg_age 2️⃣
from basic.theglory
where 나이>=31 1️⃣
group by 성별 2️⃣
having AVG_AGE>41 3️⃣
```

🏅**중첩(일반) 서브쿼리**
- WHERE 절에서 사용

- **상관 서브쿼리**: 메인 쿼리의 컬럼을 참조 → 각 행마다 반복 실행됩니다.
