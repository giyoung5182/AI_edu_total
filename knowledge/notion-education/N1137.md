## 이 실습으로 하는 것
구글 시트에 새 행이 추가되면 Gmail로 알림이 가도록 Make 시나리오를 만듭니다.
## 진행 단계
1. **새 시나리오 생성** — Scenarios → Create a new scenario
2. **Google Sheets Watch Rows** — Connection 본인 구글 계정, 테스트 시트 선택, Where to start: All new rows, Limit: 1
3. **Gmail Send an Email** — To는 본인 이메일, Subject·Content에 이전 모듈(Watch Rows)의 열 변수를 삽입
4. **Run once + 테스트** — Waiting for data 상태에서 시트에 새 행을 추가하면 자동 실행, 이메일 수신 확인
5. **토글 ON** — 정상 확인 후 오른쪽 상단 토글을 Active로
## 막히는 지점
- 파일 검색이 안 될 경우: Spreadsheet 드롭다운 맨 아래 "Enter a Spreadsheet ID" 선택 후 URL의 /spreadsheets/d/ 뒤 ID 붙여넣기
- 변수 삽입: 입력창 클릭 후 나타나는 드롭다운에서 "1. Google Sheets \> Row \> B" 형태로 선택
- "Waiting for data..."가 안 끝나면: Make 새로고침 → Run once 다시 클릭 → 새 행 추가 → 1\~2분 대기
