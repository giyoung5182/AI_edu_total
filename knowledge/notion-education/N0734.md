# 9️⃣ (보너스) Canvas로 나만의 업무 웹앱 만들기

정리일: 2026-10-08 · 교육 에셋 N0734

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 01. 이번 실습에서 할 일
오늘의 하이라이트입니다. 코드 한 줄 몰라도, 자연어로 말만 하면 Gemini Canvas가 작동하는 웹앱을 만들어줍니다. 배포·서버 같은 어려운 건 없습니다. 본인 PC에서 더블클릭하면 열리는 **단일 HTML 파일** 하나를 만드는 것이 목표입니다.
순서는 이렇습니다. 먼저 Canvas로 간단한 웹앱을 하나 만들어 감을 잡고 → 실무 데이터 대신 더미 데이터를 만들고 → CDMO 수주 ROI 시뮬레이터를 '탐색 → 정교화 → 형식화' 대화로 완성한 뒤 → 마지막엔 본인 업무 웹앱을 직접 만들어 PC에 저장합니다.
- Canvas 첫 웹앱 — 자연어 한 줄로 즉석 생성
- 실무 데이터 대신 더미 데이터 만들기 (칼럼만 주고 생성)
- CDMO 수주 ROI 시뮬레이터 — 입력 폼·계산·차트·다운로드
- 본인 업무 웹앱 1건 빌드·디버깅·고도화 → 로컬 저장·더블클릭 실행
> 오늘 메인 예시는 CDMO(원료의약품 위탁개발생산) 수주 ROI 시뮬레이터입니다. 영업·생산·품질·R&D 어느 직무든, 마지막 단계에서 본인 업무에 맞는 웹앱으로 바꿔 만들게 됩니다.
---
## 02. 단계별 진행
### 1단계. Canvas 첫 웹앱 — 자연어 한 줄로
'코딩'이라는 단어는 잊으셔도 됩니다. 오늘은 Gemini에게 한국어로 부탁만 합니다. Canvas는 그 부탁을 실제로 작동하는 웹앱으로 만들어 옆 화면에 띄워줍니다.
**Canvas와 단일 HTML 한눈에 보기**
- **Canvas**: Gemini가 만든 웹앱을 옆 화면에서 미리보기 + 대화로 수정하는 모드
- **단일 HTML 파일**: 파일 하나에 화면·기능이 다 들어 있어, 인터넷 없이 더블클릭으로 실행
- **배포 불필요**: 서버·도메인 필요 없음. PC에 저장만 하면 끝
진행합니다.
1. `gemini.google.com`에서 입력창의 **+** 를 누르고 **Canvas**를 선택합니다.
2. 아래처럼 간단한 웹앱을 하나 부탁해 감을 잡습니다.
```javascript
간단한 '시약·원료 유효기간 D-day 계산기' 웹앱을 단일 HTML 파일로 만들어줘.
- 유효기간 날짜를 입력하면 오늘부터 며칠 남았는지 보여줘
- 30일 이하로 남으면 빨간색 경고
- 한국어 UI, 깔끔한 카드 디자인
```
1. 옆 미리보기에서 직접 날짜를 넣어보고, '글자 더 크게' 같은 말로 한 번 수정해 봅니다. (대화로 바로 바뀝니다)
### 직접 해보기 (6분)
위 프롬프트를 넣어 D-day 계산기를 만들고, 미리보기에서 날짜를 바꿔봅니다. 그다음 "경고 기준을 7일로 바꿔줘", "색을 더 차분하게" 같은 말로 두세 번 수정해 봅니다. 코드 없이 자연어만으로 웹앱이 바뀌는 흐름에 익숙해지는 것이 목적입니다.
### 2단계. 더미 데이터 만들기 — 실무 데이터 대신
본인 업무에서 자주 보는 표의 **칼럼만** 떠올려 아래처럼 요청합니다. 실무 데이터를 올리는 대신, 똑같은 모양의 가상 데이터를 만들어 쓰는 것입니다.
```javascript
나는 교육기관 CDMO 사업 담당자야. 수주 분석용 더미 데이터가 필요해.
아래 칼럼으로 가상의 데이터 30행을 만들어줘. (실제 데이터 아님, 학습용)
칼럼: 고객사명 / 프로젝트명 / 수주금액 / 생산원가 / 예상납기(주) / 수율(%)
CSV 형식으로 출력해줘.
```
직무별 칼럼 예시 — 본인 표를 떠올려보세요
- **CDMO 영업/사업개발**: 고객사 / 프로젝트 / 수주금액 / 생산원가 / 수율
- **생산(김천·충주)**: 라인 / 근무자수 / 교대조 / 가동시간 / 생산량
- **품질(QA/QC)**: 제품 / 일탈유형 / 발생건수 / 처리상태
- **SCM·구매**: 원자재 / 현재고 / 일평균소비 / 입고예정일
- **바이오 R&D**: 후보물질 / 단계 / 주요지표 / 다음 마일스톤
생성된 더미 데이터를 복사해 둡니다. 다음 단계 웹앱에 붙여넣습니다.
> 민감 정보 없이, 실무와 똑같은 모양의 연습 데이터가 생깁니다. 이 더미가 이후 웹앱의 재료가 됩니다. 실제 고객사명·수주 금액 등은 절대 입력하지 않습니다.
### 직접 해보기
본인 직무 칼럼으로 더미 데이터 30행을 만들어 복사해 둡니다. 위 예시를 그대로 써도 되고, 본인 표 칼럼으로 바꿔도 됩니다.
### 3단계. CDMO 수주 ROI 시뮬레이터 — 입력 폼 + 계산
이번엔 한 번에 완성형으로 부탁하지 않습니다. **탐색 → 정교화 → 형식화** 세 단계로 Gemini와 대화하며 만듭니다. 이 흐름만 익히면 본인 웹앱도 같은 방식으로 만들 수 있습니다.
**대화 흐름 미리보기 (3라운드)**: ① 탐색 — 의도만 던지고 구성안을 먼저 받기 / ② 정교화 — 받은 안에 조건 추가 / ③ 형식화 — '단일 HTML 파일로' 출력 사양 지정.
**1라운드 — 탐색.** 의도만 던지고 구성을 먼저 물어봅니다.
```javascript
[1라운드 — 탐색]
CDMO 수주 건의 수익성(ROI)을 계산하는 웹앱을 만들고 싶어.
수주금액·생산원가·예상납기·수율을 입력하면 예상 마진과 ROI가 나오게.
어떤 입력 항목과 결과 항목으로 구성하면 좋을지 먼저 제안해줘.
바로 만들지 말고 내가 확인한 후 진행해줘.
```
**2라운드 — 형식화.** 마음에 드는 구성으로 단일 HTML 생성을 지시합니다.
```javascript
[2라운드 — 형식화]
좋아, 그 구성으로 단일 HTML 파일로 만들어줘.
- 입력 폼 + 계산 결과 카드
- ROI가 마이너스면 빨강, 플러스면 초록으로 표시
- 한국어 UI, 깔끔한 디자인, PC에 저장 가능한 단일 HTML
(차트는 다음 단계에서 추가할게)
```
수주금액·생산원가·납기·수율을 넣으면 마진·ROI가 자동 계산되는 웹앱이 나옵니다. 완성형 프롬프트를 외우지 않고도 대화 몇 번으로 같은 결과에 도달합니다.
### 직접 해보기 (8분)
1라운드로 구성안을 받아 한 번 검토하고, 2라운드로 단일 HTML을 만듭니다. 미리보기에서 숫자를 넣어 ROI가 계산되는지, 음수일 때 빨강으로 바뀌는지 확인합니다.
### 4단계. 차트 + 다운로드 버튼 추가
계산만으로는 '보여주기'가 약합니다. 차트를 얹고 저장 버튼을 달면, 회의·보고에 그대로 가져갈 수 있는 웹앱이 됩니다. 위 대화를 이어서 추가합니다.
```javascript
방금 만든 ROI 웹앱에 아래를 추가해줘.
- 수율을 70%~99%까지 바꿔가며 ROI가 어떻게 변하는지 막대그래프 (Chart.js CDN 사용)
- 우측 상단에 'HTML로 저장' 버튼 — 현재 입력값까지 포함해 단일 HTML 파일로 다운로드
```
**'단일 HTML 파일로'** 라는 말이 핵심입니다. 이 문구가 있어야 인터넷 없이 더블클릭으로 열리는 독립 파일이 만들어집니다. 차트가 안 보이면 "Chart.js CDN으로 단일 HTML 다시 만들어줘"라고 한 번 더 요청합니다.
### 직접 해보기 (6분)
차트와 저장 버튼을 추가합니다. 수율을 바꿨을 때 막대그래프가 움직이는지 보고, 'HTML로 저장'을 눌러 파일이 받아지는지 확인합니다.
### 5단계. 본인 업무 웹앱 빌드 + 로컬 저장·더블클릭 검증
이제 본인 업무로 갑니다. 2단계의 더미 데이터를 재료로 '나에게 필요한 웹앱'을 만듭니다. 완벽하지 않아도 됩니다. 작동하면 성공입니다.
**직무별 웹앱 아이디어 — 본인 자리를 고르세요**
- **CDMO 영업**: 수주 ROI 시뮬레이터 / 고객사별 수주 현황 대시보드
- **생산**: 교대조 근무표 자동 생성기 / 라인 가동률 계산기
- **품질(QA/QC)**: 일탈 유형별 대응 체크리스트 / 검사 일정 트래커
- **SCM·구매**: 재고 회전·소진일 계산기
- **바이오 R&D**: 후보물질 단계 비교 보드 / 실험 일정 트래커
아래 템플릿을 본인 업무로 채워 첫 버전을 만듭니다. (변수는 \[ \]로)
```javascript
나는 교육기관 [부서/직무]야.
[무엇을 입력하면] → [무엇을 보여주는] 웹앱을 단일 HTML 파일로 만들어줘.
- 데이터는 아래 더미를 써줘 (붙여넣기)
- 입력 폼 / 계산 또는 차트 / 'HTML로 저장' 버튼 포함
- 한국어 UI, 깔끔한 디자인

[더미 데이터 붙여넣기]
```
**디버깅·고도화도 자연어로** 합니다. 예: "숫자에 천 단위 콤마", "모바일에서도 잘 보이게", "결과를 표로도 보여줘".
마지막으로 **'HTML로 저장' 버튼**(또는 Canvas 다운로드)으로 PC에 저장한 뒤, 그 파일을 **더블클릭**해 브라우저에서 인터넷 없이 열리는지 검증합니다.
### 직접 해보기 (14분)
본인 직무 웹앱을 만들고, 자연어로 두세 번 다듬은 뒤, PC에 저장해 더블클릭으로 열어봅니다.
**성공 기준**
- 단일 HTML 파일이 PC에 저장됐는가
- 그 파일을 더블클릭하면 인터넷 없이 브라우저에서 열리는가
- 입력 → 결과(계산/차트)가 작동하는가
- 본인 업무 더미 데이터로 의미 있는 결과가 나오는가
> 작동하는 단일 HTML 웹앱 1건이 PC에 남습니다. 코딩 없이도 본인 업무 도구를 직접 만들 수 있다는 감각이 생기는 것이 오늘의 핵심입니다.
## ⚠️ 주의사항
- **실무 데이터 금지**: 실제 고객사명·수주 금액·환자/임상 정보·미공개 수치는 입력하지 않습니다. 오늘은 더미 데이터로만 진행합니다.
- **외부 공유 전 확인**: 만든 웹앱을 외부로 공유하거나 업무에 정식 사용하기 전에는 사내 보안·IT 정책을 확인합니다.
- **계산 검증**: AI가 만든 계산식은 한 번 직접 검산합니다. 특히 마진·ROI처럼 숫자가 중요한 경우, 손으로 한 케이스를 확인해 식이 맞는지 봅니다.
## 핵심 정리
- Canvas는 자연어로 부탁하면 작동하는 웹앱을 만들어 옆 화면에 띄우고, 대화로 고쳐가는 모드다
- 목표는 배포가 아니라, PC에서 더블클릭으로 열리는 단일 HTML 파일 하나다
- 실무 데이터 대신 더미 데이터(칼럼만 주고 생성)로 안전하게 만든다
- 한 번에 완성형으로 시키지 말고 탐색 → 정교화 → 형식화 3단계로 대화한다
- '단일 HTML 파일로'라는 문구가 독립 실행 파일을 만드는 핵심이다
- AI가 만든 계산식은 한 케이스 직접 검산하고, 실무 적용 전 사내 정책을 확인한다
