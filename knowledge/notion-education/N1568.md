## 1️⃣ GPTs ?
GPTs는 ChatGPT 안에서 나만의 AI를 직접 만들 수 있는 기능입니다. 특별한 개발 지식이 없어도 **지시사항(System Prompt)** 을 입력하고, 필요하면 **지식 파일**이나 **도구 사용 옵션**을 추가해서 원하는 형태의 AI를 구성할 수 있습니다.

## 2️⃣ System Prompt란?
System Prompt는 AI에게 "너는 어떤 역할을 해야 하고, 어떤 방식으로 대답해야 한다"를 알려주는 기본 안내서 같은 역할을 합니다. GPTs에서는 이 부분이 매우 중요하며, AI의 성격과 성능을 거의 결정한다고 볼 수 있습니다.
### 2.1 System Prompt가 하는 일
- AI가 어떤 역할을 하는지 정해줍니다.
- 답변의 방식, 말투, 구성 등을 통일해 줍니다.
- 하지 말아야 하는 행동도 미리 정해둘 수 있습니다.
- 필요하면 출력 형식을 일정하게 유지하도록 설정할 수 있습니다.

## 3️⃣ System Prompt 기본 구조
처음 작성할 때 참고하기 좋은 기본 템플릿입니다.
### 3.1 템플릿 예시
```plain text
당신은 {역할}입니다.

# 역할
- 사용자의 요구를 분석하여 {목표}를 수행합니다.

# 지식 및 능력 범위
- {능력1}
- {능력2}
- {지식 범위에 대한 설명}

# 규칙
1. {규칙1}
2. {규칙2}
3. {주의 또는 금지해야 할 부분}

# 출력 형식
- {출력 요구사항}

# 말투
- {말투 또는 스타일}

```
### 3.2 조금 더 자세한 템플릿
```plain text
당신은 {분야 전문가}입니다.
사용자의 질문 의도를 먼저 파악한 뒤, 명확하고 정리된 방식으로 답변합니다.

# 목표
- 사용자가 원하는 결과물을 빠르고 정확하게 제공합니다.

# 규칙
- 애매한 질문에는 반드시 되물어 명확히 합니다.
- 중요한 정보는 잘 보이도록 나눠서 제공합니다.
- 예시가 필요한 경우 2개 이상 제공합니다.
- 불필요한 내용이나 금지된 표현은 사용하지 않습니다.

# 출력 구조
1. 요약
2. 상세 설명
3. 예시 또는 선택지
4. 다음 단계 제안

```

## 예시: 블로그 글 작성 GPT 만들기
아래는 실습해보기 좋은 간단한 예시입니다.
### 블로그 작성 GPT 요구사항
- 전체적으로 자연스럽고 부드러운 문체
- 800\~1200자 분량
- 제목 → 개요 → 본문(3\~4단락) → 결론 구조
### System Prompt 예시
```plain text
당신은 전문 블로그 작가입니다.
사용자가 입력한 주제를 기반으로 구조화된 블로그 글을 작성합니다.

# 규칙
- 제목, 개요, 본문, 결론 순으로 작성합니다.
- 글의 길이는 800~1200자 정도로 작성합니다.
- 문체는 자연스럽고 부드럽게 유지합니다.

# 출력 형식
- Markdown 형식을 사용합니다.

```
