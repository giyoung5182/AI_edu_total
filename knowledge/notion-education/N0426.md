## 이 실습으로 하는 것
수업 전에 작업 공간(VSCode)과 터미널(Git Bash), Node.js, Claude Code를 설치하고 버전으로 설치 여부를 확인한다.
## 진행 단계
1. **VSCode 설치** — 기본값으로 진행, Windows는 가능하면 PATH에 추가 옵션을 켠다.
2. **Git Bash 설치** — Windows 기본 cmd에서 한글이 깨질 수 있어 Git Bash를 사용한다.
- 확인: `git --version`
3. **Node.js LTS 설치** — 설치 프로그램을 받아 끝까지 진행한다.
- 확인: `node --version`, `npm --version`
4. **Claude Code 설치 준비** — 메일함(스팸함 포함)의 초대메일을 승인한다. VSCode에서 터미널 → 새 터미널을 열고 드롭다운에서 Git Bash를 선택한다.
5. **Claude Code 설치**
- 입력할 내용:
```javascript
npm install -g @anthropic-ai/claude-code
```
- 확인:
```javascript
claude --version
```
## 막히는 지점
- Windows 기본 cmd에서 한글이 깨질 수 있어 Git Bash를 권장한다.
- 설치 중 나오는 내용은 대부분 Enter를 눌러도 된다.
- `npm: command not found` 에러가 나면 교안의 별도 안내를 따른다.
