# 실습 2 — 문의 메일 분류

정리일: 2026-10-08 · 교육 에셋 N1084

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 메일 20건을 한 줄 프롬프트(1차)와 유형·출력 형식·보류 규칙을 넣은 프롬프트(2차)로 분류해 결과를 비교합니다.
## 진행 단계
1. **파일 열기** — 메모장으로 열어 전체 선택(Ctrl+A) → 복사
2. **1차 시도** — 아래 한 줄만 입력 + 메일 본문 붙여넣기
- 입력할 내용:
```javascript
아래 고객 문의 메일을 유형별로 분류해줘.
```
3. **결과 기록** — 분류된 건수, 유형 개수, 근거를 밝혔는지 표에 기록
4. **2차 시도** — **새 대화창**에서 개선한 프롬프트로 재실행
- 입력할 내용(표준 답안):
```javascript
아래 고객 문의 메일 20건을 다음 6개 유형으로 분류하라.

유형:
1. 견적·계약   2. 기술 문의   3. 클레임·품질 이의
4. 자료 요청   5. 납기·일정   6. 신규 거래

출력 형식: 표 (메일번호 | 발신자 | 유형 | 판단 근거 한 줄)

주의:
- 두 유형에 걸치면 주된 유형 하나만 고르고 근거에 "복합" 표기
- 판단이 애매한 건은 "판단 보류"로 표기하고 이유를 적을 것
- 유형을 임의로 추가하거나 바꾸지 말 것

[메일 본문 붙여넣기]
```
5. **비교** — 판단 보류 3건(MAIL-06, MAIL-13, MAIL-20)이 잡혔는지 확인
- 정상 결과: 애매한 3건이 "판단 보류"로 잡히면 프롬프트가 잘 설계된 것
## 막히는 지점
- 2차는 **새 대화창**에서 해야 합니다. 같은 창에서 하면 1차 답을 참고해 순수한 비교가 안 됩니다.
