# ③ 글자 입력과 배치

**실습 순서**
**Step 1.** 엑셀 파일의 `명함 설계·검수` 시트를 엽니다.
**Step 2.** `C8`에서 가장 크게 보여줄 항목을 확인하고, 실제로 캔바에 옮길 문구는 `C9:C15`에서 확인합니다. `C8`은 강조할 항목을 정하는 칸이므로 글자 자체를 복사하지 않습니다. 선택하지 않은 QR과 뒷면 내용(`C16:C19`)은 이 단계에서 넣지 않습니다.

수강생은 별도로 이미지를 찾거나 엑셀에 기록하지 않습니다. 강사가 명함 레퍼런스 한 장을 화면에 띄우고 아래 순서로 분석합니다.
**Step 1.** 첫눈에 어떤 요소가 보이는지 말합니다.
**Step 2.** 이름·하는 일·연락처가 어떤 순서로 읽히는지 짚습니다.
**Step 3.** 색과 글자, 여백이 만드는 분위기를 쉬운 말로 설명합니다. 예: `밝은 바탕과 짙은 글자를 써서 차분하고 또렷해 보인다.`
**Step 4.** 참고할 요소 한 가지를 골라 캔바에서 색·서체·배치 중 하나를 적용하는 모습을 보여줍니다.
추가 시연에서는 레퍼런스 세 장을 ChatGPT에 넣어 표로 비교하는 방법을 보여줄 수 있습니다. 아래 지시문은 강사 시연용이며 워크시트 과제가 아닙니다.
```plain text
첨부한 명함 레퍼런스 세 장만 보고 비교해 줘. 보이지 않는 브랜드 정보나 의도는 추측하지 말고, 화면에서 확인되는 근거를 적어 줘.

| 레퍼런스 | 첫눈에 보이는 요소 | 정보를 읽는 순서 | 색과 톤 | 디자인 느낌을 쉬운 말로 표현 |

표 아래에 공통 구성 순서, 서로 다른 색과 분위기, 참고할 요소 두 가지와 이유를 정리해 줘. 색·글자·여백·배치에서 확인한 근거를 들어 설명하고, 디자인 자체를 새로 만들지는 마.
```

# GPT로 디자인을 점검하고 시안을 개선합니다 · 강사 시연
**강사 시연 · 디자인 개선 요청**
수강생은 캔바에서 본인 명함 앞면을 완성합니다. AI 디자인 점검은 강사 시연으로 진행합니다. 강사가 화면을 캡처해 ChatGPT에 첨부하고, 아래 지시문으로 피드백을 받은 뒤 수정 제안 한 가지를 캔바에 반영합니다. 수강생은 어떤 피드백이 구체적이고 실제로 적용 가능한지 살펴봅니다.
이미지·HTML 시안 생성은 선택 강사 시연입니다. 아래 요청문은 참고용이며, 수강생 실습에는 포함하지 않습니다.
### 디자인 개선 피드백 요청
```plain text
첨부한 이미지는 내가 캔바에서 만든 명함 앞면이야. 문구를 새로 쓰거나 사실을 추측하지 말고, 디자인만 검토해 줘.

아래 기준을 표로 정리해 줘.
| 기준 | 화면에서 확인되는 점 | 개선이 필요한 이유 | 캔바에서 바꿀 구체적인 방법 |

확인 기준:
- 이름·상호·한 줄 소개 중 무엇이 먼저 보이는가
- 정보를 읽는 순서가 자연스러운가
- 글자와 배경의 대비가 충분한가
- 글자와 요소의 정렬이 맞는가
- 정보 묶음 사이에 여백이 있는가

중요한 수정 제안은 세 개까지만 적어 줘. '더 세련되게'처럼 막연하게 말하지 말고, 어떤 요소를 선택해 어디로 옮기거나 크기·색을 어떻게 바꿀지 구체적으로 적어 줘. 마지막에 이 디자인의 느낌을 쉬운 말 한 문장으로 표현해 줘.
```
### 이미지 시안 요청
아래 내용을 채워 GPT의 이미지 생성 기능에 요청합니다. 명함 정면이 평평하게 보이도록 하고, 목업 사진이나 기울어진 연출은 제외합니다.
```plain text
가로형 명함 디자인 시안을 만들어 줘.
크기는 92 × 52mm 비율이고, 결과는 명함 앞면을 정면에서 본 평면 디자인으로 보여 줘.
들어갈 문구는 아래와 같아. 철자와 띄어쓰기를 그대로 사용해 줘.
- 이름/상호: [내용]
- 한 줄 소개: [내용]
- 직함: [내용]
- 연락처: [내용]
디자인 방향: [원하는 분위기와 색]
가장 중요한 정보가 먼저 보이고, 글자 주변에 여백이 충분하도록 구성해 줘.
명함 바깥의 책상·손·소품은 넣지 말고, 장식은 필요한 만큼만 사용해 줘.
```
### HTML 시안 요청
이미지 대신 실제 문구를 선명하게 비교하고 싶을 때 사용합니다. 받은 HTML은 미리보기로 확인하고, 코드를 고칠 필요는 없습니다.
```plain text
아래 내용으로 가로형 명함 앞면의 독립 실행형 HTML 시안을 만들어 줘.
화면과 인쇄 미리보기에서 명함 크기가 92 × 52mm가 되도록 하고, 외부 이미지나 라이브러리는 사용하지 마.
텍스트는 아래 문구를 그대로 사용하고 임의로 고치거나 추가하지 마.
- 이름/상호: [내용]
- 한 줄 소개: [내용]
- 직함: [내용]
- 연락처: [내용]
원하는 분위기와 색: [내용]
가장 중요한 정보가 먼저 읽히도록 글자 크기와 위치를 정하고, 여백과 대비를 충분히 둬.
HTML과 CSS를 한 파일에 넣고, 명함 바깥 목업은 만들지 마.
```
### 시안을 비교하고 캔바에서 수정합니다

- AI가 제안한 수정 중 캔바에서 바로 적용할 수 있는 것은 무엇인가?
- 수정 후 이름·하는 일·연락처가 더 잘 읽히는가?
