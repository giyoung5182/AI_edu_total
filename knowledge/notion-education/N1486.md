# 역설계 — 내 문서로 Gem 설정문 만들기 (1~5단계)

정리일: 2026-10-08 · 교육 에셋 N1486

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
이미 잘 쓴 문서 하나를 AI에게 주고 "이것처럼 쓰는 AI의 설정문을 짜라"고 시켜 설정문을 받은 뒤, 검수하고 Gem으로 저장합니다.
## 진행 단계
1. **재료 준비** — 오늘은 전원 부록 C의 자료 1(딜러사 서류 보완 안내 메일)을 복사해 옵니다. 본인 문서를 쓸 때는 실명·번호를 삭제하고 `A딜러사`, `B기계`, `[금액]`처럼 바꿔 넣습니다.
2. **역설계 프롬프트 실행** — 아래를 붙여넣고 맨 아래에 내 문서를 붙입니다.
- 입력할 내용:
```javascript
당신은 AI 설정문(시스템 프롬프트)을 설계하는 전문가입니다.

아래는 제가 실제 업무에서 작성한 문서입니다.
앞으로 이와 같은 문서를 계속 만들어줄 AI 담당자를 만들려고 합니다.

먼저 이 문서를 분석해 주세요.
1. 어떤 사람이 쓴 글인가 (역할과 강점)
2. 문서의 구조는 어떻게 되어 있는가
3. 문체와 톤의 특징은 무엇인가
4. 문서에서 의도적으로 피한 것은 무엇인가

분석이 끝나면, 그 분석을 바탕으로 아래 다섯 항목의
설정문을 작성해 주세요.

[역할]      어떤 담당자인지, 잘하는 것 3가지를 번호로
[맥락]      늘 적용되는 상황과 받는 사람
[할 일]      요청받으면 어떤 순서로 움직일지 단계별로
[조건]      분량·형식과 금지 사항
[지식]      기준이 되는 참고 자료와 원칙

설정문에 반드시 포함해 주세요.
- 알려주지 않은 날짜·금액·금리·조항 번호는 만들지 않고
  사용자가 채울 자리는 [ ]로 비워 둘 것
- 필요한 정보가 빠졌으면 추측하지 말고 먼저 질문할 것

설정문은 바로 복사해 쓸 수 있게 한 덩어리로 정리해 주세요.

---
[내 문서]
(여기에 붙여넣기)
---
```
- 정상 결과: 문서 분석 뒤 다섯 항목 설정문이 나옵니다. 분석을 먼저 시키는 이유는 바로 "설정문 만들어줘"라고 하면 범용 문장이 나오기 때문입니다.
1. **검수 4가지** — 역할이 내 업무와 맞는가(직접 고침) / 진행 방식 1단계가 "확인"인가("정보가 빠졌으면 먼저 질문" 한 줄 추가) / 수치 금지 조항이 들어갔는가(직접 써넣기) / 다섯 줄 넘는 규칙이 있는가(안 지켜도 문제없는 줄은 삭제)
2. **Gem으로 저장** — Gemini 왼쪽 사이드바 "Gems" → "새 Gem 만들기" → 이름 입력(업무 이름으로) → 지침 칸에 검수한 설정문 붙여넣기 → 저장. 저장 직후 설정문을 메모장에도 복사합니다.
3. **바로 써보기** — 만들어진 Gem을 열고 짧게 요청합니다.
- 입력할 내용:
```javascript
A딜러사에 리스 실행 서류 중 사업자등록증과 견적서가
아직 안 들어왔어. 이번 주 금요일까지 부탁하는 안내문 써줘.
```
- 정상 결과: 두 줄만 썼는데도 같은 품질이 나옵니다(역할·형식·금지 조항이 이미 Gem 안에 들어 있기 때문).
## 막히는 지점
- 붙여넣을 문서가 없으면 부록 C의 자료 1 사용
- 설정문이 너무 길면 `핵심만 남기고 절반으로 줄여줘`
- 결과가 내 문체와 다르면 예시 칸에 내 문서를 통째로 하나 넣기
- Gems 메뉴가 안 보이면 사이드바 확장 버튼 확인
- 한도 초과가 뜨면 잠시 뒤 풀림
