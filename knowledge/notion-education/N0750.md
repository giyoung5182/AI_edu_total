**비유로 이해하기: "VBA 매크로는 원가 보고서의 표준 양식"**
자주 쓰는 월간 비용·집행 보고서 양식을 만들어두면 매번 처음부터 작성하지 않아도 되듯, VBA 매크로는 엑셀에서의 반복 클릭/입력 작업을 한 번에 처리합니다. 그리고 ChatGPT가 있으니, **표준 양식을 AI가 대신 만들어주는 것**과 같습니다. 코딩을 몰라도 AI에게 "이런 자동화를 만들어줘"라고 요청하면 됩니다.

---
### VBA란 무엇인가?

**VBA (Visual Basic for Applications)** = 엑셀에 내장된 자동화 프로그래밍 도구
코딩을 몰라도 ChatGPT가 코드를 만들어주니 걱정하지 마세요!

**VBA로 할 수 있는 것:**
- 버튼 클릭 한 번으로 예산·집행 데이터 자동 정리
- 특정 조건에 따라 셀 색상 자동 변경 (예: 원가 초과·지급 임박 항목 빨간색)
- 여러 현장·공종별 집행 시트를 하나로 자동 취합
- 월간 비용·집행 보고서 양식 자동 생성
# 2️⃣ 더미 데이터 자동 생성 & VBA 코드 만들기
### 더미 데이터란?

**더미 데이터** = 실습/테스트용으로 만든 가상의 샘플 데이터
실제 업무 데이터를 사용하기 전에, 더미 데이터로 먼저 자동화를 테스트합니다.

### \[실습\] ChatGPT로 더미 데이터 만들기

**미션: 예산 집행 현황 더미 데이터를 ChatGPT로 생성하기**
**Step 1.** ChatGPT에 아래 프롬프트를 입력하세요
```markdown
## 역할
당신은 엑셀 데이터 구조화 전문가입니다.

## 요청
건설 프로젝트 월간 예산 집행 현황 더미 데이터를 만들어줘.

## 데이터 구조
- A열: 집행일자 (2026-05-05 ~ 2026-05-30, 평일만)
- B열: 현장 (A현장, B현장, C현장 중 랜덤)
- C열: 공종 (토공, 골조, 마감, 기계, 전기 중 랜덤)
- D열: 예산금액 (백만원 단위)
- E열: 집행금액 (백만원 단위)
- F열: 집행상태 (정상 60%, 주의 30%, 초과 10% 비율로)
- G열: 초과사유 (초과인 경우만: 물량증가/단가상승/공정변경/기성조정 중 랜덤)

## 조건
- 최소 30행 이상
- 골조 공종의 초과율이 가장 높게 설정 (분석 시 인사이트 도출 가능하도록)
- 엑셀에 바로 붙여넣을 수 있는 표 형태로 출력

## 출력
탭으로 구분된 표 형태로 출력해줘 (엑셀 복사-붙여넣기 가능하도록)
```
**Step 2.** ChatGPT 결과를 엑셀에 붙여넣기 (Ctrl+V)
**Step 3.** 데이터가 정상적으로 입력되었는지 확인

### \[실습 1\] 비용 초과 항목 자동 색상 표시

**미션: "초과" 항목을 자동으로 빨간색으로 표시하는 매크로 만들기**
**Step 1.** 제공된 실습 파일 **「예산집행현황_색상표시.xlsx」**를 열어주세요. (공종별 15건의 정상/주의/초과 데이터가 입력되어 있습니다)
**Step 2.** ChatGPT에 아래 프롬프트를 입력하세요
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
B열에 "초과"라고 적힌 셀과 같은 행 전체를 빨간색 배경으로 자동 표시하는 VBA 매크로를 만들어줘.

## 조건
- 데이터는 A1부터 시작 (1행은 헤더)
- B열에 "초과"가 있으면 해당 행 전체(A~B열)를 빨간색 배경 + 흰색 글자로 변경
- B열에 "정상"이 있으면 해당 행을 초록색 배경으로 변경
- B열에 "주의"가 있으면 해당 행을 노란색 배경으로 변경
- 코드에 한글 주석 포함

## 출력
VBA 코드만 출력해줘. 설명은 코드 내 주석으로.
```
**Step 3.** ChatGPT가 생성한 코드를 복사
**Step 4.** 엑셀에서 Alt + F11 → 모듈에 붙여넣기
**Step 5.** Alt + F8 → "집행현황_색상표시" 선택 → 실행
**예상 결과:** "초과" 행은 빨간색, "정상" 행은 초록색, "주의" 행은 노란색으로 자동 표시됩니다.

### \[실습 2\] 월간 원가 보고서 자동 생성

**미션: 예산 집행 데이터를 분석하여 보고서를 자동 생성하는 매크로 만들기**
**Step 1.** 제공된 실습 파일 **「월간예산집행_보고서.xlsx」**를 열어주세요. (현장 3곳, 5일간의 집행 데이터 55건이 입력되어 있습니다)
**Step 2.** ChatGPT에 아래 프롬프트를 입력하세요
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
건설 프로젝트 월간 예산 집행 현황 보고서를 자동 생성하는 VBA 매크로를 만들어줘.

## 데이터 구조 ("데이터" 시트)
- A열: 집행일자
- B열: 현장명 (A현장, B현장, C현장)
- C열: 공종
- D열: 예산금액
- E열: 집행금액
- F열: 집행상태 (정상/주의/초과)
- G열: 초과사유

## 매크로 기능
1. "보고서" 시트를 새로 생성
2. 상단: 보고서 제목 "월간 예산 집행 현황 보고서" + 오늘 날짜
3. 중단: 집행 통계 요약 (총 예산, 총 집행, 집행률, 정상/주의/초과 각 건수)
4. 하단: 초과 항목만 필터링한 목록

## 조건
- 한글 주석 포함
- 기존 "보고서" 시트가 있으면 삭제 후 새로 생성

## 출력
VBA 코드만 출력해줘.
```
**Step 3.** 코드를 모듈에 붙여넣기 → Alt + F8 → 실행
**Step 4.** "보고서" 시트가 자동 생성되었는지 확인

### 디버깅: 오류가 발생했을 때

- 시트명: "데이터"
- 데이터 범위: A1:G55

오류 원인을 분석하고, 수정된 코드를 전체로 다시 작성해줘.
