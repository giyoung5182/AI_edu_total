# 활동 1-3 — 전처리 실행

정리일: 2026-10-08 · 교육 에셋 N1079

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AI에게 전처리 규칙을 주어 데이터를 정리시키고, 결과를 검증합니다.
## 진행 단계
1. **규칙 입력** — 아래 7개 규칙을 그대로 복사합니다.
- 입력할 내용:
```plain text
아래 기준으로 데이터를 정리하고, 정리된 데이터로 다시 집계하라.

전처리 규칙:
1. 부서명: 앞뒤 공백 제거, "영업팀"은 "영업"으로 통일
2. 직급: 한자 표기를 한글로 변환
3. 중복 행: 응답번호가 중복되거나 전체 내용이 동일한 행은 뒤에 나온 것을 제외
(이하 교안 참고)
```
1. **정리 내역 확인** — 집계 결과보다 먼저 제외·수정 내역을 봅니다.
2. **재집계** — 부서가 7개로 줄었는지 확인합니다.
3. **순위 비교** — 전처리 전후 1위가 바뀌었는지 봅니다.
## 막히는 지점
- 검증 체크: 제외한 행 수와 사유를 밝혔는가 / 수정한 셀 내용을 보고했는가 / 결측을 0으로 채우지 않았는가 / 이상치를 지우지 않고 표시했는가 / 부서 개수가 실제와 맞는가
- 확인이 안 되면 "어느 행을 왜 제외했는지 목록으로 보여줘"를 추가로 요청합니다.
