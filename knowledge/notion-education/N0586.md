# 5. 설치 및 로그인 — 1단계 CLI 설치 + 로그인

정리일: 2026-10-08 · 교육 에셋 N0586

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클로드 코드에 한 줄을 부탁해 GitHub CLI와 Vercel CLI 설치 및 로그인까지 진행합니다.
## 진행 단계
1. **요청 입력** — 클로드 코드에 아래 문장을 입력합니다.
- 입력할 내용:
```plain text
깃허브 CLI랑 버셀 CLI 설치하고 로그인까지 도와줘
```
2. **로그인 승인** — 로그인 중 브라우저 창이 뜨면 새 탭에서 Authorize 버튼을 클릭한 뒤 터미널로 돌아오면 끝납니다.
## 막히는 지점
- 클로드 코드가 깃허브 비번을 물어요: 터미널에서 gh auth login 먼저 실행
- `command not found: vercel`: CLI 설치 안 됨 / 터미널 재시작 필요 → npm install -g vercel 다시 실행 후 터미널 종료 → 재실행
- 어느 폴더에서 명령어를 쳐야 하나요: index.html이 보이는 폴더에서 ls로 확인
