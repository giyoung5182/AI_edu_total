# 1️⃣ 코딩이 아니라 '지시'입니다
## 1-1. 왜 지금 바이브 코딩인가요?
지금의 생성형 AI는 단순히 답변을 잘하는 수준을 넘어서, 실제로 작동하는 웹 도구의 초안을 빠르게 만들어낼 수 있습니다.
중요한 것은 개발자가 되는 것이 아니라, 반복적인 보고·취합·정리 업무를 더 빠르게 해결하는 방법을 익히는 것입니다.

**무엇을 만들까? → 내가 만들려고, 하려고 하는 것을 어떻게 요청해야할까?**


## 1-2. 바이브 코딩에서 필요한 관점
1. 코드를 직접 쓰지 않아도 됩니다.
2. 대신 해결하고 싶은 문제를 구체적으로 설명해야 합니다.
3. 좋은 지시는 좋은 결과물을 만듭니다.
4. 빠르게 만들어 보고, 눈으로 확인하고, 바로 수정하는 흐름이 핵심입니다.

> TIP: 바이브 코딩에서 가장 중요한 역량은 문법 지식이 아니라 `업무 병목을 구조화해서 설명하는 능력`입니다.


# 2️⃣ 일반 AI와 개발 작업 에이전트는 무엇이 다를까요?
대화형 AI는 질문에 답하고 글·아이디어·표·요약을 만들어주는 도구입니다. 반면 개발 작업 에이전트는 작업 폴더나 코드 저장소를 읽고, 파일을 수정하고, 실행 결과를 확인하면서 결과물을 완성하는 도구에 가깝습니다.

💡 핵심은 `답변을 받는 도구`와 `작업을 맡기는 도구`의 차이입니다.
