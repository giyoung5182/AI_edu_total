# 실습 2. 노트북 정리 — 폐기, 로그아웃, 삭제

정리일: 2026-10-08 · 교육 에셋 N1105

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
백업의 이동과 검증이 끝난 뒤에만 시작합니다. 공용 노트북에서 키는 관리 화면에서 폐기하고, 로그인은 도구와 브라우저 양쪽에서 끊고, 파일은 삭제합니다.
## 진행 단계
1. **키 폐기** — 브라우저에서 Google AI Studio에 접속해 API 키 관리 화면을 열고 발급했던 키를 삭제합니다. ("API Key" 메뉴에서 삭제(휴지통) 동작을 찾습니다. 화면 구성은 바뀔 수 있습니다.)
2. **키 폐기 확인** — 채팅 페이지에서 아무 질문이나 보내 봅니다.
- 정상 결과: 답변이 실패(401/403 로그)하면 키가 죽은 것입니다. 이번에는 이 실패가 성공의 신호입니다.
3. **Claude Code 로그아웃** — 창②에서 `/logout` 을 입력합니다.
4. **브라우저 로그아웃** — 배부받은 Google 계정을 로그아웃하고, 브라우저에 저장된 비밀번호가 있으면 설정에서 삭제합니다.
5. **서버 종료** — 창①에서 Ctrl+C 로 서버를 끕니다.
6. **폴더 삭제** — 터미널에서 `cd ~ && rm -rf disaster-bot` 을 입력합니다. 프로젝트 폴더를 통째로, 복구 불가능하게 지우므로 백업 검증이 끝났을 때만 실행합니다.
7. **최종 확인** — `ls` 를 입력해 disaster-bot 폴더가 사라졌는지 확인합니다.
## 막히는 지점
- 키를 지웠는데 챗봇이 계속 답함: 원인 다른 키 존재 또는 반영 지연. 해결 키 관리 화면에 남은 키가 없는지 확인하고 1\~2분 뒤 다시 시도
- `/logout` 이 목록에 없음: 원인 명령어 변경 가능성. 해결 `/help` 로 로그아웃 계열 명령을 찾고, 없으면 강사에게 알림
- `rm` 명령이 무서움: 정상적인 감각. 해결 백업 검증을 한 번 더 하고 실행, 불안하면 강사와 함께 실행
