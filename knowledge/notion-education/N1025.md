## 이 실습으로 하는 것
다음 시간 실습을 위해 MySQL, MySQL Workbench, DBeaver를 설치하고 localhost에 연결합니다(Windows/Mac 별도 안내).
## 진행 단계
1. **MySQL 설치** — MySQL Community Server를 내려받아 설치합니다(Mac은 반드시 macOS로 변경). 설치 중 root 사용자 비밀번호를 설정하고 기억해 둡니다. Windows는 services.msc에서 MySQL이 실행중인지, Mac은 System Settings의 MySQL에서 Start MySQL Server 후 Running 상태인지 확인합니다.
2. **MySQL Workbench 설치** — 다운로드 후 설치(Mac은 애플리케이션에 등록), root 비밀번호로 접속합니다.
3. **DBeaver 설치** — dbeaver.io/download에서 설치합니다.
4. **localhost**** 연결** — Database → New Database Connection → MySQL 선택
- 입력할 내용: Server Host `localhost`, Port `3306`, Database `test_db`(또는 빈칸), Username `root`, Password(설치 시 입력한 비밀번호)
5. **basic DB 만들고 users.csv 업로드** — Database를 우클릭해 Create New Database로 basic이라는 DB를 만들고, 데이터 가져오기로 실습자료의 users.csv를 업로드합니다. 한글 컬럼 깨짐 방지를 위해 euc-kr 인코딩으로 변경하고 SQL 편집기를 새로 만듭니다.
## 막히는 지점
- 사용자 이름에 한글이 들어가 있으면 MySQL 설치 오류가 납니다(교안의 해결 링크 참고).
- Workbench가 Visual C++ 2019 재배포 패키지를 요구하면 VC_redist.x64.exe를 설치합니다.
- DBeaver에서 Public Key Retrieval is not allowed 오류가 나면 교안의 가이드를 따릅니다.
