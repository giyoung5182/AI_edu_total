# [실습] 품질정책문서 + 맥락 더하기 2 : deep research로 도메인 지식 레포트 만들기

정리일: 2026-10-08 · 교육 에셋 N1073

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
deep research 기능으로 도메인 지식 레포트를 만들고, 이를 맥락으로 제공해 품질정책문서의 퀄리티 변화를 확인합니다.
## 진행 단계
1. **도메인 지식 레포트 생성** — 각자 딥리서치 기능으로 도메인 지식 레포트를 하나씩 만듭니다.
- 입력할 내용(예시 프롬프트 요약): 각 테이블의 업무 의미, 발생 가능한 데이터 품질 오류, 업무 영향, 반드시 점검할 핵심 컬럼, 결측·중복·날짜 오류·범위 오류·코드 불일치 관점의 점검 기준, 데이터 매니저가 매월 확인할 품질 지표, 처음 보는 사람을 위한 용어 정리를 포함한 Markdown 보고서.
2. **문장 공유** — 2주차 패들릿에 '가장 유용했던 문장 1개'와 '가장 위험했던 문장 1개'를 공유합니다.
3. **레포트를 context로 제공** — 도메인 지식 레포트를 context로 주고 데이터품질정책문서를 GPT로 작성합니다.
4. **평가** — 도메인 지식의 전문성이 더해진 좋은 문서가 나왔는지 패들릿에 퀄리티를 평가합니다.
## 막히는 지점
- 위험한 문장을 따로 보는 이유: AI는 '답안 생성기'가 아니라 '초안 생성 + 검증 대상'이기 때문입니다.
