# 실습 · 내 업무 지시문 만들기 (15분)

정리일: 2026-10-08 · 교육 에셋 N0570

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
매달 또는 매주 반복해서 만드는 문서 하나를 골라 RCTCK 워크시트로 내 업무용 지시문을 만들고, 결과를 보고 빠진 블록을 보완합니다.
## 진행 단계
1. **반복 문서 고르기 (2분)** — 내가 매달 또는 매주 반복해서 만드는 문서를 하나 고릅니다.
2. **워크시트 채우기 (8분)** — 아래 워크시트를 채웁니다.
- 입력할 내용:
```plain text
[R] 당신은 ____________ 입니다.
    능력 1) ____________
    능력 2) ____________

[C] 현장 / 부서 : ____________
    수신처       : ____________
    문서 종류    : ____________
    제출 시점    : ____________
    진짜 목적    : ____________

[T] 1) ____________
    2) ____________
    3) ____________
    4) 작업 전에 내가 놓친 항목이 있으면 먼저 알려 주세요.

[C] 형식 : ____________
    금지 : 제가 제공하지 않은 수치·판정은 절대 만들지 마세요.
           자료에 없는 항목은 [확인 필요]로 표시하세요.
           확실하지 않으면 아는 척하지 말고 질문해 주세요.

[K] 원자료     : ____________
    골든 샘플  : ____________
```
3. **ChatGPT에 넣고 확인 (3분)** — 채운 지시문을 ChatGPT에 넣고 결과를 확인합니다.
4. **진단표로 보완 (2분)** — 진단표를 보고 빠진 블록을 하나 찾아 보완합니다.
- 정상 결과(완료 기준): R에 직함뿐 아니라 능력이 번호로 들어감 / C에 수신처와 진짜 목적이 적힘 / T가 3단계 이상이고 앞뒤가 연결됨 / C에 지어내기 금지와 \[확인 필요\] 표기가 들어감 / K에 원자료와 골든 샘플이 구분됨 / 지시문을 따로 저장함
