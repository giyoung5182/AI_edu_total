## 이 실습으로 하는 것
코드를 만들기 전에 구성 계획을 먼저 확인하고, Claude Code가 dashboard.py 저장·패키지 설치·streamlit 실행까지 하게 한다.
## 진행 단계
1. **계획 먼저 요청 (Step 3)** — 경영진 질문(추세·지역 순위·상품 비중·달성률)과 보여줄 것(사이드바 필터, KPI 카드, 탭별 차트, 하단 테이블)을 적어 계획을 요청한다.
- 입력할 내용:
```javascript
Streamlit 매출 분석 대시보드를 만들려고 해.
바로 코드 만들지 말고, 구성 계획을 먼저 보여줘.

데이터 파일 경로: day2/실습_영업팀_매출데이터.xlsx
(컬럼: 날짜, 지역, 카테고리, 매출, 건수, 목표매출)

경영진이 알고 싶은 것:
1. 매출 추세 (올라가나? 내려가나?)
2. 지역 순위 (어디가 1등?)
3. 상품 비중 (뭐가 잘 팔려?)
4. 목표 달성률 (몇 %?)

보여줄 것: 사이드바 필터, KPI 카드, 탭별 차트, 하단 테이블
```
1. **계획 조정 후 코드 요청** — 계획을 확인하고 조정한 뒤 KPI 카드에 전월 대비 증감률 화살표, 하단 CSV 다운로드 버튼을 추가해 day2/dashboard.py 생성을 요청한다.
2. **저장 + 실행 (Step 4)** — VSCode 터미널에서 claude 실행 → 위 프롬프트 요청 → dashboard.py 저장 + pip install + streamlit run → 터미널의 [개별 링크 제외] 을 브라우저로 접속.
- 정상 결과: 대시보드 화면이 브라우저에 표시됨
## 막히는 지점
- streamlit run은 터미널을 켜 둔 상태로 계속 떠 있어야 접속이 유지된다. 화면을 닫거나 Ctrl+C를 누르면 대시보드도 종료된다.
- 사내 실제 데이터를 외부 배포(share.streamlit.io)하는 것은 절대 금지, 사내 서버 배포는 정보보안팀 사전 확인.
