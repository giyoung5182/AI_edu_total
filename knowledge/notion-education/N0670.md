# 실습 1: GAS 설치 + 작동 확인

정리일: 2026-10-08 · 교육 에셋 N0670

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
구글 시트를 새로 만들어 기존 지출결의서 시트를 옮기고, Apps Script 코드를 설치해 제출 버튼이 작동하는 것을 확인함.
## 진행 단계
1. **구글 시트 새로 만들기(STEP A)** — 구글 드라이브 \[+ 새로 만들기\] → \[Google 스프레드시트\] 또는 주소창에 sheets.new 입력. 파일 이름을 "교육기관_지출결의서_자동화"로 변경
- 정상 결과: 브라우저 탭 제목이 바뀌고 드라이브에도 해당 이름으로 보임
2. **기존 데이터 가져오기(STEP B)** — 기존 파일을 우클릭 → \[연결 앱\] → \[Google Sheets\]로 열고, 시트 탭 4개(지출결의서·매장정보·거래처목록·월별지출집계)를 탭 우클릭 → \[다른 스프레드시트로 복사\]로 이동. 새 \[제출이력\] 시트를 만들고 1행 A\~N에 헤더 입력(제출일시, 매장명, 명의구분, 법인명, 사업자번호, 대표자명, 본부장, 결의일, 결의인, 내용, 거래처, 공급가, 부가세, 총액)
- 정상 결과: 하단 시트 탭에 4개 시트가 있고 제출이력 헤더 순서가 코드와 일치
3. **Apps Script 코드 설치(STEP C)** — \[확장 프로그램\] → \[Apps Script\]로 편집창 열기(팝업 차단 시 허용), 편집창 제목이 올바른 파일인지 확인, 기본 코드 전체 삭제 후 교안의 코드 전체를 붙여넣고 Ctrl+S로 저장
- 입력할 내용: Claude에게 파일 구조·셀 구조·동작 순서·메뉴를 명시한 GAS 코드 요청 프롬프트(교안 참고). 코드 전체는 교안 참고
4. **권한 허용 + 메뉴 확인(STEP D)** — 시트로 돌아가 F5 새로고침, \[지출결의서\] 메뉴 → \[제출\] 클릭 → \[권한 검토\] → 계정 선택 → \[고급\] → \[(파일명)(으)로 이동\] → \[허용\]
- 정상 결과: 메뉴에 제출·폼 초기화·월별집계 갱신 3개 항목이 보임
5. **테스트(STEP E)** — 매장명 선택, 결의일 입력, 내용·공급가 입력 후 메뉴에서 제출 → 확인 팝업 \[예\] → 완료 팝업 \[예\]
- 정상 결과: 제출이력 2행에 제출일시·매장명·내용·공급가가 저장되고 부가세(공급가 x 10%)와 총액이 자동 계산됨
## 막히는 지점
- .xlsx 파일에서는 Apps Script가 실행되지 않음 → 드라이브에서 새 구글 시트로 시작
- 크롬 팝업 차단 → 주소창 팝업 차단 아이콘에서 허용
- Apps Script는 파일마다 따로 연결됨 → 작업 파일에서 직접 열기
- 메뉴가 안 보이면 F5 또는 onOpen 수동 실행 / 매장명 알림이 계속 나오면 FORM 셀 주소 수정 / 엉뚱한 열에 저장되면 헤더 순서 확인 / null getRange 오류는 시트명(공백 포함) 확인 / FORM is not defined는 코드 전체 재복사
- 오류 메시지는 말로 설명하지 말고 전체를 복사해 Claude에게 전달
