## 2-1. Excel로 데이터 구조 확인
> 먼저 파일을 열어 “어떤 컬럼이 있고, 어떤 질문에 답할 수 있는 데이터인지”를 파악합니다.
```plain text
실습파일/교육기관생산설비데이터_실습.xlsx의 첫 시트를 읽고 데이터 구조를 설명해줘.

다음 항목을 포함해줘.
1. 전체 행 수와 컬럼 수
2. 주요 컬럼 8개와 쉬운 설명
3. 이 데이터로 분석할 수 있는 질문 5개
4. 분석 전에 확인해야 할 주의사항
```
## 2-2. 핵심 운영 지표 한 번에 보기
> 설비 데이터는 숫자만 보는 것이 아니라, “가동률이 낮은지”, “수율이 낮은지”, “정지시간이 긴지”, “조치가 필요한지”를 같이 봐야 합니다.
```plain text
실습파일/교육기관생산설비데이터_실습.xlsx를 읽고 생산설비 운영 현황을 요약해줘.

아래 지표를 계산해줘.
가동률과 수율은 엑셀에 0~1 사이 소수로 저장되어 있으니 85%는 0.85, 98%는 0.98 기준으로 계산하고, 결과 표에서는 % 형식으로 표시해줘.

- 전체 설비 로그 수
- 평균 가동률
- 평균 수율
- 총 정지시간(h)
- 조치필요여부가 Y인 건수
- 가동률 85% 미만인 건수
- 수율 98% 미만인 건수

결과는 표와 3줄 요약으로 정리해줘.
```
## 2-3. 조치 우선순위 설비 찾기
> 단순히 `조치필요여부=Y`만 보지 말고, 가동률·수율·정지시간 조건을 함께 걸어 실제로 먼저 확인할 대상을 좁힙니다.
```plain text
실습파일/교육기관생산설비데이터_실습.xlsx에서 조치 우선순위 설비를 골라줘.

조건은 다음과 같아.
가동률과 수율은 엑셀에 0~1 사이 소수로 저장되어 있으니 85%는 0.85, 98%는 0.98 기준으로 계산해줘.

- 조치필요여부가 Y
- 그리고 아래 중 하나 이상에 해당
  - 가동률이 85% 미만
  - 수율이 98% 미만
  - 정지시간(h)이 3시간 이상

결과를 조치우선순위_설비.csv로 저장해줘.
저장 후 공장, 라인, 설비ID, 설비명, 가동률, 수율, 정지시간(h), 이상유형, 담당팀, 다음점검일 컬럼만 표로 보여줘.
가동률과 수율은 사람이 보기 쉽게 % 형식으로 표시해줘.
```
## 2-4. 공장·라인·담당팀 관점으로 원인 묶기
> 현장 리더에게는 개별 설비 목록보다 “어느 공장/라인/담당팀에 부담이 몰리는지”가 더 중요할 때가 많습니다.
```plain text
실습파일/교육기관생산설비데이터_실습.xlsx를 기준으로 다음 집계를 만들어줘.

1. 공장별 평균 가동률, 평균 수율, 총 정지시간, 조치필요 건수
2. 공장-라인별 총 정지시간 상위 10개
3. 담당팀별 조치필요 건수와 총 정지시간
4. 이상유형별 발생 건수

가동률과 수율은 표에서는 % 형식으로 보여줘.
각 표 아래에 바로 확인해야 할 포인트를 1문장씩 붙여줘.
```
## 2-5. 보고 코멘트 만들기
> 마지막에는 분석 결과를 실행 가능한 문장으로 바꿉니다. 숫자 나열보다 “어디를 먼저 볼지”가 드러나야 합니다.
```plain text
실습파일/교육기관생산설비데이터_실습.xlsx 분석 결과를 바탕으로 보고용 코멘트를 작성해줘.

조건은 다음과 같아.
- 1단락으로 작성
- 가장 위험해 보이는 공장/라인/설비 조합을 언급
- 가동률, 수율, 정지시간, 이상유형 중 근거가 되는 지표를 포함
- 가동률과 수율은 사람이 보기 쉽게 % 형식으로 표현
- 마지막 문장에는 확인 액션 2개를 제안
- 과장하지 말고 데이터에서 확인 가능한 내용만 써줘
```

1. 저가동 설비만 긴급 추리기

오전 생산회의 20분 전, 공장장이 “정말 가동률이 낮은 설비만 먼저 보자”고 요청한 상황입니다.

기존 조건을 `조치필요여부가 Y이고, 가동률이 80% 미만인 설비만`으로 바꾸고 결과 파일명을 `조치우선순위_저가동설비_80pct.csv`로 저장합니다.

수율이나 정지시간 조건 때문에 포함된 설비가 아니라, 실제 저가동 설비만 남는지 확인합니다.




2. 특정 이상유형 집중 점검하기

정비 담당자가 “베어링 온도 상승 알람이 반복된다”는 보고를 받아, 해당 이상유형의 발생 위치를 먼저 좁혀야 하는 상황입니다.

`이상유형`이 `베어링 온도 상승`인 행만 골라 `베어링온도_점검대상.csv`로 저장합니다.

해당 이상유형이 어느 공장, 라인, 담당팀에 몰려 있는지 확인합니다.




3. 팀별 조치 부담 파악하기

주간 운영회의에서 “어느 팀에 조치 업무가 몰려 있는가”를 확인해 인력 배분을 논의해야 하는 상황입니다.

담당팀별로 `조치필요 건수`, `총 정지시간`, `평균 가동률`을 계산합니다.

어느 팀에 조치 부담이 몰리는지, 단순 건수와 정지시간 기준이 같은 결론을 내는지 확인합니다.





## 2-8. 분석은 도구보다 질문 설계가 먼저입니다
> 도구가 분석의 품질을 결정하는 것이 아닙니다. 더 중요한 것은 무엇을 분석해야 하는지, 어떤 기준으로 판단할지, 누구의 의사결정에 쓸 결과인지 먼저 정하는 것입니다.
같은 엑셀 파일을 보더라도 질문이 달라지면 결과도 달라집니다. 저가동 설비를 찾을 것인지, 정지시간이 긴 라인을 볼 것인지, 담당팀별 조치 부담을 볼 것인지에 따라 조건, 집계 단위, 출력 형식이 모두 달라집니다.
분석을 시작하기 전에는 아래 4가지를 먼저 정리합니다.
1. 이번 분석으로 결정해야 할 것은 무엇인가?
2. 어떤 기준을 넘으면 문제로 볼 것인가?
3. 공장, 라인, 설비, 담당팀 중 어떤 단위로 볼 것인가?
4. 최종 산출물은 표, 파일, 보고 메모 중 무엇이어야 하는가?
Claude Code는 계산과 정리를 빠르게 도와주는 도구입니다. 하지만 좋은 분석은 도구가 대신 정해주지 않습니다. 리더의 역할은 데이터를 보며 “무엇을 물어볼 것인가”를 먼저 정하는 데 있습니다.
