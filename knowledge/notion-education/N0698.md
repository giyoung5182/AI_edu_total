# 2. GitHub 가입

정리일: 2026-10-08 · 교육 에셋 N0698

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
코드를 클라우드에 보관하는 GitHub 계정을 만듭니다.
## 진행 단계
1. **접속** — [github.com](http://github.com) 접속 후 우측 상단 **Sign up**을 클릭합니다.
2. **정보 입력** — 이메일 / 비밀번호 / 유저네임을 입력합니다.
- 주의: 유저네임은 나중에 주소에 들어갈 수 있으니 신중히 정합니다 (예: [github.com/내이름](http://github.com/내이름)).
3. **이메일 인증** — 인증 링크를 클릭하면 가입이 완료됩니다.
## 막히는 지점
- GitHub 인증 메일이 안 오는 경우: 스팸으로 분류됐을 수 있으므로 스팸 / 프로모션 폴더를 확인
