# 기본 명령어 다섯 가지 직접 실행 (pwd, ls, cd, mkdir, cp)

정리일: 2026-10-08 · 교육 에셋 N1324

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
"지금 터미널에서 하나씩 직접 실행해 봅니다"로 제시된 기본 명령어 다섯 가지를 직접 입력해 봅니다.
## 진행 단계
1. **pwd — 현재 위치 확인**
- 입력할 내용:
```bash
pwd
```
- 정상 결과: `/home/username` 형태의 전체 경로 출력
1. **ls — 파일 목록 보기** (`-al`을 붙이면 숨김 파일과 상세 정보)
```bash
ls
ls -al
```
1. **cd — 위치 이동**
```bash
cd hanbit-ai      # hanbit-ai 폴더 안으로 이동
cd ..             # 한 단계 위로 이동
cd ~              # 어디에 있든 홈으로 이동
```
- 정상 결과: 프롬프트의 `~`가 `~/hanbit-ai`로 바뀌면 이동 성공
1. **cp — 파일 복사** (`cp 원본 대상` 순서)
```bash
cp memo.txt memo_backup.txt   # 같은 위치에 다른 이름으로 복사
cp memo.txt test/             # test 폴더 안으로 복사
ls test
```
1. **apt update / upgrade** — update가 먼저, upgrade가 나중
```bash
sudo apt update
sudo apt upgrade -y
```
## 막히는 지점
- 명령이 전혀 안 먹음: PowerShell에 입력 중일 수 있음. 프롬프트가 `PS C:\...`면 Ubuntu 탭에서 재시도
- sudo 비밀번호가 틀림: Windows가 아니라 Ubuntu 계정 비밀번호 입력
