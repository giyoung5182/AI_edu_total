# 실습 2 — 차트 유형 선택 및 Excel 차트 생성

정리일: 2026-10-08 · 교육 에셋 N1367

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
데이터의 성격에 맞는 차트 유형을 Copilot에게 추천받고 선택한 차트를 Excel에서 직접 만듭니다.
## 진행 단계
1. **차트 유형 추천 요청** — Copilot 채팅 창에 입력
- 입력할 내용:
```javascript
아래 데이터로 임원 보고용 차트를 만들려고 해.
데이터 구조: 5개 분야(법인자문, 소송, 부동산, 노동, 지재권)의 2025년 1~6월 매출, 비용, 수익률이 포함되어 있어.

아래 목적에 맞는 차트 유형을 각각 추천해줘:
① 분야별 월별 수익률 변화 추이를 보여주고 싶을 때
② 상반기 전체 매출에서 각 분야의 비중을 보여주고 싶을 때
③ 분야별 올해 상반기 총매출을 비교하고 싶을 때

각 목적마다 추천 차트 유형, 이유, Excel에서 만드는 방법을 알려줘.
```
2. **본인이 만들 차트 1개 선택** — ① 꺾은선 그래프(수익률 추이) / ② 원형·도넛 차트(매출 비중) / ③ 묶음 막대 그래프(총매출 비교)
3. **Excel에서 차트 만들기** — 실습 1 파일에서 데이터 범위 선택(Ctrl로 다중 선택 가능) → 삽입 탭에서 차트 유형 클릭 → 우측 상단 + 버튼으로 제목·범례·데이터 레이블 추가 → 차트 제목을 더블클릭해 의미 있는 제목으로 수정
4. **차트 복사** — 차트를 클릭하고 Ctrl+C로 복사해 PPT에 붙여넣을 준비
- 정상 결과: 데이터 특성에 맞는 차트가 Excel에 생성되고 PPT 삽입 준비 완료
