# 바이브코딩이란?

**바이브코딩 = 생성형 AI와 함께 코딩을 하는 행위**<br>(최근엔 에이전틱 엔지니어링이라고 부르기도 합니다)

- **과거** : 생성형 AI에게 조언이나 도움을 받고 **내가 직접** 코딩
- **현재** : **지시**하면 AI가 알아서 **직접** 코딩하고, 실행하고, 오류를 수정함

활용의 자유도가 높고, AI가 내 PC를 조작/열람할 수 있어서 **업무자동화에 가장 적합한 방식**입니다. 코딩을 몰라도 AI에게 지시만 하면 됩니다!

# 바이브코딩의 효능 👨🏻‍⚕️
### 1. 내 업무가 쾌적해집니다
- 파일 작업·웹 검색 등을 모두 AI가 수행할 수 있습니다.
- 필요 시 간단한 웹페이지를 빠르게 만들 수 있습니다.
### 2. 우리 팀 자동화 시스템을 직접 만들 수 있습니다
- 대시보드·자동화 프로그램 등을 직접 만들 수 있습니다.
- 우리 팀에 맞게 제작·수정할 수 있습니다.
- 협업·소통 리소스를 줄이고, 실시간 데이터 확인으로 투명한 의사결정을 돕습니다.
### 3. 우리 팀의 성공 확률을 높일 수 있습니다
- 직접 만든 시스템에 AI를 내장해 성능을 고도화합니다.
- 데이터 기반 예측 모델로 의사결정 품질을 높입니다.

# Claude Code 소개
[원본 이미지 제외]
## 클로드 데스크톱 앱 ‘Code’ 탭으로 쓰는 AI 코딩 도구
Claude Code는 Anthropic이 만든 AI 코딩 도구로, **클로드 데스크톱 앱의 ‘Code’ 탭**에서 바로 사용합니다. 작업 폴더를 선택하고 입력창에 지시하면 아래와 같은 일을 합니다:
- 파일을 **직접 읽고, 쓰고, 실행**
- 파일 관리·프로그램 실행 등 PC 작업 수행
- 웹 검색, 외부 도구 연동
- 프로젝트 전체를 이해하고 코드 수정
