# 실습 1 — 오류 탐지 SQL 작성

정리일: 2026-10-08 · 교육 에셋 N1373

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
열 사용량·민원 데이터에서 결측, 중복, 범위 초과, 형식 오류를 SQL로 찾습니다.
## 진행 단계
1. **결측값 탐지** — 문제1 열사용량 결측 현황 요약(SUM(CASE WHEN ... IS NULL)), 문제2 민원 결측 현황 요약, 각각 직접 풀어보는 예제로 결측 행 조회
2. **중복 탐지** — 문제3 GROUP BY + HAVING COUNT(\*) \> 1
3. **범위 초과 탐지** — 문제4 음수·5000 초과값, 문제5 처리완료일이 접수일보다 앞선 날짜 논리 오류
4. **형식 오류 탐지** — 문제6 LIKE '.**.**' 날짜 형식, 비표준 지역명
5. **종합 요약** — 오류 유형·발생 테이블·발견 건수·영향 표 채우기
## 막히는 지점
- 수정 전에 반드시 어떤 오류가 얼마나 있는지 먼저 파악해야 함. 무작정 UPDATE부터 하면 안 됨
- IS NULL은 빈 값(NULL), = ''는 빈 문자열을 찾으므로 둘 다 체크
