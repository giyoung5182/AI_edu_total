**목표**: 교안 57개를 재사용 가능한 표준 모듈로 바꿔, 새 교육의 제안서·커리큘럼·교안을 모듈 조립으로 빠르게 만드는 구조 만들기

## 데이터 구조
- **교안 개념 사전**: 교안의 권·교시·Part 1개 = 1행 (418행, 원재료)
- **표준 모듈**: 같은 내용을 가르친 세부 주제를 묶은 부품. 개념 사전 행과 연결
- **표준 용어**: 같은 개념을 다르게 부른 이름을 하나로 정리
- **고객사별 교육 / 자료 목록**: 실적 근거(언제·누구에게 진행했는지)
## 단계
### 1단계 · 표준 모듈 만들기 (완료 · 31개 확정)
1. 모듈 후보 목록과 정의·포함 기준 작성 (Claude)
2. 개념 사전 418행을 모듈 1개에 배정, 맞는 모듈이 없으면 메모에 새 모듈 제안 (Claude)
3. 모듈별 파생 현황 정리: 몇 개 교안·몇 고객사에서 썼는지, 분량 범위 (Claude)
4. **대표님 검토**: 모듈 이름·범위 확정, 모듈별 대표 판본(가장 잘 만든 것) 선정
5. 상태를 '확정'으로 변경
### 2단계 · 표준 용어 정리 (완료 · 13개 확정)
1. 같은 개념의 변형 이름 수집 (예: RCTCK / RCTC+K / R.C.T.C / ROPE+K / ROPEK)
2. 변형별 사용 교안·최근 사용일 정리
3. **대표님 결정**: 심지 표준 이름 1개씩 확정
### 3단계 · 커리큘럼 조립기 (완료 · Claude 스킬 simji-curriculum-builder, 아래 역산 테스트 페이지)
1. 고객 요청(대상·시간·도구·제약) → 표준 모듈 조합 + 시간표 + 실적 근거를 내는 Claude 프로젝트 또는 스킬 제작
2. 과거 교육 2\~3건으로 역산 테스트 (실제 커리큘럼과 비교)
### 4단계 · 상품 라인·레벨 지도 (완료 · 아래 하위 페이지)
1. 모듈 × 대상 수준(입문·실무·개발) 표
2. 재구매 고객 진행 순서로 기초→심화 로드맵
### 5단계 · 도구 변경 알림 (완료 · 매주 월요일 '노션 주간 점검'에 추가)
1. 주간 자동 점검에 '도구별 영향 교안' 조회 추가
### 6단계 · 개념 설명 카드 (1차 19장 · 교육 프로젝트 › 개념 설명 카드 DB, 상태 '초안')
1. 핵심 개념별 정의·비유·실습·막히는 지점 카드 (강사 지원·교안 사이트용)
## 작업 원칙
- 원본 교안은 수정하지 않음. 모든 가공은 별도 DB에서
- 교안에 실제로 적힌 내용만 근거로 삼음
- 이름·범위·대표 판본처럼 판단이 필요한 것은 '후보'로 두고 대표님이 확정
- 계정·비밀번호·연락처·실명은 어떤 칸에도 옮기지 않음
