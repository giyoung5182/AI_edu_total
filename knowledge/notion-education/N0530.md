# (강사 시연) 예시를 넣으면 이렇게 달라진다 — 상담이력으로 고객 안내 문구 만들기

정리일: 2026-10-08 · 교육 에셋 N0530

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
한 줄로만 요청할 때와, 잘 쓴 예시 2개를 먼저 보여 주고 요청할 때 결과가 어떻게 달라지는지 비교하는 강사 시연입니다.
## 진행 단계
1. **시연 ① — 한 줄 요청** — 08_상담이력_보충.txt 첨부 후 입력.
- 입력할 내용:
```plain text
첨부한 상담이력으로 고객사에 보낼 처리 결과 안내 문구를 건별로 써줘.
```
- 볼 것: 건마다 길이·구성·말투가 다름 / 귀책이 확인 중·미기재인 건도 원인을 단정하는지 / 내부 메모가 고객 문구에 섞이는지
1. **시연 ② — 예시 2개 포함 요청** — 같은 채팅에서 \[예시 1\], \[예시 2\]와 ［규칙］(순서: 인사·건 이름 → 확인 결과 → 처리 결과 → 마무리 1문장 / 귀책이 확인 중이거나 비어 있으면 원인을 쓰지 말고 '확인 중' / 자료에 없는 보상·일정은 약속하지 않음 / 내부 메모는 넣지 않음)을 넣어 5건의 안내 문구를 요청(이하 교안 참고).
- 정상 결과: 5건이 모두 예시와 같은 순서·길이·말투로 나오고, 확인 중인 건은 '확인 중'으로 남으며 예시 속 사실이 다른 건에 섞이지 않음
## 막히는 지점
- 시연 ①에서 원인을 추측해 채움, 내부 메모가 고객 문구로 들어감
