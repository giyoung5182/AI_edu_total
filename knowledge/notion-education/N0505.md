# 실습 1-1. Golden Sample로 제안서 초안 만들기 (15분)

정리일: 2026-10-08 · 교육 에셋 N0505

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
기존 제안서(기준 전시 프로젝트 PLANNING 챕터)의 문체와 구조를 Golden Sample로 삼아, 새 클라이언트 제안서의 PLANNING 섹션 초안을 Claude로 만들고 체이닝으로 개선되는 과정을 확인합니다.
## 진행 단계
1. **준비** — claude.ai 접속 후 좌측 상단 New conversation을 클릭합니다.
2. **Step 1 — 프롬프트를 입력창에 붙여넣기** — \[클라이언트 브리프\] 부분만 교체합니다(오늘은 연습용 브리프 사용).
- 입력할 내용: RCTCK 5요소 프롬프트. 구성은 R(수석 기획자), C(회사 수행 이력과 제안서 PLANNING 챕터 작성 상황), T(PROLOGUE·INSIGHT·STRATEGY·SOLUTION 구성), C(Golden Sample과 동일한 톤, PROLOGUE는 "X는 Y가 아니라 Z다" 형식, 전략명 영어 2\~3단어, 추상 개념은 공간의 구체적 요소와 연결, "혁신적인" 등 남발 금지), K(Golden Sample 발췌 + 클라이언트 브리프). (전문은 교안 참고)
3. **Step 2 — 결과 확인 (3분)**
- 정상 결과: PROLOGUE가 역설적 선언으로 시작 / STRATEGY 전략명이 영어 2\~3단어 / 추상적 개념이 공간 요소(헤더 구조, 동선 설계 등)와 연결됨
4. **Step 3 — 체이닝으로 개선 (7분)** — 같은 대화창에서 입력합니다. 처음 결과가 70% 수준이면 충분합니다.
- 입력할 내용(Prologue 감성이 약할 때): `PROLOGUE 섹션을 더 철학적인 문체로 다시 써줘. "공간은 X가 아니라 Y다"로 시작하고, 건설사의 주거 공간 철학이 기준 전시 프로젝트 Golden Sample처럼 깊이 있게 담기도록 해줘.`
- 입력할 내용(Strategy가 추상적일 때): `STRATEGY 섹션의 각 전략을 전시 공간의 구체적인 실행 요소와 연결해서 다시 써줘.` (이하 교안 참고)
- 입력할 내용(문체가 다를 때): `K에 넣어준 기준 전시 프로젝트 제안서 문체를 더 가깝게 따라줘.` (이하 교안 참고)
5. **Step 4 — 실제 프로젝트로 적용** — 연습용 브리프 대신 진행 중인 실제 프로젝트의 클라이언트, 전시명, 컨셉 키워드, 타겟, 부스 규모, 강조 포인트를 채워 다시 해봅니다.
- 체크리스트: PROLOGUE 역설적 선언 / INSIGHT 3가지가 서로 다른 관점 / STRATEGY 전략명 영문 2\~3단어 / 추상 개념과 공간 요소 연결 / 체이닝 1회 이상
## 막히는 지점
- 교안에 별도 기재 없음 (무료 한도 도달 시 잠시 대기 후 재시도하거나 ChatGPT·Gemini에서 동일 프롬프트 사용).
