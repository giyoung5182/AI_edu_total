## 2-3. 요청 프롬프트
```plain text
학생들의 응답을 모아서 볼 수 있게 만들어줘.

[기능]
- 각 문제별로 학생들이 어떤 보기를 골랐는지 집계
- 집계 결과를 막대그래프로 보여주는 화면을 따로 추가
- 집계 화면은 하단의 작은 버튼으로만 들어가게
- 전체 응답 수와 문제별 정답률도 표시

[기술 조건]
- 브라우저 localStorage는 절대 쓰지 마
- Artifacts의 공유 저장소(window.storage, shared 옵션)를 사용해줘
- 저장이 실패해도 앱이 멈추지 않게 예외 처리해줘
- 응답은 문제를 다 푼 시점에 한 번만 저장해줘
- 저장되는 데이터에 이름 같은 개인정보를 넣지 마

나머지 기능은 그대로 유지해줘.
```
> **핵심 — "window.storage"라고 정확한 이름을 주는 게 핵심입니다**<br>"데이터를 저장해줘"라고만 하면 여러 방법 중 하나를 고르는데,<br>그중 상당수가 Artifacts에서 안 됩니다. 이름을 짚어주면 바로 맞는 방법으로 갑니다.
**추가한 기능**
- 학생이 5문제를 다 풀면(결과 화면 진입 시) 딱 한 번, 문제별로 고른 보기 번호만 익명으로 저장돼요. 이름 등 개인정보는 저장하지 않습니다.
- 화면 맨 아래에 아주 작고 흐릿한 "📊" 버튼이 있어요. 퀴즈 화면 어디에도 눈에 띄지 않게 배치해서 학생이 실수로 누르기 어렵게 했습니다.
- 그 버튼을 누르면 집계 화면으로 전환되어 전체 응답 수, 문제별 정답률, 그리고 보기별 선택 인원을 막대그래프로 보여줘요. "새로고침"으로 다시 불러올 수 있고 "닫기"로 원래 화면으로 돌아갑니다.
- 문제 순서가 학생마다 섞여도 정확히 집계되도록 각 문제에 고유 id를 부여해 매칭했어요.
- `window.storage`(shared: true) 저장/조회는 모두 try/catch로 감싸서, 저장이 실패해도 퀴즈 진행에는 전혀 영향이 없습니다.
