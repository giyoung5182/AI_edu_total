# 실습 2. 환각 관찰 3질문 + 같은 질문 다시 묻기

정리일: 2026-10-08 · 교육 에셋 N0595

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
질문의 종류(회사 내부 정보 / 준 자료 안 / 준 자료 밖)에 따라 AI의 답과 확인 방법이 어떻게 달라지는지 관찰하고, 원문 대조 후 판정 상태로 기록합니다.
## 진행 단계
1. **먼저 예측** — P1-3 예측 칸: 자료 없이 회사 내부 수치를 물으면 숫자를 말할까, 모른다고 할까? / 규정집에 금액이 없는 항목을 물으면?
2. **질문 1 (자료 없음, 대화 ①)** — 새 채팅. + 메뉴에 Gmail·Google Drive 같은 앱이 보이면 임시 채팅 사용.
- 입력할 내용:
```javascript
교육기관 22 정산팀이 2026년 상반기에 반려한 출장 정산 건수와
주요 반려 사유 3가지를 알려줘.
```
- 결과를 P1-3 질문 1 행에 기록(답 요지 / 출처 표시 / 기준일 / 판정 상태).
1. **질문 1 다시 (대화 ②)** — 새 채팅에서 글자 하나 바꾸지 않고 다시 입력, 두 답의 같은 점·다른 점을 재실행 비교 칸에 기록.
2. **질문 2 (준 자료 안, 대화 ③)** — 새 채팅 → + → 사진 및 파일 추가 → 04_출장관리_사내규정집.docx 첨부.
```javascript
첨부한 사내 규정집을 근거로 답해줘.
개인카드로 결제하고 나중에 정산하는 출장 건에서 영수증을 첨부하지 않으면
정산이 어떻게 처리되는지 알려줘.
근거 조항 번호와 원문 문장을 그대로 인용해줘.
```
- 직접 원문 대조: 규정집에서 Ctrl+F로 AI가 댄 조항 번호 검색, 인용문과 원문이 한 글자씩 같은지 확인.
1. **질문 3 (준 자료 밖, 같은 대화 ③)** — 파일은 다시 올리지 않음.
```javascript
해외 출장 중 현지 택시비·통신비 같은 기타 경비의 1일 상한액은 얼마야?
근거 조항 번호와 원문 문장을 인용해줘.
```
- 규정집에서 '기타 경비', '통신비', '교통비'를 Ctrl+F로 검색해 금액이 실제로 적혀 있는지 확인.
1. **판정** — 판정 상태 5가지(근거 확인 / 근거 불일치 / 근거 없는 단정 / 확인 불가 응답 / 보류) 중 하나로 기록. 대화 ③은 닫지 말고 실습 3에서 이어서 사용.
## 막히는 지점
- 연결 앱이 있는 상태에서 질문 1은 내 메일·드라이브를 검색할 수 있음 → 임시 채팅 사용, 검색 표시가 보이면 중지 버튼으로 멈춤(교안: 임시 채팅 버튼 위치는 확인 필요 표기).
- 규정집 업로드가 계속 돌면 10초 대기, 안 되면 파일을 입력창으로 끌어다 놓기.
