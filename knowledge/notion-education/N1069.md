# 03. 데이터 추출 및 가공 실습 (집계·GROUP BY·HAVING·서브쿼리)

정리일: 2026-10-08 · 교육 에셋 N1069

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
집계함수와 GROUP BY, HAVING, 서브쿼리로 데이터를 요약하고 단계적으로 가공합니다.
## 진행 단계
1. **집계함수** — COUNT, AVG, MAX, MIN, SUM을 한 쿼리에서 함께 씁니다.
```sql
select count(*)as cnt
, avg(나이)as avg_age
, max(나이)as max_age
, min(나이)as min_age
, sum(나이)as sum_age
from basic.theglory
```
2. **GROUP BY** — 성별을 기준 컬럼으로 두고 집계합니다.
```sql
select 성별, count(*)as cnt, avg(나이)as avg_age
from basic.theglory
group by 성별
```
- 정상 결과: 여자의 평균 나이 38.25세, 남자 37세로 비교됨
3. **WHERE + GROUP BY + HAVING** — 나이 31 이상(WHERE), 성별별 평균 나이(GROUP BY), 평균 41 초과(HAVING).
```sql
select 성별, avg(나이)as avg_age
from basic.theglory
where 나이>=31
group by 성별
having AVG_AGE>41
```
4. **중첩 서브쿼리** — 특정 인물의 나이보다 나이가 많은 데이터를 반환합니다.
```sql
select *
from basic.theglory
where 나이 > (select 나이 from basic.theglory where 이름='문동은')
;
```
5. **스칼라 서브쿼리** — theglory2 파일을 업로드한 뒤 이름이 일치하는 건수와 결제금액 합계를 컬럼으로 반환합니다.
```sql
select 이름, 나이
, (select count(*) from theglory2 where theglory2.이름=theglory.이름) as same_name_cnt
, (select sum(결제금액) from theglory2 where theglory2.이름=theglory.이름)as same_name_sumamount
from basic.theglory
;
```
6. **인라인 뷰** — 나이 33 이상 데이터의 나이·직업 컬럼을 FROM 절 서브쿼리로 뽑습니다. AS로 명칭을 반드시 기재합니다.
```sql
select x.나이, x.직업
from(	select *
	  from basic.theglory
	  where 나이>=33
   )as x
```
## 막히는 지점
- 기준 컬럼과 집계함수를 쓰고 GROUP BY를 쓰지 않으면 에러가 발생합니다.
- 서브쿼리는 () 안에 SELECT, FROM을 명시해야 하고, 쿼리 마지막에 ; 와 ORDER BY를 쓸 수 없습니다.
