# 실습 2 | Deep Research 경쟁사·트렌드 리서치 (15분)

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Deep Research로 경쟁사 SNS 전략·트렌드 등 본인이 궁금한 주제의 심층 보고서 초안을 만듭니다.
## 진행 단계
1. **표준 예시 확인 (3분)** — 경쟁사 SNS 전략 분석 프롬프트가 왜 이렇게 구성됐는지 읽습니다.
2. **나만의 리서치 주제 직접 작성 (4분)** — 주제(A\~E 중 선택 또는 직접 정하기)와 선택 이유를 한 줄로 적고, 분석 목적 + 분석 항목 + 기준 + 형식을 포함해 프롬프트를 작성합니다.
3. **Deep Research 실행 (5분)** — gemini.google.com 접속 후 입력창 아래 툴바에서 "Deep Research" 아이콘을 선택하고 프롬프트를 입력합니다.
- 정상 결과: 조사 계획이 먼저 표시되며, 필요하면 수정 후 확인 → 3\~5분 대기
4. **결과 활용 (3분)** — 즉시 후속 질문을 하고 구글 문서로 내보내 드라이브에 저장합니다.
- 입력할 내용:
```javascript
이 분석에서 교육기관가 이번 달 SNS에 바로 올릴 수 있는
콘텐츠 아이디어 5개를 실행 방법과 함께 제안해줘
```
## 막히는 지점
- 무료 계정 월 5회 한도. 접속이 안 되는 경우 강사 화면을 함께 보며 진행
- 조사 계획 단계를 그냥 넘기지 말고 방향·빠진 항목·범위를 확인
