# 실습 4. 데이터 검색 체계 설계

정리일: 2026-10-08 · 교육 에셋 N1226

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
사람들이 데이터를 찾는 방식을 고려해 검색 체계를 설계하고 복합 조건 쿼리를 작성한다.
## 진행 단계
1. **5가지 검색 방식 이해** — 키워드, 업무 영역별, 태그, 담당 부서, 개인정보 포함 여부.
2. **검색 체계 설계서 작성** — 태그·담당 부서·개인정보 포함 여부 검색의 설명·예시 쿼리·적합한 상황을 채운다.
3. **심화: 복합 조건 검색** — 에너지공급관리 영역 중 개인정보 포함 컬럼을 조회(테이블명·컬럼명·컬럼 설명·담당 부서 표시). 교안 문제로는 고객민원관리 영역의 '민원' 태그 컬럼 조회가 제시되며 결과를 패들릿에 업로드한다.
## 막히는 지점
- 캡쳐가 안 되면 쿼리문만 댓글로 작성한다.
