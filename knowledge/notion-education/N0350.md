## 이 실습으로 하는 것
오늘 만든 것을 새 대화에서 그대로 이어받을 수 있도록 coding 폴더에 06_인수인계.md를 저장하고, 폴더를 통째로 보관합니다.
## 진행 단계
1. **인수인계 문서 요청** — coding 폴더에 06_인수인계.md로 저장.
- 입력할 내용: 무엇을 왜 만들었는지 / 누가 언제 쓰는지 / 구현된 기능 / 저장 방식과 데이터 구조 / 아직 안 한 것과 다음에 할 것 / 오늘 막혔던 지점과 해결 방법
2. **폴더 확인** — 02_명세서.md, 03_데이터.csv, 04_결과물.html, 05_백업.html, 06_인수인계.md, CLAUDE.md, skill 폴더가 있는지 봅니다.
3. **읽는 순서 한 줄 추가** — CLAUDE.md 맨 위에 "작업을 시작하기 전에 CLAUDE.md와 02_명세서.md를 먼저 읽는다..."를 더합니다.
4. **폴더 보관** — 본인에게 메일로 보내거나 USB에 담습니다.
## 막히는 지점
