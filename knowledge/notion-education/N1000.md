# PART 03 :: 실습 자료 준비하기

정리일: 2026-10-08 · 교육 에셋 N1000

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

**이번 PART에서는**, 오늘 만들 화면에 넣을 실습 데이터를 준비합니다. 사내 자료를 가져오지 않고, 형태는 같고 내용만 가짜인 데이터를 만듭니다. 40분짜리 실습 중심 PART입니다.

## 지금 우리가 있는 곳
앞에서 오늘 하루 쓸 방식과 벽 대응법을 익혔습니다. 이제 실제로 화면에 넣을 재료, 즉 데이터를 준비합니다. 다음 PART(PRD 작성)에서 명세를 쓸 때 이 데이터의 형태를 그대로 참고합니다.
---
## 시작하기 전에

**사내 자료를 가져오지 않으셔도 됩니다.** 화면을 만들려면 그 안에 들어갈 내용이 있어야 하는데, 실제 자료를 쓰면 클라이언트 정보가 결과물에 그대로 남고 나중에 공유할 때 노출됩니다. 그래서 형태는 실제와 똑같고 내용만 가짜인 데이터를 만들어 씁니다.

### 이 PART에서 하는 것
- 내 자료가 어떤 형태인지 먼저 구분
- 형태에 맞춰 실습용 CSV 만들기
- 극단값 · 빈 값을 일부러 섞어 넣기
- 만들어진 데이터 확인하기

**어제 적으신 것 대부분이 ①이나 ③입니다.** 실적 집계·정산·현황 취합은 ①, 문서 검토·동향 조사·소재 검수는 ③입니다. 어느 쪽이든 오늘 만들 것은 CSV 한 장입니다. ④(예산 배분 계산기, 매체 단가 산출처럼 입력하는 것이 곧 데이터인 경우)라면 이 Step은 건너뛰고 다음 PART로 넘어가면 됩니다 - 다만 명세의 제약 칸에 넣어볼 경계값(0을 넣었을 때, 합이 100이 아닐 때 등)은 메모해 두세요.

---
## Step 02 :: 왜 CSV인가
엑셀에서 "다른 이름으로 저장 → CSV" 하면 그대로 나옵니다. 이미 쓰시던 형식입니다. 엑셀로도 열리고, 메모장으로도 열리고, 화면이 그대로 읽습니다.

**엑셀 파일(.xlsx)을 직접 읽게 하지 않는 이유** - 엑셀 파일은 압축된 형식이라 읽으려면 외부에서 불러오는 것이 필요합니다. 오늘 계속 금지해온 그것입니다. CSV는 글자만 들어 있어서 화면 코드가 바로 읽습니다.

극단값이 있다

아주 긴 이름 · 0원 · 100% 같은 것

**극단값과 빈 값이 핵심입니다.** 이름이 30자인 항목이 하나 있어야 화면이 깨지는 것을 발견합니다. 빈 값이 세 건은 있어야 조용한 실패를 직접 확인할 수 있습니다. 문서·자료(③) 유형은 10\~20건이 현실적입니다.

## Step 04 :: 형태별로 만들어 달라고 합니다.
### ① 표 모음
```javascript
coding 폴더에 03_데이터.csv 로 저장해줘.

조건이야.
- 40건 만들어줘
- 첫 줄은 열 이름
- 실제 광고 실무에서 나올 법한 형태로
- 다만 클라이언트명은 A사, B사 식으로
- 금액은 실제와 비슷한 자릿수로
- 상태가 골고루 섞이게
- 이름이 30자쯤 되는 것도 두 건 넣어줘
- 값이 비어 있는 것도 세 건 넣어줘
- 숫자가 0인 것도 하나 넣어줘
- 날짜는 지난 것과 앞으로 올 것을 섞어줘
- 한글이 안 깨지게 UTF-8로 저장해줘

만들고 나서 파일 경로와 총 건수를 알려줘.
```

**UTF-8로 저장해줘를 빼먹지 마세요.** 없으면 엑셀에서 열었을 때 한글이 깨져 보입니다.

### ② 표 + 양식
엑셀 자료와 워드 보고 양식을 함께 쓰는 경우입니다. 위 요청에 조건을 더 붙입니다.
```javascript
위 조건에 더해서
- 출력 양식의 항목이 전부 채워질 수 있는 열을 넣어줘
- 양식에 있는데 데이터에 없는 항목이 있으면 알려줘
```

양식에는 있는데 자료에는 없는 항목이 나오면, 그 자리를 무엇으로 채울지를 지금 정해야 합니다. 안 정하면 AI가 알아서 채웁니다.

### ③ 문서 · 자료

**오늘 만드는 것은 문서를 읽는 화면이 아닙니다.** 대신 문서에서 뽑아낸 항목을 관리·비교·집계하는 화면을 만듭니다. 문서를 읽는 것은 지금까지 하시던 대로 AI에게 시키면 됩니다.

```javascript
coding 폴더에 03_데이터.csv 로 저장해줘.

조건이야.
- 15건 만들어줘
- 첫 줄은 열 이름
- 문서에서 뽑아낸 항목이라고 가정하고
- 원문 내용이 아니라 판정에 쓸 항목만
- 상태가 골고루 섞이게 (완료 · 미완료 · 확인필요)
- 메모가 아주 긴 것도 하나 넣어줘
- 담당자가 비어 있는 것도 두 건 넣어줘
- 한글이 안 깨지게 UTF-8로 저장해줘

만들고 나서 파일 경로와 총 건수를 알려줘.
```

이미지를 다루는 경우, 이미지 파일 자체는 넣지 않습니다. 파일 이름이나 링크만 항목으로 넣어둡니다.
