# 실습 2. 데이터 관리 개선 방안 도출

정리일: 2026-10-08 · 교육 에셋 N0340

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
3회차까지 실습하며 발견한 데이터 관리 문제를 구체적·측정 가능·실행 가능한 개선 과제로 바꾸고 우선순위를 정한다.
## 진행 단계
1. **문제점 정리** — 실습에서 발견한 문제를 표의 "문제점" 칸에 적는다(예시: 지역명 불일치).
2. **근본 원인·개선 방안** — 원인(예: 자유 입력 허용)과 개선 방안(예: 드롭다운 선택으로 입력 방식 변경)을 적는다.
3. **우선순위 판단** — 중요도·긴급도(높음/중간/낮음)로 긴급도×중요도 매트릭스에 따라 1\~4순위를 정한다(즉시 착수 / 계획 수립 후 착수 / 위임·간소화 / 보류).
4. **담당·기한** — 담당과 기한을 지정하고 5개 이상 도출한다.
