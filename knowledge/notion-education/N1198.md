## 이 실습으로 하는 것
WSL 홈(`~/`) 아래에 작업 폴더를 만들고 파이썬 가상환경과 패키지를 설치합니다. `/mnt/c/...` 경로에서 작업하면 속도 저하와 권한 문제가 생길 수 있습니다.
## 진행 단계
1. **폴더·가상환경 만들기**
```bash
mkdir -p ~/hanbit-ai
cd ~/hanbit-ai
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install pypdf chromadb voyageai google-genai tavily-python rank-bm25
```
1. **설치 확인**
```bash
pip list | grep -E "pypdf|chromadb|voyageai|google-genai|tavily|rank-bm25"
```
- 정상 결과: 여섯 패키지가 모두 목록에 보임
## 막히는 지점
- 터미널을 새로 열면 가상환경이 꺼져 있음: `cd ~/hanbit-ai && source .venv/bin/activate` 먼저 실행. 프롬프트 앞에 `(.venv)`가 붙어 있으면 켜진 상태
- pip 설치가 매우 느리거나 실패: 네트워크 확인 후 pip install만 재실행
