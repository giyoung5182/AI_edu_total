# MISSION 2. 팀 손익계산서 완성하기

---

## 이 실습으로 하는 것
팀 노션 페이지 또는 워크시트의 손익계산서 표를 직접 채워 예상 순이익과 손익분기점을 구한다.
## 진행 단계
1. **지출 기입** — 재료비 합계, 포장재, 소모품, 예비비(10%), 총 지출을 채운다
2. **매출 기입** — 예상 판매가(개당), 예상 판매 수량, 예상 총 매출을 채운다
3. **결과 계산** — 예상 순이익, 손익분기점을 채운다
4. **공식 직접 써보기**
- 입력할 내용:
```javascript
개당 원가 = 총 지출 ÷ 예상 판매 수량 = ___원
개당 마진 = 판매가 - 개당 원가 = ___원
손익분기점 = 총 지출 ÷ 개당 마진 = ___개
```
