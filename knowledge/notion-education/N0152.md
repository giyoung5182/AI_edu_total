```plain text
1. claude.ai 로그인

   → 한글 계정이면 [기능], 영문이면 [Capabilities] 또는 [Features]
5. "코드 실행 및 파일 생성" (Code execution and file creation) 항목의
   토글이 켜짐(파란색/오른쪽)인지 확인. 꺼져 있으면 켜기
```

## 모델 설정 — 오늘 쓸 조합
[원본 이미지 제외]
```plain text
모델 선택창에 뜨는 것:

  Fable 5
  Opus 4.8      — 복잡한 작업용
  Sonnet 5      — 일상적인 작업에 가장 효율적  ★ 오늘 이걸로
  Haiku 4.5     — 가장 빠른 답변
  ── 하단 ──
  노력 (드롭다운)
  더 많은 모델 → Opus 4.7 / Opus 4.6 / Opus 3 / Sonnet 4.6
```
### ⚠️ 가장 흔한 실수 — "4.8이 최신이니까 Sonnet 4.8"
**Sonnet 4.8은 존재하지 않습니다. 4.8은 Opus에 붙은 숫자입니다.**
Sonnet 계열은 **5와 4.6 두 개뿐**입니다. 그런데 목록에서 Opus 4.8이 Sonnet 5보다 **위에** 있고 숫자도 커 보여서, "Sonnet 쓰라고 했으니 4.8" 하고 Opus를 켜는 일이 자주 생깁니다.
```plain text
❌  Sonnet 4.8   ← 이런 건 없습니다
✅  Sonnet 5     ← 목록 세 번째 줄, 체크 표시가 붙어 있는 것
```
> 📌 **안내할 때는 숫자 말고 위치로**<br>"Sonnet 5요"라고만 하면 위에서부터 훑다가 Opus를 누릅니다.<br>"위에서 세 번째, 파란 체크 붙어 있는 거요"라고 하세요.
### 📖 (참고) Fable 5는 뭔가요
목록 맨 위에 설명도 없이 놓여 있어서 제일 궁금해지는 이름입니다.
2026년 6월 9일에 공개된 모델로, Anthropic이 Opus보다 위에 두는 "Mythos 등급"의 첫 공개 모델입니다. Anthropic은 이 모델을 자사가 일반에 공개한 모델 중 가장 능력이 뛰어나다고 설명하며, 길고 복잡한 여러 단계 작업에서 격차가 가장 크게 벌어진다고 밝히고 있습니다.
**그래서 오늘 쓰면 안 됩니다. (어차피 PRO 버전은 따로 사용 불가능! 0722 기준)** <br>능력이 높다는 건 한도를 그만큼 빨리 쓴다는 뜻이고, 우리가 만들 퀴즈 앱은 그 능력이 전혀 필요 없는 작업입니다.
> 📖 **알아두면 좋은 것 — 같은 모델을 골라도 다른 모델이 답할 때가 있습니다**<br>Fable 5는 능력이 높은 만큼 오용 위험도 커서, 특정 주제의 질문은<br>**자동으로 다른 모델에게 넘겨 답하도록** 안전장치가 걸려 있습니다.<br>"분명 이 모델을 골랐는데 답이 좀 다른데?" 싶은 상황이 생길 수 있는 이유입니다.
AI 도구를 가르칠 때 "내가 고른 것과 실제로 답하는 것이 항상 같지는 않다"는 사례로 쓸 만합니다.
**"노력" 설정** — 다섯 단계
```plain text
낮음 / 중간(기본값) / 높음 / 엑스트라 / 최대

화면 안내 문구 그대로:
"더 높은 노력은 더 철저한 응답을 의미하지만,
 시간이 더 오래 걸리고 한도를 더 빨리 사용합니다"
```
**"사고" 토글** — 기본 켜짐. "더 복잡한 작업에 대해 깊이 사고합니다"
> **핵심 — 오늘 지정 조합: Sonnet 5 + 노력 중간 + 사고 기본값**
**오늘은 기본값 "중간" 그대로 둡니다.**
## 한도 — 이것 때문에 모델을 고르는 겁니다
### Pro 계정 기준
Anthropic 공식 안내에 따르면, Pro는 대화가 비교적 짧고 연산 부담이 적은 모델을 쓸 경우 **5시간마다 최소 45개 메시지**를 보낼 수 있고, 이 한도는 **5시간마다 리셋**됩니다. 실제 횟수는 메시지 길이, 첨부 파일, 대화 길이, 사용하는 모델에 따라 달라집니다.
**여기서 놓치면 안 되는 단서가 "짧은 대화 기준"입니다.**
```plain text
짧은 대화        "이거 뭐야?" → 세 줄 답변           → 소모 적음
아티팩트 작업     프롬프트 20줄 → 코드 400줄 생성      → 소모 큼
                수정 요청 → 코드 400줄 다시 읽고 다시 쓰기 → 더 큼
                수정 10번째 → 그동안 쌓인 것 전부 다시 읽기 → 훨씬 큼
```
아티팩트 작업은 짧은 대화가 아닙니다. 그리고 **뒤로 갈수록 한 번의 소모가 계속 커집니다.**

## Projects — 맥락을 고정하는 도구 (3분 시연)
> **참고** 실무자들이 Projects를 쓰는 진짜 이유는 파일 보관이 아니라 **맥락 고정**입니다.
```plain text
관련 대화와 자료를 한 폴더에 묶어두는 기능.

프로젝트에 파일을 넣으면
→ 그 안의 모든 대화가 그 파일을 자동 참조
→ 매번 파일을 다시 올릴 필요가 없음
```
**사용 순서**
```plain text
STEP 1. 왼쪽 사이드바 → [프로젝트] → [새 프로젝트]
STEP 2. 이름: "초등 SW 수업"
STEP 3. [프로젝트 지침]에 아래를 입력   ← 이게 핵심
```
> 💡 **진짜 강력한 건 "지침(Instructions)"입니다**
프로젝트마다 지침을 넣을 수 있습니다.
```plain text
나는 초등 5~6학년 SW 강사다.
답변은 항상 학생 눈높이 예시를 포함하고,
전문용어를 쓸 때는 반드시 괄호에 쉬운 설명을 달아라.
학습 목표를 먼저 제시한 뒤 활동을 설명해라.
```
```plain text
STEP 4. 교안 파일 하나 업로드
STEP 5. 프로젝트 안에서 새 대화를 열고 질문
```
> 이 지침이 이 프로젝트 안 **모든 대화에 자동으로 적용**됩니다.<br>매번 "초등학생 대상이야"를 반복할 필요가 없어집니다.
선생님들 같은 수업을 여러 학교에서 하시죠.<br>학교별로 프로젝트를 하나씩 만들어두면 학교마다 맥락이 분리됩니다.

## Artifacts란 정확히 무엇인가
```plain text
Claude가 만든 코드를 실제로 "실행해서"
화면 오른쪽에 띄워주는 기능.

코드를 보여주는 게 아니라, 동작하는 결과물을 보여줍니다.
```
## 실행 환경 — 이 하나가 전부를 결정합니다
```plain text
Artifacts는 브라우저 안의 격리된 방(샌드박스)에서 실행됩니다.

이 방에는 두 겹의 문이 잠겨 있습니다:
  ① 샌드박스 — 바깥(claude.ai 본체)에 손대지 못하게 막음
  ② 보안 정책(CSP) — 어디에 접속할 수 있는지, 뭘 저장할 수 있는지 제한
```
> **참고 — 유리 상자 비유**<br>안이 훤히 보이고 안에서 뭘 하든 자유롭지만, **밖으로 손을 뻗을 수는 없습니다.**<br>이 비유 하나로 아래 표가 전부 설명됩니다.

## (참고) 오늘 반드시 지킬 금지 조건 3가지
> **주의 — 이 세 줄이 오늘 만들 모든 프롬프트에 들어갑니다. 이유를 알아야 응용이 됩니다.**
**① AI 호출 금지**
```plain text
Claude로 만든 앱 안에서 다시 Claude를 부를 수 있습니다.
"AI가 문제를 자동 생성하는 퀴즈" 같은 게 기술적으로 가능합니다.

그런데 그렇게 만들면
→ 학생이 링크를 열었을 때 Claude 로그인 화면이 뜹니다
→ 학생은 만 18세 미만이라 계정을 만들 수 없습니다
→ 거기서 끝입니다
```
**② localStorage 금지**
```plain text
웹 개발을 조금 아시는 분은 localStorage를 떠올리실 겁니다.
브라우저에 데이터를 저장하는 가장 표준적인 방법입니다.

Artifacts에서는 막혀 있습니다. 그런데 실패 방식이 고약합니다:
  · 오류 메시지가 안 뜹니다
  · 앱은 정상적으로 화면에 나옵니다
  · 저장 버튼도 눌립니다
  · 데이터만 아무 데도 안 갑니다

이게 "조용한 실패"입니다. 1권 PART 3-4에서 다룬 세 번째 벽입니다.
```
> 💡 **Claude 내부 지시문에도 명시되어 있습니다**<br>Claude가 아티팩트를 만들 때 받는 시스템 지시에는<br>"localStorage, sessionStorage 등 브라우저 저장소 API를 절대 사용하지 말 것"이라고 적혀 있습니다.<br>그래서 보통은 알아서 피합니다.
그런데도 가끔 새어 나옵니다. 특히 **다른 곳에서 코드를 복사해 붙여넣을 때** 그렇습니다.<br>그래서 오늘 프롬프트에 금지 조건을 명시적으로 넣습니다.
**③ 외부 이미지·라이브러리 금지**
```plain text
학교 방화벽이 외부 주소를 막는 경우가 있습니다.
집에서는 되는데 학교에서만 안 되는 상황이 여기서 나옵니다.
필요하면 이모지나 도형으로 대체하게 하세요.
```

## 3-0. 아티팩트를 만드는 세 가지 경로
같은 아티팩트를 만드는 길이 하나가 아닙니다. 실습 중에 사이드바를 눌러보고 "이건 뭐예요?" 하는 질문이 나오니 미리 정리합니다.
### 경로 1 — 채팅창 (오늘 실습)
```plain text
새 대화 → 프롬프트 입력 → 오른쪽 패널에 결과물
```
가장 기본입니다. **오늘 실습은 전부 이 경로로 진행합니다.**
이 경로를 쓰는 이유는 기능이 더 좋아서가 아닙니다. 오늘 배우는 핵심이 "만든 다음 대화로 고쳐나간다"인데, 채팅창에서 시작하면 그 흐름이 화면에 그대로 보이기 때문입니다.

학교 안에서 수업 자료를 돌려쓰는 방식으로 그대로 쓸 수 있습니다.
