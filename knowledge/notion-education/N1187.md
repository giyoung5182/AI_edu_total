# 실습 5 — 조건부 메일 알림

정리일: 2026-10-08 · 교육 에셋 N1187

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
집계 결과를 보고 조건에 해당하면 메일을 보내고, 해당하지 않으면 보내지 않는 알림을 만듭니다.
## 진행 단계
1. **요청하기**
```javascript
같은 스크립트에 함수를 추가해줘.

[할 일] 주간 집계 후 조건을 확인하고 메일을 보낸다.

[발송 조건] 아래 중 하나라도 해당하면 발송
1. 지연 건이 1건 이상
2. 보류 건이 5건 이상
3. 완료일 누락이 3건 이상
4. 상태값 이상이 3건 이상

[발송하지 않는 경우]
- 위 조건에 하나도 해당하지 않으면 발송하지 않고 "특이사항 없음. 메일을 보내지 않았습니다" 알림만 표시

[메일 내용]
제목: [업무요청] 확인 필요 항목 N건 - MM/DD
본문: 이번 주 업무요청 처리 현황 요약(전체·상태별 건수, 평균 소요일, 확인 필요 항목, 지연 건 목록, 7일 이상 경과 안내) (형식 전문은 교안 참고)

[예외]
- 메일 주소는 코드 맨 위에 변수로 빼줘
- 발송 후 발송 일시를 주간집계 시트 맨 아래에 기록해줘

메뉴에 「알림 발송」 항목을 추가해줘.
```
2. **본인 메일로 테스트** — 코드 맨 위 변수에 본인 이메일을 넣고 실행합니다.
3. **확인 표대로 점검** — 그대로 실행(지연 건이 있으므로 발송) / 메일 도착·제목·본문 형식 확인 / 지연 건을 전부 완료로 바꾸고 실행(발송 안 함) / 주간집계 맨 아래에 발송 일시 기록
## 막히는 지점
- "조건에 해당 안 되면 보내지 않는다"가 핵심 — 매주 무조건 메일이 오면 아무도 안 읽게 됨
- 다른 사람 주소로 보내면 곤란한 상황이 생기므로 본인 메일로 먼저 테스트
