# STEP 6 · 노션에 저장하고 역량 키워드 자동 채우기

정리일: 2026-10-08 · 교육 에셋 N0434

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
완성한 STAR 카드를 노션 표에 저장하고 역량 키워드를 AI 자동 채우기로 채운다.
## 진행 단계
1. **표 만들기** — 속성 네 개: 경험 제목(제목, 내가) / STAR 정리(텍스트, 대화에서 복사) / 역량 키워드(AI 자동 채우기) / 선정(체크박스, 내가). 속성을 더 만들지 않는다.
2. **붙여넣기** — 대화창에서 `*복사`를 입력하면 표에 넣을 형태로 세 장이 나온다. 그대로 복사해 붙여넣는다.
3. **자동 채우기 설정** — 역량 키워드 속성 이름 클릭 → AI 자동 채우기에서 요약 선택 → 설정 창에서 기본 탭 유지 → 에이전트 지침의 영문 기본값을 지우고 아래를 넣음 → 생성하기로 한 건 확인 후 전체 실행.
- 입력할 내용:
```javascript
이 행의 STAR 정리를 읽고 드러나는 직무 역량을 두 개까지 뽑으세요.

쉼표로 구분해 나열하세요.
성실함, 열정 같은 태도 표현은 쓰지 마세요.
무엇을 할 줄 아는지가 드러나는 말로 쓰세요.
원문에 근거가 없으면 하나만 쓰거나 비워 두세요.
반드시 한국어로 쓰세요.
```
1. **결과 확인** — 세 행이 모두 한국어인가 / 원문에 없는 내용이 없는가 / 태도 표현이 아니라 역량어인가
## 막히는 지점
- 마지막 줄을 빼면 영어가 나올 수 있음
- 성실함·열정이 나오면 STAR 정리가 추상적이라는 뜻(행동이 구체적이지 않음)
- 노션 화면은 자주 바뀌므로 버튼 이름이나 위치가 다르면 화면에 보이는 것을 따를 것
