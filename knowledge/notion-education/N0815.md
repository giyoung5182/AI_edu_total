## PART B ㅣ 이미지 생성 AI 기초 완전 가이드
목표: 어떤 이미지 AI를 언제 쓸지 정확히 알고, 파메스테틱 제품 사진·카드뉴스·릴스 썸네일을 한글 깨짐 없이 직접 만들 수 있다
---
## 이미지 생성 AI가 작동하는 원리
```plain text
STEP 1. 랜덤 노이즈 (모자이크처럼 흐릿한 상태) 에서 시작
         ↓
STEP 2. 내가 입력한 프롬프트가
         "이 노이즈를 어떤 방향으로 정제할지" 안내
         ↓
STEP 3. 수십~수백 번 반복하며 노이즈 → 이미지로 수렴
         ↓
STEP 4. 최종 이미지 완성

모델마다 결과가 다른 이유:
① 학습 데이터의 종류와 양 (어떤 이미지를 얼마나 봤는가)
② 프롬프트 해석 방식 (언어 이해 모델의 성능)
③ 학습 목표 (예술적 감성 vs 사실적 정확도 vs 텍스트 정확도)

→ "최고의 모델"은 없습니다.
   "내 작업에 가장 맞는 모델"을 고르는 게 핵심입니다.
```

## ❓ 왜 이미지 프롬프트는 영어로 써야 더 잘 나오나요?
> 이것부터 이해하면 이미지 AI가 훨씬 쉬워집니다.
---
### 이유 1 — AI가 영어 이미지를 더 많이 봤다
```plain text
이미지 생성 AI는 인터넷의 수십억 장 이미지를 학습했습니다.
그 이미지들 대부분이 영문 설명(캡션)과 함께 저장되어 있습니다.

예시:
영문 캡션: "white marble texture, luxury, clean, soft lighting"
→ AI가 본 이미지: 고급 대리석 사진 수백만 장

한글 캡션: "흰 대리석, 고급스러운, 깔끔한, 부드러운 조명"
→ AI가 본 이미지: 극소수

결론:
영어 프롬프트 → AI가 정확히 이해 → 원하는 이미지 출력
한국어 프롬프트 → AI가 어림짐작 → 원하는 이미지와 다를 수 있음
```
### 이유 2 — 특히 텍스트(글자)는 더 심각하다
```plain text
이미지 안에 한글 텍스트를 넣으면:

AI가 학습한 한글 이미지 데이터가 극히 적음
→ 한글 자모를 인식하지 못함
→ 글자처럼 보이는 이상한 기호로 대체
→ 읽을 수 없는 깨진 글자 출력

이것이 바로 카드뉴스에 한글을 AI로 직접 넣을 수 없는 이유입니다.
해결법은 뒤에서 상세히 설명합니다.
```
### 이유 3 — 그래도 한국어로 해도 됩니다 (단, 텍스트 제외)
```plain text
장면·분위기·구도는 한국어로 입력해도 어느 정도 나옵니다.
ChatGPT 4o는 한국어 이해 능력도 상당히 좋습니다.

한국어로 해도 되는 것:
✅ "흰 대리석 위에 마호로사 병 놓아줘"
✅ "장미꽃잎 흩어진 배경으로 해줘"
✅ "부드러운 따뜻한 조명으로"

절대 한국어로 하면 안 되는 것:
❌ 이미지 안에 들어갈 한글 텍스트
   예: "수분광의 비밀"이라는 글자를 이미지에 넣어달라고 하기
   → 무조건 깨짐. 예외 없음.

영어 프롬프트를 쓰는 가장 큰 이유는 텍스트 깨짐이 아니라
구도·소재·조명의 표현 정확도를 높이기 위함입니다.
```

비율/형태
```plain text

vertical 9:16        → 세로형 (릴스·스토리용)
horizontal 16:9      → 가로형 (블로그·유튜브 썸네일)
```
분위기/스타일
```plain text
luxury minimal       → 고급스럽고 미니멀한 (마호로사, 세멘잘에 어울림)
fresh clean          → 신선하고 깔끔한 (그린박신 스트롱에 어울림)
bold energetic       → 강렬하고 에너제틱한 (민타비20에 어울림)

editorial style      → 에디토리얼 스타일 (잡지 화보 느낌)
```
배경/소재
```plain text
white marble surface     → 흰 대리석 위 (고급스러운 느낌)
light wood surface       → 밝은 우드 위 (따뜻하고 자연스러운 느낌)
dark charcoal background → 어두운 챠콜 배경 (드라마틱한 느낌)
cream linen fabric       → 크림색 린넨 천 위 (부드럽고 자연스러운 느낌)
glass surface            → 유리 위 (모던하고 시원한 느낌)
flower petals scattered  → 꽃잎 흩어진 배경 (로맨틱한 느낌)
```
조명
```plain text
soft diffused lighting       → 부드러운 확산광 (기본 제품 사진에 무난)
warm studio lighting         → 따뜻한 스튜디오 조명 (아늑하고 고급스러운 느낌)
dramatic spotlight           → 드라마틱한 스포트라이트 (강렬한 느낌)
natural daylight             → 자연광 (친근하고 자연스러운 느낌)
backlit glow                 → 역광 글로우 (신비롭고 감성적인 느낌)
2700K warm white             → 따뜻한 노란빛 조명 (K값이 낮을수록 더 따뜻함)
5000K cool white             → 시원한 흰빛 조명 (K값이 높을수록 더 차가움)
```
구도
```plain text
flat lay                → 위에서 내려다본 평면 구도 (제품 여러 개 배치할 때)
close-up                → 클로즈업 (제품 디테일 강조할 때)
centered composition    → 중앙 정렬 구도 (안정적이고 깔끔한 느낌)
side angle              → 측면 구도 (제품 높이감 표현할 때)
lifestyle scene         → 라이프스타일 장면 (실생활 사용 컨셉)
```
화질 + 텍스트 없음 (항상 마지막에 추가)
```plain text
professional photography     → 전문 사진 품질
hyperrealistic               → 극도로 사실적인
no text                      → 텍스트 없음
no letters                   → 글자 없음
no korean characters         → 한글 없음
```
> ⚠️ no text / no letters / no korean characters 는 항상 마지막에 넣으세요<br>이 세 줄이 없으면 AI가 멋대로 글자를 집어넣습니다.

### 왜 한글이 깨지는가? — 원인 완전 이해
```plain text
AI 이미지 생성 프롬프트에 한글을 넣으면 이렇게 됩니다:

입력: "수분광의 비밀이라고 이미지에 써줘"

- AI는 이미지를 픽셀(점)로 그립니다
- 한글 자모(ㄱ,ㄴ,ㄷ / ㅏ,ㅑ,ㅓ...)의 픽셀 패턴을

- 그래서 대충 비슷한 기호를 그려버립니다

→ 해결 방법: AI로는 배경만 만들고,
   한글 텍스트는 Canva에서 직접 입력합니다.
```

## 이미지 체이닝 — 결과가 마음에 안 들 때
### 체이닝 원칙
```plain text
"처음부터 완벽한 이미지를 원해요"라는 마음을 버리세요.

1~2가지씩 단계별로 수정하는 것이 훨씬 효율적입니다.
한 번에 너무 많이 바꾸면 AI가 방향을 잃습니다.

1차 프롬프트 → 60% (방향 확인)
2차 수정     → 75% (배경·소재 정교화)
3차 수정     → 85% (조명·분위기 정교화)
4차 수정     → 90%+ (세부 디테일 완성)
```
### 체이닝 명령 5종
```plain text
// 1. 배경·소재만 바꾸기
"배경을 흰 대리석에서 크림색 린넨으로 바꿔줘.
나머지는 그대로 유지해줘."

// 2. 조명만 바꾸기
"조명을 더 따뜻하고 부드럽게 바꿔줘.
배경과 구도는 그대로."

// 3. 구도만 바꾸기
"제품을 화면 오른쪽으로 옮기고
왼쪽에 장미꽃을 추가해줘.
조명과 배경은 그대로."

// 4. 분위기만 바꾸기
"전체적으로 더 고급스럽고 부드럽게.
색감을 크림과 골드 톤으로 통일해줘."

// 5. 시리즈 만들기 (같은 분위기로 다른 제품)
"방금 만든 이미지의 배경, 조명, 분위기를 완전히 유지하고
마호로사 병을 민타비20 병으로만 바꿔줘."
```

### R — Role (역할)
왜 중요한가?<br>역할이 없으면 AI는 '일반인 수준'으로 답합니다. 역할을 주면 '전문가 수준'으로 답합니다.
```plain text
❌ 역할 없이:
"마호로사 인스타 글 써줘"
→ 평범하고 어디서 본 듯한 글

✅ 역할 부여 후:
"너는 10년 경력의 에스테틱 원장이자
파메스테틱 전문 SNS 작가야."
→ 전문성 있고 신뢰가 가는 글
```
에스테틱 원장 Role 라이브러리 — 복사해서 바로 사용
```plain text
// 인스타 본문용
"너는 10년 이상 경력의 에스테틱 전문 원장이자
파메스테틱 제품 SNS 전문 작가야.
피부과학적 근거를 갖추면서도 친근하게 전달하는 게 특기야."

// 릴스 대본용
"너는 인스타그램 릴스 시청 지속률 최적화 전문가야.
0~3초 훅, 4~25초 정보 전달, 26~30초 CTA 구조를
자연스럽게 구성하는 에스테틱 콘텐츠 전문가야."

// 블로그용
"너는 에스테틱 전문 블로거이자 SEO 전문가야.
네이버 블로그 상위 노출을 위한 키워드 중심 글쓰기가 특기야."

// 고객 상담용
"너는 파메스테틱 전속 에스테틱 원장으로서
고객의 피부 고민에 공감하고 적합한 제품을 추천하는 상담사야."

// 브랜딩용
"너는 소셜미디어 브랜딩 전략가야.
에스테틱 원장의 팬덤을 만드는 퍼스널 브랜딩이 전문이야."
```

### C — Context (맥락)
왜 중요한가?<br>같은 제품이라도 팔로워 수, 타겟, 채널에 따라 글이 완전히 달라집니다.
```plain text
❌ 맥락 없이: "마호로사 글 써줘" → AI가 임의로 정해버림

✅ 맥락 포함:
"채널: 인스타그램 | 팔로워: 8,000명
타겟: 30~40대 건성·민감성 피부 여성
브랜드 컨셉: 에스테틱 원장이 직접 쓰는 제품만 추천
현재 시즌: 봄철 환절기
이 맥락에서 마호로사를 소개하는 글 써줘."
→ 딱 맞는 맥락의 글
```
Context 체크리스트
```plain text
□ 채널: 인스타그램 / 블로그 / 틱톡
□ 팔로워 규모
□ 타겟 피부 고민
□ 내 브랜드 컨셉 한 줄
□ 현재 시즌·이슈 (환절기, 여름 대비 등)
□ 이 글의 목적 (판매 유도 / 정보 제공 / 팬덤 형성)
```

### T — Task (과제)
왜 중요한가?<br>"글 써줘"보다 "①②③ 순서로 해줘"가 훨씬 정확합니다.
```plain text
❌ 막연한 Task:
"마호로사 인스타 글 써줘"

✅ 단계별 Task:
"다음 순서로 작업해줘:
1단계. 메이크업 들뜸으로 고민하는 고객 공감 문장 1~2줄
2단계. 마호로사의 핵심 해결 포인트 1가지 (과대광고 없이)
3단계. CTA: 댓글에 수분광 남겨주시면 사용법 DM 드려요
4단계. 해시태그 5개"
```

### C — Constraint (제약)
에스테틱 원장 필수 Constraint 세트 — 복사해서 사용
```plain text
// 법적 제약 (필수!)
"화장품법 위반 표현 절대 금지:
치료, 완치, 100% 개선, 의학적 효능,
피부 재생, 세포 회복 같은 의약품 표현"

// 형식 제약
"본문: 200~300자 이내
해시태그: 5개 포함
CTA: 마지막에 반드시 포함
줄바꿈: 2~3줄마다 (모바일 가독성)"

// 톤 제약
"전문가 권위 + 친근한 언니 느낌
과도한 세일즈 표현 금지"
```

### K — Knowledge (지식)
왜 중요한가?<br>AI는 파메스테틱 제품을 모릅니다. 알려줘야 씁니다. 이것이 GEMS의 핵심입니다.
단기 해결 — 프롬프트에 직접 붙여넣기
```plain text
[K - Knowledge]
마호로사 제품 정보:
- 정식명: 악센다 마호로사 크림미스트 100ml
- 컨셉: 스킨 하이라이터 + 레이어링 미스트 2중 기능
- 핵심 성분: 마린콜라겐, 3중 히알루론산, 엘로퍼스GGL100
- 사용법: 토너 후 / 메이크업 픽서로도 가능
- 가격: 소비자가 69,000원
- 합법 표현: "수분층을 쌓아주는", "광택감 부여"
```
장기 해결 — GEMS 세팅 (2권 모듈 3에서 실습)<br>한 번만 입력하면 이후 모든 대화에 자동 적용

### 파메스테틱 제품 데이터베이스 — GEMS에 탑재할 전체 데이터
```plain text
■ 악센다 마호로사 크림미스트 100ml
컨셉: 스킨 하이라이터 + 레이어링 미스트 2중 기능
브랜드 스토리: '마녀의 눈물' — 신비한 수분광 부여
가격: 파머가 59,000원 / 노출가 69,000원
```

```plain text
아래 고객 상담을 다음 순서로 단계적으로 생각해줘:

Step 4: 사용법과 기대 효과를 고객 입장에서 설명
```
