# 실습 2 — 명세화 프롬프트로 3개 문서 통합 추출하기

정리일: 2026-10-08 · 교육 에셋 N0319

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 1의 샘플 문서 3건으로 하나의 통합 표를 만든다.
## 진행 단계
1. **통합 추출 요청** — Copilot 채팅 창을 새로 열고 프롬프트를 복사, 문서 자리에 실습 1 각 문서 내용을 붙여넣음
- 입력할 내용:
```javascript
아래 자문 의견서 3건을 분석하여 하나의 통합 표로 만들어줘.
추출 항목: 문서번호, 의뢰인, 접수일, 쟁점, 결론(또는 검토 상태), 특이사항
처리 규칙:
- 문서번호는 순서대로 1, 2, 3으로 부여해줘.
- 접수일은 YYYY-MM-DD 형식으로 통일해줘.
- 항목을 찾을 수 없으면 "미확인"으로 표시해줘.
- 쟁점이 여러 개면 세미콜론(;)으로 구분해줘.

[샘플 문서 1 텍스트]
---
[샘플 문서 2 텍스트]
---
[샘플 문서 3 텍스트]
```
2. **출력 표 검토** — 체크 항목(3행 여부, YYYY-MM-DD, "미확인" 처리, 세미콜론 구분, 열 추가·누락 없음)으로 직접 확인
3. **수정 요청** — 기대와 다르면 후속 프롬프트로 수정(문서 2 접수일 누락 → 본문에서 다시 찾기, 문서 3 담당 변호사 빈 칸 → "미배정")
4. **저장** — 완성된 표를 Excel에 붙여넣어 `자문의견서_추출_실습.xlsx`로 저장
- 정상 결과: 구조가 제각각인 세 문서가 통일된 컬럼의 표 한 장으로 정리되고, 항목이 누락된 문서 3은 "미확인" 또는 "미배정"으로 처리됨
## 막히는 지점
- 교안에 별도 항목 없음(결과가 기대와 다르면 후속 프롬프트로 수정 요청)
