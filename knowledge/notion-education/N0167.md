## 세 가지 쓰는 방법
### 방법 A · 그냥 참고만 하기 (권장)
3교시에 AI와 인터뷰하며 **본인 것을 만드실 겁니다.**<br>그때 "이 정도로 적으면 되는구나"를 확인하는 용도로 보세요.
```plain text
□ 내 것과 비교해서 빠진 항목이 있는지 확인
□ 화면 구성을 이 정도로 자세히 적었는지 확인
□ 완료 조건이 분명한지 확인
```
### 방법 B · 그대로 쓰기
시간이 부족하거나, 오후에 합류하셨거나, 주제가 안 떠오르실 때.
```plain text
1. 세 개 중 하나를 고릅니다
2. class-tool 폴더에 넣습니다
3. 파일 이름을 prd.md 로 바꿉니다
4. 각 파일 맨 아래의 프롬프트를 그대로 씁니다
```
> 💡 부끄러운 선택이 아닙니다. **하나를 끝까지 완성하는 것**이 오늘의 목표입니다.
### 방법 C · 내 수업으로 바꾸기
구조는 그대로 두고 **내용만** 바꾸는 방식입니다. 가장 실용적입니다.
```plain text
prd.md의 내용을 '식물의 한살이'로 바꿔줘.
구조와 화면 구성은 그대로 두고 내용만 고쳐줘.
```

## 자주 나오는 질문
**Q. 이걸 제가 직접 써야 하나요?**<br>아닙니다. 3교시에는 **AI의 질문에 답만 하시면** 됩니다. 답이 모이면 "정리해줘" 한 줄로 AI가 만들어줍니다. 이 예시는 결과물이 어떻게 생겼는지 보여드리는 것뿐입니다.
**Q. 세 개를 섞어도 되나요?**<br>됩니다. 다만 오늘은 **하나만** 하세요. 섞으면 범위가 커져서 못 끝냅니다.
**Q. 예시보다 더 간단해도 되나요?**<br>됩니다. 「무엇을 / 화면 구성 / 완료 조건」 세 개만 있어도 만들 수 있습니다.
**Q. 예시보다 더 복잡하게 하고 싶은데요.**<br>오늘은 참으세요. 배포까지 끝낸 뒤 집에서 얹으시면 됩니다. 오늘 목표는 **한 바퀴 완주**입니다.
