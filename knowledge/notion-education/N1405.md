# 활동 5-2 — 조건을 넣어 재작성

정리일: 2026-10-08 · 교육 에셋 N1405

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
출력 구조와 작성 규칙을 넣어 회의록을 다시 만들고, 1차와 비교합니다.
## 진행 단계
1. **조건을 넣어 재작성**
- 입력할 내용:
```javascript
너는 제조업 경영관리 부서의 회의록 담당자다.
아래 녹취록을 정식 회의록으로 정리하라.

출력 구조:

## 회의 개요
(일시, 장소, 참석자)

## 안건별 논의 요약
(안건마다 소제목, 주요 발언 요지 3줄 이내)

## 결정 사항
| 번호 | 결정 내용 | 근거 발언자 |

## 액션 아이템
| 번호 | 할 일 | 담당자 | 기한 | 비고 |

## 미결 사항
(결론이 나지 않은 것)

## 확인 필요
(담당자 또는 기한이 명시되지 않은 항목)

작성 규칙:
- 발언 중 스스로 정정한 내용은 최종 발언을 기준으로 한다
- "8월 중", "조만간" 같은 모호한 기한은 그대로 적고 확인 필요에 넣는다
- 담당자가 지목되지 않은 과제는 담당자란을 비우고 확인 필요에 넣는다
- 녹취록에 없는 내용을 추가하지 않는다
- 발언자가 불명확한 부분은 "발언자 불명"으로 표기한다
```
1. **결과 비교** — 워크시트에 1차·2차의 액션 아이템 수, 담당자 명시, 기한 명시, 미결 사항, 확인 필요를 비교합니다.
2. **핵심 관찰** — 담당자는 있는데 기한이 없는 과제가 확인 필요에 잡혔는지 확인합니다.
3. **규칙 추가**
- 입력할 내용:
```javascript
추가 규칙:
- 담당자와 기한 중 하나라도 비어 있으면 확인 필요에 넣는다
- "8월 중"처럼 날짜가 특정되지 않은 기한도 확인 필요로 분류한다
```
- 정상 결과: 추가 규칙 후 기한이 없는 과제와 모호한 기한이 확인 필요로 분류됩니다.
## 막히는 지점
- "담당자는 있고 기한만 없는 경우"를 놓치기 쉬움 → 추가 규칙 필요
- 미결 사항이 "결정 사항"으로 들어가 있으면 틀린 회의록
