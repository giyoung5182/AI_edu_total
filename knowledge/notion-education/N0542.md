# 실습 3. 카드 3 — 고객 회신 초안: 좋은 예시 vs 오염된 예시

정리일: 2026-10-08 · 교육 에셋 N0542

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
사실이 들어 있는 오염된 예시(A)와 형식만 전달하는 좋은 예시(B)로 고객 회신 초안을 만들어, 예시 오염을 직접 확인합니다. (교안에는 '향후 과제'로 표시)
## 진행 단계
1. **실행 A — 오염된 예시** — 새 채팅에 \[역할\]\[맥락\]\[과업\]\[예시\]\[대상 자료\] 프롬프트를 붙여넣어 실행(이하 교안 참고).
2. **A 기록** — P2-4 표 A 열에 점검 질문 3개(예시의 고객사명·사람 이름 / 금액·날짜·비율 / 원인·보상 문장이 예시에서 왔는지) 기준으로 기록.
3. **실행 B — 좋은 예시** — 새 채팅에서 \[예시\] 블록만 형식 예시(구조만 참고, 내용 사용 금지)로 바꿔 실행.
- 입력할 내용:
```plain text
[예시 — 형식 예시(EX-CL-901, 교육용 가상 사례). 문단 순서와 어조만 참고하고, 예시의 고객사·금액·원인·조치는 절대 사용하지 않는다. 사실은 [대상 자료]에서만 가져온다.]
(이하 교안 참고)
```
- 정상 결과: (1)\~(4) 네 문단 구조, 예시의 이름·표현이 없고, 날짜 자리는 \[회신 예정일 확인 필요\]
1. **B 기록·수정 요청 1회** — B 결과에서 어긋난 문장 1개를 골라 \[유지할 것\]\[바꿀 것\]\[근거\] 문형으로 수정 요청하고 P2-5에 기록.
## 막히는 지점
- 예시 오염 / \[예시\] 블록 교체 중 \[대상 자료\]까지 지움 / 수정 요청 시 초안 전체가 바뀜
