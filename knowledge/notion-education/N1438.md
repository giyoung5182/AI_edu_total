## 이 실습으로 하는 것
새 프롬프트를 쓰지 않고 3교시에 만든 GPTs로 데이터를 분석해, 대시보드에 넣을 결과를 표로 정리합니다.
## 진행 단계
1. **업무 유형 고르기** — 집계형 / 점검형 / 조사형 / 문서형 중 선택(숫자를 더하는가 → 집계형, 무엇과 무엇을 맞춰보는가 → 점검형, 흩어진 걸 모으는가 → 조사형, 글을 쓰는가 → 문서형)
2. **내 GPT 열기** — ChatGPT → GPT 탐색 → 내 GPT → 3교시에 만든 도구 열기
3. **데이터 넣고 분석 요청** — 유형별 요청 예시를 사용
- 입력할 내용(집계형 예시):
```javascript
이 데이터를 정리해줘.
1. 한눈에 볼 지표 4개
2. 상태별 또는 유형별 분포
3. 부서별 또는 기간별 비교
4. 눈에 띄는 것 3가지
(이하 교안 참고)
결과를 표로 정리해줘. 대시보드에 넣을 거야.
```
- 정상 결과: 마지막 줄 "대시보드에 넣을 거야"를 쓰면 화면에 넣기 좋은 형태로 정리됨
4. **결과 정리** — 핵심 결과 1\~4와 확인이 필요한 것을 표에 기록
## 막히는 지점
