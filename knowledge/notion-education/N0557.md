# 실습 4. 데이터 사전 — 열의 뜻부터 정하기 (향후 과제)

정리일: 2026-10-08 · 교육 에셋 N0557

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
열의 뜻을 파일 근거로 정리하고, 근거 없는 정의는 추측하지 않고 확인 필요로 남겨 담당자 질문 목록으로 만듭니다.
## 진행 단계
1. **데이터 사전 초안 요청** — 두 시트의 대상 열에 대해 실제 값 분포를 코드로 확인한 뒤 작성하게 합니다(출력 표: 시트 \| 열 이름 \| 뜻 \| 단위/형식 \| 실제 값 범위·종류 \| 빈칸 수 \| 정의의 근거 \| 상태). 근거 없는 정의는 상태를 확인 필요로 적게 합니다.
2. **P3-4에 옮겨 적기** — 답변을 워크시트에 붙여 넣습니다.
3. **필수 9항목 체크(AI 없이)** — 정산번호 고유성, 숙박비_박당, 일비_1일, 출장지→지역, 승인상태, 출발일·복귀일, 영수증첨부, 시간 열 단위, 점수 열 척도가 사전에 있는지 O/X로 확인하고 빠진 것은 추가 요청합니다.
4. **담당자 확인 질문 목록** — 확인 필요 항목을 질문 문장으로 적습니다.
- 정상 결과: 파일 근거 있는 정의와 확인 필요 정의가 구분됨
## 막히는 지점
- 모든 줄이 파일로 확인으로 나옴 → 근거를 파일에서 인용하게 하고 인용할 수 없으면 확인 필요로 바꾸게 요청
- 답이 중간에 끊기면 `이어서 출력하라. 이미 쓴 줄은 반복하지 마라.` 입력
