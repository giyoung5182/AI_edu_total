## 이 실습으로 하는 것
형식이 서로 다른 샘플 문서 3건을 읽고, 어떤 항목을 뽑을지 스스로 정의한다.
## 진행 단계
1. **샘플 문서 3건 읽기** — 명확한 구조형, 서술형 혼합, 항목 누락형 문서를 읽음
2. **추출 항목 적기** — 공통으로 추출할 수 있는 항목을 빈칸에 직접 적음
- 입력할 내용:
```javascript
내가 추출하고 싶은 항목:
① ________________
② ________________
③ ________________
④ ________________
```
3. **비교 후 확정** — 옆 수강생과 비교한 뒤 최종 추출 항목을 확정
- 정상 결과:
```javascript
확정된 추출 항목: 문서번호 / 의뢰인 / 접수일 / 쟁점 / 결론(또는 검토 상태) / 특이사항
```
## 막히는 지점
- 교안에 별도 항목 없음
