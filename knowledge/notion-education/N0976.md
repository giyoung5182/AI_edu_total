# 2부 · 이미지 AI는 어떻게 작동합니까
## 이미지 원리 하나 · 그림을 그리지 않고 노이즈를 걷어낸다
[원본 이미지 제외]
이미지 생성 AI는 무작위 잡음에서 시작해 형태가 아닌 부분을 걷어내는 방식으로 작동합니다. 화가가 흰 종이에 선을 긋는 것이 아니라, 조각가가 돌덩어리를 깎아 내는 쪽에 가깝습니다.
**그래서 생기는 현상**
- 같은 요청을 넣어도 매번 결과가 다릅니다. 오류가 아니라 구조상 당연합니다
- "아까 그거 다시 만들어 줘"가 되지 않습니다
- 좋은 결과가 나오면 **그 자리에서 저장**해야 합니다
```plain text
잘못된 방식: "다시 만들어 줘"          → 완전히 다른 이미지
올바른 방식: "이 이미지에서 구도와 색은 그대로 두고,
             하단 여백만 지금의 두 배로 넓혀 줘"  → 기준을 유지한 수정
```

# 6부 · 카드뉴스 여러 장 만들기
카드뉴스는 이미지 한 장이 아니라 **시리즈**입니다. 톤이 흔들리면 안 됩니다.
```plain text
1단계  기획 — 몇 장에 무엇을 담을지 텍스트로 먼저 정한다
2단계  1장 완성 — 경로 A 또는 B로 첫 장을 확정한다
3단계  나머지 장 확장 — 1장 기준으로 이어 만든다
4단계  전수 확인 — 글자·숫자를 눈으로 대조한다
```
**1단계 기획 요청**
```plain text
현장 시설관리 인력(기계·전기·소방) 채용을 위한 카드뉴스 5장을 기획해 줘.
아직 이미지는 만들지 말고 기획안 텍스트만 줘.

대상: 경력 3년 이상 시설관리 유자격자, 30~50대
채널: 채용 사이트 및 사내 추천 공유용
톤: 과장 없이 사실 중심. 감성적 표현은 쓰지 말 것

각 장마다 아래를 써 줘.
- 장 번호와 역할 (후킹 / 정보 / 정보 / 신뢰 / 행동유도)
- 헤드라인 (15자 이내)
- 본문 (40자 이내)
- 배경 이미지 방향 (한 줄)

내가 제공하지 않은 급여·복리후생 조건은 절대 만들지 마.
확정 필요한 항목은 [확인 필요]로 표시해 줘.
```
**3단계 시리즈 확장 지시문** `이미지 원리 하나`
```plain text
이 스타일과 색상 규칙을 그대로 유지하면서
[다음 장 주제]로 한 장 더 만들어 줘.
구도와 여백 위치도 동일하게 유지해 줘.
```

**실무자만 아는 지점 — 첫 장에 시간을 쓰세요**
첫 장을 완성하는 데 시간을 쓰고, 나머지는 위 한 줄로 이어 가세요.
각 장을 따로 만들면 톤이 제각각이 되어 결국 다시 만들게 됩니다.

# 7부 · 발산에서 수렴으로
한도를 낭비하지 않는 절차입니다. **이미지를 만들기 전에 텍스트 단계에서 발산을 끝내는 것**이 핵심입니다.
```plain text
1단계  발산 (텍스트만)
```
