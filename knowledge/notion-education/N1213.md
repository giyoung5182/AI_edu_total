# PoC 경로 B. 반복 보고서 초안 도구 만들기

정리일: 2026-10-08 · 교육 에셋 N1213

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
데이터 파일이 없는 사람이 매주 반복하는 보고서 작성을 Claude Code에 위임하는 도구를 만든다.
## 진행 단계
1. **내 반복 보고서 구조 정리 (직접 작성)** — 보고서명, 섹션 구성, 작성 소요 시간을 텍스트로 정리한다.
- 입력할 내용:
```javascript
매주 작성하는 보고서의 구조를 텍스트로 정리:

보고서명: [이름]
섹션 구성:
1. [섹션 1 제목]: [어떤 내용]
2. [섹션 2 제목]: [어떤 내용]

보통 작성에 걸리는 시간: [시간]분
```
2. **Claude Code로 보고서 초안 도구 만들기** — 프롬프트 하나로 초안을 만들고, 확인 후 수정 요청을 반영해 docx로 저장한다.
- 입력할 내용:
```javascript
나는 [직무]이고 매주 [보고서명]을 작성해.
구조는:
[Step 1에서 정리한 내용]

아래 "이번 주 상황"을 위 구조에 맞는 보고서 초안으로 변환해줘.

요청:
1. 보고서 초안을 채팅으로 먼저 보여줘
2. 확인 후 내가 수정을 요청하면 반영해줘
3. 최종본을 [보고서명]_날짜.docx 파일로 폴더에 저장해줘

이번 주 상황:
[이번 주 있었던 일을 순서 상관없이 자유롭게 작성]
```
3. **이번 주 실제 내용으로 테스트** — 실제 업무 내용을 넣어 결과를 확인하고, 원하는 형태가 아니면 그 자리에서 조정을 요청한다.
- 정상 결과: 원하는 형태의 보고서가 나온다. 예) "2번 섹션을 표 형식으로 바꿔줘"
