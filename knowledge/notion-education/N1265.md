# 4-4. NotebookLM 실전 활용 프롬프트

정리일: 2026-10-08 · 교육 에셋 N1265

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
노트북에 올린 문서를 근거로 기준 확인, 청구 문서 초안, FAQ, 교육 자료를 생성합니다.
## 진행 단계
1. **공종·하자 기준 확인** — 입력할 내용 예:
```javascript
타일 하자 중 "단차"와 "줄눈깨짐"의 처리 기준이 달라?
공종별 처리 절차를 표 형식으로 정리해줘. (공종 / 1차 접수 / 업체 지시 / 완료 확인)
```
2. **계약·청구 관련 확인** — 입력할 내용 예:
```javascript
이 계약서에서 하자보수 청구 가능 기간 조항 찾아줘.
업로드한 기존 청구서 형식 그대로 이번 달 것 초안을 만들어줘.
```
3. **현장 운영 기준 확인** — 사전점검 당일 타임라인·업무분장 표, 신규 매니저용 FAQ 10개, 에스컬레이션 절차 요약 등
4. **교육 자료 생성** — 업무표준 문서 기반 초보매니저 1시간 교육 계획, CS교육 핵심 카드 10장, 고객 응대 금지 행동 추출
