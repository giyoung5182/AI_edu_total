# C-1. 클라이언트 메일 3버전 자동화

정리일: 2026-10-08 · 교육 에셋 N0339

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 내용을 어조가 다른 3가지 버전의 클라이언트 메일로 한 번에 만듭니다.
## 진행 단계
1. **상황 입력** — 상황, 전달할 핵심 내용, 원하는 결과, 클라이언트 관계
2. **1단계** — 커뮤니케이션 목표 정리
3. **2단계** — 버전 A(정중·유연) / B(명확·단호) / C(협력·파트너십), 제목 포함·본문 5\~8문장 이내·마지막 문장은 다음 액션 제안
4. **3단계** — 버전별 선택 가이드
## 막히는 지점
- 2단계 작성 전 1단계를 먼저 완료.
