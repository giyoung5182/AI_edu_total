# Step 3 — 차트로 상관관계 확인 (Claude Code)

정리일: 2026-10-08 · 교육 에셋 N0368

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
매출과 검색량의 관계를 차트 이미지로 만들고 상관계수를 해석합니다.
## 진행 단계
1. **프롬프트 입력**
- 입력할 내용: 차트 1(월별 매출 vs 검색량 이중 y축 라인차트, 비슷하게 움직이는 구간 배경 초록 강조), 차트 2(검색량 vs 매출 산점도 + 추세선 + 상관계수 r), 2×1 그리드, 300dpi, trend_chart.png 저장, 한글 폰트 처리, 상관계수 해석 두세 문장.
2. **확인 포인트** — trend_chart.png 생성 후 열어서 확인, 한글 축 레이블, r 값 해석이 데이터와 맞는지.
## 막히는 지점
- 한글 깨짐 시 폰트 수정 재요청.
