# 5. 재실행 원리 체감하기 (심화, 선택)

정리일: 2026-10-08 · 교육 에셋 N0500

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
버튼을 누르는 순간 파일 전체가 위에서 아래로 다시 실행되는 Streamlit의 재실행 원리를 체감합니다.
## 진행 단계
1. **코드 교체 및 저장** — hello_streamlit.py 내용을 아래 코드로 바꾸고 VSCode에서 저장(Ctrl+S). 터미널이 이미 실행 중이면 브라우저에서 F5 새로고침만으로 반영
- 입력할 내용:
```javascript
import streamlit as st
st.title("재실행 체감 실습")
clicked = st.button("버튼 클릭")
if clicked:
 st.write("버튼을 눌렀습니다! 이 순간 전체 코드가 처음부터 다시 실행됩니다.")
st.write("이 문장은 버튼을 누르든 안 누르든 항상 다시 나타납니다.")
```
1. **버튼 클릭** — 버튼을 누르는 순간 파일 전체가 위에서 아래로 다시 실행됨
