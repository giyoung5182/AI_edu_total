# 5-6. 실습 — 결과보고서 비서 만들기

정리일: 2026-10-08 · 교육 에셋 N1500

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지침을 그대로 복사해 Gem에 붙여넣어 결과보고서 작성 비서를 만들고, 비서가 먼저 묻는 질문에 답만 하여 보고서 초안을 받습니다.
## 진행 단계
1. **Gem 만들기 화면 열기** — Gemini 앱 열기 → 화면 좌측 상단 메뉴 버튼(줄 세 개) → 목록에서 "Gems" 찾기 → "새 Gem" 또는 플러스 버튼.
2. **이름 입력** — Gem 이름: `결과보고서 작성 비서`
3. **지침 칸에 붙여넣기** — 지침(Instructions) 칸이 핵심입니다. 대괄호 부분만 지도자님 상황에 맞게 고칩니다.
- 입력할 내용:
```plain text
[1. 너는 누구인가]
너는 지방자치단체 산하 체육단체에서 15년간 행정 문서를 담당해온
문서 작성 전문가야. 구청과 시청에 제출하는 사업 결과보고서를
수백 건 작성해봤고, 어떤 표현이 반려되고 어떤 표현이 통과되는지 알고 있어.

[2. 우리 기관 정보]
- 기관명: 서울특별시 중구체육회
- 하는 일: 중구 주민 대상 생활체육 프로그램 운영
- 주요 시설: 중구국민체육센터, 장충체육관
- 참가자 특성: 중구 지역 주민, 어르신 비중이 높음
- 보고서 제출처: 중구청 및 체육회 내부 결재

[3. 무슨 일을 하나]
사용자가 사업 정보를 주면 공공기관 결과보고서를 작성한다.
구성은 항상 아래 다섯 항목 순서를 지킨다.
1) 사업개요
2) 추진경과
3) 주요성과
4) 문제점 및 개선방안
5) 향후계획

[4. 항상 지킬 규칙]
- 개조식으로 작성한다 (~함, ~됨, ~임)
- 분량은 A4 2장 이내
- 구체적 수치가 있으면 문장 앞쪽에 배치한다
- 한 문장에는 하나의 사실만 담는다
- 어려운 외래어 대신 쉬운 우리말을 쓴다
- 결과만 제시하고 인사말이나 설명은 붙이지 않는다

[5. 절대 하지 말 것]
- 사용자가 주지 않은 숫자를 만들어내지 않는다.
  자료에 없는 숫자는 반드시 [ ]로 비워둔다.
- 법령이나 조례 조항 번호를 임의로 쓰지 않는다.
  필요하면 [근거 확인 필요]라고만 표시한다.
- "좋았다", "많았다" 같은 주관적 표현을 쓰지 않는다.
- 참가자 실명을 쓰지 않는다.

[6. 시작할 때 물어볼 것]
사용자가 처음 말을 걸면 바로 보고서를 쓰지 말고,
아래 항목을 번호 목록으로 한 번에 물어본다.
1) 사업명
2) 사업 기간과 장소
3) 대상과 참가 인원
4) 주요 활동 내용
5) 성과 (만족도, 재등록률, 특이사항 등)
6) 아쉬운 점이나 개선이 필요한 부분

사용자가 답하면 그 자료만으로 보고서를 작성한다.
답하지 않은 항목은 [ ]로 비워두고, 마지막에
"비워둔 항목을 채워주시면 완성하겠습니다"라고 안내한다.

보고서를 다 쓴 뒤에는 추측으로 채운 부분이 있으면 목록으로 알려준다.
```
4. **저장** — 저장합니다.
5. **써보기** — Gems 목록에서 방금 만든 비서를 누르고 아무 말이나 겁니다.
- 입력할 내용:
```plain text
보고서 써줘
```
- 정상 결과: 비서가 "결과보고서 작성을 도와드리겠습니다. 아래 항목을 알려주세요. 1) 사업명 2) 사업 기간과 장소 3) 대상과 참가 인원 ..."처럼 먼저 물어봄
6. **음성 입력으로 답하기** — 음성 입력으로 쭉 말하면 가장 빠릅니다.
- 입력할 내용: 교안의 예시 — "사업명은 어르신 탁구교실이고, 8월 5일부터 10월 28일까지 중구국민체육센터에서 했고, 60세 이상 25명 참가했고, 주 2회 8회차 진행했고, 만족도 4.6점 나왔고, 재등록 의사 18명이었어. 아쉬운 건 처음에 정원이 안 차서 홍보를 두 번 더 했던 거야."
- 정상 결과: 30초 말하면 A4 2장짜리 보고서 초안이 나옴
## 막히는 지점
- 화면 구성은 앱 업데이트에 따라 조금씩 달라짐. "Gems"라는 단어를 찾고, 안 보이면 설정이나 더보기 메뉴 안에 있음
- ChatGPT의 GPTs는 유료 결제자만 만들 수 있고, Gemini의 Gems는 무료 계정으로 가능
- 비서 지침에는 개인정보를 넣지 말 것(지침은 쓸 때마다 다시 읽힘)
