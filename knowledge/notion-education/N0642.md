# 실습 1. 무질서 집필 — 조율 없이 나눠 맡긴다

정리일: 2026-10-08 · 교육 에셋 N0642

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
회의방에 집필 모드를 추가하고, 집필 에이전트 셋에게 지시 없이 세 장을 나눠 맡긴 뒤 결과물의 어긋남을 직접 수집합니다.
## 진행 단계
1. **주제 고르기** — 첫 유럽 여행 가이드북 / 사회초년생 첫 재테크 가이드 / 재난 생존 가이드 중 하나의 주제 블록을 골라 프롬프트의 \[주제 블록\] 자리에 붙입니다. 작업 전 터미널 A의 Claude Code에서 `/clear`를 실행합니다.
- 입력할 내용(Claude Code 프롬프트 요약):
```javascript
회의방 페이지에 집필 모드를 추가해 주세요.
1. /meeting 페이지에 [집필 모드] 탭을 추가 (기존 회의 기능은 그대로)
2. 가이드북: [주제 블록]
3. [무질서 집필 시작] 버튼 -> 집필 에이전트 셋(gemini-2.5-flash-lite)이 각자 한 장씩 독립 호출로 작성.
   지시는 장 제목까지만, 형식·분량·용어·다른 장 정보는 주지 않음
4. 진행 상황이 채팅방 말풍선과 상태 표시(대기/집필 중/완료)로 중계
5. 완성된 세 장을 카드로 표시(장 번호, 제목, 글자 수, 누르면 전문), 실패한 장만 "실패" 표시
6. 서버 로그에 시작·완료를 한 줄씩
(이하 교안 참고)
```
1. **서버 재시작 후 \[집필 모드\] 탭 열기**
2. **\[예측\]** 세 장을 이어 읽었을 때 어떤 어색함이 생길지 예측해 적습니다.
3. **\[무질서 집필 시작\]** 클릭, 말풍선과 상태 표시로 세 명의 집필을 지켜봅니다.
4. **카드 세 장을 펼쳐 처음부터 끝까지 이어 읽기**
5. **\[확인\] 어긋난 곳 수집** — 실행은 한 번이면 충분하고, 위치(몇 장, 어느 문장)를 메모합니다.
- 같은 내용을 두 장 이상이 설명하는 곳 / 같은 대상을 장마다 다르게 부르는 곳 / 말투나 형식이 장끼리 충돌하는 곳 / (보너스) 같은 사안인데 숫자나 순서가 장마다 다른 곳
6. **옆자리와 수집 결과 비교**
## 막히는 지점
- 세 장이 너무 멀쩡하게 나온 경우: 다시 실행하지 않아도 됨, 하나만 찾아도 충분
- 일부 장만 생성 실패: 호출 오류, 터미널 B 로그를 Claude Code에 붙여넣어 해결 후 재실행
- 카드가 안 뜸: "완료된 장이 카드로 표시되는지 점검해 주세요"라고 요청
