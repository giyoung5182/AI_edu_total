# 학생 워크시트 · 브랜드 3요소 확정

정리일: 2026-10-08 · 교육 에셋 N0346

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
종이 워크시트로 팀의 상호명·슬로건·브랜드 컬러를 확정합니다. 로고 디자인은 이후 회차에서 진행합니다.
## 진행 단계
1. **공식 상호명** — 확정 상호명과 선정 이유 기재
- 3\~5음절 내외로 부르기 쉽고, 이름만 듣고 무엇을 파는지 짐작 가능하며, 다른 팀과 겹치지 않을 것
2. **슬로건** — 핵심 가치를 10글자 내외 한 문장으로 (핵심 혜택 + 약속)
- 예시: "내 맘대로 고르는 달콤함", "오늘 하루의 향을 담다"
3. **브랜드 컬러** — 메인 컬러 1개, 보조 컬러 1개의 색상명과 선택 이유 기재
- 메인은 부스 전체 인상, 보조는 강조 요소에 사용
4. **라벨 스티커 부착 위치** — 포장의 어느 부분에 붙일지와 필요 수량(목표 생산 개수 기준) 기재
