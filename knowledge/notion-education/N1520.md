# 활동 1 — 내 에이전트 만들기 (Genspark 또는 ChatGPT GPTs)

정리일: 2026-10-08 · 교육 에셋 N1520

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
세션 1에서 만든 5요소 프롬프트를 지침으로 저장해 내 AI 솔루션 1차 버전(에이전트)을 만든다.
## 진행 단계
1. **Padlet에 핵심 기능 올리기** — "내 솔루션의 핵심 기능 중 딸 하나만 남긴다면?"을 한 줄로 올린다(`세션6 · 내 에이전트`).
2. **옵션 A. Genspark** — genspark.ai 로그인 → Custom Agent / + New / Custom Agent Store 우측 상단 Create New → 한 문장으로 설명(구조 \[역할\]+\[핵심 기능\]+\[출력 형식\])하면 지침 자동 작성 → 대화로 다듬기 → 미리보기(Preview)에 샘플 1\~2건 넣고 Update로 저장. 수정은 카드 ⋯ → Configure.
3. **옵션 B. GPTs** — chatgpt.com → GPT 탐색(Explore GPTs) → 만들기(Create) → 대화로 만들기 또는 Configure(이름·설명, 지침, 대화 스타터, 지식, 기능) → 미리보기 테스트 → Create → 공개 범위 선택. 수정은 내 GPT(My GPTs) → GPT 편집(Edit GPT) → 우측 상단 Update.
- 입력할 내용:
```javascript
당신은 [직무] 전문가 AI 어시스턴트입니다.
역할: [내 솔루션 목적] 전문 분석가
입력 받을 데이터: [형식 / 주요 컴럼]
처리 방법:
1. 입력 데이터에서 [이상 항목 / 핵심 이슈]를 찾아냅니다
2. [유형 분류 기준]에 따라 분류합니다
3. 각 항목의 [우선순위/위험도]를 판단합니다
출력 형식: 분석 요약 / TOP 3 우선 처리 항목(표) / 전체 분류 결과(표) / 다음 단계 액션 아이템
규칙: 입력 데이터에 없는 정보는 절대 만들지 않는다. 불확실한 항목은 "확인 필요"로 표시한다.
```
## 막히는 지점
- "만들기"=Create New, "고치기"=카드 ⋯ → Configure, "저장"=Update처럼 기능(동사)으로 찾기
- "만들기"가 안 보이면 무료 플랜일 가능성(GPTs 제작은 Plus 이상) → Genspark로 진행
- GPT 편집 후 Update를 누르지 않으면 초안 상태
