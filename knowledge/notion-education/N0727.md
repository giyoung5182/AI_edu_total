## 4️⃣ 데이터준비 & 입력 폼 구축 : 예산·원가 데이터 기반 다지기
# 1️⃣ 왜 데이터 준비가 중요한가?
### AI 자동화의 핵심: "쓰레기가 들어가면 쓰레기가 나온다"

**GIGO (Garbage In, Garbage Out)**
아무리 뛰어난 AI라도, 입력 데이터가 엉망이면 결과도 엉망입니다.
다음시간에 진행할 MVP 프로젝트의 성패는 **데이터 준비 품질**에 달려 있습니다.

**문제 유형**

**현장 사례**

**AI 처리 시 결과**




**용어 불일치**

"집행완료" vs "기성반영" vs "지급예정" vs "완료" 혼용

AI가 같은 의미로 인식하지 못해 집행률 통계 오류




**값 누락**

집행상태 빈 칸, 공종코드·계정코드 미입력

분석 대상에서 제외되거나 오류 발생




**형식 불일치**

"2026-03-01" vs "3/1" vs "2026.03.01"

날짜로 인식하지 못해 정렬/필터 불가




**중복 데이터**

같은 현장, 같은 공종, 같은 집행 건이 두 번 입력

금액이 뻥튀기되어 잘못된 통계



**비유로 이해하기: "데이터 준비는 터파기 공사"**
건물을 짓기 전에 터파기(기초 공사)가 탄탄해야 하듯, AI 자동화 시스템도 **데이터 구조가 탄탄해야** 합니다. 터파기가 부실하면 건물이 기울듯, 데이터가 부실하면 AI 분석 결과가 틀어집니다.

```markdown
## 역할
당신은 건설 프로젝트 예산·원가 데이터 관리 전문가입니다.

## 맥락
교육기관 아파트 신축 프로젝트에서 현장별·공종별 예산 집행 현황 데이터를 체계적으로 수집하려고 합니다.
현재는 각 담당자가 자유 형식으로 기록하여 월마감 데이터 정리에 매월 1시간 이상 소요됩니다.

## 요청
AI 분석에 최적화된 예산 집행 현황 데이터 입력 템플릿을 설계해주세요.

## 출력 형식
1. 컬럼 구조 (컬럼명 / 데이터 타입 / 입력 규칙 / 예시값)
2. 각 컬럼의 드롭다운 선택지 목록
3. 데이터 유효성 검사 규칙 (잘못된 입력 방지)
4. 엑셀에서 드롭다운을 설정하는 방법 안내
```
**ChatGPT가 제시한 템플릿을 엑셀에 적용해보세요:**
1. 컬럼명 입력
2. 데이터 유효성 검사로 드롭다운 설정
3. 샘플 데이터 5행 직접 입력하여 테스트

# 3️⃣ 더미 데이터 생성 & 용어 표준화
### \[실습\] 더미 데이터 생성 (10\~20행)

**미션: 설계한 입력 템플릿에 맞는 테스트 데이터를 ChatGPT로 생성하세요.**
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 데이터 시뮬레이션 전문가입니다.

## 요청
아래 컬럼 구조에 맞는 예산 집행 현황 더미 데이터 20행을 생성해줘.

## 컬럼 구조
- 집행일자: YYYY-MM-DD (2026-03-25 ~ 2026-04-04)
- 현장명: A현장, B현장, C현장
- 공종: 토공, 골조, 마감, 기계, 전기
- 계정: 재료비, 노무비, 외주비, 장비비, 경비
- 예산금액: 백만원 단위
- 집행금액: 백만원 단위
- 집행상태: 정상, 주의, 초과
- 초과사유: (초과인 경우만) 물량증가, 단가상승, 공정변경, 기성조정
- 후속상태: 후속조치 완료, 후속조치 중, 미조치
- 작성자: 김원가, 이예산, 박집행

## 조건
- 골조 공종의 초과율을 가장 높게 설정 (약 40%)
- 토공과 전기 공종은 초과율 15~20%
- 미조치 항목이 5건 이상 포함
- 탭으로 구분하여 엑셀 붙여넣기 가능한 형태로 출력
```
**생성된 데이터를 엑셀에 붙여넣고, 입력 템플릿의 유효성 검사가 작동하는지 확인하세요.**

---
### 용어 표준화
AI가 데이터를 정확하게 처리하려면, **같은 의미의 값이 같은 용어**로 표현되어야 합니다.

**\[실습\] 용어 표준화 사전 만들기**
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 데이터 표준화 컨설턴트입니다.

## 요청
건설 프로젝트 예산 집행·원가 현황 데이터에서 자주 사용되는 용어를 표준화해줘.

## 출력 형식
표 형태로 다음 항목별 표준화 사전을 만들어줘:
1. 집행상태 (실무에서 혼용되는 표현 → 표준 용어)
2. 원가 초과 사유 유형 (분류 체계)
3. 리스크 등급 (1~5등급 정의)
4. 후속 조치 상태 (진행 단계)

## 예시
| 실무 표현 | 표준 용어 | 코드 |
| 집행완료, 기성반영, 지급완료, 예정대로 | 정상 | NORMAL |
| 초과, 오버, 예산초과, 계획대비 증가 | 초과 | OVER |
```
**만들어진 표준화 사전을 엑셀 별도 시트에 정리하고, 드롭다운 선택지에 반영하세요.**

# 4️⃣ 예외 케이스 정의 & 입력→처리→출력 흐름 설계
### 예외 케이스 정의
실제 업무 데이터에서는 예상치 못한 상황이 항상 발생합니다. 미리 정의해두면 AI가 더 정확하게 처리합니다.

**\[실습\] 예외 케이스 정의하기**
```markdown
## 역할
당신은 데이터 품질 관리 전문가입니다.

## 맥락
건설 프로젝트 예산 집행 현황 데이터를 AI로 자동 분석하는 시스템을 구축 중입니다.

## 요청
다음 상황에서 발생할 수 있는 예외 케이스와 처리 방법을 정의해줘.

## 확인할 예외 상황
1. 값 누락: 집행상태가 비어있는 경우 → 어떻게 처리?
2. 비정형 문장: 비고란에 "기성 확정 전이라 지급 보류" 같은 자유 텍스트 → 어떻게 분류?
3. 중복 입력: 같은 날, 같은 현장, 같은 공종의 집행 건이 2번 입력 → 어떻게 처리?
4. 이상값: 한 공종에서 하루에 초과 100건 → 데이터 오류인가, 실제인가?
5. 날짜 오류: 미래 날짜 입력, 주말 날짜 입력 → 어떻게 검증?

## 출력 형식
| 예외 상황 | 발생 원인 | 처리 방법 | 엑셀 구현 방법 |
```

---
### "입력 → 처리 → 출력" 흐름 시나리오 작성

**AI 자동화 시스템의 기본 구조:**
**입력(Input)** → **처리(Process)** → **출력(Output)**
이 흐름을 명확히 정의하는 것이 MVP 프로젝트의 첫걸음입니다.


**\[실습\] 입력→처리→출력 흐름 시나리오 작성**
아래 프롬프트로 본인의 업무에 맞는 자동화 흐름을 설계하세요.
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 업무 자동화 설계 전문가입니다.

## 맥락
교육기관 예산·원가 담당자가 AI를 활용한 업무 자동화 시스템을 구축하려 합니다.

## 요청
아래 업무 중 하나를 선택하여 "입력→처리→출력" 흐름 시나리오를 작성해줘.

## 업무 후보 (하나 선택)
A. 월간 예산 집행 현황 → 월간 비용·집행 보고서 자동 생성
B. 공종별 집행률 데이터 → 원가 초과 추이 분석 리포트
C. 현금 유출 예정 데이터 → 현금흐름 주의 항목 추출
D. 미청구·미수 현황 → 회수 리스크 보고서 생성

## 출력 형식
### 1. 입력 (Input)
- 데이터 형태: (엑셀/텍스트/CSV)
- 컬럼 구조: (최소 5개 컬럼)
- 데이터 양: (일/주/월 단위 예상 건수)
- 입력 주체: (누가 입력하는가)

### 2. 처리 (Process)
- AI 처리 단계: (어떤 분석/변환을 하는가)
- 사용 도구: (ChatGPT, VBA, Genspark 등)
- 핵심 로직: (요약/분류/계산/시각화 등)

### 3. 출력 (Output)
- 결과물 형태: (보고서/대시보드/알림)
- 수신 대상: (현장소장/본부장/원가관리팀)
- 활용 방법: (의사결정/후속 대책/월마감 검토)
```
**이 시나리오는 오후 5\~6차시 MVP 프로젝트의 기초가 됩니다.**
**완료된 시나리오를 패들렛에 올려주세요.**

### 제공된 실습 파일로 데이터 분석 체험

**\[실습\] ChatGPT 데이터 분석 체험**

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]

제공된 실습 파일 **「예산집행현황_데이터분석.xlsx」**를 ChatGPT에 업로드하여 분석해보세요.
**Step 1.** chatgpt.com 접속 → 입력창 **+** **아이콘** 클릭 → 파일 선택
**Step 2.** 아래 프롬프트 입력
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 데이터 분석 전문가입니다.

## 요청
업로드한 예산 집행 현황 데이터를 분석하여 다음을 제공해주세요.

## 분석 항목
1. 전체 요약 통계 (총 예산, 총 집행, 집행률, 정상/주의/초과 비율)
2. 현장별 초과율 비교 (막대 차트)
3. 공종별 초과 빈도 (파이 차트)
4. 가장 초과가 많은 현장과 공종 식별
5. 다음 월마감 회의 시 집중해야 할 비용 리스크 3가지 추천
```
**Step 3.** 결과에서 차트와 인사이트를 확인하세요.
**핵심 교훈:** 입력 데이터의 구조가 깔끔할수록 AI 분석 결과도 정확합니다. 이것이 바로 데이터 준비가 중요한 이유입니다.

### 📌 핵심 정리
```markdown
✅ 1. GIGO: 쓰레기 데이터 → 쓰레기 결과. 데이터 준비가 AI 활용의 기초
✅ 2. 입력 템플릿: 1행=헤더, 1셀=1정보, 선택형 값, 날짜 형식 통일
✅ 3. 더미 데이터: ChatGPT로 테스트용 샘플 데이터를 빠르게 생성

✅ 5. 예외 케이스: 값 누락, 중복, 이상값 등을 미리 정의하여 오류 방지
✅ 6. 입력→처리→출력: AI 자동화의 기본 구조. MVP 프로젝트의 설계 시작점
```
