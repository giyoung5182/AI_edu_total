# 2-2. 첫 대화 실습 — 3단계

정리일: 2026-10-08 · 교육 에셋 N0400

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
ChatGPT에 접속해 세 번의 대화로 AI와 이어서 대화하고 수정을 요청해 보는 첫 실습입니다.
## 진행 단계
1. **ChatGPT 첫 접속** — 스마트폰은 앱스토어/플레이스토어에서 "ChatGPT" 검색 후 설치, "Sign up" → "Continue with Google"로 가입합니다. 컴퓨터는 크롬에서 chatgpt.com 접속 후 "Sign up" → 구글 계정으로 가입합니다.
- 정상 결과: 채팅 입력창이 보임(무료 버전으로 충분)
2. **Step 1. 가볍게 시작하기**
- 입력할 내용:
```plain text
안녕하세요. 저는 소상공인 사장님입니다.
오늘 처음으로 AI를 써보려고 합니다.
제가 어떤 일에 AI를 써볼 수 있는지 3가지만 알려주세요.
```
3. **Step 2. 이어서 대화하기 — 내 상황 넣기**
- 입력할 내용:
```plain text
저는 은평구에서 순대국집을 운영합니다.
그 중에서 저한테 가장 유용할 것 같은 것 하나만
더 구체적으로 설명해줘.
```
4. **Step 3. 마음에 안 들면 수정 요청하기**
- 입력할 내용:
```plain text
너무 어렵게 썼어. 더 쉬운 말로 다시 써줘.
```
또는
```plain text
더 짧게, 핵심만 3줄로 줄여줘.
```
- 정상 결과: 3\~4번 대화를 이어가면 처음보다 훨씬 좋은 결과물이 나옴
