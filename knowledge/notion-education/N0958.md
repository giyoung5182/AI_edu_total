> **학습 목표**
1. Copilot에게 맡길 작업과 반드시 직접 확인해야 할 작업을 구분할 수 있다.
2. 분석을 시작하기 전에 데이터 구조와 품질을 점검할 수 있다.
3. 분석 설계에서 결론을 왜곡하는 요인을 미리 찾아낼 수 있다.
> ⚠️ **보안 주의**
실습에는 이 교안의 **가상 데이터만** 사용합니다. 실제 지점 실적, 인사 정보, 고객 정보는 입력하지 않습니다.
**파일 업로드가 막혀 있어도 복사·붙여넣기는 막히지 않습니다.** 무엇을 입력할지는 결국 사람이 판단해야 합니다.

## 1️⃣ 오늘 답할 질문
이번 교육은 실제 부서에서 나온 질문 하나를 끝까지 따라갑니다.
> **지점장 속성(나이·성별·직전보직 등)에 따라 점포 변경 시 성과가 어떻게 달라지는가**
더 구체적으로 — 남자 지점장 뒤에 여자 지점장이 부임했을 때 성과가 얼마나 개선되었는가
이 질문은 **실무에서 실제로 자주 요청되는 형태**입니다.
그리고 동시에 **가장 잘못 분석되기 쉬운 형태**이기도 합니다.
오늘 이 질문에 대해 두 가지 답을 만들게 됩니다.
```plain text
1차 답변  →  숫자만 보고 낸 결론
2차 답변  →  그 숫자가 왜 그렇게 나왔는지 파고든 결론

두 답이 정반대입니다.
```
**둘 다 만들어보는 것이 오늘의 핵심입니다.** <br>1차만 만들고 보고하면 어떤 일이 생기는지 직접 겪어보시게 됩니다.

> ⚠️ **오늘 세울 두 가지 원칙**
**원칙 1 — 계산은 맡기지 않습니다.**<br>Copilot은 언어 모델입니다. 표를 만드는 능력은 뛰어나지만, 수십 개 숫자를 더하고 비율을 내는 작업에서 **틀린 값을 자신 있게 내놓습니다.** 더 위험한 건 표만 봐서는 틀린 걸 알 수 없다는 점입니다.
**원칙 2 — 원인은 맡기지 않습니다.**<br>데이터에는 원인이 없습니다. 숫자의 차이만 있을 뿐입니다. 그런데 Copilot에게 물으면 그럴듯한 원인을 만들어냅니다. 이게 보고서에 들어가면 **사실이 아닌 내용을 임원에게 보고하는 것**이 됩니다.

### 🖥️ 실습 1 — 자연어로 계산시키고, 검증까지 (8분)
**Excel을 열지 않고도 계산이 됩니다.** 먼저 되는 걸 확인해보겠습니다.
---
**1단계. Copilot 열기**
```plain text
Excel 홈 탭 → Copilot 클릭
```
**2단계. 자연어로 요청 (2분)**
[원본 이미지 제외]
아래를 입력창에 붙여넣고 Enter를 누릅니다.
```plain text
아래 수치의 합계와 평균을 계산해줘.
그리고 각 항목이 전체에서 차지하는 비율을
소수점 둘째 자리까지 알려줘.

서울01지점 1,247
경기03지점 892
인천05지점 1,563
부산07지점 734
대구09지점 2,108
대전11지점 445
광주13지점 1,092
```
> 💡 **붙여넣기가 안 되면**
```plain text
방법 1: 메모장에 붙여넣기 → 다시 복사 → Copilot에 붙여넣기
방법 2: 입력창에서 Ctrl + Shift + V
```
**결과 예시**
```plain text
합계    8,081
평균    1,154.43

지점        수치     비율
서울01지점  1,247   15.43%
경기03지점    892   11.04%
인천05지점  1,563   19.34%
부산07지점    734    9.08%
대구09지점  2,108   26.09%
대전11지점    445    5.51%
광주13지점  1,092   13.51%
합계        8,081  100.00%
```
**셀에 수식을 하나도 안 쓰고 표가 나왔습니다.** 비율 총합도 100%로 맞습니다.
> 💡 **이게 Copilot의 기본 효용입니다**
메모나 메일에 흩어진 숫자를 그대로 붙여넣으면 정리된 표가 나옵니다. 데이터가 Excel에 없어도 됩니다.
회의 중에 받은 숫자, 카톡으로 온 실적, 메일에 적힌 수치 — 전부 이렇게 처리할 수 있습니다.
---
**3단계. 시트로 옮기기 (1분)**
답변 아래에 **\[새 시트에 추가\]** 버튼이 있습니다. 클릭하십시오.
```plain text
① [새 시트에 추가] 클릭
② 새 시트가 생기면서 표가 들어감
③ 시트 이름을 "실습1"로 변경
```
> ⚠️ **버튼이 안 보이면**
답변 영역을 마우스로 훑어보십시오. 답변 형태에 따라 버튼 위치가 달라집니다.
없으면 표를 드래그로 선택해 복사한 뒤 새 시트에 붙여넣으셔도 됩니다.
---
**4단계. 검산 (2분)**
**여기가 오늘 실습의 핵심입니다.**
시트로 옮겨졌으니 이제 확인할 수 있습니다. 빈 셀에 아래를 입력하십시오.
```plain text
=SUM(수치가 있는 범위)
```
예를 들어 수치가 B2:B8에 있다면
[원본 이미지 제외]
```plain text
=SUM(B2:B8)
```
```plain text
□ 8,081이 나오는가?
□ Copilot이 말한 값과 같은가?
```
평균도 확인합니다.
```plain text
=AVERAGE(B2:B8)   → 1154.428571...
```
> 💡 **1분 걸립니다. 그런데 이 1분이 핵심입니다**
방금 확인하신 게 뭘까요. **"AI가 맞았다"가 아니라 "내가 확인할 수 있었다"** 입니다.
그리고 확인할 수 있었던 이유는 **결과가 시트에 있었기 때문**입니다.
---
### 그럼 계산은 어떻게 하나
숫자를 계산시키지 말고 **수식을 받으십시오.**
```plain text
이 데이터를 Excel A2:B8에 붙였을 때
합계와 각 항목 비율을 구하는 수식을 알려줘.
각 인수의 의미도 설명해줘.
```
**수식은 Excel이 계산하므로 틀릴 일이 없습니다.**
> 💡 **계산 결과가 아니라 계산할 자리를 받으십시오**
이 한 문장이 오늘 교육의 절반입니다. 원본 데이터가 바뀌어도 자동으로 갱신된다는 이점까지 따라옵니다.

### 🖥️ 실습 2 — 데이터 파악과 품질 점검 (13분)
**1단계. 눈으로 먼저 훑기 (2분)**
```plain text
① 하단 시트 탭을 하나씩 클릭
② 각 시트의 1행(머리글)을 읽기
③ Ctrl + End 를 눌러 데이터 끝까지 이동
   → 행 번호로 대략적인 행 수 확인
④ Ctrl + Home 으로 다시 위로
```
```plain text
지점마스터        45개 지점의 지역·규모 정보
지점장발령이력    140건의 부임·이임 이력과 지점장 속성
월별성과          지점별 월별 실적 (2023.01 ~ 2026.06)
```
> 💡 **Ctrl + End 는 실무에서 자주 씁니다**
데이터가 어디까지 있는지 3초에 확인됩니다. 스크롤로 내리지 마십시오.
---
**2단계. 구조와 품질을 한 번에 물어보기 (5분)**
```plain text
이 파일의 구조와 데이터 품질을 점검해줘.

[구조]
각 시트의 행 수, 열 구성, 시트 간 연결 열

[품질 점검]
- 값이 비어 있는 열과 그 건수
- 같은 항목인데 표기가 다른 경우 (예: 2024-05 / 2024.05)
- 다른 값들과 자릿수가 크게 다른 값
- 특정 지점의 특정 기간이 통째로 빠져 있는지

[출력]
구조는 표로, 품질은 각 항목을 ✅ / ⚠️ / ❌ 로 표시
문제가 있으면 어느 시트 어느 행인지 명시

계산하지 마. 시트도 수정하지 마. 점검 결과만 알려줘.
```

> 💡 **"계산하지 마, 수정하지 마"가 핵심입니다**

이때 파일을 첨부하는 게 아니라, **모드를 바꿔야 합니다.**

### 모드 바꾸는 법
```plain text
① Copilot 창 상단의 모드 표시 클릭
② [편집] 선택
③ 같은 프롬프트를 다시 입력
```
이제 열려 있는 시트를 직접 읽습니다. 첨부가 필요 없습니다.
```plain text
□ 모드를 [편집]으로 바꿨다
□ "이 파일의 구조를 알려줘"에 시트 정보가 나온다
```

### 그럼 시트가 바뀌는 건 어떻게 막나
**편집 모드는 시트를 바꿀 수 있습니다.** 그런데 시트를 읽으려면 편집 모드여야 합니다.
그래서 **안전장치를 따로 걸어야 합니다.**
#### 안전장치 1 — 원본 시트를 복사해두십시오
**이게 가장 확실합니다.** 시작 전에 30초만 투자하십시오.
```plain text
① 시트 탭에서 마우스 오른쪽 클릭
② [이동/복사] 선택
③ "복사본 만들기" 체크   ← 반드시
④ [확인]
⑤ "지점마스터 (2)" 같은 시트가 생김
⑥ 시트 탭 더블클릭 → 이름을 "원본_백업"으로 변경
```
문제가 생겨도 여기서 다시 시작하면 됩니다.
#### 안전장치 2 — 프롬프트에 못박으십시오
```plain text
시트는 수정하지 마. 분석 결과만 알려줘.
```
편집 모드에서도 이 문구가 있으면 Copilot이 대체로 읽기만 합니다.
> ⚠️ **다만 보장은 되지 않습니다**
프롬프트는 **부탁**이지 **차단**이 아닙니다. Copilot이 판단을 달리하면 시트를 건드릴 수 있습니다.
**원본 복사가 유일한 확실한 방법입니다.** 프롬프트 문구는 보조 장치로만 생각하십시오.
#### 안전장치 3 — 중지 버튼 위치를 익혀두십시오
```plain text
입력창 오른쪽 아래 모서리
```
시트가 이상하게 바뀌고 있으면 **끝까지 기다리지 말고 즉시 멈추십시오.**

### 자릿수 오류인지 확인하는 법
`신계약건수`에 180건, 190건, 210건처럼 큰 값이 나왔을 겁니다.
**숫자가 크다는 것만으로는 오류라고 못 합니다.** 이렇게 확인하십시오.
```plain text
그 행들의 신계약보험료도 함께 보여줘.
건수와 보험료가 비례하는지 확인하고 싶어.
```
**결과를 보면 판단이 됩니다.**
```plain text
180건인데 보험료가 998만원  →  건당 5만원
정상이라면 건당 40~60만원

→ 건수만 자릿수가 틀린 입력 오류
```
> 💡 **판단 근거는 "연관된 값과 함께 안 움직인다"입니다**


> 💡 **구간 설정에 정답은 없습니다**

```plain text
[설계]
- 성과 지표: 신계약건수
- 비교 전: 전임 지점장 마지막 6개월 평균
```

## 6️⃣ 1권 정리
```plain text
데이터를 받으면
     ↓
구조부터 파악한다 (계산 안 함, 수정 안 함)
     ↓

     ↓

     ↓

     ↓
```
