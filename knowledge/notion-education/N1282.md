# 실습 3 | 카드뉴스 5장 완성본 만들기 (30분)

## 이 실습으로 하는 것
Gems와 대화로 카드뉴스 기획을 확정하고, 경로 A 또는 B로 5장 완성본을 만든다.
## 진행 단계
1. **사전 확인** — 카드뉴스 기획 Gems v4 등록 완료 / ChatGPT 로그인 / Canva 로그인(경로 A 선택 시)
2. **STEP 1 Gems와 대화로 기획 확정 (5분)** — Gems 열기 → "카드뉴스 만들고 싶어" 입력 → Gems가 묻는 3가지(제품·목적·이미지 타입)에 답변 → 추가 질문에 답하고 구성 확정 → 기획 출력 + 두 가지 경로 제공
3. **STEP 2 경로 선택 및 실행 (20분)**
- 경로 A: Gems의 장별 배경 이미지 프롬프트를 ChatGPT에 붙여넣기 → 저장 → Canva에서 텍스트 추가(각 장 3–4분)
- 경로 B: Gems의 완성본 요청 프롬프트 전체를 ChatGPT에 붙여넣기 → 결과 확인
4. **STEP 3 수정 및 완성 (5분)** — 수정이 필요한 부분을 Gems에 입력 → 수정 프롬프트 생성 → ChatGPT에 붙여넣기 → 재확인
- 정상 결과(완성 체크): 텍스트가 이미지 위에 명확하게 보이는가 / 화장품법 위반 표현이 없는가 / 5장 CTA에 댓글 키워드가 있는가 / "이번 주 바로 올릴 수 있다" 확인
5. **STEP 4 다운로드 및 저장 (2분)** — 경로 A: Canva → 공유 → 다운로드 → PNG → 전체 페이지 / 경로 B: ChatGPT 이미지 우클릭 → 이미지 저장(장별로). 파일명: \[제품명\]_카드뉴스_날짜
## 막히는 지점
- Gems가 바로 기획 출력함: 시스템 프롬프트 미반영 → Gems v4 프롬프트 재등록 확인
- 경로 B에서 텍스트가 안 나옴: 합성 명시 누락 → Gems 수정 프롬프트 재요청
- 텍스트가 배경에 묻혀서 안 보임: 대비 부족 → Gems에 "텍스트 대비 강하게 수정해줘"
- 배경에 영문 텍스트가 같이 나옴: 금지 명령 미포함 → Gems에 "배경 텍스트 제거해줘"
- 5장 분위기가 각각 다름: 따로따로 생성 → 경로 A에서 1장 기준 연속 생성 요청
- Canva 폰트가 없음: 유료 계정 폰트 → Noto Sans KR, Nanum Gothic은 무료
