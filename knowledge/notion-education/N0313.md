# 실습 4. 데이터 사전 — 열의 뜻부터 정하기

정리일: 2026-10-08 · 교육 에셋 N0313

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
두 시트의 열마다 뜻·단위·빈칸 의미를 정리하고, 파일에 근거가 없는 정의는 "확인 필요"로 남겨 담당자 질문 목록으로 만든다. (교안상 '향후 과제' 토글)
## 진행 단계
1. **데이터 사전 초안 요청** — 업무시간실태조사·출장정산내역 시트의 대상 열에 대해 코드로 값 분포를 먼저 확인한 뒤 작성하게 한다
- 입력할 내용: 첨부 파일의 두 시트에 대해 데이터 사전 초안을 만들어라. 코드로 각 열의 실제 값 분포를 먼저 확인한 뒤 작성한다. 출력 표: 시트 \| 열 이름 \| 뜻(정의) \| 단위/형식 \| 실제 값 범위·종류 \| 빈칸 수 \| 정의의 근거 \| 상태. 파일 근거가 없는 정의는 추측하지 말고 상태를 "확인 필요"로 적는다 (이하 교안 참고)
2. **P3-4에 옮겨 적기** — 답변 아래 복사 아이콘 → 워크시트 P3-4 표 첫 칸 → Ctrl+V (한 칸에 몰리면 손으로 옮겨 적음)
3. **필수 9항목 체크** — 정산번호 고유성·숙박비_박당·일비_1일·출장지→지역·승인상태·출발일/복귀일·영수증첨부·시간 열 단위·점수 열 척도가 사전에 있는지 O/X 표시, X는 추가 요청
4. **담당자 확인 질문 목록** — "확인 필요" 항목을 질문 문장으로 작성 (예: 승인상태 '정상'은 규정 검토 완료를 의미합니까?)
- 정상 결과: 파일 근거 있는 줄은 "정의의 근거" 칸에 열 이름·값 분포·비고 문구가 적혀 있음
## 막히는 지점
- 모든 줄이 "파일로 확인" → 근거를 파일에서 인용하게 하고 인용 못 하면 확인 필요로 바꾸도록 재요청
- 지역 구분은 파일에 열로 없음 → 확인 필요로 변경
- 영수증첨부의 "미첨부"와 빈칸을 따로 세도록 요청
