# 이미지 A. 모델 중심 광고 시안

정리일: 2026-10-08 · 교육 에셋 N1261

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프리미엄 숏패딩 런칭 캠페인용으로 모델이 보이는 광고 시안(이미지 A)을 Gemini로 만듭니다.
## 진행 단계
1. **스타일 선택** — Gemini에서 이미지에 어울리는 스타일을 화면에서 직접 선택 (같은 프롬프트라도 스타일에 따라 분위기가 달라짐)
2. **프롬프트 입력**
- 입력할 내용:
```javascript
[무엇을 만들지] 프리미엄 숏패딩 런칭 캠페인용 광고 이미지
[분위기/톤] 고급스럽고 절제된 분위기, 따뜻한 조명
[배경/환경] 겨울 도시 야경
[구도/촬영 방식] 20대 후반~30대 초반 모델 1명이 보이는 인스타그램 피드 광고형 구도
[용도] 프리미엄 숏패딩 런칭 캠페인용 메인 비주얼

- 패딩 색상은 블랙 또는 다크네이비
- 문구가 들어갈 여백 확보
- 과장된 로고 없음
```
