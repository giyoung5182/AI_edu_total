# 실습 — 회사 소개서 설계서 (25분)

정리일: 2026-10-08 · 교육 에셋 N0353

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
용역 실적 데이터를 정리한 뒤 설계서 4블록으로 발표자료 설계서를 만들고, 사람이 세 항목을 검토해 저장합니다.
## 진행 단계
1. **1단계 실적 데이터 정리 (7분)** — 첨부한 용역 실적 CSV를 AI에게 정리시킴
- 입력할 내용: 교안의 1단계 프롬프트(관할본부 표기 통일, 금액 백만원 환산, 연도별·사업부문별 집계, 재계약률 계산, 반복 현장의 연속 수행 기간 계산, 애매한 행은 \[확인 필요\] 표시, 제공하지 않은 실적 추가 금지)
- 정상 결과: 환산한 행 목록과 집계 표, \[확인 필요\] 표시
2. **2단계 설계서 초안 생성 (8분)** — 블록 1\~4(맥락 / 슬라이드 설계도 / 디자인 규격 / 산출 규칙)와 작업 순서를 담은 프롬프트에 CSV를 올려 설계서 초안을 받음
- 입력할 내용: 교안의 2단계 설계서 프롬프트(앞부분 발췌, 이하 교안 참고)
```javascript
[블록 1. 맥락] 개요 / 유의사항 / 최종 목적 / 전체 흐름(10장)
[블록 2. 슬라이드 설계도] 장마다 분류·헤드메시지·내용 설명·시각 요소
[블록 3. 디자인 규격] 색상 코드, 글꼴, 글자 크기, 16:9, 레이아웃 규칙
[블록 4. 산출 규칙] 말투, 사실 관계, 구성, 재량
(이하 교안 참고)
```
3. **3단계 세 항목 검토 (7분)** — 유의사항, 헤드메시지(순서대로 읽어 논리가 이어지는지), \[확인 필요\] 표시를 사람이 검토
4. **4단계 초안 제작 (1분)**
5. **5단계 저장 (2분)** — 설계서를 파일로 저장
- 정상 결과(완료 기준): 네 블록이 모두 채워짐 / 유의사항 3개 이상 / 모든 헤드메시지가 결론 문장 / 금액 단위가 백만원으로 통일되고 환산 내역 보고 / 자료에 없던 실적이 새로 생기지 않음
## 막히는 지점
- 금액 단위가 백만원·억·원으로 섞여 있어 환산 지시가 없으면 잘못 합산됨
- AI가 없는 실적 수치를 만들어 넣을 수 있음: 자료에 없는 수치는 \[확인 필요\]로 표시하게 함
