## 이 실습으로 하는 것
5차시 기획안을 Genspark AI Developer에 옮겨 입력/처리/출력 구조로 정리하고 구현 방향을 확정합니다.
## 진행 단계
1. **접속** — genspark.ai 접속 후 로그인
2. **기획안 준비** — 문제 정의 / 입력 데이터 3종 / 출력 형태 / 성공 기준
3. **구조 설계 프롬프트 입력**
- 입력할 내용(요약): 역할(예산·원가 업무 자동화 시스템 기획자) / 맥락(문제 정의·입력 데이터 3종·출력물은 5차시 확정 내용) / 요청(입력/처리/출력 구조 정리) / 출력 형식(1. 입력: 수집 방법·필수 필드, 2. 처리: 분석 단계·핵심 판단 기준, 3. 출력: 결과물 형태·자동 생성 항목) (이하 교안 참고)
4. **비교·확정** — 결과를 본인 기획안과 비교하고 구현 방향을 확정
