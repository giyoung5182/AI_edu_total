> ⚠️ 이 문서는 **Windows(윈도우) 기준**으로 작성되었습니다.
## ✅ 설치 순서 한눈에 보기
총 **5가지**를 순서대로 설치하면 됩니다.
1. Python (파이썬) — 코드 실행의 기반
2. Git + Git Bash — 파일 버전 관리 도구
3. GitHub CLI — AI 에이전트와 GitHub 연결
4. 코드 에디터 — 코드를 작성하는 편집기
5. Node.js — npm 명령어 실행 환경
6. Claude Code — AI 코딩 에이전트

## 2단계. Git 설치
Git은 코드 파일을 관리하는 도구입니다. 설치하면 **Git Bash**(터미널처럼 사용하는 프로그램)도 함께 설치됩니다.
👉 Git 다운로드 바로가기
> 💡 설치 중 옵션이 많아 복잡해 보일 수 있는데, 기본값 그대로 "Next"를 눌러 설치해도 됩니다.
---
## 3단계. GitHub CLI 설치
GitHub CLI를 설치하면 Claude Code 같은 AI 에이전트가 GitHub와 연동해서 작업할 수 있습니다.
**설치 방법:**
1. **터미널을 엽니다** — 시작 메뉴에서 `cmd` 또는 `Git Bash`를 검색해 실행하세요.
2. 아래 명령어를 **순서대로** 복사해서 붙여넣고 Enter를 누르세요.
```bash
# 1. GitHub CLI 설치
winget install --id GitHub.cli

# 2. GitHub 계정 인증
gh auth login
```
> 💡 `gh auth login` 실행 후 안내 메시지가 나타나면, 방향키로 선택하고 Enter를 누르세요. 최종적으로 브라우저에서 GitHub 로그인을 완료하면 됩니다.
---
## 4단계. 코드 에디터 설치
코드를 작성하고 실행하는 편집기입니다. **둘 중 하나만 선택**해서 설치하세요.
### VSCode 설치
**VSCode**: code.visualstudio.com
VSCode는 편집기 안에서 터미널을 바로 열 수 있어, Claude Code를 에디터를 떠나지 않고 바로 실행할 수 있습니다. 상단 메뉴 **Terminal → New Terminal** 또는 단축키 **Ctrl + \`** 를 누르면 터미널이 열리고, `claude`를 입력하면 Claude Code를 바로 실행할 수 있습니다.
### VSCode 확장 프로그램
왼쪽 사이드바의 블록 모양 아이콘(Extensions)을 클릭하고 이름을 검색해 설치하면 됩니다.
**필수 확장 프로그램**
- **Python** — 설치 링크
- **Jupyter** — 설치 링크
**추천 확장 프로그램**
- **Office Viewer** (엑셀·워드 파일을 편집기에서 바로 열기) — 설치 링크
- **vscode-pdf** (PDF 파일 미리보기) — 설치 링크

## 6단계. Claude Code 설치
> ⚠️ **Claude Pro 이상 구독**이 필요합니다.
Claude Code는 AI가 직접 코드를 작성하고 실행해주는 도구입니다.
📖 Claude Code 공식 설치 문서
### 옵션 A. Claude Desktop 앱으로 사용
👉 Claude Desktop 다운로드
Claude 데스크톱 앱을 설치하면 별도 설정 없이 Claude Code 기능을 바로 사용할 수 있습니다.
### 옵션 B. 터미널에서 직접 설치
1. 터미널(cmd, Git Bash 등)을 엽니다.
2. 아래 명령어를 입력하고 Enter를 누릅니다.
```bash
npm install -g @anthropic-ai/claude-code
```
1. 설치가 완료되면, 터미널에 `claude`를 입력해 실행할 수 있습니다.
**🔧 권한 자동 허용 설정 (선택사항)**
Claude Code를 실행할 때마다 권한을 묻는 창이 번거롭다면, Claude에게 아래 내용을 그대로 입력하세요.
```bash
클로드 코드 실행할 때마다 권한 무조건 허용으로 설정되게끔
settings.json에 설정해줘
```
