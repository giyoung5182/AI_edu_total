# 실습 A-1 | 공문 RCTCK 프롬프트 직접 작성하기

정리일: 2026-10-08 · 교육 에셋 N0406

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
기업지원부 담당자 상황에서 글로벌강소기업 육성사업 참가기업 모집 공문을 RCTCK 5요소로 직접 작성하고, 강사 표준 작성본과 비교합니다.
## 진행 단계
1. **빈칸 워크시트 작성** — R(역할)·C(맥락)·T(과업)·C(제약)·K(Golden Sample) 빈칸을 혼자 또는 옆 사람과 함께 채움
2. **표준 작성본과 비교** — 강사가 공개하는 표준 작성본과 비교
- 입력할 내용(표준 작성본 요약):
```javascript
R: 너는 교육기관 33 기업지원부 공문 작성 담당자야. 기업 지원사업 안내 공문을 수백 건 작성한 경험이 있어. 충청북도 공공기관 공문 표준 양식을 완벽하게 숙지하고 있고, 항상 공식적이되 수신 기업이 이해하기 쉬운 어조로 작성해.
C: 충북 지역 수출 유망 중소기업에게 보내는 '2026년 글로벌강소기업 육성사업' 참가기업 모집 공문을 작성해야 해. 공문은 우편 발송과 이메일 동시 발송 예정이야.
T: 아래 내용을 포함한 안내 공문을 작성해줘: 1. 공문 기본 형식 2. 사업 개요 3. 세부 지원 내용 표 4. 신청 대상 및 자격 요건 5. 신청 방법 및 접수처 6. 문의처
C: 충청북도 공공기관 공문 표준 양식 준수. A4 1장 이내. 내가 제공하지 않은 항목은 [미기재 - 담당자 입력 필요]로 표시. 확인 불가한 수치는 임의로 작성 금지.
K: 아래는 충청북도가 실제 발행한 지역산업맞춤형 일자리지원 사업 공고문이야. 이 문체와 구성 방식 그대로 작성해줘. [공고문 전문 붙여넣기]
```
3. **비교 체크리스트** — R(기관·부서·경력·어조), C(수신 대상·발송 방식), T(번호 분해·표 형식), C(분량·\[미기재\]·임의 작성 금지), K(문서 유형·"이 문체와 구성 방식 그대로") 항목 점검
4. **공문 검증 체크리스트** — 공고번호·수신·발신·제목 형식, 날짜·신청기간, 수치 일치, 문의처 최신 여부, \[미기재\] 표시, Golden Sample에 없던 내용의 임의 추가 여부, 민감 정보 마스킹
## 막히는 지점
- K는 같은 유형끼리 매칭하고 민감 정보를 마스킹하며 A4 1\~2장 분량을 유지할 것
- 공고문을 기관 공문으로 변환할 때 발행 기관·접수 방법·공고 번호 등은 수동 확인 필요
