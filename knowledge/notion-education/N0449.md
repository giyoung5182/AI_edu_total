# 실습 : 내 컴퓨터 파일 정리하기

정리일: 2026-10-08 · 교육 에셋 N0449

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AI 에디터에 프롬프트만 입력해 한 폴더에 섞인 파일을 확장자 기준으로 자동 분류합니다.
## 진행 단계
1. **ChatGPT 데스크톱 앱 다운로드** — 데스크톱 앱을 내려받습니다.
2. **실습파일 준비** — 실습파일 zip의 대상 폴더 `확장자별+파일+예제`를 준비합니다. 현재 PDF, XLSX, PNG, PPTX 파일이 한 폴더에 섞여 있습니다.
3. **예시 프롬프트 입력** — Codex(Antigravity)에서 프롬프트만으로 폴더를 정리합니다.
- 입력할 내용:
```javascript
확장자별 파일 예제 폴더의 파일을 확장자 기준으로 정리해줘.
1) 해당 폴더에 하위 폴더(PDFs, Excels, Images, PPTs)를 만들어줘.
2) .pdf는 PDFs, .xlsx는 Excels, .png는 Images, .pptx는 PPTs로 이동해줘.
3) 기존 파일명은 변경하지 말고, 이동 내역을 마지막에 요약해줘.
```
- 정상 결과: 목표 상태 — `PDFs`, `Excels`, `Images`, `PPTs` 4개 폴더로 자동 정리됨
