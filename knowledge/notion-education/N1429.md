# 2. Visual Studio Code 설치 (Office Viewer·Python·Korean 확장)

정리일: 2026-10-08 · 교육 에셋 N1429

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
코드 편집기 Visual Studio Code를 설치하고 확장 기능을 추가합니다.
## 진행 단계
1. **설치 파일 실행** — 자신의 OS에 맞는 설치 파일을 다운로드하고 실행합니다.
2. **동의 후 다음.**
3. **추가 작업 모두 체크 후 다음** — 바탕 화면 바로가기 / "Code(으)로 열기"를 파일·디렉터리 메뉴에 추가 / 지원 파일 형식 편집기로 등록 / PATH에 추가.
4. **설치** — 완료까지 기다린 뒤 "Visual Studio Code 실행"을 체크한 상태로 종료.
5. **테마 색상 선택** 후 모두 다음.
6. **확장 설치** — 확장 아이콘 클릭 → 검색창에 "office viewer" / "python" / "korean" 검색 후 설치.
