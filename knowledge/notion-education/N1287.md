# Claude in Excel 실습 1 — 다중 시트 통합 + 형식 통일

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
여러 월별 시트를 자연어 지시만으로 하나의 '1분기' 시트로 통합하고 형식을 통일합니다.
## 진행 단계
1. **상황 확인** — 1·2·3월 실적이 별도 시트에 있고 2월 시트만 헤더가 영문.
2. **Claude에 요청**
- 입력할 내용:
```javascript
1월, 2월, 3월 시트를 하나의 '1분기' 시트로 통합해줘.
헤더를 한글로 통일하고, 날짜 형식은 YYYY-MM-DD로 변경해줘.
시트 이름도 '1분기'로 바꿔줘.
```
3. **결과 확인** — 2월 시트의 'Date'→'날짜', 'Amount'→'금액' 자동 통일, 완료 후 변경 사항 요약 보고.
## 막히는 지점
- AI가 직접 시트를 수정하므로 중요 파일은 백업 후 작업(Ctrl+Z로 실행 취소 가능).
