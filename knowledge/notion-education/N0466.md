# 실습 2. 작업 명세를 AGENTS.md로 저장 — 동일 사건 기준 스스로 정하기

정리일: 2026-10-08 · 교육 에셋 N0466

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
회차마다 같은 사건의 기준이 달라지지 않도록, 사람이 정한 기준을 AGENTS.md에 고정한다.
## 진행 단계
1. **틀 붙여넣기** — 목적 / 입력 파일 / 출력 파일과 형식 / 처리 규칙 / 금지 / 끝나면 확인할 것 6칸 구성의 AGENTS.md 틀을 메모장에 붙여넣음(이하 교안 참고)
2. **4번 ② 채우기** — 고객사·시기·현상·가리키는 표현·유형 중 무엇이 맞아야 같은 사건인지 골라 매핑 성공 / 확인 필요 / 연결 안 함 기준을 문장으로
3. **4번 ⑦ 채우기** — 메일 번호가 비었을 때, 앞 메일을 가리키는데 원문이 없을 때 처리 방법 1줄 이상
4. **저장** — 파일 → 다른 이름으로 저장 → 파일 이름 AGENTS.md, 형식 모든 파일, 인코딩 UTF-8
## 막히는 지점
- AGENTS.md가 AGENTS.md.txt로 저장됨 → 탐색기 보기 → 파일 확장명 켜고 이름을 AGENTS.md로 변경
