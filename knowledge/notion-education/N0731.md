# Gemini로 음악 만들기
이제 다시 신입 마케터의 상황으로 돌아가 보겠습니다.
우리는 이미
- 프리미엄 숏패딩 캠페인의 방향을 정했고,
- 근거를 조사했습니다.
그렇다면 그 분위기에 맞는 **짧은 음악 시안도 함께 만들어볼 수 있지 않을까요?**
### **첫 번째 음악 만들기**
여기서는 특정 브랜드를 직접 넣기보다, <br>프리미엄 겨울 패딩 캠페인에 어울리는 차분하고 세련된 분위기를 잡는 데 집중합니다.
#### **음악 프롬프트의 뼈대**
- **무엇을 만들지**: 길이와 종류 (예: 30초 배경음악)
- **분위기/톤**: 느낌을 형용사로 (예: 세련되고 따뜻한)
- **배경/환경**: 어떤 장면에 깔릴지 (예: 겨울 도시)
- **구성/전개**: 어떻게 흘러갈지 (예: 잔잔하게 시작해 후반에 차오르는)
- **용도**: 어디에 쓸지 (예: 브랜드 필름 배경음악)
아래 프롬프트를 그대로 입력해보겠습니다.
```plain text
[무엇을 만들지] 프리미엄 겨울 패딩 캠페인용 30초 음악 초안
[분위기/톤] 세련되고 따뜻한 분위기, 과하지 않은 광고 배경음악 느낌
[배경/환경] 겨울 도시의 공기감이 느껴지는 무드
[구성/전개 방식] 짧은 브랜드 필름이나 광고 영상 뒤에 자연스럽게 깔릴 수 있는 흐름
[용도] 프리미엄 숏패딩 캠페인 무드 샘플용

- 특정 브랜드명은 넣지 않기
- 멜로디는 과하지 않게
- 배경음악처럼 자연스럽게 이어지게
```

#### **프롬프트를 바꾸면 음악이 어떻게 달라질까**
음악도 글·이미지와 똑같습니다. 입력한 설명이 결과를 좌우합니다. <br>한 부분씩만 바꿔 넣으며, 무엇이 달라지는지 직접 들어 볼까요?
**예시 1. 분위기를 바꾸기 (차분함 → 활기참)**
```javascript
[무엇을 만들지] 프리미엄 겨울 패딩 캠페인용 30초 음악 초안
[분위기/톤] 밝고 경쾌하며 활기찬 분위기, 젊은 감각의 광고 음악 느낌
[배경/환경] 도심에서 활동적으로 움직이는 겨울 장면
[구성/전개 방식] 처음부터 리듬감 있게 시작해 끝까지 경쾌하게
[용도] 프리미엄 숏패딩 캠페인 무드 샘플용

- 특정 브랜드명은 넣지 않기
- 배경음악처럼 자연스럽게 이어지게
```
**예시 2. 악기·편성을 바꾸기 (피아노 중심 → 현악기 중심)**
```javascript
[무엇을 만들지] 프리미엄 겨울 패딩 캠페인용 30초 음악 초안
[분위기/톤] 고급스럽고 웅장한 분위기
[배경/환경] 눈 내리는 겨울 도시의 넓은 풍경
[구성/전개 방식] 잔잔하게 시작해 후반부에 현악기가 차오르는 흐름
[악기] 현악기(스트링) 중심, 피아노는 보조로
[용도] 브랜드 필름 오프닝 배경음악

- 특정 브랜드명은 넣지 않기
- 가사 없이 연주곡으로
```
**예시 3. 용도를 바꾸기 (브랜드 필름 → 짧은 SNS 영상)**
```javascript
[무엇을 만들지] 15초 SNS 숏폼 영상용 음악 초안
[분위기/톤] 세련되면서 임팩트 있는 분위기
[배경/환경] 빠르게 전환되는 겨울 패션 컷
[구성/전개 방식] 짧은 시간 안에 시선을 잡는 후킹 위주
[용도] 인스타그램 릴스, 짧은 숏폼 배경음악

- 특정 브랜드명은 넣지 않기
- 도입 2초 안에 분위기가 잡히게
```

### AI는 소리를 어떻게 만들까?
소리도 컴퓨터에서는 숫자로 저장되는 데이터입니다.<br>AI는 방대한 소리 데이터를 그대로 다루는 대신, **오디오 토큰이나 압축된 표현**으로 바꿔 처리합니다.
음악을 만드는 대표적인 방식은 두 가지입니다.
- **다음 소리 예측하기:** 앞의 소리를 바탕으로 다음에 올 소리 조각을 차례로 생성합니다.
- **디퓨전:** 무작위 잡음에서 시작해, 잡음을 단계적으로 제거하며 음악을 완성합니다.

<summary>**Gemini의 음악 엔진은?**</summary>
AI 음악 모델은 소리를 압축된 표현으로 바꿔 생성합니다. <br>모델에 따라 앞의 소리를 참고해 다음 오디오 토큰을 이어 만들기도 하고, 잡음에서 소리를 다듬는 디퓨전 방식을 사용하기도 합니다.
Gemini의 음악 기능은 Lyria 3를 사용하지만, 구체적인 생성 방식은 공개되지 않았습니다. <br>다만 실시간 모델인 Lyria RealTime은 앞의 음악을 참고해 다음 소리를 이어 만드는 방식을 사용합니다.

사용자가 생성 방식을 선택하는 것은 아닙니다. 프롬프트에는 원하는 **분위기·장르·악기·템포·보컬·곡 구조**를 적으면 됩니다.
</details>
이때 프롬프트는 음악의 방향을 정합니다.<br>**분위기·장르·악기·템포·보컬·용도**를 구체적으로 적을수록 원하는 결과에 가까워집니다.
> AI는 소리 조각을 이어가거나 잡음을 다듬어 음악을 만든다.
따라서 좋은 음악 프롬프트는 원하는 소리를 구체적인 언어로 설명해야 한다.
> ⚠️ 특정 가수나 곡을 그대로 따라 하도록 요청하기보다, 분위기와 악기·보컬 특징으로 표현합니다. 미공개 캠페인 정보도 입력하지 않습니다.
