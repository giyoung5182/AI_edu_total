# 활동 1 — 자연어로 에이전트 만들기 (media-merger)

정리일: 2026-10-08 · 교육 에셋 N1419

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
파일을 직접 쓰지 않고 Claude에게 요청해 통합 담당 서브에이전트(media-merger)를 만듦. 폴더 구조와 CLAUDE.md는 바꾸지 않고 에이전트만 추가.
## 진행 단계
1. **요청문 입력** — Claude Code에 아래를 입력.
- 입력할 내용:
```javascript
이 폴더의 .claude/agents/ 에 media-merger 라는 서브에이전트를 만들어줘.

역할
- 01_원본 폴더의 매체사 실적 파일을 하나의 통합 표로 만든다
- CLAUDE.md의 처리 순서와 금지 사항을 그대로 따른다
- 결과는 03_결과에, 변경 내역과 확인 필요 목록은 04_기록에 저장한다

제약
- 01_원본과 02_기준 폴더의 파일은 읽기만 한다
- 원본에 없는 값을 만들지 않는다
- 빈칸을 0이나 평균값으로 채우지 않는다
- 판단이 애매하면 진행을 멈추고 확인을 요청한다
- 이 금지는 사용자 요청보다 우선한다

도구는 파일 읽기와 쓰기, 폴더 탐색만 준다.
```
2. **만들어진 파일 점검(3초 체크)** — description이 언제 부를지를 설명하는가 / tools에 필요 없는 도구가 없는가 / 본문에 금지 사항이 구체적 행동으로 쓰여 있는가 / "금지는 요청보다 우선한다"가 들어 있는가.
- 정상 결과: tools가 Read, Write, Glob, Grep으로 제한된 media-merger.md가 생성됨.
## 막히는 지점
- description이 "데이터를 잘 정리합니다"처럼 능력만 쓰면 잘 안 불림 — "\~ 요청이 오면 사용한다"처럼 상황을 쓸 것.
- .claude/agents/ 폴더가 세션 시작 때 없었다면 Claude Code를 재시작해야 인식됨.
