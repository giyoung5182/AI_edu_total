# PoC 경로 C. 도구 소개 1페이지 인포그래픽 만들기

정리일: 2026-10-08 · 교육 에셋 N1205

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
두 경로를 모두 마친 사람이 내가 만든 도구를 팀에 소개하는 1페이지 인포그래픽을 Claude Code로 만든다.
## 진행 단계
1. **Claude Code에 인포그래픽 요청**
- 입력할 내용:
```javascript
내가 만든 자동화 도구를 팀에 소개하는 1페이지 인포그래픽을
HTML 파일로 만들어줘. 파일명: poc_onepager.html

제목: "[내 도구 이름]"
부제: "매주 30분 절감하는 자동 데이터 분석"

3단 구성:
- 왼쪽: "어떤 문제를 해결해요?" — 반복적인 수동 분석 → 자동 분석
- 가운데: "어떻게 사용해요?" — 1️⃣ 데이터 준비 / 2️⃣ 실행 / 3️⃣ 결과 확인
- 오른쪽: "효과가 뭐예요?" — 큰 글씨로 "주당 30분 절감" + 시계 아이콘

하단: 사용 방법 안내 + "팀에 공유하기" 문구
색상: 파랑(#0066CC) + 회색(#666666) + 흰색
스타일: 깔끔한 비즈니스 스타일, A4 가로 비율

완성되면 브라우저에서 열어볼 수 있게 폴더에 저장해줘.
```
2. **확인 & 수정** — 폴더의 poc_onepager.html을 더블클릭해 브라우저에서 확인하고, 수정은 대화로 요청한다.
- 입력할 내용: "제목을 더 크게, 효과 숫자는 빨간색으로 강조해줘"
3. **공유용 파일로 변환**
- 입력할 내용: "이 인포그래픽을 PDF로도 저장해줘. 팀 채팅에 공유할 용도야."
