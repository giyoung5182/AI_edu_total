# Part 2. SNS 홍보 실전 (인스타·블로그·카카오 유형별 실습)

정리일: 2026-10-08 · 교육 에셋 N1356

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 가게 정보를 넣은 RCTCK 프롬프트로 SNS 채널별 홍보글 초안을 만듭니다.
## 진행 단계
1. **2-1 인스타그램 포스팅 3유형** — 신메뉴/신상품 소개, 계절/시즌 이벤트, 일상/가게 스토리
- 입력할 내용: \[R\] 동네 소상공인 SNS 마케터 / \[C\] 가게 이름·신메뉴·가격·특징 / \[T\] 인스타그램 포스팅 글 / \[C\] 3문장 이내·이모티콘 2개 이하·해시태그 5개 / \[K\] 밝은 느낌
- 소재가 없을 때: 업종을 넣고 7월 인스타그램 소재 아이디어 10가지 요청
2. **2-2 네이버 블로그 포스팅** — 가게 소개 포스팅 초안(제목 1개 + 본문 300\~400자, 검색 키워드는 동네이름 + 업종명)
3. **2-3 카카오톡 단체 문자 4종** — 이벤트 공지(100자 이내), 임시 휴무 안내(70자 이내), 영업 재개 알림(80자 이내), 리뷰 요청 문자(100자 이내)
