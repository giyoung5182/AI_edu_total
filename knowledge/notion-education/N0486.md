# 대조 검증과 내보내기 (Verify content)

정리일: 2026-10-08 · 교육 에셋 N0486

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
생성된 슬라이드가 설계서·조사 결과와 일치하는지 대조하고 내보냅니다.
## 진행 단계
1. **Verify content** — 툴바에서 Verify content 클릭 → 이 페이지만/전체 덱 선택 → AI가 수치·주장·출처를 웹 또는 업로드 파일과 대조 → 검증한 슬라이드마다 참조 링크와 검증 표시
2. **사람이 하는 대조 점검** — 없던 숫자가 생기지 않았는가 / 출처 표기가 사라지지 않았는가 / "추측" 표기가 유지되었는가 / 결론이 원본보다 강해지지 않았는가 / 6장에 내 실제 경험이 그대로 있는가
3. **손실 고치기**
- 입력할 내용:
```javascript
아래 세 가지를 수정해줘.

1. 출처가 있는 항목에 각주로 출처를 다시 넣어줘
2. "추측" 표기를 복원해줘
3. 내가 준 자료에 없는 숫자는 전부 삭제해줘
```
1. **AI 흔적 제거** — 혁신적·압도적, 급격히 변화하는, 새로운 가치 창출, 기여하고자 합니다 같은 표현 삭제
2. **내보내기** — Export → 형식 선택(고칠 것=PPTX, 바로 보낼 것=PDF, 여럿이 볼 것=Google Slides) → 내려받기 → 파일명 정리 → 본인 메일로 발송. 내보내기는 크레딧이 들지 않음.
## 막히는 지점
- Verify content 버튼은 생성 후 툴바에 뜨므로, 생성 전 화면에서 안 보이는 게 정상
- 자주 나타나는 손실: "보임"→"급증"(단서 사라짐), 출처 삭제, "추측"이 사실로
