# 1장 — Make.com 외부 연결 사례 (교육기관 맞춤형)
> 2권에서 배운 것: 구글 시트 → 조건 → 이메일<br>이 장에서 배울 것: GAS로 이미 한 것을 Make.com으로 어떻게 확장하는가
---
## GAS와 Make.com의 역할 분담 — 다시 한번
```plain text
GAS:       구글 시트 안에서 데이터를 처리·계산·저장
Make.com:  처리된 결과를 외부 앱으로 전달하거나
           외부에서 들어오는 것을 자동으로 받는 것

핵심:
GAS만으로도 이메일은 보낼 수 있음
Make.com이 필요한 순간은
"구글 생태계 밖으로 나가야 할 때"
```
---
## 외부 연결이란 무엇인가
```plain text
구글 생태계 안:
  구글 시트 ↔ 구글 드라이브 ↔ Gmail ↔ 구글 폼
  → GAS로 충분

구글 생태계 밖:
  슬랙 / 노션 / 카카오 / 라인 / 네이버 / ERP
  → Make.com이 필요

예:
  GAS로 원장 정리 완료
  → Gmail로 이메일 발송 (GAS로 가능)
  → 슬랙 채널에도 알림 (Make.com 필요)
  → 노션 DB에도 기록 (Make.com 필요)
```
---
[개별 성장·업무 분석은 제외했습니다.]
## 슬랙이 없다면? — 대안
```plain text
슬랙 미사용 시 대안:

Gmail로 대체:
  슬랙 알림 대신 이메일로 동일하게 구현
  → 슬랙 모듈 대신 Gmail 모듈로 교체

라인 Works:
  교육기관이 라인 Works 사용 중이라면
  Make.com에 Line Works 모듈 있음

카카오톡:
  공식 API 없음 → 이메일로 대체 권장
  카카오 비즈니스 채널 있으면 알림톡 가능
  (별도 신청 필요)
```

## GAS + Make.com 동시 실행 — 핵심 연결법
```plain text
GAS 코드 마지막에 이 코드를 추가하면
GAS 실행 완료 순간 Make.com도 동시에 실행됩니다:

  var webhookUrl = '[개별 링크 제외]
  UrlFetchApp.fetch(webhookUrl, {
    method: 'post',
    contentType: 'application/json',
    payload: JSON.stringify({
      완료시각: new Date().toLocaleString('ko-KR'),
      처리건수: N,
      담당자: '이름'
    })
  });

Make.com에서:
  Custom Webhook 트리거
  → GAS에서 보낸 데이터 받기
  → Slack/Gmail로 전달

→ 이렇게 하면 GAS 버튼 하나로
  시트 처리 + 외부 알림이 동시에 실행됩니다
```

# 2장 — Make.com 자동화 설계 워크시트
> GAS 워크시트처럼, Make.com으로 자동화할 수 있는 업무를 직접 설계합니다.<br>"생각해보세요"가 아니라 단계별로 채우면 완성됩니다.
---
## 워크시트를 쓰기 전에 — Make.com에서 자동화 가능한 것
```plain text
GAS로 하는 것:
  구글 시트 안에서 데이터를 처리하고 정리하는 것

Make.com으로 하는 것:
  처리된 결과를 외부 채널로 전달하거나
  외부에서 들어오는 데이터를 자동으로 받는 것

Make.com 자동화에는 반드시 두 가지가 있어야 합니다:
  ① 시작점 (트리거): 어떤 일이 생겼을 때?
  ② 연결 채널: 어디서 어디로?

Make.com이 잘 하는 것:
  이메일 자동 발송 / 슬랙 알림 / 구글 시트 저장
  정기 보고서 발송 / 조건 달성 시 즉시 알림
  이메일 수신 → 드라이브 저장

Make.com이 못 하는 것:
  이지포스·ERP 직접 접속 (로그인 필요한 외부 시스템)
  카카오톡 발신 (공식 API 없음)
  구글 시트 내 복잡한 데이터 계산 → 이건 GAS
```
---
## 자동화 아이디어 발굴 — 3가지 질문
```plain text
질문 1: 내가 매일·매주 반복하는 알림·보고·전달은?
  → 누군가에게 정기적으로 파일이나 메시지를 보내는 일
  → 특정 상황이 되면 알려줘야 하는 일

질문 2: 결과가 나왔을 때 "이걸 OOO한테 보내야 하는데" 하는 일은?
  → GAS로 처리한 결과를 이메일·슬랙으로 보내는 흐름

질문 3: 뭔가 들어올 때마다 손으로 옮기는 일은?
  → 이메일 첨부파일, 구글 시트 입력 등
```
