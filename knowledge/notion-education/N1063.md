# ① 로고

정리일: 2026-10-08 · 교육 에셋 N1063

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
포장 스티커와 부스 간판에 쓸 정사각형 로고를 AI로 만듭니다.
## 진행 단계
1. **팀 기본 정보 정리** — 가게 이름, 파는 것, 손님, 가격, 느낌, 메인/보조 컬러를 메모장에 적어 둠
2. **로고 프롬프트 입력**
- 입력할 내용:
```javascript
중학교 플리마켓에서 쓸 가게 로고를 만들어줘.

- 가게 이름: [이름]
- 파는 것: [아이템]
- 주고 싶은 느낌: [예: 귀여운 / 깔끔한 / 웃긴]
- 색: [메인 컬러]과 [보조 컬러]만 사용

조건은 이래.
- 가로세로 비율이 같은 정사각형
- 배경은 단색
- 가게 이름 "[이름]"을 정확한 한글로 크게 넣을 것
- 아주 작게 줄여도 알아볼 수 있을 만큼 단순할 것
- 그림은 1개만 넣을 것

서로 다른 스타일로 4개 만들어줘.
```
1. **고쳐달라고 요청** — 너무 복잡함/색이 많음/느낌이 다름/글자가 깨짐/이름이 안 보임 상황별 요청 문구 사용
2. **저장** — 파일명 교육기관_팀명_로고.png, 제출 폴더에 업로드
## 막히는 지점
- AI가 만든 그림 안의 한글은 획이 빠지거나 없는 글자가 섞일 수 있어 확대해서 한 자씩 확인
