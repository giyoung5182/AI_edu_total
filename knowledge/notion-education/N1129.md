# 실습 1. 작업 폴더 준비 — 고객 문의 메일·클레임이력 연결 (필수)

정리일: 2026-10-08 · 교육 에셋 N1129

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
고객 문의 메일 가운데 클레임성 메일이 클레임이력의 어느 건과 이어지는지 정리하는 일을 위해, 같은 작업을 자료만 바꿔 다시 실행할 때를 대비한 회차별 폴더부터 나눕니다.
## 진행 단계
1. **폴더 만들기** — 바탕화면에 D2P3_작업(00_원본보관 / 1회차 / 기록)을 만들고 받은 원본 파일을 1회차 폴더에 복사(Ctrl 누른 채 끌기, Mac은 Option)합니다.
2. **Work 켜기** — 경로 A: 앱 왼쪽 위 ChatGPT 메뉴 → Chat / Work 토글에서 Work → 1회차 폴더만 접근 허용. 경로 B: chatgpt.com 맨 위 가운데 토글에서 Work → 입력창 아래 파일로 두 파일 첨부.
3. **시작 점검 요청**
- 입력할 내용:
```plain text
작업 시작 전 점검: 지금 실제로 열 수 있는 파일 이름과 시트 이름·메일 개수만 알려 줘. 아직 파일을 만들거나 고치지 마.
```
- 정상 결과: 01 시트 3개(업무시간실태조사 · 출장정산내역 · 클레임이력), 02 메일 20건(MAIL-01 \~ MAIL-20)
1. **응답 저장** — 응답을 메모장에 붙여넣어 기록 폴더에 저장합니다.
## 막히는 지점
- Work가 보이지 않음: Chat / Work 토글 확인, 없으면 새로고침 후 강사 호출
- 폴더 접근이 안 됨(경로 A): 경로 B로 전환
- 파일 첨부 개수가 막힘(경로 B): 두 번에 나눠 첨부
- 원본이 이미 바뀜: 00_원본보관에서 다시 복사
