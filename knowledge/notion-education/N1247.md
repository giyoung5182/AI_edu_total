# 1단계. WSL2와 Ubuntu 설치

정리일: 2026-10-08 · 교육 에셋 N1247

## 이 실습으로 하는 것
Windows 노트북 안에 WSL2와 Ubuntu를 설치하고 Ubuntu 사용자 계정을 만듭니다.
## 진행 단계
1. **PowerShell 관리자 실행** — 시작 메뉴 → "PowerShell" 검색 → 마우스 오른쪽 클릭 → 관리자 권한으로 실행
2. **설치 명령 입력** — Enter로 실행. 이 명령 하나가 WSL 기능 활성화, 리눅스 커널 설치, Ubuntu 배포판 설치를 처리
- 입력할 내용:
```powershell
wsl --install
```
또는
```php
wsl --install -d Ubuntu-24.04
```
1. **재부팅** — 설치 완료 메시지 확인 후 컴퓨터 재부팅
2. **계정 만들기** — 재부팅 후 자동으로 열리는 Ubuntu 창에서 사용자 이름 입력(영문 소문자), 비밀번호 입력(화면에 표시되지 않는 것이 정상), 비밀번호 재입력
- 정상 결과: 이 비밀번호는 Windows 로그인 비밀번호와 별개이며, Windows 비밀번호가 없어도 동일하게 진행
3. **설치 상태 확인**
- 입력할 내용:
```powershell
wsl --list --verbose
```
- 정상 결과: Ubuntu가 VERSION 2로 표시되면 정상
[원본 이미지 제외]
## 막히는 지점
- wsl --install이 인식되지 않음: Windows Update 후 재시도(Windows 10은 2004 이상 필요)
- 재부팅 후 Ubuntu 창이 안 뜸: 시작 메뉴에서 "Ubuntu"를 직접 실행
- WSL 설치 중 가상화 오류: BIOS에서 가상화(VT-x/SVM) 활성화 후 1단계 재수행
- sudo 비밀번호가 계속 틀림: Windows 비밀번호가 아니라 1단계에서 만든 Ubuntu 계정 비밀번호 입력
