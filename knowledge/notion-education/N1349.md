# Step 0 — 데이터 현황 파악

정리일: 2026-10-08 · 교육 에셋 N1349

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Claude Code에 엑셀 파일 경로를 적어 데이터의 날짜 범위·수치 컬럼·카테고리 컬럼을 요약받고 차트 아이디어를 얻는다. 코드 없이 채팅으로만 진행한다.
## 진행 단계
1. **프롬프트 작성** — 실습_영업팀_매출데이터.xlsx 파일 경로를 프롬프트에 직접 적는다.
- 입력할 내용:
```javascript
실습_영업팀_매출데이터.xlsx 파일 대상으로,
데이터의 날짜범위, 주요 수치 컬럼, 카테고리 컬럼을 요약해줘.
차트로 보여주면 좋을 인사이트 아이디어도 포함해줘.
```
1. **답변 확인** — AI가 데이터를 읽고 요약과 아이디어를 준다.
## 막히는 지점
- 기본 경로는 day2/Day2_reference_data/실습_영업팀_매출데이터.xlsx 이며, claude를 실행한 폴더가 day2/가 아니면 전체 경로를 적는다.
