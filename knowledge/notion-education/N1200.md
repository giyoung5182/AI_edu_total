# 실습 — 지금 만드세요 (10분)

정리일: 2026-10-08 · 교육 에셋 N1200

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
제공된 지침을 우리 현장에 맞게 고쳐 부서 전용 GPTs를 만들고 저장합니다.
## 진행 단계
1. **만들기 진입** — ChatGPT 왼쪽 사이드바 \[GPT 탐색\] → \[+ 만들기\] → \[구성(Configure)\] 탭.
2. **지침 수정(4분)** — 지침을 붙여넣고 세 곳만 고칩니다: 역할의 현장 유형, 작업 순서의 분류 기준, 출력 형식의 장 구성.
3. **지식 파일(2분)** — 기존 보고서를 올립니다.
4. **테스트(3분)** — 오른쪽 미리보기에 실습 파일 01번 메모를 넣습니다.
- 정상 결과: 미측정 항목이 "미측정"으로 나옵니다.
5. **저장(1분)** — \[만들기\] → 공개 범위 선택 후 저장.
## 완료 기준
- 지침에 역할·작업 순서·출력 형식·금지 사항 네 덩어리 / 금지 사항에 미제공 수치 생성 금지 / 지식 파일에 골든 샘플 / 저장 및 이름 / 워크시트와 완성 지침을 따로 저장
