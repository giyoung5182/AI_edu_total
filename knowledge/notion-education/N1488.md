# 6️⃣ 실습: PRD를 MVP로 구현하기 (단일 HTML 웹앱)

정리일: 2026-10-08 · 교육 에셋 N1488

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
PRD를 AI에 붙여넣어 단일 HTML 웹앱 초안을 만들고 더미 데이터로 입력·처리·출력을 검증합니다.
## 진행 단계
1. **마스터 프롬프트 준비** — 아래 프롬프트 뒤에 PRD를 붙여넣습니다.
- 입력할 내용:
```javascript
아래 PRD를 바탕으로 브라우저에서 바로 실행 가능한 업무용 웹앱을 만들어줘.
반드시 HTML, CSS, JavaScript만 사용해서 하나의 HTML 파일로 완성해줘.
외부 프레임워크는 사용하지 말고, 복사해서 저장한 뒤 바로 실행할 수 있어야 해.
필수 조건: 입력 영역/실행 버튼/결과 영역이 명확, 클릭 시 즉시 반응, 빈 입력 시 안내 문구, 더미 데이터 자동 입력 버튼, 결과 복사 버튼, 복잡하지 않은 비즈니스 스타일, 실제 회사 데이터 입력을 유도하지 않음
아래는 PRD야.
[여기에 작성한 PRD 붙여넣기]
```
2. **기본 완성 기준 확인** — 입력창이 있는가 / 실행 버튼이 눌리는가 / 결과 영역이 보이는가 / 입력을 바꾸면 출력도 바뀌는가 / 빈·잘못된 입력에 안내 문구가 나오는가 / 더미 데이터 자동 입력 버튼이 있는가 / 결과 복사 버튼이 있는가. 만족하면 단일 HTML MVP로 인정.
3. **더미 데이터로 검증** — 예: KPI 도구라면 "구매팀 목표 120 실적 98 / 영업팀 목표 150 실적 162 / 생산팀 목표 200 실적 187".
4. **첫 수정 요청** — 예: "결과를 표 말고 카드 형태로 보여줘." "빈 값이 있으면 빨간 안내 문구를 보여줘." "복사 버튼을 추가해줘." "제목을 더 직관적으로 바꿔줘."
## 막히는 지점
- 실제 회사 데이터 대신 더미 데이터로 테스트하며, 민감 정보는 AI에 그대로 입력하지 않습니다.
