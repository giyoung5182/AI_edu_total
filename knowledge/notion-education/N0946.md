# Part 1 · AI 이미지를 계속 고쳐 쓰는 법
## 1️⃣ 문제를 정확히 봅시다
지점 홍보물이나 목표 안내 이미지를 AI로 만드셨을 겁니다. 결과물은 나쁘지 않습니다.
**문제는 다음 주입니다.**
```plain text
팀별 인원이 바뀝니다
날짜가 바뀝니다
문구 한 줄만 고치면 되는데 방법이 없습니다
     ↓
결국 처음부터 다시 만듭니다
     ↓
폰트도 색도 배치도 달라집니다
     ↓
지난주 것과 이어지지 않습니다
```
**진짜 문제는 "수정이 안 된다"가 아니라 "매번 새로 만들어야 한다"입니다.**

## 3️⃣ 방법 1 — 처음부터 분리해서 만들기 (권장)
앞으로 만드실 것은 이 방식을 쓰면 편집에 좋습니다.
### 1단계. 배경만 AI로 생성합니다
**글자를 넣지 말라고 명시**하는 것이 핵심입니다.
```plain text
영화관과 팝콘, 음료가 있는 밝고 활기찬 분위기의
배경 이미지를 만들어줘.

조건:
- 상단과 중앙에 빈 공간을 넉넉히 둘 것
- 글자나 문자는 절대 넣지 말 것
- 포스터 배경으로 사용할 이미지
- 비율은 세로형 (4:5)
- 색감은 밝고 따뜻하게
```
다른 용도로 쓰실 때는 이 틀에 바꿔 넣으시면 됩니다.
```plain text
[장면 설명]의 배경 이미지를 만들어줘.

조건:
- 상단과 중앙에 텍스트를 넣을 빈 공간을 둘 것
- 글자나 문자는 절대 넣지 말 것
- 포스터 배경용 이미지
- 비율: [4:5 / 16:9 / 1:1]
- 분위기: [밝고 활기찬 / 차분하고 신뢰감 있는]
- 색감: [지정]
```
> 💡 **한글 깨짐 문제가 여기서 해결됩니다**
AI 이미지에서 한글이 깨지는 게 가장 큰 불만이실 텐데, **애초에 글자를 안 넣으면 깨질 일이 없습니다.** 글자는 Canva에서 얹습니다.
### 2단계. Canva에서 배경으로 올립니다
```plain text
① Canva 앱 실행
② 새 디자인 만들기 → 크기 선택
③ 업로드 → 생성한 이미지 선택
④ 배경으로 배치, 화면에 꽉 채우기
```
### 3단계. 텍스트를 얹습니다
- 제목, 팀별 숫자, 날짜를 **각각 별도 텍스트 상자**로 넣습니다
- 표가 필요하면 도형과 텍스트를 조합합니다
- 한 상자에 여러 정보를 넣지 마십시오. 나중에 수정할 때 불편합니다
### 4단계. 저장해두고 다음 주에 복제합니다
```plain text
① 완성된 디자인을 저장
② 다음 주에 해당 디자인 → 복제
③ 숫자와 날짜만 수정
④ 30초면 끝
```

## 4️⃣ 방법 2 — 이미 만든 이미지 고치기
기존 이미지를 살려야 하는 경우입니다.
### 글자 위에 덮어쓰기 (가장 빠름)
```plain text
① Canva에 기존 이미지 업로드
② 고칠 글자 위에 도형을 얹어 가림
   - 배경색과 비슷한 색으로 맞추면 티가 덜 남
③ 그 위에 새 텍스트 작성
```
숫자 하나 바꾸는 정도면 이 방법으로 충분합니다.
### 지우고 다시 쓰기
```plain text
① Canva 편집 도구로 기존 글자 영역 제거
② 배경이 복원되면 새 텍스트 얹기
```
배경이 복잡하면 자국이 남을 수 있으니 확인하십시오.
### PPT로 옮겨서 작업하기
```plain text
① Canva에서 작업한 결과를 PPTX로 다운로드
② 파워포인트에서 열기
③ 텍스트 상자가 살아 있으므로 그대로 수정
```
> ⚠️ **Canva에서 만든 텍스트는 PPT에서도 편집됩니다. AI 이미지 속 글자는 안 됩니다.**
이 차이를 기억하십시오. "PPT로 변환하면 수정된다"는 말은 **Canva 텍스트에만 해당**합니다.

## 6️⃣ 처음부터 재사용을 염두에 두고 기획하기
새 홍보물을 만드실 때 이 프롬프트로 시작하시면 처음부터 재사용 가능한 구조가 나옵니다.
```plain text
지점에서 사용할 [용도] 안내물을 만들려고 해.

대상: [누가 보는가]
전달할 내용: [핵심 메시지]
사용처: [게시판 / 단톡방 / 인쇄물]

어떤 구성으로 만들면 좋을지 제안해줘.

특히 매주 바뀌는 항목과 고정 항목을 구분해서 알려줘.
바뀌는 항목은 한 곳에 모아서 배치하는 방향으로 제안해줘.

배경 이미지 생성용 프롬프트도 함께 작성해줘.
글자는 넣지 않는 조건으로.
```
> 💡 **"바뀌는 항목과 고정 항목을 구분해서"가 핵심입니다**
이 한 줄이 없으면 예쁜 이미지 한 장으로 끝납니다. 넣으면 **매주 재사용하는 틀**이 나옵니다.
바뀌는 부분을 한 곳에 모아두면 매주 찾아다닐 필요가 없어서, 수정이 30초에 끝납니다.

## 3️⃣ 1단계 — 검색어 다듬기
"은퇴 후 연금"으로 검색하면 광고성 영상이 먼저 나옵니다. **검색어를 바꿔야 합니다.**
AI에게 검색어를 만들게 하십시오.
```plain text
유튜브에서 자료용 영상을 찾으려고 해.

주제: 은퇴 후 연금의 필요성
용도: 보험 컨설턴트 니즈 환기용으로 보여줄 영상

원하는 것:
- 전문가 인터뷰 또는 방송 보도 영상
- 특정 상품을 권유하지 않는 중립적 내용
- 10분 내외 길이

원하지 않는 것:
- 보험사 광고
- 특정 상품 판매 영상
- 개인 유튜버의 주관적 주장

검색어 후보를 5개 만들어줘.
각 검색어가 어떤 유형의 영상을 걸러내는지도 설명해줘.
```
주제만 바꿔서 계속 쓰실 수 있습니다.


```plain text

- 영상의 핵심 주장

- 인용할 만한 발언과 해당 시점
- 자료로 활용할 때 주의할 점
```

### (TIP) 해당 구간부터 바로 재생하는 링크 만들기
유튜브 URL 뒤에 시간을 붙이면 그 지점부터 시작됩니다.
```plain text
[개별 링크 제외]
```
`t=765`는 **765초**, 즉 12분 45초 지점입니다.
```plain text
계산법: (분 × 60) + 초
12분 45초 → (12 × 60) + 45 = 765
```
> 💡 **컨설턴트에게 공유할 때 유용합니다**
"이 영상 12분쯤 보세요"라고 하면 아무도 안 봅니다. 링크를 누르면 바로 그 장면이 나오면 봅니다.

## 6️⃣ 무엇을 물어야 할지 모를 때 — 메타프롬프팅
1권에서 Gem 지시문을 만들 때 썼던 기법입니다. **이미지든 영상이든 다른 업무든 똑같이 적용됩니다.**
프롬프트를 직접 쓰기 어려우면, AI에게 쓰게 하십시오.
### 상황만 설명하고 나머지를 맡길 때
```plain text
나는 [상황]에 있어.
[목표]를 하려고 해.

좋은 결과를 얻으려면 네가 나에게
어떤 정보를 물어봐야 하는지 먼저 질문해줘.

내가 답한 뒤에 작업을 시작해줘.
```
### 프롬프트를 아예 만들게 할 때
```plain text
[목적]을 위한 프롬프트를 작성하려고 해.

네가 최고의 결과를 낼 수 있는 프롬프트를
직접 작성해줘.

작성 후, 그 프롬프트가 왜 그렇게 구성되었는지
간단히 설명해줘.
```
### 결과가 마음에 안 들 때
```plain text
방금 결과가 기대와 달랐어.

내 요청에서 어떤 부분이 불명확했는지 알려줘.
어떻게 다시 물으면 좋을지 수정된 질문을 제안해줘.
```
> 💡 **오늘 배운 것 중 가장 오래 씁니다**
업무가 바뀌어도, 도구가 바뀌어도 그대로 적용되기 때문입니다. 프롬프트 작성법을 외우는 것보다 **AI에게 질문을 만들게 하는 습관**이 훨씬 오래 갑니다.

## 정리
### 이미지
```plain text
배경과 글자를 분리해서 만든다
     ↓
한 번 만든 틀을 계속 재사용한다
     ↓
매주 숫자와 날짜만 바꾼다
```
### 영상
```plain text
검색은 사람이, 검색어는 AI가
     ↓

     ↓

     ↓
시간 링크로 저장해서 공유
```

## 오늘 핵심 세 가지
```plain text
1. Gem = 반복 업무를 위한 전용 AI
   한 번 만들면 계속 씁니다.
   자료가 바뀌면 파일만 교체하면 됩니다.

2. K(Knowledge) = 근거를 못박는 것
   "첨부 자료에 있는 내용만"
   이 한 줄이 신뢰할 수 있는 답과 아닌 답을 가릅니다.

3. 메타프롬프팅 = 질문을 AI에게 맡기는 것
   무엇을 물어야 할지 모를 때,
   AI에게 먼저 물어보게 하십시오.
```
