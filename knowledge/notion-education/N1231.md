# 실습 6: AI로 M코드 다루기

정리일: 2026-10-08 · 교육 에셋 N1231

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클릭 메뉴에 없는 변환이 필요할 때 M코드를 AI에게 해석·수정시킵니다.
## 진행 단계
1. **문제1: 코드 해석** — 쿼리를 열고 홈 → 고급 편집기. M코드를 복사해 AI에게 줍니다.
```javascript
아래는 엑셀 파워쿼리 고급 편집기의 M코드야. 무슨 일을 하는지 한 줄씩 설명해줘.    (M코드 전체 붙여넣기)
```
- 정상 결과: 설명이 내 클릭 순서(빈 행 제거 → 중복 제거 → 공백 제거 → 대문자 → 값 바꾸기 → 타입 변경)와 일치.
2. **문제2: 클릭 메뉴에 없는 변환** — 받은 코드 전체를 고급 편집기에 붙여넣고 완료.
```javascript
[상황] Excel 파워쿼리를 쓰고 있어.    [현재 코드] (고급 편집기 M코드 전체 붙여넣기)    [요청] 열사용량_Gcal 값이 상위 10%에 드는 행에는 "집중관리", 나머지는 "일반"인           새 열 "관리등급"을 추가하는 단계를 기존 코드에 넣어서 전체 코드를 다시 줘.    [조건] 각 단계에 주석으로 설명해줘.
```
- 정상 결과: 집중관리 6건 내외.
3. **문제3: 오류를 AI로 해결** — 적용된 단계에서 날짜 값 바꾸기 단계 하나를 삭제하고 Error 발생 확인 후 입력합니다.
```javascript
파워쿼리에서 타입 변환 후 일부 행에 Error가 떠.    Error 셀을 클릭하면 이렇게 나와:    "DataFormat.Error: 날짜로 구문 분석할 수 없습니다. 26년4월3일"    원인과 해결 방법을 알려줘.
```
삭제한 값 바꾸기 단계를 재추가합니다.
4. (직접 풀어보기) 내 업무의 변환 하나를 \[상황\]/\[현재 코드\]/\[요청\]/\[조건\] 템플릿으로 프롬프트를 작성해 보냅니다.
## 막히는 지점
- 오류 메시지는 요약·번역하지 말고 화면의 메시지를 통째로 복사해서 줍니다.
