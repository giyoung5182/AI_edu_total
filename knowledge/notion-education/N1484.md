# 실습 4 — 주간 집계

정리일: 2026-10-08 · 교육 에셋 N1484

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
처리이력 59행을 상태별 건수·평균 소요일·부서별 건수로 집계해 주간집계 시트에 표로 작성합니다.
## 진행 단계
1. **요청하기** — 아래 프롬프트를 같은 스크립트에 함수를 추가하도록 요청합니다.
```javascript
같은 스크립트에 함수를 추가해줘.

[할 일]
처리이력 시트를 집계해 주간집계 시트에 쓴다.

1. 주간집계 시트를 비우고 새로 작성한다
2. 아래 항목을 집계한다
  [상태별] 완료 / 진행중 / 보류 각각의 건수와 비율
  [소요일] 완료 건의 평균·최대·최소 소요일 (완료일이 비어 있는 건은 계산에서 제외하고 "완료일 누락 N건"으로 별도 표시)
  [부서별] 요청부서별 건수 (많은 순)
  [분류별] 분류별 건수 (많은 순)
  [지연] 희망완료일이 오늘보다 이전이고 상태가 완료가 아닌 건의 목록 (접수번호 | 요청부서 | 제목 | 희망완료일 | 경과일, 경과일 내림차순)
3. 맨 위에 "집계일시"와 "대상 건수"를 표시한다

[예외]
- 처리이력이 비어 있으면 "데이터가 없습니다" 알림 후 중단
- 상태값이 완료/진행중/보류가 아닌 건은 "확인 필요"로 별도 집계하고 건수를 표시
- 희망완료일이 비어 있는 건은 지연 판정에서 제외하고 "기일 미정 N건"으로 표시

[서식] 제목은 후게, 지연 건 중 경과일 7일 이상은 배경색 주황
메뉴에 「주간 집계」 항목을 추가해줘.
```
2. **결과 확인** — 예상(완료 40 / 진행중 12 / 보류 6 / 확인 필요 1 / 완료일 누락 1)과 실제를 적어 비교합니다.
- 정상 결과: 어제 손으로 세었던 숫자, 3교시 GPTs가 낸 숫자와 세 개가 일치하면 검증 끝
## 막히는 지점
- 완성 코드는 먼저 직접 요청해 본 뒤 막혔을 때만 보는 용도
- 검증 방법 비교: 손으로 필터(느리지만 확실) / GPT 집계(빠르지만 매번 다를 수 있음) / GAS 집계(빠르고 항상 같음)
