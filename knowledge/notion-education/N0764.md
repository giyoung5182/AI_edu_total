본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

“이거 자동으로 되면 좋겠다” 싶은 것, 또는 팀에서 가장 번거로운 반복 작업을 떠올려 보세요.

이런 아이디어면 딱 좋아요
- 숫자나 텍스트를 넣으면 결과가 바로 나오는 것
- 매일 반복하는 소소한 불편함
- 작은 기능 여러 개를 한 화면에 모아둔 것 <br>(나만의 업무 툴)


**❌ 이런 건 어려울 수 있어요. - **사내 담당자와 협의가 필요해요.
- 사내 시스템(ERP 등) 연동이 필요한 것
- 사내 기밀 정보를 활용해야 하는 서비스

### 아이디어가 정해졌다면, 아래 세 가지를 미리 정리해 오세요.
1. 뭘 입력하나요? (숫자, 날짜, 텍스트 등)
2. 어떤 계산·변환이 필요한가요?
3. 결과를 어떻게 보여주면 좋을까요?

### 과제 선정 워크시트
아래 4가지 질문에 답하면서 자동화할 업무를 선정하세요:
```plain text
1. 매주 또는 매월 반드시 해야 하는 작업은 무엇인가?
   → _____________________________________

   → _____________________________________

3. 입력 데이터는 어떤 형태인가? (Excel / 텍스트 / 이메일 등)
   → _____________________________________

4. 원하는 결과물은 무엇인가? (보고서 / 차트 / 대시보드 / 이메일 등)
   → _____________________________________
```
