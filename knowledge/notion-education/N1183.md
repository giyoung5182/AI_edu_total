# Step 06 — 예외가 들어왔을 때 처리 기준 정하기

정리일: 2026-10-08 · 교육 에셋 N1183

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
일부러 이상한 자료를 넣어 예외 규칙을 보완하고, 사람이 볼 지점을 결과에 표시하게 합니다.
## 진행 단계
1. **이상한 자료 넣기** — 3-9_오류데이터.xlsx 자료를 추가해서 주간 보고를 다시 만들어줘
2. **예외 규칙 넣고 다시 시키기** — 날짜가 이번 기간 밖인 건 / 금액이 비었거나 음수인 건 / 같은 건이 두 번 들어온 것을 확인해 보고 맨 위에 '확인 필요 항목'으로 따로 알리고, 집계에서 빼고 빼다는 사실을 적어줘
3. **규칙에 없는 오류 확인** — 잘못 입력된 상태값, 지나치게 큰 금액 등을 AI가 알아서 알려주는지 확인
4. **빠진 조건 추가** — 필수 항목이 비어 있는 경우 / 진행상태가 데이터 사전에 없는 값 / 다른 데이터보다 금액의 자릿수가 크게 다른 경우 / 마감예정일이 접수일보다 빠른 경우를 '확인 필요 항목'에 넣기
## 막히는 지점
- AI가 이번에 알아서 처리했다고 다음에도 같은 방식으로 처리된다는 보장은 없으므로 반복 확인이 필요한 조건은 규칙으로 남김
