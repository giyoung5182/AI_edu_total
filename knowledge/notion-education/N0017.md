## 5.1 AX Quick Win이란?
### 결론 한 줄
> "지금 당장 30분을 줄일 수 있는 것 1개" 를 찾아서 실행하는 것입니다. 크게 시작하지 않아도 됩니다.
### AI 도입의 흔한 실패 패턴
```plain text
실패 패턴 A — "전체를 바꿔야 해":
"우리 회사 전체 업무 프로세스를 AI로 바꾸면 좋겠는데..."
→ 너무 커서 시작을 못 함 → 아무것도 안 바뀜

실패 패턴 B — "완벽한 시스템 만들고":
"GEMS를 완벽하게 세팅하고 나서 써야지"
→ 완벽한 세팅을 기다리다 → 결국 안 씀

실패 패턴 C — "교육만 받고 끝":
"오늘 배웠으니까 나중에 써야지"
→ 일주일 뒤 70% 기억 사라짐 → 안 씀

AX Quick Win의 접근:
"지금 당장 30분을 줄일 수 있는 것 1개만 찾아라"
→ 작게 시작 → 성공 경험 → 자연스럽게 확장
```
### Quick Win 업무 선택 기준 — 4가지 체크
```plain text
✅ 기준 1 — 반복성: 주 2회 이상 하는 업무인가?
   (자주 할수록 AI 효과가 큼)

✅ 기준 2 — 정형성: 매번 비슷한 패턴인가?
   (매번 달라지는 창의적 업무보다 패턴 있는 것이 AI에 적합)

✅ 기준 3 — 데이터 준비도: 참고할 자료나 양식이 있는가?
   (GEMS에 탑재할 제품 정보, 고객 패턴 등)

✅ 기준 4 — 2주 내 실행 가능성: 바로 테스트할 수 있는가?
   (시스템 구축이 필요한 복잡한 것보다 지금 당장 시도 가능한 것)
```

## 5.3 교육기관 실무 시나리오별 AI 워크플로우
### 시나리오 A — 신제품 입고 당일 (기존 6시간 → AI 2시간)
```plain text
기존 방식:
① 제품 성분표·설명서 검토 (1시간)
② 인스타 소개 본문 작성 (1시간)
③ 카드뉴스 기획·디자인 (3시간)
④ 원장님 공지 작성 (30분)
⑤ 파머 가이드 정리 (1시간)
합계: 6–7시간

AI 활용 방식:
① 제품 정보 Claude에 붙여넣기 → 요약·분석 (10분)
② GEMS 3 → 인스타 본문 3종 즉시 생성 → 1종 선택·수정 (10분)
③ GEMS 2 → 카드뉴스 기획 생성 (5분)
   GPT 4o → 이미지 5장 생성 (10분)
   Canva → 완성 (20분)
④ GEMS 3 → 원장님 카카오톡 공지 (3분)
⑤ Canvas → 파머 제품 가이드 1페이지 (10분)
합계: 약 68분
```
### 시나리오 B — 주간 콘텐츠 플래닝 (기존 3시간 → AI 20분)
```plain text
기존 방식:
매주 월요일 오전
① 지난 주 게시물 반응 확인 (30분)
② 이번 주 소재 회의 (1시간)
③ 주간 캘린더 정리 (30분)
④ 각 담당자에게 소재 배분 (30분)
합계: 2.5–3시간

AI 활용 방식:
① Deep Research → 이번 주 트렌드 키워드 확인 (5분)
② GEMS 2 → 주간 소재 7개 캘린더 즉시 생성 (3분)
③ 팀원 공유 링크 발송 (2분)
합계: 10분
→ 절약 시간: 주 2.5–3시간 = 월 10–12시간
```
### 시나리오 C — 고객 DM 처리 루틴 (기존 2시간/일 → 20분/일)
```plain text
현재 상황:
오전 DM 확인 → 건당 7–10분 답변 → 15–20건 = 1.5–2시간

AI 활용 루틴:
오전 DM 열기
→ GEMS 1 (Claude Projects) 동시에 열기
→ DM 1개 복사 → GEMS에 붙여넣기
→ 답변 3초 생성 → 확인 → 발송 (30초)
→ 다음 DM...
15–20건 = 10–15분

추가 자동화 (ManyChat 연동 시):
→ 특정 키워드 댓글 → 자동 DM 발송 (GEMS에서 만든 문구 활용)
→ 담당자 손 없이 24시간 자동 응대
```

```plain text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

파메스테틱 제품 관련 고객 인스타그램 DM 답변

- 일 평균 DM: 15–20건

  · 담당자마다 답변 품질 차이
  · 같은 질문에 매번 처음부터 작성
  · 화장품법 표현 실수 위험
  · 퇴근 후 DM 대응 공백

  STEP 1. Claude Projects에 GEMS 1 세팅 (오늘 완성)
  STEP 2. 파메스테틱 제품 데이터 탑재
  STEP 3. 고객 DM 수신 → 복사 → GEMS 1에 붙여넣기
  STEP 4. 답변 즉시 생성 → 검토 후 발송
자동화 수준: 반자동 (AI 생성 + 사람 검토 후 발송)

4. 기대 효과
- 시간: 건당 7–10분 → 1분 이하 (90% 단축)
- 일 절감: 약 1.5–2시간
- 품질: 누가 답해도 동일 수준, 법적 안전
- 고객 경험: 빠른 답변 → 신뢰도 향상

5. 2주 실행 계획
1주차:
  D+0: GEMS 1 세팅 완료 (오늘 실습 결과물 활용)
  D+1–3: 실제 DM 10건 GEMS 테스트
  D+4–7: 프롬프트 수정 및 보완
  체크: 건당 소요 시간 3분 이하 달성?

2주차:
  D+8–10: 팀원 전체 GEMS 링크 공유 + 사용법 안내
  D+11–14: 전체 적용 + 효과 측정
  성공 기준: 일 DM 처리 시간 30분 이하 달성

```

### 막힐 때 꺼내쓰는 체이닝 5종
```plain text
① AI 결과가 마음에 안 들 때:
"[이 부분]이 마음에 안 드는데, [이 방향]으로 수정해줘.
나머지는 그대로 유지해줘."

② 너무 길거나 짧을 때:
"[N자]로 [압축/확장]해줘. 핵심 메시지는 유지하면서."

③ 다른 제품에 적용할 때:
"이 구조와 톤 그대로, [제품A]를 [제품B]로만 바꿔서 다시 써줘."

④ 더 전문적으로 만들 때:
"피부과학 용어 1개를 자연스럽게 추가해서
일반인도 이해할 수 있게 쉽게 풀어써줘."

⑤ 다른 채널로 변환:
"이 인스타 본문을 블로그 포스팅 형식으로 변환해줘.
길이는 1,500자, 소제목 3개 포함."
```
