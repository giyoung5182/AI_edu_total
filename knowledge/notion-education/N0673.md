# STEP 1 · 다듬기 (12분)

정리일: 2026-10-08 · 교육 에셋 N0673

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 포트폴리오 웹페이지를 항목별로 한 번에 하나씩 수정 요청해 다듬는다.
## 진행 단계
1. **색과 여백** — 요청 예시: 전체 색을 차분하게 바꾸고 섹션 사이 여백을 넓히세요. 문장은 그대로 두세요.
2. **첫 화면** — 요청 예시: 스크롤 없이 보이는 영역에 한 줄 소개가 먼저 오게 하세요.
3. **경험 카드** — 요청 예시: 각 카드에서 결과가 가장 크게 보이도록 배치를 바꾸세요.
4. **휴대폰** — 요청 예시: 휴대폰 화면에서 글자가 작습니다. 본문 크기를 키우고 여백을 늘리세요.
5. **인쇄** — 요청 예시: 인쇄했을 때 섹션이 중간에 잘리지 않도록 페이지 나눔을 정리하세요.
- 정상 결과: 다음 단계에서 PDF로 뽑을 때 경험 카드가 두 쪽에 걸쳐 잘리지 않음
6. **멈출 때 알기** — 마음에 들면 그 상태에서 멈춤. 이전 상태로 돌아가려면 아래처럼 요청
- 입력할 내용:
```javascript
방금 수정 전 상태로 되돌려 주세요.
색과 여백은 그 전 버전이 나았습니다.
```
## 막히는 지점
- 세 가지를 한꺼번에 말하면 하나만 반영됨
- 5번(인쇄)을 빠뜨리면 경험 카드가 두 쪽에 걸쳐 잘림
- 수정 요청이 쌓이면 앞의 요청과 뒤의 요청이 충돌함
