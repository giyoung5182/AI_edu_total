# 활동 5 — 팀 켜기 (에이전트 팀)

정리일: 2026-10-08 · 교육 에셋 N1328

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
기본적으로 꺼져 있는 에이전트 팀 기능을 켜고, 자연어로 팀을 요청해 서브에이전트와의 차이를 확인함.
## 진행 단계
1. **기능 켜기** — settings.json에 넣거나 셸 환경 변수로 설정.
- 입력할 내용:
```javascript
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}
```
2. **팀 요청** — 켠 뒤 자연어로 요청.
- 입력할 내용:
```javascript
매체 실적 통합 작업을 팀으로 처리해줘.

팀원 셋을 만들어줘.
- 파일 정리 담당: 01_원본 파일을 읽어 표준 형식으로 변환
- 검증 담당: 변환 결과의 정합성과 금지 사항 위반 점검
- 기록 담당: 변경 내역과 확인 필요 목록 작성

공유 작업 목록으로 조율하고,
검증 담당이 문제를 발견하면 정리 담당에게 직접 알리게 해줘.
```
- 달라지는 점: 서브에이전트는 검증자 발견 → 메인 보고 → 메인이 재작업 지시, 에이전트 팀은 검증자가 정리자에게 직접 메시지.
## 막히는 지점
- 실험적 기능이며 토큰을 훨씬 많이 씀. 교안은 이 사례에는 팀이 필요 없고 서브에이전트로 충분하다고 설명함.
