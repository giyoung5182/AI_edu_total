# 1. RCTCK — K(Knowledge)란 무엇인가

## 1-1. 핵심 질문: 왜 말로 설명하면 안 되는가?
프롬프트를 아무리 정교하게 써도 넘지 못하는 벽이 있습니다.<br>바로 "느낌"입니다.
```plain text
"전문적이고 간결하게, 공문서 스타일로, 딱딱하지 않게,
 수신자가 이해하기 쉽게, 우리 기관 특유의 어조로..."

→ 이것을 말로 다 설명해도 AI는 여전히 임의로 해석합니다.
→ "전문적"의 정도, "간결"의 기준을 AI가 알 수 없습니다.
```
**해결책은 설명이 아니라 예시입니다.**
[원본 이미지 제외]
```plain text
말로 설명할 때 (K 없음):
  → AI가 "전문적"의 기준을 임의로 설정
  → 전국 어디서나 볼 수 있는 평범한 공문체

실제 문서를 보여줄 때 (K 있음):
  → AI가 문장 길이, 어휘 선택, 단락 구조를 패턴으로 학습
  → 교육기관 33 특유의 문체와 구성이 재현됨
```
이것이 **Golden Sample 기법**입니다.
---
## 1-2. Golden Sample — 정의와 선택 기준
**Golden Sample** = 출력 품질의 기준이 되는, 우리 기관이 실제로 잘 쓴 문서 1건
### 왜 Golden Sample 1건이 강력한가
```plain text
일반적인 프롬프트 개선 방식:
  지시문을 더 길고 정교하게 작성한다
  → 한계: 아무리 설명해도 "느낌"까지는 전달 불가

Golden Sample 방식:
  잘 쓴 문서 1건을 통째로 넣는다
  → AI가 해당 문서의 패턴을 전체적으로 학습
  → 문체, 어휘, 단락 구성, 결론 짓는 방식까지 재현

→ "어떻게 써야 하는지 말로 설명하기 어려운 것"을
   문서 한 건으로 단번에 전달하는 방법
```

## 1-3. K 사용 시 반드시 지켜야 할 3가지
```plain text
원칙 1: 같은 유형끼리 매칭
  공문 만들 땐 공문을 K로
  보고서 만들 땐 보고서를 K로
  다른 유형을 넣으면 효과 감소

원칙 2: 민감 정보는 반드시 마스킹
  담당자명: 프로님 → 담당자A
  기업명: (주)OO기업 → 기업A
  연락처: [연락처 비공개] → 010-○○○○-○○○○
  결재 미완료 문서는 사용하지 않음

원칙 3: 분량 조절
  너무 길면 AI 처리 속도 저하 + 패턴 학습 흐려짐
  A4 1~2장 분량이 가장 효율적
  긴 문서는 핵심 섹션만 발췌해서 사용
```

## 1-5. K 전후 비교 — 실제 차이
### K 없이 요청할 때
```plain text
프롬프트:
"교육기관에서 글로벌강소기업 육성사업
 참가기업 모집 공문을 써줘.
 전문적이고 친절한 어조로."

AI가 생성하는 결과 (예시):
"안녕하십니까. 귀사의 무궁한 발전을 기원합니다.
 교육기관 33에서는 지역 중소기업의 글로벌 역량 강화를
 위하여 다음과 같이 글로벌강소기업 육성사업 참가기업을
 모집하오니 많은 관심과 참여 바랍니다."

→ 어디서나 볼 수 있는 평균적인 공문체
→ 교육기관 특유의 표현·구성이 없음
```
### K 적용 후 (충청북도 반도체 공고문을 K로 활용)
```plain text
프롬프트:
"아래는 충청북도가 실제 발행한 지역산업맞춤형 일자리지원
 사업 공고문이야. 이 문체와 구성 방식 그대로
 글로벌강소기업 육성사업 참가기업 모집 공문을 써줘.

 [충청북도 공고 제2026-475량 호 전문 붙여넣기]"

AI가 생성하는 결과:
→ 사업명·수행기관·지원 내용 구성 방식이 Golden Sample과 동일
→ "기업 귀중" 형식, 신청 방법 단계 표시 방식까지 재현
→ "충청북도 공공기관 문서"라는 느낌이 살아있음
→ 담당자가 수정할 사항이 훨씬 줄어듦
```

## 2-1. 오늘 사용할 Golden Sample: 충청북도 반도체 분야 공고문
> 오늘 실습에서 K(Knowledge)로 활용할 문서입니다.
**충청북도 공고 제2026-475량 호**<br>2026년 지역산업맞춤형 일자리지원사업<br>충청북도 반도체 분야 산업 대상 공고<br>(2026. 3. 16. 충청북도지사 발행)
### 이 공고문을 Golden Sample로 쓰는 이유
```plain text
✅ 충청북도 공식 발행 → 공공기관 표준 문체
✅ 사업명·지원내용·신청대상·신청방법 구조가 표준적
✅ 기업 대상 + 개인(근로자) 혼합 형식
✅ 결재·발행까지 완료된 검증된 문서
✅ 교육기관과 동일 지역·대상
```
### 이 공고문의 구성 요소 분석
```plain text
공고 번호: 충청북도 공고 제2026-475량 호
제목: 2026년 지역산업맞춤형 일자리지원 사업 충청북도 반도체 분야 산업 대상 공고

1. 사업개요
   - 사업명, 지원기간, 공고규모

2. 세부사업 및 수행기관 (표 형식)
   - 사업명 | 사업내용 | 수행기관

3. 신청대상
   - 지역·규모 기준

4. 지원신청 방법
   - 신청기간, 신청방법, 접수처

→ 이 구조가 충청북도 공고문 표준 양식
   새 공문 작성 시 같은 구조로 출력됩니다
```
