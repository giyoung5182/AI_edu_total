# 자유 대시보드 구성하기
> 목표: 정해진 정답을 따라 만드는 것이 아니라, 실습 파일 중 하나를 골라 `내가 보고 싶은 업무 질문`을 정하고 직접 대시보드의 구조를 잡아봅니다. Claude Code는 완성본을 대신 만들어주는 도구이기도 하지만, 이번 실습에서는 먼저 아이디어를 넓게 보고 스스로 선택하는 흐름을 연습합니다.
## 1. 사용할 데이터 고르기
아래 파일 중 하나를 선택합니다. 처음부터 세 파일을 모두 합치려고 하지 말고, 1차 버전은 한 파일만 사용합니다.
- `실습파일/교육기관영업거래처데이터_실습.xlsx`
- `실습파일/교육기관생산설비데이터_실습.xlsx`
- `실습파일/교육기관품질데이터_실습.xlsx`
선택 기준은 단순합니다. `영업 기회를 보고 싶으면 영업`, `설비 상태와 생산성을 보고 싶으면 생산설비`, `불량과 검사 결과를 보고 싶으면 품질`을 고릅니다.

## 2. 먼저 업무 질문 하나 정하기
대시보드는 차트 모음이 아니라 질문에 답하는 화면입니다. 파일을 고른 뒤 아래처럼 질문을 하나 정합니다.
- 영업 데이터: `어떤 거래처를 먼저 챙겨야 할까?`
- 생산설비 데이터: `어떤 설비나 라인이 운영 리스크가 클까?`
- 품질 데이터: `어떤 공정이나 제품군에서 품질 이슈가 반복될까?`
질문이 정해지면 KPI, 차트, 표를 고르기가 쉬워집니다.

## 3. 대시보드 아이디어 고르기
### 영업 거래처 데이터로 해볼 수 있는 방향
- 파이프라인 현황: 계약단계별 계약금액과 계약확률을 봅니다.
- 우선관리 거래처: 계약금액이 크고 다음 조치가 가까운 거래처를 찾습니다.
- 리스크 점검: 리스크요인이 있는 거래처와 담당팀을 확인합니다.
- 지역/산업군 분석: 어느 지역이나 산업군에서 매출 기회가 큰지 비교합니다.
### 생산설비 데이터로 해볼 수 있는 방향
- 설비 운영 현황: 가동률, 정지시간, 생산수량을 봅니다.
- 이상 징후 점검: 점검결과가 주의/이상인 설비를 따로 봅니다.
- 라인별 생산성 비교: 라인별 수율, 불량수량, 에너지사용량을 비교합니다.
- 점검 우선순위: 조치필요여부와 다음점검일을 기준으로 먼저 볼 설비를 정합니다.
### 품질 데이터로 해볼 수 있는 방향
- 검사 결과 현황: 적합/부적합 비율과 심각도를 봅니다.
- 결함 유형 분석: 어떤 결함유형이 자주 나오는지 확인합니다.
- 공정별 품질 이슈: 공정, 라인, 제품군별로 문제를 비교합니다.
- 조치 상태 확인: 조치가 필요한 항목이 어느 부서에 남아 있는지 봅니다.

## 4. 1차 버전은 작게 만들기
처음부터 완성형을 목표로 하지 않습니다. 아래 4가지만 있으면 1차 대시보드로 충분합니다.
- KPI 카드 3\~4개
- 차트 2\~3개
- 우선 확인 대상 표 1개
- 필터 1\~2개
예를 들어 품질 데이터를 선택했다면 `전체 검사 건수`, `부적합 건수`, `부적합률`, `조치 필요 건수` 정도만 먼저 잡습니다. 그다음 공정별 부적합 건수 차트와 결함유형별 차트를 넣으면 기본 흐름이 만들어집니다.

## 5. Claude Code에게 먼저 설계만 요청하기
바로 HTML을 만들라고 하지 말고, 먼저 설계안을 받아봅니다.
```plain text
실습파일/[선택한 파일명].xlsx를 사용해서 대시보드 아이디어를 잡고 싶어.

아직 HTML 파일은 만들지 말고, 먼저 설계안만 제안해줘.
아래 항목을 포함해줘.
- 이 데이터로 답할 수 있는 업무 질문 3개
- 초보자가 만들기 쉬운 대시보드 주제 3개
- 각 주제별 KPI 카드 후보
- 각 주제별 차트 후보
- 표로 보여주면 좋은 항목
- 1차 버전에서 빼도 되는 요소

나는 아이디어를 보고 하나를 골라서 직접 만들어볼 거야.
```

## 6. 선택한 주제로 1차 대시보드 만들기
설계안 중 하나를 고른 뒤, 너무 많은 조건을 넣지 말고 작게 시작합니다.
```plain text
방금 제안한 주제 중 [선택한 주제]로 1차 HTML 대시보드를 만들어줘.

조건은 다음과 같아.
- 선택한 엑셀 파일 하나만 사용
- KPI 카드 3~4개
- 차트 2개
- 우선 확인 대상 표 1개
- 필터는 1~2개만
- 파일명은 my_dashboard.html
- 화면 아래에는 `내가 이 대시보드로 확인하려는 질문`을 2줄로 정리

먼저 단순하게 만들고, 나중에 수정할 수 있게 구성해줘.
```

## 7. 만든 뒤에는 질문으로 고쳐보기
대시보드는 한 번에 완성하지 않고 질문을 바꿔가며 다듬습니다. 아래 중 하나만 골라 수정해봅니다.
- KPI 하나 바꾸기: `건수` 중심에서 `금액`, `비율`, `우선순위` 중심으로 바꿉니다.
- 차트 하나 바꾸기: `전체 현황` 차트를 `부서/라인/지역별 비교` 차트로 바꿉니다.
- 표 기준 바꾸기: `전체 목록` 대신 `먼저 확인할 Top 10`만 보여줍니다.
- 필터 하나 추가하기: 담당팀, 공정, 계약단계, 조치상태처럼 업무자가 자주 볼 기준을 넣습니다.
- 메모 영역 바꾸기: `상황 / 리스크 / 다음 액션` 3줄로 정리합니다.
