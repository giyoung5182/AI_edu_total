# 지출결의서 자동화 워크시트 (STEP 1~6) + 추가 기능 설계

정리일: 2026-10-08 · 교육 에셋 N1152

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지출결의서 입력 폼 → 제출이력 저장 → 월별 집계 갱신을 Google Apps Script로 자동화하고, 워크시트 STEP 1\~6으로 추가 기능까지 설계합니다.
## 진행 단계
1. **STEP 1. 현재 업무 흐름** — 자동화 전 작업 순서를 적습니다(폼 입력 → 집계 파일 열기 → 매장 탭·월 열 찾기 → 금액 수동 입력 → 저장 → 반복).
2. **STEP 2. 판단 vs 규칙** — 각 단계를 사람이 판단할 일과 규칙대로 반복되는 일로 나눕니다(내역 결정은 판단, 파일 열기·탭 찾기·금액 옮기기는 규칙).
3. **STEP 3. 자동화 대상** — 제출 시 제출이력 저장과 월별집계 갱신을 자동화 대상으로 정합니다.
4. **STEP 4. 파일 구조** — 입력 시트(지출결의서), 이력 시트(제출이력), 보고서 시트(월별지출집계)와 열 구성을 정리합니다.
5. **STEP 5. 트리거** — 메뉴 버튼으로 실행합니다(제출 / 폼 초기화 / 월별집계 갱신).
6. **STEP 6. Claude 요청 프롬프트(추가 기능용)** — 완성한 코드에 기능을 더하도록 Claude에 요청합니다.
- 입력할 내용:
```javascript
오늘 완성한 지출결의서 자동화 코드에 기능을 추가해줘.

[추가 기능 1: 본부장별 집계]
제출 완료 후 '본부장별집계' 시트도 자동 갱신
- 매장정보 시트 C열(본부장)을 참조해서 본부장별로 분류
- 형식: 본부장명 | 1월~12월 | 연합계

[추가 기능 2: 이상 지출 감지]
월별집계 갱신 시 이상 지출 감지 추가
- 각 매장의 이번 달 지출이 최근 3개월 평균의 2배 초과하면
  '이상 지출' 시트에 해당 매장·금액·초과율 표시

기존 코드는 그대로 유지하고 이 두 기능만 추가해줘.
```
- 정상 결과: 매장 드롭다운·거래처 드롭다운이 동작하고, 제출 버튼으로 제출이력이 저장되며, 월별집계 갱신 버튼으로 매장별 월간 집계가 생성됨
## 막히는 지점
- .xlsx 파일에서 Apps Script가 실행 안 됨: 구글 드라이브에서 새 구글 시트로 만들어 해결
- 팝업 차단으로 Apps Script 편집창이 안 열림: 크롬 팝업 허용
- 코드를 올바른 파일이 아닌 빈 시트에 저장: 올바른 파일에서 Apps Script 열기
