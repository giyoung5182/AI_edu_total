# 2. 1부 — 재료리스트 마감 (60분)
## 2-1. 도입 안내 (5분 이내)
- 오늘이 발주 마감일. 오늘 확정되지 않은 재료는 10월 판매에 사용 불가
- 작성 순서 준수. 재료 검색보다 목표 생산 개수와 판매 가격 입력이 우선
- 상품 페이지의 배송 예정일 확인 후 장바구니에 담기
## 2-2. 학생 작성 순서
**Step 1. 목표 생산 개수 입력**
- 몇 개를 만들어 팔 것인지 결정
- 숫자만 입력. 단위를 함께 입력할 경우 계산 오류 발생
**Step 2. 판매 가격 입력**
- 손님 1명이 1개를 살 때 낼 금액
- 중간발표에서 정한 가격이 있으면 그대로 입력 후 계산 결과를 보고 조정
**Step 3. 재료 검색 및 입력**
- 품명은 용량·수량·규격까지 기재 (예: 글리세린 투명 비누베이스 1kg)
- 구매 링크 필수 입력. 링크 없을 경우 발주 시 동일 상품 확인 불가
- 배송비는 항목마다 확인해 입력. 무료배송은 0 입력
- 수령처 표시. 상하는 재료는 팀원 집, 나머지는 센터
**Step 4. 계산 결과 확인**
- 단위 원가, 마진, 마진율 자동 계산
- 마진율 30% 미만 시 판매가 인상 / 재료 교체 / 구성 축소 중 선택
- 잔액이 음수일 경우 재료 삭감
## 2-3. 누락 빈발 항목
- 개별 포장재 (봉투, 용기, 상자)
- 라벨 스티커 용지
- 배송비 (항목별 개별 부과 여부)
- 일회용 장갑, 물티슈, 테이프 등 소모품
- 부스 진열용 소품
## 2-4. 팀별 개입 순서 및 지도 내용
- 착수가 늦은 팀부터 순회
**1순위 · HSH SOUP STUDIO**
- 재료 입력 0건, 재료 검색부터 착수 지원
- 목표 생산 개수 칸에 단위가 포함되어 계산 오류 발생 중 → 숫자만 재입력
- 판매 가격 미입력 → 입력 후 계산 결과 확인
- 필수 포함 항목 점검: 개별 포장재, 라벨, 소모품
**2순위 · 두바이상한 사람들**
- 재료 입력 0건
- 파일 하단 메모에 판매 목표 금액 210,000원, 목표 수량 40개 기재 → 정식 계산 칸으로 이전 (1개당 판매가 5,250원)
- 디저트 재료는 10월까지 보관 불가 → 가격만 조사해 기록, 실제 구매는 10월 진행
- 이번 발주 대상: 도시락 용기, 포장 끈, 스티커, 일회용 장갑, 위생 모자, 물티슈, 쓰레기봉투
- 핵심 재료(피스타치오 스프레드 등)의 용량 대비 단가 확인 → 한 통으로 도시락 몇 개 제작 가능한지 계산 → 결과에 따라 구성 품목 수 조정
**3순위 · 지름글로리**
- 재료 품명 1건만 입력, 금액 전체 미입력
- 원가 0원 상태에서 판매가 4,000원이 입력되어 마진율 100%로 표시 중 → 원가 입력 전 수치임을 설명
- 랜덤박스는 등급별 구성이 다르므로 평균 단위 원가로 계산

## 2-5. 마스터 결재 기준
- 총 지출액이 배송비 포함 150,000원 이하
- 목표 생산 개수와 판매 가격 입력 완료, 계산 정상 작동
- 마진율 30% 이상
- 전 항목 구매 링크 기재
- 전 항목 수령처 표시
- 포장재 및 소모품 포함
- 결재 완료 팀은 대기 없이 2부 워크시트 선행 시작

# 3. 2부 — 브랜드 3요소 확정 (30분)
## 3-1. 도입 설명
- 플리마켓 당일 다수의 부스가 나란히 설치되는 환경
- 무엇을 파는 곳인지 즉시 드러나지 않으면 손님의 발걸음이 멈추지 않음
- 브랜딩: 제품에 고유한 이름과 시각적 표시를 부여해 다른 부스와 구별되게 하는 작업
- 이번 시간은 종이 작업만 진행. 로고 디자인은 이후 회차에서 진행
## 3-2. 확정할 세 가지
**첫째, 공식 상호명**
- 3\~5음절 내외로 부르기 쉬울 것
- 이름만 듣고 무엇을 파는지 짐작 가능할 것
- 다른 팀과 겹치지 않을 것
- 현재 팀명 유지 또는 신규 작명 중 팀 내 결정
**둘째, 슬로건**
- 핵심 가치를 10글자 내외 한 문장으로 압축
- 구성: 핵심 혜택 + 약속
- 예시: "내 맘대로 고르는 달콤함", "오늘 하루의 향을 담다"
**셋째, 브랜드 컬러**
- 메인 컬러 1개, 보조 컬러 1개
- 메인 컬러는 부스 전체 인상, 보조 컬러는 강조 요소에 사용
