# 실습: 고치고 다시 확인하기

정리일: 2026-10-08 · 교육 에셋 N1355

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 웹앱을 직접 눌러 보며 어긋난 곳을 찾고, 세 토막 틀로 AI에게 하나씩 고쳐 달라고 합니다.
## 진행 단계
1. **어긋난 곳 찾기** — 직접 눌러 보며 반응이 없거나 결과가 엉뚱한 곳을 찾습니다.
2. **세 토막으로 말하기** — 무엇을 했더니 / 무엇이 나와야 하는데 / 무엇이 나왔다 순서로 적어 캔버스에 보냅니다.
- 입력할 내용(교안 예시):
```javascript
버튼을 눌렀는데 아무 반응이 없어. 누르면 입력한 내용으로 결과가 나오게 고쳐줘
```
- 빨간 에러 메시지가 뜨면 메시지를 그대로 복사해 붙여넣고 "이 에러가 떴어, 고쳐줘"라고 합니다.
3. **한 번에 하나씩** — 고쳐진 것을 확인한 다음 그다음 문제로 넘어갑니다.
4. **반복** — 마음에 들게 동작할 때까지 반복합니다(두세 번\~예닐곱 번 걸릴 수 있음).
## 막히는 지점
- '안 돼요', '이상해요'처럼 막연하게 말하면 막연한 답이 돌아옴
- 여러 개를 한꺼번에 시키면 어디가 고쳐지고 어디가 새로 망가졌는지 분간하기 어려움
