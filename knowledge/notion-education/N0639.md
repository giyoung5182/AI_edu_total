# 여기까지를 실습 화면에서 확인합니다 — AI 원리 실험소(15분)

정리일: 2026-10-08 · 교육 에셋 N0639

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설명 파트까지의 내용(다음 토큰 예측, 컨텍스트 윈도우, 환각, 새 대화로 옮기기)을 AI 원리 실험소 화면에서 직접 눌러 보며 확인합니다.
## 진행 단계
1. **실험소 열기** — Claude에 로그인한 상태에서 교안의 실험소 주소를 새 탭에서 엽니다. 로그인하지 않으면 AI 기능이 동작하지 않음
2. **복제** — 오른쪽 위 공유 버튼 → Copy(복제)로 내 것으로 만들기. Copy하면 AI가 켜지고 사용량은 내 계정에서 나감
3. **AI 기능 확인** — 실험1 → \[내 문장으로 직접\]에 `이번 리뉴얼의 목표는` 등 아무 문장을 쓰고 \[다음 후보 뽑기\] 클릭 → CLAUDE 사용 허용을 켜기
4. **탭 5개를 순서대로** — ① 다음 말 고르기(3분): 맨 위 후보만 계속 고르면 어떤 문장이 되는지 / ② 컨텍스트 윈도우(4분): 앞에서 정한 규칙이 어떻게 밀려나는지 / ③ 할루시네이션(3분): 조건만 바꿨을 때 답이 갈리는 모습 / ④ 새 대화로 옮기기(5분): 요약해서 옮길 때 규칙이 살아남는지 / ⑤ 정리 퀴즈(3분): 열한 문항
## 막히는 지점
- 링크로 연 화면은 보기만 되고 AI 기능이 꺼져 있음 → Copy 필요
- CLAUDE 사용 허용을 켜지 않으면 AI 기능이 적용되지 않음
