## 🎨 6. Part 3. 이미지 생성 모델 완전 비교 — 어떤 모델을 언제 써야 하는가
> ⏱ 소요 시간: 12:00 \~ 12:30 \| 전원 공통 \| 강사 설명 + 선택 실습<br>💡 **이 섹션의 목표:** "이미지 생성 AI"는 하나가 아닙니다. 2026년 현재 10개 이상의 모델이 각자 다른 강점으로 경쟁 중입니다. 오늘 우리 업무에 맞는 도구를 정확히 고르는 눈을 기릅니다.
### 6-0. 먼저 알아야 할 것 — 이미지 생성 AI의 작동 원리
모든 이미지 생성 AI는 **확산 모델(Diffusion Model)** 이라는 동일한 핵심 기술을 씁니다. 그런데 왜 결과물이 이렇게 다를까요?
```plain text
이미지 생성 AI의 공통 작동 원리:

랜덤 노이즈(점묘화처럼 흐릿한 상태)에서 시작
        ↓
텍스트 프롬프트가 "이 노이즈를 어떤 방향으로 정제할지" 안내
        ↓
수십~수백 번의 단계를 거쳐 노이즈 → 이미지로 수렴
        ↓
최종 이미지 완성

모델마다 결과가 다른 이유:
① 학습 데이터의 종류와 양 (어떤 이미지를 얼마나 봤는가)
② 프롬프트 해석 방식 (언어 이해 모델의 성능)
③ 학습 목표 (예술적 감성 vs 사실적 정확도 vs 텍스트 정확도)
④ 후처리 방식 (색상 보정, 해상도 향상 등)

→ 즉, "최고의 모델"은 없습니다.
   "내 작업에 가장 맞는 모델"을 고르는 것이 핵심입니다.
```

#### 🥇 모델 1. ChatGPT GPT Image (구 DALL-E) — 우리 교육의 메인 도구
**한 줄 요약:** 프롬프트를 가장 잘 이해하고, 복잡한 지시를 가장 정확하게 따르는 모델
```plain text
핵심 특징:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 언어 이해 최강: "왼쪽에 대리석 카운터, 오른쪽에 브러시드 메탈
  선반, 천장에는 LED 코브 조명"이라고 하면 정확히 그대로 생성
• 대화형 반복 수정: ChatGPT와 같은 창에서 대화하듯 수정 가능
• 텍스트 렌더링 우수: 영문 사인, 라벨, 숫자 정확도 높음
• 맥락 유지: 같은 채팅 내에서 이전 이미지 스타일 참조 가능

전시 디자인 실무에서 최강인 이유:
• "재질은 유지하고 조명만 바꿔줘" → 정확히 그대로 실행
• 복잡한 6요소 프롬프트 전체를 한 번에 처리
• RCTCK 프롬프트 구조와 완벽 호환
• 기획팀 제안서용 이미지부터 디자인팀 렌더링까지 범용

한계:
• 한글 텍스트는 여전히 왜곡 (→ PPT에서 별도 삽입)
• 특정 브랜드 로고 생성 불가
• 부분 수정(Inpainting) 기능 제한적

접근 방법: ChatGPT Plus ($20/월) 또는 무료 계정 일일 제한 내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
**전시 디자인 추천 프롬프트 구조:**
```plain text
[역할 부여] + [6요소: 공간유형+스타일+재질+조명+구도+화질]
→ 가장 높은 정확도로 원하는 공간 이미지 생성
```

#### 🥈 모델 2. Midjourney v7 — 예술적 감성과 포토리얼리즘의 정점
**한 줄 요약:** 아름다움으로는 따라올 모델이 없는, 감성적 비주얼의 왕
```plain text
핵심 특징:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 시각적 퀄리티 최강: AI가 생성할 수 있는 가장 '예쁜' 이미지
• 영화적 분위기: 드라마틱한 조명, 시네마틱 구도 자동 적용
• 포토리얼리즘 1위: 실제 사진과 구분하기 어려운 현실감
• 스타일 일관성: 같은 분위기의 여러 이미지를 쉽게 유지
• 2026년 웹 UI 완비: 더 이상 Discord 불필요

전시 디자인에서 Midjourney가 빛나는 순간:
• 클라이언트에게 "와우(WOW)" 반응이 필요한 제안서 첫 장
• 럭셔리·프리미엄 브랜드의 감성적 무드보드
• 전시 공간의 야간·이벤트 분위기 시각화
• 아트 갤러리, 럭셔리 쇼룸 컨셉 이미지

한계:
• 복잡한 구체적 지시(재질 정확도, 정확한 구도) 따르기 어려움
  → "왼쪽 벽에 대리석"을 지시해도 무시하는 경우 있음
• 텍스트 렌더링 취약 (텍스트 30~40% 정확도)
• 무료 플랜 없음 (최소 $10/월)
• 프롬프트가 짧고 감성적일수록 잘 작동
  → 6요소 구조 대신 "분위기 키워드 위주" 프롬프팅 필요

접근 방법: midjourney.com (웹 가입) | Basic $10/월, Standard $30/월
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
**Midjourney 전용 프롬프트 스타일 (기술 지시 대신 감성 지시):**
```plain text
❌ ChatGPT 방식 (Midjourney에서 잘 안 됨):
"Calacatta marble floor, 2800K warm spotlights,
 35mm eye-level, golden ratio composition..."

✅ Midjourney 방식 (감성·분위기 중심):
"luxury exhibition showroom, warm golden hour light,
 silent before opening, marble and brass, editorial,
 architectural digest cover shot, cinematic --ar 16:9 --v 7"

핵심 파라미터:
--ar 16:9    → 가로세로 비율 (제안서용 와이드)
--ar 4:3     → 일반 무드보드 비율
--v 7        → 최신 Midjourney v7 사용
--style raw  → AI 자동 미화 줄이고 프롬프트 충실도 높임
--s 250      → 스타일화 강도 (0~1000, 낮을수록 사실적)
```

### 6-6. DALL-E의 작동 원리 — 왜 프롬프트 정확도가 결과를 결정하는가

```plain text
ChatGPT GPT Image 생성 과정:

텍스트 프롬프트 입력
        ↓
GPT-4o가 언어적으로 완전히 파싱 및 이해

        ↓
```

> **Q11. AI 결과를 믿어도 될까요?A.** AI는 경험 있는 PM의 보조 도구입니다. AI가 만든 초안을 나용한 PM이 검토·수정하는 방식이 최적입니다. AI가 초안을 5분 안에 만들고, 사람이 3분 검토하면 총 8분. 처음부터 수기로 작성하는 데 걸리는 2시간과 비교해보세요.
> **Q12. 사진 정보가 외부로 나가지 않나요?A.** Gemini는 대화 기록을 Google이 서비스 개선 목적으로 활용할 수 있습니다. 실습에서는 공개 가능한 사진을 사용합니다. 내부 기밀 현장은 회사 AI 사용 정책을 먼저 확인하세요. 민감 정보가 포함된 사진은 Gemini 설정에서 '활동 저장' 옵션을 끄는 방법도 있습니다.
> **Q13. 나이가 있어서 잘 할 수 있을지 모르겠어요A.** 오늘 배울 건 딱 3가지입니다. ① 사진 올리기 ② 질문 붙여넣기 ③ 결과 보기. 카카오톡 쓸 수 있다면 Gemini도 쓸 수 있습니다. 현장에서 가장 실용적이고 즉각적인 효과를 볼 수 있는 분이 바로 공무팀입니다. 오늘 첫 성공 경험을 만드는 것이 목표입니다.

## 🎓 마무리 — 오늘 교육의 핵심 7줄 요약
```plain text
1. ChatGPT는 이미지를 '만드는' 도구,
   Gemini는 이미지를 '읽고 분석하는' 도구입니다.
   두 도구를 연계하면 최강 워크플로우가 완성됩니다.

2. 좋은 프롬프트는 RCTCK 5요소로 구성됩니다.
   Role(역할) + Context(맥락) + Task(과업)
   + Constraints(제약) + Knowledge(참조자료)
   이 5개를 채울수록 AI 출력 품질이 극적으로 달라집니다.

3. AI를 하나만 쓰지 마세요.
   Gemini(분석) → ChatGPT(생성) → Gemini(텍스트) 파이프라인으로
   각 AI의 강점만 활용하면 혼자서는 불가능한 품질이 나옵니다.

4. 프롬프트는 6요소 구조로 씁니다.
   [공간유형]+[스타일]+[재질]+[조명]+[구도]+[화질]
   이 6가지를 채울수록 원하는 이미지에 가까워집니다.

5. 한 번에 완벽하려 하지 마세요.
   발산(방향 탐색)으로 시작하고, 체이닝(수렴 정제)으로 완성하세요.
   평균 3~5회 체이닝으로 90%+ 품질이 달성됩니다.

6. Gemini는 무료, 지금 당장 쓸 수 있습니다.
   현장 사진 1장 올리고 질문하는 것부터 시작하세요.

7. 내일 당장 황금 프롬프트 1가지만 써보세요.
   RCTCK 중 Role 하나만 추가해도 결과가 달라집니다.
   첫 번 쓰는 게 가장 어렵습니다. 두 번째부터는 자연스럽습니다.
```
