# 시작 전에 꼭 알아야 할 것
## 1. 앱은 무료지만 GPT나 클로드 구독이 필요합니다.
오픈모션 자체는 무료로 받고 쓸 수 있습니다. 다만 실제로 영상을 만드는 건 클로드 코드나 코덱스가 담당하기 때문에, 둘 중 하나의 구독이 있어야 작동합니다. 앱만 받아두고 왜 안 되지 하고 헤매는 분들이 여기서 막힙니다.
이미 클로드나 챗지피티를 유료로 쓰고 계시다면 그걸 그대로 연결하면 됩니다. API 키를 따로 발급받아 붙이는 과정은 없습니다.
---
# 가장 중요한 것부터, 퀄리티는 소재가 만듭니다
**상업적으로 쓸 만한 퀄리티가 나오려면, 화면 녹화와 이미지 자료를 제대로 준비해서 넣어야 합니다.** <br>이게 이 가이드에서 제일 중요한 부분입니다.
오픈모션은 없는 걸 상상해서 그려주는 툴이 아닙니다. 여러분이 준 소재를 정확하게 배치하고 움직이게 만들어주는 툴입니다. 그래서 소재의 품질이 결과물 품질의 상한선을 정합니다.
공식 예제 영상들이 좋아 보이는 이유가 여기 있습니다. <br>배경 사진, 제품 화면, 로고가 전부 진짜 파일이라서 진짜처럼 보이는 겁니다. AI가 그린 게 아닙니다.
## 준비해야 할 것
- **로고**: 배경이 투명한 PNG. JPG로 넣으면 흰 박스가 따라붙습니다
- **제품 화면 녹화**: 실제로 쓰는 장면을 화면 녹화로 찍어두세요. 마우스 움직임은 천천히, 불필요한 클릭 없이. 맥은 Command+Shift+5, 윈도우는 Windows키+G로 녹화합니다
- **제품 스크린샷**: 화면 녹화가 어려운 구간은 정지 화면으로. 브라우저 창은 정리해서 북마크바나 탭이 안 보이게 찍습니다
- **배경 이미지**: 필요하면 고해상도 사진. 저화질 이미지를 넣으면 그 부분만 티가 납니다
## 자주 하는 오해!!
**소재를 대충 주고 프롬프트로 때우려고 하면 퀄리티가 안 올라갑니다.** 화면 녹화를 흔들리게 찍거나, 로고를 캡처해서 넣거나, 저화질 이미지를 쓰면 그 부분에서 결과물이 무너집니다.
반대로 소재만 제대로 준비하면 프롬프트가 평범해도 결과가 상업적으로 쓸 만하게 나옵니다.

# 1단계. 앱 받기
1. 브라우저에서 openmotion.design 접속
2. 오른쪽 위 Download 버튼 클릭
3. 버튼이 알아서 내 기기에 맞는 파일을 골라줍니다. 안 맞으면 버튼 아래 Apple silicon / Intel / Windows 중에서 직접 선택
4. 받은 파일 실행해서 설치
사이트가 전부 영어라 불편하시면, 페이지 아무 데나 마우스 오른쪽 클릭 후 한국어로 번역을 누르세요. 크롬과 엣지 모두 됩니다.
맥에서 확인되지 않은 개발자 경고가 뜨면, 시스템 설정의 개인정보 보호 및 보안 항목 맨 아래에서 확인 없이 열기를 눌러주세요.
---
# 2단계. AI 연결하기
앱을 처음 열면 오른쪽에 채팅 패널이 보입니다. 그 아래에 드롭다운 두 개가 있어요.
1. 왼쪽 드롭다운에서 Claude 또는 Codex 선택
2. 오른쪽 드롭다운에서 모델 선택 (처음이면 기본값 그대로 두셔도 됩니다)
3. 로그인 창이 뜨면 평소 쓰는 계정으로 로그인
패널 위에 초록색 점과 함께 연결 상태가 표시되면 준비 완료입니다.
---
# 3단계. 소재 넣기
준비한 화면 녹화와 이미지를 앱에 먼저 올립니다.
1. 채팅 입력창 왼쪽의 + 아이콘으로 파일 첨부
2. 프롬프트 안에서 그 첨부물을 지목
프롬프트에서 첨부물을 부를 때는 대괄호 안에 이름을 넣습니다.
```javascript
[attachment-logo]
[attachment-screen-recording]
```
소재를 먼저 올려두고 장면을 만들기 시작하는 게 순서입니다. 장면부터 만들고 나중에 소재를 끼워 넣으면 배치를 다시 잡아야 합니다.
---
# 4단계. 내 소재에 맞는 프롬프트 뽑기
무슨 문장을 써야 할지 막막하시면, 아래를 클로드나 챗지피티에 그대로 붙여넣으세요. 만들고 싶은 걸 말하면 장면별 프롬프트를 순서대로 만들어줍니다.
```javascript
당신은 모션그래픽 영상의 장면별 제작 지시서를 작성하는 전문가입니다.

저는 OpenMotion이라는 앱을 사용합니다. 이 앱은 장면을 하나씩 순서대로 만들어 쌓는 방식이고, HTML과 CSS로 화면을 구성한 뒤 영상으로 렌더링합니다. 따라서 지시가 구체적이고 시각적일수록 결과가 정확합니다.

제가 만들고 싶은 영상과 제가 가진 소재를 말씀드리면, 다음 규칙에 따라 장면별 프롬프트를 작성해주세요.

규칙:
1. 전체 길이를 장면 5~8개로 나눌 것. 장면 하나는 1~2초 분량
2. 각 장면은 반드시 "Build scene N: "으로 시작하는 영어 문장으로 작성
3. 첫 장면 외에는 "Continues from scene N-1: "을 붙여 앞 장면과 이어지게 할 것
4. 각 장면마다 배경색, 요소의 위치, 움직이는 방향, 등장 방식, 소요 시간을 명시할 것
5. 글자를 넣을 때는 정확한 문구와 색, 굵기, 크기를 지정할 것
6. 제가 가진 소재를 쓸 자리는 [attachment-이름] 형태로 표기하고, 어느 장면에서 어떤 소재를 써야 하는지 알려줄 것
7. 제가 준비해야 할 소재가 더 있다면 먼저 알려줄 것
8. 화려한 효과보다 정확한 배치와 자연스러운 타이밍을 우선할 것
9. 결과는 장면별로 번호를 매겨, 각각 복사해서 바로 붙여넣을 수 있는 형태로 출력할 것

제가 만들고 싶은 영상:
(여기에 원하는 영상을 적어주세요)

제가 가진 소재:
(로고, 화면 녹화, 스크린샷 등 준비한 것을 적어주세요)
```

# 5단계. 고치기
영상이 나온 뒤에 마음에 안 드는 부분은 캔버스에서 직접 고칩니다. 이게 원클릭 생성기와 가장 다른 점입니다.
고칠 수 있는 것: 레이어, 등장 타이밍, 이징(움직임의 가속과 감속), 색상, 카메라 움직임, 사운드
말로 고쳐도 됩니다. 채팅창에 3번 장면 텍스트가 너무 빨리 사라져, 0.5초 더 유지해줘 처럼 요청하면 반영됩니다.
상업적으로 납품할 결과물이라면 이 단계에 시간을 제일 많이 쓰셔야 합니다. 첫 결과물을 그대로 쓰는 경우는 거의 없습니다.

# 자주 막히는 부분
## 결과가 싸구려처럼 보일 때
프롬프트 문제가 아니라 소재 문제인 경우가 대부분입니다. 화면 녹화 화질, 로고 파일 형식, 배경 이미지 해상도를 먼저 점검하세요.
## 결과가 뭉개지거나 엉뚱하게 나올 때
장면 하나에 너무 많은 걸 요청한 경우입니다. 장면을 둘로 쪼개세요.
## 움직임이 너무 빠르거나 느릴 때
프롬프트에 초 단위를 명시하세요. over 0.8 seconds, hold for 1 second 처럼 씁니다.
## 글자가 이상하게 나올 때
한글은 폰트 문제가 생길 수 있습니다. 프롬프트에서 폰트를 지정하거나, 글자 없이 배경만 만들고 자막은 편집 프로그램에서 얹는 방법도 있습니다.
## 한 번에 완성하려고 할 때
가장 흔한 실패 원인입니다. 장면 하나 만들고 확인, 다음 장면 만들고 확인. 이 순서를 지키셔야 합니다.
