# 2단계 직접 해보기: 더미 데이터 30행 만들기

정리일: 2026-10-08 · 교육 에셋 N1308

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실무 데이터 대신 같은 모양의 가상 데이터를 만들어 이후 웹앱의 재료로 씁니다.
## 진행 단계
1. **칼럼 정하기** — 본인 업무에서 자주 보는 표의 칼럼만 떠올립니다. 교안의 예시를 그대로 써도 됩니다.
2. **더미 데이터 요청**
```javascript
나는 교육기관 CDMO 사업 담당자야. 수주 분석용 더미 데이터가 필요해.
아래 칼럼으로 가상의 데이터 30행을 만들어줘. (실제 데이터 아님, 학습용)
칼럼: 고객사명 / 프로젝트명 / 수주금액 / 생산원가 / 예상납기(주) / 수율(%)
CSV 형식으로 출력해줘.
```
3. **복사해 두기** — 생성된 더미 데이터를 복사해 둡니다. 다음 단계 웹앱에 붙여넣습니다.
## 막히는 지점
- 실제 고객사명·수주 금액 등은 절대 입력하지 않습니다.
