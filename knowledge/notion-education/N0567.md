# 2-1. Excel로 데이터 구조 확인

정리일: 2026-10-08 · 교육 에셋 N0567

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
파일을 열어 어떤 컬럼이 있고 어떤 질문에 답할 수 있는 데이터인지 파악합니다.
## 진행 단계
1. **프롬프트 입력** — 첫 시트를 읽고 데이터 구조를 설명하도록 요청합니다.
- 입력할 내용:
```javascript
실습파일/교육기관생산설비데이터_실습.xlsx의 첫 시트를 읽고 데이터 구조를 설명해줘.

다음 항목을 포함해줘.
1. 전체 행 수와 컬럼 수
2. 주요 컬럼 8개와 쉬운 설명
3. 이 데이터로 분석할 수 있는 질문 5개
4. 분석 전에 확인해야 할 주의사항
```
