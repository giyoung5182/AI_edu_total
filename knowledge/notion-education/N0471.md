# 실습 3. 나만의 채팅방 만들기 — 프롬프트 조립

정리일: 2026-10-08 · 교육 에셋 N0471

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
공통 골격에 내 선택(채팅방 이름, 말투, 스타일 블록)을 채워 프롬프트를 조립하고, Claude Code로 AI 채팅방을 만듭니다.
## 진행 단계
1. **선택** — 채팅방 이름, 말투를 정하고 스타일 블록(슬랙형/카카오톡형/라인형) 중 하나를 고름
2. **프롬프트 조립** — 메모장에서 공통 골격 + 빈칸 두 개 + 스타일 블록 붙이기
- 입력할 내용(공통 골격 일부):
```plain text
FastAPI로 AI 채팅 웹 서비스를 만들어 주세요. 요구사항입니다.

1. 브라우저에서 열리는 채팅 페이지를 만들어 주세요.
   입력창에 질문을 쓰고 전송하면 대화 목록에 질문과 답변이
   말풍선으로 쌓입니다.
   페이지 최상단에는 가로 메뉴바를 두고, 지금은 "채팅" 메뉴
   하나만 넣어 주세요.
   메뉴바 아래에 채팅방 이름을 표시해 주세요.
   채팅방 이름: ______

2. 채팅 화면의 스타일입니다.
   [스타일 블록]

3. 답변은 Gemini API(모델: gemini-2.5-flash)가 생성합니다.
   API 키는 .env 파일의 GEMINI_API_KEY 값을 읽어 사용하고,
   코드에 키를 직접 적지 마세요.
   말투: ______
(이하 교안 참고)
```
1. **Claude Code에 입력** — 터미널 A에 입력하고 승인 요청을 읽으며 진행
2. **서버 실행** — 터미널 B에서 Claude Code가 알려준 서버 실행 명령 입력
3. **채팅** — 브라우저에서 [개별 링크 제외] 을 열고 "안녕하세요" 입력, 정한 말투로 답이 오는지 확인
4. **로그 확인** — 질문 한 건이 로그 몇 줄로 나타나는지 세어 봄
5. **\[예측\]** — 서버를 끄면 새로고침 때 어떻게 될지 예측해 적음
6. **\[확인\]** — 터미널 B에서 Ctrl+C로 서버를 끄고 새로고침해 예측과 비교, 서버를 다시 켜면 채팅방이 되살아남
## 막히는 지점
- 페이지는 열리는데 답변이 안 옴 → .env 키 앞뒤 공백·따옴표 제거 후 서버 재시작
- 401/403 에러 로그 → 키가 유효하지 않음, 배부받은 키와 대조
- Address already in use → 터미널 B에서 Ctrl+C 후 재실행, 안 되면 8001 포트 실행 요청
- 스타일이 고른 블록과 다르게 나옴 → 정상 편차, 구체적으로 고쳐 달라고 요청
