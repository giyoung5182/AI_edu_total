# [실습 2] 월간 원가 보고서 자동 생성

정리일: 2026-10-08 · 교육 에셋 N1458

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
예산 집행 데이터를 분석해 "보고서" 시트를 자동으로 만드는 매크로를 ChatGPT로 만들어 실행합니다.
## 진행 단계
1. **실습 파일 열기** — 「월간예산집행_보고서.xlsx」를 엽니다(현장 3곳, 5일간의 집행 데이터 55건).
2. **ChatGPT에 프롬프트 입력**
- 입력할 내용:
```markdown
## 역할
당신은 엑셀 VBA 전문가입니다.

## 요청
건설 프로젝트 월간 예산 집행 현황 보고서를 자동 생성하는 VBA 매크로를 만들어줘.

## 데이터 구조 ("데이터" 시트)
- A열: 집행일자
- B열: 현장명 (A현장, B현장, C현장)
- C열: 공종
- D열: 예산금액
- E열: 집행금액
- F열: 집행상태 (정상/주의/초과)
- G열: 초과사유

## 매크로 기능
1. "보고서" 시트를 새로 생성
2. 상단: 보고서 제목 "월간 예산 집행 현황 보고서" + 오늘 날짜
3. 중단: 집행 통계 요약 (총 예산, 총 집행, 집행률, 정상/주의/초과 각 건수)
4. 하단: 초과 항목만 필터링한 목록

## 조건
- 한글 주석 포함
- 기존 "보고서" 시트가 있으면 삭제 후 새로 생성

## 출력
VBA 코드만 출력해줘.
```
3. **코드 붙여넣고 실행** — 코드를 모듈에 붙여넣기 → Alt+F8 → 실행
4. **확인** — "보고서" 시트가 자동 생성되었는지 확인합니다.
## 막히는 지점
- 오류가 나면 오류 메시지를 그대로 ChatGPT에 보내 수정된 코드를 받음(교안의 디버깅 프롬프트 템플릿: 오류 메시지 + 코드 + 상황\[엑셀 버전·시트명·데이터 범위\])
- 저장 시 .xlsm 형식으로 저장
