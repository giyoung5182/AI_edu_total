# 팀에게 종합 보고 대시보드 만들기

정리일: 2026-10-08 · 교육 에셋 N0410

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
메인 에이전트가 두 에이전트를 불러 일을 나눠 맡기고, 결과를 하나의 HTML 대시보드로 합칩니다.
## 진행 단계
1. **에이전트 등록 확인** — `.claude/agents` 폴더에 보상 검토 에이전트와 면책 점검 에이전트가 있는지, 재시작을 했는지 확인합니다.
2. **종합 보고 요청** — 입력창에 입력하고 엔터를 누릅니다.
- 입력할 내용:
```plain text
이번 주 사고 접수 현황을 종합 보고 대시보드로 만들어줘.
먼저 보상 검토 에이전트로 data 폴더의 사고 건들을 건별 검토하고,
다음 면책 점검 에이전트로 면책 가능성이 있는 건을 따로 정리해줘.

두 결과를 합쳐서, 한눈에 보는 HTML 대시보드 파일로 만들어줘.
- 판정별 건수(보상가능, 추가확인, 면책, 심사보류)를 요약해서 보여줘
- 건별 보상 검토 결과를 표로 정리해줘
- 면책 가능성이 있는 건은 눈에 띄게 표시해줘
- 결과는 dashboard.html 파일로 저장해줘

원본 자료에 없는 내용은 임의로 만들지 말고 '확인 필요'로 표시해줘.
```
- 정상 결과: 화면에 에이전트가 차례로 호출되는 것이 보입니다. 파일 저장 여부를 물으면 1번(yes) 입력.
1. **결과물 확인** — 실습 폴더에 생긴 `dashboard.html`을 두 번 눌러 브라우저에서 대시보드를 확인합니다.
