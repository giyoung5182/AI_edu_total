# 실습: 동작 붙이기

정리일: 2026-10-08 · 교육 에셋 N1457

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
3교시에서 받아 둔 design.md와 HTML 파일을 Gemini Canvas에 넣어, 보기만 하던 화면을 입력하면 반응하는 웹앱으로 바꿉니다.
## 진행 단계
1. **Canvas 켜기** — Gemini Canvas를 캔버스 모드로 켭니다.
2. **파일 첨부** — design.md와 HTML 파일을 입력창에 그대로 첨부합니다.
3. **동작 요청** — 한 마디로 요청합니다.
- 입력할 내용:
```javascript
이 HTML 디자인 코드를 절대 변형하지 않고, 있는 그대로 사용하여라.
이를 동작하는 웹앱으로 만들어줘.
```
- 정상 결과: 옆 화면에 3교시의 디자인이 그대로 뜨고, 입력칸에 적으면 받아들이고 버튼을 누르면 반응함
4. **확인** — 눌렀을 때 실제로 반응하는지 확인합니다.
