# 실습 1: 매크로 기록기로 첫 자동화

정리일: 2026-10-08 · 교육 에셋 N1491

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
클릭을 그대로 코드로 기록하는 매크로 기록기로 코딩 없이 첫 매크로를 만들고 버튼에 연결합니다.
## 진행 단계
1. **문제1 서식 통일 매크로 기록** — 개발 도구 → 매크로 기록 → 이름 `서식정리` → 1행 굵게+배경색, 표 전체 모든 테두리, 열 머리글 경계선 더블클릭 → 기록 중지 → 복사본 시트에서 서식 지운 뒤 매크로 실행
- 정상 결과: 서식을 지웠던 복사본 시트에 1초 만에 동일한 서식이 적용됨
2. **문제2 절대 참조 vs 상대 참조** — \[상대 참조로 기록\] 끈 상태로 `절대테스트`(A1 노란색), 켠 상태로 `상대테스트`(A1 파란색) 기록 → C5 셀을 클릭한 상태에서 각각 실행
- 정상 결과: 절대테스트는 A1, 상대테스트는 C5가 색칠됨
3. **문제3 버튼 만들기** — 삽입 → 도형 → 둥근 사각형 → "서식 정리" 입력 → 우클릭 → 매크로 지정 → `서식정리`
4. **직접 풀어보는 예제** — 인쇄 영역 설정, 열 숨기기, 틀 고정 등 자주 하는 클릭 2\~3개를 나만의 매크로로 기록하고 버튼까지 연결
5. **기록된 코드 들여다보기** — Alt+F11 → Module1에서 코드 확인(읽기만)
