## 1-2. 발산 먼저, 수렴 나중 — AI 활용의 황금 원칙

[원본 이미지 제외]
AI를 쓸 때 가장 많이 하는 실수:
```plain text
글 작성 요청
→ "이게 아닌데..." → "조금 수정해줘"
→ 또 수정 요청 → 또 수정...
→ 처음 방향에서 벗어나지 못하고 60% 수준에서 멈춤
```
**올바른 방법 — 발산 먼저, 수렴 나중:**
```plain text
[발산 단계] 여러 방향을 먼저 넓게 탐색
"A안(따뜻한 느낌), B안(세련된 느낌), C안(유머 있는 느낌) 3가지 만들어줘"
→ 가장 마음에 드는 방향 선택

[수렴 단계] 선택된 방향을 단계적으로 정교화
→ 말투 조정 → 분량 조정 → 세부 내용 완성
→ 90%+ 품질 달성
```

## 1-3. 체이닝 — 60% → 90% 품질 높이기
[원본 이미지 제외]
**체이닝 원칙:**
- 한 번에 1\~2가지만 수정 요청
- "전부 다시 써줘"는 방향을 잃음
- 3\~5번 수정으로 90%+ 달성 가능
**체이닝 4단계 예시:**
```plain text
STEP 1. 방향 탐색 (60%)
"이번 주 여름 이벤트 홍보글 A안, B안, C안 3가지 만들어줘"
→ B안 선택

STEP 2. 분위기 정교화 (→ 75%)
"B안 방향으로, 좀 더 따뜻하게 바꿔줘. 나머지는 그대로."

STEP 3. 내용 세부 조정 (→ 85%)
"우리 가게 30년 전통 부분을 더 강조해줘."

STEP 4. 마무리 (→ 90%+)
"마지막에 방문 유도 문구 하나만 추가해줘."
```

### 유형 1. 신메뉴 / 신상품 소개
```plain text
[R] 너는 동네 소상공인 SNS 마케터야.
    자연스럽고 광고 같지 않은 홍보글을 잘 써.

    이번에 [신메뉴/신상품]을 출시했어.
    가격은 [가격], 특징은 [특징 1~2가지].

[T] 인스타그램 포스팅 글을 써줘.

[C] 3문장 이내, 이모티콘 2개 이하, 해시태그 5개 포함.

[K] 기대감을 높이는 밝은 느낌으로. 손님이 먹고 싶어지게.
```
**외식업 예시:**
```plain text

가격은 10,000원이고, 30년 전통 육수로 만든 시원한 맛이 특징이야.

인스타그램 포스팅 글을 써줘.
3문장 이내, 이모티콘 2개 이하, 해시태그 5개 포함.
여름 더위를 날려버리는 시원하고 상쾌한 느낌으로.
```

## 3-1. 리뷰 답변이 왜 중요한가
리뷰 답변은 리뷰를 남긴 분만 보는 게 아닙니다. **새로 방문할 손님들이 더 많이 봅니다.**

AI 활용 팁




감사·칭찬 리뷰

진심 감사 + 재방문 기대

리뷰에서 언급된 구체적 내용 다시 언급

사과 + 개선 의지 강조

프롬프트에 "변명 없이"라고 명시




악성 리뷰 (사실 다름)

## 4-2. AI 이미지 생성 원리 — 쉽게 이해하기
**확산 모델(Diffusion Model) 작동 원리:**
```plain text
① 처음엔 텔레비전 '모래알(노이즈)'처럼 흐릿한 화면에서 시작
② 내가 입력한 텍스트 지시가
   "이 노이즈를 어떤 방향으로 정리할지" 안내
③ 수십~수백 번의 단계를 거쳐
   노이즈 → 선명한 이미지로 완성

비유: 흐릿한 사진을 점점 선명하게 현상하는 것처럼.
내가 말한 내용이 현상 방향을 결정합니다.
```
[원본 이미지 제외]
**핵심 원리:**
- 구체적으로 말할수록 원하는 결과가 나온다
- 모델마다 결과가 다른 이유: 학습 데이터·언어 이해력·학습 목표가 다르기 때문
- "최고의 모델"은 없다 — "내 목적에 맞는 모델"을 고르는 것이 핵심

#### 🥇 모델 1. ChatGPT GPT Image (구 DALL-E) — 우리 교육의 메인 도구
**한 줄 요약:** 프롬프트를 가장 잘 이해하고, 복잡한 지시를 가장 정확하게 따르는 모델
```plain text
핵심 특징:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 언어 이해 최강: "왼쪽에 대리석 카운터, 오른쪽에 브러시드 메탈
  선반, 천장에는 LED 코브 조명"이라고 하면 정확히 그대로 생성
• 대화형 반복 수정: ChatGPT와 같은 창에서 대화하듯 수정 가능
• 텍스트 렌더링 우수: 영문 사인, 라벨, 숫자 정확도 높음
• 맥락 유지: 같은 채팅 내에서 이전 이미지 스타일 참조 가능

전시 디자인 실무에서 최강인 이유:
• "재질은 유지하고 조명만 바꿔줘" → 정확히 그대로 실행
• 복잡한 6요소 프롬프트 전체를 한 번에 처리
• RCTCK 프롬프트 구조와 완벽 호환
• 기획팀 제안서용 이미지부터 디자인팀 렌더링까지 범용

한계:
• 한글 텍스트는 여전히 왜곡 (→ PPT에서 별도 삽입)
• 특정 브랜드 로고 생성 불가
• 부분 수정(Inpainting) 기능 제한적

접근 방법: ChatGPT Plus ($20/월) 또는 무료 계정 일일 제한 내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
**전시 디자인 추천 프롬프트 구조:**
```plain text
[역할 부여] + [6요소: 공간유형+스타일+재질+조명+구도+화질]
→ 가장 높은 정확도로 원하는 공간 이미지 생성
→ 체이닝 3~4회로 90%+ 달성 가능
```

#### 🥈 모델 2. Midjourney v7 — 예술적 감성과 포토리얼리즘의 정점
**한 줄 요약:** 아름다움으로는 따라올 모델이 없는, 감성적 비주얼의 왕
```plain text
핵심 특징:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 시각적 퀄리티 최강: AI가 생성할 수 있는 가장 '예쁜' 이미지
• 영화적 분위기: 드라마틱한 조명, 시네마틱 구도 자동 적용
• 포토리얼리즘 1위: 실제 사진과 구분하기 어려운 현실감
• 스타일 일관성: 같은 분위기의 여러 이미지를 쉽게 유지
• 2026년 웹 UI 완비: 더 이상 Discord 불필요

전시 디자인에서 Midjourney가 빛나는 순간:
• 클라이언트에게 "와우(WOW)" 반응이 필요한 제안서 첫 장
• 럭셔리·프리미엄 브랜드의 감성적 무드보드
• 전시 공간의 야간·이벤트 분위기 시각화
• 아트 갤러리, 럭셔리 쇼룸 컨셉 이미지

한계:
• 복잡한 구체적 지시(재질 정확도, 정확한 구도) 따르기 어려움
  → "왼쪽 벽에 대리석"을 지시해도 무시하는 경우 있음
• 텍스트 렌더링 취약 (텍스트 30~40% 정확도)
• 무료 플랜 없음 (최소 $10/월)
• 프롬프트가 짧고 감성적일수록 잘 작동
  → 6요소 구조 대신 "분위기 키워드 위주" 프롬프팅 필요

접근 방법: midjourney.com (웹 가입) | Basic $10/월, Standard $30/월
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
**Midjourney 전용 프롬프트 스타일 (기술 지시 대신 감성 지시):**
```plain text
❌ ChatGPT 방식 (Midjourney에서 잘 안 됨):
"Calacatta marble floor, 2800K warm spotlights,
 35mm eye-level, golden ratio composition..."

✅ Midjourney 방식 (감성·분위기 중심):
"luxury exhibition showroom, warm golden hour light,
 silent before opening, marble and brass, editorial,
 architectural digest cover shot, cinematic --ar 16:9 --v 7"

핵심 파라미터:
--ar 16:9    → 가로세로 비율 (제안서용 와이드)
--ar 4:3     → 일반 무드보드 비율
--v 7        → 최신 Midjourney v7 사용
--style raw  → AI 자동 미화 줄이고 프롬프트 충실도 높임
--s 250      → 스타일화 강도 (0~1000, 낮을수록 사실적)
```

#### 🏅 모델 4. Adobe Firefly Image 3\~5— 법적으로 가장 안전한 상업용 선택
**한 줄 요약:** 저작권 걱정 없이 클라이언트 납품 가능한 유일한 완전 상업 안전 모델
```plain text
핵심 특징:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 100% 저작권 안전: Adobe Stock + 공개 라이선스 이미지만으로 학습
• 상업적 면책 보장: Adobe가 저작권 분쟁 시 법적 보호 제공
• Photoshop 완전 통합: Generative Fill, 배경 확장, 인페인팅
• Content Authenticity Initiative(CAI) 워터마크 내장

전시 디자인에서 Firefly가 핵심인 순간:
• 완성된 이미지의 부분만 수정 (Inpainting)
  → Photoshop에서 영역 선택 후 AI로 대체
  → 예: 완성 이미지에서 바닥재만 대리석으로 교체
• 클라이언트 납품용 최종 이미지 (법적 안전 필수)
• 기존 사진 배경 확장 (Generative Expand)
  → 실제 현장 사진을 더 넓은 공간으로 자연스럽게 확장
• 업스케일링 후 품질 유지

한계:
• 순수 생성 이미지 퀄리티는 Midjourney·FLUX에 비해 낮음
• 빈 화면에서의 창의적 생성보다는 편집·보완에 특화

접근 방법: firefly.adobe.com | 무료 월 25크레딧 / Adobe CC 포함
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


```
[원본 이미지 제외]
[원본 이미지 제외]
**Firefly 전시 디자인 활용 핵심 3가지:**
```plain text
활용 1. Generative Fill — 이미지 부분 교체
 Photoshop에서:
 1. AI 이미지 열기
 2. 바꾸고 싶은 영역을 선택 도구로 선택
 3. Generative Fill 클릭 → 원하는 재질 텍스트 입력
 4. 자연스럽게 해당 부분만 교체
 → 예: DALL-E로 만든 공간 이미지에서 "바닥만 테라조로 교체"

활용 2. Generative Expand — 이미지 캔버스 확장
 1. AI 이미지 열기
 2. 캔버스 크기 늘리기 → 빈 영역 선택
 3. Generative Fill → 자연스럽게 주변 확장
 → 와이드 무드보드 제작, 세로 이미지를 가로로 확장

활용 3. 업스케일링 후 대형 인쇄
 1. DALL-E/Midjourney 원본 이미지 저장
 2. Firefly에서 Super Resolution 적용
 3. 해상도 2~4배 향상
 → A4 → A0 대형 전시 그래픽 인쇄 품질 달성
```

## 4-5. 발산 → 수렴 — AI 이미지의 황금 원칙
**흔한 실수:**
```plain text
이미지 생성 → "이게 아닌데..." → 조금 수정해줘
→ 다시 수정 → 다시 수정
→ 처음 방향에서 벗어나지 못하고 멈춤
```
**올바른 방법:**
```plain text
[발산] "A안(따뜻한), B안(시원한), C안(밝은) 3가지 만들어줘"
→ 가장 마음에 드는 방향 선택

[수렴 1] "B안 방향으로, 색감을 더 청량하게 바꿔줘. 나머지 유지."
[수렴 2] "왼쪽 아래에 텍스트 넣을 여백을 더 만들어줘."
```

## 5-2. Gem A — 홍보글 & SNS 비서 (완전판)
아래를 복사해서 Gemini Gem "요청사항" 칸에 붙여넣으세요.<br>【 】 부분만 내 가게 정보로 바꿔서 사용합니다.
```plain text
[R - Role]
당신은 동네 소상공인 전문 SNS 마케터입니다.
자연스럽고 따뜻한 홍보글로 단골을 늘리는 데 10년 경력이 있습니다.
광고 냄새 없이 진심이 느껴지는 글을 잘 씁니다.

[O - Objective]

[P - Process]
사용자가 홍보 내용을 입력하면,

4단계: "수정이 필요한 부분이 있으신가요?"로 마무리
마지막으로 반드시: "가격·날짜·메뉴명은 올리시기 전에 직접 확인해주세요."

#은평순대국 #은평구맛집 #여름냉면 #신메뉴 #증산동맛집

이번 주부터 시원한 물냉면(10,000원)이 새로 나왔습니다.
더운 여름 꼭 한번 들러주세요!

[K - Constraints]
우리 가게 정보:
- 가게 이름: 【가게 이름】
- 업종: 【업종】
- 위치: 【위치】
- 대표 메뉴/서비스: 【내용】
- 가게 특징: 【특징】
```

```plain text
[가게 이름] 드림

- 가게 이름: 【가게 이름】
```

```plain text
[R - Role]

한글 텍스트는 AI 이미지에 넣지 않고, 캔바에서 추가하도록 안내하는 것이 원칙입니다.

[O - Objective]
사용자가 원하는 홍보 이미지의 느낌을 설명하면,
ChatGPT 또는 Gemini에 바로 붙여넣을 수 있는
최적화된 6요소 이미지 프롬프트를 만들어줍니다.

[P - Process]
사용자가 이미지 요청을 입력하면,
1단계: 용도 파악 (인스타그램 / 카카오톡 배경 / 가게 입구 사인 / 이벤트 배너 등)

        [주제/대상] + [스타일] + [분위기] + [색감] + [구도] + [용도]
3단계: 한국어 프롬프트 제공
4단계: 필요시 영문 프롬프트도 함께 제공 (더 정확한 결과를 원할 때)
5단계: "한글 텍스트는 canva.com에서 이미지 위에 추가하세요" 반드시 안내
6단계: "마음에 안 드는 부분이 있으면 말씀해주세요, 수정해드릴게요"

시원하고 청량한 여름 물냉면 한 그릇,
나무 테이블 위에 놓인 모습, 클린 미니멀 스타일,
청량하고 시원한 분위기, 흰색과 하늘색 색감,
위에서 내려다보는 구도,
인스타그램 정사각형 비율, 텍스트 없이

clean minimal style, cool summer vibes,
white and sky blue color palette, overhead shot,
```

## 자주 나오는 질문
**Q1. Gem은 한 번 만들면 영구적으로 사용할 수 있나요?**<br>A. 네, Gemini 계정에 저장되어 언제든 사용할 수 있습니다. 가게 정보가 바뀌면 "요청사항"을 수정하면 즉시 반영됩니다.
**Q2. AI 이미지를 SNS에 올려도 되나요?**<br>A. 개인 SNS 용도는 대체로 문제없습니다. 블로그나 상업적 사용은 해당 AI 서비스 이용약관을 먼저 확인하세요.
**Q3. Gem B(리뷰 답변)가 쓴 글을 그대로 올려도 되나요?**<br>A. 가게 이름을 반드시 직접 넣고, 내 말투로 살짝 다듬은 후 올리세요. AI 답변임을 알리는 규정은 없지만, 직접 다듬으면 훨씬 자연스럽습니다.
**Q4. AI 이미지를 만들 때 실제 사람 얼굴을 넣어도 되나요?**<br>A. 본인 사진은 괜찮습니다. 타인의 사진(특히 연예인, 공인)을 변환하거나 합성하는 것은 초상권 침해 가능성이 있으니 삼가세요.
**Q5. Gem C(이미지 프롬프트 비서)와 직접 AI 이미지 만드는 것의 차이가 뭔가요?**<br>A. Gem C는 내 가게 분위기를 기억하고, 어떤 이미지를 요청해도 우리 가게 스타일에 맞는 프롬프트를 자동으로 만들어줍니다. 이미지 생성 자체는 ChatGPT나 Gemini에서 별도로 진행합니다.
