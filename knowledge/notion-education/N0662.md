# 6장 · 실습 1 · 폴더 정리

정리일: 2026-10-08 · 교육 에셋 N0662

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Claude Code가 내 파일을 실제로 읽고 다룬다는 것을 눈으로 확인하며, 한 번에 시키지 않기를 처음 연습합니다.
## 진행 단계
1. **STEP 1 · 실습 폴더 준비·연결 (5분)** — 압축 파일을 바탕화면에 풀고 폴더 이름이 sw-practice인지 확인한 뒤, Code 탭 → 로컬 → 폴더 선택 → sw-practice를 선택합니다.
- 정상 결과: 폴더가 연결되고 Claude가 응답
2. **STEP 2 · 먼저 물어보기 (7분)** — 정리는 아직 하지 말라고 하고 기준을 먼저 묻습니다.
- 입력할 내용:
```javascript
이 폴더 안에 뭐가 있는지 살펴보고,
어떤 기준으로 정리하면 좋을지 먼저 알려줘.
정리는 아직 하지 마.
```
- 정상 결과: 정리 기준이 화면에 글로 나와 있고 마음에 듦. 마음에 안 들면 기준을 다시 말해 재정리
3. **STEP 3 · 실행시키기 (10분)** — 기준이 정해지면 실행을 지시하고 승인 화면에서 수락/거절합니다.
- 입력할 내용:
```javascript
방금 말한 기준대로 폴더를 나누고 파일을 옮겨줘.
파일 이름도 규칙에 맞게 바꿔줘.
```
- 정상 결과: "정리를 완료했습니다" 같은 응답
4. **STEP 4 · 기록 남기기 (4분)**
- 입력할 내용:
```javascript
정리한 내용을 정리보고서.md 파일로 만들어줘.
어떤 파일을 어디로 옮겼는지 알 수 있게.
```
- 정상 결과: 폴더 안에 정리보고서.md 생성
5. **STEP 5 · 눈으로 확인하기 (4분)** — 파일 탐색기(맥은 Finder)에서 sw-practice 폴더의 구조 변화와 정리보고서.md를 직접 봅니다.
## 막히는 지점
- 승인을 안 눌러서 멈춰 있음 → 승인 화면의 수락 버튼
- 파일이 사라진 것 같음 → 새로 만들어진 하위 폴더 안 확인
- 결과가 마음에 안 듦 → 되돌리지 말고 "이렇게 바꿔줘"로 다시 지시
- 중간에 오류 → 오류 메시지를 그대로 복사해 붙여넣기
