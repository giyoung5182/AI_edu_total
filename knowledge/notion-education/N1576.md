# 3️⃣ 세션 3 · 엑셀을 코딩 없이 자동화하기

정리일: 2026-10-08 · 교육 에셋 N1576

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

**도구:** ChatGPT + VBA
**세션 목표:** 손으로 반복하던 엑셀 작업을, ChatGPT가 짜준 코드로 **클릭 한 번에** 끝내봅니다. 코딩 지식은 필요 없습니다.
### 📖 개념: 코드는 AI가 씁니다. 우리는 "뭘 원하는지"만 말합니다
**VBA(Visual Basic for Applications)**는 엑셀 안에서 도는 자동화 언어입니다. 예전엔 이걸 배워야 자동화를 했지만, 이제는 **ChatGPT가 VBA 코드를 대신 써줍니다. 우리는 복사해서 붙여넣고 실행하기만 하면 됩니다.**

그래서 이 세션의 진짜 실력은 "코딩"이 아니라 **"내가 원하는 걸 정확히 말로 설명하는 것"** — 세션 1의 5요소가 여기서도 그대로 통합니다. 오늘은 밋밋한 예제 하나가 아니라, 실제로 매주 손 아프게 하던 작업 두 가지를 자동화해봅니다.

[원본 이미지 제외]

**Padlet에 올리기** (`세션3 · 엑셀 자동화`) — "내가 매주/매월 반복하는 엑셀 작업 1가지 + 대략 걸리는 시간"을 올려주세요. 오늘 실습을 내 작업에 어떻게 응용할지 계속 떠올리며 진행합니다.

---
## 🔥 활동 1 — 흩어진 여러 시트를 한 방에 통합하기
**왜 이걸 먼저 하나:** 라인별·부서별·월별로 시트가 쪼개져 있어서, 매번 복사-붙여넣기로 합치던 그 작업입니다. 이걸 매크로 하나로 끝내는 걸 보면 "아, 이래서 자동화구나"가 바로 옵니다.
**실습 파일:** `세션3_통합실습_라인별생산실적.xlsx` (1라인 / 2라인 / 3라인 시트 포함)

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]

### 실행 방법 (VBA 기본 조작을 여기서 한 번에 익힙니다)
1. 실습 파일을 엽니다.
2. ChatGPT에 아래 프롬프트를 붙여넣고, 생성된 VBA 코드를 복사합니다.
3. 엑셀에서 **\[개발도구\] → \[Visual Basic\]** 을 엽니다. → **\[삽입\] → \[모듈\]** 로 빈 코드 창을 만들고, 복사한 코드를 붙여넣습니다.
1. 단축키는 Alt F11입니다.
4. **F5**(또는 실행 ▶ 버튼)를 눌러 실행합니다.
5. "통합" 시트가 새로 생기고, 세 라인 데이터가 한 곳에 모였는지 확인합니다.

**\[개발도구\] 탭이 안 보이면**: \[파일\] → \[옵션\] → \[리본 사용자 지정\]에서 오른쪽 목록의 "개발 도구"에 체크하세요. 회사 PC는 매크로 실행이 막혀 있을 수 있으니, "보안 경고"가 뜨면 IT팀에 매크로 사용 가능 여부를 먼저 확인하세요.


실제 엑셀 파일을 통째로 ChatGPT에 올리지 말고, **컬럼 구조와 조건만 말로 설명**하세요. 코드는 데이터 없이도 만들 수 있습니다.

```javascript
나는 VBA를 전혀 모르는 비개발자야.

다음 엑셀 자동화 코드를 단계별로 설명하면서 작성해줘:

목표: "1라인", "2라인", "3라인" 이름의 시트에 있는 생산 실적 데이터를
     "통합" 이라는 새 시트에 하나로 합치는 매크로

요구사항:
1. 각 시트의 헤더(1행)는 통합 시트에 한 번만 남긴다
2. 시트 이름을 통합 시트의 마지막 열에 "출처 라인"으로 표시한다
3. 실행 후 몇 개 행이 통합됐는지 메시지로 알려준다

코드 작성 후, 어디에 붙여넣어야 하는지도 알려줘.
```
<details>
<summary>예상 결과 확인하기 👀 (AI가 만들어줄 코드의 대략적인 형태)</summary>
```javascript
Sub 시트통합()
    Dim ws As Worksheet, target As Worksheet
    Dim lastRow As Long, i As Long, cnt As Long
    Set target = Sheets.Add
    target.Name = "통합"
    ' 헤더 복사 + 각 시트 순회하며 행 붙여넣기 + "출처 라인" 표시
    ' ... (실제 코드는 조금씩 다를 수 있습니다)
    MsgBox cnt & "개 행이 통합되었습니다"
End Sub
```
변수명이나 세부 구조는 달라도, "각 시트를 돌며 → 통합 시트에 이어붙이고 → 출처를 표시"라는 뼈대는 동일합니다.
</details>

**한 걸음 더 — 내 상황으로 바꿔보기:** "요구사항"을 내 업무 조건으로 바꿔 다시 요청해보세요. 예: 합칠 시트를 "월별(1월/2월/3월)"로, 출처 표시를 "부서명"으로. 조건만 바꿔도 AI가 코드를 새로 짜줍니다.


**Padlet에 올리기** — 통합된 "통합" 시트 결과(캡처)나 "이걸 내 어떤 작업에 쓰겠다"를 올려주세요.

## 🔥 활동 2 — 두 표를 자동으로 매칭해서 채우기 (조회 자동화)
**왜 이게 클라이맥스인가:** 부품코드로 단가표를 일일이 찾아 옮겨 적던 작업, VLOOKUP도 헷갈리던 그 작업을 **매크로가 알아서 찾아 채우고 합계까지 계산**합니다. "매주 하던 대조 작업이 클릭 한 번"이 되는 순간입니다.
**실습 파일:** `세션3_매칭실습_부품매칭.xlsx` (부품마스터 / 입고내역 시트 포함)

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]

[원본 이미지 제외]
**실행 방법:** 활동 1과 동일합니다 (파일 열기 → ChatGPT 프롬프트 → 코드 복사 → \[개발도구\]→\[Visual Basic\]→\[삽입\]→\[모듈\] 붙여넣기 → F5 → "입고내역" 시트에 부품명·단가·합계가 채워지는지 확인).
```plain text
나는 VBA를 전혀 모르는 비개발자야.

다음 엑셀 자동화 코드를 단계별로 설명하면서 작성해줘:

목표: "입고내역" 시트의 A열(부품코드)을 기준으로 "부품마스터" 시트에서
     부품명과 단가를 찾아 입고내역 시트에 자동으로 채워 넣는 매크로

요구사항:
1. 입고내역 시트: A열 부품코드, B열 입고수량이 이미 있음
2. C열에 부품명, D열에 단가를 부품마스터 시트에서 찾아 채운다
3. E열에 "입고수량 × 단가"로 합계 금액을 계산한다
4. 부품마스터에 없는 코드는 "코드 확인 필요"라고 표시하고 빨간 글씨로 강조한다
5. 실행 후 몇 개 행을 처리했는지 메시지로 알려준다

코드 작성 후, 어디에 붙여넣어야 하는지도 알려줘.
```

이 패턴 하나로 "견적서-단가표 대조", "입고내역-발주서 매칭", "회원명단-등급표 결합" 같은 매주 반복 작업을 전부 응용할 수 있습니다.


**한 걸음 더**: 찾을 값을 단가 대신 "재고 수량"이나 "담당자"로 바꾸거나, 없는 코드 처리 방식을 바꿔서 다시 요청해보세요.


**Padlet에 올리기** — 자동으로 채워진 입고내역 결과나 "내 업무의 어떤 대조 작업에 쓸지"를 올려주세요. 남들이 올린 응용 아이디어가 곧 여러분의 활용 목록이 됩니다.


**오류가 나도 당황하지 마세요.** 빨간 오류 메시지가 뜨면 그대로 복사해서 ChatGPT에 "이 오류가 났는데 어떻게 고쳐?"라고 붙여넣으면 됩니다. 대부분 스스로 고쳐줍니다.

### 📌 세션 3 핵심 정리
① VBA는 몰라도 된다. ChatGPT에게 **"뭘 자동화하고 싶은지"만 정확히 설명**하면 코드는 AI가 쓴다.
② 프롬프트에 "단계별로 설명하면서"를 넣으면 이해하기 쉬운 코드가 나온다.
③ 오류가 나면 **오류 메시지를 그대로 AI에게** 보여주면 대부분 스스로 고친다.

**다음 단계 예고** — 오늘 익힌 자동화 스킬(특히 더미 데이터 만들기)은 세션 5에서 테스트 데이터를 준비하거나, MVP 결과물을 엑셀로 다듬을 때(세션 7) 그대로 활용됩니다.
