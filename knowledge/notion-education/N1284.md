# STEP 3 — 수정하면 자동 반영 확인

정리일: 2026-10-08 · 교육 에셋 N1284

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
게시한 뒤 대화에서 수정하면 같은 주소에 자동 반영되는지, 휴대폰에서도 반영되는지 확인합니다.
## 진행 단계
1. **수정** — 게시 후 대화에서 수정 요청 → 같은 주소에 자동 반영(다시 게시 버튼을 누를 필요 없음)
2. **반영 확인** — 이미 링크를 열어 둔 학생은 새로고침만 하면 바뀐 내용이 보임
3. **폰 확인** — 게시 후 본인 폰으로 한 번 열어보기
4. **모바일에서 안 보일 때**
- 입력할 내용:
```plain text
축하 효과가 휴대폰에서 안 보여.
모바일 브라우저에서도 확실히 보이는 방식으로 바꿔줘. 나머지는 그대로.
```
## 막히는 지점
- 리허설에서 수정 4개 중 축하 효과만 휴대폰에서 안 보임(원인 후보: 휴대폰의 "동작 줄이기" 설정, 또는 코드가 PC 기준). "PC에서 확인한 건 확인한 게 아니다"
