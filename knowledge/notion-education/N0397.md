# 활동 2 — 우리 업무 분류하기

정리일: 2026-10-08 · 교육 에셋 N0397

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 업무에 AI를 쓸지 말지 정하는 판단 기준을 실제 업무 15건에 적용해 A/B/C 등급으로 분류합니다. (25분)
## 진행 단계
1. **판단 기준 확인** — 판단 3축(정답이 하나인가 초안이 필요한가 / 틀렸을 때 알아챈 수 있는가 / 틀렸을 때 무슨 일이 일어나는가)과 A 바로 활용 · B 검증 후 활용 · C 사용 부적합 기준을 확인합니다.
2. **워크시트 개인 작성 (12분)** — 제시된 업무 12건(회의 녹취록 정리, 사과 공문 초안, 비용 집계, 영문 메일 번역 등)에 등급과 이유를 적습니다.
3. **내 업무 3건 추가** — 13\~15번에 본인 업무를 적고 등급과 이유를 적습니다.
4. **전체 공유 (5분)** — 가장 판단이 어려웠던 번호와 이유를 표시합니다.
- 정상 결과: 공유 후 표준 답안과 비교. 부서마다 등급이 달라질 수 있음
## 막히는 지점
- 정답이 하나인 문제는 아님. 의견이 갈리는 항목은 B로 보고 원본과 대조
- 같은 업무도 책임 소재에 따라 등급이 달라짐
