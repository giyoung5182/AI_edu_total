# 활동 2-2 — 교차 분석과 해석

정리일: 2026-10-08 · 교육 에셋 N1169

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
두 변수를 함께 보고 상관관계인지 인과관계인지 판단해 기록합니다. (9분)
## 진행 단계
1. **교차 분석 요청** — 아래 프롬프트를 입력합니다.
- 입력할 내용:
```javascript
아래 교차 분석을 수행하고, 각각에 대해
"상관관계인가 인과관계인가"를 판단해 설명하라.

1. 직급 × 회의 시간
2. 근속연수 × 자동화 가능성 점수
3. 반복도 × 자동화 가능성
4. AI 사용 경험 × 주간 총 업무시간

각 분석마다:
- 관찰된 패턴을 한 줄로 서술
- 인과관계로 볼 수 있는지 판단
- 인과가 아니라면 숨은 제3의 변수 가능성을 제시
- 자료만으로 판단이 어려우면 "추가 확인 필요"로 표기
```
1. **판단 기록** — 워크시트(교차 / 관찰된 패턴 / 인과? / 숨은 변수 가능성)에 4건을 적습니다.
## 막히는 지점
- 4번(AI 경험 × 업무시간)은 인과 방향을 알 수 없음. 알 수 없다고 쓰는 것이 정직한 분석
- 확인하려면 같은 사람의 교육 전후 업무시간을 비교해야 함(교안의 선택 내용)
