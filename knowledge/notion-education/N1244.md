# 문제2: 사용요금 항목을 금액 높은 순으로

정리일: 2026-10-08 · 교육 에셋 N1244

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
2023-07-01 데이터 중 요금종별이 사용요금인 항목을 금액이 높은 순서대로 보여줍니다.
## 진행 단계
1. **쿼리 작성** — 기준일자와 요금종별로 필터하고 금액 내림차순으로 정렬합니다.
```sql
SELECT `기준일자`, `구분`, `계약종별`, `용도`, `요금종별`, `절기구분`, `시간대별 차등`, `냉동기종류`, `금액`
FROM KDHC
WHERE `기준일자` = '2023-07-01'
  AND `요금종별` = '사용요금'
ORDER BY `금액` DESC
LIMIT 5;
```
2. **정답화면 비교** — 최상위 금액이 151.66(온수·업무용·난방용)인 5건이 나오는지 확인합니다.
## 막히는 지점
- 교안에 별도 기재 없음
