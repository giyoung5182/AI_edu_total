# 내 에이전트 업그레이드 3단계 (역설계·딥리서치·BMAD 복제)

정리일: 2026-10-08 · 교육 에셋 N1503

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
수업 기법 3가지로 내 에이전트(시스템 프롬프트)를 업그레이드합니다.
## 진행 단계
1. **Step 1 — 역설계(수업 기법 4)** — 내 최고 결과물을 붙여넣고 역설계 요청
- 입력할 내용:
```javascript
지금 내가 가장 잘 쓴 기획서를 분석해서, 이런 글을 자동으로 쓰는 시스템 프롬프트를 만들어줘
```
1. **Step 2 — 딥 리서치 변환(수업 기법 3)** — 새 정보를 먼저 공부시키고 프롬프트 업데이트
- 입력할 내용:
```javascript
2025년 최신 인스타그램 알고리즘 변화를 검색해서, 이 에이전트에 반영해줘
```
1. **Step 3 — BMAD 복제(수업 기법 2)** — 잘 작동하는 팩을 다른 분야에 맞게 변형
- 입력할 내용:
```javascript
이 Pack 2 시스템 프롬프트를 '이벤트 기획' 특화 버전으로 변형해줘. 구조는 그대로, 용어만 이벤트 업계로 치환
```
## 막히는 지점
- 없는 정보를 지어냄: Constraints 부재 → "없는 정보는 절대 지어내지 말 것, 모르면 질문할 것" 추가
- 답변이 너무 짧음: Role 정의 빈약 → "20년 경력의 전문가"처럼 구체적 경력 추가
- 원하는 형식 안 나옴: 출력 형식 미지정 → Constraints에 포맷 구체적 명시
- 지시사항 일부 빠뜨림: Task 과부하 → Step-by-Step으로 번호 분리, Chain of Thought 유도 추가
