## 이 실습으로 하는 것
앞의 예시는 참고용이고, 내 실제 업무로 RCTCK 프롬프트를 직접 만들어 실행한다.
## 진행 단계
1. **자동화할 업무 고르기 (3분)** — 존 네이밍·컨셉 텍스트 / 수정 요청 메일 / 레퍼런스 이미지 분석 / 이미지 생성 영문 프롬프트 / 디자인 컨셉 설명서 / 디자인 변경 내역 정리 중에서 고른다.
2. **RCTCK 워크시트 작성 (10분)** — Role, Context, Task, Constraint, Knowledge 빈칸을 채운다. K에는 실제 자료를 붙여넣는다.
- 정상 결과: 이미지 분석이 필요하면 Gemini에서 이미지를 첨부해 분석 프롬프트를 먼저 실행하고, 결과를 K에 붙여넣어 Claude에서 텍스트 작업
3. **실행·확인 (10분)** — 존 네이밍이 기억에 남는지 / 설명문이 제품 나열에 그치지 않는지 / 메일 톤이 너무 딱딱하거나 과하게 사과하지 않는지 확인하고 보강 프롬프트를 쓴다.
4. **강사 피드백** — 결과물을 화면에 띄우고 함께 확인한다. 만든 프롬프트는 저장한다.
