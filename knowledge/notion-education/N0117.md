## 2. GitHub 가입

**단계별 따라하기**
- [github.com](http://github.com) 접속 → 우측 상단 **Sign up** 클릭
- 이메일 / 비밀번호 / 유저네임 입력
- ⚠️ 유저네임 주의 — 나중에 주소에 들어갈 수 있으니 신중히 (예: github.com/내이름)
- 이메일 인증 링크 클릭 → 가입 완료

---
## 3. Vercel 가입

**단계별 따라하기**
- vercel.com 접속 → 우측 상단 **Sign Up**
- **"Continue with GitHub" 버튼 클릭 ← 핵심!**
- GitHub 권한 승인 화면 → Authorize 클릭
- 두 서비스가 자동 연결되어 가입 완료


**왜 GitHub 계정으로 가입하나요?**
- 이메일로 따로 가입하면 — 나중에 GitHub와 연결하는 단계가 추가로 필요
- 처음부터 GitHub 계정으로 가입하면 — 두 서비스가 한 번에 자동 연결되어 더 깔끔

---
## 4. 사전 준비 체크리스트

**배포 전 아래 2가지만 준비되어 있으면 돼요**

- [ ] Node.js 설치 — nodejs.org에서 LTS 버전 다운로드 후 설치 마법사
- [ ] 클로드 코드(Claude Code)를 내 프로젝트 폴더에서 실행 중

**GitHub CLI / Vercel CLI 설치도 직접 안 해도 돼요!**
- 키 포인트 — 수강생이 직접 해야 하는 건 마지막 "로그인 창 넘기는 버튼 클릭"뿐이에요
- Node.js만 미리 설치되어 있으면 — 나머지는 아래 배포 프롬프트 하나에 다 포함되어 있어요
- 클로드 코드가 터미널에서 설치·로그인·배포를 순서대로 실행합니다

---
## 5. 설치 및 로그인 — 클로드 코드에 한 줄로 부탁

**1단계 — CLI 설치 + 로그인**

```plain text
깃허브 CLI랑 버셀 CLI 설치하고 로그인까지 도와줘
```

로그인 중 브라우저 창이 뜨면 — 새 탭에서 Authorize 버튼 클릭 후 터미널로 돌아오면 끝납니다

---
## 6. 배포하기 — 클로드 코드에 한 줄로 부탁

**2단계 — 첫 배포**

```plain text
이 폴더를 깃허브 새 저장소에 올리고, 버셀로 배포해서 사이트 주소 알려줘
```

**재배포 — 파일 수정 후 다시 올릴 때**

```plain text
수정한 거 깃허브 푸시하고 버셀에 다시 배포해줘
```

어느 폴더에서 명령어를 쳐야 하나요?

클로드 코드가 깃허브 비번을 물어요
