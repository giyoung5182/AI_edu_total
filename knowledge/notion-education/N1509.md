# 실습 1. 회의방을 만들고, 싸움을 붙인다

정리일: 2026-10-08 · 교육 에셋 N1509

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
/meeting 회의방 페이지를 만들고, 사회자 없이 영업팀장·개발팀장 두 AI만 넣어 "신제품, 다음 달 출시 강행이냐, 3개월 연기냐" 안건으로 회의를 시킵니다.
## 진행 단계
1. **/clear 실행** — 작업 시작 전 터미널 A의 Claude Code에서 `/clear`를 실행합니다.
2. **프롬프트 입력** — 두 팀장의 이름 빈칸을 채워 Claude Code 프롬프트를 입력하고 진행합니다.
- 입력할 내용: 교안의 "AI들이 회의하는 단체 채팅방 페이지를 만들어 주세요" 프롬프트 (6개 요구사항: /meeting 페이지, 에이전트 두 명, 고정 안건, 4라운드 8회 발언 후 종료, 화면 구성, 서버 로그)
3. **서버 재시작 후 /meeting 열기**
4. **\[예측\]** 사회자 없이 8번 발언하면 회의가 어떻게 끝날지, 합의가 나올지 예측해 적습니다.
5. **\[회의 시작\]** 을 누르고 화면에서 손을 뗍니다. 관전합니다.
6. **\[확인\]** 회의가 끝나면 발언록을 처음부터 읽으며 항목을 찾고 발언의 시각을 메모합니다.
- 평행선: 같은 주장이 표현만 바뀌어 반복되는 곳
- 전제 불일치: 서로 다른 숫자나 가정 위에서 말하는 곳
- 결론 부재: 발언은 쌓였는데 안건의 답이 없는 상태
- (보너스) 상대 말을 인용하고도 논점을 비껴가는 곳
7. **옆자리와 발언록 비교** — 실행마다 대사가 달라 서로 다른 명장면을 찾습니다.
## 막히는 지점
- 두 팀장이 서로 칭찬하고 금방 합의함: 브리프 반영이 약한 상태. "양보하기 어려운 것을 끝까지 지키도록 지시를 강화해 주세요"라고 요청
- 말풍선이 회의 끝난 뒤 한꺼번에 뜸: "발언이 생길 때마다 저장되어 폴링에 잡히게 바꿔 주세요"라고 요청
- 발언이 너무 길고 문어체: "발언을 세 문장 이내 구어체로 제한해 주세요"라고 요청
- \[중지\]가 안 먹힘: 터미널 B에서 Ctrl+C로 서버를 끄고 중지 버튼 수리를 요청
