# 4. 사전 준비 체크리스트

정리일: 2026-10-08 · 교육 에셋 N0646

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
배포 전에 필요한 두 가지(Node.js 설치, 클로드 코드 실행)를 확인합니다.
## 진행 단계
1. **Node.js 설치** — nodejs.org에서 LTS 버전을 다운로드해 설치 마법사로 설치합니다.
2. **클로드 코드 실행** — 클로드 코드(Claude Code)를 내 프로젝트 폴더에서 실행 중인 상태로 둡니다.
- 참고: GitHub CLI / Vercel CLI는 직접 설치하지 않아도 되며, Node.js만 설치되어 있으면 나머지는 다음 단계의 프롬프트에 포함됩니다.
