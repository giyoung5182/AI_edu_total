# 실습 3. SQL로 메타데이터 관리 테이블 조회

## 이 실습으로 하는 것
메타데이터 테이블에 샘플 데이터를 넣고 SQL로 조회해 실제 카탈로그 검색처럼 활용한다. (MySQL 기준)
## 진행 단계
1. **관리 테이블 생성** — meta_tables(테이블 단위), meta_columns(컬럼 단위)를 CREATE TABLE로 만든다.
2. **샘플 데이터 INSERT** — 3개 테이블(heat_usage, complaints, facilities)의 테이블·컬럼 메타데이터를 등록한다.
- 정상 결과: table_id 1\~3으로 heat_usage, complaints, facilities가 조회됨
3. **메타데이터 조회** — 전체 목록(ORDER BY biz_domain), 특정 업무 영역(WHERE biz_domain), 개인정보 컬럼(JOIN + WHERE is_pii = 'Y').
- 정상 결과: 개인정보 컬럼으로 complaints.customer_id, heat_usage.customer_id가 조회됨
4. **태그 기반 검색 과제** — '민원' 키워드가 태그 또는 설명에 있는 테이블을 찾는 쿼리를 작성한다.
```sql
SELECT table_name, table_desc, owner_dept, tags
FROM meta_tables
WHERE tags LIKE '%민원%' OR table_desc LIKE '%민원%';
```
## 막히는 지점
- meta_columns의 table_id는 meta_tables의 table_id를 참조하며, JOIN으로 연결해 조회한다.
