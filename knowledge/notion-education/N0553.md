# 리라이팅 실습 2: 예산 초과 검토 요청 메모

정리일: 2026-10-08 · 교육 에셋 N0553

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
현장/본부에 공유할 예산 초과 검토 요청 메모를 3요소 프롬프트로 작성합니다.
## 진행 단계
1. **Before 확인**
```javascript
골조비가 예산보다 많이 나와서 검토 요청 메모 좀 써줘.
기성 지급이 다음 주라서 빨리 확인해야 해.
공식적으로 써줘.
```
1. **After 프롬프트를 ChatGPT에 입력**
- 입력할 내용:
```javascript
## 역할
당신은 교육기관 현장 원가관리 담당자입니다.

## 맥락
- 수신: 사업본부 원가관리팀장
- 프로젝트: ○○아파트 신축공사
- 검토 대상: 골조 공종 5월 누계 집행 현황
  - 현 상태: 실행예산 대비 집행률이 계획보다 8%p 높음
  - 영향 항목: 철근 가공·조립, 콘크리트 타설, 장비 임차료
- 요청 사항: 초과 원인 확인 + 6월 지급 예정 금액 조정 가능성 검토
- 회신 기한: 2026.05.13 (목)
- 목적: 예산 초과 원인 검토 및 후속 조치 요청

## 출력 형식
1. 메모 제목
2. 수신/발신/문서번호/시행일자
3. 검토 요청 배경 (1~2 단락)
4. 확인 요청 사항 (번호 목록, 공종·계정 명시)
5. 영향 항목 리스트 (표: 공종 / 계정 / 차이 원인 / 확인 필요 사항)
6. 회신 기한 및 협조 요청
```
1. **결과 확인** — 결과물이 실제 업무에 바로 쓸 수 있는 수준인지 확인합니다.
