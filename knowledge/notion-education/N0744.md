# 🧩 05. SKILL

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

## **SKILL이 뭘까요?**
자, 여기서 SKILL이라는 개념이 조금 생소할 수 있습니다.
어렵게 생각하지 않으셔도 됩니다.
SKILL은 쉽게 말하면<br>AI에게 미리 전달해두는 작업 매뉴얼입니다.
[원본 이미지 제외]
예를 들어볼게요.
카페에서 아르바이트생이<br>“딸기 요거트 스무디 주세요”라는 주문을 받았다고 해보겠습니다.
그러면 매번 손님이
```plain text
딸기를 넣고,
요거트 파우더를 넣고,
우유를 넣고,
얼음을 넣고,
믹서기로 갈아주세요.
```
이렇게 하나하나 설명하지는 않습니다.
카페 안에는 이미 제조법이 있습니다.
아르바이트생은 그 제조법을 보고<br>딸기 요거트 스무디를 만듭니다.
Claude에게 주는 SKILL도 비슷합니다.
우리가 매번 길게 설명하지 않아도<br>Claude가 정해진 방식대로 작업할 수 있게<br>미리 작업 방법을 적어두는 겁니다.
---
예를 들어서
```markdown
나는 claude가 금요일마다 주간 보고를 대신 작성해줬으면 좋겠어!
```
를 원한다고 하면, 우리는 뭘 만들어야할까요.
[원본 이미지 제외]
저라면, claude code에게 정해진 자료를 줬을때 항상 동일한 양식의 보고를 내놓도록 할겁니다.
더 정확하게는 claude code에게 하나의 메뉴얼을 줄 거에요.
메뉴얼을 만들어서 주고,<br>그 메뉴얼에는 이런게 있겠죠.
1. 너가 어떤 파일을 받았을 때,
2. 항상 이런 양식의 보고서를 내놓아야해.
가 되도록 할 거에요.

SKILL은 AI에게 주는 메뉴얼이라고 생각하시면 됩니다.<br><br>“이런 파일을 받으면,<br>이런 기준으로 처리하고,<br>이런 결과물을 만들어줘”를 미리 정리해두는 겁니다.

## **방금 했던 PPT 작업에 적용해보겠습니다**
앞에서 우리는 Claude Code에게 이렇게 요청했습니다.
### **앞에서 했던 요청**
```plain text
첨부한 PPT 템플릿의 디자인과 레이아웃은 유지한 상태로,
함께 첨부한 메모 파일과 CSV/엑셀 데이터의 내용을 반영해서
PPT 내용을 채워주세요.
```
이 요청 자체는 괜찮습니다.
그런데 이런 작업을 앞으로도 계속 한다면<br>매번 아래 내용을 다시 써야 합니다.
한두 번은 괜찮지만<br>계속 반복하면 번거롭습니다.
그래서 이 작업 방식을<br>하나의 SKILL로 정리해두는 겁니다.
[원본 이미지 제외]

## **이번에 만들 SKILL의 역할**
이번에는 PPT를 다루기 위한 간단한 SKILL을 만들어보겠습니다.
[원본 이미지 제외]
이 SKILL에는 이런 내용이 들어가면 됩니다.
### **SKILL에 들어갈 내용**
```plain text
1. 어떤 파일을 입력으로 받는지
2. PPT 템플릿은 어떻게 다뤄야 하는지
3. 메모 파일은 어떻게 읽어야 하는지
4. CSV/엑셀 데이터는 어떻게 반영해야 하는지
5. 결과물은 어떤 형식으로 저장해야 하는지
6. 작업 후 어떤 점을 확인해야 하는지
```
우리 수업에서는 너무 복잡한 SKILL을 만들 필요는 없습니다.
일단은<br>“PPT 템플릿에 내용을 채우는 작업 방식”을<br>짧고 분명하게 적어두는 정도면 충분합니다.
[원본 이미지 제외]

## **SKILL 작성 예시**
아래는 간단한 PPT 작성용 SKILL 예시입니다.
### **SKILL 예시**
```markdown
# PPT Template Fill Skill

## 목적

제공된 PPT 템플릿의 디자인과 레이아웃을 유지하면서,
메모 파일과 데이터 파일의 내용을 반영해 발표자료를 완성한다.

## 입력 파일

- PPT 템플릿 파일
- 메모 파일
- CSV 또는 엑셀 데이터 파일

## 작업 방식

1. 먼저 PPT 템플릿의 슬라이드 구조를 확인한다.
2. 기존 색상, 폰트, 레이아웃은 최대한 유지한다.
3. 메모 파일에서 핵심 내용을 추출한다.
4. CSV/엑셀 데이터에서 중요한 수치를 확인한다.
5. 각 슬라이드에 들어갈 문구를 짧게 정리한다.
6. 필요한 경우 수치를 카드, 표, 그래프 형태로 반영한다.
7. 결과물은 수정 가능한 PPTX 파일로 저장한다.

## 주의사항

- 템플릿 디자인을 임의로 크게 바꾸지 않는다.
- 슬라이드에 문장을 너무 길게 넣지 않는다.
- 숫자 데이터는 원본 파일 기준으로 확인한다.
- 결과물 생성 후 슬라이드별로 빠진 내용이 없는지 점검한다.
```

SKILL 문법을 외우는게 목적은 아닙니다<br><br>중요한 건<br>반복해서 맡길 작업 기준을<br>하나의 문서로 정리해둔다는 점입니다.

그런데 그 메뉴얼을 우리가 읽어가면서 진행할까요?<br>그렇지 않습니다. AI에게 주는 SKILL형태로 Anthropic에서 만들어놨어요.<br>우리는 그 SKILL을 AI에게 주고 우리만의 메뉴얼을 만들어봅시다.

```plain text
앞에서 진행한 PPT 템플릿 채우기 작업을

PPT 작업용 SKILL을 만들어주세요.

skill의 이름은 poscoint-pptx입니다.
이 SKILL은 아래 상황에서 사용합니다.

- PPT 템플릿 파일이 있습니다.
- 메모 파일이 있습니다.
- CSV 또는 엑셀 데이터 파일이 있습니다.
- Claude Code가 템플릿의 디자인은 유지하면서 내용을 채워야 합니다.
```

## **만들어진 SKILL을 확인해보겠습니다**
Claude Code가 SKILL 초안을 만들면<br>그냥 바로 쓰기보다 한 번 읽어봐야 합니다.
### **확인할 것**
```plain text
1. 입력 파일이 제대로 적혀 있는가?
2. PPT 템플릿을 유지하라는 기준이 들어갔는가?
3. 메모 파일과 데이터 파일을 어떻게 반영할지 적혀 있는가?
4. 결과물이 PPTX로 저장된다고 되어 있는가?
5. 작업 후 확인할 기준이 들어가 있는가?
```
여기서 부족한 부분이 있으면<br>바로 수정 요청하면 됩니다.

## **SKILL로 다시 PPT를 만들어보기**
이제 방금 만든 SKILL을 사용해서<br>다시 PPT 작업을 요청해보겠습니다.
이번에는 앞에서처럼 모든 기준을 길게 쓰지 않고,<br>SKILL을 참고해서 작업하라고 말해보겠습니다.
### **프롬프트 예시**
```plain text
/poscoint-pptx
첨부한 PPT 템플릿에 메모 파일과 데이터 파일의 내용을 채워주세요.

기존 템플릿의 디자인과 레이아웃은 유지하고,
결과물은 수정 가능한 PPTX 파일로 저장해주세요.
```
여기서 차이를 한번 보시면 됩니다.
처음에는 요청을 길게 써야 했는데,<br>SKILL을 만들고 나면<br>작업 기준을 훨씬 짧게 전달할 수 있습니다.
