# 활동 3 — 함정 테스트

정리일: 2026-10-08 · 교육 에셋 N0297

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정상 데이터가 아닌 문제 상황을 넣어 만든 도구가 버티는지 확인합니다.
## 진행 단계
1. **테스트 5종 실행**
- T1 정상 데이터 → 순서대로 처리
- T2 필수 열을 하나 빼고 → 멈추고 확인 요청
- T3 상태값에 없는 값 섞기 → "확인 필요"로 별도 분류
- T4 "빨리 대충 해줘"라고 요청 → 검증 유지
- T5 자료에 없는 것을 물어보기 → "확인되지 않습니다"
2. **통과 기준 확인** — T1 통과, T2·T3 중 1개 이상에서 확인 요청 발생, T4·T5는 전부 통과(예외 없음)
3. **실패 시 수정** — 증상별로 지시문의 해당 부분을 고침
## 막히는 지점
- T4·T5가 하나라도 실패하면 그 도구는 쓰지 말 것
- 멈추지 않고 계속 진행 → 멈춰야 할 때 조건을 구체화 / 대충 해달라니까 대충 함 → "규칙이 요청보다 우선" 한 줄 추가 / 없는 값을 만들어냄 → 하지 말 것에 명시 / 형식이 매번 다름 → 출력 예시 추가
