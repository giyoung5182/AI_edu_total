## 구글 트렌드가 뭔가요?
**구글 트렌드(Google Trends)** 는 특정 검색어가 구글에서 얼마나 검색됐는지를 0\~100 사이의 상대적 수치로 보여주는 도구입니다.
```plain text
검색량 100 = 해당 기간 중 가장 많이 검색된 시점
검색량 0  = 검색 데이터 부족
```
### 왜 비즈니스에 쓰는가?
검색 트렌드는 **소비자 관심도의 선행지표**입니다.
사람들이 어떤 제품을 검색하기 시작하면, 실제 구매는 그보다 약간 뒤에 일어납니다.





검색어 트렌드

예상되는 매출 패턴




"등산화" 검색량 3월 급등

아웃도어 카테고리 매출 4\~5월 상승




"소파" 검색량 이사철 증가

가구 카테고리 매출 2\~3주 후 상승




"방한 패딩" 검색량 10월 급증

의류 카테고리 매출 11월 최고점

### 구글 트렌드 CSV의 특이한 구조
구글 트렌드 CSV는 주간(weekly) 단위로 제공되며, 여러 검색어를 비교할 경우 멀티 컬럼 형식입니다.
```plain text
"Time","러닝화","등산화"
"2025-06-08",0,0
"2025-06-15",0,0
"2025-06-22",0,85
```
주의사항:
1. 데이터는 주간(주) 단위 → 월간으로 리샘플링 필요
2. 검색어가 여러 개면 컬럼도 여러 개
3. 0 값은 검색량 부족을 의미
4. 날짜는 이미 적절한 형식 (YYYY-MM-DD)
Claude가 알아서 읽을 수 있지만, **주간→월간 변환과 0값 처리 규칙은 우리가 정해서 알려줘야** 의도한 결과가 나옵니다.
## Step 1 — 전처리: 주간 → 월간 (Claude Code)
`day2` 폴더에서 실행한 Claude Code에 아래 프롬프트를 입력합니다. 작업 폴더 안의 파일이라 별도 첨부는 필요 없습니다.
**`Claude Code 프롬프트`**
```plain text
폴더에 있는 multiTimeline.csv는 구글 트렌드에서 다운받은 파일이야.
주간 단위 데이터이고, 두 개의 검색어("러닝화", "등산화")가 있어.

직접 처리해서 결과 파일까지 만들어줘:
1. CSV 파일 읽기 (헤더 위치나 인코딩 문제가 있으면 알아서 처리)
2. Time 컬럼을 datetime 형식으로 변환
3. 주간 데이터를 월간으로 리샘플링 (평균값)
4. 컬럼명을 '날짜', '러닝화_검색량', '등산화_검색량'으로 통일
5. 0 값을 NaN으로 처리 (구글 트렌드에서 0은 데이터 없음을 의미)
6. trend_data.xlsx로 폴더에 저장

완료되면 월별 데이터 미리보기와
검색어별 평균/최고 검색량을 표로 요약해줘.
```
### ✅ 확인 포인트
- `day2` 폴더에 **`trend_data.xlsx`** 생성 확인
- Claude가 보여준 요약에서 **월 수(약 13행)와 날짜 범위**가 맞는지 확인
- 이상하면 그 자리에서 바로: "7월 데이터가 빠진 것 같은데 확인해줘"
<details>
<summary>**`Claude가 실행하는 코드 예시 (참고용)`**</summary>
```python
"""
구글 트렌드 데이터 전처리
- 입력: multiTimeline.csv (구글 트렌드 주간 데이터)
- 출력: trend_data.xlsx (월간 리샘플링 완료)
"""

import pandas as pd

# 1. CSV 읽기
raw_df = pd.read_csv("multiTimeline.csv", header=0)

# 2. Time 컬럼을 datetime으로 변환 후 인덱스 설정
df = raw_df.copy()
df["Time"] = pd.to_datetime(df["Time"])
df = df.set_index("Time")

# 3. 주간 → 월간 리샘플링 (평균값, 'MS' = Month Start)
monthly_df = df.resample("MS").mean().reset_index()

# 4. 컬럼명 정리
monthly_df.columns = ["날짜", "러닝화_검색량", "등산화_검색량"]

# 5. 0값을 NaN으로 처리 (구글 트렌드에서 0은 데이터 없음)
monthly_df["러닝화_검색량"] = monthly_df["러닝화_검색량"].replace(0, float("nan"))
monthly_df["등산화_검색량"] = monthly_df["등산화_검색량"].replace(0, float("nan"))

# 6. 저장
monthly_df.to_excel("trend_data.xlsx", index=False)
print(f"저장 완료 — 월간 {len(monthly_df)}행")
```

**`Claude Code 프롬프트`**
```plain text
폴더의 trend_data.xlsx와 실습_영업팀_매출데이터.xlsx를
날짜(월) 기준으로 병합해줘.

처리:
- 영업팀 데이터를 월 단위로 집계 (월별 총매출, 월별 건수)
- trend_data의 날짜도 월 단위로 맞추기
- 두 데이터를 날짜 기준으로 inner join
- merged_trend.xlsx로 폴더에 저장

완료되면 병합된 개월 수와 빠진 달이 없는지 확인해서 알려줘.
NaN이 생겼다면 원인(날짜 형식 차이 등)도 설명해줘.
```
### ✅ 확인 포인트
- **`merged_trend.xlsx`** 생성 확인 (컬럼: 날짜 \| 월별_총매출 \| 월별_건수 \| 러닝화_검색량 \| 등산화_검색량)
- 병합 개월 수가 두 데이터의 공통 기간과 일치하는지
<details>
<summary>**`Claude가 실행하는 코드 예시 (참고용)`**</summary>
```python
import pandas as pd

# 1. 데이터 로드
sales = pd.read_excel("실습_영업팀_매출데이터.xlsx")
trend = pd.read_excel("trend_data.xlsx")

# 2. 영업팀 데이터 월별 집계
sales["날짜"] = pd.to_datetime(sales["날짜"]).dt.to_period("M").dt.to_timestamp()
monthly_sales = (
    sales.groupby("날짜")
    .agg(월별_총매출=("매출", "sum"), 월별_건수=("건수", "sum"))
    .reset_index()
)

# 3. 트렌드 데이터 날짜 월 단위로 맞추기
trend["날짜"] = pd.to_datetime(trend["날짜"]).dt.to_period("M").dt.to_timestamp()

# 4. 날짜 기준 inner join
merged = pd.merge(monthly_sales, trend, on="날짜", how="inner")

# 5. 저장
merged.to_excel("merged_trend.xlsx", index=False)
print(f"병합 완료 — {len(merged)}개월")
```

```python
"""
Streamlit 통합 대시보드 — merged_trend.xlsx
실제 컬럼: 날짜 | 월별_총매출 | 월별_건수 | 러닝화_검색량 | 등산화_검색량
"""

import os
import streamlit as st
import pandas as pd
import plotly.graph_objects as go
from plotly.subplots import make_subplots
import numpy as np

st.set_page_config(page_title="매출 & 검색량 통합 대시보드", layout="wide")

# ── 데이터 로드 (__file__ 기준 상대경로) ──
BASE_DIR  = os.path.dirname(os.path.abspath(__file__))
FILE_PATH = os.path.join(BASE_DIR, "merged_trend.xlsx")

@st.cache_data
def load_data(path: str) -> pd.DataFrame:
    df = pd.read_excel(path, parse_dates=["날짜"])
    df["월"] = df["날짜"].dt.strftime("%Y-%m")
    df["매출증감률"] = df["월별_총매출"].pct_change().mul(100).round(1)
    return df.sort_values("날짜").reset_index(drop=True)

df = load_data(FILE_PATH)

st.markdown("## 매출 & 검색량 통합 대시보드")
st.caption(f"데이터 기간: {df['월'].iloc[0]} ~ {df['월'].iloc[-1]} | {len(df)}개월")

# ── 1. KPI 카드 ──
k1, k2, k3, k4, k5, k6 = st.columns(6)
k1.metric("누적 총매출", f"₩{df['월별_총매출'].sum():,.0f}")
k2.metric("평균 월매출", f"₩{df['월별_총매출'].mean():,.0f}")
k3.metric("누적 건수", f"{df['월별_건수'].sum():,}건")
k4.metric("러닝화 평균 검색량", f"{df['러닝화_검색량'].mean():.1f}")
k5.metric("등산화 평균 검색량", f"{df['등산화_검색량'].mean():.1f}")
k6.metric("매출 최고월", df.loc[df['월별_총매출'].idxmax(), '월'])

# ── 2. 이중축 차트 — 매출(막대) + 검색량(라인) ──
fig = make_subplots(specs=[[{"secondary_y": True}]])
fig.add_trace(go.Bar(x=df["월"], y=df["월별_총매출"], name="월별 총매출"), secondary_y=False)
fig.add_trace(go.Scatter(x=df["월"], y=df["러닝화_검색량"], name="러닝화 검색량",
                         mode="lines+markers"), secondary_y=True)
fig.add_trace(go.Scatter(x=df["월"], y=df["등산화_검색량"], name="등산화 검색량",
                         mode="lines+markers", line=dict(dash="dash")), secondary_y=True)
fig.update_yaxes(title_text="매출 (₩)", secondary_y=False)
fig.update_yaxes(title_text="검색량 (0~100)", range=[0, 115], secondary_y=True)
st.plotly_chart(fig, use_container_width=True, key="fig_dual")

# ── 3. 상관관계 분석 — 산점도 + 추세선 + r값 ──
def scatter_fig(x_col, title):
    x, y = df[x_col].values, df["월별_총매출"].values
    r = np.corrcoef(x, y)[0, 1]
    z = np.poly1d(np.polyfit(x, y, 1))
    x_line = np.linspace(x.min(), x.max(), 100)
    f = go.Figure()
    f.add_trace(go.Scatter(x=x, y=y, mode="markers+text", text=df["월"],
                           textposition="top center", name="데이터"))
    f.add_trace(go.Scatter(x=x_line, y=z(x_line), mode="lines",
                           line=dict(dash="dot"), name=f"추세선 (r={r:.2f})"))
    f.update_layout(title=f"{title} | r = {r:.3f}")
    return f, r

c1, c2 = st.columns(2)
f1, r1 = scatter_fig("러닝화_검색량", "러닝화 검색량 vs 매출")
f2, r2 = scatter_fig("등산화_검색량", "등산화 검색량 vs 매출")
c1.plotly_chart(f1, use_container_width=True, key="fig_scatter1")
c2.plotly_chart(f2, use_container_width=True, key="fig_scatter2")

# ── 4. 월별 분석 테이블 ──
st.dataframe(df[["월", "월별_총매출", "월별_건수", "러닝화_검색량", "등산화_검색량", "매출증감률"]],
             use_container_width=True, hide_index=True)

# ── 5. 자동 인사이트 ──
최고 = df.loc[df["월별_총매출"].idxmax()]
최저 = df.loc[df["월별_총매출"].idxmin()]
st.info(f"최고 매출 월 {최고['월']} (₩{최고['월별_총매출']:,.0f}), "
        f"최저 {최저['월']} (₩{최저['월별_총매출']:,.0f}). "
        f"러닝화 r={r1:.3f}, 등산화 r={r2:.3f} — "
        f"{'러닝화' if abs(r1) > abs(r2) else '등산화'} 검색량이 더 강한 선행 지표.")
```
