# Custom Webhook + Search Rows + Router 3분기 + Update Row

정리일: 2026-10-08 · 교육 에셋 N0509

## 이 실습으로 하는 것
Webhook으로 시나리오를 시작해 대기 행을 찾고, 세 갈래(관리자·취소 당사자·추가 당사자)로 나눠 메일을 보낸 뒤 시트의 발송여부를 갱신합니다.
## 진행 단계
1. **Custom Webhook** — Webhook name 지정 후 Add → Webhook URL 복사, Waiting for data 표시
2. **테스트 데이터 전송** — 브라우저에서 URL 뒤에 ?test=1 접속, 또는 Redetermine data structure에 샘플 JSON 입력
3. **Search Rows** — Filter: I열(발송여부) Equal to 대기, Limit 100
4. **Router (3 브랜치)** — 기본 2개 + Add route로 1개 추가
5. **브랜치 1 관리자** — Filter 관리자체크 = TRUE → Gmail (관리자 이메일)
6. **브랜치 2 취소 당사자** — Filter 삭제직원이메일 Is not empty → Gmail
7. **브랜치 3 추가 당사자** — Filter 추가직원이메일 Is not empty → Gmail
8. **Update a Row** — 각 Gmail 뒤에 추가, Row number에 Search Rows의 Row Number 변수, I열에 "발송완료" 입력
9. **전체 테스트** — 세 메일 수신과 I열 "발송완료" 변경 확인
## 막히는 지점
- Row number 설정: 드롭다운에서 Search Rows 모듈의 Row Number 변수를 선택해야 해당 행이 업데이트됨
- 브랜치별로 이메일이 다르게 와야 정상. 같은 내용이 3번 오면 Filter 조건이 잘못된 것
- 실제 수업에서는 GAS 버튼이 Webhook URL을 호출하며, 사전 실습은 임시 방법으로 연결 확인
