# 실습 1. 팀 채팅방 만들기

정리일: 2026-10-08 · 교육 에셋 N0418

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
집필팀의 협업 과정을 실시간으로 중계하는 팀 채팅방 페이지를 추가하고, 말풍선 하나와 서버 메시지 기록 한 줄을 짝짓는다.
## 진행 단계
1. **프롬프트 입력** — 작업 시작 전 창②(Claude Code)에서 `/clear`를 실행하고 프롬프트를 입력한다
- 입력할 내용:
```javascript
집필팀의 협업 과정을 보여주는 팀 채팅방을 만들어 주세요. 요구사항입니다.

1. /team 경로에 새 페이지를 만들고 상단 메뉴에 추가해 주세요.

2. 오케스트레이터 집필의 모든 에이전트 간 통신을 메시지 기록으로 남겨 주세요. 메시지 한 건의 형식은 time, from, to, type, content 항목을 가진 JSON입니다. (이하 교안 참고)
```
2. **서버 재시작** — 창①에서 서버를 재시작하고 /team 페이지를 연다
3. **관전** — \[집필 시작\]을 누르고 화면에서 손을 떼고, 지시서 전달 말풍선 5건 / 1\~5장 담당 배지가 "집필 중"으로 바뀌는 순간 / 집필 보고 말풍선 / 오케스트레이터 배지 "검토 중" / 검토 결과와 수정 요망 말풍선을 확인한다
4. **편집장 질문 답하기** — 편집장 질문 말풍선이 뜨면 입력칸에 답하고 내 답장이 말풍선으로 올라가는지 확인한다
5. **짝짓기** — 완료 선언까지 지켜본 뒤 인상 깊은 말풍선 하나를 고르고, 창① 로그에서 같은 시각의 기록 한 줄을 찾아 같은 메시지임을 설명한다
- 정상 결과: 메시지가 1초 안에 화면에 반영되고 화면 말풍선과 로그 한 줄이 1:1로 대응됨
## 막히는 지점
- 말풍선이 안 올라옴 → 새로고침 후에도 그대로면 "채팅방 폴링이 동작하지 않습니다. 점검해 주세요"라고 요청
- 말풍선이 한꺼번에 몰려 뜨임 → "메시지가 발생 즉시 저장되어 폴링에 잡히게 바꿔 주세요"라고 요청
- 429 에러 → 1\~2분 뒤 재실행, 반복되면 호출 간 대기를 늘려 달라고 요청
