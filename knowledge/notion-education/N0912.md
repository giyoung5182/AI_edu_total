## PART 4. Canva AI 심화 — Magic Studio 워크플로우 체이닝 (40분)
> Canva AI를 "예쁜 이미지 만드는 곳"으로만 쓰면 진짜 힘을 못 씁니다. 파워유저는 Magic Studio의 여러 도구를 **체이닝**해서 하나의 콘텐츠를 수십 개 포맷으로 자동 확장합니다.
---
### 4-1. Magic Studio는 개별 기능이 아니라 "연결된 워크플로우"
```plain text
Canva AI 2026년 기준 핵심 도구 지도:

Magic Design    — 프롬프트/이미지 → 완성 레이아웃 생성
Magic Media     — 텍스트 → 이미지·영상 생성 (Dream Lab 통합)
Magic Write     — 브랜드 보이스 반영 카피 생성
Magic Switch    — 완성 디자인을 다른 포맷·언어로 즉시 변환
Magic Grab      — 이미지 안의 특정 요소만 분리·재배치
Magic Expand    — 배경 확장
Magic Morph     — 이미지 안 특정 형태를 다른 형태로 변형
Magic Animate   — 정적 디자인에 애니메이션 적용
Bulk Create     — 데이터(CSV/시트)를 대량 디자인으로 자동 변환

★ 파워유저는 이 도구들을 하나씩 따로 쓰지 않고
  체인으로 연결해서 하나의 결과물을 수십 개 파생물로 만듭니다.

내부 구조 참고: Canva의 AI 오케스트레이션은
여러 파운데이션 모델(OpenAI 계열 포함)을 조합해서
각 도구별로 최적 모델을 자동 배분하는 방식으로 작동합니다.
→ 이 때문에 같은 Magic Studio 안에서도 도구마다
  결과물의 "성격"이 다르게 느껴지는 것이 정상입니다.
```

### 4-2. Magic Switch — 하나의 콘텐츠를 모든 포맷으로
```plain text
Magic Switch는 완성된 디자인을 다른 형식·크기·언어로
즉시 변환하는 기능입니다. 단순 리사이즈가 아니라
내용 자체를 문맥에 맞게 재구성합니다.

실전 예시 — 화이트보드를 여러 포맷으로:
"이 포스터를 발표 자료로 변환해줘"
"이 발표 자료를 요약 이메일로 바꿔줘"
"이 문서를 가로형으로 바꿔줘"
"이 강의 소개서를 영어로 번역해줘" (100개 이상 언어 지원)

강사 활용 — 콘텐츠 1개 → 5개 채널로 자동 확장:
Step 1. 강의 홍보 포스터 1개를 Canva로 완성
Step 2. Magic Switch로:
        → 인스타그램 정사각형 버전
        → 카카오톡 공유용 세로형 버전
        → 이메일 뉴스레터용 요약 버전
        → 발표용 슬라이드 버전
Step 3. 채널별로 5분 안에 모두 완성

→ "포스터 하나 만들면 5개 채널용 콘텐츠가 자동으로 나온다"가
   Magic Switch의 진짜 힘입니다.
```

### 4-3. Bulk Create — 데이터 기반 대량 콘텐츠 생성
```plain text
Bulk Create는 Magic Studio 안에 포함된 게 아니라
Canva 앱스토어에서 무료로 추가하는 별도 앱이지만,
Magic Write와 결합하면 폭발적인 생산성을 냅니다.

작동 원리:
1. 구글 시트/CSV에 데이터를 입력
   (예: 회차별 주제, 날짜, 핵심 키워드)
2. Canva 디자인에 데이터를 "연결"
3. Bulk Create 실행 → 데이터 행 개수만큼 디자인이
   자동으로 대량 생성됨

강사 활용 — 회차별 홍보 카드 10장을 한 번에:
시트에 [회차, 날짜, 주제, 핵심 문구] 4개 열을 채워두고
Bulk Create 실행 → 9회차 전체의 홍보 카드뉴스가
디자인 하나의 템플릿을 기반으로 자동 완성됨

실무 규모 참고 사례: 실제 200개 제품을 보유한 쇼핑몰이
Bulk Create + Magic Write 조합으로 한 시간 안에
전체 프로모션 그래픽을 완성한 사례가 있습니다.
→ 강사에게는 "9회차 카드뉴스" 정도지만,
   같은 원리로 수백 개 단위까지 확장 가능한 구조입니다.
```

### 4-4. Magic Write — "첫 초안 작성기"가 아니라 "2차 편집기"로 쓰기
```plain text
⚠ 파워유저 원칙: Magic Write를 최초 카피라이터로 쓰지 말 것

이유: AI가 생성한 문구를 수정 없이 그대로 쓰면
     "AI가 만든 마케팅 문구" 특유의 티가 남 (상투적 표현)

올바른 사용:
1. 이사님이 직접 핵심 메시지를 짧게라도 먼저 작성
2. Magic Write에게 "이 문장을 다듬어줘,
   브랜드 보이스는 [따뜻하고 신뢰감 있게] 유지하면서"
   → 2차 편집기로 사용
3. 나온 결과를 다시 한번 이사님 특유의 어투로 손질

→ Magic Write는 초안 작성기가 아니라 다듬는 도구로 쓸 때
   결과물이 훨씬 자연스럽습니다.
```

### 4-5. Brand Kit — 왜 반드시 먼저 설정해야 하는가
```plain text
실증 데이터:
Brand Kit을 먼저 설정하고 시작하면 AI 결과물의
브랜드 일치도가 20%에서 80%로 상승한다는 연구 결과가 있습니다.

Brand Kit에 등록해야 할 것:
- 로고
- 브랜드 컬러 (심지 또는 교육기관 20 관련 색상)
- 폰트
- 톤앤매너 가이드 (텍스트로 간단히 기술 가능)

설정 후 효과:
Magic Design·Magic Write·Magic Media 등 모든 AI 도구가
자동으로 이 Brand Kit을 참조해서 결과물을 생성
→ 매번 색상·폰트를 수동으로 맞추지 않아도
   일관된 톤의 강의 자료가 나옴
```

### 4-6. 데이터 스토리텔링 — Canva Sheets + Magic Charts
```plain text
활용 사례:
수강생 만족도 조사 원본 데이터(CSV)를
Canva Sheets에 붙여넣기 →
Magic Charts가 데이터 특성에 맞는 차트 유형을
자동으로 선택(막대·선·폭포형 등)해서 시각화 +
트렌드 요약까지 자동 생성

강사 활용:
매 회차 수강생 피드백을 누적 기록해두고,
"지금까지 만족도 추이를 차트로 만들고
 트렌드를 요약해줘" → 즉시 시각 자료 완성
→ 대표님께 성과 보고할 때도 바로 활용 가능
```

### 4-8. 실습 (15분)
```plain text
실습 1 (7분): Magic Switch 체이닝 실습
  강의 홍보 포스터 1개를 Magic Design으로 생성 →
  Magic Switch로 2가지 다른 포맷(인스타 정사각형,
  이메일 요약)으로 즉시 변환해보기

실습 2 (5분): Brand Kit 설정
  심지 또는 개인 강의 브랜드 컬러 2~3개, 폰트 1개를
  Brand Kit에 등록 후, Magic Design으로 카드 하나 생성해서
  자동 반영되는지 확인

실습 3 (3분): Magic Write를 2차 편집기로 사용해보기
  직접 쓴 짧은 문구를 Magic Write에게 "다듬어줘" 요청 →
  Zero-Shot으로 바로 생성 요청한 것과 결과 비교
```

## PART 5. 3개 도구 통합 실습 (10분)
```plain text
실전 파이프라인 완성해보기:

Step 1. NotebookLM에 3회차 교안 업로드
        → "핵심 내용 5개를 강의 슬라이드용으로 정리해줘"

Step 2. 나온 결과를 마크다운 헤딩으로 재구조화 후 Gamma에 붙여넣기
        → 카드 단위 슬라이드 생성

Step 3. 완성된 슬라이드 중 핵심 1장을 Canva로 옮겨서
        Magic Switch로 SNS 홍보 카드로 변환

→ NotebookLM(근거) → Gamma(발표) → Canva(홍보)
  하나의 원천 자료가 3가지 다른 결과물로 흐르는 것을 직접 체감
```
