# 실습 2. 카드 2 — 고객 문의 메일 분류: 예외 규칙 하나만 바꾸기

정리일: 2026-10-08 · 교육 에셋 N1083

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
메일 20건을 유형 사전으로 분류(v1)한 뒤 예외 규칙 블록 하나만 추가(v2)해, 어떤 메일의 유형이 바뀌는지와 판단 근거 인용을 확인한다.
## 진행 단계
1. **v1 — 유형 사전만 있는 분류** — 새 채팅 → 프롬프트 붙여넣기 → 메모장에서 메일 전문(Ctrl+A, Ctrl+C)을 맨 아래 자리에 붙여넣기 → Enter
- 입력할 내용: \[역할\]/\[과업\]/\[유형 사전 Q·K·C·S·I와 제외 기준\]/\[출력 3열 표 + 유형별 건수\]/\[메일 본문\] (교안 참고)
- 정상 결과: 메일번호·유형 코드·판단 근거 3열 표 + 유형별 건수
2. **5건 기록** — MAIL-05, 06, 10, 13, 20의 v1 유형을 워크시트 P2-3에 기록
3. **v2 — 예외 규칙만 추가** — 새 채팅에서 v1과 같은 프롬프트 + `H 판단 보류` 유형과 ［예외 처리 규칙］(복합 메일은 주(+부) 표기, H는 이유 기재, 새 유형 금지)
4. **v2 기록** — 같은 5건 + 유형별 건수
5. **스스로 판정** — 내 판단·근거 문구(메모장 Ctrl+F)·판정 기록
## 막히는 지점
- 한글이 깨짐 → 연결 프로그램에서 메모장으로 다시 열기
- 표 없이 문단으로 나옴 → '3열 표로만 다시 보여줘. 분류 결과는 바꾸지 마라.'
- 합계가 20이 아님 → 맨 위 안내 문구를 메일로 센 경우 MAIL-01\~20만 다시 세게 요청
- 판단 근거 인용이 원문에 없음 → 해당 메일에서 그대로 다시 인용하게 요청
