# Copilot Chat FAQ
### 1. 코파일럿 챗 실습 전 준비환경
Copilot Chat은 기본적으로 OneDrive나 SharePoint와 같은 클라우드에 저장된 파일을 기준으로 동작합니다.
따라서 실습 중에 사용하는 파일은 개인 PC에만 저장되어 있을 경우 Copilot에서 정상적으로 인식되지 않을 수 있으며, 파일을 활용하려면 클라우드에 업로드하는 과정이 필요합니다.
이를 원활하게 하기 위해 OneDrive를 활성화하여 사용하는 것을 권장 드립니다.
특히 OneDrive 데스크톱 앱이 실행되어 있으면, 다운로드한 파일이 자동으로 OneDrive에 동기화되어 Copilot에서 바로 활용할 수 있어 실습이 훨씬 수월해집니다.
반대로 OneDrive가 연결되어 있지 않은 경우에는 파일 업로드를 별도로 진행해야 하거나 Copilot에서 파일을 찾지 못하는 상황이 발생할 수 있습니다.
OneDrive 데스크톱 앱이 실행되어 있는 경우, PC의 일부 기본 폴더(바탕화면, 문서, 사진 등)에 저장된 파일은 자동으로 OneDrive에 동기화됩니다.
따라서 해당 위치에 파일을 다운로드하거나 저장하면 사용자가 별도로 업로드를 하지 않아도 자동으로 OneDrive에 업로드되며, Copilot에서 바로 활용할 수 있어 실습 진행이 매우 수월해집니다.
다만 모든 파일이 자동으로 OneDrive에 저장되는 것은 아니며, 다운로드 폴더(Downloads)나 OneDrive와 연결되지 않은 다른 폴더에 저장된 파일은 자동으로 동기화되지 않습니다.
이 경우에는 파일을 직접 OneDrive 폴더로 이동하거나, 별도로 업로드를 진행해야 Copilot에서 활용할 수 있습니다.
따라서 실습 시에는 가급적 OneDrive와 연결된 폴더(바탕화면, 문서 등)에 파일을 저장하여 자동 동기화 기능을 활용하는 것을 권장드립니다.

### 11. Copilot Chat ‘/사람’ 명령어 사용 제한 안내
Copilot Chat에서 사용하는 ‘/사람’ 명령어는 모든 환경에서 공통으로 제공되는 기능이 아닙니다.
해당 기능은 Microsoft 365 Copilot 환경에서 조직 내 사용자 정보(사람, 조직도 등)에 접근할 수 있는 경우에만 제공되는 기능으로, 일반 Copilot Chat(웹 버전)에서는 기본적으로 제공되지 않을 수 있습니다.
또한 ‘/사람’ 명령어의 사용 가능 여부는 다음과 같은 조건에 따라 달라질 수 있습니다.
- Microsoft 365 Copilot 라이선스 보유 여부
- 조직(회사)의 보안 및 관리자 설정
- 사용 중인 Copilot 버전 또는 실행 환경 (웹, Teams, 앱 등)
따라서 일부 환경에서는 해당 명령어가 표시되지 않거나, 입력하더라도 동작하지 않을 수 있으며 이는 오류가 아닌 정상 동작 차이에 해당합니다.
‘/사람’ 기능은 조직 데이터와 연동된 기능이므로, 사용 환경에 따라 제공 여부가 달라질 수 있다는 점 참고 부탁드립니다.
