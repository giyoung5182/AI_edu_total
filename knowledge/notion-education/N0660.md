# 실습 2-C-1. 견적서 → 현장 완료 보고서

정리일: 2026-10-08 · 교육 에셋 N0660

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
견적서 내용을 기반으로 클라이언트 제출용 현장 완료 보고서 초안을 생성합니다.
## 진행 단계
1. **프롬프트 입력 (6분)** — \[R-Role\] 공무 담당 매니저 / \[C-Context\] 시공 완료 후 공식 완료 보고 / \[T-Task\] 표지 정보, 공사 개요, 항목별 완료 현황 표, 특이 사항, A/S 안내, 마무리 문구 / \[C-Constraint\] "\~하였습니다" 공문체, 금액 숫자+한글 병기, 마크다운 표, 수량 단위 명확 표기, A4 1.5\~2장 / \[K-Knowledge\] 공사 정보(항목·수량·특이 사항)
- 입력할 내용: 교안의 RCTCK 프롬프트(공사 정보 포함)를 그대로 입력 (이하 교안 참고)
2. **결과 확인 (3분)**
- 정상 결과: 표지 정보 포함, 항목별 표가 깔끔함, 금액 숫자+한글 병기, "\~하였습니다" 공문체, A/S 안내 문구 포함, 현장 추가 항목까지 특이 사항에 반영
3. **체이닝 (4분)** — 특이 사항 섹션이 단순 나열이면 "특이 사항 및 현장 대응 내역을 더 구체적으로, 경위·처리 방법을 각각 3\~4문장으로, 공문 어투 유지"를 요청. A/S 안내는 기간·연락 방법·하자 보수와 추가 요청의 구분·긴급 연락처를 포함하도록 보강 요청.
## 막히는 지점
- 특이 사항 섹션이 단순 나열에 그칠 때: 체이닝으로 경위·처리 방법을 구체화
