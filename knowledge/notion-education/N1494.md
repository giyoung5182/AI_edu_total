# (향후 과제) 문장 4층 분류와 내 기준 정하기 — 호텔 예약 변경 메모

정리일: 2026-10-08 · 교육 에셋 N1494

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
교육용 가상 메모 10문장(EX-1\~EX-10)을 사람이 먼저 세운 기준으로 사실/해석/제안/미확인으로 분류한 뒤, ChatGPT 분류와 비교해 갈린 문장을 찾습니다.
## 진행 단계
1. **예측 기록** — 워크시트 Part4 시트 A-1 예측 칸(사실 문장 수, 가장 갈릴 문장 번호)
2. **내 기준 먼저 쓰기** — Part4 시트 → A-2 내 기준 문장 → "나는 ***이면 사실로 본다" / "나는 ***이면 해석으로 본다" 각 1줄
3. **10문장 손으로 분류** — A-3 분류표의 내 분류(B열)·표기 보완 O/X(C열)
- 입력할 내용: 교안의 EX-1\~EX-10 문장(교육용 가상 사례, 실제 데이터 아님). 예: EX-1 "8월 호텔 예약 변경 요청은 42건임(8/1\~8/31 접수 기준, 변경요청 대장)." (이하 교안 참고)
4. **AI 분류와 비교** — ChatGPT 새 채팅 → 프롬프트(\[역할\] 보고서 검토 담당자 / 사실·해석·제안·미확인 기준 / 해석을 사실처럼 단정하면 "해석(단정 오류)" 표시) 붙여넣기 → 맨 아래 줄을 EX 문장으로 교체 → Enter(줄바꿈은 Shift+Enter)
- 정상 결과: A-3 표 EX-1\~EX-10 10행의 "내 분류"·"AI 분류"·"불일치" 칸이 모두 채워짐
5. **내 자료 적용** — A-4에 Part 3 결과 문장 3개 적용
## 막히는 지점
- "\~때문", "\~로 인해" 문장은 원인 주장인지 확인
- 원파일로 다시 계산 가능한지, 다른 설명이 가능한지 두 질문을 기준 문장에 넣어 보기
