# 실습 2. 카드 2 — 고객 문의 메일 분류: 예외 규칙 하나만 바꾸기

정리일: 2026-10-08 · 교육 에셋 N1082

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
유형 사전만 있는 분류(v1)에 예외 규칙 블록 하나만 더해(v2) 결과가 어떻게 달라지는지 비교합니다. (교안에는 '향후 과제'로 표시)
## 진행 단계
1. **v1 — 유형 정의만 있는 분류** — 메일 전문을 붙여넣어 분류.
- 입력할 내용(요약, 이하 교안 참고):
```plain text
[역할] 너는 고객 문의 메일을 담당 부서로 배정하기 위해 분류하는 담당이다.
[과업] 아래 고객 문의 메일 20건을 유형 사전에 따라 분류하라.
[유형 사전] Q 견적·예약 / K 계약 / C 클레임 / S 정산·결제 / I 자료·안내 (유형별 제외 기준 포함)
[출력] 표 1개: 메일번호 | 유형 코드 | 판단 근거(메일 본문 속 문구를 따옴표로 인용)
(이하 교안 참고)
```
- 정상 결과: 메일번호·유형 코드·판단 근거 3열 표 + 표 아래 유형별 건수
1. **v1 기록** — MAIL-05, 06, 10, 13, 20의 유형을 P2-3 표 v1 열에 기록.
2. **v2 — 예외 규칙만 추가** — 새 채팅에서 v1과 글자 하나 다르지 않게 두고 H 판단 보류 유형과 예외 처리 규칙(복합 메일은 주 유형 (+부 유형), H는 이유 기재, 새 유형 생성 금지)만 추가.
- 정상 결과: 일부 메일의 유형이 H 또는 Q (+I) 형태로 바뀜
3. **v2 기록·스스로 판정** — 같은 5개 메일의 v2 결과와 내 판단을 기록.
## 막히는 지점
- 합계가 20이 아님 / 판단 근거가 인용이 아니라 해석 / 사전에 없는 유형 생성 / 복합 메일을 하나로만 표시 / H를 너무 많이 씀 / 부 유형 표기가 행마다 다름
