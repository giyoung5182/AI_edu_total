# Block 3 — Gemini Gems 직군별 세팅

정리일: 2026-10-08 · 교육 에셋 N1017

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
강사가 기획팀 Gem을 화면에서 시연한 뒤, 전원이 각자 직군에 맞는 Gem을 세팅합니다.
## 진행 단계
1. **Gem 만들기 진입** — gemini.google.com → 좌측 사이드바 → "Gems 탐색" → 우측 상단 "+ 새 Gem 만들기".
2. **이름 입력** — 직군별 Gem 이름 입력란에 이름을 입력(교안 예: 기획팀 "교육기관 제안서 기획봇", 디자인팀 "교육기관 컨셉 텍스트봇", 공무팀 "교육기관 공무 자동화봇").
3. **지침 붙여넣기** — 지침 입력란에 역할·글쓰기 원칙 등 지침 전체를 복사해 붙여넣음(지침 전문은 교안 참고).
4. **저장** — 저장 버튼 → 사이드바에 표시됨. 저장 전 오른쪽 테스트 대화창에서 미리 테스트 가능.
5. **테스트** — 직군별 테스트 문장으로 동작 확인.
- 정상 결과: 기획팀은 PROLOGUE가 역설적 선언으로 시작하고 STRATEGY 전략명에 영문이 붙음 / 디자인팀은 존 네이밍이 기억에 남고 페르소나가 나이·직업으로 구체화됨 / 공무팀은 공문 번호 형식과 수신·발신·제목·본문·붙임 구조, '\~하였습니다' 공문체
