# 실습 3. 자동 채점기 만들기

정리일: 2026-10-08 · 교육 에셋 N1027

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정답이 알려진 질문 세트로 챗봇 답변을 AI가 1\~5점으로 채점하는 평가 장치를 만들고, K값을 바꿔 가며 리포트로 비교합니다.
## 진행 단계
1. **질문 세트 만들기** — evals/questions.json에 질문·정답 5쌍(id, question, reference_answer)을 만들도록 Claude Code에 요청합니다.
- 입력할 내용: 교안의 프롬프트 1) — evals 폴더 생성, "questions" 배열, 한글 그대로 저장, 5쌍 입력, 저장 후 JSON 문법 확인 (이하 교안 참고)
2. **자동 평가 기능 추가** — 프롬프트 2): questions.json을 읽어 각 질문을 챗봇 파이프라인에 통과시키고, Gemini가 점수(1\~5)·근거 정합성(예/아니오)·사유로 채점. 호출 사이 대기, /evals 리포트(문항별 점수 표, 평균, 정합성 통과 수, K값 기록), "평가 실행" 버튼과 K값 입력칸.
3. **K=3 평가 실행** — 서버 재시작 후 /evals에서 실행. 5문항이라 몇 분 걸리며 창①의 로그로 진행을 봅니다.
4. **리포트 확인** — 평균 점수와 문항별 점수. 점수가 낮은 문항은 사유를 읽고 해당 질문을 /search에 넣어 검색부터 점검합니다.
5. **예측** — K를 8로 올리면 평균 점수가 오를지 내릴지 이유와 함께 적습니다.
6. **K=8 재실행·비교** — 두 리포트를 비교합니다.
7. **K값 결정** — 리포트를 근거로 시스템의 K값을 하나 정합니다(정답은 없음).
## 막히는 지점
- 평가 도중 429 에러: 창②에 "호출 사이 대기를 더 길게 잡아 주세요"라고 요청한 뒤 재실행.
- 채점 결과가 형식대로 안 나옴: "채점 출력을 JSON 형식으로 고정해 주세요"라고 요청.
- 같은 조건인데 점수가 조금 다름: 정상 범위. 평균의 큰 추세로 판단.
- 특정 문항만 계속 0점대: 검색 실패 가능성. /search에서 정확한 청크가 나오는지 확인.
