# 핫🔥한 깃허브 스킬 TOP 10
트렌드 딸깍이 직접 확인하고 정리한 리스트임. <br>카드뉴스에 나온 5개 + 여기서만 공개하는 보너스 5개까지 총 10개.
일단 사용법은** 깃허브 링크를 클로드에게 복붙하고 “설치하는법 단계별로 알려줘” 라고만 해도 다 알려줌.**

## 카드뉴스에 나온 5개
### 1. draw-your-font
<embed src="[개별 링크 제외]"></embed>
**뭐하는 거?** 종이에 손글씨 쓰고 사진 찍어서 넘기면 그 필체 그대로 TTF/WOFF 폰트 파일로 만들어줌. "둥글게", "굵게" 같은 디테일도 말로 요청하면 다듬어줌.
**설치**
```plain text
GitHub 레포 클론 후 README 안내 따라 설치
```
**라이브 데모**: 설치 없이 브라우저에서 바로 체험 가능
**링크**: [https://github.com/danilo-znamerovszkij/draw-your-font](https://github.com/danilo-znamerovszkij/draw-your-font)
**한계**: 알파벳 기준이라 한글은 아직 지원 안 됨

### 2. open-image-prompts
**뭐하는 거?** 이미지 생성 프롬프트와 결과 이미지를 짝지어 모아둔 검색 가능한 자료 창고. "저 이미지 뭐로 만든 거지?" 문제를 정면으로 해결함. 프롬프트 약 1만4천개, 이미지 2만4천여 장을 185개 카테고리로 분류해둠.
**설치**
```bash
git clone https://github.com/NanmiCoder/open-image-prompts.git
cd open-image-prompts
# macOS/Linux
./start.sh
# Windows
start.bat
```
**라이브 데모**: 갤러리 구경 가능<br>👉 [개별 링크 제외]
**링크**: [https://github.com/NanmiCoder/open-image-prompts](https://github.com/NanmiCoder/open-image-prompts)
💡 웹사이트만 봐도 됨? vs 설치까지 해야 됨?
웹사이트(openimages.relakkesyang.org)는 그냥 눈으로 프롬프트-이미지 갤러리<br>구경하는 뷰어임. 궁금한 사람은 이거만 열어봐도 충분함.
설치본은 다름. 이건 AI 에이전트(클로드코드 등)한테 심어주는 기능임.<br>설치하면 작업 중에 "이런 느낌 프롬프트 찾아줘" 했을 때 AI가 웹사이트<br>안 열고도 로컬 DB 1만4천개를 바로 뒤져서 참고자료로 씀.
정리하면 — 구경만 할 거면 웹사이트, 내 AI 워크플로우에 박아넣고<br>싶으면 설치. 목적이 다름.
**한계**: 이미지 전부 받으려면 저장공간 4GB 넘게 필요함 (DB만 받는 경량 옵션도 있음)

### 3. claude-quest
**뭐하는 거?** 클로드 코드 작업할 때 터미널 텍스트 대신 픽셀아트 RPG 캐릭터가 실시간으로 반응함. 파일 읽기=마법 시전, bash 명령=공격 애니메이션, 코드 작성=끄적이는 애니메이션, 에러=데미지(회복됨), 성공=승리 댄스, git push=SHIPPED 무지개 배너.
**설치**
```bash
npm install -g claude-quest
```
설치 후 클로드 코드 돌리는 것과 **별도의 새 터미널 탭**에서:
```bash
cq
```
[원본 이미지 제외]
**링크**: [https://github.com/Michaelliv/claude-quest](https://github.com/Michaelliv/claude-quest)
**참고**: 완전 로컬 동작, API 키나 네트워크 연결 필요 없음. 레벨업하면서 모자/얼굴/오라/트레일 코스튬도 풀림.

### 4. Finn-loop
**뭐하는 거?** 기획-개발-검수 3단계로 나눠 도는 바이브코딩 조립라인. 첫 스킬이 애매한 구석 없어질 때까지 질문한 뒤 작업 항목으로 등록하고, 두 번째 스킬이 정해진 범위만 만들어서 반영 요청을 올리고, 세 번째 스킬이 기준과 대조해 검토 의견을 남김. 최종 반영 결정만은 반드시 사람이 하게 못박아둠.
**설치**: 레포 README 참고
**참고 자료**: 제작자 Alex Finn이 직접 만든 사용법 가이드<br>👉 [개별 링크 제외]
**링크**: https://github.com/finna/Finn-loop

### 5. graph-engineering
**뭐하는 거?** AI 에이전트 여러 개 굴리는 자동화 체계의 설계 방법론. 프롬프트 다듬는 단계보다 한 층 아래, 정보의 짜임새(지식그래프)와 작업 순서(태스크그래프)를 다룸. 동남대 대학원 지식그래프 강의를 영어로 번역한 자료 기반. 내 프로젝트를 예시로 단계별로 가르쳐주는 티칭 모드 있음.
**설치**
```bash
git clone https://github.com/codejunkie99/graph-engineering.git
cp -r graph-engineering/graph-engineering ~/.claude/skills/
```
**사용법**: 클로드한테 "지식그래프 만들어줘" 또는 "graph engineering 가르쳐줘"라고 요청
**링크**: https://github.com/codejunkie99/graph-engineering
**한계**: 상당히 학술적인 내용이라 진입장벽 있는 편

## 🎁 보너스 5개 (카드뉴스엔 안 나왔지만 이것도 좋음)
### 6. humanizer-stack
AI가 쓴 티를 지우는 글 다듬기 도구. 문체를 가리고 짜임새만 봐도 AI 글을 93% 넘게 잡아낸다는 연구 근거를 역이용해서, 단어를 고치는 1차와 글 구조를 다시 짜는 2차를 순서대로 돌림. 제안서, 뉴스레터처럼 사람 냄새 필요한 글에 씀.
- **링크**: https://github.com/NulightJens/humanizer-stack
- **한계**: 영어 기준이라 한국어 문장엔 제한적
### 7. story-to-handdrawn-video
글로 쓴 이야기를 손그림 일기 만화 스타일 영상으로 자동 변환. 문장 넣으면 원문 표현 살려서 장면 나누고 손글씨 자막까지 얹어줌. 소리는 일부러 비워둬서 목소리 따로 입히기 좋음.
- **링크**: https://github.com/gnipbao/story-to-handdrawn-video
- **참고**: Remotion(영상 렌더링 프레임워크) 기반. Node.js/Python/FFmpeg 등 개발 환경 세팅 필요해서 진입장벽 있는 편
### 8. andrej-karpathy-skills
클로드 코드가 반복하는 실수(애매한 지시 마음대로 해석, 100줄이면 될 걸 1000줄로 부풀리기 등)를 4가지 원칙으로 정리한 규칙집. 코딩 전에 가정을 먼저 말하게 하고 최소한만 짜게 만듦. CLAUDE.md 파일 하나 붙여넣는 수준이라 부담 없음.
- **링크**: https://github.com/multica-ai/andrej-karpathy-skills
### 9. agents-council
- [https://github.com/0xwilliamortiz/agents-council](https://github.com/0xwilliamortiz/agents-council)
여러 AI에게 같은 질문을 던져 회의시키는 도구. 각자 답한 뒤 의장 역할 AI가 종합해서 결론을 냄. 이미 깔려있고 구독 중인 도구들을 불러 쓰는 방식이라 추가 요금이 없다는 게 특징.
### 10. pi-config
- [https://github.com/realchendahuang/pi-config](https://github.com/realchendahuang/pi-config)
터미널용 AI 코딩 도구 "Pi"를 쓰는 개발자가 자기 작업 환경 전체(플러그인 17개 + 전역 스킬 18개)를 공개한 저장소. 튜토리얼에 가까운 구성이라 어떤 도구를 갖춰야 완성되는지 훑어보기 좋음.
