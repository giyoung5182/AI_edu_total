## 이 실습으로 하는 것
VS Code에서 hello.py를 만들어 터미널로 실행하고, 코드 작성부터 결과 확인까지 한 화면에서 이뤄지는 흐름을 체험합니다.
## 진행 단계
1. **test 폴더 생성 및 열기** — 바탕화면에서 test 폴더를 만들고 열기 → 빈 공간 우클릭 → 코드로 열기 또는 터미널에서 열기
- 입력할 내용(터미널에서 열 경우): `code .` + 엔터
2. **파이썬 파일 생성** — 좌측 탐색기의 새 파일 아이콘을 눌러 `hello.py` 생성
3. **코드 내용 붙여넣기** — 코드 블록 안의 내용만 복사해 붙여넣고 Ctrl+S로 저장
- 입력할 내용:
```javascript
# hello.py — 순수 파이썬 스크립트
print("Hello, 오롱씨!")
name = "오롱"
print(f"{name}님, 오늘 매출 데이터를 분석해봅시다.")
```
1. **TERMINAL 탭 열고 실행** — Ctrl+J로 터미널을 열고 실행
- 입력할 내용: `python hello.py`
- 정상 결과: 터미널에 결과가 한 번 출력되고 프로그램이 즉시 종료됨
## 막히는 지점
- 코드 블록 위의 안내 문장(예: 저장 Ctrl+S)까지 같이 복사해 붙여넣으면 `NameError: name Ctrl is not defined` 같은 오류가 납니다. 코드 블록 테두리 안의 내용만 복사했는지 확인합니다.
