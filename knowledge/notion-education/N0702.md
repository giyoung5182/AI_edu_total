### 유형별 프롬프트 전략
**1. 요약형 보고서 프롬프트**
```markdown
## 역할
당신은 교육기관 현장 원가관리 담당자입니다.

## 맥락
아래는 이번 주(2026.05.05~05.09) 월간 예산 집행 취합 결과입니다:
- 총 공종 4개: 정상 1개, 주의 2개, 초과 1개
- 주의/초과 공종: 골조(예산 대비 +8%, 단가상승), 마감(+4%, 기성 청구 지연), 전기(+6%, 자재 선급금 집중)

## 출력 형식
원가관리팀장님께 보고할 수 있는 1페이지 주간 비용 집행 요약 보고서.
핵심 수치와 즉시 후속 조치 필요 사항 중심으로 작성.
```

**요약형 프롬프트 전략 해설:**
- **역할**: "현장 원가관리 담당자" → 예산·집행·원가 변동을 직접 관리하는 실무자 관점
- **맥락 제약**: 기간/공종수/주의·초과 현황을 **구체적 수치로** 제공 → AI가 지어내지 않도록 제약
- **출력 제약**: "1페이지", "핵심 수치 중심" → **분량과 초점을 제한**하여 긴 설명 방지
- **핵심**: 요약형은 "적게, 빨리, 수치 중심"이 관건. 해석이나 배경 설명은 요청하지 않음

**2. 분석형 보고서 프롬프트**
```markdown
## 역할
당신은 건설 프로젝트 원가 데이터 분석 전문가입니다.

## 맥락
아래는 4월 한 달간 공종별 예산 대비 집행 현황 데이터입니다:
- 골조: 계획 집행률 45%, 실적 43% (달성률 95.6%)
- 마감: 계획 집행률 42%, 실적 35% (달성률 83.3%)
- 전기: 계획 집행률 38%, 실적 37% (달성률 97.4%)

## 출력 형식
1. 공종별 집행 달성률 비교 분석
2. 마감 공종 달성률이 낮은 원인 추정 (3가지)
3. 후속 대책 권고사항 (우선순위별)
4. 다음 달 중점 관리 공종 제안
```

**분석형 프롬프트 전략 해설:**
- **역할**: "원가 데이터 분석 전문가" → 요약형과 다르게 **분석적 사고**를 요구하는 역할
- **맥락 제약**: 3개 공종의 **비교 데이터**를 제공 → AI가 패턴과 차이를 발견할 수 있도록 유도
- **출력 제약**: "비교 분석", "원인 추정", "후속 대책 권고" → **단계별 분석 깊이**를 명시적으로 요청
- **핵심**: 분석형은 "왜 그런지, 어떤 패턴이 있는지"가 관건. 단순 나열이 아닌 **인사이트 도출**을 요청

**3. 설득형 보고서 프롬프트**
```markdown
## 역할
당신은 교육기관 원가관리팀장입니다.

## 맥락
마감 공종의 집행 달성률이 3개월 연속 85% 미만 유지되고 있습니다.
주요 원인은 기성 청구 지연과 일부 자재 단가 상승으로 인한 집행 계획 차질로 파악됩니다.
추가 예산 및 현금 집행 승인 8,000만원을 본부장님께 요청해야 합니다.

## 출력 형식
다음 구조의 설득형 품의서를 작성해줘:
1. 현황 및 문제점 (집행 달성률 데이터 기반)
2. 미조치 시 리스크 (월마감 지연, 현금흐름 부담, 비용 리스크 확대)
3. 해결 방안 및 소요 예산
4. 기대 효과 (집행률 회복 목표, 월마감 안정화 가능성)
```

**설득형 프롬프트 전략 해설:**
- **역할**: "원가관리팀장" → 예산을 요청할 수 있는 **의사결정 권한이 있는 역할**
- **맥락 제약**: "문제 상황 + 원인 + 예산 규모"를 구체적으로 → **설득의 근거**를 제공
- **출력 제약**: "현황→리스크→해결안→기대효과" → **설득 논리 구조**를 직접 지정
- **핵심**: 설득형은 "미조치 시 리스크"를 넣는 것이 핵심. AI에게 **"안 하면 어떻게 되는지"를 쓰게 하면** 설득력이 높아짐

구글 시트 연동으로 예산 집행 데이터 자동 저장, 슬랙 알림 전송 등

### 각 구성 요소 상세 설명
**1️⃣ Instructions (지침) — "GPT의 성격을 정의하는 설계도"**
Instructions은 GPT가 **매번 대화 시작 시 자동으로 읽는 지침서**입니다. 1차시에서 배운 프롬프트 3요소(역할·맥락·출력형식)를 **영구적으로 저장해두는 것**이라고 생각하면 됩니다.
**잘 쓴 Instructions의 특징:**
- 역할과 전문 분야를 명확히 정의
- 답변 시 지켜야 할 규칙 명시 (예: "수치 산출 시 반드시 입력 데이터 기준 표시")
- 출력 형식 기본값 설정 (예: "항상 표 형식으로")
- 하지 말아야 할 것 명시 (예: "추측으로 수치를 만들지 마세요")
---
**2️⃣ Knowledge (지식 파일) — "참고 자료 라이브러리"**
업로드한 파일을 기반으로 답변하므로, **환각을 크게 줄일 수 있습니다.**
**업로드 가능한 파일 유형:**
- PDF (사내 매뉴얼, 법규 문서, 가이드라인)
- 엑셀/CSV (집행 현황표 양식, 데이터 템플릿)
- 텍스트/Word (보고서 양식, SOP 문서)
**예산·원가 활용 예시:**
- 월간 비용·집행 보고서 양식 업로드 → 양식에 맞는 문서 자동 생성
- 가상 예산 집행 데이터 템플릿 업로드 → 컬럼 구조 기반 답변
- 과거 익명화된 비용 리스크 보고서 업로드 → 유사 유형 기반 후속 대책 제안
---
**3️⃣ Actions (작업/API 연결) — "단순 답변을 넘어 실제 작업 수행"**

**Actions는 GPTs를 "답변하는 AI"에서 "일하는 AI"로 진화시키는 기능입니다.**
외부 서비스와 API(Application Programming Interface)로 연결하면, GPT가 답변만 하는 것이 아니라 **실제로 데이터를 가져오거나, 파일을 만들거나, 알림을 보내는** 등의 작업을 수행할 수 있습니다.

**API란?**
- API = 프로그램끼리 소통하는 연결 통로
- 비유: 레스토랑에서 웨이터가 주문을 받아 주방에 전달하고, 음식을 가져다주는 역할 = API
- GPT가 "오늘 집행 현황 가져와" → API로 구글 시트에 요청 → 실시간 데이터 반환

### GPTs 만들기 실습

**\[실습\] 예산·원가 업무용 GPTs 구조 설계하기**
실제로 GPTs를 만들어보겠습니다. ChatGPT 좌측 메뉴에서 **\[GPT 탐색\]** → **\[만들기\]**를 클릭하세요.
**Step 1.** 이름과 설명 입력
- 이름: `교육기관 비용·집행 보고 도우미`
- 설명: `월간 비용·집행 보고서 작성 및 공종별 원가 초과 원인 분석을 도와주는 AI`
**Step 2.** Instructions(지침) 입력
```markdown
## 역할
당신은 교육기관 아파트 신축 프로젝트의 원가관리 담당자입니다.

## 행동 규칙
1. 모든 답변은 입력된 데이터와 사용자가 제공한 조건만 근거로 작성하세요.
2. 보고서는 다음 구조로 작성하세요:
   - 보고서 헤더(기준월, 대상, 작성자)
   - 공종별 예산 대비 집행 현황
   - 주요 차이 원인 (표: 번호/공종/차이/원인)
   - 액션아이템 (표: 번호/할 일/담당자/기한)
3. 수치가 부족하면 추정하지 말고 "추가 확인 필요"로 표시하세요.
4. 전문용어는 괄호 안에 쉬운 설명을 넣어주세요.
5. 표, 체크리스트 형태를 적극 활용하세요.
```
**Step 3.** Conversation Starters(유도 질문) 설정
- "이번 달 예산 집행 현황을 정리해줘"
- "공종별 원가 초과 원인 분석해줘"
- "월간 현금흐름 주의 항목 정리해줘"
- "추가 예산 승인 품의서 작성해줘"
**Step 4.** 저장 후 테스트
- 유도 질문 중 하나를 클릭하여 결과 확인
- 매번 역할/맥락을 입력하지 않아도 일관된 결과가 나오는지 확인


**비유로 이해하기: "GPTs는 원가관리팀 전용 무전기 채널"**
일반 ChatGPT가 모든 주파수를 수신하는 라디오라면, GPTs는 **우리 원가관리팀 전용 채널에 맞춰진 무전기**입니다. 예산·집행 관련 질문을 하면 항상 우리 프로젝트 맥락에 맞는 답변이 나옵니다. 한 번 채널을 설정해두면 매번 주파수를 맞출 필요가 없습니다.

### Deep Research란?

**ChatGPT Deep Research** = 복잡한 질문에 대해 여러 출처를 탐색·분석·종합하여 **출처가 포함된 구조화 보고서**를 만들어주는 리서치 기능
