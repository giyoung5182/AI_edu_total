## 이 실습으로 하는 것
이미지 프롬프트를 직접 써서 AI 이미지를 만들고, 이어서 수정 요청해 본다.
## 진행 단계
1. **도전 1 (쉬움)**
```javascript
"봄날 벚꽃이 피어있는 공원,
 따뜻하고 밝은 분위기,
 수채화 스타일"
```
1. **도전 2 (보통)** — 내가 좋아하는 계절, 장소, 풍경을 직접 묘사해서 만들어 보기(예: "가을 단풍길" / "바닷가 일출" / "눈 내리는 시골 마을")
2. **도전 3 (심화)** — 동창회나 모임 초대 카드에 쓸 배경 이미지 만들어 보기
```javascript
"____ 모임 초대 카드 배경으로 쓸 이미지,
 ____ 분위기, ____ 스타일,
 텍스트 여백 있게, 가로형"
```
1. **이어서 수정 요청**
```javascript
"더 밝게 바꿔줘"
"색감을 따뜻하게 조정해줘"
"꽃을 더 많이 추가해줘"
```
## 막히는 지점
- 한글 텍스트는 AI가 잘 못 씀: 배경 이미지만 AI로 만들고 캔바(canva.com)에서 텍스트를 따로 추가
- 한 번에 1\~2가지만 수정 요청, "나머지는 그대로 유지해줘"를 붙임
