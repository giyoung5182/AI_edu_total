# NotebookLM 실습 — 충북 기업·산업 동향 분석 보고서 만들기

정리일: 2026-10-08 · 교육 에셋 N0463

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
공개된 공식 통계 보고서 2개를 NotebookLM에 올려 질의응답과 보고서 초안을 만들고 수치를 검증합니다.
## 진행 단계
1. **STEP 1 접속 및 노트북 생성 (2분)** — Chrome → notebooklm.google.com → 구글 계정 로그인 → \[+ 새로 만들기\] → 노트북 이름 입력 → \[만들기\].
2. **STEP 2 소스 2개 업로드 (3분)** — \[+ 소스 추가\] → \[파일 업로드\]. 파일명 옆 ✓ = 정상, ⚠️ = 강사에게 문의.
3. **STEP 3-1 채팅창 질문 — 소스 A (3분)** — 소스 A 파일에서만 답하게 하고 사업체 수·종사자 수(연도별 증감), 증가율 상위 시군 TOP 3 표, 가장 늘어난/줄어든 업종을 요청. 수치마다 출처 표시, 자료에 없으면 "자료 없음".
4. **STEP 3-2 보고서 기능 — 소스 B (5분)** — 노트 패널 → \[보고서\] → 소스 B 파일만 참고해 충청북도 섹션 수치만 사용(다른 지역 수치 혼용 금지)하도록 지시하고 광공업 생산·출하, 제조업 재고, 대형소매점 판매, 원장님 보고용 핵심 메모 3줄, 다음 달 체크 포인트 2가지를 요청. 수치마다 출처 표시, 공문서 문어체, 잠정치 표기.
5. **STEP 4 검증 (2분)** — 인용 번호를 클릭해 원문과 수치 대조, 충북 외 다른 지역 수치가 섞이지 않았는지 확인.
6. **심화 도전(선택)** — 사업체 구조 심화 분석 / 충북 vs 충청권 비교 / 경영진 보고 1분 스크립트(자료에 있는 내용만, 출처 괄호 표시).
## 막히는 지점
- 소스 등록 시 ⚠️ 표시가 나오면 강사에게 문의.
- 딥 리서치 결과는 반드시 원출처 확인, 소스 날짜 확인(오래된 자료는 오래된 수치를 인용).
