# 대화 Flow형 Gem 만들기 (AI 행사 콘텐츠 제작 매니저)

정리일: 2026-10-08 · 교육 에셋 N0388

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
질문·확인·승인·산출물 선택이 순차로 진행되는 대화 Flow형 Gem을 만들고 테스트한다.
## 진행 단계
1. **메타프롬프트로 Gem 지시문 설계** — Gemini 일반 채팅에 메타프롬프트를 입력해 Instructions 초안을 받고, 체크리스트(결과 즉시 생성 금지, 한 번에 한 주제 질문, 미정 기록, 확정 후 제작, 톤 일치, 자료 외 사실 금지)로 검토한다. 빠진 항목은 보정 요청한다.
- 입력할 내용: 원하는 대화 Flow 8단계와 지식 자료 사용 규칙을 적은 메타프롬프트(교안 참고)
- 결과가 길거나 Flow가 빠지면 제공된 표준 지시문 파일 사용
2. **새 Gem 만들기** — gemini.google.com → Gems → New Gem → 이름 입력 → Instructions 붙여넣기 (아직 저장하지 않음)
3. **가상 지식 자료 연결** — Knowledge → Add files → Upload files로 가상 가이드 업로드 후 Save
4. **대화 Flow 테스트** — 첫 요청 입력 후 응답 카드를 한 줄씩 입력, 행사 기획 브리프 확인 후 '확정', 산출물 메뉴에서 5번 전체 패키지 선택
- 정상 결과: 바로 결과물을 만들지 않고 확인된/부족한 정보를 정리해 질문. 장소·링크·QR은 '미정'으로 표시
5. **(보너스) 이미지·영상 연결** — Images/Videos에서 Gem이 만든 프롬프트로 생성
6. **정상 상황 밖 테스트** — 자료에 없는 실제 정보 요구, 민감정보 입력 시도, Flow 건너뛰기
## 막히는 지점
- Instructions는 AI를 유도하는 지시이므로 만든 뒤 여러 상황으로 테스트하고 보완해야 한다.
- 영상 생성 기능은 구독 플랜·라이선스·관리자 설정에 따라 보이지 않을 수 있다(그 경우 영상 프롬프트까지 완성하고 강사 결과와 비교).
