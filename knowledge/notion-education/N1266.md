# Step 4 — 데이터 검증: 최종 품질 점검

정리일: 2026-10-08 · 교육 에셋 N1266

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
정제 후 한 번의 쿼리로 오류 건수를 점검하고, 결과별 건수를 집계합니다.
## 진행 단계
1. **통합 품질 점검 쿼리** — SUM(CASE WHEN ...)으로 설비ID_결측, 점검일_결측, 점검자_결측, 비표준_결과, 날짜논리_오류를 한 번에 집계합니다.
- 정상 결과: 전체건수 5, 비표준_결과 0, 설비ID_결측 0, 날짜논리_오류 1(L007은 담당자 확인 중인 보류 건).
2. **실습 과제** — 결과(정상/주의/위험)별 건수 집계 쿼리를 직접 작성합니다.
```sql
SELECT result AS 점검결과, COUNT(*) AS 건수 FROM inspection_log GROUP BY result ORDER BY 건수 DESC;
```
- 정상 결과: 정상 5.
## 막히는 지점
- 날짜논리_오류가 1인 것은 L007을 삭제하지 않고 메모만 달아 둔 보류 건이기 때문입니다.
