## 2.1 Gemini Canvas — AI와 함께 편집하는 작업 공간
### 결론 한 줄
> Canvas는 AI가 답변을 "출력"하는 게 아니라, 나와 같은 문서를 함께 편집하는 모드입니다.
---
### 일반 채팅 vs Canvas — 교육기관 실무 기준
파메스테틱 민타비20 소개 자료를 만든다고 해 봅시다.
**일반 채팅 방식:**
```plain text
1. Gemini에 "민타비20 소개 자료 써줘" 입력
2. AI가 텍스트를 채팅창에 출력
3. 복사 → 구글 문서 / 노션에 붙여넣기
4. 내가 직접 편집 (단락 나누기, 표 추가, 길이 조정)
5. 다시 Gemini에 "이 부분 수정해줘" → 복사 → 붙여넣기
→ 왔다갔다 5–6번 반복, 총 소요: 30–40분
```
**Canvas 방식:**
```plain text
1. Canvas 모드에서 "민타비20 소개 기획서 만들어줘" 입력
2. 오른쪽에 Canvas 문서 창 자동 오픈
3. AI가 문서 형태로 직접 작성 (눈앞에서 실시간으로)
4. 마음에 안 드는 부분 클릭 → "이 부분 더 구체적으로" 요청
5. 완성되면 구글 문서로 원클릭 내보내기
→ 총 소요: 10–15분
```
손이 절반으로 줄어드는 셈입니다.
---
### Canvas 켜는 방법
```plain text
STEP 1. gemini.google.com 접속 → 구글 계정 로그인
STEP 2. 입력창 아래 툴바에서 "Canvas" 아이콘 선택
        (도구 메뉴에서 직접 켜야 합니다. 자동으로 열리지 않습니다)
STEP 3. 아이콘 활성화 확인 후 프롬프트 입력
```
> 💡 Canvas는 데스크탑 웹(gemini.google.com)에서 사용합니다.<br>모바일 앱에서는 열람은 가능하지만 텍스트 스타일·형식 편집은 데스크탑에서만 됩니다.
---
### Canvas 화면 구조
```plain text
┌───────────────────┬────────────────────────────────┐
│ 왼쪽: 채팅 영역    │ 오른쪽: Canvas 문서 영역         │
│                   │                                │
│ AI에게 지시하는 곳  │ 문서가 실시간으로 만들어지는 곳   │
│                   │                                │
│ "2장 내용 더 길게"  │ [내용이 여기에 출력됩니다]       │
│ "표로 바꿔줘"      │                                │
│ "톤 더 전문적으로"  │ (원하는 부분 클릭하면           │
│                   │  직접 편집도 가능합니다)          │
└───────────────────┴────────────────────────────────┘
```
완성 후 오른쪽 상단 "구글 문서로 내보내기" 버튼 → 구글 드라이브에 자동 저장됩니다.

## 2.2 Canvas 프롬프트 작성법 — 왜 이렇게 써야 하는가
> 프롬프트를 잘 쓰는 것이 결과물의 80%를 결정합니다.<br>복사해서 쓰는 것도 좋지만, **왜 이렇게 썼는지**를 이해해야<br>다음에 혼자 응용할 수 있습니다.
---
### 좋은 Canvas 프롬프트의 3가지 구조
**① 목적 + 독자 + 형식을 한 문장에 담습니다**
```plain text
❌ 목적만 있는 프롬프트:
"민타비20 소개 자료 만들어줘"
→ AI가 누구를 위한 자료인지, 어떤 형식인지 모름
→ 너무 일반적이거나, 엉뚱한 방향의 결과물

✅ 목적 + 독자 + 형식이 있는 프롬프트:
"파메스테틱 민타비20 제품 소개 1-page 기획서를 만들어줘.
독자: 처음 제품을 접하는 신규 고객
형식: 포지셔닝 한 줄 / 추천 대상 / 핵심 성분 / 사용법 / FAQ / CTA"
→ AI가 독자 수준에 맞게, 원하는 구조로 정확하게 작성
```
💡 **비즈니스 인사이트**<br>고객 대상 자료와 원장님(파머) 대상 자료는 쓰는 언어가 달라야 합니다.<br>고객에게는 "피부 고민 해결"을 앞세우고,<br>원장님에게는 "성분 차별점과 마진"을 앞세워야 설득력이 있습니다.<br>AI에게 "독자"를 명확히 알려주면 이 차이를 자동으로 반영합니다.
---
**② 제약 조건은 "하지 말 것"과 "반드시 할 것"을 동시에 넣습니다**
```plain text
❌ 제약 없는 프롬프트:
"세멘잘 소개 글 써줘"
→ 과대광고 표현 포함될 수 있음
→ 분량·형식 제멋대로

✅ 제약이 명확한 프롬프트:
"세멘잘 50ml 제품 소개 글을 써줘.
반드시: 보르피린 50,000ppm 10배 강화 사실 포함, 파머가 360,000원 명시
하지 말 것: 치료·재생·완치 등 화장품법 위반 표현, 경쟁사 언급
분량: 200자 이내"
```
💡 **비즈니스 인사이트**<br>에스테틱 브랜드에서 화장품법 위반은 단순 실수가 아닙니다.<br>SNS 게시물 하나로 계정 제재, 과태료, 브랜드 신뢰 손상이 동시에 올 수 있습니다.<br>AI에게 금지 표현을 명시해두면 매번 사람이 검수하는 수고를 줄일 수 있습니다.<br>GEMS에 이 제약을 한 번만 저장해두면 이후에는 자동으로 적용됩니다.
---
**③ 체이닝 — 한 번에 완성하려 하지 않습니다**
```plain text
프롬프트는 대화입니다. 한 번에 완벽한 결과를 바라지 마세요.

1차 요청: 전체 구조 잡기
"민타비20 고객 배포용 1-page 기획서 초안 만들어줘"

2차 수정: 특정 부분 개선
"첫 번째 포지셔닝 문장을 더 임팩트 있게 바꿔줘"

3차 수정: 형식 변환
"FAQ 섹션을 표 형식으로 바꿔줘"

4차 변환: 다른 채널용으로 재활용
"이 내용을 인스타 본문 200자로 압축해줘"
```
💡 **비즈니스 인사이트**<br>기획서 1개를 만들면 끝이 아닙니다.<br>같은 제품 정보로 고객용 기획서 → 인스타 본문 → 카카오톡 공지 → 원장님 가이드를<br>체이닝으로 연속 생성할 수 있습니다.<br>처음 한 번의 프롬프트 투자가 4–5가지 결과물로 돌아오는 구조입니다.
---
### Canvas 수정 명령어 — 교육기관 맞춤
**구조 변경:**
```plain text
"이 문서를 표 형식으로 재구성해줘"
"5장짜리 카드뉴스 구조로 바꿔줘 (1장 표지 ~ 5장 CTA)"
"목차를 추가해줘"
```
**내용 수정:**
```plain text
"3번째 단락을 더 자세하게 늘려줘 (구체적 수치 포함)"
"첫 문장을 더 강한 훅으로 바꿔줘 (스크롤 멈추는 문장으로)"
"화장품법에 위반될 수 있는 표현이 있으면 모두 수정해줘"
```
**톤·스타일:**
```plain text
"에스테틱 전문가가 직접 쓴 것처럼 자연스럽게 바꿔줘"
"원장님들에게 보내는 공식 공지 느낌으로"
"고객에게 설명하는 친근한 말투로"
```
**재활용:**
```plain text
"이걸 인스타 본문 200자로 압축해줘 (해시태그 포함)"
"이 내용을 카카오톡 공지 형식으로 바꿔줘 (150자 이내)"
"원장님 교육 자료 형식으로 변환해줘"
```

## 🔴 실습 1 \| Canvas로 교육기관 실무 자료 만들기 (20분)
**산출물:** 파메스테틱 제품 1개의 소개 기획서 또는 마케팅 자료 완성본 1부
---
### STEP 1 — 표준 예시 확인 (3분)
아래 프롬프트가 어떻게 구성됐는지 먼저 읽어봅니다.<br>**복사해서 쓰기 전에, 각 줄이 왜 들어갔는지 생각해 보세요.**
```plain text
[표준 예시 프롬프트 — 민타비20 고객 배포용 기획서]

파메스테틱 민타비20 제품 소개 1-page 기획서를 Canvas로 만들어줘.

[독자] 처음 비타민C 앰플을 써보려는 30대 여성 고객
[목적] 제품 신뢰도를 높이고 구매 문의로 연결

[포함할 내용]
1. 한 줄 포지셔닝 (기억에 남는 문장)
2. 이런 분에게 추천 (구체적 피부 고민 3가지)
3. 핵심 성분 설명 (영국 DSM사 비타민C 20%, pH 4.71, 쉬운 말로)
4. 사용법 3단계
5. 자주 묻는 질문 3개
6. 구매 유도 CTA

[반드시] 파머가 79,000원 명시 / 주름개선·미백 기능성 화장품 표현 사용
[하지 말 것] 치료·완치·피부 재생 등 화장품법 위반 표현
[톤] 전문 에스테틱 원장이 고객에게 설명하는 따뜻하고 신뢰 있는 말투
```
**이 프롬프트에서 눈여겨볼 것:**
```plain text
"독자"를 명시했습니다
→ AI가 30대 여성이 이해할 수 있는 수준으로 성분을 설명합니다
→ 전문 용어를 남발하지 않습니다

"목적"을 적었습니다
→ 단순 소개가 아니라 "구매 문의 연결"이 목표임을 AI가 인지합니다
→ CTA를 강하게 쓰는 방향으로 작성됩니다

"반드시"와 "하지 말 것"을 분리했습니다
→ 법적으로 써야 하는 표현과 쓰면 안 되는 표현을 동시에 관리합니다
→ 이 두 줄만 바꾸면 다른 제품에도 즉시 응용할 수 있습니다
```

### STEP 2 — 나만의 프롬프트 직접 작성 (5분)
표준 예시를 참고해서, **본인 업무에 맞는 프롬프트를 직접 써봅니다.**<br>완벽하지 않아도 됩니다. 일단 써보는 것이 핵심입니다.

```plain text
대상 제품: □ 민타비20  □ 마호로사  □ 그린박신 스트롱  □ 세멘잘

독자: ___________________________

```
**직접 작성한 프롬프트:**
```plain text
(여기에 직접 작성해 보세요)
```
> 💡 **프롬프트 잘 쓰는 팁 — 지금 막히는 분들께**<br>"독자"가 생각 안 난다면 → 가장 최근에 응대한 고객을 떠올려 보세요<br>"목적"이 막힌다면 → 이 자료를 보고 나서 상대방이 어떤 행동을 하길 원하는지 쓰면 됩니다<br>("더 알고 싶다 → 문의", "믿음이 생긴다 → 구매", "방법을 안다 → 사용")
---
### STEP 3 — Canvas 실행 + 수정 (10분)
```plain text
1. Gemini Canvas 모드 열기
2. 직접 작성한 프롬프트 입력 (또는 표준 예시 사용)
3. 초안 확인

수정 명령 최소 2회 실행:
수정 1: 마음에 안 드는 부분 1곳 지목해서 수정 요청
수정 2: 다른 형식으로 변환 (예: "이 내용을 인스타 본문 200자로 압축해줘")
```

```plain text
→ 링크 복사 → 카카오톡 나에게 보내기

완성 체크:

□ 수정 명령 2회 이상 실행
□ "이거 실제로 쓸 수 있다" 수준 확인
□ 구글 문서 저장 완료
```

## 2.3 Gemini Deep Research — AI가 직접 인터넷을 분석해서 보고서를 써줍니다
### 결론 한 줄
> Deep Research는 AI가 지금 이 순간 수백 개의 웹 페이지를 직접 검색하고,<br>교차 검증해서 심층 보고서를 만들어 주는 기능입니다.
---
### 일반 검색 vs Deep Research — 교육기관 마케터 관점
```plain text
기존 경쟁사 분석 방법:
① 경쟁사 인스타 직접 방문 (5–6개 계정)
② 게시물 유형·반응 수동 집계
③ 엑셀로 정리
④ 인사이트 도출 후 팀 공유 자료 작성
→ 총 소요: 3–4시간, 월 1회도 벅참

Deep Research 활용:
① 질문 1개 입력
② 대기 (3–5분)
③ 출처 포함 심층 보고서 완성
→ 총 소요: 5–7분, 매주도 가능
```
---
### Deep Research 작동 원리 — 3단계
```plain text
1단계 — 조사 계획 수립
질문을 받으면 AI가 먼저 "무엇을 어떻게 조사할지" 계획을 보여줍니다.
이 계획을 내가 수정할 수 있습니다.
→ "3번 항목은 빼고, 교육기관 포지셔닝 관련 내용을 추가해줘"

2단계 — 자율 웹 검색
계획이 확정되면 AI가 수백 개의 웹 페이지를 자율적으로 방문합니다.
사람이 손댈 필요 없이 알아서 진행합니다.

3단계 — 보고서 생성
수집한 정보를 종합해서 출처 링크 포함 보고서로 정리합니다.
```
> ⚠️ **무료 계정 한도**<br>Deep Research는 무료 계정 기준 **월 5회** 사용 가능합니다.<br>교육 당일 1회씩은 사용할 수 있지만, 수요가 몰리는 시간대에<br>일시적으로 제한될 수 있습니다.<br>강사가 먼저 시연한 후, 가능한 분들은 직접 실행해 봅니다.

## 2.4 Deep Research 프롬프트 작성법 — 왜 이렇게 써야 하는가
> Deep Research는 질문이 구체적일수록 보고서 퀄리티가 올라갑니다.<br>일반 검색 키워드가 아니라, "리서치 의뢰서"를 쓴다는 느낌으로 접근해야 합니다.
---
### 좋은 Deep Research 프롬프트의 3가지 원칙
**① 분석 대상과 목적을 함께 명시합니다**
```plain text
❌ 목적 없는 프롬프트:
"에스테틱 SNS 마케팅 분석해줘"
→ 너무 넓어서 방향 없이 일반적인 내용만 나옴
→ 실무에 바로 쓸 수 있는 내용이 없음

✅ 대상과 목적이 있는 프롬프트:
"국내 에스테틱 전용 화장품 브랜드들의 2026년 인스타그램 마케팅 전략을
교육기관·파메스테틱의 차별화 포인트 도출 목적으로 분석해줘"
→ AI가 교육기관 관점으로 필터링해서 분석
→ 바로 써먹을 수 있는 인사이트가 나옴
```
💡 **비즈니스 인사이트**<br>리서치는 "정보 수집"이 목적이 아닙니다. "의사결정"이 목적입니다.<br>"다음 달에 어떤 콘텐츠를 올릴지", "어떤 제품을 더 밀지",<br>"경쟁사 대비 우리가 뭘 강조해야 할지"를 결정하기 위한 근거를 모으는 겁니다.<br>따라서 프롬프트에 "이 결과를 무엇에 쓸 것인지"를 적으면<br>AI가 의사결정에 필요한 내용을 중심으로 보고서를 씁니다.
---
**② 분석 항목을 번호로 나열합니다**
```plain text
❌ 항목 없는 프롬프트:
"파메스테틱 경쟁사 분석해줘"
→ AI가 무엇을 얼마나 깊이 분석할지 스스로 결정
→ 내가 원하는 내용이 빠질 수 있음

✅ 항목이 명확한 프롬프트:
"파메스테틱 경쟁 에스테틱 브랜드 인스타 전략을 분석해줘.
항목:
1. 주력 콘텐츠 유형 비율 (릴스 / 카드뉴스 / 일반 게시물)
2. 가장 반응 좋은 게시물 주제와 형식
3. CTA 방식 (자동DM 키워드, 링크 등)
4. 성분·효능 소통 방식의 특징
5. 교육기관가 당장 적용할 수 있는 인사이트 3가지"
→ 5개 항목 전부 빠짐없이 커버
→ 마지막 항목에서 실행 가능한 제안까지 받을 수 있음
```
💡 **비즈니스 인사이트**<br>분석 항목의 마지막에 항상 **"우리가 당장 적용할 수 있는 것"** 을 넣으세요.<br>아무리 좋은 분석도 실행으로 이어지지 않으면 의미가 없습니다.<br>이 한 줄이 있냐 없냐에 따라 보고서의 활용도가 완전히 달라집니다.
---
**③ 조사 계획 단계에서 반드시 한 번 검토합니다**
```plain text
Deep Research는 실행 전에 "이렇게 조사하겠습니다" 계획을 보여줍니다.
이 단계를 그냥 넘기지 마세요.

확인할 것:
□ 내가 원하는 방향과 일치하는가?
□ 빠진 항목이 있는가?
□ 너무 넓거나 좁게 잡힌 항목이 있는가?

수정 예시:
"2번 항목은 인스타만 보지 말고 블로그도 포함해줘"
"4번 항목을 삭제하고 대신 고객 댓글 반응 분석을 추가해줘"
```
💡 **비즈니스 인사이트**<br>AI에게 "조사 계획을 먼저 보여줘"라고 하는 것은<br>팀원에게 "일 시작하기 전에 방향 맞추자"라고 하는 것과 같습니다.<br>수정하지 않고 그냥 진행하면 나중에 "이건 내가 원하던 게 아닌데" 가 됩니다.<br>30초 검토로 5분짜리 리서치의 방향이 완전히 달라집니다.

## 🔴 실습 2 \| Deep Research 경쟁사·트렌드 리서치 (15분)

### STEP 1 — 표준 예시 확인 (3분)
아래 프롬프트가 왜 이렇게 구성됐는지 읽어봅니다.
```plain text
[표준 예시 프롬프트 — 경쟁사 SNS 전략 분석]

국내 에스테틱 전용 화장품 브랜드들의 2026년 인스타그램 마케팅 전략을
교육기관·파메스테틱의 차별화 포인트 도출 목적으로 심층 분석해줘.

[분석 항목]
1. 주력 콘텐츠 유형과 비율 (릴스 / 카드뉴스 / 일반 게시물)
2. 팔로워 규모 대비 인게이지먼트 특성
3. 가장 반응 좋은 게시물 주제와 형식
4. CTA 방식 (자동DM 키워드, 링크, 댓글 이벤트 등)
5. 성분·효능 소통 방식의 특징 (어떤 언어를 쓰는가)
6. 교육기관가 이번 달 바로 적용할 수 있는 전략 3가지

[기준] 2026년 최신 데이터 기준
[형식] 브랜드별 비교표 포함, 마지막에 교육기관 실행 제안
```
**이 프롬프트에서 눈여겨볼 것:**
```plain text
"차별화 포인트 도출 목적"을 명시했습니다
→ 단순 현황 나열이 아니라 교육기관에 유리한 관점으로 분석

"브랜드별 비교표 포함"을 요청했습니다
→ 텍스트보다 표가 팀 공유·보고용으로 훨씬 유용

"이번 달 바로 적용"이라고 했습니다
→ "참고 자료"가 아니라 "실행 지침"으로 만드는 한 줄
```

### STEP 2 — 나만의 리서치 주제 직접 작성 (4분)

```plain text
□ A. 경쟁 에스테틱 브랜드 SNS 전략 비교
□ B. 2026년 여름 피부 관리 트렌드 + 소비자 키워드

□ D. 에스테틱 고객 구매 결정 요인 분석
□ E. 직접 정하기: ___________________________

선택 이유 (한 줄로): ___________________________
```
**직접 작성한 프롬프트:**
```plain text
(분석 목적 + 분석 항목 + 기준 + 형식 포함해서 작성해 보세요)
```
> 💡 **막히는 분들께**<br>분석 항목이 생각 안 난다면 → "내가 이 보고서를 보고 어떤 결정을 내릴 건지"를<br>먼저 적고, 그 결정에 필요한 정보를 항목으로 쓰면 됩니다.
