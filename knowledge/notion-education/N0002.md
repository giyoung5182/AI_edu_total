본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

> 무드모드 게시물에 댓글 남겨주셔서 보내드리는 가이드예요. 10분이면 끝납니다.
이 가이드는 오픈소스 프로젝트 [korean-law-mcp](https://github.com/chrisryugj/korean-law-mcp)를 클로드에 연결하는 방법이에요. 연결하면 AI가 기억에 기대 답하는 대신, 질문할 때마다 법제처의 법령과 판례 원문을 직접 찾아보고 답합니다. 인용한 조항이 실제로 있는지까지 다시 확인해줘요.

**준비물**
- 법제처 Open API 인증키(OC) (무료, 아래 STEP 1\~2에서 받아요)
- 클로드 계정 또는 챗GPT Plus 이상

---
## STEP 1. 법제처 Open API 사용 신청하기
[원본 이미지 제외]
1. 법제처 Open API 신청 페이지에 접속합니다.
2. 회원가입 후 로그인합니다.
3. **Open API 사용 신청** 버튼을 누르고 신청서를 작성합니다. <br>활용 목적은 "개인 학습용"처럼 간단히 적어도 됩니다.
## STEP 2. 인증키(OC) 복사해 두기
[원본 이미지 제외]
1. 신청서를 내면 **인증키(OC)**가 발급됩니다. `honggildong` 처럼 생긴 영문 값이에요.
2. 다음 단계에서 쓸 수 있게 복사해 둡니다.

인증키는 내 계정 열쇠 같은 거라 다른 사람에게 공유하지 마세요.

## STEP 3. 클로드 설정에서 커넥터 메뉴 열기
[원본 이미지 제외]
1. 클로드(데스크톱 앱 또는 claude.ai) 왼쪽 아래 **내 이름**을 누르고 **설정**으로 들어갑니다.
2. **커넥터** 메뉴에서 **커스텀 커넥터 추가**를 누릅니다.
## STEP 4. 이름과 주소 넣고 추가하기
[원본 이미지 제외]
1. 이름은 `korean-law` (아무 이름이나 괜찮아요).
2. URL 칸에 아래 주소를 붙여 넣고, 맨 끝 `honggildong`을 STEP 2에서 받은 **내 인증키**로 바꿉니다.
```javascript
[개별 링크 제외]
```
1. **추가**를 누르면 등록 완료입니다.

주소를 잘못 넣었다면 커넥터를 삭제하고 다시 추가해야 해요. 수정은 안 됩니다.

## STEP 5. 도구를 "항상 사용"으로 바꾸기 (중요)
[원본 이미지 제외]
1. 커넥터 목록에서 방금 추가한 **korean-law**의 **구성**을 누릅니다.
2. 도구 목록이 나오면 전부 **항상 사용**으로 바꿉니다.
3. 이걸 해둬야 질문할 때마다 승인 버튼을 누르지 않아도 AI가 바로 법령을 검색해요.
## STEP 6. 새 대화에서 켜고 물어보기
[원본 이미지 제외]
1. 새 대화를 열고 입력창 아래 **＋** 버튼에서 **korean-law**가 켜져 있는지 확인합니다.
2. 아래 질문으로 테스트해 보세요. 조문 원문이 그대로 나오면 성공입니다.
```javascript
근로기준법 제74조 알려줘
```

**이렇게 물으면 더 좋아요**
계약서나 문자 내용을 그대로 붙여 넣고, 끝에 아래 문장을 붙이면 답을 한 번 더 걸러줍니다.
`인용한 조항이랑 판례가 실제로 있는지 검증까지 해줘`

## 챗GPT 사용자는 이렇게
[원본 이미지 제외]
챗GPT도 같은 주소로 연결할 수 있어요. STEP 1\~2에서 받은 인증키는 그대로 씁니다.

ChatGPT **Plus 이상** 요금제에서, **웹(****chatgpt.com****)**에서만 됩니다. 무료·Go 요금제와 모바일 앱은 안 돼요.

### GPT STEP 1. 새 앱 만들고 주소 넣기
[원본 이미지 제외]
1. **설정 → 플러그인**에서 **추가**(또는 ＋)를 누릅니다.
[원본 이미지 제외]
1. **맞춤형 mcp를 누르고** 이름은 `korean-law`, MCP 서버 URL은 클로드 STEP 4와 같은 주소를 넣습니다.
```javascript
[개별 링크 제외]
```
1. 맨 끝 `honggildong`은 내 인증키로 바꾸고, 인증은 **인증 없음**을 고릅니다.
2. "이 앱을 신뢰합니다" 체크 박스가 보이면 체크하고 **만들기**를 누릅니다.
3. 새 대화 입력창의 **＋** 버튼 → **더보기** → **개발자 모드**를 누릅니다.
4. **korean-law**를 선택하고 "근로기준법 제74조 알려줘"로 테스트해 보세요.
5. 도구 실행 전에 확인 창이 뜨면 **허용**을 누르면 됩니다.

- **연결이 안 돼요**: 주소 끝에 내 인증키를 제대로 넣었는지 확인하세요. 틀렸다면 커넥터를 삭제하고 다시 추가합니다.
- **매번 승인하라고 떠요**: STEP 5에서 도구를 전부 "항상 사용"으로 바꿨는지 확인하세요.
- **느리거나 가끔 실패해요**: 여러 사람이 같이 쓰는 공용 서버라 그럴 수 있어요. 잠시 뒤 다시 시도하면 됩니다.
- **그래도 안 되면**: 막힌 화면을 캡처해서 @moodmode.ai 로 DM 주세요.
