# (실습) 5-5. 개인화된 Gem 만들기

정리일: 2026-10-08 · 교육 에셋 N0540

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
제공된 Gem A/B/C 프롬프트 중 내 업무에 필요한 것을 골라 내 가게 정보로 개인화해 Gemini에 저장합니다.
## 진행 단계
1. **Step 1** — Gemini → 왼쪽 사이드바 → "Gems" → "+ 새 Gem 만들기"
2. **Step 2** — Gem A/B/C 중 내 업무에 가장 필요한 것을 고를 내 업무에 맞게 고도화(노트북LM을 활용해 가게 정보를 넣어주면 더 좋음) → "요청사항" 칸에 붙여넣기
3. **Step 3** — 【 】 부분을 내 가게 정보로 교체
4. **Step 4** — 이름 입력 후 저장
5. **Step 5** — 첧 대화 테스트
- 입력할 내용: 안녕! 나를 소개해줘. 너는 어떤 걸 도와줄 수 있어?
6. **Step 6** — 실제 업무 내용으로 테스트 + 수정할 부분이 있다면 수정 요청
- Gem A: 이번 주 \[소식\]을 홍보하고 싶어. / Gem B: 이런 리뷰가 달렸어: "\[리뷰 내용\]" / Gem C: \[용도\]에 쓸 이미지 프롬프트 만들어줘.
