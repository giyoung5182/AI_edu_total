# Watch Rows + Router + 텔레그램 실습

정리일: 2026-10-08 · 교육 에셋 N1477

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
시트에 입력된 유형에 따라 두 갈래로 나눠 서로 다른 텔레그램 메시지를 보내는 시나리오를 만듭니다.
## 진행 단계
1. **텔레그램 봇 만들기** — @BotFather에서 /newbot → 이름·아이디 지정 → Bot Token 복사 → 그룹 채팅방에 봇 초대 → getUpdates로 Chat ID 확인
2. **Watch Rows** — 테스트 시트, All new rows, Limit 1
3. **Router 추가** — Flow Control → Router (빈 브랜치 2개)
4. **브랜치 1 — 발주 Filter + Telegram Send a Message** — 유형(B열) Equal to 발주, Text에 품목·수량·거래처·입고예정일 변수 삽입
5. **브랜치 2 — 렌탈 Filter + Telegram** — 유형 = 렌탈, 매장·품목·수량·출고예정일 삽입
6. **테스트** — Save → 토글 ON → 발주 행, 렌탈 행을 각각 추가해 서로 다른 메시지 수신 확인
## 막히는 지점
- Connection 오류: Bot Token 입력만으로 연결됨, 콜론 포함 전체 복사
- 그룹 채팅방 ID는 음수(-)로 시작하는 것이 정상
