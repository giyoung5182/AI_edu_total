- 5번은 제작자를 특정할 수 있는 말을 피하고, "이런 유형이 섞이면 격자가 흔들립니다"로만 말합니다.

## 3. 시연 리허설 — 반드시 사전 확인
### ⚠ 교재의 프롬프트는 아직 실제 생성 검증을 거치지 않았습니다
교재의 프롬프트는 원리에 맞게 설계된 것이지, 실제 모델에 넣어본 결과는 아닙니다. **교육 전에 직접 돌려보셔야 합니다.**
```plain text
[리허설 체크리스트]

□ 2권 2-4 사례 1 프롬프트를 그대로 넣어 생성
   → 캐릭터가 세 명 나오는가
   → 상하단 여백이 실제로 비는가
   → [금지] 블록이 작동하는가

□ 같은 재료로 4단계 STYLE LOCK 수정 테스트
   → 여백만 넓혀지는가, 다른 게 바뀌는가

□ STYLE LOCK 없이 같은 수정 요청 (비교용 실패 사례 확보)
   → 이걸 화면으로 나란히 보여주는 게 2권의 하이라이트

□ 센터 게시물 캡처 첨부 후 3권 3-3 프롬프트 테스트
   → 캐릭터가 얼마나 유지되는가
   → 캡처 화질로 충분한가

□ 한글 문구 삽입 테스트 (원리 둘 시연용)
   → 짧은 문구는 정말 잘 나오는가
   → 일시·장소까지 넣으면 깔리는가
   → 이 두 결과를 나란히 보여주는 게 1권의 하이라이트

□ Gemini 무료 계정 하루 생성 한도 확인 (당일 소진 방지)
```
### 소재가 안 나올 때 대체안
연합 운동회 캐릭터(젬리 형태 3색)는 형태가 독특해서 재현이 어려울 수 있습니다.
```plain text
1순위  연합 운동회 (9/19)  — 캐릭터 3색, 색 제한 예시가 명확
2순위  잠금해제 UNLOCK (9/5) — 단순한 형태, 재현 쉬움
3순위  교통비 환급 안내      — 버스 하나. 가장 안전함
```
리허설에서 1순위가 두 번 연속 실패하면 2순위로 교체합니다. 교재의 프롬프트도 함께 수정합니다.

## 6. 이번 교육의 승부처
세 가지만 남기면 성공입니다.
1. **캡처 첨부로 캐릭터 이어 만들기 (3-3)**
담당자가 "소수만 한다"고 한 것을 전원에게 열어주는 지점. 현장에서 바로 따라하게 해도 좋음
2. **여백을 미리 잡는 한 문장 (2-1)**
가장 즉각적으로 효과가 보이는 부분. 여백 지정 전후를 나란히 보여줄 것
3. **\[확인 필요\] 강제 조항 (4-3)**
청년정책 홍보는 숫자 오류가 곷 사고. 서포터즈가 실수하면 센터가 책임집니다
