# STEP 4 — 학생에게 전달하는 방법 (QR코드 만들기)

정리일: 2026-10-08 · 교육 에셋 N0529

---

## 이 실습으로 하는 것
게시한 링크를 학생에게 전달하는 방법을 정하고, 교실 화면용 QR코드 페이지를 만듭니다.
## 진행 단계
1. **전달 방법 선택** — 교실에 화면이 있으면 QR코드를 띄움 / 학습관리시스템이 있으면 공지에 링크 / 태블릿을 나눠주면 미리 브라우저에 열어두고 배포 / 학교 홈페이지는 임베드 코드(허용 도메인 지정 필요)
2. **QR코드 페이지 요청**
- 입력할 내용:
```plain text
이 링크로 접속하는 QR코드 페이지를 만들어줘.
큰 QR코드 하나와 그 아래 주소를 텍스트로도 크게.
교실 화면에 띄울 거라 전체적으로 크게. 외부 라이브러리 없이.
```
- 정상 결과: 화면에 띄우면 학생들이 폰으로 찍어서 바로 들어옴(주소를 불러줄 필요 없음)
## 막히는 지점
- 게시 취소는 되돌릴 수 없음. 실수로 내리면 앱과 저장된 학생 응답이 전부 사라지므로 수정하고 싶으면 내리지 말고 그냥 고칠 것
