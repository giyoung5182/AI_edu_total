# Part 3 · 캐릭터와 톤 유지하기
1권에서 "격자로 보면 다른 계정 같다"고 했죠. 원인은 `원리 하나`였습니다. **매번 무작위 잡음에서 새로 시작**하니까요.
해결책은 간단해요. **새로 시작하지 않으면 됩니다.** 방법이 두 가지인데, 쉬운 것부터 갑니다.

## 방법 하나 · 기존 게시물을 첨부하세요
제일 쉽고 제일 정확한 방법이에요. 최근 모델들은 참조 이미지의 특징을 보존하는 능력이 크게 좋아졌습니다.
```plain text
[센터 인스타 게시물 캡처를 첨부한 뒤]

첨부한 이미지의 캐릭터 생김새, 색상, 선 굵기, 배경 처리 방식을
그대로 유지해 줘.
캐릭터의 자세만 [작은 깃발을 들고 팔을 위로 올린 모습]으로 바꾸고,
나머지는 첨부 이미지와 동일하게 만들어 줘.
위쪽 3분의 1과 아래쪽 3분의 1은 단색 여백으로 비워 줘.
```

**지금 바로 해보실 수 있어요**
- 원본 파일 없어도 됩니다. **인스타에서 캡처한 걸로 충분해요**
- 말로 설명하기 어려운 특징까지 따라옵니다
- 스마트폰만 있으면 됩니다


**두 가지만 주의하세요**
캡처는 화질이 낮아서 결과물이 살짝 뭉개질 수 있어요. 중요한 게시물은 담당자께 원본을 받으시고요.
그리고 **다른 기관이나 남의 이미지를 첨부해 따라 만드는 건 조심하셔야 합니다.** 우리 계정 게시물이라 괜찮은 거예요.

## 방법 둘 · 고정 블록을 만들어두세요
캡처를 매번 찾기 번거로우면, 아예 글로 고정해둘 수 있어요. 프롬프트를 두 덩어리로 쪼갭니다.
```plain text
[고정 블록]  ← 한 번 정하고 계속 복사해서 씁니다
  스타일 / 색상 규칙 / 캐릭터 생김새 / 배경 처리 / 여백 규칙

[변수 블록]  ← 게시물마다 이 부분만 바꿉니다
  무엇을 하고 있나 / 어떤 소품이 있나
```
고정 블록 전문은 부록 C에 있어요. 여기선 **변수 블록만 갈아 끼우는 감각**을 봐주세요.





게시물

변수 블록에 넣을 문장




운동회 모집

캐릭터가 작은 깃발 하나를 들고 한쪽 팔을 위로 올린 자세




교통비 지원 안내

캐릭터가 버스 정류장 표지판 옆에서 손을 흔드는 자세




휴관 공지

캐릭터가 눈을 감고 두 손을 모은 채 앉아 있는 자세




정책 상담 안내

캐릭터가 안경을 쓰고 서류 한 장을 든 자세




공모전 홍보

캐릭터가 트로피를 두 손으로 들어올린 자세



**유지할 것을 바꿀 것보다 길게 쓰세요**
고정 블록이 열 줄이고 변수가 한 줄이면 톤이 유지됩니다. 반대로 쓰면 매번 다른 그림이 나와요.
고정 블록은 **메모장이나 카톡 나에게 보내기**에 저장해두세요. 매번 다시 쓰지 마시고 복사해서 쓰시면 됩니다.

## 고정 블록을 AI한테 만들게 하는 법
직접 쓰기 막막하면, **잘 나온 게시물을 보여주고 뽑아내게** 하면 돼요.
```plain text
[잘 나온 센터 게시물 2~3장을 첨부한 뒤]

이 이미지들을 다른 AI로 재현하려고 해. 아래 항목으로 분석해 줘.

① 전체 컨셉 (한 문장)
② 캐릭터의 형태 특징 (비율, 선 굵기, 눈과 입 처리)
③ 사용된 색 3가지 (색상명과 HEX 코드)
④ 배경 처리 방식
⑤ 이걸 재현할 수 있는 프롬프트 (6요소 구조로)

추정한 항목은 [추정]이라고 표시하고, 확실하지 않은 건 지어내지 마.
```

**이게 왜 중요하냐면**
이 결과물이 있어야 **다른 서포터즈도 같은 톤으로 만들 수 있어요.** 한 명의 감각에 의존하면 그 사람이 빠졌을 때 톤이 무너집니다.
기수가 바뀌어도 계정 톤이 유지되는 방법이 이거예요.

## 시리즈로 이어 만들기
첫 장이 완성되면 **대화를 끊지 말고** 이어서 요청하세요.
```plain text
1장 완성
   ↓
"STYLE LOCK. 이 스타일과 색상 규칙을 그대로 유지하면서
 캐릭터가 [다른 자세]인 이미지로 한 장 더 만들어 줘."
   ↓
2장
   ↓
"같은 구성으로 세로 9대 16 스토리 버전을 만들어 줘."
   ↓
스토리용
```

**새 대화창을 열지 마세요**
새 창을 열면 앞의 이미지 맥락이 사라집니다. 이미지를 다시 올려야 하고, 그러면 미묘하게 톤이 달라져요.
**하나의 행사는 하나의 대화창에서.** 카드뉴스 다섯 장이 필요하면 다섯 번 새로 만드는 게 아니라, 한 장 잘 만들고 네 번 이어가는 겁니다.

## 한글 문구 얹기
`원리 둘`
AI가 만든 건 배경까지고, **바뀔 정보**는 우리가 얹습니다.
```plain text
1  캔바 앱 → 인스타그램 게시물 규격 선택
2  배경 이미지 업로드, 화면 전체에 맞추기
3  텍스트 추가 → 미리 비워둔 여백 위에 배치
4  글자가 잘 안 보이면 반투명 사각형을 뒤에 깔기
5  다운로드 → 업로드
```

**캔바 계정이 없으시면**
가입이 번거로우면 대안이 있어요.
**인스타 스토리 편집기**로 텍스트 얹고 스크린샷 (제일 빠름), 또는 **폰 기본 사진 앱**의 마크업 기능.
다만 위치 조정과 규격 저장은 캔바가 편해요. 활동 계속하실 거면 한 번 가입해두시는 게 낫습니다.

### 문구 얹을 때 세 가지
**하나. 행사명은 한 줄에.** 두 줄로 넘어가면 시선이 분산돼요. 긴 이름은 앞을 작게, 뒤를 크게.
```plain text
2026 충북청년축제        ← 작게
연합 운동회              ← 크게
```
**둘. 아래쪽 정보는 네 개까지.** 일시·장소·대상·신청방법이 기본이고, 더 필요하면 링크로 넘기세요.
**셋. 글자 크기는 세 단계까지.** 행사명 / 소제목 / 본문. 네 단계 넘으면 지저분해집니다.

# Part 4 · 홍보 문구 뽑기
## 같은 정보인데 왜 반응이 다를까
센터에 오는 정보는 대부분 이런 형태죠.
```plain text
2026년 청년 국가기술자격 응시료 지원 사업
- 지원대상: 만 19~34세 청년
- 지원내용: 응시료 50퍼센트 지원
- 신청방법: 온라인 접수
```
이걸 그대로 올리면 안 읽혀요. **정보의 순서가 기관 기준**이기 때문입니다.
읽는 사람 기준으로 뒤집으면 이렇게 돼요.
```plain text
자격증 시험 접수하려다
응시료 보고 미룬 적 있으신가요

절반은 나라가 냅니다
만 19~34세 충북 청년이면 신청 가능해요
```
바뀐 건 정보가 아니라 **시작점**입니다. 1권에서 본 그 게시물이 잘 된 이유와 똑같아요.

**저장과 공유**

**좋아요보다 훨씬 강한 신호예요. 내용이 유용하다는 뜻이니까요**




**카드뉴스**

**넘기는 행동이 가산점이고, 안 본 사람에겐 두 번째 장으로 다시 노출됩니다**




해시태그

개수가 제한되고 노출 기여도 줄었어요. 많이 붙이기보다 정확하게 몇 개만




게시 직후 반응

초반 반응이 낮으면 거기서 멈춥니다. 올리는 시간이 중요해요



**여기서 나오는 결론 두 개**
**하나. 카드뉴스 두 번째 장을 잘 만드세요.** 첫 장을 안 본 사람에게 두 번째 장이 다시 보입니다. 보통 두 번째 장은 대충 만드는데, **단독으로 봐도 이해되게** 만들면 도달이 달라져요.
**둘. 저장해두고 싶은 걸 만드세요.** 정책 안내가 유리합니다. 마감일과 신청 방법이 정리된 카드뉴스는 나중에 다시 보려고 저장하거든요. 막연한 분위기 게시물보다 **정보가 빼곡한 것**이 오히려 멀리 갑니다.


알고리즘은 수시로 바뀝니다. 위 내용은 2026년 상반기 기준이에요.
숫자에 집착하지 마시고 **"저장하고 싶게, 보내고 싶게"** 이 방향만 기억하시면 세부 규칙이 바뀌어도 통합니다.

## 문구 변환 프롬프트
### 하나 · 센터 계정 게시물용
```plain text
너는 청년 정책을 청년 눈높이로 옮기는 홍보 담당자야.

[안내문]
(공고 내용 그대로 붙여넣기)

위 안내문을 인스타그램 게시물 문구로 바꿔 줘. 아래 조건을 지켜 줘.

1. 첫 문장은 정책 이름이 아니라,
   읽는 사람이 겪었을 상황으로 시작할 것
2. 전체 다섯 줄 이내
3. 신청 자격과 마감일은 반드시 포함할 것
4. 안내문에 없는 내용은 절대 만들어내지 말 것.
   확인이 필요한 부분은 [확인 필요]로 표시할 것
5. 느낌표는 두 개까지만
6. "여러분", "많은 관심 바랍니다" 같은 표현은 쓰지 말 것
7. 마지막에 저장하거나 친구에게 보낼 이유가 되는 한 줄을 붙일 것

문구 3안을 서로 다른 시작점으로 작성해 줘.
```

**4번이 제일 중요합니다**
AI는 모르는 정보를 그럴듯하게 지어내요. 정책 홍보에서 금액이나 마감일이 잘못 나가면 게시물 내리는 걸로 안 끝납니다. **신청하려다 놓친 사람이 생겨요.**
`[확인 필요]` 표시를 강제하는 게 이걸 구조적으로 막습니다. 그리고 **표시된 항목은 반드시 원문과 대조**하세요. 표시만 시키고 안 보면 의미가 없어요.

### 둘 · 개인 채널용
홍보 파트는 개인 블로그·인스타·스레드에 올리시죠. 센터 계정과 같은 문구를 그대로 쓰면 어색해요.
```plain text
너는 내 개인 SNS 계정에 올릴 글을 쓰는 사람이야.

[정보]
(행사나 정책 내용 붙여넣기)

[내 계정 성격]
- 플랫폼: (인스타 / 블로그 / 스레드)
- 평소 말투: (예: 반말체, 짧은 문장, 이모지 거의 안 씀)
- 팔로워: (예: 또래 대학생, 지역 친구들)

위 정보를 내 계정에 올릴 글로 바꿔 줘.

1. 홍보처럼 보이지 않게, 내 경험이나 생각에서 시작할 것
2. 정보는 글 중간이나 끝에 자연스럽게 넣을 것
3. 사실 관계는 [정보]에 있는 것만 쓸 것
4. 내 말투로 쓸 것. 공식적인 표현은 쓰지 말 것

두 가지 버전으로 작성해 줘.
```

**말투를 설명하지 말고 AI가 알아내게 하세요**
훨씬 정확한 방법이 있어요.
`이건 내가 쓴 글 중 가장 마음에 드는 거야. [글 붙여넣기] 이 글을 분석해서 1) 말투, 2) 글의 구조, 3) 문장 호흡을 추출해 줘. 그리고 앞으로 내가 어떤 상황을 던지든 이 글과 같은 스타일로 새 글을 써주는 지침을 네가 직접 짜줘.`
나온 지침을 저장해두고 계속 쓰시면 됩니다.


**AI가 써준 걸 그대로 올리지 마세요**
**본인 말투로 한 번 고쳐서** 올리셔야 개인 계정 글로 읽힙니다. 요즘은 AI가 쓴 글을 사람들이 금방 알아봐요.

## 서포터즈가 알아둘 것

**정확성이 제일 중요합니다**
- 날짜, 금액, 자격 요건은 **사람이 직접 확인**합니다
- AI는 빈칸을 창작으로 메워요. 이게 정책 홍보에서 제일 위험합니다
- 재미가 목적이 되면 안 됩니다. 공공기관 SNS의 목적은 **딱딱한 정보를 쉽게 전달하는 것**이고, 재미는 수단이에요


**저작권·초상권·개인정보**
- AI가 만든 이미지도 실제 사람 얼굴을 닮게 만들면 문제가 됩니다. 인물은 실루엣이나 단순화된 형태로 지정하세요
- 다른 기관 게시물을 첨부해 "이렇게 만들어 줘" 하는 건 피하시고요
- 참여자 명단, 연락처, 신청서 같은 자료는 AI에 올리지 마세요
- 센터 공식 계정에 올릴 이미지는 담당자 확인을 거치세요

## E. 수정할 때 (STYLE LOCK)
```plain text
STYLE LOCK — 아래는 그대로 유지할 것:
- 구도와 시선 높이
- 캐릭터의 생김새와 비율
- 색상 규칙과 선 굵기
- 배경 처리 방식
- 상하단 여백의 크기

내가 명시적으로 요청한 것만 바꿀 것. 나머지는 전부 동일하게.

[바꿀 것]
- (여기에 하나만)
```
자주 쓰는 \[바꿀 것\] 문장들이에요.
```plain text
- 아래쪽 여백을 지금의 두 배로 늘려 줘

- 요소 개수를 절반으로 줄이고 배경은 단색으로 정리해 줘
- 전체 색조만 [색]으로 바꿔 줘
```
