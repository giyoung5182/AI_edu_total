AI가 쓴 한글 글에서 AI 티만 골라 지워주는 도구예요. 한국 개발자가 만들었고 오픈소스라 무료입니다.
**내용은 한 글자도 안 바뀝니다.** 사실, 수치, 고유명사, 직접 인용은 100% 원문 그대로 두고 문체와 리듬만 손봐요. 원문이 30% 넘게 바뀌면 경고하고 50%를 넘으면 아예 멈춥니다.
> 아래 세 가지 방법 중 **본인 상황에 맞는 하나만** 하시면 됩니다. 다 할 필요 없어요.
# 1. 그냥 써보고 싶다 (설치 없음, 1분)
제일 쉬운 방법입니다. 설치도 로그인도 필요 없어요.
1. 브라우저에서 **imnotai.kr** 접속
2. AI가 쓴 글을 붙여넣기 (PDF 업로드도 됩니다)
3. **빠른** 또는 **정밀** 중에 선택
4. 결과 복사
**언제 이걸 쓰나요**
한 번만 써볼 때, 또는 가끔 쓸 때. 매번 글을 옮겨 담는 게 번거로워지면 아래 2번으로 넘어가세요.
# 2. 클로드나 ChatGPT에 붙여두고 쓰고 싶다
한 번 등록해두면 대화 중에 "이 글 AI 티 없애줘"라고만 하면 됩니다.
## 1단계. 아래 파일 다운로드
바로 올릴 수 있게 압축해둔 파일입니다. 깃허브 들어가실 필요 없어요.

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]


## 2단계. 클로드 웹 또는 데스크톱 앱에 올리기
1. 좌하단 **사용자 지정** → **스킬**
2. 우측 상단 **+** → 업로드
3. 방금 받은 zip 그대로 선택 (압축 풀 필요 없습니다)
4. 목록에서 토글 켜기
5. **새 대화 열기** (기존 대화에서는 안 잡힙니다)
한 번 등록하면 계정에 저장돼서 웹이든 데스크톱 앱이든 로그인만 하면 따라옵니다. 기기마다 따로 설치할 필요 없어요.
## ChatGPT에 올리기
1. 같은 zip을 스킬 메뉴에서 업로드
2. 활성화 후 새 대화
3. `@`로 직접 부르거나 그냥 "AI 티 없애줘"라고 하면 알아서 잡습니다
> **주의**: 웹이나 앱에 올리면 단일 호출 버전으로 돕니다. 정밀도는 3번이 가장 높아요.
# 3. 정밀하게 쓰고 싶다 (클로드 코드)
탐지, 윤문, 내용 감사, 자연스러움 검증을 4개로 나눠 돌리는 완전판입니다.
클로드 코드 안에서 아래 두 줄을 차례로 실행하세요.
```javascript
/plugin marketplace add epoko77-ai/im-not-ai
```
```javascript
/plugin install humanize-korean@im-not-ai
```
새 세션을 열고 `/humanize-korean` 또는 그냥 "이 글 AI 티 없애줘"라고 하면 됩니다.
코덱스 CLI, 깃허브 코파일럿 CLI, 제미나이 CLI도 지원합니다. 단 이쪽들은 단일 호출만 돌아가요.
