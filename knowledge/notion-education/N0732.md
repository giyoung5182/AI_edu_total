# 1️⃣ 자동화 주제 정하기
### MVP란?

**MVP** = 핵심 기능만 담은 **가장 작은 작동 시스템**
완벽한 시스템이 아니라, "이 방향이 쓸모 있을지 빠르게 확인할 수 있는 최소 결과물"을 만드는 것이 목적입니다.


**비유: "MVP는 예산 시뮬레이션"**
본 예산 확정 전에 여러 시나리오로 방향을 먼저 검토하듯, MVP는 **"이 아이디어가 실무에서 쓸모 있을까?"를 빠르게 확인**하기 위한 작은 버전입니다.

# 2️⃣ 문제/목표/사용자 정의
**핵심 질문**: "누가, 언제, 무엇을 위해 쓰는가?"

**\[실습\] ChatGPT로 문제 정의 작성**
```markdown
## 역할
당신은 건설 프로젝트 예산·원가 업무 자동화 컨설턴트입니다.

## 입력
- 자동화 주제: [선택한 주제]
- 현재 업무 상황: [지금 어떤 불편함/비효율이 있는지 구체적으로]

## 요청
위 주제를 한 문장 "문제 정의"로 정리해줘.

## 형식
[누가] + [어떤 상황에서] + [무엇을 겪고 있으며] + [어떤 결과가 발생하는가]

## 조건
- 측정 가능한 수치 포함 (예: "매주 3시간", "월 15건")
```

---
### 문제 정의 예시 (참고)
- "원가 담당자가 매일 현장별 예산 집행 현황을 취합하여 월간 비용·집행 보고서를 작성하는 데 매월 마감 시 2시간 이상 소요되어, 실제 원가 초과 원인 검토에 투입할 시간이 부족하다"
- "원가 담당자가 집행 현황표에서 초과 항목을 수동으로 식별하고 후속 대책을 수립하는 데 월 2회 각 3시간이 소요되어, 비용 리스크가 누적된 후에야 대응하게 된다"
---

**\[실습\] 기획안 채우기**
```markdown
## 프로젝트 기획안

### 1. 문제 정의
[확정된 한 문장]

### 2. 목표
- 핵심 목표: [한 줄]
- 성공 기준: [수치. 예: "월간 비용·집행 보고서 작성시간 70% 절감"]

### 3. 사용자
- 주 사용자: [직무/직급]
- 사용 빈도: [매일/매주/매월]
- 사용 시점: [언제 쓰는가]
```

# 4️⃣ 성공 기준 설정

**성공 기준 = "이 시스템이 잘 작동했다고 어떻게 알 수 있나?"**
거창한 KPI 말고, **본인이 체감 가능한 수치 1\~2개**면 충분합니다.


**\[실습\] 성공 기준 표 작성**
```markdown
## 역할
당신은 프로젝트 성과 측정 전문가입니다.

## 입력
- 자동화 주제: [주제]
- 문제 정의: [문제]
- 출력물: [결정한 출력 형태]

## 요청
이 시스템의 성공 기준을 Before / After 표로 정리해줘.

## 출력 형식
| 기준 항목 | Before (지금) | After (목표) | 측정 방법 |

## 예시
| 월간 비용·집행 보고서 작성시간 | 120분/월 | 30분/월 (75% 절감) | 타이머 측정 |
| 원가 초과 탐지 시점 | 월 2회 수동 확인 | 데이터 입력 시 자동 경고 | 경고 발생 시점 기록 |
```
**완성된 기획안 전체를 패들렛에 올려주세요. 6차시에서 이 기획안을 바탕으로 AI Developer로 실제 시스템을 만듭니다.**

### 📌 5차시 정리
```markdown
✅ 1. MVP = 핵심 기능만 담은 최소 작동 시스템. 완벽할 필요 없음
✅ 2. 문제 정의: [누가] + [어떤 상황] + [무엇을 겪고] + [어떤 결과] 한 문장
✅ 3. 입력 데이터: 4차시 입력 템플릿 그대로 활용 가능
✅ 4. 출력물 유형: 보고서 / 의사결정 보조 / 분류·집계 중 선택
✅ 5. 성공 기준: Before → After 수치
✅ 6. 다음 차시(6차시)에서 AI Developer로 실제 작동시킵니다
```
