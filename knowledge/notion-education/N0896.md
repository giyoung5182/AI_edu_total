## 요소 3. 그릇·배경 — 담는 것과 바닥
### 그릇 (음식별로 자연스러운 것)





음식 종류

어울리는 그릇




찌개·전골

검은 무쇠 전골냄비, 뚝배기, 은색 스테인리스 냄비




구이·고기

무쇠 불판, 돌판, 무쇠 그릴, 나무 도마




탕·국

뚝배기, 흰 도자기 대접




볶음·무침

흰 접시, 옹기 종지, 스테인리스 볼




튀김·안주

나무 트레이, 유산지 깐 바구니, 검은 슬레이트




면류

흰 사발, 검은 대접, 대나무 채반




주류

브랜드 맥주잔, 소주잔, 은색 주전자


### 배경 바닥





원하는 느낌

프롬프트에 쓸 단어




고급스럽고 차분

어두운 우드 테이블, 검은 대리석, 짙은 색 원목




밝고 깨끗

밝은 나무 테이블, 흰 대리석, 밝은 원목




전통·향토

한지 느낌 배경, 무명천, 옹기 질감 바닥




캐주얼

콘크리트 바닥, 크래프트 종이, 스테인리스 판


### 소품 (넣거나 빼기)
```plain text
소품 최소화 / 소품 없이 음식만
(넣을 경우) 수저 한 벌, 소주병, 반찬 종지 1~2개
⚠️ 소품이 많으면 지저분해 보임. "소품 최소화"가 안전함
```

## 요소 4. 조명 — 밝기와 온도
⚠️ **"밝게"가 아니라 색온도(K)로 지정하면 정확해짐.** 아래에서 고르기만 하면 됨.
### 색온도 (분위기별)





원하는 분위기

색온도 + 표현




따뜻하고 아늑함 (한식당·고깃집)

2700\~3000K 따뜻한 조명, 노란빛이 도는




자연스러운 낮 느낌

5000K 자연광, 창가에서 들어오는 빛




깨끗하고 시원함 (모던·주류)

5500\~6500K 밝고 선명한 조명




은은하고 고급스러움

낮은 조도의 따뜻한 조명, 주변이 살짝 어두운


### 빛의 방향 (선택)





원하는 느낌

표현




입체감·윤기 강조

측면에서 들어오는 빛 (측광)




부드럽고 균일

위에서 부드럽게 퍼지는 빛




극적이고 고급스러움

한쪽에서만 들어오는 빛, 그림자가 진한




뒤에서 김·윤기 강조

뒤쪽에서 비치는 역광, 김이 빛나게


### 그림자
```plain text
부드러운 그림자 (자연스럽고 무난 — 기본값)
선명한 그림자 (또렷하고 강한 느낌)
```

## 요소 5. 구도 — 어느 각도에서
⚠️ 아래 5개 중 **음식에 맞는 것 하나**를 고름.





각도 이름

어떻게 보이나

어울리는 음식




**탑다운 (90도, 위에서)**

접시를 정수리에서 내려다봄

여러 반찬, 상차림, 평평한 음식, 배달 메뉴




**45도 하이앵글**

비스듬히 위에서 (가장 무난)

대부분의 음식, 찌개, 구이




**눈높이 테이블샷**

식탁에 앉은 사람 눈높이

높이 있는 음식, 층층이 쌓인 버거·케이크, 국물이 찰랑이는




**클로즈업 (접사)**

음식의 한 부분을 크게

질감 강조 (고기 단면, 치즈, 튀김옷)




**와이드샷**

음식 + 매장 분위기까지

매장 홍보, 테이블 세팅 전체


### 렌즈 느낌 (선택 — 몰라도 됨)
```plain text
배경을 흐리게, 음식만 또렷하게  → "얕은 심도, 배경 흐림"
전체가 다 선명하게              → "전체적으로 선명하게"
가까이 크게                     → "85~100mm 접사 느낌"
```

## 조합 예시 — 6요소를 이어 붙이면
**예시 1. 김치찜 (소식탭용)**
```plain text
고등어김치찜 1인분, 고등어 2토막·묵은지·대파, 갓 끓여 김이 오르는 상태 /
따뜻하고 정갈한 전통 한식당 분위기 /
검은 무쇠 전골냄비, 어두운 우드 테이블, 소품 최소화 /
2700~3000K 따뜻한 조명, 측면에서 들어오는 빛, 부드러운 그림자 /
45도 하이앵글, 얕은 심도로 배경 흐림 /
4K 고화질, 소식탭 게시용 정사각.
이미지에 텍스트·로고 넣지 말 것. 상단 1/3 비워둘 것.
```
**예시 2. 삼겹살 구이 (인스타용)**
```plain text
삼겹살 구이, 노릇하게 익은 3줄, 불판 위에서 지글거리며 익는 중 /
활기차고 푸짐한 고깃집 분위기 /
무쇠 불판, 밝은 나무 테이블, 소주잔 하나 /
2700K 따뜻한 조명, 뒤쪽 역광으로 기름 윤기 강조 /
눈높이 테이블샷 /
4K 고화질, SNS 게시용 정사각.
이미지에 텍스트·로고 넣지 말 것.
```
**예시 3. 맥주 (메뉴판용)**
```plain text
생맥주 한 잔, 거품이 살아있고 잔에 물방울이 맺힌 시원한 상태 /
편안하고 정겨운 호프 분위기 /
브랜드 맥주잔, 어두운 우드 테이블, 소품 없이 /
5500K 밝고 선명한 조명, 측광으로 거품 강조 /
눈높이 클로즈업, 얕은 심도 /
인쇄용 고해상도, A4 세로.
이미지에 텍스트·숫자·로고 넣지 말 것. 하단에 가격 들어갈 자리 비울 것.
```
