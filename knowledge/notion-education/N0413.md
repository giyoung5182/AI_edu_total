## 이 실습으로 하는 것
같은 안내서 6장 요약을 요소 하나씩 더해 v0\~v3으로 실행하고, 어떤 요소가 결과를 바꿨는지 내 합격 기준으로 판정한다.
## 진행 단계
1. **합격 기준 정하기** — 워크시트 P2-1에 기준 3개(합격 기준 4종 틀에서 최소 2종)
2. **새 채팅 + 안내서 첨부** — + → 사진 및 파일 추가
- 정상 결과: 입력창 위에 파일 이름 카드가 붙음
3. **v0 — 조건 없음**
```javascript
첨부한 안내서의 6장을 요약해줘.
```
4. **v1 — C(맥락)만 추가** — 읽는 사람(기업고객 구매담당자)과 용도(취소·변경 비용 판단)를 넣고 '앞의 답변은 무시하고 처음부터 다시' 요청
5. **v2 — 내 합격 기준을 제약으로 추가** — 대괄호 \[내 합격 기준 1\~3\]을 내 문장으로 바꿔서 입력, 개조식 A4 반 장 이내
6. **v3 — K 처리 규칙만 추가** — 근거는 6장뿐, 수치는 원문 그대로, \[확인 필요\]는 남기기, 없는 내용은 '담당 컨설턴트 확인 필요', 마지막 줄 근거 표기
7. **기록·판정** — P2-2 표에 달라진 점·충족 수·남은 문제 기록, 원문(Ctrl+F)과 수치 2\~3개 대조
8. **남길 것** — v3 프롬프트 전문 → 카드 1 ④, 합격 기준 → ⑦
## 막히는 지점
- 파일 카드에 오류 표시 → × 눌러 제거 후 재첨부
- v0이 1장부터 전체를 요약 → 파일은 읽었지만 6장을 놓친 상태, 그대로 기록
- v2 결과에 \[내 합격 기준 1\] 글자가 보임 → 대괄호를 바꾸지 않고 보낸 것
- 답이 중간에 끊김 → '이어서 작성해줘.'
