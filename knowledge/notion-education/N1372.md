# 실습 2. 작업 명세를 AGENTS.md로 저장 — 동일 사건 기준 스스로 정하기 (필수)

정리일: 2026-10-08 · 교육 에셋 N1372

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
회차마다 '같은 사건'의 기준이 달라지지 않도록 사람이 정할 업무 판단을 AGENTS.md 4번(처리 규칙)에 적어 고정합니다.
## 진행 단계
1. **틀 붙여넣기** — 교안의 AGENTS.md 틀(1. 목적 \~ 6. 끝나면 확인할 것)을 메모장에 붙여넣습니다.
- 입력할 내용: # AGENTS.md — 클레임이력·고객문의메일 연결 작업 지침 / 6개 칸 (목적 · 입력 파일 · 출력 파일과 형식 · 처리 규칙 · 금지 · 끝나면 확인할 것) (이하 교안 참고)
2. **4번 ② 세 칸 채우기** — 고객사·시기·현상·가리키는 표현·유형 중 무엇이 맞아야 같은 사건인지 골라 문장으로 씁니다.
3. **4번 ⑦ 채우기** — 메일 번호가 비었을 때, 앞 메일을 가리키는데 그 원문이 없을 때 어떻게 할지 1줄 이상 씁니다.
4. **저장** — 파일 → 다른 이름으로 저장 → 파일 이름 AGENTS.md, 파일 형식 모든 파일, 인코딩 UTF-8 → 1회차 폴더.
## 막히는 지점
- AGENTS.md가 AGENTS.md.txt로 저장됨: 파일 탐색기 보기 → 파일 확장명을 켜고 이름을 AGENTS.md로 변경(Mac: 파일 정보 ⌘+I)
