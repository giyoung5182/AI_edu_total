# 실습 목표 1 · PPT 템플릿과 업무 자료로 PPTX 만들기

정리일: 2026-10-08 · 교육 에셋 N1504

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
PPT 템플릿과 업무 자료를 Claude Code에 전달해서 수정 가능한 PPTX 결과물을 만듭니다.
## 진행 단계
1. **실습 파일 넣기** — 실습자료.zip의 파일들을 Claude Code에 넣습니다.
2. **Skill 설치** — PPT 작업용 설명서(Skill)를 설치합니다.
- 입력할 내용:
```markdown
다음 SKILL을 설치해주세요.
npx skills add https://github.com/anthropics/skills --skill pptx
LibreOffice는 설치해서 진행해주세요.
```
1. **템플릿 채우기 요청** — 템플릿과 자료를 반영하도록 요청합니다.
- 입력할 내용:
```plain text
첨부한 PPT 템플릿의 디자인과 레이아웃은 유지한 상태로,
함께 첨부한 메모 파일과 CSV/엑셀 데이터의 내용을 반영해서
PPT 내용을 채워주세요.
```
- 정상 결과: Claude Code가 템플릿과 자료를 확인하고 새로운 PPTX 파일을 만들어 줍니다.
