## 이 실습으로 하는 것
Windows 파일을 WSL(Ubuntu)로 가져오는 두 가지 방법을 따라 해 봅니다.
## 진행 단계
1. **탐색기로 가져오기** — Windows 탐색기 실행 → 왼쪽 목록에서 Linux → Ubuntu → home → 사용자명 순서로 이동(또는 주소창에 `\\wsl.localhost\Ubuntu\home\사용자명`) → 옮길 파일을 복사해 붙여넣기
2. **현재 위치를 탐색기로 열기**
```bash
explorer.exe .
```
- 마지막 마침표는 "현재 폴더"라는 뜻
1. **WSL에서 Windows 파일 접근** — C 드라이브는 `/mnt/c`에 연결
```bash
ls /mnt/c[로컬 경로]
cp /mnt/c[로컬 경로] ~/hanbit-ai/
```
## 막히는 지점
- 탐색기에 Linux 항목이 없음: Ubuntu 터미널을 한 번 실행한 뒤 탐색기 새로고침
- `:Zone.Identifier` 파일이 생김: Windows 보안 꼬리표이며 무해. `find . -name "*:Zone.Identifier" -delete`로 정리
- 실습 작업은 반드시 `~/` 아래에서 수행
