# 1️⃣ 시장 조사하기 (Deep Research)

정리일: 2026-10-08 · 교육 에셋 N0330

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
국내 프리미엄 숏패딩 시장을 Gemini Deep Research로 조사하고, 조사 계획을 확인한 뒤 출처를 검증합니다.
## 진행 단계
1. **Deep Research 선택** — Gemini → 도구 → Deep Research. 기본 소스는 Google Search만 사용.
2. **프롬프트 입력**
- 입력할 내용:
```javascript
국내 프리미엄 숏패딩 시장을 조사해줘.
다음 형식으로 정리해줘.

1. 최근 소비자 구매 포인트
2. 대표 경쟁사들의 메시지 차이
3. 소비자가 반응하는 콘텐츠 유형
4. 후발주자가 들어갈 수 있는 기회 3가지
5. 내부 보고용 7문장 요약
```
1. **조사 계획 읽기·수정** — 바로 보고서가 나오지 않고 조사 계획이 먼저 뜸. 바꾸고 싶으면 한 줄 추가.
- 입력할 내용:
```javascript
경쟁사는 3곳 이상 비교해주고, 최근 1년 자료 위주로 조사해줘.
```
1. **연구 시작** — 보고서 생성에 몇 분 걸림.
2. **출처 확인** — 출처 2\~3개를 클릭해 내용 일치 / 날짜 / 출처의 성격(공식 통계·기사인지, 블로그·광고성 글인지)을 확인. 이상하면 항목을 빼거나 "이 부분 출처를 다시 확인해서 보강해줘"라고 재요청.
3. **저장** — Google Docs 내보내기 대신(사내 환경에서 Google Docs 미실행) 콘텐츠 복사 후 Word에 붙여넣어 저장.
