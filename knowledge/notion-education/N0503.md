## 이 실습으로 하는 것
미처리 요청 여러 건을 한 번에 가져와 하나의 이메일 본문으로 합쳐 보내는 시나리오를 만듭니다.
## 진행 단계
1. **새 시나리오 생성**
2. **Schedule 트리거** — Every week / Monday / 09:00 / Asia/Seoul (테스트 시에는 Every day로 설정 후 나중에 변경)
3. **Search Rows** — Filter: Column I, Equal to, 미처리 / Limit 100, Run once로 조회 건수 확인
4. **Iterator** — Array: "2. Google Sheets \> Rows" 선택
5. **Text Aggregator** — Source Module "3. Iterator", Text는 "▶ " + 매장명 + " / " + 요청유형 + " / " + 타임스탬프, Row separator n
6. **Gmail** — Content에 "5. Text aggregator \> Text" 삽입
7. **전체 Run once 테스트** — 메일 본문에 3개 항목이 줄바꿈으로 나열되면 성공
## 막히는 지점
- 개념: Search Rows는 여러 행(배열), Iterator는 하나씩 꺼냄, Text Aggregator는 다시 하나로 합침
- Iterator 드롭다운에 Rows가 안 보이면 Search Rows 모듈을 먼저 Run once
- Text Aggregator 변수가 안 보이면 Run once로 Iterator까지 실행 후 재시도
