# 13장 · 배포 — 인터넷 주소 만들기

## 13-1. 왜 필요한가
지금 만드신 `index.html`은 **내 컴퓨터 안에만 있습니다.**
```plain text
지금 상태     내 노트북에서만 열림 → 학생은 못 봄
필요한 상태   인터넷 주소가 있음   → 학생이 QR로 접속
```
그리고 3장에서 본 대로, **학생은 AI 서비스 계정을 만들 수 없습니다.** 그래서 이 주소 방식이 유일한 배포 경로입니다.
## 13-2. 쓰는 도구 두 개

보관된 파일을 실제 주소로 띄움


둘 다 무료이고, 사전 안내에서 이미 가입해 오셨습니다.
> 📖 **Git과 GitHub는 다릅니다**<br>Git은 오전에 설치한 **프로그램**이고, GitHub는 파일을 올리는 **웹사이트**입니다. 이름만 비슷합니다.

```plain text
1. Claude 데스크톱 앱을 완전히 종료합니다
   → 창만 닫는 게 아니라 프로그램을 완전히 끕니다
```

프로그램 설치하고 컴퓨터 껐다 켜는 것과 같은 이유입니다.
> ⚠️ **재실행 후 아직 입력창에 아무것도 치지 마세요.** 다음 단계는 다른 곳에서 합니다.

그래서 이 단계만큼은 **사람이 직접 확인**합니다.

### 💡 왜 프라이빗으로 올리나요
퍼블릭으로 올리면 누구나 코드를 볼 수 있습니다. 혹시 자료 안에 학생 이름이나 개인적인 내용이 들어 있을 수 있으니, **처음부터 프라이빗으로 올리는 습관**을 들이시는 게 좋습니다.
> 💡 프라이빗으로 올려도 **배포된 웹 주소는 누구나 접속할 수 있습니다.** 코드만 안 보이는 것입니다. 학생 접속에는 문제가 없습니다.

## STEP 6 · 주소 확인 · 앱처럼 만들기 (7분)
### ① 주소를 열어봅니다
```plain text
1. 화면에 나온 https:// 주소를 복사합니다
2. 브라우저 주소창에 붙여넣고 엽니다
3. 만든 화면이 그대로 나오는지 확인합니다
```
### ② 휴대폰으로 접속해봅니다
**이게 오늘의 마지막 확인입니다.**
```plain text
1. 휴대폰 브라우저에 주소를 입력하거나
2. 옆자리 선생님께 주소를 보내서 열어보게 하세요
```
> 💡 **내 노트북이 아닌 곳에서 열려야 진짜입니다.** 학생이 접속하는 상황과 같습니다.
### ③ 앱처럼 만들어봅니다 ★
4교시에 만든 `manifest.json`이 여기서 일을 합니다. **배포된 뒤에야 동작합니다.**
**휴대폰에서 할 일**
```plain text
[안드로이드 · 크롬]
  주소를 연 상태에서 → 우측 위 ⋮ → "홈 화면에 추가"

[아이폰 · 사파리]
  주소를 연 상태에서 → 아래 공유 버튼 → "홈 화면에 추가"
```
**확인할 것**
```plain text
□ 홈 화면에 아이콘이 생겼는가
□ 이름이 내가 정한 이름으로 나오는가
□ 아이콘을 눌렀을 때 주소창 없이 전체화면으로 뜨는가
```
> 💡 **주소창이 사라지면 학생 눈에는 앱입니다.**<br>설치한 것도 아니고 앱스토어를 거친 것도 아닌데, 화면만 보면 앱과 구분이 안 됩니다.
> ⚠️ **휴대폰 기종과 브라우저에 따라 조금씩 다릅니다.** 전체화면이 안 되고 주소창이 남아도 정상 동작입니다. 아이콘이 생기는 것만으로도 학생 접근성은 크게 좋아집니다.

## 15-4. 더 할 수 있는 것 — 시연
여기서부터는 **오늘 실습하지 않습니다.** 이런 것도 있다는 것만 보시면 됩니다.
### ① 여러 작업을 나눠서 시키기
큰 것을 만들 때는 작업을 나눠서 동시에 진행시킬 수 있습니다. 화면을 만드는 쪽과 자료를 다루는 쪽을 따로 맡기는 식입니다.
오늘처럼 파일 하나짜리에는 필요 없지만, 규모가 커지면 유용해집니다.
### ② 브라우저를 다루게 하기
Claude Code가 직접 웹사이트에 접속해서 자료를 모아올 수도 있습니다. 이런 식으로 외부 도구를 연결하는 방식을 **MCP**라고 부릅니다.
### ③ 자료를 저장하는 기능 붙이기
오늘은 "보여주기"까지만 했습니다. 학생이 입력한 걸 저장하려면 별도 서비스를 연결해야 합니다. 필요해지면 그때 하시면 됩니다.
