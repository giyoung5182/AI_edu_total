# 실습 2 — 만들게 하기 (문서·엑셀을 파일로 저장)

정리일: 2026-10-08 · 교육 에셋 N0443

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
결과를 화면에 보여주는 대신 AI가 폴더에 파일로 저장하게 합니다.
## 진행 단계
1. **문서 만들기** — 문의 메일 20건을 6개 유형(견적·계약 / 기술 문의 / 클레임·품질 이의 / 자료 요청 / 납기·일정 / 신규 거래)으로 분류해 문의분류_결과.md 저장. 유형별 건수 표, 대표 사례 1건, 판단 보류 건과 이유. 애매한 건은 "판단 보류"
- 정상 결과: 파일이 실제로 폴더에 생김, 내용이 맞음
2. **엑셀 만들기** — 클레임이력 시트를 월별·귀책별로 집계해 클레임_월별집계.xlsx 저장. 시트 3개(월별 요약, 귀책별 요약, 원본 정리), 원본 수정 금지, 통일한 표기 기록, 금액 천원 단위
- 정상 결과: 새 엑셀 생성, 시트 3개, 원본 그대로, 수정 내역 기록
## 막히는 지점
- "원본 파일은 수정하지 마라"를 반드시 넣고 새 파일로 만들게 합니다.
