# 실습② — Gemini Gem 만들기

정리일: 2026-10-08 · 교육 에셋 N1203

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
본인이 반복하는 업무 하나를 정해 Gemini Gem으로 만들고, 지침을 한 줄 고쳐 결과가 어떻게 달라지는지 비교합니다.
## 진행 단계
1. **반복 업무 하나 선택** — 예: 회의록 정리, 문의 답변, 보고서 초안
2. **브라우저로 Gems 들어가기** — 앱이 아니라 브라우저 주소창에 gemini.google.com을 직접 입력, 왼쪽 메뉴에서 Gems로 들어가 '새 Gem'을 누릅니다.
3. **지침 칸에 그대로 입력**
- 입력할 내용:
```javascript
[역할]   우리 부서 문서를 정해진 형식으로 정리하는 보조자.
[목표]   입력한 내용을 표로 정리.
[절차]   ① 항목별로 분리  ② 표로 이관  ③ 빠진 칸을 「확인 필요」로 표시
[예시]   | 항목 | 내용 | 확인 필요 |  형식으로 출력.
[지식]   근거가 없으면 지어내지 말고 「확인 필요」로 기재.
```
- 제약 세 줄과 출력 형식 한 줄을 지침 맨 아래에 이어 붙입니다(근거 없으면 「확인 필요」 표시 / 계산 과정 표시 / 개인정보와 진행 중 사건은 요약·인용 금지 / 서술형은 개조식, 종결어미 \~함·\~임·\~예정, 구어체 금지).
4. **내 업무 문장을 넣어 실행** — 1단계에서 정한 업무 내용을 직접 입력합니다.
5. **지침을 한 줄 고쳐 다시 실행** — 아래 중 하나를 추가하고 결과를 비교합니다: 표로 정리할 것 / 항목당 세 줄 이내 / 확인 필요 항목은 표 아래에 모을 것 / 숫자는 원문 표기 그대로(반올림 금지)
## 막히는 지점
- 교안에 명시된 항목은 없습니다. 막히면 손을 들어 현장에서 해결하고, 끝까지 안 되면 미리 만들어 둔 예시 링크를 받습니다.
