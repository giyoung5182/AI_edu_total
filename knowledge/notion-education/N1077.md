# Step 5 — 제출 전 최종 점검

## 이 실습으로 하는 것
담당 선생님께 결재받기 전에 팀원 전원이 체크리스트로 재료리스트를 점검합니다.
## 진행 단계
1. **점검** — 총 지출액이 배송비 포함 150,000원 이하 / 모든 상품에 링크 / 배송비 확인 / 상품명에 용량·수량·규격 / 포장재 포함 / 소모품 포함 / 재료별 배송지(집·센터) 표시 / 마진율 30% 이상 / 품절·장기 배송 상품 없음
2. **확인·결재** — 팀장 확인 서명 후 담당 선생님 결재를 받습니다.
