## Part 0. 오프닝 — 왜 지금 AI를 배워야 하는가 (20분)
### 시대가 바뀌었습니다
우리가 처음 인터넷을 배웠을 때를 기억하시나요?<br>"이메일이 뭐냐"던 시절, "검색창에 글자를 입력한다"는 것 자체가 낯설었던 시절이 있었습니다.
AI도 지금 그 시점에 와 있습니다.<br>지금 배우지 않으면 나중에는 더 어색하고 더 늦습니다.<br>반대로, 지금 익숙해지면 일상이 훨씬 편해집니다.
### AI는 젊은 사람 것이 아닙니다
오히려 AI는 **경험이 풍부한 사람에게 더 강력합니다.**
AI는 도구입니다. 도구를 어떻게 활용하느냐는 삶의 경험과 판단력에 달려 있습니다.<br>30년간 쌓아온 삶의 맥락, 사람을 다루는 감각, 중요한 것을 가려내는 눈.<br>이것들이 AI를 제대로 활용하게 만드는 진짜 능력입니다.

### 1-4. LLM은 어떻게 작동하는가
**핵심 한 문장:**
> LLM은 엄청난 양의 문장을 학습하고, 다음에 어떤 단어가 오면 가장 자연스러운지를 확률로 예측하는 모델입니다.
```plain text
예시:
"오늘 점심은 김치..." 입력
→ AI가 계산: "찌개(42%) / 볶음밥(28%) / 전(11%)..."
→ 가장 확률 높은 "찌개"를 선택
→ "오늘 점심은 김치찌개..."
→ 다음 단어 계속 예측 반복 → 문장 완성
```
**중요한 사실 두 가지:**
첫째, AI는 '이해'하는 게 아니라 '예측'합니다.<br>의미를 알아서 대답하는 것처럼 보여도, 근본은 통계적 패턴 예측입니다.
둘째, 같은 질문에도 매번 답이 조금씩 다릅니다.<br>"왜 어제랑 답이 달라요?" — 확률에 약간의 무작위성이 더해지기 때문입니다.
**일반 프로그램과의 결정적 차이:**

### 1-5. 할루시네이션 — AI가 거짓말하는 이유
**할루시네이션(Hallucination)이란:**
> AI가 없는 정보를 있는 것처럼, 틀린 내용을 맞는 것처럼 자신 있게 말하는 현상입니다.<br>
[원본 이미지 제외]
**왜 생기나:**<br>AI는 "모른다"고 멈추는 대신, 그 자리에 **가장 그럴듯한 말을 채워 넣습니다.**<br>빈칸을 두지 않고 그럴싸한 내용을 만들어내는 것이 AI에게는 더 자연스러운 출력입니다.
**실제 사례 유형:**
```plain text
존재하지 않는 통계:
"한국 65세 이상 AI 활용률은 2025년 기준 38.4%입니다" (만들어낸 수치)

틀린 날짜·역사:
"○○법은 2022년 3월 15일 개정되었습니다" (날짜 오류)

없는 사람 발언:
"○○ 교수는 저서에서 이렇게 말했습니다..." (실제로 한 말이 아닐 수 있음)

존재하지 않는 장소:
"서대문구 ○○동에 있는 ○○카페를 추천합니다" (없는 가게)
```
**특히 주의할 상황:**
- 구체적인 숫자, 통계, 비율
- 특정 인물의 발언 인용
- 최신 뉴스나 최근 변경된 정책
- 법 조항이나 의학 정보
**황금 원칙:**
```plain text
AI = 빠른 초안 작성자
사람 = 최종 판단자

수치 · 날짜 · 사람 이름 · 법 조항은
반드시 원본 자료로 직접 확인하세요.
```
> 할루시네이션은 AI의 결함이 아니라 구조적 특성입니다.<br>AI가 80%를 빠르게 만들고, 사람이 20%를 검토하고 책임지면 됩니다.<br>이것이 AI 시대에도 사람의 역할이 사라지지 않는 이유입니다.

### 1-6. 토큰과 컨텍스트 윈도우 — AI의 기억 한계
**토큰이란:**<br>AI는 글자가 아니라 토큰(단어 또는 단어 조각) 단위로 처리합니다.
```plain text
"안녕하세요"      →  [안녕] [하세요]          약 2토큰
"인공지능"        →  [인공] [지능]            약 2토큰
이미지 (사진 1장) →                           수백~수천 토큰
```
한국어는 영어보다 토큰을 더 많이 소비하는 경향이 있습니다.<br>무료 플랜에서 "오늘 사용량을 다 썼어요"의 정체가 바로 토큰 소진입니다.
**컨텍스트 윈도우:**<br>AI는 대화 전체를 영구 기억하는 게 아닙니다. 한 번에 읽을 수 있는 분량 안의 내용만 참조합니다.
```plain text
컨텍스트 윈도우 = AI가 한 번에 볼 수 있는 최대 분량
```
이를 넘으면 가장 오래된 내용부터 잊기 시작합니다.
**긴 대화에서 AI가 헤맬 때 해결책:**
- 새 대화를 시작합니다 (가장 확실한 방법)
- 핵심 내용을 다시 정리해 입력합니다

## Part 2. 프롬프트 엔지니어링 기초\~고도화 (1시간)
### 2-1. 프롬프트란 무엇인가
**프롬프트(Prompt):**<br>AI에게 내가 하는 말, 즉 **질문이나 지시문**을 뜻합니다.
> AI의 성능은 같아도, 어떻게 물어보느냐에 따라 결과가 완전히 달라집니다.
**가장 쉬운 비유:**
```plain text
AI를 아주 유능한 비서라고 생각해보세요.
그 비서에게 "뭔가 해줘"라고 하면 당연히 헤맵니다.
"이런 목적으로, 이런 형식으로, 이 분량으로 만들어줘"라고 하면
정확하게 해냅니다.

프롬프트 = 비서에게 주는 구체적인 업무 지시서
```
**연구 결과:**<br>같은 AI 모델이라도 좋은 프롬프트를 사용하면 정확도가 61%에서 87%까지 올라갑니다.<br>도구가 아니라 **사용법**이 결과를 결정합니다.

### 2-2. GIGO 원칙 — 기본 중의 기본
```plain text
GIGO: Garbage In, Garbage Out
쓰레기를 넣으면 쓰레기가 나온다.

모호한 질문 → 모호한 답변
```

### 2-3. R.C.T.C 공식 — AI를 제대로 활용하는 4가지 열쇠
이 공식 하나만 기억하면 오늘부터 AI 활용 수준이 완전히 달라집니다.<br>
[원본 이미지 제외]
```plain text
R — Role        역할 부여   어떤 전문가처럼 행동할지
C — Context     맥락 설명   배경, 상황, 목적을 알려줌
T — Task        구체적 요청  무엇을 해달라고 명확하게 지시
C — Constraints 형식과 제약  길이, 말투, 형식, 금지 사항 등
```
> GIGO 원칙 — 4요소 중 하나라도 빠지면 AI는 추측으로 채웁니다. 4개 모두 줘야 원하는 결과가 나옵니다.
---
### R — 역할 부여 (Role)
AI에게 어떤 전문가 역할을 맡길지 정해주는 것입니다.<br>AI는 역할을 주면 그 역할에 맞는 언어, 깊이, 관점으로 답합니다.
```plain text
❌ 역할 없음:
"건강에 대해 알려줘"
→ 피상적이고 교과서 같은 일반 답변

✅ 역할 부여:
"당신은 50대 이상을 위한 건강 상담 전문가입니다.
 쉬운 말로 친근하게 설명해주세요."
→ 나이대에 맞는 맞춤화된, 훨씬 유용한 답변
```
**역할 부여 예시 모음:**





상황

역할 프롬프트




건강 정보

"당신은 노년기 건강 전문가입니다. 쉬운 말로 설명해주세요."




여행 계획

"당신은 시니어 여행 전문 플래너입니다."




글쓰기 도움

"당신은 따뜻한 글쓰기를 잘하는 작가입니다."




법률·행정

"당신은 생활법률 상담 전문가입니다. 어려운 용어는 쉽게 풀어주세요."




요리

"당신은 한국 전통 요리 전문 요리사입니다."


**팁:**
- "당신은 ○○ 전문가입니다"로 시작
- 경력, 전문 분야를 구체적으로 쓸수록 더 좋음
- 내 상황(나이, 배경)도 함께 알려주면 더 잘 맞춤화됨

### C — 맥락 설명 (Context)
AI에게 상황을 충분히 알려주는 것입니다.
```plain text
❌ 맥락 없음:
"여행 계획 짜줘"
→ AI는 어디로, 누가, 얼마나, 어떤 스타일인지 전혀 모릅니다.

✅ 맥락 있음:
"나는 65세 부부입니다.
 걸음이 조금 불편해서 무리한 일정은 피하고 싶어요.
 2박 3일 강원도 여행을 계획 중이고,
 단풍 구경과 온천을 꼭 포함하고 싶습니다.
 이동은 렌터카를 선호합니다."
```
**맥락 체크리스트 — 5W1H:**





항목

질문

예시




누가 (Who)

나는 누구인가, 대상은 누구인가

"65세 여성", "초등학생 손자에게"




무엇을 (What)

무엇에 대한 것인가

"여행 계획", "감사 편지"




왜 (Why)

목적이 무엇인가

"어버이날 선물로"

장소나 채널은

"카카오톡으로", "강원도로"




언제 (When)

시기, 기간은

"다음 주 금요일", "2박 3일"




어떻게 (How)

방식, 조건은

"렌터카로", "무리하지 않게"

### T — 구체적 요청 (Task)
무엇을 해달라는지 **동사로 명확히** 지시합니다.
```plain text
효과적인 동사:
작성해줘   → 편지, 문자, 글, 계획서
요약해줘   → 긴 내용을 짧게 정리
번역해줘   → 한국어 ↔ 영어
설명해줘   → 쉬운 말로 풀어서
추천해줘   → 목록으로 정리해서 제안
비교해줘   → 두 가지 이상의 차이점
고쳐줘     → 기존 글을 수정·개선
```
**단계별 지시도 효과적입니다:**
```plain text
"다음 순서로 해줘:
 1단계. 내 상황을 먼저 분석해줘.
 2단계. 가능한 방법 3가지를 제안해줘.
 3단계. 각 방법의 장단점을 정리해줘."
```
---
### C — 형식과 제약 (Constraints)
결과물의 형태와 조건을 지정합니다.
```plain text
분량 지정:
"3줄로 요약해줘" / "A4 반 장 분량으로" / "200자 이내로"

말투·어조 지정:
"친근하고 따뜻하게" / "격식체(합니다체)로" / "쉬운 말로"

형식 지정:
"표 형식으로" / "번호 목록으로" / "카카오톡 메시지 형식으로"

금지 사항 지정:
"추측성 내용은 쓰지 마" / "부정적인 표현은 빼줘"
```

### 2-5. 결과물 개선하기 — 이어서 대화하는 법
첫 번째 답이 마음에 안 들어도 괜찮습니다.<br>AI와는 **대화를 이어가며** 결과물을 다듬어 나갑니다.
```plain text
분량 조정:
"더 짧게 줄여줘. 핵심만 남기고."
"조금 더 길게, 구체적으로 써줘."

말투 조정:
"더 따뜻하고 친근하게 바꿔줘."
"쉬운 말로 다시 써줘."

형식 조정:
"표 형식으로 다시 정리해줘."
"번호 목록으로 바꿔줘."

내용 조정:
"2번 항목을 더 자세히 설명해줘."
"○○ 내용을 추가해줘."

원하는 부분 유지:
"마음에 드는 부분은 유지하고, 마지막 문단만 바꿔줘."
```
> 한 번에 하나씩 수정 요청하는 것이 효과적입니다.<br>3\~4번 이어서 다듬으면 처음보다 훨씬 좋은 결과물이 나옵니다.

## 자주 나오는 질문 (1부)
**Q1. AI 결과가 왜 매번 달라요?**
AI는 확률을 기반으로 답을 만들기 때문에, 같은 질문이라도 매번 조금씩 다른 답이 나옵니다. 이건 버그가 아니라 원래 그런 구조입니다. 일관된 결과를 원할 때는 Gem(나만의 비서)을 만들어두거나, "이전에 해준 스타일 유지해서 써줘"라고 추가 입력하면 됩니다.
**Q2. AI가 틀린 정보를 쓰는 경우가 있어요.**
AI는 없는 정보를 만들어내기도 합니다. 이건 모든 AI의 구조적 한계입니다.<br>대응법: 수치·날짜·고유명사는 반드시 직접 확인. 중요한 문서는 AI 초안 → 사람 검토 → 최종 확인 순서로.
**Q3. 무료로 써도 충분한가요?**
처음에는 무료로도 충분합니다. ChatGPT 무료, Gemini 무료, 뤼튼(완전 무료)으로 오늘 배운 것 모두 가능합니다. 지금 단계에서 유료 결제는 필요하지 않습니다.
**Q4. 스마트폰으로도 다 되나요?**
ChatGPT 앱이나 Gemini 앱으로 대부분 가능합니다. 긴 문서 작업이나 파일 업로드는 PC가 더 편합니다.
