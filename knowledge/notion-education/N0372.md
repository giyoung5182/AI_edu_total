# 실습 2. 골격부터 구축

정리일: 2026-10-08 · 교육 에셋 N0372

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
워크시트를 기획서 프롬프트로 바꿔 Claude Code에 전달하고, 골격부터 단계별로 에이전트 팀을 만듭니다.
## 진행 단계
1. **초기화** — 창②(Claude Code)에서 /clear 실행
2. **기획서 프롬프트 입력** — ［목표］([①]), ［입력 자료］([②]), ［결과물］([③]), ［팀 구성］([⑤]), ［작업 방식］(1단계 입력 화면과 팀 뼈대 → 2단계 담당 에이전트를 하나씩 합류 → 3단계 최종 결과물 화면)
3. **1단계 실행** — 골격이 완성되면 반드시 실행해 보고 동작 확인 후 2단계로
4. **에이전트 합류 확인** — 하나 합류시킬 때마다 채팅방에 그 담당의 말풍선이 올라오는지 확인
5. **막히면** — 로그부터 붙여넣기
6. **시간 관리** — 남은 시간 절반이 지나면 기능 추가를 멈추고 완주 확인으로 전환
## 막히는 지점
- 로그부터 붙여넣기: 창①의 오류 로그를 창②에 붙여넣고 "이 오류를 해결해 주세요"
- 대화가 꼬이면 /clear 후 현재 상태와 목표를 새로 설명
- 같은 오류가 세 번 반복되면 범위 축소
- 10분 이상 혼자 막혀 있지 않기, 손을 들어 강사 호출
