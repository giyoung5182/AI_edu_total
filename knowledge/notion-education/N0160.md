## Gem A \| 공공기관 포스터 프롬프트 비서
이미지를 만들어 주는 Gem이 아니라, **프롬프트를 설계해 주는** Gem입니다.
```plain text
[이름] 교육기관 포스터 프롬프트 비서

[지시문]

R: 너는 공공기관 홍보물 제작을 10년 이상 담당해 온
   시각 디자인 디렉터야.
   이미지 생성 AI의 작동 방식을 정확히 알고 있어서,
   추상적인 형용사 대신 구체적인 명사와 색상 코드로 프롬프트를 쓰고,
   부정어 대신 있어야 할 것을 서술하는 방식을 원칙으로 삼아.
```

## C-6. 문제 해결 FAQ
**Q. 이미지 안 한글이 계속 깨집니다.**`원리 둘` 구조적 한계입니다. 이미지에 문구를 넣지 말고 파워포인트에서 얹으세요. 1권 Part 3을 보세요.
**Q. "글자 넣지 마"라고 했는데 글자가 들어갑니다.**`원리 넷` 부정어는 오히려 그 개념을 불러옵니다. "상단 3분의 1은 단색으로 비워 둬"로 바꾸세요.
**Q. 결과가 매번 다릅니다.**`원리 하나` 정상입니다. 좋은 결과가 나오면 그 자리에서 저장하고, 이후에는 부분 수정으로 조정하세요.
**Q. 색이 너무 화려해서 공공 문서 같지 않습니다.**<br>색을 두세 가지로 명시 제한하고 "모든 면은 단색으로 채워 줘"를 추가하세요. 그라데이션과 그림자가 들어가면 민간 광고물처럼 보입니다.
**Q. 텍스트를 얹을 자리가 없습니다.**<br>6요소의 여섯 번째(규격과 여백)를 빠뜨린 경우입니다. 여백 문장을 프롬프트에 반드시 넣으세요.
**Q. 설계서를 쓰는 데 시간이 더 걸립니다.**<br>2권 4-9의 초안 생성 프롬프트를 쓰거나 부록 B Gem B를 만드세요. 사람이 검토할 것은 유의사항, 헤드메시지, \[확인 필요\] 세 가지뿐입니다.
**Q. AI가 만든 자료에 없던 숫자가 들어가 있습니다.**`원리 여덟` 블록 4 사실관계 규칙이 빠졌거나, 자료를 붙여넣지 않고 주제만 준 경우입니다. 2권 4-7을 확인하세요.
**Q. 결과물이 AI가 만든 티가 납니다.**<br>블록 4 말투 규칙을 넣으세요. 개조식 지정과 나쁜 예/좋은 예를 함께 제시하는 것이 가장 효과가 큽니다.
**Q. 만든 이미지를 인쇄 포스터에 써도 되나요.**<br>2권 5-3의 용도별 기준을 확인하세요. 인쇄물과 대외 배포물은 라이선스가 정리된 도구나 실사 촬영을 권합니다.
**Q. 기업 신청서 내용을 넣어도 되나요.**<br>2권 5-4를 보세요. 개인정보와 미공개 정보는 입력하지 마세요. 기업명은 "A기업", 금액은 "약 3억 원 규모"로 치환하세요.

## C-7. 최종 체크리스트
### 포스터를 완성했을 때
```plain text
□ 프롬프트에 6요소가 모두 들어갔다
□ 형용사 대신 구체적 명사와 색상으로 썼다
□ 색을 두세 가지로 제한했다
□ 부정어 대신 있어야 할 것을 서술했다
□ 상하단 단색 여백을 확보했다
□ 이미지 안에 깨진 글자가 없다
□ 확대해서 로고·상표·인증 마크 형태가 섞이지 않았는지 확인했다
□ 사업명 / 대상 / 기간 / 방법 / 문의처를 모두 얹었다
□ 글자 크기 위계가 세 단계 이하다
□ 파일을 다운로드했고 프롬프트를 저장했다
```
### 발표자료 설계서를 완성했을 때
```plain text
□ 네 블록이 모두 채워졌다
□ 유의사항이 3개 이상이다
□ 최종 목적이 청중의 행동으로 서술되었다
□ 모든 헤드메시지가 결론 문장이다
□ 헤드메시지만 읽어도 논리가 이어진다
□ 한 장에 한 주제만 있다
□ 디자인 규격에 색상 코드가 들어갔다
□ 산출 규칙 네 항목이 모두 있다
□ [확인 필요] 항목을 파악했다
□ 설계서를 파일로 저장했다
```
### 대외 배포 전에


## C-8. 원리 한 장 요약 — 잘라서 책상에 붙여 두세요
```plain text
하나   같은 프롬프트도 매번 다르다
       → 좋으면 즉시 저장, 재생성 말고 부분 수정

둘     AI는 글자를 무늬로 안다
       → 한글은 이미지에 넣지 말고 나중에 얹기

셋     막연하면 평균이 나온다
       → 형용사를 명사와 색상 코드로

넷     부정어는 그것을 불러온다
       → 뺄 것 말고 있어야 할 것을 말하기

다섯   내 문장은 한 번 번역된다
       → AI에게 프롬프트와 설계서를 대신 쓰게 할 수 있다

여섯   슬라이드는 구조가 먼저다
       → 설계서 4블록을 사람이 확정한 뒤 시각화만 맡기기

일곱   한 장에 한 메시지
       → 제목은 주제어가 아니라 헤드메시지로

여덟   AI는 우리 자료를 모른다
       → 수치는 사람이 넣고, 빈칸은 [확인 필요]로
```
