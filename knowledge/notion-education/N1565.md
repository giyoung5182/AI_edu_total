## 1. 바이브코딩(Vibe Coding)이란?
기존 개발 방식은 모든 코드를 사람이 직접 작성했어요. 하지만 바이브코딩은 AI와 함께 코드를 만들어가는 새로운 개발 패러다임이에요. 마치 오케스트라 지휘자가 음악의 흐름을 주도하듯, 개발자는 '무엇을 만들지'에 집중하고 AI가 '어떻게 만들지'를 도와줍니다.
💡 바이브코딩의 핵심 철학
- 의도(Intent) 중심: 세부 구현보다 '무엇을 만들 것인가'에 집중합니다
- 빠른 반복(Rapid Iteration): 작게 만들고, 빠르게 테스트하고, 즐시 개선합니다
- AI와의 협업: AI는 파트너이지 대체자가 아닙니다. 함께 더 나은 코드를 만들어갑니다

📚 비유로 이해하기
- 기존 개발 = 요리사가 직접 재료를 썸고 자르고 조리하는 것: 모든 단계를 직접 수행합니다
- 바이브코딩 = 셰프가 레시피와 맛의 방향을 제시하고 수셰프가 조리를 돕는 것: 의도를 명확히 하고 AI가 구현을 도와줍니다

> 요즘 제가 '바이브 코딩(vibe coding)'이라고 부르는 새로운 방식에 푹 빠져 있습니다. 코딩의 느낌(vibe)에 온전히 몸을 맡기고, AI의 폭발적인 성능을 믿으며, '코드' 그 자체가 존재한다는 사실조차 잊어버리는 단계죠.
이게 가능한 건 요즘 LLM(예를 들어 Cursor Composer에 Sonnet 조합) 성능이 말도 안 되게 좋아졌기 때문입니다. 저는 **SuperWhisper**를 써서 음성으로 명령을 내리기 때문에 키보드도 거의 안 건드려요. 직접 코드를 찾기 귀찮아서 "사이드바 여백 좀 반으로 줄여줘" 같은 진짜 사소한 것들까지 그냥 말로 시킵니다.
바뀐 코드를 일일이 확인(diff)하지도 않고 그냥 무조건 'Accept All'을 눌러버립니다. 에러가 나면? 아무 설명 없이 에러 메시지만 복사해서 던져주는데, 신기하게도 대충 다 고쳐져요. 코드가 제가 이해할 수 있는 범위를 금방 넘어서버려서, 제대로 파악하려면 한참을 들여다봐야 할 정도죠. 가끔 AI가 버그를 못 잡으면, 그냥 대충 피해 가거나 버그가 사라질 때까지 이것저것 막 시켜봅니다.
주말에 가볍게 해보는 프로젝트용으로는 정말 최고고, 하는 내내 즐겁습니다. 사실 웹 앱을 만들고는 있지만 이걸 진짜 '코딩'이라고 하긴 어렵죠. **그저 보고, 말하고, 실행하고, 복붙하는 게 전부인데... 어쨌든 이게 돌아가거든요.**

## 2. 게임 만들어보기
바이브코딩의 재미를 가장 빠르게 느낄 수 있는 방법은 게임을 만들어 보는 것입니다. AI에게 프롬프트 한 줄을 던지면, 실제로 플레이할 수 있는 웹 게임이 만들어집니다.
### 함께 만들어 봅시다
**🎮 뱀 게임 (Snake Game)**
```plain text
HTML, CSS, JavaScript로 동작하는 뱀 게임(Snake Game)을 만들어줘.

- 방향키로 뱀을 조종
- 먹이를 먹으면 뱀이 길어지고 점수 증가
- 벽이나 자기 몸에 부딪히면 게임 오버
- 상단에 현재 점수 표시
- 게임 오버 시 "다시 시작" 버튼
- 전체를 하나의 HTML 파일로 작성
- 디자인은 다크 모드, 네온 색상으로 깔끔하게
```

### 다른 게임도 도전해 보세요
시간 여유가 있거나 뱀 게임을 빨리 완성했다면, 아래 중 하나를 더 만들어 보세요.
**🧱 벽돌깨기**
```plain text
HTML, CSS, JavaScript로 벽돌깨기(Breakout) 게임을 만들어줘.
마우스로 패들을 좌우로 움직여 공을 튕겨 벽돌을 부수는 게임.
점수 표시, 목숨 3개, 게임 오버 시 다시 시작 버튼 포함.
전체를 하나의 HTML 파일로 작성해줘.
```
**🎯 두더지 잡기**
```plain text
HTML, CSS, JavaScript로 두더지 잡기(Whac-A-Mole) 게임을 만들어줘.
3x3 격자에서 두더지가 랜덤으로 나타나고, 클릭하면 점수 획득.
30초 타이머, 점수 표시, 종료 후 결과 화면 포함.
전체를 하나의 HTML 파일로 작성해줘.
```
**🃏 카드 매칭 (짝맞추기)**
```plain text
HTML, CSS, JavaScript로 카드 뒤집기 짝맞추기 게임을 만들어줘.
4x4 격자에 이모지 8쌍이 뒤집어져 있고, 두 장을 클릭해서 같으면 열림.
시도 횟수 표시, 전부 맞추면 축하 메시지와 다시 시작 버튼.
전체를 하나의 HTML 파일로 작성해줘.
```
> **포인트**: 코드를 한 글자도 이해할 필요 없습니다. 프롬프트만 잘 쓰면 AI가 전부 만들어줍니다. 이것이 바이브코딩의 핵심입니다.
### 게임을 개선해 보기
만든 게임이 마음에 안 드는 부분이 있다면, 바로 피드백을 줘 보세요.
```plain text
뱀의 속도를 좀 더 빠르게 해줘.
```
```plain text
배경에 격자 무늬를 넣어줘.
```
```plain text
최고 점수(하이스코어)를 기록하는 기능을 추가해줘.
```
이렇게 **"만들기 → 확인 → 피드백 → 개선"** 사이클을 도는 것이 바이브코딩의 전부입니다. 이 감각을 기억하고, 이제 대시보드 만들기로 넘어갑시다.

### 1️⃣우리가 사용할 재료는 무엇인가요?
이번 실습에서는 실제 방산 산업 데이터를 연상시키는
**방산 산업 대시보드용 실습 데이터셋**을 활용할 거예요.
이 데이터에는 다음과 같은 정보가 들어 있습니다.
- 발주기관
- 기관유형
- 지역
- 사업분야
- 프로젝트명
- 프로젝트단계
- 고객등급
- 예상계약금액
- 최근12개월매출
- 수주확률
- 예상마진율
- 위험도
이 데이터를 가지고
**"어떤 지역과 사업분야가 핵심 사업 기회인지"**,
"어떤 프로젝트가 수주 가능성이 높은지"를 한눈에 보여주는 대시보드를 만들어볼 겁니다.
---



### 2️⃣ 실습 : AI에게 일을 시키는 3단계 프로세스
이제 ChatGPT나 Gemini를 켜세요.
우리는 **HTML 하나로 동작하는 반응형 웹 대시보드**를 만들 겁니다.
### STEP 1. 역할 부여하고 데이터 주입하기
AI에게 내가 누구이고, 어떤 데이터를 가지고 있는지 명확히 알려주세요.
파일을 업로드하거나 데이터 일부를 복사해서 붙여넣으면 됩니다.
> 💬 프롬프트 예시
"너는 지금부터 **세계 최고의 프론트엔드 개발자이자 데이터 분석가**야.
내가 업로드한 '방산 산업 프로젝트 데이터'를 바탕으로
** HTML 파일** 형태의 대시보드 코드를 작성해줘.
디자인은 모던하고 깔끔한 다크 모드 스타일로 부탁해."
### STEP 2. 구체적인 시각화 요구하기
단순히 "그려줘"라고 하면 AI도 막막합니다.
데이터 특성에 맞게 구체적으로 요구하는 것이 중요합니다.
> 📌 우리가 구현할 핵심 차트 3가지
1. **지역별 프로젝트 수 (Bar Chart)**
→ 어느 지역에 사업 기회가 많이 몰려 있는가?
2. **사업분야별 예상계약금액 비중 (Doughnut Chart)**
→ 어떤 사업영역이 전체 파이프라인 금액에서 가장 큰 비중을 차지하는가?
3. **고객등급별 평균 수주확률 (Bar Chart)**
→ 전략 고객일수록 실제 수주 가능성이 높은가?
> 💬 추가 프롬프트 예시
"데이터를 분석해서 다음 3가지 차트를 Chart.js 라이브러리를 사용해 그려줘.
1. `지역` 컬럼을 활용한 지역별 프로젝트 수 (Bar Chart)
2. `사업분야`별 `예상계약금액(억원)`의 합계 비율 (Doughnut Chart)
3. `고객등급`에 따른 `수주확률(%)` 평균 (Bar Chart)
그리고 상단에는 다음 KPI 카드도 보여줘.
- 전체 프로젝트 수
- 총 예상계약금액
- 평균 수주확률
- 수주/수행 단계 프로젝트 수
필터 영역에는 `지역`, `사업분야`, `프로젝트단계` 드롭다운도 추가해줘."

## 4. 자유 실습: 만들고 싶은 웹사이트 만들기
대시보드까지 함께 만들어 봤으니, 이제 바이브코딩의 진짜 재미를 느껴볼 차례입니다. **만들고 싶은 것을 자유롭게** 만들어 보세요.
### 실습 방법
1. 아래 예시 중 마음에 드는 것을 고르거나, 직접 아이디어를 떠올립니다.
2. 프롬프트를 AI에 입력합니다.
3. 결과를 HTML 파일로 저장해서 실행합니다.
4. 마음에 안 드는 부분은 피드백을 줘서 계속 개선합니다.
### 예시 1 — 실시간 주식 모의투자 사이트
```plain text
HTML, CSS, JavaScript로 주식 모의투자 시뮬레이터를 만들어줘.

- 시작 시 가상 자금 1,000만 원 보유
- 5개 가상 종목 (AI반도체, 그린에너지, 바이오신약, 우주항공, 로봇공학)
- 각 종목의 가격이 3초마다 랜덤으로 등락 (현실적인 범위: -3%~+3%)
- 실시간 가격 차트 (최근 20개 데이터 포인트)
- 매수/매도 버튼, 보유 수량, 평균 매입가 표시
- 상단에 총 자산(현금 + 주식 평가액), 수익률 표시
- 전체를 하나의 HTML 파일로 작성
- 디자인은 증권사 HTS 느낌의 다크 모드
```
### 예시 2 — 개인 포트폴리오 웹사이트
```plain text
HTML, CSS, JavaScript로 개인 포트폴리오 웹사이트를 만들어줘.

- 상단: 이름, 직함, 한 줄 소개
- 섹션 1: About Me (자기소개)
- 섹션 2: Skills (기술/역량을 프로그레스 바로 시각화)
- 섹션 3: Experience (경력사항 타임라인)
- 섹션 4: Contact (연락처, 이메일 링크)
- 스크롤 시 부드러운 애니메이션 효과
- 반응형 디자인 (모바일에서도 보기 좋게)
- 전체를 하나의 HTML 파일로 작성
- 디자인은 모던하고 미니멀한 스타일
```
### 예시 3 — 팀 프로젝트 칸반 보드
```plain text
HTML, CSS, JavaScript로 칸반 보드(Kanban Board)를 만들어줘.

- 3개 열: "할 일" / "진행 중" / "완료"
- 카드를 드래그 앤 드롭으로 열 사이 이동 가능
- 새 카드 추가 버튼 (제목, 담당자, 마감일 입력)
- 카드 삭제 기능
- 카드에 우선순위 색상 표시 (높음: 빨강, 중간: 노랑, 낮음: 초록)
- 전체를 하나의 HTML 파일로 작성
- 디자인은 Notion 스타일로 깔끔하게
```
### 예시 4 — 오늘의 점심 룰렛
```plain text
HTML, CSS, JavaScript로 점심 메뉴 랜덤 룰렛을 만들어줘.

- 원형 룰렛에 메뉴 8개 (김치찌개, 돈까스, 파스타, 쌀국수,
  초밥, 햄버거, 비빔밥, 치킨)
- "돌리기" 버튼을 누르면 룰렛이 회전하다가 천천히 멈추며 메뉴 선정
- 선정된 메뉴를 크게 표시 + 축하 효과
- 메뉴를 추가/삭제할 수 있는 편집 기능
- 전체를 하나의 HTML 파일로 작성
- 디자인은 밝고 귀여운 스타일
```
### 예시 5 — 지출 관리 가계부
```plain text
HTML, CSS, JavaScript로 간단한 가계부 웹앱을 만들어줘.

- 수입/지출 입력 (날짜, 카테고리, 금액, 메모)
- 카테고리: 식비, 교통, 쇼핑, 문화, 의료, 기타
- 월별 수입/지출 요약 표시
- 카테고리별 지출 비율 도넛 차트
- 최근 거래 내역 리스트
- 데이터는 브라우저 localStorage에 저장 (새로고침해도 유지)
- 전체를 하나의 HTML 파일로 작성
- 디자인은 깔끔한 라이트 모드
```
### 예시 6 — 타이머 & 스톱워치
```plain text
HTML, CSS, JavaScript로 뽀모도로 타이머를 만들어줘.

- 집중 시간 25분 / 휴식 시간 5분 자동 전환
- 시작, 일시정지, 리셋 버튼
- 원형 프로그레스 바로 남은 시간 시각화
- 완료된 뽀모도로 횟수 카운트
- 타이머 종료 시 알림음
- 전체를 하나의 HTML 파일로 작성
- 디자인은 집중에 도움이 되는 차분한 색감
```
### 자유 실습 팁
