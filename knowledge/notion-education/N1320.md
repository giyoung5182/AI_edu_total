# 실습 2: AI에게 VBA 시키기

정리일: 2026-10-08 · 교육 에셋 N1320

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
조건 분기·가변 범위 작업(완료 건만 새 시트로 추출)을 AI에게 시키고, 코드 리뷰와 검증까지 합니다.
## 진행 단계
1. **문제1 프롬프트 작성** — 상황/데이터 구조/원하는 결과/제약/요청 5요소
- 입력할 내용:
```javascript
[상황] Excel VBA로 반복 작업을 자동화하려고 해. VBA는 잘 모르니 실행 방법까지 알려줘.
[데이터 구조] "민원현황" 시트에 A1부터 표가 있어.
   A열: 접수일, B열: 지역, C열: 민원유형, D열: 처리상태 (1행은 머리글, 데이터 약 60행)
[원하는 결과] 처리상태가 "완료"인 행만 "완료건"이라는 새 시트로 복사해줘.
[제약] 원본 데이터는 절대 수정하면 안 돼. 실행할 때마다 "완료건" 시트는 초기화 후 다시 만들어줘.
[요청] 전체 코드 + 붙여넣고 실행하는 방법 단계별로 + 각 부분에 한국어 주석.
```
1. **실행 전 코드 리뷰(30초)** — 시트 이름 일치 / Delete·Kill·SaveAs 대상 / 원본 시트 직접 수정 여부
2. **실행** — Alt+F11 → 삽입 → 모듈 → 코드 붙여넣기 → F5
- 정상 결과: `완료건` 시트, 머리글 1행, 처리상태 모두 `완료`, 결과 데이터 39행
3. **검증 3종 세트** — 건수 대조(39 = 39), 샘플(첫·마지막 행) 확인, 원본 무결성(60행 유지)
4. **문제2 핑퐁** — 조건을 '지역이 판교'로 변경 → 추출 건수 메시지창 → 입력창으로 지역 묻기(강남 입력 시 강남만 추출)
- 정상 결과: "판교" 추출 시트에 데이터 3행
5. **직접 풀어보는 예제** — InputBox로 민원유형 입력 → 해당 행만 새 시트로 추출 → 건수 MsgBox
## 막히는 지점
- 시트 이름 불일치는 VBA 오류 9의 가장 흔한 원인
- 개인정보 컬럼이 든 파일은 AI 업로드 금지, 열 구성과 가짜 예시만 설명
