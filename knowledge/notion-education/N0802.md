## 1️⃣ 노코드(No-Code) 데이터 분석이란 무엇일까요?
우리가 흔히 생각하는 데이터 분석은 검은 화면에 복잡한 코드를 치는 것이었죠. 하지만 생성형 AI의 등장으로 판도가 바뀌었습니다.

## 2️⃣ 데이터 분석의 프로세스
데이터 분석은 요리와 비슷합니다. 좋은 재료(데이터)를 다듬고(전처리), 맛을 보고(EDA), 요리하는(분석) 과정이 필요하죠. 전문가들이 따르는 **6단계 프로세스**를 알아볼까요?
### Step 1. 문제 정의 (Problem Definition)
- **"무엇을 해결하고 싶은가?"**를 명확히 합니다.
- 예시: "우리 VIP 고객은 왜 이탈할까?", "20대에게 어떤 상품을 팔아야 할까?"

### Step 2. 데이터 수집 (Data Collection)
- 문제를 해결하는 데 필요한 재료를 모으는 단계입니다.
- 사내 데이터(DB), 외부 데이터, 설문조사 결과 등이 포함됩니다.

### Step 3. 데이터 전처리 (Data Preprocessing) ⭐ **\[핵심\]**
- **"Garbage In, Garbage Out (쓰레기가 들어가면 쓰레기가 나온다)"**
- 날것의 데이터를 분석 가능한 상태로 깨끗하게 닦는 과정입니다. 전체 분석 시간의 80%를 차지할 정도로 중요합니다.
- **결측치 처리:** 비어있는 값(Null)을 채우거나 제거
- **이상치 제거:** 말도 안 되게 튀는 값(예: 나이가 200살) 삭제
- **데이터 형변환:** 날짜가 문자로 되어있다면 날짜 형식으로 변경

### Step 4. 탐색적 데이터 분석 (EDA)
- 데이터의 생김새를 파악하는 단계입니다.
- 평균, 기초 통계량 확인, 분포 시각화 등을 통해 데이터에 대한 감을 잡습니다.

### Step 5. 모델링 및 심층 분석 (Modeling & Analysis)
- 본격적으로 통계적 기법이나 머신러닝을 적용해 패턴을 찾거나 미래를 예측합니다.

### Step 6. 결과 해석 및 시각화 (Reporting)
- 분석 결과를 이해하기 쉽게 차트로 그리고, 비즈니스 인사이트로 변환하여 보고합니다.

### STEP 1-3. 데이터 분석 (값 구하기)

- **결과 예시**
- 서울특별시 성동구 : 평균 147,600만 원
- 서울특별시 종로구 : 평균 233,000만 원
- 서울특별시 동대문구 : 평균 125,000만 원
*(※ 예시는 일부 데이터 기준이며 실제 실행 시 전체 데이터로 계산됩니다.)*

### 1) **월별 거래금액의 합계 / 평균 계산**

- 해당 월 전체 거래금액 합계

→ **지역별 선호 면적대가 다른지**를 표로 확인 가능.
### 3) **거래금액 기준 상위 10개 아파트 목록**
- 거래금액(만원) 기준 내림차순 정렬
- 고가 거래 단지 TOP10 확인
- 서울의 고가 아파트 분포 파악 가능.
### 4) **주택유형(아파트/오피스텔 등) 비율**
- 이 데이터는 대부분 ‘아파트’이지만
→ 만약 다양한 유형이 있다면 **거래유형 구성비 분석** 가능.

### STEP 2. 데이터 시각화
- **목표:**
앞에서 분석한 결과(또는 새롭게 분석한 것)를 시각화하여 그래프로 나타내봅시다.
---
**예시 시각화 작업**
```plain text
이 데이터에서 월별 거래금액 합계와 평균을 막대+선 혼합 plotly 그래프로 시각화해줘.
```
- 월별 거래금액 **합계 = 막대그래프(bar)**
- 월별 **평균 거래금액 = 선그래프(line)**
- 단일 차트에 두 데이터 결합
→ 월별 시장 규모(총액)와 가격 수준(평균)의 **관계 분석 가능**
