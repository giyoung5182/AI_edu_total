# 실습 1 · 여비정산 계산기 만들기

정리일: 2026-10-08 · 교육 에셋 N1512

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실제 회사 여비 기준(교통비·숙박비·식비·일비)을 넣어 쓸 수 있는 여비정산 계산기를 Claude 아티팩트로 만든다.
## 진행 단계
1. **새 채팅 열기** — claude.ai에서 왼쪽 위 「새 채팅」 클릭 (1교시 게임과 섞이지 않게)
2. **프롬프트 붙여넣기** — 아래 프롬프트를 통째로 붙여넣는다
- 입력할 내용:
```plain text
아래 기준으로 여비정산 계산기를 만들어줘.

교통비 (개인차량 이용 시)
= (왕복거리(km) x 유가 ÷ 연비 + 통행료) x 1.1   (십원 단위 반올림)
연비: 하이브리드 15.04, 경유 13.83, 휘발유 12.77, 전기 168.9, LPG 9.45

숙박비: 일반 50,000원/1박, 서울·경기·제주 70,000원/1박
식비: 일반 15,000원/1회, 서울·경기·제주 18,000원/1회
일비: 당일 10,000원, 1박 20,000원

입력항목: 왕복거리, 차종, 통행료, 숙박일수, 식사횟수, 지역(일반/서울경기제주)
출력: 항목별 금액과 합계를 표로

간단한 계산 도구니까 복잡하게 만들지 말고, 대신 입력 양식을 깔끔하게 구성해줘.
```
1. **전송** — 전송 버튼 클릭
2. **숫자 입력** — 오른쪽에 열린 화면 입력창에 숫자를 넣어 본다
3. **합계 확인** — 합계가 표로 나오는지 확인한다
- 정상 결과: 항목별 금액과 합계가 표로 출력됨
