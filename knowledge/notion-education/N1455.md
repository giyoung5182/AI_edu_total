# 실습 · 민원 대장 → 회신 공문 (10분)

정리일: 2026-10-08 · 교육 에셋 N1455

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
민원 접수 대장을 정제 기준에 따라 정리해 발주처 제출용 회신 공문으로 바꿉니다.
## 진행 단계
1. **집계부터 시켜 보기** — "이 파일에서 8월 민원 처리 건수를 알려줘"라고 물으면 중복 접수·민원이 아닌 요청·완료일시 누락·완료일 오류·유형 표기 갈라짐 때문에 실제와 다른 숫자가 나옵니다.
2. **정제 기준을 넣은 프롬프트 실행** — \[R\]\[T\]\[C\]\[K\] 구조로 역할·맥락·과업(동일 위치·증상 반복 건 통합 표시, 민원 아닌 요청 제외·명시, 유형 표기 통일, 유형별 접수·완료·처리중 집계, 데이터 오류 행 목록화, 회신 공문 작성)·제약(개조식 \~함/\~임, 수신·제목·본문·붙임·끝., 제공하지 않은 수치 생성 금지, 오류는 \[확인 필요\]로 표시, 사과·변명 금지)을 지정하고 09번 공문 샘플 본문을 붙여넣습니다.
3. **체크** — 유효 민원 수가 단순 집계와 다르게 나왔는가 / 통합·제외 건이 명시되었는가 / 데이터 오류 건이 별도 목록으로 나왔는가 / 공문 형식을 지켰는가 / 재발 건이 별도로 언급되었는가.
4. **수신처 바꾸기** — 입력할 내용:
```javascript
같은 내용을 입주사 앞 안내문으로 다시 작성하세요.
수신은 입주 3개사이고, 존대 서술형(~습니다)으로 쓰세요.
설비 전문 용어는 일반인이 이해할 수 있는 말로 풀어 쓰세요.
불편에 대한 양해를 구하는 문장을 앞부분에 넣으세요.
```
## 막히는 지점
- 집계 숫자가 틀림: 정제 기준 미제시 → 중복·제외 기준을 먼저 지시
- 단위를 섞어서 합산: 단위 통일 지시 누락 → "억은 백만원으로 환산 후 합산"을 명시
- 긴 파일 뒷부분을 놓침: 컨텍스트 한계 → 시트·기간 단위로 나눠 올리기
- 원인을 단정해서 씀: "원인 추정은 \~로 추정되며 확인 필요함 형태로" 지시
