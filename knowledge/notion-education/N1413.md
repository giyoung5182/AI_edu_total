## 이 실습으로 하는 것
만들었다는 말만 믿지 않고 직접 열어 확인한다.
## 진행 단계
1. **열기** — 파일 탐색기(Mac: Finder) → 작업 폴더 → index.html 더블클릭
2. **확인** — 화면이 뜨는가 / prd.md 내용이 들어 있는가 / 글자가 충분히 큰가 / 버튼이 눌리는가 / 휴대폰으로 봐도 괜찮을 것 같은가
- 휴대폰 크기 확인: 브라우저 창을 가로로 좁게 줄임
- 정상 결과: 브라우저에 화면이 뜨면 OK
## 막히는 지점
- 브라우저가 안 열림 → 오른쪽 클릭 → 연결 프로그램 → 크롬/엣지
- 화면이 하얗게 빔 → STEP 4 오류 수정
- 글자 깨짐 → "한글이 깨져. 고쳐줘"
- 내용이 다름 → prd.md를 제대로 안 읽은 것, 다시 요청
- 파이썬 설치 오류가 뜰 경우: python.org에서 Python install manager(.msix) 설치 후 검은 창의 y/N 질문에 Y + Enter(교안 참고)
