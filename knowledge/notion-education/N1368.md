# 활동 2 — 더미 테스트 데이터 만들기

정리일: 2026-10-08 · 교육 에셋 N1368

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실제 데이터 대신 테스트용 가짜 데이터를 만들어 예외 상황까지 미리 검증합니다.
## 진행 단계
1. **테스트 데이터 요청** — 활동 1과 같은 대화창에서 입력
- 입력할 내용:
```javascript
앞에서 만든 데이터 사전에 맞는
현실적인 테스트 데이터 20행을 만들어줘.

조건:
- 광고 매체 실적 데이터로, 실제 업무에서 나올 법한 내용
- 정상 케이스 70%, 이상·예외 케이스 30% 포함
- 이상 케이스에 반드시 포함할 것
  · 컬럼명이 기준표와 다른 파일 1개
  · 날짜 형식이 다른 행
  · 단위가 문자로 표기된 값 (1.2M 등)
  · 결측값
  · 동일 매체·동일 일자 중복 행
  · 전주 대비 비정상적으로 큰 값

표 형식으로 출력하고,
마지막에 "이 데이터셋에 포함된 이상 케이스 목록"을 정리해줘.
```
2. **이상 케이스 목록 확인**
- 정상 결과: 표 형식 테스트 데이터 20행 + 마지막에 이상 케이스 목록
## 막히는 지점
- 정상 데이터만으로 테스트하면 실전에서 반드시 터집니다. 이상 케이스를 20\~30% 넣습니다.
