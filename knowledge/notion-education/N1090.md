# Step A·B · 위임표에서 주제 고르고 프로세스 쪼개기

정리일: 2026-10-08 · 교육 에셋 N1090

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
1일차 위임표에서 자동화할 업무 1건을 고르고, 단계로 쪼개 단계마다 누가·어떤 자료로·무엇을 만드는지 표로 정리합니다.
## 진행 단계
1. **주제 고르기 (Step A)** — `06_워크시트_1일차.xlsx` › `Part1` 시트 P1-6 위임표에서 단계(As-Is)·Pain(★)·위임 구분(To-Be)·핵심 변화 1줄을 봅니다. 기준: ★ 단계가 있고 위임 구분이 AI 초안 또는 규칙·도구 처리 / 입력 자료가 정해져 있음 / 매주·매월 반복됨.
- 위임표가 없거나 맞는 업무가 없으면 P1-5 판단표의 내 업무(13\~15번) 중 1건 또는 교안의 사례 ①\~④ 중 1개.
- 메모장에 업무 이름과 출처 1줄 적기.
2. **프로세스 쪼개기 (Step B)** — 메모장에 아래 표 틀을 붙여넣고 아는 칸부터 채웁니다. 빈칸은 Step D 인터뷰에서 마저 채웁니다.
- 입력할 내용:
```javascript
[프로세스 쪼개기 표]
번호 | 단계(동사 하나) | 하는 일 | 누가(사람 / AI / 앱스크립트) | 필요한 자료 | 결과물 | 판단이 필요한가(예/아니오)
1 |  |  |  |  |  |
(…6행까지)
작업 순서(먼저 만들 단계):
```
- 요령: 한 단계에 동사 하나, 누가 칸은 하나만, 필요한 자료는 파일·시트·열 이름까지, 앞 단계 결과물 이름 = 뒤 단계 자료 이름, 판단이 필요한 단계(승인·예외·대외 발송·원인 확정)는 사람으로 남김.
## 막히는 지점
- 위임표가 없거나 맞는 업무가 없을 때: P1-5 판단표 또는 사례 ①\~④ 사용.
