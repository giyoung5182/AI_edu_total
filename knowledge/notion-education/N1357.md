# 데모 3: 견적서 초안 자동화

정리일: 2026-10-08 · 교육 에셋 N1357

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
CoT 프롬프트로 견적서 초안을 엑셀 붙여넣기용 표로 만듭니다.
## 진행 단계
1. **항목 목록화** — 빠진 항목은 '\[추가 확인 필요\]'로 표시합니다.
2. **대분류 정렬** — 목공·도장·전기·조명·설비·운반·기타 등.
3. **견적서 표 작성** — 단가 제공 항목은 그대로, 없는 항목은 '\[단가 확인 필요\]', 대분류마다 소계, 마지막에 총계(공급가액·부가세·합계).
4. **별도 정리** — 단가 확인 필요 항목과 누락 가능성이 있는 공종.
## 막히는 지점
- 3단계 표 작성 전 반드시 1·2단계 완료.
