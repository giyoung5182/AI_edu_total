## 4-1. 데이터 유형 이해 및 선택
이 미니 프로젝트에서 각 조는 네 가지 데이터 유형 중 하나를 선택하여 실습을 진행합니다. 선택한 유형에 따라 추출 항목, 차트 형태, 보고서 구성이 모두 달라지므로, 각 유형의 특성을 먼저 이해한 후 조에 맞는 유형을 선택합니다.
**① 송무팀 사건 처리 통계** — 사건번호, 유형(민사·형사·행정), 접수일, 처리 기간, 결과(승소·패소·합의)를 포함하는 데이터입니다. 유형별 처리 기간 분포나 승소율 같은 인사이트를 도출하기에 적합하며, 막대·누적 막대 그래프가 주로 사용됩니다.
**② 자문 의뢰 분야별 패턴** — 의뢰 분야(노동·부동산·세무 등), 월별 의뢰 건수, 평균 처리 시간을 포함하는 데이터입니다. 어떤 분야의 수요가 증가하는지, 처리 시간이 긴 분야는 어디인지 파악하기에 적합합니다. 꺾은선·비교 막대 그래프가 주로 사용됩니다.
**③ 팀 업무 시간 분석** — 담당자별, 업무 유형별 소요 시간을 기록한 데이터입니다. 팀 전체 업무 시간 분포와 병목 업무를 찾아내어 업무 효율화 방안을 도출하기에 적합합니다.
**④ 고객 만족도 데이터** — 응답자, 항목별 점수(1\~5점), 자유 의견 코멘트를 포함하는 데이터입니다. 텍스트 코멘트를 분류하고 요약하는 실습이 포함되어 비정형 텍스트 처리 능력을 가장 폭넓게 활용할 수 있습니다.

## 4-2. 데이터 → 인사이트 → 한 장 보고서 풀 워크플로우
이 미니 프로젝트의 핵심은 모듈 1\~3에서 각각 배웠던 기술들을 **하나의 연속된 흐름으로 연결**하는 것입니다. 각 단계의 결과물이 다음 단계의 입력값으로 자연스럽게 이어지도록 아래 4단계 흐름을 머릿속에 그려두고 실습에 임합니다.
```plain text
[1단계: 데이터 수집·정리]
  비정형 텍스트 → 표 변환 (모듈 2 기술 적용)
          ↓
[2단계: 분석·인사이트 도출]
  Copilot으로 핵심 수치·패턴·이상치 추출
          ↓
[3단계: 시각화]
  차트 유형 선택 → Excel 차트 생성 (모듈 3 기술 적용)
          ↓
[4단계: 한 장 보고서 완성]
  Executive Summary + 차트 + 핵심 수치
  → PPT 1슬라이드 완성
```

### 소단계 A — 데이터 전처리 및 표 변환 (8분)
1. Copilot 채팅 창을 열고 아래 프롬프트를 작성합니다. `[항목1], [항목2]` 자리에는 실습 1에서 조원들과 합의한 핵심 추출 항목을 직접 입력합니다.
```plain text
아래 텍스트에서 [항목1], [항목2], [항목3], [항목4]를 추출하여 표로 정리해줘.
처리 규칙:
- 누락값은 "미확인"으로 표시해줘.
- 중복 항목이 있으면 별도 행으로 표시하고 "(중복)" 표시를 추가해줘.
- 날짜는 YYYY-MM-DD 형식으로 통일해줘.
- 숫자 단위는 통일해줘 (예: 모두 "건" 또는 모두 "시간"으로).

[실습 1에서 준비한 샘플 데이터 붙여넣기]
```

## 나만의 샘플 데이터 만드는 방법
위 샘플이 본인 업무와 거리감이 느껴진다면 아래 두 가지 방법으로 직접 만들 수 있습니다. 단, 실제 사건번호·고객명·수익 수치 등 기밀 정보는 절대 입력하지 않고 반드시 가상의 내용으로 대체합니다.
**방법 1 — 실제 업무 데이터를 가상 데이터로 치환하기**
실제 업무 데이터의 구조(항목 구성, 형식)는 그대로 유지하되, 아래와 같이 실제 정보만 치환합니다.
```plain text
실제 이름·고객명 → 프로님, 김철수, A사, B법인 등 가상 이름
실제 날짜       → 임의 날짜 (표기 방식을 의도적으로 혼재시킴)
                  예: 1월5일 / 2025.1.8 / 1/15 / 2025-02-03
실제 수치       → 임의 숫자 (단위 표기도 일부 다르게)
                  예: 45일 / 78d / 30일간 / 약 2달
처리 상태       → 일부 항목을 의도적으로 비워두거나 "미정" 처리
```
**방법 2 — Copilot에게 샘플 생성 요청하기**
아래 프롬프트에서 `[업무 유형]` 자리에 본인의 업무(예: 인사 채용 이력 관리, 프로젝트별 비용 집계, 고객 민원 처리 이력)를 입력합니다.
```plain text
나는 [업무 유형]을 담당하고 있어.
실무에서 자주 발생하는 비정형 메모 형태의 샘플 데이터를 만들어줘.

조건:
- 8~10개 항목
- 날짜 표기 방식이 4가지 이상 혼재할 것
  (예: 1월5일 / 2025.1.8 / 1/15 / 2025-02-03)
- 구분자가 통일되지 않을 것 (쉼표, 대시, 슬래시, 공백 혼용)
- 특정 항목이 2~3개 행에서 누락되어 있을 것
- 한 항목에서 눈에 띄는 이상치(급증 또는 급감)가 포함될 것
- 모든 이름·수치·내용은 가상으로 작성해줘.
```

## 실습 후 정리 사항
**결과물 저장**: 완성된 한 장 보고서 PPT, 정형화된 Excel 파일, 실습 중 사용한 프롬프트 목록을 하나의 폴더에 저장합니다. 폴더명은 `트랙2_미니프로젝트_[조이름]_[날짜]`로 정리합니다.
**프롬프트 라이브러리 최종 업데이트**: 이번 실습에서 가장 효과적이었던 프롬프트와 수정이 많았던 프롬프트를 모두 기록합니다. 특히 재프롬프트로 오류를 수정한 경우 "문제 상황 → 재프롬프트 → 개선 결과" 형태로 메모해 두면 실무에서 재사용하기 좋습니다.
**업무 적용 30일 계획 수립**: 토론 질문 3에서 말했던 기술을 구체적인 30일 실행 계획으로 발전시킵니다. 예를 들어 "매주 금요일 팀 주간 회의록을 Copilot으로 정형화 표로 만들어 공유하겠다"처럼 주기와 방법이 포함된 계획을 세우고 캘린더에 등록합니다.
**팀 공유 문서 작성**: 트랙 2 전체(모듈 1\~4)에서 배운 핵심 프롬프트 패턴과 실습에서 발견한 팁을 팀 공유 문서(사내 위키, Notion, Google Docs 등)에 정리하여 팀원들과 함께 활용할 수 있도록 합니다.

## 트랙 2 전체 요약
트랙 2의 네 가지 모듈을 통해 다음과 같은 역량을 키웠습니다.
**모듈 1**에서는 Copilot이 처리할 수 있는 데이터 자동화의 범위와 한계를 이해하고, 파일 없이 텍스트만으로도 데이터를 정리하는 기본 워크플로우를 익혔습니다. **모듈 2**에서는 비정형 텍스트에서 정형 데이터를 추출하는 명세화 프롬프트와 품질 체크리스트 자동 생성 방법을 배웠습니다. **모듈 3**에서는 데이터를 차트로 시각화하고 VBA 자동화를 적용하며 임원 보고용 Executive Summary를 작성하는 방법을 익혔습니다. **모듈 4**인 이번 미니 프로젝트에서는 이 모든 기술을 하나의 연속된 워크플로우로 통합하여, 비정형 데이터에서 한 장 보고서까지의 전 과정을 실전처럼 완성했습니다.
이제 Copilot을 단순한 검색 도구나 글쓰기 보조 도구가 아니라, **데이터 처리와 보고서 작성의 실질적인 업무 파트너**로 활용할 수 있는 역량을 갖추게 되었습니다.
