# [실습] AI 결과물 사실검증 프롬프트

정리일: 2026-10-08 · 교육 에셋 N1125

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AI가 작성한 보고서/분석 결과를 프롬프트로 사실검증합니다. 집행률 수치, 예산·단가 데이터, 현금흐름 판단이 포함된 문서는 반드시 사실검증·편향성 검증을 모두 수행합니다.
## 진행 단계
1. **사실검증 프롬프트 입력**
```markdown
답변에서 사실 주장만 추려서 검토해 주세요.

- 사실로 단정된 문장은 무엇인지
- 근거가 텍스트 내부에 충분한지
- 출처 링크로 확인 가능한지
- 과도하게 일반화되거나 단정적인 표현은 없는지
- 모호하거나 추가 근거가 필요한 부분은 무엇인지

검증 결과를 [문제 없음 / 주의 필요 / 근거 부족]으로 분류해 주세요.
```
