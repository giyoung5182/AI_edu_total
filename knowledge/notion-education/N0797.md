본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

**세션 목표:** AI 솔루션에 넣을 입력 데이터와 템플릿을 설계하고, 실제 테스트 데이터를 준비합니다.
### 📖 개념: AI 솔루션의 품질은 입력 데이터에 달려있다

**"쓰레기 인풋 → 쓰레기 아웃풋 (Garbage In, Garbage Out)"** — AI가 좋은 결과를 내려면 입력 데이터가 구조적이고 명확해야 합니다.

**Padlet에 올리기** (`세션5 · 입력 설계`) — "내 솔루션이 다룰 데이터가 지금 어디에 있나(엑셀/공문서/종이/시스템)"와 "그 데이터가 얼마나 구조화되어 있나"를 한 줄로 올려주세요. 데이터가 흩어져 있을수록 활동 1의 템플릿 설계가 더 중요해집니다.


**활동 1 → 2는 한 흐름으로 이어집니다.** 활동 1에서 입력 템플릿을 설계하면, 그 템플릿을 그대로 활동 2의 재료로 넘겨 테스트 데이터를 만듭니다. 같은 대화창에서 연속으로 진행하세요.

---
### 🔥 활동 1 — 입력 템플릿 설계
```javascript
내가 만들 AI 솔루션은:
- 직무: [예: 구매팀]
- 목적: [예: 협력업체 견적 자동 비교]
- 처리할 데이터: [예: 협력업체 10곳의 견적서]
```
### 🔥 활동 2 — 더미 테스트 데이터 생성
```javascript
앞에서 설계한 [내 솔루션명] 입력 템플릿에 들어갈
현실적인 테스트 데이터 15~20행을 만들어줘.

조건:
- 실제 [직무] 업무에서 발생할 법한 내용으로
- 정상 케이스 70%, 이상/예외 케이스 30% 포함
- 이상 케이스 예시: 값 누락, 기준치 초과, 비정형 텍스트 포함

표 형식으로 출력하고, 마지막에 "이 데이터셋에 포함된 이상 케이스 목록"을 정리해줘.
```
---
### 🔥 활동 3 — 입력→처리→출력 흐름 시나리오 작성
[원본 이미지 제외]
```javascript
내 AI 솔루션 흐름 시나리오를 구성해서 제안해줘. 아래는 템플릿이야.

INPUT (입력)
├── 입력 방식: □ 엑셀 업로드  □ 텍스트 붙여넣기  □ 직접 입력
├── 핵심 입력 항목 3가지: ① ② ③

PROCESS (처리) — AI가 할 일
├── 처리 작업 1: [예: 지연 항목 자동 탐지]
├── 처리 작업 2: [예: 원인 유형 분류 (납기/품질/인력)]
└── 처리 작업 3: [예: 위험도 순위 정렬]

OUTPUT (출력)
├── 출력물 1: [예: 이슈 요약 보고서]
├── 출력물 2: [예: 액션 아이템 목록]
└── 형식: □ 텍스트 □ 표 □ 보고서(Word/PDF)
```

**Padlet에 올리기** (`세션5 · 입력 설계`) — 완성한 "입력 → 처리 → 출력" 흐름 시나리오를 올려주세요. 이 한 장이 세션 6에서 만들 에이전트의 설계도이고, **여기서 정한 입력이 발표의 ② 데모 입력**이 됩니다. 다른 사람의 흐름과 비교하면 내가 빠뜨린 처리 단계가 보입니다.

---
### 📌 세션 5 핵심 정리
① AI의 품질은 입력 데이터의 품질로 결정된다 — 구조화가 핵심.
② 더미 데이터에 이상 케이스(예외)를 20\~30% 포함해야 실전에서 오류가 없다.
③ "입력 → 처리 → 출력" 흐름을 명확히 정의해야 다음 단계로 갈 수 있다.
