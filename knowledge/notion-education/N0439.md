# 실습 4 — 누락 항목 보완 재프롬프트 + 내 업무 함수 요청하기

정리일: 2026-10-08 · 교육 에셋 N0439

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
체크리스트에서 발견된 문제를 재프롬프트로 보완하고, 본인 업무에 필요한 Excel 함수를 Copilot에게 요청한다.
## 진행 단계
1. **(파트 A) 누락 항목 보완** — 문제 항목을 재프롬프트 예시를 참고해 수정 요청
- 입력할 내용:
```javascript
이전에 만든 표에서 문서 3번의 "쟁점" 항목이 "미확인"으로
되어 있는데, 원문을 다시 보니 "하도급법 위반 여부 검토"라는
내용이 있었어. 해당 행을 수정해줘.
```
2. **(파트 A) 날짜 형식·열 추가** — 날짜 형식 수정과 "처리 상태" 열 추가도 같은 방식으로 요청(교안에 예시 프롬프트 있음, 이하 교안 참고)
- 정상 결과: 수정이 올바르게 반영되었는지 확인 후 최종 표를 Excel에 저장
3. **(파트 B) 내 업무 함수 요청** — `[원하는 동작]` 자리에 본인 업무에 필요한 함수 작업을 입력
- 입력할 내용:
```javascript
Excel에서 [원하는 동작]을 하는 함수를 알려줘.
- 데이터 범위: [내 데이터의 열 구조 설명]
- 조건: [원하는 조건]
- 출력: [원하는 결과 형태]
수식과 함께 각 인수의 의미도 설명해줘.
```
- 정상 결과: 수식과 각 인수 설명이 즉시 제공됨
