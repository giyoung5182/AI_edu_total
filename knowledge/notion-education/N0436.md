본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

## 이 실습으로 하는 것
설계서의 수치·표시를 보존표에 옮기고, Gamma로 발표자료를 만든 뒤 보존표와 대조합니다. (선택 심화 실습)
## 진행 단계
1. **보존표 먼저 작성** — Part4 시트 \[G\] 예측 칸 먼저 → \[B\] 근거표의 수치(C열)·n·분모·기간·단위(E열)·출처(F열)·상태(G열)를 \[G\]로 복사
2. **슬라이드용 텍스트 준비** — 채팅 P4-보고서에 프롬프트를 붙여넣고 Enter → 결과 답변의 복사 아이콘 → 메모장에 임시 보관
3. **Gamma 접속·로그인** — 새 탭(Ctrl+T) → gamma.app → 로그인 버튼 → Continue with Google 계열 버튼 → 본인 Google 계정 \[확인 필요 — 버튼 문구·화면 배치\]
- 정상 결과: 로그인 후 작업 목록(대시보드) 화면 \[확인 필요 — 화면 배치\]
4. **발표자료 생성·대조** — (교안 참고) 생성된 슬라이드를 보존표와 대조
