# 1차 데모 테스트 & 오류 수정

정리일: 2026-10-08 · 교육 에셋 N1299

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 시스템에 데이터를 넣어 결과를 검증하고, 문제를 AI Developer에게 자연어로 수정 요청합니다.
## 진행 단계
1. **URL 열기 → 데이터 입력** — 예시 데이터(또는 본인 데이터) 업로드/입력
2. **작동 확인** — 요약/분류/액션추천 3가지 기능과 보고서 형태 확인
3. **체크리스트 점검**
- 요약 수치가 원본 데이터와 일치하는가
- 분류 기준이 일관되게 적용되었는가
- 액션추천이 실무에서 실행 가능한 수준인가
- 단순 규칙 3개(TOP3/영향도/이상치)가 정확히 작동하는가
- 보고서 포맷이 정한 템플릿과 일치하는가
4. **수정 요청**
- 입력할 내용:
```javascript
방금 만든 시스템에서 다음 문제를 수정해줘:

1. [발견된 문제 1] → [원하는 수정]
2. [발견된 문제 2] → [원하는 수정]

수정된 시스템 URL을 다시 줘.
```
## 막히는 지점
- "전부 다시 해줘" 대신 문제를 구체적으로 짚어야 정확히 수정됨
