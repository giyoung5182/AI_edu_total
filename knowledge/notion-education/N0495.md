# AGENT 03 · 취업 준비 사용 예시

정리일: 2026-10-08 · 교육 에셋 N0495

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
이력과 목표를 기억하는 개인용 에이전트로 공고 비교·자소서 소재·면접 답변·준비 계획을 받아 봅니다. (강의 마지막 시연분)
## 진행 단계
1. **대괄호 교체** — `[내 정보]`·`[목표]`의 `[대괄호]` 부분을 본인 정보로 바꿉니다.
2. **공고 탐색**
```javascript
이번 주 올라온 공고 중에 나한테 맞는 것 찾아줘
```
1. **자소서 문단**
```javascript
자소서에 청년인턴 경험을 어떻게 쓸지 문단 하나로 잡아줘
```
1. **면접 약점 답변**
```javascript
경력이 짧다는 약점, 면접에서 어떻게 답하면 좋을까
```
1. **준비 계획**
```javascript
지금부터 목표 시점까지 뭘 준비해야 할지 월 단위로 짜줘
```
## 막히는 지점
- 채용 정보는 AI가 특히 잘 지어내는 영역이므로 후보를 좁히는 도구로만 사용하고 공식 채용 사이트 원문으로 확인.
- 등록 금지: 주민등록번호, 주소, 연락처, 계좌번호, 가족·건강 정보. 업무 중 알게 된 내용은 개인 프로젝트에도 등록 금지.
