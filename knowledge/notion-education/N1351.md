# 사전 준비 · 설치 체크리스트 (Claude Code 환경 세팅)

정리일: 2026-10-08 · 교육 에셋 N1351

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
워크숍 전에 노트북에 VSCode, Git Bash, Claude Code를 설치하고 로그인해 첫 한국어 명령까지 확인합니다.
## 진행 단계
1. **환경 체크** — 윈도우 10/11, 관리자 권한, 와이파이, 디스크 5GB 이상을 표에 체크합니다.
2. **1단계 VSCode 설치** — code.visualstudio.com에서 Download for Windows → 설치 마법사 기본값(PATH에 추가 체크 확인) → 실행.
- 정상 결과: VSCode가 켜짐
3. **2단계 Git Bash 설치** — git-scm.com/download/win에서 다운로드 → 기본값으로 설치 → VSCode 재시작. 터미널 → 새 터미널에서 오른쪽 위 드롭다운에 Git Bash가 있는지 확인.
- 입력할 내용:
```javascript
git --version
```
- 정상 결과: git version 2.45.0.windows.1 처럼 버전 번호가 나옴
1. **3단계 Claude Code 설치** — Git Bash 터미널에서 npm으로 설치하고 버전을 확인합니다.
- 입력할 내용:
```javascript
npm install -g @anthropic-ai/claude-code
claude --version
```
- 정상 결과: x.x.x (Claude Code) 처럼 버전 번호가 나옴
1. **4단계 교육용 계정 로그인** — 교육용 워크스페이스에 입장해 계정을 활성화한 뒤, 터미널에서 실행합니다. (당일 강사와 함께 해도 됨)
- 입력할 내용:
```javascript
claude
```
- 정상 결과: 브라우저가 열려 로그인 → 인증 완료 표시 → 터미널 하단에 \> 입력 프롬프트가 나타남
1. **5단계 첫 명령** — 한국어 명령을 입력합니다.
- 입력할 내용:
```javascript
잘 작동해?
```
- 정상 결과: "네, 잘 작동합니다!" 처럼 한국어 응답이 돌아오면 세팅 완료
## 막히는 지점
- npm: command not found → Node.js가 없음. LTS 버전으로 설치
- claude가 한국어로 응답하지 않음 → 첫 명령에 "한국어로 답해줘" 한 줄 추가
- 경로 인식 문제가 생기면 교안에 안내된 참고 글 확인
