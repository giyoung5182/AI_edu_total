> 무드모드 "한국인 전용 AI 스킬 125개" 게시물에서 오셨죠? KTX 시간표, 아파트 실거래가, 판례, 종목 공시, 최저가까지 클로드가 바로 찾아 답하게 해주는 스킬 묶음(k-skill) 설치 방법과 분야별 질문 예시예요.
## k-skill이 뭔가요?
NomaDamas 팀이 깃허브에 무료로 공개한 한국 생활용 AI 스킬 125개 묶음이에요. 교통, 부동산, 법률, 투자, 쇼핑, 날씨, 생활 정보까지 20개 분야로 나뉘어 있어요. 클로드에 붙여 두면 "이번 주말 부산 가는 KTX 있어?"처럼 평소 말투로 물어도 해당 데이터를 조회해서 답해줘요.
- 라이선스: MIT (누구나 무료로 쓰고 고칠 수 있는 공개 라이선스)
- 대부분의 공공데이터 스킬은 운영자 서버(프록시)를 거쳐서, 내가 따로 키를 발급받지 않아도 돼요.

## 제일 쉬운 방법: 깃허브 주소만 붙여넣기
플러그인 설치나 설정 화면에 들어갈 필요 없어요. 깃허브 주소를 붙여넣고 하고 싶은 걸 말하면 돼요.
- **클로드:** 코워크(Cowork)를 열고 아래 주소를 붙여넣은 뒤 하고 싶은 걸 말해요.
- **ChatGPT:** 워크 화면을 열고 똑같이 주소를 붙여넣고 말해요.
```plain text
https://github.com/NomaDamas/k-skill 이거 보고 이번 주말 부산 가는 KTX 시간표 알려줘
```
---

**질문 예시에만 기대지 마세요.** 아래 예시는 출발점일 뿐이에요. 직접 물어보면서 답이 마음에 안 들면 지역·기간·조건을 바꿔 다시 묻고, 내 상황에 맞게 계속 고쳐 가는 게 가장 중요해요.

## 분야별로 이렇게 물어보세요
깃허브 주소 뒤에 평소 말투로 물으면 됩니다(명령어로 설치했다면 주소 없이 물어도 돼요). 어떤 스킬을 쓸지는 AI가 고릅니다.
### 🏠 부동산
**이렇게 물어보세요**
```plain text
곧 매매할건데 어딜 사야 투자하기 좋을까?
```
클로드가 아파트·빌라 실거래가와 전월세(real-estate-search), LH 분양·임대 공고(lh-notice-search), 법원 경매 매각공고(court-auction-notice-search)를 찾아 지역별로 모아 비교해 줍니다. 관심 지역과 예산을 같이 적으면 비교 범위가 좁혀집니다.

어느 동네가 오를지 예측해 주지는 않습니다. 실거래가·청약·경매 자료를 모아 보여 줄 뿐이고, 살지 말지는 그 자료를 보고 직접 판단하셔야 합니다.

이런 질문도 됩니다.
```plain text
마포구 공덕동 아파트 최근 실거래가 알려줘
```
```plain text
지금 접수 중인 LH 청약 공고 있어? 마감일도 같이
```
```plain text
이번 달 서울 법원 경매로 나온 아파트 찾아줘
```

### ⚖️ 법률
**이렇게 물어보세요**
```plain text
이거 환불 불가라는데 이거 맞는거야?
```
클로드가 korean-law-search로 관련 법령 조문과 판례, 유권해석을 찾아 줍니다. 판매처의 환불 안내 문구나 약관을 같이 붙여 넣으면 관련 조문과 나란히 놓고 볼 수 있습니다.
iros-registry-automation은 인터넷등기소에서 부동산·법인 등기부등본을 장바구니에 담고, 결제 뒤 열람·저장하는 과정을 돕습니다. 결제는 직접 하셔야 합니다.
이런 질문도 됩니다.
```plain text
전세 보증금을 못 돌려받고 있어. 관련 법 조문이랑 판례 찾아줘
```
```plain text
이 집 등기부등본 떼는 거 도와줘
```

### 🛒 쇼핑
**이렇게 물어보세요**
```plain text
이 제품 어디가 최저가인지 찾아와
```
클로드가 쿠팡(coupang-product-search), 네이버쇼핑(naver-shopping-search), 다나와(danawa-price-search)에서 같은 상품을 찾아 판매처별 가격을 비교합니다. 다나와 쪽은 배송비를 더한 실구매가와 카드 할인가까지 확인합니다. "이 제품" 자리에 제품명이나 모델명을 넣어 주세요.
이런 질문도 됩니다.
```plain text
에어팟 프로 쿠팡, 네이버쇼핑, 다나와 가격 비교해줘
```

## 꼭 알아둘 것

- **조회만 해줘요.** KTX는 시간표 조회만 되고 예매·대기·결제·취소는 안 돼요. 항공권도 검색·가격 비교까지만 돼요.
- 등기부등본은 떼는 흐름을 도와주지만 결제는 직접 해야 해요.
- 부동산·법률·투자 답변은 참고용이에요. 매매·소송 판단은 원문 확인과 전문가 상담 뒤에 직접 하세요.
- 공공데이터 조회는 개인 비영리 용도로만 쓰라고 안내돼 있어요. 대량 수집이나 접근 제한 우회는 금지예요.
- 토스증권처럼 내 계좌를 보는 스킬은 내 로그인·인증이 따로 필요해요.
- 쿠팡, 네이버 같은 서비스 이름은 기능 설명용이고 공식 제휴가 아니에요.

- 일부 스킬은 따로 인증 정보가 필요할 수 있어요. 설치 뒤 클로드에 "k-skill-setup 실행해줘"라고 하면 필요한 설정을 확인해줘요.
- 공공 API 프록시 개인정보 처리 안내: k-skill-proxy.nomadamas.org/privacy
