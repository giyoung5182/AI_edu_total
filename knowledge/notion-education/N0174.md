# 9장 · 오늘 만드는 것의 구조
> ⏱️ 14:00 \~ 14:07 (7분)
## 9-1. 파일 두 개로 만듭니다
오늘 만들 결과물은 **파일 두 개**입니다.
```plain text
class-tool/
  ├── index.html        ← 화면과 기능 전부
  └── manifest.json     ← 휴대폰에서 앱처럼 보이게 하는 설정
```
`index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 설치도, 실행 준비도 필요 없습니다.
> 💡 **왜 파일 하나에 다 넣나요**
웹 화면을 만드는 방법은 여러 가지가 있습니다. 큰 서비스는 파일을 수십 개로 나누고 별도의 준비 과정을 거칩니다.
하지만 그럴수록 **막힐 곳이 늘어납니다.** 오늘은 하나를 끝까지 완성하는 게 목표이므로 가장 단순한 방식으로 갑니다.
파일 하나로도 **끌어서 옮기기, 즉시 정답 확인, 움직임** 전부 됩니다. 부족하지 않습니다.
## 9-2. manifest.json — 앱처럼 보이게 하는 쪽지

학생이 휴대폰 브라우저에서 "홈 화면에 추가"를 누르면 이렇게 달라집니다.

## 9-3. 필요해지면 얹을 수 있습니다
기본은 파일 하나입니다. 하지만 만들다 보면 아쉬운 순간이 옵니다. 그럴 때 **말 한 줄로 얹으면** 됩니다.
**① 움직임이 필요할 때**
```plain text
움직임이 좀 있었으면 좋겠어.
설치 없이 주소로 불러오는 방식으로 애니메이션을 넣어줘.
```
> 💡 설치가 아니라 **주소를 적어두고 불러오는 방식**입니다. 파일 수도 안 늘어납니다.
**② 파일이 너무 길어졌을 때**
```plain text
index.html이 너무 길어진 것 같아.
화면이랑 기능을 파일로 나눠줘.
```
> 💡 화면이 세 개 이상이 되면 이 시점이 옵니다. 오늘은 대부분 필요 없습니다.
> ⚠️ **둘 다 급하지 않습니다.** 먼저 동작하게 만들고, 시간이 남으면 얹으세요.
