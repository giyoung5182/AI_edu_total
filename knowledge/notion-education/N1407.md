# 워크시트 예시 답안 — 전체 현황 월말 보고서 자동 취합

정리일: 2026-10-08 · 교육 에셋 N1407

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
부서별 자료를 취합해 월말 보고서를 만드는 업무를 6단계 워크시트(예시 답안)로 설계하고, 보고서 자동 생성을 요청하는 프롬프트까지 만듭니다.
## 진행 단계
1. **STEP 1. 현재 업무 흐름** — 부서에 자료 요청 → 부서별 다른 형식의 파일 수신 → 형식 통일 → 월말 보고서 수동 정리 → 전월 대비 증감률 수동 계산 → 완성.
2. **STEP 2. 판단 vs 규칙** — 자료 요청·수신, 형식 통일, 보고서 정리, 증감률 계산은 \[규칙\] 자동화 가능, 내용 판단·해석은 \[판단\] 자동화 불가.
3. **STEP 3. 자동화 대상** — 부서별 데이터 취합 → 월말 보고서 자동 생성 + 증감률 자동 계산.
4. **STEP 4. 파일 구조** — 입력은 부서별 공유 시트, 이력은 '월별현황', 보고서는 '월말보고서'(현재 PDF 형식과 동일하게 자동 생성).
5. **STEP 5. 트리거** — 버튼 클릭 \[월말 보고서 생성\], 추후 매월 말일 자동 실행 + 이메일 발송(5회차).
6. **STEP 6. Claude 요청 프롬프트**
- 입력할 내용:
```javascript
Google Apps Script 코드를 만들어줘.

[내 업무 상황]
매월 말일에 각 부서 자료를 취합해서 월말 보고서를 만들어.
현재는 수동으로 정리하는데 자동화하고 싶어.

[동작]
[월말 보고서 생성] 버튼 클릭 시:
1. 각 부서 시트 데이터 읽기
2. 이번 달 / 전월 비교 계산
3. 증감률 자동 계산 (이번달-전월)/전월×100
(이하 교안 참고)
```
