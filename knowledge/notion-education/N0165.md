# 먹이사슬 잇기 — 누가 누구를 먹을까
## 무엇을
학생이 화면에 흩어진 **생물 카드 6장을 끌어다가 먹이사슬 순서대로 연결한다.**
```plain text
햇빛 → 벼 → 메뚜기 → 개구리 → 뱀 → 매
```
다 연결하고 '확인' 버튼을 누르면 맞았는지 알려준다.<br>틀렸으면 **어디가 잘못됐는지, 왜 그런지** 한 줄로 설명해준다.
## 왜
먹이사슬은 그림으로 보면 이해한 것 같지만, **직접 순서를 만들어보면 헷갈리는 부분이 드러난다.**
특히 "메뚜기와 개구리 중 누가 먼저인가" 같은 지점에서 학생마다 생각이 갈린다.<br>틀려보고 이유를 듣는 과정이 설명을 듣는 것보다 오래 남는다.
## 사용자
- 초등 5\~6학년
- 과학 「생물과 환경」 단원 정리 차시
- 수업 중 개인 태블릿 또는 모둠별 한 대
- 모둠 대결로 진행해도 좋음
## 화면 구성
```plain text
1. 맨 위 — 제목 "먹이사슬을 이어보세요"
          그 아래 "화살표 방향은 먹는 쪽입니다"

2. 위쪽 영역 — 생물 카드 6장이 뒤섞여 놓여 있다
              각 카드에 이름과 간단한 그림(또는 이모지)

3. 아래쪽 영역 — 빈 자리 6칸이 화살표로 이어져 있다
                □ → □ → □ → □ → □ → □
                카드를 끌어다 놓으면 자리에 들어간다

4. 여섯 칸이 다 차면 — '확인하기' 버튼이 나타난다

5. 확인을 누르면
   · 맞은 자리는 초록색으로 표시
   · 틀린 자리는 주황색으로 표시
   · 아래에 한 줄 설명이 나온다
     예) "개구리는 메뚜기를 먹어요. 순서를 바꿔볼까요?"

6. 다 맞으면 — "먹이사슬 완성!" 축하 문구
              그리고 "이 중 하나가 사라지면 어떻게 될까요?" 생각 질문

7. 맨 아래 — '다시 하기' 버튼
```
## 완료 조건
- 카드 6장을 손가락으로 끌어서 빈 자리에 넣을 수 있다
- 잘못 놓은 카드를 다시 빼서 옮길 수 있다
- 여섯 칸이 다 차면 확인 버튼이 나타난다
- 확인하면 **맞은 곳과 틀린 곳이 색으로 구분**된다
- **틀린 이유가 한 줄로 설명**된다
- '다시 하기'로 처음부터 할 수 있다
- 휴대폰 세로 화면에서 잘리지 않는다
## 오늘 넣지 않는 것
- 점수 저장, 순위표
- 로그인
- 여러 개의 먹이사슬 문제 (하나로 충분)
- 시간 제한, 타이머
## 애매한 것
- 카드에 그림을 넣을지 이모지로 할지 (이모지로 시작)
- 틀렸을 때 정답을 알려줄지 힌트만 줄지 (힌트만)
- 축하 문구에 애니메이션을 넣을지 (시간 남으면)

### 내 수업에 맞게 바꾸고 싶으시면
먹이사슬 대신 **순서나 분류가 있는 것**이면 뭐든 됩니다.
```plain text
· 분리수거 — 쓰레기를 알맞은 통에 넣기
· 물의 순환 — 증발 → 응결 → 강수 → 모임
· 식물의 한살이 — 씨앗 → 싹 → 잎 → 꽃 → 열매
· 역사 사건 순서 맞추기
· 컴퓨터 부품과 하는 일 짝짓기
```
바꾸실 때는 이렇게 말씀하세요.
```plain text

틀렸을 때 설명도 그에 맞게 고쳐줘.
```
