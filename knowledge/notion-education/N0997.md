# 2. 1부 — 재료리스트 최종 확정 (30분)
## 2-1. 오늘이 마감일
- 오늘이 재료리스트 최종 마감일
- 빠진 항목을 채우고 계산까지 맞추는 것이 목표
## 2-2. 모든 팀 공통 확인 항목
- 팀 이름과 컨셉 칸 기입
- 목표 생산 개수 기입 (숫자만, "개" 붙이면 계산 안 됨)
- 판매 가격 기입
- 단가와 배송비를 칸에 직접 입력 (최종 금액은 자동 계산되므로 손으로 적지 않기)
- 모든 항목에 구매 링크 기재
- 수령처(센터/집) 표시
- 마진율 30% 이상 확인
## 2-3. 계산 공식 다시 보기
```javascript
단위 원가 = 총 지출액 ÷ 목표 생산 개수
마진 = 판매 가격 − 단위 원가
마진율(%) = 마진 ÷ 판매 가격 × 100
```
- 단위 원가보다 판매 가격이 낮으면 팔 때마다 손해
- 화면에 뜨는 숫자를 그대로 믿지 말고, 계산기로 한 번 직접 확인
## 2-4. AI에게 부탁하기 — 빠진 재료 찾기
재료를 다 담았다고 생각해도 포장재나 소모품이 빠지는 경우가 많음. 아래 형식으로 물어볼 것.
```javascript
나는 중학교 플리마켓에서 [우리 아이템]을 [목표 개수]개 만들어서
개당 [판매가]원에 팔 예정이야.

지금 장바구니에 담은 재료는 다음과 같아.
[재료 목록을 그대로 붙여넣기]

이 목록에서 빠진 것이 있는지 알려줘.
만드는 데 필요한 재료, 포장재, 현장에서 쓸 소모품으로 나눠서
빠진 것만 목록으로 알려줘.
```
- 받은 목록을 그대로 담지 말고, 우리에게 진짜 필요한 것만 골라 담기
- 가격은 AI에게 묻지 말고 직접 검색해 확인
## 2-5. AI에게 부탁하기 — 가격 구조 점검
계산해보니 손해가 나거나 마진율이 너무 낮을 때 사용.
```javascript
재료비로 총 [총 지출액]원을 썼고, [목표 개수]개를 만들 예정이야.
판매 가격은 [판매가]원으로 생각하고 있어.

단위 원가와 마진율을 계산해주고,
마진율이 30%가 안 되면 어떻게 고치면 좋을지
세 가지 방법을 비교해서 알려줘.
```
- 목표 개수 늘리기, 판매가 올리기, 품목 덜어내기 중 무엇이 우리 팀에 맞는지 판단하는 데 사용
## 2-6. 팀별 확인 사항
**두바이상한 사람들**
- 계산까지 마무리된 상태, 아래 세 가지만 보완
- 수령처 칸이 전부 공란 → 항목별로 센터인지 집인지 표시
- 먹거리를 파는 팀인데 위생용품이 없음 → 추가
- 일회용 장갑
- 물티슈
- 일회용 테이블보

- 담은 식품의 유통기한 확인 → 10월 24일까지 먹을 수 있는지 상품 페이지에서 확인
**MIREN**
- 재료는 거의 다 채워진 상태

- 공병 수량과 사쉐 속지 수량을 대조해 목표 개수 결정
- 왁스 1통으로 몇 개를 만들 수 있는지 계산해 수량 확인
- 빠진 항목

**지름글로리**
- 파일을 먼저 정리해야 함
- 잔여 시드머니 칸에 `#REF!` 오류 발생
- 같은 품목 목록이 시트 아래쪽에 한 벌 더 들어가 있음 → 중복분 삭제
- 합계가 두 가지로 잡혀 있어 어느 쪽이 맞는지 확인 필요
- **현재 가격 구조로는 팔수록 손해**
- 예산을 거의 다 썼는데 목표 개수는 18개로 잡혀 있음
- 화면에 뜨는 마진율은 중복된 아래쪽 합계를 기준으로 계산된 숫자라 틀림
- 정확한 총 지출액으로 단위 원가를 계산기로 다시 계산해 볼 것
- 세 가지 중 하나를 선택해 구조 수정
- 목표 개수 늘리기 (랜덤박스 한 개에 들어가는 물건 수를 줄이면 더 많이 만들 수 있음)
- 판매 가격 올리기
- 비싼 품목 덜어내기
- 랜덤박스는 등급별 구성이 다르므로 평균 단위 원가로 계산

# 3. 2부 — 브랜드 3요소 확정 (25분)
## 3-1. 왜 필요한가
- 플리마켓 당일에는 여러 부스가 나란히 늘어섬
- 무엇을 파는 곳인지 한눈에 드러나지 않으면 손님의 발걸음이 멈추지 않음
- 브랜딩: 우리 제품에 고유한 이름과 표시를 붙여 다른 부스와 구별되게 만드는 일
- 이 시간은 이름·문장·색까지만 확정, 그림 작업은 3부에서 시작
## 3-2. 확정할 세 가지
**첫째, 공식 상호명**
- 3\~5음절 내외로 부르기 쉬울 것
- 이름만 듣고 무엇을 파는지 짐작 가능할 것
- 다른 팀과 겹치지 않을 것
- 지금 팀명을 그대로 쓸지, 새로 지을지 팀 내에서 결정
- 팀 이름이 아직 없는 팀은 이 시간에 확정
**둘째, 슬로건**
- 핵심 가치를 10글자 내외 한 문장으로 압축
- 구성: 핵심 혜택 + 약속
- 예시: "오늘 하루의 향을 담다", "뭐가 나올지 모르는 재미"
**셋째, 브랜드 컬러**
- 메인 컬러 1개, 보조 컬러 1개
- 메인 컬러는 부스 전체 인상, 보조 컬러는 강조 요소에 사용

## 3-3. AI에게 부탁하기 — 가게 이름 후보 받기
```javascript
나는 중학교 플리마켓에서 가게를 열 거야.

- 파는 것: [아이템을 구체적으로]
- 손님: [누구에게 팔 것인지]
- 가격대: 개당 [판매가]원
- 우리 팀이 주고 싶은 느낌: [예: 귀엽다 / 고급스럽다 / 웃기다]

이 가게에 어울리는 이름 후보를 10개 지어줘.
조건은 이래.
- 3~5음절 내외로 짧을 것
- 이름만 듣고 무엇을 파는지 짐작할 수 있을 것
- 중학생이 보고 재미있다고 느낄 것

이름마다 왜 그렇게 지었는지 한 줄로 설명도 같이 써줘.
```
- 마음에 드는 것이 없으면 "더 웃긴 쪽으로", "더 깔끔한 쪽으로"처럼 방향을 주고 다시 요청

## 3-5. AI에게 부탁하기 — 컬러 정하기

- 완성된 그림은 PNG로 저장해 Canva에 올릴 준비
## 4-3. Canva 작업 순서
**1단계. 캔버스 만들기**
- canva.com 접속 후 우측 상단 \[디자인 만들기\] 클릭
- \[맞춤형 크기\] 선택
- 단위를 mm로 변경, 가로 50 세로 50 입력
- 라벨 스티커 표준 규격이며 크게 늘려 써도 깨지지 않음
**2단계. 배경 컬러 지정**
- 좌측 \[배경\] 탭에서 2부에 정한 메인 컬러 선택
- AI가 알려준 색상 코드(HEX)가 있으면 직접 입력
**3단계. AI로 만든 그림 올리기**
- 좌측 \[업로드\] 탭 → \[파일 업로드\] → 저장해둔 PNG 선택
- 캔버스에 끌어다 놓고 크기 조정
**4단계. 상호명 입력**
- 좌측 \[텍스트\] → \[제목 추가\] → 상호명 입력
- 추천 한글 폰트
- 굵고 단단한 느낌: 지마켓산스 Bold, 에스코어드림 7
- 친근하고 둥근 느낌: 배달의민족 주아, 티머니 둥근바람 Bold
- 깔끔한 느낌: Pretendard Bold
- 글자 색은 보조 컬러로 지정해 배경과 대비 확보
**5단계. 정렬과 여백**
- 가장자리에서 3mm 이상 안쪽으로 모든 요소 배치
- \[위치\] → \[가운데 정렬\]로 균형 조정
**6단계. 다운로드와 제출**
- 우측 상단 \[공유\] → \[다운로드\] → PNG 선택
- 파일명: 교육기관_팀명_로고.png
- 지정 폴더에 업로드
## 4-4. 제출 전 확인
- 손바닥 크기로 줄였을 때 상호명이 읽히는가
- 사용한 색이 3개 이하인가
- 가장자리 글자가 잘리지 않는가
- 그림 안에 깨진 글자가 섞여 있지 않은가
- 파일명 형식을 지켰는가
## 4-5. 자주 하는 실수
- AI가 준 그림을 그대로 로고로 쓰기 → 가게 이름이 없으면 손님이 무엇을 파는지 알 수 없음
- 요소를 너무 많이 넣기 → 실제 스티커 크기로 줄이면 뭉개짐, 아이콘 1개면 충분
- 색을 여러 개 쓰기 → 메인과 보조 두 가지만 사용
- 글자를 가장자리에 붙이기 → 인쇄할 때 잘려 나감
- AI가 그린 그림 속 글자를 그대로 두기 → 한글이 깨져 있으므로 지우고 Canva에서 다시 입력
