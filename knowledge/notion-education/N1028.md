# Step E·F · 상황별 시작점으로 첫 단계 1개 만들고 설계서 갱신

정리일: 2026-10-08 · 교육 에셋 N1028

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 상황에 맞는 시작점 1개를 골라 첫 단계 1개만 오늘 완성하고, 결과를 설계서에 기록합니다.
## 진행 단계
1. **시작점 고르기 (Step E)** — 같은 규정으로 문의·초안이 반복 → E-1 지침 먼저(프로젝트) / 열 이름·형식이 제각각이거나 개인정보 섞임 → E-2 자료 먼저 / 자료를 올릴 수 없거나 없음 → E-2-1 가짜 데이터 만들기 / 여러 파일을 읽어 결과 파일, 회차마다 반복 → E-3 폴더 먼저(Work + AGENTS.md) / 시트 1개의 모든 행에 같은 규칙, 매주·매월 반복 → E-4 자동 실행 먼저(앱스크립트 + 트리거) / 설계서 7번에 도구가 둘 이상 → E-5 조합.
2. **첫 단계 1개 완성** — 선택한 시작점의 토글 절차를 따릅니다(예: E-4는 시트 준비 → ChatGPT에 Apps Script 코드 요청 → Apps Script에 붙여넣고 저장 → 실행·권한 허용 → 로그 건수와 직접 센 건수 비교 → 필요하면 트리거).
- 입력할 내용(E-4 코드 요청 일부):
```javascript
Google Apps Script 코드를 짧게 만들어 줘. 코드를 모르는 사람이 Google 시트에 붙여넣어 쓸 코드임.
- 입력 시트: [시트 이름] (1행 머리글, 열은 위치가 아니라 머리글 이름으로 찾기)
- 할 일: [정리 / 불러오기]
- 조건: '[열 이름]'이 "[값]" 인 행
- 결과 시트: [결과 시트 이름] (매번 지우고 다시 쓰기 — 두 번 실행해도 행이 늘지 않게)
- 끝나면 실행 로그에 건수 출력
- 입력 시트 값 수정·행 삭제·메일 발송 코드는 넣지 말 것
(이하 교안 참고)
```
3. **설계서 갱신 (Step F)** — 설계서 14번에 시작점 / 완료한 단계 / 돌려 본 결과 / 원본과 다른 점·\[확인 필요\] / 다음 단계(쓸 도구)를 적습니다. 결과가 기대와 다르면 설계서의 해당 칸(5번 입력 자료·8번 지침·12번 완료 기준)부터 고치고 다시 돌려 v1.1로 올립니다.
## 막히는 지점
- 실제 사내 정보는 넣지 않고 가짜 데이터를 사용합니다.
- Work가 AGENTS.md를 알아서 읽는지는 \[확인 필요\]이므로 요청문에 적고 첫 보고로 확인합니다.
- 원본 수정·삭제를 묻는 창이 뜨면 거부합니다.
