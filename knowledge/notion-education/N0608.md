# 2-5. 보고 코멘트 만들기

정리일: 2026-10-08 · 교육 에셋 N0608

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
분석 결과를 실행 가능한 문장으로 바꿔 어디를 먼저 볼지 드러나는 보고 코멘트를 만듭니다.
## 진행 단계
1. **프롬프트 입력** — 조건을 지정해 보고용 코멘트를 요청합니다.
- 입력할 내용:
```javascript
실습파일/교육기관생산설비데이터_실습.xlsx 분석 결과를 바탕으로 보고용 코멘트를 작성해줘.

조건은 다음과 같아.
- 1단락으로 작성
- 가장 위험해 보이는 공장/라인/설비 조합을 언급
- 가동률, 수율, 정지시간, 이상유형 중 근거가 되는 지표를 포함
- 가동률과 수율은 사람이 보기 쉽게 % 형식으로 표현
- 마지막 문장에는 확인 액션 2개를 제안
- 과장하지 말고 데이터에서 확인 가능한 내용만 써줘
```
