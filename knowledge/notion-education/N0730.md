```plain text
[카메라 움직임]

```
**작성 요령**
- **\[카메라 움직임\]** 에는 화면이 어떤 방식으로 움직일지 적습니다. 너무 복잡하게 쓰기보다 천천히 앞으로 이동, 부드럽게 따라감처럼 간단하고 안정적인 표현이 좋습니다.
- **\[피사체 움직임\]** 에는 인물, 제품, 공간 안 요소가 어떻게 움직일지 적습니다. 처음에는 큰 동작보다 눈 깜빡임, 옷자락 흔들림, 공기 흐름처럼 미세한 움직임이 더 잘 맞습니다.
- **\[조명/배경 유지\]** 에는 원래 이미지에서 유지하고 싶은 무드와 환경을 적습니다. 배경 유지, 색감 유지, 겨울 공기감 유지처럼 쓰면 됩니다.
- **\[영상 느낌/품질\]** 에는 결과물이 어떤 인상으로 나오길 원하는지 적습니다. 부드럽고 자연스럽게, 과한 변형 없이, 안정적으로 이어지는 느낌처럼 적으면 됩니다.
예를 들어 앞에서 만든 프리미엄 숏패딩 이미지를 바탕으로<br>아래처럼 작성할 수 있습니다.
```plain text
[카메라 움직임] 카메라는 모델을 향해 천천히 앞으로 이동
[피사체 움직임] 모델은 차분하게 걷고, 옷자락과 머리카락은 겨울 바람에 살짝 흔들림
[조명/배경 유지] 겨울 새벽 도시 배경과 고급스럽고 차가운 공기감은 그대로 유지
[영상 느낌/품질] 부드럽고 자연스럽게 이어지는 광고 영상 초안, 형태가 무너지지 않게 안정적으로 생성
```

## 프롬프트를 바꾸면 영상이 어떻게 달라질까
같은 이미지라도 움직임 설명을 바꾸면 영상의 느낌이 달라집니다. <br>한 항목씩 바꿔 넣으며 비교해볼까요?
**예시 1. 템포를 빠르게 (차분한 광고 → SNS 숏폼)**
```javascript
[카메라 움직임] 카메라와 장면 전환 템포를 조금 더 빠르게 조정
[피사체 움직임] 같은 인물과 같은 콘셉트를 유지하되 움직임은 조금 더 경쾌하게
[조명/배경 유지] 겨울 도시 배경과 세련된 분위기는 그대로 유지
[영상 느낌/품질] SNS 숏폼 광고처럼 템포를 조금 더 빠르게, 너무 과하지 않고 세련된 느낌으로
```
**예시 2. 카메라 움직임을 바꾸기 (전진 → 좌우 이동)**
```javascript
[카메라 움직임] 카메라가 좌측에서 우측으로 천천히 수평 이동하며 제품을 보여줌
[피사체 움직임] 모델은 제자리에서 가볍게 자세를 잡고, 패딩 표면의 질감이 드러나게
[조명/배경 유지] 겨울 도시 배경과 차분한 색감 유지
[영상 느낌/품질] 안정적이고 고급스러운 제품 소개 영상 느낌
```
**예시 3. 제품 중심 영상으로 (모델 없이 제품만)**
```javascript
[카메라 움직임] 제품을 중심으로 카메라가 아주 천천히 줌인
[피사체 움직임] 패딩은 고정된 채, 주변 공기와 미세한 빛 변화만 자연스럽게
[조명/배경 유지] 미니멀한 스튜디오 배경과 프리미엄한 조명 유지
[영상 느낌/품질] 상세페이지 상단에 들어갈 짧은 제품 무빙컷, 형태가 또렷하게 유지
```
- 세 예시 중 두 개 이상을 직접 넣어 만들고, 첫 영상과 비교
- 템포(예시 1), 카메라 움직임(예시 2), 피사체 유무(예시 3)를 바꿨을 때 영상 느낌이 어떻게 달라지는지
- 어떤 설명에서 형태가 잘 유지되고, 어떤 설명에서 흔들리는지
- 보통 움직임이 작을수록 안정적

## 주의사항
### 1. 업로드하는 이미지는 권한이 있는 것만 사용합니다
직접 제작한 이미지, 사내에서 사용 권한이 있는 이미지, 교육용으로 허용된 이미지 중심으로 활용하는 것이 안전합니다.
### 2. 움직임은 작게 잡는 편이 좋습니다
처음부터 인물이 크게 움직이거나 카메라가 빠르게 이동하면 형태가 무너지거나 장면이 불안정해질 수 있습니다.
처음에는 **천천히, 살짝, 자연스럽게 **같은 표현이 더 적합합니다.
### 3. 텍스트, 로고, 제품 디테일은 다시 확인해야 합니다
생성형 영상은 디테일이 흔들리거나 바뀌는 경우가 있으므로, 대외 배포 전에 반드시 다시 검수해야 합니다.
### 4. 업무에서는 완성본보다 기획 시안 용도로 먼저 보는 것이 좋습니다
처음에는 무빙 포스터 시안, 분위기 확인용 샘플, 내부 보고용 레퍼런스 정도로 활용하는 것이 현실적입니다.
### 5. 외부 공개 전에는 내부 가이드를 확인해야 합니다
AI 생성 콘텐츠 표시 기준, 브랜드 가이드, 대외 커뮤니케이션 기준은 조직 정책에 따라 다를 수 있으므로 외부 사용 전 확인이 필요합니다.
## 핵심 정리
- 이미지에서 출발(image to video)하면 시안의 구도·색감을 유지한 채 움직임만 입힐 수 있다
- 카메라 움직임/피사체 움직임/배경 유지/영상 느낌, 네 항목으로 적는다
- 영상은 디테일이 흔들리므로 완성본이 아니라 기획 시안 용도로 먼저 쓰고, 외부 사용 전 검수·내부 가이드 확인
## 더 알아보기
#### AI가 영상을 어떻게 만드는가
영상은 정지 이미지인 ‘프레임’이 시간 순서대로 이어진 것입니다. 보통 1초에 24\~30장의 프레임이 재생됩니다.<br>많은 영상 생성 AI는 이미지 생성처럼 잡음에서 시작해, 프롬프트에 맞는 장면과 움직임을 단계적으로 만들어갑니다.
영상에서 어려운 점은 같은 인물과 사물의 모습이 프레임마다 자연스럽게 이어지도록 만드는 것입니다. <br>이를 **시간적 일관성(temporal consistency)**이라고 합니다. <br>일관성이 깨지면 얼굴이나 옷이 바뀌고, 배경과 사물의 형태가 흔들릴 수 있습니다.
영상 데이터를 학습한 모델은 물체와 장면이 시간에 따라 변하는 패턴도 익힙니다. <br>(이 능력은 다음 장면이나 환경의 변화를 예측하는 **월드 모델 연구**와도 연결되지만, 모든 영상 생성 AI가 월드 모델이라는 뜻은 아닙니다.)
움직임이 빠르고 복잡할수록 시간적 일관성을 유지하기 어렵습니다. <br>처음에는 인물과 카메라의 움직임을 한두 가지로 제한하고, 천천히 자연스럽게 움직이도록 작성하는 것이 안정적입니다.
