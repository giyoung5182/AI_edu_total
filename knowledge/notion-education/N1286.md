# [실습] 리더의 AI 리서치 → 검증 → 의사결정

정리일: 2026-10-08 · 교육 에셋 N1286

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
하나의 AI 대화창에서 4단계 체인(리서치 → 사실검증 → 편향성 검증 → 최종 보고서)을 직접 경험함. 각 Step의 프롬프트를 복사해 붙여넣음.
## 진행 단계
1. **Step 1. 리서치** — 아래 프롬프트를 복사해 붙여넣음.
- 입력할 내용:
```javascript
## 역할
너는 건설산업 전문 리서치 애널리스트야.

## 지시
2026년 하반기 국내 건설산업의 주요 리스크 요인 5개를 분석해줘.
각 리스크에 대해 다음을 포함해줘:
1. 리스크 설명 (구체적 수치 포함)
2. (해당 기업)에 미치는 영향
3. 대응 전략 제안

## 출력양식
- 형식: 표 (리스크명 | 설명 | 영향 | 대응)
- 톤: 리더 전략회의 보고용
- 분량: A4 1페이지
```
2. **Step 2. 사실검증** — 결과가 나오면 같은 대화창에 이어서 붙여넣음.
- 입력할 내용:
```javascript
위 보고서에 대해 사실검증을 수행해줘.
1. 언급된 수치/통계의 출처가 있는지 확인
2. 특정 사례나 기업명이 실제인지 확인
3. 날짜나 시점이 정확한지 확인
4. 확인되지 않는 내용은 "⚠️ 검증 필요"로 표시

결과를 표로 정리:
| 항목 | 내용 | 검증 결과 | 비고 |
```
3. **Step 3. 편향성 검증** — 이어서 붙여넣음.
- 입력할 내용:
```javascript
이제 편향성 검증을 수행해줘.
1. 부정적 리스크만 강조하고 기회를 누락하지 않았는지
2. 특정 관점으로 치우친 결론은 없는지
3. 반대 근거나 다른 해석이 가능한 부분은 없는지
4. 리더가 이 보고서만 보고 판단하면 놓칠 수 있는 것은?

결과를 표로 정리:
| 편향 유형 | 해당 내용 | 위험도 | 보완 방법 |
```
4. **Step 4. 최종 보고서** — 이어서 붙여넣음.
- 입력할 내용:
```javascript
위의 사실검증과 편향성 검증 결과를 반영해서,
최종 리더 전략회의용 1페이지 브리프를 다시 작성해줘.

- 검증 안 된 수치는 "추정" 표기
- 누락된 관점 보완
- 형식: 핵심 리스크 3개 + 각각의 대응 방안 + 즉시 조치 필요 항목
```
- 정상 결과(확인 포인트): 사실검증에서 "⚠️ 검증 필요"가 나온 항목을 확인하고, 최초 보고서와 검증 후 최종 보고서의 차이를 비교함. "AI 답변을 그대로 쓰면 안 되는 이유"를 체감하는 것이 핵심.
## 막히는 지점
- 교안의 데이터 보안 기준: 입찰 금액·원가·계약 조건 같은 항목은 입력 금지, 내부 보고서는 고유명사·수치 제거 후 일반화 입력, 공개 법규·일반 절차·가상 데이터는 사용 가능.
