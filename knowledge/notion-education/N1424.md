# Step B · 프로세스 쪼개기

정리일: 2026-10-08 · 교육 에셋 N1424

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
고른 업무를 단계로 나누고, 단계마다 필요한 자료와 결과물을 목록으로 만든 뒤 작업 순서를 정함.
## 진행 단계
1. **표 틀 붙여넣기** — 메모장에 아래 틀을 붙여넣고 아는 칸부터 채움. 빈칸이 있어도 되며 Step D 인터뷰에서 마저 채움.
- 입력할 내용:
```javascript
[프로세스 쪼개기 표]
번호 | 단계(동사 하나) | 하는 일 | 누가(사람 / AI) | 필요한 자료 | 결과물 | 판단이 필요한가(예/아니오)
1 |  |  |  |  |  |
2 |  |  |  |  |  |
(…6번까지)
작업 순서(먼저 만들 단계):
```
2. **쪼개기** — 위임표의 단계(As-Is)를 그대로 가져와 시작. 한 단계에 동사 하나, 동사가 둘이면 두 단계로.
3. **칸 채우기** — 누가는 하나만(AI면 새 채팅·데이터 분석·프로젝트·Work 중 어디인지). 필요한 자료는 파일·시트·열 이름까지. 결과물은 다음 단계의 자료 이름과 이어 씀.
4. **작업 순서 정하기** — 결과를 원본과 맞춰 보기 쉬운 단계부터. 판단이 필요한 단계는 도구로 만들지 않음.
- 정상 결과: 교안의 표준 답변(출장정산 확인 목록, 작업 순서 3 → 4 → 5)과 같은 모양의 표.
## 막히는 지점
- 자료가 없으면 "없음"으로 적고 Step E-2-1(가짜 데이터) 대상으로 넘김.
- 사람과 AI가 섞이면 두 단계로 나눔.
- 판단이 필요한 단계는 누가=사람으로 두고 표에서 지우지 않음.
