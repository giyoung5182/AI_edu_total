# 실습 3. AI 챗봇 만들기

정리일: 2026-10-08 · 교육 에셋 N1333

---

## 이 실습으로 하는 것
터미널 A의 Claude Code에 챗봇 제작을 지시하고, 서버를 껐다 켜며 서비스의 생사가 서버에 달려 있음을 확인합니다.
## 진행 단계
1. **프롬프트 입력** — 아래 프롬프트를 그대로 입력하고 승인 요청을 읽으며 진행
- 입력할 내용(앞부분):
```plain text
FastAPI로 AI 챗봇 웹 서비스를 만들어 주세요. 요구사항입니다.

1. 브라우저에서 열리는 채팅 페이지를 만들어 주세요. 입력창에 질문을 쓰고 전송하면 대화 목록에 질문과 답변이 말풍선으로 쌓이는 단순한 화면이면 됩니다.

2. 답변은 Gemini API(모델: gemini-2.5-flash)가 생성합니다. API 키는 .env 파일의 GEMINI_API_KEY 값을 읽어 사용하고, 코드에 키를 직접 적지 마세요.

3. 서버 터미널에 로그가 자세히 출력되게 해 주세요. 질문을 받은 시각, Gemini 호출 시작, 응답 반환과 소요 시간이 각각 한 줄씩 보이면 좋겠습니다.
(이하 교안 참고)
```
1. **서버 실행** — 터미널 B에서 Claude Code가 알려준 서버 실행 명령 입력
2. **접속** — 브라우저에서 [개별 링크 제외] 열기
3. **질문** — 챗봇에 "안녕하세요" 등 입력
4. **로그 확인** — 터미널 B에 올라오는 로그 확인
5. **서버 끄기** — 터미널 B에서 Ctrl+C
6. **새로고침** — 연결 불가 화면 확인
7. **서버 재시작** — 다시 켜고 새로고침하면 챗봇이 되살아남
## 막히는 지점
- 페이지는 열리는데 답변이 안 옴 → .env 키 앞뒤 공백·따옴표 제거 후 서버 재시작
- 401/403 → 키가 유효하지 않음, 실습 2로 돌아가 재발급
- 429 → 무료 사용량 한도 초과, 1\~2분 대기
- Address already in use → Ctrl+C 후 재실행, 안 되면 8001 포트 실행 요청
