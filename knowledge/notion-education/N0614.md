# 첫 번째 음악 만들기

정리일: 2026-10-08 · 교육 에셋 N0614

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
특정 브랜드 없이 프리미엄 겨울 패딩 캠페인에 어울리는 차분하고 세련된 분위기의 30초 음악 시안을 만든다.
## 진행 단계
1. **프롬프트 뼈대 이해** — 무엇을 만들지 / 분위기·톤 / 배경·환경 / 구성·전개 / 용도
2. **프롬프트 입력** — 아래 프롬프트를 그대로 입력
- 입력할 내용:
```javascript
[무엇을 만들지] 프리미엄 겨울 패딩 캠페인용 30초 음악 초안
[분위기/톤] 세련되고 따뜻한 분위기, 과하지 않은 광고 배경음악 느낌
[배경/환경] 겨울 도시의 공기감이 느껴지는 무드
[구성/전개 방식] 짧은 브랜드 필름이나 광고 영상 뒤에 자연스럽게 깔릴 수 있는 흐름
[용도] 프리미엄 숏패딩 캠페인 무드 샘플용

- 특정 브랜드명은 넣지 않기
- 멜로디는 과하지 않게
- 배경음악처럼 자연스럽게 이어지게
```
## 막히는 지점
- 특정 가수나 곡을 그대로 따라 하도록 요청하기보다 분위기와 악기·보컬 특징으로 표현. 미공개 캠페인 정보는 입력하지 않음
