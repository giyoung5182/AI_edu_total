# Step 2. Subagent 생성(자연어로 만들기)

정리일: 2026-10-08 · 교육 에셋 N1087

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
사고 접수 건을 약관 기준과 대조해 판정하는 보상 검토 Subagent를 자연어 브리핑으로 만듭니다.
## 진행 단계
1. **Claude Code 실행** — 지난 시간에 만든 실습 폴더(예: work)에서 폴더 빈 공간을 오른쪽 클릭해 터미널을 열고 `claude`를 입력합니다.
2. **Claude에게 짧게 브리핑** — 입력창에 아래를 붙여넣고 엔터. 판정 4종의 대략 기준, 역할, 출력 형태, 모델만 알려주면 나머지는 Claude가 초안으로 채웁니다.
- 입력할 내용:
```javascript
data 폴더의 사고 접수 건을 보상 검토하는 서브에이전트를 .claude/agents/ 폴더에 만들어줘.
사고 건을 운전자보험 약관의 보상 기준과 대조해서, 건별로 아래 4개 중 하나로 판정하고
사유와 함께 표로 정리하는 역할이야.

- 보상가능: 보장 항목에 해당하며 보상 가능
- 추가확인: 서류 미비나 금액 미확정 등으로 추가 정보가 필요할 때
- 면책: 음주, 무면허 등 보상하지 않는 손해에 해당할 때
- 심사보류: 사고 경위 불명확 등으로 조사 후 판단이 필요할 때

'보상 검토', '사고 건 검토', '보상 심사', '사고 접수 검토' 요청이 오면
반드시 이 에이전트가 쓰이도록 description을 써줘.
에이전트 이름(name)은 영어 소문자와 하이픈으로 지어줘.
도구는 모두 허용해줘. 모델은 Sonnet으로 해줘.
```
- 정상 결과: 붙여넣기 시 화면이 다르게 뜰 수 있으나 문제 없는 상태이며 그대로 엔터를 누르거나 한 번 더 붙여넣기하면 펼쳐져 보입니다.
1. **Claude가 초안 생성** — Claude가 에이전트 이름, 호출 조건(description), 도구(tools), 모델(model), 판정 표, 시스템 프롬프트를 채워 `.claude/agents/`에 저장합니다. 파일 생성 진행 여부를 물으면 허용(1번 또는 엔터)을 선택합니다.
2. **중요한 규칙만 짧게 보정** — 초안이 나오면 필요한 규칙만 덧붙입니다.
- 입력할 내용:
```javascript
좋아. 세 가지만 반영해줘.
자료에 없는 내용은 추측하지 말고 '확인 필요'로 표시해.
애매하면 보상가능으로 단정하지 말고 추가확인으로 둬.
최종 보상금액은 확정하지 말고 1차 검토 의견만 내.
```
1. **만들어진 것 확인** — 실습 폴더의 `.claude/agents` 폴더 안에 에이전트 파일(예: `claim-compensation-assessor.md`)이 생긴 것을 확인합니다.
2. **재시작** — 입력창에서 `/exit`로 끄고(또는 Ctrl+C 두 번) 같은 폴더에서 다시 `claude`를 실행하면 새 에이전트가 목록에 등록됩니다.
## 막히는 지점
- 에이전트 이름은 영어 소문자와 하이픈만 인식. 한글 이름이면 "Agent type ... not found" 오류
- 처음 만든 에이전트는 현재 대화에서 .claude 폴더가 인식 안 될 수 있어 재시작 필요
