# STEP 7 · 웹페이지 섹션 구성 확정

## 이 실습으로 하는 것
포트폴리오 웹페이지의 섹션 구성을 확정해 다음 파트에서 만드는 일만 남기도록 한다.
## 진행 단계
1. **섹션별 재료 확인** — 01 첫 화면(이름·직무·한 줄 소개) / 02 소개 / 03 경력 / 04\~06 경험 01\~03(STAR 카드) / 07 역량 / 08 연락처.
2. **경력 섹션 쓰기** — 공백기·직무 전환을 숨기지 말고 각 구간에 한 줄씩 무엇을 했는지 적는다.
3. **전체 톤 하나 고르기** — 전문적(대기업·공공기관) / 간결한(스타트업) / 따뜻한(로컬 브랜드·커뮤니티) / 과감한(크리에이티브 직군)
4. **4권 정리 체크** — 교안의 확인 항목 9개를 점검한다.
## 막히는 지점
- 구성이 확정되지 않으면 5권에서 반드시 막힘. 03 경력과 07 역량이 자주 비어 있음
