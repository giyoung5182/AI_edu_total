# Claude in Chrome이란?

**Claude in Chrome** = Claude Code에 웹 브라우저를 더해주는 크롬 확장 프로그램

Claude Code는 내 컴퓨터의 파일과 앱을 다룹니다. 하지만 웹사이트를 열거나, 검색하거나, 웹 화면을 클릭하는 일은 브라우저가 있어야 합니다. Claude in Chrome은 Claude Code가 크롬 브라우저를 직접 다루게 해줍니다.
[원본 이미지 제외]



**Claude in Chrome이 없으면**<br>Claude Code는 내 컴퓨터의 파일·앱만 다룰 수 있음. 웹사이트는 직접 다루지 못함.




**Claude in Chrome이 있으면**<br>Claude Code가 웹 브라우저를 직접 열고 검색·클릭·수집까지 처리함.




**참고 — MCP(Model Context Protocol)**
- AI에 외부 도구를 연결하는 이런 방식을 넓게는 MCP라 부릅니다.
- Claude in Chrome도 이 방식으로 연결되는 도구의 하나이며, 같은 방식으로 다양한 서비스(메일·캘린더·사내 도구 등)를 연결할 수 있습니다.

---
# 오늘 사용할 도구: Claude in Chrome

**Claude in Chrome** = Claude Code가 크롬 브라우저를 자동으로 조작하게 해주는 확장 프로그램

Claude in Chrome을 연결하면 Claude Code가 다음과 같은 일을 할 수 있습니다:
- 웹사이트에 **직접 접속**
- 페이지 내용을 **읽고 탐색**
- 버튼을 클릭하거나, 검색어를 입력하는 등 **브라우저 조작**
- 수집한 정보를 **정리하여 결과물 생성**
예를 들어 “우리 회사 홈페이지에서 최신 보도자료를 가져와줘”라고 하면, Claude Code가 직접 브라우저를 열고 자료를 수집해옵니다.
---
# Claude in Chrome 설치 → 클릭

크롬 웹스토어에서 ‘Claude’ 확장을 설치한 뒤 Claude Code와 연결합니다.<br>① 크롬 우상단 확장 아이콘에서 Claude 고정<br>② Claude 계정으로 로그인<br>③ 클로드 데스크톱 앱 좌측의 ‘Customize → 커넥터’에서 **‘Claude in Chrome’ 클릭 후 활성화하기**

설치가 잘 됐는지는 크롬 오른쪽 위의 Claude 아이콘과 Claude Code의 커넥터가 켜져 있는지로 확인합니다.
[원본 이미지 제외]

**크롬 우상단에 Claude 아이콘이 보이고 커넥터가 켜져 있으면 준비 완료!**<br>이제 Claude Code에 웹 작업을 시킬 수 있습니다.

- 연결 상태가 궁금하면 'Code' 탭 입력창에 `/chrome` 을 입력해 확인할 수 있습니다.

# Claude in Chrome 테스트

설치가 잘 되었는지 간단히 테스트해봅시다. Claude Code에서 아래처럼 시켜보세요.

```javascript
카카오맵에서 광화문에서 롯데타워까지 대중교통 경로를 검색하고, 검색 결과 화면을 캡처해.
그리고 경로들을 엑셀로 읽기 좋게 정리해.
```

**결과물**: 캡처 1장, 엑셀 파일 1개


**크롤링 시 주의사항**: 크롤링 전에 해당 사이트의 `robots.txt`를 반드시 확인하세요!<br>`www.사이트주소.com/robots.txt` 에 크롤링 허용 여부가 명시되어 있습니다.

# 실습 — 법인카드 사용내역 설문폼 제출하기

**일에 바로 쓰는 실습**: 너무 바빠 밀려버린 법인카드 사용내역 정리 업무를 Claude in Chrome으로 단숨에 정리 및 제출해보세요!

[첨부 원본 제외: 파일 권리·개인정보 확인 전입니다.]


```javascript
이 엑셀 파일은 내가 사용한 법인카드 사용내역이야.
여기 설문폼에 제출해야해.
 - 법인카드 사용내역 제출 설문폼 : [개별 링크 제외]

 아래와 같은 순서로 작업을 해보자.
 1) 클로드인크롬으로 위 링크 2개 열고 작업 테스트 진행
 2) 작성 방식을 학습하고 가장 빠르게 작업을 끝낼 수 있는 방안 세운 후 아래 3~4번 수행
 3) 클로드인크롬으로 위 링크 8개 한 번에 띄우기
 4) 엑셀 파일 참고하여 각각 내용 채우기


완료되면 말해줘. 내가 검토하고 제출 버튼을 직접 누를게.
```
- 실행하면 Claude in Chrome이 브라우저 창을 띄웁니다.
- 작성이 완료되면 제대로 입력되었는지 검토해주세요.
- 수정사항이 있다면 수정하고, 제출해주세요.

# 스몰 프로젝트 — 웹 조작 자율 실습 (15분)

**프롬프트 예시 없이, 내 업무와 관련된 웹 작업 직접 지시해보기**<br>업무 중 자주 들어가는 웹사이트를 하나 골라, 평소 그 사이트에서 직접 하던 일을 Claude Code에게 본인의 표현으로 시켜보세요. "한 줄 지시 → 결과 확인 → 다시 요청"을 스스로 반복하는 것이 이 실습의 핵심입니다.<br>\<예시\>
- **🔋 에너지·가스** — LNG·천연가스 시세 공시 페이지에서 주간 시세 동향 수집·정리
- **⚡ 에너지·발전** — 전력거래소 홈페이지에서 오늘의 전력수급·SMP 현황을 수집해 엑셀로 정리
- **💼 영업** — 관세청 수출입 통계 또는 담당 품목 시세 페이지에서 전일 대비 변동 정리
- **📊 경영관리·재무** — 한국은행 경제통계 사이트에서 환율·금리 주요 지표를 수집해 요약
✅ 클리어 조건: 업무에서 실제로 쓰는 웹사이트에서 Claude Code가 수집해 만든 결과물 파일 1개<br>💡 막히면 원하는 결과를 더 구체적으로 다시 지시해주세요!

# 마무리 — 같은 작업을 다음엔 더 빨리

방금 한 웹 수집 작업에 시간이 걸렸다면, 한 번 더 시킬 때는 훨씬 빠르게 끝낼 수 있습니다. Claude Code에 이렇게 시켜보세요.

```javascript
방금 완료한 OOOO 작업을 다음에 또 할 수 있도록 skill 문서로 등록해줘.
```
그러면 Claude Code가 본인이 방금 한 절차를 그대로 문서화해서 저장합니다. 다음 세션에서 해당 문서를 전달하며 같은 작업을 지시하면 첫 번째보다 훨씬 빠르게 끝납니다.
