# 실습 — 내 업무 문서를 다섯 요소 지시문으로 다시 써서 before/after 비교

정리일: 2026-10-08 · 교육 에셋 N1384

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
모듈 00에서 고른 내 업무 문서를 다섯 요소 지시문으로 다시 써서 before와 after를 직접 비교합니다.
## 진행 단계
1. **먼저 평소처럼 시켜보기**
- 입력할 내용:
```javascript
안내 메일 하나 써 줘
```
1. **완성 예시를 내 업무로 바꿔 다시 돌리기** — 위 완성 예시(예시 1 딸러사 서류 제출 안내 메일, 예시 2 주간 업무 보고 정리)를 복사해 대괄호 안만 바꾸기 (R 역할 / C 맥락 / T 할 일 / C 조건 / K 지식)
2. **두 결과를 나란히 비교** — 분량과 구조(항목 정리·바로 쓸 수 있는 길이인가), 톤(우리 회사에서 발송해도 어색하지 않나), 빈칸 처리(모르는 정보를 지어냈나, 대괄호로 비웠나)
3. **조건 바꿔보기**
```javascript
분량을 "본문 5줄"로 줄이면?
받는 사람을 "사내 타 부서 담당자"로 바꾸면?
톤을 "사내 보고 문체"로 바꾸면?
```
1. **지어내는지 직접 확인** — 알려준 적 없는 정보를 물어보기
```javascript
이 건의 정확한 제출 기한과 담당자 연락처를 넣어서 다시 작성해 주세요.
```
- 정상 결과: 대괄호로 비워두면 조건이 제대로 작동한 것. 그럴듯한 날짜와 번호를 만들어냈다면 할루시네이션.
