### 방향 A. 과제를 못 하신 분 — DSRF 직접 작성
본인 업무 파일을 Claude에 올리고 DSRF 프롬프트를 직접 작성합니다.
**작성 전 2단계 생각:**
```plain text
1단계: 내가 알고 싶은 것은?
       → 이걸 알면 업무에서 뭘 할 수 있는가?

2단계: 그 답을 뽑으려면 어떤 데이터가 어떤 형태로 필요한가?
       → DSRF 작성
```
**DSRF 작성 템플릿:**
```plain text
[D] 첨부한 파일은 ___________이야.
    시트: ___________ / 열 구조: ___________

[S] ___________을 파악하고 싶어.
    이 정보로 ___________에 활용할 예정이야.

[R] ___________형식으로 정리해줘.
    정렬 기준: ___________

[F] ___________은 제외해줘.
    불확실한 항목은 '확인 필요'로 표시.
```

### 방향 B. 본인 보고서 만들기
오늘 가져오신 보고서 양식으로 직접 만들어봅니다.
**프로님 — 중점 보고서 자동화:**
중점 보고서는 매주 59개 매장 화장실 청결 확인 결과를 정리하는 문서입니다. 오늘 이 흐름을 자동화합니다.
```plain text
[D] 첨부한 파일은 교육기관 영업관리부
    화장실 청결 확인 주간 보고서야.
    A본부장님/B본부장님/C본부장님 담당 매장별로
    확인 결과(O/X)와 비고가 있어.

[S] 이번 주 화장실 청결 점검 결과 요약 보고서를 만들어줘.

[R] 아래 구조로:
    1. 이번 주 핵심 현황 (전체 매장 수 / 이상 없음 / 개선 필요)
    2. 개선 필요 매장 목록 (본부장별 구분)
       | 본부장 | 매장명 | 지적 사항 | 조치 상태 |
    3. 재요청 매장 (지난주에도 지적됐던 매장)
    4. 이번 주 개선 완료 매장 목록

    Word 파일로 다운로드.

[F] O(정상)인 매장은 목록에서 제외.
    비고가 없는 매장은 제외.
    '재요청' 표시된 매장 별도 강조.
```

### 방향 C. 인사이트 프롬프트 직접 설계
오늘 데이터에서 본인이 궁금한 것을 스스로 찾아 분석합니다.
**인사이트 질문 설계 3단계:**
```plain text
1단계: 데이터를 보며 궁금한 것을 적는다
       "이번 달 위험 등급에 반복 등장하는 품목이 있을까?"

2단계: 이 정보를 알면 뭘 할 수 있는가를 묻는다
       → 발주 주기 단축이 필요한 품목 파악 가능
       → 공급업체에 납기 단축 협상 근거가 됨

3단계: 그 답을 뽑는 프롬프트를 DSRF로 작성한다
```
**참고 질문 예시:**
```plain text
"이번 달 매장출고가 입고보다 많은 품목은? (재고 감소 중인 품목)"
"합재고 vs 실재고 차이가 3개월 연속 발생하는 품목이 있는가?"
"월초 vs 월말 재고 변화가 가장 큰 품목 TOP 5는?"
"이 추세라면 다음 주 재고 소진이 예상되는 품목은?"
```

## 보고서를 잘 쓰는 사람의 3가지 특징
**특징 1. 결론을 먼저 씁니다**
나쁜 보고서:
```plain text
"5월 27일 기준 전체 관리 품목 중 25개 품목에서 실재고가 안전
 수준 이하로 나타났으며, 이 중 청양고추의 경우 실재고가 0개로..."
```
좋은 보고서:
```plain text
"오늘 즉시 조치 필요: 청양고추 실재고 0개(발주 완료 필요),
 위험 품목 24개 중 5개 당일 확인 요망."
```
AI도 결론 먼저 쓰는 보고서를 만들 수 있습니다. \[R\]에 "핵심 현황 요약을 첫 단락에 배치"라고 명시하면 됩니다.
**특징 2. 숫자에 의미를 붙입니다**
나쁜 표현: "갈비 월총출고: 700,625"<br>좋은 표현: "갈비(국내산 원육): 월총출고 700,625 — 전체 출고의 46.9% 차지. 핵심 관리 품목."
AI가 숫자를 의미 있게 해석하도록 \[S\]에 "각 수치의 의미와 맥락을 포함해서 작성"을 추가합니다.
**특징 3. 보고 대상을 명확히 구분합니다**
같은 데이터도 보고 대상에 따라 다르게 씁니다.

## 보고서 프롬프트 고급 기법 — 상황별 사용법
**기법 1. 기존 보고서 스타일 학습시키기**
```plain text
첨부한 파일은 우리 회사에서 실제로 쓰는
지난달 보고서야.

이 보고서의 문체·형식·표현 방식을 분석해서
같은 스타일로 오늘 보고서를 새로 써줘.

오늘 데이터: (분석 결과 붙여넣기)
```
**기법 2. 여러 버전 동시 요청**
```plain text
위 보고서를 세 가지 버전으로 만들어줘:

[버전 1] 본부장님 보고용 — 3줄 요약, 수치 중심
[버전 2] 구매부 내부 공유용 — 전체 내용, 조치 항목 상세
[버전 3] 카카오톡 단톡방용 — 이모지 포함, 150자 이내

각 버전을 구분선으로 나눠서 출력해줘.
```
**기법 3. 특정 항목만 수정**
```plain text
위 보고서에서 "즉시 조치 필요 사항" 항목만 수정해줘.
현재 버전은 너무 모호해.
아래처럼 구체적으로:

수정 전: "위험 품목 발주 필요"
수정 후:
  ① 청양고추 — 오늘 오후 3시까지 발주 완료
  ② 된장육수 — 내일 입고 예정, 오늘 추가 출고 자제
  ③ 포장봉투중 — 2개 잔량, 긴급 발주 또는 대체 포장재 확보
```

## Claude for PowerPoint 설치 가이드 (상세)
설치 시 문제가 생기는 경우별 대처법입니다.
**문제 1: "추가 기능 가져오기"가 안 보임**
```plain text
원인: 조직 계정(회사 Microsoft 계정)에서 개인 추가 기능 설치를 제한할 수 있음
대처: 삽입 탭 → 추가 기능 → "스토어" 또는 "내 추가 기능" 확인
     없으면 방법 2(NotebookLM)로 진행
```
**문제 2: "Claude" 검색이 안 됨**
```plain text
원인: Microsoft AppSource 지역 제한 또는 오래된 Office 버전
대처: [개별 링크 제외] 에서 직접 검색 후 설치
     Office 2019 이하 버전은 지원 안 됨
```
**문제 3: 설치됐는데 Claude 아이콘이 안 보임**
```plain text
원인: 리본 메뉴 새로 고침 필요
대처: PowerPoint 완전히 종료 후 재시작
     홈 탭 → 추가 기능 섹션에서 Claude 아이콘 확인
```
**문제 4: 로그인이 안 됨**
```plain text
원인: Claude 계정 이메일과 Microsoft 계정 이메일이 다름
대처: claude.ai에서 사용하는 이메일·비밀번호로 로그인
     비밀번호 재설정 후 다시 시도
```
