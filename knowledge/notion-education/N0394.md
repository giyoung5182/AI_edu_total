# (향후 과제) 6장 설계서 작성

정리일: 2026-10-08 · 교육 에셋 N0394

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 2 경영진 보고서를 발표자료로 만들기 전에, 사람이 장 순서를 정하고 ChatGPT에는 슬라이드 없이 설계서 텍스트(4블록)만 쓰게 합니다.
## 진행 단계
1. **예측** — \[F\] 예측 칸: 6장 헤드메시지만 이어 읽으면 결정 요청까지 도달할까
2. **빈 양식 확인** — 블록 1 맥락 / 블록 2 장별 설계(6장) / 블록 3 디자인 규격 / 블록 4 산출 규칙
3. **장 순서 정하기** — 1장 요약 · 2\~5장 근거 영역별 · 6장 제안·측정 계획·결정 요청. 각 장 "다음 장 연결"(E열)에 독자의 다음 질문을 먼저 적기
4. **설계서 요청** — 채팅 P4-보고서에 프롬프트 붙여넣기 → `2장 [영역]`\~`5장 [영역]`을 정한 영역 이름으로 교체 → 빈 양식 붙여넣기 → Enter
- 입력할 내용: "위 경영진 보고서와 근거표로 발표자료 설계서를 작성해 줘. 슬라이드는 아직 만들지 말 것. 설계서 텍스트만." (이하 교안 참고)
- 정상 결과: 장 1\~6 행의 메시지·증거·시각 형식·다음 장 연결 4칸 모두 채움 + 헤드메시지 연결 점검 칸 기록
## 막히는 지점
- 대화가 끊겼으면 새 채팅 → 근거표·경영진 보고서 파일 첨부 → 첫 줄을 "첨부한 경영진 보고서와 근거표로"로 바꿔 전송
