# PoC 경로 A Step 2. 민감정보 제거 (Claude Code)

정리일: 2026-10-08 · 교육 에셋 N0309

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
샘플 CSV에서 개인 식별 정보와 개인 의견을 제거해 정제된 cleaned_data.xlsx를 만든다.
## 진행 단계
1. **실습 폴더 준비** — poc 폴더에 sample_raw_data.csv(또는 내 실제 파일)를 저장하고 Claude Code의 작업 폴더로 지정한다.
- 정상 결과: poc 폴더에 원본 파일이 있다.
2. **정제 프롬프트 입력** — Claude Code에 컬럼 처리 기준(날짜 유지, 개인 식별 정보 삭제, 팀/부서 유지, 수치 유지, 개인 의견/피드백 삭제)과 출력 컬럼 순서(날짜 → 팀/부서 → 수치 데이터)를 알려 준다.
- 입력할 내용:
```javascript
폴더의 sample_raw_data.csv에서 민감정보를 제거해서
정제된 파일을 만들어줘.

사전 작업:
파일을 먼저 읽어서 실제 컬럼명을 확인한 뒤,
아래 기준에 따라 유지/삭제를 판단해줘.

컬럼 처리 기준 (역할 기반):
- 날짜 관련 컬럼 ✅ 유지
- 개인 식별 정보 (이름, 사번, ID 등) ❌ 삭제
- 팀/부서 정보 ✅ 유지
- 수치 데이터 (검색량, 매출 등) ✅ 유지
- 개인 의견/피드백 ❌ 삭제

출력 컬럼 순서:
날짜 → 팀/부서 → 수치 데이터 (파일에 있는 순서대로)

요청:
1. 실제 컬럼 목록과 유지/삭제 판단 결과를 먼저 표로 보여줘
2. 위 기준으로 정제된 cleaned_data.xlsx를 폴더에 저장해줘
3. 완료 후 정제 전/후 컬럼 수와 행 수를 요약해줘
```
3. **결과 확인** — 유지/삭제 판단 표가 기준과 맞는지 본다.
- 정상 결과: poc 폴더에 cleaned_data.xlsx가 생기고, 파일을 직접 열었을 때 이름·사번·피드백 컬럼이 사라져 있다.
## 막히는 지점
- 담당팀을 개인정보로 잘못 판단했다면: "담당팀은 개인정보가 아니라 유지해야 해"
- 실제 업무 파일에는 고객명·사번 같은 민감정보가 있을 수 있으므로, 보안 정책상 AI 도구에 올려도 되는 데이터인지 먼저 확인하고 확실하지 않으면 샘플 데이터로 실습한다.
