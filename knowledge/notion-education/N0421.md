## 이 실습으로 하는 것
AI에게 프롬프트 한 번으로 플레이 가능한 웹 게임을 만들고, 피드백으로 고쳐 본다.
## 진행 단계
1. **뱀 게임 만들기**
- 입력할 내용:
```javascript
HTML, CSS, JavaScript로 동작하는 뱀 게임(Snake Game)을 만들어줘.

- 방향키로 뱀을 조종
- 먹이를 먹으면 뱀이 길어지고 점수 증가
(이하 교안 참고)
```
1. **피드백으로 개선** — 아래와 같이 한 줄씩 요청한다.
- 입력할 내용:
```javascript
뱀의 속도를 좀 더 빠르게 해줘.
```
```javascript
배경에 격자 무달를 넣어줘.
```
```javascript
최고 점수(하이스코어)를 기록하는 기능을 추가해줘.
```
1. **다른 게임 도전(시간 여유 시)** — 벽돌깨기, 두더지 잡기, 카드 매칭(짝맞추기) 프롬프트를 교안에서 고른다.
