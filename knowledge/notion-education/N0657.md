# 이월 실습 B. 슬라이드 자동 생성

정리일: 2026-10-08 · 교육 에셋 N0657

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
방금 만든 보고서를 바탕으로 같은 채팅에서 6장짜리 슬라이드를 만들고 차트 이미지를 삽입함.
## 진행 단계
1. **프롬프트 입력** — 보고서를 만든 같은 채팅창에서 이어서 붙여넣기(같은 채팅이면 AI가 보고서 내용을 기억하므로 별도 설명 불필요)
- 입력할 내용: 6장 구성 요청 — 1장 표지 / 2장 핵심 현황 요약(KPI 3개 카드) / 3장 재고 위험 현황 표(색 구분) / 4장 불일치 TOP3 표 / 5장 즉시 조치 사항 / 6장 다음 주 주의 관찰 포인트. 디자인은 깔끔·전문적, 파란색 계열 메인, PowerPoint 파일로 다운로드
2. **차트 삽입** — 3회차에서 만든 차트 PNG 3개(막대·도넛·묶음막대)를 해당 슬라이드에 직접 삽입
- 3장 → 도넛 차트, 4장 → 묶음 막대 차트, 2장 → KPI 수치 확인
