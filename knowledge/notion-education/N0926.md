# 1부. Claude Code란 무엇인가 (15분)
---
## 1-1. 한 줄 정의
> **Claude Code = 내 컴퓨터의 폴더를 직접 읽고, 파일을 만들 수 있는 Claude**
지금까지 쓰던 Claude(claude.ai)는 브라우저 안에 있었습니다. 자료를 보여주려면 내가 복사해서 붙여넣거나 파일을 업로드해야 했습니다. Claude Code는 **내 컴퓨터 안에서 실행**됩니다. 그래서 폴더를 통째로 맡길 수 있습니다.
```plain text
claude.ai (지금까지)
  나 → 자료를 복사·업로드 → Claude가 읽음 → 답변을 다시 복사해서 문서로 옮김

Claude Code (오늘부터)
  나 → "이 폴더의 파일들 검토해줘" → Claude가 알아서 열어 읽음
     → 결과를 파일로 저장까지
```
**차이는 "누가 자료를 나르느냐"입니다.** 지금까지는 사람이 날랐고, 이제는 AI가 직접 가져다 봅니다.

## 1-4. 터미널이 뭐고, 왜 터미널을 쓰나
```plain text
터미널 = 마우스 클릭 대신 글자로 컴퓨터에 지시하는 창

영화에서 해커들이 검은 화면에 글자를 치는 그 장면입니다.
오전에 Cursor 아래쪽에서 npm run dev를 쳤던 그 창이 터미널입니다.
```
**왜 버튼이 아니라 터미널인가요.** 버튼은 만들어둔 기능만 누를 수 있습니다. 터미널은 **말로 시키는 것이라 기능이 정해져 있지 않습니다.** Claude Code가 폴더를 읽고, 판단하고, 파일을 만들고, 그 결과를 다시 읽는 식으로 여러 일을 이어서 할 수 있는 이유입니다.
**터미널 명령어를 외울 필요는 없습니다.** 오늘 외울 것은 `claude` 한 단어뿐이고, 나머지는 전부 한국어 문장입니다.

## 2-2. STEP 1 — PowerShell 열기
PowerShell은 이미 써봤습니다. 오전에 Cursor 터미널 맨 앞에 있던 `PS [로컬 경로] 그 `PS`가 PowerShell입니다.
```plain text
① 키보드 Windows 키를 누릅니다
② powershell 이라고 입력합니다
③ 검색 결과에서 [Windows PowerShell]을 클릭합니다
```
**열리면 이런 화면입니다**
```plain text
Windows PowerShell
Copyright (C) Microsoft Corporation. All rights reserved.

PS [로컬 경로]>
```
**관리자 권한으로 실행할 필요 없습니다.** 그냥 클릭해서 여는 것으로 충분합니다.
**PowerShell과 CMD 구분하기**
```plain text
PowerShell   PS [로컬 경로]>     ← 맨 앞에 PS
CMD          [로컬 경로]>        ← PS 없음
```
`PS`가 안 보이면 CMD라는 다른 창입니다. 창을 닫고 다시 여세요. 두 창은 명령어 규칙이 달라서 구분이 중요합니다.
---
## 2-3. STEP 2 — 설치 명령 실행
```plain text
아래를 그대로 복사해서 붙여넣고 Enter

irm [개별 링크 제외] | iex
```
**명령어 뜯어보기**
```plain text
irm    Invoke-RestMethod의 줄임말. 인터넷에서 파일을 받아와라
|      파이프. 앞에서 받은 것을 뒤로 넘겨라
iex    Invoke-Expression의 줄임말. 넘어온 것을 실행해라

즉 "설치 파일을 받아서 바로 실행해라"는 뜻입니다.
```
**붙여넣기가 안 될 때**
```plain text
PowerShell에서는 Ctrl+V가 안 먹는 경우가 있습니다.
→ 창 안에서 오른쪽 클릭을 하면 붙여넣기가 됩니다.
```
**화면에서 일어나는 일**
```plain text
① 다운로드 진행 표시가 나타납니다
② 설치 위치와 진행 상황이 여러 줄 올라갑니다
③ 1~2분 정도 걸립니다
④ 설치 완료 안내가 나오고 입력 커서(PS ...>)가 돌아옵니다
```
멈춘 것처럼 보여도 기다리세요. 실제로 내려받는 중입니다.
---
## 2-4. STEP 3 — PowerShell 창을 새로 열기
**이 단계를 건너뛰면 다음 단계에서 반드시 오류가 납니다.**
방금 설치한 프로그램을 컴퓨터가 인식하려면 창을 새로 열어야 합니다. 프로그램의 위치 정보가 **창을 열 때 한 번만** 읽히기 때문입니다.
```plain text
① 지금 쓰던 PowerShell 창을 완전히 닫습니다 (오른쪽 위 X)
② Windows 키 → powershell 입력 → 다시 실행합니다
```

**앞으로 업데이트는 신경 쓰지 않아도 됩니다.** 새 버전이 나오면 백그라운드에서 알아서 갱신됩니다.

## 3-2. STEP 2 — 로그인 방식 선택
```plain text
① 로그인 방식을 묻는 목록이 나타납니다
② 방향키 ↑ ↓ 로 이동합니다
③ Claude 계정으로 로그인하는 항목에 놓고 Enter를 누릅니다
```
**우리는 각자 Claude Pro 계정이 있으므로 계정 로그인 방식을 고릅니다.** API 키를 넣는 방식은 별도 결제가 필요하므로 오늘 쓰지 않습니다.
**마우스는 쓸 수 없습니다.** 터미널이라 방향키와 Enter로만 고릅니다. 목록에서 마우스로 클릭해도 선택되지 않으니 당황하지 마세요.
---
## 3-3. STEP 3 — 브라우저에서 승인
```plain text
① 브라우저가 자동으로 열립니다
② 평소 쓰던 Claude 계정으로 로그인합니다
   (이미 로그인되어 있으면 이 단계는 건너뜁니다)
③ 접근을 허용하겠냐는 화면에서 승인 버튼을 누릅니다
④ 성공 메시지가 뜨면 브라우저를 닫고 PowerShell 창으로 돌아옵니다
```
**브라우저가 안 열리면** 터미널 화면에 주소가 함께 표시됩니다. 그 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요.
**다른 계정으로 로그인되어 있으면** 브라우저에서 계정을 바꾼 뒤 다시 승인하세요. 회사 계정과 개인 계정이 섞여 있는 경우 자주 발생합니다.

## 3-4. STEP 4 — 로그인 확인 후 일단 종료
터미널 화면이 대화 입력창으로 바뀌었으면 로그인 완료입니다. **로그인은 한 번만 하면 됩니다.** 다음부터는 `claude`만 입력하면 바로 실행됩니다.
로그인만 확인했으면 여기서 한 번 종료합니다. 실습은 **실습 폴더 안에서** 시작해야 하기 때문입니다.
```plain text

/exit

또는 Ctrl + C 를 두 번 누릅니다.
```
**왜 폴더가 중요한가요.** Claude Code는 **실행한 위치의 폴더**를 자기 작업 공간으로 인식합니다. 엉뚱한 곳에서 실행하면 우리 실습 자료를 못 봅니다. **이것이 Claude Code를 쓸 때 가장 중요한 감각입니다.** 오전에 터미널 경로를 확인했던 것과 같은 원리입니다.

## 6-1. 첫 번째 — 이 폴더에 뭐가 있는지 물어보기
```plain text
입력창에 그대로 입력하고 Enter

이 폴더에 어떤 파일들이 있는지 읽어주고, 각 파일 마다의 주제를 한 줄씩 표로 정리해줘.
```
**화면에서 일어나는 일**
```plain text
① 권한을 묻는 메시지 → 1번 또는 Enter
② Claude가 폴더 목록을 확인합니다
③ data 폴더에 클레임 10건, 그리고 매뉴얼 파일이 있다는 정리가 나옵니다
```
**내가 아무것도 업로드하지 않았는데 Claude가 폴더 내용을 알고 있습니다.** 이것이 claude.ai와의 첫 번째 차이입니다.
---
## 6-2. 두 번째 — 파일 하나 읽히기
```plain text
data 폴더의 클레임_01_강남점.txt를 읽고
어떤 내용인지 3줄로 요약해줘.
```
강남점의 정육 변색 건이 요약되어 나옵니다.
**여기까지는 claude.ai에 파일을 올려서 요약시키는 것과 결과가 비슷합니다.** 차이는 "내가 올리지 않았다"는 점뿐입니다.
> **파일 이름을 정확히 치기 번거로우면 ****`@`****를 쓰세요.** 입력창에서 `@`를 누르면 폴더 안 파일 목록이 뜨고, 골라서 넣을 수 있습니다. 오타로 "파일을 찾을 수 없다"는 답을 받는 일이 없어집니다.
---
## 6-3. 세 번째 — 여러 파일을 한 번에 세어보기
```plain text
data 폴더의 클레임이 총 몇 건인지 세고,
매장별로 몇 건씩 접수됐는지 표로 정리해줘.
```
**여기서 달라집니다. 화면을 잘 보세요.**
```plain text
① Claude가 파일 목록을 확인합니다
② 10개 파일을 차례로 열어 읽는 모습이 화면에 나타납니다
   (Read 또는 파일명이 줄줄이 지나갑니다)
③ 매장별 건수를 세어 표로 만들어 줍니다

  → 수원영통점 2건, 부천중동점 2건, 나머지 각 1건
```
**파일 10개를 하나씩 열어 확인한 것입니다.** 사람이 하면 10번 클릭할 일을 한 문장으로 끝냈습니다.
여기서 나온 **2건씩 접수된 매장을 기억해 두세요.** 3권에서 반복 접수 매장을 골라내는 에이전트를 만들 때 그대로 이어집니다.

