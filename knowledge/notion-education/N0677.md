# 실습 3. 새 대화 인수인계 5칸(P1-4)

정리일: 2026-10-08 · 교육 에셋 N0677

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
긴 작업을 새 대화로 옮길 때 5칸 양식의 인수인계 메모를 만들고, 자료 재첨부 전후로 새 대화가 어떻게 달라지는지 관찰합니다.
## 진행 단계
1. **먼저 예측** — AI 초안의 "검증된 결과" 칸이 실제보다 넓게 적힐까? 파일을 다시 첨부하지 않고 조항 원문을 물으면?
2. **AI에게 초안만 맡기기** — 실습 2의 대화 ③에서 입력
- 입력할 내용:
```plain text
이 대화를 새 대화로 옮기려고 해. 아래 5칸 양식으로 인수인계 메모 초안을 써줘.
① 현재 목표
② 확정 기준
③ 원자료(파일명과 조항 번호)
④ 검증된 결과
⑤ 미확인 항목
규칙:
- 이 대화에 실제로 나온 내용만 쓴다.
- ④에는 "사람이 원문과 대조했다"고 이 대화에서 확인된 것만 쓰고, 그렇지 않으면 ⑤로 보낸다.
- 각 칸은 3줄 이내 개조식.
```
1. **사람이 확정** — P1-4 AI 초안 요지 열에 옮기고(칸을 더블클릭 후 붙여넣기) 사람 확정본 열에 칸마다 3줄 이내로 수정. ④는 P1-3에서 직접 대조한 것만 남기고 나머지는 ⑤로 이동
2. **새 대화 ④ — 파일 없이 메모만** — 확정한 5칸을 붙여 넣고 ③ 원자료의 조항 하나를 원문 그대로 인용해 달라고 요청. 결과를 "재첨부 전" 칸에 기록
3. **규정집 재첨부 후 다시 요청** — 같은 조항 원문 인용 + ① 현재 목표에 맞는 안내문 5줄 이내(② 확정 기준 준수, ⑤ 미확인 항목은 확정처럼 쓰지 않기). 결과를 "재첨부 후" 칸과 "② 확정 기준 준수 체크"에 기록
- 정상 결과: 재첨부 전에는 "파일이 없어 확인할 수 없다"류 답(또는 원문처럼 보이는 인용 → 원문 대조 필요), 재첨부 후에는 조항 원문 인용 + 5줄 이내 안내문
## 막히는 지점
- AI 초안 ④에 모두 "검증됨"으로 들어가면: "④ 칸에서 '사람이 원문과 대조했다'는 말이 이 대화에 없는 줄은 모두 ⑤로 옮겨서 다시 써줘."
- 새 대화 답이 ② 확정 기준을 어기면 해당 기준만 고치고 나머지는 유지하도록 요청
- 메모가 길면 칸마다 3줄 이내로 줄이되 ②·⑤는 지우지 않음
