# 실습 1. 문서 처리 페이지 만들기

정리일: 2026-10-08 · 교육 에셋 N0624

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
PDF를 업로드하면 청크 카드 목록이 나타나는 문서 처리 페이지를 Claude Code로 추가하고, 손상된 조각을 직접 찾아봅니다.
## 진행 단계
1. **대화 초기화와 프롬프트 입력** — 터미널 Claude Code에서 `/clear`를 실행한 뒤 프롬프트를 입력하고 승인 요청을 읽으며 진행합니다.
- 입력할 내용:
```javascript
지금 프로젝트에 문서 처리 페이지를 추가해 주세요. 요구사항입니다.

1. /documents 경로에 새 페이지를 만들어 주세요.
   기존 채팅 페이지 상단에 두 페이지를 오가는 메뉴도 넣어 주세요.

2. 페이지에서 PDF 파일을 업로드하면 서버가 다음을 수행합니다.
   - PDF에서 텍스트를 추출(파싱)합니다.
   - 텍스트를 청크로 자릅니다. 기본값: 청크 크기 500자, 오버랩 50자.
   - 청크 크기와 오버랩은 페이지의 입력칸에서 바꿀 수 있게 해 주세요.
(이하 교안 참고)
```
1. **서버 재시작** — 터미널 B에서 Ctrl+C 후 실행 명령을 다시 입력합니다.
2. **PDF 업로드** — 브라우저에서 [개별 링크 제외] 을 열고 "지진 국민행동요령" PDF를 업로드합니다.
- 정상 결과: 청크 카드 목록이 나타납니다.
3. **원문 대조** — 카드 세 장을 눌러 보고 원문 PDF의 어느 부분에서 온 조각인지 대조합니다.
4. **손상 조각 찾기** — 표가 한 줄로 붙은 것, 그림 캡션만 남은 것, 문장이 어색하게 끊긴 것이 후보입니다. 찾은 조각의 청크 번호를 메모합니다.
## 막히는 지점
- 업로드 후 아무 반응 없음: 처리 시간 소요. 창①의 로그에서 "파싱 시작"이 보이면 정상입니다.
- 청크에 글자가 깨짐: 창②에 로그와 함께 "한글이 깨집니다. 인코딩을 확인해 주세요"라고 요청합니다.
- 특정 PDF만 파싱 실패: 스캔본(이미지) PDF입니다. 다른 문서로 진행하고 강사에게 알립니다.
- 페이지 이동 메뉴가 안 보임: 새로고침(Ctrl+F5)을 합니다.
