### 실습 진행 방법
**STEP 1.** 자동화할 업무 1가지 결정
3권에서 작성한 상황 카드 프롬프트를 사용하거나, 지금 새로 작성합니다.
```plain text
판단 기준:
✅ 매일 또는 매주 반복하는가?
✅ 구글 시트(또는 엑셀) 데이터를 다루는 작업인가?
✅ 입력·집계·분류·이메일 발송 중 하나인가?
→ 해당되면 GAS 자동화 가능
```
**STEP 2.** 3권 템플릿으로 Claude에 요청
파일 구조·셀 위치·동작 순서·메뉴 구성을 포함해서 요청합니다.
**STEP 3.** 코드 받으면 3가지 확인 후 설치
```plain text
확인 1: 시트명 일치 여부
확인 2: 셀 주소 일치 여부
확인 3: 헤더 순서 일치 여부
→ 확인 후 Apps Script에 붙여넣기 → 저장 → 테스트
```
**STEP 4.** 오류 나면 오류 메시지 복사 → Claude에 전달
**STEP 5.** 정상 작동 확인 → 단톡방에 결과 공유

```plain text
  A열: 날짜 / B열: 매장명 / C열: 품명 / D열: 수량 / E열: 유형(추가·취소)

시트 2: '발주이력'
  제출된 발주 내역이 쌓이는 곳
  헤더: A=제출일시, B=날짜, C=매장명, D=품명, E=수량, F=유형

이 구조로 [발주입력] 시트에서 데이터를 읽어서
[발주이력] 시트에 한 줄씩 저장하는 GAS 함수를 만들어줘."
```

### 막히는 상황별 대처
**"Apps Script를 열었는데 어제 만든 코드가 없어요"**
```plain text
원인: 어제 다른 파일에서 Apps Script를 열었거나
      지금 다른 파일이 열려 있음

해결:
오늘 만든 "교육기관_지출결의서_자동화" 파일을 열고
거기서 [확장 프로그램] → [Apps Script] 클릭

Apps Script는 파일마다 따로 연결됩니다.
A 파일에서 만든 코드는 B 파일에서 보이지 않습니다.
```
**"설치했는데 메뉴가 안 나와요"**
```plain text
해결 순서:
① F5로 새로고침
② 여전히 없으면: Apps Script 편집창 열기
   → 상단 함수 드롭다운에서 "onOpen" 선택
   → ▶ 실행 버튼
   → 권한 허용 팝업 나오면 허용
③ 구글 시트로 돌아와서 확인
```
**"버튼이 있는데 클릭해도 아무 반응이 없어요"**
```plain text
원인: 권한 허용이 안 된 상태
해결:
Apps Script 편집창에서 함수 하나 선택 → ▶ 실행
→ 권한 허용 팝업 → 허용
→ 이후 메뉴에서 클릭해도 정상 실행됨
```
**"코드 수정이 필요한 것 같은데 어떻게 해야 하나요"**
```plain text
Claude에게:
"내 코드 일부를 수정해야 해.

[현재 코드의 해당 부분]
const SHEET_FORM = '지출결의서';  ← 현재

[변경하고 싶은 것]
내 파일에서 시트 이름이 '발주폼'으로 되어있어.
이 부분만 수정해줘.
코드 전체를 다시 주지 말고 수정 부분만 알려줘."
```

### GAS 자동화 핵심 원칙 복습
```plain text
원칙 1. 구글 시트(.gsheet) 형식에서만 작동
        .xlsx 파일에서는 Apps Script 실행 안 됨
        → 드라이브에서 새로 만든 구글 시트에서만

원칙 2. 시트명·셀 주소는 정확히 일치해야 함
        공백 하나, 대소문자 하나 달라도 오류
        → 코드 먼저 확인하고 실제 탭 이름 대조

원칙 3. 헤더 순서 = 코드의 저장 순서
        제출이력 헤더 A~N 순서 = appendRow 순서
        → 데이터가 엉뚱한 열에 들어가면 이것부터 확인

원칙 4. 오류 메시지는 그대로 복사해서 Claude에
        "뭔가 안 된다"가 아니라 오류 코드 전체 복붙
        → Claude가 정확한 원인을 바로 찾아줌

원칙 5. 테스트는 반드시 실제 데이터로
        "설치됐다"와 "정상 작동한다"는 다름
        → 작은 데이터로 먼저 테스트 → 결과 직접 확인
```

### 5회차 예고 — Make.com으로 외부 연결
GAS가 "구글 시트 안에서의 자동화"라면, Make.com은 "앱과 앱 사이를 연결하는 자동화"입니다.
```plain text
GAS가 할 수 있는 것:
구글 시트 데이터 처리 + 구글 이메일 발송

Make.com이 추가로 할 수 있는 것:
카카오 알림톡 자동 발송
슬랙·텔레그램 메시지 자동 발송
네이버 폼 → 구글 시트 연동
파일 변경 감지 → 자동 알림

5회차 실습 예정:
재고 위험 품목 자동 분석 → 카카오 알림톡 자동 발송
업무보고 완성 → 단톡방 자동 공유
```
**5회차 전 준비사항:**





과제

내용




① Make.com 계정 생성

make.com 접속 → \[Get started free\] → 무료 가입




② 오늘 GAS 자동화 실제 업무에 1번 사용

정상 작동 여부 확인 후 단톡방에 결과 공유




③ 자동 알림 희망 채널 1가지 결정

카카오·슬랙·이메일 중 어디로 받고 싶은지




④ "받고 싶은 자동 알림 1가지"

단톡방에 미리 공유 (예: "재고 위험 품목 명단을 매일 아침 카카오로")
