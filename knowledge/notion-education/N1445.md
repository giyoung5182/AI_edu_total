# 실습① — NotebookLM 노트북 만들기

정리일: 2026-10-08 · 교육 에셋 N1445

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
NotebookLM에 공개 자료를 소스로 넣고, 범위를 한정해 질문한 뒤 각주로 원문을 대조합니다.
## 진행 단계
1. **새 노트북 만들기** — 노트북 이름을 입력합니다.
- 입력할 내용: `교육기관 29 공개자료`
2. **자료 넣기** — 교안에 적힌 웹사이트 주소를 소스로 등록합니다.
3. **읽혔는지 확인**
- 입력할 내용: `등록한 자료의 목차를 알려줘`
4. **범위를 한정해서 질문**
- 입력할 내용:
```javascript
등록한 자료 안에서만 답해 주세요.
근거 위치를 함께 표시해 주세요.
자료에 없으면 「자료에 없음」이라고 답해 주세요.

이 자료에 실린 2024년 조정개시율과 조정성공률을 알려줘
```
5. **각주를 눌러 원문과 대조** — 타이핑 없이 답에 붙은 각주 번호를 눌러 원문 위치로 이동해 확인합니다.
6. **오디오 개요 미리 걸어두기** — 오디오 개요 생성 버튼을 눌러 둡니다.
## 막히는 지점
- 자료가 개편되어 주소가 바뀐 경우 강사가 현장에서 대체 주소를 안내합니다.
