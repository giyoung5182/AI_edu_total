## 이 실습으로 하는 것
5권에서 쓴 지시문을 CLAUDE.md 파일로 옮겨 저장합니다. 달라지는 것은 마크다운 제목(##)으로 나누고 파일 경로를 넣는 두 가지뿐입니다.
## 진행 단계
1. **블록 대응** — \[역할\]·\[맥락\]→## 이 폴더가 하는 일 / 설계서 \[4\]→## 범위 밖 / \[지식\]→## 폴더 구조 / \[수행할 일\]→## 처리 순서 / \[제약\]→## 반드시·## 절대 금지 / \[예외 처리\]→## 멈추고 물어야 하는 상황 / \[완료 판정\]→## 완료 판정 / \[예시\]→## 변환 예시
2. **CLAUDE.md**** 작성** — 교안 완성본 예시 일부:
```javascript
# 매체 실적 통합 작업

## 이 폴더가 하는 일

매체사별 실적 파일을 하나의 통합 표로 만든다.
처리 과정에서 발견된 문제를 함께 보고한다.

## 범위 밖

- 성과 해석과 코멘트 작성
- 보고서 대외 발송
- 원본 파일 수정

## 폴더 구조

- `01_원본/` 매체사 실적 파일. 읽기만 한다
- `02_기준/` 컬럼 기준표와 데이터 사전
- `03_결과/` 통합 표를 저장한다
- `04_기록/` 변경 내역과 확인 필요 목록을 저장한다

(이하 교안 참고)
```
