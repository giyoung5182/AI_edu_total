# 나만의 에이전트 만들고 실행하기

정리일: 2026-10-08 · 교육 에셋 N0479

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
설계한 4축으로 나만의 에이전트를 만들고 실제 업무 요청을 넣어 다듬습니다.
## 진행 단계
1. **폴더에서 ****`claude`**** 실행**
2. **4축을 적어 에이전트 생성** — 이름(name)은 영어 소문자와 하이픈으로 요청합니다.
- 입력할 내용: 교안의 '에이전트 제작 프롬프트'(\[내가 만들 Agent\]를 .claude/agents/ 폴더에 만들어줘 / \[역할\] / \[정보 범위\] / \[출력 형식\] / \[페르소나 및 판단 기준\] …) (이하 교안 참고)
3. **Claude Code 재시작** — 새 에이전트가 등록되게 합니다.
4. **이름으로 불러 업무 요청** — 예: "OO 에이전트한테 이거 맡겨줘"
5. **결과 다듬기** — 원하는 형식이 아니면 예시를 주며 고칩니다.
## 막히는 지점
- 자료가 필요한 에이전트라면 폴더 안에 관련 파일을 넣어 두고 시킵니다.
