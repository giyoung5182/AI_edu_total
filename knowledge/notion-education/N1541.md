단순히 질문에 답하는 챗봇(Chatbot)과 달리, **AI 에이전트**는 스스로 계획을 세우고, 도구(검색, 엑셀, 이메일 등)를 사용하여 복합적인 업무를 수행하는 '지능형 비서'입니다.

### 🧠 에이전트의 작동 원리
AI 에이전트는 신입 사원에게 업무를 맡기는 과정과 매우 흡사합니다. 아래 그림을 통해 그 흐름을 직관적으로 이해해 봅시다.
[원본 이미지 제외]
1. **인식 (Perception):** "최근 가계 부채 데이터 좀 봐줘."라는 지시를 인식합니다.
2. **계획 (Planning):** "데이터를 어디서 찾지? 한국은행 ECOS? 뉴스? 찾은 다음엔 전월 대비 증감율을 계산해야겠군."이라며 계획을 수립합니다.
3. **행동 (Action - Tool Use):** 젠스파크(Genspark)로 최신 정보를 검색하고, 엑셀(Excel)로 데이터를 분석하는 등 실제 도구를 사용합니다.
4. **결과 (Output):** "보고서 초안이 완성되었습니다."라며 최종 결과물을 제출합니다.

### ✅ AI Agent란 무엇인가?
**AI Agent**는 인간의 명령을 받아 스스로 **목표를 달성하기 위한 행동을 수행하는 인공지능 시스템**입니다.
즉, 단순히 “질문에 답하는 AI”가 아니라, **상황을 인식하고, 판단하며, 도구를 사용해 문제를 해결하는 존재**입니다.

### VS Code + Codex 설치 가이드
이번 단계에서는 Visual Studio Code 안에서 Codex를 사용하는 방법을 실습합니다.
Codex는 OpenAI의 코딩 에이전트로, 사용자가 작성한 요청을 바탕으로 프로젝트 파일을 읽고, 코드를 수정하고, 필요한 작업을 단계적으로 수행할 수 있도록 도와줍니다.
기존 ChatGPT가 브라우저에서 코드를 설명하거나 생성해주는 방식이었다면, VS Code Extension 방식은 실제 개발 환경 안에서 Codex를 바로 사용할 수 있다는 점이 다릅니다.
즉, 개발자가 작업 중인 코드 파일과 폴더 구조를 보면서 Codex에게 기능 구현, 오류 수정, 리팩토링, 코드 설명 등을 요청할 수 있습니다.

### VS Code의 장점
1. **경량과 속도**:
- VS Code는 가볍고 빠르게 실행됩니다. 대규모 IDE와 비교했을 때 더 적은 자원을 사용하여 신속한 코드 편집이 가능합니다.
2. **확장성**:
- 다양한 확장(Extensions)을 통해 기능을 쉽게 추가할 수 있습니다. Python, JavaScript, HTML, CSS 등 여러 언어에 대한 지원을 통해 개발 환경을 사용자 맞춤형으로 구성할 수 있습니다.
3. **통합 터미널**:
- 내장된 터미널 기능을 통해 코드 실행, Git 명령어 사용, 패키지 관리 등을 IDE 내부에서 바로 할 수 있습니다. 이로 인해 작업 흐름이 훨씬 매끄럽습니다.
4. **Git 통합**:
- Git과의 통합이 잘 되어 있어 버전 관리 작업이 용이합니다. 변경 사항을 쉽게 확인하고, 커밋하거나 푸시할 수 있습니다.
5. **디버깅 기능**:
- 강력한 디버깅 도구를 제공하여 코드 실행 중 오류를 쉽게 찾고 수정할 수 있습니다. 중단점 설정, 변수 검사 등의 기능이 포함되어 있습니다.
6. **다양한 테마와 커스터마이징**:
- 다양한 색상 테마와 레이아웃을 제공하여 사용자 취향에 맞게 편집기를 꾸밀 수 있습니다. JSON 파일을 통해 세부 설정도 가능합니다.
7. **강력한 IntelliSense**:
- 코드 자동 완성, 문서화, 변수 및 함수 제안 기능이 제공되어 개발 생산성을 높여줍니다. 특히 자주 사용하는 라이브러리의 함수에 대한 정보도 자동으로 표시됩니다.
8. **마크다운 지원**:
- 마크다운 문서 작성 및 미리보기가 가능하여 문서화 작업이 편리합니다. 주석 및 README 파일 작성 시 유용합니다.
9. **크로스 플랫폼**:
- Windows, macOS, Linux 등 다양한 운영 체제에서 동일한 사용자 경험을 제공합니다. 어느 환경에서든 일관된 작업이 가능합니다.
10. **커뮤니티와 지원**:
- 활발한 사용자 커뮤니티가 있으며, 많은 자료와 튜토리얼이 온라인에 존재합니다. 문제 해결 시 도움을 받을 수 있는 리소스가 풍부합니다.
이런 다양한 장점 덕분에 VS Code는 많은 개발자들에게 선호되는 편집기입니다. 프로그래밍을 시작하는 초보자부터, 전문 개발자에 이르기까지 폭넓은 사용자를 위한 도구입니다.

## **STEP 2. Visual Studio Code Extension 으로 Codex 이용하기**
먼저 Visual Studio Code를 실행한 뒤, 왼쪽 사이드바에서 Extensions 아이콘을 클릭합니다.
Extensions 화면은 VS Code에서 사용할 수 있는 다양한 확장 프로그램을 검색하고 설치하는 공간입니다.
검색창에 \`codex\`를 입력합니다.
