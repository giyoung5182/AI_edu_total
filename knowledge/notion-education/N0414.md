# 실습 4. R&R 정의서 및 RACI 작성

정리일: 2026-10-08 · 교육 에셋 N0414

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
공사 데이터 품질 활동별 RACI 매트릭스와 데이터 매니저 R&R 정의서를 작성한다.
## 진행 단계
1. **RACI 이해** — R 실행 / A 최종 책임 / C 협의 / I 보고.
2. **RACI 표 완성** — 참여자(데이터 오너·데이터 매니저·데이터 입력자·IT 담당·거버넌스위원회) × 7개 활동의 빈칸에 R·A·C·I를 채운다.
3. **R&R 정의서 작성** — 담당 부서·주요 책임·최종 책임·협의 대상·보고 대상·주요 산출물·점검 주기.
## 막히는 지점
- A(최종 책임)는 활동당 반드시 1명이어야 한다. 두 명이 A면 사실상 아무도 책임지지 않는다.
