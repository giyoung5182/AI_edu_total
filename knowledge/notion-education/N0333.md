# 실습 1. 발표 양식 작성 — 5단계 발표 구조(OPSEA)

정리일: 2026-10-08 · 교육 에셋 N0333

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 결과를 오프닝→문제→솔루션→효과→실행계획 5단계 구조로 정리해 팀 발표 슬라이드 구성안을 작성한다. (기준: MySQL)
## 진행 단계
1. **구성안 작성** — 템플릿의 슬라이드 3\~7번(오프닝/문제/솔루션/효과/실행계획) 주요 내용을 팀이 채운다. 예시 답안 참고 가능.
2. **역할 분담** — 5분 발표: 오프닝+핵심 성과 30초(팀장) / 문제 1분(팀원 A) / 정제·개선 결과 Before→After 2분(팀원 B) / 확산 계획 1분(팀원 C) / 소감·적용 아이디어 30초(팀장).
3. **SQL로 수치 뽑기** — Before 결측 현황, Before 지역명 종류, After CASE WHEN 표준화 후 종류 수, 민원 유형 분류 현황 쿼리 4개를 실행해 슬라이드에 붙인다.
- 입력할 내용: 예) `SELECT COUNT(*) AS 전체_행수, SUM(CASE WHEN \`열사용량\` IS NULL THEN 1 ELSE 0 END) AS 결측_건수, ... FROM heat_usage;\` (이하 교안 참고)
- 정상 결과: 전체 382행 / 결측 47건 / 결측률 12.3%, 표준화 후 지역명 종류 6, 분류완료 124건(80.0%) / 미분류 31건(20.0%)
