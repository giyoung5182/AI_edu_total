# 활동 1-1 — AI에게 점검 요청

정리일: 2026-10-08 · 교육 에셋 N1176

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
ChatGPT에 실습 데이터를 올려 5단계 점검을 요청하고, 결과를 워크시트에 기록합니다.
## 진행 단계
1. **파일 업로드** — ChatGPT에 `01_실습데이터_통합.xlsx`를 파일 통째로 첨부합니다. (엑셀을 통째로 올리면 AI가 시트를 골라 읽어 복사·붙여넣기보다 정확합니다.)
2. **점검 요청** — 아래 프롬프트를 그대로 복사해 입력합니다.
- 입력할 내용:
```plain text
업로드한 파일의 "업무시간실태조사" 시트를 점검하라.
2행이 열 이름, 3행부터 데이터다.

아래 5단계로 점검하고 각 단계 결과를 표로 보고하라.

1단계 구조: 열 개수, 데이터 행 수, 병합/빈 행 여부
2단계 결측: 열별 결측 건수와 비율
3단계 이상치: 물리적으로 불가능한 값, 범위 이탈, 음수
(이하 교안 참고)
```
1. **결과 정리** — 5단계별로 워크시트(단계 / 발견 내용 / 건수)에 적습니다.
2. **누락 확인** — 정답 토글과 대조해 놓친 게 있는지 봅니다.
