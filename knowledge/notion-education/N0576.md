# 트랙 1. 자유주제

정리일: 2026-10-08 · 교육 에셋 N0576

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만들 것을 스스로 정하고, 기존에 만든 것을 재조합해 Claude Code로 구현한다.
## 진행 단계
1. **다섯 칸 설계** — ① 해결할 일 ② 입력 자료 ③ 원하는 출력 ④ 필요한 부품 ⑤ 팀 명단
2. **강사 확인** — 확인 포인트는 ②의 확보 가능성과 ③의 크기.
3. **프롬프트 입력** — \[목표\]\[입력 자료\]\[결과물\]\[구성\]을 채워 창②에 입력 (프롬프트 전문은 교안 참고)
4. **단계별 구축** — 1단계 입력 화면과 뼈대, 2단계 기능을 하나씩 합류, 3단계 최종 결과물 화면. 각 단계 동작을 확인한 뒤 넘어간다.
## 막히는 지점
- 창①의 오류 로그를 창②에 붙여넣어 해결 요청. 엉키면 /clear 후 상태와 목표를 다시 설명.
- 같은 오류가 세 번 반복되면 그 기능을 빼거나 단순화.
- 새 문서를 재료로 쓸 때는 공개된 소형 문서만 사용 (회사 자료·개인정보 문서 금지).
