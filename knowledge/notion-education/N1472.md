# 실습 A 수정 4회 — 한 번에 하나씩

정리일: 2026-10-08 · 교육 에셋 N1472

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
퀴즈 앱을 네 번에 걸쳐 하나씩 고치며 회귀를 피하는 요청 방식을 익힙니다.
## 진행 단계
1. **축하 효과**
- 입력할 내용: `정답을 맞혔을 때 축하 효과를 추가해줘. 다른 기능은 그대로 두고.`
2. **문제 순서 섞기**
- 입력할 내용: `문제 순서를 매번 무작위로 섞어줘. 나머지는 그대로.`
3. **번호 표시**
- 입력할 내용: `지금 몇 번째 문제인지 상단에 표시해줘 (예: 3 / 5). 나머지는 그대로.`
4. **다시 풀기 버튼**
- 입력할 내용: `마지막 결과 화면에 "다시 풀기" 버튼을 추가해줘. 나머지는 그대로.`
- 각 요청 후 결과를 확인하고 다음으로 진행
## 막히는 지점
- 요청 5개를 몰아서 넣으면 잘 돌던 기능이 깨질 수 있음(회귀)
- 화면이 그대로면 왼쪽 답변부터 읽기
