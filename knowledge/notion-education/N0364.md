## 이 실습으로 하는 것
내 업무에 맞는 컬럼을 설계하고 Claude Code로 가상 데이터 엑셀(my_data.xlsx)을 만든다.
## 진행 단계
1. **먼저 생각해보기** — 내 부서는? / 매달 보고하는 숫자는? / 비교하고 싶은 기준은? / 꼭 보고 싶은 인사이트는? 표에 답한다.
2. **부서별 컬럼 예시 참고** — 경영지원(인사·재무), 생산품질(생산·품질), 연구(프로젝트·특허), 사업 예시 컬럼.
3. **가상 데이터 생성** — 프롬프트 템플릿을 내 업무에 맞게 수정해 입력한다.
- 입력할 내용:
```javascript
엑셀 파일을 만들어줘.

【목적】
[내 직군/팀명] 업무용 가상 데이터 생성

【컬럼 구성】
- 날짜: 2025-01 ~ 2026-06 (월별, 18개월)
- [카테고리 컬럼 1]: [값 예시] (예: 부서명)
- [숫자 컬럼 1]: [범위] (예: 50~200 사이 정수)
- [숫자 컬럼 2]: [범위] (예: 0.0~1.0 사이 소수)
- [목표 컬럼]: [범위] (예: 100~300 사이 정수)

【저장】
파일 경로: day2/data/my_data.xlsx
시트명: Data
위 경로에 엑셀 파일로 저장해줘.
```
- 정상 결과: day2/data/my_data.xlsx 생성 확인
1. **작업 폴더 이동** — 터미널에서 data 폴더로 이동(cd) 후 claude 실행. 아래 프롬프트로 만들 수 있는 대시보드를 추천받는다.
```javascript
지금 선택한 엑셀 파일로 streamlit 라이브러리 활용해서 어떤 대시보드를 만들 수 있을지 컬럼과 데이터 검토해서 추천해줘.
```
