# MISSION 1. 실전 장바구니 채우기 (CFO 주도)

정리일: 2026-10-08 · 교육 에셋 N1260

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
쿠팡에서 필요한 재료를 실제로 검색하고, 재료리스트 엑셀을 완성한다. (CFO 주도)
## 진행 단계
1. **엑셀 열기** — CFO가 엑셀 파일(재료리스트)을 연다
2. **구매 목록 결정** — 팀 전원이 의논하여 구매할 재료 목록을 결정한다
3. **가격 확인** — CFO가 쿠팡에서 각 품목을 검색하고 가격을 확인한다
4. **엑셀 입력** — 엑셀의 제품명, 수량, 단가, 배송비 칸에 숫자만 입력한다
- 정상 결과: 구매 링크 칸에 URL을 붙여넣으면 나중에 실제 주문할 때 바로 찾을 수 있다
5. **예산 조정** — 총 지출액이 135,000원을 넘지 않도록 조정한다
## 막히는 지점
- 엑셀 입력 규칙: 잘못된 입력 "3개", "2,000원", "무료" / 올바른 입력 3 / 2000 / 0
