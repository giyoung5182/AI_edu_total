## **0-1. 먼저 한 문장으로 이해하기**
**Microsoft 365 Copilot은 Word, Excel, PowerPoint, Outlook, Teams 같은 업무 도구 안에서 사용하는 회사용 AI 비서입니다.**
[원본 이미지 제외]
예를 들어 다음과 같은 일을 시킬 수 있습니다.
- Word 문서 초안 작성 및 요약
- Excel 데이터 분석과 표 해석
- PowerPoint 발표자료 초안 생성
- Outlook 이메일 요약 및 답장 초안 작성
- Teams 회의 내용 요약과 할 일 정리
- 회사 문서와 업무 데이터를 바탕으로 질문하고 답변 받기
다만, **어떤 요금제를 쓰느냐에 따라 AI가 볼 수 있는 정보와 사용할 수 있는 위치가 달라집니다.**

## **0-2. 가장 먼저 알아야 할 용어**
## **Copilot Chat**
브라우저나 Microsoft 365 Copilot 앱에서 사용하는 **업무용 AI 채팅창**입니다.
ChatGPT처럼 질문을 입력하고 답을 받는 방식입니다.
예시:
> “이 보고서를 5줄로 요약해줘.”
“중학생 대상 AI 교육 프로그램 이름을 10개 제안해줘.”
“첨부한 파일에서 예산 관련 내용만 정리해줘.”
적격 Microsoft 365 업무용 계정을 가진 사용자는 **별도의 Microsoft 365 Copilot 유료 라이선스가 없어도 Copilot Chat을 사용할 수 있습니다.**
하지만 여기서 말하는 “무료”는 완전히 아무것도 구매하지 않아도 된다는 뜻이 아닙니다.
- 회사가 적격 Microsoft 365 구독을 사용 중이어야 함
- 회사 또는 학교 계정으로 로그인해야 함
- 조직의 관리자가 사용을 허용해야 할 수 있음
---
## **Microsoft 365 Copilot Business**
Word, Excel, PowerPoint, Outlook, Teams 등 **실제 Microsoft 365 앱 안에 Copilot을 넣어주는 유료 AI 추가 기능**입니다.
쉽게 말하면 다음과 같습니다.
- Copilot Chat만 사용: AI 채팅창에서 질문
- Copilot Business 사용: Word, Excel, PowerPoint, Outlook, Teams 안에서 직접 AI 사용
예시:
- Word 문서를 열고 “이 문서를 정책 제안서 형식으로 다시 써줘”
- Excel 파일을 열고 “매출이 감소한 원인을 분석해줘”
- PowerPoint에서 “이 Word 문서를 10장 발표자료로 만들어줘”
- Outlook에서 “이 긴 이메일 대화를 요약하고 정중한 답장을 작성해줘”
- Teams에서 “회의 내용을 요약하고 담당자별 할 일을 정리해줘”
---
## **Microsoft 365 Business Standard / Premium**
이것은 AI만 파는 상품이 아니라, 회사가 사용하는 **기본 업무 도구 묶음**입니다.
일반적으로 다음이 포함됩니다.
- Word
- Excel
- PowerPoint
- Outlook
- Teams
- 회사용 이메일
- OneDrive 클라우드 저장소
- SharePoint
- 기타 협업 도구
여기에 **Copilot Business가 함께 들어간 묶음 상품**을 구매할 수도 있습니다.
---
## **Work IQ**
Work IQ는 Copilot이 사용자의 업무 흐름을 이해하도록 돕는 기능입니다.
쉽게 표현하면 다음과 같습니다.
> 일반 AI는 “지금 사용자가 입력한 질문”을 중심으로 답합니다.
Work IQ가 적용된 Copilot은 사용자가 접근할 권한이 있는 업무 자료, 업무 관계, 작업 흐름 등을 함께 참고해 답할 수 있습니다.
예를 들면 다음과 같습니다.
> “지난주 A사업 관련해서 결정된 내용을 정리해줘.”
Work IQ를 사용하는 Copilot은 사용 권한이 허용된 범위 안에서 이메일, 일정, 문서, 회의, 업무 관계 등을 연결해 관련 내용을 찾을 수 있습니다.
단, Copilot이 회사의 모든 정보를 무조건 보는 것은 아닙니다.
- 사용자가 원래 열람할 수 없는 자료는 Copilot도 볼 수 없음
- 회사가 설정한 보안 및 접근 권한을 따름
- 잘못된 권한 설정이 있으면 AI 도입 전에 정리하는 것이 좋음
---
## **에이전트**
에이전트는 특정 업무를 반복적으로 수행하도록 만든 **전문 AI 직원 또는 자동화 도구**에 가깝습니다.
예시:
- 사내 규정만 답변하는 인사 규정 안내 에이전트
- 사업계획서를 검토하는 제안서 점검 에이전트
- 고객 문의를 분류하는 상담 에이전트
- 회의 준비자료를 모으는 프로젝트 에이전트
- 데이터 분석을 전문으로 하는 분석 에이전트
Copilot Business에는 Microsoft가 미리 만들어 둔 일부 리서치·분석·업무 지원 에이전트가 포함됩니다.

## **Excel에서 여는 방법 — 네 가지**
지금 하나씩 눌러보십시오.
### **방법 1. 홈 탭 리본 (기본)**
```plain text
① 상단 [홈] 탭 클릭
② 리본 오른쪽 끝에서 Copilot 아이콘 찾기
③ 클릭 → 화면 오른쪽에 Copilot 창이 열림
```
> ⚠️ **Copilot 아이콘은 홈 탭에만 있습니다**
데이터 탭이나 삽입 탭에는 없습니다.
### **방법 2. 화면 오른쪽 아래 버튼**
```plain text
Excel 창의 오른쪽 아래 모서리에 Copilot 아이콘
```
### **방법 3. 셀에서 바로 열기**
```plain text
① 데이터 안의 셀 하나를 클릭
② 셀 옆에 반짝이는 아이콘(스파클)이 나타남
③ 그 아이콘 클릭
```
### **방법 4. 키보드**
```plain text
Alt → H → F → X
```
순서대로 하나씩 누릅니다.

아무 생각 없이 질문을 던지면 **Copilot이 시트를 바꿉니다.** 파악 단계에서 이러면 원본이 손상됩니다.
### **편집 모드가 강력한 지점**
편집 모드를 제대로 쓰면 **분석 보고서를 통째로 만들어냅니다.**
```plain text
프롬프트 입력 → 30초~2분 대기
→ 유형별 집계, 상위 항목 정리, 차트까지 포함된 시트 생성
```
직접 하면 몇 시간 걸릴 작업입니다. 다만 **결과를 사람이 반드시 검수**해야 합니다.
### **오늘의 원칙**
```plain text
파악·점검 단계  → 채팅 모드 (또는 프롬프트로 제한)
실제 작업 단계  → 편집 모드 (원본 복사 후)
```
**모드 바꾸는 방법**
```plain text
Copilot 창 상단에서 모드 선택 → [채팅] 클릭
```
모드 선택이 안 보이면 **프롬프트에 못박으십시오.**
```plain text
시트를 수정하지 마. 분석 결과만 알려줘.
```
> 💡 **오늘 프롬프트에 "수정하지 마"가 계속 나오는 이유입니다**

## **0-7. 대화 시작자와 채팅 제안 버튼**
**뭘 물어야 할지 모를 때 클릭만 하면 됩니다.**
### **대화 시작자**
Copilot을 열면 창 위쪽에 예시 목록이 뜹니다.
```plain text
- 데이터 인사이트를 표시해 주세요
- 수식 열 제안
- 이 데이터를 요약해 주세요
```
### **채팅 제안 버튼**
[원본 이미지 제외]
답변 아래에 다음 질문을 추천하는 버튼이 붙습니다.
```plain text
- [다른 인사이트를 볼 수 있을까요?]
- [그리드에 모든 인사이트를 추가하세요]
```
[원본 이미지 제외]
**\[그리드에 모든 인사이트를 추가하세요\]** 를 누르면 **새 시트가 생기면서** 발견된 인사이트가 한 번에 정리됩니다.
> 💡 **버튼을 눌러보는 것부터 시작하십시오**
프롬프트를 잘 쓰는 건 나중 얘기입니다. 처음에는 **뜨는 버튼을 눌러보면서** 뭘 할 수 있는지 감을 잡는 게 빠릅니다.

```plain text

④ 창 위쪽 대화 시작자 목록 확인
```

## **0-9. AI에게 줄 데이터를 먼저 준비하세요.**
**여기가 오늘 교육에서 가장 실무적인 부분입니다.**
코파일럿이 아무리 좋아도 **데이터가 흩어져 있으면 아무것도 못 합니다.** AI를 잘 쓰는 사람과 못 쓰는 사람의 차이는 프롬프트가 아니라 **데이터를 준비하는 기본기**에서 갈립니다.

## **(참조) 파워쿼리 — 여러 파일을 자동으로 취합하기**
**부서에서 가장 자주 하시는 작업일 겁니다.** 여러 부서가 보낸 엑셀 파일을 하나로 합치는 것.
**파워쿼리를 쓰면 클릭 몇 번으로 끝나고, 이후엔 새로고침만 누르면 됩니다.**
#### **취합 방법**
```plain text
① 취합할 파일들을 폴더 하나에 모읍니다
   (그 폴더엔 취합 대상만 있어야 합니다)

② 새 Excel 파일을 엽니다

③ [데이터] 탭 → [데이터 가져오기]

④ [파일에서] → [폴더에서]

⑤ 폴더 선택 → [열기]

⑥ 폴더 내 파일 목록이 표시됨 → 확인

⑦ [결합] → [결합 및 로드]

⑧ 파일 병합 창에서 예제 시트 선택
   → 데이터가 제대로 보이는지 확인 → [확인]

⑨ 폴더 안 모든 파일이 한 번에 취합됨
```
#### **다음 달에는**
```plain text
① 새 파일을 그 폴더에 넣기
② 취합된 표에서 마우스 오른쪽 클릭 → [새로고침]
③ 끝
```
> 💡 **이게 코파일럿보다 먼저 배워야 할 기술입니다**
취합 자체는 AI가 아니라 **엑셀 기본 기능**으로 해결됩니다. 그리고 훨씬 정확합니다.
**AI는 취합된 데이터를 분석하는 데 쓰십시오.** 순서가 이렇습니다.
```plain text
파워쿼리로 취합  →  코파일럿으로 분석
```
> ⚠️ **파일 양식이 같아야 합니다**
시트 이름과 머리글 위치가 파일마다 다르면 취합이 어긋납니다. **양식을 배포할 때 이걸 통일해두는 것**이 자동화의 8할입니다.
### **오늘 실습은 파워쿼리 없이 갑니다**
실습 파일이 이미 한 파일에 정리되어 있기 때문입니다. **다만 실제 업무에서는 위 절차를 먼저 거치셔야 합니다.**

## **0-10. 알아두면 좋은 최신 Excel 기능**
코파일럿과 함께 쓰면 좋은 기능들입니다. **오늘 다루지는 않지만 알아두면 좋습니다.**





기능

하는 일




**포커스 셀**

셀 선택 시 같은 데이터를 자동 강조




**동적 배열**

한 번의 수식으로 여러 행 결과 반환




**트리밍 참조**

**`A:.A`**처럼 콜론 앞에 마침표 → 실제 데이터 범위만 참조




**피벗 자동 새로고침**

데이터 추가 시 피벗이 자동 갱신




**람다 함수**

나만의 사용자 정의 함수 등록




**Copilot 함수**

셀 안에서 AI로 추출·분류·감정분석


> 💡 **트리밍 참조가 의외로 유용합니다**
**`=SUM(A:A)`**는 열 전체를 계산해서 느립니다. **`=SUM(A:.A)`**처럼 **콜론 뒤에 마침표**를 찍으면 실제 데이터가 있는 범위만 봅니다.
수식 속도가 빨라지고, 데이터가 늘어나도 자동으로 범위가 확장됩니다.
> 💡 **람다 함수로 나만의 함수를 만들 수 있습니다**
자주 쓰는 수식 조합을 함수로 등록해두는 기능입니다.
```plain text
① 원하는 수식을 LAMBDA로 작성
② 그 공식을 복사
③ [수식] 탭 → [이름 관리자] → [새로 만들기]
④ 참조 대상에 붙여넣기
⑤ 함수 이름과 설명 입력 → [확인]
⑥ =내함수이름(범위) 로 사용
```
부서에서 반복해서 쓰는 계산이 있으면 이걸로 만들어두십시오.

## **0-11. 프롬프트 쓸 때 지킬 세 가지**
공식 문서가 강조하는 지점입니다.
### **① 표 또는 범위를 명확히 지정하십시오**
```plain text
나쁜 예:  이 데이터 분석해줘
좋은 예:  월별성과 시트의 신계약건수 열을 분석해줘
```
### **② 열 머리글을 그대로 쓰십시오**
시트에 적힌 이름을 **정확히 그대로** 쓰십시오.
```plain text
나쁜 예:  성별에 따라 실적이 어떻게 다른지
좋은 예:  '지점장발령이력' 시트의 '성별' 열과
          '월별성과' 시트의 '신계약건수' 열을 사용해서
```
### **③ 한 번에 하나씩 요청하십시오**
복합 요청은 일부만 처리되거나 엉뚱하게 섞입니다.
> ⚠️ **한국어 프롬프트에는 한계가 있습니다**
공식 문서에 명시된 내용입니다. **Copilot은 주로 영어 자료로 학습되어, 프롬프트나 데이터가 영어가 아닌 경우 제대로 작동하지 않을 수 있습니다.**
결과가 계속 이상하면 영어로 한 번 물어보고 비교해 보십시오.
