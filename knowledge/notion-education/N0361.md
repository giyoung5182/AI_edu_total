# VS Code 파이썬 첫걸음 마케팅 아이디어 봇 만들기

정리일: 2026-10-08 · 교육 에셋 N0361

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
사용자의 입력에 반응하는 간단한 자동 카피라이터 봇을 만들며 VS Code의 작동 원리를 파악합니다.
## 진행 단계
1. **준비물 및 환경 세팅** — python.org에서 Python 설치 파일을 받아 실행, VS Code 설치 후 확장 프로그램(Extensions)에서 Python 검색·설치
2. **작업 공간 생성** — 바탕화면에 `idea` 폴더를 만들고 우클릭 → Code로 열기 / 터미널에서 열기(`code .` + 엔터) / VS Code 파일 \> 폴더 열기
3. **파일 생성** — 좌측 탐색기 새 파일 아이콘으로 `idea_bot.py` 생성
4. **봇 코드 작성** — 빈 화면에 아래 코드를 그대로 붙여넣기
```javascript
# 사용자에게 인사하고 입력을 받는 단계
print("안녕하세요! 저는 당신의 아이디어 봇입니다.")
product = input("오늘 홍보하실 제품이나 핵심 주제를 입력해주세요 입력 ")

# 입력받은 내용을 바탕으로 결과를 출력하는 단계
print("\n--- 자동 생성된 카피라이팅 초안 ---")
print("1. 감성 타겟팅 일상에 특별함을 더하는, " + product)
print("2. 논리 타겟팅 10년의 노하우가 담긴 압도적 효율, " + product)
print("3. 행동 유도형 더 늦기 전에 지금 바로 " + product + " 경험해보세요!")
print("----------------------------------")
```
1. **실행** — 우측 상단 ▷ 재생 버튼 클릭, 또는 편집기 빈 공간 우클릭 \> Python 실행 \> 터미널에서 Python 파일 실행
2. **결과 확인** — 하단 터미널에서 봇이 인사하고 입력을 기다림. 텀블러나 수영복 같은 단어를 입력하고 엔터
- 정상 결과: 3가지 버전의 문장이 조합되어 출력됨
3. **문구 추가 및 업데이트** — 기존 print() 아래에 새 코드를 추가하고 Ctrl+S로 반드시 저장한 뒤 재생 버튼(Run Python File)을 다시 눌러 새 버전 실행
- 입력할 내용:
```javascript
print("4. 혜택 강조형 파격적인 혜택으로 만나는, " + product)
print("5. 호기심 유발형 당신이 몰랐던 " + product + "의 진짜 가치")
```
## 막히는 지점
- 코드를 추가한 뒤에는 변경된 파일을 반드시 저장해야 합니다(윈도우는 Ctrl + S).
