## 실습① — NotebookLM 노트북 만들기
### 1단계 · 새 노트북 만들기
노트북 이름:
```javascript
교육기관 29 공개자료
```
### 2단계 · 자료 넣기 (웹사이트 주소)
아래 주소를 소스로 등록합니다.
```javascript
[개별 링크 제외]
```
> 자료가 개편되어 주소가 바뀐 경우 강사가 현장에서 대체 주소를 안내합니다.
### 3단계 · 읽혔는지 확인
```javascript
등록한 자료의 목차를 알려줘
```
### 4단계 · 범위를 한정해서 질문 (그대로 입력)
```javascript
등록한 자료 안에서만 답해 주세요.
근거 위치를 함께 표시해 주세요.
자료에 없으면 「자료에 없음」이라고 답해 주세요.

이 자료에 실린 2024년 조정개시율과 조정성공률을 알려줘
```
### 5단계 · 각주를 눌러 원문과 대조
타이핑 없이, 답에 붙은 각주 번호를 눌러 원문 위치로 이동해 확인합니다.
### 6단계 · 오디오 개요 미리 걸어두기
NotebookLM 화면에서 오디오 개요 생성 버튼을 눌러 둡니다.

## 실습② — Gemini Gem 만들기
### 1단계 · 내가 반복하는 업무 하나 선택
본인이 평소 반복하는 업무 하나를 정합니다. (예: 회의록 정리, 문의 답변, 보고서 초안)
### 2단계 · 브라우저로 Gems 들어가기
앱이 아니라 브라우저 주소창에 아래 주소를 직접 입력합니다.
```javascript
gemini.google.com
```
왼쪽 메뉴를 펼쳐서 Gems 항목으로 들어간 뒤 '새 Gem'을 누릅니다.
### 3단계 · 지침 칸에 그대로 입력
```javascript
[역할]   우리 부서 문서를 정해진 형식으로 정리하는 보조자.
[목표]   입력한 내용을 표로 정리.
[절차]   ① 항목별로 분리  ② 표로 이관  ③ 빠진 칸을 「확인 필요」로 표시
[예시]   | 항목 | 내용 | 확인 필요 |  형식으로 출력.
[지식]   근거가 없으면 지어내지 말고 「확인 필요」로 기재.
```
지침 맨 아래에 아래 제약 세 줄을 이어서 붙입니다.
```javascript
근거가 없으면 지어내지 말고 「확인 필요」로 표시할 것
숫자를 낼 때는 계산 과정을 함께 표시할 것
개인정보와 진행 중 사건은 요약하거나 인용하지 말 것
```
출력 형식을 지정하는 한 줄도 함께 넣습니다.
```javascript
서술형 항목은 개조식으로 작성하고, 종결어미는 ~함 · ~임 · ~예정을 사용할 것. 구어체 금지.
```
### 4단계 · 내 업무 문장을 넣어 실행
1단계에서 정한 본인 업무 내용을 직접 입력해 실행해 봅니다.
### 5단계 · 지침을 한 줄 고쳐 다시 실행
아래 중 하나를 지침에 추가해 보고, 결과가 어떻게 달라지는지 비교합니다.
```javascript
· 표로 정리할 것
· 항목당 세 줄을 넘기지 말 것
· 확인이 필요한 항목은 표 아래에 따로 모을 것
· 숫자는 원문 표기 그대로 쓸 것 — 반올림 금지
```
