# 실습 ② 불러오기 — 조건에 맞는 행만 「확인 필요」 시트로

정리일: 2026-10-08 · 교육 에셋 N0585

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
결제방법이 "개인카드 후정산"이고 영수증첨부가 "미첨부"인 행만 새 시트 「확인 필요」로 불러온다. 원본은 읽기만 하고 매번 지우고 다시 쓴다.
## 진행 단계
1. **프롬프트 입력** — 같은 ChatGPT 대화에 붙여넣고 Copy code
- 입력할 내용:
```javascript
같은 시트에 쓸 함수를 하나 더 만들어 줘. 앞의 markRows는 그대로 두고 추가할 함수만 줘.
- 입력 시트: 출장정산내역 (1행 머리글, 열은 머리글 이름으로 찾기)
- 조건: '결제방법'이 "개인카드 후정산" 이고 '영수증첨부'가 "미첨부" 인 행
- 결과 시트: 확인 필요 (없으면 새로 만들기)
- 결과 시트는 매번 내용을 지우고 1행에 머리글, 2행부터 조건에 맞는 행 전체를 쓰기(두 번 실행해도 행이 늘지 않게)
- 끝나면 실행 로그에 불러온 건수 출력
- 입력 시트는 읽기만 하고 수정하지 말 것
- 함수 이름: copyCheckRows
```
1. **붙여넣기·저장** — 편집기 기존 코드 맨 아래 빈 줄에 붙여넣고 저장 (기존 코드는 지우지 않음)
2. **실행** — 드롭다운에서 `copyCheckRows` 선택 → 실행. 권한 창이 다시 뜨면 실습 ①과 같은 방법으로 허용
3. **결과 확인** — 실행 로그의 건수와 `확인 필요` 시트 확인, 한 번 더 실행해도 행 수가 그대로인지 확인
- 정상 결과: 실행 로그 `확인 필요 16건`, 시트는 머리글 1행 + 16행
## 막히는 지점
- 0건이면 조건 글자에 띄어쓰기가 다른지(`개인카드 후정산`) 확인
