# 이월 실습 A. 보고서 초안

정리일: 2026-10-08 · 교육 에셋 N0569

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
3회차 분석 결과를 바탕으로 \[D\]\[S\]\[R\]\[F\] 형식 프롬프트로 보고서 초안(Word)을 만들고 3단계로 검토함.
## 진행 단계
1. **시작 전 확인** — 3회차 채팅창이 열려 있으면 같은 채팅에서 이어서 진행, 없으면 새 Claude 채팅창을 열고 프롬프트 붙여넣기
2. **프롬프트 입력** — \[D\] 분석 결과 / \[S\] 보고서 상황·수신자 / \[R\] A4 1페이지 구성(핵심 요약 3줄, 위험 현황 표, 불일치 TOP3 표, 조치 사항, 다음 주 관찰 포인트), Word(.docx) 다운로드 / \[F\] 소스에 없는 수치 사용 금지, 불확실 항목은 '확인 필요', 구성비 소수점 1자리 %
- 정상 결과: 보고서가 나오면 3단계 검토 진행
3. **1단계 수치 대조** — 핵심 수치 3개를 3회차 분석 결과와 직접 비교
4. **2단계 현장 맥락 추가** — AI 초안에 없는 담당자 맥락을 직접 추가
5. **3단계 언어 확인** — 본부장이 30초 안에 핵심을 파악할 수 있는 언어인지, 전문 용어가 많지 않은지 확인
## 막히는 지점
- 3회차에서 Claude가 구성비를 0.4686... 형태로 생성한 오류 발생. \[F\]에 "소수점 1자리 %. 예: 46.9%"를 명시하면 방지됨
