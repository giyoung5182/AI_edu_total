# 1. 🔥 1단계 — GPTs로 결과물 만들기 (10분)
## 내 업무는 어느 유형인가
**어제 만드신 프롬프트가 다 달랐습니다.** 본인에게 맞는 유형을 고르세요.





유형

어떤 일

예




**① 집계형**

숫자를 모아 보여준다

처리 현황, 클레임 통계, 미수 현황




**② 점검형**

기준과 대조해 문제를 찾는다

규정 상충, 라이선스 현황, 규격 이탈




**③ 조사형**

흔어진 정보를 정리한다

시장 자료, 경쟁사 동향, 사례 수집




**④ 문서형**

글을 쓰고 검토한다

정관 개정, 공문, 제안서



**모르겠으면 이 질문으로**
· 숫자를 더하는가 → **집계형**
· 무엇과 무엇을 맞춰보는가 → **점검형**
· 흔어진 걸 모으는가 → **조사형**
· 글을 쓰는가 → **문서형**

---
## 3교시에 만든 GPTs를 엽니다

---
### 유형별 요청 예시
**① 집계형**
```plain text
이 데이터를 정리해줘.

1. 한눈에 볼 지표 4개
2. 상태별 또는 유형별 분포
3. 부서별 또는 기간별 비교
4. 눈에 띄는 것 3가지

표본이 적은 항목은 건수를 함께 표시하고,
확인된 사실과 추정을 구분해줘.
원본에 없는 숫자를 만들지 마.

결과를 표로 정리해줘. 대시보드에 넣을 거야.
```
**② 점검형**
```plain text
이 자료를 기준과 대조해 점검해줘.

1. 전체 점검 건수와 통과 / 미통과
2. 미통과 항목 목록 — 무엇이 기준과 다른지
3. 조치가 시급한 것과 나중에 해도 되는 것
4. 판단이 애매해 사람 확인이 필요한 항목

기준에 없는 항목을 임의로 판정하지 말고
"기준 확인 필요"로 표시해줘.

결과를 표로 정리해줘. 대시보드에 넣을 거야.
```
**③ 조사형**
```plain text
이 자료들을 읽고 정리해줘.

1. 핵심 발견 3가지
2. 항목별 요약 — 무엇을 알게 됐는가
3. 자료간 엇갈리는 부분이 있는가
4. 더 확인해야 할 것

각 내용이 어느 자료에서 나왔는지 반드시 표시하고,
자료에 없는 내용은 추가하지 마.

결과를 표로 정리해줘. 대시보드에 넣을 거야.
```
**④ 문서형**
```plain text
이 문서를 검토해줘.

1. 문서 개요 — 목적, 분량, 구성
2. 검토 항목별 결과 — 통과 / 수정 필요
3. 수정이 필요한 부분과 그 이유
4. 판단이 애매해 사람 확인이 필요한 것

확정되지 않은 것을 단정하지 말고,
검토 기준이 없는 항목은 "기준 확인 필요"로 표시해줘.

결과를 표로 정리해줘. 대시보드에 넣을 거야.
```

**① 집계형 — 숫자와 차트**
```plain text
아래 내용으로 단일 HTML 파일 대시보드를 만들어줘.

[제목]
[예: 업무요청 처리 현황 — 2026년 8월]

2. [지표명] : [값]
3. [지표명] : [값]
4. [지표명] : [값]
   ※ [주의가 필요한 지표는 주황색으로]

[중단 차트 2개]
왼쪽 — [무엇을] 도넛 차트
  데이터: [항목1] [값], [항목2] [값]
오른쪽 — [무엇을] 가로 막대
  데이터: [항목1] [값], [항목2] [값]

[하단 표]
제목: [무엇 목록]
열: [열1] | [열2] | [열3] | [열4]
데이터:
[한 줄씩 붙여넣기]

(공통 조건은 아래 참조)
```
**② 점검형 — 통과/미통과와 조치 목록**
```plain text
아래 내용으로 단일 HTML 파일 점검 결과 화면을 만들어줘.

[제목]
[예: 사내 규정 상충 점검 결과]

[상단 요약 카드 4개]
1. 전체 점검 : [N]건
2. 통과 : [N]건
3. 조치 필요 : [N]건   ← 주황색
4. 확인 필요 : [N]건

[중단 — 점검 항목별 결과]
항목마다 카드로 보여줘.
각 카드에: 항목명 / 상태 / 한 줄 설명
상태는 색으로 구분 (통과 초록 / 조치필요 주황 / 확인필요 회색)

항목:
[항목명] | [상태] | [설명]
[한 줄씩 붙여넣기]

[하단 — 조치 필요 목록]
시급한 것을 위로 정렬
열: 항목 | 무엇이 문제인가 | 어떻게 할까 | 기한
데이터:
[한 줄씩 붙여넣기]

(공통 조건은 아래 참조)
```
**③ 조사형 — 발견과 출처**
```plain text
아래 내용으로 단일 HTML 파일 조사 결과 화면을 만들어줘.

[제목]
[예: 경쟁사 동향 조사 — 2026년 8월]

[상단 — 핵심 발견 3개]
큰 카드 세 개로. 각각 한 문장 + 받침 설명 한 줄
1. [발견] / [설명]
2. [발견] / [설명]
3. [발견] / [설명]

[중단 — 항목별 정리]
항목마다 박스로.
각 박스에: 항목명 / 내용 / 출처
출처는 작게 회색으로 맨 아래

항목:
[항목명] | [내용] | [출처]
[한 줄씩 붙여넣기]

[하단 — 더 확인해야 할 것]
```
