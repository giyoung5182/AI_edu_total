# 이미지 A 편집하기 (팔레트)

정리일: 2026-10-08 · 교육 에셋 N1369

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
처음 만든 이미지 A를 새로 만들지 않고 기존 이미지를 바탕으로 더 쓰기 좋게 편집합니다. 팔레트로 영역을 지정하면 글로만 요청할 때보다 원하는 부분이 정확히 반영됩니다.
## 진행 단계
1. **채팅창에 사진 업로드**
2. **팔레트 입장** — 사진을 클릭하여 팔레트로 입장
3. **참고 지정** — 원하는 색상을 선택하여 영역을 선택하거나 텍스트를 입력하여 AI가 참고할 수 있도록 함
4. **프롬프트에 설명 추가** — 팔레트로 입력한 그림 혹은 텍스트에 대한 설명을 프롬프트에 추가
- 입력할 내용:
```javascript
[무엇을 만들지] 기존 광고 이미지를 더 프리미엄한 방향으로 편집한 이미지
[분위기/톤] 더 차분하고 정제된 프리미엄 톤
[배경/환경] 기존 겨울 도시 배경을 더 미니멀하게 정리한 환경
[구도/촬영 방식] **빨간색 펜으로 선택한 영역**의 기존 모델 구도는 유지하되 패딩 실루엣과 여백이 더 잘 보이게 조정
[용도] 광고 문구 삽입까지 고려한 개선 시안

- 색감은 더 차분하게
- 패딩 실루엣은 더 선명하게
- 배경은 더 미니멀하게
- 문구 여백은 더 넓게
```
