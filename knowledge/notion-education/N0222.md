# 이미지 · 여섯 가지를 알려줍니다
"예쁘게 만들어줘"로는 원하는 게 나오지 않습니다. 이미지도 **범위를 좁혀줘야** 합니다(원리 1).





요소

쓰는 내용

예




**무엇을**

주제·대상

노트북으로 서류를 검토하는 직장인




**어떤 분위기로**

톤·감정

차분하고 신뢰감 있는




**어떤 형식으로**

사진·일러스트·3D

단순한 선으로 그린 플랫 일러스트




**색감은**

주요 색

흰색 배경에 검정과 진한 파랑 계열




**구도는**

배치·시선

가운데 인물, 주변은 여백으로 비움




**어디에 쓸**

용도·비율

사내 발표 자료 표지용 가로형


### 그대로 써보는 예시
```plain text
사내 교육 안내 자료에 넣을 표지 이미지를 만들어 주세요.

- 대상 : 노트북 앞에서 교육받는 직장인들
- 분위기 : 차분하고 신뢰감 있는, 과하게 밝지 않게
- 형식 : 단순한 선으로 그린 플랫 일러스트
- 색감 : 흰 배경에 검정과 진한 파랑 계열
- 구도 : 가로형, 가운데 여백을 남겨 제목을 넣을 수 있게
- 글자는 넣지 마세요.
```

**한글은 기대하지 마세요**
AI 이미지는 한글을 제대로 못 씁니다. 글자를 넣으면 깨진 글자처럼 나옵니다.
**해결법** — 이미지는 글자 없이 만들고, 제목은 파워포인트나 워드에서 위에 올려 씁니다. 그래서 예시 마지막에 "글자는 넣지 마세요"를 넣었습니다.


**무료 계정은 이미지 생성 횟수가 제한됩니다.** 한 번에 잘 나오길 기대하기보다, 위 여섯 가지를 처음부터 채워 넣는 편이 결국 빠릅니다.

# 이미지 고쳐나가기
마음에 안 들면 처음부터 다시 쓰지 말고 **바꿀 것만 말합니다.**
```plain text
좀 더 단순하게, 요소를 줄여줘
배경을 흰색으로 바꿔줘
사람을 빼고 사물만 남겨줘
세로형으로 다시 만들어줘
더 차분한 분위기로, 채도를 낮춰줘
```

# 발표자료 · 구조부터 잡습니다
슬라이드를 바로 만들어달라고 하면 뿌리 없는 것이 나옵니다. **목차 → 슬라이드별 내용 → 쓸 문장** 순서로 가야 쓸 만해집니다.
```plain text
다음 주제로 10분짜리 사내 발표를 준비합니다.
주제 : [주제 입력]
듣는 사람 : [팀장 / 부서원 / 타 부서]

답을 쓰기 전에, 먼저 이 발표가 끝났을 때 듣는 사람이
무엇을 알고 있어야 하는지 세 가지를 정리해 주세요.
그 다음 그것을 전달하기 위한 슬라이드 구성을 짜 주세요.

- 슬라이드는 6장 이내로 합니다.
- 각 장마다 제목과 핵심 내용 3줄을 씁니다.
- 제가 알려주지 않은 수치는 넣지 말고 [ ]로 비워 두세요.
```

**"끝났을 때 무엇을 알고 있어야 하는가"를 먼저 시키는 것이 핵심입니다.**
목적을 먼저 정리하게 하면 구성이 날카로워집니다. 모듈 03에서 배운 CoT입니다.

### 이어서 쓸 수 있는 요청
```plain text
3번 슬라이드를 실제 발표할 문장으로 풀어줘
이 구성에서 빠진 관점이 있으면 짚어줘
반대하는 사람이 할 만한 질문 3개를 만들어줘
각 장에 넣을 만한 표나 도표를 제안해줘
```

**"반대하는 사람의 질문 3개"** — 보고 전에 가장 쓸모 있는 요청입니다.
내가 놓친 구멍을 미리 찾아줍니다.

**발표자료를 만들 때도** — 실적 수치, 고객사명, 내부 기준은 입력하지 않습니다.
구조와 문장만 받아오고, **숫자는 사내에서 직접 채우십시오.**
