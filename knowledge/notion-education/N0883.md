## Q1. Supabase 연동하면 비용이 얼마나 들어요?
**A.** 교육기관 규모(6\~20명이 쓰는 사내 업무 도구)에서는 **사실상 무료**로 충분합니다.
```plain text
Supabase 요금제 4단계:

Free (무료)
  · 데이터베이스 500MB
  · 월 활성 사용자(MAU) 50,000명까지
  · 파일 저장 1GB
  · 프로젝트 2개까지
  ⚠️ 7일간 미접속 시 프로젝트 자동 일시정지
    (데이터는 안 사라짐, 재개 버튼만 누르면 됨)

Pro — $25/월 (프로젝트 1개당)
  · 데이터베이스 8GB / MAU 10만 명 / 파일 저장 100GB
  · 일시정지 없음 + 자동 백업

Team — $599/월
  · 보안 인증(SOC2 등) 필요한 대기업용, 교육기관에는 불필요

Enterprise — 협의 가격
  · 대규모 기업 전용, 해당 없음
```
**교육기관 6명 시나리오 기준 결론:**
```plain text
Free 플랜으로 시작해도 충분합니다.
500MB는 텍스트·숫자 데이터 기준으로 수십~수백 년치 분량입니다.
(아래 Q3에서 구체적으로 설명)

업무용 앱은 매일 또는 매주 쓰는 경우가 많아서
"7일 미접속 시 일시정지" 제약도 실질적으로 문제되지 않습니다.

유료 전환이 필요해지는 시점:
  데이터가 500MB를 넘어설 만큼 누적되거나 (이미지 다량 저장 시)
  외부 사용자가 많아져서 동시접속이 빈번해질 때
```
> 💡 **2026년 기준 중요 업데이트:** 최근 Lovable에는 **Lovable Cloud**라는 내장 기능이 생겼습니다. 별도로 Supabase 홈페이지에 가입하지 않아도, Lovable 안에서 클릭 한 번으로 같은 기능(데이터베이스·로그인·파일저장)을 바로 쓸 수 있습니다. 아래 실습 방법은 이 Lovable Cloud 기준으로 안내합니다.

### 🔧 실제 연동 방법 — Supabase(Lovable Cloud) 데이터베이스 연결하기
```plain text
방법 A — Lovable Cloud로 바로 시작 (가장 쉬움, 추천)

STEP 1. Lovable 프로젝트 화면에서
  왼쪽 패널 상단의 [+] 버튼 클릭
  → 패널 선택 메뉴가 열림
  → "Cloud" 클릭

STEP 2. Cloud 탭에서 "Database" 섹션 확인
  → 만약 테이블 목록이 보이면 이미 연결된 상태
  → 안 보이면 채팅창에 아래처럼 요청:

  "이 앱에 데이터베이스를 연결해줘.
   [어떤 데이터를 저장할지] 저장할 수 있는 테이블을 만들어줘."

  예시 (프로님 휴무 앱 기준):
  "직원 이름, 기존 휴무일, 변경 후 휴무일, 변경 사유,
   부장님 알림 여부를 저장하는 테이블을 만들어줘."

STEP 3. Lovable이 자동으로:
  → 데이터베이스 테이블 생성
  → 필요한 코드 작성
  → 몇 초~몇 분 후 완료 메시지 표시

STEP 4. Cloud 탭에서 데이터 확인
  → 테이블 클릭하면 실제 저장된 데이터를 표로 볼 수 있음
  → 구글 시트처럼 행과 열 형태로 보입니다
```
```plain text
방법 B — 기존 Supabase 계정 직접 연결하기
  (이미 Supabase 가입을 따로 한 경우)

STEP 1. supabase.com 접속 → 회원가입(무료) → 새 프로젝트 생성
  → 프로젝트 이름 입력 → 비밀번호 설정 → 지역 선택 (Asia 권장)

STEP 2. 프로젝트 생성 완료 후
  왼쪽 메뉴 [Settings] → [API] 클릭
  → "Project URL"과 "anon public" 키 복사해두기

STEP 3. Lovable로 돌아가서
  → 프로젝트 설정(Settings) → Integrations 탭 → Supabase 찾기
  → [Connect Supabase] 클릭
  → 방금 복사한 Project URL과 키 붙여넣기

STEP 4. 연결 완료 메시지("✅ Supabase connected") 확인
  → 이제 채팅창에서 데이터 저장 기능을 요청하면 됩니다
```
> ⚠️ 처음 시작할 때는 \*\*방법 A(Lovable Cloud)\*\*가 훨씬 간단합니다. 방법 B는 이미 Supabase를 다른 용도로 쓰고 있거나, 데이터베이스를 직접 세세하게 관리하고 싶을 때만 사용하세요.
상세한 진행은 다음 회차에 할 예정입니다.

## Q2. 아이디·비밀번호로 회원가입·로그인 관리 기능도 가능해요?
**A.** 가능합니다. Supabase(Lovable Cloud)에 **Auth(인증)** 기능이 기본 포함되어 있습니다.
```plain text
구현 가능한 로그인 방식:

① 이메일 + 비밀번호 로그인 (가장 기본)
② 구글 계정으로 로그인 (소셜 로그인)
   → 교육기관처럼 구글 워크스페이스 쓰는 조직에 적합
③ 매직 링크 (비밀번호 없이 이메일 인증 링크로 로그인)
④ 역할 기반 접근 제어 (RLS)
   → "이 사람은 조회만", "이 사람은 입력도 가능"처럼
     사용자별 권한 구분 가능
```
**교육기관 적용 예시 (프로님 휴무 앱):**
```plain text
직원 17명에게 각자 계정 발급
→ 본인은 본인 휴무만 조회·요청 가능
→ 프로님(관리자)만 전체 등록·수정 가능
→ 부장님은 전체 조회만 가능 (읽기 전용)
```
---
### 🔧 실제 구현 방법 — 로그인 기능 추가하기
```plain text
STEP 1. 데이터베이스 연동이 먼저 되어 있어야 함 (Q1 참고)

STEP 2. Lovable 채팅창에 요청:

  "이메일과 비밀번호로 회원가입·로그인하는 기능을 추가해줘.
   로그인 화면과 회원가입 화면을 만들어줘.
   로그인하지 않은 사용자는 메인 화면에 접근할 수 없게 해줘."

STEP 3. Lovable이 자동으로:
  → 로그인/회원가입 화면 생성
  → 인증 로직 연결
  → 완료 후 직접 회원가입 테스트해보기

STEP 4. (선택) 권한 구분이 필요하면 추가 요청:

  "관리자 계정과 일반 직원 계정을 구분해줘.
   관리자만 데이터를 수정·삭제할 수 있고,
   일반 직원은 본인이 입력한 데이터만 조회할 수 있어야 해."

STEP 5. (선택) 구글 계정으로 로그인하고 싶으면:

  방법 1 — 가장 간단한 방법:
  Lovable 채팅창에 "구글 계정으로 로그인하는 기능 추가해줘"
  라고 요청 → Lovable이 단계별로 안내해줌

  방법 2 — 직접 설정 (조금 더 복잡함):
  ① Google Cloud Console(console.cloud.google.com) 접속
  ② "API 및 서비스" → "사용자 인증 정보" → "OAuth 클라이언트 ID 만들기"
  ③ 승인된 리디렉션 URI에 Supabase가 알려주는 콜백 URL 입력
  ④ 발급받은 클라이언트 ID·보안 비밀번호를
     Supabase의 "Authentication" → "Providers" → "Google"에 입력
  ⑤ Lovable에서 "구글 로그인 버튼 추가해줘"라고 요청

  ⚠️ 방법 2는 강사 도움 없이 처음 혼자 하기엔 다소 어려울 수 있습니다.
     이메일·비밀번호 로그인(방법 1)으로 먼저 시작하는 것을 권장합니다.
```

## Q3. 데이터베이스 500MB면 실제로 어느 정도 저장할 수 있어요?
**A.** 텍스트·숫자 데이터 기준으로는 **사실상 거의 무제한**에 가깝습니다.
```plain text
교육기관 시나리오로 환산하면:

예시 1 — 프로님 (플레이스 요청 관리)
  한 건당 약 0.5~1KB → 500MB ÷ 1KB ≈ 약 50만 건 저장 가능
  하루 10건씩 쌓여도 1년 3,650건 → 500MB 채우려면 100년 이상

예시 2 — 프로님 (휴무 변경 17명)
  하루 평균 3~5건 변경 → 1년 약 1,500건
  → 수백 년치 데이터 저장 가능

예시 3 — 프로님 (차량 정비 13대)
  월 20건 → 1년 240건 → 용량 걱정 거의 없음
```
**용량을 실제로 많이 쓰는 경우:**
```plain text
❌ 이미지를 직접 저장 (사진, 첨부파일)
   → 이건 "Storage"라는 별도 공간(1GB)을 씁니다.
     정비 사진을 많이 올리면 이쪽이 먼저 찰 수 있음

❌ 모든 변경 이력을 무제한 누적해도 그래도 수년은 버팁니다.

→ 일반적인 회사 업무 도구(텍스트·숫자 위주)는
  500MB가 사실상 "거의 무제한"이라고 보면 됩니다.
```

## Q4. GAS로 만든 자동화 시트를 Lovable 앱에 불러올 수 있어요?
**A.** 가능합니다. Lovable에는 **Google Workspace 커넥터**가 내장되어 있어서 별도 API 키 발급 없이 연동됩니다.
```plain text
방식 A — 실시간 연동 (구글 시트와 앱이 항상 같은 데이터 공유)
  앱이 구글 시트와 직접 연결되어
  시트에 데이터가 추가되면 앱에도 자동 반영됨
  → 기존 GAS 자동화는 그대로 유지, 앱은 보기 좋게 보여주는 창구

방식 B — 가져오기(Import) 한 번만
  구글 시트 데이터를 한 번 Supabase로 복사해 옮긴 후
  이후로는 앱 자체에서 데이터 관리
  → 구글 시트와 앱이 따로 운영됨 (동기화 없음)
```
---
### 🔧 실제 연동 방법 — 구글 시트 연결하기
```plain text
STEP 1. Lovable 프로젝트 화면 → 왼쪽 채팅창에 요청:

  "이 앱을 내 구글 시트와 연동해줘.
   시트의 데이터를 앱에서 실시간으로 보고,
   앱에서 입력하면 시트에도 자동으로 반영되게 해줘."

STEP 2. Lovable이 "Connect Google Workspace" 같은 연결 버튼을 제시함
  → 클릭

STEP 3. 구글 로그인 팝업이 뜸
  (팝업이 안 뜨면 브라우저 팝업 차단 해제 필요)
  → 연동할 구글 계정으로 로그인
  → 권한 요청 화면에서 [Allow] 클릭

STEP 4. 연결할 Google 서비스 범위(scope) 선택
  → "Google Sheets" 항목 체크 확인
  → 기본값 그대로 두어도 무방

STEP 5. Lovable 화면으로 자동 복귀 + 연결 완료 메시지 확인

STEP 6. 채팅창에 추가로 요청:

  "[시트 이름] 구글 시트의 [시트탭 이름] 데이터를
   불러와서 이 화면에 표로 보여줘."

  예시 (프로님 차량정비 시트):
  "차량정비관리대장의 이달정비내역 시트를 불러와서
   화면에 표로 보여주고, 새로 입력하면 시트에도 추가되게 해줘."
```
> 💡 한 번 연결한 구글 계정은 다른 Google 서비스(Gmail, Calendar, Docs 등)에도 같은 방식으로 추가 연결할 수 있습니다. 예를 들어 "구글 시트 + Gmail"을 함께 연동하면, 폼 제출 시 시트 저장과 이메일 발송을 동시에 처리하는 것도 가능합니다.

## Q5. 엑셀 파일을 업로드하면 자동으로 데이터 정리해주는 기능도 가능해요?
**A.** 가능합니다. 사용자가 .xlsx 파일을 업로드하면 앱이 내용을 읽어서 자동으로 표·목록으로 정리해줍니다.
```plain text
작동 방식:
  사용자가 [파일 선택] 버튼 클릭 → 엑셀 파일 업로드
  → 앱이 파일 내용을 읽음
  → 정해진 열 구성에 맞춰 자동으로 데이터베이스에 저장
  → 화면에 정리된 표로 즉시 표시
```
---
### 🔧 실제 구현 방법 — 엑셀 업로드 기능 추가하기
```plain text
STEP 1. 데이터베이스 연동이 먼저 되어 있어야 함 (Q1 참고)
  → 업로드된 데이터를 저장할 공간이 필요하기 때문

STEP 2. Lovable 채팅창에 요청:

  "엑셀 파일(.xlsx)을 업로드할 수 있는 버튼을 화면에 추가해줘.
   업로드하면 자동으로 [업체명], [금액], [날짜] 열을 인식해서
   읽어들이고, 목록에 자동으로 추가되게 해줘.
   업로드 형식이 다르면 오류 메시지를 보여줘."

STEP 3. Lovable이 자동으로:
  → 파일 업로드 버튼(UI) 생성
  → 엑셀 파싱(읽기) 로직 작성
  → 데이터베이스 저장 연결

STEP 4. 직접 테스트
  → 실제 업무에서 쓰는 엑셀 파일 하나를 업로드해보고
    제대로 인식되는지, 빠진 열은 없는지 확인

STEP 5. 형식이 안 맞을 때 추가 요청:

  "업로드한 엑셀의 열 순서가 [실제 순서]로 되어 있는데
   이 순서에 맞게 다시 인식하도록 고쳐줘."
```
**교육기관 적용 예시:**
```plain text
프로님 "차량 정비비 관리"
```

## Q6. 구글 시트 API 연동도 돈이 들어요?
**A.** 무료입니다. 교육기관 규모에서는 비용 걱정 없습니다.
```plain text
Google Sheets API 무료 사용 한도:
  분당 읽기 요청: 300회/분 (프로젝트당)
  분당 쓰기 요청: 60회/분 (사용자당)
  일일 요청 횟수: 사실상 무제한

교육기관 6명 시나리오 기준:
  각 앱이 분당 수십 회 정도만 호출
  → 무료 한도 안에서 여유롭게 작동, 비용 발생 가능성 사실상 0%

유료 전환이 필요한 경우:
  수백~수천 명이 동시 접속하는 대규모 외부 공개 서비스일 때
  → 교육기관처럼 사내 6~20명이 쓰는 도구는 해당 없음

⚠️ 게다가 Lovable의 Google Workspace 커넥터를 쓰면
   별도로 API 키를 직접 발급받을 필요도 없습니다.
   Q4에서 안내한 방법대로 로그인 한 번이면 끝입니다.
```

## Q7. 데이터를 자동 분석해서 보고용 대시보드 만들고, 이미지로 다운로드도 가능해요?
**A.** 가능합니다. 데이터 분석 → 대시보드 구성 → 이미지 다운로드까지 전부 구현됩니다.
```plain text
① 데이터 자동 분석
  업로드된 데이터에서 자동으로:
  · 이번 달 총 지출액 / 업체별 지출 순위 Top 5
  · 전월 대비 증감률 / 기준 초과 항목 자동 추출

② 원하는 항목만 정리한 대시보드
  요청한 항목들로만 화면 구성 가능
  차트 형태도 지정 가능: 막대 그래프, 원형 그래프, 선 그래프 등

③ 이미지(PNG)로 다운로드
  [이미지로 저장] 버튼 → 현재 화면을 PNG 파일로 다운로드

④ PDF 다운로드도 동일하게 가능
```
---
### 🔧 실제 구현 방법 — 분석 대시보드 + 다운로드 기능 만들기
```plain text
STEP 1. 데이터베이스 연동 + 데이터가 어느 정도 쌓여 있어야 함
  (샘플 데이터로 먼저 테스트해도 무방)

STEP 2. Lovable 채팅창에 항목을 구체적으로 명시해서 요청:

  "이 데이터를 분석해서 보고용 대시보드 화면을 만들어줘.
   포함할 항목:
   1. 이번 달 전체 합계 (큰 숫자로, 요약 카드)
   2. 항목별 순위 Top 5 (막대 그래프)
   3. 상태별 비율 (원형 그래프)
   4. 전월 대비 증감률 (퍼센트, 증가는 빨간색 화살표 아이콘)

   디자인은 깔끔하고 전문적인 느낌으로,
   인쇄해도 보기 좋게 여백을 충분히 둬줘."

STEP 3. 화면 완성 후 다운로드 기능 추가 요청:

  "이 화면 우측 상단에 [이미지로 저장] 버튼을 추가해줘.
   클릭하면 현재 화면 전체가 PNG 파일로 다운로드되게 해줘."

  (PDF가 필요하면)
  "PDF로 다운로드하는 버튼도 추가해줘.
   A4 용지에 맞게 레이아웃을 정리해서 출력되게 해줘."

STEP 4. 직접 다운로드 테스트
  → 버튼 클릭 → 파일이 다운로드 폴더에 저장되는지 확인
  → 이미지가 깨지거나 잘리지 않는지 확인

STEP 5. 레이아웃이 마음에 안 들면 구체적으로 수정 요청:

  "다운로드된 이미지에서 그래프가 잘려서 보여.
   여백을 더 주고 전체가 다 보이게 고쳐줘."
```
**교육기관 적용 예시 (프로님 지출결의서 대시보드):**
```plain text
"매장별 지출결의서 데이터를 분석해서
 다음 항목들로 보고용 대시보드를 만들어줘:
 1. 이번 달 전체 매장 지출 합계 (요약 카드)
 2. 매장별 지출 순위 Top 10 (막대 그래프)
 3. 제출완료 / 미제출 / 반려 비율 (원형 그래프)
 4. 전월 대비 증감률 (요약 카드)

 화면 우측 상단에 [보고서 이미지로 저장] 버튼을 추가해서
 클릭하면 이 화면 전체가 PNG 이미지로 다운로드되게 해줘."
```
> 💡 위 기능들(데이터 분석, 차트, 이미지·PDF 다운로드)은 모두 Lovable 코드 안에서 처리되는 기능이라 **별도 외부 서비스 비용이 들지 않습니다.**

## 전체 정리
```plain text
Supabase(Lovable Cloud) · Google Sheets API
  → 교육기관 규모에서는 사실상 비용 없이 운영 가능

구현 가능한 것들:
  ✅ 실제 데이터 저장 (새로고침해도 안 사라짐)
  ✅ 로그인·회원 관리 (이메일/비밀번호, 구글 로그인, 권한 구분)
  ✅ 구글 시트 실시간 연동 (별도 API 키 발급 불필요)
  ✅ 엑셀 파일 업로드 자동 정리
  ✅ 데이터 자동 분석 + 보고용 대시보드
  ✅ 이미지(PNG)·PDF 다운로드

전부 Lovable 채팅창에 자연어로 요청만 하면 구현됩니다.
```
