# 3-4. ChatGPT 실습 (25분) · 텍스트·이미지·파일·음성

정리일: 2026-10-08 · 교육 에셋 N0409

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
ChatGPT의 텍스트·이미지·파일 분석·음성 기능을 차례로 체험하고, 강사 입장에서의 활용 포인트를 확인합니다.
## 진행 단계
1. **기본 텍스트 생성 (5분)** — 강의 소개문 만들기
- 입력할 내용: "60대 이상 시니어를 대상으로 AI 일상 활용법을 가르치는 강의 소개문을 친근하고 쉽게 3줄로 써줘"
- 정상 결과: 어조·난이도가 요청에 맞는지, 수정해 바로 쓸 수 있는지, RCTC+K로 구체화하면 어떻게 달라지는지 확인
2. **이미지 생성 (5분)** — "배를 그려줘" 입력 후 어떤 '배'를 그리는지 확인, 이어서 "바다를 항해하는 배를 그려줘"로 구체적 프롬프트의 차이 체험
3. **파일 분석 (10분)** — 기존 강의 자료 PDF 업로드 후 "핵심 내용을 3줄로 요약", "수강생용 퀴즈 5개", "어려워할 만한 용어를 쉽게 설명" 요청
4. **음성 대화 체험 (5분)** — 음성 모드를 켜고 "오늘 강의에서 AI가 뭔지 설명하는 좋은 비유를 알려줘"라고 질문
## 막히는 지점
- 무료 메시지 한도가 소진되면 잠시 후 다시 하거나 다른 AI로 이어서 진행
