## 두 도구는 어떤 역할을 하나요?
두 도구는 AI의 자료 조사에서 서로 다른 부분을 돕습니다. <br>**multi-source-search는 자료를 찾고 근거를 비교하는 조사 방법을 정하고, <br>Agent Reach는 자료 수집에 쓸 검색·읽기 도구를 연결합니다.**
### ① multi-source-search — 여러 출처를 대조해 답변의 근거를 정리하는 스킬
**SandBase Skills에 포함된 조사용 스킬**입니다. AI가 사용할 수 있는 검색과 웹페이지 읽기 기능을 활용해, 여러 자료를 찾아보고 중요한 주장을 원문과 대조하도록 조사 순서를 정해줍니다.
업무용 서비스를 비교한다면 **공식 기능 안내, 공개 후기, 관련 기사 등 서로 다른 자료를 확인하고 설명이 일치하는지 비교**하도록 지시합니다.
**구체적으로 하는 일**
- **여러 경로로 자료 찾기:** 사용할 수 있는 검색 도구를 확인하고, 공식 문서·기사·논문 등 질문에 맞는 자료를 찾습니다.
- **원출처 확인하기:** 같은 발표문을 옮긴 기사 여러 개를 서로 독립된 근거처럼 중복 계산하지 않도록 합니다.
- **서로 다른 설명 비교하기:** 출처들이 공통으로 말하는 내용과 의견·수치가 엇갈리는 부분을 구분합니다.
- **주장과 근거 연결하기:** 결론 옆에 원문 링크를 붙이고, 확인된 사실과 추론, 아직 자료가 부족한 부분을 나눠 정리하도록 합니다.
**이럴 때 활용할 수 있어요**
“우리 팀에 맞는 협업 서비스를 비교해줘”, “보고서에 넣을 이 주장이 맞는지 확인해줘”, “이 제품의 광고와 실사용 리뷰가 어떻게 다른지 찾아줘” 같은 요청에 활용할 수 있습니다.
이 스킬이 지시하는 핵심은 **왜 그런 결론을 내렸는지 확인할 수 있는 답변**입니다. 실제 조사 범위는 사용하는 AI의 검색·페이지 읽기 기능에 따라 달라지며, 출처 비교만으로 답의 정확성이 보장되는 것은 아닙니다. [스킬 원문](https://github.com/sandbaseai/sandbase-skills/blob/main/research/multi-source-search/SKILL.md)
### ② Agent Reach — AI가 사이트별 자료 수집 도구를 사용하도록 연결하는 도구
웹페이지, 영상, SNS, 커뮤니티는 자료를 가져오는 방법이 제각각입니다. **Agent Reach는 검색, 웹페이지 읽기, 영상 자막 추출, 게시물 조회 등에 필요한 외부 프로그램을 AI가 쓰는 환경에 연결하고, 어떤 기능이 준비됐는지 점검하는 오픈소스 도구**입니다.
공개 게시물이나 댓글을 가져올 수 있도록 돕고, 자료 분석과 답변 작성은 사용 중인 AI가 수행합니다.
**구체적으로 하는 일**
- **웹 자료 읽기:** 연결된 검색·읽기 도구로 웹페이지 본문과 공개 GitHub 자료 등을 가져오는 방법을 제공합니다.
- **영상 내용을 텍스트로 가져오기:** 지원되는 YouTube 영상의 자막을 추출해 AI가 내용을 정리하는 데 쓸 수 있게 합니다.
- **SNS·커뮤니티 자료 찾기:** 필요한 설정이 된 X·Reddit 등의 게시물이나 댓글을 검색·조회하는 도구를 연결합니다. 플랫폼마다 가능한 작업은 다릅니다.
- **연결 상태 점검하기:** 어떤 기능을 바로 쓸 수 있고, 어떤 기능에 로그인이나 추가 설정이 필요한지 확인합니다.
**이럴 때 활용할 수 있어요**
“이 영상의 자막을 읽고 핵심을 정리해줘”, “이 제품에 대한 공개 불만을 찾아줘”, “이 GitHub 프로젝트와 관련 이슈를 살펴봐줘”처럼 여러 플랫폼의 자료를 AI에게 전달하려는 상황에 활용할 수 있습니다.
기존 검색·브라우저와 기능이 겹칠 수 있어, **추가 효과는 연결되는 도구에 따라 달라집니다.** 사이트의 로그인·접근 제한은 그대로 적용됩니다. [공식 저장소](https://github.com/Panniantong/Agent-Reach)

## 6. 업무와 일상에서 바로 쓰는 질문
**스킬 메뉴가 안 보여요.** Claude는 웹·데스크톱의 Customize → Skills를 확인하세요. ChatGPT는 지원 계정·워크스페이스인지 먼저 확인합니다. 앱에 메뉴가 없으면 웹에서 시도하세요.
**업로드에 실패해요.** 전체 저장소 ZIP이나 압축을 푼 폴더 대신, 페이지 맨 위의 설치용 ZIP을 선택했는지 확인하세요. Claude는 코드 실행 설정, 회사 계정은 스킬 업로드 권한도 확인합니다.
**네이버 카페나 특정 커뮤니티가 안 열려요.** 로그인·멤버십·사이트 제한이 있는 자료까지 읽을 수 있다는 뜻은 아닙니다. 접근 가능한 다른 출처를 요청하거나, 직접 제공할 수 있는 본문을 붙여넣어 비교하세요.
**Agent Reach도 여기에 업로드하면 되나요?** 스킬 파일만 올려서는 필요한 외부 도구와 로그인이 준비되지 않습니다. 일반 채팅앱에서 바로 설치된다고 안내하지 않습니다. 이 페이지의 공통 요청문은 Agent Reach의 설치 대체품이 아닙니다.
**출처가 많으면 답이 맞는 건가요?** 같은 원문을 인용한 글일 수 있습니다. 중요한 결정에는 원문 내용과 날짜를 확인하고, 자료가 부족한 부분은 남겨두세요.
