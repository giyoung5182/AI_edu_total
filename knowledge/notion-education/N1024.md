# 실습 2 — 데이터 정제 SQL 작성

정리일: 2026-10-08 · 교육 에셋 N1024

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
탐지한 오류를 SELECT로 먼저 확인한 뒤 UPDATE로 수정합니다. 황금 원칙은 SELECT로 먼저 보고 UPDATE는 나중에입니다.
## 진행 단계
1. **비표준 지역명 표준화** — SELECT 미리보기 → UPDATE(CASE WHEN) → 수정 후 재확인(0행이면 완료)
2. **날짜 형식 표준화** — DATE_FORMAT(STR_TO_DATE(usage_date, '%Y.%m.%d'), '%Y-%m-%d') 미리보기 → UPDATE → 재확인
3. **결측값 처리** — 민원 유형 NULL을 '미분류'로 UPDATE → 유형별 건수로 재확인
4. **음수 사용량 처리 방안 논의** — 원천 데이터 재확인 후 수정 / NULL로 표시하여 제외 / 해당 행 삭제 중 업무 판단으로 선택
## 막히는 지점
- WHERE 조건이 잘못되면 의도하지 않은 행까지 전체 수정, CASE WHEN 분기 누락 시 엉뚱한 값, 트랜잭션 없이 실행하면 롤백 불가
- 임시값('미분류')으로 방치하면 통계 왜곡이 지속되므로 원천 확인 후 교체
- 음수 사용량은 원천 데이터 재확인 우선, 삭제는 최후의 수단
