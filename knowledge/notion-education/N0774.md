# 바이브코딩 업무자동화 프로젝트

그동안 나를 괴롭혀왔던 **'내 업무의 비효율'**, 이번 시간엔 그것을 **실제로 없애 봅니다**. 바이브코딩은 도구일 뿐이며, **내 업무 문제를 푸는 결과물을 직접 만들어 내는 것**이 목표입니다.

---
# AI로 할 수 있는 두 가지



**'제거' (1 → 0)**<br>기존에 있던 **비효율을 없애는 것**




**'영감' (0 → 1)**<br>없던 것을 **새로 만들어내는 것**



AI의 가치는 이 두 가지로 나뉩니다. 오늘 우리가 집중할 것은 **'제거'** — 즉, 업무에서 반복적이고 비효율적인 부분을 AI로 없애는 것입니다.
---
# '제거'한다는 것 ✂️
## 1. 사소한 고민도 생산성을 해친다
> 그게 뭐였더라, 어디에 있더라, 어떻게 하더라?
작은 고민들이 쌓이면 업무 흐름이 끊기고, 집중력이 떨어집니다. 정보를 찾거나 절차를 기억하는 데 쓰는 에너지를 줄일 수 있다면, 본질적인 업무에 더 집중할 수 있습니다.
## 2. 손이 빨라도, 지친다
> 100개 하는데 1시간이면 돼! → 클릭·타이핑 3만 번 + 집중 과다
"손이 빠르니까 괜찮아"라고 생각하지만, 반복 작업은 물리적 피로뿐 아니라 **정신적 에너지를 소모**합니다. 빠르다고 해서 효율적인 것이 아닙니다.
## 3. 경과/결과 확인이 잦아지면 조직도 무너진다
> 직접 일일이 찾아보거나, 일일이 보고하라고 시키거나 (신뢰↓)
현황을 파악하기 위해 매번 물어보거나 보고를 시키는 것은 조직의 신뢰와 효율을 동시에 떨어뜨립니다.
---
# 3가지 제거

**고민 제거** → 업무체계, 시스템으로 해결<br>정보를 찾거나 절차를 기억하는 고민을 시스템이 대신합니다.


**클릭 제거** → 자동화, 효율화 (작업환경)<br>반복적인 클릭·타이핑·복사붙여넣기를 자동화합니다.


**확인 제거** → 크고 작은 대시보드<br>현황을 물어보지 않아도 한눈에 볼 수 있는 대시보드를 만듭니다.

# 📐 업무 프로세스 구조화 (실습 진입 전)

**핵심 메시지**: AI에게 일을 시키려면, 내 업무를 먼저 **'단계'**로 쪼개야 한다.

## AI 활용 업무자동화 공식
```javascript
Input   →   AI   →   Output

내 업무에서 AI에게 무엇을 주었을 때, 무엇을 해주길 바라시나요?
```
**예시: 월간 해외법인 실적 보고**
- Input: 각 법인이 보낸 월간 실적 데이터 (엑셀/메일)
- AI: 취합 → 전월/예산 대비 비교 → 주요 이슈 정리
- Output: 경영진 보고용 요약 리포트 (HTML/PPT)

# 🌞 바이브코딩 업무자동화 프로젝트 🌞  (\~16:25)
[원본 이미지 제외]
1. **프로젝트 주제 : 내 업무의 비효율을 제거하는 웹사이트 제작하기**
2. **문제 정의** **예시** : "내가 제거하고 싶은 업무는 무엇인가?"
3. **AI와 설계를 해보세요** : "이 문제를 해결하려면 뭐가 필요한지 같이 정리해보자"
4. **결과물 개발** : AI와 대화하며 결과물 만들기
1. 대외비 자료 사용X  → 더미데이터 제작해서 진행
5. **테스트까지 해보세요** : 원하는 대로 동작하는지 확인, 개선 요청
6. **프로젝트 제출 :** 추후 공지

**Tip: 프롬프트가 막힐 때 쓰는 기법 3가지**
**① 개괄식 정리** — 역할·목표·조건을 짧게 구조화해 전달<br>   👉  "역할: 재무회계 담당 / 목표: 전표 검토 현황판 / 조건: 한 페이지, 표와 그래프"
**② 단계별 지시** — 한 번에 모두 요청하지 않고 나눠서<br>   👉  "내 업무를 먼저 이해해줘" → "자동화할 부분을 찾아줘" → "화면을 설계해줘"
**③ 역질문기법** — 아이디어 구상과 설계부터 AI에게 시키기<br>   👉  "이런 문제를 해결하고 싶은데, 어떻게 만들면 좋을지 나를 인터뷰해서 파악해줘"
