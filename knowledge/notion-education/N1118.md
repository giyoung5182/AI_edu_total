# 실습 · 근무 원자료 → 월간 요약 (5분)

정리일: 2026-10-08 · 교육 에셋 N1118

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
465행 근무 원자료를 집계하고 수기 월간요약과 대사해 인력 운영 현황을 작성합니다.
## 진행 단계
1. **성명 표기 통일** — 공백·괄호·직책 표기 차이를 같은 사람으로 처리.
2. **직종별 집계** — 총 근무일수와 총 근무시간.
3. **월간요약 시트와 대조** — 차이가 나는 항목을 표로 제시.
4. **대근결원내역 점검** — 중복 입력이나 미배정 건 찾기.
5. **비정상 행 추출** — 근무시간 0시간·24시간 등.
6. **개조식 작성** — 인력 운영 현황 장.
- 제약: 차이가 나는 수치는 임의로 맞추지 말고 양쪽을 제시한 뒤 \[확인 필요\]로 표시, 제공하지 않은 수치는 만들지 않기, 첨부 파일 데이터만 사용.
- 체크: 총 근무시간이 요약 시트와 다르게 나왔는가 / 차이를 임의로 맞추지 않았는가 / 대근 미배정·중복·시간 이상 행을 찾았는가.
## 막히는 지점
- 같은 사람을 다른 사람으로 셈: 표기 흔들림 → "성명 표기를 먼저 통일하라"를 1단계로
- 긴 파일 뒷부분을 놓침: 시트·기간 단위로 나눠 올리기
