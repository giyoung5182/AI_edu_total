# 실습 — 내 보고서 설계서 만들기 (활동 4)

정리일: 2026-10-08 · 교육 에셋 N1221

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
진단 보고서를 발표자료 설계서(4블록)로 바꾸고, 슬라이드로 만든 뒤 원본과 대조 검증합니다.
## 진행 단계
1. **보고서 점검 (5분)** — 숫자 문장·표본 크기 표기·추정 문장·계산 가정·사라지기 쉬운 단서를 표로 점검하는 프롬프트 실행
2. **설계서 초안 생성 (8분)** — 슬라이드는 만들지 않고 설계서 텍스트만, 슬라이드 5\~7장, 헤드메시지는 결론 문장으로, 보고서에 없는 수치는 \[확인 필요\]
- 입력할 내용(앞부분):
```javascript
아래 보고서를 읽고, 발표자료 설계서 초안을 작성해 줘.
아직 슬라이드는 만들지 말고 설계서 텍스트만 줘.

설계서는 네 블록으로 구성해 줘.
블록 1 맥락: 개요, 유의사항 3개 이상, 최종 목적, 전체 흐름
블록 2 슬라이드 설계도: 각 장마다 분류 / 헤드메시지 / 내용 설명 / 시각 요소.
       표가 아니라 줄글로 서술해 줘
블록 3 디자인 규격: 색상 코드, 글꼴, 크기, 레이아웃 규칙
블록 4 산출 규칙: 말투, 사실 관계, 구성, 재량
(이하 교안 참고)
```
1. **세 항목 검토 (7분)** — 유의사항(경영진 특성과 맞는가) / 헤드메시지(순서대로 읽으면 논리가 이어지는가) / ［확인 필요］(자료 구멍)
2. **슬라이드 생성 (3분)** — Gamma/genspark(Create new → Paste in text), ChatGPT/Gemini/Claude("HTML 슬라이드로 만들어줘"), 파워포인트 코파일럿, 직접 제작 중 선택
3. **대조 검증 (2분)** — 없던 숫자가 생기지 않았는가 / n= 유지 / '추정' 표기 유지 / 결론이 원본보다 강해지지 않았는가 / 특정 부서 지목 표현이 생기지 않았는가
- 고치는 프롬프트: "모든 수치 뒤에 (n=숫자)를 다시 넣어줘 / "추정" 표기를 복원해줘 / 내가 준 보고서에 없는 숫자는 전부 삭제해줘"
## 막히는 지점
- 슬라이드로 바뀔 때 사라지기 쉬운 것: 단서(표본이 작음), 표본 크기(n=), '추정' 표기
