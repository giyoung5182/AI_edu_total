# 2. 1부 — 재료리스트 마감 (30분)
## 2-1. 오늘이 마감일
- 오늘이 재료리스트 최종 마감일
- 빠진 항목을 채우고, 목표 생산 개수와 판매 가격까지 기입하는 것이 목표
## 2-2. 모든 팀 공통 확인 항목
- 팀 이름과 컨셉 칸 기입
- 목표 생산 개수 기입
- 판매 가격 기입
- 단위 원가 산출 (총 지출액 ÷ 목표 생산 개수)
- 마진율 확인 (판매가 − 단위 원가, ÷ 판매가 × 100)
- 빈칸으로 남은 항목 보완
- 구매 링크가 열리는지, 품절은 아닌지 확인
## 2-3. 팀별 확인 사항
**GLMF**
- 판매 품목과 구성을 팀원끼리 먼저 정리한 뒤 리스트와 대조
- **스타벅스 기프트카드 3만원권 처리**
- 예산의 20%를 차지하며, 팔 물건이 아니라 경품에 해당
- 재료비에 넣으면 단위 원가가 부풀려져 마진 계산이 어긋남
- 경품으로 유지할 경우 별도 항목으로 표시하고 금액 재검토
- 가죽끈 항목에만 배송비 2,800원 발생 → 같은 판매자에서 함께 살 품목이 있는지 확인
- 남은 예산 사용 계획 수립
**DIY 머핀**
- 팀 이름 칸 공란 → 2부에서 정한 상호명 기입
- **위생용품 전면 누락** → 추가 필요
- 일회용 장갑
- 위생모 또는 두건
- 물티슈
- 일회용 테이블보
- 쓰레기봉투
- 남은 예산이 적은 편 → 위생용품 확보를 위해 기존 품목 수량 조정 검토
- 수량 불일치: 머핀 60개 대비 디저트컵 100개 → 목표 생산 개수 확정 후 재산정
- 9번 디저트컵 항목의 구매 링크가 2번 머핀 링크와 동일 → 올바른 링크로 교체
- 배송비 칸 전체 공란 → 항목별 확인 후 입력
**삼위일체 피크닉**
- 팀 이름 칸 공란 → 2부에서 정한 상호명 기입
- 예산 절반 이상이 남아 있음 → 아래 누락 항목 보완에 사용
- 초콜릿 컴파운드를 담았으나 만들고 포장할 재료 없음
- 실리콘 몰드
- 개별 포장재
- 일회용 장갑
- 음료 판매 관련 누락 항목
- 얼음 또는 아이스박스
- 컵 뚜껑
- 돗자리 2개, 미니테이블 2개 → 한 번에 몇 팀을 받을지 정한 뒤 수량 조정 판단
## 2-4. 마감 기준
- 총 지출액 150,000원 이하
- 팀 이름, 목표 생산 개수, 판매 가격 기입 완료
- 마진율 30% 이상
- 모든 항목에 구매 링크 기재
- 배송비 항목별 확인 완료
- 먹거리 팀은 위생용품 포함

# 3. 2부 — 브랜드 3요소 확정 (25분)
## 3-1. 왜 필요한가
- 플리마켓 당일에는 여러 부스가 나란히 늘어섬
- 무엇을 파는 곳인지 한눈에 드러나지 않으면 손님의 발걸음이 멈추지 않음
- 브랜딩: 우리 제품에 고유한 이름과 표시를 붙여 다른 부스와 구별되게 만드는 일
- 이 시간은 종이 작업만 진행, 화면 작업은 3부에서 시작
## 3-2. 확정할 세 가지
**첫째, 공식 상호명**
- 3\~5음절 내외로 부르기 쉬울 것
- 이름만 듣고 무엇을 파는지 짐작 가능할 것
- 다른 팀과 겹치지 않을 것
- 지금 팀명을 그대로 쓸지, 새로 지을지 팀 내에서 결정
- GLMF는 초성이라 손님이 읽기 어려움 → 읽을 수 있는 이름인지 재검토
**둘째, 슬로건**
- 핵심 가치를 10글자 내외 한 문장으로 압축
- 구성: 핵심 혜택 + 약속
- 예시: "내 맘대로 고르는 달콤함", "돗자리 깔고 잠깐 쉬어가기"
**셋째, 브랜드 컬러**
- 메인 컬러 1개, 보조 컬러 1개
- 메인 컬러는 부스 전체 인상, 보조 컬러는 강조 요소에 사용

## 4-2. Canva 작업 순서
**1단계. 캔버스 만들기**
- canva.com 접속 후 우측 상단 \[디자인 만들기\] 클릭
- \[맞춤형 크기\] 선택
- 단위를 mm로 변경, 가로 50 세로 50 입력
- 라벨 스티커 표준 규격이며 크게 늘려 써도 깨지지 않음
**2단계. 배경 컬러 지정**
- 좌측 \[배경\] 탭에서 2부에 정한 메인 컬러 선택
**3단계. 상호명 입력**
- 좌측 \[텍스트\] → \[제목 추가\] → 상호명 입력
- 추천 한글 폰트
- 굵고 단단한 느낌: 지마켓산스 Bold, 에스코어드림 7
- 친근하고 둥근 느낌: 배달의민족 주아, 티머니 둥근바람 Bold
- 깔끔한 느낌: Pretendard Bold
- 글자 색은 보조 컬러로 지정해 배경과 대비 확보
**4단계. 요소 추가**
- 좌측 \[요소\] 탭에서 우리 아이템과 관련된 키워드 검색
- 단색 2D 그래픽 선택, 사진이나 3D는 줄이면 뭉개짐
- 요소는 1개까지만 사용
**5단계. 정렬과 여백**
- 가장자리에서 3mm 이상 안쪽으로 모든 요소 배치
- \[위치\] → \[가운데 정렬\]로 균형 조정
**6단계. 다운로드와 제출**
- 우측 상단 \[공유\] → \[다운로드\] → PNG 선택
- 파일명: 교육기관_팀명_로고.png
- 지정 폴더에 업로드
## 4-3. 제출 전 확인
- 손바닥 크기로 줄였을 때 상호명이 읽히는가
- 사용한 색이 3개 이하인가
- 가장자리 글자가 잘리지 않는가
- 파일명 형식을 지켰는가
## 4-4. 자주 하는 실수
- 요소를 너무 많이 넣기 → 실제 스티커 크기로 줄이면 뭉개짐, 아이콘 1개면 충분
- 색을 여러 개 쓰기 → 메인과 보조 두 가지만 사용
- 글자를 가장자리에 붙이기 → 인쇄할 때 잘려 나감
