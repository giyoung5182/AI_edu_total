# Streamlit 기초 체험 (VSCode)

## 이 실습으로 하는 것
Streamlit 파일을 만들고 터미널에서 실행해, 브라우저에 웹페이지가 뜨고 입력값을 바꾸면 화면이 다시 그려지는 것을 확인합니다.
## 진행 단계
1. **파일 생성 + 터미널 열기** — `hello_streamlit.py` 파일을 만들고 Ctrl+J로 터미널 열기
2. **스트림릿 설치** — 터미널에 입력 (또는 클로드코드에 요청)
- 입력할 내용: `py -m pip install streamlit`
3. **코드 붙여넣기** — 코드 블록 안의 내용만 복사해 붙여넣기(박스 바깥 설명 문장은 복사하지 않기), `hello_streamlit.py`로 저장(Ctrl+S)
- 입력할 내용:
```javascript
# hello_streamlit.py — Streamlit 웹 앱
import streamlit as st
st.write("Hello, 오롱 씨!")
name = st.text_input("이름을 입력하세요", "오롱")
st.write(f"{name}님, 오늘 매출 데이터를 분석해봅시다.")
```
1. **실행** — 터미널에 명령어 입력
- 입력할 내용: `streamlit run hello_streamlit.py` (또는 `py -m streamlit run hello_streamlit.py`)
- 정상 결과: VSCode 터미널은 켜진 채로 남고, 브라우저가 자동으로 열려 [개별 링크 제외] 에 웹페이지가 뜸. 프로그램은 종료되지 않고, 이름을 바꾸면 화면이 곧바로 다시 그려짐
## 막히는 지점
- 스트림릿 코드는 우측 상단 재생 버튼으로 실행할 수 없고, 터미널에 streamlit run 명령어를 직접 입력해야 합니다.
