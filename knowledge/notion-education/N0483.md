# STEP 5 | 첫 테스트 — 실제 업무 내용으로 돌려보기

정리일: 2026-10-08 · 교육 에셋 N0483

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
등록한 Gem에 실제 업무 내용을 넣어 결과를 점검한다.
## 진행 단계
1. **테스트 입력** — 공문(사업명·신청 기간·지원 대상·지원 내용·문의처 입력) / 보고서(1부 더미데이터) / 회의록(녹취록 샘플) 중 내 업무에 맞게
2. **결과 점검** — P의 순서·형식·분량 / 입력하지 않은 수치·날짜 생성 여부 / \[미기재\] 표시 / Golden Sample 문체 유사성
3. **개선** — 고칠 부분은 지시문의 해당 칸 수정 → 저장 → 재테스트
## 막히는 지점
- 너무 길다 → P에 분량 제한(예: A4 1장)
- 문체가 어색하다 → K의 Golden Sample을 더 구체적인 문서로 교체
- 빠진 항목 → P의 출력 항목에 추가
- 임의로 수치 생성 → 금지 문구 추가
