## 이 실습으로 하는 것
터미널 두 창과 브라우저 한 창으로 작업 환경을 만들고 Claude Code를 실행합니다.
## 진행 단계
1. **터미널 열기** — WSL 터미널을 두 개 엽니다 (시작 메뉴 → Ubuntu를 두 번 실행)
2. **작업 폴더 만들기** — 두 창 모두에서 이동
- 입력할 내용:
```plain text
cd ~
mkdir disaster-bot
cd disaster-bot
```
1. **Claude Code 실행** — 터미널 A에서 `claude` 입력
2. **폴더 신뢰** — "Yes, I trust this folder" 선택
3. **명령어 훑기** — /help 입력
## 막히는 지점
- claude: command not found → 터미널을 완전히 닫고 새로 연 뒤 다시 실행, 그래도 안 되면 진행요원 호출
- 로그인 화면이 나타남 → 첫 실행 인증, 브라우저에서 로그인
- /init이 오래 걸림 → 빈 폴더 기준 1분 내외면 정상
