# 실습 1. 내 계정 설정 3곳 점검 (보충)

정리일: 2026-10-08 · 교육 에셋 N1522

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
본인 ChatGPT 계정의 메모리·맞춤 지침·모델 개선(학습 사용) 설정을 설정 화면에서 직접 확인하고 메모장에 기록한다. 메모리나 맞춤 지침이 켜져 있으면 실습 결과가 사람마다 달라질 수 있기 때문.
## 진행 단계
1. **준비와 예측** — ChatGPT 웹(chatgpt.com) 로그인, 새 채팅 화면, 메모장 1개를 준비하고 '내 메모리는 켜져 있을까', '맞춤 지침에 무언가 적혀 있을까'를 먼저 적는다
2. **설정 열기** — 화면 왼쪽 아래 본인 이름(프로필) 클릭 → 메뉴에서 설정 클릭 (위치·이름이 다르면 프로필 아이콘 근처 톱니바퀴 모양 메뉴 사용, 교안에서도 \[확인 필요\]로 표시)
3. **메모리 확인** — 설정 창 왼쪽 목록에서 개인 맞춤 클릭 → 메모리 항목의 켜짐/꺼짐 확인
- 정상 결과: 메모리 켜짐/꺼짐 상태를 설정 화면에서 직접 확인함
4. **메모리 관리 확인** — 메모리 관리 버튼이 있으면 클릭해 저장된 항목 개수와 업무 관련 항목 유무만 확인 (지우거나 끄는 것은 본인 판단, 오늘 실습 진행에는 영향 없음)
5. **맞춤 지침 확인** — 같은 개인 맞춤 화면에서 맞춤 지침(커스텀 인스트럭션) 입력칸에 적힌 내용 확인
6. **모델 개선 확인** — 설정 창 왼쪽 목록에서 데이터 제어 클릭 → 모두를 위한 모델 개선 항목의 켜짐/꺼짐 확인
7. **AI 답과 대조** — 설정 창을 닫고 새 채팅에서 아래 프롬프트를 붙여넣고 Enter
- 입력할 내용:
```plain text
지금 이 대화에서 네가 참고하고 있는 나에 대한 정보(메모리, 맞춤 지침 등)가 있다면 항목별로 그대로 보여줘.
없으면 "없음"이라고만 답해.
추측으로 채우지 말고, 확실하지 않은 항목은 "확인 불가"라고 적어줘.
```
- 정상 결과: 2\~6번에서 본 설정 상태와 AI의 답이 서로 맞음. 둘이 다르면 설정 화면을 믿음 (AI 답은 보조 확인용). 메뉴 이름이 다르거나 찾을 수 없으면 '메뉴 위치 확인 불가'로 기록(오답 아님)
1. **기록** — 메모장에 `메모리: 켜짐/꺼짐 · 저장 항목 유무 · 맞춤 지침: 있음/없음 · 모델 개선: 켜짐/꺼짐 · 점검 날짜` 형식으로 남김 (Part 1 Step 05 보안 기준에서 다시 봄)
## 막히는 지점
- 메뉴가 안 보임 → 화면 오른쪽 위·왼쪽 아래의 프로필 아이콘을 차례로 눌러 설정 찾기. 그래도 없으면 강사에게 화면 보여 주기
- AI 답이 설정 화면과 다름 → 아래 요청으로 다시 확인
```plain text
설정 화면에서는 [메모리가 꺼져 있음 / 맞춤 지침이 비어 있음]으로 보여.
방금 답에서 이와 다른 부분이 어디서 나온 것인지 설명하고, 근거가 없으면 "근거 없음"으로 표시해줘.
```
