# 실습 4 — 해석 멘트 생성 → Executive Summary → PPT 1슬라이드 완성

정리일: 2026-10-08 · 교육 에셋 N1217

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
수익성 데이터에서 해석 멘트와 Executive Summary를 만들고, 차트·KPI·요약을 PPT 한 장에 담습니다.
## 진행 단계
1. **\[파트 A\] 해석 멘트 요청** — Copilot에 실습 1의 표와 함께 입력
- 입력할 내용:
```javascript
아래 2025년 상반기 분야별 수익성 데이터를 분석하고
임원 보고용 해석 멘트를 작성해줘.
- 핵심 인사이트 2가지 (구체적인 수치와 증감률 포함)
- 주목할 이상치 또는 특이 변화 1가지 (어떤 분야, 어떤 달인지 명시)
- 다음 액션 제안 1가지
문체: 단언형, 수치 중심, 불필요한 수식어 없이

[실습 1의 수익성 데이터 표 붙여넣기]
```
2. **체크리스트로 검토** — 수치가 실제 데이터와 일치하는지 / 불확실한 표현이 없는지 / 이상치가 구체적(분야·월·수치)인지 / 액션이 실행 가능한지
3. **필요 시 후속 프롬프트로 개선** — 예: 수치가 빠진 인사이트에 증가율 추가, 액션 제안에 시기와 담당 주체 포함 요청
4. **Executive Summary 요청**
- 입력할 내용:
```javascript
위에서 작성한 해석 멘트를 바탕으로
임원 보고용 Executive Summary를 작성해줘.
분량: 5줄 이내
구성:
① 한 줄 결론 (가장 중요한 발견)
② 핵심 수치 2~3개 (전기 대비 변화율 포함)
③ 주요 리스크 또는 기회 1가지
④ 권고 액션 1가지
문체: 단언형, 수치 중심, 군더더기 없이
```
5. **\[파트 B\] PPT 1슬라이드 구성** — 빈 슬라이드에 ① 제목(20\~24pt, 굵게) ② 실습 2의 차트(좌측) ③ 삽입 → 도형 → 직사각형 3개로 KPI 박스(핵심 수치 1개씩) ④ 주목 포인트 1줄 ⑤ 하단 Executive Summary(10\~12pt)를 배치
6. **체크리스트로 점검·저장** — 3초 안에 핵심 메시지 전달 / 차트 제목·KPI 일치 / Executive Summary 수치 일치 / 글씨 크기 / 색상 3가지 이내 확인 후 `수익성분석_보고슬라이드_[날짜].pptx`로 저장
- 정상 결과: 표·차트·KPI 박스·Executive Summary가 한 슬라이드에 배치된 임원 보고용 1슬라이드
## 막히는 지점
- Copilot이 계산을 잘못하거나 데이터를 잘못 해석할 수 있어 숫자는 원본 데이터와 대조합니다.
- "단언형, 수치 중심, 군더더기 없이" 문체 지시가 없으면 "\~한 것으로 보입니다" 같은 불확실 표현이 나옵니다.
