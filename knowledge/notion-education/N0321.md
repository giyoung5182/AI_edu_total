# Step 3. 메인에 연결하고 실행하기 (라우팅)

정리일: 2026-10-08 · 교육 에셋 N0321

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 Subagent를 이름으로 불러 사고 10건을 한 번에 검토시키고, 라우팅 개념을 확인합니다.
## 진행 단계
1. **이름을 불러 맡기기** — 터미널 입력창에 아래를 입력하고 엔터를 누릅니다.
- 입력할 내용:
```javascript
보상검토 에이전트한테 data 폴더의 사고 건들을 보상 검토 맡겨줘.
운전자보험 약관의 보상 기준을 기준으로, 건별로 판정과 사유를 표로 정리해줘.
```
- 정상 결과: Claude가 해당 담당자에게 배정해 실행하고, 폴더 안 사고 건들을 하나씩 읽으며 검토를 시작합니다.
1. **이름을 뺀 경우 확인** — 이름 없이 요청하면 메인 Claude가 에이전트를 부르지 않고 직접 처리할 수 있습니다. 화면에 에이전트 이름 없이 메인이 파일을 읽는 흐름만 보이면 이 경우입니다(고장이 아닌 자동 라우팅의 성질).
2. **반드시 고정하고 싶을 때** — 입력창에서 `@`를 눌러 에이전트를 태그하면 해당 에이전트 실행이 보장됩니다.
3. **(참고) 자가 복제 오류 대응** — 에이전트 생성 프롬프트 맨 마지막에 아래를 적거나, 에이전트 파일 YAML에 `disallowedTools: [Agent]`를 넣고 `/exit` 후 `claude`로 재시작합니다.
- 입력할 내용:
```javascript
"추가로, 이 에이전트가 스스로를 무한 호출하거나 다른 에이전트에게 업무를 토스하지 못하도록 설정(disallowedTools)에 'Agent'를 반드시 추가해줘."
```
## 막히는 지점
- 이름을 빼면 메인이 직접 처리해 버리는 경우가 있음
- 이름을 불러도 안 되면 요청에 "보상검토" 같은 지칭이 있는지, description에 "보상 검토, 사고 건 검토, 보상 심사" 호출 문구가 있는지 확인
- 서브에이전트가 스스로를 반복 호출하는 현상(Waiting for background agents)
