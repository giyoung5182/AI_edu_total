# GPT로 디자인을 점검하고 시안을 개선합니다 (선택)

정리일: 2026-10-08 · 교육 에셋 N0690

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
완성한 캔바 앞면을 ChatGPT로 점검받고, 필요하면 이미지 또는 HTML 시안을 받아 비교한 뒤 캔바에서 수정합니다(선택).
## 진행 단계
1. **앞면 완성 후 캡처** — 캔바에서 앞면을 완성하고 화면 캡처로 앞면만 캡처해 ChatGPT에 첨부합니다.
2. **디자인 개선 지시문 보내기**
- 입력할 내용:
```javascript
첨부한 이미지는 내가 캔바에서 만든 명함 앞면이야. 문구를 새로 쓰거나 사실을 추측하지 말고, 디자인만 검토해 줘.

아래 기준을 표로 정리해 줘.
| 기준 | 화면에서 확인되는 점 | 개선이 필요한 이유 | 캔바에서 바꿀 구체적인 방법 |
(이하 교안 참고)
```
1. **반영** — 수정 제안 중 한두 가지만 캔바 원본에 반영합니다. 최종 문구와 연락처는 엑셀에 기록한 내용을 기준으로 확인합니다.
2. **다른 방향 시안 (이미지 또는 HTML 중 선택)** — 교안의 이미지 시안 요청문 또는 HTML 시안 요청문에 이름/상호·한 줄 소개·직함·연락처·분위기를 채워 보냅니다. 생성 결과는 참고용입니다.
3. **비교하고 수정** — 캔바 시안과 GPT 시안을 나란히 보며 이름·상호와 하는 일이 먼저 읽히는지 확인하고, 상단의 글자 크기·색·`위치` 메뉴에서 필요한 부분만 수정합니다.
4. **시트 확인** — `명함 설계·검수` 시트 `B24:B26`이 실제 선택과 같은지, 오탈자나 잘못된 연락처가 없는지 확인합니다.
## 막히는 지점
- 생성 결과는 참고용이며, 최종 인쇄 파일은 캔바에서 완성합니다.
