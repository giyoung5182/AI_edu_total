## 이 실습으로 하는 것
공용 PC에 있는 결과물을 내 메일과 내 노션으로 가져온다.
## 진행 단계
1. **보낼 것 정리** — 내 메일로 portfolio.html, PDF, 재료 텍스트 파일 4개를 첨부해 발송
2. **노션 내보내기** — 커리어 아카이브 페이지 오른쪽 위의 점 세 개를 누르고 내보내기를 선택
3. **형식 선택** — PDF 또는 마크다운
4. **하위 페이지 포함 켜기** — 표까지 함께 내보낸다
5. **메일 전송** — 내려받은 파일을 본인 메일로 전송
6. **반출 점검** — 메일이 실제로 도착했는지 받은편지함에서 확인 / 첨부파일이 열리는지 / 휴대폰에서도 열리는지 / PDF에 색이 나오는지 / 노션 내보내기에 표가 포함되었는지
- 정상 결과: 첫 번째(받은편지함 도착 확인)를 반드시 수행
## 막히는 지점
- 4번을 켜지 않으면 가치관 진단 표와 경험 목록 표가 빠짐
- 보냈다고 생각했는데 임시보관함에 있는 경우가 자주 있음
