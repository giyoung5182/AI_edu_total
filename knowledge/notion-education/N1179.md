# 실습 — 퀴즈 앱 만들기 (STEP 1 설계 → 2 생성 → 3 수정 → 4 검증)

정리일: 2026-10-08 · 교육 에셋 N1179

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
SW 기초 퀴즈 앱(5문제)을 설계 → 생성 → 수정 → 검증 4단계로 만든다.
## 진행 단계
1. **STEP 1 설계 (5분)** — 네 축으로 사양 정하기: 대상(초등 5\~6학년, 각자 폰 접속) / 내용(SW 기초 5문제: 알고리즘·순서도·반복문·입출력·버그) / 동작(한 문제씩 → 즉시 채점 → 해설 → 최종 점수) / 제약(AI 호출 금지, 외부 리소스 금지, 모바일 필수)
- 네 칸을 못 채우면 Claude에게 "초등 5학년용 SW 퀴즈 앱을 만들려고 해. 어떤 형태가 좋을지 세 가지 안을 제안하고, 각각의 장단점을 표로 정리해줘"라고 요청
2. **STEP 2 생성 (12분)** — 새 대화를 열고(1차시 대화에서 이어하지 않음), 모델을 Sonnet으로 바꾼 뒤 아래 프롬프트 입력
- 입력할 내용:
```plain text
초등학교 5~6학년 대상 SW 수업에서 쓸 퀴즈 앱을 만들어줘.
교사가 링크를 공유하면 학생들이 각자 휴대폰으로 접속해서 푸는 방식이야.

[내용]
- 객관식 4지선다 문제 5개
- 주제는 컴퓨터·코딩 기초 개념 (알고리즘, 순서도, 반복문, 입력과 출력, 버그)
- 한 문제씩 보여주고, 답을 고르면 정답 여부를 바로 알려줘
- 오답일 때는 왜 틀렸는지 한 줄 설명
- 마지막에 점수와 격려 메시지

[문제 스타일 예시]
"컴퓨터에게 일을 시키려면 순서를 정해줘야 해요.
 이렇게 정해진 순서를 뭐라고 부를까요?"

[디자인]
- 초등학생 대상이므로 큰 글씨, 밝고 친근한 색상
- 버튼은 손가락으로 누르기 쉬운 크기
- 휴대폰 세로 화면 기준으로 배치

[기술 조건]
- 순수 HTML과 자바스크립트로만 만들어줘. AI 호출 기능은 넣지 마
- 외부 이미지나 외부 라이브러리는 쓰지 말고, 필요하면 이모지나 도형으로 표현해줘
- 문제 목록은 코드 맨 위에 따로 모아서 주석과 함께 정리해줘
```
- 정상 결과: 처음부터 끝까지 풀어보고, 다 틀리면 0점·다 맞히면 만점이 나오는지 확인
3. **STEP 3 수정 (15분)** — 요청을 하나씩 넣고 결과를 확인한 뒤 다음으로 진행
- 입력할 내용: "정답을 맞혔을 때 축하 효과를 추가해줘. 다른 기능은 그대로 두고." / "문제 순서를 매번 무작위로 섞어줘. 나머지는 그대로." / "지금 몇 번째 문제인지 상단에 표시해줘 (예: 3 / 5). 나머지는 그대로." / "마지막 결과 화면에 "다시 풀기" 버튼을 추가해줘. 나머지는 그대로."
- 진도가 빠른 경우 힌트 추가 요청(정답을 직접 알려주지 않고 생각할 방향만 제시)
4. **STEP 4 검증 (3분)** — 동작 정확도(5문제 진행, 정답 판정, 오답 해설, 점수 일치) / 내용 품질(학년 수준, 정답 정확히 하나, 해설 이해도, 사실관계, 한글 깨짐) / 사용 환경(폰 화면에서 글자·버튼 잘림 여부)
## 막히는 지점
- 생성 중에는 입력하지 말고 오른쪽 미리보기가 안정된 뒤 다음 요청
- 옆자리와 결과가 다른 것은 확률적 생성이라 정상
- 수정을 한꺼번에 넣으면 원래 잘 돌던 기능이 깨지는 회귀 발생. "나머지는 그대로" 명시
- 점수 계산은 반드시 검산하고, 문제 내용의 사실관계는 사람이 읽어서 확인
