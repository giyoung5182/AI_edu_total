## 이 실습으로 하는 것
가게 이름 글씨 자체를 디자인으로 삼는 워드마크형 로고 하나를 Canva로 만들어 제출한다.
## 진행 단계
1. **캔버스 만들기** — canva.com 접속 → 우측 상단 \[디자인 만들기\] → \[맞춤형 크기\] → 단위 mm, 가로 50 세로 50
- 라벨 스티커 표준 규격이며 크게 늘려 써도 깨지지 않음
2. **배경 컬러 지정** — 좌측 \[배경\] 탭에서 2부에 정한 메인 컬러 선택
3. **상호명 입력** — 좌측 \[텍스트\] → \[제목 추가\] → 상호명 입력, 글자 색은 보조 컬러로 지정해 배경과 대비 확보 (추천 폰트는 교안 참고)
4. **요소 추가** — 좌측 \[요소\] 탭에서 키워드 검색, 단색 2D 그래픽 선택, 요소는 1개까지
5. **정렬과 여백** — 가장자리에서 3mm 이상 안쪽으로 배치, \[위치\] → \[가운데 정렬\]
6. **다운로드와 제출** — 우측 상단 \[공유\] → \[다운로드\] → PNG, 파일명 교육기관_팀명_로고.png, 지정 폴더에 업로드
- 제출 전 확인: 손바닥 크기로 줄였을 때 상호명이 읽히는가 / 색 3개 이하 / 가장자리 글자가 잘리지 않는가 / 파일명 형식
## 막히는 지점
- 요소를 너무 많이 넣기 → 실제 스티커 크기로 줄이면 뭉개짐, 아이콘 1개면 충분
- 색을 여러 개 쓰기 → 메인과 보조 두 가지만 사용
- 글자를 가장자리에 붙이기 → 인쇄할 때 잘려 나감
