# 실습 RCTC 프롬프트 작성 실습 (엑셀 데이터 분석)

정리일: 2026-10-08 · 교육 에셋 N1517

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
강사가 제공한 가상 실적 데이터를 Claude 앱(또는 ChatGPT)에 넣고, RCTC 프롬프트를 직접 작성해 분석을 요청한다.
## 진행 단계
1. **Claude 앱 설치 및 파일 업로드 (3분)** — Claude 앱 새 채팅에서 첨부 버튼으로 단톡방에서 받은 엑셀 파일을 선택한다. ChatGPT는 새 채팅에서 임시 채팅을 선택한 뒤 파일을 업로드한다. 노트북만 있으면 데이터를 복사해 채팅창에 붙여넣는다.
2. **RCTC 프롬프트 직접 작성 (7분)** — 분석 질문 3개 중 1개를 고른다(달성률 진단 / 지역별 편중 분석 / 만족도 분석). R(역할), C(맥락), T(과업), C(제약)를 채운다.
- 입력할 내용(R 예시):
```javascript
너는 ____ 경력 ___년의 전문가야.
____ 경험이 있어.
결과물은 ____ 어조로 작성해.
```
- 시트 선택: 질문 1·2는 기업지원실적_2025, 질문 3은 기업만족도_2025
3. **프롬프트 전송 및 결과 확인 (5분)** — 파일 첨부 여부를 확인하고 전송한다. 결과가 마음에 안 들면 정렬·요약·표 형식 재요청을 한다.
- 정상 결과: T에서 요청한 항목이 모두 포함되고 표가 요청대로 나온다.
## 막히는 지점
- 결과 체크: 요청 항목 누락, 표 형식, 데이터에 없는 내용, 핵심 수치 원본 대조
