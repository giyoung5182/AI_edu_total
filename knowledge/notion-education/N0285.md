## Step C · 설계서 1장 틀
① 아래 틀 복사 → 메모장에 붙여넣기 → Step A·B에서 적은 것부터 옮겨 적기 → `D2P5_설계서.txt`로 저장
- `→` 뒤 힌트는 채운 뒤 지움
```plain text
[설계서 1장]  작성자:      / 작성일:      / 버전: v1

1. 업무 이름:
   → 동사로 끝나게. 예: 출장정산 확인 목록 만들기
2. 지금 방식과 걸리는 시간:
   → 누가 · 얼마나 자주 · 무엇을 + 1회 걸리는 시간(본인 추정, "추정"이라고 적기)
3. 목표:
   → 도구가 끝나면 손에 남는 것 1줄(결과 시트·파일·답변 모양)
4. 프로세스 쪼개기 표:
   → Step B 표 붙여넣기(번호 | 단계 | 하는 일 | 누가 | 필요한 자료 | 결과물 | 판단 필요) + 작업 순서
5. 원하는 도구 조합:
   → 6번 단계 번호별 도구(새 채팅·데이터 분석 / 프로젝트 / Work + 폴더)
6. 반복 주기:
   → 사람이 언제 다시 돌리나(매일·매주·매월) + 그때 바꿔 넣을 것(새 회차 입력 파일)

   → 6번 단계 번호 + 누가(직책) + 무엇을 결정
8. 완료 기준:
   → "이것이 나오면 이 단계 끝" 1~3줄(건수가 원본과 같음, 두 번 돌려도 같음 등)
```

② 개인정보 가리기 — 성명·연락처·카드번호 같은 칸은 가명(예: `직원01`)으로 바꾸거나 열을 지움. 사내 보안 정책이 우선(1일차 Part 1 Step 05)
③ 열 이름 통일 — 1행에 머리글 한 줄, 병합 셀·빈 행·소계 행 없음, 같은 뜻의 열은 설계서 5번에 적은 이름 그대로
- 이유: `AGENTS.md`는 **열 이름 글자**로 열을 찾음 → 한 글자만 달라도 0건
④ AI로 상태 점검 — 새 채팅에 정리본 첨부(입력창 왼쪽 **+** → **사진 및 파일 추가**) → 아래 입력 → **Enter**
```plain text
첨부 파일의 [시트 이름] 시트만 코드로 직접 확인해 줘.
- 먼저 읽은 행 수(머리글 제외)와 열 이름을 보고해 줘.
- 5단계 점검: 구조 · 결측(0과 빈칸 구분) · 이상값 · 일관성(같은 대상의 다른 표기, 날짜 형식 섞임) · 중복
- 결과 표: 단계 / 발견 내용 / 건수 / 행번호
- 원본 값은 고치지 말고, 빈칸을 0으로 채우지 말 것
```
⑤ 고칠지 말지는 사람이 결정 — 이상값은 지우지 않고 표시, 고친 내용은 `정리기록.txt`에 한 줄씩(행번호 · 전 → 후 · 이유)
- 첫 단계 끝: 정리본 1개 + 정리기록 → 설계서 5번 상태를 "있음(정리본)"으로 고침
</details>

<summary>E-2-1 데이터가 없는 사람 — 가짜 데이터 만들기</summary>
- 왜: 실제 자료를 사외 AI에 올릴 수 없음 / 아직 자료가 쌓이지 않음 / 개인정보가 섞여 가리기 어려움 → **열 구조가 같은 가짜 데이터**로 도구를 먼저 만들고, 실제 자료에는 사내 환경에서 적용
- 준비: 실제 자료의 **열 이름과 값의 종류만** 메모(실제 값은 옮기지 않음)
① ChatGPT **새 채팅**에 아래 프롬프트 복사 → `[ ]` 바꾸기 → **Enter**
```plain text
교육·도구 제작용 가짜 데이터를 엑셀 파일로 만들어 줘. 실제 회사·사람 정보는 쓰지 마.
- 시트 이름: [예: 출장정산내역]
- 열(이 순서 그대로): [예: 정산번호, 부서, 성명, 출장지, 출발일, 결제방법, 영수증첨부, 금액]
- 열마다 값의 종류: [예: 정산번호는 EX-0001부터 차례로 / 결제방법은 "법인카드" 또는 "개인카드 후정산" / 영수증첨부는 "첨부" 또는 "미첨부" / 금액은 숫자]
- 행 수: [예: 50]행 (1행은 머리글)
- 일부러 넣을 오류 — 넣은 위치를 행번호와 함께 별도 목록으로 알려 줘:
  · 빈칸 [2]개
  · 형식 오류 [2]개 (예: 금액 칸에 "1,200,000원"처럼 글자, 날짜 표기 섞기)
  · 중복 [1]개 (같은 정산번호)
- 성명·회사명은 "가상직원01", "가상고객사A"처럼 누가 봐도 가짜인 이름
- 코드로 만들어서 .xlsx 파일로 내려받을 수 있게 해 줘
```





문장

하는 일




`열(이 순서 그대로)` · `열마다 값의 종류`

실제 자료와 구조를 똑같이 맞춤 → 나중에 실제 자료로 바꿔도 도구가 그대로 돌아감




`일부러 넣을 오류` · `행번호 목록`

도구가 오류를 찾는지 맞춰 볼 기준이 생김




`누가 봐도 가짜인 이름`

실존 인물·회사로 오해할 일 방지




`코드로 만들어서 .xlsx`

행 수·오류 개수를 정확히 맞춤


② 파일 받기 — 답에 나온 **파일 이름 링크** 클릭 → 내려받기 \[확인 필요 — 계정·화면에 따라 파일 생성 방식이 다를 수 있음\]
- 링크 없이 글로만 답하면: `xlsx 파일로 만들어 줘` 한 번 더
- 그래도 파일이 없으면: `표로 보여 줘` → 표를 복사해 엑셀 빈 시트 A1에 붙여넣기
③ 받은 오류 목록의 행번호를 엑셀에서 직접 찾아가 실제로 그 칸에 오류가 있는지 확인 → 이 목록이 나중에 도구 결과와 맞춰 볼 기준
**주의**
- 파일 이름에 가짜 표시: `EX_출장정산_가짜데이터.xlsx`
- 가짜 데이터의 건수·금액을 실제 수치처럼 보고서에 쓰지 않음
- 실제 자료를 붙여넣고 "비슷하게 바꿔 줘"로 만들지 않음 → 그 순간 원본이 AI에 들어감
- 오류 개수는 적게 — 도구 결과와 하나씩 맞춰 볼 수 있을 만큼
- 첫 단계 끝: 가짜 데이터 파일 + 오류 목록 → 설계서 5번 상태를 "가짜 데이터(EX_)"로 고침

① 폴더 만들기 — 내 업무 폴더는 **영어 소문자 · 숫자 · 하이픈**으로(2일차 Part 3 「폴더·파일 이름은 한글보다 영어」)

```plain text
expense-check/        ← 업무 하나 = 폴더 하나
```

```plain text
아래 설계서로 AGENTS.md를 써 줘. 2일차에 배운 6칸 순서 그대로:
```
