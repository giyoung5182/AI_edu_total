# Step 03 :: 화면을 맞춥니다.

정리일: 2026-10-08 · 교육 에셋 N1346

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
시작 전에 네 가지 항목을 눈으로 확인해 오늘 화면 상태를 맞춥니다.
## 진행 단계
1. **로그인 확인** — Claude 데스크톱 앱에 교육용 계정으로 로그인되어 있는지 봅니다.
- 정상 결과: 교육용 계정으로 로그인됨 (아니면 로그인 화면에서 계정을 다시 확인)
2. **프로젝트 확인** — 프로젝트 `내업무-실습`이 목록에 보이는지 봅니다.
- 정상 결과: 목록에 보임 (아니면 검색창에 이름을 직접 입력해 찾기)
3. **파일 위치 확인** — 1일차에 만든 파일 네 개가 바탕화면 `project` 폴더 한 곳에 모여 있는지 봅니다.
- 정상 결과: 한 폴더에 모여 있음 (흩어져 있으면 지금 옮기기)
4. **Code 탭 확인** — 상단 `Code` 탭이 보이는지 봅니다.
- 정상 결과: Code 탭이 보임
## 막히는 지점
- 탭이 안 보이면 계정을 확인한다. 교육용 계정이 아니면 안 보인다.
- 오늘은 `Code` 탭에서 바탕화면에 새 폴더 `coding`을 만들어 연결한다. 1일차의 `project` 폴더와는 다른 폴더다. (연결 방법은 다음 PART에서 안내)
