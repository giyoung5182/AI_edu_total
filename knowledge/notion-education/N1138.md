# ② 제품 가상 이미지

정리일: 2026-10-08 · 교육 에셋 N1138

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
메뉴판·상품 안내판·포스터에 쓸 제품 홍보용 사진을 AI로 만듭니다. 이 이미지에는 글자를 넣지 않습니다.
## 진행 단계
1. **제품 정보 구체화** — 팀 유형별(먹거리/향·화장품/문구·굿즈) 작성 요령에 맞게 재료·그릇·용기·배경 등을 적음
2. **프롬프트 입력**
- 입력할 내용:
```javascript
제품 홍보용 사진을 만들어줘.

- 제품: [아이템을 아주 구체적으로]
- 포장 상태: [예: 투명 용기에 담겨 있음 / 비닐 봉투에 들어 있음]
- 분위기: [예: 밝고 깔끔하게 / 따뜻하고 감성적으로]

조건은 이래.
- 제품이 화면 가운데 크게 들어갈 것
- 배경은 단순할 것
- 글자는 넣지 말 것
- 실제 사진처럼 보일 것

서로 다른 구도로 3개 만들어줘.
```
1. **확인** — 실제로 팔 물건과 너무 다르지 않은지 확인 (그림 느낌을 원하면 '귀여운 일러스트로'로 변경)
2. **저장** — 파일명 교육기관_팀명_제품이미지.png
## 막히는 지점
- 받은 것과 차이가 크면 항의를 받게 됨 / 지나치게 화려하면 신뢰가 떨어짐
