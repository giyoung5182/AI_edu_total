# 3단계 직접 해보기: CDMO 수주 ROI 시뮬레이터

정리일: 2026-10-08 · 교육 에셋 N0462

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
한 번에 완성형을 시키지 않고 탐색 → 정교화 → 형식화 대화로 ROI 시뮬레이터를 만듭니다.
## 진행 단계
1. **1라운드 — 탐색**
```javascript
CDMO 수주 건의 수익성(ROI)을 계산하는 웹앱을 만들고 싶어.
수주금액·생산원가·예상납기·수율을 입력하면 예상 마진과 ROI가 나오게.
어떤 입력 항목과 결과 항목으로 구성하면 좋을지 먼저 제안해줘.
바로 만들지 말고 내가 확인한 후 진행해줘.
```
2. **구성안 검토** — 받은 구성안을 한 번 검토합니다.
3. **2라운드 — 형식화**
```javascript
좋아, 그 구성으로 단일 HTML 파일로 만들어줘.
- 입력 폼 + 계산 결과 카드
- ROI가 마이너스면 빨강, 플러스면 초록으로 표시
- 한국어 UI, 깔끔한 디자인, PC에 저장 가능한 단일 HTML
(차트는 다음 단계에서 추가할게)
```
- 정상 결과: 수주금액·생산원가·납기·수율을 넣으면 마진·ROI가 자동 계산됩니다.
4. **확인** — 미리보기에서 숫자를 넣어 ROI가 계산되는지, 음수일 때 빨강으로 바뀌는지 봅니다.
## 막히는 지점
- AI가 만든 계산식은 한 케이스 직접 검산합니다.
