# 5. 설치 및 로그인 — 4개 단계로 따라가기

정리일: 2026-10-08 · 교육 에셋 N0501

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
GitHub CLI와 Vercel CLI를 Claude Code로 설치하고 로그인합니다. 수강생이 직접 하는 것은 마지막 로그인 창의 버튼 클릭뿐입니다.
## 진행 단계
1. **5-1 CLI 설치** — Code 탭 입력창에 입력합니다.
- 입력할 내용:
```javascript
깃허브 CLI랑 버셀 CLI 설치해줘.
```
2. **5-2 앱 완전 종료 후 재실행** — 새로 설치한 명령어(gh, vercel)는 앱을 다시 시작해야 인식됩니다. 재실행 후 아직 Code 탭 입력창에 지시하지 않습니다.
3. **5-3 설치 확인** — Code 탭 입력창이 아니라 내장 터미널(Ctrl+\`)에서 직접 입력합니다.
- 입력할 내용:
```javascript
gh --version
vercel --version
```
- 정상 결과: 버전 숫자가 두 줄 다 뜸. `command not found`면 앱을 한 번 더 완전히 종료 후 재실행, 그래도 안 되면 5-1로 돌아가 재설치
4. **5-4 로그인** — Code 탭 입력창으로 돌아와 입력합니다.
- 입력할 내용:
```javascript
gh auth login이랑 vercel login 실행해줘. 인증은 내가 브라우저에서 직접 할게.
```
- 정상 결과: 브라우저 새 탭에서 Authorize 클릭 후 Code 탭에 "Logged in" 같은 메시지
## 막히는 지점
- `gh: command not found` / `vercel: command not found` → 설치 직후 터미널이 새 명령어 위치를 모름. 앱 재시작 후 내장 터미널에서 확인
- 클로드 코드가 깃허브 비번을 물어요 → 터미널에서 `gh auth login` 먼저 실행
