# 실습 7 — 화면용 데이터 만들기

정리일: 2026-10-08 · 교육 에셋 N1257

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
대시보드가 읽을 집계 결과 시트(화면데이터)를 스크립트로 만들고 웹에 게시한다. 대시보드는 원본 59행이 아니라 미리 집계한 결과를 읽는다.
## 진행 단계
1. **함수 추가 요청** — 같은 스크립트에 함수를 추가해 달라고 요청한다
- 입력할 내용:
```javascript
같은 스크립트에 함수를 추가해줘.

[할 일]
"화면데이터" 시트를 만들고 아래 형태로 집계 결과를 쓴다.

구분 | 항목 | 값
지표 | 전체건수 | 58
지표 | 완료 | 40
(이하 교안 참고: 진행중·지연, 차트1 상태별, 차트2 부서별, 표 지연 건 형태)

[조건]
- 숫자에 쉼표나 단위를 넣지 말고 순수한 숫자만 쓴다
- 실행할 때마다 전체를 지우고 다시 쓴다
- 맨 아래에 갱신일시를 기록한다

메뉴에 「화면데이터 갱신」 항목을 추가해줘.
```
2. **웹에 게시하기** — 구글 시트 → 파일 → 공유 → 웹에 게시 → 게시할 시트: 화면데이터, 형식: 쉼표로 구분된 값(.csv) → 게시 → 주소 복사
- 정상 결과: 주소가 `[개별 링크 제외] 형태면 성공
## 막히는 지점
- 회사 정책으로 웹 게시가 막힐 수 있음 → 시간을 낙비하지 말고 바로 폴백(실습 8)으로 넘어감
