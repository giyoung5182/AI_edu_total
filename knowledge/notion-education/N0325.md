# Flow로 영상 만들기

정리일: 2026-10-08 · 교육 에셋 N0325

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
앞에서 만든 이미지를 Flow에 넣어 짧은 영상 샘플을 만든다.
## 진행 단계
1. **Create with Flow 선택**
2. **새 프로젝트 선택**
3. **Video 선택** — 우측 하단에서 Video를 선택하고 x1을 선택해 한 번에 하나의 동영상만 나오게 한다.
4. **이미지 업로드·프롬프트 입력** — 이전에 만든 이미지를 업로드하고 프롬프트를 입력한다.
- 입력할 내용:
```javascript
[카메라 움직임]
[피사체 움직임]
[조명/배경 유지]
[영상 느낌/품질]
```
- 예: \[카메라 움직임\] 카메라는 모델을 향해 천천히 앞으로 이동 / \[피사체 움직임\] 모델은 차분하게 걷고, 옷자락과 머리카락은 겨울 바람에 살짝 흔들림 / \[조명/배경 유지\] 겨울 새벽 도시 배경과 고급스럽고 차가운 공기감은 그대로 유지 / \[영상 느낌/품질\] 부드럽고 자연스럽게 이어지는 광고 영상 초안, 형태가 무너지지 않게 안정적으로 생성
## 막히는 지점
- 처음부터 인물이 크게 움직이거나 카메라가 빠르게 이동하면 형태가 무너지거나 장면이 불안정해질 수 있음. 천천히, 살짝, 자연스럽게 같은 표현이 적합.
- 생성형 영상은 텍스트·로고·제품 디테일이 흔들리거나 바뀔 수 있어 대외 배포 전 검수 필요.
