# GitHub·Vercel 가입 (단계별 따라하기)

정리일: 2026-10-08 · 교육 에셋 N1211

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 컴퓨터의 HTML을 인터넷에 공개하기 위해 GitHub(코드 보관)과 Vercel(공개)에 가입하고 두 서비스를 연결합니다.
## 진행 단계
1. **GitHub 가입** — [github.com](http://github.com) 접속 → 우측 상단 **Sign up** → 이메일/비밀번호/유저네임 입력 → 이메일 인증 링크 클릭
- 주의: 유저네임은 나중에 주소에 들어갈 수 있으니 신중히
2. **Vercel 가입** — vercel.com 접속 → 우측 상단 **Sign Up** → **"Continue with GitHub" 버튼 클릭** → 가입 및 로그인
3. **GitHub 연결** — 로그인 후 좌측 하단 **Connect with GitHub** 클릭 → 권한 승인 화면에서 Authorize 클릭 → 같은 자리에 나타난 install 버튼 클릭 후 진행
- 정상 결과: 두 서비스 자동 연결 완료
## 막히는 지점
- GitHub 인증 메일 미수신 → 스팸/프로모션 폴더 확인
- 이메일로 따로 가입하면 나중에 GitHub과 연결하는 단계가 추가로 필요
