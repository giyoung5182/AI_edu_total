# 컨텍스트 엔지니어링

바이브코딩에서는 프롬프트 엔지니어링을 기반으로 한 **컨텍스트 엔지니어링**이 가장 중요합니다.

**컨텍스트(Context) = 맥락**. AI에게 단순히 질문을 잘하는 것(프롬프트 엔지니어링)을 넘어서, AI가 작업에 필요한 **모든 맥락 정보**를 체계적으로 제공하는 것이 컨텍스트 엔지니어링입니다.
### LLM에게 넘겨줘야 하는 정보
- **시스템 지침** : "친절한 튜터처럼 행동해" 또는 "출처만 출력해"와 같은 규칙
- **사용자 프롬프트** : "이 기사를 요약해 줘"와 같은 특정 질문 또는 작업
- **대화 기록** : 일관성을 유지하기 위한 이전 상호작용
- **외부 데이터** : 모델에 제공되는 **문서**, 데이터베이스 또는 API 결과
- **도구** : 웹 검색이나 파일 조작 같은 **도구**에 대한 접근

사실 LLM을 잘 사용하고 있었던 유저는 이미 어느 정도 컨텍스트 엔지니어링을 하고 있었던 것입니다.<br>요청 → 응답받은 것 직접 실행 → 실행 결과를 LLM에게 공유 → 다시 요청... 이 과정 자체가 맥락을 쌓아가는 과정이기 때문입니다.

---

**AI에게 우리 회사 업무에 컨텍스트로 제공하면 좋은 자료**
- 무역·수출입 업무 매뉴얼·사업부 운영규정 주요 발췌
- 우리 회사 공문·품의서·보고서 양식 샘플
- 거래처·해외 바이어 응대 톤·표준 커뮤니케이션 문구 모음
- 무역 직무 용어집, 담당자 제출·결재 라인
문서 작업 시, AI가 이 자료를 볼 수 있도록 해두면, 매번 설명을 다시 하지 않고도 동일한 품질의 결과물이 나옵니다.
