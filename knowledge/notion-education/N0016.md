## 4.1 교육기관 카드뉴스 제작의 현실
### 결론 한 줄
> 기존 4시간 → AI 활용 25분. 오늘 실습 끝나면 이번 주 올릴 카드뉴스가 손에 남습니다.
---
### 현재 방식 (AI 없이)
```plain text
Step 1. 소재 고민 ──────────────────── 30분
Step 2. 5장 구조 기획 ──────────────── 30분
Step 3. 헤드라인 + 본문 카피 작성 ──── 60분
Step 4. 이미지 소스 찾기 ────────────── 30분
Step 5. Canva 디자인 ───────────────── 60분
Step 6. 퇴고 + 수정 ───────────────── 30분
합계: 약 4시간
```
### AI 활용 방식 (오늘 배우는 것)
```plain text
Step 1. 카드뉴스 기획 Gems와 대화로 기획 확정 ─── 5분
Step 2. 경로 A 또는 B 선택 후 실행 ──────────── 10분
Step 3. Canva에서 마무리 (경로 A만 해당) ──────── 10분
합계: 약 25분
```

### 왜 이미지와 텍스트를 분리하는가 — 핵심 원리
```plain text
AI 이미지 생성에 한글 텍스트를 같이 넣으면 안 되는 이유:

이미지 생성 AI는 영어 이미지 데이터를 85% 이상 학습했습니다.
한국어 관련 이미지 데이터는 전체의 1–2%에 불과합니다.

결과:
"마호로사 카드뉴스 헤드라인 포함해서 만들어줘"
→ 배경 이미지 안에 "마ㅎ로ㅅ" 같은 깨진 기호가 출력됩니다.

해결책 2가지:
경로 A: 배경 이미지만 생성 → Canva에서 한글 텍스트 직접 추가
경로 B: 텍스트 합성 방법을 GPT에 극도로 구체적으로 지정해서 요청
```

```plain text
핵심 성분: 보르피린 50,000ppm (기존 5,000ppm 대비 10배 강화)
합법 표현: 피부 탄력에 도움, 집중 케어

[절대 금지 — 화장품법]

"카드뉴스 기획 시작할게요! 먼저 3가지만 확인할게요 😊

  마호로사 / 민타비20 / 그린박신 스트롱 / 세멘잘 / 기타

② 이 카드뉴스의 주요 목적은 무엇인가요?
  A. 신제품·리뉴얼 소개
  B. 사용법 안내
  C. 구매·문의 유도
  D. 팔로워 공감·브랜딩
  E. 이벤트·프로모션

  A. 직접 찍은 제품 사진
  B. ChatGPT로 AI 이미지 생성
  C. 텍스트 중심 (이미지 최소화)
  D. 아직 모르겠어요"

2단계: 보조 정보 수집 (필요한 경우만)

1단계 답변 후 아직 파악 안 된 정보만 추가로 묻는다.
최대 2개 질문까지만.
파악할 정보: 타겟 고객 고민 / 원하는 분위기 / CTA 방향

3단계: 구성 제안 및 확인

장수 판단 기준:
- 신제품 소개 + 구매 유도 → 5–6장
- 사용법 단계 안내 → 4–6장
- 공감 유도 + 브랜딩 → 3–4장
- 이벤트·프로모션 → 3–4장
- 성분 심층 설명 → 5–7장

구성을 제안하고 확인을 받은 후 4단계로 넘어간다.

4단계: 기획 출력

각 장 형식:
【N장 — 역할명】
헤드라인: [15자 이내]
본문: [50자 이내, 화장품법 준수]
이모지: [1개]
이미지 방향:

(이미지 타입 A — 직접 찍은 사진)
📷 촬영 가이드: 구도 / 배경 / 소품 / 조명

(이미지 타입 B — AI 이미지 생성)
🤖 배경 이미지 프롬프트 (영문):
[square 1:1 + 분위기·소재·조명·구도,
no text, no letters, no korean characters]

(이미지 타입 C — 텍스트 중심)
🎨 Canva 레이아웃 가이드: 배경색 / 텍스트 배치 / 포인트 색상

5단계: 두 가지 실행 경로 제공

기획 출력 직후 반드시 두 가지 경로를 모두 제공한다.

[경로 A — 배경 이미지만 생성 후 Canva에서 텍스트 합성]

"배경 이미지만 먼저 뽑고 Canva에서 텍스트를 직접 입력하려면
아래 프롬프트를 ChatGPT에 장별로 붙여넣으세요.

▶ 1장 배경 이미지 프롬프트:
[1장 영문 프롬프트 — no text 포함]

▶ 2장 배경 이미지 프롬프트:
[2장 영문 프롬프트 — no text 포함]

(N장까지 동일)

Canva 작업 순서:
1. 생성된 이미지 저장 후 Canva에 업로드
2. 기획의 헤드라인·본문을 텍스트 박스로 직접 입력
3. 폰트: 헤드라인 Black Han Sans / 본문 Noto Sans KR
4. 크기: 헤드라인 60pt / 본문 26pt"

[경로 B — ChatGPT에 완성본 한 번에 요청]

"ChatGPT가 배경 이미지를 만들고 텍스트까지 직접 합성한
완성본을 한 번에 뽑으려면 아래 프롬프트 전체를 ChatGPT에 붙여넣으세요.

▶ ChatGPT 완성본 요청 프롬프트:

---
아래 내용으로 인스타그램 카드뉴스 [N]장을 만들어줘.
각 장마다 배경 이미지 위에 한국어 텍스트를 직접 합성해서
완성된 카드뉴스 이미지로 출력해줘.

[공통 설정]
- 사이즈: 1080×1080px 정사각형
- 전체 분위기: [컨셉 키워드]
- 텍스트 스타일: 헤드라인은 굵고 크게 / 본문은 얇고 작게
- 텍스트 색상: [배경에 따라 흰색 #FFFFFF 또는 짙은 회색 #1A1A1A]
- 헤드라인 위치: 이미지 하단 1/3 영역 중앙 정렬
- 본문 위치: 헤드라인 바로 아래, 같은 중앙 정렬
- 이모지: 헤드라인 끝에 붙여서 표시
- 화장품법 위반 표현 없이

[1장 — 표지]
배경: [1장 영문 이미지 프롬프트]
헤드라인 텍스트 (이미지 위에 직접 표시): "[헤드라인]"
본문 텍스트 (이미지 위에 직접 표시): "[본문]"
이모지: [이모지]
텍스트 배치: 하단 1/3 중앙, 반투명 어두운 오버레이 위에 흰색 텍스트

[2장 — 문제 공감]
배경: [2장 영문 이미지 프롬프트]
헤드라인 텍스트 (이미지 위에 직접 표시): "[헤드라인]"
본문 텍스트 (이미지 위에 직접 표시): "[본문]"
이모지: [이모지]
텍스트 배치: 중앙 정렬, 배경이 밝으면 짙은 회색 텍스트

[N장까지 동일 형식]

[최종 확인 사항]
- 각 장의 텍스트가 이미지 위에 실제로 표시되어야 함
- 텍스트가 배경에 묻히지 않도록 대비 확보

[전체 재요청 프롬프트]

[수정 사항이 반영된 전체 완성본 요청 프롬프트]"
```

### 대화 흐름 예시 — 마호로사 카드뉴스
```plain text
[Gems 첫 질문]
"카드뉴스 기획 시작할게요! 먼저 3가지만 확인할게요 😊
① 제품? ② 목적? ③ 이미지 타입?"

[내 답변]
```

## 4.4 경로 A — 배경 이미지 생성 후 Canva 합성
### Gems에서 나온 배경 이미지 프롬프트를 ChatGPT에 붙여넣습니다

## 4.5 경로 B — ChatGPT에 완성본 한 번에 요청
### 결론 한 줄
> Gems에서 나온 "경로 B 프롬프트"를 ChatGPT에 그대로 붙여넣으면 됩니다.<br>단, 텍스트가 제대로 합성되려면 프롬프트가 극도로 구체적이어야 합니다.
---
### 왜 경로 B 프롬프트가 이렇게 긴가
```plain text
"카드뉴스 만들어줘"만 하면 GPT가 이미지만 뽑거나
텍스트를 이미지 밖에 별도 출력하는 이유가 4가지입니다.

문제 1. "텍스트 합성" 명시 없음
→ GPT가 이미지만 뽑음
해결: "배경 이미지 위에 한국어 텍스트를 직접 합성해서 출력"

문제 2. 텍스트 위치 미지정
→ 텍스트가 제품 위에 겹치거나 가장자리에 잘림
해결: "헤드라인 위치: 이미지 하단 1/3 중앙 정렬"

문제 3. 대비 미지정
→ 밝은 배경에 흰 텍스트가 안 보임
해결: "반투명 어두운 오버레이 위에 흰색 텍스트"

문제 4. 배경에 영문 텍스트 같이 출력
→ 배경 이미지 안에도 GPT가 임의 텍스트를 넣음
해결: "배경 이미지 안에 별도 텍스트나 기호 없이,
      오직 지정한 텍스트만 표시"
```
💡 **비즈니스 인사이트**<br>GPT에게 결과물을 요청할 때는 "완성된 결과물"을 머릿속에 그리고<br>그 결과물에 필요한 조건을 하나씩 나열하는 것이 핵심입니다.<br>"카드뉴스 만들어줘"는 조건이 0개입니다.<br>"사이즈, 텍스트 위치, 색상, 대비, 합성 방식"을 모두 명시하면<br>GPT가 처음부터 원하는 결과물을 뽑아냅니다.<br>이 원칙은 카드뉴스뿐 아니라 GPT에게 모든 결과물을 요청할 때 동일하게 적용됩니다.
---

```plain text
→ 수정 프롬프트를 ChatGPT에 붙여넣기
```
