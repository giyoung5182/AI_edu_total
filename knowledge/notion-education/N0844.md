---
## 결론 한 줄
Claude Pro로 차트를 만들고 NotebookLM으로 인사이트가 담긴 인포그래픽 구조를 뽑습니다. 숫자가 스토리가 되는 과정입니다.
---
## 왜 이 챕터를 하는가
Ch 1에서 분석 결과를 만들었습니다. 이제 그 결과를 **보여줘야** 합니다.
```plain text
표만 있는 보고서:
"갈비(국내산 원육) 700,625 / 배추-국내산 274,413 / 등갈비-BOX 166,331..."
→ 숫자 나열. 본부장님이 30초 안에 핵심을 파악하기 어려움.

차트가 있는 보고서:
→ "갈비가 압도적 1위구나" 한눈에 파악

인포그래픽이 있는 보고서:
→ "TOP 3가 전체의 62%를 차지한다. 이 품목 발주가 핵심이다." 스토리 전달
```
**시각화는 꾸미기가 아닙니다.** 같은 데이터를 더 빠르게, <br>더 정확하게 전달하는 수단입니다. 경영진 보고에서 시각화의 유무가 보고서의 설득력을 바꿉니다.

## 실습 전 개념 — AI 차트의 한계와 활용법
Claude Pro로 차트를 만들 때 알아야 할 것들입니다.
**할 수 있는 것:**
```plain text
✅ 데이터 기반 차트 이미지(PNG) 생성
✅ 색깔·제목·축 레이블 커스터마이징
✅ 차트 설명 텍스트 자동 생성
✅ 여러 차트 타입 변환
```
**할 수 없는 것 (주의):**
```plain text
❌ 엑셀 파일 안에 차트를 직접 삽입
❌ 인터랙티브 차트 (클릭하면 드릴다운되는 형태)
❌ 실시간 데이터 연동
```
**올바른 활용:**
```plain text
Claude Pro → PNG 차트 이미지 다운로드
→ Word 보고서 또는 PPT 슬라이드에 직접 삽입
```

### 차트 2 — 재고 위험 등급 도넛 차트
같은 채팅에서 이어서 요청합니다.
```plain text
[D] 방금 분석한 재고 부족 4단계 분류 결과를 활용할거야.
    긴급 1개 / 위험 24개 / 주의 0개 / 관찰 5개였어.

[S] 이 분포를 도넛 차트로 만들고 싶어.

[R] 아래 조건으로 만들어줘:
    - 차트 종류: 도넛 차트 (donut chart)
    - 항목: 긴급·위험·주의·관찰 4가지
    - 각 항목에 개수와 비율(%) 함께 표시
    - 색깔: 긴급=빨간색 / 위험=주황색 / 주의=노란색 / 관찰=초록색
    - 도넛 가운데에 "총 30개 품목 주의 필요" 텍스트
    - 제목: '5월 27일 재고 위험 현황'
    - 각 등급 옆에 해당 품목명 목록을 범례로 추가해줘.
    - PNG 파일로 다운로드

[F] 주의 0개는 표시하되 비율 0%로 표시.
    범례는 차트 오른쪽에 배치.
```

## 실습 2-B. NotebookLM으로 인포그래픽 구조 생성 (25분)
차트는 숫자를 보여줍니다. 인포그래픽은 숫자에 **의미와 스토리**를 담습니다.
### 왜 NotebookLM인가
Claude Pro도 인포그래픽 구조를 만들 수 있습니다. 그런데 NotebookLM은 소스 기반이라 내가 올린 데이터 안에서만 답합니다. 즉 **"있는 데이터에서 인사이트를 뽑는 것"** 에 특화됩니다. <br>없는 내용을 지어내지 않습니다.
---
**STEP 1.** notebooklm.google.com 접속 → 새 노트북 생성
**STEP 2.** 소스 추가
오늘 분석한 결과를 아래 형식으로 텍스트 붙여넣기 합니다.
```plain text
[소스 텍스트 — 아래 내용을 복사해서 NotebookLM에 붙여넣기]

교육기관 5월 재고파악 분석 결과 (2026년 5월 27일 기준)

■ 월간 출고 현황
- 전체 품목 수: 약 180개
- 월간 출고 TOP 1: 갈비(국내산 원육) 700,625
- 월간 출고 TOP 2: 배추-국내산 274,413
- 월간 출고 TOP 3: 등갈비-BOX(스페인) 166,331
- TOP 3 합계가 전체 월간 출고의 약 62% 차지
- 월간 출고 TOP 10 품목이 전체 출고의 약 85% 차지

■ 재고 위험 현황 (5월 27일)
- 긴급(실재고 0): 청양고추 1개 품목
- 위험(실재고 10 이하): 24개 품목
  주요 품목: 된장육수(1개), 등갈비-BOX 스페인(2개), 포장봉투중(2개)
- 관찰(합재고vs실재고 차이 10 이상): 5개 품목
- 전체 관리 품목 중 약 16%가 위험 이상 단계

■ 합재고 vs 실재고 불일치
- 1위: 돌판김치(20kg) 차이 982개
- 2위: 삼겹살(네덜란드)kg 차이 865개
- 3위: 적채-국내산 차이 577개
- 불일치 주요 원인: 대량 입고 품목에서 수령 수량 오차 발생 가능성

■ 특이 사항
- 된장육수: 이번 달 월간 출고 10위권 진입, 27일 실재고 1개로 긴급 발주 필요
- 청양고추: 27일 실재고 0개, 즉시 발주 및 매장 출고 중단 검토 필요
```
**STEP 3.** 인포그래픽 구조 요청
```plain text
이 데이터를 바탕으로 A4 1장짜리 경영진 보고용 인포그래픽을 구성하고 싶어.

[포함할 요소]
1. 핵심 KPI 카드 3개
   (가장 임팩트 있는 숫자 + 한 줄 설명)

2. 이번 달 출고 패턴에서 발견한 인사이트 2가지
   (데이터에서 발견할 수 있는 의미 있는 패턴)

3. 즉시 조치가 필요한 항목 요약
   (오늘 당장 해야 할 것 3가지)

4. 다음 달 주의 관찰 포인트 1가지

각 요소에 들어갈:
- 제목 문구
- 핵심 수치 또는 내용
- 설명 문구 (2줄 이내)
를 구체적으로 작성해줘.

PPT 슬라이드에 바로 복사해서 쓸 수 있게.
소스에 없는 내용은 절대 추가하지 마.
```

# Ch 2 심화 — 시각화가 보고서를 바꾸는 이유
---
## 시각화는 꾸미기가 아닙니다
시각화를 "보기 좋게 만드는 작업"으로 생각하는 경우가 많습니다. <br>하지만 시각화의 진짜 목적은 **커뮤니케이션**입니다.
```plain text
표: 정보를 나열한다
차트: 정보 간의 관계를 보여준다
인포그래픽: 정보에 의미와 스토리를 담는다
```
**경영진 보고에서 시각화의 중요성:**
본부장님이 보고서를 읽는 시간은 평균 30초입니다. <br>표로 가득 찬 보고서와 차트·인포그래픽이 있는 보고서는 30초 안에 전달되는 정보량이 완전히 다릅니다.
---
## 나쁜 차트 vs 좋은 차트
**나쁜 차트의 특징:**
```plain text
❌ 차트 종류가 데이터에 맞지 않음
   (10개 항목을 파이 차트로 → 너무 작은 조각들)

❌ 축 레이블이 없거나 단위가 없음
   (숫자만 있고 "개수인지 금액인지" 알 수 없음)

❌ 색깔이 너무 많거나 의미 없이 사용됨
   (무지개색 막대 → 핵심이 어디인지 모름)

❌ 제목이 없거나 "차트1"처럼 의미 없는 제목

❌ 데이터보다 장식이 더 많음 (3D 효과, 그림자 등)
```
**좋은 차트의 특징:**
```plain text
✅ 보는 사람이 5초 안에 핵심을 파악할 수 있음
✅ 제목만 봐도 무엇을 보여주는지 알 수 있음
✅ 강조해야 할 항목만 색깔로 구분
✅ 단위·출처가 명확히 표시됨
✅ 불필요한 장식이 없음
```

## NotebookLM 고급 활용 — 오디오 브리핑
NotebookLM의 독특한 기능 중 하나가 오디오 브리핑입니다. 소스 내용을 2명의 진행자가 팟캐스트 형식으로 토론하는 오디오로 자동 생성합니다.

```plain text

    회의 전에 미리 파악하게 하기"

   "출퇴근 중에 이번 달 분석 결과 오디오로 복습"

활용 3: 비전문가에게 전달
   "숫자에 약한 팀원에게 텍스트 대신 오디오로 공유"
```
**오디오 브리핑 생성 방법:**
```plain text
① NotebookLM 우측 상단 "오디오 개요" 클릭
② "커스텀 지침" 입력 가능:
   "이번 달 재고 현황을 구매부 담당자를 위해
    가장 중요한 3가지 포인트를 중심으로 2분 분량으로 설명해줘."
③ 생성 클릭 (약 1~2분 소요)
```

### 인포그래픽 구조를 PPT로 만드는 방법 (상세)
NotebookLM이 인포그래픽 텍스트 구조를 만들었으면 PPT에 적용합니다.
**STEP 1. 새 PPT 파일 열기**
빈 프레젠테이션 → 레이아웃: "빈 화면" 선택
**STEP 2. KPI 카드 3개 만들기**
```plain text
① 삽입 → 도형 → 직사각형 3개 나란히 배치
② 각 직사각형 안에 텍스트 상자 추가:
   - 위: KPI 제목 (16pt, 굵게)
   - 가운데: 핵심 수치 (32pt, 굵게, 강조 색)
   - 아래: 설명 문구 (12pt)
③ 직사각형 테두리 색: 회사 메인 컬러
```
**STEP 3. 인사이트 섹션 추가**
```plain text
① 아래쪽에 텍스트 상자 2개 나란히 배치
② 각각 NotebookLM 인사이트 1·2 텍스트 입력
③ 제목: "이번 달 주요 인사이트" (14pt, 굵게)
```
**STEP 4. 즉시 조치 섹션 추가**
```plain text
① 오른쪽 또는 아래에 텍스트 상자
② 번호 목록으로 조치 항목 입력
③ 가장 긴급한 항목에 빨간색 표시
```
**STEP 5. Ch 2-A 차트 삽입**
```plain text
삽입 → 그림 → 장치에서
→ 다운로드한 PNG 차트 선택
→ 슬라이드 적절한 위치에 배치
→ 크기 조정 (Shift 키 누르고 드래그: 비율 유지)
```

## NotebookLM 고급 기능 — 소스 관리
여러 달 치 분석 결과를 NotebookLM에 소스로 쌓아두면 장기 트렌드 분석이 가능합니다.
**소스 관리 방법:**
```plain text
노트북 구조:
교육기관 구매부 분석 노트북
  └── 소스 1: 3월 재고 현황 분석 결과
  └── 소스 2: 4월 재고 현황 분석 결과
  └── 소스 3: 5월 재고 현황 분석 결과 (오늘)

→ 3개월 치 소스가 쌓이면:
"3개월 연속으로 재고 위험 등급에 등장하는 품목이 있어?
 있으면 그 품목들을 발주 주기 조정 우선 대상으로 정리해줘."
```
**소스 업데이트 주기:**
```plain text
매월 분석 완료 후 → NotebookLM 기존 노트북에 소스 추가
→ 점점 풍부해지는 장기 데이터 기반이 됩니다
```

## 이번 달 인포그래픽을 다음 달에 재사용하는 방법
한 번 잘 만든 인포그래픽 구조는 다음 달에 데이터만 바꿔서 재사용합니다.
**NotebookLM에서 요청:**
```plain text
"이번에 만든 인포그래픽 구조를 템플릿으로 저장하고 싶어.

변경되는 부분:
- 날짜: [YYYY년 MM월]
- 수치들: [해당 월 수치]

고정되는 부분:
- 전체 구조 (KPI 3개 + 인사이트 2개 + 조치 사항)
- 섹션 제목들

다음 달에 이 템플릿에 새 수치만 채워 넣을 수 있게 만들어줘."
```
결과를 라이브러리 ⑤번 시트에 저장합니다.
