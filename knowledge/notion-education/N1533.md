# 활동 2 — 자동화 과제 정의서 작성

정리일: 2026-10-08 · 교육 에셋 N1533

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
9개 항목의 자동화 과제 정의서를 작성합니다.
## 진행 단계
1. **기본 항목** — \[1\] 대상 업무 \[2\] 수행 주기 \[3\] 현재 소요 시간 \[4\] 관련 자료
2. **\[5\] 우선 추진 과제와 선정 근거**
3. **\[6\] 입력 · 처리 · 출력** — '실적 파일'이 아니라 '엑셀·CSV, 5\~6개, 컬럼 구조 상이'까지 구체적으로
4. **\[7\] 사람의 확인 지점**
5. **\[8\] 성공 기준(숫자로)** · **\[9\] 최소 완성 범위**
6. **과제 검수 3초 체크** — 매주/매월 반복되는가, 입력 파일이 실제로 존재하는가, 결과물 형식이 정해져 있는가. 셋 다 예여야 통과.
- 정상 결과: 완성한 정의서를 저장. \[6\]은 3권 데이터 설계, \[7\]은 4권 Agent 설계서의 승인 지점, \[8\]은 5권 테스트 케이스의 재료가 됨.
## 막히는 지점
- \[6\]이 흐릿하면 뒤가 전부 흐릿해진다 / \[7\]을 비우면 나중에 사고가 난다 / \[9\]가 없으면 끝없이 손보게 된다
