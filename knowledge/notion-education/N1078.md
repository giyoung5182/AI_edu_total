# Step 01 :: 매번 말하던 규칙을 CLAUDE.md 파일로 만듭니다

정리일: 2026-10-08 · 교육 에셋 N1078

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
오늘 반복해서 말한 규칙을 coding 폴더의 CLAUDE.md 파일 하나로 묶어, 매 요청마다 자동으로 읽히게 합니다.
## 진행 단계
1. **반복한 규칙 떠올리기** — 세 번 이상 말한 것은 규칙입니다(금액 천 단위 쉼표, 숫자 오른쪽 정렬, 빈 값은 0으로 채우지 않기 등).
2. **CLAUDE.md**** 만들기** — coding 폴더 바로 안(하위 폴더 아님)에 파일을 둡니다.
- 입력할 내용: "coding 폴더에 CLAUDE.md 파일을 만들어줘. 내용은 아래 그대로." 뒤에 용도·표기·화면·데이터 처리·금지·작업 방식·자주 틀리는 것 항목을 적은 규칙문(교안 참고)
3. **본인 업무에 맞게 수정** — `[ ]` 부분만 바꿉니다. 맨 아래 "자주 틀리는 것"은 비워두고 같은 실수를 만날 때마다 한 줄씩 채웁니다.
## 막히는 지점
- 길수록 나빠집니다. 20\~30줄로 시작하고 "이건 AI가 알아낼 수 있나?"를 기준으로 알아낼 수 있으면 지웁니다.
