# 실습 3. 벡터DB 적재

정리일: 2026-10-08 · 교육 에셋 N0659

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
청크를 임베딩해서 ChromaDB에 저장합니다.
## 진행 단계
1. **프롬프트 입력** — Claude Code에 벡터DB 적재 기능 추가를 요청합니다.
- 입력할 내용:
```javascript
문서 처리 페이지에 벡터DB 적재 기능을 추가해 주세요. 요구사항입니다.

1. 로컬에서 무료로 동작하는 ChromaDB를 사용해 주세요.
   데이터는 프로젝트 폴더 안에 저장되게 해 주세요.

2. 임베딩은 Gemini 임베딩 API(모델: gemini-embedding-001,
   출력 차원 768)를 사용해 주세요.
(이하 교안 참고)
```
1. **서버 재시작** — 터미널 B에서 서버를 재시작합니다.
2. **업로드와 적재** — "지진 국민행동요령"을 청크 크기 500자로 업로드하고 적재 버튼을 누릅니다.
3. **로그 확인** — 임베딩 진행과 적재 완료를 지켜봅니다.
4. **현황 확인** — 화면 상단 현황이 "적재 완료: 총 N개 청크 (문서 1부)"로 바뀌는 것을 확인합니다.
## 막히는 지점
- 첫 적재가 유난히 느림: 임베딩 모델 최초 다운로드, 1회성입니다.
- 적재 중 멈춘 듯함: 창①의 로그를 확인하고, 5분 이상 완전히 멈춰 있으면 창②에 로그를 붙여넣고 문의합니다.
- 메모리 부족 오류: "청크를 나눠서 배치로 적재하도록 바꿔 주세요"라고 요청합니다.
- 적재 후 개수가 0으로 표시: "적재는 성공 로그가 났는데 현황이 0개입니다. 원인을 찾아 주세요"라고 요청합니다.
