# 13장 · 배포 — 인터넷 주소 만들기 (STEP 1~6)

정리일: 2026-10-08 · 교육 에셋 N1162

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
내 컴퓨터에만 있던 index.html을 GitHub와 Vercel로 인터넷에 올려 주소와 QR 코드를 받습니다.
## 진행 단계
1. **STEP 1 · 배포 도구 설치 (7분)** — Claude Code에게 부탁합니다.
- 입력할 내용:
```javascript
깃허브 CLI랑 버셀 CLI 설치해줘.
```
- 정상 결과: "설치가 완료되었습니다" 같은 응답.
1. **STEP 2 · 앱 껐다 켜기 (3분)** — Claude 데스크톱 앱을 완전히 종료 후 다시 실행하고 Code 탭에서 아까 쓰던 폴더를 다시 선택합니다. 재실행 후 아직 입력창에 아무것도 치지 않습니다.
2. **STEP 3 · 설치 확인 (4분)** — Ctrl+\` 로 내장 터미널을 열고 두 줄을 직접 입력합니다.
- 입력할 내용:
```javascript
gh --version
vercel --version
```
- 정상 결과: 두 줄 모두 버전 숫자가 나옴(gh version 2.x.x / Vercel CLI 3x.x.x).
1. **STEP 4 · 로그인 (6분)**
- 입력할 내용:
```javascript
gh auth login이랑 vercel login 실행해줘.
인증은 내가 브라우저에서 직접 할게.
```
- 브라우저에서 사전에 가입한 계정으로 로그인하고 \[Authorize\]/\[승인\]을 클릭합니다. 정상 결과: "로그인되었습니다" 같은 메시지.
1. **STEP 5 · 배포 (8분)**
- 입력할 내용:
```javascript
이 폴더를 깃허브에 올리고 버셀로 배포해서 주소 알려줘.
깃허브에는 프라이빗으로 올려줘.
```
- 정상 결과: https:// 로 시작하는 주소가 화면에 나옴(3\~5분).
1. **STEP 6 · 주소 확인 · 앱처럼 만들기 (7분)** — 주소를 브라우저에서 열고, 휴대폰이나 다른 사람 기기에서도 열어 보고, 홈 화면에 추가해 보고, QR을 만듭니다.
- 입력할 내용:
```javascript
이 주소로 QR 코드를 만들어줘. 인쇄해서 쓸 거야.
```
- 정상 결과(체크리스트): https:// 주소를 받음 / 브라우저에서 열림 / 휴대폰·다른 기기에서도 열림 / 홈 화면에 추가함 / QR 코드 생성.
## 막히는 지점
- STEP 2를 건너뛰면 다음 단계가 안 됨.
- command not found: 앱을 한 번 더 완전히 껐다 켜고 다시 확인, 그래도 안 되면 STEP 1 설치 요청을 다시 실행.
- 배포는 됐는데 화면이 하얌: index.html이 폴더 최상위에 있는지 확인.
- GitHub 비밀번호를 물어봄: 로그인이 안 된 상태이므로 STEP 4를 다시.
- 주소가 안 나옴: "배포된 주소 알려줘"라고 다시 요청.
