# 실습 3 — 본인 업무에 GAS 적용

정리일: 2026-10-08 · 교육 에셋 N0686

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
앞 실습에서 익힌 설치 방법과 프롬프트 작성법을 본인 업무에 직접 적용함.
## 진행 단계
1. **자동화할 업무 1가지 결정** — 매일 또는 매주 반복하는가, 구글 시트(또는 엑셀) 데이터를 다루는가, 입력·집계·분류·이메일 발송 중 하나인가를 기준으로 판단
2. **템플릿으로 Claude에 요청** — 파일 구조·셀 위치·동작 순서·메뉴 구성을 포함해 요청
- 입력할 내용: 시트별 열 구성을 설명하고 "이 구조로 \[입력\] 시트에서 데이터를 읽어 \[이력\] 시트에 한 줄씩 저장하는 GAS 함수를 만들어줘" 형식으로 요청
3. **코드 받으면 3가지 확인 후 설치** — 시트명 일치, 셀 주소 일치, 헤더 순서 일치 확인 후 Apps Script에 붙여넣기 → 저장 → 테스트
4. **오류 시** — 오류 메시지를 복사해 Claude에게 전달
5. **정상 작동 확인** — 단톡방에 결과 공유
## 막히는 지점
- Apps Script는 파일마다 따로 연결되므로 작업 파일을 열고 거기서 Apps Script를 열기
- 메뉴가 안 나오면 F5 → 안 되면 onOpen을 수동 실행
- 클릭해도 반응이 없으면 권한 허용이 안 된 상태이므로 함수를 한 번 실행해 권한 허용
