## 이 실습으로 하는 것
Ubuntu 터미널에서 패키지 목록을 갱신하고 파이썬 관련 도구를 설치합니다.
## 진행 단계
1. **패키지 갱신** — update → upgrade 순서
```bash
sudo apt update && sudo apt upgrade
```
1. **파이썬 도구 설치**
```bash
sudo apt install -y python3-venv python3-pip unzip
```
1. **설치 확인**
```bash
python3 --version
```
- 정상 결과: Python 3.10 이상 출력
