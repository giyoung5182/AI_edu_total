# 이미지 B. 제품 중심 시안

정리일: 2026-10-08 · 교육 에셋 N0415

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 제품을 모델 없이 실루엣과 볼륨감이 드러나는 제품 중심 시안(이미지 B)으로 만듭니다.
## 진행 단계
1. **프롬프트 입력**
- 입력할 내용:
```javascript
[무엇을 만들지] 같은 제품의 제품 중심 광고 시안
[분위기/톤] 차분하고 프리미엄한 느낌
[배경/환경] 겨울 스튜디오 촬영 느낌의 미니멀한 배경
[구도/촬영 방식] 모델 없이 제품 중심, 패딩의 실루엣과 볼륨감이 잘 보이는 상세페이지 메인 비주얼형 구도
[용도] 프리미엄 상세페이지 메인 비주얼 초안

- 제품 존재감이 잘 드러나게
- 배경은 미니멀하고 차분하게
- 패딩 형태가 선명하게 보이게, - 패딩은 흰색으로
```
