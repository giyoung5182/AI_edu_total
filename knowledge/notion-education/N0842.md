## 시각화 마스터 클래스 — 실무 고급 패턴
---
### 패턴 1. 전월 대비 차트
이번 달과 지난달을 나란히 비교하는 묶음 막대 차트입니다.
```plain text
[D] 두 달의 월간 출고 TOP 10 데이터야.
    [4월 데이터] (첫 번째 표)
    [5월 데이터] (두 번째 표)

[S] 두 달을 나란히 비교하는 차트를 만들고 싶어.

[R] 묶음 가로 막대 차트:
    - 각 품목별로 4월(파란색)·5월(주황색) 막대를 나란히
    - x축: 출고량
    - y축: 품목명 (5월 출고량 내림차순)
    - 증가한 품목에 ▲ 표시, 감소한 품목에 ▼ 표시
    - 제목: '4월 vs 5월 월간 출고 비교'
    - PNG 파일 다운로드

[F] 두 달 모두 TOP 10에 있는 품목만 포함.
    품목명 코드 제거.
```

### 패턴 2. 재고 소진 예측 차트
현재 재고와 일평균 출고량으로 소진 예상일을 시각화합니다.
```plain text
[D] 재고파악 27일 시트야.
    실재고와 매장출고 데이터가 있어.
    일평균 출고량 = 매장출고 / (이번 달 영업일 수)로 계산해줘.

[S] 현재 실재고가 언제 소진될지 예측하고 싶어.
    소진 예상일 = 실재고 / 일평균 출고량

[R] 가로 막대 차트:
    - x축: 소진까지 남은 일수
    - y축: 품목명
    - 색깔 구분: 7일 이하 = 빨간색 / 8~14일 = 주황 / 15일 이상 = 초록
    - 각 막대에 "D-[남은일수]" 레이블
    - 제목: '재고 소진 예상일 (27일 기준)'
    - 상위 15개 품목(소진 임박 순서)만 표시

[F] 실재고 0인 품목은 "이미 소진"으로 별도 표시.
    일평균 출고량이 0인 품목은 제외.
```
> **활용 포인트:** "청양고추 D-0 (이미 소진), 된장육수 D-1, 포장봉투중 D-2" 같은 차트를 매일 아침 담당자에게 공유하면 발주 타이밍을 놓치지 않습니다. 4회차에서 이것을 자동화합니다.

### 패턴 3. 합재고 vs 실재고 불일치 히트맵
여러 품목의 불일치 심각도를 한눈에 보여주는 차트입니다.
```plain text
[D] 재고파악 27일 시트야.

[S] 합재고와 실재고 불일치를 시각적으로 보여주고 싶어.

[R] 버블 차트 또는 산점도:
    - x축: 합재고
    - y축: 실재고
    - 버블 크기: 차이(합재고-실재고) 절대값
    - 색깔: 차이가 클수록 진한 빨간색
    - 대각선(합재고=실재고 기준선) 표시
    - 기준선 아래(실재고 부족) 품목에 레이블 표시
    - 제목: '합재고 vs 실재고 불일치 현황'

[F] 합재고·실재고 모두 0인 품목 제외.
    차이 10 이상인 품목만 레이블 표시.
    코드 제거.
```

### NotebookLM 활용 — 보고서 내러티브 자동 생성
인포그래픽 구조뿐 아니라 보고서에 들어갈 서술형 내러티브도 생성할 수 있습니다.
```plain text
NotebookLM에 오늘 분분석 결과를 소스로 추가한 후:

"이번 달 재고 현황을 경영진에게 보고하는
 2분짜리 구두 브리핑 스크립트를 작성해줘.

 포함할 내용:
 1. 이번 달 가장 중요한 발견 1가지 (첫 문장)
 2. 지표별 현황 (수치 중심)
 3. 즉시 조치가 필요한 것 1~2가지
 4. 마무리 한 마디

 소스에 없는 내용은 절대 포함하지 마.
 경어체로 작성."
```
이 스크립트를 보고서 앞에 "요약 브리핑"으로 추가하면 경영진이 30초 안에 핵심을 파악할 수 있습니다.

### 차트 생성 실패 시 대안 방법들
Claude Pro가 PNG 차트를 만들지 못하는 경우가 있습니다. 이때 쓸 수 있는 대안들입니다.
**대안 1. 텍스트 기반 시각화**
```plain text
"차트 이미지 대신 텍스트로 된 가로 막대 차트를 만들어줘.

예시:
갈비(국내산) ████████████████████ 700,625 (46.9%)
배추-국내산  ████████ 274,413 (18.4%)
등갈비BOX   ████ 166,331 (11.1%)

이 방식으로 TOP 10을 표현해줘."
```
**대안 2. 이모지 활용 시각화**
```plain text
"재고 위험 등급을 이모지로 시각화해줘.
🔴 긴급: [품목명]
🟠 위험: [품목명]
🟡 주의: [품목명]
🟢 관찰: [품목명]

카카오톡 단톡방에 바로 붙여넣을 수 있는 형태로."
```
**대안 3. 엑셀 차트 직접 만들기**
피벗 결과 파일을 받은 후 엑셀에서 직접 차트를 만듭니다.
```plain text
① 피벗 결과 파일 열기
② 데이터 선택 (품목명 + 월총출고 열)
③ 삽입 → 차트 → 가로 막대형
④ 차트 디자인 → 스타일 선택
⑤ 차트 제목 입력
⑥ 파일로 저장 → PNG로 내보내기
   (차트 우클릭 → 그림으로 저장)
```

### 시각화 결과물 품질 체크리스트
보고서에 차트를 넣기 전에 확인합니다.
**내용 정확성:**
- [ ] 수치가 원본 분분석 결과와 일치하는가
- [ ] 품목명 앞 코드(c00, 078 등)가 제거됐는가
- [ ] 정렬 순서가 맞는가 (내림차순인지 확인)
- [ ] 총 항목 수가 맞는가 (TOP 10이면 10개인가)
**시각적 품질:**
- [ ] 제목이 명확하게 표시됐는가
- [ ] 축 레이블과 단위가 있는가
- [ ] 색깔이 의미를 전달하는가 (위험=빨간색 등)
- [ ] 수치 레이블이 읽기 쉽게 표시됐는가
- [ ] 해상도가 충분한가 (인쇄 시 흐릿하지 않은가)
**파일 관리:**
- [ ] 파일명에 날짜가 포함됐는가 (5월_월간출고_TOP10.png)
- [ ] 구글 드라이브 3회차 폴더에 저장됐는가
- [ ] 보고서·PPT에 삽입할 준비가 됐는가

## NotebookLM vs Claude Pro — 언제 어떤 것을 쓰는가
오늘 처음 NotebookLM을 써보면서 "Claude로도 되는데 왜 굳이?"라는 생각이 들 수 있습니다. 차이를 명확히 이해합니다.
**Claude Pro를 써야 할 때:**
```plain text
✅ 파일을 분분석해서 집계·정렬·계산이 필요할 때
✅ 차트 이미지 파일을 만들어야 할 때
✅ Word·Excel 파일을 다운로드해야 할 때
✅ 복잡한 수식이나 코드가 필요할 때
✅ 새로운 아이디어·제안이 필요할 때 (소스 밖 지식 활용)
```
**NotebookLM을 써야 할 때:**
```plain text
✅ 내가 올린 데이터 안에서만 답을 원할 때
   (없는 내용을 지어내지 않아야 할 때)
✅ 여러 소스를 합쳐서 요약·분분석할 때
✅ 팟캐스트 형식의 오디오 브리핑이 필요할 때
✅ 장기적으로 데이터를 축적해서 트렌드를 보고 싶을 때
```
**오늘 실습에서의 역할 분담:**
```plain text
재고파악 파일 분분석 → Claude Pro (파일 처리 능력)
차트 생성 → Claude Pro (이미지 생성 능력)
인포그래픽 텍스트 → NotebookLM (소스 기반 구조화)
오디오 브리핑 → NotebookLM (Audio Overview 기능)
보고서 초안 → Claude Pro (문서 생성 능력)
슬라이드 생성 → Claude for PowerPoint (앱 내 통합)
```

## 오늘 실습 2 전체 프롬프트 모음 — 복사해서 바로 쓰기
### 프롬프트 2-A-①: 월간 출고 TOP 10 가로 막대 차트
```plain text
[D] Ch 1에서 만든 5월 월간출고 TOP 10 데이터야.
    (같은 채팅에 이미 있음)

[S] 이 데이터를 가로 막대 차트로 시각화하고 싶어.
    보고서와 PPT 슬라이드에 삽입할 예정이야.

[R] 가로 막대 차트(horizontal bar chart):
    - x축: 월총출고 수량 (천 단위 콤마. 예: 700,625)
    - y축: 품목명 (TOP 1이 가장 위, TOP 10이 가장 아래)
    - 각 막대 오른쪽 끝에 수치·구성비 표시
      형식: "700,625 (46.9%)"
    - TOP 1 막대: #1F4E79 (진한 파란색)
    - TOP 2~10 막대: #5B9BD5 (연한 파란색)
    - 제목: '5월 월간 매장출고 TOP 10'
    - 크기: 1600px × 800px
    - PNG 파일 다운로드

[F] 품목명 코드(c00, 078 등) 제거.
    배경 흰색. 불필요한 3D 효과 없이 플랫 디자인으로.
    구성비는 소수점 1자리 %.
```

### 프롬프트 2-A-②: 재고 위험 도넛 차트
```plain text
[D] 오늘 분분석한 5월 27일 재고 위험 현황이야.
    긴급 1개 / 위험 24개 / 주의 0개 / 관찰 5개.

[S] 재고 위험 등급 분포를 도넛 차트로 시각화하고 싶어.
    경영진 보고 자료에 사용할 예정이야.

[R] 도넛 차트(donut chart):
    - 4개 항목: 긴급·위험·주의·관찰
    - 각 조각에 등급명·개수·비율 표시
      예: "위험 24개 (80%)"
    - 색깔: 긴급=#CC0000 / 위험=#FF6600 / 주의=#FFCC00 / 관찰=#339933
    - 도넛 중앙 텍스트: "총 30개 품목\n발주 검토 필요"
    - 제목: '5월 27일 재고 위험 현황'
    - 크기: 1000px × 800px
    - PNG 파일 다운로드

[F] 비율 소수점 1자리 %. 배경 흰색. 범례 차트 오른쪽에.
    주의 0개는 조각 없이 범례에만 "주의: 0개 (0%)" 표시.
```

### 프롬프트 2-A-③: 합재고 vs 실재고 묶음 막대 차트
```plain text
[D] Ch 1에서 만든 합재고 vs 실재고 불일치 TOP 5 데이터야.

[S] 합재고와 실재고를 나란히 비교하는 차트를 만들고 싶어.
    어느 품목에서 차이가 큰지 한눈에 보이게.

[R] 묶음 가로 막대 차트(grouped horizontal bar chart):
    - 각 품목별로 합재고(파란색 #2E75B6)·실재고(빨간색 #C00000) 막대 나란히
    - x축: 재고 수량
    - y축: 품목명 (차이 큰 순서대로, 위에서 아래로)
    - 각 묶음 오른쪽에 차이값 표시. 예: "Δ982"
```
