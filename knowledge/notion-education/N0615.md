# 실습 2-A. 비즈머니 알림 — 프롬프트 직접 작성

정리일: 2026-10-08 · 교육 에셋 N0615

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
비즈머니 잔액이 기준 이하가 되면 이메일을 보내는 GAS 요청 프롬프트를 템플릿 빈칸을 채워 직접 작성하고 코드를 받아 설치함.
## 진행 단계
1. **실습 파일 확인** — 실습 파일을 구글 드라이브에 올려 구글 시트로 열고 \[비즈머니_잔액\] 시트의 셀을 클릭해 이름 상자의 주소와 값 확인
- 정상 결과: C4=누적 충전액, F4=현재까지 소진액, I4=현재 잔액(=C4-F4), C5=일 평균 소진, F5=광고 중단 예상일
2. **프롬프트 작성** — \[내 업무 상황\] / \[파일 구조\] / \[동작 순서\] / \[트리거\] / \[메뉴\] 템플릿의 \[___\]와 힌트를 보며 채움
- 입력할 내용: "Google Apps Script 코드를 만들어줘." + 업무 상황 + 시트명·셀 주소 + 동작 순서(잔액 계산, 기준 이하이면 이메일 발송, 초과이면 아무것도 하지 않음) + 매일 오전 9시 트리거 + 메뉴(잔액 확인, 테스트 이메일 발송). 전체 템플릿은 교안 참고
3. **코드 받기** — 작성한 프롬프트를 Claude 새 채팅창에 붙여넣기
4. **설치** — 구글 시트에서 \[확장 프로그램\] → \[Apps Script\]에 붙여넣고 저장, F5 새로고침 후 \[광고 관리\] 메뉴 확인
5. **테스트** — \[테스트 이메일 발송\] 클릭 → 이메일 도착 확인
## 막히는 지점
- 시트 이름은 탭 이름과 한 글자도 달라서는 안 됨
- "초과이면 아무것도 하지 않음"을 명시하지 않으면 조건 외 동작이 생길 수 있음
- 테스트 함수가 없으면 설치 직후 이메일 도착 여부를 확인할 수 없음
