# 문제4: 계약종별 사용요금 통계

정리일: 2026-10-08 · 교육 에셋 N0511

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
2023-07-01 사용요금만 대상으로 계약종별 건수·평균·최소·최대 사용요금을 구하고 평균 높은 순으로 정렬합니다.
## 진행 단계
1. **쿼리 작성**
```sql
SELECT
    `계약종별`,
    COUNT(*) AS 사용요금_건수,
    ROUND(AVG(`금액`), 2) AS 평균사용요금,
    MIN(`금액`) AS 최소사용요금,
    MAX(`금액`) AS 최대사용요금
FROM KDHC
WHERE `기준일자` = '2023-07-01'
  AND `요금종별` = '사용요금'
GROUP BY `계약종별`
ORDER BY 평균사용요금 DESC;
```
2. **정답화면 비교** — 전체(평균 100.69), 업무용(97.47), 공공용(85.65), 주택용(85.02) 순인지 확인합니다.
