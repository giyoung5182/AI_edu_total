# 3.9 체이닝 실습 (카드뉴스 배경 이미지 60%→90%)

정리일: 2026-10-08 · 교육 에셋 N0315

---

## 이 실습으로 하는 것
첫 이미지(60\~70% 수준)를 만들고, 한 번에 하나씩만 바꾸는 체이닝으로 90% 이상으로 올린다.
## 진행 단계
1. **1차 생성** — 아래를 입력한다.
- 입력할 내용:
```javascript
여름 건강 관리 관련 카드뉴스 배경 이미지.
밝고 산뜻한 느낌. 초록색 계열. 4K.
```
1. **2차 체이닝** — 같은 채팅창에서 구도만 바꾼다.
- 입력할 내용:
```javascript
분위기와 색감은 그대로 유지해줘.
구도만 세로 비율(9:16)로 바꿔줘.
아래쪽 1/3은 텍스트 넣을 공간으로 비워줘.
```
1. **3차 체이닝** — 색감만 바꾼다.
- 입력할 내용:
```javascript
구도는 그대로. 색감을 좀 더 따뜻하게.
초록 + 따뜻한 베이지 톤으로.
```
## 막히는 지점
- 한 번에 여러 요소를 바꾸면 전혀 다른 이미지가 나올 수 있음
- 새 채팅창을 열면 이전 맥락이 사라짐
