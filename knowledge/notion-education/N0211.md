# 1. 📖 개념 — 무엇이 달라지나
## 지금까지 우리가 한 방식
```javascript
① 파일을 연다
② 필요한 부분을 찾는다
③ 복사한다
④ ChatGPT에 붙여넣는다
⑤ 결과를 받는다
⑥ 다시 복사해서 파일에 붙여넣는다
⑦ 저장한다
```
**AI가 한 일은 ⑤번 하나뿐입니다.** 나머지 여섯 개는 전부 사람이 했습니다.
---
## Work 기능을 쓰면
```javascript
① 폴더를 열어준다
② 무엇을 할지 말한다
③ AI가 직접 읽고, 만들고, 저장한다
```

**차이는 "손이 있느냐"입니다.**
지금까지 AI는 ***말만 할 수 있었습니다.***
이제는 ***파일을 직접 만질 수 있습니다.***

# 2. 🔥 실습 1 — 읽게 하기 (10분)
## 폴더 연결
```javascript
① 채팅창 옆 Work 기능을 켠다
② 어제 받은 실습 폴더를 지정한다
③ 파일 목록이 보이는지 확인한다
```

**연결됐는지 확인하는 법**
*"이 폴더에 무슨 파일이 있어?"*라고 물어보세요.
***5개 파일명을 정확히 말하면*** 연결된 것입니다.

---
## 여러 파일을 한 번에 읽게 하기
**붙여넣기로는 못 하던 일입니다.**
```javascript
이 폴더의 파일을 전부 읽고 아래를 정리해줘.

1. 각 파일이 어떤 내용인지 한 줄씩
2. 서로 연결되는 부분이 있는지
   (예: 어떤 파일의 내용이 다른 파일에서 언급되는지)
3. 이 자료들로 답할 수 있는 질문 5개

파일에 없는 내용은 추측하지 말고
"확인되지 않음"으로 표시해줘.
```

## 어제 못 풀었던 것을 다시
**어제 5교시에서 규정 상충을 찾았지만 판단은 못 했습니다.**
```javascript
04_품질관리_사내규정집.docx 와
05_생산품질_회의녹취록.docx 를 함께 읽고

규정집에서 서로 다른 기준이 적힌 부분을 찾은 뒤,
회의록에서 실무가 어느 쪽을 따르는지 확인해줘.

결과는 이렇게 정리해줘.
| 항목 | 규정 A | 규정 B | 실무 적용 | 근거 발언 |

회의록에 언급이 없으면 "확인 필요"로 표시해줘.
```
**두 파일을 동시에 보면서 대조합니다.** 붙여넣기로는 번거로웠던 작업입니다.

## 엑셀 만들기
**보고서보다 이게 더 실무적입니다.**
```javascript
01_실습데이터_통합.xlsx 의 클레임이력 시트를 읽고

"클레임_월별집계.xlsx" 파일로 저장해줘.

[만들 시트]
1. 월별 요약 — 건수, 처리비용 합계, 평균 처리일
2. 귀책별 요약 — 당사 / 고객사 / 원인미상
3. 원본 정리 — 표기가 흔들린 항목을 통일한 것

[주의]
- 원본 파일은 수정하지 마라
- 표기를 통일했다면 무엇을 바꿨는지 세 번째 시트에 기록
- 금액은 천원 단위, 숫자 서식 적용
```

**"원본 파일은 수정하지 마라"를 반드시 넣으세요.**
폴더 안의 파일을 ***덮어쓸 수 있기 때문***입니다.
새 파일로 만들게 하는 게 안전합니다.

# 4. 🔥 실습 3 — 여러 파일을 한 번에 (12분) ★
**파일 하나씩 하던 일을 묶어서 시킵니다.**
---
## 자료 묶음 만들기
```javascript
이 폴더의 03, 04, 05 파일을 읽고
신규 입사자용 안내 자료를 만들어줘.

[만들 파일]
"신입_업무안내.md"

[구성]
1. 우리가 만드는 제품 (03에서)
2. 품질 기준과 판정 절차 (04에서)
3. 실무에서 자주 나오는 상황 (05에서)
4. 헷갈리기 쉬운 것 — 규정과 실무가 다른 부분

[주의]
- 각 항목에 어느 파일 어느 부분에서 왔는지 표시
- 세 자료에 없는 내용은 넣지 마라
- 4번은 특히 중요하니 빠뜨리지 마라
```
---

**4번이 이 실습의 핵심입니다.**
***규정과 실무가 다른 부분***은 세 파일을 다 봐야 나옵니다.
사람이 하려면 세 문서를 펼쳐놓고 대조해야 하는 일이죠.

---
## 파일 정리도 시켜보기
```javascript
이 폴더를 정리해줘.

1. 내가 만든 결과물 파일을 "산출물" 하위 폴더로 옮겨줘
2. 원본 5개 파일은 그대로 두고
3. 무엇을 옮겼는지 목록으로 알려줘

원본은 절대 옮기거나 이름을 바꾸지 마라.
```

**실행 전에 한 번 더 생각하세요.**
파일을 옮기고 이름을 바꾸는 건 ***되돌리기 어렵습니다.***
중요한 폴더에서는 ***먼저 복사본을 만들고*** 시키세요.
