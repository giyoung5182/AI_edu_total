# Step 02 :: 뼈대부터 세웁니다

정리일: 2026-10-08 · 교육 에셋 N0355

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
새 세션을 열고 04_결과물.html을 뼈대부터 한 조각씩 쌓으며, 매번 확인합니다.
## 진행 단계
1. **① 뼈대만** — 화면 틀과 제목·기간만 만들게 합니다. 확인: 제목과 기간이 맞나.
- 입력할 내용: "\[ 역할 \] 너는 광고 실무에서 쓰는 도구를 만드는 개발자다. \[ 할 일 \] coding 폴더의 02_명세서.md 를 읽고 화면 틀만 만들어라 ... \[ 하면 안 되는 것 \] 외부에서 불러오는 것을 사용하지 않는다 / 요청하지 않은 기능을 추가하지 않는다 \[ 출력 \] coding 폴더에 04_결과물.html 파일 하나"
2. **② 저장소 연결** — 브라우저 저장소를 연결합니다. 확인: 값을 바꾸면 남나. "지금 있는 내용은 그대로 두고 추가만 해줘"를 빼지 않습니다.
3. **③ 데이터 표** — 확인: 데이터가 다 나오나.
4. **④ 요약** — 전체 건수와 단계별 개수, 계산에 쓴 건수와 제외한 건수. 확인: 숫자가 맞나.
5. **⑤ 상태 표시** — 단계 칸을 세 종류 이하 색으로 구분. 확인: 구분이 되나.
6. **⑥ 확인 필요 항목** — 값이 빈 항목만 모아 사유를 한 줄씩. 확인: 빈 값이 표시되나.
- 정상 결과: 매번 브라우저를 새로고침해 확인하고, 이상하면 직전 한 걸음 안에서 원인을 찾습니다.
## 막히는 지점
- 뼈대만 시켰는데 다 만들어버립니다: 「요청하지 않은 기능을 추가하지 않는다」를 넣으세요.
- 저장소를 붙이니 앞의 것이 사라집니다: 「지금 있는 내용은 그대로 두고 추가만 해줘」를 붙이세요.
- 값을 바꿔도 저장이 안 됩니다: 「값을 바꾸면 저장소에 실제로 저장되는지 확인해줘. 저장이 안 되고 있다면 원인을 찾아 고쳐줘」
- 빈 값이 0으로 계산됩니다: 「값이 비어 있으면 계산에서 제외하고, 제외한 건수를 표시해줘」
