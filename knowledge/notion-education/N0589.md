# 패들렛에 게임 링크와 에러 해결 경험 공유하기

정리일: 2026-10-08 · 교육 에셋 N0589

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
만든 게임 링크와 에러 해결 경험을 패들렛에 공유합니다.
## 진행 단계
1. **패들렛 열기** — 교안에 안내된 수업용 패들렛에 접속합니다.
2. **게시물 작성** — 게임 링크와 함께 아래 양식으로 작성
- 입력할 내용:
```plain text
### 에러 상황
{상황 서술}

### 해결 방법
{해결 시 시도했던 방법 / 프롬프트}
```
