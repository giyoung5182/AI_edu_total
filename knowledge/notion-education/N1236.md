# 5-4. Claude 실습 (10분) · 긴 문서 요약과 글쓰기 비교

정리일: 2026-10-08 · 교육 에셋 N1236

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 입력을 여러 AI에 넣어 긴 문서 요약과 글쓰기 품질의 차이를 직접 비교합니다.
## 진행 단계
1. **긴 문서 요약 능력 비교 (5분)** — 강의 자료 전체(또는 긴 텍스트)를 Claude에 붙여넣기
- 입력할 내용: "이 내용 전체를 읽고, 강사 입장에서 가장 중요한 포인트 5가지를 뽑아줘"
- 정상 결과: 같은 내용을 ChatGPT에도 해 보고 어느 쪽이 맥락을 더 정확히 파악했는지, 요약 품질이 어떻게 다른지 확인
2. **글쓰기 품질 비교 (5분)** — 같은 프롬프트를 ChatGPT·Gemini·Claude에 동시에 입력
- 입력할 내용: "AI 강사로서 수강생의 신뢰를 얻는 방법을 진심 어린 글로 써줘"
- 정상 결과: 어느 쪽이 가장 자연스럽게 읽히는지, "AI가 쓴 것 같은 느낌"이 어디서 더 강한지 확인
## 막히는 지점
- Claude 무료 한도는 긴 대화·문서 분석 시 빠르게 소진됨
