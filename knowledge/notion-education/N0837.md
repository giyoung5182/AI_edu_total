### 기법 1 — 보고서에 데이터 시각화를 자연스럽게 연결하기
보고서 초안을 만들 때 차트가 들어갈 위치를 미리 안내하는 방식입니다.
```plain text
[R]에 추가:
"차트가 들어갈 위치에는 [차트명 삽입]이라는 플레이스홀더를 넣어줘.
 예: [5월 월간 출고 TOP 10 차트 삽입]"
```
그러면 보고서 초안에 차트 삽입 위치가 표시되어 나중에 PNG를 끼워 넣기 쉽습니다.

### 기법 2 — 이전 달 보고서와 비교 분석
이전 달 보고서가 있으면 Claude에 함께 올려서 비교 분분석을 요청할 수 있습니다.
```plain text
[D] 두 개의 파일을 첨부했어.
    파일 1: 이번 달(5월) 재고 현황 분분석 결과
    파일 2: 지난 달(4월) 재고 현황 보고서

[S] 두 달을 비교해서 변화가 가장 큰 항목을 파악하고 싶어.

[R] 비교 표:
    | 항목 | 4월 | 5월 | 변화 | 비고 |
    변화가 큰 순서로 정렬.
    증가한 것은 ▲, 감소한 것은 ▼로 표시.

[F] 두 달 모두 존재하는 항목만 비교.
    한 달만 있는 항목은 "신규" 또는 "소멸"로 표시.
```

### 기법 3 — 보고서 톤 자동 조정
보고 대상에 따라 같은 내용을 다른 톤으로 자동 변환합니다.
**본부장님 보고용 (결론 먼저, 간결하게):**
```plain text
"위 보고서를 본부장님 구두 보고용 2분 브리핑 스크립트로 변환해줘.
 결론부터 말하고, 숫자 중심으로, 불필요한 설명 없이."
```
**현장 담당자용 (즉시 조치 중심):**
```plain text
"위 보고서에서 프로님이 오늘 당장 해야 할 것만
 체크리스트 형식으로 뽑아줘.
 ①②③ 순서로, 각 항목에 완료 체크박스 포함."
```
**단톡방 공유용 (짧고 이모지 포함):**
```plain text
"위 보고서 핵심을 카카오톡 단톡방용으로 요약해줘.
 150자 이내. 이모지 포함. 핵심 수치와 즉시 조치 사항만."
```

```plain text

매달 바뀌는 부분:
- 날짜 → [YYYY년 MM월 DD일]

- 수량 → [수량]
```

## 보고서 완성 후 — 실제 제출까지의 흐름
보고서 Word 파일을 다운로드한 후 실제 제출 전까지 해야 할 것들입니다.
**STEP 1. Word 파일 열기 + 전체 통독**
```plain text
다운로드한 .docx 파일을 Word에서 열고
처음부터 끝까지 한 번 읽습니다.
읽으면서 이상한 부분에 형광펜으로 표시합니다.
```
**STEP 2. 수치 검증 (3개 이상)**
```plain text
핵심 수치를 원본 분분석 결과와 직접 대조합니다.

예:
보고서: "갈비(국내산 원육) 월총출고 700,625"
원본:   피벗 결과 파일에서 확인 → 700,625 ✅

보고서: "위험 품목 24개"
원본:   2회차 분분석 결과 → 24개 ✅
```
**STEP 3. 현장 맥락 추가**
```plain text
AI가 모르는 배경 정보를 직접 추가합니다.

예:
AI 초안: "된장육수 실재고 1개, 즉시 발주 필요"
추가:    "(5/28 입고 예정, 발주 완료)"

AI 초안: "돌판김치 합재고 vs 실재고 차이 982개"
추가:    "(5/25 납품 시 수량 오차 발생, 검수 재실시 예정)"
```
**STEP 4. 보고 대상 최종 확인**
```plain text
본부장님께 드리는 보고서라면:
- 전문 용어가 최소화됐는가
- 결론이 앞에 나와 있는가
- 30초 안에 핵심을 파악할 수 있는가
```
**STEP 5. 최종 파일 저장**
```plain text
파일명: 구매부_5월_재고현황_20260527_최종.docx
저장 위치: 구글 드라이브/3회차/보고서/
```

### 프로님 — 지출결의서 집계 보고서 (오늘 실습) + 5회차 자동화 예고
**핵심 업무:** 매일 지출결의서(전일·당일 지출 내역)를 확인하고 매장별 지출을 매출 파일에 수동 입력.
**지출결의서 구조:**
```plain text
교육기관(법인) 전일지출 / 당일지출
개인사업자 전일지출 / 당일지출
각각: 항목 | 매장명 | 금액 | 비고
```
**오늘 실습 (Claude로 집계):**
```plain text
[D] 첨부한 파일은 교육기관 3월 21일 지출결의서야.
    전일지출(C~F열)과 당일지출(G~J열) 두 구간이 있고
    각 구간에 항목·매장명·금액·비고가 있어.
    개인사업자 지출은 K~N열(전일)과 O~R열(당일)에 있어.

[S] 매장별 지출 합계와 항목별 지출 합계를 집계하고 싶어.
    월말 결산 보고서 작성에 활용할 예정이야.

[R] 두 가지 표로 만들어줘:

    [표 1] 매장별 지출 합계 (전일+당일 합산)
    | 매장명 | 항목 수 | 합계 금액(원) |
    금액 내림차순 정렬. 맨 아래 전체 합계.

    [표 2] 항목별 지출 합계
    | 항목 | 건수 | 합계 금액(원) |
    금액 내림차순 정렬.

    Word 파일로 다운로드.

[F] 합계 행 제외.
    금액이 없는 빈 행 제외.
    금액 천 단위 콤마. 법인과 개인사업자 구분 없이 합산.
```
**5회차 자동화 연결:**
```plain text
오늘 (수동):
지출결의서 Claude에 올리기 → 집계 표 + 보고서 초안 받기

5회차 GAS 이후 (자동):

→ GAS가 자동으로 매장별 금액을 읽어서
→ 매출 파일 해당 매장 시트에 자동 입력
→ 담당자 개입 불필요
```
