## 플랜 먼저: 복잡한 일은 계획부터
복잡한 작업을 한 번에 시키면 결과가 엉뚱할 수 있습니다. **플랜 **는 실행 전에 AI에게 계획을 먼저 세우게 하고, 검토 후 실행하는 방식입니다.
```mermaid
flowchart LR
    A["1. 계획 요청 : '계획부터 보여줘'"] --> B["2. 계획 검토 : 사람이 확인·수정"]
    B --> C["3. 실행 지시 : '이대로 실행해'"]
    C --> D["4. 결과 검증"]
```
**실전 프롬프트:**
```plain text
아래 작업을 하려고 해. 바로 실행하지 말고 단계별 계획을 먼저 보여줘.
작업: {내가 진행할 작업}
```
예시)
```plain text
아래 작업을 하려고 해. 바로 실행하지 말고 단계별 계획을 먼저 보여줘.
작업: 3개 부서 매출 데이터를 하나로 합치고, 부서별 소계와 전체 합계를 넣은 보고서 만들기.
```
**→ AI 계획 확인 후:**
```plain text
계획 좋아. 2단계에서 컬럼명이 다른 경우도 처리해줘.
마지막에 날짜를 파일명에 넣는 단계도 추가해. 이대로 실행해줘.
```
💡 복잡한 작업은 반드시 “계획 → 검토 → 실행” 순서로 진행하세요.

#### 1. `hello_streamlit.py` 파일 생성 + 터미널 열기 (Ctrl + J)
[원본 이미지 제외]
#### 2. 스트림릿 직접 설치
- 터미널에 입력
```javascript
py -m pip install streamlit
```
- 혹은, 그냥 클로드코드에 요청!
#### **3. 아래 코드 블록 안의 내용만 복사해서 붙여넣기 (박스 바깥 설명 문장은 복사하지 않기)**
```javascript
# hello_streamlit.py — Streamlit 웹 앱
import streamlit as st
st.write("Hello, 오롱 씨!")
name = st.text_input("이름을 입력하세요", "오롱")
st.write(f"{name}님, 오늘 매출 데이터를 분석해봅시다.")
```
**파일명** **`hello_streamlit.py`** ** 로 저장 (Ctrl+S)**
```javascript
hello_streamlit.py
```
#### 4. 터미널에 아래 명령어 입력
```javascript
streamlit run hello_streamlit.py
```
```python
py -m streamlit run hello_streamlit.py
```
[원본 이미지 제외]
VSCode 터미널은 그대로 켜진 채로 남아있고, 브라우저가 자동으로 열리며 [개별 링크 제외] 웹페이지가 뜹니다. <br>프로그램은 종료되지 않고 계속 실행 상태를 유지하며, 입력값(이름)을 바꾸면 화면이 곧바로 다시 그려집니다.
#### **5. 재실행 원리 체감하기 (심화, 선택)**
hello_streamlit.py 내용을 아래 코드로 바꾸고 **`VSCode에서 저장 (Ctrl+S) `**→ 터미널이 이미 실행 중이면 브라우저에서 **`F5 새로고침`**만으로 반영됩니다.
```javascript
import streamlit as st
st.title("재실행 체감 실습")
clicked = st.button("버튼 클릭")
if clicked:
 st.write("버튼을 눌렀습니다! 이 순간 전체 코드가 처음부터 다시 실행됩니다.")
st.write("이 문장은 버튼을 누르든 안 누르든 항상 다시 나타납니다.")
```
버튼을 누르는 순간 파일 전체가 위에서 아래로 다시 실행됩니다. <br>이후 실습에서 사이드바 필터를 바꾸면 차트가 자동으로 갱신되는 것도 동일한 원리입니다.
이 원리를 먼저 알고 들어가면 대시보드 코드의 필터 부분을 훨씬 쉽게 이해합니다.
