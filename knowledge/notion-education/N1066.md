# STEP 5 | 첫 테스트 — 실제 업무 내용으로 돌려보기

정리일: 2026-10-08 · 교육 에셋 N1066

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
등록한 Gem을 실제 업무 내용으로 테스트하고 결과를 점검합니다.
## 진행 단계
1. **입력** — 사업명·기간·대상 등 업무 내용 입력
2. **출력 형식 확인** — P의 순서·형식·분량이 지켜졌는가
3. **내용 정확성 확인** — 입력하지 않은 수치·날짜를 만들어내지 않았는가, \[미기재\] 표시, Golden Sample과 문체 유사
4. **개선** — 지시문의 해당 칸 수정 → 저장 → 재테스트
## 막히는 지점
- 결과가 길다 → P에 분량 제한 / 문체 어색 → Golden Sample 교체 / 항목 누락 → P에 추가 / 임의 수치 → 금지 문구 추가
