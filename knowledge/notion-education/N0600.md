# 실습 ① 자료 정리 — 빈칸·숫자 아닌 칸 색칠

## 이 실습으로 하는 것
영수증첨부가 빈칸인 행과 항공료가 숫자가 아닌 칸을 앱스크립트로 색칠한다. 값은 그대로 두고 색만 바꾼다.
## 진행 단계
1. **Google 시트로 열기** — 드라이브에 `01_출장실습데이터_통합.xlsx` 업로드 → 파일 → Google Sheets로 저장 → 파일 이름을 `D2P4_정산정리_실습`으로 변경
- 정상 결과: 이름 옆 `.XLSX` 표시가 없고 `출장정산내역` 탭이 보임
2. **코드 받아 붙여넣기** — 확장 프로그램 → Apps Script 열기, ChatGPT 새 채팅에 프롬프트 입력 후 Copy code, 기본 코드 삭제 후 붙여넣고 저장
- 입력할 내용:
```javascript
Google Apps Script 코드를 짧게 만들어 줘. 코드를 모르는 사람이 Google 시트에 붙여넣어 쓸 코드임.
- 시트 이름: 출장정산내역 (1행 머리글, 2행부터 데이터)
- 열은 위치(A열·B열)가 아니라 1행 머리글 이름으로 찾기
- 할 일 1: '영수증첨부' 칸이 빈칸인 행 전체를 연한 노란색으로 칠하기
- 할 일 2: '항공료' 칸이 숫자가 아닌 칸만 연한 빨간색으로 칠하기(값은 고치지 않음)
- 끝나면 실행 로그에 칠한 행 수와 칸 수를 출력
- 값 수정·행 삭제·메일 발송 코드는 넣지 말 것
- 함수 이름: markRows
답변: 코드 전체 한 덩어리 + 실행할 함수 이름
```
1. **실행하고 권한 허용** — 드롭다운에서 `markRows` 선택 → 실행 → 권한 검토 → 계정 선택 → 확인하지 않은 앱 화면에서 고급 → 이동(안전하지 않음) → 스프레드시트 보기·수정 확인 후 허용
- 메일 보내기 권한이 보이면 취소
2. **결과 확인** — 실행 로그와 시트 확인
- 정상 결과: 실행 로그 `노란 행 1개, 빨간 칸 1개`, 값은 그대로이고 색만 바뀜
## 막히는 지점
- 수가 다르면 시트 이름이 `출장정산내역`인지, 1행 머리글 글자가 프롬프트와 같은지 확인
