## 이 실습으로 하는 것
Artifacts 실행 권한(코드 실행 및 파일 생성 토글)이 켜져 있는지 확인한다.
## 진행 단계
1. **로그인** — claude.ai 로그인
2. **설정 열기** — 왼쪽 사이드바 맨 아래 이름 이니셜이 든 동그라미 아이콘 클릭 → 메뉴에서 ［설정］(Settings) 클릭
3. **기능 탭 찾기** — 설정 창 왼쪽 탭 목록에서 "기능" 계열 탭(한글 계정 \[기능\], 영문 \[Capabilities\] 또는 \[Features\])
4. **토글 확인** — "코드 실행 및 파일 생성"(Code execution and file creation) 항목의 토글이 켜짐(파란색/오른쪽)인지 확인. 꺼져 있으면 켜기
- 정상 결과: 토글이 켜진 상태이고, 항목 아래에 파일 생성·코드 실행 관련 설명 한 줄이 붙어 있음
## 막히는 지점
