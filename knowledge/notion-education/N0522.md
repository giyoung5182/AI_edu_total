## 이 실습으로 하는 것
Claude Code가 실제로 실행되고, 내 폴더에 연결된 상태를 만듭니다.
## 진행 단계
1. **Git 설치 (8분)** — Windows는 git-scm.com에서 \[Install for Windows\] → x64 설치 파일을 받아 설치마법사를 진행합니다. 에디터 선택 화면만 \[Use Notepad as Git's default editor\]로 바꾸고 나머지는 기본값 \[Next\]입니다. Mac은 터미널에서 `git --version`으로 먼저 확인합니다.
- 입력할 내용: `git --version`
- 정상 결과: `git version 2.55.x` 같은 숫자가 나오면 통과
2. **Node.js 설치 (8분)** — nodejs.org에서 \[Get Node.js®\] → 페이지 맨 아래 ［Windows 설치 프로그램 (.msi)］(Mac은 .pkg)을 받아 설치합니다. 'Add to PATH'는 켜 둔 채 두고, Tools for Native Modules의 자동 설치 체크박스는 비워 둡니다.
- 입력할 내용: `node -v` 그리고 `npm -v`
- 정상 결과: `v24.x.x` 와 `11.x.x` 같은 두 줄
3. **앱 재시작 (2분)** — Claude 데스크톱 앱을 완전히 종료한 뒤 다시 실행하고, 교육용 계정으로 로그인되어 있는지 확인합니다.
4. **폴더 연결 (5분)** — sw-practice.zip을 다운로드해 압축을 풉니다. 화면 위쪽 \[Code\] 탭 → 입력창 위 \[로컬\] 선택 → \[폴더 선택\] → 바탕화면에 새 폴더 sw-practice를 만들어 선택합니다.
5. **첫 인사 (2분)** — 입력창에 아래 문장을 입력합니다.
- 입력할 내용: `안녕? 이 폴더에서 작업할 거야. 한국어로 답해줘.`
- 정상 결과: 한국어로 답이 오면 환경 구축 완료
## 막히는 지점
- 폴더 선택 버튼이 안 눌림: Git 미설치(윈도우) → STEP 1로 돌아가기
- "업그레이드하세요"가 뜸: 개인 무료 계정 → 로그아웃 후 교육용 계정으로
- "온라인에서 로그인하세요": 인증이 덜 끝남 → 로그인 후 앱 완전 종료 → 재실행
- Code 탭이 안 보임: 앱 버전이 오래됨 → 왼쪽 아래 업데이트 안내 클릭
- 영어로 답함: "한국어로 답해줘" 추가
- Node 설치가 끝없이 진행됨: Native Modules 체크함 → 중단하지 말고 기다리기
- "PC를 보호했습니다"(SmartScreen): \[추가 정보\] → \[실행\]
- "확인되지 않은 개발자"(Mac): 시스템 설정 → 개인정보 보호 및 보안 → \[그래도 열기\]
- 백신이 설치를 차단: 혼자 백신을 끄지 말고 손들기
- 오늘 "제 파일이 안 보여요"가 되면 실행 위치가 \[로컬\]인지 먼저 확인
