## 이 실습으로 하는 것
명세서와 데이터를 "한 번에 다" 시켜 화면을 만들어 보고, 결과는 좋아 보여도 무엇이 남는지 확인합니다.
## 진행 단계
1. **새 세션 열기, 프롬프트 입력**
- 입력할 내용:
```javascript
coding 폴더의 02_명세서.md 와 03_데이터.csv 을 읽고,
화면을 하나 만들어줘. 명세서에 적힌 대로 다 넣고 보기 좋게 만들어줘.

coding 폴더에 임시.html 로 저장해줘.
```
1. **열어 보기** — 파일 탐색기에서 임시.html을 더블클릭해 엽니다.
2. **남는 문제 확인** — AI가 혼자 정한 것이 수십 가지 섞여 있음 / 한 군데를 고치면 다른 데가 같이 바뀜 / 저장이 안 들어가 있어 새로고침하면 사라짐
3. **파일 버리기** — 이 파일은 버리고 다음 Step부터 다시 만듭니다.
