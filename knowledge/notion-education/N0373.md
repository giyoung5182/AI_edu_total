# 활동 2 — 두 표를 자동으로 매칭해서 채우기 (조회 자동화)

정리일: 2026-10-08 · 교육 에셋 N0373

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
부품코드로 단가표를 찾아 채우고 합계까지 계산하는 매크로를 ChatGPT로 만들어 실행합니다.
## 진행 단계
1. **실행 방법** — 활동 1과 동일(파일 열기 → ChatGPT 프롬프트 → 코드 복사 → \[개발도구\]→\[Visual Basic\]→\[삽입\]→\[모듈\] 붙여넣기 → F5)
- 입력할 내용: 입고내역 시트 A열(부품코드) 기준으로 부품마스터에서 부품명·단가를 찾아 C·D열에 채우고, E열에 입고수량×단가 합계 계산, 마스터에 없는 코드는 "코드 확인 필요" 빨간 글씨 표시, 실행 후 처리 행 수를 메시지로 알림
- 정상 결과: "입고내역" 시트에 부품명·단가·합계가 채워짐
2. **Padlet 업로드** — 채워진 결과 또는 내 업무의 어떤 대조 작업에 쓸지를 올림
- 한 걸음 더: 찾을 값을 "재고 수량"이나 "담당자"로 바꾸거나 없는 코드 처리 방식을 바꿔 다시 요청
## 막히는 지점
- 오류 메시지가 뜨면 그대로 복사해 ChatGPT에 붙여넣어 고치게 함
