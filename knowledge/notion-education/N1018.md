## 이 실습으로 하는 것
시트의 지정 범위를 읽어 업체별 금액 목록을 하나의 메일로 보내는 월간 현황 시나리오를 만듭니다.
## 진행 단계
1. **Schedule** — 테스트는 Every day 09:00 (실제는 Every month / Day 28), Timezone Asia/Seoul
2. **Get a Range** — Range A2:B6 (헤더 제외), Value render option: Formatted value
3. **Iterator** — Array: "2. Google Sheets \> Data" 또는 "Rows"
4. **Text Aggregator** — Source Module "3. Iterator", Text는 업체명 + ": " + 금액 + "원", Row separator n
5. **Gmail** — Content에 "5. Text aggregator \> Text"와 "200만원 초과 업체는 별도 검토 바랍니다" 안내 문구 삽입
6. **테스트** — Save → Run once → 업체별 목록 메일 수신 확인
## 막히는 지점
- Range 형식: "시트명!셀범위" 또는 "A2:B6", 시트명이 한글이면 '합계테스트'!A2:B6 형식이 필요할 수 있음
- 200만원 초과 강조: 조건부 텍스트는 복잡하므로 수업에서는 본문 안내 문구를 추가하는 간단 방법 권장
