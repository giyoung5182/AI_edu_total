# 자주 받는 질문
<details>
<summary>제 일은 매번 내용이 달라서 자동화할 게 없는데요?</summary>
여기서 말하는 「반복」은 **내용이 같다는 뜻이 아니라 처리 순서가 비슷하다**는 뜻입니다.
A사 규격서와 B사 규격서는 프로토콜도 레지스터 맵도 다릅니다. 하지만
```javascript
통신 방식 확인 → 제어 항목 정리 → 범위값 구분 → 문의 항목 추린다
```
이 순서는 매번 같습니다. **절차가 같으면 반복 업무입니다.**
1교시에서 본인 업무를 동작 단위로 쪼개 보시면 바로 확인됩니다.
</details>
<details>
<summary>가장 힘든 업무를 자동화하고 싶은데요?</summary>
힘든 이유가 대개 **판단이 복잡해서**입니다. 판단이 복잡하면 규칙이 없다는 뜻이고, 규칙이 없으면 자동화가 안 됩니다.
업무 **전체**를 자동화하려는 게 아닙니다. 비효율의 핵심 부분만 해결하면 됩니다.
```javascript
연동 규격 검토 120분
= 문서 훑기 20분 + 항목 추출·정리 60분 + 판단 25분 + 문의서 15분
                        ↑                      ↑
                  자동화 가능            자동화 가능

판단 25분만 남기면 120분 → 50분이 됩니다.
```
</details>
<details>
<summary>사내 자료를 올려도 되나요?</summary>
오늘 배포된 자료는 고객사가 비식별화를 마쳐 제공한 것이라 그대로 쓰셔도 됩니다.
본인 문서를 쓰고 싶으시면 **대외비와 개인정보가 없는 범위**에서 올려 주세요.
사내에서 실제로 쓸 때의 허용 범위는 5교시에서 따로 정리합니다.
</details>
<details>
<summary>교안은 교육 끝나면 닫히나요?</summary>
아닙니다. **계속 열람하실 수 있습니다.**
사내 공유나 신규 입사자 교육 자료로 재사용하셔도 됩니다.
실습 프롬프트도 교안 안에서 바로 복사해 쓰실 수 있습니다.
</details>
