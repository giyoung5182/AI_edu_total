## 1️⃣ 자연어로 수식 만들기
**수식을 몰라도 됩니다.** 원하는 걸 말로 설명하면 수식이 나옵니다.
### 새 열 만들기
```plain text
월별성과 시트에 새 열을 만들어줘.

열 이름: 건당보험료
계산: 신계약보험료 ÷ 신계약건수

소수점 없이 정수로 표시해줘.
수식으로 만들어줘.
```
### 조건이 들어간 수식
```plain text
지점마스터 시트에 새 열을 만들어줘.

열 이름: 규모구분
조건: 기준FC수가 45 이상이면 "대",
      25 이상이면 "중", 나머지는 "소"

수식으로 만들어줘.
```
> ⚠️ **값만 들어갔으면 다시 요청하십시오**
```plain text
계산 결과 말고 수식으로 만들어줘.
```
**수식이어야 원본이 바뀔 때 자동으로 갱신됩니다.**
### 남이 만든 수식 이해하기
```plain text
D2 셀의 수식이 무엇을 계산하는지
한 줄씩 설명해줘.
각 인수가 무엇을 의미하는지도 알려줘.
```
```plain text
이 수식에서 달러 표시($)가 왜 붙었는지 설명해줘.
```
> 💡 **인수인계 받을 때 가장 유용합니다**
전임자가 만든 복잡한 수식을 뜯어볼 때 시간이 크게 줄어듭니다.
### 막힐 때 — 좋은 질문 방식
```plain text
아래 수식이 원하는 값을 내지 않아.

[내가 넣은 수식]
(수식 붙여넣기)

[데이터 구조]
- A열 지점코드, B열 연월(YYYY-MM 텍스트), C열 신계약건수

[결과]
빈 값이 나옴 (기대값은 28)

원인이 뭔지 알려주고 수정된 수식을 알려줘.
```
**내가 쓴 수식 · 데이터 구조 · 실제 값 · 기대값** 네 가지를 주면 대부분 한 번에 해결됩니다.
> ⚠️ **텍스트 날짜 조건은 자주 막힙니다**
`2025-01` 같은 텍스트에 `>=` 부등호를 쓰면 AVERAGEIFS가 무시합니다.
**숫자로 바꿔서 비교하십시오.**
```plain text
=VALUE(SUBSTITUTE(B2,"-",""))   →  202501
```
실무에서 가장 자주 걸리는 함정입니다.

## 2️⃣ 차트 만들기
**차트 종류를 몰라도 됩니다.** 무엇을 보고 싶은지만 말하면 됩니다.
### 추세 보기
```plain text
월별성과 시트로 2023년부터 2026년까지
전체 신계약건수의 월별 추이를 보여주는 차트를 만들어줘.

차트는 새 시트에 만들어줘.
```
### 비교하기
```plain text
지점규모별 평균 신계약건수를 비교하는 막대 차트를 만들어줘.
지점마스터 시트의 지점규모를 기준으로 해줘.
```
### 다듬기
```plain text
방금 만든 차트의 제목을 "지점규모별 월평균 신계약건수"로 바꾸고,
막대에 값을 표시해줘.
```
```plain text
막대 차트 말고 가로 막대로 바꿔줘.
값이 큰 순서로 정렬해줘.
```
> 💡 **차트 제목은 결론으로 쓰십시오**
"지점규모별 신계약건수"보다 **"대형 지점이 소형 대비 2.8배"** 가 낫습니다.
보고받는 사람은 차트를 분석하지 않습니다. **제목을 읽습니다.**

## 3️⃣ COPILOT 함수 — 셀 안에서 AI 쓰기
**가장 새로운 기능입니다.** 수식처럼 셀에 입력하면 AI가 답을 채웁니다.
```plain text
=COPILOT("무엇을 할지", 범위)
```
### 쓸 수 있는 곳
**① 텍스트 요약**
```plain text
=COPILOT("이 피드백을 한 문장으로 요약", A2:A20)
```
**② 분류·태그 지정**
```plain text
=COPILOT("아래 내용을 긍정/부정/중립으로 분류", B2)
```
수백 건의 의견을 하나씩 읽지 않고 분류합니다. **아래로 채우면 전체가 처리됩니다.**
**③ 텍스트 생성**
```plain text
=COPILOT("이 지점 정보로 소개 문구 한 줄 작성", A2:D2)
```
**④ 샘플 데이터 만들기**
```plain text
=COPILOT("보험 상품명 예시 10개")
```
### ⚠️ 계산에는 쓰지 마십시오
공식 문서가 명시하고 있습니다.
> **정확도나 재현성이 필요한 작업에는 SUM, AVERAGE, IF 같은 기본 수식을 사용하십시오.**
```plain text
=COPILOT("합계 계산", A2:A100)     ✗
=SUM(A2:A100)                      ✓
```
**COPILOT 함수는 글을 다루는 데 씁니다.**

## 1️⃣2️⃣ VBA 코드 만들기
**Copilot은 코드를 만들어주고, 실행은 사람이 합니다.**
### 요청 프롬프트
```plain text
Excel VBA 매크로를 작성해줘.

[기능]
지점마스터 시트에서 지점규모가 "대형"인 행만 골라
"대형지점" 시트에 복사하기

[파일 구조]
- 시트명: 지점마스터
- 1행: 항목명 (A열 지점코드, B열 지점명, C열 지역, D열 지점규모)
- 2행부터 데이터

[조건]
- 결과는 "대형지점" 시트에 출력 (헤더 포함)
- 기존 시트가 있으면 내용을 지우고 새로 작성
- 복사한 행 수를 완료 메시지로 표시
- 각 줄에 주석을 달 것

[금지]
- 원본 시트를 수정하지 말 것
- 파일을 저장하는 코드를 넣지 말 것
```
> 💡 **"파일을 저장하는 코드를 넣지 마"가 중요합니다**
저장 코드가 들어가면 **결과를 확인하기도 전에 원본이 덮어써집니다.** 눈으로 본 뒤 사람이 저장하는 게 안전합니다.
### 실행 전에 반드시 확인하십시오
```plain text
이 코드가 하는 일을 단계별로 설명해줘.
원본 시트를 수정하거나 삭제하는 부분이 있으면
몇 번째 줄인지 알려줘.
```
### 실행 순서
```plain text
① 파일을 사본으로 저장   ← 반드시
② Alt + F11  (VBA 편집기 열기)
③ 삽입 → 모듈
④ 코드 붙여넣기
⑤ F5 실행
```
> ⚠️ **VBA는 Ctrl + Z가 안 됩니다**
실행하면 되돌릴 방법이 없습니다. **사본으로만 실행하십시오.**
매크로 실행이 막혀 있으면 `파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 매크로 설정`에서 확인하십시오. 조직 정책으로 잠겨 있을 수 있습니다.
### 오류가 났을 때
```plain text
아래 코드 실행 중 오류가 났어.

[오류 메시지]
(오류창 내용 그대로 복사)

[멈춘 줄]
(노란색으로 표시된 줄 그대로 복사)

[상황]
- 시트명:
- 데이터 행 수:

원인과 수정된 코드를 알려줘.
수정한 부분이 어디인지 표시해줘.
```
> 💡 **오류 메시지를 그대로 복사하십시오**
"안 돼요"라고 하면 AI도 추측할 수밖에 없습니다. **오류 번호와 노란 줄**을 붙여넣으면 대부분 한 번에 해결됩니다.
### 만든 코드는 저장해두십시오
```plain text
' 용도: 대형 지점만 추출
' 작성: 2026-08
' 사용법: 지점마스터 시트 준비 후 실행
' 주의: 사본에서만 실행할 것
```
**다음 달에 처음부터 다시 만드는 시간이 사라집니다.**

## 1️⃣3️⃣ 파워쿼리 — 여러 파일 취합
**부서에서 가장 자주 하실 작업일 겁니다.**
Copilot이 파워쿼리를 **대신 만들어주지는 않습니다.** 방법을 알려줍니다.
### 물어보는 방식
```plain text
여러 엑셀 파일을 하나로 합치려고 해.
```

## 1️⃣5️⃣ 그 외 알아두면 좋은 Excel 기능





기능

하는 일




**포커스 셀**

셀 선택 시 같은 행·열 자동 강조




**트리밍 참조**

`=SUM(A:.A)` — 실제 데이터 범위만 참조




**동적 배열**

한 수식으로 여러 행 결과 반환




**피벗 자동 새로고침**

데이터 추가 시 자동 갱신


> 💡 **트리밍 참조가 의외로 유용합니다**
`=SUM(A:A)`는 열 전체를 계산해서 느립니다. **콜론 뒤에 마침표**를 찍으면 실제 데이터가 있는 범위만 봅니다.
수식 속도가 빨라지고, 데이터가 늘어나도 범위가 자동 확장됩니다.

