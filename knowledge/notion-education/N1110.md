# 실습 3 | 릴스 대본 + 자동DM 완성

정리일: 2026-10-08 · 교육 에셋 N1110

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지금 이 자리에서 릴스 대본 1편 + 자동DM 문구를 완성합니다.
## 진행 단계
1. **내 제품·타겟 선택 (3분)** — 제품, 타겟 고민, 훅 타입(공감형/질문형/충격형), CTA 키워드를 정합니다.
2. **GEMS 2로 대본 생성 (10분)** — GEMS 2(릴스 대본 전략가)에 입력합니다.
- 입력할 내용:
```javascript
제품: 【선택한 제품】
타겟 고민: 【선택한 고민】
훅 타입: 【선택한 타입】
30초 릴스 대본 3가지 버전으로 써줘
```
- 정상 결과: 결과 중 가장 마음에 드는 버전 1개 선택
1. **체이닝으로 다듬기 (5분)**
- 입력할 내용:
```javascript
①번 버전에서 훅 문장을 더 강하게 바꿔줘.
본문은 그대로, CTA만 '댓글에 【키워드】' 형식으로 수정해줘.
```
1. **자동DM 문구 생성 (7분)** — GEMS 4(고객 상담 비서)에 입력합니다.
- 입력할 내용:
```javascript
CTA 키워드는 '【키워드】'야.
자동DM 문구 3가지 버전:
- 버전 A: 사용법 중심
- 버전 B: 구매 유도 중심
- 버전 C: 1:1 상담 연결
각각 150자 이내로
```
1. **완성본 저장 (5분)** — 릴스 대본 최종본, 자동DM 문구 선택본, CTA 키워드, ManyChat 설정 예정일, 촬영 예정일을 정리합니다.
- 정상 결과: 제품·타겟 선택 / 릴스 대본 3종 생성 / 최종 버전 1개 + 체이닝 / 자동DM 문구 3종 / 이번 주 촬영 날짜 잡기 완료
