## 이 실습으로 하는 것
파이썬 환경을 한 번에 확인하는 점검 스크립트를 만들어 실행합니다.
## 진행 단계
1. **스크립트 만들고 실행**
```bash
cd ~/hanbit-ai && source .venv/bin/activate
cat > check_env.py << 'EOF'
for pkg in ["pypdf", "chromadb", "voyageai", "google.genai", "tavily", "rank_bm25"]:
    try:
        __import__(pkg)
        print(f"패키지 {pkg}: OK")
    except ImportError:
        print(f"패키지 {pkg}: 설치 필요")
EOF
python3 check_env.py
```
- 정상 결과: 모든 항목이 OK면 준비 완료. Claude Code는 `claude doctor`로 별도 확인
1. **총괄 체크리스트 확인** — WSL2·Ubuntu 계정, Windows Terminal 기본 프로필 Ubuntu, claude --version, claude doctor, Claude Code 인증, \~/hanbit-ai와 .venv, 패키지 6종, 점검 스크립트 OK
