# 실습 2 — 가능/불가능 경계 케이스 직접 테스트

정리일: 2026-10-08 · 교육 에셋 N0440

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
세 가지 요청을 순서대로 Copilot에 입력해 가능/한계/불가능 경계를 직접 경험합니다.
## 진행 단계
1. **케이스 A — 가능한 요청(텍스트 기반)**
- 입력할 내용:
```javascript
아래 매출 데이터를 분기별로 합산하여 표로 만들어줘.

1월: 1,200만원
2월: 980만원
3월: 1,540만원
4월: 870만원
5월: 1,100만원
6월: 1,320만원
```
- 정상 결과: Q1(1\~3월), Q2(4\~6월) 합산 표가 즉시 생성
1. **케이스 B — 한계가 있는 요청(로컬 파일 접근 시도)**
- 입력할 내용:
```javascript
내 컴퓨터 C드라이브에 있는 sales_2024.xlsx 파일을 열어서 1월 매출을 알려줘.
```
- 정상 결과: 로컬 파일에 직접 접근할 수 없다고 안내하며 텍스트로 붙여넣도록 유도
1. **케이스 C — 불가능한 요청(실시간 데이터 연동)**
- 입력할 내용:
```javascript
현재 코스피 지수를 가져와서 우리 팀 포트폴리오 수익률과 비교해줘.
```
- 정상 결과: 실시간 외부 데이터 연동은 불가능하며, 검색이 지원되면 최근 지수를 웹에서 찾아 안내하거나 불가능함을 명시
1. **생각해보기** — 케이스 B처럼 파일 접근이 안 될 때 대안 워크플로우로 같은 작업을 어떻게 할지, 내 업무에서 즉시 처리 가능한 작업과 불가능한 작업을 각각 하나씩 떠올려보기
