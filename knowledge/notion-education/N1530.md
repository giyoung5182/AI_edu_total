# 카드뉴스 제작 완전 워크플로우 — 3단계 10분 완성

정리일: 2026-10-08 · 교육 에셋 N1530

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
AI로는 배경만 만들고 한글 텍스트는 Canva에서 직접 입력해 한글 깨짐 없는 카드뉴스를 10분 안에 만드는 워크플로우를 따라 합니다.
## 진행 단계
1. **STEP 1 \| ChatGPT로 카드뉴스 텍스트 기획 (2분)** — 카드뉴스 5장(표지 1 + 본문 3 + CTA 1)의 헤드라인(20자 이내)·본문(50자 이내)·이미지 방향을 기획합니다.
- 입력할 내용:
```javascript
파메스테틱 에스테틱 원장으로서 민타비20 소개 인스타 카드뉴스 5장을 기획해줘.
구성: 표지 1장 + 본문 3장 + CTA 1장
각 장마다: 헤드라인 20자 이내 / 본문 50자 이내 / 이미지 방향 한 줄
(이하 교안 참고)
```
1. **STEP 2 \| ChatGPT 4o로 배경 이미지 생성 (3분)** — STEP 1의 이미지 방향을 참고해 영문 프롬프트로 배경을 만듭니다(끝에 no text, no letters, no korean characters).
- 입력할 내용: "square 1:1 bold dramatic cosmetic photography, red ampoule bottle standing on dark navy surface, ... no text, no letters, no korean characters" (이하 교안 참고)
2. **STEP 3 \| Canva에서 한글 텍스트 합성 + 완성 (5분)** — 새 디자인(인스타그램 게시물 1080×1080px) → 배경 이미지 업로드 → 텍스트 추가 → 폰트·색상 설정 → 계정명 추가(선택) → 공유 \> 다운로드 \> PNG.
- 정상 결과: Hook·Body·Action·Hashtags 구조의 5장 카드뉴스. 1장 완성 후 페이지 복제로 텍스트만 바꾸면 2\~3장부터 장당 1분.
## 막히는 지점
- 배경 이미지가 너무 어두워 텍스트가 안 보일 때: 이미지 편집에서 밝기를 올리거나 텍스트 상자에 반투명 검정 배경(투명도 50%) 추가
- 텍스트가 이미지 분위기와 안 어울릴 때: 폰트·색상 변경
- AI 이미지 프롬프트에 한글 텍스트를 넣으면 깨지므로 텍스트는 Canva에서 입력
