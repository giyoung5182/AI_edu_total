# 바이브코딩 기초 실습

정리일: 2026-10-08 · 교육 에셋 N1064

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Claude Code에 역질문 방식으로 요구사항을 정리시켜 엑셀 업로드 대시보드 웹앱을 만들 준비를 합니다.
## 진행 단계
1. **프롬프트 예시 입력**
```javascript
나는 지금부터 엑셀 파일을 업로드하면 웹 화면에서 표와 차트로 보여주는 대시보드 웹앱을 만들거야.
그런데 기술스택은 뭘사용할지, 디자인은 어떻게할지 아직 정해지않았어.
너가 어떻게 하면 좋을지, 지금부터 필요한 정보를 나에게 질문해가면서 정리해주고, 내가 결정해야할 사항들은 선택지를 줘서 선택하게 해줘.
질문은 필요한 만큼 진행해줘
한번에 질문을 하나씩 해줘.
```
2. **질문에 답하기** — Claude Code가 한 번에 하나씩 물어보는 질문에 답하고, 선택지가 있으면 고릅니다.
3. **꼭 들어가야 하는 내용 반영** — 기술 스택은 React + Vite로, run.bat라는 실행파일을 만들어 실행하게 하고, 디자인은 design.md를 참고하도록 합니다.
## 막히는 지점
- 교안에 별도 기재 없음 (장점: 한 번에 좋은 프롬프트로 실행하는 쪽이 답변이 좋고 결과 테스트·수정 과정이 줄어든다고 적혀 있음)
