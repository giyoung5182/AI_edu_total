# 실습 2 — 전처리 → 분석 → 시각화 → 보고서 풀 워크플로우 실행

정리일: 2026-10-08 · 교육 에셋 N0445

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
비정형 텍스트에서 출발해 표, 인사이트, 차트, Executive Summary를 거쳐 한 장 보고서까지 연속된 흐름으로 완성합니다. (35분)
## 진행 단계
1. **소단계 A 전처리·표 변환 (8분)** — 추출 항목을 넣어 Copilot에 표 변환을 요청하고 품질 체크리스트 프롬프트로 검증한 뒤, ⚠️·❌ 항목은 재프롬프트로 고쳐 Excel에 저장합니다.
- 입력할 내용:
```javascript
아래 텍스트에서 [항목1], [항목2], [항목3], [항목4]를 추출하여 표로 정리해줘.
처리 규칙:
- 누락값은 "미확인"으로 표시해줘.
- 중복 항목이 있으면 별도 행으로 표시하고 "(중복)" 표시를 추가해줘.
- 날짜는 YYYY-MM-DD 형식으로 통일해줘.
- 숫자 단위는 통일해줘 (예: 모두 "건" 또는 모두 "시간"으로).

[실습 1에서 준비한 샘플 데이터 붙여넣기]
```
1. **소단계 B 인사이트 도출 (7분)** — 완성된 표로 패턴·이상치·변화를 분석시키고, 수치를 표와 대조한 뒤 헤드라인 1문장(30자 이내, 수치 포함, 단언형)을 만듭니다.
2. **소단계 C 차트 생성 (10분)** — 차트 유형을 추천받고 Excel에서 데이터 범위 선택 → 삽입 탭 → 차트 유형 → 제목·범례·데이터 레이블 추가 순으로 만듭니다.
3. **소단계 D 한 장 보고서 완성 (10분)** — Executive Summary(5줄 이내)를 작성하고 PPT에 헤드라인·차트·KPI 박스 3개·주목 포인트·Executive Summary를 배치한 뒤 체크리스트로 점검하고 파일로 저장합니다.
- 정상 결과: 정형 표 → 인사이트 → 차트 → Executive Summary → 한 장 보고서까지 완성
## 막히는 지점
- Copilot 수치가 표와 다르면 재프롬프트로 수정 요청
- 시간이 부족하면 Executive Summary까지만 완성
