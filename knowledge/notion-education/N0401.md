# 실습 1. 빈칸 채워 지침 쓰기 — ROPEK 다섯 요소 틀

정리일: 2026-10-08 · 교육 에셋 N0401

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
「출장규정 문의 도우미」(프로젝트 지침)를 ROPEK 다섯 요소 빈칸 틀로 처음부터 씁니다.
## 진행 단계
1. **빈칸 틀 복사** — 아래 틀을 메모장에 붙여넣습니다.
- 입력할 내용:
```javascript
[R 역할]
너는 (    ) 담당자다.
잘하는 것: ① (   ) ② (   ) ③ (   )

[O 목적]
(   )이 (   )을 물으면 답한다.
다루는 범위: (   ) / 다루지 않는 것: (   )

[P 처리 방식] 요청받으면 이 순서로 진행한다.
1. (   )이 빠졌으면 답하기 전에 먼저 묻는다.
2. (   )
3. (   )
4. 규정이 서로 다르거나 파일에 없으면 (   )
- 응답 양식: ① (  ) ② (  ) ③ (  ) ④ (  )
(이하 교안 참고)
```
2. **( ) 빈칸 채우기** — 규정 파일을 열어 참고하고 `→ 힌트` 줄은 지웁니다.
3. **(선택) 새 채팅에서 다듬기** — 채운 지침을 붙여넣고 맨 아래에 `빈칸 채운 지침을 다듬어 줘. R·O·P·E·K 다섯 요소 이름과 순서는 그대로 두고, 금액·비율·기한 숫자는 넣지 마.` 를 추가해 Enter
4. **완성 지침을 메모장에 저장** — 실습 2에서 이어서 다듬습니다.
- 막힐 때(메타 프롬프팅): ② 대신 새 채팅에 "바로 만들지 말고 먼저 필요한 정보를 나에게 물어봐 줘. 한 번에 하나씩 질문해 줘."를 포함한 프롬프트를 쓰고, 질문이 끝나면 `지금까지 답한 내용으로 위 빈칸 틀을 채워 줘`
## 막히는 지점
- 빈칸에 쓸 말이 떠오르지 않을 때는 메타 프롬프팅을 씁니다.
- 규정 원문과 금액·비율·기한 숫자는 지침에 넣지 않고 파일에서 찾게 합니다.
