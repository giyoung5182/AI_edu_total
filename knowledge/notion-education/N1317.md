# (강사 시연) 한 줄 요청 vs DSRF 요청 — 업무시간 실태조사 점검

정리일: 2026-10-08 · 교육 에셋 N1317

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 점검을 한 줄로 시킬 때와 DSRF 네 칸으로 시킬 때의 결과 차이를 비교한다.
## 진행 단계
1. **시연 ① 한 줄 요청** — 같은 채팅에서 입력
- 입력할 내용:
```javascript
업무시간실태조사 시트 데이터에 문제 있는지 봐줘.
```
- 볼 것: 점검 내용이 매번 다름 / 빈칸을 0으로 채우거나 이상한 값을 지우고 바로 평균을 내는지 / 응답번호 없이 건수로만 끝나는지
2. **시연 ② DSRF 요청** — 새 채팅에 01 첨부 후 입력
- 입력할 내용: \[상황\]·\[D 데이터\]·\[S 범위\]·［과업］(구조·빈칸·말이 안 되는 값·부서 표기 차이·응답번호 중복 5가지)·［R 결과 형태］(점검 항목 | 발견 내용 | 건수 | 응답번호 | 처리 제안)·［F 조심할 것］(빈칸 0 대체 금지, 이상값은 표시만, 원본 수정 금지) (이하 교안 참고)
- 정상 결과: 5가지 점검이 빠짐없이 나오고, 발견마다 응답번호가 붙고, 빈칸·이상값을 건드리지 않고 표시만 함
3. **기대 결과 확인** — 읽은 행 58행 / 빈칸 회의_시간 3건(R-005, R-022, R-043) / 클레임처리_시간 −1.5(R-009), 반복도점수 7(R-017) / 부서 표기 차이 R-056, R-057 / 응답번호 R-056 2행 중복(내용 달라 삭제하지 않고 확인 필요)
