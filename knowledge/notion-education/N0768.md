## Guide Mode?
[원본 이미지 제외]
**Genspark Guide Mode**는 PPT나 문서를 바로 생성하는 “원샷 AI 생성” 방식과 달리,<br>AI가 **컨설턴트처럼 질문 → 전략 → 구조 → 디자인 → 생성**의 단계로 사용자를 안내하는 **단계형 생성 모드**입니다.
### 언제 어떤 모드를 쓸지 판단 기준
- [ ] 30초 안에 러프한 초안만 필요하면 일반 생성
- [ ] 숫자/근거가 들어가야 하는 의사결정용 자료면 Guide Mode
### 시장 분석 시 Guide mode 플로우
```javascript
Phase 1 Strategy (전략 분석)
↓
Phase 2 Substance (콘텐츠 근거 보강)
↓
Phase 3 Structure (슬라이드 구조 설계)
↓
Phase 4 Surface (디자인 적용)
↓
Phase 5 Build (PPT 생성)
```
