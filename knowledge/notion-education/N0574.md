## 이 실습으로 하는 것
GitHub 계정으로 Vercel에 가입해 두 서비스를 한 번에 연결합니다.
## 진행 단계
1. **접속** — vercel.com 접속 후 우측 상단 **Sign Up**을 클릭합니다.
2. **GitHub로 가입** — **"Continue with GitHub"** 버튼을 클릭합니다 (교안에서 핵심으로 표시).
3. **권한 승인** — GitHub 권한 승인 화면에서 **Authorize**를 클릭합니다.
- 정상 결과: 두 서비스가 자동 연결되어 가입 완료
- 참고: 이메일로 따로 가입하면 나중에 GitHub와 연결하는 단계가 추가로 필요합니다.
