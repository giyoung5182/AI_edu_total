## 이 실습으로 하는 것
오전 작업 폴더를 연결한 새 세션에서 prd.md를 확인한다.
## 진행 단계
1. **새 세션 시작** — Claude 데스크톱 앱 → Code 탭 → 로컬 → 오전에 쓰던 폴더 선택 → 새 세션
- 새 세션인 이유: 대화가 길수록 결과가 나빠지므로 오전 대화와 섞지 않음
2. **prd.md**** 확인** — 파일 탐색기에서 class-tool 폴더 안 prd.md 확인
- 정상 결과: 폴더가 연결되고 class-tool 안에 prd.md가 있음
## 막히는 지점
- prd.md가 안 보이면 다른 폴더(바탕화면, 문서)를 찾아보고, 없으면 STEP 0의 압축 작성으로 대체
