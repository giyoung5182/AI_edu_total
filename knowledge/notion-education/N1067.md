# 실습 1 — 세팅과 첫 실행

정리일: 2026-10-08 · 교육 에셋 N1067

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
구글 시트에서 앱스크립트 편집기를 열어 가장 짧은 코드로 메뉴를 만들고 처음 실행한다.
## 진행 단계
1. **편집기 열기** — 구글 시트 상단 「확장 프로그램」 → 「Apps Script」 클릭, 새 탭에서 편집기가 열린다. 팝업이 안 열리면 주소창 오른쪽 끝 팝업 차단 아이콘을 눌러 허용한다.
2. **코드 붙여넣기** — 기존 내용을 전부 지우고 아래를 붙여넣는다.
- 입력할 내용:
```javascript
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('업무요청')
    .addItem('테스트', '테스트')
    .addToUi();
}

function 테스트() {
  SpreadsheetApp.getUi().alert('연결되었습니다');
}
```
1. **저장·새로고침·실행** — Ctrl+S로 저장, 구글 시트 탭에서 F5 새로고침, 상단에 「업무요청」 메뉴 확인, 업무요청 → 테스트 클릭.
- 정상 결과: 「업무요청」 메뉴가 생기고 알림이 뜬다.
2. **권한 승인** — 「권한 검토」 → 본인 구글 계정 선택 → '확인되지 않은 앱' 화면에서 좌측 하단 「고급」 → 「(프로젝트명)(으)로 이동(안전하지 않음)」 → 「허용」.
- 정상 결과: 직접 만든 스크립트가 구글 검토를 받지 않아 경고가 뜨는 것이며, 본인이 만든 것이면 문제없다. 남이 준 코드는 내용을 확인한다.
## 막히는 지점
- 메뉴가 안 생김: F5 새로고침. 그래도 없으면 편집기 상단 함수 드롭다운에서 onOpen 선택 후 ▶ 실행.
- 저장이 안 됨: Ctrl+S 다시.
- 구문 오류: 전체 삭제 후 처음부터 다시 복사(부분 복사 금지).
- 엑셀 파일은 구글 시트로 변환해야 스크립트가 붙는다.
