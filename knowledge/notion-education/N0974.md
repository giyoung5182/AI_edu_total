```plain text
 앞세우고, 일반 건물관리 실적은 뒤로 모을 것.
 24시간 상주 체계와 장애 대응 시간을 수치로 제시할 것."
```

```plain text
- 배경색: #FFFFFF (기본) / #F4F5F7 (섹션 구분용)
- 주색상: #(회사 CI 표준색 코드)
- 강조색: #(포인트 색 하나만)
- 글꼴: 프리텐다드 또는 본고딕(Noto Sans KR)

- 비율: 16:9 고정
- 레이아웃 규칙:
  · 하단에 빈 공간이 남지 않도록 화면 전체를 채울 것
  · 요소 간 겹침과 잘림이 없도록 배치할 것
  · 실적 수치는 표 또는 그래프로 제시하고 줄글로 나열하지 말 것
- 이미지: 미니멀 벡터 아이콘과 평면 그래픽만 사용
```

색은 세 개까지만 쓰세요. 번거로우면 메인색 하나만 주고 "어울리는 색 2개를 알아서 골라 줘"라고 해도 됩니다.


## 블록 4 · 산출 규칙
여기가 **AI 티를 없애는 블록**입니다.
```plain text
1) 말투
   - 구어체 사용 금지. 개조식으로 작성할 것
   - 예: "당사는 ~~~를 수행하고 있습니다" (X) / "수행 실적: ~~~" (O)

2) 사실 관계
   - 내가 제공하지 않은 실적·수치·현장명·인증명은 절대 추가하지 말 것
   - 자료에 없는데 필요한 항목은 [확인 필요]로 표시할 것
   - 금액 단위가 섞여 있으면 백만원으로 환산한 뒤 합산하고,
     환산 과정을 별도로 보고할 것

3) 구성
   - 한 장에 두 가지 이상의 주제를 섞지 말 것
   - 내용이 넘치면 억지로 넣지 말고 장을 분리할 것
   - 분리했을 경우 어느 부분을 추가·수정했는지 보고할 것

4) 재량
   - 설계도는 가이드이며, 맥락상 필요한 내용은 추가해도 됨
   - 지시대로만 따르지 말고 빠진 부분이 있으면 보완할 것
```

**2번의 마지막 줄이 우리 자료에서 특히 중요합니다.**
용역실적 데이터는 금액 단위가 백만원·억·원으로 섞여 있습니다.
이 지시가 없으면 15.2억이 15.2백만원으로 합산됩니다.

# 설계서를 AI에게 대신 쓰게 하기
```plain text
아래 자료를 읽고, 발표자료 설계서 초안을 작성해 줘.
아직 슬라이드는 만들지 말고 설계서 텍스트만 줘.

설계서는 네 블록으로 구성해 줘.
블록 1 맥락: 개요, 유의사항 3개 이상, 최종 목적, 전체 흐름
블록 2 슬라이드 설계도: 각 장마다 분류 / 헤드메시지 / 내용 설명 / 시각 요소.
       표가 아니라 줄글로 서술해 줘
블록 3 디자인 규격: 색상 코드, 글꼴, 크기, 레이아웃 규칙
블록 4 산출 규칙: 말투, 사실 관계, 구성, 재량

조건
- 슬라이드는 총 8~10장
- 헤드메시지는 주제어가 아니라 결론이 담긴 완성 문장으로
- 자료에 없는 수치는 절대 추가하지 말고 [확인 필요]로 표시
- 금액 단위가 섞여 있으면 백만원으로 환산 후 합산하고 환산 내역을 보고할 것
- 유의사항 항목은 이 자료의 특성을 근거로 직접 판단해서 써 줘

[자료]
```

**AI가 쓴 설계서에서 반드시 사람이 검토해야 하는 세 항목**
1. 유의사항 — AI는 심사자를 모릅니다. 여기는 사람이 채워야 합니다
2. 헤드메시지 — 순서대로 읽어 논리가 이어지는지 확인
3. \[확인 필요\] 표시 — 어디에 구멍이 있는지 파악
