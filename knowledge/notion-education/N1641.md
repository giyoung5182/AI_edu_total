## ✅ 환경 세팅
### 1단계 · VSCode 설치
VSCode 는 코드를 쓰고 보는 에디터이지만, 우리는 주로 **VSCode 안의 터미널** 을 사용합니다.
**내가 할 일**<br>1. [개별 링크 제외] 에서 “Download for Windows” 클릭<br>2. 설치 마법사 → 기본값 그대로 → **“PATH 에 추가” 체크 확인**<br>3. 설치 완료 후 VSCode 실행
**체크포인트**: VSCode 가 켜지면 OK.
---
### 2단계 · Git Bash 설치
윈도우 기본 cmd 는 한글이 깨질 수 있어서 Git Bash 를 사용합니다.
**내가 할 일**<br>1. [개별 링크 제외] 에서 다운로드<br>2. 설치 마법사 → 기본값 그대로 → 완료<br>3. VSCode 를 다시 시작
**확인**: VSCode 에서 **터미널 → 새 터미널** 을 열고 오른쪽 위 드롭다운에서 **“Git Bash”** 가 선택 가능한지 확인.
```plain text
# 새 터미널에서 한 번 쳐봅니다
git --version
```
> **AI 가 보여줄 예상 결과**
```plain text
git version 2.45.0.windows.1
```
**체크포인트**: 버전 번호가 나오면 OK. 안 나오면 손을 들어주세요.
---
### 3단계 · Claude Code 설치
Claude Code 는 npm 패키지로 설치합니다.
**내가 할 일** — Git Bash 터미널에서
```plain text
npm install -g @anthropic-ai/claude-code
```
설치가 끝나면 버전을 확인합니다.
```plain text
claude --version
```
> **AI 가 보여줄 예상 결과**
```plain text
x.x.x (Claude Code)
```
**체크포인트**: 버전 번호가 나오면 OK.
---
### 4단계 · 교육용 계정 로그인
1. **클로드코드 워크스페이스에 입장합니다. (이 부분부터는 당일에 강사님과 함께 하셔도 좋습니다. )**
```plain text
계정활성화 링크(hansol.com 도메인 필수) : [개별 링크 제외]
```
1. **계정 활성화 후에 터미널 환경에서 아래 실행**
```plain text
claude
```
처음 실행 시 브라우저가 열리고 로그인 화면이 나옵니다.
1. 활성화한 계정으로 로그인
2. 브라우저가 “인증 완료” 를 보여주면 터미널로 돌아옵니다
**체크포인트**: 터미널 하단에 `>` 입력 프롬프트가 나타나면 로그인 완료.
---
### 5단계 · 첫 명령 — “잘 작동해?”
이제 첫 한국어 명령을 던져봅니다.
```plain text
잘 작동해?
```
> **AI 가 보여줄 예상 결과** (대략 이런 톤)
네, 잘 작동합니다! 😊 무엇을 도와드릴까요?<br>현재 폴더, 파일 분석, 코드 작성, 데이터 처리 등 다양한 작업을 도와드릴 수 있습니다.
**체크포인트**: 한국어 응답이 돌아오면 **세팅 완료!**

## 🗂 데이터 4계층 분류표
### LV 1 · 외부 공개 데이터 — ✓ 자유 사용
홈페이지·IR·보도자료·공시 데이터, 공개 매뉴얼, 일반 시세(네이버 증권 등).





예시

사용 가능 명령




세방전지 분기 IR 자료

“이 PDF 핵심 요약해줘”




네이버 증권 004490 시세

“5일 추이 가져와서 분석”




공개 안전 매뉴얼

“안전 수칙 10개만 한국어 요약”


### LV 2 · 사내 일반 데이터 — ✓ 사용 가능
생산 로그·라인 코드·일반 품질 지표. 외부 노출돼도 영업 영향이 미미한 수준. **본 교육 실습의 주력 영역.**





예시

사용 가능 명령




일일 생산량·불량률 CSV

“CSV 30개 합쳐서 불량률 2% 초과만 추출”




라인 코드 (L1\~L4)

“라인별 분포 분석해줘”




모델 코드 (EFB/AGM)

“모델별 평균 비교”


### LV 3 · 사내 기밀 데이터 — ⚠️ 마스킹 후 사용
미공개 재무·고객 단가·핵심 공정 파라미터. **고객사명·금액·고유 코드는 마스킹**(고객A, \*\*\* 처리) 후 사용.





예시

사용 전 처리




고객별 단가표

고객사명 → “고객A, 고객B”




미공개 재무 수치

절대 금액 → 비율(%)로 변환




핵심 공정 파라미터

실제 수치 → 범위(“정상값 대비 -5%”)


### LV 4 · 개인정보 — ✗ 절대 금지
사번·연락처·주민번호·인사평가. **개인정보보호법 별도 책임** 발생.





예시

대안




직원 명단

dummy 데이터(`프로님`, `김철수`)로 패턴만 검증 후 본 데이터에 코드만 로컬 실행




인사평가 결과

dummy 점수로 분석 코드 작성 → 본 데이터는 코드를 로컬에서만 실행




사번 포함 출퇴근 로그

사번을 익명 ID 로 치환 후 사용

## 🛡 권장 워크플로우
```plain text
A. 코드 작성·실행 위주
   → LV 1·2 데이터를 풀 활용. AI 는 헤더·결과 요약만 봅니다.

B. 해석·인사이트 명령
   → LV 1·2 만. LV 3 데이터는 마스킹 후 한정 사용.

C. LV 4 (개인정보)
   → dummy 데이터로 패턴 검증 → 본 데이터에는 "코드만 로컬 실행".
   → AI 에 본 데이터 절대 노출 금지.
```

## 🔧 실용 팁
- AI 가 만든 코드는 **로컬 PC 에서 실행됩니다.** 즉, 코드가 우리 PC 의 파일을 읽지만, **AI 서버로 우리가 보내는 것은 우리가 직접 입력하거나 AI 가 명시적으로 읽기로 한 텍스트뿐** 입니다.
- 의심스러우면 `-dry-run` 또는 “실행 전에 무엇을 할지 먼저 알려줘” 한 줄을 추가하세요. AI 가 단계 분해를 먼저 보여줍니다.
- AI 가 “이 파일 읽어도 될까요?” 하고 묻는 단계 (Edit/Read 권한 확인) 가 있습니다. 매번 한 번씩 눈으로 확인하는 습관을 만들어 두세요.
