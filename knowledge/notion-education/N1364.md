# AGENT 01 · 청년사업 안내 담당 사용 예시

정리일: 2026-10-08 · 교육 에셋 N1364

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
형식이 다른 정책문서 여러 건을 등록한 에이전트에게 안내자료를 만들게 하고, 숫자의 근거를 점검합니다. (강의 STEP 01\~14 시연분)
## 진행 단계
1. **모집 중인 사업 비교표 요청**
- 입력할 내용:
```javascript
지금 모집 중인 사업만 뽑아서 신청 자격·기간·지원내용 비교표로 정리해줘.
수신자는 청년, 기준 시점은 오늘, 모집 중인 것만.
```
1. **숫자의 근거 위치 점검**
- 입력할 내용:
```javascript
방금 만든 표에서 날짜·금액·자격요건을 전부 뽑아서,
각각 어느 공고문의 어느 항목에서 나온 것인지 표로 알려줘.
근거를 찾을 수 없는 항목은 [근거 없음]으로 표시해줘.
```
1. **다른 사업으로 같은 형식 반복**
- 입력할 내용:
```javascript
이번에는 [마을기업] 사업으로 같은 형식의 안내자료 만들어줘
```
## 막히는 지점
- 상위 계획과 하위 공고를 함께 등록해야 교차 참조가 성립(하위 공고만 등록하면 일반 요약 수준)
- 기본계획은 청년을 19\~34세로 정의하나 청년마을 공모계획은 활동지역 시·군·구 조례를 우선 준용하므로, `[문서 간 대조 규칙]` 5번이 단일 숫자 확정을 차단
