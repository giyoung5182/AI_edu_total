## 2. 🔥 실습 7 — 화면용 데이터 만들기 (10분) ★
**대시보드는 원본 59행을 그대로 읽지 않습니다.** 미리 집계한 결과를 읽습니다.
---
### 요청하기
```javascript
같은 스크립트에 함수를 추가해줘.

[할 일]
"화면데이터" 시트를 만들고 아래 형태로 집계 결과를 쓴다.

구분 | 항목 | 값
지표 | 전체건수 | 58
지표 | 완료 | 40
지표 | 진행중 | 12
지표 | 지연 | 3
차트1 | 완료 | 40
차트1 | 진행중 | 12
차트1 | 보류 | 6
차트2 | 영업 | 12
차트2 | 생산 | 11
표 | REQ-2026-017 | 생산/측정기 렌탈 계약 연장/12

[조건]
- 이 시트는 대시보드가 읽을 용도이므로
  숫자에 쉼표나 단위를 넣지 말고 순수한 숫자만 쓴다
- 실행할 때마다 전체를 지우고 다시 쓴다
- 맨 아래에 갱신일시를 기록한다

메뉴에 「화면데이터 갱신」 항목을 추가해줘.
```
---
### 집계를 왜 미리 하나 ★





방식

문제




화면이 원본 59행을 직접 계산

느리고, **계산 로직이 화면에 흔어짐**




시트에서 집계하고 화면은 표시만

빠르고 **수정할 곳이 한 군데**



**집계는 시트에서, 표시는 화면에서.**
나중에 지표를 바꿀 때 ***스크립트만 고치면*** 됩니다.

---

**주소가 이렇게 생겼으면 성공입니다.**


## 3. 🔥 실습 8 — 대시보드 제작 (20분) ★
### 요청하기
**ChatGPT에 아래를 넣습니다.** 대괄호 안을 본인 상황에 맞게 바꿉니다.
```javascript
아래 조건으로 단일 HTML 파일 대시보드를 만들어라.

[데이터 출처]
Google Sheets CSV 게시 URL:
[여기에 주소 붙여넣기]

CSV 구조
구분 | 항목 | 값
구분이 "지표"인 행은 요약 카드
"차트1"은 상태별 도넛 차트
"차트2"는 부서별 가로 막대
"표"는 지연 건 목록 (값은 부서/제목/경과일을 슬래시로 구분)

[만들 화면]
상단: 요약 카드 4개 (전체건수 / 완료 / 진행중 / 지연)
       지연은 1건 이상이면 주황색으로 강조
중단: 좌측 상태별 도넛 차트 / 우측 부서별 가로 막대
하단: 지연 건 표 (경과일 내림차순, 7일 이상은 붉게)

[기술 조건]
- HTML 파일 하나로 완결 (CSS, JS 포함)
- CSV를 fetch로 읽어 화면을 그릴 것
- 로딩 중 표시와 오류 처리 포함
- 한글이 깨지지 않게 UTF-8 명시
- 새로고침하면 최신 데이터가 반영될 것
- 차트 라이브러리는 CDN으로 불러오되
  로드 실패 시 표로 대체 표시할 것
- 화면 상단에 마지막 갱신일시 표시

[디자인]
- 흰 배경, 군더더기 없는 업무용
- 숫자가 크고 잘 보일 것
- 노트북 화면 기준 (1280px)
```

```javascript

② 받은 HTML 코드를 붙여넣기
③ Code.gs에 아래 함수 추가

function doGet() {
  return HtmlService.createHtmlOutputFromFile('dashboard')
    .setTitle('업무요청 현황');

④ 상단 「배포」 → 「새 배포」
⑤ 유형: 웹 앱
⑥ 액세스 권한: 링크가 있는 모든 사용자
   (또는 내 조직 내 사용자)
⑦ 배포 → URL 복사
```

## 6. 📌 핵심 정리
**① 집계는 시트에서, 표시는 화면에서**
지표를 바꿀 때 한 군데만 고치면 됩니다.

**③ 링크 하나면 공유가 끝난다**
시트 권한을 주지 않아도 됩니다.
**④ 한 번에 완성되지 않는다**
오류 메시지를 그대로 전달해 하나씩 고칩니다.
