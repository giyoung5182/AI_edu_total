**세션 목표:** Genspark 또는 ChatGPT GPTs를 활용해 **내 AI 솔루션 1차 버전**을 실제로 만들고 테스트합니다. (각자 자기 것을 만들고, 막히면 팀원끼리 먼저 도와줍니다. 여기서 나온 결과가 발표의 ③ 결과가 됩니다.)
**🧩 오늘 만드는 '에이전트'가 뭔가요? (쉽게)**
거창한 게 아닙니다. **세션 1에서 만든 좋은 프롬프트(5요소)를 한 번 저장해두고, 다음부터는 데이터만 넣으면 알아서 돌아가게 만든 것**이 에이전트입니다. 매번 프롬프트를 새로 쓰지 않아도 되는, 나만의 자동 도우미라고 생각하세요.
- **"에이전트/GPTs" = 저장해 둔 나만의 AI 도우미**
- **"지침 / 시스템 프롬프트" = 그 도우미에게 미리 심어두는 규칙(=5요소)**
- **"MVP(1차 버전)" = 완벽하진 않아도 지금 바로 써볼 수 있는 가장 작은 버전**

### 🔥 활동 1 — 내 에이전트 만들기 (Genspark 또는 ChatGPT GPTs)

**도구는 편한 것으로.** 둘 다 "지침(시스템 프롬프트)을 넣어 나만의 에이전트를 만든다"는 원리는 동일합니다. ChatGPT Plus/Team이 있으면 GPTs를, 로그인 없이 무료로 시작하려면 Genspark를 추천합니다.


**세션 1의 5요소가 여기서 완성됩니다.** 지침(시스템 프롬프트)은 5요소를 저장해 둔 것 — 역할=①, 입력 데이터=②맥락, 처리 방법=③지시, 출력 형식=④, 규칙=⑤제약. 5요소를 한 번 잘 짜서 에이전트에 심어두는 것이 오늘의 목표.

[원본 이미지 제외]
**옵션 A. Genspark 커스텀 에이전트 (Custom Agent)** — 무료로도 시작 가능
**① 만들기**
1. genspark.ai 접속 → 로그인.
2. 커스텀 에이전트 만드는 화면으로 들어갑니다. 진입 경로는 여러 가지 — 홈의 **"Custom Agent"**, 좌측 사이드바 **"+ New"**, 또는 **Custom Agent Store**(커스텀 에이전트 스토어). 스토어 화면 **우측 상단 "Create New"** 버튼을 누르면 시작됩니다.
3. **한 문장으로 설명하면 지침이 자동으로 만들어집니다.** Genspark는 빈칸을 처음부터 채우는 방식이 아니라, 원하는 바를 말로 설명하면 **지침(Instructions)을 자동 작성**해줍니다. 구조: `[역할] + [핵심 기능] + [출력 형식]` (예: "품질 불량 데이터를 넣으면 이슈를 요약·분류하고 우선 조치 항목을 표로 뽑아주는 품질 분석 어시스턴트를 만들어줘.")
4. 자동 생성된 지침을 확인하고, 이어서 대화로 다듬습니다(예: "출력에 긴급도 열을 추가해줘"). 더 정교하게는 아래 **지침 프롬프트 구조**를 참고.
5. **미리보기(Preview)**에 샘플 데이터 1\~2건을 넣어 확인하고 **"Update"**로 저장합니다.
**② 수정/편집 (나중에 다시 고치기)**
1. **Custom Agent Store**에서 내가 만든 에이전트 카드를 찾습니다.
2. 카드의 **점 3개(⋯) 메뉴 → "Configure"**(구성)를 엽니다.
3. 지침을 대화로 바꾸거나(예: "납기 이슈도 분류 대상에 넣어줘") 직접 수정한 뒤 **"Update"**로 저장. 매번 **미리보기(Preview)**로 확인하며 반복 개선.
4. 삭제도 같은 ⋯ 메뉴에 있지만 **복구가 안 되므로**, 실습에선 삭제보다 Configure로 고치는 연습을 권합니다.
**공유·비용:** ⋯ 메뉴의 **"Share"**에서 공개 범위(나만 / 링크 가진 누구나 / 스토어 공개)를 고릅니다. 무료 플랜으로도 만들 수 있고, 실행 시 크레딧을 소모합니다.

**막히면** — 버튼 이름은 자주 바뀝니다. "만들기"=**Create New**, "고치기"=카드 **⋯ → Configure**, "저장"=**Update**처럼 기능(동사)으로 찾으면 헤매지 않습니다. "+ New"가 안 보이면 "Custom Agent"/"Build"를 찾아보세요.

**옵션 B. ChatGPT GPTs (맞춤형 GPT)** — 만들기·편집은 유료(Plus 이상), 써보기만 하면 무료도 가능
**① 만들기**
1. chatgpt.com 접속 → 로그인. **만들기·편집은 유료 플랜(Plus/Business 등) 필요**(써보기만 하는 건 무료도 로그인하면 가능).
2. **"GPT 탐색(Explore GPTs)"** → 우측 상단 **"만들기(Create)"** → GPT 편집기.
3. 방식은 두 가지 — **대화로 만들기**(말로 설명하면 자동 초안) / **직접 설정하기**(**Configure** 화면). 대화로 뼈대 → 설정 화면에서 다듬기 권장.
4. **Configure** 주요 항목: **이름·설명**, **지침(Instructions)**(=시스템 프롬프트, 아래 구조 사용), **대화 스타터(Conversation starters)**, **지식(Knowledge)**(참고 문서 파일 업로드), **기능(Capabilities)**(웹 검색·이미지·코드 인터프리터 등). **액션(Actions)**은 고급 기능이라 오늘은 생략.
5. 우측 **미리보기(Preview)**로 테스트 → 우측 상단 **"만들기(Create)"** → 공개 범위(나만 / 링크 / 조직 / 스토어) 선택 저장.
**② 수정/편집 (나중에 다시 고치기)**
1. **"GPT 탐색(Explore GPTs)" → "내 GPT(My GPTs)"**로 이동.
2. 수정할 GPT를 골라 **"GPT 편집(Edit GPT)"**을 엽니다(대화 중이라면 상단 이름 메뉴에서 바로 Edit GPT).
3. 고친 뒤 **반드시 우측 상단 "업데이트(Update)"**를 눌러야 반영됩니다(안 누르면 초안 상태 — 가장 자주 막히는 지점).
4. 편집기 우측 상단 **더보기(•••) → 버전 기록(version history)**로 되돌리기, **공유(Share)**로 공개 범위 변경.

**막히면** — "만들기"가 안 보이면 무료 플랜일 가능성(GPTs 제작은 Plus 이상 전용) → Genspark(옵션 A)로 진행. 편집했는데 결과가 안 바뀌면 **Update를 눌렀는지**부터 확인.


**두 도구 공통 4단계** — ① **지침(Instructions)**에 5요소로 역할·규칙을 적는다 → ② **미리보기**로 테스트 → ③ **저장/업데이트** → ④ **공유 범위** 설정. 지침이 곧 세션 1의 5요소이므로, **수정한다는 건 결국 "5요소 중 어느 칸을 고칠지" 고르는 일**입니다.

```plain text
당신은 [직무] 전문가 AI 어시스턴트입니다.
역할: [내 솔루션 목적] 전문 분석가
입력 받을 데이터: [형식 / 주요 컬럼]
처리 방법:
1. 입력 데이터에서 [이상 항목 / 핵심 이슈]를 찾아냅니다
2. [유형 분류 기준]에 따라 분류합니다
3. 각 항목의 [우선순위/위험도]를 판단합니다
출력 형식: 분석 요약 / TOP 3 우선 처리 항목(표) / 전체 분류 결과(표) / 다음 단계 액션 아이템
규칙: 입력 데이터에 없는 정보는 절대 만들지 않는다. 불확실한 항목은 "확인 필요"로 표시한다.
```

### 🔥 활동 2 — 1차 테스트 & 오류 수정
- [ ] 정상 데이터 10행 입력 → 예상 결과와 일치하는가?
- [ ] 이상 케이스 포함 데이터 → 이상값을 잘 탐지하는가?
- [ ] 출력 형식이 요청한 대로 나오는가?
- [ ] 데이터에 없는 내용을 만들어내지 않는가? (환각 체크)
**오류가 나오면 이 프롬프트로 수정 요청:**
```plain text
방금 테스트에서 다음 문제가 나왔습니다:
[문제 내용: 예) "안전 이슈인데 납기 이슈로 분류됨"]
이 문제를 수정해서 다시 분석해줘.
수정할 부분: 1. [예: 안전 키워드 탐지 기준 추가] 2. [예: 분류 우선순위 규칙 추가]
다음에 이런 케이스가 들어오면 어떻게 처리할지도 알려줘.
```

**Padlet에 올리기** (`세션6 · 내 에이전트`) — 완성한 에이전트의 이름·한 줄 설명과 샘플 결과 캡처를 올려주세요. 다른 사람 에이전트를 구경하는 것이 세션 7 고도화 아이디어의 원천이 됩니다.

### 📌 세션 6 핵심 정리
① 좋은 프롬프트 = 역할 정의 + 처리 방법 + 출력 형식 + 환각 방지 규칙.
② 테스트는 "정상 케이스"와 "이상 케이스"를 모두 포함해야 실전에서 쓸 수 있다.
③ 오류가 나면 오류 메시지를 그대로 AI에게 보여주면 대부분 스스로 수정한다.
