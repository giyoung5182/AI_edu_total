# ③ 글자 입력과 배치 (Step 1~5)

정리일: 2026-10-08 · 교육 에셋 N0623

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
엑셀에 확정한 문구를 캔바 텍스트 상자로 입력해 74 × 34mm 사각형 안에 위계와 정렬을 맞춰 배치합니다.
## 진행 단계
1. **내용 확인** — 엑셀 `명함 설계·검수` 시트 `C8:C15`에서 앞면에 넣을 내용을 확인합니다(한 줄 소개는 `C9`). 선택하지 않은 QR과 뒷면 내용(`C16:C19`)은 넣지 않습니다.
2. **문구 복사** — 캔바에서는 정보를 새로 만들지 않고 엑셀에 확정한 문구만 복사해 사용합니다.
3. **텍스트 상자 추가** — 좌측 텍스트 → 텍스트 상자 추가 → 항목별 글자를 붙여넣기 → 상단 바 숫자로 크기 조절 → 74 × 34 사각형 안으로 드래그. 항목마다 따로 반복합니다.
- 입력 순서: 가장 크게 넣을 것 → 한 줄 소개 → 이름·직함 → 전화번호 → 연락 수단 1개 → QR코드 자리(4권)
4. **정렬** — 글자 상자들을 함께 선택 → 위치 → 정렬 탭 → 왼쪽 또는 가운데 정렬. 한 명함에서는 한 가지 정렬만 씁니다.
5. **기록** — `B24`에 색 조합, `B25`에 서체를 적고, `B26`의 앞면 유형과 함께 가장 크게 보일 항목을 확인합니다.
- 정상 결과: 모든 글자가 사각형 안에 있고 배경이 화면 끝까지 채워집니다.
## 막히는 지점
- 글자가 사각형 선에 닿으면 안으로 더 들여 놓습니다.
- 1단(가장 큰 글자)은 하나만 둡니다.
