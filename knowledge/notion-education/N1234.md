# 6. 배포하기 — 첫 배포와 재배포

정리일: 2026-10-08 · 교육 에셋 N1234

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Claude Code에 한 줄 요청으로 프로젝트를 GitHub에 올리고 Vercel로 배포합니다.
## 진행 단계
1. **첫 배포**
- 입력할 내용:
```javascript
이 프로젝트를 깃허브에 푸시하고 버셀로 배포해줘. 깃허브 푸시할땐 '프라이빗'으로 해줘.
```
- 프라이빗으로 푸시하는 이유: 코드 내 민감정보 유출을 막기 위함
2. **재배포** — 파일 수정 후 다시 올릴 때
- 입력할 내용:
```javascript
수정한 거 깃허브 푸시하고 버셀로 재배포해줘
```
3. **.gitignore 확인** — 올리면 안 되는 파일(.env, node_modules/, Thumbs.db, desktop.ini, \*.log, dist/, build/ 등) 제외 목록
- 입력할 내용:
```javascript
이 폴더에 .gitignore 파일 만들어줘.
API 키·비밀번호·node_modules·윈도우 시스템 파일(Thumbs.db, desktop.ini) 등의 민감정보가 깃허브에 안 올라가게 해줘.
```
## 막히는 지점
- 배포는 됐는데 사이트가 빈 화면 → `index.html`이 루트(최상위) 폴더에 없음
- 명령어 입력 폴더 위치 혼동 → `index.html`이 보이는 폴더에서 `ls`로 확인
