# 4-4. Gemini 실습 (15분) · 접속·이미지 질문·AI Mode

정리일: 2026-10-08 · 교육 에셋 N1155

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
Gemini에 접속해 같은 질문을 ChatGPT와 비교하고, 사진으로 질문하는 방식과 구글 검색 AI Mode를 체험합니다.
## 진행 단계
1. **접속 + 기본 대화 (5분)** — gemini.google.com 또는 스마트폰 Gemini 앱
- 입력할 내용: "나는 AI 강사야. 60\~70대 수강생에게 AI란 무엇인지 설명하는 가장 쉬운 방법을 알려줘"
- 정상 결과: ChatGPT 결과와 어조·깊이·예시가 어떻게 다른지 비교
2. **이미지로 질문하기 (5분)** — 주변 물건 사진을 찍어 올리고 "이게 뭔지 설명해줘", 또는 강의 슬라이드 사진을 찍어 "이 내용을 한 줄로 요약해줘"
3. **구글 검색 AI Mode 체험 (5분)** — 구글 검색에서 "AI 교육 트렌드 2026" 입력 후 결과 위 AI 요약 확인
- 정상 결과: 기존 구글 검색과 어떻게 다른지, 출처가 표시되는지 확인
## 막히는 지점
- 교안에 별도로 적힌 막히는 지점 없음
