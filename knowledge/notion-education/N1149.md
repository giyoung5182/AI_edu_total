# 4. 실습 — 폴더를 세 사람이 동시에 살펴보기

정리일: 2026-10-08 · 교육 에셋 N1149

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
한 폴더를 구조 담당·중복 담당·위험 담당 세 관점으로 나눠 서브에이전트에게 맡기고, 결과를 종합합니다.
## 진행 단계
1. **폴더 선택** — 새 세션을 열고 sw-practice 폴더를 선택합니다.
2. **세 관점 프롬프트 입력**
- 입력할 내용:
```plain text
이 폴더를 세 가지 관점에서 각각 따로 살펴봐줘.
서브에이전트를 활용해서 나눠서 진행해줘.

1) 구조 담당 — 어떤 폴더 구조로 나누면 좋을지 제안(기준 두세 가지, 장단점)
2) 중복 담당 — 같은 내용인데 이름만 다른 파일, 버전이 여러 개인 파일을 찾고 남길 것·지울 것 제안
3) 위험 담당 — 이 폴더에 있으면 안 될 것 같은 파일을 찾고 왜 그렇게 판단했는지 설명

세 가지 결과를 각각 보여준 다음, 마지막에 종합해서 정리 계획을 제안해줘.
아직 파일은 옮기지 마.
```
1. **결과 확인** — 마지막 줄(파일을 옷기지 말 것)이 1교시에서 배운 "하지 말아야 할 것"입니다.
2. **이어서 요청** — 종합 계획이 마음에 들면 위험 담당이 짚은 파일은 옮기지 않고 '따로_확인.md'에 목록만 적도록 요청합니다. 자동으로 지우게 하지 마세요.
## 막히는 지점
- 세 개로 안 나뉘고 한 번에 답하면 "결과를 세 관점으로 정리해 준 것"으로 설명하고 넘어갑니다(강사 메모).
