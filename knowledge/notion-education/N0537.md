# (향후 과제) 경영진 · 고객사 · 실무자 3종

정리일: 2026-10-08 · 교육 에셋 N0537

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
실습 2 보고서의 같은 사실을 경영진(결정 요청) · 고객사(회신 초안) · 실무자(재확인 체크리스트) 3종으로 내보냅니다. 수치·판정 상태는 그대로 두고 순서·범위만 바꿉니다.
## 진행 단계
1. **예측** — Part4 시트 \[E\] 예측 칸에 고객사 버전에서 빠질 근거ID 나열
2. **고객사 공유 기준 3줄 작성** — E-1: 알릴 수 있는 사실 / 알리면 안 되는 사실 / 원인 미확인일 때 쓰는 표현
3. **독자별 3종 요청** — 사이드바 최근 목록 → 채팅 P4-보고서 → 프롬프트 붙여넣기 → `(① 기준 3줄 붙여넣기)` 줄에 E-1 3행 복사해 붙여넣기 → Enter
- 입력할 내용: "같은 근거표로 독자별 문서 3종을 만들어 줘. 수치·단위·n/분모·판정 상태…\[확인 필요\] 표시는 세 문서 모두 근거표와 같아야 한다." (이하 교안 참고)
- 대화가 끊겼으면 새 채팅 → D1P4_근거표_v1.md 첨부 → "같은 근거표로"를 "첨부한 근거표로"로 바꿔 전송
4. **근거ID 사용표 점검** — E-2 표 행마다 경영진·고객사·실무자 칸 O/X
- 정상 결과: 고객사용에 내부 정산 수치·성명 없음
## 막히는 지점
- 경영진용을 줄여 돌려쓰면 고객사 회신에 내부 정산 수치가 들어가거나 원인이 단정되고, 실무자에게 필요한 정산번호·접수번호가 빠짐
