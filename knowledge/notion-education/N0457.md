# 실습 1. 브라우저로 API 맛보기

정리일: 2026-10-08 · 교육 에셋 N0457

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프로그램 없이 브라우저 주소창만으로 API를 호출해 보고, 돌아온 JSON에서 경로를 따라 값을 찾습니다.
## 진행 단계
1. **날씨 API 호출** — 브라우저 새 탭의 주소창에 아래를 붙여넣고 엽니다.
- 입력할 내용:
```javascript
[개별 링크 제외]
```
2. **현재 기온 찾기** — 화면에 뜬 JSON에서 경로를 따라가 현재 기온을 찾습니다. 지금 판교의 실제 기온입니다.
3. **좌표 바꿔 다시 열기** — latitude, longitude 값을 다른 도시 좌표로 바꿔 다시 엽니다. (예: 제주 33.50, 126.53)
4. **두 번째 주문** — 새 탭에 붙여넣습니다.
- 입력할 내용:
```javascript
[개별 링크 제외]
```
5. **trade_price 찾기** — JSON에서 trade_price를 찾습니다. 지금 이 순간 비트코인의 원화 가격입니다.
6. **옆자리와 비교** — 몇 초 차이로 열었을 뿐인데 숫자가 다를 수 있습니다. 살아 있는 데이터라는 뜻입니다.
## 막히는 지점
- 글자가 한 줄로 빽빽하게 나옵니다 — 정상입니다. JSON 원문 그대로입니다.
- 페이지가 안 열립니다 — 주소를 복사하다 일부가 잘렸을 가능성이 큽니다. 한 줄 전체를 다시 복사해 붙입니다.
