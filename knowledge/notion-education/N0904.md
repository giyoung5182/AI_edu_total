# 1. 데이터 전처리 자동화: 가능 범위와 한계 먼저 알기

정리일: 2026-10-08 · 교육 에셋 N0904

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 실습 시작 전 준비
실습을 시작하기 전에 다음 사항을 직접 확인합니다.
- `copilot.microsoft.com`에 접속하여 로그인합니다. 계정이 없거나 접속이 안 된다면 즉시 강사에게 알립니다.
- 메모장, Word, 또는 브라우저 새 탭을 열어 프롬프트를 복사·붙여넣기할 준비를 합니다.
- Excel을 열어 새 빈 시트를 하나 준비합니다.
> ⚠️ **보안 주의**: 사내 기밀 데이터나 고객 개인정보는 외부 AI 서비스에 입력하지 않습니다. 실습에서는 반드시 이 교안에 있는 샘플 데이터를 사용합니다.
---

## 학습 목표
이 모듈을 마치면 다음 세 가지를 할 수 있게 됩니다.
1. Copilot으로 처리 가능한 데이터 자동화의 범위를 명확히 구분하고, 업무 상황에 따라 적합한 도구와 방식을 선택할 수 있습니다.
2. 무료·유료 버전별로 기능 차이가 무엇인지 이해하고, 자신의 조직 환경에 맞는 워크플로우를 설계할 수 있습니다.
3. 파일 첨부 없이 텍스트를 복사·붙여넣기하는 방식만으로도 데이터를 구조화된 표로 정리하는 실습을 직접 수행할 수 있습니다.

## 1-1. 데이터 전처리 자동화 수요 1위 케이스
많은 실무자들이 데이터 정리 작업에 상당한 시간을 소비하고 있습니다. 실제 현장에서 가장 빈번하게 요청되는 데이터 전처리 작업 유형을 살펴보면 크게 네 가지로 나눌 수 있습니다.
**1위 — 흩어진 텍스트를 표로 정리하는 작업<br>**이메일, 메모, 채팅 내역, 보고서 텍스트 등 여러 곳에 분산된 정보를 하나의 일관된 표 형태로 만드는 작업이 가장 많은 시간을 차지합니다. 기존에는 수작업으로 30분에서 1시간이 걸리던 작업이 Copilot을 활용하면 2\~3분 안에 초안이 만들어집니다.
**2위 — 중복·누락 데이터 검수** <br>수백 개의 행이 있는 데이터에서 중복된 항목이나 빠진 값을 찾아내는 작업은 사람이 직접 하면 눈이 피로하고 오류가 생기기 쉽습니다. Copilot에게 체크리스트 생성을 요청하면 어떤 항목에 문제가 있는지 빠르게 파악할 수 있습니다.
**3위 — 여러 문서를 항목별로 통합<br>**여러 팀원이 각자 작성한 보고서나 의견서를 하나의 통합 표로 만드는 작업은 기존에 반나절 이상 걸렸지만, Copilot에게 프롬프트 한 번으로 통합 요청을 하면 즉시 초안이 나옵니다.
**4위 — 보고용 요약 수치 추출<br>**긴 텍스트 안에 흩어져 있는 숫자와 핵심 지표를 골라내서 보고용으로 정리하는 작업도 Copilot이 빠르게 처리할 수 있습니다.

## 1-2. Copilot 무료/유료 버전별 기능 차이
Copilot은 하나의 이름으로 불리지만, 실제로는 접속 방법과 라이선스에 따라 사용할 수 있는 기능이 크게 다릅니다. 이 차이를 정확히 이해하지 못하면 "Copilot이 안 된다"는 오해가 생기거나, 필요한 기능을 찾지 못하는 상황이 발생합니다. 따라서 어떤 버전을 어떤 상황에서 쓸 수 있는지를 명확히 알아두는 것이 중요합니다.
- **Copilot 무료 버전 (웹)<br>**`copilot.microsoft.com`에서 Microsoft 계정으로 로그인하면 누구나 무료로 사용할 수 있습니다. 텍스트를 붙여넣어 정리하거나, 글을 요약하거나, 질문에 답하는 등 기본적인 대화형 작업은 무료 버전에서도 충분히 가능합니다. 단, 파일을 직접 업로드하여 내용을 분석하거나, Excel 파일 안에서 Copilot 버튼을 사용하는 기능은 지원되지 않습니다.
- **Copilot Pro<br>**개인이 월 약 \$20(한화 약 3만 원 수준)을 내고 구독하는 유료 버전입니다. 개인 Microsoft 365 앱과 연동되어, Word나 PowerPoint, Excel 등의 앱 안에서 Copilot 기능을 직접 사용할 수 있습니다. 파일 업로드 후 분석도 가능합니다.
- **M365 Copilot<br>**기업 단위로 구매하는 라이선스로, IT 관리자가 조직 테넌트에 활성화해야 합니다. 조직 내 SharePoint, Teams, Outlook 등과 깊게 연동되며, 회사 내부 데이터를 Copilot이 참조하여 답변을 생성할 수 있습니다. 대용량 파일 처리나 조직 전체 데이터 연동이 필요한 기업 환경에 적합합니다.

## 1-3. 가능한 것 vs 불가능한 것 — 경계 이해와 대안 워크플로우
Copilot을 처음 사용하는 사람들이 가장 많이 겪는 혼란 중 하나는 "이 작업이 되는 건지 안 되는 건지"를 모른다는 것입니다. 잘못된 기대를 갖고 시도하면 실망으로 이어지고, 반대로 "어차피 안 되겠지"라는 오해로 활용을 포기하는 경우도 있습니다. 따라서 명확한 경계를 이해하는 것이 실무 활용의 첫걸음입니다.
**Copilot으로 가능한 작업**을 살펴보면 다음과 같습니다. 채팅 창에 텍스트를 붙여넣고 표로 변환하도록 요청하는 것은 가장 기본적인 기능으로, 무료 버전에서도 즉시 사용할 수 있습니다. 특정 조건으로 데이터를 필터링하거나 정렬하도록 요청하는 것도 가능합니다. 또한 Excel 수식에 오류가 발생했을 때 원인을 설명하고 수정 방향을 제안하는 것도 Copilot이 잘 처리하는 영역입니다. VLOOKUP, SUMIF, COUNTIF 같이 자주 쓰이는 함수 작성을 요청하면 상황에 맞게 수식을 생성해 줍니다.
**Copilot으로 불가능하거나 한계가 있는 작업**도 분명히 존재합니다. 실시간으로 외부 시스템(예: 회사 ERP, 영업 CRM)에 접속하여 데이터를 자동으로 가져오는 것은 불가능합니다. 수만 행에 달하는 대용량 Excel 파일을 직접 처리하는 것도 무료 버전에서는 지원되지 않으며, Pro 버전에서도 크기 제한이 있습니다. 사내 네트워크 안에서만 접근 가능한 시스템에 직접 연결하는 것도 특별한 설정 없이는 불가능합니다.
파일을 직접 업로드할 수 없는 상황에서는 아래 **대안 워크플로우**를 사용합니다.

대안 워크플로우
1. 파일에서 정리가 필요한 데이터 일부를 드래그하여 복사합니다.
2. Copilot 채팅 창에 붙여넣고, 원하는 작업을 프롬프트로 설명합니다.
3. Copilot이 생성한 결과물을 복사합니다.
4. Excel이나 Word 등 원하는 도구에 붙여넣어 활용합니다.
5. 필요하다면 Excel 수식이나 기능을 추가로 적용하여 확장합니다.

### 🖥️ 실습 2 — 가능/불가능 경계 케이스 직접 테스트
방금 배운 가능/불가능 경계를 머리로 이해하는 것과 직접 경험하는 것은 다릅니다. 아래 세 가지 케이스를 순서대로 Copilot에 입력하고 결과를 비교해봅니다.
**케이스 A — 가능한 요청 (텍스트 기반)**

**케이스 B — 한계가 있는 요청 (로컬 파일 접근 시도)**

```plain text

```
→ **예상 결과**: 로컬 파일에 직접 접근할 수 없다고 안내하며, 텍스트로 복사하여 붙여넣도록 유도합니다.
**케이스 C — 불가능한 요청 (실시간 데이터 연동)**
아래 내용을 그대로 복사하여 Copilot에 입력합니다.
```plain text
현재 코스피 지수를 가져와서 우리 팀 포트폴리오 수익률과 비교해줘.
```
→ **예상 결과**: 실시간 외부 데이터 연동은 불가능하며, 검색이 지원되는 경우 최근 지수를 웹에서 찾아 안내하거나 불가능함을 명시합니다.
세 케이스를 모두 테스트한 후 다음 두 가지를 생각해봅니다.
- 케이스 B처럼 파일 접근이 안 될 때, 대안 워크플로우를 적용하면 어떻게 같은 작업을 할 수 있을까요?
- 내 업무에서 Copilot으로 즉시 처리할 수 있는 작업과 불가능한 작업을 각각 하나씩 떠올려봅니다.

## 1-4. 텍스트 기반 데이터 정리 — 파일 없이 처리하는 방법
파일 업로드 없이 텍스트 복사·붙여넣기만으로 Copilot을 활용하는 핵심 프롬프트 패턴을 배웁니다. 프롬프트란 Copilot에게 전달하는 지시문으로, 어떻게 작성하느냐에 따라 결과물의 품질이 크게 달라집니다.
**좋은 프롬프트의 3가지 구성 요소**는 다음과 같습니다. 첫째는 **무엇을 해달라는지**(지시), 둘째는 **어떤 형태로 출력해달라는지**(형식), 셋째는 **예외 상황을 어떻게 처리할지**(규칙)입니다. 이 세 가지가 명확할수록 Copilot은 의도에 맞는 결과를 한 번에 출력해 줍니다.
아래는 텍스트 기반 표 변환에 사용하는 기본 프롬프트 패턴입니다.
```plain text
아래 텍스트 데이터를 표로 정리해줘.
컬럼: [항목명1], [항목명2], [항목명3]
누락값은 "미확인"으로 표시하고,
중복 항목이 있으면 별도로 표시해줘.

[여기에 데이터를 붙여넣기]
```
구분자가 일정하지 않고 형식이 뒤섞여 있는 텍스트도 Copilot은 패턴을 파악하여 표로 변환해 줍니다. 다만 데이터가 지나치게 복잡하거나 모호한 경우에는 결과가 의도와 다를 수 있으므로, 항상 결과를 검토하고 필요한 부분을 수정하는 습관을 가져야 합니다.

### 🖥️ 실습 3 — 비정형 텍스트 데이터를 표로 변환하기
아래 샘플 데이터 중 본인의 업무와 가장 가까운 것을 하나 선택하여 실습합니다.

**\[나만의 샘플 데이터 만드는 방법\]**
위 샘플이 본인 업무와 거리감이 느껴진다면 아래 두 가지 방법으로 직접 만들 수 있습니다. 단, 실제 고객명·계약 내용 등 기밀 정보는 절대 입력하지 않고 반드시 가상의 내용으로 대체합니다.
**방법 1 — 기존 메모를 가상 데이터로 치환하기**
실제 업무 메모의 구조(형식·항목)는 그대로 유지하되, 아래와 같이 실제 정보만 치환합니다.
```plain text
고객·의뢰인 이름 → 프로님, 김철수 등 가상 이름
날짜           → 임의 날짜 (예: 3월 1일, 3/5 등)
금액           → 임의 숫자 (예: 500만원, 1,200만원)
회사명         → A사, B법인 등 익명 처리
```
**방법 2 — Copilot에게 샘플 생성 요청하기**
아래 프롬프트에서 `[업무 유형]` 자리에 본인의 업무(예: 법무 자문 의뢰 접수, 영업 고객 상담 이력, 인사 면접 일정 관리)를 입력합니다.
```plain text
나는 [업무 유형]을 담당하고 있어.
실무에서 자주 발생하는 비정형 메모 형태의 샘플 데이터를 만들어줘.
조건:
- 7~10개 항목
- 날짜 표기 방식이 3가지 이상 섞여 있을 것 (예: 4/1, 4월2일, 4.3)
- 구분자가 통일되지 않을 것 (쉼표, 대시, 슬래시 혼용)
- 담당자나 상태 정보가 일부 누락되어 있을 것
모든 이름과 내용은 가상으로 만들어줘.
```
---
선택한 샘플(또는 직접 만든 데이터)로 아래 단계를 진행합니다.
1. 위에서 선택한 샘플의 프롬프트를 Copilot 채팅 창에 붙여넣고 전송합니다.
2. 출력된 결과를 아래 기준으로 검토합니다.
- 날짜 형식이 YYYY-MM-DD로 통일되었는지 확인합니다.
- 누락값이 "미배정" 또는 "미확인"으로 처리되었는지 확인합니다.
- 구분자가 섞여 있어도 열이 올바르게 분리되었는지 확인합니다.
3. 수정이 필요한 항목이 있다면 아래 후속 프롬프트로 개선을 요청합니다.
```plain text
날짜 열에서 연도가 빠진 항목은 2025년으로 채워줘.
이름에서 직책(대리, 과장 등)이 포함된 경우 직책을 별도 열로 분리해줘.
```
1. 완성된 표를 Excel에 붙여넣고 `Ctrl + T`를 눌러 표 서식을 적용합니다.
**기대 결과**: 날짜 형식이 통일되고 누락 항목이 일관된 텍스트로 처리된 깔끔한 표가 생성됩니다. `Ctrl + T`를 적용하면 이후 필터·정렬 기능을 즉시 활용할 수 있는 데이터베이스 형태가 됩니다.

## 실습 후 정리 사항
**결과물 저장**: 실습 1\~3에서 만든 결과물(비교표, 변환된 표)을 하나의 문서에 정리하여 `Copilot_모듈1_실습결과_[날짜].docx` 형식으로 저장합니다.
**프롬프트 메모**: 이번 실습에서 사용한 프롬프트 중 자신의 업무에 유용하다고 느낀 것을 별도로 메모해 두는 습관을 기릅니다. 개인별 프롬프트 라이브러리를 만들면 실무 적용 속도가 빨라집니다.
**보안 확인**: 실습 중 혹시라도 실제 업무 데이터를 입력한 경우, 해당 데이터가 민감 정보인지 확인하고 조직의 데이터 보안 정책에 따라 조치합니다.
**팀 공유**: 유용하다고 판단한 프롬프트와 워크플로우를 팀원에게 공유하여 팀 전체의 생산성 향상으로 연결합니다.

## 모듈 요약 및 다음 모듈 안내
이 모듈에서 다음 세 가지를 배웠습니다.
1. 실무에서 Copilot 데이터 전처리 자동화의 수요가 가장 높은 케이스 네 가지를 이해하고, 기존 작업 대비 시간이 얼마나 단축되는지 확인했습니다.
2. Copilot의 무료·유료 버전별 기능 차이를 명확히 파악하여 본인의 환경에 맞는 활용 방식을 선택할 수 있게 되었습니다.
3. 파일 업로드 없이 텍스트 복사·붙여넣기만으로도 비정형 데이터를 구조화된 표로 만드는 실습을 직접 완료했습니다.
다음 모듈인 **"비정형을 정형으로: 텍스트에서 데이터 뽑아내기"** 에서는 오늘 배운 기초 위에서 더 복잡한 비정형 문서(PDF, 이메일 묶음, 자문 의견서 등)에서 필요한 데이터만 정교하게 추출하는 고급 프롬프트 패턴을 배웁니다.
