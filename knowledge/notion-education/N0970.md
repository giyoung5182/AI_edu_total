# 제로샷과 퓨샷 — 예시를 주느냐의 차이
**제로샷** 은 예시 없이 바로 시키는 방식입니다.
```plain text
이 메모를 정식 점검일지로 바꿔줘
```
가장 빠르지만, "정식"이 무엇인지를 AI가 정합니다. 그래서 매번 다른 모양이 나옵니다.

**퓨샷** 은 원하는 모양을 먼저 보여 주고 시키는 방식입니다.

**모듈 04에서 배운 골든 샘플 기법이 바로 퓨샷입니다.**
기존 운영보고서를 붙여넣고 "이 형식 그대로"라고 한 것 — 그게 예시를 먼저 보여 준 것입니다.
이름을 몰라도 이미 쓰고 계십니다.






상황

선택

이유




빠른 초안만 필요할 때

제로샷

속도가 중요




**발주처 제출 문서**

**퓨샷**

**형식 일관성이 생명**




AI가 내 의도를 계속 잘못 잡을 때

퓨샷

예시로 방향을 고정



**실무자만 아는 지점 — 나쁜 예시도 주세요**
좋은 예시만 주면 AI가 "어느 선까지가 안 되는지"를 모릅니다.
`이런 문장은 피해 줘 — "향후 지속적인 관리를 통해 만전을 기하겠음"`
좋은 예 1개 + 나쁜 예 1개가 좋은 예 3개보다 정확합니다.

# 단계별 사고 — 과정을 쓰게 만들기
복잡한 일을 한 번에 시키면 AI는 중간을 건너뛰고 그럴듯한 결론만 내놓습니다.
> 수학 문제를 "답만 써" 와 "풀이 과정을 보여줘" 의 차이입니다.
> 과정을 쓰게 하면 스스로 오류를 발견합니다.
마법의 한 문장입니다.
```plain text
단계별로 생각해서 답해 줘
```

**실무자만 아는 지점 — 중간 결과를 보여달라고 하세요**
체크리스트 판정 검증처럼 결과만 받으면 맞는지 확인할 길이 없습니다.
`각 항목마다 기준값과 측정값을 나란히 보여 주고, 어떤 근거로 기준 초과로 판단했는지 적어 줘`
근거를 쓰게 하면 **틀렸을 때 어디서 틀렸는지가 보입니다.**

# 멀티턴 — 한 번에 안 나올 때
```plain text
1단계  넓게 시작 — 방향만 잡는 첫 질문
2단계  좁히기 — 부족한 부분만 집어 조건 추가
3단계  정제 — "이 부분만 다시", "1번과 3번 합쳐줘"
```

**함정 둘**
1. 긴 작업 중간에 새 대화를 여는 것 — 앞 맥락이 전부 날아갑니다
2. 부정형 지시만 반복하는 것 — "이렇게 하지 마" 보다 "이렇게 해 줘"가 훨씬 잘 먹습니다


**실무자만 아는 지점 — 고칠 때는 범위를 명시하세요**
"좀 더 간결하게" 하면 전체를 다시 씁니다. 잘 나온 부분까지 바뀌어 버립니다.
`구성과 수치는 그대로 두고, 3장 조치사항 부분만 둘로 줄여 줘`
**유지할 것을 먼저 말하고, 바꿀 것을 나중에** — 이 순서를 지키세요.

# 체이닝 — 큰 작업을 조각내기
한 번에 시키면 뭉개지는 작업을 순서대로 나눕니다. 우리 업무에서는 이렇게 나눕니다.
```plain text
1단계  정제  — 표기 통일 · 중복 제거 · 단위 환산
2단계  집계  — 유형별 · 기간별 수치 도출
3단계  검증  — 기존 수치와 대조, 차이 목록화
4단계  작성  — 공문 · 보고서 형식으로 변환
```

**왜 나누어야 하는가**
한 번에 시키면 AI가 정제를 대충하고 집계로 넘어갑니다. 그럼 숫자가 틀립니다.
나누면 **각 단계 결과를 사람이 확인하고 넘어갈 수 있습니다.**
이게 모듈 05 실습이 3단계로 된 이유입니다.

# 교차 검증 — 발주처 제출 전 마지막 관문
`원리 4`를 역으로 쓰는 방법입니다.
```plain text
새 대화창을 각각 열어서 같은 질문을 3번 돌린다
→ 3번 모두 같은 답이 나오면 신뢰할 만하다
→ 답이 갈리면 그 항목이 바로 사람이 봐야 할 지점이다
```

**같은 대화창에서 반복하면 의미가 없습니다.** 앞 답변을 보고 따라가버립니다.
반드시 **새 대화창을 열어서** 돌리세요.


**수강생 설명용 비유**
중요한 진단은 병원 한 곳만 가지 않습니다. 두 곳에서 같은 진단이 나오면 믿을 만합니다.
AI도 똑같습니다. 발주처에 나가는 숫자는 세 번 물으세요.

같은 작업을 여러 건 할 때

한 건 완성 후 **"같은 방식으로 다음 건"** 으로 이어가면 톤이 유지됩니다




**숫자가 들어간 문서**

**완성 후 숫자만 전부 뽑아 원본과 대조합니다. 예외 없습니다**
