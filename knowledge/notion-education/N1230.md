# 실습 4 — 품질 데이터 추출 (핵심)

정리일: 2026-10-08 · 교육 에셋 N1230

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 성적서를 두고 1차(한 줄)와 2차(규격 기준을 K 칸에 넣음) 결과를 비교해, K 칸 하나가 결과를 어떻게 바꾸는지 확인합니다. 이 교시의 핵심 실습이며 반드시 끝내야 합니다.
## 진행 단계
1. **시트 복사** — 엑셀 아래 탭에서 품질성적서_ANYBES 선택 → 전체 복사
2. **1차 시도** — 아래 한 줄만 입력 + 데이터 붙여넣기
- 입력할 내용:
```javascript
이 성적서에서 부적합 항목을 찾아줘.
```
3. **건수 적기** — 반드시 숫자를 워크시트에 기록
4. **2차 시도** — **새 대화창**에서 규격 기준을 넣어 재실행
- 입력할 내용:
```javascript
아래 품질 성적서에서 규격을 벗어난 항목을 전부 찾아라.

규격 기준:
(항목별 규격 기준 10개 — 교안 참고)

중요:
- 판정란의 기재 내용은 무시하고 실측값과 위 규격만 대조하라
- 판정란이 "적합"인데 실측값이 벗어난 건은 별도로 표시하라
- 단위가 명백히 잘못 입력된 것으로 보이는 값도 지적하라

출력: 검사번호 | 항목 | 실측값 | 규격 | 판정란 기재 | 비고
```
5. **차이 확인** — 판정란이 "적합"인데 이탈한 건이 잡혔는지 보기
- 정상 결과: 2차에서 규격 이탈 6건(판정란 "적합"인 이탈 3건 포함)이 나와야 함
6. **(선택) 세 번째 시도** — 시간이 되면 CoT(1단계 규격 정리 → 2단계 대조 → 3단계 이탈 목록화 → 4단계 판정란과 불일치 찾기 → 5단계 판단 어려운 건 분류)를 붙여 근거가 보이는지 확인
## 막히는 지점
- 2차는 새 대화창에서 실행합니다.
- 1차 프롬프트는 판정란만 읽기 때문에 이탈 건 대부분을 놓칩니다.
