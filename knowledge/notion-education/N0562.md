# VBA 기본 사용 방법 (for Windows)

정리일: 2026-10-08 · 교육 에셋 N0562

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
엑셀에서 개발도구를 켜고 VBA 편집기에 코드를 붙여 넣어 실행한다.
## 진행 단계
1. **파일 - 옵션** 메뉴로 들어간다.
2. **리본 사용자 지정 - 개발도구** 체크박스에 체크하고 확인을 클릭한다.
3. 리본메뉴 **개발도구**에서 **Visual Basic**을 클릭한다.
4. **삽입 - 모듈**로 새 모듈을 만든다. 하나의 모듈은 하나의 기능이다.
5. VBA 코드를 붙여 넣는다.
- 입력할 내용:
```javascript
A1:B10 영역의 배경색을 노란색으로 변경해주는 VBA 코드를 알려줘.
```
1. 초록색 재생(▶) 버튼을 클릭하면 코드가 실행된다.
