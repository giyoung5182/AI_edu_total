# 프롬프트 · 교육기관 2026 S/S 숏패딩 B2B 홍보 장표 (템플릿 사용)

정리일: 2026-10-08 · 교육 에셋 N1175

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
회사 템플릿을 사용해 Genspark로 B2B 홍보용 PPT 6장을 만들어 봅니다.
## 진행 단계
1. **템플릿 준비** — 교안에 첨부된 템플릿 pptx 사용
2. **프롬프트 입력** — 【기본 정보】(대상·목적·제품·형식·톤), 【핵심 메시지】, 【필수 포함 요소】(기능 스펙, 친환경 가치, B2B 전용 서비스, 마지막 슬라이드 CTA)를 구조화해 입력
- 형식 예: 프레젠테이션용 16:9, 6슬라이드 분량, 톤은 프리미엄 가치 강조
3. **리서치 단계** — "리서치 단계에서 제품 관련 실제 정보를 검색해서 반영"하도록 지시
4. **결과 확인** — 슬라이드 개요 6장(표지, 브랜드 가치, 제안 제품, 기능성, 친환경 가치, 제안·문의)과 완성 장표를 확인
- 참고: 어떤 모드를 쓸지 — 30초 안에 러프한 초안이면 일반 생성, 숫자·근거가 필요한 의사결정용 자료면 Guide Mode (전략 분석 → 콘텐츠 근거 보강 → 슬라이드 구조 설계 → 디자인 적용 → PPT 생성)
## 막히는 지점
