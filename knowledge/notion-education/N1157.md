1. **AI Studio 접속** — [개별 링크 제외]
2. **로그인** — 배부받은 Google 계정
3. **키 발급** — API 키 발급 메뉴에서 새 키 생성 (화면 구성은 수시로 바뀌므로 "API Key" 또는 "API 키" 문구를 찾음)
4. **키 복사 후 메모장에 임시 보관**
5. **.env 파일 만들기** — 리눅스(우분투) 영역의 disaster-bot 폴더에서 새로 만들기 → 텍스트 문서, 파일명을 `.env`로 하여 생성

## 막히는 지점
- 키 발급 버튼이 보이지 않음 → 페이지 상단·좌측 메뉴에서 "API" 문구 찾기
- 발급 시 프로젝트 선택 요구 → 정상, 기본 제안 프로젝트 선택
- 발급 직후가 키가 가장 노출되기 쉬운 순간 → 채팅창·공유 문서에 붙여넣지 않음
