# 실습 — PPT 작업용 SKILL 만들기

정리일: 2026-10-08 · 교육 에셋 N1487

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
앞에서 한 PPT 템플릿 채우기 작업을 반복해서 쓸 수 있는 SKILL 형태로 정리해 본다.
## 진행 단계
1. **자료 확인** — 앞에서 사용한 PPT 템플릿과 자료 파일을 확인한다.
2. **SKILL 초안 요청** — Claude Code에게 PPT 작업용 SKILL 초안을 만들어달라고 요청한다.
- 입력할 내용:
```javascript
앞에서 진행한 PPT 템플릿 채우기 작업을
앞으로 반복해서 사용할 수 있도록
PPT 작업용 SKILL을 만들어주세요.

skill의 이름은 poscoint-pptx입니다.
이 SKILL은 아래 상황에서 사용합니다.

- PPT 템플릿 파일이 있습니다.
- 메모 파일이 있습니다.
- CSV 또는 엑셀 데이터 파일이 있습니다.
- Claude Code가 템플릿의 디자인은 유지하면서 내용을 채워야 합니다.
```
1. **SKILL 내용 읽기** — 입력 파일, 템플릿 유지 기준, 메모·데이터 반영 방법, PPTX 저장, 작업 후 확인 기준이 들어갔는지 본다.
2. **부족한 기준 추가 요청** — 부족한 기준을 하나 이상 추가 요청한다.
3. **SKILL로 PPT 다시 만들기**
- 입력할 내용:
```javascript
/poscoint-pptx
첨부한 PPT 템플릿에 메모 파일과 데이터 파일의 내용을 채워주세요.

기존 템플릿의 디자인과 레이아웃은 유지하고,
결과물은 수정 가능한 PPTX 파일로 저장해주세요.
```
1. **차이 확인** — 처음에는 요청을 길게 써야 했는데 SKILL을 만들고 나면 작업 기준을 훨씬 짧게 전달할 수 있는지 기존 요청 방식과 비교한다.
