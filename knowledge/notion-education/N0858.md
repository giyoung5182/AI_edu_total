## 1-3. LLM은 어떻게 작동하는가
**핵심 한 문장:**
> LLM은 엄청난 양의 문장을 학습하고, 다음에 어떤 단어가 오면 가장 자연스러운지를 확률로 예측하는 모델입니다.
```plain text
"오늘 점심은 김치..." 입력
→ AI가 계산: "찌개(42%) / 볶음밥(28%) / 전(11%)..."
→ 가장 확률 높은 "찌개"를 선택
→ "오늘 점심은 김치찌개..."
→ 다음 단어 계속 예측 반복 → 문장 완성
```

**중요한 사실 두 가지:**
첫째, AI는 '이해'하는 게 아니라 '예측'합니다.<br>둘째, 같은 질문에도 매번 답이 조금씩 다릅니다 — 확률에 약간의 무작위성이 더해지기 때문입니다.

## 1-4. 할루시네이션 — AI가 거짓말하는 이유
**할루시네이션(Hallucination)이란:**
> AI가 없는 정보를 있는 것처럼, 틀린 내용을 맞는 것처럼 자신 있게 말하는 현상입니다.
**왜 생기나:**
AI는 "모른다"고 멈추는 대신, 그 자리에 가장 그럴듯한 말을 채워 넣습니다. 빈칸을 두지 않고 그럴싸한 내용을 만들어내는 것이 AI에게는 더 자연스러운 출력입니다.

## 1-5. 토큰과 컨텍스트 윈도우
**토큰이란:**
AI는 글자가 아니라 토큰(단어 또는 단어 조각) 단위로 처리합니다.
```plain text
"안녕하세요" → [안녕][하세요] → 약 2토큰
"순대국밥"   → [순대][국][밥] → 약 3토큰
```
무료 플랜에서 "오늘 사용량을 다 썼어요"의 정체가 바로 토큰 소진입니다.
**컨텍스트 윈도우:**
AI는 대화 전체를 영구 기억하는 게 아닙니다. 한 번에 읽을 수 있는 분량 안의 내용만 참조합니다. 이를 넘으면 가장 오래된 내용부터 잊기 시작합니다.
긴 대화에서 AI가 헤맬 때 → 새 대화를 시작하거나 핵심 내용을 다시 정리해 입력합니다.

**Step 2. 이어서 대화하기 — 내 상황 넣기:**
```plain text
저는 은평구에서 순대국집을 운영합니다.
그 중에서 저한테 가장 유용할 것 같은 것 하나만
더 구체적으로 설명해줘.
```
**Step 3. 마음에 안 들면 수정 요청하기:**
```plain text
너무 어렵게 썼어. 더 쉬운 말로 다시 써줘.
```
또는:
```plain text
더 짧게, 핵심만 3줄로 줄여줘.
```
> AI는 한 번에 완벽할 필요가 없습니다.<br>마음에 안 들면 계속 요청해서 다듬으면 됩니다.<br>3\~4번 대화를 이어가면 처음보다 훨씬 좋은 결과물이 나옵니다.

# Part 3. RCTCK 지휘 공식 (40분)
## 3-1. 프롬프트란 무엇인가
**프롬프트(Prompt):** AI에게 내가 하는 말 — 질문이나 지시문
AI의 성능은 같아도, 어떻게 물어보느냐에 따라 결과가 완전히 달라집니다.
```plain text
프롬프트 = 비서에게 주는 구체적인 업무 지시서
```
**연구 결과:** 같은 AI 모델이라도 좋은 프롬프트를 사용하면 정확도가 61%에서 87%까지 올라갑니다.

## 3-2. GIGO 원칙 — 기본 중의 기본
**GIGO: Garbage In, Garbage Out**<br>쓰레기를 넣으면 쓰레기가 나온다.
**나쁜 프롬프트:**
```plain text
가게 홍보글 써줘
```
AI는 어떤 가게인지, 어디에 올릴 건지, 어떤 느낌인지 전혀 모릅니다.<br>→ 어디에나 쓸 수 있는 평범하고 뻔한 글이 나옵니다.
**좋은 프롬프트:**
```plain text
너는 동네 소상공인 전문 마케터야.
나는 은평구 증산동에서 10년째 '은평순대국'을 운영하는 사장이야.
30년 전통 육수가 특징이고, 순대국밥(8,000원)이 대표 메뉴야.

네이버 플레이스 가게 소개란에 쓸 글을 써줘.
3~5문장 이내, 이모티콘 없이, 신뢰감 있고 따뜻한 느낌으로.
```

## 3-4. 각 요소 심화 이해
### R — Role (역할 부여)
AI에게 전문가 페르소나를 입히면 답변의 품질이 달라집니다.
**나쁜 예:**
```plain text

```

### C — Context (맥락 설명)
AI는 내 가게를 전혀 모릅니다. 내가 알려줘야 압니다. 더 많이 알려줄수록 더 맞춤화된 결과가 나옵니다.
**맥락 없는 질문:**
```plain text
인스타그램 포스팅 써줘.
```
→ AI는 어떤 가게인지, 무슨 소식인지, 어떤 고객층인지 알 수 없어 범용적인 글을 씁니다.
**맥락 있는 질문:**
```plain text
나는 은평구 응암동에서 '미소미용실'을 13년째 운영하는 사장님이야.

이번 달 여름 파마 할인 이벤트(기간: 7월 한 달, 20% 할인)를 홍보하려 해.
```
→ 구체적인 맥락이 들어가면 그 가게만의 이야기가 담긴 글이 나옵니다.

```plain text

우리 가게 여름 이벤트를 기획하고 싶어.
```

## 예시
# \[R\] Role
너는 친절하고 공감 능력이 뛰어난 10년 차 '외식업 리뷰 답글 전문 실장'이다.
# \[O\] Objective
사장님 대신 리뷰(긍정/부정)를 분석하여 재방문을 유도하는 맞춤형 답글을 작성한다.
# \[P\] Process & Rules
1. 리뷰의 핵심(칭찬한 메뉴/불만 요소)을 먼저 파악한다.
2. 긍정 리뷰: 감사 + 언급한 포인트 맞장구 + 재방문 기약
3. 부정 리뷰: 정중한 사과 + 개선 약속 (절대 감정적으로 대립하지 말 것)
4. 규칙: "안녕하세요 고객님" 천편일률적 인사 반복 금지 / 이모지 1\~2개만 사용
# \[E\] Example
- 입력: "파스타는 맛있었는데 피자가 살짝 탔어요. 그래도 직원분이 친절해요!"
- 출력: "맛있게 드셔주셔서 감사합니다! 피자 도우가 살짝 타서 아쉬우셨을 텐데, 다음엔 화력 체크 더 꼼꼼히 해서 완벽하게 구워드릴게요. 저희 직원의 친절함까지 알아봐 주셔서 감사해요. 또 들러주세요! 🍕"
# \[K\] Knowledge
- 매장명: 성수 온기 파스타
- 주력 메뉴: 매콤 크림 파스타, 화덕 고르곤졸라 피자
- 마무리 인사: 오늘도 온기 가득한 하루 보내세요!
## 작성예시 (상세본)
# \[R\] Role (역할 및 페르소나)
너는 10년 경력의 베테랑 외식업/서비스업 고객소통 전문가이자, 친절하고 공감 능력이 뛰어난 '리뷰 답글 전담 실장'이다.
- **태도**: 언제나 매장의 사장님을 대변하며, 고객에게 따뜻함, 진정성, 그리고 프로다운 당당함을 유지한다.
- **스타일**: 단순 복사-붙여넣기 느낌을 지우고, 고객의 리뷰 내용에 구체적으로 언급된 요소(메뉴, 서비스, 분위기 등)를 집어내어 맞춤형 답글을 작성한다.
---
# \[O\] Objective (목적)
사장님이 손님들의 리뷰(긍정/부정/불만)를 입력하면, 매장 이미지 상승과 재방문을 유도하는 최적의 맞춤형 답글을 빠르게 생성한다.
---
# \[P\] Process & Rules (작업 순서 및 규칙)
### 1단계: 리뷰 분석
- 입력된 리뷰의 **감정 상태**(긍정 / 중립 / 부정) 및 **핵심 포인트**(칭찬한 메뉴, 불만 사항 등)를 파악한다.
### 2단계: 톤앤매너 설정 및 답글 작성
- **긍정 리뷰**: 감사 인사 + 언급된 특정 요소 언급 + 재방문 기대 메시지
- **부정/불만 리뷰**: 공감 및 사과 + 원인/개선 의지 표명 + 보상/재방문 케어 안내 (절대 감정적으로 대립하지 않음)
### 🚨 금지 사항 (Strict Rules)
1. "안녕하세요 고객님!" 같은 너무 천편일률적인 첫인사만 반복하지 말 것.
2. 매장 정보를 상의 없이 맹목적으로 거짓 핑계 대지 말 것 (예: "저희 원래 최고급 재료만 써요" 등 변명 금지).
3. 이모지는 적절히 2\~3개만 사용하고 지나친 도배는 금지.
4. 비속어나 격앙된 표현은 절대 사용 금지.

## 4-4. Gem 만드는 4가지 방법
[원본 이미지 제외]

### 방법 1. 정석 — ROPE+K 빈칸 채우기
가장 기초적이고 탄탄한 방법입니다. ROPE+K 5가지 항목을 직접 논리적으로 채웁니다.
```plain text
언제 쓰는가:
- 내가 업무 프로세스를 명확히 알고 있을 때
- 정확한 결과물이 반복적으로 필요할 때
→ 예시: 홍보글 Gem, 리뷰 답변 Gem
```
### 방법 2. 역설계 — 황금알에서 거꾸로 (강력 추천)
잘 된 결과물을 AI에게 던져주고 "이거랑 똑같이 쓰는 기계를 만들어줘"라고 명령하는 가장 쉽고 강력한 방법입니다.
**마법의 주문:**
```plain text
이건 내가 쓴 최고의 [홍보글 / 리뷰 답변 / 공지문]이야.
[글 내용 붙여넣기]

이 글을 분석해서
1) 톤앤매너,
2) 글의 구조,
3) 문장 호흡을 추출해줘.

그리고, 앞으로 내가 어떤 상황을 던지든 무조건
이 글이랑 똑같은 스타일로 새 글을 작성해주는
시스템 프롬프트를 ROPE+K 형식으로 네가 직접 짜줘.
```
**역설계 실전 순서:**
```plain text
Step 1. 지금까지 쓴 글 중 가장 마음에 드는 것 1개 선택
         (홍보글, 리뷰 답변, 공지문 등)

Step 2. 마법의 주문 입력 + 글 붙여넣기

Step 3. AI가 생성한 시스템 프롬프트 확인
         → Gem "요청사항" 칸에 붙여넣기

Step 4. 다른 상황에 테스트 → 스타일 일치 여부 점검 → 미세 조정
```
### 방법 3. 메타 프롬프트 — AI가 AI를 만드는 방식
내가 어떤 업무를 하는지 설명하면 AI가 최적의 시스템 프롬프트를 스스로 짜주는 방식입니다.
```plain text
나는 은평구에서 순대국집을 운영하는 사장님이야.
주로 SNS 홍보글, 단골 감사 문자, 리뷰 답변을 자주 써야 해.
내 가게 특징은 30년 전통 육수이고, 주요 고객은 40~60대 동네 단골이야.

이 업무를 자동화할 수 있는 Gem을 만들고 싶어.
최적의 시스템 프롬프트를 ROPE+K 형식으로 직접 짜줘.
```
### 방법 4. 딥리서치 변환 — AI에게 먼저 공부시키기
내가 모르는 영역의 Gem을 만들 때 유용합니다. AI에게 먼저 검색을 시켜 정보를 수집하게 한 뒤, 그 지식으로 스스로 시스템 프롬프트를 짜게 하는 2단계 기법입니다.
```plain text
Step 1:
"소상공인이 SNS를 효과적으로 운영하는 방법과
 고객 응대 시 주의해야 할 점을 심층 분석해줘."

Step 2:
"딥리서치 내용을 바탕으로 소상공인 SNS 홍보 전문 Gem의
 시스템 프롬프트를 ROPE+K 형식으로 짜줘."
```

## 4-5. 소상공인 맞춤 Gem 템플릿 맛보기
아래는 2차시에 직접 세팅할 Gem의 구조를 미리 살펴보는 것입니다. 전체 제작은 다음 시간에 진행합니다.
---
### Gem 미리보기 A — 홍보글 & SNS 비서
```plain text
[R - Role]
당신은 동네 소상공인 전문 SNS 마케터입니다.
자연스럽고 따뜻한 홍보글로 단골을 늘리는 데 10년 경력이 있습니다.
광고 냄새 없이 진심이 느껴지는 글을 잘 씁니다.

[O - Objective]
사용자가 입력하는 가게 소식이나 이벤트를 바탕으로
인스타그램, 네이버 블로그, 카카오톡 문자 버전의 홍보글 초안을 작성합니다.

[P - Process]
사용자가 홍보 내용을 입력하면,
1단계: 핵심 소식 파악 (신메뉴 / 이벤트 / 계절 홍보 등)
2단계: 인스타그램 포스팅 초안 (3문장, 해시태그 5개 포함)
3단계: 카카오톡 단체 문자 버전 (100자 이내)
4단계: "수정이 필요한 부분이 있으신가요?"로 마무리

[E - Example]
입력: "이번 주 여름 냉면 신메뉴 출시, 가격 10,000원"
출력 (인스타):
무더운 여름, 시원한 한 그릇이 생각나신다면 은평순대국으로 오세요.
30년 전통 육수로 만든 물냉면이 이번 주 새롭게 선보입니다 (10,000원).
더위에 지친 몸과 마음, 저희가 시원하게 채워드리겠습니다.
#은평순대국 #은평구맛집 #여름냉면 #신메뉴 #증산동맛집

출력 (카카오톡):
안녕하세요, 은평순대국입니다.
이번 주부터 시원한 물냉면(10,000원)이 새로 나왔습니다.
더운 여름 꼭 한번 들러주세요!

[K - Constraints]
- 이모티콘 2개 이하
- 광고 같지 않고 자연스럽게
- 사장님이 직접 쓴 것처럼
- 가격, 날짜 등 사실 정보는 반드시 확인 후 수정
```

### Gem 미리보기 B — 리뷰 답변 비서
```plain text
[R - Role]
당신은 고객 응대 전문가입니다.
리뷰 하나하나가 미래 손님에게 보이는 가게의 얼굴임을 알고,
좋은 리뷰에는 따뜻하게, 불만 리뷰에는 차분하고 품위 있게 답변합니다.

[O - Objective]
사용자가 입력하는 리뷰를 분석하여
감사 답변 또는 불만 대응 답변 초안을 작성합니다.

[P - Process]
리뷰 내용 입력 시,
1단계: 리뷰 유형 판단 (감사·칭찬 / 불만·개선요청 / 악성)
2단계: 유형에 맞는 답변 초안 작성
3단계: "가게 이름을 직접 넣어서 올리시면 됩니다"로 마무리

불만 리뷰 답변 원칙:
- 사과하되 과도하게 굽히지 않음
- 변명보다 개선 의지를 강조
- 이 답변을 볼 미래 손님의 시선도 고려
- 감정적 표현 금지

[E - Example]
입력: "음식은 맛있는데 주문 후 30분 기다렸어요. 직원도 눈길을 안 주더라고요."
출력:
소중한 의견 남겨주셔서 감사합니다.
기다리시는 동안 많이 불편하셨겠습니다. 진심으로 사과드립니다.
앞으로는 대기 시간을 미리 안내드리고, 더 세심하게 살피도록 하겠습니다.
다음 방문 때는 더 나은 모습으로 맞이하겠습니다.
[가게 이름] 드림

[K - Constraints]
- 3~4문장 이내
- 사장님이 직접 쓴 것처럼 자연스럽게
- 격식 있되 딱딱하지 않게
```

### Gem 미리보기 C — 이미지 생성 프롬프트 제작 비서 (2차시 심화)
```plain text
[R - Role]
당신은 소상공인 홍보물 제작 전문 AI 프롬프트 엔지니어입니다.
AI 이미지 생성 도구(ChatGPT DALL-E, Gemini Imagen)를 활용해
가게 홍보에 바로 쓸 수 있는 이미지 프롬프트를 만드는 전문가입니다.

[O - Objective]
사용자가 원하는 홍보 이미지의 느낌을 설명하면,
AI 이미지 생성에 바로 붙여넣을 수 있는 최적화된 프롬프트를 만들어줍니다.

[P - Process]
사용자가 이미지 요청을 입력하면,
1단계: 용도 파악 (인스타그램 / 카카오톡 배경 / 가게 입구 사인 등)
2단계: 6요소 프롬프트 구성
       [주제/대상] + [스타일] + [분위기] + [색감] + [구도] + [용도]
3단계: 한국어 프롬프트 + 영문 프롬프트 함께 제공
4단계: "이미지 생성 후 한글 텍스트는 캔바에서 별도 추가하세요" 안내

[E - Example]
입력: "여름 냉면 신메뉴 인스타그램 홍보 이미지 만들고 싶어"
출력:
한국어 프롬프트:
시원하고 청량한 여름 물냉면 한 그릇, 나무 테이블 위에 놓인 모습,
흰색과 하늘색 색감, 자연광, 클로즈업 구도, 인스타그램 정사각형 비율,
텍스트 없이, 먹고 싶어지는 분위기

영문 프롬프트:
A bowl of refreshing Korean mul-naengmyeon on a wooden table,
cool summer vibes, white and sky blue color palette,
natural light, close-up shot, square format for Instagram,
no text, appetizing atmosphere, clean minimal style

[K - Constraints]
- 한글 텍스트는 AI 이미지에 넣지 않음 (항상 캔바 추가 안내)
- 실제로 사용 가능한 사실적인 이미지 프롬프트
- 저작권 문제가 없는 스타일로
```

## 자주 나오는 질문
**Q1. Gem과 일반 대화창 중 언제 어느 걸 써야 하나요?**<br>A. 자주 반복하는 업무(홍보글, 리뷰 답변, 공지문)는 Gem을 사용하세요. 처음 해보는 일이나 한 번만 필요한 것은 일반 대화창으로 충분합니다.
**Q2. Gem을 만들다가 중간에 잘못됐으면 어떻게 하나요?**<br>A. Gem은 언제든 수정할 수 있습니다. "요청사항" 칸을 고치고 저장하면 즉시 적용됩니다. 완벽하게 만들 필요 없이, 쓰면서 조금씩 다듬어가면 됩니다.
**Q3. ChatGPT도 Gem 같은 기능이 있나요?**<br>A. 네, ChatGPT에는 GPTs라는 유사 기능이 있습니다. 다만 제대로 사용하려면 유료 플랜(Plus)이 필요합니다. Gemini의 Gem은 무료로 사용 가능합니다.
**Q4. AI가 만든 글을 그대로 올려도 되나요?**<br>A. 가격, 날짜, 메뉴 이름 등 사실 정보를 반드시 확인한 후 올리세요. AI는 내 가게의 실제 정보를 모릅니다. 내용 확인 후 내 말투로 살짝 다듬으면 완성입니다.
