### 🟡 Cursor 사용자
Cursor에서는 더 편하게 쓸 수 있어요. 자동 호출도 됨.
### 1단계 — 깃허브에서 다운로드
```bash
git clone https://github.com/msitarzewski/agency-agents
cd agency-agents
```
### 2단계 — Cursor에 설치
```bash
./scripts/install.sh --tool cursor
```
이러면 Cursor의 `.cursor/rules/` 폴더에 자동으로 설치돼요.
### 3단계 — 사용
Cursor 채팅창에서:
```plain text
@frontend-developer React로 카운트다운 컴포넌트 만들어줘
```
> 💡 Windows 사용자라면 `install.sh`가 안 돌아갈 수 있어요.<br>그럴 땐 그냥 `engineering/frontend-developer.md` 파일 내용 복사해서 채팅창에 붙여넣고 쓰면 됨.

## 🚀 한 단계 더 — 여러 명 동시에 협업시키기
Claude Code, Cursor 같은 도구에서는 여러 에이전트를 **동시에** 호출할 수 있어요.
```plain text
4명한테 병렬로 시켜줘:

1. 마케팅 전문가 → 무드모드 릴스 카피 3개
2. 카피라이터 → 영문 슬로건 3개
3. 브랜드 전략가 → 키워드 5개
4. 그로스 해커 → 도달률 전략 3가지

동시에 실행해줘.
```
→ 진짜 회사처럼 4명이 동시에 일하고, 각자 결과를 보고합니다.<br>이게 진짜 미친 기능이에요. 한번 써보면 못 돌아옴.
