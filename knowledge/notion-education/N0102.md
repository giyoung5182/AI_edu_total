## **오늘 만들 최종 결과물**

엑셀 파일을 넣으면<br>웹 화면에서 데이터를 표로 보여주고,<br>중요한 수치는 카드로 정리하고,<br>차트로도 확인할 수 있게 만들어보겠습니다.

```plain text

→ 표로 보기
→ 차트로 보기
→ GitHub 저장
→ Vercel 배포
```

## **화면은 이렇게 구성합니다**
먼저 화면 구성을 잡고 가겠습니다.
Claude Code에게 바로 만들라고 하기 전에<br>어떤 화면이 필요한지 정리해두는 게 좋습니다.
### **화면 구성**
```plain text
1. 상단 제목
   - 해외법인 실적 대시보드

2. 엑셀 업로드 영역
   - 파일 선택 버튼
   - 업로드 안내 문구

3. 핵심 지표 카드
   - 총 매출
   - 총 영업이익
   - 평균 영업이익률
   - 법인 수

4. 차트 영역
   - 지역별 매출 차트
   - 분기별 매출 추이 차트
   - 법인별 영업이익 차트

5. 데이터 표
   - 원본 엑셀 데이터 표시
   - 검색 또는 필터
```

## **Claude Code에게 요청하기**
이제 Claude Code에게 웹앱을 만들어달라고 요청해보겠습니다.
이번 실습에서는<br>프론트엔드만 사용합니다.
React + Vite로 만들고,<br>엑셀 파일은 xlsx 라이브러리로 읽고,<br>차트는 recharts로 보여주는 구조로 요청합니다.
### **프롬프트 예시**
```plain text
엑셀 파일을 업로드하면
웹 화면에서 표와 차트로 보여주는 대시보드 웹앱을 만들어주세요.

기술 스택은 React + Vite로 해주세요.
run.bat라는 실행파일을 만들어서 실행하게 해주세요.

이번 실습에서는 백엔드와 데이터베이스를 사용하지 않습니다.
엑셀 파일은 브라우저에서 직접 읽어주세요.

엑셀 파일 읽기는 xlsx 라이브러리를 사용하고,
차트는 recharts를 사용해주세요.

기능은 아래와 같습니다.

1. .xlsx 파일 업로드
2. 첫 번째 시트 데이터 읽기
3. 원본 데이터를 표로 표시
4. 핵심 지표 카드 표시
5. 지역별 매출 차트 표시
6. 분기별 매출 추이 차트 표시
7. 법인별 영업이익 차트 표시
8. 검색 또는 필터 기능 추가

디자인은 아래 design.md를 참고해주세요.
[design.md]
```

## **Vercel에 배포하기**
이제 GitHub에 올린 프로젝트를<br>Vercel에 배포해보겠습니다.
Vercel에 배포하면<br>내 컴퓨터에서만 보이던 웹앱을<br>링크로 다른 사람에게 공유할 수 있습니다.
```markdown
여태까지의 진행사항을 vercel에 배포해줘
```
[원본 이미지 제외]
### 수동 배포 순서
```plain text
1. Vercel에 접속합니다.
2. GitHub 저장소를 선택합니다.
3. 프로젝트 설정을 확인합니다.
4. Deploy 버튼을 누릅니다.
5. 배포가 끝나면 생성된 링크를 확인합니다.
6. 링크를 열어서 웹앱이 정상 작동하는지 확인합니다.
```
