# Step 01 :: 같은 질문을 세 환경에서 비교합니다.

정리일: 2026-10-08 · 교육 에셋 N1043

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 질문을 웹, 앱의 채팅, 앱의 Cowork에서 실행해 Claude가 내 컴퓨터 폴더에 접근할 수 있는지 차이를 확인합니다.
## 진행 단계
1. **웹** — `[개별 링크 제외] 접속해 새 대화를 열고, project 폴더 주소창의 경로를 복사해 아래 문구의 \[복사한 경로\] 자리에 넣습니다.
```javascript
[복사한 경로]
위 폴더에 어떤 파일이 들어 있는지 알려줘
```
- 정상 결과: 내 컴퓨터의 폴더에 직접 접근할 수 없다는 답이 나옵니다.
2. **앱의 채팅** — 데스크톱 앱 좌측 상단 `새로 생성`을 클릭, 입력창이 `채팅`인 상태에서 똑같은 문구를 넣습니다.
- 정상 결과: 결과는 같습니다. 앱을 설치한 것만으로 파일 접근이 허용되는 것은 아닙니다.
3. **앱의 Cowork** — `새로 생성`을 클릭, 입력창이 `Cowork`인 상태에서 똑같은 문구를 넣습니다. 세션에 폴더 추가를 요청하면 승인합니다.
- 정상 결과: 파일 이름이 그대로 나옵니다.
4. (심화) 같은 대화에서 파일 내용을 읽게 합니다.
```javascript
3-1_캠페인현황_원본.xlsx 파일을 열어서 몇 행짜리 표인지 알려줘
```
## 막히는 지점
- 이후 실습은 Claude 앱에서만 진행하므로 웹 창은 닫습니다. 웹과 앱을 함께 열어두면 입력 위치를 혼동할 수 있습니다.
- 화면에 Cowork가 안 보이는 것은 정상일 수 있습니다(채팅과 Cowork 통합 적용 중). 합쳐진 화면에서는 문장을 그냥 대화창에 넣습니다.
