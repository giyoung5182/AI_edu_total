### 1-0. 주제 발굴 프레임워크 — 맥락으로 찾는 법 (25분)
> 과제 3단계에서 주제 후보를 뽑아 오셨지만, "다음 강의는 또 뭘 다루지?"라는 고민은 계속 반복됩니다. <br>오늘은 매번 막막해하지 않고 스스로 주제를 계속 뽑아낼 수 있는 방법 자체를 배웁니다.
**왜 맥락이 먼저인가**
```plain text
"AI 강의를 만들자"고 생각하면 막막합니다.
"이 사람들이 언제, 어떤 순간에 AI가 필요한가"를 먼저 그리면
주제가 저절로 따라옵니다.

주제는 "AI 기능"에서 출발하지 않고 "삶의 장면"에서 출발할 때
훨씬 쉽게, 훨씬 많이 나옵니다.
```
**세 가지 맥락 렌즈**
```plain text
렌즈 1 — 일상생활 맥락
  특정 삶의 장면 하나를 떠올리고, 그 장면에 AI를 대입해봅니다.
  - 아침에 일어나서: 오늘 일정 확인, 날씨 확인
  - 가족 관련: 자녀 숙제 봐주기, 부모님 병원 동행 준비, 손주 선물 고르기
  - 여가: 여행 계획, 취미 배우기, 사진 정리
  - 소비: 가계부, 물건 비교하며 구매 결정

  예: "여행 계획 세우는 AI 활용법" / "가족사진 AI로 복원하기"

렌즈 2 — 업무 맥락
  특정 직무 하나를 정하고, 그 직무의 반복 업무를 떠올립니다.
  - 사무직 공통: 이메일, 보고서, 회의록, 발표자료
  - 직군별: 영업(제안서), 마케팅(콘텐츠), 인사(채용공고), 자영업(SNS 홍보)

  예: "회의록 5분 만에 정리하기" / "발표자료 순식간에 만들기"

렌즈 3 — 상황별 맥락
  시기·이벤트·인생의 특정 국면을 떠올립니다.
  - 계절/시즌: 설·추석 인사말, 여름휴가 계획, 연말정산
  - 인생 이벤트: 이사, 이직, 자녀 입시, 결혼 준비
  - 돌발 상황: 급하게 자료 찾아야 할 때, 사기 문자 판별

  예: "사기 문자, AI로 3초 만에 확인하기" / "명절 인사말 AI로 준비하기"
```

### 1-1. 왜 "화법"이 아니라 "설계"가 달라야 하는가
```plain text
2회차에서 배운 것: 같은 개념을 다른 말투로 설명하는 법
오늘 배우는 것: 같은 개념이라도 대상에 따라
  - 얼마나 반복하는지
  - 실습과 이론의 비율을 어떻게 배분하는지
  - 어떤 순서로 정보를 주는지
  - 무엇을 먼저 안심시키고 무엇을 나중에 도전시키는지
자체가 달라져야 한다는 것

성인 학습의 기본 원리(안드라고지):
성인 학습자는 아이들과 다르게 배웁니다.
- 자기주도적: 왜 배워야 하는지 납득해야 몰입한다
- 경험 기반: 자기 경험과 연결될 때 더 잘 이해한다
- 문제 중심: 추상적 개념보다 "내 문제를 어떻게 푸는가"에 반응한다

→ 세대가 다르면 "어떤 경험과 연결할지", "어떤 문제가 절실한지"가
   다르기 때문에, 같은 개념도 설계 자체를 다르게 짜야 합니다.
```

### 1-2. 세 페르소나 — 설계 차원의 차이
**60\~70대 시니어**
```plain text
핵심 심리: 새로운 기술에 대한 두려움 + "나만 뒤처지는 것 아닌가"라는 불안

설계 원칙:
- 이론 10% : 실습 90% (거의 전부 손으로 직접 해보게)
- 같은 동작을 최소 2~3번 반복시켜 "손에 익게" 함
- 도전 과제보다 성공 경험을 먼저 쌓게 함
  (어려운 것부터 주면 "역시 나는 안 되는구나"로 이탈)
- 진행 순서: 안심시키기 → 아주 쉬운 성공 1회 → 조금 더 → 반복

피해야 할 설계:
- 여러 개념을 한 시간에 몰아넣기
- "이 정도는 다들 아시죠?"라는 전제
- 진도를 강사 속도에 맞추기 (수강생 속도에 맞춰야 함)
```
**40\~50대 실무형**
```plain text
핵심 심리: "이게 내 업무에 실제로 쓸모가 있는가"

설계 원칙:
- 이론 20~30% : 실습 70~80%
- 도입부에 반드시 "이게 왜 필요한가"의 실무 사례부터 제시
  (개념 설명보다 문제 상황 제시가 먼저)
- Before/After를 시간 절약 관점으로 제시
  ("이 작업이 30분에서 3분으로 줄어듭니다")
- 실습 소재를 본인 업무와 최대한 가깝게 커스터마이징

피해야 할 설계:
- 기술 원리를 깊게 설명하는 데 시간을 씀 (관심사가 아님)
- 감성적 접근("신기하죠?")으로 시작 (설득력 없음)
```
**20\~30대 · AI 경험자**
```plain text
핵심 심리: "나보다 못한 걸 배우러 온 게 아닌가"라는 경계심

설계 원칙:
- 이론 30~40% : 실습 60~70% (단, 실습 난이도는 높게)
- 이미 아는 것을 확인시키는 질문으로 시작
  ("혹시 프롬프트 6요소 들어보셨어요?")
- 기초를 반복하지 않고, "여기서 한 단계 더" 심화로 바로 진입
- 함께 탐구하는 분위기 ("저도 최근에 알게 된 건데...")
- 실패해도 괜찮은 분위기 — 같이 실험하는 구조

피해야 할 설계:
- 기초 설명을 처음부터 반복 (무시당하는 느낌을 줌)
- 강사가 일방적으로 정답을 제시하는 구조
```

### 1-3. 혼합 연령대 — 한 강의실에 다 있을 때
```plain text
현실: 대부분의 강의는 세 유형이 섞여 있습니다.

전략 1 — 계층화된 실습 (Tiered Practice)
  기본 과제 + 심화 과제를 동시에 제시하고, 각자 속도에 맞게 선택
  "다 하신 분은 이 추가 과제도 해보세요"

전략 2 — 짝 활동 활용
  AI 경험자를 초보자 옆에 배치해서 서로 돕게 함
  → 경험자에게는 "설명해보는 것 자체가 심화 학습"이 되고,
     초보자에게는 강사 외 도움이 하나 더 생김

전략 3 — 도입부에서 눈높이 파악
  강의 시작 전 짧은 질문으로 수강생 구성 파악
  ("AI를 오늘 처음 써보시는 분, 손 들어주세요")
  → 이후 설명 밀도를 실시간으로 조정
```

### 2-1. 재설계 체크리스트 — 지금까지 배운 원칙 총동원
```plain text
□ 전체 흐름 — 강사가 말하고 싶은 순서인가, 수강생 이해가 쌓이는 순서인가
  (0회차 원칙: 도입 → 공감 → 개념 → 실전 → 마무리)

  (1-2에서 다룬 페르소나별 도입 원칙 적용됐는가)

□ 개념 설명 깊이 — 3줄 요약으로 끝나지 않고 비유·원리가 있는가
  (1회차 원칙: LLM·환각 등을 대상 수준에 맞는 비유로)

□ 정직성 — 단정적 표현, 과장, 수익 암시 표현이 섞이지 않았는가
  (7회차 검수 기준 문서 원칙 재적용 — C004·C005·C010 유형 확인)

□ 근거 — 통계·수치를 인용했다면 출처가 명확한가
  (7회차 C006·C007 유형 확인)

□ 실습 설계 — Before/After가 있는가, 체이닝으로 단계적인가
  (2회차 Before/After 시연 원칙)

□ 시각 자료 — 텍스트로 나열하지 않고 이미지·다이어그램으로
  이해를 돕는 부분이 있는가 (3회차 이미지 제작 원칙)

□ 세대별 설계 — 오늘 PART 1에서 정한 대상에 맞게 설계됐는가
```

## PART 3. 어려운 질문 대응 훈련 (50분)
> 0회차부터 계속 "못 답한 질문은 여기에 모아둔다"고 안내해 왔습니다. 오늘이 그 질문들을 실제로 다루는 시간입니다.
---
### 3-1. 준비 — 질문 은행 만들기
```plain text
아래 두 출처를 합쳐서 오늘 훈련할 질문 목록을 만듭니다.

출처 1: 과제 1단계(강의평 분석)에서 나온 실제 어려웠던 질문들
출처 2: 아래 유형별 샘플 질문 (실제 질문이 부족하면 채워서 사용)
```
### 3-2. 유형별 샘플 질문 은행
**유형 A — AI 회의론 · 불신형**
```plain text
"AI가 결국 사람 일자리를 다 뺏는 거 아닌가요?"
"AI가 하는 말을 어떻게 믿어요? 다 지어내는 거라면서요?"
"이거 배워봤자 몇 달 뒤면 또 다른 게 나오는 거 아니에요?"
```
**유형 B — 비교·도전형 (경험자 청중)**
```plain text
"ChatGPT면 다 되는데 굳이 루미를 써야 하는 이유가 뭐예요?"
"방금 그 설명, 사실 정확하지 않은 것 같은데요?"
"저는 이미 프롬프트 엔지니어링 다 아는데 오늘 뭘 더 배우나요?"
```
**유형 C — 범위 밖 질문**
```plain text
"이거 코딩도 배울 수 있는 거예요? (코딩 강의가 아닌 자리에서)"
"AI 관련 주식은 뭘 사면 좋을까요?"
"제 개인정보를 AI가 다 가져가는 거 아닌가요?"
```
**유형 D — 강사 권위 도전형**
```plain text
"강사님은 AI 전공하신 거예요?"
"이거 어디서 배우신 내용이에요? 정식 자료 맞아요?"
```
---
### 3-3. 대응 프레임 — 이미 배운 원칙 재정리
```plain text
① 인정 → 재구성 → 답변
   "좋은 질문이에요" (방어하지 않고 인정)
   → 질문의 핵심을 다시 정리 (내가 제대로 이해했는지 확인)
   → 아는 만큼 정직하게 답변

② 모르는 것은 모른다고, 대신 방법을 제시
   "그 부분은 제가 지금 정확히 답하기 어려워요.
    같이 찾아볼까요?" (Perplexity 실시간 검색 활용 — 1회차)

③ 권위 도전형은 방어하지 말고 신뢰 자산으로 전환
   "저도 계속 배우면서 강의해요. 그래서 여러분보다
    한 발 먼저 가서 시행착오를 줄여드리는 역할이에요."

④ 범위 밖 질문은 명확히 선 긋고 대안 제시
   "오늘 다루는 주제는 아니지만, 궁금하시면 강의 후에
    따로 말씀 나눠요" / 투자·자산 관련은 반드시 선을 그음
   (0회차 정직성 원칙 — 투자 권유로 오해될 답변 절대 금지)
```

### 3-4. 실전 훈련 — 역할극
```plain text
진행: 프로님가 위 질문 은행에서 무작위로 질문을 던지고,
      이사님이 그 자리에서 바로 답변합니다.

라운드 1: 예고 없이 질문 5개 (순발력 훈련)
라운드 2: 같은 질문을 다시, 이번엔 대응 프레임을 의식하며
라운드 3: 이사님이 가장 취약하다고 느낀 유형만 집중 반복

피드백 기준:
□ 방어적으로 반응하지 않았는가
□ 모르는 것을 아는 척하지 않았는가
□ 정직성 원칙(투자·수익 암시 금지)을 지켰는가
□ 질문자를 무시하거나 위축시키지 않았는가
```
