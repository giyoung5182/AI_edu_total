# 8장 실습 2 · 설계서(PRD) 작성

정리일: 2026-10-08 · 교육 에셋 N1249

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
오후에 만들 것을 문서 한 장(prd.md)으로 확정합니다. 직접 쓰지 않고 AI의 질문에 답한 뒤 "정리해줘" 한 줄로 문서를 만들게 합니다.
## 진행 단계
1. **STEP 1 유형 고르기 (7분)** — "종이나 칠판으로 하면 안 되나?"를 먼저 묻고, 반응·반복·시각화 중 하나라도 있을 때만 만듭니다. 질문 세 개(가장 헷갈려하는 것 / 활기가 필요한 순간 / 반복 설명)로 ① 개념 체험형 ② 놀이형 ③ 수업 도우미형 중 하나를 고릅니다.
- 정상 결과: 유형 하나 + "학생이 화면에서 무엇을 하는지" 한 문장
2. **STEP 2 작업 폴더 만들기 (3분)** — 새 세션으로 시작해 바탕화면에 class-tool 폴더를 만듭니다.
```javascript
class-tool 이라는 폴더를 새로 만들어주세요.
앞으로 남은 교시는 이 폴더 위에서 작업할 예정입니다.
```
- 정상 결과: 파일 탐색기에서 class-tool 폴더가 보임
[원본 이미지 제외]
3. **STEP 3 AI 인터뷰 (15분)** — \[ \] 안만 본인 것으로 바꿔 입력하고, 여섯 개 질문(무엇을/왜/사용자/화면/완료/애매한 것)에 한 번에 하나씩 답합니다.
```javascript
초등 SW 수업에서 학생들이 직접 써볼 웹 화면을 하나 만들려고 해.

유형: [개념 체험형 / 놀이형 / 수업 도우미형 중 하나]

대략의 생각: [한 문장으로]

바로 만들지 말고, 먼저 나를 인터뷰해서
아래 여섯 가지를 채워줘. 한 번에 하나씩만 물어봐.

1. 무엇을 — 학생이 화면에서 무엇을 하나
2. 왜 — 그걸 하면 뭘 알게 되나
3. 사용자 — 몇 학년이, 언제 쓰나
4. 화면 — 어떤 것들이 화면에 있어야 하나
5. 완료 — 학생이 어떤 상태가 되면 끝난 건가
6. 애매한 것 — 아직 안 정해진 것

지켜야 할 조건이야.
- 결과물은 class-tool 폴더 안에 만든다
- 따로 설치가 필요한 게 있다면 어떤 프로그램인지 미리 이야기하고 설치 계획에 대한 허락을 구한다.
- 초등학생이 보는 화면이다. 글자는 크고 쉬운 말로
- 학생들이 휴대폰으로 볼 화면이다
- 저장이나 로그인 기능이 필요할 시 복잡한 작업 계획이 될 수 있으므로 미리 구체적인 저장 방식이나 구현 방법을 정리해서 준다.

내 답이 너무 크면 줄이라고 말해줘.
여섯 개 다 물어보면 인터뷰를 끝내고 정리해줘.
```
- 정상 결과: 여섯 개에 다 답했고 Claude가 정리해 줌
[원본 이미지 제외]
4. **STEP 4 ****prd.md**** 저장하고 검토 (8분)** — 정리한 내용을 prd.md로 저장시키고 다섯 가지(학생이 하는 일 / 화면 구성 순서 / 완료 조건 / 안 넣을 것 / 저장 위치)를 확인합니다.
```javascript
지금까지 정리한 내용을 class-tool 폴더에
prd.md 파일로 저장해줘.

화면 구성도 같이 넣어줘.
어디에 무엇이 배치되는지 위에서부터 순서대로.

저장한 파일 경로를 알려줘.
```
- 정상 결과: class-tool 폴더에 prd.md가 보이고 열어서 다섯 가지가 다 있음
5. **STEP 5 화면 뼈대 보기 (7분)** — prd.md를 보고 index.html 화면 뼈대만 만들게 해 브라우저에서 열어봅니다. 마음에 안 들면 화면이 아니라 prd.md를 고칩니다.
```javascript
prd.md를 보고 화면 뼈대만 먼저 만들어줘.
class-tool 폴더 안에 index.html 파일 하나로.

기능은 아직 안 넣어도 돼.
어디에 무엇이 있는지 배치만 보고 싶어.

만들면 파일 경로를 알려줘. 내가 직접 열어볼게.
```
- 정상 결과: 브라우저에서 화면이 뜨고 대략 원하던 배치
[원본 이미지 제외]
6. **STEP 6 오후 준비 확인 (3분)** — class-tool 폴더, prd.md(여섯 항목+화면 구성+완료 조건), 넣지 않을 것, 화면 뼈대, 폴더 위치, 노트북 충전기 연결을 점검합니다.
## 막히는 지점
- 교시마다 새 세션으로 시작 / 인터뷰는 한 바퀴만 / 같은 걸 세 번 이상 고치지 않기 (사용량 절약 안내)
- 답이 잘 안 나오면 "잘 모르겠어. 보통 어떻게들 하는지 예시를 두세 개 보여줘."라고 요청
- 완료 조건이 막연하면 "무엇을 눌렀을 때 무엇이 보이면 끝"인지 분명히 적어 달라고 요청
