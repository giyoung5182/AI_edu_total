# 실습 :: 지금 한 번 써봅니다 (15분)

정리일: 2026-10-08 · 교육 에셋 N0337

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
작은 화면 하나를 만들며 지시 유형을 써 보고, AI가 말하지 않은 것을 알아서 정한다는 점을 확인합니다.
## 진행 단계
1. **고르기** — 게임/가계부/여행 계획 중에서. 조건: 넣는 값 세 개 이하, 화면 하나, 설명 없이도 무엇인지 아는 것.
2. **뼈대 세우기**
- 입력할 내용: `[ 할 일 ] (고른 것)을 단일 html 파일로 만들어줘. [ 화면 ] 입력하는 곳과 결과가 보이는 곳, 두 영역만. [ 하면 안 되는 것 ] 요청하지 않은 기능을 추가하지 않는다 / 외부에서 불러오는 것을 쓰지 않는다. 아직 기능은 넣지 마. 화면만 먼저 보고 싶어.`
3. **다듬기** — 기능 하나만. 예: "숫자를 입력하면 정답인지 알려주는 기능을 넣어줘. 다른 부분은 그대로 두고."
4. **진단하기** — ❌ "코드를 다시 짜줘" / ✅ "합계가 3만원이어야 하는데 30만원으로 나옵니다."
5. **되짚기** — 입력값 범위, 끝나는 조건, 결과 형태, 잘못된 값·빈 값 처리 등 AI가 알아서 정한 것을 찾습니다.
