# 실습 시나리오 B: 경영진 주간 보고 웹앱 (완성 예시에 샘플 값 입력)

정리일: 2026-10-08 · 교육 에셋 N1501

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
핵심 데이터를 입력하면 리더 보고용 주간 보고서가 자동 생성되는 완성 예시 웹앱에 샘플 값을 직접 넣어 본다.
## 진행 단계
1. **예시 웹앱 다운로드** — 교안에 첨부된 완성 예시 웹앱(HTML)을 내려받는다.
2. **샘플 값 입력** — 교안의 주간 보고 샘플 데이터(주요 이슈 3개와 영향도, 공정률, 무재해 일수, 안전점검 이행률, 예산집행률)를 직접 입력한다.
3. **결과 확인** — 값을 넣으면 보고서가 즉시 바뀐다.
- 참고: 이 결과물을 만든 PRD 프롬프트는 입력폼 → 보고서 자동생성 구조로 지시한다(교안 참고).
