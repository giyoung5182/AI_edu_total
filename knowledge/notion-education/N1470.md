# Step 04 :: 프로젝트에 작업 폴더를 연결합니다.

정리일: 2026-10-08 · 교육 에셋 N1470

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
project 폴더를 프로젝트에 연결해 파일을 읽고, 결과 파일을 폴더에 저장해 봅니다.
## 진행 단계
1. **폴더를 연결한 프로젝트 만들기** — 왼쪽 `프로젝트` 섹션의 `+`를 누르고, 좌측 하단 `폴더 사용`을 클릭해 바탕화면의 project 폴더를 선택합니다. 폴더 접근 확인 창이 나오면 연결을 허용합니다.
2. **이름 입력** — `이름` 칸에 붙여넣습니다.
```javascript
내업무-실습
```
- 정상 결과: 컨텍스트에 project 폴더가 생깁니다.
3. **Cowork로 요청** — `Cowork` 상태로 아래 프롬프트를 작성합니다. 경고창이 뜨면 이번 작업의 폴더 접근을 허용합니다.
```javascript
- 2-1_교육용안내.pdf
- 2-2_팀운영규칙.docx
- 2-3_지난분기보고.docx
위 자료 3개를 한 장으로 정리한 문서를 만들어서, project 폴더에 2-9_자료정리.docx 로 저장해줘
```
4. **저장 확인** — 바탕화면의 project 폴더를 열어 `2-9_자료정리.docx`가 있는지, 내용이 들어 있는지 눈으로 확인합니다.
## 막히는 지점
- 결과물이 만들어질 때마다 실제 파일이 폴더에 저장됐는지 직접 확인합니다.
- '저장했다'는데 폴더에 파일이 없으면 폴더 주소창의 경로를 복사해 붙여넣어 저장 위치를 다시 지정합니다.
- 앱에서도 project 폴더를 못 찾으면 폴더 이름(영문 소문자 project)을 확인합니다.
