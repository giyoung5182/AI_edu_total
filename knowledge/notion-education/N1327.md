# 보너스 실습 ChatGPT 데이터 분석 + 시각화

정리일: 2026-10-08 · 교육 에셋 N1327

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
가상 더미 데이터를 ChatGPT에 붙여넣어 기초 분석, 시각화 분석, 보고서 초안까지 만든다.
## 진행 단계
1. **데이터 인식 + 기초 분석 (5분)** — ChatGPT 새 채팅(임시 채팅 권장)에 프롬프트와 더미 데이터를 붙여넣는다.
- 입력할 내용: 전체 데이터 구조 설명, 달성률 100% 이상/80% 미만 목록, 전년 대비 성장 TOP 3·감소 BOTTOM 3을 요청하고 계산 방법을 설명하게 한다.
2. **시각화 분석 요청 (5분)** — 지원유형별 분석 표, 시군별 순위 표, 달성률 현황 분류, 효과적인 차트 3종 추천, 핵심 인사이트 3가지를 요청한다. 제공된 데이터 안에서만 분석하도록 제약한다.
3. **검증 + 보고서 초안 생성 (5분)** — 총 신청기업 수 합계, 달성률 80% 미만 목록, 이상한 수치를 직접 확인한 뒤, 이상 없으면 공문서 스타일 A4 1장 보고서 초안을 요청한다(가상 데이터 기반임을 상단에 명시).
