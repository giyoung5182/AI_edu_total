# 프롬프트를 바꾸면 음악이 어떻게 달라질까

정리일: 2026-10-08 · 교육 에셋 N0669

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
프롬프트의 한 부분씩만 바꿔 넣으며 음악이 어떻게 달라지는지 직접 들어 본다.
## 진행 단계
1. **예시 1. 분위기 바꾸기 (차분함 → 활기참)** — \[분위기/톤\]을 밝고 경쾌하며 활기찬 분위기로, \[배경/환경\]을 도심에서 활동적으로 움직이는 겨울 장면으로 변경해 입력
2. **예시 2. 악기·편성 바꾸기 (피아노 중심 → 현악기 중심)** — \[분위기/톤\] 고급스럽고 웅장함, \[악기\] 현악기(스트링) 중심·피아노 보조, 가사 없이 연주곡
3. **예시 3. 용도 바꾸기 (브랜드 필름 → 짧은 SNS 영상)** — 15초 SNS 숏폼 영상용, 도입 2초 안에 분위기가 잡히게
- 입력할 내용: 교안의 예시 1\~3 프롬프트 (각 프롬프트는 교안 참고)
4. **비교** — 입력한 설명이 결과를 좌우함을 들어서 확인
