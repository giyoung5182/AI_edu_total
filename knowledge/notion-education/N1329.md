# Step 01~03 :: 명세 네 칸 채우기와 명세서 저장

정리일: 2026-10-08 · 교육 에셋 N1329

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
어제 고른 과제를 오늘 만들 수 있는 크기로 좁혀 네 칸짜리 명세(02_명세서.md)로 확정한다.
## 진행 단계
1. **어제 적은 것 꺼내기** — 1-1_업무목록.xlsx의 1_주제정하기 시트 STEP 1\~9를 명세 칸으로 옮겨 적는다.
2. **만들 값어치 판단** — ① 지금 손으로 하고 있다 ② 규칙이 글로 적힌다 ③ 화면 하나로 끝난다를 모두 만족하는 것을 고른다. 도구 유형은 하나만 고른다.
3. **범위 좁히기** — 기능을 하나로 / 대상을 좁게 / 화면을 하나로. 범위 확인 4항목(화면 하나, 핵심 기능 2개 이하, 30분 안에 설명, 내일 써볼 수 있음).
4. **명세 네 칸 채우기** — 목적 / 입력 / 출력 / 제약. 막히면 AI가 되묻게 한다.
- 입력할 내용:
```javascript
나는 아래 도구를 만들려고 한다.
요구사항 명세를 함께 완성해 달라.

[ 만들고 싶은 것 ]
(두세 문장으로 자유롭게)

요청이야.
1) 목적 · 입력 · 출력 · 제약 네 요소 중 빠진 것을 물어라.
2) 특히 제약에서 아래를 반드시 확인하라.
   - 값이 비었을 때 어떻게 하는가
   - 잘못된 값이 들어왔을 때 어떻게 하는가
3) 한 번에 하나씩만 물어라.
4) 내가 답하면 네 칸을 채운 표로 정리하라.
5) 내가 말하지 않은 조건을 넣지 마라.
6) 아직 코드는 작성하지 마라.
```
1. **명세서 저장** — 정리한 내용을 coding 폴더에 02_명세서.md로 저장하게 한다.
- 입력할 내용: "지금까지 정리한 내용을 coding 폴더에 02_명세서.md 로 저장해줘. 목적 · 입력 · 출력 · 제약 네 칸으로 정리하고, 저장한 파일 경로를 알려줘."
- 정상 결과: 파일 탐색기에서 coding 폴더에 02_명세서.md가 보인다
## 막히는 지점
- 제약 칸이 가장 자주 비므로 빈 값·잘못된 값 처리를 반드시 적는다.
- AI가 명세 도중 코드를 만들면 '아직 코드는 작성하지 마라'를 다시 넣는다.
