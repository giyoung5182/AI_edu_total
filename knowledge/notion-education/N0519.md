## 이 실습으로 하는 것
지점별 시트 10개를 하나의 "통합" 시트로 합치고, 이어서 서식까지 자동 적용합니다.
## 진행 단계
1. **문제1 프롬프트 설계와 실행** — 5요소 프롬프트를 먼저 직접 작성한 뒤 예시 버전과 비교, 통합 시트 새로 만들기·세로로 이어 붙이기·F열에 시트 이름 추가·통합 시트 자체 제외·실행마다 초기화
- 정상 결과: 통합 시트 = 머리글 1행 + 데이터 500행(10지점 × 50행), F열에 지점명
2. **문제2 두 매크로 연결** — 지점취합 직후 1행 굵게+회색 배경, 전체 테두리, 열 너비 자동 서식이 이어서 실행되게 요청
- 정상 결과: 실행 한 번에 취합 + 서식이 동시에 완료
3. **도구 선택 기준 확인** — 폴더에 파일 여러 개는 파워쿼리 폴더 병합, 한 파일 안 시트 여러 개와 병합 후 서식·저장·인쇄는 VBA
