# 3단계 · 검증 (10분)

정리일: 2026-10-08 · 교육 에셋 N1452

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
조사 결과 전부가 아니라 제안서에 실제로 들어갈 수치와 인용문(보통 3\~5개)만 골라 링크 → 내용 → 수치 → 시점 네 단계로 검증합니다.
## 진행 단계
1. **넣을 수치·인용문을 고른다** — 제안서에 실제로 들어갈 것만 3\~5개.
2. **출처 인용 요청**
- 입력할 내용:
```javascript
이 결과의 수치와 인용문을 모두 목록으로 뽑아 주세요.
각각 어느 출처의 어느 대목에서 나왔는지 인용해 주세요.
인용할 수 없는 항목은 그렇다고 표시해 주세요.
```
3. **인용하지 못하는 항목을 지운다**
4. **추측으로 표시된 조직 서술을 걸러 낸다**
## 막히는 지점
- 조직 조사는 틀리면 제안을 받는 당사자가 바로 알아봅니다. 추측 표시 항목은 제안서에 넣지 마세요.
- 자료가 부족할 때: 너무 일반론이면 대상을 좁히기 / 자료가 거의 없으면 범위를 넓히기 / 출처가 다 광고면 제외 조건 강화 / 조직 자료가 안 나오면 채널 주소를 직접 주기 / 결과가 얕으면 Skills의 심층 문헌 검토 사용.
