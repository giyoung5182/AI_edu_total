# 모델 vs 도구 — 같은 출장 1건으로 세 가지 요청해보기(P1-2)

정리일: 2026-10-08 · 교육 에셋 N0697

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
같은 출장 1건으로 문장 쓰기·합계 계산·외부 정책 확인을 요청해, 무엇이 모델의 생성이고 무엇이 도구의 결과인지 직접 관찰합니다.
## 진행 단계
1. **먼저 예측** — 워크시트 P1-2 예측 칸: 그대로 믿기 가장 어려운 요청은? 합계를 물으면 코드를 쓸까, 문장으로 답할까?
2. **요청 A: 문장 쓰기** — 새 채팅에서 \[자료\] 출장 1건(출장지·날짜·항공료·숙박비·일비)을 넣고 안내 2문장 요청
- 입력할 내용: 교안의 \[자료\] 블록 + "위 출장 건을 고객사 출장 담당자에게 안내하는 2문장을 써줘. 금액은 위 자료에 있는 값만 쓰고, 합계는 쓰지 마." (이하 교안 참고)
- 정상 결과: 2문장 안팎, \[자료\] 값만 사용
3. **요청 B-1: 계산을 문장으로** — 같은 채팅에 이어서
- 입력할 내용:
```plain text
[요청 B-1]
위 출장 건의 정산 합계를 원 단위로 알려줘.
합계 = 항공료 + (숙박비 1박당 × 숙박일수) + (일비 × 일비 일수)
일비 일수는 출발일과 도착일을 각각 1일로 센다.
답은 숫자 한 줄로만 줘.
```
- 정상 결과: 합계 숫자 한 줄. 계산 도구 사용 표시가 있는지 확인
1. **요청 B-2: 계산을 도구로**
- 입력할 내용:
```plain text
[요청 B-2]
같은 합계를 이번에는 코드로 계산해줘.
① 항목별 금액(항공료, 숙박비 합계, 일비 합계)
② 일비 일수를 어떻게 셌는지
③ 최종 합계
를 순서대로 보여주고, 사용한 코드도 함께 보여줘.
```
- 정상 결과: 항목별 금액 3줄 + 일비 일수 설명 + 최종 합계 + 코드 블록
1. **직접 검산** — 계산기나 엑셀로 항목별 금액 계산(예: `=169548*4`) 후 P1-2 본인 검산 칸에 B-1·B-2 답의 값, 일치 여부 기록
2. **요청 C: 외부 정책 확인**
- 입력할 내용:
```plain text
[요청 C]
인천–오사카 왕복 이코노미 항공권을 출발 전에 날짜 변경할 때
항공사 변경 수수료가 현재 얼마인지 알려줘.
어디에서 확인한 정보인지 출처와 기준일을 함께 적어줘.
```
- 정상 결과: 출처 링크·기준일이 붙은 안내 또는 "확인할 수 없다"는 답
1. **관찰·판정** — 관찰표(모델이 만든 부분 / 도구 흔적 / 확인 방법)를 채우고 근거 확인·불일치·보류 등으로 판정
## 막히는 지점
- B-2에 코드 없이 풀이만 나오면: "방금 계산을 실제로 코드로 실행했는지 알려줘…"로 재요청
- A에 자료에 없는 조건이 들어가면 해당 문장만 삭제 요청
- B-2 일비 일수가 규정(제15조)과 다르면 기준을 알려 주고 일비만 다시 계산
- C에 출처가 없으면 출처·확인 날짜 없는 정보는 쓰지 말고 "확인 불가"로 답하게 함
