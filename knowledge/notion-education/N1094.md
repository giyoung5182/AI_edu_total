# 데모 1: 엑셀 데이터 인사이트 자동 도출

정리일: 2026-10-08 · 교육 에셋 N1094

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
엑셀 데이터를 붙여넣고 3단계 프롬프트로 현황·패턴·인사이트를 도출합니다.
## 진행 단계
1. **데이터 구조 설명** — 열별로 설명합니다.
2. **1\~3단계 분석** — 현황 파악(데이터 품질 문제 보고) → 핵심 수치·패턴 → 실무 인사이트·권고 사항 2가지
- 입력할 내용: "아래 데이터를 분석해줘. 분석 전에 데이터 구조를 먼저 파악하고 확인해줘." (단계별 프롬프트, 교안 참고)
## 막히는 지점
- 대용량(수천 행 이상)은 샘플링 후 분석.
