# 문제1: 전체 데이터 규모 확인하기

정리일: 2026-10-08 · 교육 에셋 N1189

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
KDHC 테이블의 전체 행 수, 기준일자 종류 수, 최초·최신 기준일자를 조회합니다.
## 진행 단계
1. **데이터 올리기** — 공공데이터포털(data.go.kr/data/3070430/fileData.do)에서에서) 받은 csv 파일명을 kdhc로 변경해 DBeaver에 업로드합니다.
2. **쿼리 작성** — 문제를 풀고 정답화면(84 / 3 / 2022-10-01 / 2023-07-01)과 비교합니다.
```sql
SELECT
    COUNT(*) AS 전체_행수,
    COUNT(DISTINCT `기준일자`) AS 기준일자_종류수,
    MIN(`기준일자`) AS 최초_기준일자,
    MAX(`기준일자`) AS 최신_기준일자
FROM KDHC;
```
