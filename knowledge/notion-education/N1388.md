# Step 3. 제안서 PPT 만들기 (A 나를 파는 / B 브랜드 / C 기업 콘텐츠 기획)

정리일: 2026-10-08 · 교육 에셋 N1388

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
변환한 재료로 방향(A·B·C)에 맞는 7장짜리 발표용 제안서 슬라이드를 AI로 만들고 다듬습니다.
## 진행 단계
1. **팔레트 고르기 (Step 2)** — Steel Blue / Amber Ink / Mint Dark Green / Violet Depth / Warm Slate 중 내 WHY 분위기에 맞는 하나를 골라 이름을 Step 3 프롬프트에 그대로 넣습니다.
2. **방향에 맞는 프롬프트 복사** — 3-A 나를 파는 제안서(취업·프리랜서), 3-B 브랜드 제안서(창업·브랜드), 3-C 기업 콘텐츠 기획 제안서(특정 기업 취업·공모전) 중 하나를 선택합니다.
```javascript
(3-A 예) 당신은 취업 포트폴리오 슬라이드 전문 디자이너입니다.
아래 정보로 "나를 파는 제안서" 7장짜리 발표용 슬라이드를 만들어주세요.
- 팔레트: [Steel Blue / Amber Ink / Warm Slate 중 선택]
- 16:9 고정, 한글 산세리프, AI 스톡 사진 금지, 슬라이드당 텍스트 5줄 이하
- 7장: 표지 / 나는 누구인가 / 나의 포지션 / 핵심 역량 3가지 / 대표 프로젝트 / 나와 함께하면 / 클로징
(각 슬라이드별 세부 구성과 내 정보 입력칸은 교안 참고)
```
3. **내 정보 입력** — WHY 선언문(Step 1 변환본), 경험 3개, 기질 TOP 3·절대가치·희망 직무 또는 브랜드·기업 정보, 포트폴리오 URL을 채웁니다.
4. **수정 요청** — 사용할 수 있는 수정 프롬프트 예:
```javascript
헤드라인을 더 짧게, 20자 이내로 줄여줘
```
```javascript
AI 냄새 나는 표현 제거해줘. "다양한, 열정적인, 혁신적인" 같은 단어 없애고 구체적 행동으로 바꿔줘
```
5. **셀프 체크리스트** — WHY 선언문 포함 여부, 헤드라인이 결론인지, 경험 숫자 2개 이상, 식상한 표현 없음, 마지막 슬라이드 URL 연결, 5분 발표 분량을 확인합니다.
## 막히는 지점
- 자주 하는 실수 TOP 5: WHY를 마지막 슬라이드에만 넣기 / "저는 기획자입니다" 헤드라인 / STAR 경험에 숫자 없음 / AI 생성 텍스트 그대로 사용 / 슬라이드 한 장에 텍스트 과다
