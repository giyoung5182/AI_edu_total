# 실습 3. 프로젝트에 지침 v1.0 넣고 문의 2개 써 보기

정리일: 2026-10-08 · 교육 에셋 N0452

본문 수집·공개 편집. 도구 실행·최신 기능 재검증은 미실시. 고객·참여자 정보와 개별 접근 링크, 원본 첨부는 제외했습니다.

---

## 이 실습으로 하는 것
지침 v1.0과 규정 파일 2개를 ChatGPT 프로젝트 하나에 묶고, 실제 문의 2개로 지침이 지켜지는지 확인합니다.
## 진행 단계
1. **프로젝트 만들기** — 사이드바 프로젝트 제목 위에 마우스 → + (New project) → 이름 `출장규정 문의 도우미` → 기본 메모리 클릭 → 프로젝트 전용 메모리 선택 → 프로젝트 만들기
- 프로젝트 전용 메모리를 쓰면 다른 개인 대화가 규정 답변에 섞이지 않음(이 프로젝트에서는 Work 사용 불가).
2. **지침·소스 넣기** — 제목 오른쪽 ⋯ → 프로젝트 설정 → 지침 칸에 지침 v1.0 붙여넣기 → 저장 → 입력창 위 소스 탭 → 소스 추가로 규정 파일 2개 선택
3. **문의 2개 써 보기** — 사이드바에서 프로젝트를 클릭해 프로젝트 화면 입력창에 문의 1 입력, 다시 프로젝트를 클릭해 새 대화에서 문의 2 입력
- 입력할 내용: `도쿄로 3박 4일 출장을 가. 항공은 프리미엄이코노미로 끊어도 돼? 그리고 일비는 총 얼마 받아?`
- 입력할 내용: `출발 3일 전에 출장을 취소하면 수수료가 몇 %야?`
- 정상 결과: 답이 지침의 응답 양식 ①\~④ 모양이고 근거에 문서번호·조항이 있음. 다르면 지침 해당 칸을 고쳐 다시 저장
## 막히는 지점
- 소스 추가 오류 시 파일을 한 개씩 올립니다.
- 사이드바의 일반 새 채팅은 프로젝트 밖이므로 사용하지 않습니다.
- 기본 메모리로 만들었다면 ⋯ → 프로젝트 설정 → 메모리에서 변경 후 저장합니다.
