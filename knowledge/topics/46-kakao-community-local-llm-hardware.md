### 중국계 저가 모델(Kimi K3·DeepSeek V4.1 Flash·GLM-5.3 Flash)은 가격 경쟁력 있으나 기업 사용 제약과 전용 하네스 의존 존재

DeepSeek 공지(2026-09-10): V4.1-Flash는 552B MoE(활성 8B/16B), API ID deepseek-flash, 비혼잡 시간 50% 요금, 가중치 Hugging Face 공개. Z.ai 문서: GLM-5.3-Flash는 총 320B·활성 18B, 1M 컨텍스트, GLM-5 계열 첫 네이티브 멀티모달. 기업 사용 제약·하네스 의존·순위 변동은 커뮤니티 경험.

- Google 공식 문서: Gemma 4는 오픈 웨이트 모델로 책임 있는 상업적 사용 허용, 라이선스 Apache 2.0
- 크기: 엣지·모바일용 2B·4B(유효 파라미터), 31B dense, 26B MoE, 12B 멀티모달 등
- 텍스트·이미지·영상·오디오 입력(모델별 지원 상이), 컨텍스트는 소형(E2B·E4B) 128K·중형 이상 최대 256K, Kaggle·Hugging Face에서 배포
- supergemma4는 공식 Google 모델이 아닌 파생 버전으로, 원본 정리 시 확인에서 출처·라이선스를 공식 확인하지 못함

### DGX Spark(128GB·273GB/s)와 Mac Studio M5 Max(최대 128GB·614GB/s): 대역폭은 맥 우위, CUDA 생태계는 Spark

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

NVIDIA 공식 사양: DGX Spark는 GB10 Grace Blackwell, 128GB LPDDR5x 통합 메모리, 메모리 대역폭 273GB/s, FP4 최대 1 PFLOPS, 최대 200B 파라미터 모델 로컬 작업 가능. Apple 공식 사양: Mac Studio M5 Max는 36GB 기본·최대 128GB, 대역폭 460GB/s(40코어 GPU 구성 614GB/s), M5 Ultra는 최대 512GB·1.2TB/s, 미국 시작가 M5 Max $2,499·M5 Ultra $5,499(2026-09-22 출시). NVIDIA 개발자 포럼에서 2026-02-23 가격 변경 공지가 언급되고 마켓플레이스 가격 $4,699가 거론됨(인상 사유는 NVIDIA가 설명하지 않았고 메모리 공급 제약은 이용자 추정). 조회 시점 NVIDIA 마켓플레이스는 품절 표시. '프리필은 Spark가 유리'라는 주장은 공식 벤치마크로 확인하지 않음.

**활용할 때 확인할 점**

구매 상담 시 '생성 속도는 메모리 대역폭, 긴 프롬프트 처리는 연산 성능, 개발 도구는 CUDA 호환성'으로 기준을 나눠 제시. 가격·재고는 수시 변동이므로 공식 판매처에서 재확인.

### 로컬 LLM은 메모리 용량이 모델 크기를 결정: 64GB로는 70B급이 한계, Kimi K3급(2.8T)은 개인 장비 범위 밖

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

- Ollama 공식 모델 페이지 기준 7B 모델은 최소 8GB, 13B는 16GB, 70B는 64GB RAM이 일반적으로 필요. Kimi K3 공식 모델 카드는 총 2.8T 파라미터(활성 104B)·MXFP4 가중치로, 4비트 기준으로도 가중치만 약 1.4TB로 계산돼 Mac Studio 최대 512GB 구성도 넘어섬(단순 산술, 공식 요구사양은 미기재). 64GB 장비는 70B급 양자화 모델이 상한선에 가까움. 클라우드 프런티어 모델과 동등한 품질을 로컬에서 낸다는 공식 근거는 없음.
- [추가 2026-07-30] Ollama 공식 블로그는 Kimi K3를 2.8조 파라미터 모델로 소개. 커뮤니티: M1 맥북 64GB에서 양자화판으로 분당 약 4토큰 출력 사례(정상 사용 불가 수준), 1bit 양자화판도 수백 GB, exo 분산추론은 버그·비전 미지원으로 포기 → LLM은 아직 클라우드가 유리하고 TTS·OCR·임베딩 등 특화 모델은 로컬로 쓸 만하다는 결론
- [추가 2026-06-03] 커뮤니티 경험(공식 확인 아님): 로컬 모델은 요약·RAG 검색 용도는 쓸 만하나 긴 컨텍스트·추론·코드가 많은 에이전트 작업(OpenClaw류)은 어렵다는 의견 다수, 구매 전 OpenRouter 등으로 같은 오픈 모델을 API로 먼저 시험해 용도 적합성 확인, 목돈 대신 RunPod 등 GPU 임차 대안 언급
- [추가 2026-10-02] 128GB M5 Max에서 122B 로컬 모델은 겨우 구동, 프런티어 모델 세션 20~30개는 무난하다는 사례. Kimi K3급은 포기하고 Qwen 외 현실적 대안이 없어 구독 증설로 선회. Codex 에이전트 10개 이상 동시 실행 시 RAM 32GB에서 다운됐다는 보고

**활용할 때 확인할 점**

로컬 LLM 교육 시 '보안상 외부 전송 불가 업무용 소형 모델'과 '클라우드 프런티어 모델'의 용도를 구분. 장비 선정은 쓰려는 모델 크기에서 역산하도록 안내.

### 클라우드 AI 에이전트·API 생성 작업은 GPU 사양 거의 무관, RAM·CPU가 병렬 작업 체감 결정

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Claude Code 공식 시스템 요구사항은 4GB 이상 RAM, x64 또는 ARM64 프로세서, 인터넷 연결이며 GPU 요구사항은 없음. Claude Desktop은 macOS 11·Windows 10 이상, Linux의 Cowork 작업공간은 여유 디스크 약 25GB와 RAM 8GB 이상을 요구. API로 호출하는 이미지·영상 생성은 제공사 서버에서 연산되므로 로컬 GPU가 쓰이지 않음. 병렬 에이전트·브라우저 다중 실행 시 16~32GB 권장은 커뮤니티 체감이며 공식 권장값은 아님. 맥 모니터 관련 답은 사용 경험.
- [추가 2026-09-11] 9/11 커뮤니티: 원격 지시로 computer use를 돌리는 홈서버 용도면 결과물은 프로세서와 무관하고 차이는 OS 최적화·속도·전력, Mac 안에서는 애플 실리콘이 인텔맥보다 효율 우위라는 의견(체감).

**활용할 때 확인할 점**

비개발자 수강생 장비 안내 시 '로컬 모델을 돌리지 않으면 GPU 투자 불필요, RAM 우선'으로 정리. 최소 사양(공식)과 쾌적 사양(체감)을 구분해 제시.
