## 실제 학습 내용

### JetBrains 설문(2026년 5~7월) — Claude Code 업무 사용률 39%로 1위, Copilot 21%로 하락, Codex 16%로 급증

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- JetBrains 공식 블로그: 전 세계 전문 개발자 15,000명 이상 대상, 2026년 5~7월 기준 Claude Code 업무 사용률 약 39%(2026년 1월 18%), 미국 47%
- Claude Code를 '가장 많이 쓰는 도구'로 꼽은 비율 31%로 약 80% 전환율
- GitHub Copilot 21%(1년 전 29%), 인지도 79%
- Codex 사용률 3%(2026년 1월)→16%, 인지도 27%→65%
- 멘로벤처스 54% 점유율, 체르니 인터뷰 내용은 원본 정리 시 확인에서 원문 대조 안 함

**활용할 때 확인할 점**

- AI 코딩 도구 시장 점유 변화가 반년 단위로 크게 움직인다는 사례로 활용
- 도구 선택 교육은 특정 도구 고정보다 '위임·감독' 작업 방식 전환에 초점

### 코그니션(Devin) 연환산 매출 10억 달러 돌파 보도 — '작업 위임형' 코딩 에이전트의 성장과 래퍼 리스크

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- 블룸버그(2026-09-25) 보도: 2026년 9월 실적 기준 연환산 매출 10억 달러, 5월 4억 9,200만 달러에서 약 두 배. 이달 20억 달러 투자로 기업가치 480억 달러(3개월 전 260억 달러, 야후파이낸스 전재 기준)
- 코그니션 공식 블로그로 확인된 최신 수치는 2025-09-08 발표(4억 달러 이상 투자, 기업가치 102억 달러, Devin ARR 2024년 9월 100만 달러→2025년 6월 7,300만 달러)까지이며 2026년 수치는 공식 발표로 확인 못함

**활용할 때 확인할 점**

- 코딩 AI를 '보조형(Cursor)'과 '위임형(Devin)'으로 구분해 설명
- 위임형은 권한·배포 통제 설계가 필수라는 거버넌스 포인트와 연결

### '계획은 AI와 함께, 코딩은 직접' — AI 결과물은 자체 검토가 끝난 뒤에 사람이 읽는 작업 원칙

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 해커뉴스 원글·점수(323점·댓글 330개)는 원본 정리 시 확인에서 원문을 찾지 못해 기자 요약 기준
- 실무 원칙 요지: ①결정권 유지 ②AI 조사에 출처 요구·사람 병행 조사 ③근거 되묻기 ④AI 자체 검토 후 사람 검토 ⑤한도 소진 대비 수작업 목록

**활용할 때 확인할 점**

- AI 활용 교육에서 '자체 검토 → 사람 검토' 2단계 검수 흐름을 실습 규칙으로
- 핵심 역량 퇴화 우려는 '통제권 유지' 관점으로 설명

### 중국 순수 AI 드라마 '후서유기' 시청률 1위 보도 — 60여 명 AI 조직('뽑기사')과 사람이 쓴 각본

원본 상태: 미확인 · 원본 확인일: 2026-09-29

- 국내 언론 다수(뉴스핌 2026-09-03 등)가 AI 장편드라마의 위성TV 시청률 1위를 보도했으나 방송사·제작사 공식 자료는 확인 못함
- 인력 구성·프롬프트 길이 등 세부는 매체 보도 기준

**활용할 때 확인할 점**

- 생성 AI 영상 제작에서도 기획·각본·감정 논리는 사람이 통제한다는 사례
- '반복 생성 후 선별'이 새 직무로 자리 잡는 흐름을 직무 변화 교육에 활용

### AI가 VC 심사역을 온전히 대체하기 어려운 이유 — 분석이 아니라 좋은 딜이 도달하는 경로가 사람 네트워크

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 매체 칼럼 논지로 사실 검증 대상이 아닌 관점
- 시사점: 직무 대체 여부는 '분석 업무'보다 '입력(딜·정보)이 들어오는 경로'를 누가 쥐고 있는지로 판단

**활용할 때 확인할 점**

- 직무별 AI 대체 가능성 토론 시 '업무 입력 경로·신뢰 관계' 축을 추가
- AI 도입 효과를 분석 자동화와 소싱(관계) 영역으로 나눠 설명
