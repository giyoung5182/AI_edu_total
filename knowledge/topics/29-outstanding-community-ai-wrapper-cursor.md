## 실제 학습 내용

### Claude Code와 Cursor는 경쟁보다 영역이 다른 제품이라는 개발자 시각

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 커뮤니티 의견: Claude Code(터미널·에이전트 중심)와 Cursor(IDE 중심)는 사용 방식이 달라 단순 대결 구도로 보기 어렵다는 시각
- 참고: xAI 공식 발표상 Grok Bot이 Cursor Pro·Teams 요금제에 포함되는 등 도구 간 결합도 진행 중
- 두 제품 비교 사실관계는 기존 지식베이스(outstanding-community-claude-vs-cursor)에 정리됨

**활용할 때 확인할 점**

- 도구 비교 강의에서 '대체재'가 아닌 '작업 방식별 선택' 프레임으로 설명

### 바이브코딩·블로그 애드센스 수익은 코딩보다 사업·유통이 좌우, 애드센스 배분율은 80%(광고주 플랫폼 수수료 후)

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Google AdSense 공식 도움말: 콘텐츠 광고 수익은 광고주 플랫폼 수수료를 뗀 뒤 게시자에게 80% 배분(Google Ads 광고주 기준 약 68%)이며, 배분율만으로 판단하면 오해의 소지가 있고 사이트 총수익을 보라고 안내. 특정 시간 투입 대비 수익을 보장하는 공식 수치는 없음. 앱·사이트 수익 사례와 '사업 역량이 더 중요'라는 판단은 커뮤니티 경험.
- [추가 2026-09-28] 9/28 커뮤니티: 만드는 건 누구나 쉬운 시대라 끝판왕은 마케팅(개인 유튜브·인스타·블로그 + 유료 광고), 콘텐츠 범람으로 더 어렵다는 경험, 앱테스터 품앗이 카페 언급.

**활용할 때 확인할 점**

비개발자 대상 바이브코딩 교육에서 '만들 수 있음'과 '돈이 됨'을 분리해 기대치 관리. 수익 과장 광고 식별 사례로 활용.

### AI Wrapper 대표 사례 Cursor — 공식 발표는 2025-11 ARR 10억 달러, '20억 달러'는 2026년 보도치

원본 상태: 정정 · 원본 확인일: 2026-09-29

- Cursor 공식 블로그(Series D, 2025-11-13): 23억 달러 조달, 기업가치 293억 달러, ARR 10억 달러 돌파, 자체 모델이 대부분의 LLM보다 많은 코드를 생성한다고 언급
- ARR 20억 달러는 2026년 언론 보도치(공식 블로그 미확인)
- 2026-08-14 공식 블로그: 'Cursor is now a part of SpaceX'

**활용할 때 확인할 점**

자체 LLM 없이 워크플로우 특화로 성장한 사례로 인용하되 수치는 시점·출처 명시

**정정과 한계**

'2025년 ARR 20억 달러'는 공식 수치와 불일치 — 공식 확인치는 2025-11 기준 10억 달러, 20억 달러는 2026년 보도 기준. 또한 Cursor는 자체 모델도 운용해 순수 Wrapper로만 보기 어려움

### Wrapper 모델의 리스크 — 낮은 진입장벽·모델사 종속·모델사의 직접 진출

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 업계 일반론으로 특정 수치 검증 대상 아님
- 참고: Cursor는 자체 모델 개발로 종속 완화를 시도(공식 블로그 언급)
- [추가 2026-08-27] 커뮤니티가 모은 AI 시대 IT 기업 해자 후보: 법적 사업 자격, 고객 접점·유통망, 보안·지속적 버전관리, 실제 사람·폐쇄 루프의 비공개 데이터, 네트워크 효과, 빅테크가 관심 없을 만큼 좁은 TAM, 압도적 토큰 효율·속도, 다양한 고객 사례 기반 의사결정

**활용할 때 확인할 점**

AI 서비스 기획 교육에서 '차별화 요소(데이터·워크플로우·자체 모델)' 논의 출발점

### Cursor Auto는 무제한이 아님 — 플랜 사용량 풀에서 라우팅된 모델 단가로 차감, 초과분은 on-demand를 켰을 때만 과금

원본 상태: 정정 · 원본 확인일: 2026-09-29

- Cursor 공식(2026-09 조회): Auto는 무제한이 아니라 플랜 사용량 풀에서 차감되며 요청마다 라우팅된 모델의 정가로 청구
- 한도에 도달하면 에디터 알림 후 on-demand(종량) 사용을 켜거나 상위 플랜으로 업그레이드, on-demand 과금은 해당 기능을 켰을 때만 적용
- Auto가 어떤 모델을 쓰는지는 문서에 구체적으로 공개되지 않음('중국산 모델'은 미확인)
- 2026-07 당시의 Auto 정책과 --classic 옵션은 이번에 확인하지 못함

**활용할 때 확인할 점**

- IDE 요금제 비교 시 '무제한' 표현을 문서로 재확인하도록 교육
- 추가 결제(on-demand) 설정 여부를 월초 점검 항목에 포함

**정정과 한계**

'Cursor는 Auto로 무한 사용'은 원본 확인일의 공식 문서와 다름 — Auto도 플랜 사용량 풀에서 차감

### '사스포칼립스(SaaS 종말론)' 검증 기사 논지 — 단순 솔루션은 대체, 워크플로우 결합·해자가 있는 SaaS는 버팀

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 매체 기사 논지 요약이며 개별 기업 실적 수치는 확인하지 않음
- 교육적 요지: 'AI가 SaaS를 대체한다'는 주장은 업무 결합도·데이터 축적·전환 비용으로 나눠 봐야 함

**활용할 때 확인할 점**

- 사내 도구 자체 제작(바이브코딩) vs 구독 SaaS 판단 기준으로 '워크플로우 결합도·유지보수 부담' 제시

### Claude Code로 만든 B2B SaaS 공개 피드백 — 랜딩 문구의 추상성·가격 부재가 첫 이탈 요인

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 커뮤니티 피드백 사례
- 교육적 요지: AI로 제작 속도는 빨라졌지만 고객 문제 정의·가치 제안 문구·가격 제시는 여전히 사람의 몫

**활용할 때 확인할 점**

- 바이브코딩 창업 교육에 '랜딩 1초 테스트(무엇을·누구에게·얼마에)' 체크 포함
- 기능 나열보다 핵심 시나리오 1개 시연

### 코그니션(Devin) 연환산 매출 10억 달러 돌파 보도 — '작업 위임형' 코딩 에이전트의 성장과 래퍼 리스크

**활용할 때 확인할 점**
