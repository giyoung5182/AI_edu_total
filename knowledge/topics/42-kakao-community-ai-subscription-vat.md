## 실제 학습 내용

### 해외 AI 구독 부가세: Claude는 사업자번호(VAT ID) 입력 시 미청구, OpenAI도 개인 계정 Tax ID 입력란 제공

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

Anthropic 도움말: 세금 요건에 해당하면 결제 시 세금/VAT ID 입력란이 표시되고 Settings > Billing에서 추가·수정 가능하며, 이후 청구 주기부터 적용. OpenAI 도움말: 개인 ChatGPT 계정·Business·API 계정 모두 Tax ID 추가 방법을 안내하며, 무효한 Tax ID는 삭제되고 세금이 부과될 수 있다고 명시. 다만 OpenAI 문서는 한국 사업자번호 입력 시 VAT가 빠지는지 명시하지 않음.
- [추가 2026-09-30] '사업자번호 입력이나 부가세 내고 환급받거나 같은 것 아니냐'는 질문에 '환급이 아니라 면제이며 해외기업이라 환급 대상이 아니다'라는 답(커뮤니티 설명 — 링크된 도움말은 Tax/VAT ID 입력 절차만 안내하며 면제·환급 여부는 명시하지 않음). 커뮤니티 일부는 주소지를 해외(독일·알래스카 등)로 두고 결제한다고 언급했으나 이는 권장 방법이 아님

**활용할 때 확인할 점**

가입 즉시 사업자번호 등록(소급 불가). 면세와 매입세액공제는 별개라는 점은 기존 지식베이스 기준으로 안내.

**정정과 한계**

'GPT는 VAT를 피할 수 없다'는 답은 근거 부족: OpenAI도 개인 계정에 Tax ID 입력을 지원함. 입력 시 VAT 미청구 여부는 공식 문서로 확인되지 않아 결제 화면에서 직접 확인 필요.

### CLI '크레딧 부족'은 API 선불 크레딧 소진 — 구독 로그인(/login)으로 전환하면 구독 한도 사용, API는 서비스 연동용

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- Claude Code 오류 문서: 'Credit balance is too low'는 Console 조직의 선불 크레딧 소진을 뜻함. 대응은 결제 설정에서 크레딧 추가·자동 충전, 또는 Pro·Max·Team·Enterprise 구독자는 /login으로 구독 인증 전환
- Claude 도움말: ANTHROPIC_API_KEY 환경변수가 설정되어 있으면 Claude Code가 구독 대신 API 키로 인증해 API 요금이 부과됨. 구독만 쓰려면 claude logout 후 구독 계정으로만 로그인
- 구독(Pro/Max)은 Claude 앱과 Claude Code가 같은 사용 한도를 공유하고, 한도 소진 시 선택지로 상위 요금제 업그레이드, 사용량 크레딧, 리셋 대기, 집중 작업용 Console API 크레딧 구매가 안내됨
- JEV의 Gemini 호출 방식은 공식 확인 대상이 아님(커뮤니티 설명)

**활용할 때 확인할 점**

- '크레딧 부족'과 '사용 한도 도달'은 다른 과금 체계의 메시지라는 점을 구분해 안내
- 수강생 PC에 남아 있는 ANTHROPIC_API_KEY 환경변수로 의도치 않은 API 과금이 생길 수 있음을 주의사항으로 포함

### 해외 AI 구독에 사업자등록번호 입력 시 부가세 미청구, 매입세액공제와는 별개

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

부가가치세법 제53조의2는 국외사업자가 국내에 전자적 용역을 공급할 때 간편사업자등록·납부 특례를 두며, 사업자등록을 한 자의 과세·면세사업에 공급하는 경우는 적용 대상에서 제외(B2B). 따라서 사업자번호 입력 시 처음부터 부가세 없이 공급가액만 청구(예: $22 → $20). 이미 낸 부가세는 소급 조정 불가. 외국 간편사업자는 세금계산서 발급 대상이 아니어서 청구된 부가세의 매입세액공제가 불가하다는 설명은 원본 조사에서 국세청 원문으로 직접 대조하지 못함.

**활용할 때 확인할 점**

원리 설명(제도 → B2B 인식 → 공제와 무관) 3단계 구성. 개별 세무 처리는 세무사·국세청 상담 권고.

### Claude 유료 계정 VAT ID는 설정→청구에서 등록, 다음 청구 주기부터 적용

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

가입 시: 주소가 세금 목적상 적격이면 '세금 또는 VAT ID' 선택 입력란이 표시됨. 가입 후: 설정 → 청구 → 결제 방법 옆 '업데이트' → VAT ID 입력·수정. 청구 정보 변경은 향후 청구 주기에만 적용되며 이미 완료된 청구서는 소급 수정 불가.

**활용할 때 확인할 점**

결제 화면에서 바로 따라 하는 실습형 팁으로 제시. 소급 불가 조건 강조.

### ChatGPT 결제 통화는 위치 기준으로 정해짐 — 원화→달러 변경은 해지 후 결제 기간 종료 뒤 재구독해야 하며 '랜덤 표시'는 근거 없음

원본 상태: 정정 · 원본 확인일: 2026-09-29

- OpenAI 도움말: 결제 통화는 사용자 위치에 따라 정해지는 현지화 가격
- 이미 활성 구독이 있으면 현재 통화로 계속 청구
- 다른 지원 통화로 바꾸려면 구독을 해지하고 현재 결제 기간이 끝난 뒤 재구독해야 함
- 같은 도움말의 한국 결제수단 항목: ChatGPT 구독 결제 페이지에서 카카오페이·네이버페이·국내 카드 지원

**활용할 때 확인할 점**

- 해외 AI 구독 비용 교육 시 통화·환전 수수료·부가세(사업자번호) 이슈를 함께 정리
- 우회 접속으로 통화를 바꾸는 방식은 권장하지 않음

**정정과 한계**

'원화·달러 표시가 랜덤'이라는 경험담은 공식 설명과 다름 — 통화는 위치 기준이며 임의 선택 불가

### 해외 AI 구독을 원화로 결제하면 DCC(해외원화결제) 수수료가 추가될 수 있음 — 카드사 DCC 차단 서비스로 예방

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

- 정책브리핑(2018-07-27): DCC는 해외 가맹점에서 원화로 결제하는 서비스로, 현지통화 결제보다 수수료가 3~8% 추가
- 카드사 홈페이지·콜센터·모바일 앱에서 'DCC 사전 차단 서비스' 신청 가능, 일부 해외 사이트는 결제 시 DCC가 자동 적용될 수 있음
- 이번 사례의 차액이 DCC 때문인지, 결제 경로(앱스토어 등) 차이인지는 확인되지 않음
- 부가세 포함 여부는 계정·결제 화면의 세금 표시를 확인해야 함

**활용할 때 확인할 점**

- 해외 구독 결제 전 카드사 DCC 차단 설정 확인
- 결제 화면 금액과 카드 청구액이 다르면 결제 통화·결제 경로·해외결제 수수료를 순서대로 점검


## 이 주제를 실습할 때

가상 입력이 준비됐다면 “가격과 사용량 작업을 진행하려고 합니다. 필요한 조건과 실패 원인을 먼저 적고, 작은 입력으로 시험한 후 결과 파일과 검수 방법을 보여주세요”라고 요청합니다.

입력 읽기 성공·규칙 처리·AI 해석·저장 및 재열기는 각각 확인합니다. 소개 글이나 링크가 있다는 것만으로 실행 성공을 표시하지 않습니다.
