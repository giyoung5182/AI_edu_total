### Cursor Auto는 무제한이 아님 — 플랜 사용량 풀에서 라우팅된 모델 단가로 차감, 초과분은 on-demand를 켰을 때만 과금

원본 상태: 정정 · 원본 확인일: 2026-09-29

- Cursor 공식(2026-09 조회): Auto는 무제한이 아니라 플랜 사용량 풀에서 차감되며 요청마다 라우팅된 모델의 정가로 청구
- 한도에 도달하면 에디터 알림 후 on-demand(종량) 사용을 켜거나 상위 플랜으로 업그레이드, on-demand 과금은 해당 기능을 켰을 때만 적용
- Auto가 어떤 모델을 쓰는지는 문서에 구체적으로 공개되지 않음('중국산 모델'은 미확인)
- 2026-07 당시의 Auto 정책과 --classic 옵션은 이번에 확인하지 못함

**활용할 때 확인할 점**

- IDE 요금제 비교 시 '무제한' 표현을 문서로 재확인하도록 교육
- 추가 결제(on-demand) 설정 여부를 월초 점검 항목에 포함

**정정과 한계**

'Cursor는 Auto로 무한 사용'은 원본 확인일의 공식 문서와 다름 — Auto도 플랜 사용량 풀에서 차감

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Codex 공식 문서: Claude Code·Cursor에서 지침 파일(AGENTS.md로), settings.json(config.toml로), MCP 설정, 훅, 슬래시 명령(스킬로 변환), 서브에이전트, 프로젝트 메모리, 최근 30일 채팅 세션(최대 50개), 스킬·플러그인을 가져올 수 있음
- 방법: Codex CLI 로컬 세션에서 /import, 데스크톱 앱은 Settings > Import. 실행 중 작업·원격 세션에서는 /import 불가, 기존 설정은 변경·삭제되지 않음
