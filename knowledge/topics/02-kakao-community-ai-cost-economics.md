원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- 공식 문서: 캐시 기본 수명은 5분, 추가 비용으로 1시간 수명 선택 가능
- 가격 배수: 5분 캐시 쓰기 1.25배, 1시간 캐시 쓰기 2배, 캐시 읽기 0.1배(기본 입력 단가 대비)
- 따라서 캐시 적중 시 대부분 0.1배로 처리되던 긴 컨텍스트가 캐시 미스 시 쓰기 단가로 다시 계산되어 한 턴 사용량이 크게 뛸 수 있음
- 질문자가 겪은 '더블링'이 캐시 미스인지 버그인지는 공식 확인 불가(개인 버그 리포트 단계)

**활용할 때 확인할 점**

- 긴 세션일수록 자리 비움·모델 전환이 비용을 키우는 원리를 캐시 개념으로 설명
- 사용량이 비정상적으로 빨리 닳으면 세션 로그 분석·버그 리포트 절차 안내

### 토큰 투입량보다 성과가 기준 — '토큰 맥싱'은 회사·직무별로 허용 범위가 다르고 목표가 모호하면 효과 미미

- 공식 통계·정책이 아닌 재직자 경험과 기사 인용이 섞인 커뮤니티 논쟁
- 공통 합의: 토큰 사용량 자체가 아니라 산출된 성과로 평가, AI로 일이 빨라지면 일감이 줄기보다 할 일이 늘어남
- 루프형 자동 작업은 목표·검증 기준이 명확할 때만 효과가 있다는 경험담

**활용할 때 확인할 점**

- AI 도입 성과 지표를 '토큰 사용량'이 아니라 결과물 변화로 설계
- 에이전트 루프 실습 전 완료 기준·검증 기준을 먼저 정의하게 할 것
- '일이 줄어든다'보다 '할 일이 늘어난다'는 현장 체감을 함께 안내

### 에이전트 비용 측정과 통제 — OpenRouter는 응답마다 cost 자동 포함, 지시는 이중부정 대신 긍정문으로

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- OpenRouter 공식 문서: 모든 응답의 usage에 전체 사용 내역이 자동 포함되며 cost(청구 금액)와 cost_details.upstream_inference_cost 필드 제공. 과거 usage: {include: true} 파라미터는 더 이상 효과 없음(chat completions 포함)
- LangSmith Claude Code 플러그인(langchain-ai): 대화·도구 호출·서브에이전트 실행·컨텍스트 압축을 추적하고 LLM 실행별 토큰 사용량 기록. Node.js 18 이상 필요, 서브에이전트는 완료 시점에만 추적되어 실행 중 중단하면 기록되지 않음
- Claude Code 자체에도 --max-budget-usd(출력 모드 -p 전용)로 API 지출 상한을 두는 공식 플래그가 있음
- Anthropic 공식 프롬프트 가이드: '하지 말 것' 대신 '할 것'을 말하라(Tell Claude what to do instead of what not to do)

**활용할 때 확인할 점**

- 비용 통제는 프롬프트 금지문보다 측정(usage·cost 필드, 추적 도구)과 하드 상한(플래그·hook)으로
- 원치 않는 행동이 반복되면 부정·이중부정 지시를 긍정형 목표 서술로 바꿔보기
- 캐시 적용 여부에 따라 실제 비용이 달라지므로 측정값 기준으로 판단

### Ultrafast(2026-09-29) — 최대 8배 빠른 생성, ChatGPT·Codex에선 Pro 500 전용·구독 한도 8배 소모, API 단가는 표준의 6배

원본 상태: 공식확인 · 원본 확인일: 2026-10-06

- OpenAI 도움말: Ultrafast는 Pro 500에만 포함, 모델 선택기에서 선택. Codex 문서: Pro 500과 일부 Enterprise·Edu에서만 가능, 다른 셀프서브 플랜은 크레딧을 사도 출시 시점엔 이용 불가
- GPT-6 Astra Ultrafast는 Standard 대비 최대 8배 빠른 생성, 구독 한도 기준 8배 소모(크레딧·종량제는 6배)
- Fast 모드는 구독 한도 기준 2.5배(크레딧 2배) 소모, /fast 또는 config의 service_tier="fast"로 켬

**활용할 때 확인할 점**

- 속도 옵션(Fast·Ultrafast)은 '시간 vs 비용' 교환 — 한도 소모 배수부터 확인 후 켜기
- 데모·마감 직전 등 지연 비용이 큰 구간에만 사용
- fast/ultrafast 켜짐 여부를 항상 확인해 한도 급소진 방지
