4. 입력·결과·실패 조건을 기록하고 저장한 결과를 재연 뒤 사용합니다.

## 실제 학습 내용

### Claude Agent SDK 별도 월 크레딧(6/15 시행 예정)은 시행일에 보류, 현재는 SDK·claude -p·서드파티 앱도 구독 한도에서 차감

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- Anthropic 도움말(원안): Agent SDK용 별도 월 크레딧 Pro $20, Max 5x $100, Max 20x $200, Team Standard $20·Premium $100 등
- 적용 대상: 개인 프로젝트의 Agent SDK, Claude Code의 claude -p(비대화형), Claude Code GitHub Actions, Agent SDK로 구독 인증하는 서드파티 앱
- 크레딧 소진 시 사용 크레딧(API 표준 단가)이 켜져 있으면 과금, 꺼져 있으면 갱신까지 중단
- 2026-06-15 기준 변경 보류 공지: 'Agent SDK, claude -p, 서드파티 앱 사용은 여전히 구독 사용 한도에서 차감'

**활용할 때 확인할 점**

- 요금 개편 소문은 공식 도움말의 최신 상태(보류 여부)부터 확인
- 자동화(claude -p·GitHub Actions)는 대화형 사용과 과금 체계가 달라질 수 있는 영역으로 교육

### API 크레딧 무상 확보 경로로 프런티어 모델사 주최 해커톤 입상이 언급됨

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 참여자 경험담이며 금액 범위·지급 조건은 공식 자료로 확인하지 않음
- 해커톤마다 후원사·상금 구성이 달라 개별 공고 확인 필요

**활용할 때 확인할 점**

- 교육생 프로젝트의 API 비용 대안으로 해커톤·스타트업 크레딧 프로그램을 안내하되 조건은 공고로 확인

### ChatGPT Business·Enterprise 선불 크레딧은 사용량만큼 차감되어 구독 포함 한도보다 빨리 소진되는 체감

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- OpenAI 도움말: Business·Enterprise·Edu 크레딧은 선불 풀 방식이며 Deep Research·Thinking 모델·이미지 생성·Codex 등 고급 기능의 추가 사용에 쓰임, Business는 설정>결제에서 추가 구매
- 크레딧 단가·토큰 환산율은 별도 '요금표(rate card)' 문서 기준(이번에 수치 확인 안 함)
- '구독이 API 대비 몇 배 이득'이라는 비교는 커뮤니티 추정

**활용할 때 확인할 점**

- 기업 도입 비용 설계 시 '좌석 구독 포함 사용량'과 '선불 크레딧 종량 차감'을 분리해 예산화
- 파일럿 기간 사용량 로그로 월 예산 추정

### API 종량제는 구독과 달리 쓰는 만큼 청구, 과금 사고 방지는 콘솔 지출 한도(하드 리밋) 설정

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Claude Console: 워크스페이스별 지출 한도 설정 가능, 조직 한도보다 낮게만 설정 가능(미설정 시 조직 한도 적용), 특정 금액 도달 시 이메일 알림 설정 가능
- Claude 지출 한도는 사용자·그룹·좌석 등급·조직 단위 계층으로 적용되며, 그룹 한도도 공동 예산이 아니라 구성원 개인별로 적용
- OpenAI API: 프로젝트별 월 지출 한도는 기본적으로 초과해도 요청이 계속 처리되는 '소프트' 한도이며, 하드 리밋으로 강제하면 한도 도달 후 요청 실패, 기본 알림은 100% 시점
- '구독 200달러=API 7,000달러' 환산치는 공식 수치가 아닌 커뮤니티 주장

**활용할 때 확인할 점**

- 교육 실습용 API 키는 워크스페이스·프로젝트 단위로 분리하고 하드 리밋·알림을 먼저 설정
- OpenAI는 기본값이 '알림만'이므로 하드 리밋 선택 여부를 반드시 확인
- 개인 업무는 구독, 서비스 연동은 API라는 구분을 교육 초반에 제시

### 2026년 7월 한도 경쟁 — Claude Fable 5는 7/19(PT) 프로모션 종료 후 Max·프리미엄 좌석에 표준 포함, OpenAI는 Sol Codex 5시간 제한을 임시 해제

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Anthropic: Fable 5는 2026-07-01 재배포, 유료 요금제에서 7/7까지 주간 한도의 최대 50% 포함 후 사용 크레딧 전환 예고
- Claude 도움말: 주간 한도 50%까지 Fable 5 무료 프로모션은 2026-07-19 11:59:59 PM PT 종료(한국 시간 7/20 15:59경), Fable 5.1은 프로모션 대상 아님
- 현재 Max·프리미엄 Team·프리미엄 Enterprise 좌석은 Fable 5·5.1을 주간 한도의 최대 50%까지 추가 비용 없이 표준 포함, Pro·표준 좌석은 사용 크레딧
- OpenAI: 2026-07-12 Plus·Business·Pro의 5시간 사용 제한을 '임시로' 해제하고 1회 사용량 리셋·Sol 토큰 효율 개선(언론 보도 및 Codex 총괄 X 게시 기준, OpenAI 도움말 문서로는 미확인)

**활용할 때 확인할 점**

- 요금제 안내 자료에는 적용 날짜와 '임시·프로모션' 여부를 반드시 표기
- 벤더 간 한도 경쟁이 잦으므로 교육 직전 공식 도움말로 재확인

### ChatGPT는 국가별 현지 통화 가격을 운영 — 인도 Go ₹399·Plus ₹1,999 보도, 저가 요금제는 기능 등급 차등이라는 해석

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- OpenAI 도움말: 결제는 기본 USD이며 일부 국가에서 현지 통화 결제 제공, Go는 무료 대비 높은 한도를 제공하지만 일부 고급 기능은 Plus 이상 필요, 레거시 모델 접근은 Go에 미포함
- TechCrunch(2025-08): 인도 Go 월 ₹399, 인도 Plus 월 ₹1,999로 보도
- 43%·15% 비교율, 한국 원화 가격, 'damaged goods' 해석은 공유자 분석으로 공식 확인하지 않음

**활용할 때 확인할 점**

- 요금제 비교 교육 시 '가격'과 '제공 모델·한도 등급'을 함께 비교
- 사용자 수 통계 인용 시 요금제 등급 혼재를 주의

### Max 한도 조기 소진 대응 — 계정 추가 전에 effort 단계 조정·최상위 모델 상시 사용 중단·무거운 플러그인 정리부터

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-10-06

- 커뮤니티 실사용 팁이며 절감 효과 수치는 개인차
- 기존 카드 기준 플러그인·MCP·긴 세션 이력이 매 요청 컨텍스트를 키운다는 공식 설명과 맥락이 같음

**활용할 때 확인할 점**

- 비용 증설 전 '작업 난이도별 effort 매핑표'를 먼저 만들도록 교육
- 최상위 모델은 기획·검토 전용으로 한정


## 이 주제를 실습할 때

가상 입력이 준비됐다면 “가격과 사용량 작업을 진행하려고 합니다. 필요한 조건과 실패 원인을 먼저 적고, 작은 입력으로 시험한 후 결과 파일과 검수 방법을 보여주세요”라고 요청합니다.

입력 읽기 성공·규칙 처리·AI 해석·저장 및 재열기는 각각 확인합니다. 소개 글이나 링크가 있다는 것만으로 실행 성공을 표시하지 않습니다.
