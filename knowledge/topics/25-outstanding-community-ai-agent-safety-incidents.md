## 실제 학습 내용

### 프롬프트 인젝션 방어는 경량 모델 사전 선별 + 신뢰 불가 콘텐츠 격리, 가드 모델은 단일 GPU급(12B)부터 가능

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

Anthropic 공식 문서(Mitigate jailbreaks and prompt injections): 사용자 입력을 Claude Haiku 4.5 같은 경량 모델로 사전 선별(harmlessness screen), 알려진 인젝션 패턴 입력 검증, 반복 위반자 제한을 권장. 간접 인젝션에는 외부 콘텐츠를 tool_result로만 전달, JSON 인코딩으로 경계 구분, 최소 권한, 도구 출력 사전 선별, 인젝션이 담긴 문서로 레드팀 테스트를 권장. Meta Llama Guard 4는 12B 파라미터 dense 모델로 입력(프롬프트)과 출력(응답)을 MLCommons 13개 위험 범주(+텍스트 전용 Code Interpreter Abuse 범주)로 분류하며 단일 GPU에서 실행 가능, 공식 지원 언어는 영어 외 7개(한국어 미포함). 가드 모델의 교체·유지보수 주기에 대한 공식 권장값은 확인되지 않음.

**활용할 때 확인할 점**

가드 구조 비용은 '모든 입력을 대형 모델로 검사'가 아니라 '경량 모델 선별'로 낮추는 것이 공식 권장 방식. 한국어 서비스는 Llama Guard 공식 지원 언어 밖이므로 자체 평가셋으로 검증 필요.

- 커뮤니티 의견 정리: (1) AI 불신의 주된 원인은 결과물 검증 부담 (2) 사람이 AI 결론을 반박하려면 해당 분야 전문성과 시간이 들어 형식적 승인으로 흐르기 쉬움 (3) 저위험 콘텐츠는 빠른 출시 후 수정 전략이 가능하다는 입장. 한국 AI기본법에 고영향 AI 관련 사업자 책무 규정이 있으나, 이번에 법령 원문을 직접 열람하지 못해 사람 관리·감독 의무의 구체 내용은 확인 필요.
- [추가 2026-09-16] 아웃스탠딩 칼럼(2026-09-16) 논지: 내부 보고서 숫자 오류처럼 사람이 최종 확인하는 영역과 달리 대출 거절·채용 탈락·보험 인수 거절·진단처럼 권리·기회·재산·건강에 직접 영향을 주는 AI 판단은 '누가 권한을 부여했는지, 사람이 통제할 수 있었는지, 사전 방지조치를 했는지'까지 책임이 따짐.

### Claude Code 확인창 반복은 권한 모드 문제 — Shift+Tab 전환, 전면 우회(bypass)는 격리 환경 전용

- 기본 모드는 settings 파일의 permissions.defaultMode로 지정(.claude.json 아님), 프로젝트 .claude/settings.json의 auto·bypassPermissions 값은 적용되지 않음

**활용할 때 확인할 점**

- 확인창 피로는 모드 선택 문제로 설명, '무조건 bypass'가 아니라 auto 모드 우선 안내
