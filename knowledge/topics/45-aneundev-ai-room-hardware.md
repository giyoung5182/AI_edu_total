## 실제 학습 내용

### 클라우드 AI 에이전트·API 생성 작업은 GPU 사양 거의 무관, RAM·CPU가 병렬 작업 체감 결정

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Claude Code 공식 시스템 요구사항은 4GB 이상 RAM, x64 또는 ARM64 프로세서, 인터넷 연결이며 GPU 요구사항은 없음. Claude Desktop은 macOS 11·Windows 10 이상, Linux의 Cowork 작업공간은 여유 디스크 약 25GB와 RAM 8GB 이상을 요구. API로 호출하는 이미지·영상 생성은 제공사 서버에서 연산되므로 로컬 GPU가 쓰이지 않음. 병렬 에이전트·브라우저 다중 실행 시 16~32GB 권장은 커뮤니티 체감이며 공식 권장값은 아님. 맥 모니터 관련 답은 사용 경험.
- [추가 2026-09-11] 9/11 커뮤니티: 원격 지시로 computer use를 돌리는 홈서버 용도면 결과물은 프로세서와 무관하고 차이는 OS 최적화·속도·전력, Mac 안에서는 애플 실리콘이 인텔맥보다 효율 우위라는 의견(체감).

**활용할 때 확인할 점**

비개발자 수강생 장비 안내 시 '로컬 모델을 돌리지 않으면 GPU 투자 불필요, RAM 우선'으로 정리. 최소 사양(공식)과 쾌적 사양(체감)을 구분해 제시.

### AI 코딩용 노트북 — 웹 개발·클라우드 에이전트는 GPU보다 RAM, 메모리 증설 불가 기기는 32GB 이상 권장이라는 현업 체감

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-10-06

- 공식 사양 비교는 하지 않은 커뮤니티 경험 중심 카드
- 클라우드 모델을 호출하는 에이전트 작업은 로컬 GPU 의존도가 낮고 병렬 세션 수만큼 RAM·CPU가 체감을 좌우한다는 점은 기존 카드(K0101)와 일치
- [추가 2026-09-30] RAM 16GB 노트북은 '느리다기보다 최대 동시 작업량이 적다', 영상 편집(프리미어)은 32GB 이상 권장이라는 체감. 메인 맥북 선택은 M1 Max 64GB도 여전히 현역이라는 의견, 그래픽 작업이 없으면 Pro 64GB, 넉넉하게는 Max 128GB라는 조언(커뮤니티)

**활용할 때 확인할 점**

- 장비 추천은 '돌릴 작업(클라우드 호출 vs 로컬 모델)'부터 확인
- 증설 불가 기기는 메모리를 여유 있게
- 회사 보안 정책(맥 사용 제한, 폐쇄망)을 먼저 확인

### 로컬 소형 모델을 서브에이전트로 붙여 메인 구독 토큰을 아끼는 운용 — 9B급 로컬 모델+Plus 구독 조합 사례

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-09-29

- 개인 사례로, 수치(잔여 91% 등)는 공식 확인 대상이 아닌 커뮤니티 경험
- 서브에이전트에 작은 모델을 배정해 비용을 줄이는 원칙 자체는 Claude Code 비용 문서의 '단순 서브에이전트 작업은 작은 모델 지정' 권고와 같은 방향(단, 문서는 Claude 모델 기준)

**활용할 때 확인할 점**

- 반복·요약·분류처럼 난도가 낮은 작업을 로컬 소형 모델로 분리하는 설계 예시로 활용
- 로컬 운용은 장비·전기·유지보수 비용을 함께 계산

### Strata — MoE 전문가를 GPU·RAM·SSD에 나눠 실어 Qwen3.8-Flash-Next를 일반 PC(VRAM 12GB·RAM 32GB~)에서 돌리는 MIT 오픈소스

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

- 저장소 설명: Strata는 Qwen3.8-Flash-Next를 일반 PC에서 구동하는 소프트웨어
- 요구 사양: 그래픽카드 VRAM 12GB 이상, 시스템 RAM 32GB 이상(64GB면 모든 크기 구동), 저장공간 약 80GB
- 방식: 자주 쓰이는 전문가(expert) 수천 개는 GPU에, 전체는 RAM에 두고 CPU 연산·SSD 조회 테이블을 병행하는 메모리 오프로딩
- MIT 라이선스
- 실제 속도·품질 수치는 확인하지 않음

**활용할 때 확인할 점**

- 로컬 LLM은 GPU만이 아니라 RAM·SSD까지 포함한 메모리 구성이 관건
- 커뮤니티 화제 저장소는 공식 모델 배포처가 아니므로 보안·성능을 직접 검증
