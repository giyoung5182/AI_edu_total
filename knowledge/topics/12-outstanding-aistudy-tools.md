### Aside는 macOS·Windows용 AI 브라우저로 Free 월 500크레딧, ChatGPT·Claude 구독이나 API 키 연결 가능

원본 상태: 정정 · 원본 확인일: 2026-09-29

- 지원 OS: 공식 다운로드 페이지 기준 macOS와 Windows. Linux(우분투)는 표기 없음
- 요금제: Free $0(월 500크레딧, 루틴 3개까지), Pro 월 $20(Free의 3배 사용량, 루틴 무제한), Max 월 $200(Free의 40배), Enterprise 별도 문의
- 모델 연결: Settings > Models > Providers에서 ChatGPT Plus·Pro, Claude Pro·Max, GitHub Copilot 구독을 OAuth로 연결하거나 Anthropic·OpenAI·OpenRouter·Google·xAI 등 API 키 입력 가능. 요금제에 포함된 자체 모델도 제공
- 다른 모델을 붙이려면 API 키 공급자(예: OpenRouter)를 연결하는 방식이 공식 문서상 가능(모델 가격·가성비에 대한 언급은 문서에 없음)
- [추가 2026-08-18] 8/18 커뮤니티: Aside를 메인 브라우저로 사용, 구독 계정 연결 가능, 로그인 정보는 브라우저에 저장되고 AI가 취득하지 않는다는 설명, 한 번의 홈택스 조회 작업에 사용량 60%를 쓴 사례
- [추가 2026-09-15] Aside는 공식 변경로그에 'Windows에서 정식 제공' 항목(v1.0.914.1)이 있음(날짜 미표기, 커뮤니티는 9/14 정식 출시로 공유). 커뮤니티 활용: 블로그 원고 루틴화, Astra 모델 연동 후 API로 못 가져오는 화면을 OCR 방식으로 수집, 20달러 플랜은 부족하고 제대로 쓰려면 200달러라는 체감.

**활용할 때 확인할 점**

- 컴퓨터·브라우저 유즈 도구 소개 시 '로그인된 사이트에서 사람처럼 클릭'하는 방식과 보안 주의사항을 함께 설명
- 기존 ChatGPT·Claude 구독 재사용 가능 여부는 도입 비용 판단 포인트로 안내

**정정과 한계**

'aside에 jev를 붙이라'는 답은 공식 근거와 맞지 않음: Jev 제작사 문서는 Jev가 에이전트의 LLM을 대체하는 모델이 아니라 분류·판단용 API라고 명시하며, Aside의 공급자 목록에도 TypeSafe(Jev)는 없음.

### Aside 브라우저 에이전트는 저장 비밀번호를 AI 모델에 넘기지 않고 Vault에서 직접 자동입력하는 구조

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

Aside 공식 도움말(Password manager): 에이전트는 로그인 동작을 통해 저장 자격증명을 쓰되 '원본 비밀번호를 받지 않으며', 비밀번호를 에이전트에게 보여주지 않고 웹사이트에 직접 자동입력한다고 설명. AI 접근 범위는 비밀번호 설정·보안(에이전트 권한, 세션 권한 모드, 샌드박스) 페이지에서 제어. AI 제공자 연결은 OAuth 로그인 또는 API 키 방식이며 API 키 방식은 '자신의 제공자 계정을 통해 모델 호출을 라우팅'한다고 안내. 다만 구독 연동 시 Aside 크레딧이 전혀 차감되지 않는지는 공식 문서에 명시돼 있지 않음. Vault 저장 위치(로컬/클라우드)·암호화 방식도 해당 페이지에 명시 없음.

**활용할 때 확인할 점**

컴퓨터유즈형 도구 도입 시 '모델이 비밀번호를 보는가', '에이전트 권한 범위', '자격증명 저장 위치' 세 가지를 점검 항목으로 제시.
