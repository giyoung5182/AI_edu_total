### 로컬 모델 후보 Gemma 4는 Apache 2.0 오픈 웨이트, 2B·4B급부터 31B까지 크기 선택 가능

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Google 공식 문서: Gemma 4는 오픈 웨이트 모델로 책임 있는 상업적 사용 허용, 라이선스 Apache 2.0
- 크기: 엣지·모바일용 2B·4B(유효 파라미터), 31B dense, 26B MoE, 12B 멀티모달 등
- 텍스트·이미지·영상·오디오 입력(모델별 지원 상이), 컨텍스트는 소형(E2B·E4B) 128K·중형 이상 최대 256K, Kaggle·Hugging Face에서 배포
- supergemma4는 공식 Google 모델이 아닌 파생 버전으로, 원본 정리 시 확인에서 출처·라이선스를 공식 확인하지 못함

**활용할 때 확인할 점**

- 사내 보안상 로컬 구동이 필요한 기관 교육에서 공식 모델과 커뮤니티 파생 모델(특히 무검열 버전)의 차이·리스크를 구분해 안내

### Fable 5는 기획·검토 전용으로 두고 구현은 하위 모델 서브에이전트에 — 단독 사용 시 5시간 한도 수분 내 소진 체감

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- 공식 문서상 Claude Code 서브에이전트·팀메이트 모델은 생성 프롬프트에 지정한 모델, 서브에이전트 정의의 model 필드, CLAUDE_CODE_SUBAGENT_MODEL 환경변수 순으로 결정되며 조직의 availableModels 허용 목록에 막히면 다른 모델로 대체
- Max·Team Premium 요금제는 Fable 모델에 주간 한도의 최대 50%까지 추가 비용 없이 사용, 한도 도달 시 사용 크레딧으로 계속하거나 다른 Claude 모델로 전환(Claude 도움말)
- '10분에 백만 토큰', 'Opus 대비 몇 배' 같은 소모량 수치는 커뮤니티 체감이며 공식 수치 아님

**활용할 때 확인할 점**

- 최상위 모델은 '두뇌가 필요한 구간(기획·설계·리뷰)'에만 배치하는 역할 분담을 핵심 원칙으로
- 서브에이전트 모델 지정(프롬프트·model 필드·환경변수) 실습
- '행동강령을 하위 모델에 주입'보다 작업 분해·모델 배치가 우선이라는 커뮤니티 조언 인용 가능

### AI가 기존 기능을 망가뜨리지 않게 '기능 보존'을 명시 — 반드시 막아야 할 영역은 지시문이 아닌 권한 규칙으로

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

**활용할 때 확인할 점**

- '보존 지시(프롬프트)'와 '차단(권한·hook)'의 이중 안전장치로 교육
- git 커밋 단위 작업·되돌리기 습관과 함께 안내

### 긴 세션 관리 — 자동 compact에 맡기되 품질 저하 시 handoff.md로 정리 후 새 세션, 도구 이관도 같은 문서 방식

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

- Claude Code 공식 비용 문서는 무관한 작업으로 넘어갈 때 /clear로 새로 시작하고, /compact에 보존할 내용을 지정(예: '/compact Focus on code samples')하라고 안내
- /compact는 요약 대상 대화를 읽으므로 큰 컨텍스트 압축 자체가 큰 요청이며, 연속성이 필요 없으면 /clear는 비용이 없다고 명시
- 오래 열어 둔 세션은 매 요청마다 전체 대화를 다시 보내 사용량이 늘어날 수 있음

### AI 설명이 어렵거나 번역투일 때 — Claude Code는 output style(Explanatory·Learning·사용자 정의)로 설명 수준과 말투를 세션 단위로 고정

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- output style은 한 세션의 모든 응답에 역할·말투·형식을 적용하는 지시 묶음

- 코딩 지시를 유지하려면 frontmatter에 keep-coding-instructions: true
- 반드시 지켜야 하는 규칙은 output style이 아니라 hook이 적합하다고 문서가 구분
- 참고: '고아 데이터'는 참조 대상(예: 삭제된 게시글)이 사라져 도달할 수 없게 남은 데이터(예: 댓글)

**활용할 때 확인할 점**

- '쉽게 설명해줘' 반복 대신 독자 수준·금지 표현·설명 순서를 스타일로 고정
- 교육생에게 Explanatory·Learning 스타일을 학습 도구로 소개
