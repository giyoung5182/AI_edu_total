## 실제 학습 내용

### ChatGPT·Codex 한도 구조 — 일반 채팅과 Codex는 별개, Codex 표면·Work는 공유 풀, Plus 5시간 제한은 8/25 재도입

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- OpenAI 도움말: Codex는 Free·Go를 포함한 ChatGPT 요금제에 포함, Codex·ChatGPT Work·ChatGPT for Excel·Workspace Agents가 같은 사용량·크레딧 풀을 공유
- 일반 채팅 사용량은 Codex 크레딧 집계에 포함되지 않고, 일반 채팅 음성도 별도 한도
- Codex는 5시간·주간 사용 창을 적용, 잔여량은 설정·사용량 대시보드 또는 CLI /status로 확인
- Codex 가격 페이지: Plus 월 20달러, Pro는 100달러부터이며 Plus 대비 5배 또는 20배 한도. 한도 도달 시 Plus·Pro는 크레딧 추가 구매 가능
- 언론 보도(Notebookcheck) 기준 Plus의 Codex·Work 5시간 제한은 7/13 GPT-5.6 Sol 출시와 함께 해제됐다가 8/25 재도입, Pro 100·200달러는 제외
- OpenAI 도움말: 공유 한도·크레딧을 쓰는 요금제에서는 Codex, ChatGPT Work, ChatGPT for Excel, Workspace Agents가 하나의 한도·크레딧 풀을 공유
- 'Work follows the same usage structure as Codex' — Work와 Codex는 같은 Work & Codex 한도에서 차감
- Chat은 별도의 시작 기본값을 쓰며 Work & Codex 설정을 바꿔도 Chat 기본 모델은 바뀌지 않음
- 한도 확인: 설정 또는 사용량 대시보드, Codex CLI에서는 /status

**활용할 때 확인할 점**

- 교육 시 '채팅 한도'와 '에이전트(Codex·Work) 한도'를 분리해 설명
- 저가 플랜은 5시간 창 때문에 긴 작업이 중간에 끊길 수 있음을 사전 고지
- 한도 정책은 수시 변경되므로 수업 직전 공식 페이지 재확인

### ChatGPT 데스크톱 앱 코드 리뷰 — GitHub PR·GitLab MR 리뷰, 자동 클라우드 1차 리뷰, 로컬은 /review

원본 상태: 공식확인 · 원본 확인일: 2026-10-06

- 공식 문서: ChatGPT 데스크톱 앱 내장 Code Review 플러그인으로 코드 변경 이해·잠재 문제 조사·리뷰 피드백 준비
- GitHub PR 리뷰는 정식 제공, GitLab MR은 프리뷰
- 설정 시 Codex가 GitHub PR을 자동 리뷰해 GitHub와 리뷰 화면에 코멘트 게시
- 로컬 /review: 기준 브랜치 대비 또는 커밋 안 된 변경을 작업 트리를 바꾸지 않고 리뷰
- 팀 기준 맞춤 리뷰 지침, 줄 단위 코멘트, Comment·Approve·Request Changes 제출 지원. Git 저장소 안의 프로젝트가 필요

**활용할 때 확인할 점**

- AI 리뷰는 사람 리뷰 전 '1차 검토'로 배치 — 승인 판단은 사람
- 팀 리뷰 기준을 지침으로 넣어야 일관된 결과

### Claude Code 세션은 계정이 아닌 PC·프로젝트 폴더 단위로 로컬 저장 — 채팅(claude.ai)은 계정 클라우드

원본 상태: 공식확인 · 원본 확인일: 2026-10-06

- Claude Code 공식 문서: 세션은 프로젝트 디렉터리에 묶인 저장 대화이며 작업 중 로컬에 저장
- 기본 저장 위치 ~/.claude/projects/<project>/<session-id>.jsonl, 기본 보관 30일(cleanupPeriodDays로 변경)
- 데스크톱 앱·claude.ai/code·VS Code 확장은 각자 세션 목록을 가짐
- 이어서 하기: claude --continue(최근 세션), claude --resume(선택기), /export로 텍스트 내보내기
- Codex 계정 전환 시 세션 표시 방식은 공식 문서로 확인하지 못함(커뮤니티 경험만)

**활용할 때 확인할 점**

- 공용 PC·계정 전환 환경에서는 로컬 세션 기록이 다른 계정 사용자에게 보일 수 있음 — 보안 교육 포인트
- 계정이 바뀌어도 작업 맥락을 이어야 하면 /export나 세션 파일 재개 활용

### Gemini 앱 요금제 개편설(10/9 무료 Flash·AI Plus Pro 접근 축소)과 Gemini API 무료 티어 — 공식 문서 미확인

원본 상태: 미확인 · 원본 확인일: 2026-10-06

- 기존 지식베이스 카드 기준 Gemini API 무료 등급은 존재하며 입력이 제품 개선에 쓰이는 조건
- 'RPD 20' 등 무료 티어 수치는 공식 가격·한도 페이지로 재확인 필요

- 무료 요금제를 전제로 한 교육·실습 설계는 시행일 전후 재확인 필수
- 요금제 변경은 언론 요약보다 공식 도움말·변경 로그를 기준으로 안내

### Gemini 생성물 워터마크 — 한국에서 가시 워터마크 끄기는 AI Ultra만, 비가시 SynthID는 항상 유지

원본 상태: 정정 · 원본 확인일: 2026-10-06

- Gemini 앱 도움말: 대부분 지역은 모든 사용자가 가시 워터마크 설정 관리 가능, 인도·한국·베트남은 AI Ultra 구독자만 설정 가능하고 그 외엔 모든 시각 미디어에 가시 워터마크 자동 적용
- Gemini 앱으로 생성·편집한 모든 AI 미디어에는 비가시 SynthID 워터마크 포함, 가시 워터마크 설정은 SynthID·Content Credentials에 영향 없음
- '유튜브가 워터마크 제거 콘텐츠를 탐지'한다는 주장은 공식 출처로 확인하지 못함

**활용할 때 확인할 점**

- 워터마크 제거 도구 사용은 플랫폼 정책·AI 표시 의무 측면 위험 — 교육에서 권장 금지
- 가시 표시와 비가시 식별(SynthID)을 구분해 설명

**정정과 한계**

'비싼 구독을 해도 가시 워터마크는 못 없앤다'는 부정확 — 한국에서도 AI Ultra 구독자는 가시 워터마크 설정 가능

### AI로 디자인 툴을 직접 조작 — Claude의 공식 'Adobe for Creativity' 커넥터는 50개+ 도구, 계정 없이도 시작

- Claude 웹·모바일 채팅, Cowork 데스크톱, Claude Desktop에서 사용, 새 커넥터 설치는 iOS·Android 앱에서 불가(웹·데스크톱에서 먼저 설정)

- 커넥터가 지원하는 기능 범위를 먼저 확인하고 기대치 조정

### Cloudflare Clef — 정해진 선택지 중에서만 판단하는 오픈소스 결정 모델(Apache 2.0), 판단당 약 39~209ms

원본 상태: 공식확인 · 원본 확인일: 2026-10-06

- Cloudflare 공식 블로그(2026-10-01): 입력을 분류해 확률과 함께 정해진 타입의 답을 돌려주는 결정 모델 계열, Apache 2.0으로 Hugging Face 공개·Workers AI 호스팅
- Clef(Qwen 27B 기반)·Clef-flash(Qwen 9B 기반), 중앙값 지연 Clef-flash 38.8ms ~ Clef 209.3ms
- 텍스트·이미지 입력, 스키마 선택지를 병렬로 점수화하는 비생성형·결정적 방식, 64k 컨텍스트
- 블로그는 Jev와 비교해 비전 인코더 포함·컨텍스트 64k(Jev 32k)를 차별점으로 제시

**활용할 때 확인할 점**

- 에이전트의 '분기 판단'은 생성 모델 대신 저지연 분류 모델로 대체하는 흐름 — Jev와 함께 라우팅·필터링 사례로 활용

## 이 주제를 실습할 때

가상 입력이 준비됐다면 “뉴스와 조직 변화 작업을 진행하려고 합니다. 필요한 조건과 실패 원인을 먼저 적고, 작은 입력으로 시험한 후 결과 파일과 검수 방법을 보여주세요”라고 요청합니다.

입력 읽기 성공·규칙 처리·AI 해석·저장 및 재열기는 각각 확인합니다. 소개 글이나 링크가 있다는 것만으로 실행 성공을 표시하지 않습니다.
