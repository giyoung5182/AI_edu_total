### Claude는 사진·영상을 직접 생성하지 않음, 영상은 Remotion 같은 코드 기반 렌더링으로 제작

원본 상태: 정정 · 원본 확인일: 2026-10-06

- Claude 고객센터: Claude는 이미지 생성 도구처럼 사진·일러스트를 만들지 않음. 대신 HTML·SVG로 다이어그램·차트·인터랙티브 시각물을 만들고, 업로드한 이미지를 보고 분석 가능
- 영상: Remotion은 React 코드로 영상을 만드는 도구이며, 공식 Agent Skills(npx skills add remotion-dev/skills)를 Claude Code·Codex·Cursor 등에서 사용 가능. 즉 Claude가 '영상 파일을 직접 생성'하는 것이 아니라 영상을 렌더링하는 코드를 작성하는 방식
- 사진형 이미지가 필요하면 이미지 생성 모델(API)을 별도로 연결해야 함
- Concat은 원본 정리 시 확인에서 공식 저장소를 특정하지 못함
- [추가 2026-09-29] 9월 추가: Claude는 사진 생성이 안 된다는 확인(9/29), 교육용 동영상은 Remotion + Opus 5.5, 3D는 three.js 병행 추천(9/27).
- [추가 2026-09-09] HTML을 영상으로 렌더링하는 오픈소스 HyperFrames(HeyGen, Apache 2.0)도 Remotion과 함께 AI 코딩 에이전트용 영상 제작 대안으로 공유됨 — HTML·CSS·애니메이션을 결정적 MP4로 렌더링

- [추가 2026-09-29] - [추가 2026-10-05] 원작자 공개 자료 확인: Stephan Livera의 X 게시물(Opus 5.5 Max effort, '15초 모션그래픽 쇼릴' 한 문장 프롬프트) 존재 확인, 조회수 222만은 원문 미확인. GitHub yihui-dev/awesome-opus5-5-videos는 Opus 5.5로 만든 영상 475개와 프롬프트·원본 X 게시물 링크를 모은 저장소이며 '모든 영상은 Opus 5.5에 애니메이션을 코드(HTML·Canvas·SVG·Three.js 등)로 쓰게 해 만든 것'이라고 명시 — 영상 파일 직접 생성이 아닌 코드 렌더링이라는 이 카드의 정정과 일치. 공식(Anthropic) 발표 아님

**활용할 때 확인할 점**

- [추가 2026-09-29] 커뮤니티에서는 9/29 새벽(KST) Sonnet 5.5 사용 가능 확인, 벤치마크 점수가 높다는 반응.
