### 게임 매크로 제작·배포는 게임산업법 형사처벌 대상, Claude 거절은 '크롤링 일괄 금지'가 아니라 이용정책 판단

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

게임산업진흥에 관한 법률 제32조 제1항 제8호는 게임사가 제공·승인하지 않은 프로그램의 배포 및 배포 목적 제작을 금지(벌칙: 1년 이하 징역 또는 1천만 원 이하 벌금, 지식베이스 기준). 단순 사용자는 게임산업법 직접 처벌 조항은 없으나 형법상 업무방해 적용 가능성과 약관상 계정 제재가 있음. Anthropic 사용정책(AUP)은 '다른 플랫폼·서비스의 가드레일이나 약관을 우회하는 행위', 무단 접근, 스팸 자동화 등을 금지하며, 게임 치트·봇을 명시한 조항은 없음. 반복작업·크롤링 자체를 일괄 금지하는 문구는 확인되지 않음.

**활용할 때 확인할 점**

업무 자동화 교육에서 '허용되는 자동화'와 '약관·법률로 금지된 자동화(게임 매크로 등)'의 경계 사례로 활용. 거절 시 요청 목적·대상 서비스 약관을 먼저 확인하도록 안내.

**정정과 한계**

'크롤링성 반복작업은 원래 막힘'은 과한 일반화. 공식 정책이 금지하는 것은 다른 서비스의 약관·보호장치 우회 등이며, 정상 업무 자동화까지 일괄 차단한다는 근거는 없음. 법령 본문은 law.go.kr 접속 제한으로 이번에 직접 열람하지 못함(지식베이스 기존 확인 내용 인용).

### Claude 구독 로그인(OAuth)은 공식 앱 전용 — 제3자 프록시·웹앱으로 구독을 우회 연결하는 방식은 약관 위반 소지

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- Claude Code 법률·컴플라이언스 문서: OAuth 인증은 Free·Pro·Max·Team·Enterprise 구매자의 Claude Code 및 기타 Anthropic 네이티브 앱의 '일반적 사용'을 위한 것
- 제품·서비스를 만드는 개발자(Agent SDK 포함)는 API 키 인증을 써야 하며, 제3자 개발자가 Claude.ai 로그인을 자체 앱에 제공하거나 Free·Pro·Max 자격증명으로 사용자 요청을 중계하는 것을 허용하지 않고, 자격증명·세션 토큰을 수집·저장·중계할 수 없음. Anthropic은 사전 통지 없이 제재할 수 있다고 명시
- 개인이 자기 프로젝트에서 Agent SDK·claude -p를 쓰는 경우는 2026-06-15 기준 구독 한도에서 차감(도움말), Pro·Max 광고 한도는 '일반적 개인 사용'을 전제
- CLIProxyAPI 자체의 약관 적합성은 공식 판단 문서 없음 — 위 조항 기준으로 위험 소지 판단
- Claude Code 공식 법무·준수 문서: OAuth 인증은 Free·Pro·Max·Team·Enterprise 구독자의 Claude Code 및 Anthropic 자체 앱 '일반 사용'을 위한 것
- 제품·서비스를 만드는 개발자(Agent SDK 포함)는 Claude Console 또는 클라우드 사업자의 API 키 인증을 써야 하며, 제3자 앱에 Claude.ai 로그인을 제공하거나 Free·Pro·Max 자격증명으로 요청을 중계하는 것은 불허
- Anthropic은 사전 통지 없이 이 제한을 집행할 수 있다고 명시
- OpenAI 측 허용 여부: OpenClaw 공식 문서는 'OpenAI가 OpenClaw 같은 외부 도구에서 구독 OAuth 사용을 명시적으로 지원한다'고 쓰지만 OpenAI 자체 문서로는 확인하지 못함
- OpenAI는 Codex를 외부 제품에 깊게 통합하는 인터페이스로 Codex App Server(JSON-RPC 2.0, 오픈소스)를 공식 제공

**활용할 때 확인할 점**

- 비공식 브릿지·프록시는 계정 정지 위험을 안고 쓰는 선택임을 명확히 교육
- 다른 회사 모델을 섞을 땐 각 사 API 키나 공식 플러그인 경로 권장
- 웹앱·팀 서비스에 AI를 붙일 땐 반드시 API 키 방식

### 카카오톡을 AI 에이전트에 연결하는 비공식 방법(LOCO 프로토콜·node-kakao)은 카카오 운영정책 위반으로 이용 제한 위험

원본 상태: 정정 · 원본 확인일: 2026-10-06

- 카카오 운영정책(톡안전)은 프로그램 코드 역분석(reverse engineering) 후 정보 공유·유사 앱 제작, 비정상 프로그램으로 카카오톡 프로토콜·API를 부정 호출하는 행위, 프로토콜을 악용한 봇·매크로 제작·배포를 금지
- 위반 시 일시 또는 영구 이용 제한, 심각한 장애 발생 시 수사기관 연계 가능
- node-kakao 저장소: LOCO 프로토콜 호환 비공식 라이브러리, 'Not Maintained' 표시, '남용 시 영구 서비스 제한될 수 있음'·'언제든 작동이 멈출 수 있음' 경고
- 로컬 DB 접근 차단 여부는 공식 확인 안 됨

**활용할 때 확인할 점**

- 업무 자동화에서 메신저 연동은 공식 API·채널(카카오톡 채널 등) 우선 검토
- 비공식 프로토콜 사용은 계정 영구 제한 위험을 고지하고 교육 실습에서는 다루지 않기
- 현장 사용자가 카톡만 쓰는 경우에도 공식 경로나 사람 검수 단계를 설계

**정정과 한계**

'공공연히 말하면 불법'이라는 표현은 정확하지 않음 — 방법 공유 자체의 형사 처벌 여부는 확인되지 않았고, 확인된 것은 카카오 운영정책상 금지·이용 제한 대상이라는 점

### 비개발자 바이브코딩의 벽은 코딩보다 운영·보안 — 위험을 모르면 '보안 점검해줘'조차 요청하지 못함

원본 상태: 커뮤니티경험 · 원본 확인일: 2026-10-06

- 커뮤니티 실무 경험 정리이며 사고 빈도·배상 규모에 대한 공식 통계는 확인하지 않음
- 공통 조언: 관리자 경로 접근 통제, 저장소 공개 범위·비밀키 관리, 출시 전 별도 세션·도구로 보안 검토

**활용할 때 확인할 점**

- 바이브코딩 교육에 '배포 전 보안 체크리스트(인증·권한·비밀키·공개 범위)'를 필수 단계로 포함
- 수익화는 기술보다 수익 구조·기존 본업 연계부터 설계
- '모르는 위험'을 AI에 묻도록 질문 목록을 제공

### Gemini 생성물 워터마크 — 한국에서 가시 워터마크 끄기는 AI Ultra만, 비가시 SynthID는 항상 유지

원본 상태: 정정 · 원본 확인일: 2026-10-06

- Gemini 앱 도움말: 대부분 지역은 모든 사용자가 가시 워터마크 설정 관리 가능, 인도·한국·베트남은 AI Ultra 구독자만 설정 가능하고 그 외엔 모든 시각 미디어에 가시 워터마크 자동 적용
- Gemini 앱으로 생성·편집한 모든 AI 미디어에는 비가시 SynthID 워터마크 포함, 가시 워터마크 설정은 SynthID·Content Credentials에 영향 없음
- '유튜브가 워터마크 제거 콘텐츠를 탐지'한다는 주장은 공식 출처로 확인하지 못함

**활용할 때 확인할 점**

- 워터마크 제거 도구 사용은 플랫폼 정책·AI 표시 의무 측면 위험 — 교육에서 권장 금지
- 가시 표시와 비가시 식별(SynthID)을 구분해 설명

**정정과 한계**

'비싼 구독을 해도 가시 워터마크는 못 없앤다'는 부정확 — 한국에서도 AI Ultra 구독자는 가시 워터마크 설정 가능
