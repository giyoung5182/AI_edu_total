### 모바일에서 숫자 자판만 뜨는 입력칸은 HTML input type·inputmode 설정 문제 — 비밀번호는 type="password"로 지정

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- MDN: inputmode 속성은 입력될 데이터 종류를 브라우저에 알려 적절한 가상 키보드를 띄우게 함
- inputmode="numeric"은 숫자(0~9) 키보드, "text"는 현재 언어의 표준 키보드(기본값)
- 따라서 비밀번호 칸에 numeric 계열 설정이 들어가 있으면 모바일에서 영문 자판이 뜨지 않음

**활용할 때 확인할 점**

- 비개발자 교육: 'PC와 모바일이 다르게 동작'하면 화면 요소의 속성(type·inputmode)을 AI에게 확인시키는 질문법 연습
- 증상·기기·기대 동작을 함께 적어 AI에 묻는 템플릿 제공

### AI가 반복하는 실수(예: Windows CRLF)는 지시문이 아니라 hook으로 강제 — Claude Code hook은 매번 결정적으로 실행

원본 상태: 공식확인 · 원본 확인일: 2026-09-29

- Claude Code hook은 수명주기의 특정 시점에 실행되는 사용자 정의 셸 명령으로, LLM이 선택하길 기대하지 않고 특정 동작이 항상 일어나게 하는 결정적 통제 수단
- 예: PostToolUse 이벤트에 Edit|Write 매처를 걸어 편집된 파일마다 Prettier를 자동 실행
- 공식 문서는 '반드시 매번 일어나야 하는 것'은 output style·지시문이 아니라 hook을 쓰라고 구분
- 줄바꿈 통일 자체는 프로젝트 설정(예: 저장 형식 LF 통일)으로 해결하는 것이 일반적

**활용할 때 확인할 점**

- 규칙 분류 교육: 알아야 할 것(CLAUDE.md) / 말투(output style) / 반드시 지킬 것(hook)
- 같은 실수가 두 번 나오면 hook 후보로 기록
