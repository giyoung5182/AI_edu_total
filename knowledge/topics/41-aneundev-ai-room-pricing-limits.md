### Claude Max 20x 배율 과장 광고 주장 소송(Kahn v. Anthropic) 진행 중

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- 미국 캘리포니아 북부 연방지법 사건 Kahn v. Anthropic PBC(3:26-cv-05763). 도켓 기준 2026-06-14 제기, 2026-07-20 수정 소장 제출, 8월 관련사건 병합 신청은 기각. '20x가 5x 대비 약 1.7배'는 원고 측 주장이며 법원 판단 아님. 기각 신청 심문 2026-11-06 예정과 원고 추가 합류 내용은 보도·원고 측 로펌 게시 기준으로, 원본 조사에서 도켓으로 직접 확인하지 못함.
- [추가 2026-09-02] 9/1~9/2 커뮤니티에 소송 요지(Max 20x가 Pro의 6~8배, 5x가 3.5배라는 원고 주장)와 AI로 정리한 법률 설명이 공유됨. 소장이 인용했다는 Sonnet 4 주간 사용시간 추정치는 원문 확인하지 않음. 공식 도움말상 배율은 '세션당' 기준이고 주간 한도는 별도.

**활용할 때 확인할 점**

'제기된 소송' 수준으로만 인용, 확정 판결처럼 서술 금지. 요금제 배율 마케팅에 대한 비판적 리터러시 사례.

### Claude 프롬프트 캐시 기본 수명 5분(1시간 옵션) — 캐시가 깨지면 전체 컨텍스트가 비싼 쓰기 비용으로 재청구

원본 상태: 부분확인 · 원본 확인일: 2026-09-29

- 공식 문서: 캐시 기본 수명은 5분, 추가 비용으로 1시간 수명 선택 가능
- 가격 배수: 5분 캐시 쓰기 1.25배, 1시간 캐시 쓰기 2배, 캐시 읽기 0.1배(기본 입력 단가 대비)
- 따라서 캐시 적중 시 대부분 0.1배로 처리되던 긴 컨텍스트가 캐시 미스 시 쓰기 단가로 다시 계산되어 한 턴 사용량이 크게 뛸 수 있음
- 질문자가 겪은 '더블링'이 캐시 미스인지 버그인지는 공식 확인 불가(개인 버그 리포트 단계)

**활용할 때 확인할 점**

- 긴 세션일수록 자리 비움·모델 전환이 비용을 키우는 원리를 캐시 개념으로 설명
- 사용량이 비정상적으로 빨리 닳으면 세션 로그 분석·버그 리포트 절차 안내

### 구독제는 API 정가 환산 대비 크게 저렴 — API는 대화형이 아닌 캐싱·배치 대량 처리에 맞는 과금 구조

원본 상태: 부분확인 · 원본 확인일: 2026-10-06

- Claude API 캐시 읽기는 기본 입력 단가의 0.1배, 캐시 쓰기는 5분 1.25배·1시간 2배이며 이 배수는 Batch API 할인과 중첩 적용(공식 문서)
- 구독 요금제의 정확한 토큰 환산량은 공개되지 않으므로 '구독 30만원 = API 천만원' 같은 수치는 커뮤니티 추정
- '구독제 적자 운영' 주장은 공식 확인 불가
- [추가 2026-10-02] 기업 현장 체감: 회사가 API 방식으로 개인당 월 $2,000 한도를 줘도 정가가 높아 체감상 $200 구독과 비슷하다는 사례, 대기업은 API 비용 감당이 어렵다는 의견

**활용할 때 확인할 점**

- 비용 판단 기준: 사람이 대화하며 반복 작업하면 구독, 정형화된 대량 처리·서비스 연동은 API(캐싱·배치 설계)
- 간헐적 고급 모델 사용은 API가 유리할 수 있어 사용 패턴별 계산 예시 제공

### Cursor Auto는 무제한이 아님 — 플랜 사용량 풀에서 라우팅된 모델 단가로 차감, 초과분은 on-demand를 켰을 때만 과금

- IDE 요금제 비교 시 '무제한' 표현을 문서로 재확인하도록 교육
- 추가 결제(on-demand) 설정 여부를 월초 점검 항목에 포함

**정정과 한계**

'Cursor는 Auto로 무한 사용'은 원본 확인일의 공식 문서와 다름 — Auto도 플랜 사용량 풀에서 차감
