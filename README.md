## 사용 순서

1. 자신의 업무와 가까운 가이드 또는 예제를 고릅니다.
2. 화면에 적힌 준비물을 가상 데이터로 준비합니다.
3. 예시 요청문을 목적·입력·결과·검수 기준에 맞게 바꿉니다.
4. 정상 입력과 오류 입력을 모두 시험합니다.
5. 저장한 결과를 다시 열어 내용·형식·계산을 대조합니다.

파일 수신, 텍스트 추출/OCR, 규칙 계산, AI 의미 해석은 서로 다른 단계입니다. 규칙 계산기나 화면 시연이 AI 의미 분석을 수행한다고 가정하지 마세요. 실제 실행·공식 문서 확인·코드 확인·설계 제안·미확인은 자료 안에서 구분합니다.

## 지식과 확인 상태

지식 카드의 기존 공식확인·부분확인·커뮤니티경험·정정·미확인 상태를 보존합니다. 과거 제품명·가격·한도·일정은 원 자료의 확인 시점에 관한 기록이며 현재 조건은 공식 출처에서 다시 확인해야 합니다. 이 공개 편집 작업만으로 제품별 최신 검증이나 모든 도구의 전 기능 검증을 완료했다고 표시하지 않습니다.

실명·질문자·대화/질문/댓글 원문·개별 평가·고객사 내부 자료·인증설정은 공개 묶음에서 제외합니다. 가상 예제와 학습용 편집 답변은 실제 사내 정책이나 강사 원문 답변을 대신하지 않습니다.
