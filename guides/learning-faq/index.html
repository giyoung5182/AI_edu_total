AI로 무엇부터 자동화하면 좋을까요?

반복되고, 준비할 자료가 있으며, 맞았는지 사람이 확인할 수 있는 작은 업무부터 고르세요. 업무 전체를 처음부터 자동화할 필요는 없습니다.

  1. 지난주에 반복한 일 세 가지를 적습니다. 자료 취합·양식 맞추기·비교·보고 중 어디에 시간이 드는지 표시하세요.
  2. 한 번 처리할 자료와 원하는 결과의 예시를 준비합니다. 예: 캠페인 엑셀 3개를 같은 열로 합친 표.
  3. 소량 자료로 먼저 만들어 기존 수작업 결과와 비교합니다. 생활 일정 정리처럼 개인 사례로 시작해도 됩니다.
  • 불규칙한 판단이나 최종 승인까지 한 번에 맡기면 검수가 어려워집니다. 확정 판단은 사람이 남겨두세요.

  2. - 항목으로 목록, **글자**로 강조를 표시합니다.
  3. .md로 저장하고 미리보기에서 제목과 줄바꿈이 의도대로 보이는지 확인합니다.
  • 지침 파일이라고 모든 AI가 자동으로 읽는 것은 아닙니다. 파일명과 지원 경로는 도구별로 확인하세요.

은행·카드 계정을 연결해 납부까지 자동화할 수 있나요?
단일 HTML의 파일 읽기 기능만으로 계좌 연결과 납부를 구현할 수는 없습니다. 금융 서비스가 제공하는 인증·권한·거래 기능과 별도의 개발·검토가 필요합니다.
  1. 교육에서는 가상 거래 내역이나 허용된 내보내기 파일을 정리하는 범위로 연습합니다.
  2. 실서비스로 확장한다면 공식 연동과 인증 요구사항을 확인합니다.
  3. 실제 이체·납부는 사용자 확인과 실패 처리까지 별도 설계합니다.
  • 계좌 비밀번호를 HTML에 저장하거나 AI에게 넘기는 방법으로 구현하지 마세요. 개별 서비스의 실제 허용 조건은 이 자료에서 확인하지 않았습니다.
