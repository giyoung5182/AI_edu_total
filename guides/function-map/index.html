Spark는 내 Chrome 대신 원격 브라우저로 작업을 이어 갈 수 있습니다. Mac 폴더·원격 제어는 Mac에서 앱이 실행 중이어야 하고, Antigravity Remote Control은 내 PC가 인터넷에 연결돼 있어야 합니다.

06 · FOLDER WORKFLOW

폴더 구조는 하나로 통일하고, 규칙 파일만 도구에 맞춥니다

업무 폴더 하나를 정리해 연결하는 방식은 세 서비스 모두 똑같이 통합니다. AGENTS.md는 Codex·Antigravity·Jules가 함께 읽는 공통 규칙 파일입니다.

공통 예시: 출장정산 폴더

출장정산_AI/
├─ 규칙 파일          ← 오른쪽 표 참고
├─ input/            ← 이번 회차 원본
├─ reference/        ← 규정·판단 근거
├─ skills/           ← 반복 절차 보관용(이 이름만으로 자동 인식되지는 않음)
├─ work/             ← 중간 파일
└─ output/           ← 최종 결과 (새 파일로)

도구파일자동 인식

WorkAGENTS.md 등확인 필요

자동 인식이 확인되지 않은 도구에서는 “규칙 파일을 먼저 읽고”라고 직접 지시하세요.

초보자 사용 순서 (세 서비스 공통)

  1. 업무 폴더를 따로 만듭니다
    이번 작업에 필요한 자료만 모읍니다. Gemini 공식 도움말도 “잃으면 안 되거나 민감한 파일은 넣지 말라”고 안내합니다.
  2. 필요한 폴더만 연결합니다
    ChatGPT: Work Local·로컬 프로젝트에서 폴더를 열고 필요한 파일만 허용. Claude: 데스크톱 앱에서 폴더 연결. Gemini: Mac 앱에서 Spark에 Mac 폴더 연결(Windows는 공식 문서 미기재), 개발은 Antigravity에서 폴더 열기.
  3. 결과물을 구체적으로 설명하고 맡깁니다
    “규칙 파일을 먼저 읽고, input 파일을 reference 기준으로 검토해 output에 위반 항목 표를 엑셀로 만들어 줘.”
  4. 승인·확인 요청이 뜨면 내용을 읽고 판단합니다
    승인 요청 여부는 도구·동작·권한 모드·관리자 설정에 따라 다릅니다. 자동 허용된 작업은 매번 확인창이 뜨지 않을 수 있습니다.
  5. 결과는 새 파일로 받습니다
  6. 반복 업무는 예약으로 돌립니다
