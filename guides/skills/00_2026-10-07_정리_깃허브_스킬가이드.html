draw-your-font

손글씨 사진 한 장으로 설치 가능한 폰트 만들기
폰트클로드 코드 스킬CLIMIT 라이선스
개요
종이에 쓴 손글씨를 사진으로 찍어 넘기면 그 필체로 폰트 파일을 생성. "둥글게", "굵게" 같은 디테일은 말로 요청해 다듬기 가능(원문).
작동 방식
사진 보정(그림자·기울기 처리) → 글자 하나씩 분리 → 벡터(선)로 변환 → 글자 크기·간격 정리 → 폰트로 묶음. 모든 처리가 내 컴퓨터에서 진행(업로드 없음).
결과물
TTF, WOFF, WOFF2 폰트 파일 + 웹페이지용 CSS 코드. 만든 폰트는 상업적 사용 가능(공식 페이지).
설치
클로드 코드 스킬로 추가: 
npx skills add danilo-znamerovszkij/draw-your-font
또는 터미널에서 직접 사용(CLI): 
# 1) 글자 쓰기용 템플릿 PDF 받기
npx draw-your-font template -o template.pdf --charset minimal
# 2) 손글씨 사진으로 폰트 만들기
npx draw-your-font make photo.jpg --chars "ABCabc" --name "My Hand"
한계
README에 있는 문자 세트는 minimal, spanish 두 가지. 한글은 지원 목록에 없음.
원문 정정 — 원문은 "레포 클론 후 README 따라 설치". 실제 README 안내는 위의 npx 한 줄 방식.

open-image-prompts

프롬프트와 결과 이미지를 짝지어 모은 검색형 자료 창고
이미지 생성프롬프트에이전트 스킬
개요
"저 이미지 뭐로 만든 거지?" 문제를 해결하는 자료 창고. 프롬프트 19,686개, 이미지 34,718장, 시각 분류 라벨 185개(README 기준, 2026.9.29 갱신 — 자료가 자주 늘어남).
두 가지 사용법
  • 웹사이트: 갤러리를 눈으로 구경하고 프롬프트 복사. 설치 불필요.
  • 설치본: 내 컴퓨터에 자료를 받아 두고 AI 에이전트가 직접 검색. 스킬 2종 포함 — img-gen-taste(아트 디렉션), img-gen-prompts(로컬 갤러리 검색).
필요 환경
Git, Node.js 20.19 이상 또는 22.12 이상
설치
git clone https://github.com/NanmiCoder/open-image-prompts.git
cd open-image-prompts
# macOS/Linux
./start.sh
# Windows (파일 탐색기에서 더블클릭도 가능)
start.bat
스킬만 AI 도구에 추가: 
npx skills add NanmiCoder/open-image-prompts -g
포함된 스킬 목록만 보기: npx skills add NanmiCoder/open-image-prompts --list
용량
저장소 자체는 작음(코드만). 데이터베이스 약 80MB, 이미지 전체 약 4.3GB는 선택. DB만 받기: npm run data:pull:db
원문 보완 — Node.js 버전 조건, 스킬 2종 이름, npx skills add 설치 방법은 원문에 없던 내용(README 기준).

claude-quest

클로드 코드 작업을 픽셀아트 RPG 캐릭터로 실시간 표시
클로드 코드재미오프라인 동작
개요
클로드 코드가 일하는 동안 터미널 글자 대신 캐릭터가 행동으로 반응.
동작 대응표
  • 파일 읽기 → 마법 시전 · bash 명령 → 공격 · 코드 작성 → 끄적이기

  • 성공 → 승리 댄스 · 에러 → 데미지(회복됨) · git push → "SHIPPED!" 무지개 배너
화면 요소
마나 바 = 남은 컨텍스트(대화 기억 용량). 사용할수록 모자·얼굴·오라·이동 트레일 코스튬 해금.
설치
npm install -g claude-quest

cq

클로드 코드가 내 컴퓨터에 남기는 대화 기록 파일을 읽어서 표시. API 키·네트워크 연결 불필요.
원문 일치 — 설치·실행 명령, 오프라인 동작, 코스튬 해금 모두 README와 동일.

Finn-loop

아이디어 → 기획 → 개발 → 검수를 AI가 돌리고, 최종 반영만 사람이
클로드 코드GitHubLinear 필요
개요
스킬 3개로 도는 "AI 소프트웨어 공장". 핵심 원칙은 "병합(최종 반영)은 사람이 한다".
3단계 흐름
  • 기획(spec): 대충 적은 아이디어를 질문으로 구체화 → Linear에 작업 항목(완료 기준·제외 범위 포함) 등록

  • 검수(review): PR을 원래 작업 항목과 대조해 판정 의견 작성

사용하기

평소처럼 요청하면 Claude가 필요할 때 자동 사용. 확실히 쓰게 하려면 "○○ 스킬 써서 해줘"처럼 이름을 명시. 일부 화면에서는 /를 입력해 스킬 선택 가능.

업로드 규격 — 스킬 파일 맨 위 정보 중 name(이름)은 64자, description(설명)은 200자 이내. Claude는 이 설명을 보고 언제 스킬을 쓸지 판단. 업로드가 실패하면 ZIP 구조(폴더가 맨 위인지)와 파일 용량부터 확인.
Claude Code와 연동 — claude.ai에서 켠 스킬은 같은 Claude 계정으로 로그인한 Claude Code v2.1.273 이상에서 ~/.claude/skills/synced/로 동기화됩니다. 세션 시작 시 동기화하고 이후 약 10분마다 변경을 확인하며, /skills의 "claude.ai sync"에 표시됩니다. 세션 도중 /login했다면 재시작해야 동기화가 시작됩니다. API 키·Bedrock 인증 등에서는 동기화되지 않습니다 (공식 도움말, Claude Code 문서).

스킬 폴더 복사

SKILL.md가 들어 있는 폴더를 개인 스킬 폴더로 통째로 복사. 예: graph-engineering. 가운데 mkdir -p 줄은 스킬 폴더가 아직 없을 때 만들어 주는 명령(이미 있으면 아무 일도 안 함). 이 줄 없이 폴더가 없는 상태에서 복사하면 파일이 한 단계 위에 풀려 스킬이 인식되지 않음.

git clone https://github.com/codejunkie99/graph-engineering.git
mkdir -p ~/.claude/skills
cp -r graph-engineering/graph-engineering ~/.claude/skills/

~는 내 사용자 폴더(홈 폴더)를 뜻함. .claude처럼 점으로 시작하는 폴더는 기본적으로 숨김 상태.

사용 및 변경 반영

이미 존재하던 skills 디렉터리 안의 SKILL.md 추가·수정·삭제는 현재 세션에서 자동 감지됩니다. 세션 시작 후 최상위 ~/.claude/skills/ 또는 프로젝트의 .claude/skills/를 처음 만든 경우 /reload-skills를 실행하세요. 이때는 이후 변경에도 다시 /reload-skills가 필요합니다. 플러그인의 hooks·MCP·agents 등의 변경에는 /reload-plugins가 필요할 수 있습니다. /skills에서 목록을 확인하고, 자동 사용 또는 /스킬이름으로 호출할 수 있습니다.

개인 폴더(~/.claude/skills/)에만 둔 스킬은 클라우드에서 도는 세션에서는 불러오지 못함 (공식 문서).

5플러그인 설치

andrej-karpathy-skills, agents-council이 제공하는 방식. 터미널이 아니라 클로드 코드 채팅창에 입력.
마켓플레이스 등록

플러그인을 받아올 저장소를 등록하는 단계.

/plugin marketplace add forrestchang/andrej-karpathy-skills
플러그인 설치

등록한 곳에서 실제 플러그인을 설치하는 단계. 형식: 플러그인이름@마켓플레이스이름

/plugin install andrej-karpathy-skills@karpathy-skills
사용·해제

플러그인 속 스킬은 /플러그인이름:스킬이름으로 호출. 해제는 /plugin 메뉴에서 끄거나 /plugin uninstall 플러그인이름@마켓플레이스이름.

6CLAUDE.md 규칙 파일

andrej-karpathy-skills가 제공하는 또 다른 방식.
프로젝트 폴더로 이동

터미널에서 cd 프로젝트폴더경로

규칙 파일 내려받기

curl -o 파일이름 주소 = 인터넷 주소의 파일을 지정한 이름으로 저장.

curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

이미 CLAUDE.md가 있으면 이 명령이 덮어씀 → 기존 파일이 있다면 내용을 직접 합칠 것.
