# 명령어·스킬·프롬프트 별칭 구분하기

정리일·공식 문서 확인일 2026-10-08. [OpenAI 공식 슬래시 명령 설명](https://learn.chatgpt.com/docs/reference/slash-commands).

공식 문서 표에는 현재 28개 명령이 있습니다. 환경·접근 권한에 따라 보이는 항목은 달라집니다. 설치된 스킬과 사용자 정의 프롬프트가 더 표시될 수도 있어 전체 메뉴 개수와 공식 표의 개수는 같다고 가정하지 않습니다. 소개문에 나온 공식24개·비공식76개의 원 정리본은 미열람 상태입니다.

| 종류 | 확인 방법 | 교육에서 설명할 것 |
|---|---|---|
| 공식 앱 동작 | 공식 문서와 현재 앱 메뉴 | 새 작업·모드·설정 등의 실제 기능 |
| 설치된 스킬 | 실제 스킬 파일과 메뉴 | 설치 범위·입력·권한·결과 |
| 사용자 프롬프트 | 내가 정의한 요청문 | 목표·형식·말투의 별칭 |

예를 들어 '표로'는 일반 요청입니다. '/내별칭'도 앱에 등록되지 않았다면 그 자체로 공식 동작이나 숨은 기능을 만드는 코드가 아닙니다. 반복해서 쓰는 별칭은 다음처럼 의미를 명시해 보관하세요.

```text
별칭: 비교표
목적: 제공한 두 자료를 같은 기준으로 비교
입력: 두 자료와 비교 기준
출력: 기준/자료A/자료B/근거/미확인 표
금지: 입력에 없는 값을 채우거나 접근 권한을 추정하지 않음
```

이 자료에서는 명령을 실행하거나 앱 설정을 바꾸지 않았습니다. 같은 이름이 다른 앱에서 다른 의미로 쓰일 수 있으니 제품·환경·확인일을 함께 기록하세요.
