# 지식 수신·검증·동기화를 운영하기

정리일: 2026-10-08. 소스 버전: 2026-10-07 통합 갱신 규칙, 영향 대상 등록부, 팀 운영 및 화면 통합 검사. 조직·계정·예약 ID를 제거한 범용 편집본입니다.

자료를 받거나 오류를 발견하면 `접수 → 조사 → 수정 → 검증 → 동기화 → 완료`로 처리합니다. 입력 종류는 설문, 질문/댓글, 제출 소개, 실제 결과물, 참고자료, 공식 변경, 스킬·라이브러리, 오류, 수시 요청으로 나눕니다. 자료가 오지 않은 부분은 미수신으로 두고 받은 자료부터 처리합니다.

원본은 복사 보존합니다. 수신 등록부에는 종류, 차수, 수신일, 원본 파일명, SHA256, 버전, 작성일 근거를 남깁니다. 같은 종류·차수·해시의 재수신은 중복 처리하고, 내용이 바뀌면 새 버전으로 보존합니다. 해시 일치는 바이트 일치의 근거이며 자료 내용이 사실이라는 증거는 아닙니다.

수정 전에 영향표를 만듭니다.

| 입력 | 정리 데이터 | 설명/화면 | 배포 |
| --- | --- | --- | --- |
| 설문 | 문항·응답 집계 | 강사용 분석 | 비공개 결과 |
| 질문·댓글 | 질문/답변·편집 상태 | 학습 FAQ | 익명 편집본 |
| 주제·결과물 | 사례 ID·확인 수준 | 업무별 가이드 | 허용된 설명·예시 |
| 공식 변경 | 출처·날짜·영향 기능 | 관련 기능 안내 | 해당 페이지 |
| 오류 | 재현 입력·수정·검증 | 해당 도구·템플릿 | 관련 사본·ZIP |

역할을 나누면 총괄은 범위와 통합, 근거 담당은 출처와 해석, 제작 담당은 수정, 독립 검증 담당은 실행·대조, 자료 담당은 버전·사본을 맡습니다. 위임에는 목표·기준 버전·입력·허용 파일·출력·검증·금지 범위를 적습니다. 같은 파일과 생성기 입력·출력을 동시에 둘이 고치지 않습니다.

배포물마다 기준 경로를 하나 정하고 제작본·열람 사본·웹 사본·ZIP을 연결합니다. 오래된 생성기를 실행해 최신 편집을 지우지 않도록 현재 제작 경로와 보완 패치를 기록합니다. 경로만 다르다고 같은 버전으로 가정하지 않습니다.

화면 검수는 배열 개수에서 끝나지 않습니다. 요약의 범위, 차수 필터, 업무 분류, 검색, 상세 연결, 중복 메뉴를 실제로 확인합니다. 구 입구는 통합 화면으로 연결하고 새 차수만 검색에서 빠지지 않았는지 검사합니다. 로컬 수정·배포 파일 변경·원격 확인의 완료 상태를 따로 남깁니다.

반복 점검을 요청받았다면 기존 예약을 먼저 확인합니다. 출처별 발표일·문서 변경일·확인일을 분리하고 접근 실패도 기록합니다. 기준 내용을 처음 확보한 상태를 전체 팩트체크 완료라고 쓰지 않습니다. 설치·업그레이드·전체 재생성을 점검만으로 자동 실행하지 않습니다.

다음 작업자에게는 현재 기준본, 승인 범위, 바뀐 파일, 완료 근거, 미수신, 미확인을 전달합니다. 날짜가 붙은 인수인계 문서는 현황 지도이므로 최신 파일·시험 기록과 함께 읽습니다.
