# 이미지 갤러리에서 재사용 가능한 프롬프트 만들기

정리일 2026-10-08 · 새 작성 교육 절차. 소개된 원문 전체·갤러리 수량·모든 이미지의 사용권을 확인한 자료가 아닙니다.

참고: [소개된 갤러리](https://gpt-image2.canghe.ai/) · [원 정리본 링크](https://app.notion.com/p/3c5fd99f0e5f810b9304c49637de0ebd).

마음에 드는 이미지가 있다면 먼저 구도·색·빛·텍스트·소재를 나눠 메모합니다. 원문을 통째로 복사한 공개 모음을 만들기 전에 그 프롬프트·이미지의 출처와 이용 조건을 확인하세요.

## 갈래와 선택 기준

제품 광고(특징·배치), 인물(표정·빛), 정보 카드(글자·구조), 공간(시점·재질), 스타일 변환(유지할 요소) 중 목적에 맞는 갈래를 고릅니다. 이 분류는 새 작성이며 소개문에 나온 중국어 13갈래의 공식 번역이 아닙니다.

```text
[목적] 가상 제품의 교육용 광고 이미지
[대상] 내가 사용할 권한이 있는 가상 제품 사진
[유지] 형태·비율·색·로고 없는 표면
[변경] 배경·조명·카메라 시점
[구도] 중앙 제품, 위쪽 제목 공간, 아래쪽 설명 공간
[문구] 정확히 넣을 짧은 문장 또는 글자 없이 생성
[금지] 실제 브랜드 로고·새 제품 기능·허위 인증 표시
[출력] 가로세로 비율·필요 해상도
```

한 번에 한 요소를 바꿔 A/B 결과를 비교하고, 사용한 도구·모델·날짜·입력·프롬프트·결과·검수 항목을 기록합니다. 제품 형태가 유지되는지, 문구가 정확한지, 작은 크기에서도 읽히는지 검사합니다.

갤러리의 수량은 수집 시점과 필터에 따라 달라질 수 있습니다. 현재 데이터는541기록·22템플릿이며, 원 노션의21틀은 초보자용으로 고른21개입니다. 소개문523장은 현재 전체 수량으로 쓰지 않습니다. [원문 읽기와 정정](../references/source-reading/image-gallery.md)을 확인하고, 모델명과 결과 품질은 계정별 실제 실행 확인을 따로 기록합니다.
