# 자료 수집: 요약·분류·판단을 나눠 기록하기

정리일 2026-10-08 · 새 작성 절차. [공유된 글](https://seo2-heimish.tistory.com/20)은 카드뉴스 제작 글이 아니라 Jev 분류·판단 활용 글입니다. [TypeSafe 공식 시작 문서](https://docs.typesafe.ai/introduction/quickstart) · [Browser Use 공개 예제](https://github.com/browser-use/jev-ultrafast).

가상 자료 5개가 준비됐다면 제목·요약·원문 URL을 한 행으로 저장합니다. 다음 단계에서 주제 하나를 선택하고, 실제 결과물 유무·구체적 절차 유무·현재 사용 조건은 별도 질문으로 판단합니다. 요약에 없는 정보를 추측해서 분류 근거로 쓰지 않습니다.

```text
제공된 행마다 주제를 하나 고르세요: 제품발표/사용법/실제사례/연구/기타.
이어서 실제 결과 파일이 제시됐는지, 재현 절차가 있는지를 별도로 답하세요.
각 판단에 입력에서 확인한 근거와 부족한 정보를 붙이세요.
원문URL·자료ID를 유지하고, 처리 실패를 기타로 숨기지 마세요.
```

이 요청은 일반 AI에서도 분류 절차를 시험할 수 있는 교육예시입니다. Jev API를 연결하거나 브라우저를 실제 조작하는 구현이 아닙니다. API 도입은 승인 상태·키·비용·허용 환경을 별도로 확인합니다.

검수: 입력5행과 결과5행, 자료ID·원문URL 보존, 허용된 주제값, 근거 없는 판단의 미확인 표시, 중복과 실패 상태를 확인합니다. 출처의 속도·비용 사례는 외부 제작자의 보고이며 이번 작업에서 측정하지 않았습니다.
