# 근거에 맞춰 교재를 최소 범위로 고치기

정리일: 2026-10-08. 소스 버전: 2026-10-07 최소 교체 목록·위치 검증·추가 개선 근거. 원교재는 수록하지 않았습니다.

수업 피드백이 준비됐다면 현재 기준본과 사용자 결정부터 확인합니다. 과거의 광범위한 검토안, 최신 교체 후보, 실제 적용본을 각각 구분합니다. 검토안이 만들어졌다는 것만으로 적용 완료라고 설명하지 않습니다.

검토한 사례의 현재 범위는 핵심 6묶음·21곳, PART02~06입니다. 이전 132곳 계획은 보류됐으며 원본 적용 여부를 기록한 검증 파일은 `false`입니다. 이 수치는 해당 시점의 범위 예시이며 다른 수업의 필수 수정량이 아닙니다.

| 문제 묶음 | 고칠 내용 | 다음 단계와 연결 |
| --- | --- | --- |
| 입력 형식과 확장 한계 | CSV, 직접 문서 읽기, 사전 의미 분석을 구분 | 도구가 읽을 항목과 사람이 확인할 항목 결정 |
| 단계 번호와 누락 실습 | 안내 번호를 실제 본문과 맞춤 | 초보자가 준비·실행 순서를 따라감 |
| 중복 요청문 | 동일 인터뷰 지시의 불필요한 반복 제거 | 같은 입력을 두 번 만들지 않음 |
| 완성 기준 | 구현에 맞춰 기준만 낮추는 지시 보완 | 최초 요구와 결과를 대조 |
| HTML·데이터 백업 | 도구 파일과 저장 기록을 각각 백업 | 새 환경에서 복원 확인 |
| Skill 준비와 파일명 | 실제 준비 조건과 산출물 이름 확인 | 설치 가정으로 실습이 멈추지 않음 |

교체안 한 건에는 `기준본 버전 / 찾을 제목·문구 / 현재 문제 / 제한된 교체 문구 / 근거 / 앞뒤 단계 연결 / 적용 여부`를 적습니다. 줄 번호는 파일이 바뀌면 달라지므로 찾을 문구와 함께 씁니다.

검증 단계에서는 기존 예제·시간·순서가 유지되는지, 설명과 실제 기능이 맞는지 확인합니다. 추가 설치·새 API·서버·실습 확대는 별도 범위 결정이 필요합니다. 다른 PART의 수정 가이드를 현재 PART에 자동으로 확장하지 않습니다.

초보자 안내에는 목적, 준비할 파일, 행동 순서, 결과, 검수 방법을 넣습니다. '입력은 이미지입니다'보다 '이미지가 준비됐다면 파일을 고르고, 추출된 글자를 원문과 비교하세요'처럼 실제 행동을 설명합니다.
