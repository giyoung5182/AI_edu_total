# 카드뉴스·썸네일·PPT 제작을 하나의 프로젝트로 묶기

정리일 2026-10-08 · 사용자 공유 자료에서 얻은 주제에 대한 새 작성 설계. 언급된 PDF·XLSX 원문을 확보한 것으로 표시하지 않습니다.

## 마스터 시트가 준비됐다면

필수 열을 content_id, source_id, source_url, fact, headline, body, audience, visual_brief, status, reviewer, version으로 정합니다. 사실(fact)과 광고용 문구(headline/body)를 분리하고, 한 행이 한 카드인지 한 콘텐츠인지 명확히 정하세요. 승인된 행만 제작 대상으로 고릅니다.

```text
이 마스터 시트의 승인 행만 읽어 카드별 문안 초안을 만들어 주세요.
원 사실과 source_id를 유지하고, 빠진 필드는 확인 필요로 표시하세요.
카드별 headline·body·visual_brief·검수 항목을 출력하세요.
원본 시트를 덮어쓰지 말고 새 버전 파일로 저장하세요.
```

문안 → 사실 검수 → 이미지 시안 → 레이아웃 → 저장·재열기 → 배포 순서로 진행합니다. 중복 content_id, 누락 출처, 장문·글자 잘림, 승인 안 된 행을 오류 입력으로 시험하세요.

## 썸네일로 확장

본문에서 중심 주장 하나와 짧은 제목을 추출하고 2가지 시안을 비교합니다. 원문보다 강한 주장, 확인 안 된 수치, 실제 브랜드 자산을 추가하지 않습니다. 작은 화면·긴 제목·밝은 배경에서 대비를 검사합니다.

## PPT 스킬로 확장

스킬 입력은 목적·청중·발표 흐름·슬라이드 수·브랜드 규칙·참고자료로 정합니다. 출력은 PPTX와 슬라이드별 출처·미확인 목록입니다. 글자·표·도형이 편집 가능한지와 이미지로 굳었는지를 구분하세요.

```text
제공한 검수 완료 문안으로 교육용 5장 PPT 초안을 설계하세요.
각 장에 핵심 메시지 하나, 근거, 발표자 메모를 넣으세요.
편집 가능한 글자·표·도형과 이미지로 넣은 요소를 구분하세요.
저장한 PPT를 다시 열어 글자 잘림·폰트·출처·수치·페이지 순서를 검사하세요.
실제 파일을 만들거나 재열기를 하지 못했으면 설계안으로 표시하세요.
```

가상 데이터로 먼저 한 장을 제작해 폰트·비율·편집·재열기를 확인한 뒤 전체에 적용합니다. 이 문서 자체는 자동화 에이전트나 PPT 생성 스킬 구현·실행 결과가 아닙니다.
