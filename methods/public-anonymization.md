# 내부 지식을 공개용 문서로 편집하기

정리일: 2026-10-08. 소스 버전: 배포 익명화 검사와 실제 공유 HTML 코드 대조 기록의 2026-10-07~08 시점. 개인정보 원문과 식별자 대조표는 수록하지 않습니다.

공개 목적을 먼저 정합니다. 같은 업무를 따라 할 수 있게 만드는 것이 목적이라면 개인 사례의 이름을 가리는 데서 끝내지 않고 준비 자료·처리 방법·검수 조건을 범용으로 다시 작성합니다. 실명만 제거해도 특이한 업무, 소속, 개별 점수, 긴 직접 인용이 남으면 누구인지 추정될 수 있습니다.

공개본에서 제거할 항목은 실명, 연락처, 사용자·계정 ID, 개인 경로, 내부 URL, 서명된 다운로드 주소, 예약 ID, 개별 점수와 평가, 고객 자산, 대화 원문입니다. 직무를 추론해 특정 소속으로 확정하지 않습니다. 예시는 새 가상 데이터로 만들고 원문을 가상 데이터처럼 표시하지 않습니다.

문서 편집은 다음 순서로 진행합니다.

1. 재사용할 지식과 공개 목적을 고릅니다.
2. 개인·회사·내부 맥락을 걷어내고 입력·행동·결과·검수로 다시 씁니다.
3. 직접 인용을 의미 요약으로 바꾸고, 편집된 답변을 원저자의 답변으로 표시하지 않습니다.
4. 원본 자산·외부 글·소프트웨어의 권리를 확인합니다. 접근 가능하거나 설치됐다는 사실만으로 재배포를 허용하지 않습니다.
5. HTML 본문뿐 아니라 스크립트, JSON, 주석, 파일명, 링크, ZIP 안 파일을 검사합니다.
6. 새 창에서 공개본을 열고 외부 링크와 필요한 자료가 실제로 연결되는지 확인합니다.

공유 데이터는 허용목록으로 만듭니다. 예를 들어 `업무 유형 / 가상 입력 / 단계 / 한계 / 확인 수준`만 내보내고 내부 객체에서 일부 필드를 삭제하는 방식에만 기대지 않습니다. 저장용 백업과 공유용 파일의 목적이 다르면 출력 구조도 구분합니다.

공개 편집 기록에는 정리일, 출처 버전, 추출 주제, 제거 범주, 변경 파일, 검사 방법, 남은 미확인을 남깁니다. 원본 대조표·원본 해시와 내부 경로는 별도 비공개 기록으로 보관할 수 있습니다. 이름 후보 검색이 0건이어도 모든 개인정보가 없다는 보장은 없으므로 내용 검토와 함께 사용합니다.
