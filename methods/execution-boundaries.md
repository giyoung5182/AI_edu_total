# 실행 환경을 나누고 실패 조건을 설명하기

정리일: 2026-10-08. 소스 버전: 파일 읽기·영상·와이어프레임·실제 제출 도구 검토 및 2026-10-08 스킬 설치 기록. 환경별 설계 원칙이며 특정 제품의 최신 지원 표가 아닙니다.

| 환경 | 처리할 일 | 따로 확인할 조건 |
| --- | --- | --- |
| 브라우저 단일 HTML | 파일 선택, 로컬 파싱·규칙 비교, 미리보기, 다운로드 | 지원 형식, 외부 라이브러리 수신, 저장·복원, 브라우저 정책 |
| 숙련자 로컬 처리 | 여러 파일 변환·집계, 설치 라이브러리, 출력 구조 검사 | 런타임, 경로, 버전, 오류 로그, 대응 앱 재열기 |
| 서버 연결 | 엔진 계산, 장시간 작업, 공동 저장 | 서버 코드 수신, API 경로, 계정, 배포 환경 |
| 외부 AI/API/MCP | 의미 분류·번역 비교·연결 도구 호출 | 승인된 전송 범위, 인증, 비용, 가용성, 실제 호출 결과 |

파일 수신, 글자 추출, 계산, 의미 해석은 분리합니다. PDF가 이미지로만 되어 있으면 텍스트 파서만으로 충분하지 않을 수 있습니다. OCR 결과에는 누락·오인식이 있을 수 있으므로 원문과 비교합니다. 한 가지 엑셀 구조를 읽은 직접 파서는 수식·병합·이미지를 포함한 모든 문서를 지원한다는 뜻이 아닙니다.

외부 페이지는 로그인·접근 권한·교차 출처 정책 때문에 읽지 못할 수 있습니다. 읽지 못한 이유를 그대로 기록하고 접근 제한을 우회해 성공했다고 하지 않습니다. 영상 컷 처리와 광고 의도 분석, 이미지 영역 배치와 번역 품질 판단도 별도 기능입니다.

실패에서 배우려면 가상 입력으로 파일 형식 불일치, 빈 파일, 필수 ID 누락, 숫자 오류, 서버 미연결을 확인합니다. 수정 루프는 오류·수정·재시험을 남기고 시도 횟수나 종료 기준을 정합니다. 경고를 없애려고 완성 기준만 낮추지 않습니다.

스킬이 설치되고 형식 검사를 통과해도 의존 CLI·서버·API가 실제 작동한다고 볼 수 없습니다. 프로그램 소스를 내려받은 상태, 설치 완료, 실제 실행, 생성 결과 재열기를 따로 기록합니다. 플랫폼·계정·요금·현재 기술 사실은 사용할 때 공식 출처로 다시 확인합니다.
