# 새 차수 설문을 기존 분석에 추가하기

정리일: 2026-10-08. 소스 버전: 2026-10-07 차수별 만족도 갱신 규칙과 원본 대조 기록. 실제 응답·평가 점수는 공개하지 않고 분석 절차만 편집했습니다.

설문 파일이 준비됐다면 파일명만 보고 차수를 정하지 않습니다. 시트 이름, 교육일, 응답일, 헤더를 함께 읽고 자료 종류를 확인합니다. 일차 피드백과 종합 만족도는 별도 응답 집합으로 관리합니다.

1. 원본을 복사 보존하고 SHA256, 수신일, 파일 버전, 차수, 설문 종류, 시트명, 응답 행 수를 등록합니다. 같은 해시의 재수신은 이중 집계하지 않습니다.
2. 문항 ID에 실제 헤더, 질문 의도, 선택지, 척도를 연결합니다. 변경·신규·삭제 문항을 표로 비교합니다. 기존 코드의 고정 열 번호를 그대로 쓰지 않습니다.
3. 문항별 유효 응답 수와 무응답 수를 셉니다. 중복 판정 키가 없으면 '응답 건수'라고 표시합니다. 다른 설문의 응답 수를 더해 고유 참여자 수라고 쓰지 않습니다.
4. 같은 의미와 같은 척도인 문항만 추세로 비교합니다. 5점과 10점 척도를 직접 평균내지 않습니다. 변환 비교가 필요하면 원점수와 변환식을 나란히 남깁니다.
5. 수정된 차수만 교체하고 기존 차수는 유지합니다. 결측·미수집·미제출·0점을 구분합니다. 자료가 없는 차수를 0점으로 넣지 않습니다.
6. 정성 의견은 코딩 기준과 버전을 남깁니다. 직접 의견, 편집 요약, 해석, 개선 제안을 분리합니다. 공개 문서는 개인 인용 대신 식별 가능성을 줄인 주제 요약을 사용합니다.
7. 독립 담당자가 행 수, 문항별 분모, 누락, 차수, 합계·평균을 원본과 다시 대조합니다. 불일치는 확정 추세에 반영하기 전에 해결합니다.

가상 예: 두 설문에서 각각 20건과 18건이 수신돼도 참여자가 38명이라고 결론낼 수 없습니다. 같은 사람이 둘에 답했을 수 있고 일부가 무응답일 수 있습니다. 문항 평균 옆에는 해당 문항의 유효 응답 수를 표시합니다.

보고 결과에는 추가·수정된 문항, 비교 가능한 범위, 수치가 바뀐 이유, 남은 미확인을 포함합니다. 집계 완료, HTML 수정, 게시 완료를 별도 상태로 관리합니다. 이 절차 문서 자체가 신규 차수 분석을 실행한 증거는 아닙니다.
